# --description--

Napiš funkce `sum(items)` a `average(items)`.

# --hints--

`sum([1, 2])` vrátí `3`.

```js
assert.equal(sum([1, 2]), 3, 'sum([1, 2]) má vrátit 3');
```

`average([2, 4])` vrátí `3`.

```js
assert.equal(average([2, 4]), 3, 'average([2, 4]) má vrátit 3');
```

`stats([1, 3])` vrátí objekt se součtem a průměrem.

```js
assert.deepEqual(stats([1, 3]), { sum: 4, average: 2 }, 'stats([1, 3]) má vrátit { sum: 4, average: 2 }');
```

# --solution--

## --file-- script.js

```js
function sum(items) {
  return items.reduce((total, item) => total + item, 0);
}

function average(items) {
  return sum(items) / items.length;
}

function stats(items) {
  return { sum: sum(items), average: average(items) };
}
```
