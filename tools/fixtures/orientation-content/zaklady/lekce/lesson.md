# Lekce s obsahem

Úvodní odstavec lekce. **Proměnná neobsahuje pole, ale odkaz na něj.**

## První část

Text první části s `inline kódem` a odstavcem, kterému jde nerozumět.

> [!REMEMBER]
> **Zapamatuj si:** index se počítá od nuly.

## Druhá část

Text druhé části.

```js
const a = [1, 2, 3];
console.log(a === a);
```

### Podčást druhé části

Ještě trochu textu, aby se dalo posouvat.

## Třetí část

> [!PITFALL]
> `sort()` bez porovnávací funkce řadí čísla jako text.
