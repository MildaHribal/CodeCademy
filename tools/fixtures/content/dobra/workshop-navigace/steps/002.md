# --description--

Přidej do pravidla pro `nav` mezeru `gap: 1rem`.

# --hints--

Pravidlo `nav` má mít `gap: 1rem`.

```js
assert.equal(helpers.cssRule('nav')?.gap, '1rem');
```

# --seed--

## --file-- index.html

```html
<!DOCTYPE html>
<html lang="cs">
  <head>
    <meta charset="utf-8">
    <link rel="stylesheet" href="styles.css">
  </head>
  <body>
    <nav><a href="#">Domů</a><a href="#">Kontakt</a></nav>
  </body>
</html>
```

## --file-- styles.css

```css
body { margin: 0; }

nav { display: flex; }
```

# --solution--

## --file-- styles.css

```css
body { margin: 0; }

nav { display: flex; gap: 1rem; }
```
