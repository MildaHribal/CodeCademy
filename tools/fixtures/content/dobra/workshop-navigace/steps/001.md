# --description--

Nastav navigaci `nav` na flex kontejner: `display: flex`.

# --hints--

Prvek `nav` má mít `display: flex`.

```js
assert.equal(getComputedStyle(document.querySelector('nav')).display, 'flex');
```

Pravidlo pro `nav` má být přímo v `styles.css`.

```js
assert.equal(helpers.cssRule('nav')?.display, 'flex');
```
