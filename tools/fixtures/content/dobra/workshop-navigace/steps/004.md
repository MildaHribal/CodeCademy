# --description--

Odkazy v navigaci mají mít tmavě modrou barvu `rgb(0, 80, 160)`. Barvu nastav jen odkazům uvnitř navigace.

# --hints--

Odkaz v navigaci má barvu `rgb(0, 80, 160)`.

```js
assert.equal(getComputedStyle(document.querySelector('nav a')).color, 'rgb(0, 80, 160)', 'odkaz v nav má mít barvu rgb(0, 80, 160)');
```

# --help--

## --tip--

Potřebuješ selektor potomka: prvek uvnitř jiného prvku.

## --tip--

Stejný tvar má pravidlo pro odstavce v patičce: `footer p { color: gray; }`.

```js
// Skript navigace
for (const link of document.querySelectorAll('nav a')) {
  if (link.textContent === 'Domů') {
    link.classList.add('is-active');
  }
}
```

# --solution--

## --file-- styles.css

```css
body { margin: 0; }
a { color: black; }
nav { display: flex; gap: 1rem; }
nav a { color: rgb(0, 80, 160); }
```

# --explain--

Vysvětli, proč pravidlo `nav a` přebije pravidlo `a`.

## --model--

Selektor `nav a` má vyšší specificitu než `a`, proto vyhraje.

## --checklist--

- `nav a` je specifičtější než `a`.
- Specifičtější pravidlo vyhraje bez ohledu na pořadí.
