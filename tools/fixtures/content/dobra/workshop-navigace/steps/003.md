# --description--

Seřaď řádky tak, aby odkaz „Domů" dostal třídu `is-active`. Jeden řádek je navíc.

# --hints--

Odkaz „Domů" má třídu `is-active`.

```js
assert.ok(document.querySelector('nav a').classList.contains('is-active'), 'odkaz Domů má mít třídu is-active');
```

Odkaz „Kontakt" třídu `is-active` nemá.

```js
assert.ok(!document.querySelectorAll('nav a')[1].classList.contains('is-active'), 'odkaz Kontakt nemá mít třídu is-active');
```
