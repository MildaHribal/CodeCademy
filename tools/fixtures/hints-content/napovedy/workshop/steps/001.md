# --description--

Napiš funkci `sum(a, b)`, která vrátí součet dvou čísel.

# --hints--

`sum` je funkce.

```js
assert.equal(typeof sum, 'function', 'sum má být funkce');
```

`sum(2, 3)` vrátí `5`.

```js
assert.equal(sum(2, 3), 5, 'sum(2, 3) má vrátit 5');
```

# --help--

## --tip--

Jde o funkci s návratovou hodnotou, viz [Sčítání čísel](see:napovedy/vyklad#scitani-cisel).

## --tip-- 2

Výsledek vrať příkazem `return` a použij operátor pro sčítání.

## --tip--

Stejný tvar má násobení: `function times(x, y) { return x * y; }`.
