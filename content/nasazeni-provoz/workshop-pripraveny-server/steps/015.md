# --description--

Poslední díra: klient s velmi pomalým připojením posílá tělo rezervace minutu.
`server.close` na něj poctivě čeká, jenže správce procesů po limitu pošle `SIGKILL`.
Proces zemře uprostřed práce a v logu nezůstane ani stopa, proč.

**Úkol:** když se po `SIGTERM` server nestihne ukončit do `shutdownTimeoutMs`
z konfigurace (proměnná `SHUTDOWN_TIMEOUT_MS`), zapíše přes logger řádek s úrovní
`error` a skončí s kódem `1`. Když se ukončí včas, pojistka nic nezdrží a proces
skončí s kódem `0` hned.

Limit nastav na hostingu o kousek kratší, než čeká správce procesů (Docker 10 s,
výchozí 8 s tedy sedí), ať pojistka stihne zapsat svůj řádek.

## Co jsi postavil

Z API, které fungovalo jen na notebooku, je služba připravená na hosting i Docker:

- nastavení z prostředí na jednom místě a rychlé selhání bez povinné konfigurace,
- health check, který ověří databázi a nevyzradí podrobnosti,
- strukturované logy s úrovněmi, skrytými tajemstvími a řádkem na každý požadavek,
- request id v hlavičce, v logu i v chybové odpovědi,
- korektní ukončení, které nechá doběhnout rozpracované rezervace, neuvázne na
  keep-alive spojení a má pojistku s limitem.

Přesně tohle hlídají hostingové platformy a Docker. V lekci o kontejnerech uvidíš,
jak takovou službu zabalit do image a spustit vedle databáze.

## Udělej po svém

- **Vzhled logu:** když `NODE_ENV` není `production`, vypisuj řádky barevně a čitelně
  pro člověka, v produkci dál JSON. Rozhodnutí patří do `createLogger`.
- **Připravenost:** přidej `GET /ready`, která během vypínání vrací `503`, aby
  proxy přestala posílat nové požadavky dřív, než server zavře port.
- **Metrika:** počítej odpovědi `5xx` a vystav jejich počet na `GET /metrics`.
- **Tvoje téma:** stejné provozní vybavení přidej API, které máš ve vlastním projektu.

Když rozpracovaný požadavek nedoběhne do `SHUTDOWN_TIMEOUT_MS`, proces zapíše řádek s úrovní `error` a skončí s kódem `1`.

```js
const { spawn } = await import('node:child_process');
const http = await import('node:http');
const net = await import('node:net');
const port = await new Promise((resolve) => {
  const probe = net.createServer().listen(0, '127.0.0.1', () => { const { port } = probe.address(); probe.close(() => resolve(port)); });
});
const child = spawn(process.execPath, ['server.js'], { cwd: helpers.dir, env: { ...process.env, PORT: String(port), SHUTDOWN_TIMEOUT_MS: '600' }, stdio: ['ignore', 'pipe', 'pipe'] });
let output = '';
child.stdout.on('data', (chunk) => { output += chunk; });
child.stderr.on('data', (chunk) => { output += chunk; });
const exited = new Promise((resolve) => child.on('exit', (code) => resolve(code)));
const get = (path) => new Promise((resolve, reject) => {
  http.get({ host: '127.0.0.1', port, path, agent: false }, (res) => { res.resume(); res.on('end', () => resolve(res.statusCode)); }).on('error', reject);
});
let req;
try {
  await helpers.waitFor(() => get('/health').then((status) => status === 200), 5000)
    .catch(() => assert.fail(`Server nenastartoval. Výstup:\n${output}`));
  // Klient začne posílat rezervaci a tělo už nedošle.
  req = http.request({ host: '127.0.0.1', port, method: 'POST', path: '/api/rentals', agent: false, headers: { 'Content-Type': 'application/json' } });
  req.on('error', () => {});
  req.write('{"bikeId": 1, ');
  await helpers.wait(300);
  child.kill('SIGTERM');
  const code = await Promise.race([exited, helpers.wait(3000).then(() => 'stále běží')]);
  assert.equal(code, 1, `S SHUTDOWN_TIMEOUT_MS=600 a nedokončeným požadavkem má proces do 3 s skončit s kódem 1. Výstup:\n${output}`);
  const parse = (line) => { try { return JSON.parse(line); } catch { return null; } };
  const errorLine = output.split('\n').map(parse).find((item) => item?.level === 'error');
  assert.ok(errorLine, `Před koncem s kódem 1 má logger zapsat řádek s úrovní error. Výstup:\n${output}`);
} finally {
  req?.destroy();
  child.kill('SIGKILL');
}
```

## --tip--

Proč proces po `SIGTERM` potřebuje vlastní časovač, je v pasti v části
[SIGTERM: korektní ukončení](see:nasazeni-provoz/produkcni-rezim#sigterm-korektni-ukonceni).

## --tip--

Časovač patří do obsluhy `SIGTERM` vedle `server.close`. Aby sám nedržel proces
naživu, když všechno skončí včas, má časovač v Node metodu `unref`.

```js
  server.close(() => {
    db.close();
    process.exit(0);
  });
```

```js
import { randomUUID } from 'node:crypto';

// HTTP API půjčovny kol. Server (server.js) sem posílá každý požadavek.

async function readJson(req) {
  let body = '';
  for await (const chunk of req) body += chunk;
  return JSON.parse(body);
}

export function createApp({ db, logger, isShuttingDown = () => false }) {
  function sendJson(res, status, data) {
    if (isShuttingDown()) {
      // Během vypínání spojení po odpovědi zavři, ať keep-alive nedrží proces naživu.
      res.setHeader('Connection', 'close');
    }
    res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
    res.end(JSON.stringify(data));
  }

  async function handle(req, res) {
    const { pathname } = new URL(req.url, 'http://localhost');

    if (req.method === 'GET' && pathname === '/health') {
      try {
        db.prepare('SELECT 1').get();
        return sendJson(res, 200, { status: 'ok' });
      } catch {
        return sendJson(res, 503, { status: 'error' });
      }
    }

    if (req.method === 'GET' && pathname === '/api/bikes') {
      const bikes = db
        .prepare('SELECT id, name, type, station, price_per_day AS pricePerDay FROM bikes ORDER BY id')
        .all();
      return sendJson(res, 200, bikes);
    }

    if (req.method === 'POST' && pathname === '/api/rentals') {
      let input;
      try {
        input = await readJson(req);
      } catch {
        return sendJson(res, 400, { error: 'Tělo požadavku není platný JSON.' });
      }
      const bikeId = Number(input?.bikeId);
      const days = Number(input?.days);
      const customerName = String(input?.customerName ?? '').trim();
      if (!Number.isInteger(bikeId) || !Number.isInteger(days) || days < 1 || customerName === '') {
        return sendJson(res, 400, { error: 'Vyplň kolo, jméno a počet dní (aspoň 1).' });
      }
      const bike = db.prepare('SELECT id, price_per_day AS pricePerDay FROM bikes WHERE id = ?').get(bikeId);
      if (!bike) {
        return sendJson(res, 404, { error: 'Takové kolo v půjčovně nemáme.' });
      }
      const result = db
        .prepare('INSERT INTO rentals (bike_id, customer_name, days, created_at) VALUES (?, ?, ?, ?)')
        .run(bike.id, customerName, days, new Date().toISOString());
      return sendJson(res, 201, {
        id: Number(result.lastInsertRowid),
        bikeId: bike.id,
        days,
        totalPrice: bike.pricePerDay * days,
      });
    }

    sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
  }

  return (req, res) => {
    const startedAt = performance.now();
    const requestId = req.headers['x-request-id'] ?? randomUUID();
    res.setHeader('X-Request-Id', requestId);
    res.on('finish', () => {
      logger.info('Požadavek vyřízen', {
        requestId,
        method: req.method,
        path: new URL(req.url, 'http://localhost').pathname,
        status: res.statusCode,
        durationMs: Math.round(performance.now() - startedAt),
      });
    });
    handle(req, res).catch((error) => {
      logger.error('Neočekávaná chyba', { requestId, error: error.stack });
      if (!res.headersSent) {
        sendJson(res, 500, { error: 'Na serveru se něco pokazilo.', requestId });
      }
    });
  };
}
```

## --file-- logger.js

```js
// Strukturovaný logger: jedna událost = jeden řádek JSON na standardní výstup.

const LEVELS = ['debug', 'info', 'warn', 'error'];
const SECRET_KEYS = ['password', 'token', 'authorization', 'cookie'];
const writeToStdout = (line) => process.stdout.write(`${line}\n`);

export function createLogger({ level = 'info', write = writeToStdout } = {}) {
  const minIndex = LEVELS.indexOf(level);

  function log(entryLevel, msg, fields = {}) {
    if (LEVELS.indexOf(entryLevel) < minIndex) return;
    const safeFields = {};
    for (const [key, value] of Object.entries(fields)) {
      safeFields[key] = SECRET_KEYS.includes(key) ? '[SKRYTO]' : value;
    }
    const entry = { time: new Date().toISOString(), level: entryLevel, msg, ...safeFields };
    write(JSON.stringify(entry));
  }

  return {
    debug: (msg, fields) => log('debug', msg, fields),
    info: (msg, fields) => log('info', msg, fields),
    warn: (msg, fields) => log('warn', msg, fields),
    error: (msg, fields) => log('error', msg, fields),
  };
}
```

```js
    shutdownTimeoutMs: Number(env.SHUTDOWN_TIMEOUT_MS ?? 8000),
```

```js
import { DatabaseSync } from 'node:sqlite';

const BIKES = [
  ['Superior XC 879', 'horské', 'Brno – Výstaviště', 450],
  ['Author Mission', 'městské', 'Brno – Mendlovo náměstí', 290],
  ['Kellys Tyke 24', 'dětské', 'Brno – Výstaviště', 190],
  ['Specialized Turbo Vado', 'elektrokolo', 'Brno – Lužánky', 890],
  ['Cannondale Topstone', 'gravel', 'Brno – Lužánky', 520],
];

// Otevře databázi půjčovny. Při prvním spuštění založí tabulky a vloží kola.
export function openDatabase(file) {
  const db = new DatabaseSync(file);
  db.exec(`
    CREATE TABLE IF NOT EXISTS bikes (
      id INTEGER PRIMARY KEY,
      name TEXT NOT NULL,
      type TEXT NOT NULL,
      station TEXT NOT NULL,
      price_per_day INTEGER NOT NULL
    );
    CREATE TABLE IF NOT EXISTS rentals (
      id INTEGER PRIMARY KEY,
      bike_id INTEGER NOT NULL REFERENCES bikes (id),
      customer_name TEXT NOT NULL,
      days INTEGER NOT NULL,
      created_at TEXT NOT NULL
    );
  `);
  const { count } = db.prepare('SELECT COUNT(*) AS count FROM bikes').get();
  if (count === 0) {
    const insert = db.prepare('INSERT INTO bikes (name, type, station, price_per_day) VALUES (?, ?, ?, ?)');
    for (const bike of BIKES) insert.run(...bike);
  }
  return db;
}
```

## --file-- server.js

```js
import { createServer } from 'node:http';
import { loadConfig } from './config.js';
import { createLogger } from './logger.js';
import { openDatabase } from './db.js';
import { createApp } from './app.js';

const config = loadConfig(process.env);
const logger = createLogger({ level: config.logLevel });
const db = openDatabase(config.databaseFile);
let shuttingDown = false;
const server = createServer(createApp({ db, logger, isShuttingDown: () => shuttingDown }));

server.listen(config.port, () => {
  logger.info('Server poslouchá', { port: config.port });
});

// Marek: při nasazení nové verze hosting pošle SIGTERM, ať proces neumře natvrdo.
process.on('SIGTERM', () => {
  logger.info('Dostal jsem SIGTERM, končím');
  shuttingDown = true;
  setTimeout(() => {
    logger.error('Ukončení nestihlo limit', { timeoutMs: config.shutdownTimeoutMs });
    process.exit(1);
  }, config.shutdownTimeoutMs).unref();
  server.close(() => {
    db.close();
    process.exit(0);
  });
});
```
