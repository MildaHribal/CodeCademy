# --description--

V přehledu inzerátů je na popis místo jen na pár slov. Dlouhý text se zkrátí a výpustka `…` ukáže, že pokračuje.

**Úkol:** Napiš funkci `truncate(text, maxLength)`:

- když má text **nejvýš** `maxLength` znaků, vrátí ho beze změny,
- jinak vrátí prvních `maxLength` znaků a za ně výpustku `…` (jeden znak, ne tři tečky — nejrychleji ho zkopíruješ odsud).

Délku textu máš ve vlastnosti **`length`**, výřez od začátku dá **`slice(0, konec)`** — znak na pozici `konec` už do výsledku nepatří. Na jiných datech:

```js
const code = 'PRAHA-2026';

// 1. je text delší než limit?
if (code.length > 5) {
  // 2. prvních pět znaků
  console.log(code.slice(0, 5));
}
```

Pozor na hranici: text, který má **přesně** `maxLength` znaků, se nezkracuje.

# --hints--

Delší text `truncate` zkrátí na `maxLength` znaků a přidá `…`.

```js
assert.equal(truncate('Prodám horské kolo', 6), 'Prodám…', "truncate('Prodám horské kolo', 6) má vrátit 'Prodám…'");
assert.equal(truncate('Přilba Abus', 3), 'Při…', "truncate('Přilba Abus', 3) má vrátit 'Při…'");
```

Kratší text vrátí `truncate` beze změny a bez výpustky.

```js
assert.equal(truncate('Kolo', 10), 'Kolo', "truncate('Kolo', 10) má vrátit 'Kolo' bez výpustky");
```

Text dlouhý přesně `maxLength` znaků se nezkracuje.

```js
assert.equal(truncate('Kolo', 4), 'Kolo', "truncate('Kolo', 4) má vrátit 'Kolo' — text má přesně 4 znaky, takže se nezkracuje");
```

# --help--

## --tip--

Délka a výřez textu jsou v části [Kousky textu: at, slice a hledání](see:js-retezce-cisla/retezce#kousky-textu-at-slice-a-hledani).

## --tip--

Porovnej `text.length` s limitem. Když se text vejde, vrať ho hned. Jinak vrať výřez od `0` do `maxLength` spojený s `'…'`.

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}
```
