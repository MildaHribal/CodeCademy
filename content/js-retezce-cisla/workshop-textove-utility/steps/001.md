# --description--

V tomhle workshopu napíšeš sadu textových funkcí pro **Kolobazar** — bazar, kde lidé prodávají použitá kola a vybavení. Každý inzerát má titulek, popis, jméno prodejce, telefon a e-mail, a všechno to přichází z formuláře tak, jak to lidé napíšou: s mezerami navíc, malými písmeny, s diakritikou i emoji.

Postupně z toho uděláš čistý titulek, zkrácený popis, adresu inzerátu bez diakritiky, iniciály, telefon ve tvaru `777 123 456` a skrytý e-mail. V posledních krocích z funkcí postavíš **živý náhled inzerátu**, který se mění při psaní.

Začneš něčím, co už umíš z úvodu do JavaScriptu, a to bez návodu. Výsledky funkcí si můžeš kdykoli vypsat přes `console.log` — kontroly tomu nevadí.

**Úkol:** Napiš funkci `sellerLabel(name)`, která vrátí text `Prodává: ` a za ním jméno, třeba `Prodává: Jana Nováková`. Když je jméno prázdný řetězec, vrátí `Prodává: anonymní prodejce`.

# --hints--

`sellerLabel` vrátí `Prodává: ` a jméno prodejce.

```js
assert.equal(sellerLabel('Jana Nováková'), 'Prodává: Jana Nováková', "sellerLabel('Jana Nováková') má vrátit 'Prodává: Jana Nováková'");
assert.equal(sellerLabel('Petr'), 'Prodává: Petr', "sellerLabel('Petr') má vrátit 'Prodává: Petr'");
```

Pro prázdné jméno vrátí `sellerLabel` text `Prodává: anonymní prodejce`.

```js
assert.equal(sellerLabel(''), 'Prodává: anonymní prodejce', "sellerLabel('') má vrátit 'Prodává: anonymní prodejce'");
```

# --help--

## --tip--

Potřebuješ funkci s podmínkou a šablonový řetězec (*template literal*) — obojí znáš ze sekce Základy JavaScriptu.

## --tip--

Nejdřív podmínkou ošetři prázdné jméno a vrať pevný text. Pro ostatní jména vrať šablonový řetězec, do kterého vložíš parametr přes `${…}`.

## --tip--

Na jiných datech by stejný tvar měla funkce `cityLabel(city)`:

```js
// 1. prázdný vstup → pevný text
// 2. jinak → šablonový řetězec s parametrem
```

# --solution--

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}
```
