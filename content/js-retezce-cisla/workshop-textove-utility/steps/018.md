# --description--

Seznam inzerátů jde seřadit „podle názvu". Řazení potřebuje funkci, která o dvou titulcích řekne, který patří dřív. Samotné řazení seznamu probere sekce Pole — teď napíšeš jen porovnání.

**Úkol:** Napiš funkci `compareTitles(a, b)`, která vrátí:

- **záporné číslo**, když titulek `a` patří podle **české abecedy** před `b`,
- **kladné číslo**, když patří za `b`,
- `0`, když jsou stejné.

Pozor na česká pravidla: `Č` patří hned za `C` (před `D`), `ch` je samostatné písmeno za `h` a `ř` za `r`. Kandidáti jsou operátory `<` a `>` nebo metoda `localeCompare` — jen jedno z toho zná češtinu. A nezapomeň, že jazyk prohlížeče uživatele nemusí být čeština.

# --hints--

Titulek s `Č` patří před titulek s `D`.

```js
assert.ok(compareTitles('Čepice', 'Dres') < 0, "compareTitles('Čepice', 'Dres') má vrátit záporné číslo — Č je v abecedě před D");
assert.ok(compareTitles('Dres', 'Čepice') > 0, "compareTitles('Dres', 'Čepice') má vrátit kladné číslo");
```

`ch` patří za `h` a `ř` za `r`.

```js
assert.ok(compareTitles('Chrániče kolen', 'Helma') > 0, "compareTitles('Chrániče kolen', 'Helma') má vrátit kladné číslo — ch je v české abecedě až za h");
assert.ok(compareTitles('Řetěz', 'Rám') > 0, "compareTitles('Řetěz', 'Rám') má vrátit kladné číslo — ř je za r");
```

Stejné titulky vrátí `0`.

```js
assert.equal(compareTitles('Kolo', 'Kolo'), 0, "compareTitles('Kolo', 'Kolo') má vrátit 0");
```

Porovnání řadí česky i v prohlížeči nastaveném na jiný jazyk.

```js
// Prohlížeč bez češtiny: porovnání bez zadaného jazyka dostane angličtinu.
const english = (locales) => (locales === undefined || (Array.isArray(locales) && locales.length === 0) ? 'en' : locales);
const originalLocaleCompare = String.prototype.localeCompare;
const OriginalCollator = Intl.Collator;
String.prototype.localeCompare = function (other, locales, options) {
  return originalLocaleCompare.call(this, other, english(locales), options);
};
Intl.Collator = function (locales, options) {
  return new OriginalCollator(english(locales), options);
};
try {
  assert.ok(compareTitles('Chrániče kolen', 'Helma') > 0, "compareTitles('Chrániče kolen', 'Helma') má vrátit kladné číslo i v prohlížeči nastaveném na angličtinu — jazyk 'cs' patří do kódu");
} finally {
  String.prototype.localeCompare = originalLocaleCompare;
  Intl.Collator = OriginalCollator;
}
```

# --help--

## --tip--

Porovnání textů podle jazyka je v části [Porovnání a řazení podle češtiny](see:js-retezce-cisla/retezce#porovnani-a-razeni-podle-cestiny).

## --tip--

`<` porovnává čísla znaků v Unicode, abecedu nezná. Metoda, která ji zná, se volá na prvním textu, dostane druhý text a jako druhý argument jazyk.

## --tip--

Na jiných datech: `'Šumperk'.localeCompare('Tábor', 'cs')` vrátí záporné číslo, protože Š je v české abecedě před T.

# --explain--

Vysvětli vlastními slovy, proč `'Chrániče' < 'Helma'` vrátí `true`, i když v české abecedě patří chrániče až za helmu.

## --model--

Operátor `<` porovnává řetězce znak po znaku podle jejich čísel v Unicode. `C` má menší číslo než `H`, takže chrániče vyjdou dřív. Česká abeceda ale bere `ch` jako jedno písmeno za `h` a `Č` řadí hned za `C`, což čísla znaků nevědí. Podle jazyka porovnává až `localeCompare` s jazykem `'cs'`.

## --checklist--

- `<` porovnává čísla znaků v Unicode, ne abecedu.
- Česká abeceda má vlastní pravidla (`ch` za `h`, `Č` za `C`).
- Podle češtiny porovná `localeCompare(b, 'cs')`.
- Jazyk se píše výslovně, jinak rozhoduje prohlížeč uživatele.

// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}

// Kód inzerátu s pevnou délkou, např. INZ-000042.
function listingCode(id) {
  return `INZ-${String(id).padStart(6, '0')}`;
}

// Kolega upravil: snese i telefon zadaný s mezerami, třeba '777 123 456'.
function formatPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  return `${digits.slice(0, 3)} ${digits.slice(3, 6)} ${digits.slice(6)}`;
}

// E-mail s hvězdičkami místo jména, doména zůstane.
function maskEmail(email) {
  const at = email.indexOf('@');
  if (at === -1) {
    return email;
  }
  return email.slice(0, 1) + '*'.repeat(at - 1) + email.slice(at);
}

// Platný telefon: po odstranění mezer přesně 9 číslic.
function isValidPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  if (digits.length !== 9) {
    return false;
  }
  for (const char of digits) {
    if (!'0123456789'.includes(char)) {
      return false;
    }
  }
  return true;
}

// Iniciály ze jména: 'Jana Nováková' → 'JN'.
function initials(fullName) {
  let result = '';
  for (const word of fullName.split(' ')) {
    if (word !== '') {
      result += word.slice(0, 1).toUpperCase();
    }
  }
  return result;
}

// Od kolegy: text bez háčků a čárek, pro hledání a adresy inzerátů.
function removeDiacritics(text) {
  return text.normalize('NFD').replace(/\p{M}/gu, '');
}

// Obsahuje titulek hledaný text? Rozhoduje jen písmeno, ne velikost ani diakritika.
function matchesSearch(title, query) {
  const normalizedTitle = removeDiacritics(title).toLowerCase();
  const normalizedQuery = removeDiacritics(query.trim()).toLowerCase();
  return normalizedTitle.includes(normalizedQuery);
}

function slugify(title) {
  const allowed = 'abcdefghijklmnopqrstuvwxyz0123456789';
  let slug = '';
  for (const char of removeDiacritics(title).toLowerCase()) {
    if (allowed.includes(char)) {
      slug += char;
    } else if (slug !== '' && !slug.endsWith('-')) {
      slug += '-';
    }
  }
  return slug.endsWith('-') ? slug.slice(0, -1) : slug;
}

// Hashtag z textu: jen písmena a číslice bez diakritiky, např. #horskekolo29.
function hashtag(text) {
  const allowed = 'abcdefghijklmnopqrstuvwxyz0123456789';
  let tag = '';
  for (const char of removeDiacritics(text).toLowerCase()) {
    if (allowed.includes(char)) {
      tag += char;
    }
  }
  return tag === '' ? '' : `#${tag}`;
}

// Počet znaků tak, jak je vidí člověk (grafémy).
function countCharacters(text) {
  const segmenter = new Intl.Segmenter('cs', { granularity: 'grapheme' });
  return [...segmenter.segment(text)].length;
}

// Zkrácený text, který nekončí uprostřed slova.
function truncateAtWord(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  let cut = text.slice(0, maxLength);
  const lastSpace = cut.lastIndexOf(' ');
  if (lastSpace !== -1) {
    cut = cut.slice(0, lastSpace);
  }
  return `${cut}…`;
}
