# --description--

Celý e-mail prodejce na stránce láká spamové roboty. Kolobazar proto ukáže jen první písmeno, hvězdičky a doménu: `jana.novakova@seznam.cz` → `j************@seznam.cz`.

**Úkol:** Napiš funkci `maskEmail(email)`, která vrátí:

- první znak před zavináčem,
- za ním tolik hvězdiček `*`, kolik zbylých znaků je před zavináčem,
- a nakonec zavináč s doménou beze změny.

Když e-mail zavináč **nemá** (uživatel ho ještě dopisuje), vrátí text beze změny.

Pozici zavináče najde **`indexOf('@')`** — vrátí `-1`, když zavináč chybí. Hvězdičky vyrobí **`'*'.repeat(počet)`**. Na jiných datech (číslo karty, vidět jsou jen poslední čtyři číslice):

```js
const card = '4111222233334444';

// 1. kolik znaků skrýt
const hiddenCount = card.length - 4;

// 2. hvězdičky a zbytek
const masked = '*'.repeat(hiddenCount) + card.slice(hiddenCount);
```

> [!PITFALL]
> `'*'.repeat(-2)` nevrátí prázdný text, ale spadne s `RangeError: Invalid count value: -2`. U e-mailu bez zavináče se sem snadno dostaneš.

# --hints--

`maskEmail` nechá první znak a doménu a zbytek jména nahradí hvězdičkami.

```js
assert.equal(maskEmail('petr@email.cz'), 'p***@email.cz', "maskEmail('petr@email.cz') má vrátit 'p***@email.cz'");
assert.equal(maskEmail('jana.novakova@seznam.cz'), 'j************@seznam.cz', "maskEmail('jana.novakova@seznam.cz') má vrátit 'j' a 12 hvězdiček před '@seznam.cz'");
```

Jednoznakové jméno zůstane bez hvězdiček.

```js
assert.equal(maskEmail('a@kolobazar.cz'), 'a@kolobazar.cz', "maskEmail('a@kolobazar.cz') má vrátit 'a@kolobazar.cz' — po prvním znaku už nic neskrývá");
```

Text bez zavináče vrátí `maskEmail` beze změny a nespadne.

```js
assert.equal(maskEmail('jana.novak'), 'jana.novak', "maskEmail('jana.novak') má vrátit 'jana.novak' — bez zavináče není co skrývat");
assert.equal(maskEmail(''), '', "maskEmail('') má vrátit ''");
```

# --help--

## --tip--

Pozice a výřezy jsou v části [Kousky textu: at, slice a hledání](see:js-retezce-cisla/retezce#kousky-textu-at-slice-a-hledani), `repeat` v tabulce o úpravách.

## --tip--

Ulož si pozici zavináče. Když je `-1`, vrať e-mail hned. Počet hvězdiček je pozice zavináče minus jedna (první znak zůstává).

## --tip--

Na jiných datech: z `'Brno-střed'` nech jen `Brno` a zbytek skryj — pozice pomlčky je `4`, hvězdiček je `'Brno-střed'.length - 4`.

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}

// Kód inzerátu s pevnou délkou, např. INZ-000042.
function listingCode(id) {
  return `INZ-${String(id).padStart(6, '0')}`;
}

// Kolega upravil: snese i telefon zadaný s mezerami, třeba '777 123 456'.
function formatPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  return `${digits.slice(0, 3)} ${digits.slice(3, 6)} ${digits.slice(6)}`;
}

// E-mail s hvězdičkami místo jména, doména zůstane.
function maskEmail(email) {
  const at = email.indexOf('@');
  if (at === -1) {
    return email;
  }
  return email.slice(0, 1) + '*'.repeat(at - 1) + email.slice(at);
}
```
