# --description--

Prodejce bez profilové fotky má místo ní kolečko s iniciálami, jako to znáš z Gmailu nebo Slacku.

**Úkol:** Napiš funkci `initials(fullName)`, která vrátí první písmeno každého slova ve jméně, velkými písmeny a bez mezer:

- `Jana Nováková` → `JN`, `jan amos komenský` → `JAK`,
- mezery navíc na krajích i mezi slovy nevadí: `'  Eva   Dvořáková '` → `ED`,
- prázdné jméno vrátí prázdný text.

Nástroj si tentokrát vyber sám — všechno potřebné už znáš a rozumných cest je víc. Až budeš mít hotovo, rozmysli si, jak by vypadalo druhé řešení.

# --hints--

`initials` vrátí první písmena slov velkými písmeny.

```js
assert.equal(initials('Jana Nováková'), 'JN', "initials('Jana Nováková') má vrátit 'JN'");
assert.equal(initials('jan amos komenský'), 'JAK', "initials('jan amos komenský') má vrátit 'JAK'");
assert.equal(initials('šimon'), 'Š', "initials('šimon') má vrátit 'Š'");
```

Mezery navíc na krajích a mezi slovy nepřidají žádnou iniciálu.

```js
assert.equal(initials('  Eva   Dvořáková '), 'ED', "initials('  Eva   Dvořáková ') má vrátit 'ED' — mezery navíc se nepočítají");
```

Pro prázdné jméno vrátí `initials` prázdný text.

```js
assert.equal(initials(''), '', "initials('') má vrátit ''");
assert.equal(initials('   '), '', "initials('   ') má vrátit '' — jméno jen z mezer nemá žádné slovo");
```

# --help--

## --tip--

Slova ve jméně odděluje mezera. Rozdělení textu a past s dvojitou mezerou jsou v části [Rozdělení a spojení: split a join](see:js-retezce-cisla/retezce#rozdeleni-a-spojeni-split-a-join).

## --tip--

Jedna cesta: rozděl jméno na kousky a u každého neprázdného vezmi první znak. Druhá: projdi znaky cyklem a vezmi každý znak, před kterým byla mezera (nebo začátek textu).

## --tip--

Podcíle bez ohledu na zvolenou cestu:

```js
// 1. připrav prázdný výsledek
// 2. najdi začátek každého slova (prázdné kousky přeskoč)
// 3. připoj jeho první znak velkým písmenem
// 4. vrať výsledek
```

  const at = email.indexOf('@');

    return email;
  }

// Platný telefon: po odstranění mezer přesně 9 číslic.
function isValidPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  if (digits.length !== 9) {
    return false;
  }
  for (const char of digits) {
    if (!'0123456789'.includes(char)) {
      return false;
    }
  }
  return true;
}

// Iniciály ze jména: 'Jana Nováková' → 'JN'.
function initials(fullName) {
  let result = '';
  for (const word of fullName.split(' ')) {
    if (word !== '') {
      result += word.slice(0, 1).toUpperCase();
    }
  }
  return result;
}
