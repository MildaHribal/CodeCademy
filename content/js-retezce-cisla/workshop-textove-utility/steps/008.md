# --description--

## Hlášení

Kolega upravil tvoji funkci `formatPhone`, protože lidé píšou telefon i s mezerami. Číslo bez mezer funguje dál, ale u čísla zadaného s mezerami se na stránce objeví dvojitá mezera:

- `formatPhone('777 123 456')` vrací `'777 123  456'` (dvě mezery před `456`),
- `formatPhone('777 12 34 56')` vrací `'777 12  34 56'` (trojice se rozpadly a před `34` jsou dvě mezery).

V konzoli žádná chyba není.

## Úkol

Oprav `formatPhone` tak, aby z čísla s libovolnými mezerami vrátila tvar `777 123 456`. Změň co nejmenší kus kódu.

# --hints--

Telefon zadaný s mezerami po trojicích vrátí `formatPhone` ve správném tvaru.

```js
assert.equal(formatPhone('777 123 456'), '777 123 456', "formatPhone('777 123 456') má vrátit '777 123 456' s jednou mezerou mezi trojicemi");
```

Telefon zadaný s mezerami na jiných místech vrátí `formatPhone` taky po trojicích.

```js
assert.equal(formatPhone('777 12 34 56'), '777 123 456', "formatPhone('777 12 34 56') má vrátit '777 123 456'");
```

Telefon bez mezer funguje dál.

```js
assert.equal(formatPhone('603987654'), '603 987 654', "formatPhone('603987654') má dál vracet '603 987 654'");
```

## --tip--

Chyba odpovídá pasti z tabulky v části [Úpravy: trim, velikost písmen, padStart, replaceAll](see:js-retezce-cisla/retezce#upravy-trim-velikost-pismen-padstart-replaceall).

## --tip--

Vypiš si `digits` pro `'777 123 456'`. Kolik mezer v něm zůstalo? Kolik jich metoda s obyčejným textem odstraní?

## --tip--

Na jiných datech: `'1 250 000'.replace(' ', '')` vrátí `'1250 000'`, kdežto metoda s „všechny" v názvu vrátí `'1250000'`.

# --explain--

Vysvětli vlastními slovy, proč `phone.replace(' ', '')` u čísla `'777 123 456'` nechalo jednu mezeru.

## --model--

Metoda `replace` s obyčejným textem nahradí jen první výskyt. Z čísla proto zmizela první mezera a druhá zůstala, takže poslední trojice začínala mezerou a výsledek měl mezery dvě. `replaceAll` nahradí všechny výskyty, ať jich je kolik chce.

## --checklist--

- `replace` s textem nahradí jen první výskyt.
- Druhá mezera zůstala v číslicích a posunula poslední kousek.
- `replaceAll` nahradí všechny výskyty.

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.

  return text.slice(0, 1).toUpperCase() + text.slice(1);
```

```js
// Kolega upravil: snese i telefon zadaný s mezerami, třeba '777 123 456'.
function formatPhone(phone) {
  const digits = phone.replaceAll(' ', '');
```
