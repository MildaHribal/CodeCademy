# --description--

Každý inzerát má adresu, kterou lidé sdílejí: `kolobazar.cz/inzerat/42-horske-kolo-author`. Poslední část se jmenuje **slug**: malá písmena bez diakritiky, číslice a mezi slovy pomlčky, žádné jiné znaky.

**Úkol:** Seřaď řádky tak, aby `slugify(title)` vrátila slug titulku. Postup:

- text zbav diakritiky a převeď na malá písmena,
- projdi znaky: písmeno `a`–`z` nebo číslici připoj, místo každého jiného úseku znaků dej **jednu** pomlčku,
- pomlčka nesmí být na začátku ani na konci.

Tenhle vzor — postupné skládání řetězce v cyklu s podmínkou — vidíš poprvé, proto ho jen skládáš. V dalším kroku ho napíšeš sám. Odsazení nastavíš klávesou Tab, do mezery doplň znak, který nesmí být dvakrát za sebou. Dva řádky jsou navíc.

# --hints--

`slugify` převede titulek na malá písmena bez diakritiky s pomlčkami mezi slovy.

```js
assert.equal(slugify('Žluťoučký kůň'), 'zlutoucky-kun', "slugify('Žluťoučký kůň') má vrátit 'zlutoucky-kun'");
assert.equal(slugify('Horské kolo Author 29'), 'horske-kolo-author-29', "slugify('Horské kolo Author 29') má vrátit 'horske-kolo-author-29'");
```

Víc jiných znaků za sebou dá jednu pomlčku a na krajích žádná pomlčka není.

```js
assert.equal(slugify('  Kolo -- na prodej! '), 'kolo-na-prodej', "slugify('  Kolo -- na prodej! ') má vrátit 'kolo-na-prodej'");
assert.equal(slugify('Přilba (XL)'), 'prilba-xl', "slugify('Přilba (XL)') má vrátit 'prilba-xl' — závorka na konci nesmí nechat pomlčku");
```

Pro prázdný titulek vrátí `slugify` prázdný text.

```js
assert.equal(slugify(''), '', "slugify('') má vrátit ''");
```

# --help--

## --tip--

Odstranění diakritiky máš z opravy kolegovy funkce, viz [Diakritika a normalize](see:js-retezce-cisla/retezce#diakritika-a-normalize).

## --tip--

Pomlčka se přidá jen tehdy, když slug už něco obsahuje a zatím nekončí pomlčkou. Poslední řádek funkce odebere pomlčku, která zbyla na konci.

# --parsons--

```js
function slugify(title) {
  const allowed = 'abcdefghijklmnopqrstuvwxyz0123456789';
  let slug = '';
  for (const char of removeDiacritics(title).toLowerCase()) {
    if (allowed.includes(char)) {
      slug += char;
    } else if (slug !== '' && !slug.endsWith(__1__)) {
      slug += '-';
    }
  }
  return slug.endsWith('-') ? slug.slice(0, -1) : slug;
}
```

## --distractors--

```js
slug = char;
return slug;
```

## --blanks--

```text
1: '-'
```

function sellerLabel(name) {

function cleanTitle(title) {
  return title.trim();

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}

// Kód inzerátu s pevnou délkou, např. INZ-000042.
function listingCode(id) {
  return `INZ-${String(id).padStart(6, '0')}`;
}

// Kolega upravil: snese i telefon zadaný s mezerami, třeba '777 123 456'.
function formatPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  return `${digits.slice(0, 3)} ${digits.slice(3, 6)} ${digits.slice(6)}`;
}

// E-mail s hvězdičkami místo jména, doména zůstane.
function maskEmail(email) {
  const at = email.indexOf('@');
  if (at === -1) {
    return email;
  }
  return email.slice(0, 1) + '*'.repeat(at - 1) + email.slice(at);
}

// Platný telefon: po odstranění mezer přesně 9 číslic.
function isValidPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  if (digits.length !== 9) {
    return false;
  }
  for (const char of digits) {
    if (!'0123456789'.includes(char)) {
      return false;
    }
  }
  return true;
}

// Iniciály ze jména: 'Jana Nováková' → 'JN'.
function initials(fullName) {
  let result = '';
  for (const word of fullName.split(' ')) {
    if (word !== '') {
      result += word.slice(0, 1).toUpperCase();
    }
  }
  return result;
}

// Od kolegy: text bez háčků a čárek, pro hledání a adresy inzerátů.
function removeDiacritics(text) {
  return text.normalize('NFD').replace(/\p{M}/gu, '');
}

// Obsahuje titulek hledaný text? Rozhoduje jen písmeno, ne velikost ani diakritika.
function matchesSearch(title, query) {
  const normalizedTitle = removeDiacritics(title).toLowerCase();
  const normalizedQuery = removeDiacritics(query.trim()).toLowerCase();
  return normalizedTitle.includes(normalizedQuery);
}
