# --description--

Kolobazar posílá upozornění „nový inzerát, který tě může zajímat". Uživatel si uloží slovo, třeba `kolo`, a funkce rozhodne, jestli ho titulek obsahuje — bez ohledu na velká a malá písmena.

**Úkol:** Napiš funkci `hasKeyword(title, keyword)`, která vrátí `true`, když titulek obsahuje hledané slovo, jinak `false`. Velikost písmen nesmí rozhodovat ani v titulku, ani ve slově.

Otázku „jestli" zodpoví **`includes`**. Porovnání bez ohledu na velikost písmen uděláš tak, že **obě strany** převedeš na malá písmena přes **`toLowerCase()`**. Na jiných datech:

```js
const city = 'Hradec Králové';
const query = 'HRADEC';

const found = city.toLowerCase().includes(query.toLowerCase());
```

# --hints--

`hasKeyword` najde slovo, i když je v titulku jinými písmeny.

```js
assert.equal(hasKeyword('Horské KOLO Author', 'kolo'), true, "hasKeyword('Horské KOLO Author', 'kolo') má vrátit true");
```

`hasKeyword` najde slovo, i když je hledané slovo napsané velkými písmeny.

```js
assert.equal(hasKeyword('Silniční kolo Specialized', 'KOLO'), true, "hasKeyword('Silniční kolo Specialized', 'KOLO') má vrátit true — velikost písmen nerozhoduje ani u hledaného slova");
```

`hasKeyword` vrátí `false`, když titulek slovo neobsahuje.

```js
assert.equal(hasKeyword('Přilba Abus', 'kolo'), false, "hasKeyword('Přilba Abus', 'kolo') má vrátit false");
```

# --help--

## --tip--

Otázky „jestli" a „kde" v textu vysvětluje [Kousky textu: at, slice a hledání](see:js-retezce-cisla/retezce#kousky-textu-at-slice-a-hledani).

## --tip--

Než zavoláš `includes`, převeď na malá písmena titulek i hledané slovo. Stačí to na jednom řádku s `return`.

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}
```
