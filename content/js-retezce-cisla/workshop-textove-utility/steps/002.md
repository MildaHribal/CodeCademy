# --description--

Lidé do formuláře píšou titulek s mezerami navíc: `'  Horské kolo Author  '`. V přehledu inzerátů by takový titulek odskočil od ostatních a hledání by ho porovnávalo i s mezerami.

**Úkol:** Napiš funkci `cleanTitle(title)`, která vrátí titulek bez bílých znaků (mezer, tabulátorů, nových řádků) na začátku a na konci. Mezery **uvnitř** titulku zůstanou.

Na to je metoda **`trim()`**. Pamatuj, že řetězec se nedá změnit: `trim()` vrátí **nový** řetězec a ten musí funkce vrátit. Na jiných datech:

```js
const city = '  Brno ';
const cleanCity = city.trim();
```

> [!PITFALL]
> `title.trim();` na samostatném řádku nic nezmění — výsledek se zahodí a `title` má mezery dál.

# --hints--

`cleanTitle` odstraní mezery na začátku a na konci titulku.

```js
assert.equal(cleanTitle('  Horské kolo  '), 'Horské kolo', "cleanTitle('  Horské kolo  ') má vrátit 'Horské kolo'");
```

`cleanTitle` odstraní i tabulátor a nový řádek na krajích.

```js
assert.equal(cleanTitle('\tPřilba Abus\n'), 'Přilba Abus', "cleanTitle('\\tPřilba Abus\\n') má vrátit 'Přilba Abus' — tabulátor i nový řádek jsou bílé znaky");
```

Mezery uvnitř titulku zůstanou beze změny.

```js
assert.equal(cleanTitle(' Kolo  Author Traction '), 'Kolo  Author Traction', "cleanTitle(' Kolo  Author Traction ') má nechat dvě mezery uvnitř a vrátit 'Kolo  Author Traction'");
```

# --help--

## --tip--

Jde o úpravu textu, která vrací nový řetězec — viz [Řetězec se nedá změnit](see:js-retezce-cisla/retezce#retezec-se-neda-zmenit).

## --tip--

Zavolej `trim()` na parametru a výsledek rovnou vrať z funkce.

# --explain--

Vysvětli vlastními slovy, proč funkce s řádkem `title.trim();` a potom `return title;` vrátí titulek pořád s mezerami.

## --model--

Řetězce v JavaScriptu jsou neměnné, žádná metoda nepřepíše znaky uvnitř. `trim()` proto nevyčistí `title`, ale vrátí nový řetězec bez mezer. Když ho neuložím ani nevrátím, zahodí se, a `return title` vrátí původní text. Správně je vrátit přímo výsledek `trim()`.

## --checklist--

- Řetězec se nedá změnit, metody vracejí nový řetězec.
- `trim()` nevyčistí proměnnou, na které ho zavolám.
- Výsledek metody musím uložit nebo vrátit, jinak se zahodí.

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}
```
