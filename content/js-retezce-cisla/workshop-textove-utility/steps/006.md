# --description--

Každý inzerát má číslo z databáze, třeba `42`. Na stránce a v e-mailech se ukazuje jako kód s pevnou délkou, aby se dal nadiktovat do telefonu: `INZ-000042`.

**Úkol:** Napiš funkci `listingCode(id)`, která z čísla `id` vrátí text `INZ-` a za ním číslo doplněné zleva nulami na **šest** číslic.

Doplnění zleva udělá **`padStart(délka, výplň)`**. Je to ale metoda **řetězce** — číslo nejdřív převeď přes `String(id)`. Na jiných datech:

```js
const minutes = 5;
const clock = String(minutes).padStart(2, '0');
```

> [!PITFALL]
> `id.padStart(6, '0')` na čísle spadne s hláškou `TypeError: id.padStart is not a function` — číslo žádnou metodu `padStart` nemá.

# --hints--

`listingCode` doplní číslo nulami zleva na šest číslic a přidá `INZ-`.

```js
assert.equal(listingCode(42), 'INZ-000042', "listingCode(42) má vrátit 'INZ-000042'");
assert.equal(listingCode(7), 'INZ-000007', "listingCode(7) má vrátit 'INZ-000007'");
```

Číslo, které už šest číslic má, zůstane beze změny.

```js
assert.equal(listingCode(123456), 'INZ-123456', "listingCode(123456) má vrátit 'INZ-123456'");
```

## --tip--

Převeď `id` na řetězec, zavolej na něm `padStart` s délkou `6` a výplní `'0'` a výsledek připoj za `'INZ-'`.

# --solution--

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}

// Kód inzerátu s pevnou délkou, např. INZ-000042.
function listingCode(id) {
  return `INZ-${String(id).padStart(6, '0')}`;
}
```
