# --description--

Titulek `horské kolo` vypadá v přehledu nedbale. Stačí změnit první písmeno na velké, zbytek nech, jak ho prodejce napsal (`GT` nebo `XL` musí zůstat velkými písmeny).

**Úkol:** Napiš funkci `capitalize(text)`, která vrátí text s velkým prvním písmenem a zbytkem beze změny. Prázdný text vrátí prázdný.

Text rozdělíš na dva kousky přes **`slice`**: `text.slice(0, 1)` je první znak a `text.slice(1)` všechno od druhého znaku do konce. První kousek převedeš metodou **`toUpperCase()`** a oba spojíš operátorem `+`. Na jiných datech:

```js
const code = 'abc-123';

// 1. první znak a zbytek
const first = code.slice(0, 1);
const rest = code.slice(1);

// 2. poskládej zpátky
const shouted = first.toUpperCase() + rest;
```

> [!PITFALL]
> `text[0].toUpperCase()` u prázdného textu spadne: `''[0]` je `undefined` a skončí to `TypeError: Cannot read properties of undefined (reading 'toUpperCase')`. `slice(0, 1)` vrátí u prázdného textu prázdný řetězec.

# --hints--

`capitalize` změní první písmeno na velké a zbytek nechá beze změny.

```js
assert.equal(capitalize('horské kolo'), 'Horské kolo', "capitalize('horské kolo') má vrátit 'Horské kolo'");
assert.equal(capitalize('kolo GT XL'), 'Kolo GT XL', "capitalize('kolo GT XL') má vrátit 'Kolo GT XL' — zbytek textu se nemění");
```

`capitalize` funguje i s písmenem s diakritikou na začátku.

```js
assert.equal(capitalize('čelovka Petzl'), 'Čelovka Petzl', "capitalize('čelovka Petzl') má vrátit 'Čelovka Petzl'");
```

Pro prázdný text vrátí `capitalize` prázdný text a nespadne.

```js
assert.equal(capitalize(''), '', "capitalize('') má vrátit '' a nesmí spadnout");
```

# --help--

## --tip--

Jde o výřez textu a past s prázdným řetězcem — viz [Znak na neexistující pozici](see:js-retezce-cisla/retezce#znak-na-neexistujici-pozici).

## --tip--

První kousek dá `slice` od `0` do `1`, zbytek `slice` od `1`. Velké písmeno udělá `toUpperCase()` jen na prvním kousku.

# --solution--

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}
```
