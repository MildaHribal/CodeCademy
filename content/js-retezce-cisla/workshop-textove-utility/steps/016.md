# --description--

Pod polem „Popis" je počítadlo `128 / 300`. Lidé do popisu píšou emoji (`Top stav 👍🏽`) a počítadlo musí ukázat tolik znaků, kolik jich **vidí** — jinak by jim formulář tvrdil, že limit překročili, i když ne.

**Úkol:** Napiš funkci `countCharacters(text)`, která vrátí počet znaků tak, jak je vidí člověk: emoji s odstínem pleti nebo emoji rodiny je jeden znak, písmeno s háčkem taky.

Na výběr máš tři způsoby počítání z lekce: vlastnost `length`, rozprostření do pole `[...text]` a `Intl.Segmenter` s nastavením `granularity`. Jen jeden z nich počítá to, co vidí člověk.

# --hints--

Obyčejný text a text s diakritikou spočítá `countCharacters` podle písmen.

```js
assert.equal(countCharacters('Kolo'), 4, "countCharacters('Kolo') má vrátit 4");
assert.equal(countCharacters('Žluťoučký'), 9, "countCharacters('Žluťoučký') má vrátit 9");
```

Emoji s odstínem pleti je jeden znak.

```js
assert.equal(countCharacters('Top stav 👍🏽'), 10, "countCharacters('Top stav 👍🏽') má vrátit 10 — palec s odstínem pleti je jeden znak, i když má length 4");
```

Emoji složené z více postav je jeden znak.

```js
assert.equal(countCharacters('Pro 👨‍👩‍👧'), 5, "countCharacters('Pro 👨‍👩‍👧') má vrátit 5 — rodina je na obrazovce jeden znak");
```

# --help--

## --tip--

Tři způsoby počítání porovnává část [Unicode: diakritika a emoji](see:js-retezce-cisla/retezce#unicode-diakritika-a-emoji).

## --tip--

Potřebuješ grafémy. Segmenter vytvoříš s jazykem `'cs'` a `granularity: 'grapheme'`, jeho metoda `segment(text)` vrátí kousky a jejich počet zjistíš po rozprostření do pole.

## --tip--

Na jiných datech: `[...new Intl.Segmenter('cs', { granularity: 'word' }).segment('Ahoj světe')].length` vrátí počet úseků po slovech a mezerách.

# --explain--

Vysvětli vlastními slovy, proč `'Top stav 👍🏽'.length` vrátí 12, a ne 9 znaků, které vidíš.

## --model--

`length` počítá kódové jednotky, ne znaky na obrazovce. Emoji palce zabírá dvě jednotky a odstín pleti je samostatný znak s dalšími dvěma, takže jeden viditelný palec přidá čtyři. Na počítadlo pro lidi potřebuju grafémy, a ty spočítá `Intl.Segmenter` s `granularity: 'grapheme'`.

## --checklist--

- `length` počítá kódové jednotky, ne viditelné znaky.
- Emoji zabírá víc jednotek, emoji s odstínem pleti se skládá ze dvou znaků.
- Viditelné znaky (grafémy) spočítá `Intl.Segmenter`.

// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}

// Kód inzerátu s pevnou délkou, např. INZ-000042.
function listingCode(id) {
  return `INZ-${String(id).padStart(6, '0')}`;
}

// Kolega upravil: snese i telefon zadaný s mezerami, třeba '777 123 456'.
function formatPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  return `${digits.slice(0, 3)} ${digits.slice(3, 6)} ${digits.slice(6)}`;
}

// E-mail s hvězdičkami místo jména, doména zůstane.
function maskEmail(email) {
  const at = email.indexOf('@');
  if (at === -1) {
    return email;
  }
  return email.slice(0, 1) + '*'.repeat(at - 1) + email.slice(at);
}

// Platný telefon: po odstranění mezer přesně 9 číslic.
function isValidPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  if (digits.length !== 9) {
    return false;
  }
  for (const char of digits) {
    if (!'0123456789'.includes(char)) {
      return false;
    }
  }
  return true;
}

// Iniciály ze jména: 'Jana Nováková' → 'JN'.
function initials(fullName) {
  let result = '';
  for (const word of fullName.split(' ')) {
    if (word !== '') {
      result += word.slice(0, 1).toUpperCase();
    }
  }
  return result;
}

// Od kolegy: text bez háčků a čárek, pro hledání a adresy inzerátů.
function removeDiacritics(text) {
  return text.normalize('NFD').replace(/\p{M}/gu, '');
}

// Obsahuje titulek hledaný text? Rozhoduje jen písmeno, ne velikost ani diakritika.
function matchesSearch(title, query) {
  const normalizedTitle = removeDiacritics(title).toLowerCase();
  const normalizedQuery = removeDiacritics(query.trim()).toLowerCase();
  return normalizedTitle.includes(normalizedQuery);
}

function slugify(title) {
  const allowed = 'abcdefghijklmnopqrstuvwxyz0123456789';
  let slug = '';
  for (const char of removeDiacritics(title).toLowerCase()) {
    if (allowed.includes(char)) {
      slug += char;
    } else if (slug !== '' && !slug.endsWith('-')) {
      slug += '-';
    }
  }
  return slug.endsWith('-') ? slug.slice(0, -1) : slug;
}

// Hashtag z textu: jen písmena a číslice bez diakritiky, např. #horskekolo29.
function hashtag(text) {
  const allowed = 'abcdefghijklmnopqrstuvwxyz0123456789';
  let tag = '';
  for (const char of removeDiacritics(text).toLowerCase()) {
    if (allowed.includes(char)) {
      tag += char;
    }
  }
  return tag === '' ? '' : `#${tag}`;
}
