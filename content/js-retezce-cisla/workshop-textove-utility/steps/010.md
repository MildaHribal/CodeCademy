# --description--

Než se telefon na stránce ukáže, Kolobazar ho zkontroluje. Tentokrát bez návodu — cyklus `for…of` přes znaky řetězce znáš ze sekce Základy JavaScriptu.

**Úkol:** Napiš funkci `isValidPhone(phone)`, která vrátí `true`, když telefon po odstranění **všech mezer** obsahuje přesně devět znaků a každý z nich je číslice `0`–`9`. Jinak vrátí `false`.

# --hints--

Devět číslic bez mezer i s mezerami je platný telefon.

```js
assert.equal(isValidPhone('777123456'), true, "isValidPhone('777123456') má vrátit true");
assert.equal(isValidPhone('777 123 456'), true, "isValidPhone('777 123 456') má vrátit true — mezery se nepočítají");
```

Telefon s jiným počtem číslic není platný.

```js
assert.equal(isValidPhone('77712345'), false, "isValidPhone('77712345') má vrátit false — číslic je jen osm");
assert.equal(isValidPhone('7771234567'), false, "isValidPhone('7771234567') má vrátit false — číslic je deset");
assert.equal(isValidPhone(''), false, "isValidPhone('') má vrátit false");
```

Telefon s jiným znakem než číslicí není platný.

```js
assert.equal(isValidPhone('77712345a'), false, "isValidPhone('77712345a') má vrátit false — 'a' není číslice");
assert.equal(isValidPhone('777-12-345'), false, "isValidPhone('777-12-345') má vrátit false — pomlčka není číslice");
assert.equal(isValidPhone('+77712345'), false, "isValidPhone('+77712345') má vrátit false — plus není číslice");
assert.equal(isValidPhone('7771234.5'), false, "isValidPhone('7771234.5') má vrátit false — tečka není číslice");
```

# --help--

## --tip--

Znaky textu projdeš cyklem `for…of` — viz [Cykly](see:js-zaklady/cykly). Mezery odstraníš jako v opravě `formatPhone`.

## --tip--

Jestli je znak číslice, zjistíš třeba tak, že se zeptáš, jestli ho obsahuje text `'0123456789'`. Při prvním znaku, který číslicí není, můžeš vrátit `false` rovnou z cyklu.

## --tip--

Postup jako podcíle:

```js
// 1. odstraň mezery
// 2. zkontroluj délku
// 3. projdi znaky a u první nečíslice vrať false
// 4. když cyklus doběhne, vrať true
```

## --file-- script.js

```js
// Kolobazar: textové utility pro inzeráty v bazaru kol.
// Každá funkce dostane text a vrátí nový text, číslo nebo true/false.

// Popisek prodejce pod inzerátem.
function sellerLabel(name) {
  if (name === '') {
    return 'Prodává: anonymní prodejce';
  }
  return `Prodává: ${name}`;
}

// Titulek bez bílých znaků na krajích.
function cleanTitle(title) {
  return title.trim();
}

// Text s velkým prvním písmenem, zbytek beze změny.
function capitalize(text) {
  return text.slice(0, 1).toUpperCase() + text.slice(1);
}

// Obsahuje titulek hledané slovo? Velikost písmen nerozhoduje.
function hasKeyword(title, keyword) {
  return title.toLowerCase().includes(keyword.toLowerCase());
}

// Zkrácený text s výpustkou, když je delší než maxLength.
function truncate(text, maxLength) {
  if (text.length <= maxLength) {
    return text;
  }
  return text.slice(0, maxLength) + '…';
}

// Kód inzerátu s pevnou délkou, např. INZ-000042.
function listingCode(id) {
  return `INZ-${String(id).padStart(6, '0')}`;
}

// Kolega upravil: snese i telefon zadaný s mezerami, třeba '777 123 456'.
function formatPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  return `${digits.slice(0, 3)} ${digits.slice(3, 6)} ${digits.slice(6)}`;
}

// E-mail s hvězdičkami místo jména, doména zůstane.
function maskEmail(email) {
  const at = email.indexOf('@');
  if (at === -1) {
    return email;
  }
  return email.slice(0, 1) + '*'.repeat(at - 1) + email.slice(at);
}

// Platný telefon: po odstranění mezer přesně 9 číslic.
function isValidPhone(phone) {
  const digits = phone.replaceAll(' ', '');
  if (digits.length !== 9) {
    return false;
  }
  for (const char of digits) {
    if (!'0123456789'.includes(char)) {
      return false;
    }
  }
  return true;
}
```
