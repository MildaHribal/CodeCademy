# --description--

Teď už může fungovat pořádné hledání. Uživatel napíše do vyhledávání `zidle`, `ŽIDLE` nebo ` židle ` a pokaždé chce najít inzerát `Židle IKEA`.

**Úkol:** Napiš funkci `matchesSearch(title, query)`, která vrátí `true`, když titulek obsahuje hledaný text. Nesmí přitom rozhodovat:

- velikost písmen,
- diakritika (v titulku ani v hledaném textu),
- mezery na krajích hledaného textu.

Prázdné hledání odpovídá každému titulku.

Hodí se ti tvoje `removeDiacritics`, `toLowerCase`, `trim` a `includes` — rozmysli si, na kterou stranu porovnání patří který.

> [!TIP]
> Tady máš hotové hledání, klidně si dej pauzu. Zbytek workshopu přidá adresu inzerátu, počítadlo znaků a nakonec živý náhled.

# --hints--

`matchesSearch` najde titulek bez ohledu na diakritiku a velikost písmen.

```js
assert.equal(matchesSearch('Židle IKEA', 'zidle'), true, "matchesSearch('Židle IKEA', 'zidle') má vrátit true");
assert.equal(matchesSearch('Horske kolo', 'HORSKÉ'), true, "matchesSearch('Horske kolo', 'HORSKÉ') má vrátit true — diakritika nerozhoduje ani v hledaném textu");
```

Mezery na krajích hledaného textu nevadí.

```js
assert.equal(matchesSearch('Horské kolo Author', '  kolo '), true, "matchesSearch('Horské kolo Author', '  kolo ') má vrátit true — mezery na krajích hledání se ignorují");
```

Když titulek hledaný text neobsahuje, vrátí `matchesSearch` `false`.

```js
assert.equal(matchesSearch('Přilba Abus', 'kolo'), false, "matchesSearch('Přilba Abus', 'kolo') má vrátit false");
```

Prázdné hledání odpovídá každému titulku.

```js
assert.equal(matchesSearch('Přilba Abus', ''), true, "matchesSearch('Přilba Abus', '') má vrátit true");
assert.equal(matchesSearch('Přilba Abus', '   '), true, "matchesSearch('Přilba Abus', '   ') má vrátit true — hledání jen z mezer je prázdné");
```

# --help--

## --tip--

Hledání bez diakritiky popisuje konec části [Diakritika a normalize](see:js-retezce-cisla/retezce#diakritika-a-normalize).

## --tip--

Obě strany převeď do stejné podoby: bez diakritiky a malými písmeny. Hledanému textu navíc ořízni mezery. Pak stačí jedno `includes`.

## --tip--

Na jiných datech: `removeDiacritics('Čeněk').toLowerCase()` a `removeDiacritics('ČENĚK').toLowerCase()` dají stejný text `cenek`.

}

function maskEmail(email) {

    }

// Od kolegy: text bez háčků a čárek, pro hledání a adresy inzerátů.
function removeDiacritics(text) {
  return text.normalize('NFD').replace(/\p{M}/gu, '');
}

// Obsahuje titulek hledaný text? Rozhoduje jen písmeno, ne velikost ani diakritika.
function matchesSearch(title, query) {
  const normalizedTitle = removeDiacritics(title).toLowerCase();
  const normalizedQuery = removeDiacritics(query.trim()).toLowerCase();
  return normalizedTitle.includes(normalizedQuery);
}
