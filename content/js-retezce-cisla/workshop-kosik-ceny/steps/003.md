# --description--

U každé hry v košíku je políčko „Počet kusů". Jeho hodnota přijde vždycky jako **text** — a zákazník do něj může napsat cokoli, nebo ho nechat prázdné.

**Úkol:** Napiš funkci `parseQuantity(input)`, která z textu udělá počet kusů:

- text s číslem převede na číslo (mezery na krajích nevadí): `' 3 '` → `3`,
- desetinné číslo zaokrouhlí dolů: `'2.7'` → `2`,
- když text číslo není (`'tři'`), je prázdný nebo je menší než `1`, vrátí `1` — v košíku je vždycky aspoň jeden kus.

Převod přísně celého textu udělá **`Number(text)`**, nečíslo pozná **`Number.isNaN(číslo)`**. Pozor, prázdný text je pro `Number` nula — ošetří ho podmínka „menší než 1". Na jiných datech:

```js
// 1. převeď text
const age = Number(' 42 ');

// 2. ověř, že jde o číslo
if (Number.isNaN(age)) {
  console.log('Věk není číslo');
}
```

# --hints--

`parseQuantity` převede text s číslem na číslo a mezery na krajích ignoruje.

```js
assert.equal(parseQuantity('3'), 3, "parseQuantity('3') má vrátit číslo 3");
assert.equal(parseQuantity(' 12 '), 12, "parseQuantity(' 12 ') má vrátit 12");
```

Desetinné číslo `parseQuantity` zaokrouhlí dolů.

```js
assert.equal(parseQuantity('2.7'), 2, "parseQuantity('2.7') má vrátit 2");
```

Nečíselný, prázdný nebo příliš malý vstup dá `1`.

```js
assert.equal(parseQuantity('tři'), 1, "parseQuantity('tři') má vrátit 1 — text není číslo");
assert.equal(parseQuantity(''), 1, "parseQuantity('') má vrátit 1 — pozor, Number('') je 0");
assert.equal(parseQuantity('0'), 1, "parseQuantity('0') má vrátit 1");
assert.equal(parseQuantity('-4'), 1, "parseQuantity('-4') má vrátit 1");
assert.equal(parseQuantity('3ks'), 1, "parseQuantity('3ks') má vrátit 1 — celý text musí být číslo");
```

## --tip--

Převody textu na číslo porovnává tabulka v části [Z textu na číslo](see:js-retezce-cisla/cisla#z-textu-na-cislo-number-parseint-parsefloat).

## --tip--

Po převodu přes `Number` ošetři jednou podmínkou oba špatné případy (`NaN` a číslo menší než 1). Na konci vrať číslo zaokrouhlené dolů.

# --solution--

## --file-- script.js

```js
// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}

// Počet kusů z textu formuláře; nesmysl, prázdné pole a méně než 1 → 1.
function parseQuantity(input) {
  const quantity = Number(input);
  if (Number.isNaN(quantity) || quantity < 1) {
    return 1;
  }
  return Math.floor(quantity);
}
```
