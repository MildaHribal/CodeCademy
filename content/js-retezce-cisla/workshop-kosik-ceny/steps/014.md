# --description--

## Hlášení

Zákazník poslal snímek potvrzovacího e-mailu: „Celkem 1299.0089 Kč. Kolik mám vlastně zaplatit?"

Text do e-mailu skládá kolegova funkce `orderTotalText(subtotalHalere, shippingHalere)`:

- `orderTotalText(129900, 8900)` vrací `'Celkem 1299.0089 Kč'`, čekali jsme `'Celkem 1388.00 Kč'`,
- `orderTotalText(150000, 0)` vrací `'Celkem 1500.000 Kč'`.

Šablona e-mailu opravdu chce tečku a dvě desetinná místa, český formát tu nepoužívej.

## Úkol

Oprav `orderTotalText` tak, aby vrátila součet mezisoučtu a dopravy s dvěma desetinnými místy. Změň co nejmenší kus kódu.

# --hints--

`orderTotalText` sečte mezisoučet a dopravu a vypíše je s dvěma desetinnými místy.

```js
assert.equal(orderTotalText(129900, 8900), 'Celkem 1388.00 Kč', "orderTotalText(129900, 8900) má vrátit 'Celkem 1388.00 Kč'");
assert.equal(orderTotalText(4990, 8900), 'Celkem 138.90 Kč', "orderTotalText(4990, 8900) má vrátit 'Celkem 138.90 Kč'");
```

Objednávka s dopravou zdarma má dvě desetinná místa.

```js
assert.equal(orderTotalText(150000, 0), 'Celkem 1500.00 Kč', "orderTotalText(150000, 0) má vrátit 'Celkem 1500.00 Kč'");
```

# --help--

## --tip--

Past odpovídá části [toFixed vrací řetězec](see:js-retezce-cisla/cisla#tofixed-vraci-retezec).

## --tip--

Jakého typu je `subtotal`? Co udělá `+` s řetězcem a číslem? Nejdřív sečti čísla, dvě desetinná místa přidej až výsledku.

## --tip--

Na jiných datech: `(12.5).toFixed(2) + 3` je `'12.503'`, kdežto `(12.5 + 3).toFixed(2)` je `'15.50'`.

# --explain--

Vysvětli vlastními slovy, jak z mezisoučtu 1 299 Kč a dopravy 89 Kč vznikl text `1299.0089`.

## --model--

`toFixed(2)` nevrací číslo, ale řetězec `'1299.00'`. Operátor `+` s řetězcem na jedné straně nesčítá, ale spojuje text, takže k `'1299.00'` přilepil `89`. Správně se nejdřív sečtou čísla a `toFixed` se použije až na výsledek, na výpis.

## --checklist--

- `toFixed` vrací řetězec.
- `+` s řetězcem spojuje text místo sčítání.
- Nejdřív se počítá s čísly, `toFixed` až na výpis.

```js
// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}

// Počet kusů z textu formuláře; nesmysl, prázdné pole a méně než 1 → 1.
function parseQuantity(input) {
  const quantity = Number(input);
  if (Number.isNaN(quantity) || quantity < 1) {
    return 1;
  }
  return Math.floor(quantity);
}

// Cena řádku v haléřích: cena za kus × počet kusů.
function lineTotal(unitPriceHalere, quantity) {
  return unitPriceHalere * quantity;
}

// Mezisoučet košíku v haléřích z cen jednotlivých řádků.
function cartSubtotal(lineTotals) {
  let subtotal = 0;
  for (const total of lineTotals) {
    subtotal += total;
  }
  return subtotal;
}

// DPH obsažená v ceně s DPH, v celých haléřích.
function vatIncluded(grossHalere, ratePercent) {
  return Math.round(grossHalere * ratePercent / (100 + ratePercent));
}

// Od kolegy: cena řádku pro starý export do účetnictví, které chce koruny.
function lineTotalKc(priceKc, quantity) {
  return Math.round(priceKc * quantity * 100) / 100;
}

// Cena v haléřích jako český text: 139770 → '1 397,70 Kč'.
function formatCzk(halere) {
  const czk = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK' });
  return czk.format(halere / 100);
}

// Řádek košíku: 'Carcassonne 2× · 1 598,00 Kč'.
function priceLine(name, unitPriceHalere, quantity) {
  return `${name} ${quantity}× · ${formatCzk(lineTotal(unitPriceHalere, quantity))}`;
}

// Cena po slevě v celých haléřích, zaokrouhlená na nejbližší haléř.
function applyDiscount(halere, percent) {
  return Math.round(halere * (100 - percent) / 100);
}

function gamesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} hra`;
  }
  if (category === 'few') {
    return `${count} hry`;
  }
  return `${count} her`;
}

// Počet kusů ve správném tvaru: 1 kus, 3 kusy, 7 kusů.
function piecesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} kus`;
  }
  if (category === 'few') {
    return `${count} kusy`;
  }
  return `${count} kusů`;
}

// Cena dopravy v haléřích: zdarma od 1 500 Kč a pro prázdný košík.
function shippingPrice(subtotalHalere) {
  if (subtotalHalere === 0 || subtotalHalere >= 150000) {
    return 0;
  }
  return 8900;
}

--edit--
// Od kolegy: text do potvrzovacího e-mailu, e-mailová šablona chce tečku a dvě desetinná místa.
function orderTotalText(subtotalHalere, shippingHalere) {
  const subtotal = (subtotalHalere / 100).toFixed(2);
  const shipping = shippingHalere / 100;
  return `Celkem ${subtotal + shipping} Kč`;
}
--edit--
```
