# --description--

Hrací doupě doručuje za **2 dny** od objednávky. Přepravce ale o víkendu nejezdí: když by doručení vyšlo na sobotu nebo neděli, přijde balík v pondělí.

**Úkol:** Napiš funkci `deliveryDate(orderDate)`, která dostane datum objednávky jako text `'2026-09-14'` a vrátí datum doručení ve stejném tvaru.

Kandidáti: `Temporal.PlainDate.from`, metoda `add` a vlastnost `dayOfWeek` (`1` pondělí až `7` neděle) — nebo `Date` s jeho `getDay` (`0` neděle až `6` sobota). Vyber si. S `Temporal` odpadnou měsíce od nuly i přetékání, `toString()` vrátí přesně tvar `2026-09-16`.

# --hints--

Objednávka v pondělí dorazí ve středu, na konci roku se přejde do dalšího roku.

```js
assert.equal(String(deliveryDate('2026-09-14')), '2026-09-16', "deliveryDate('2026-09-14') (pondělí) má vrátit '2026-09-16'");
assert.equal(String(deliveryDate('2026-12-30')), '2027-01-01', "deliveryDate('2026-12-30') má vrátit '2027-01-01'");
```

Doručení, které by vyšlo na sobotu, se posune na pondělí.

```js
assert.equal(String(deliveryDate('2026-09-17')), '2026-09-21', "deliveryDate('2026-09-17') (čtvrtek) má vrátit '2026-09-21' — sobota 19. 9. se posune na pondělí");
```

Doručení, které by vyšlo na neděli, se posune na pondělí.

```js
assert.equal(String(deliveryDate('2026-09-18')), '2026-09-21', "deliveryDate('2026-09-18') (pátek) má vrátit '2026-09-21' — neděle 20. 9. se posune na pondělí");
assert.equal(String(deliveryDate('2026-10-23')), '2026-10-26', "deliveryDate('2026-10-23') má vrátit '2026-10-26' — i o víkendu se změnou času");
```

# --help--

## --tip--

Počítání s datem bez pastí popisuje [Temporal: datum bez pastí](see:js-retezce-cisla/intl-a-datum#temporal-datum-bez-pasti).

## --tip--

Z textu vytvoř `PlainDate`, přičti dva dny a podle `dayOfWeek` výsledku přičti ještě dva dny (sobota), nebo jeden (neděle). Nakonec vrať `toString()`.

## --tip--

Na jiných datech: splatnost faktury za 14 dní je `Temporal.PlainDate.from(issued).add({ days: 14 }).toString()`.

// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}

// Počet kusů z textu formuláře; nesmysl, prázdné pole a méně než 1 → 1.
function parseQuantity(input) {
  const quantity = Number(input);
  if (Number.isNaN(quantity) || quantity < 1) {
    return 1;
  }
  return Math.floor(quantity);
}

// Cena řádku v haléřích: cena za kus × počet kusů.
function lineTotal(unitPriceHalere, quantity) {
  return unitPriceHalere * quantity;
}

// Mezisoučet košíku v haléřích z cen jednotlivých řádků.
function cartSubtotal(lineTotals) {
  let subtotal = 0;
  for (const total of lineTotals) {
    subtotal += total;
  }
  return subtotal;
}

// DPH obsažená v ceně s DPH, v celých haléřích.
function vatIncluded(grossHalere, ratePercent) {
  return Math.round(grossHalere * ratePercent / (100 + ratePercent));
}

// Od kolegy: cena řádku pro starý export do účetnictví, které chce koruny.
function lineTotalKc(priceKc, quantity) {
  return Math.round(priceKc * quantity * 100) / 100;
}

// Cena v haléřích jako český text: 139770 → '1 397,70 Kč'.
function formatCzk(halere) {
  const czk = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK' });
  return czk.format(halere / 100);
}

// Řádek košíku: 'Carcassonne 2× · 1 598,00 Kč'.
function priceLine(name, unitPriceHalere, quantity) {
  return `${name} ${quantity}× · ${formatCzk(lineTotal(unitPriceHalere, quantity))}`;
}

// Cena po slevě v celých haléřích, zaokrouhlená na nejbližší haléř.
function applyDiscount(halere, percent) {
  return Math.round(halere * (100 - percent) / 100);
}

function gamesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} hra`;
  }
  if (category === 'few') {
    return `${count} hry`;
  }
  return `${count} her`;
}

// Počet kusů ve správném tvaru: 1 kus, 3 kusy, 7 kusů.
function piecesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} kus`;
  }
  if (category === 'few') {
    return `${count} kusy`;
  }
  return `${count} kusů`;
}

// Cena dopravy v haléřích: zdarma od 1 500 Kč a pro prázdný košík.
function shippingPrice(subtotalHalere) {
  if (subtotalHalere === 0 || subtotalHalere >= 150000) {
    return 0;
  }
  return 8900;
}

// Od kolegy: text do potvrzovacího e-mailu, e-mailová šablona chce tečku a dvě desetinná místa.
function orderTotalText(subtotalHalere, shippingHalere) {
  const subtotal = subtotalHalere / 100;
  const shipping = shippingHalere / 100;
  return `Celkem ${(subtotal + shipping).toFixed(2)} Kč`;
}

// Datum doručení: za 2 dny, víkend se posune na pondělí. Vstup i výstup '2026-09-14'.
function deliveryDate(orderDate) {
  let delivery = Temporal.PlainDate.from(orderDate).add({ days: 2 });
  if (delivery.dayOfWeek === 6) {
    delivery = delivery.add({ days: 2 });
  } else if (delivery.dayOfWeek === 7) {
    delivery = delivery.add({ days: 1 });
  }
  return delivery.toString();
