# --description--

V tomhle workshopu spočítáš košík e-shopu **Hrací doupě**, který prodává deskové hry. Postupně napíšeš převod na haléře, součet košíku, DPH, slevu, dopravu, „3 hry" ve správném tvaru a datum doručení. V posledních krocích z funkcí oživíš **shrnutí košíku**, které se přepočítá, jakmile zákazník změní počet kusů.

Začneš něčím, co už umíš, a to bez návodu.

**Úkol:** Napiš funkci `shippingLabel(shippingKc)`, která pro cenu dopravy `0` vrátí `Doprava zdarma`, jinak text `Doprava 89 Kč` s cenou z parametru.

# --hints--

Pro nulovou cenu vrátí `shippingLabel` text `Doprava zdarma`.

```js
assert.equal(shippingLabel(0), 'Doprava zdarma', "shippingLabel(0) má vrátit 'Doprava zdarma'");
```

Pro jinou cenu vrátí `shippingLabel` text `Doprava` s cenou a `Kč`.

```js
assert.equal(shippingLabel(89), 'Doprava 89 Kč', "shippingLabel(89) má vrátit 'Doprava 89 Kč'");
assert.equal(shippingLabel(129), 'Doprava 129 Kč', "shippingLabel(129) má vrátit 'Doprava 129 Kč'");
```

# --solution--

## --file-- script.js

```js
// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}
```
