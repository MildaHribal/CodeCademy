# --description--

Haléře zákazníkovi ukázat nejde. `79900` musí na stránce vypadat jako `799,00 Kč` a `139770` jako `1 397,70 Kč` — s čárkou, mezerou mezi tisíci a `Kč` za číslem.

**Úkol:** Napiš funkci `formatCzk(halere)`, která cenu v haléřích vrátí jako český text ceny.

Použij formatter **`new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK' })`** a jeho metodu **`format`**. Formatter počítá s korunami, takže haléře vyděl stovkou až uvnitř `format(…)`. Na jiných datech (ceny v centech v eurech):

```js
const eur = new Intl.NumberFormat('de-DE', { style: 'currency', currency: 'EUR' });
const label = eur.format(1990 / 100);
```

> [!NOTE]
> Mezery ve výsledku jsou nezalomitelné (U+00A0), aby se cena nerozdělila na dva řádky. Kontroly s tím počítají.

# --hints--

`formatCzk` vrátí cenu s čárkou, dvěma desetinnými místy a `Kč`.

```js
const plain = (text) => String(text).replace(/\s/g, ' ');
assert.equal(plain(formatCzk(79900)), '799,00 Kč', "formatCzk(79900) má vrátit '799,00 Kč'");
assert.equal(plain(formatCzk(4990)), '49,90 Kč', "formatCzk(4990) má vrátit '49,90 Kč'");
```

Tisíce jsou oddělené mezerou.

```js
const plain = (text) => String(text).replace(/\s/g, ' ');
assert.equal(plain(formatCzk(139770)), '1 397,70 Kč', "formatCzk(139770) má vrátit '1 397,70 Kč'");
```

Nula je `0,00 Kč`.

```js
const plain = (text) => String(text).replace(/\s/g, ' ');
assert.equal(plain(formatCzk(0)), '0,00 Kč', "formatCzk(0) má vrátit '0,00 Kč'");
```

Cena je česky i v prohlížeči nastaveném na jiný jazyk.

```js
// Prohlížeč bez češtiny: formátovač bez zadaného jazyka dostane angličtinu.
const english = (locales) => (locales === undefined || (Array.isArray(locales) && locales.length === 0) ? 'en' : locales);
const plain = (text) => String(text).replace(/\s/g, ' ');
const OriginalNumberFormat = Intl.NumberFormat;
const originalToLocaleString = Number.prototype.toLocaleString;
Intl.NumberFormat = function (locales, options) {
  return new OriginalNumberFormat(english(locales), options);
};
Number.prototype.toLocaleString = function (locales, options) {
  return originalToLocaleString.call(this, english(locales), options);
};
try {
  assert.equal(plain(formatCzk(139770)), '1 397,70 Kč', "formatCzk(139770) má vrátit '1 397,70 Kč' i v prohlížeči nastaveném na angličtinu — jazyk 'cs-CZ' patří do kódu");
} finally {
  Intl.NumberFormat = OriginalNumberFormat;
  Number.prototype.toLocaleString = originalToLocaleString;
}
```

## --tip--

Formátování měny je v části [Intl.NumberFormat: ceny, procenta a jednotky](see:js-retezce-cisla/intl-a-datum#intl-numberformat-ceny-procenta-a-jednotky).

Formatter si klidně vytvoř uvnitř funkce. Do `format` pošli haléře vydělené stovkou a výsledek vrať.
