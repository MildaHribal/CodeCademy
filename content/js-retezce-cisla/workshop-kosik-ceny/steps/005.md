# --description--

Mezisoučet košíku je součet všech řádků.

**Úkol:** Napiš funkci `cartSubtotal(lineTotals)`, která dostane **pole** cen řádků v haléřích, třeba `[79900, 44900, 14970]`, a vrátí jejich součet. Prázdný košík má součet `0`.

S poli se pořádně seznámíš v sekci Pole. Na tenhle krok stačí vědět, že pole projdeš cyklem **`for…of`** stejně jako znaky řetězce. Průběžný součet drž v proměnné přes `let` a přičítej k ní operátorem `+=`. Na jiných datech:

```js
const distancesKm = [12, 8, 21];

// 1. začni od nuly
let totalKm = 0;

// 2. přičti každou položku
for (const distance of distancesKm) {
  totalKm += distance;
}
```

# --hints--

`cartSubtotal` sečte ceny řádků v haléřích.

```js
assert.equal(cartSubtotal([79900, 44900, 14970]), 139770, 'cartSubtotal([79900, 44900, 14970]) má vrátit 139770');
assert.equal(cartSubtotal([4990]), 4990, 'cartSubtotal([4990]) má vrátit 4990');
```

Prázdný košík má součet `0`.

```js
assert.equal(cartSubtotal([]), 0, 'cartSubtotal([]) má vrátit 0');
```

# --help--

## --tip--

## --tip--

Součet začni na nule, v cyklu k němu přičítej každou cenu a po cyklu ho vrať.

# --solution--

## --file-- script.js

```js
// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}

// Počet kusů z textu formuláře; nesmysl, prázdné pole a méně než 1 → 1.
function parseQuantity(input) {
  const quantity = Number(input);
  if (Number.isNaN(quantity) || quantity < 1) {
    return 1;
  }
  return Math.floor(quantity);
}

// Cena řádku v haléřích: cena za kus × počet kusů.
function lineTotal(unitPriceHalere, quantity) {
  return unitPriceHalere * quantity;
}

// Mezisoučet košíku v haléřích z cen jednotlivých řádků.
function cartSubtotal(lineTotals) {
  let subtotal = 0;
  for (const total of lineTotals) {
    subtotal += total;
  }
  return subtotal;
}
```
