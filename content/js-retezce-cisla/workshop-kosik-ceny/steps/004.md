# --description--

Řádek košíku ukazuje cenu za všechny kusy jedné hry.

**Úkol:** Napiš funkci `lineTotal(unitPriceHalere, quantity)`, která vrátí cenu řádku v haléřích: cena za kus krát počet kusů.

Protože obě čísla jsou celá, výsledek je přesný a nic se nezaokrouhluje. Na jiných datech (vstupenky na festival):

```js
const ticketHalere = 129000;
const tickets = 3;
const ticketsTotal = ticketHalere * tickets;
```

# --hints--

`lineTotal` vynásobí cenu za kus počtem kusů.

```js
assert.equal(lineTotal(79900, 2), 159800, 'lineTotal(79900, 2) má vrátit 159800');
assert.equal(lineTotal(4990, 3), 14970, 'lineTotal(4990, 3) má vrátit 14970 — přesně 149,70 Kč');
assert.equal(lineTotal(44900, 1), 44900, 'lineTotal(44900, 1) má vrátit 44900');
```

# --solution--

## --file-- script.js

```js
// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}

// Počet kusů z textu formuláře; nesmysl, prázdné pole a méně než 1 → 1.
function parseQuantity(input) {
  const quantity = Number(input);
  if (Number.isNaN(quantity) || quantity < 1) {
    return 1;
  }
  return Math.floor(quantity);
}

// Cena řádku v haléřích: cena za kus × počet kusů.
function lineTotal(unitPriceHalere, quantity) {
  return unitPriceHalere * quantity;
}
```
