# --description--

Ceny přicházejí z administrace v korunách: `799`, `49.9`, `4.35`. Počítat s nimi budeš v celých haléřích, protože desetinná čísla jsou v počítači jen přibližná.

**Úkol:** Napiš funkci `toHalere(koruny)`, která cenu v korunách převede na **celé** haléře.

Vynásobit stovkou nestačí: `4.35 * 100` je `434.99999999999994`. Výsledek násobení proto zaokrouhli na nejbližší celé číslo přes **`Math.round`**. Na jiných datech (délka v metrech na celé centimetry):

```js
const lengthM = 1.15;
const lengthCm = Math.round(lengthM * 100);
```

> [!PITFALL]
> `Math.floor(4.35 * 100)` vrátí `434` — dolů zaokrouhlené `434.999…` ztratí haléř. Na převod patří `Math.round`.

# --hints--

`toHalere` převede cenu v korunách na celé haléře.

```js
assert.equal(toHalere(799), 79900, 'toHalere(799) má vrátit 79900');
assert.equal(toHalere(19.99), 1999, 'toHalere(19.99) má vrátit 1999');
```

`toHalere` vrátí celé číslo i u cen, kde násobení stovkou vyjde nepřesně.

```js
assert.equal(toHalere(4.35), 435, 'toHalere(4.35) má vrátit 435, ne 434.99999999999994');
assert.equal(toHalere(1.15), 115, 'toHalere(1.15) má vrátit 115, ne 114.99999999999999');
assert.equal(toHalere(49.9), 4990, 'toHalere(49.9) má vrátit 4990');
```

## --tip--

Nejdřív vynásob stovkou, pak výsledek pošli do `Math.round` a vrať ho.

# --explain--

Vysvětli vlastními slovy, proč e-shop převádí ceny na haléře a proč při převodu nestačí vynásobit stovkou.

## --model--

Desetinná čísla se ve dvojkové soustavě ukládají jen přibližně, takže součty a násobky cen v korunách můžou vyjít o kousek vedle a po zaokrouhlení chybí haléř. Celá čísla jsou uložená přesně, proto počítám v haléřích. Samotné násobení stovkou ale může vyjít nepřesně, třeba `4.35 * 100` je `434.99999999999994`, a proto výsledek zaokrouhlím přes `Math.round` na nejbližší celé číslo.

## --checklist--

- Desetinná čísla jsou v počítači uložená jen přibližně.
- Celá čísla jsou přesná, proto se počítá v haléřích.
- Násobení stovkou může vyjít o kousek vedle.
- `Math.round` výsledek srovná na nejbližší celé číslo, `Math.floor` by haléř ubral.

## --file-- script.js

// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}
