# --description--

Ikona košíku ukazuje počet her. „1 hry" nebo „5 hra" vypadá jako rozbitý web, a jak ukázala lekce, podmínka `count === 1` na češtinu nestačí.

**Úkol:** Seřaď řádky tak, aby `gamesLabel(count)` vrátila počet s tvarem slova „hra": `1 hra`, `3 hry`, `5 her`.

Postup: `Intl.PluralRules` vrátí kategorii čísla a podle ní funkce vybere tvar. Takový vzor vidíš poprvé, proto ho jen skládáš; v dalším kroku ho napíšeš sám. Do mezery doplň kategorii pro čísla 2 až 4. Dva řádky jsou navíc.

# --hints--

`gamesLabel` vybere tvar podle českých pravidel pro 1, 2–4 a 5 a víc.

```js
assert.equal(gamesLabel(1), '1 hra', "gamesLabel(1) má vrátit '1 hra'");
assert.equal(gamesLabel(3), '3 hry', "gamesLabel(3) má vrátit '3 hry'");
assert.equal(gamesLabel(5), '5 her', "gamesLabel(5) má vrátit '5 her'");
```

Nula, 21 a 24 dostanou tvar podle češtiny, ne podle poslední číslice.

```js
assert.equal(gamesLabel(0), '0 her', "gamesLabel(0) má vrátit '0 her'");
assert.equal(gamesLabel(21), '21 her', "gamesLabel(21) má vrátit '21 her'");
assert.equal(gamesLabel(24), '24 her', "gamesLabel(24) má vrátit '24 her' — tvar „hry\" mají jen čísla 2 až 4");
```

## --tip--

Kategorie čísel popisuje [Množné číslo: Intl.PluralRules](see:js-retezce-cisla/intl-a-datum#mnozne-cislo-intl-pluralrules).

## --tip--

Kategorie jsou `'one'`, `'few'`, `'many'` a `'other'`. Čísla 2 až 4 patří do té, která v angličtině znamená „několik".

# --parsons--

```js
function gamesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} hra`;
  }
  if (category === __1__) {
    return `${count} hry`;
  }
  return `${count} her`;
}
```
