# --description--

Ceny v e-shopu jsou **s DPH**. Na faktuře ale musí být, kolik z ceny je daň. Deskové hry mají sazbu 21 %, knihy o hrách 0 % a třeba jídlo 12 %.

**Úkol:** Napiš funkci `vatIncluded(grossHalere, ratePercent)`, která vrátí DPH obsaženou v ceně s DPH, zaokrouhlenou na **celé haléře**.

Daň obsažená v ceně se počítá `cena × sazba / (100 + sazba)` — ne `cena × sazba / 100`, to by byla daň, kterou teprve přičítáš k ceně bez DPH. Výsledek zaokrouhli přes `Math.round`. Na jiných datech (spropitné 10 % obsažené v zaplacené částce):

```js
const paidHalere = 55000;
const tipPercent = 10;
const tipIncluded = Math.round(paidHalere * tipPercent / (100 + tipPercent));
```

# --hints--

`vatIncluded` vrátí DPH obsaženou v ceně s DPH.

```js
assert.equal(vatIncluded(121000, 21), 21000, 'vatIncluded(121000, 21) má vrátit 21000 — z 1 210 Kč s DPH je daň 210 Kč');
assert.equal(vatIncluded(11200, 12), 1200, 'vatIncluded(11200, 12) má vrátit 1200');
```

Výsledek je zaokrouhlený na celé haléře.

```js
assert.equal(vatIncluded(79900, 21), 13867, 'vatIncluded(79900, 21) má vrátit 13867 (13866,94… zaokrouhleno na celé haléře)');
```

S nulovou sazbou je DPH nula.

```js
assert.equal(vatIncluded(59900, 0), 0, 'vatIncluded(59900, 0) má vrátit 0');
```
