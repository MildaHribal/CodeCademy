# --description--

Shrnutí košíku bude psát „doručíme pozítří" nebo „za 3 dny". Nejdřív potřebuješ počet kalendářních dnů mezi dvěma daty.

**Úkol:** Napiš funkci `daysUntil(fromDate, toDate)`, která dostane dvě data jako text `'2026-09-14'` a vrátí, o kolik **kalendářních dnů** je `toDate` později. Stejné datum dá `0`.

Nástroj si vyber sám. Pamatuj na past z lekce: ne každý den má 24 hodin, a kontroly se ptají i přes změnu času.

# --hints--

`daysUntil` vrátí počet kalendářních dnů mezi daty.

```js
assert.equal(daysUntil('2026-09-14', '2026-09-16'), 2, "daysUntil('2026-09-14', '2026-09-16') má vrátit 2");
assert.equal(daysUntil('2026-09-14', '2026-12-24'), 101, "daysUntil('2026-09-14', '2026-12-24') má vrátit 101");
assert.equal(daysUntil('2026-09-14', '2026-09-14'), 0, "daysUntil('2026-09-14', '2026-09-14') má vrátit 0");
```

Počet dní sedí i přes změnu času na podzim a na jaře.

```js
assert.equal(daysUntil('2026-10-24', '2026-10-27'), 3, "daysUntil('2026-10-24', '2026-10-27') má vrátit 3 — 25. října má den 25 hodin");
assert.equal(daysUntil('2027-03-27', '2027-03-30'), 3, "daysUntil('2027-03-27', '2027-03-30') má vrátit 3 — 28. března má den jen 23 hodin");
```

# --help--

## --tip--

Proč nestačí dělit milisekundy, ukazuje past [Rozdíl dnů a letní čas](see:js-retezce-cisla/intl-a-datum#rozdil-dnu-a-letni-cas).

## --tip--

Jedna cesta počítá kalendářní dny přímo (typ pro datum bez času má metodu, která vrátí délku do jiného data). Druhá dělí rozdíl milisekund délkou dne — pak ale výsledek musí zaokrouhlit tak, aby 2,96 i 3,04 dalo 3.

## --tip--

Podcíle bez ohledu na cestu:

```js
// 1. z obou textů vyrob datum
// 2. zjisti rozdíl v dnech
// 3. vrať celé číslo
```

# --explain--

Vysvětli vlastními slovy, proč `Math.floor((to - from) / 86400000)` nad objekty `Date` může vrátit o den méně.

## --model--

Rozdíl dvou `Date` je v milisekundách a dělení 86 400 000 předpokládá, že každý den má 24 hodin. V noci, kdy se mění letní čas, má ale den 23 nebo 25 hodin, takže rozdíl vyjde třeba 2,96 dne a `Math.floor` z něj udělá 2. `Temporal.PlainDate` a `until` počítají kalendářní dny bez hodin, a proto takovou chybu nemají.

## --checklist--

- Rozdíl objektů `Date` je v milisekundách.
- Při změně letního času nemá den 24 hodin.
- Rozdíl pak není celé číslo a zaokrouhlení dolů ubere den.
- `Temporal.PlainDate` s `until` počítá kalendářní dny.

```js
// Hrací doupě: ceny v košíku e-shopu s deskovými hrami.
// Peníze se počítají v celých haléřích (79900 = 799,00 Kč), na koruny se převádí až při výpisu.

// Popisek dopravy v korunách: 0 → 'Doprava zdarma'.
function shippingLabel(shippingKc) {
  if (shippingKc === 0) {
    return 'Doprava zdarma';
  }
  return `Doprava ${shippingKc} Kč`;
}

// Cena v korunách → celé haléře (4.35 → 435).
function toHalere(koruny) {
  return Math.round(koruny * 100);
}

// Počet kusů z textu formuláře; nesmysl, prázdné pole a méně než 1 → 1.
function parseQuantity(input) {
  const quantity = Number(input);
  if (Number.isNaN(quantity) || quantity < 1) {
    return 1;
  }
  return Math.floor(quantity);
}

// Cena řádku v haléřích: cena za kus × počet kusů.
function lineTotal(unitPriceHalere, quantity) {
  return unitPriceHalere * quantity;
}

// Mezisoučet košíku v haléřích z cen jednotlivých řádků.
function cartSubtotal(lineTotals) {
  let subtotal = 0;
  for (const total of lineTotals) {
    subtotal += total;
  }
  return subtotal;
}

// DPH obsažená v ceně s DPH, v celých haléřích.
function vatIncluded(grossHalere, ratePercent) {
  return Math.round(grossHalere * ratePercent / (100 + ratePercent));
}

// Od kolegy: cena řádku pro starý export do účetnictví, které chce koruny.
function lineTotalKc(priceKc, quantity) {
  return Math.round(priceKc * quantity * 100) / 100;
}

// Cena v haléřích jako český text: 139770 → '1 397,70 Kč'.
function formatCzk(halere) {
  const czk = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK' });
  return czk.format(halere / 100);
}

// Řádek košíku: 'Carcassonne 2× · 1 598,00 Kč'.
function priceLine(name, unitPriceHalere, quantity) {
  return `${name} ${quantity}× · ${formatCzk(lineTotal(unitPriceHalere, quantity))}`;
}

// Cena po slevě v celých haléřích, zaokrouhlená na nejbližší haléř.
function applyDiscount(halere, percent) {
  return Math.round(halere * (100 - percent) / 100);
}

function gamesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} hra`;
  }
  if (category === 'few') {
    return `${count} hry`;
  }
  return `${count} her`;
}

// Počet kusů ve správném tvaru: 1 kus, 3 kusy, 7 kusů.
function piecesLabel(count) {
  const category = new Intl.PluralRules('cs').select(count);
  if (category === 'one') {
    return `${count} kus`;
  }
  if (category === 'few') {
    return `${count} kusy`;
  }
  return `${count} kusů`;
}

// Cena dopravy v haléřích: zdarma od 1 500 Kč a pro prázdný košík.
function shippingPrice(subtotalHalere) {
  if (subtotalHalere === 0 || subtotalHalere >= 150000) {
    return 0;
  }
  return 8900;
}

// Od kolegy: text do potvrzovacího e-mailu, e-mailová šablona chce tečku a dvě desetinná místa.
function orderTotalText(subtotalHalere, shippingHalere) {
  const subtotal = subtotalHalere / 100;
  const shipping = shippingHalere / 100;
  return `Celkem ${(subtotal + shipping).toFixed(2)} Kč`;
}

// Datum doručení: za 2 dny, víkend se posune na pondělí. Vstup i výstup '2026-09-14'.
function deliveryDate(orderDate) {
  let delivery = Temporal.PlainDate.from(orderDate).add({ days: 2 });
  if (delivery.dayOfWeek === 6) {
    delivery = delivery.add({ days: 2 });
  } else if (delivery.dayOfWeek === 7) {
    delivery = delivery.add({ days: 1 });
  }
  return delivery.toString();
}

// Datum doručení česky: '2026-09-16' → 'středa 16. září'.
function formatDeliveryDate(isoDate) {
  return Temporal.PlainDate.from(isoDate).toLocaleString('cs-CZ', { weekday: 'long', day: 'numeric', month: 'long' });
}
```
