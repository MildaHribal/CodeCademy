# --description--

Marketing chce u některých her podtitul: „Azul: Portugalské kachličky". U jiných
žádný nebude. Kdyby byl podtitul povinný, musela by ho mít každá hra v katalogu —
a kdyby byl jen `string`, musel by být všude aspoň prázdný text.

**Úkol:** rozšiř katalog o nepovinné podtituly.

1. V typu `Hra` přidej klíč `podtitul` s textem, který **může chybět**.
2. Doplň podtitul dvěma hrám v katalogu: Azulu (id 1) a Dixitu (id 3). Text si
   vymysli, bude vidět na účtence.
3. V `kosik.ts` napiš a vyexportuj funkci `nazevHry(hra)`. Vrátí název a za
   dvojtečkou podtitul (`Azul: Portugalské kachličky`), a když hra podtitul nemá,
   jen její název.

Volitelný klíč pozná TypeScript podle jednoho znaku za jménem klíče. Ten znak do
typu přidá `undefined`, takže na `hra.podtitul` se nedá sáhnout, dokud neřekneš,
co se stane, když chybí.

# --hints--

Klíč `podtitul` je v typu `Hra` volitelný.

```js
const kod = [
  "import type { Hra } from './katalog.ts';",
  "const bez: Hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'skladem' };",
  "const s: Hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'skladem', podtitul: 'Zachraň svět' };",
  "// @ts-expect-error podtitul může chybět, nedá se na něj rovnou sáhnout",
  "const delka: number = bez.podtitul.length;",
  "console.log(bez, s, delka);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Klíč podtitul má být v typu Hra volitelný (a jen textový). Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

`nazevHry` spojí název a podtitul dvojtečkou a mezerou.

```js
const { nazevHry } = await helpers.importFile('kosik.ts');
const hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'skladem', podtitul: 'Zachraň svět' };
assert.equal(nazevHry(hra), 'Pandemic: Zachraň svět', "nazevHry(hra s podtitulem) má vrátit 'Pandemic: Zachraň svět'");
```

Když hra podtitul nemá, `nazevHry` vrátí jen název.

```js
const { nazevHry } = await helpers.importFile('kosik.ts');
assert.equal(nazevHry({ id: 9, nazev: 'Pandemic', cena: 1190, stav: 'skladem' }), 'Pandemic', 'nazevHry(hra bez podtitulu) má vrátit jen Pandemic, bez dvojtečky');
assert.equal(nazevHry({ id: 9, nazev: 'Duch', cena: 290, stav: 'skladem', podtitul: '' }), 'Duch', 'nazevHry(hra s prázdným podtitulem) má vrátit jen Duch');
```

Azul a Dixit mají v katalogu podtitul, Osadníci ne.

```js
const { najdiHru } = await helpers.importFile('kosik.ts');
assert.equal(typeof najdiHru(1).podtitul, 'string', 'Azul (id 1) má mít v katalogu podtitul');
assert.ok(najdiHru(1).podtitul.length > 0, 'podtitul Azulu nemá být prázdný text');
assert.equal(typeof najdiHru(3).podtitul, 'string', 'Dixit (id 3) má mít v katalogu podtitul');
assert.equal(najdiHru(2).podtitul, undefined, 'Osadníci z Katanu (id 2) mají zůstat bez podtitulu');
```

# --help--

## --tip--

Jde o [volitelný klíč](see:nastroje-typescript/zakladni-typy#volitelne-klice-a-readonly).
Značka pro „může chybět" se píše v typu, ne v datech.

## --tip--

V `nazevHry` se musíš rozhodnout mezi dvěma výsledky. Hodí se ti podmínka,
ternární operátor nebo `??` — vyber, co je v jednom výrazu nejčitelnější.

## --tip--

Stejný tvar na jiných datech:
`` const stitek = uzivatel.prezdivka ? `${uzivatel.jmeno} (${uzivatel.prezdivka})` : uzivatel.jmeno; ``

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}
```
