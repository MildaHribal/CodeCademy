# --description--

V minulém týmu někdo do katalogu omylem přidal položku přímo z komponenty
(`katalog.push(novaHra)`) a e-shop pak ukazoval jinou nabídku, než co bylo
v databázi. A jinde se přepisovalo `hra.id`, takže odkazy přestaly sedět.

Typy tyhle dvě věci umí zakázat — a stojí to jedno slovo.

**Úkol:** v `katalog.ts` zakaž dvě změny.

1. Klíč `id` v typu `Hra` už nepůjde po vytvoření hry přepsat.
2. Do `katalog` už nepůjde přidávat ani z něj mazat. Anotace pole se změní tak,
   aby z ní zbyly jen metody, které vracejí nové pole (`map`, `filter`, `slice`,
   `find`).

Obojí platí **jen při kontrole typů**. Za běhu je to pořád obyčejné pole
a obyčejný objekt — skutečný zámek dělá až `Object.freeze`.

# --hints--

Klíč `id` v typu `Hra` nejde přepsat.

```js
const kod = [
  "import type { Hra } from './katalog.ts';",
  "const hra: Hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'skladem' };",
  "hra.cena = 990;",
  "// @ts-expect-error id se po vytvoření nesmí měnit",
  "hra.id = 10;",
  "console.log(hra);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Klíč id má být v typu Hra jen ke čtení, ostatní klíče se měnit smí. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Do katalogu nejde přidávat, ale dá se z něj číst a filtrovat.

```js
const kod = [
  "import { katalog } from './katalog.ts';",
  "const levne = katalog.filter((hra) => hra.cena < 500);",
  "const prvni = katalog[0];",
  "// @ts-expect-error do katalogu se nesmí přidávat",
  "katalog.push(prvni);",
  "console.log(levne.length, prvni.nazev, katalog.length);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'katalog má být pole jen ke čtení — push nesmí projít, filter a čtení podle indexu ano. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Zbytek modulu funguje dál a kontrola typů projde.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
const { najdiHru, pridej, mezisoucet } = await helpers.importFile('kosik.ts');
assert.equal(najdiHru(5).nazev, 'Carcassonne', 'najdiHru(5) má dál vracet Carcassonne');
assert.equal(mezisoucet(pridej([], najdiHru(5), 2)), 1580, 'mezisoucet(pridej([], Carcassonne, 2)) má vrátit 1580');
```

# --help--

## --tip--

Hledáš slovo, kterým se v typu označí, že se hodnota po vytvoření nemění —
je v lekci [Volitelné klíče a readonly](see:nastroje-typescript/zakladni-typy#volitelne-klice-a-readonly).

## --tip--

Jednou ho napíšeš před jméno klíče v typu `Hra`, podruhé před typ pole
v anotaci `katalog`.

## --tip--

Stejný zápis na jiných datech: `type Uzivatel = { readonly email: string; jmeno: string }`
a `const role: readonly string[] = ['admin', 'redaktor'];`.

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}
```

## --file-- sklad.ts

```ts
import { najdiHru } from './kosik.ts';

// Sklad: co se dá hned koupit. Psal kolega Tomáš.
export function jeSkladem(id: number): boolean {
  const hra = najdiHru(id);
  return hra?.stav === 'skladem';
}

export function kolikSkladem(ids: number[]): number {
  return ids.filter((id) => jeSkladem(id)).length;
}
```
