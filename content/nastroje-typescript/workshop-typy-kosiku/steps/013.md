# --description--

Katalog se filtruje na deseti místech: co je skladem, co je do tisícovky, co má
podtitul. Napsat deset funkcí by bylo hloupé — stačí jedna, která podmínku
dostane jako parametr. Je to stejný vzor jako u `shrnuti`, jen místo formátovače
předáváš rozhodovací funkci.

**Úkol:** v `kosik.ts` napiš a vyexportuj funkci `filtrujKatalog(hry, podminka)`.

- První parametr je seznam her, který se nesmí měnit — takový, jaký je dnes
  `katalog`.
- Druhý parametr je funkce, která o jedné hře rozhodne ano/ne.
- Funkce vrátí nové pole her, které podmínkou prošly. Když neprojde žádná, vrátí
  prázdné pole.

Typ druhého parametru napiš rovnou do hlavičky, nové jméno typu pro něj
nezakládej.

# --hints--

`filtrujKatalog` vrátí jen hry, které projdou podmínkou.

```js
const { filtrujKatalog } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const skladem = filtrujKatalog(katalog, (hra) => hra.stav === 'skladem');
assert.deepEqual(skladem.map((hra) => hra.id), [1, 2, 5, 6], 'filtrujKatalog(katalog, hra => hra.stav === "skladem") má vrátit hry s id 1, 2, 5 a 6');
const levne = filtrujKatalog(katalog, (hra) => hra.cena < 500);
assert.deepEqual(levne.map((hra) => hra.nazev), ['Krycí jména', 'Čtyřlístek', 'Duch'], 'filtrujKatalog(katalog, hra => hra.cena < 500) má vrátit Krycí jména, Čtyřlístek a Ducha');
```

Když podmínkou neprojde nic, vrátí prázdné pole a původní seznam nechá být.

```js
const { filtrujKatalog } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
assert.deepEqual(filtrujKatalog(katalog, (hra) => hra.cena > 5000), [], 'filtrujKatalog na podmínku, kterou nic nesplní, má vrátit prázdné pole');
assert.equal(katalog.length, 7, 'filtrujKatalog nemá měnit původní katalog');
```

`filtrujKatalog` přijme i katalog, do kterého se nesmí zapisovat.

# --help--

## --tip--

Podmínka je funkce jako hodnota — stejně jako `Formatovac` v kroku
[Formátování ceny jako typ funkce](see:nastroje-typescript/workshop-typy-kosiku/011),
jen vrací něco jiného než text.

## --tip--

První parametr má být pole jen ke čtení, jinak do něj `katalog` nepošleš.
Samotné filtrování za tebe udělá metoda pole, kterou znáš z JavaScriptu.

## --tip--

Stejný tvar na jiných datech:
`export function vyberUzivatele(lidi: readonly Uzivatel[], podminka: (uzivatel: Uzivatel) => boolean): Uzivatel[]`

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}
```

```ts
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}

export function filtrujKatalog(hry: readonly Hra[], podminka: (hra: Hra) => boolean): Hra[] {
  return hry.filter(podminka);
}
```
