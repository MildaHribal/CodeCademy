# --description--

`stav: string` je typ, který nic nehlídá. Projde `'skladem'`, `'Skladem'`,
`'na sklade'` i `'ano'` — a e-shop pak zobrazí prázdné místo, protože se
podmínka `stav === 'skladem'` nikdy netrefí. Stav má jen tři možné hodnoty,
tak je do typu napiš.

**Úkol:** v `katalog.ts` napiš a vyexportuj typ `Stav`, který povolí jen
hodnoty `'skladem'`, `'na-objednavku'` a `'vyprodano'`, a použij ho u klíče
`stav` v typu `Hra`.

Stejný zápis na jiných datech — způsob dopravy:

```ts
export type Doprava = 'osobne' | 'zasilkovna' | 'kuryr';
```

Pak pusť `npx tsc --noEmit`. Kontrola najde v datech jednu hru, která tomuhle
typu neodpovídá — oprav ji tak, aby seděla na typ. Hodnoty stavů píše frontend
bez diakritiky a bez mezer.

# --hints--

Typ `Stav` povolí jen tři hodnoty a `Hra.stav` je typu `Stav`.

```js
const kod = [
  "import type { Hra, Stav } from './katalog.ts';",
  "const a: Stav = 'skladem';",
  "const b: Stav = 'na-objednavku';",
  "const c: Stav = 'vyprodano';",
  "// @ts-expect-error 'sklade' je překlep, do typu Stav nepatří",
  "const preklep: Stav = 'sklade';",
  "const hra: Hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'vyprodano' };",
  "const stav: Stav = hra.stav;",
  "console.log(a, b, c, preklep, stav);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Typ Stav má povolit právě skladem, na-objednavku a vyprodano a Hra.stav má být typu Stav. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Kontrola typů celého projektu projde — data v katalogu typu odpovídají.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby — jedna hra v katalogu má stav, který do typu Stav nepatří. Kontrola hlásí:\n' + r.stdout + r.stderr);
```

Krycí jména mají stav `vyprodano` a ostatní hry zůstaly beze změny.

```js
const { katalog, najdiHru } = { ...await helpers.importFile('katalog.ts'), ...await helpers.importFile('kosik.ts') };
assert.equal(katalog.length, 7, 'katalog má dál obsahovat všech sedm her');
assert.equal(najdiHru(4).stav, 'vyprodano', 'Krycí jména (id 4) mají mít stav vyprodano — bez diakritiky, hodnotu nemaž');
assert.deepEqual(katalog.map((hra) => hra.stav).filter((stav) => stav === 'skladem').length, 4, 'čtyři hry mají zůstat skladem');
```
