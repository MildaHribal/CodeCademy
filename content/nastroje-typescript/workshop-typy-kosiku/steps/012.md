# --description--

Účtenka potřebuje z košíku řádky: název hry s podtitulem, počet kusů a částka za
celou položku. Formátování částky si funkce nechá poslat zvenku — proto ten typ
`Formatovac` z minulého kroku.

Seřaď řádky tak, aby `shrnuti(kosik, format)` vrátila pole textů, jeden na každou
položku košíku. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc a do řešení
nepatří. V jednom místě chybí typ druhého parametru — doplň ho.

Tvar jednoho řádku: `Azul: Portugalské kachličky ×2 — 1 998 Kč`.

# --hints--

`shrnuti` vrátí jeden text na každou položku košíku.

```js
const { shrnuti, naKoruny } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const radky = shrnuti([{ hra: katalog[0], kusy: 2 }, { hra: katalog[6], kusy: 1 }], naKoruny);
assert.ok(Array.isArray(radky), 'shrnuti má vrátit pole textů');
assert.equal(radky.length, 2, 'shrnuti má vrátit dva řádky pro košík o dvou položkách');
```

Řádek obsahuje název s podtitulem, počet kusů a částku za celou položku.

```js
const { shrnuti, naKoruny } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const [prvni] = shrnuti([{ hra: katalog[0], kusy: 2 }], naKoruny);
assert.match(prvni, /^Azul: /u, `řádek má začínat názvem hry i s podtitulem, přišlo: ${prvni}`);
assert.match(prvni, /×2/u, `řádek má obsahovat počet kusů ×2, přišlo: ${prvni}`);
assert.match(prvni, /1\s998 Kč/u, `řádek má obsahovat částku za obě hry, tedy 1 998 Kč, přišlo: ${prvni}`);
```

Částku formátuje funkce, kterou `shrnuti` dostane v druhém parametru.

```js
const { shrnuti } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const [radek] = shrnuti([{ hra: katalog[6], kusy: 3 }], (castka) => `${castka} bodů`);
assert.match(radek, /870 bodů/u, `s formátovačem (castka) => castka + ' bodů' má řádek obsahovat „870 bodů", přišlo: ${radek}`);
```

Prázdný košík dá prázdné pole a kontrola typů projde.

```js
const { shrnuti, naKoruny } = await helpers.importFile('kosik.ts');
assert.deepEqual(shrnuti([], naKoruny), [], 'shrnuti([], naKoruny) má vrátit prázdné pole');
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
```

# --parsons--

```ts
export function shrnuti(kosik: Polozka[], format: __1__): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}
```

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;
```

```ts
// Sklad: co se dá hned koupit. Psal kolega Tomáš.
export function jeSkladem(id: number): boolean {
  const hra = najdiHru(id);
  return hra?.stav === 'skladem';

export function kolikSkladem(ids: number[]): number {
```
