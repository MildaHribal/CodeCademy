# --description--

Katalog je pole objektů a TypeScript si jeho tvar odvodil sám — jenže pokaždé
znovu a jen z těch dat, která tam právě jsou. Až budeš psát funkci, která hru
dostane jako parametr, budeš potřebovat **jméno** pro ten tvar.

**Úkol:** v `katalog.ts` napiš typ `Hra` a použij ho u katalogu.

1. `Hra` má klíče `id` (číslo), `nazev` (text), `cena` (číslo) a `stav` (text).
2. Typ exportuj, budeš ho importovat v dalším souboru.
3. Katalogu dej anotaci, že je to pole her.

Zápis pro jiná data — tvar recenze a pole recenzí:

```ts
export type Recenze = {
  hvezdicky: number;
  text: string;
};

export const recenze: Recenze[] = [{ hvezdicky: 5, text: 'Paráda.' }];
```

Po uložení pusť v terminálu `npx tsc --noEmit`. Když jsi typ napsal správně,
příkaz nevypíše nic.

# --hints--

Typ `Hra` popisuje hru s klíči `id`, `nazev`, `cena` a `stav`.

```js
const kod = [
  "import type { Hra } from './katalog.ts';",
  "const hra: Hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'skladem' };",
  "const nazev: string = hra.nazev;",
  "const cena: number = hra.cena;",
  "const stav: string = hra.stav;",
  "console.log(hra.id, nazev, cena, stav);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Typ Hra má mít klíče id (number), nazev (string), cena (number) a stav (string) a být exportovaný. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Typ `Hra` odmítne hru s cenou jako textem i hru bez názvu.

```js
const kod = [
  "import type { Hra } from './katalog.ts';",
  "// @ts-expect-error cena musí být číslo, ne text",
  "const spatnaCena: Hra = { id: 9, nazev: 'Pandemic', cena: '1190', stav: 'skladem' };",
  "// @ts-expect-error chybí klíč nazev",
  "const bezNazvu: Hra = { id: 9, cena: 1190, stav: 'skladem' };",
  "console.log(spatnaCena, bezNazvu);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Typ Hra má odmítnout cenu jako text a hru bez názvu — klíče nesmí být volitelné. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Data v katalogu zůstala beze změny.

```js
const { katalog } = await helpers.importFile('katalog.ts');
assert.equal(katalog.length, 7, 'katalog.ts má dál obsahovat všech sedm her');
assert.deepEqual(katalog.map((hra) => hra.id), [1, 2, 3, 4, 5, 6, 7], 'id her v katalogu se nemají měnit');
assert.deepEqual(katalog[1], { id: 2, nazev: 'Osadníci z Katanu', cena: 1290, stav: 'skladem' }, 'druhá hra v katalogu mají zůstat Osadníci z Katanu za 1290 Kč');
```

Kontrola typů celého projektu projde bez chyby.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
```

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}
```
