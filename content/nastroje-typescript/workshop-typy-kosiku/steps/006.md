# --description--

## Hlášení

Zákaznická podpora hlásí: „Když si někdo otevře odkaz na hru, která už v e-shopu
není, stránka se nenačte." V logu serveru je:

```text
TypeError: Cannot read properties of undefined (reading 'stav')
    at jeSkladem (sklad.ts:6:14)
```

Kontrola typů to viděla dopředu. `npx tsc --noEmit` hlásí:

```text
sklad.ts(6,10): error TS18048: 'hra' is possibly 'undefined'.
```

## Úkol

Oprav `jeSkladem` v `sklad.ts` tak, aby pro neznámé `id` vrátila `false` místo
pádu — hru, která v katalogu není, nemá smysl nabízet skladem. Ostatní funkce
v souboru nech být a změň co nejmenší kus kódu.

> [!PITFALL]
> Nepoužívej `hra!.stav` ani `as Hra`. Obojí kontrolu jen umlčí, ale hodnota
> zůstane `undefined` a program spadne dál.

# --hints--

`jeSkladem` pozná hru, která je skladem, i hru, která skladem není.

```js
const { jeSkladem } = await helpers.importFile('sklad.ts');
assert.equal(jeSkladem(1), true, 'jeSkladem(1) má vrátit true — Azul je skladem');
assert.equal(jeSkladem(3), false, 'jeSkladem(3) má vrátit false — Dixit je na objednávku');
assert.equal(jeSkladem(4), false, 'jeSkladem(4) má vrátit false — Krycí jména jsou vyprodaná');
```

`jeSkladem` u neznámého `id` vrátí `false` a nespadne.

```js
const { jeSkladem } = await helpers.importFile('sklad.ts');
assert.equal(jeSkladem(99), false, 'jeSkladem(99) má vrátit false, hra s id 99 v katalogu není');
assert.equal(jeSkladem(0), false, 'jeSkladem(0) má vrátit false');
```

`kolikSkladem` funguje dál, i když je mezi id neznámé číslo.

```js
const { kolikSkladem } = await helpers.importFile('sklad.ts');
assert.equal(kolikSkladem([1, 2, 3]), 2, 'kolikSkladem([1, 2, 3]) má vrátit 2 — Azul a Osadníci jsou skladem');
assert.equal(kolikSkladem([1, 99, 4]), 1, 'kolikSkladem([1, 99, 4]) má vrátit 1 a nespadnout na neznámém id');
assert.equal(kolikSkladem([]), 0, 'kolikSkladem([]) má vrátit 0');
```

Kontrola typů projde bez chyby.

# --help--

## --tip--

`najdiHru` vrací `Hra | undefined`, protože `find` nemusí nic najít. Kontrola ti
nedovolí sáhnout na vlastnost, dokud případ „nenašlo se" neošetříš — viz
[past `Object is possibly 'undefined'`](see:nastroje-typescript/zakladni-typy#typicke-chyby-a-pasti).

## --tip--

Ošetřit to jde buď podmínkou, která se z funkce vrátí dřív, nebo operátorem,
který na `undefined` nesáhne a rovnou vrátí `undefined`. Stejný tvar na jiných
datech: `najdiUzivatele(email)?.role === 'admin'`.

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}
```

## --file-- sklad.ts

```ts
import { najdiHru } from './kosik.ts';

// Sklad: co se dá hned koupit. Psal kolega Tomáš.
export function jeSkladem(id: number): boolean {
  const hra = najdiHru(id);
  return hra.stav === 'skladem';
}

export function kolikSkladem(ids: number[]): number {
  return ids.filter((id) => jeSkladem(id)).length;
}
```
