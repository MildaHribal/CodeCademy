# --description--

Testy ověřují, co kód **umí**. U typů je zajímavější druhá strana: co kontrola
**odmítne**. Kdyby někdo v typu `Stav` omylem změnil sjednocení na `string`,
všechny běžné testy projdou dál — a překlepy ve stavech se vrátí.

Na tohle má TypeScript direktivu `@ts-expect-error`. Napíšeš ji do komentáře nad
řádek a znamená: *na tomhle řádku čekám chybu*. Když tam chyba je, kontrola mlčí.
Když tam chyba **není**, kontrola se ozve sama (`TS2578: Unused '@ts-expect-error'
directive`) — takže test nikdy tiše nezestárne.

V projektu přibyl soubor `kontroly.ts`. V horní části jsou řádky, které projít
musí. Dolní část je na tobě.

**Úkol:** doplň do `kontroly.ts` tři situace, které kontrola typů odmítnout musí,
a nad každou z nich napiš direktivu s očekávanou chybou:

- hru se stavem, který v typu `Stav` není,
- položku košíku, která má počet kusů jako text,
- přidání hry do katalogu.

Pak pusť `npx tsc --noEmit`. Musí být ticho: každá direktiva má pod sebou
skutečnou chybu a projekt je jinak v pořádku.

# --hints--

Projekt i s doplněnými kontrolami projde kontrolou typů.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby — hlášení TS2578 znamená, že nad direktivou žádná chyba není. Kontrola hlásí:\n' + r.stdout + r.stderr);
```

V `kontroly.ts` jsou aspoň tři direktivy a každá kryje skutečnou chybu.

```js
const zdroj = files['kontroly.ts'] ?? '';
const pocet = (zdroj.match(/@ts-expect-error/g) || []).length;
assert.ok(pocet >= 3, `kontroly.ts má mít aspoň tři direktivy @ts-expect-error, našel jsem ${pocet}`);
const bezDirektiv = zdroj.replace(/^[\t ]*\/\/[\t ]*@ts-expect-error.*$/gm, '');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${bezDirektiv}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const radky = new Set(r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts(')).map((radek) => radek.split(':')[0]));
assert.ok(radky.size >= 3, `bez direktiv má kontrola typů najít aspoň tři chybné řádky, našla ${radky.size}. Výpis:\n` + r.stdout);
```

Tři hlídané situace: neplatný stav, počet kusů jako text a přidání do katalogu.

```js
const zdroj = files['kontroly.ts'] ?? '';
const bezDirektiv = zdroj.replace(/^[\t ]*\/\/[\t ]*@ts-expect-error.*$/gm, '');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${bezDirektiv}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const radky = bezDirektiv.split('\n');
const cisla = [...new Set([...r.stdout.matchAll(/^\.kontrola\.ts\((\d+),/gm)].map((shoda) => Number(shoda[1])))];
const chybne = cisla.map((cislo) => radky[cislo - 1] ?? '');
assert.ok(chybne.some((radek) => /stav/i.test(radek)), 'jedna z kontrol má být hodnota s neplatným stavem. Chybné řádky:\n' + chybne.join('\n') + '\n' + r.stdout);
assert.ok(chybne.some((radek) => /kusy/.test(radek)), 'jedna z kontrol má být položka košíku s počtem kusů jako textem. Chybné řádky:\n' + chybne.join('\n') + '\n' + r.stdout);
assert.ok(chybne.some((radek) => /push/.test(radek)), 'jedna z kontrol má být přidání hry do katalogu (katalog je jen ke čtení). Chybné řádky:\n' + chybne.join('\n') + '\n' + r.stdout);
```

# --help--

## --tip--

Direktiva se píše jako obyčejný řádkový komentář **nad** kontrolovaný řádek,
klidně i s vysvětlením za ní. Platí vždy jen na ten jeden následující řádek.

## --tip--

Hry, položky a katalog už máš v souboru naimportované z horní části. Stačí
zapsat hodnotu, která typu odporuje — třeba stav, který v seznamu stavů není.

## --tip--

Aby TypeScript proměnné nebral jako nepoužité, vypiš je na konci souboru do
`console.log` — stejně jako to dělá horní část souboru.

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}

export function filtrujKatalog(hry: readonly Hra[], podminka: (hra: Hra) => boolean): Hra[] {
  return hry.filter(podminka);
}

export function sleva(castka: number): number {
  if (castka <= 2000) return 0;
  return Math.min(Math.round(castka * 0.1), 500);
}

export function seradPodleNazvu(hry: readonly Hra[]): Hra[] {
  return [...hry].sort((a, b) => a.nazev.localeCompare(b.nazev, 'cs'));
}

export function celkem(kosik: Polozka[]): number {
  const mezi = mezisoucet(kosik);
  if (mezi === 0) return 0;
  const poSleve = mezi - sleva(mezi);
  return poSleve >= 2500 ? poSleve : poSleve + 99;
}
```

## --file-- kontroly.ts

```ts
// Typové testy. Nic nespouští a nic nepočítá — jen popisují, co kontrola typů
// musí přijmout a co musí odmítnout. Běží spolu s projektem: npx tsc --noEmit.
import { katalog, POPISY_STAVU } from './katalog.ts';
import type { Hra, Stav } from './katalog.ts';
import { mezisoucet, nazevHry } from './kosik.ts';
import type { Polozka } from './kosik.ts';

// Tohle projít musí.
const hra: Hra = { id: 99, nazev: 'Pandemic', cena: 1190, stav: 'skladem' };
const polozka: Polozka = { hra, kusy: 2 };
const soucet: number = mezisoucet([polozka]);
const popis: string = POPISY_STAVU[hra.stav];
console.log(nazevHry(hra), soucet, popis, katalog.length);

// Tohle projít nesmí. Nad každý takový řádek patří direktiva, která kontrole
// řekne, že tady chybu čekáš.
// @ts-expect-error 'sklade' není platný stav
const preklep: Stav = 'sklade';

// @ts-expect-error kusy musí být číslo, ne text
const spatnaPolozka: Polozka = { hra, kusy: '2' };

// @ts-expect-error katalog je readonly, hry do něj nejdou přidávat
katalog.push(hra);

console.log(preklep, spatnaPolozka);
```
