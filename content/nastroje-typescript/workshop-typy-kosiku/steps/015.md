# --description--

Katalog se zákazníkovi ukazuje seřazený podle názvu. Čtyřlístek patří mezi
Carcassonne a Dixit, ne až za Osadníky — a obyčejné řazení textů to samo neudělá.
Tuhle věc jsi psal v JavaScriptu, tak ji napiš znovu bez návodu.

**Úkol:** v `kosik.ts` napiš a vyexportuj funkci `seradPodleNazvu(hry)`. Dostane
seznam her jen ke čtení (takový, jaký je `katalog`), vrátí **nové** pole
seřazené podle názvu tak, jak by to čekal český zákazník. Původní seznam zůstane
beze změny.

Typy si tady vynutí, že to napíšeš správně: do seznamu jen ke čtení se řadit
nedá, takže tě kontrola sama postrčí k tomu vyrobit nejdřív kopii.

# --hints--

`seradPodleNazvu` seřadí hry podle české abecedy.

```js
const { seradPodleNazvu } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const serazene = seradPodleNazvu(katalog);
assert.deepEqual(serazene.map((hra) => hra.nazev), ['Azul', 'Carcassonne', 'Čtyřlístek', 'Dixit', 'Duch', 'Krycí jména', 'Osadníci z Katanu'], 'seradPodleNazvu(katalog) má vrátit hry v pořadí Azul, Carcassonne, Čtyřlístek, Dixit, Duch, Krycí jména, Osadníci z Katanu — Č patří mezi C a D');
```

Původní seznam zůstane beze změny.

```js
const { seradPodleNazvu } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const pred = katalog.map((hra) => hra.id);
seradPodleNazvu(katalog);
assert.deepEqual(katalog.map((hra) => hra.id), pred, 'seradPodleNazvu nemá měnit pořadí v původním katalogu — vrať nové pole');
```

Funkce si poradí i s prázdným seznamem a s jednou hrou.

```js
const { seradPodleNazvu, najdiHru } = await helpers.importFile('kosik.ts');
assert.deepEqual(seradPodleNazvu([]), [], 'seradPodleNazvu([]) má vrátit prázdné pole');
assert.deepEqual(seradPodleNazvu([najdiHru(7)]).map((hra) => hra.nazev), ['Duch'], 'seradPodleNazvu s jednou hrou má vrátit tu hru');
```

Řazení výslovně říká, že jde o češtinu.

```js
const zdroj = helpers.stripComments(files['kosik.ts'], 'js');
assert.match(zdroj, /localeCompare\([^)]*['"]cs['"]|Collator\(\s*['"]cs['"]/, "Jazyk 'cs' má být v kódu vidět (v localeCompare nebo v Intl.Collator). Bez něj se pořadí řídí nastavením počítače a na jiném stroji vyjde jinak.");
```

Kontrola typů projde bez chyby.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby — do pole jen ke čtení se řadit nedá, udělej si kopii. Hlásí:\n' + r.stdout + r.stderr);
```

# --explain--

Vysvětli vlastními slovy, proč `seradPodleNazvu` vrací nové pole místo toho, aby
seřadila to, které dostala.

## --model--

Řazení na místě mění pole, které patří někomu jinému — tady rovnou katalogu
celého e-shopu. Kdo si ho jinde v aplikaci vykresluje, najednou vidí jiné pořadí,
aniž by o to požádal, a chyba se hledá strašně těžko. Proto si funkce udělá kopii
a seřadí až tu. V typech je to vidět: katalog je označený jako pole jen ke čtení,
takže mi kontrola řazení na místě ani nedovolí.

## --checklist--

- Řazení na místě mění původní pole, ne kopii.
- Původní pole může používat i jiná část aplikace.
- Kopie vznikne rozbalením do nového pole.
- Typ jen ke čtení tuhle chybu odhalí ještě před spuštěním.

o češtinu.

## --tip--

`[...mesta].sort((a, b) => a.nazev.localeCompare(b.nazev, 'cs'))`

import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}

export function filtrujKatalog(hry: readonly Hra[], podminka: (hra: Hra) => boolean): Hra[] {
  return hry.filter(podminka);
}

export function sleva(castka: number): number {
  if (castka <= 2000) return 0;
  return Math.min(Math.round(castka * 0.1), 500);
}
