# --description--

Frontend chce do filtru „Dostupnost" vypsat všechny stavy jako tlačítka. Jenže
typ `Stav` za běhu neexistuje — nedá se z něj udělat pole. Napsat stavy podruhé
jako obyčejné pole by znamenalo mít je na dvou místech a jednou je zapomenout
srovnat.

Jde to naopak: napsat **seznam hodnot** a typ z něj nechat odvodit.

**Úkol:** v `katalog.ts` nahraď ručně psané sjednocení stavů odvozeným typem.

1. Vyexportuj konstantu `STAVY` s hodnotami `'skladem'`, `'na-objednavku'`
   a `'vyprodano'` v tomhle pořadí, a to tak, aby si TypeScript zapamatoval
   přesné hodnoty místo `string[]`.
2. Typ `Stav` odvoď z té konstanty, ať v souboru nejsou stavy napsané dvakrát.

Hodí se ti `as const`, operátor `typeof` (ten, který v typech vrátí typ hodnoty)
a indexování typu pole. Pořadí těch tří věcí musíš složit sám.

# --hints--

Konstanta `STAVY` obsahuje tři stavy v pořadí skladem, na-objednavku, vyprodano.

```js
const { STAVY } = await helpers.importFile('katalog.ts');
assert.ok(Array.isArray(STAVY), 'katalog.ts má exportovat pole STAVY');
assert.deepEqual([...STAVY], ['skladem', 'na-objednavku', 'vyprodano'], 'STAVY má obsahovat tři stavy v pořadí skladem, na-objednavku, vyprodano');
```

Typ `Stav` dál povolí jen tyhle tři hodnoty.

```js
const kod = [
  "import type { Hra, Stav } from './katalog.ts';",
  "const a: Stav = 'skladem';",
  "const b: Stav = 'vyprodano';",
  "// @ts-expect-error 'sklade' je překlep, do typu Stav nepatří",
  "const preklep: Stav = 'sklade';",
  "const hra: Hra = { id: 9, nazev: 'Pandemic', cena: 1190, stav: 'na-objednavku' };",
  "console.log(a, b, preklep, hra.stav);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Typ Stav má dál povolit právě skladem, na-objednavku a vyprodano. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Typ `Stav` je ze `STAVY` odvozený, ne opsaný podruhé.

```js
const zdroj = helpers.stripComments(files['katalog.ts'], 'js');
assert.match(zdroj, /typeof\s+STAVY/, 'Typ Stav má vzniknout z konstanty STAVY (přes typeof), ať nejsou stavy v souboru napsané dvakrát');
```

Kontrola typů projde a katalog zůstal beze změny.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
const { katalog } = await helpers.importFile('katalog.ts');
assert.equal(katalog.length, 7, 'katalog má dál obsahovat všech sedm her');
assert.equal(katalog[3].stav, 'vyprodano', 'Krycí jména mají dál stav vyprodano');
```

# --help--

## --tip--

Připomeň si [literálové typy](see:nastroje-typescript/zakladni-typy#sjednoceni-a-literalove-typy)
a tip o `as const` pod nimi: pole zapsané `as const` si nechá přesné hodnoty
a nerozšíří je na `string`.

## --tip--

`typeof STAVY` je typ toho pole. Z typu pole vytáhneš typ prvku hranatými
závorkami s `number` uvnitř.

## --tip--

Stejný vzor na jiných datech:
`const ROLE = ['admin', 'redaktor'] as const;` a `type Role = (typeof ROLE)[number];`

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}
```

// Sklad: co se dá hned koupit. Psal kolega Tomáš.
export function jeSkladem(id: number): boolean {
  const hra = najdiHru(id);
  return hra?.stav === 'skladem';

export function kolikSkladem(ids: number[]): number {
  return ids.filter((id) => jeSkladem(id)).length;

export type Hra = {
