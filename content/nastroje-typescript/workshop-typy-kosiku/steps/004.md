# --description--

Košík je pole položek a každá položka je hra a počet kusů. Typ `Hra` už máš
v `katalog.ts`, takže si ho do `kosik.ts` naimportuješ a složíš z něj další typ.

**Úkol:** v `kosik.ts` udělej tři věci.

1. Naimportuj typ `Hra` z `katalog.ts` zápisem `import type { … } from '…'`.
2. Napiš a vyexportuj typ `Polozka`: klíč `hra` je `Hra`, klíč `kusy` je číslo.
3. Napiš a vyexportuj funkci `mezisoucet(kosik)`, která z pole položek spočítá
   celkovou cenu (cena hry krát počet kusů). Parametr otypuj jako pole položek,
   návratový typ jako číslo. Prázdný košík má mezisoučet `0`.

Tvar zápisu na jiných datech — objednávka a součet hmotností:

```ts
import type { Zbozi } from './sklad.ts';

export type Radek = { zbozi: Zbozi; kusy: number };

export function hmotnost(radky: Radek[]): number {
  // sečti radek.zbozi.gramy * radek.kusy
  return 0;
}
```

Slovo `type` v importu není ozdoba. Node soubor `.ts` spouští tak, že z něj
**smaže typy** — a o `Hra` nemá jak vědět, že je typ. Bez `import type` ti
`node ukazka.ts` spadne na `SyntaxError: The requested module './katalog.ts'
does not provide an export named 'Hra'`.

# --hints--

Typ `Polozka` má klíč `hra` typu `Hra` a klíč `kusy` typu `number`.

```js
const kod = [
  "import type { Polozka } from './kosik.ts';",
  "import { katalog } from './katalog.ts';",
  "const polozka: Polozka = { hra: katalog[0], kusy: 2 };",
  "const kusy: number = polozka.kusy;",
  "const nazev: string = polozka.hra.nazev;",
  "// @ts-expect-error kusy musí být číslo, ne text",
  "const spatne: Polozka = { hra: katalog[0], kusy: '2' };",
  "console.log(kusy, nazev, spatne);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Typ Polozka má mít klíče hra (typu Hra) a kusy (number) a být exportovaný. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

`mezisoucet` sečte cenu za všechny kusy v košíku.

```js
const { mezisoucet, najdiHru } = await helpers.importFile('kosik.ts');
const kosik = [
  { hra: najdiHru(1), kusy: 2 },
  { hra: najdiHru(3), kusy: 1 },
];
assert.equal(mezisoucet(kosik), 2888, 'mezisoucet([Azul ×2, Dixit ×1]) má vrátit 2888 (999 × 2 + 890)');
assert.equal(mezisoucet([{ hra: najdiHru(7), kusy: 3 }]), 870, 'mezisoucet([Duch ×3]) má vrátit 870 (290 × 3)');
```

Prázdný košík má mezisoučet `0`.

```js
const { mezisoucet } = await helpers.importFile('kosik.ts');
assert.equal(mezisoucet([]), 0, 'mezisoucet([]) má vrátit 0');
```

Kontrola typů projde a `ukazka.ts` jde spustit.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
const beh = await helpers.run('node ukazka.ts');
assert.equal(beh.code, 0, 'node ukazka.ts má doběhnout bez chyby — importuješ typ Hra zápisem import type? Běh hlásí:\n' + beh.stderr);
```

# --explain--

Vysvětli vlastními slovy, proč se typ z jiného souboru importuje zápisem
`import type { Hra }`, a ne obyčejným `import { Hra }`.

## --model--

Node soubor `.ts` nepřekládá, jen z něj smaže typy a zbytek spustí. Obyčejný
import ale smazat nemůže — z názvu `Hra` nepozná, jestli je to typ, nebo funkce.
Nechá ho tam a při spuštění zjistí, že takový export neexistuje. `import type`
je pro něj jasný pokyn: tohle je jen pro kontrolu typů, celý řádek zahoď.

## --checklist--

- Typy za běhu neexistují, zbyde z nich prázdné místo.
- Node ani `tsc` z názvu nepozná, jestli je `Hra` typ, nebo hodnota.
- `import type` říká „tenhle import je jen pro kontrolu, při spuštění ho smaž".
- Bez něj spadne běh na chybějícím exportu, ne kontrola typů.

# --solution--

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}
```
