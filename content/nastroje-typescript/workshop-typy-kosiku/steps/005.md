# --description--

Košík se musí dát naplnit. Funkce `pridej` vrátí **nový** košík — původní pole
nechá být, aby šlo tlačítko „zpět" a aby se dvě části aplikace nepraly o stejná
data.

**Úkol:** v `kosik.ts` napiš a vyexportuj funkci `pridej(kosik, hra, kusy)`.

1. Parametry otypuj: `kosik` je pole položek, `hra` je hra, `kusy` je číslo.
   Návratový typ je pole položek.
2. Když hra v košíku ještě není, přibude na konec nová položka.
3. Když už v košíku je, zvýší se jen její počet kusů.
4. Původní pole ani jeho položky se nesmí změnit.

Pak v `ukazka.ts` poskládej košík ze dvou položek (`katalog[0]` dvakrát,
`katalog[2]` jednou), vypiš jeho mezisoučet a pod něj mezisoučet košíku
s jedním kusem navíc.

Vzor na jiných datech — tak vypadá „vrať nové pole se změněnou položkou":

```ts
export function oznacSplneno(ukoly: Ukol[], id: number): Ukol[] {
  // 1. projdi všechny úkoly
  // 2. u toho s daným id vrať jeho kopii se změnou
  // 3. ostatní vrať beze změny
  return ukoly.map((ukol) => (ukol.id === id ? { ...ukol, splneno: true } : ukol));
}
```

# --hints--

`pridej` přidá do prázdného košíku novou položku.

```js
const { pridej } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const novy = pridej([], katalog[0], 2);
assert.deepEqual(novy, [{ hra: katalog[0], kusy: 2 }], 'pridej([], Azul, 2) má vrátit košík s jednou položkou: Azul ×2');
```

Když hra v košíku už je, `pridej` zvýší její počet kusů a nepřidá druhou položku.

```js
const { pridej } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const kosik = [{ hra: katalog[0], kusy: 2 }, { hra: katalog[2], kusy: 1 }];
const novy = pridej(kosik, katalog[0], 3);
assert.equal(novy.length, 2, 'pridej(košík s Azulem, Azul, 3) nemá přidat druhou položku se stejnou hrou');
assert.equal(novy[0].kusy, 5, 'Azul už byl v košíku 2×, po pridej(…, Azul, 3) má mít 5 kusů');
assert.equal(novy[1].kusy, 1, 'ostatní položky mají zůstat beze změny');
```

Nová hra přibude na konec košíku.

```js
const { pridej } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const kosik = [{ hra: katalog[0], kusy: 1 }];
const novy = pridej(kosik, katalog[6], 2);
assert.equal(novy.length, 2, 'pridej(košík s Azulem, Duch, 2) má vrátit košík o dvou položkách');
assert.deepEqual(novy[1], { hra: katalog[6], kusy: 2 }, 'nová položka (Duch ×2) má být na konci košíku');
```

`pridej` nezmění původní košík ani jeho položky.

```js
const { pridej } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const kosik = [{ hra: katalog[0], kusy: 2 }];
const pred = structuredClone(kosik);
pridej(kosik, katalog[0], 3);
pridej(kosik, katalog[1], 1);
assert.deepEqual(kosik, pred, 'původní košík se nemá změnit — vrať nové pole a novou položku, ne upravenou původní');
```

# --help--

## --tip--

Položky jsou objekty a měnit se nesmí ani ony, ani pole. Připomeň si
[úpravu bez mutace](see:js-objekty/reference-a-mutace#uprava-bez-mutace-novy-objekt) — kopie se dělá
rozbalením `{ ...objekt }`.

## --tip--

Hodí se ti rozhodnutí „je hra už v košíku?" a pak dvě různé cesty: u té první
projdeš položky a jednu z nich nahradíš kopií se změněným počtem, u té druhé
vrátíš nové pole s položkou navíc.

## --tip--

Stejný tvar na jiných datech: `kapely.some((k) => k.id === id)` odpoví, jestli
už v seznamu je, a `[...kapely, { id, koncerty: 1 }]` vyrobí nové pole s položkou
navíc.

# --solution--

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}
```

import { katalog } from './katalog.ts';

console.log('Hra s id 2:', najdiHru(2));

const kosik: Polozka[] = [
