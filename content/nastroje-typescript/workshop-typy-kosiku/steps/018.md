# --description--

Všechny díly jsou hotové, zbývá je poskládat do něčeho, co je vidět.

**Úkol:** v `ukazka.ts` vypiš celou účtenku košíku, ve kterém je dvakrát první
hra z katalogu a jednou třetí hra. V tomhle pořadí:

- nadpis `Účtenka — Herna`,
- řádky ze shrnutí košíku, každý na vlastním řádku,
- mezisoučet, sleva a celková částka i s dopravou, každé s popiskem.

Všechny částky proženeš formátovačem, ať jsou všude stejně. Spusť **Spustit**
a podívej se na výsledek — tohle je ta věc, kterou jsi za posledních osmnáct
kroků postavil.

## Co teď umíš

Vzal jsi modul, který byl v JavaScriptu, a dal mu typy: tvar produktu, stavy jako
sjednocení literálů, položky košíku, funkce jako hodnoty. Typy ti po cestě našly
překlep v datech, pád na neznámém id a pokus měnit katalog zvenku — všechno ještě
před spuštěním.

V další lekci půjdeš o patro výš: jak z neznámých dat bezpečně zjistit, co v nich
je (zúžení typu), jak namodelovat stav, který má jen některé kombinace hodnot,
a jak napsat funkci, která si typ nechá určit od toho, kdo ji volá.

## Udělej po svém

Testy tyhle věci nekontrolují, ber je jako hřiště:

- Přidej do typu `Hra` klíč `stitky` (pole textů) a k němu funkci, která vrátí
  hry s daným štítkem. Vodítko: `filtrujKatalog` už máš, stačí mu dát podmínku.
- Napiš druhý formátovač, který ceny vypíše v eurech, a pusť jím tu samou
  účtenku. Vodítko: typ `Formatovac` ti hlídá, že se vejde do stejné škvíry.
- Přepiš katalog na hry, které tě baví — filmy, desky, tenisky. Typy ti u toho
  napoví, co všechno musíš změnit, a kontrola ti řekne, na co jsi zapomněl.

## --tip--

Všechno, co potřebuješ, je vyexportované z `kosik.ts`. Nic nového nepočítej —
jen zavolej a vypiš.

## --tip--

Shrnutí vrací pole textů, takže ho vypíšeš po řádcích cyklem. Košík si postav
přímo z položek katalogu, `najdiHru` tu potřeba není.

## --tip--

Řádek s popiskem a částkou vypadá na jiných datech takhle:
`` console.log(`Poštovné: ${naKoruny(poplatek)}`); ``

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}

export function filtrujKatalog(hry: readonly Hra[], podminka: (hra: Hra) => boolean): Hra[] {
  return hry.filter(podminka);
}

export function sleva(castka: number): number {
  if (castka <= 2000) return 0;
  return Math.min(Math.round(castka * 0.1), 500);
}

export function seradPodleNazvu(hry: readonly Hra[]): Hra[] {
  return [...hry].sort((a, b) => a.nazev.localeCompare(b.nazev, 'cs'));
}

export function celkem(kosik: Polozka[]): number {
  const mezi = mezisoucet(kosik);
  if (mezi === 0) return 0;
  const poSleve = mezi - sleva(mezi);
  return poSleve >= 2500 ? poSleve : poSleve + 99;
}
```

## --file-- ukazka.ts

```ts
import { katalog } from './katalog.ts';
import { celkem, mezisoucet, naKoruny, shrnuti, sleva } from './kosik.ts';
import type { Polozka } from './kosik.ts';

const kosik: Polozka[] = [
  { hra: katalog[0], kusy: 2 },
  { hra: katalog[2], kusy: 1 },
];

console.log('Účtenka — Herna');
for (const radek of shrnuti(kosik, naKoruny)) {
  console.log(`  ${radek}`);
}
console.log(`Mezisoučet: ${naKoruny(mezisoucet(kosik))}`);
console.log(`Sleva: ${naKoruny(sleva(mezisoucet(kosik)))}`);
console.log(`Celkem i s dopravou: ${naKoruny(celkem(kosik))}`);
```
