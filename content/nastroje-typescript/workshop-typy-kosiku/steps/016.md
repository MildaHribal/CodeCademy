# --description--

Poslední výpočet: kolik zákazník doopravdy zaplatí. Skládá se ze tří věcí, které
už máš hotové, a jednoho nového pravidla o dopravě.

**Úkol:** v `kosik.ts` napiš a vyexportuj funkci `celkem(kosik)`. Dostane položky
košíku a vrátí částku k zaplacení:

- mezisoučet košíku snížený o slevu,
- k tomu doprava 99 Kč,
- doprava je zdarma, když je částka **po slevě** aspoň 2 500 Kč,
- prázdný košík stojí 0 Kč, dopravu za nic neúčtujeme.

Použij funkce, které už v souboru jsou — nepočítej mezisoučet ani slevu znovu.

# --hints--

Prázdný košík stojí nula.

```js
const { celkem } = await helpers.importFile('kosik.ts');
assert.equal(celkem([]), 0, 'celkem([]) má vrátit 0 — u prázdného košíku se dopravou nezačíná');
```

Levný košík zaplatí dopravu 99 Kč.

```js
const { celkem, najdiHru } = await helpers.importFile('kosik.ts');
assert.equal(celkem([{ hra: najdiHru(7), kusy: 1 }]), 389, 'celkem([Duch ×1]) má vrátit 389 — 290 Kč a 99 Kč doprava');
assert.equal(celkem([{ hra: najdiHru(1), kusy: 1 }]), 1098, 'celkem([Azul ×1]) má vrátit 1098 — 999 Kč a 99 Kč doprava');
```

Od 2 500 Kč po slevě je doprava zdarma.

```js
const { celkem, najdiHru } = await helpers.importFile('kosik.ts');
assert.equal(celkem([{ hra: najdiHru(1), kusy: 2 }, { hra: najdiHru(3), kusy: 1 }]), 2599, 'celkem([Azul ×2, Dixit ×1]) má vrátit 2599 — mezisoučet 2888 minus sleva 289 je 2599, doprava zdarma');
assert.equal(celkem([{ hra: najdiHru(5), kusy: 2 }]), 1679, 'celkem([Carcassonne ×2]) má vrátit 1679 — mezisoučet 1580, sleva žádná, doprava 99 Kč');
```

Sleva se odečte dřív, než se rozhoduje o dopravě.

```js
const { celkem, najdiHru } = await helpers.importFile('kosik.ts');
assert.equal(celkem([{ hra: najdiHru(2), kusy: 2 }]), 2421, 'celkem([Osadníci ×2]) má vrátit 2421 — mezisoučet 2580, sleva 258, po slevě 2322, a to je pod 2500, takže doprava 99 Kč');
assert.equal(celkem([{ hra: najdiHru(6), kusy: 7 }]), 2556, 'celkem([Čtyřlístek ×7]) má vrátit 2556 — mezisoučet 2730, sleva 273, po slevě 2457, doprava 99 Kč');
```

# --help--

## --tip--

Nic nového se tu neučí — skládáš `mezisoucet` a `sleva` z předchozích kroků.

## --tip--

Nejdřív si spočítej mezisoučet, pak z něj odečti slevu a teprve na výsledek se
ptej, jestli má na dopravu zdarma. Prázdný košík vyřeš hned na začátku.

## --tip--

Podobný tvar na jiných datech:
`const kZaplaceni = poPoplatcich >= limitProDopravuZdarma ? poPoplatcich : poPoplatcich + postovne;`

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}

export function filtrujKatalog(hry: readonly Hra[], podminka: (hra: Hra) => boolean): Hra[] {
  return hry.filter(podminka);
}

export function sleva(castka: number): number {
  if (castka <= 2000) return 0;
  return Math.min(Math.round(castka * 0.1), 500);
}

export function seradPodleNazvu(hry: readonly Hra[]): Hra[] {
  return [...hry].sort((a, b) => a.nazev.localeCompare(b.nazev, 'cs'));
}
```

```ts
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {

    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,

  }
  return [...kosik, { hra, kusy }];

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;

export function shrnuti(kosik: Polozka[], format: Formatovac): string[] {
  return kosik.map((polozka) => {
    const castka = polozka.hra.cena * polozka.kusy;
    return `${nazevHry(polozka.hra)} ×${polozka.kusy} — ${format(castka)}`;
  });
}

export function filtrujKatalog(hry: readonly Hra[], podminka: (hra: Hra) => boolean): Hra[] {
  return hry.filter(podminka);
}

export function sleva(castka: number): number {
  if (castka <= 2000) return 0;
  return Math.min(Math.round(castka * 0.1), 500);
}

export function seradPodleNazvu(hry: readonly Hra[]): Hra[] {
  return [...hry].sort((a, b) => a.nazev.localeCompare(b.nazev, 'cs'));
}

export function celkem(kosik: Polozka[]): number {
  const mezi = mezisoucet(kosik);
  if (mezi === 0) return 0;
  const poSleve = mezi - sleva(mezi);
  return poSleve >= 2500 ? poSleve : poSleve + 99;
}
```
