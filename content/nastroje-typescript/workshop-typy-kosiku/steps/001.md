# --description--

E-shop Herna prodává deskové hry. Košík mu napsal kolega v JavaScriptu, pak
soubory přejmenoval na `.ts` a odešel na jiný projekt. Kontrola typů na projektu
ještě nikdy neběžela. Tvoje práce: modul otypovat — a cestou zjistíš, že v datech
je chyba, o které nikdo nevěděl.

Projekt má pět souborů:

- `katalog.ts` — data e-shopu: pole her s `id`, `nazev`, `cena` a `stav`.
- `kosik.ts` — logika košíku. Tady budeš psát nejvíc.
- `ukazka.ts` — vypíše účtenku. Spustíš ji tlačítkem **Spustit**.
- `tsconfig.json` — nastavení kontroly typů. Má `"strict": true`, takže
  neotypovaný parametr je chyba.
- `package.json` — kvůli `"type": "module"`.

První krok je z JavaScriptu, který už umíš, a napíšeš ho bez návodu.

**Úkol:** v `kosik.ts` doplň tělo funkce `najdiHru(id)`. Dostane číselné `id`
a vrátí hru z katalogu s tímhle `id`; když taková není, vrátí `undefined`.
Katalog nesmí změnit.

Typ parametru `id` je v seedu už napsaný — parametr se odvodit nedá, o tom bude
celý workshop. Návratový typ nepiš, ten si TypeScript odvodí sám.

> [!TIP]
> Po každém kroku zmáčkni **Spustit**. `ukazka.ts` vypíše, co modul zrovna umí —
> hned uvidíš, jestli to dělá, co má.

# --hints--

`kosik.ts` exportuje funkci `najdiHru`.

```js
const kosik = await helpers.importFile('kosik.ts');
assert.equal(typeof kosik.najdiHru, 'function', 'kosik.ts má exportovat funkci najdiHru — chybí před ní export?');
```

`najdiHru(id)` vrátí hru s daným `id` — první, prostřední i poslední v katalogu.

```js
const { najdiHru } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
assert.deepEqual(najdiHru(1), katalog[0], 'najdiHru(1) má vrátit Azul, první hru v katalogu');
assert.deepEqual(najdiHru(4), katalog[3], 'najdiHru(4) má vrátit Krycí jména');
assert.deepEqual(najdiHru(7), katalog[6], 'najdiHru(7) má vrátit Ducha, poslední hru v katalogu');
```

Když hra s tím `id` v katalogu není, `najdiHru` vrátí `undefined`.

```js
const { najdiHru } = await helpers.importFile('kosik.ts');
assert.equal(najdiHru(99), undefined, 'najdiHru(99) má vrátit undefined, hra s id 99 neexistuje');
assert.equal(najdiHru(0), undefined, 'najdiHru(0) má vrátit undefined');
```

`najdiHru` katalog nezmění.

```js
const { najdiHru } = await helpers.importFile('kosik.ts');
const { katalog } = await helpers.importFile('katalog.ts');
const pred = structuredClone(katalog);
najdiHru(3);
assert.deepEqual(katalog, pred, 'najdiHru(3) nemá měnit katalog (pořadí ani obsah)');
```

# --solution--

## --file-- kosik.ts

```ts
import { katalog } from './katalog.ts';

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}
```
