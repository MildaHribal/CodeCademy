# --description--

Ceny se na webu, na účtence i v e-mailu formátují jinak. Modul košíku proto
nebude vědět, **jak** se cena vypíše — dostane to jako funkci zvenku. Aby
kontrola věděla, jaká funkce se tam smí předat, dostane ta funkce jméno typu.

**Úkol:** v `kosik.ts` přidej dvě věci.

1. Vyexportuj typ `Formatovac`: funkce, která bere jedno číslo a vrací text.
2. Vyexportuj konstantu `naKoruny` toho typu. Z čísla udělá text s cenou
   v korunách: tisíce oddělené mezerou a za číslem `Kč` (`2 888 Kč`).
   Oddělovač tisíců podle českého zvyku umí `toLocaleString('cs-CZ')`.

Anotaci u parametru `naKoruny` psát nemusíš — typ `Formatovac` ho určuje, takže
si ho TypeScript doplní sám.

# --hints--

Typ `Formatovac` popisuje funkci z čísla na text.

```js
const kod = [
  "import type { Formatovac } from './kosik.ts';",
  "const jednoduchy: Formatovac = (castka) => `${castka} Kč`;",
  "const delsi: Formatovac = (castka: number): string => String(castka);",
  "// @ts-expect-error formátovač bere číslo, ne text",
  "const spatny: Formatovac = (castka: string) => castka;",
  "console.log(jednoduchy(1), delsi(2), spatny(3));",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
assert.equal(r.code, 0, 'Typ Formatovac má být (castka: number) => string a být exportovaný. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

`naKoruny` oddělí tisíce mezerou a přidá `Kč`.

```js
const { naKoruny } = await helpers.importFile('kosik.ts');
assert.equal(typeof naKoruny, 'function', 'kosik.ts má exportovat naKoruny');
assert.match(naKoruny(2888), /^2\s888 Kč$/u, `naKoruny(2888) má vrátit „2 888 Kč" s mezerou mezi tisíci, vrátilo: ${naKoruny(2888)}`);
assert.match(naKoruny(1234567), /^1\s234\s567 Kč$/u, `naKoruny(1234567) má vrátit „1 234 567 Kč", vrátilo: ${naKoruny(1234567)}`);
```

Malá čísla `naKoruny` nechá být.

```js
const { naKoruny } = await helpers.importFile('kosik.ts');
assert.equal(naKoruny(0), '0 Kč', 'naKoruny(0) má vrátit „0 Kč"');
assert.equal(naKoruny(999), '999 Kč', 'naKoruny(999) má vrátit „999 Kč" bez oddělovače');
```

Kontrola typů projde bez chyby.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
```

# --help--

## --tip--

Typ funkce se píše jako seznam parametrů, šipka a návratový typ —
viz [Typy funkcí](see:nastroje-typescript/zakladni-typy#typy-funkci).

## --tip--

`naKoruny` není `function`, ale konstanta s anotací typu `Formatovac`. Text
složíš šablonovým řetězcem z převedeného čísla a jednotky.

## --tip--

Stejný tvar na jiných datech:
`type Zkratka = (jmeno: string) => string;` a `const iniciala: Zkratka = (jmeno) => jmeno.slice(0, 1);`

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
```

```ts
import { katalog } from './katalog.ts';
import type { Hra } from './katalog.ts';

export type Polozka = {
  hra: Hra;
  kusy: number;
};

// Najde hru v katalogu podle id. Když taková není, vrátí undefined.
export function najdiHru(id: number) {
  return katalog.find((hra) => hra.id === id);
}

export function mezisoucet(kosik: Polozka[]): number {
  return kosik.reduce((soucet, polozka) => soucet + polozka.hra.cena * polozka.kusy, 0);
}

export function pridej(kosik: Polozka[], hra: Hra, kusy: number): Polozka[] {
  const uzTam = kosik.some((polozka) => polozka.hra.id === hra.id);
  if (uzTam) {
    return kosik.map((polozka) =>
      polozka.hra.id === hra.id ? { ...polozka, kusy: polozka.kusy + kusy } : polozka,
    );
  }
  return [...kosik, { hra, kusy }];
}

export function nazevHry(hra: Hra): string {
  return hra.podtitul ? `${hra.nazev}: ${hra.podtitul}` : hra.nazev;
}

export type Formatovac = (castka: number) => string;

export const naKoruny: Formatovac = (castka) => `${castka.toLocaleString('cs-CZ')} Kč`;
```
