# --description--

Máme `unknown` data, ale potřebujeme jim dát strukturu. Využijeme knihovnu `zod`. Zod validuje data za běhu a zároveň z nich dokáže odvodit TypeScriptové typy, abychom nepsali to samé dvakrát.

**Úkol:** Naimportuj `z` ze `zod`. Pak vytvoř `stationSchema` přes `z.object(...)`. Mělo by mít naprosto stejné klíče a typy, jako náš stávající `interface Station`.

> [!PITFALL] Zod a typy
> Pro číslo použij `z.number()`, pro řetězec `z.string()`, pro boolean `z.boolean()`.


```js
assert.match(files['index.ts'], /const\s+stationSchema\s*=\s*z\.object/, 'Kód musí obsahovat const stationSchema = z.object(...)');
```


## --file-- index.ts

```ts
import { z } from 'zod';
interface Station {
  id: string;
  name: string;
  bikesAvailable: number;
  isRenting: boolean;
}

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

// Zde definuj stationSchema
const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});

// 2. Vytvoř funkci getStations
export async function getStations() {
  const response = await fetch('https://api.example.com/stations');
  const data: unknown = await response.json();
  return data;
}
```
