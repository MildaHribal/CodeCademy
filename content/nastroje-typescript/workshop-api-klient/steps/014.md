# --description--

Hláška jako text stačí na výpis, ale ne na rozhodování. Stanice, která neexistuje, je něco
jiného než spadlý server: v prvním případě má uživatel vidět „taková stanice tu není", ve
druhém „zkus to za chvíli". Když je chyba jen řetězec, musel by se ten rozdíl hádat
z jeho znění.

**Úkol:** Zaveď typ `ApiError` jako rozlišené sjednocení tří variant, rozlišených vlastností
`kind`: `notFound` (server odpověděl stavem 404), `serverError` (jiný neúspěšný stav — nese
navíc číselné pole `status`) a `invalidData` (odpověď neodpovídá schématu). Každá varianta
má i `message` s českou hláškou. V `Result<T>` pak nahraď text tímto typem a `fetchJson`
uprav tak, aby chybu zařadila do správné varianty.

# --hints--

`index.ts` prochází kontrolou typů bez chyb.

```js
const result = await helpers.run('npx tsc --noEmit', { timeoutMs: 60000 });
```

Stav 404 dá chybu druhu `notFound`.

```js
globalThis.fetch = async () => new Response('Nenalezeno', { status: 404 });
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, false, `při stavu 404 má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'notFound', `při stavu 404 má mít chyba kind 'notFound', ale je to ${JSON.stringify(result.error)}`);
assert.equal(typeof result.error.message, 'string', `i varianta notFound má nést message jako text, ale je typu ${typeof result.error.message}`);
```

Jiný neúspěšný stav dá `serverError` i s číslem stavu.

```js
globalThis.fetch = async () => new Response('Chyba serveru', { status: 503 });
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, false, `při stavu 503 má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'serverError', `při stavu 503 má mít chyba kind 'serverError', ale je to ${JSON.stringify(result.error)}`);
assert.equal(result.error.status, 503, `varianta serverError má nést status 503, ale je to ${JSON.stringify(result.error)}`);
```

Odpověď mimo schéma dá `invalidData`.

```js
globalThis.fetch = async () => new Response(JSON.stringify([{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: '3', isRenting: true }]), { status: 200 });
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, false, `pro odpověď s bikesAvailable: "3" má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'invalidData', `pro odpověď mimo schéma má mít chyba kind 'invalidData', ale je to ${JSON.stringify(result.error)}`);
assert.match(result.error.message, /bikesAvailable/, `hláška má pojmenovat vadné pole bikesAvailable, ale zní: ${result.error.message}`);
```

Platná odpověď se pořád vrátí jako úspěch.

```js
const good = [{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: 3, isRenting: true }];
globalThis.fetch = async () => new Response(JSON.stringify(good), { status: 200 });
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, true, `pro platnou odpověď má getStations() vrátit ok: true, ale vrátila ${JSON.stringify(result)}`);
assert.deepEqual(result.data, good, 'pole data má obsahovat stažené stanice beze změny');
```

# --help--

## --tip--

Rozlišovací vlastnost musí mít v každé variantě jinou pevnou hodnotu. Napiš ji jako text v uvozovkách, ne jako `string` — jinak varianty nerozliší ani překladač.

## --tip--

Pole `status` patří jen do jedné z variant. To je v pořádku: u ostatních by stejně nemělo co obsahovat a překladač se na ně bez ověření `kind` nepustí.

## --tip--

Stav 404 se pozná dřív než obecné `!response.ok`, takže jeho větev musí být v pořadí první.

```ts
import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

export type ApiError =
  | { kind: 'notFound'; message: string }
  | { kind: 'serverError'; status: number; message: string }
  | { kind: 'invalidData'; message: string };

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: ApiError };

export async function fetchJson<T>(url: string, schema: z.ZodType<T>): Promise<Result<T>> {
  const response = await fetch(url);
  if (response.status === 404) {
    return { ok: false, error: { kind: 'notFound', message: `Na adrese ${url} nic není.` } };
  }
  if (!response.ok) {
    return {
      ok: false,
      error: { kind: 'serverError', status: response.status, message: `Server odpověděl stavem ${response.status}.` },
    };
  }
  const data: unknown = await response.json();
  const parsed = schema.safeParse(data);
  if (!parsed.success) {
    const issue = parsed.error.issues[0];
    return {
      ok: false,
      error: { kind: 'invalidData', message: `Pole ${issue.path.join('.')} neodpovídá schématu: ${issue.message}` },
    };
  }
  return { ok: true, data: parsed.data };
}

const userSchema = z.object({ name: z.string() });
type User = z.infer<typeof userSchema>;

export async function getUser(id: number) {
  return fetchJson(`https://api.example.com/users/${id}`, userSchema);
}

const statusSchema = z.object({ status: z.string() });
type Status = z.infer<typeof statusSchema>;
export async function checkStatus() {
  return fetchJson('https://api.example.com/status', statusSchema);
}

export async function getStations() {
  return fetchJson('https://api.example.com/stations', stationsSchema);
}
```
