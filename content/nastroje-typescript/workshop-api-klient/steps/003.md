# --description--

Zkusili jsme si, že typ `any` projde kompilací, i když obsahuje zjevné nesmysly (jako `data.cokoliv.neexistuje`). Změníme proto typ na `unknown`. Typ `unknown` nás donutí před použitím ověřit, co v datech opravdu je.

**Úkol:** Doplň typovou anotaci `unknown` k proměnné `data`. Pak umaž zkušební logování, protože kontrola typů ti ho oprávněně odmítne.

# --hints--

`index.ts` prochází kontrolou typů bez chyb.

```js
const result = await helpers.run('npx tsc --noEmit', { timeoutMs: 60000 });
assert.equal(result.code, 0, `tsc má projít bez chyb, ale vypsal:\n${result.stdout}`);
```

Proměnná `data` je označena jako `unknown`.

```js
assert.match(files['index.ts'], /const\s+data\s*:\s*unknown\s*=/, 'Proměnná data musí mít explicitní typ unknown');
```
