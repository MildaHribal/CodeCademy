# --description--

Máme schéma, ze kterého jsme odvodili náš typ. Přejděme k záchraně samotných dat! API vrací pole stanic.
Zod umí popsat pole libovolného prvku pomocí `z.array()`.

**Úkol:** Vytvoř schéma pro pole stanic: `const stationsSchema = z.array(stationSchema)`. Pak ve `getStations` tohle schéma použij a vyvaliduj stažená `unknown` data přes `.parse(data)`. Následně z funkce data vrať.

## --file-- index.ts

```ts
import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

// Zde definuj stationSchema
const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

// 2. Vytvoř funkci getStations
export async function getStations() {
  const response = await fetch('https://api.example.com/stations');
  const data: unknown = await response.json();
  return stationsSchema.parse(data);
}
```
