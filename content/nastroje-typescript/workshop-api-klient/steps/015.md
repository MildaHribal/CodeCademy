# --description--

Kolega mezitím přidal do klienta vyhledávání: typ `StationQuery`, pomocnou funkci `buildUrl`
a `searchStations`. Typy sedí, `tsc` mlčí, a přesto přišlo tohle hlášení.

## Hlášení

„Když do vyhledávání napíšu **Praha & okolí**, dostanu zpátky výsledky pro **Praha** a zadaný
limit se úplně ignoruje. Bez toho ampersandu to funguje normálně."

## Úkol

Najdi v `buildUrl` místo, kde se hodnota dostane do adresy, a oprav ho tak, aby parametr dorazil
na server celý a nerozbil ty za sebou. Ostatní funkce klienta musí fungovat dál. Změň co
nejmenší kus kódu.

Dotaz s ampersandem dorazí na server celý.

```js
let requested = '';
globalThis.fetch = async (url) => {
  requested = String(url);
  return new Response('[]', { status: 200 });
};
const mod = await helpers.importFile('index.ts');
await mod.searchStations({ q: 'Praha & okolí', limit: 5 });
const query = new URL(requested).searchParams;
assert.equal(query.get('q'), 'Praha & okolí', `parametr q má dorazit celý, ale server dostal adresu ${requested}`);
assert.equal(query.get('limit'), '5', `parametr limit má být 5, ale server dostal adresu ${requested}`);
```

Zbytek klienta funguje dál.

```js
const good = [{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: 3, isRenting: true }];
globalThis.fetch = async () => new Response(JSON.stringify(good), { status: 200 });
let mod = await helpers.importFile('index.ts');
const fine = await mod.getStations();
assert.equal(fine.ok, true, `getStations() má nad platnou odpovědí vrátit ok: true, ale vrátila ${JSON.stringify(fine)}`);
assert.deepEqual(fine.data, good, 'getStations() má vrátit stažené stanice beze změny');
globalThis.fetch = async () => new Response('Nenalezeno', { status: 404 });
mod = await helpers.importFile('index.ts');
const missing = await mod.getStations();
assert.equal(missing.error.kind, 'notFound', `při stavu 404 má chyba pořád mít kind 'notFound', ale je to ${JSON.stringify(missing.error)}`);
```

# --help--

## --tip--

Znaky `&`, `=`, `?` a `#` mají v adrese zvláštní význam: oddělují parametry a jejich hodnoty. Hodnota, která je obsahuje, se musí do dotazu vložit jinak než doslova.

## --tip--

Projdi `buildUrl` řádek po řádku a hledej ten, kde se z klíče a hodnoty stává kus textu. Dostanou se tam přesně tak, jak přišly.

## --tip--

Zakódovat jeden kus adresy umí `encodeURIComponent`. Celý dotaz včetně oddělovačů za tebe složí `URLSearchParams`. Obojí je správná cesta, jen jedna z nich je menší zásah.

function buildUrl(base: string, query: StationQuery): string {
