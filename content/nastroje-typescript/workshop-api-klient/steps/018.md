# --description--

Klient je hotový: stáhne data, ověří je schématem, rozliší druh chyby a krátký výpadek sítě
přejde bez hlášky. Zbývá ukázat, že se s ním dá pracovat — a to bez toho, aby ti někdo
diktoval zápis.

**Úkol:** Napiš a vyexportuj funkci `getAvailableStations()`. Vrací `Promise<Result<Station[]>>`
a uvnitř si data nechá poslat z `getStations()`. Když se stahování nepovedlo, vrátí tu samou
chybu beze změny. Když se povedlo, vrátí jen stanice, které zrovna půjčují a mají aspoň jedno
volné kolo.

Zadání ti říká jen chování. Jak na to, jsi napsal v předchozích krocích.

# --hints--

`index.ts` prochází kontrolou typů bez chyb.

```js
const result = await helpers.run('npx tsc --noEmit', { timeoutMs: 60000 });
assert.equal(result.code, 0, `tsc má projít bez chyb, ale vypsal:\n${result.stdout}`);
```

Nad platnými daty projdou jen stanice, které mají co půjčit.

```js
const list = [
  { id: 's1', name: 'Hlavní nádraží', bikesAvailable: 3, isRenting: true },
  { id: 's2', name: 'Anděl', bikesAvailable: 0, isRenting: true },
  { id: 's3', name: 'Dejvická', bikesAvailable: 4, isRenting: false }
];
globalThis.fetch = async () => new Response(JSON.stringify(list), { status: 200 });
const mod = await helpers.importFile('index.ts');
assert.equal(typeof mod.getAvailableStations, 'function', 'index.ts má exportovat funkci getAvailableStations');
const result = await mod.getAvailableStations();
assert.equal(result.ok, true, `nad platnými daty má getAvailableStations() vrátit ok: true, ale vrátila ${JSON.stringify(result)}`);
assert.deepEqual(result.data, [list[0]], `projít má jen Hlavní nádraží (Anděl nemá volné kolo, Dejvická nepůjčuje), ale přišlo ${JSON.stringify(result.data)}`);
```

Chyba serveru projde beze změny.

```js
globalThis.fetch = async () => new Response('Chyba serveru', { status: 503 });
const mod = await helpers.importFile('index.ts');
const result = await mod.getAvailableStations();
assert.equal(result.ok, false, `při stavu 503 má getAvailableStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'serverError', `chyba má projít beze změny, tedy s kind 'serverError', ale je to ${JSON.stringify(result.error)}`);
assert.equal(result.error.status, 503, `chyba má nést status 503, ale je to ${JSON.stringify(result.error)}`);
```

Výpadek sítě nic nevyhodí.

```js
globalThis.fetch = async () => { throw new TypeError('fetch failed'); };
const mod = await helpers.importFile('index.ts');
let result = null;
try {
  result = await mod.getAvailableStations();
} catch (error) {
  assert.fail(`getAvailableStations() nemá vyhazovat výjimku, ale spadla na: ${error}`);
}
assert.equal(result.ok, false, `při výpadku sítě má getAvailableStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'network', `při výpadku sítě má chyba mít kind 'network', ale je to ${JSON.stringify(result.error)}`);
```

# --help--

## --tip--

Nejdřív si nech poslat výsledek stahování. Než se dostaneš k datům, musíš vyřešit variantu s chybou — jinak tě k nim překladač nepustí.

## --tip--

Chybovou variantu není třeba nijak přebalovat. Má už přesně ten tvar, který má tvoje funkce vrátit, takže ji stačí poslat dál.

## --tip--

Na výběr prvků pole se hodí metoda, kterou znáš z `js-pole`: nechá jen ty, pro které podmínka platí. Podmínky jsou dvě a musí platit obě.

# --explain--

Shrň vlastními slovy, co tenhle klient umí navíc oproti prostému `fetch` a kde se ti to
bude hodit.

## --model--

`fetch` sám vrací `any` a věří serveru na slovo. Tenhle klient data nejdřív prožene schématem,
takže se dovnitř programu dostane jen to, co odpovídá typu — a ten typ se odvozuje z téhož
schématu, takže se s kontrolou za běhu nemůže rozejít. Výsledek se vrací jako `Result`, kde
`ok` rozhoduje, jestli jsou k dispozici data, nebo chyba, a druh chyby (`notFound`,
`serverError`, `invalidData`, `network`) určuje, co uvidí uživatel. Stejný vzor se hodí na
každou hranici programu, kam přitečou cizí data.

## --checklist--

- Data z odpovědi jsou `unknown` a dál je pustí až schéma.
- Typ se odvozuje ze schématu, takže se s validací nerozejde.
- `Result` nese úspěch i chybu v jednom typu a nutí volajícího rozhodnout.
- Druh chyby říká, co ukázat uživateli a jestli má smysl to zkusit znovu.
- Stejně se ošetřuje každá hranice: formulář, `localStorage`, nastavení prostředí.

type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

export type ApiError =
  | { kind: 'notFound'; message: string }
  | { kind: 'serverError'; status: number; message: string }
  | { kind: 'invalidData'; message: string }
  | { kind: 'network'; message: string };

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: ApiError };

export type FetchOptions = {
  retries?: number;
};

export async function fetchJson<T>(url: string, schema: z.ZodType<T>, options: FetchOptions = {}): Promise<Result<T>> {
  const retries = options.retries ?? 0;
  let lastMessage = 'Požadavek se nepodařilo odeslat.';
  for (let attempt = 0; attempt <= retries; attempt++) {
    let response: Response;
    try {
      response = await fetch(url);
    } catch (error: unknown) {
      lastMessage = error instanceof Error ? error.message : String(error);
      continue;
    }
    if (response.status === 404) {
      return { ok: false, error: { kind: 'notFound', message: `Na adrese ${url} nic není.` } };
    }
    if (!response.ok) {
      return {
        ok: false,
        error: { kind: 'serverError', status: response.status, message: `Server odpověděl stavem ${response.status}.` },
      };
    }
    const data: unknown = await response.json();
    const parsed = schema.safeParse(data);
    if (!parsed.success) {
      const issue = parsed.error.issues[0];
      return {
        ok: false,
        error: { kind: 'invalidData', message: `Pole ${issue.path.join('.')} neodpovídá schématu: ${issue.message}` },
      };
    }
    return { ok: true, data: parsed.data };
  }
  return { ok: false, error: { kind: 'network', message: lastMessage } };
}

const userSchema = z.object({ name: z.string() });
type User = z.infer<typeof userSchema>;

export async function getUser(id: number) {
  return fetchJson(`https://api.example.com/users/${id}`, userSchema);
}

const statusSchema = z.object({ status: z.string() });
type Status = z.infer<typeof statusSchema>;
export async function checkStatus() {
  return fetchJson('https://api.example.com/status', statusSchema);
}

export async function getStations() {
  return fetchJson('https://api.example.com/stations', stationsSchema, { retries: 2 });
}

export type StationQuery = {
  q: string;
  limit: number;
};

function buildUrl(base: string, query: StationQuery): string {
  const parts: string[] = [];
  for (const [key, value] of Object.entries(query)) {
    parts.push(`${encodeURIComponent(key)}=${encodeURIComponent(String(value))}`);
  }
  return `${base}?${parts.join('&')}`;
}

export async function searchStations(query: StationQuery) {
  return fetchJson(buildUrl('https://api.example.com/stations', query), stationsSchema);
}

export async function getAvailableStations(): Promise<Result<Station[]>> {
  const result = await getStations();
  if (!result.ok) {
    return result;

  return {
    ok: true,
    data: result.data.filter((station) => station.isRenting && station.bikesAvailable > 0),
