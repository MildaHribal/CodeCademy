# --description--

Kód, který kontroluje odpověď a stahuje data, budeme potřebovat pořád. Přesuňme ho do samostatné funkce.

**Úkol:** Vytvoř asynchronní funkci `fetchJson(url: string)`. Přesuň do ní z `getStations` všechno od `fetch(url)` přes zahození výjimky u `!ok` až po volání `.json()`. Z funkce `fetchJson` vracej proměnnou data typu `unknown`. Ve `getStations` ji pak použij.

```ts
import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

export async function fetchJson(url: string) {
  const response = await fetch(url);
  if (!response.ok) {
    throw new Error('API selhalo');
  }
  const data: unknown = await response.json();
  return data;
}

export async function getStations() {
  const data = await fetchJson('https://api.example.com/stations');
  return stationsSchema.parse(data);
}
```
