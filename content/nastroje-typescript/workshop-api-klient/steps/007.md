# --description--

## Hlášení

Zod data správně ohlídá, ale co když server vrátí HTML stránku s textem „Nenalezeno“ (404)?

## Úkol

Před voláním `.json()` v `getStations` zkontroluj `response.ok`. Pokud je `false`, vyhoď vlastní výjimku `Error('API selhalo')`.

## --file-- index.ts

```ts
import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

// Zde definuj stationSchema
const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

// 2. Vytvoř funkci getStations
export async function getStations() {
  const response = await fetch('https://api.example.com/stations');
  if (!response.ok) {
    throw new Error('API selhalo');
  }
  const data: unknown = await response.json();
  return stationsSchema.parse(data);
}
```
