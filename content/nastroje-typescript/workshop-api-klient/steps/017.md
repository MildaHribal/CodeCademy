# --description--

Výpadek sítě bývá krátký. Klient, který to po chvíli zkusí znovu, ušetří uživateli polovinu
chybových hlášek. Jenže opakovat se nesmí všechno: kdyby se takhle opakoval zápis, poslala by
se objednávka dvakrát. Z opakování je tedy volba a volba patří do typu, ne do vzduchu.

**Úkol:** Přidej typ `FetchOptions` s nepovinným číselným polem `retries` a rozšiř `fetchJson`
o třetí parametr `options` typu `FetchOptions`, který má výchozí hodnotu prázdného objektu.
Chování:

- `retries` je počet pokusů **navíc**. Když se nezadá, proběhne jediný pokus jako dosud.
- Opakuje se jen odmítnutý `fetch`. Odpověď serveru — ať je to 404, 503, nebo data mimo
  schéma — se nikdy neopakuje, ta už je konečná.
- Po vyčerpání pokusů se vrátí chyba druhu `network` s hláškou z posledního pokusu.

Nakonec ať si `getStations` vyžádá dvě opakování navíc. `getUser` a `checkStatus` nech beze
změny — ty žádné nastavení nepředávají.

# --hints--

`index.ts` prochází kontrolou typů bez chyb.

```js
const result = await helpers.run('npx tsc --noEmit', { timeoutMs: 60000 });
assert.equal(result.code, 0, `tsc má projít bez chyb, ale vypsal:\n${result.stdout}`);
```

Po dvou selháních sítě se třetí pokus povede.

```js
const good = [{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: 3, isRenting: true }];
let calls = 0;
globalThis.fetch = async () => {
  calls++;
  if (calls < 3) throw new TypeError('fetch failed');
  return new Response(JSON.stringify(good), { status: 200 });
};
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, true, `getStations() má po dvou selháních sítě uspět na třetí pokus, ale vrátila ${JSON.stringify(result)}`);
assert.deepEqual(result.data, good, 'pole data má obsahovat stažené stanice beze změny');
assert.equal(calls, 3, `fetch se měl zavolat 3× (první pokus a dvě opakování), ale zavolal se ${calls}×`);
```

Když síť selže pokaždé, vrátí se chyba `network` a pokusy se nepřetáhnou.

```js
let calls = 0;
globalThis.fetch = async () => {
  calls++;
  throw new TypeError(`fetch failed (pokus ${calls})`);
};
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, false, `když síť selže pokaždé, má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'network', `chyba má mít kind 'network', ale je to ${JSON.stringify(result.error)}`);
assert.equal(calls, 3, `fetch se měl zavolat 3× a víc ne, ale zavolal se ${calls}×`);
assert.match(result.error.message, /pokus 3/, `hláška má pocházet z posledního, třetího pokusu, ale zní: ${result.error.message}`);
```

Volání bez nastavení se neopakuje.

```js
let calls = 0;
globalThis.fetch = async () => {
  calls++;
  throw new TypeError('fetch failed');
};
const mod = await helpers.importFile('index.ts');
const result = await mod.checkStatus();
assert.equal(result.ok, false, `checkStatus() má při výpadku sítě vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(calls, 1, `checkStatus() si opakování nevyžádala, takže se fetch měl zavolat 1×, ale zavolal se ${calls}×`);
```

Odpověď serveru se neopakuje.

```js
let calls = 0;
globalThis.fetch = async () => {
  calls++;
  return new Response('Chyba serveru', { status: 500 });
};
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.error.kind, 'serverError', `stav 500 má dát chybu s kind 'serverError', ale je to ${JSON.stringify(result.error)}`);
assert.equal(calls, 1, `odpověď serveru se opakovat nemá, takže se fetch měl zavolat 1×, ale zavolal se ${calls}×`);
```

# --help--

## --tip--

Pokus musí jít zopakovat, takže patří do cyklu. Ten proběhne o jedno kolo víc, než kolik je povolených opakování.

## --tip--

Opakovat se má jen větev, kde volání skončilo výjimkou. Všechny ostatní větve výsledek rovnou vracejí, takže z cyklu odejdou samy.

## --tip--

Nepovinné pole se čte s náhradou, na to je operátor `??`. A hlášku z posledního nepovedeného pokusu si odlož do proměnné nad cyklem, ať ji máš i po jeho doběhnutí.

export async function fetchJson<T>(url: string, schema: z.ZodType<T>): Promise<Result<T>> {
  let response: Response;
  try {
    response = await fetch(url);
  } catch (error: unknown) {
    const message = error instanceof Error ? error.message : String(error);
    return { ok: false, error: { kind: 'network', message } };
  }
  if (response.status === 404) {
    return { ok: false, error: { kind: 'notFound', message: `Na adrese ${url} nic není.` } };
  }
  if (!response.ok) {
    return {
      ok: false,
      error: { kind: 'serverError', status: response.status, message: `Server odpověděl stavem ${response.status}.` },
    };
  }
  const data: unknown = await response.json();
  const parsed = schema.safeParse(data);
  if (!parsed.success) {
    const issue = parsed.error.issues[0];
    return {
      ok: false,
      error: { kind: 'invalidData', message: `Pole ${issue.path.join('.')} neodpovídá schématu: ${issue.message}` },
    };
  }
  return { ok: true, data: parsed.data };
}

import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

export type ApiError =
  | { kind: 'notFound'; message: string }
  | { kind: 'serverError'; status: number; message: string }
  | { kind: 'invalidData'; message: string }
  | { kind: 'network'; message: string };

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: ApiError };

export type FetchOptions = {
  retries?: number;
};

export async function fetchJson<T>(url: string, schema: z.ZodType<T>, options: FetchOptions = {}): Promise<Result<T>> {
  const retries = options.retries ?? 0;
  let lastMessage = 'Požadavek se nepodařilo odeslat.';
  for (let attempt = 0; attempt <= retries; attempt++) {
    let response: Response;
    try {
      response = await fetch(url);
    } catch (error: unknown) {
      lastMessage = error instanceof Error ? error.message : String(error);
      continue;
    }
    if (response.status === 404) {
      return { ok: false, error: { kind: 'notFound', message: `Na adrese ${url} nic není.` } };
    }
    if (!response.ok) {
      return {
        ok: false,
        error: { kind: 'serverError', status: response.status, message: `Server odpověděl stavem ${response.status}.` },
      };
    }
    const data: unknown = await response.json();
    const parsed = schema.safeParse(data);
    if (!parsed.success) {
      const issue = parsed.error.issues[0];
      return {
        ok: false,
        error: { kind: 'invalidData', message: `Pole ${issue.path.join('.')} neodpovídá schématu: ${issue.message}` },
      };
    }
    return { ok: true, data: parsed.data };
  }
  return { ok: false, error: { kind: 'network', message: lastMessage } };
}

const userSchema = z.object({ name: z.string() });
type User = z.infer<typeof userSchema>;

export async function getUser(id: number) {
  return fetchJson(`https://api.example.com/users/${id}`, userSchema);
}

const statusSchema = z.object({ status: z.string() });
type Status = z.infer<typeof statusSchema>;
export async function checkStatus() {
  return fetchJson('https://api.example.com/status', statusSchema);
}

export async function getStations() {
  return fetchJson('https://api.example.com/stations', stationsSchema, { retries: 2 });
}

export type StationQuery = {
  q: string;
  limit: number;
};

function buildUrl(base: string, query: StationQuery): string {
  const parts: string[] = [];
  for (const [key, value] of Object.entries(query)) {

  }
  return `${base}?${parts.join('&')}`;
}

export async function searchStations(query: StationQuery) {
  return fetchJson(buildUrl('https://api.example.com/stations', query), stationsSchema);
}
