# --description--

Vyhozená výjimka má jednu nepříjemnou vlastnost: v typech po ní není ani stopa. Signatura
funkce vypadá stejně, ať vyhazuje, nebo ne, a `try` se dá zapomenout, aniž by se překladač
ozval. Chybu proto přesuneme z výjimky do návratové hodnoty, kde ji typový systém uvidí.

**Úkol:** Zaveď generický typ `Result<T>` jako [[rozlišené sjednocení]] dvou variant: úspěšná
má `ok: true` a pole `data` typu `T`, neúspěšná má `ok: false` a pole `error` s hláškou pro
uživatele. Pak přepiš `fetchJson` tak, aby vracela `Promise<Result<T>>` a **za žádných
okolností nevyhodila výjimku** — ani při chybném stavovém kódu, ani při neplatných datech.
Volající funkce upravovat nemusíš, výsledek jen předávají dál.

# --hints--

`index.ts` prochází kontrolou typů bez chyb.

```js
const result = await helpers.run('npx tsc --noEmit', { timeoutMs: 60000 });
assert.equal(result.code, 0, `tsc má projít bez chyb, ale vypsal:\n${result.stdout}`);
```

Platná odpověď se vrátí jako úspěch s daty.

```js
const good = [{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: 3, isRenting: true }];
globalThis.fetch = async () => new Response(JSON.stringify(good), { status: 200 });
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, true, `pro platnou odpověď má getStations() vrátit ok: true, ale vrátila ${JSON.stringify(result)}`);
assert.deepEqual(result.data, good, 'pole data má obsahovat stažené stanice beze změny');
```

Chybný stavový kód nic nevyhodí, jen vrátí neúspěch.

```js
globalThis.fetch = async () => new Response('Služba je dočasně nedostupná', { status: 500 });
const mod = await helpers.importFile('index.ts');
let result = null;
try {
  result = await mod.getStations();
} catch (error) {
  assert.fail(`při stavu 500 už nemá padat výjimka, ale spadla: ${error}`);
}
assert.equal(result.ok, false, `při stavu 500 má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(typeof result.error, 'string', `pole error má být hláška pro uživatele, ale je typu ${typeof result.error}`);
```

Neplatná data taky nic nevyhodí a hláška pojmenuje vadné pole.

```js
globalThis.fetch = async () => new Response(JSON.stringify([{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: '3', isRenting: true }]), { status: 200 });
const mod = await helpers.importFile('index.ts');
let result = null;
try {
  result = await mod.getStations();
} catch (error) {
  assert.fail(`při neplatných datech už nemá padat výjimka, ale spadla: ${error}`);
}
assert.equal(result.ok, false, `pro odpověď s bikesAvailable: "3" má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.match(String(result.error), /bikesAvailable/, `hláška má pojmenovat vadné pole bikesAvailable, ale zní: ${result.error}`);
```

# --help--

## --tip--

Rozlišené sjednocení poznáš podle společné vlastnosti, která má v každé variantě jinou pevnou hodnotu. Tady je to `ok`.

## --tip--

Každé `throw` v té funkci nahraď návratem neúspěšné varianty. Stavový kód, který se do hlášky hodí, je v `response.status`.

## --tip--

Návratový typ napiš do hlavičky funkce sám, i když by si ho překladač odvodil. Pak tě upozorní na větev, kde ses na tvar výsledku nepovedl.

# --explain--

Vysvětli vlastními slovy, proč se volajícímu lépe pracuje s vráceným `Result<T>` než
s vyhozenou výjimkou.

## --model--

Návratový typ je vidět v signatuře funkce: `Promise<Result<T>>` říká, že se to může
nepovést. Vyhozená výjimka v typech není nikde, takže na ni jde zapomenout a překladač
mlčí. `Result` je navíc rozlišené sjednocení — dokud volající neověří `ok`, TypeScript mu
`data` nepustí. Ošetření chyby se tak z dobré vůle stává podmínkou překladu.

## --checklist--

- Návratový typ je v signatuře vidět, vyhozená výjimka ne.
- `Result` je rozlišené sjednocení, vlastnost `ok` říká, která varianta platí.
- Dokud volající `ok` neověří, k `data` se nedostane.
- Na ošetření chyby se proto nedá zapomenout.

```ts
import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: string };

export async function fetchJson<T>(url: string, schema: z.ZodType<T>): Promise<Result<T>> {
  const response = await fetch(url);
  if (!response.ok) {
    return { ok: false, error: `Server odpověděl stavem ${response.status}.` };
  }
  const data: unknown = await response.json();
  const parsed = schema.safeParse(data);
  if (!parsed.success) {
    const issue = parsed.error.issues[0];
    return { ok: false, error: `Pole ${issue.path.join('.')} neodpovídá schématu: ${issue.message}` };
  }
  return { ok: true, data: parsed.data };
}

const userSchema = z.object({ name: z.string() });
type User = z.infer<typeof userSchema>;

export async function getUser(id: number) {
  return fetchJson(`https://api.example.com/users/${id}`, userSchema);
}

const statusSchema = z.object({ status: z.string() });
type Status = z.infer<typeof statusSchema>;
export async function checkStatus() {
  return fetchJson('https://api.example.com/status', statusSchema);
}

export async function getStations() {
  return fetchJson('https://api.example.com/stations', stationsSchema);
}
```
