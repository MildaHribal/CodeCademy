# --description--

Když teď server pošle stanici, u které je `bikesAvailable` textem, `schema.parse` vyhodí
`ZodError`. Její zpráva je několikařádkový výpis JSONu se všemi nalezenými problémy — do logu
dobré, ale nikdo jiný v programu s tím nic nesvede.

**Úkol:** V `fetchJson` přejdi z `schema.parse` na `schema.safeParse`. Ta místo výjimky vrátí
objekt, ze kterého se dá vyčíst, jestli validace prošla. Když neprošla, vyhoď vlastní
`new Error(…)`, jehož hláška pojmenuje **první vadné pole** — seznam problémů najdeš
v `error.issues` a každý problém má vlastnost `path` (cesta k poli) a `message`. Když prošla,
vrať zvalidovaná data jako dosud.

> [!PITFALL] K datům se nedostaneš dřív, než ověříš úspěch
> Výsledek `safeParse` je [[rozlišené sjednocení]]: buď `success: true` a data, nebo
> `success: false` a chyba. Dokud `success` neotestuješ, překladač ti data nepustí —
> hlásí `Property 'data' does not exist on type …`. Není to obtěžování, je to celý smysl
> toho typu.


# --help--

## --tip--

Zod má vedle metody, která vyhazuje, ještě variantu, která nic nevyhodí a výsledek vrátí. Jmenuje se podobně.

## --tip--

Ve výsledku se ptáš na vlastnost `success`. Ve větvi neúspěchu je pod `error` seznam `issues`; pro hlášku ti stačí ten první.

## --tip--

Cestu k poli složíš z `path` (je to pole, spoj ho tečkou) a důvod přidáš z `message` téhož problému.

```ts
import { z } from 'zod';
type Station = z.infer<typeof stationSchema>;

const example: Station = {
  id: "s1",
  name: "Hlavní nádraží",
  bikesAvailable: 5,
  isRenting: true
};

const stationSchema = z.object({
  id: z.string(),
  name: z.string(),
  bikesAvailable: z.number(),
  isRenting: z.boolean(),
});
const stationsSchema = z.array(stationSchema);

export async function fetchJson<T>(url: string, schema: z.ZodType<T>) {
  const response = await fetch(url);
  if (!response.ok) {
    throw new Error('API selhalo');
  }
  const data: unknown = await response.json();
  const parsed = schema.safeParse(data);
  if (!parsed.success) {
    const issue = parsed.error.issues[0];
    throw new Error(`Odpověď z ${url} neodpovídá schématu: ${issue.path.join('.')} — ${issue.message}`);
  }
  return parsed.data;
}

const userSchema = z.object({ name: z.string() });
type User = z.infer<typeof userSchema>;

export async function getUser(id: number) {
  return fetchJson(`https://api.example.com/users/${id}`, userSchema);
}

const statusSchema = z.object({ status: z.string() });
type Status = z.infer<typeof statusSchema>;
export async function checkStatus() {
  return fetchJson('https://api.example.com/status', statusSchema);
}

export async function getStations() {
  return fetchJson('https://api.example.com/stations', stationsSchema);
}
```
