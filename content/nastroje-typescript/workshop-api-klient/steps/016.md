# --description--

Klient zatím počítá s tím, že odpověď vůbec dorazí. Jenže když server neběží nebo vypadne
wifi, `fetch` svůj slib odmítne a z `fetchJson` vyletí výjimka — přesně to, čeho jsme se
v předchozích krocích zbavovali.

Chytit ji nestačí. V režimu `strict` má proměnná v `catch` typ `unknown`, protože v JavaScriptu
se dá vyhodit úplně cokoliv: text, číslo, `null`. Než z ní přečteš `message`, musíš překladači
dokázat, že jde opravdu o `Error` — [[zúžení typu|zúžením]], ne přetypováním.

**Úkol:** Přidej do `ApiError` čtvrtou variantu `network` s polem `message` a ošetři ve
`fetchJson` odmítnutý slib tak, aby skončil touto variantou. Hlášku vezmi z chycené hodnoty,
když je to `Error`; když to `Error` není, poraď si jinak — `message` musí zůstat neprázdný
text.

> [!PITFALL] `catch (error) { return error.message }` neprojde
> Překladač hlásí `'error' is of type 'unknown'`. Svádí to napsat `(error as Error).message`,
> jenže to je jen slib, který za běhu nikdo nekontroluje: u vyhozeného textu ti tam přistane
> `undefined`.


Odmítnutý `fetch` skončí chybou druhu `network` s hláškou z chycené chyby.

```js
globalThis.fetch = async () => { throw new TypeError('fetch failed'); };
const mod = await helpers.importFile('index.ts');
let result = null;

  result = await mod.getStations();
} catch (error) {
  assert.fail(`při výpadku sítě už nemá padat výjimka, ale spadla: ${error}`);
}
assert.equal(result.ok, false, `při výpadku sítě má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'network', `chyba má mít kind 'network', ale je to ${JSON.stringify(result.error)}`);
assert.match(result.error.message, /fetch failed/, `hláška má vycházet z chycené chyby 'fetch failed', ale zní: ${result.error.message}`);
```

Funguje to i tehdy, když se vyhodí něco, co není `Error`.

```js
globalThis.fetch = async () => { throw 'spojení bylo přerušeno'; };
const mod = await helpers.importFile('index.ts');
const result = await mod.getStations();
assert.equal(result.ok, false, `i po vyhození textu má getStations() vrátit ok: false, ale vrátila ${JSON.stringify(result)}`);
assert.equal(result.error.kind, 'network', `i po vyhození textu má chyba mít kind 'network', ale je to ${JSON.stringify(result.error)}`);
assert.equal(typeof result.error.message, 'string', `message má zůstat text, ale je typu ${typeof result.error.message}`);
assert.ok(result.error.message.length > 0, 'message nemá zůstat prázdná, když se vyhodí text místo Error');
```

Platná odpověď i chyby serveru fungují dál.

```js
const good = [{ id: 's1', name: 'Hlavní nádraží', bikesAvailable: 3, isRenting: true }];
globalThis.fetch = async () => new Response(JSON.stringify(good), { status: 200 });
let mod = await helpers.importFile('index.ts');
const fine = await mod.getStations();
assert.equal(fine.ok, true, `pro platnou odpověď má getStations() vrátit ok: true, ale vrátila ${JSON.stringify(fine)}`);
globalThis.fetch = async () => new Response('Chyba serveru', { status: 503 });
mod = await helpers.importFile('index.ts');
const broken = await mod.getStations();
assert.equal(broken.error.kind, 'serverError', `při stavu 503 má chyba pořád mít kind 'serverError', ale je to ${JSON.stringify(broken.error)}`);
```

# --help--

## --tip--

Výjimku může vyhodit jen samotné volání `fetch`; zbytek funkce už pracuje s hotovou odpovědí. Ohlídat stačí ten jeden řádek.

## --tip--

Zúžení `unknown` na `Error` udělá operátor `instanceof`. Ve větvi, kde platí, je `message` přístupná bez protestů.

## --tip--

Když to `Error` není, hodnotu buď převeď na text, nebo použij vlastní náhradní hlášku. Obojí je v pořádku, `message` jen nesmí zůstat prázdná.

# --explain--

Vysvětli vlastními slovy, proč má proměnná v `catch` typ `unknown` a co to znamená pro tvůj
kód.

## --model--

V JavaScriptu se dá vyhodit jakákoliv hodnota, ne jen `Error`. TypeScript proto v režimu
`strict` neví o chycené hodnotě nic a dá jí typ `unknown`. Než z ní něco přečteš, musíš typ
zúžit — třeba přes `instanceof Error`. Přetypování `as Error` je jen tvrzení pro překladač,
za běhu nezmění nic, takže u vyhozeného textu dostaneš `undefined`.

## --checklist--

- Vyhodit se dá cokoliv, ne jen `Error`.
- Proto je chycená hodnota `unknown` a bez ověření se z ní nedá číst.
- Zúžení přes `instanceof` platí i za běhu.
- `as Error` překladač uklidní, ale za běhu nic neověří.

```ts
export type ApiError =
  | { kind: 'notFound'; message: string }
  | { kind: 'serverError'; status: number; message: string }
  | { kind: 'invalidData'; message: string }
  | { kind: 'network'; message: string };

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: ApiError };

export async function fetchJson<T>(url: string, schema: z.ZodType<T>): Promise<Result<T>> {
  let response: Response;
  try {
    response = await fetch(url);
  } catch (error: unknown) {
    const message = error instanceof Error ? error.message : String(error);
    return { ok: false, error: { kind: 'network', message } };
  }
  if (response.status === 404) {
    return { ok: false, error: { kind: 'notFound', message: `Na adrese ${url} nic není.` } };
  }
  if (!response.ok) {
    return {
      ok: false,
      error: { kind: 'serverError', status: response.status, message: `Server odpověděl stavem ${response.status}.` },
    };
  }
  const data: unknown = await response.json();
  const parsed = schema.safeParse(data);
  if (!parsed.success) {
    const issue = parsed.error.issues[0];
    return {
      ok: false,
      error: { kind: 'invalidData', message: `Pole ${issue.path.join('.')} neodpovídá schématu: ${issue.message}` },
    };
  }
  return { ok: true, data: parsed.data };
}
```
