# --description--

Nejprve si zopakujeme definici typů. Představ si, že stavíme klienta pro systém sdílených kol. Budeme potřebovat typ pro stanici.

**Úkol:** Vytvoř `interface Station`, který popíše data stanice.

Stanice má:
- `id`: textový řetězec
- `name`: textový řetězec
- `bikesAvailable`: číslo
- `isRenting`: pravdivostní hodnota (boolean)
