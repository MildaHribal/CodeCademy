# --description--

Zkusíme si stáhnout data ze serveru. Metoda `.json()` na odpovědi z historických důvodů vrací `any`. To znamená, že TypeScript přestane hlídat, co s daty děláme.

**Úkol:** Vytvoř asynchronní funkci `getStations()`, která stáhne data přes `fetch('https://api.example.com/stations')` a vrátí je.
Abychom si ověřili, že TypeScript opravdu nic nehlídá, přidej před vrácením výpis `console.log(data.cokoliv.neexistuje);`.

export async function getStations() {
  const response = await fetch('https://api.example.com/stations');
  const data = await response.json();
  console.log(data.cokoliv.neexistuje);
  return data;
}
