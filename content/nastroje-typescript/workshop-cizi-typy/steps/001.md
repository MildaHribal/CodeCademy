# --description--

Koncertní agentura má modul se statistikami: kolik se vydělalo, kde se hraje,
jak jsou koncerty obsazené. Napsal ho kolega v JavaScriptu a před odchodem
soubory přejmenoval na `.ts`. Kontrola typů na tom projektu ještě nikdy neběžela.

Spusť si ji v terminálu:

```sh
npx tsc --noEmit
```

Vypíše **deset řádků v šesti funkcích**. Vypadá to jako katastrofa, ale je to
seznam práce — a každá položka je jedna skutečná chyba, která by dřív nebo
později spadla na uživatele. V tomhle workshopu je projdeš od shora dolů. Žádné
`any`, žádné `as`: pokaždé se opraví to, co je opravdu špatně.

Data v `koncerty.ts` jsou v pořádku, sahat na ně nebudeš (až na jednu výjimku
ke konci). Pracuješ v `statistiky.ts`.

První hlášení zní:

```text
statistiky.ts(7,23): error TS7006: Parameter 'seznam' implicitly has an 'any' type.
statistiky.ts(8,25): error TS7006: Parameter 'soucet' implicitly has an 'any' type.
statistiky.ts(8,33): error TS7006: Parameter 'koncert' implicitly has an 'any' type.
```

Tři řádky, jedna příčina: parametr `seznam` nemá typ, takže TypeScript neví ani,
co je v něm za prvky — a proto nezná ani parametry callbacku uvnitř.

**Úkol:** otypuj funkci `trzba`. Bere seznam koncertů, do kterého nezapisuje,
a vrací číslo. Uvnitř nic měnit nemusíš: jakmile bude znát typ parametru, odvodí
si zbytek sám.

Typ seznamu, do kterého se nezapisuje, se píše takhle (na jiných datech):

```ts
export function pocetMist(sedadla: readonly Sedadlo[]): number {
  return sedadla.length;
}
```

# --hints--

Kontrola už nehlásí implicitní `any`.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.ok(!r.stdout.includes('TS7006'), 'Kontrola už nemá hlásit TS7006 (implicitní any) — otypuj parametr funkce trzba. Hlásí:\n' + r.stdout);
```

`trzba` spočítá tržbu za všechny koncerty.

```js
const { trzba } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(trzba(koncerty), 3658100, 'trzba(koncerty) má vrátit 3658100 — součet prodaných vstupenek krát vstupné');
assert.equal(trzba([koncerty[2]]), 94500, 'trzba([koncert v Ostravě]) má vrátit 94500 (210 × 450)');
```

Prázdný seznam má tržbu nula.

```js
const { trzba } = await helpers.importFile('statistiky.ts');
assert.equal(trzba([]), 0, 'trzba([]) má vrátit 0');
```

`trzba` přijme i seznam, do kterého se nesmí zapisovat.

```js
const kod = [
  "import { koncerty } from './koncerty.ts';",
  "import { trzba } from './statistiky.ts';",
  "const celkem: number = trzba(koncerty);",
  "// @ts-expect-error trzba bere seznam koncertů, ne číslo",
  "const spatne = trzba(42);",
  "console.log(celkem, spatne);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'trzba má brát readonly Koncert[] a vracet number — jinak ji nejde zavolat s katalogem koncertů. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam) {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.mesto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return koncert.prodano * hodnota;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
