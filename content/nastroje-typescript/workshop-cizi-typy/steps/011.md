# --description--

Agentura kromě koncertů eviduje i kapely a místa. Všechno má `id` a všude se
hledá to samé. Místo tří skoro stejných funkcí napíšeš jednu, která si typ nechá
určit od toho, kdo ji volá — a vrátí přesně ten typ, který dostala, se všemi jeho
vlastnostmi.

**Úkol:** v `statistiky.ts` napiš a vyexportuj funkci `podleId`. Dostane seznam
položek, do kterého nezapisuje, a číslo. Vrátí položku s tímhle `id`, nebo nic,
když taková není. Funguje na jakoukoli položku, která má číselné `id`.

Tohle je generická funkce s podmínkou na typový parametr — obojí jsi viděl
v lekci o zúžení a generikách. Zkus ji napsat bez koukání zpátky.

# --hints--

`podleId` najde koncert podle jeho `id`.

```js
const { podleId } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(podleId(koncerty, 2)?.kapela, 'Vojtěch Dyk', 'podleId(koncerty, 2) má vrátit koncert Vojtěcha Dyka');
assert.equal(podleId(koncerty, 4)?.misto, 'Praha', 'podleId(koncerty, 4) má vrátit koncert v Praze');
assert.equal(podleId(koncerty, 99), undefined, 'podleId(koncerty, 99) má vrátit undefined');
assert.equal(podleId([], 1), undefined, 'podleId([], 1) má vrátit undefined');
```

Stejná funkce funguje i na jiná data s `id`.

```js
const { podleId } = await helpers.importFile('statistiky.ts');
const kapely = [
  { id: 10, nazev: 'Zrní', zanr: 'folk' },
  { id: 11, nazev: 'Mydy', zanr: 'elektro' },
];
assert.deepEqual(podleId(kapely, 11), kapely[1], 'podleId(kapely, 11) má vrátit kapelu Mydy — funkce nemá být svázaná s koncerty');
```

Kontrola typů vrátí přesně ten typ, který dostala.

```js
const kod = [
  "import { koncerty } from './koncerty.ts';",
  "import { podleId } from './statistiky.ts';",
  "const kapela: string | undefined = podleId(koncerty, 2)?.kapela;",
  "const mista = [{ id: 1, nazev: 'Sono', kapacita: 800 }];",
  "const kapacita: number | undefined = podleId(mista, 1)?.kapacita;",
  "// @ts-expect-error položky bez id se prohledávat nedají",
  "podleId([{ nazev: 'bez id' }], 1);",
  "console.log(kapela, kapacita);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'podleId má být generická a vracet stejný typ, jaký dostala — včetně vlastností, o kterých sama neví. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Kontrola typů projde a zbytek modulu funguje.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
const { trzba, popisStavu } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(trzba(koncerty), 3658100, 'trzba(koncerty) má dál vracet 3658100');
assert.equal(popisStavu({ stav: 'vyprodano' }), 'Vyprodáno', 'popisStavu má dál fungovat');
```

# --help--

## --tip--

Typový parametr se píše do špičatých závorek za jméno funkce a podmínku na něj
dá `extends` — viz [Generika](see:nastroje-typescript/zuzovani-a-genericita#generika-typ-jako-parametr).

## --tip--

Podmínka na typový parametr říká „cokoli, co má číselné id". Návratový typ je
ten samý parametr, plus možnost, že se nic nenašlo.

## --tip--

Stejný tvar na jiných datech:
`export function posledni<T>(polozky: readonly T[]): T | undefined`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  return [...koncerty, novy];
}

// Stav koncertu: každá varianta nese jen svoje data.
export type StavKoncertu =
  | { stav: 'v-prodeji'; zbyva: number }
  | { stav: 'vyprodano' }
  | { stav: 'zruseno'; duvod: string };

export function stavKoncertu(koncert: Koncert): StavKoncertu {
  if (koncert.zruseno) {
    return { stav: 'zruseno', duvod: koncert.zruseno };
  }
  if (koncert.prodano >= koncert.kapacita) {
    return { stav: 'vyprodano' };
  }
  return { stav: 'v-prodeji', zbyva: koncert.kapacita - koncert.prodano };
}

export function popisStavu(stav: StavKoncertu): string {
  switch (stav.stav) {
    case 'v-prodeji':
      return `V prodeji, zbývá ${stav.zbyva} vstupenek`;
    case 'vyprodano':
      return 'Vyprodáno';
    case 'zruseno':
      return `Zrušeno: ${stav.duvod}`;
    default: {
      const nezname: never = stav;
      return nezname;
    }
  }
}
```
