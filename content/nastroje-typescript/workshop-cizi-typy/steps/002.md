# --description--

Další hlášení:

```text
statistiky.ts(13,54): error TS2551: Property 'mesto' does not exist on type 'Koncert'. Did you mean 'misto'?
```

Tohle je ta nejčastější chyba, kterou typy chytají — a v JavaScriptu by tiše
prošla. `mistaKonani` by vrátila pole samých `undefined` a v aplikaci by bylo
prázdné místo tam, kde měl být seznam měst.

TypeScript navíc rovnou napovídá: `Did you mean 'misto'?` U překlepu nabídne
nejbližší existující klíč.

**Úkol:** oprav `mistaKonani` tak, aby vracela seznam měst, kde se hraje —
každé jednou. Nic jiného na funkci neměň.

Po opravě spusť `npx tsc --noEmit` a podívej se, že hlášení ubylo. Zkus taky
**Spustit** — `ukazka.ts` teď místo `[ undefined, undefined ]` vypíše města.

# --hints--

Kontrola už nehlásí neexistující vlastnost.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.ok(!r.stdout.includes('TS2551'), 'Kontrola už nemá hlásit TS2551 (vlastnost neexistuje). Hlásí:\n' + r.stdout);
```

`mistaKonani` vrátí města bez opakování a v pořadí, v jakém jsou v seznamu.

```js
const { mistaKonani } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.deepEqual(mistaKonani(koncerty), ['Brno', 'Praha', 'Ostrava'], 'mistaKonani(koncerty) má vrátit Brno, Praha, Ostrava — Praha je v seznamu dvakrát, ale ve výsledku má být jednou');
assert.deepEqual(mistaKonani([]), [], 'mistaKonani([]) má vrátit prázdné pole');
```

Tržba funguje dál.

```js
const { trzba } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(trzba(koncerty), 3658100, 'trzba(koncerty) má dál vracet 3658100');
```

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.mesto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return koncert.prodano * hodnota;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
