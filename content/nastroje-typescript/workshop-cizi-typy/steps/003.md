# --description--

Třetí hlášení se týká funkce `obsazenost`:

```text
statistiky.ts(19,22): error TS18048: 'koncert' is possibly 'undefined'.
statistiky.ts(19,40): error TS18048: 'koncert' is possibly 'undefined'.
```

Tuhle situaci jsi řešil ve workshopu o košíku. Napiš to znovu, bez návodu.

**Úkol:** oprav `obsazenost` tak, aby pro neznámé `id` vrátila `0` a pro známé
spočítala obsazenost v procentech jako dosud. Bez `as`, bez vykřičníku.

# --hints--

Kontrola už nehlásí možné `undefined`.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.ok(!r.stdout.includes('TS18048'), 'Kontrola už nemá hlásit TS18048 (možná undefined). Hlásí:\n' + r.stdout);
```

`obsazenost` spočítá procenta pro existující koncerty.

```js
const { obsazenost } = await helpers.importFile('statistiky.ts');
assert.equal(obsazenost(1), 80, 'obsazenost(1) má vrátit 80 — 640 z 800 míst');
assert.equal(obsazenost(2), 100, 'obsazenost(2) má vrátit 100 — vyprodáno');
assert.equal(obsazenost(3), 35, 'obsazenost(3) má vrátit 35 — 210 z 600 míst');
```

Neznámé `id` vrátí nulu a nespadne.

```js
const { obsazenost } = await helpers.importFile('statistiky.ts');
assert.equal(obsazenost(99), 0, 'obsazenost(99) má vrátit 0 — koncert s id 99 neexistuje');
assert.equal(obsazenost(0), 0, 'obsazenost(0) má vrátit 0');
```

Oprava nepoužívá `as` ani vykřičník.

```js
const zdroj = helpers.stripComments(files['statistiky.ts'], 'js');
assert.doesNotMatch(zdroj, /\bas\s+[A-Z]/, 'Oprava se má obejít bez přetypování přes as — to by kontrolu jen umlčelo');
assert.doesNotMatch(zdroj, /koncert!\./, 'Oprava se má obejít bez vykřičníku (koncert!.prodano) — ten je jen kratší zápis toho samého tvrzení');
```

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return koncert.prodano * hodnota;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
