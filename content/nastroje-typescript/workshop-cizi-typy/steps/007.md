# --description--

Poslední dvě hlášení z původních deseti:

```text
statistiky.ts(36,12): error TS2339: Property 'push' does not exist on type 'readonly Koncert[]'.
statistiky.ts(37,3): error TS4104: The type 'readonly Koncert[]' is 'readonly' and cannot be assigned to the mutable type 'Koncert[]'.
```

Data v `koncerty.ts` jsou schválně označená jako seznam jen ke čtení — nabídka
koncertů se mění jen na jednom místě v aplikaci a nikdo jiný do ní nemá zapisovat.
Kolegova `pridejKoncert` tohle pravidlo porušuje.

**Úkol:** oprav `pridejKoncert` tak, aby původní nabídku nechala být a vrátila
**nový** seznam se zadaným koncertem na konci.

Nebudu ti říkat, čím to udělat — způsobů je několik a projde každý, který vrátí
nové pole a do původního nesáhne. Typ `readonly Koncert[]` v `koncerty.ts` neměň,
je tam správně.

> [!TIP]
> Tímhle krokem máš hotovou celou opravu — kontrola typů poprvé mlčí. Dobré místo
> na pauzu. Ve zbytku workshopu už modul jen vylepšuješ.

# --hints--

Kontrola typů projde bez jediné chyby — tímhle jsi vyčistil všech deset hlášení.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít úplně bez chyby. Hlásí:\n' + r.stdout + r.stderr);
```

`pridejKoncert` vrátí nový seznam s koncertem navíc.

```js
const { pridejKoncert } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const novy = { id: 9, kapela: 'Aneta Langerová', misto: 'Plzeň', datum: '2026-12-05', kapacita: 900, prodano: 120, vstupne: 690 };
const seznam = pridejKoncert(novy);
assert.equal(seznam.length, koncerty.length + 1, 'pridejKoncert má vrátit seznam o jeden koncert delší');
assert.deepEqual(seznam[seznam.length - 1], novy, 'nový koncert má být na konci vráceného seznamu');
assert.deepEqual(seznam.slice(0, koncerty.length), [...koncerty], 'ostatní koncerty mají zůstat na svých místech');
```

Původní nabídka zůstane beze změny, i když se přidává dvakrát.

```js
const { pridejKoncert } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const pred = structuredClone([...koncerty]);
pridejKoncert({ id: 9, kapela: 'Aneta Langerová', misto: 'Plzeň', datum: '2026-12-05', kapacita: 900, prodano: 120, vstupne: 690 });
pridejKoncert({ id: 10, kapela: 'Kryštof', misto: 'Zlín', datum: '2026-12-12', kapacita: 1500, prodano: 300, vstupne: 850 });
assert.deepEqual([...koncerty], pred, 'pridejKoncert nemá měnit původní nabídku koncertů — vrať nové pole');
```

Zbytek modulu funguje dál.

```js
const { trzba, prumernaObsazenost, mistaKonani } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(trzba(koncerty), 3658100, 'trzba(koncerty) má dál vracet 3658100');
assert.equal(prumernaObsazenost(koncerty), 73, 'prumernaObsazenost(koncerty) má dál vracet 73');
assert.deepEqual(mistaKonani(koncerty), ['Brno', 'Praha', 'Ostrava'], 'mistaKonani(koncerty) má dál vracet tři města');
```

# --help--

## --tip--

Seznam jen ke čtení má schválně jen metody, které nic nemění a vracejí nové pole —
připomíná to [`readonly`](see:nastroje-typescript/zakladni-typy#volitelne-klice-a-readonly).
Jednu takovou cestu k novému poli znáš z JavaScriptu i bez metod.

## --tip--

Funkce má vrátit nové pole, ve kterém jsou všechny dosavadní koncerty a za nimi
ten nový. Původní pole u toho nikdo neotevírá.

## --tip--

Tenhle tvar potkáš na jiných datech často:
`const sVracenym = [...dostupneKnihy, vracenaKniha];`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
