# --description--

Web potřebuje z každého stavu udělat větu pro návštěvníka. Napíšeš ji tak, aby ti
kontrola typů sama ukázala všechna místa, kam sáhnout, až někdy k stavům přibude
čtvrtý.

**Úkol:** v `statistiky.ts` napiš a vyexportuj funkci `popisStavu`. Dostane stav
koncertu a vrátí text:

- pro koncert v prodeji větu, která začíná slovy `V prodeji` a obsahuje počet
  zbývajících vstupenek,
- pro vyprodaný koncert `Vyprodáno`,
- pro zrušený koncert větu, která začíná slovem `Zrušeno` a obsahuje důvod.

Rozhodování napiš jako `switch` přes rozlišovač a přidej mu větev pro případ,
který nemůže nastat — tu s typem, do kterého se nedá nic přiřadit. Právě ona
z kontroly udělá hlídače úplnosti; jak přesně vypadá, je v lekci
[Vyčerpávající `switch` a `never`](see:nastroje-typescript/zuzovani-a-genericita#vycerpavajici-switch-a-never).

# --hints--

`popisStavu` popíše koncert v prodeji i s počtem zbývajících vstupenek.

```js
const { popisStavu, stavKoncertu } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const popis = popisStavu(stavKoncertu(koncerty[0]));
assert.match(popis, /^V prodeji/u, `popis koncertu v prodeji má začínat slovy „V prodeji", vrátilo: ${popis}`);
assert.match(popis, /160/u, `popis koncertu v Brně má obsahovat počet zbývajících vstupenek (160), vrátilo: ${popis}`);
```

Vyprodaný a zrušený koncert mají svoje věty.

```js
const { popisStavu, stavKoncertu } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(popisStavu({ stav: 'vyprodano' }), 'Vyprodáno', "popisStavu({ stav: 'vyprodano' }) má vrátit přesně „Vyprodáno\"");
const zruseny = popisStavu(stavKoncertu(koncerty[2]));
assert.match(zruseny, /^Zrušeno/u, `popis zrušeného koncertu má začínat slovem „Zrušeno", vrátilo: ${zruseny}`);
assert.ok(zruseny.includes(koncerty[2].zruseno), `popis zrušeného koncertu má obsahovat důvod z dat, vrátilo: ${zruseny}`);
```

Funkce hlídá, že jsou pokryté všechny varianty.

```js
const zdroj = helpers.stripComments(files['statistiky.ts'], 'js');
assert.match(zdroj, /:\s*never\b/, 'Ve větvi, která nemůže nastat, má být proměnná typu never — jinak ti kontrola nová varianta stavu neohlásí');
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby. Hlásí:\n' + r.stdout + r.stderr);
```

`popisStavu` bere jen platné stavy — nic jiného kontrola nepustí.

```js
const kod = [
  "import { popisStavu } from './statistiky.ts';",
  "const text: string = popisStavu({ stav: 'vyprodano' });",
  "const dalsi: string = popisStavu({ stav: 'v-prodeji', zbyva: 10 });",
  "// @ts-expect-error takový stav v typu StavKoncertu není",
  "popisStavu({ stav: 'odlozeno', novyDatum: '2026-12-01' });",
  "// @ts-expect-error variantě v-prodeji chybí zbyva",
  "popisStavu({ stav: 'v-prodeji' });",
  "console.log(text, dalsi);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'popisStavu má brát právě typ StavKoncertu — ne any a ne obecný objekt. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

# --explain--

Vysvětli vlastními slovy, proč se do poslední větve `switch`e píše proměnná typu
`never` a co se stane, až ke stavům přibude čtvrtý.

## --model--

Do proměnné typu `never` se nedá přiřadit žádná hodnota. Dokud jsou v `switch`i
pokryté všechny varianty, do poslední větve žádná nezbývá — hodnota má typ `never`
a řádek projde. Jakmile do sjednocení přidám čtvrtý stav a zapomenu na něj
`case`, může do té větve spadnout, kontrola to pozná a ohlásí mi chybu přesně
tam, kde mám doplnit chování. Je to hlídač úplnosti, který se ozve při psaní,
a ne u zákazníka.

## --checklist--

- Do typu `never` se nedá přiřadit žádná hodnota.
- Když jsou pokryté všechny varianty, v poslední větvi nic nezbývá.
- Nová varianta tam něco nechá, a přiřazení proto přestane procházet.
- Chybu ohlásí kontrola typů, ne až běh programu.

# --help--

## --tip--

`switch` se ptá na rozlišovač, tedy na klíč `stav`. Uvnitř každé větve je stav
zúžený na jednu variantu, takže na její data můžeš sáhnout.

## --tip--

Větev `default` potřebuje vlastní blok se složenými závorkami, aby se v ní dala
deklarovat proměnná. Ta proměnná má typ, do kterého se nedá přiřadit žádná
hodnota.

## --tip--

Na jiných datech vypadá ta větev takhle:
`default: { const neznamaPlatba: never = platba; return neznamaPlatba; }`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  return [...koncerty, novy];
}

// Stav koncertu: každá varianta nese jen svoje data.
export type StavKoncertu =
  | { stav: 'v-prodeji'; zbyva: number }
  | { stav: 'vyprodano' }
  | { stav: 'zruseno'; duvod: string };

export function stavKoncertu(koncert: Koncert): StavKoncertu {
  if (koncert.zruseno) {
    return { stav: 'zruseno', duvod: koncert.zruseno };
  }
  if (koncert.prodano >= koncert.kapacita) {
    return { stav: 'vyprodano' };
  }
  return { stav: 'v-prodeji', zbyva: koncert.kapacita - koncert.prodano };
}
```

```ts
}

export function popisStavu(stav: StavKoncertu): string {
  switch (stav.stav) {
    case 'v-prodeji':
      return `V prodeji, zbývá ${stav.zbyva} vstupenek`;
    case 'vyprodano':
      return 'Vyprodáno';
    case 'zruseno':
      return `Zrušeno: ${stav.duvod}`;
    default: {
      const nezname: never = stav;
      return nezname;
    }
  }
}
```
