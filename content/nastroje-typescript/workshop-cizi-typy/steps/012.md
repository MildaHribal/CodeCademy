# --description--

Na hlavní stránku chce agentura jedno číslo: kolik vstupenek je dohromady ještě
v prodeji. Vyprodané a zrušené koncerty se do něj nepočítají — a jen u koncertů
v prodeji vůbec existuje údaj o zbývajících vstupenkách.

Přesně proto je stav rozlišené sjednocení: počet zbývajících vstupenek si
z hodnoty nepřečteš, dokud kontrole neukážeš, že jde o koncert v prodeji.

**Úkol:** v `statistiky.ts` napiš a vyexportuj funkci `zbyvaCelkem`. Dostane
seznam koncertů, do kterého nezapisuje, a vrátí součet zbývajících vstupenek
přes všechny koncerty, které jsou v prodeji. U prázdného seznamu vrátí nulu.

Stav koncertu zjistíš funkcí z minulých kroků, nepočítej ho znovu.

# --hints--

`zbyvaCelkem` sečte zbývající vstupenky jen u koncertů v prodeji.

```js
const { zbyvaCelkem } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(zbyvaCelkem(koncerty), 460, 'zbyvaCelkem(koncerty) má vrátit 460 — 160 v Brně a 300 u Lennyho; Praha je vyprodaná a Ostrava zrušená');
assert.equal(zbyvaCelkem([koncerty[0]]), 160, 'zbyvaCelkem([koncert v Brně]) má vrátit 160');
```

Vyprodané ani zrušené koncerty se nezapočítají.

```js
const { zbyvaCelkem } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(zbyvaCelkem([koncerty[1]]), 0, 'zbyvaCelkem([vyprodaný koncert]) má vrátit 0');
assert.equal(zbyvaCelkem([koncerty[2]]), 0, 'zbyvaCelkem([zrušený koncert]) má vrátit 0 — i když na něj vstupenky zbývaly');
assert.equal(zbyvaCelkem([]), 0, 'zbyvaCelkem([]) má vrátit 0');
```

Zrušený koncert se nepočítá, ani kdyby na něm zbývala spousta míst.

```js
const { zbyvaCelkem } = await helpers.importFile('statistiky.ts');
const zruseny = { id: 20, kapela: 'Kapela', misto: 'Brno', datum: '2026-12-01', kapacita: 5000, prodano: 10, vstupne: 500, zruseno: 'Nemoc' };
const vProdeji = { id: 21, kapela: 'Jiná kapela', misto: 'Zlín', datum: '2026-12-02', kapacita: 100, prodano: 40, vstupne: 400 };
assert.equal(zbyvaCelkem([zruseny, vProdeji]), 60, 'zbyvaCelkem má z těchhle dvou koncertů započítat jen ten v prodeji, tedy 60 vstupenek');
```

Kontrola typů projde bez chyby.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.equal(r.code, 0, 'npx tsc --noEmit má projít bez chyby — na zbyva se dá sáhnout až po zúžení stavu. Hlásí:\n' + r.stdout + r.stderr);
```

# --help--

## --tip--

Údaj `zbyva` má jen jedna varianta stavu. Dostaneš se k němu porovnáním
rozlišovače — viz [zúžení podmínkou](see:nastroje-typescript/zuzovani-a-genericita#zuzeni-podminkou).

## --tip--

Projdi koncerty jeden po druhém, u každého si zjisti stav a zeptej se ho, jestli
je v prodeji. Až uvnitř té podmínky má hodnota klíč s počtem.

## --tip--

Stejný tvar na jiných datech:
`if (platba.stav === 'zaplaceno') { celkem += platba.castka; }`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  return [...koncerty, novy];
}

// Stav koncertu: každá varianta nese jen svoje data.
export type StavKoncertu =
  | { stav: 'v-prodeji'; zbyva: number }
  | { stav: 'vyprodano' }
  | { stav: 'zruseno'; duvod: string };

export function stavKoncertu(koncert: Koncert): StavKoncertu {
  if (koncert.zruseno) {
    return { stav: 'zruseno', duvod: koncert.zruseno };
  }
  if (koncert.prodano >= koncert.kapacita) {
    return { stav: 'vyprodano' };
  }
  return { stav: 'v-prodeji', zbyva: koncert.kapacita - koncert.prodano };
}

export function popisStavu(stav: StavKoncertu): string {
  switch (stav.stav) {
    case 'v-prodeji':
      return `V prodeji, zbývá ${stav.zbyva} vstupenek`;
    case 'vyprodano':
      return 'Vyprodáno';
    case 'zruseno':
      return `Zrušeno: ${stav.duvod}`;
    default: {
      const nezname: never = stav;
      return nezname;
    }
  }
}

export function podleId<T extends { id: number }>(polozky: readonly T[], id: number): T | undefined {
  return polozky.find((polozka) => polozka.id === id);
}

// Kolik vstupenek zbývá dohromady na koncertech, které se dají koupit.
export function zbyvaCelkem(seznam: readonly Koncert[]): number {

  for (const koncert of seznam) {
    const stav = stavKoncertu(koncert);
    if (stav.stav === 'v-prodeji') {
      zbyva += stav.zbyva;
    }
  }
  return zbyva;
}
```
