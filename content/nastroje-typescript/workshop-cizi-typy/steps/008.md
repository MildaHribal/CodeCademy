# --description--

Modul je opravený, teď ho rozšíříš. Web agentury má u každého koncertu ukazovat
stav: kolik zbývá vstupenek, jestli je vyprodáno, nebo že se koncert nekoná.
Každý stav má jiná data — a přesně na to je rozlišené sjednocení.

**Úkol:** připrav podklady ve dvou souborech.

1. V `koncerty.ts` přidej do typu `Koncert` nepovinný klíč `zruseno` s textem
   (důvod zrušení). U koncertu v Ostravě (id 3) důvod vyplň, text si vymysli —
   ostatní koncerty nech bez něj.
2. V `statistiky.ts` napiš a vyexportuj typ `StavKoncertu` se třemi variantami.
   Rozlišovač se jmenuje `stav`:
   - `'v-prodeji'` a k tomu číslo `zbyva`,
   - `'vyprodano'` a nic dalšího,
   - `'zruseno'` a k tomu text `duvod`.

Funkci, která stav spočítá, napíšeš v dalším kroku.

# --hints--

Typ `Koncert` má nepovinný klíč `zruseno` a Ostrava má vyplněný důvod.

```js
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(typeof koncerty[2].zruseno, 'string', 'Koncert v Ostravě (id 3) má mít vyplněný důvod zrušení');
assert.ok(koncerty[2].zruseno.length > 0, 'důvod zrušení nemá být prázdný text');
assert.equal(koncerty[0].zruseno, undefined, 'ostatní koncerty mají zůstat bez klíče zruseno');
assert.equal(koncerty[3].zruseno, undefined, 'ostatní koncerty mají zůstat bez klíče zruseno');
```

Typ `StavKoncertu` má tři varianty se správnými daty.

```js
const kod = [
  "import type { StavKoncertu } from './statistiky.ts';",
  "const vProdeji: StavKoncertu = { stav: 'v-prodeji', zbyva: 120 };",
  "const vyprodano: StavKoncertu = { stav: 'vyprodano' };",
  "const zruseno: StavKoncertu = { stav: 'zruseno', duvod: 'Nemoc kapely' };",
  "// @ts-expect-error varianta v-prodeji musí mít zbyva",
  "const bezZbyva: StavKoncertu = { stav: 'v-prodeji' };",
  "// @ts-expect-error takový stav v typu není",
  "const vymysleny: StavKoncertu = { stav: 'odlozeno' };",
  "console.log(vProdeji, vyprodano, zruseno, bezZbyva, vymysleny);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'Typ StavKoncertu má mít tři varianty rozlišené klíčem stav, každou jen se svými daty. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Data z jedné varianty nejdou číst, dokud se stav nezúží.

```js
const kod = [
  "import type { StavKoncertu } from './statistiky.ts';",
  "function popis(stav: StavKoncertu): string {",
  "  if (stav.stav === 'zruseno') return stav.duvod;",
  "  return 'jiný stav';",
  "}",
  "// @ts-expect-error duvod má jen varianta zruseno",
  "function spatne(stav: StavKoncertu): string { return stav.duvod; }",
  "console.log(popis({ stav: 'vyprodano' }), spatne({ stav: 'vyprodano' }));",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'Varianty se mají lišit daty: duvod má patřit jen k variantě zruseno a být čitelný až po zúžení. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

# --help--

## --tip--

Nepovinný klíč se v typu značí jedním znakem za jménem — viz
[volitelné klíče](see:nastroje-typescript/zakladni-typy#volitelne-klice-a-readonly).
Sjednocení variant se píše svislými čarami, každá varianta na svém řádku.

## --tip--

Každá varianta je celý objektový typ, ne jen hodnota rozlišovače. Společný má
jen klíč `stav`, zbytek se liší.

## --tip--

Tvar na jiných datech:
`type StavPlatby = { stav: 'ceka' } | { stav: 'zaplaceno'; castka: number } | { stav: 'vracena'; duvod: string };`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  return [...koncerty, novy];
}
```
