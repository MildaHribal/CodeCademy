# --description--

Čtvrté hlášení vypadá zvláštně:

```text
statistiky.ts(26,28): error TS2363: The right-hand side of an arithmetic operation must be of type 'any', 'number', 'bigint' or an enum type.
```

Přeloženo: **napravo od operátoru je něco, s čím se nedá počítat.** Funkce
`trzbaPriCene` dostává `hodnota: string` — vstupné, které uživatel napsal do
formuláře — a rovnou jím násobí. V JavaScriptu by `640 * '700'` prošlo
(a `640 * '7e5'` taky, a `640 * ''` vyšlo nula), tady se kontrola ozve.

Anotace typu nic nepřevádí. Převod musíš udělat sám, a hlavně ošetřit, že
uživatel může napsat cokoli.

**Úkol:** oprav `trzbaPriCene` tak, aby text z formuláře převedla na číslo
a s ním počítala.

- Když z textu žádné číslo nevyjde (třeba `'sedm set'` nebo prázdné pole),
  vrátí funkce `0`.
- Záporné vstupné taky nedává smysl — i tam vrátí `0`.
- Parametr nech dál jako text, takhle to opravdu přijde z formuláře.

Vzor na jiných datech:

```ts
const kapacita = Number(zFormulare.kapacita);
if (!Number.isFinite(kapacita) || kapacita <= 0) {
  return 'Zadej kapacitu jako kladné číslo.';
}
```

Kontrola už nehlásí počítání s textem.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.ok(!r.stdout.includes('TS2363'), 'Kontrola už nemá hlásit TS2363 (počítání s textem). Hlásí:\n' + r.stdout);
```

`trzbaPriCene` spočítá tržbu při ceně z formuláře.

```js
const { trzbaPriCene } = await helpers.importFile('statistiky.ts');
assert.equal(trzbaPriCene(1, '700'), 448000, "trzbaPriCene(1, '700') má vrátit 448000 — 640 prodaných krát 700");
assert.equal(trzbaPriCene(3, '500'), 105000, "trzbaPriCene(3, '500') má vrátit 105000");
assert.equal(trzbaPriCene(1, '0'), 0, "trzbaPriCene(1, '0') má vrátit 0 — vstupné zdarma znamená nulovou tržbu");
```

Nesmyslný vstup vrátí nulu.

```js
const { trzbaPriCene } = await helpers.importFile('statistiky.ts');
assert.equal(trzbaPriCene(1, 'sedm set'), 0, "trzbaPriCene(1, 'sedm set') má vrátit 0 — z textu žádné číslo nevyjde");
assert.equal(trzbaPriCene(1, '-200'), 0, "trzbaPriCene(1, '-200') má vrátit 0 — záporné vstupné nedává smysl");
assert.equal(trzbaPriCene(99, '700'), 0, "trzbaPriCene(99, '700') má vrátit 0 — koncert s id 99 neexistuje");
```

Výsledek je vždycky číslo, nikdy `NaN`.

```js
const { trzbaPriCene } = await helpers.importFile('statistiky.ts');
for (const vstup of ['', '   ', 'abc', 'NaN', '1e3abc']) {
  const vysledek = trzbaPriCene(1, vstup);
  assert.ok(Number.isFinite(vysledek), `trzbaPriCene(1, '${vstup}') má vrátit číslo, vrátilo: ${vysledek}`);
}
```

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return koncert.prodano * hodnota;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
