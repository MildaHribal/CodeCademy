# --description--

Páté hlášení:

```text
statistiky.ts(31,3): error TS2322: Type 'Koncert | undefined' is not assignable to type 'Koncert'.
  Type 'undefined' is not assignable to type 'Koncert'.
```

Přečteno odspodu: `undefined` se nedá dosadit tam, kde má být `Koncert`. Funkce
`prvniVyprodany` v hlavičce slibuje, že vrátí koncert — ale uvnitř používá
hledání, které nemusí nic najít.

Jsou dvě cesty, jak to spravit, a je důležité vybrat správně:

1. **Vymyslet náhradní hodnotu** (třeba první koncert v seznamu). To by byla
   lež: volající by dostal koncert, který vyprodaný není.
2. **Přiznat pravdu v hlavičce.** Funkce vrací koncert, **nebo** nic — a ten,
   kdo ji volá, se s tím musí vypořádat.

**Úkol:** oprav hlavičku `prvniVyprodany` tak, aby říkala pravdu o tom, co
funkce vrací. Tělo nech beze změny.

# --hints--

Kontrola už nehlásí nesedící návratový typ.

```js
const r = await helpers.run('npx tsc --noEmit');
assert.ok(!r.stdout.includes('TS2322'), 'Kontrola už nemá hlásit TS2322 (návratový typ nesedí). Hlásí:\n' + r.stdout);
```

`prvniVyprodany` najde vyprodaný koncert, a když žádný není, vrátí `undefined`.

```js
const { prvniVyprodany } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(prvniVyprodany(koncerty)?.id, 2, 'prvniVyprodany(koncerty) má vrátit koncert s id 2 — jediný vyprodaný');
assert.equal(prvniVyprodany([koncerty[0], koncerty[2]]), undefined, 'prvniVyprodany(seznam bez vyprodaného koncertu) má vrátit undefined');
assert.equal(prvniVyprodany([]), undefined, 'prvniVyprodany([]) má vrátit undefined');
```

Volající je na `undefined` upozorněný ještě před spuštěním.

```js
const kod = [
  "import { koncerty } from './koncerty.ts';",
  "import { prvniVyprodany } from './statistiky.ts';",
  "// @ts-expect-error výsledek může být undefined, tady na něj sahám bez kontroly",
  "const kapela: string = prvniVyprodany(koncerty).kapela;",
  "const opatrne: string = prvniVyprodany(koncerty)?.kapela ?? 'žádný';",
  "console.log(kapela, opatrne);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'Návratový typ má přiznat, že funkce nemusí nic najít — pak kontrola upozorní každého, kdo na výsledek sáhne bez ošetření. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Zbytek modulu funguje dál.

```js
const { trzba, obsazenost, mistaKonani } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(trzba(koncerty), 3658100, 'trzba(koncerty) má dál vracet 3658100');
assert.equal(obsazenost(4), 75, 'obsazenost(4) má vrátit 75');
assert.deepEqual(mistaKonani(koncerty), ['Brno', 'Praha', 'Ostrava'], 'mistaKonani(koncerty) má dál vracet tři města');
```

# --explain--

Vysvětli vlastními slovy, proč je lepší přiznat `undefined` v návratovém typu než
vrátit náhradní hodnotu.

## --model--

Návratový typ je slib, který funkce dává všem, kdo ji volají. Když slíbí koncert
a žádný vyprodaný není, musí si něco vymyslet — a volající se pak rozhoduje podle
hodnoty, která není pravdivá. Když místo toho přizná, že nemusí nic najít, přenese
rozhodnutí tam, kam patří: každý, kdo funkci volá, si sám řekne, co se má stát,
když nic není. A kontrola typů mu to nedovolí přeskočit.

## --checklist--

- Návratový typ je slib vůči tomu, kdo funkci volá.
- Náhradní hodnota zamlčí, že se nic nenašlo.
- `Koncert | undefined` přesune rozhodnutí na volajícího.
- Se `strictNullChecks` kontrola nedovolí na výsledek sáhnout bez ošetření.

# --help--

## --tip--

Podívej se na typ, který vrací hledání v poli — připomíná ho past
[`Object is possibly 'undefined'`](see:nastroje-typescript/zakladni-typy#typicke-chyby-a-pasti).
Hlavička funkce má říkat totéž.

## --tip--

Měníš jednu věc za dvojtečkou v hlavičce funkce. Tělo zůstane přesně takové,
jaké je.

## --tip--

Na jiných datech vypadá stejná hlavička takhle:
`export function najdiUzivatele(email: string): Uzivatel | undefined`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
