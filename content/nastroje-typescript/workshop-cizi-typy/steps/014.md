# --description--

Administrace umí u koncertu změnit cokoli kromě `id` — a posílá jen ta pole,
která uživatel opravdu upravil. Typ pro takovou změnu už máš skoro hotový: je to
nový koncert, u kterého je všechno nepovinné.

**Úkol:** v `statistiky.ts` napiš a vyexportuj funkci `upravKoncert`. Dostane
seznam koncertů (nezapisuje do něj), `id` upravovaného koncertu a objekt se
změnami, ve kterém může být kterákoli vlastnost nového koncertu — a nemusí být
žádná. Vrátí nový seznam, ve kterém má koncert s tímhle `id` změněné hodnoty
a ostatní koncerty zůstaly beze změny. Když koncert s daným `id` v seznamu není,
vrátí seznam, jaký dostala.

Typ změn odvoď dalším pomocným typem z toho, který jsi napsal v minulém kroku —
ať se `id` nedá přepsat ani omylem.

# --hints--

`upravKoncert` změní jen vyjmenované hodnoty jednoho koncertu.

```js
const { upravKoncert } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const upraveny = upravKoncert(koncerty, 1, { vstupne: 650 });
assert.equal(upraveny.length, koncerty.length, 'upravKoncert má vrátit seznam stejně dlouhý');
assert.equal(upraveny[0].vstupne, 650, 'koncert s id 1 má mít nové vstupné 650');
assert.equal(upraveny[0].kapela, 'Zrní', 'ostatní vlastnosti upraveného koncertu mají zůstat');
assert.equal(upraveny[0].id, 1, 'id upraveného koncertu se nemá změnit');
assert.equal(upraveny[1].vstupne, koncerty[1].vstupne, 'ostatní koncerty se měnit nemají');
```

Změnit jde víc hodnot najednou i žádná.

```js
const { upravKoncert } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const dve = upravKoncert(koncerty, 3, { misto: 'Olomouc', kapacita: 700 });
assert.equal(dve[2].misto, 'Olomouc', 'místo koncertu s id 3 se má změnit');
assert.equal(dve[2].kapacita, 700, 'kapacita koncertu s id 3 se má změnit');
const zadna = upravKoncert(koncerty, 3, {});
assert.deepEqual(zadna[2], koncerty[2], 'prázdný objekt změn nemá koncert nijak změnit');
```

Neznámé `id` nechá seznam beze změny a původní seznam se nemění.

```js
const { upravKoncert } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const pred = structuredClone([...koncerty]);
const stejny = upravKoncert(koncerty, 99, { vstupne: 1 });
assert.deepEqual(stejny, pred, 'upravKoncert s neznámým id má vrátit seznam beze změny');
upravKoncert(koncerty, 1, { vstupne: 1 });
assert.deepEqual([...koncerty], pred, 'upravKoncert nemá měnit původní seznam');
```

Kontrola typů dovolí jen vlastnosti koncertu — a `id` mezi ně nepatří.

```js
const kod = [
  "import { koncerty } from './koncerty.ts';",
  "import { upravKoncert } from './statistiky.ts';",
  "const a = upravKoncert(koncerty, 1, { vstupne: 650 });",
  "const b = upravKoncert(koncerty, 1, {});",
  "const c = upravKoncert(koncerty, 1, { misto: 'Olomouc', kapacita: 700, zruseno: 'Nemoc' });",
  "// @ts-expect-error id se upravovat nesmí",
  "upravKoncert(koncerty, 1, { id: 8 });",
  "// @ts-expect-error vstupné je číslo",
  "upravKoncert(koncerty, 1, { vstupne: '650' });",
  "// @ts-expect-error takovou vlastnost koncert nemá",
  "upravKoncert(koncerty, 1, { poznamka: 'nic' });",
  "console.log(a.length, b.length, c.length);",
].join('\n');
await helpers.run(`cat > .kontrola.ts <<'KONEC'\n${kod}\nKONEC`);
const r = await helpers.run('npx tsc --noEmit --strict --target esnext --module nodenext --moduleResolution nodenext --types node --allowImportingTsExtensions --ignoreConfig .kontrola.ts');
const chybyKontroly = r.stdout.split('\n').filter((radek) => radek.startsWith('.kontrola.ts('));
assert.deepEqual(chybyKontroly, [], 'Typ změn má mít všechny vlastnosti koncertu nepovinné a klíč id v něm být nesmí. Kontrola typů hlásí:\n' + r.stdout + r.stderr);
```

Typ změn je odvozený, ne opsaný.

```js
const zdroj = helpers.stripComments(files['statistiky.ts'], 'js');
```

# --help--

## --tip--

Pomocný typ, který udělá ze všech klíčů nepovinné, je v tabulce v lekci
[keyof a pomocné typy](see:nastroje-typescript/zuzovani-a-genericita#keyof-a-pomocne-typy).
Dá se zabalit do sebe s tím z minulého kroku.

## --tip--

Nový seznam vyrobíš tak, že projdeš položky a u té jedné vrátíš spojení původního
koncertu se změnami. Pořadí při spojování rozhoduje o tom, co vyhraje.

## --tip--

Na jiných datech vypadá stejná úprava takhle:
`clanky.map((clanek) => (clanek.id === id ? { ...clanek, ...zmeny } : clanek))`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  return [...koncerty, novy];
}

// Stav koncertu: každá varianta nese jen svoje data.
export type StavKoncertu =
  | { stav: 'v-prodeji'; zbyva: number }
  | { stav: 'vyprodano' }
  | { stav: 'zruseno'; duvod: string };

export function stavKoncertu(koncert: Koncert): StavKoncertu {
  if (koncert.zruseno) {
    return { stav: 'zruseno', duvod: koncert.zruseno };
  }
  if (koncert.prodano >= koncert.kapacita) {
    return { stav: 'vyprodano' };
  }
  return { stav: 'v-prodeji', zbyva: koncert.kapacita - koncert.prodano };
}

export function popisStavu(stav: StavKoncertu): string {
  switch (stav.stav) {
    case 'v-prodeji':
      return `V prodeji, zbývá ${stav.zbyva} vstupenek`;
    case 'vyprodano':
      return 'Vyprodáno';
    case 'zruseno':
      return `Zrušeno: ${stav.duvod}`;
    default: {
      const nezname: never = stav;
      return nezname;
    }
  }
}

export function podleId<T extends { id: number }>(polozky: readonly T[], id: number): T | undefined {
  return polozky.find((polozka) => polozka.id === id);
}

// Kolik vstupenek zbývá dohromady na koncertech, které se dají koupit.
export function zbyvaCelkem(seznam: readonly Koncert[]): number {
  let zbyva = 0;
  for (const koncert of seznam) {
    const stav = stavKoncertu(koncert);
    if (stav.stav === 'v-prodeji') {
      zbyva += stav.zbyva;
    }
  }
  return zbyva;
}

// Koncert, který ještě nemá id — takový přijde z formuláře.
export type NovyKoncert = Omit<Koncert, 'id'>;

export function vytvorKoncert(novy: NovyKoncert, seznam: readonly Koncert[]): Koncert[] {
  const dalsiId = Math.max(0, ...seznam.map((koncert) => koncert.id)) + 1;
  return [...seznam, { ...novy, id: dalsiId }];
}
```
