# --description--

Formulář „přidat koncert" posílá všechna data kromě `id` — to přiděluje systém.
Psát kvůli tomu druhý typ, který se od `Koncert` liší o jediný klíč, by byla
práce navíc: až někdo do koncertu přidá vlastnost, zapomene ji tam doplnit.

**Úkol:** v `statistiky.ts` přidej dvě věci.

1. Vyexportuj typ `NovyKoncert`. Je to koncert bez klíče `id`, odvozený z typu
   `Koncert` pomocným typem — nepiš klíče znovu.
2. Vyexportuj funkci `vytvorKoncert`. Dostane nový koncert bez `id` a seznam
   dosavadních koncertů, do kterého nezapisuje. Vrátí nový seznam, na jehož konci
   je nový koncert s `id` o jedna větším, než je nejvyšší dosud použité. Když je
   seznam prázdný, dostane nový koncert `id` rovné jedné.

# --hints--

`vytvorKoncert` přidá koncert s dalším volným `id`.

```js
const { vytvorKoncert } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
const novy = { kapela: 'Aneta Langerová', misto: 'Plzeň', datum: '2026-12-05', kapacita: 900, prodano: 120, vstupne: 690 };
const seznam = vytvorKoncert(novy, koncerty);
assert.equal(seznam.length, koncerty.length + 1, 'vytvorKoncert má vrátit seznam o jeden koncert delší');
assert.equal(seznam[seznam.length - 1].id, 5, 'nový koncert má dostat id 5 — nejvyšší dosud použité je 4');
assert.equal(seznam[seznam.length - 1].kapela, 'Aneta Langerová', 'nový koncert si má nechat data z formuláře');
```

Typ `NovyKoncert` je odvozený z `Koncert` a `id` v něm chybí.

```js
const kod = [

  "const prvniId: number = seznam[0].id;",
```

# --explain--

Vysvětli vlastními slovy, proč je lepší `NovyKoncert` odvodit z typu `Koncert`
než mu klíče napsat znovu.

## --model--

Opsané klíče jsou kopie, která se přestane shodovat hned, jak někdo do koncertu
přidá vlastnost. Nikdo si nevzpomene, že ji má doplnit i na druhém místě — a formulář
tichounce přestane posílat něco, co má. Odvozený typ se změní sám: je to ten samý
typ mínus jeden klíč. Navíc je v kódu vidět úmysl, tedy že jde o koncert bez `id`,
ne o nějaký jiný, podobný typ.

## --checklist--

- Opsané klíče se rozejdou, jakmile se původní typ změní.
- Odvozený typ se změní automaticky s ním.
- `Omit` z typu vyhodí vyjmenované klíče, ostatní nechá.
- Z názvu a odvození je vidět úmysl: koncert bez `id`.

# --help--

## --tip--

Pomocný typ, který z typu vyhodí vyjmenované klíče, je v tabulce v lekci
[keyof a pomocné typy](see:nastroje-typescript/zuzovani-a-genericita#keyof-a-pomocne-typy).

## --tip--

Nejvyšší dosud použité `id` najdeš z čísel v seznamu. Pozor na prázdný seznam:
hledání maxima z ničeho vrací `-Infinity`, tam potřebuješ začít od nuly.

## --tip--

Sestavení nového objektu z formulářových dat a jednoho klíče navíc vypadá na
jiných datech takhle: `{ ...zFormulare, id: dalsiId, vytvoreno: new Date() }`

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  if (seznam.length === 0) return 0;
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / seznam.length);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  return [...koncerty, novy];
}

// Stav koncertu: každá varianta nese jen svoje data.
export type StavKoncertu =
  | { stav: 'v-prodeji'; zbyva: number }
  | { stav: 'vyprodano' }
  | { stav: 'zruseno'; duvod: string };

export function stavKoncertu(koncert: Koncert): StavKoncertu {
  if (koncert.zruseno) {
    return { stav: 'zruseno', duvod: koncert.zruseno };
  }
  if (koncert.prodano >= koncert.kapacita) {
    return { stav: 'vyprodano' };
  }
  return { stav: 'v-prodeji', zbyva: koncert.kapacita - koncert.prodano };
}

export function popisStavu(stav: StavKoncertu): string {
  switch (stav.stav) {
    case 'v-prodeji':
      return `V prodeji, zbývá ${stav.zbyva} vstupenek`;
    case 'vyprodano':
      return 'Vyprodáno';
    case 'zruseno':
      return `Zrušeno: ${stav.duvod}`;
    default: {
      const nezname: never = stav;
      return nezname;
    }
  }
}

export function podleId<T extends { id: number }>(polozky: readonly T[], id: number): T | undefined {
  return polozky.find((polozka) => polozka.id === id);
}

// Kolik vstupenek zbývá dohromady na koncertech, které se dají koupit.
export function zbyvaCelkem(seznam: readonly Koncert[]): number {
  let zbyva = 0;
  for (const koncert of seznam) {
    const stav = stavKoncertu(koncert);
    if (stav.stav === 'v-prodeji') {
      zbyva += stav.zbyva;
    }
  }
  return zbyva;
}

// Koncert, který ještě nemá id — takový přijde z formuláře.
export type NovyKoncert = Omit<Koncert, 'id'>;

export function vytvorKoncert(novy: NovyKoncert, seznam: readonly Koncert[]): Koncert[] {
  const dalsiId = Math.max(0, ...seznam.map((koncert) => koncert.id)) + 1;
  return [...seznam, { ...novy, id: dalsiId }];
}
```
