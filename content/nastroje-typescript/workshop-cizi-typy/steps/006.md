# --description--

## Hlášení

Manažerka agentury píše: „V reportu mi u průměrné obsazenosti svítí **3 %**.
Přitom nejhorší koncert máme obsazený z 35 procent a jeden je vyprodaný. Jak
může vyjít tři?"

Funkci `prumernaObsazenost` dopsal kolega Tomáš do `statistiky.ts` těsně před
odchodem. `npx tsc --noEmit` na ni nehlásí **nic** — typy jsou v pořádku,
sečítají se čísla a vrací se číslo.

> [!REMEMBER]
> **Kontrola typů hlídá tvary hodnot, ne jejich význam.** Že se dělí špatným
> číslem, pozná až test nebo člověk.

## Úkol

Oprav `prumernaObsazenost` tak, aby vracela skutečný průměr obsazeností všech
koncertů v seznamu, zaokrouhlený na celá procenta. U prázdného seznamu vrať `0`
(dnes by z něj vyšlo `NaN`). Změň co nejmenší kus kódu, zbytek funkce nech být.

# --hints--

`prumernaObsazenost` spočítá průměr obsazeností všech koncertů.

```js
const { prumernaObsazenost } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(prumernaObsazenost(koncerty), 73, 'prumernaObsazenost(koncerty) má vrátit 73 — průměr z 80, 100, 35 a 75 procent');
assert.equal(prumernaObsazenost([koncerty[0]]), 80, 'prumernaObsazenost([koncert v Brně]) má vrátit 80 — u jednoho koncertu je průměr jeho obsazenost');
assert.equal(prumernaObsazenost([koncerty[1], koncerty[2]]), 68, 'prumernaObsazenost([Praha, Ostrava]) má vrátit 68 — průměr ze 100 a 35 je 67,5');
```

Prázdný seznam vrátí nulu, ne `NaN`.

```js
const { prumernaObsazenost } = await helpers.importFile('statistiky.ts');
const vysledek = prumernaObsazenost([]);
assert.equal(vysledek, 0, `prumernaObsazenost([]) má vrátit 0, vrátila: ${vysledek}`);
```

Zbytek modulu funguje dál a kontrola typů mlčí.

```js
const { trzba, obsazenost, prvniVyprodany } = await helpers.importFile('statistiky.ts');
const { koncerty } = await helpers.importFile('koncerty.ts');
assert.equal(trzba(koncerty), 3658100, 'trzba(koncerty) má dál vracet 3658100');
assert.equal(obsazenost(3), 35, 'obsazenost(3) má dál vracet 35');
assert.equal(prvniVyprodany(koncerty)?.id, 2, 'prvniVyprodany(koncerty) má dál vracet koncert s id 2');
const r = await helpers.run('npx tsc --noEmit');
assert.ok(!r.stdout.includes('prumernaObsazenost'), 'Oprava nemá přidat novou typovou chybu. Kontrola hlásí:\n' + r.stdout);
```

# --help--

## --tip--

Projdi si výpočet na dvou koncertech s tužkou: co se sčítá a čím se to má dělit,
aby vyšel průměr.

## --tip--

Číslo `100` ve výpočtu je tam ze dvou různých důvodů. Jedno z nich je převod na
procenta, druhé tam nemá co dělat.

## --tip--

Průměr na jiných datech: `soucetZnamek / znamky.length` — dělí se **počtem
položek**, ne velikostí stupnice.

## --file-- statistiky.ts

```ts
// Statistiky koncertů. Modul psal kolega v JavaScriptu; po přejmenování na .ts
// hlásí kontrola typů deset řádků chyb. Data v koncerty.ts jsou v pořádku.
import { koncerty } from './koncerty.ts';
import type { Koncert } from './koncerty.ts';

// Tržba za všechny koncerty: prodané vstupenky krát cena vstupenky.
export function trzba(seznam: readonly Koncert[]): number {
  return seznam.reduce((soucet, koncert) => soucet + koncert.prodano * koncert.vstupne, 0);
}

// Seznam měst, kde se hraje, každé jednou.
export function mistaKonani(seznam: readonly Koncert[]): string[] {
  return [...new Set(seznam.map((koncert) => koncert.misto))];
}

// Obsazenost koncertu v procentech, zaokrouhlená na celá procenta.
export function obsazenost(id: number): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  return Math.round((koncert.prodano / koncert.kapacita) * 100);
}

// Kolik by koncert vydělal, kdyby vstupné bylo takové, jaké přišlo z formuláře.
export function trzbaPriCene(id: number, hodnota: string): number {
  const koncert = koncerty.find((jeden) => jeden.id === id);
  if (!koncert) return 0;
  const cena = Number(hodnota);
  if (!Number.isFinite(cena) || cena < 0) return 0;
  return koncert.prodano * cena;
}

// První vyprodaný koncert v seznamu.
export function prvniVyprodany(seznam: readonly Koncert[]): Koncert | undefined {
  return seznam.find((koncert) => koncert.prodano === koncert.kapacita);
}

// Průměrná obsazenost všech koncertů v procentech. Dopsal kolega Tomáš.
export function prumernaObsazenost(seznam: readonly Koncert[]): number {
  let soucet = 0;
  for (const koncert of seznam) {
    soucet += Math.round((koncert.prodano / koncert.kapacita) * 100);
  }
  return Math.round(soucet / 100);
}

// Přidá koncert do nabídky.
export function pridejKoncert(novy: Koncert): Koncert[] {
  koncerty.push(novy);
  return koncerty;
}
```
