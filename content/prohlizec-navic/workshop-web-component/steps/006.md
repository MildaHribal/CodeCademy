# --description--

Vedle hvězd má být drobným písmem informace, kolik lidí už film hodnotilo. Ta data ale komponenta nemá a mít nemá — patří stránce. Proto pro ně necháš **díru**, do které si stránka vloží, co chce.

[[slot komponenty|Značka `<slot>`]] uvnitř stínu je právě taková díra: prohlížeč do ní promítne potomky, které komponenta má ve [[světlý strom|světlém stromu]] zvenčí. Text mezi `<slot>` a `</slot>` je záložní hodnota, když stránka nedodá nic.

```js
this.shadowRoot.innerHTML = `
  <style>
    .stitek { color: #94a3b8; font-size: 0.8rem; }
  </style>
  <strong>349 Kč</strong>
  <span class="stitek"><slot>bez akce</slot></span>
`;
```

**Úkol:** Krok má dvě poloviny, komponentu a stránku:

1. Ve `vykresli()` přidej za hvězdy `<span class="popis">` a do něj `<slot>` se záložním textem `Tvoje hodnocení`. Do stylů přidej pravidlo `.popis` s barvou `#94a3b8` a velikostí `0.78rem`.
2. Ve `vyrobKartu` nastav komponentě text složený z počtu hlasů a slova `hlasů` (například `412 hlasů`). Vlastnost `hlasy` je v datech každého filmu.

# --hints--

Ve stínu je slot se záložním textem.

```js
const novy = document.createElement('hodnoceni-hvezdy');
document.body.append(novy);
await helpers.flush();
const slot = novy.shadowRoot.querySelector('slot');
assert.ok(slot, 've stínu má být značka <slot>');
assert.equal(slot.textContent.trim(), 'Tvoje hodnocení', 'bez obsahu zvenčí má slot ukázat záložní text „Tvoje hodnocení"');
novy.remove();
```

Karta pošle komponentě počet hlasů a ten se promítne do slotu.

```js
const prvek = document.querySelector('#filmy .film[data-id="vlny"] hodnoceni-hvezdy');
assert.equal(prvek.textContent.trim(), '412 hlasů', 'karta má komponentě dát text „412 hlasů" (počet z vlastnosti hlasy)');
const slot = prvek.shadowRoot.querySelector('slot');
assert.equal(slot.assignedNodes().length > 0, true, 'text ze stránky se má promítnout do slotu — leží ve světlém stromu komponenty?');
```

Popisek má svoje vlastní, drobnější písmo.

```js
const prvek = document.querySelector('#filmy .film[data-id="bratri"] hodnoceni-hvezdy');
assert.equal(prvek.textContent.trim(), '254 hlasů', 'Bratři mají 254 hlasů');
const popis = prvek.shadowRoot.querySelector('.popis');
assert.ok(popis, 'popisek má být v prvku s třídou popis');
assert.equal(getComputedStyle(popis).color, 'rgb(148, 163, 184)', 'pravidlo .popis má mít barvu #94a3b8');
```

# --help--

## --tip--

Jak slot funguje a co je záložní obsah, ukazuje lekce u nadpisu [Slot: obsah, který dodá stránka](see:prohlizec-navic/web-components#slot-obsah-ktery-doda-stranka).

## --tip--

Slot patří do řetězce, kterým skládáš obsah stínu, a jeho obal si obarvíš vlastní třídou. Na straně stránky nastavuješ text **komponentě samotné**, ne ničemu uvnitř ní — v proměnné `hvezdy` ji ve `vyrobKartu` už máš.

## --tip--

Při skládání textu z čísla a slova nezapomeň na mezeru: `pocet + ' komentářů'`.

// Filmy, které redakce tenhle měsíc sleduje. Pole je jen ke čtení.
const filmy = [
  { id: 'vlny', nazev: 'Vlny', rok: 2024, rezie: 'Jiří Mádl', hodnoceni: 5, hlasy: 412 },
  { id: 'banik', nazev: 'Baník', rok: 2024, rezie: 'Ondřej Provazník', hodnoceni: 4, hlasy: 187 },
  { id: 'zivot-k-sezrani', nazev: 'Život k sežrání', rok: 2024, rezie: 'Kristina Dufková', hodnoceni: 3, hlasy: 96 },
  { id: 'bratri', nazev: 'Bratři', rok: 2023, rezie: 'Tomáš Mašín', hodnoceni: 2, hlasy: 254 },
];

// Prvky stránky, se kterými budeš pracovat.
const seznam = document.querySelector('#filmy');
const prumer = document.querySelector('#prumer');
const formular = document.querySelector('#hodnoceni');
const vystup = document.querySelector('#vystup');

// Formulář nic neodesílá, jen vypíše, co by na server poslal.
formular.addEventListener('submit', (udalost) => {
  udalost.preventDefault();
  const radky = [...new FormData(formular)].map(([klic, hodnota]) => klic + ': ' + hodnota);
  vystup.textContent = radky.join('\n');
});

// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });

    // 1. Zjisti, kolik hvězd má svítit

        :host {
          display: inline-flex;

          font-size: 1.35rem;
          line-height: 1;
        }
        .plne { color: #f59e0b; }
      </style>

    `;
  }

    this.vykresli();
  }
}

customElements.define('hodnoceni-hvezdy', HodnoceniHvezdy);

// Karta jednoho filmu ze šablony #sablona-filmu.
function vyrobKartu(film) {
  const karta = document.querySelector('#sablona-filmu').content.firstElementChild.cloneNode(true);
  karta.dataset.id = film.id;
  karta.querySelector('.film__nazev').textContent = film.nazev;
  karta.querySelector('.film__rok').textContent = film.rok;
  karta.querySelector('.film__rezie').textContent = 'Režie: ' + film.rezie;
  const hvezdy = karta.querySelector('hodnoceni-hvezdy');
  hvezdy.setAttribute('hodnota', film.hodnoceni);
  hvezdy.setAttribute('name', film.id);
  return karta;
}

--edit--
