# --description--

Komponenta si přečte atribut jednou, při připojení do stránky. Kdyby ho pak někdo změnil — skript, DevTools nebo za chvíli tvoje vlastní klikání — hvězdy by zůstaly na starých hodnotách. Po tomhle kroku bude prvek na změnu atributu reagovat sám.

Prohlížeč hlídá jen ty atributy, o které si řekneš. Seznam jmen dáš do statické vlastnosti a na změnu pak reaguješ v metodě, kterou prohlížeč zavolá se jménem atributu a starou a novou hodnotou.

**Úkol:** Přidej do třídy dvě věci:

1. statický seznam sledovaných atributů, ve kterém bude `hodnota`,
2. metodu životního cyklu pro změnu atributu — když se stará a nová hodnota liší, zavolá překreslení.

Dokud nepřidáš obojí, nestane se nic a konzole bude mlčet.

# --hints--

Třída hlásí, že sleduje atribut `hodnota`.

```js
const trida = customElements.get('hodnoceni-hvezdy');
assert.deepEqual([...(trida.observedAttributes ?? [])], ['hodnota'], 'statický seznam sledovaných atributů má obsahovat jediné jméno: hodnota');
```

Změna atributu zvenčí prvek překreslí.

```js
const prvek = document.querySelector('#filmy .film[data-id="bratri"] hodnoceni-hvezdy');
assert.equal(prvek.shadowRoot.querySelectorAll('button.plna').length, 2, 'Bratři začínají na dvou hvězdách');
prvek.setAttribute('hodnota', '5');
await helpers.flush();
assert.equal(prvek.shadowRoot.querySelectorAll('button.plna').length, 5, 'po změně atributu na 5 má svítit pět hvězd');
prvek.setAttribute('hodnota', '1');
await helpers.flush();
assert.equal(prvek.shadowRoot.querySelectorAll('button.plna').length, 1, 'a po změně na 1 jediná');
```

Zápis stejné hodnoty komponentu nepřekresluje zbytečně.

```js
const prvek = document.querySelector('#filmy .film[data-id="vlny"] hodnoceni-hvezdy');
const puvodni = prvek.shadowRoot.querySelector('button');
prvek.setAttribute('hodnota', '5');
await helpers.flush();
assert.equal(prvek.shadowRoot.querySelector('button'), puvodni, 'když se hodnota nezměnila, nemá se nic překreslovat — porovnáváš starou a novou hodnotu?');
```

Vykreslení při připojení funguje dál.

```js
const novy = document.createElement('hodnoceni-hvezdy');
novy.setAttribute('hodnota', '4');
document.body.append(novy);
await helpers.flush();
assert.equal(novy.shadowRoot.querySelectorAll('button.plna').length, 4, 'nově vložený prvek s atributem hodnota="4" má rovnou ukázat čtyři hvězdy');
novy.remove();
```

# --help--

## --tip--

Obě jména i pořadí, v jakém prohlížeč metody volá, najdeš v lekci u nadpisu [Atributy: `observedAttributes` a `attributeChangedCallback`](see:prohlizec-navic/web-components#atributy-observedattributes-a-attributechangedcallback).

## --tip--

Seznam je **statická** vlastnost třídy (platí pro třídu, ne pro jednotlivý prvek) a obsahuje jména atributů jako řetězce. Metoda pro změnu dostane tři argumenty: jméno, starou a novou hodnotu.

## --tip--

Stejný pár u komponenty s odpočtem by vypadal takhle:

```text
sleduj: ['do-kdy']
při změně: když se stará a nová hodnota liší, přepočítej a překresli
```
