# --description--

Hvězdy jsou zatím šedý text v základní velikosti. Teď si komponenta přinese **vlastní styly** — a to tak, že je nikdo zvenčí omylem nepřepíše a ony samy nerozbijí nic na stránce.

Styly patří přímo do stínu: do jeho obsahu napíšeš značku `<style>` a pravidla v ní platí jen uvnitř. Sám prvek zvenčí vybereš selektorem `:host`.

Pro jinou komponentu by to vypadalo takhle:

```js
this.shadowRoot.innerHTML = `
  <style>
    :host { display: block; padding: 0.5rem; }
    .cena { color: #16a34a; }
  </style>
  <span class="cena">349 Kč</span>
`;
```

**Úkol:** Ve `vykresli()` skládej obsah stínu jako HTML: značku `<style>` a za ní dva prvky `<span>` — první s třídou `plne` a plnými hvězdami, druhý s prázdnými.

Ve stylech nastav:

- `:host` — `display: inline-flex`, `align-items: center`, `gap: 0.4rem`, `font-size: 1.35rem`, `line-height: 1` a barvu `#64748b`,
- `.plne` — barvu `#f59e0b`.

# --hints--

Ve stínu je značka `<style>` a prvek má z pravidla `:host` layout `inline-flex`.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
assert.ok(prvek.shadowRoot.querySelector('style'), 've stínu má být značka <style> s pravidly komponenty');
assert.equal(getComputedStyle(prvek).display, 'inline-flex', 'pravidlo :host má prvku nastavit display: inline-flex');
```

Plné hvězdy jsou zlaté, prázdné zůstanou šedé.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
const plne = prvek.shadowRoot.querySelector('.plne');
assert.ok(plne, 'plné hvězdy mají být v prvku s třídou plne');
assert.equal(plne.textContent, '★★★★', 'u Baníku (hodnota 4) mají být čtyři plné hvězdy');
assert.equal(getComputedStyle(plne).color, 'rgb(245, 158, 11)', 'plné hvězdy mají mít barvu #f59e0b');
assert.equal(getComputedStyle(prvek.shadowRoot.querySelectorAll('span')[1]).color, 'rgb(100, 116, 139)', 'prázdné hvězdy mají zdědit barvu #64748b z :host');
```

Styl komponenty neuteče ven na stránku.

```js
const odstavec = document.createElement('p');
odstavec.className = 'plne';
odstavec.textContent = 'test';
document.body.append(odstavec);
await helpers.flush();
assert.notEqual(getComputedStyle(odstavec).color, 'rgb(245, 158, 11)', 'pravidlo .plne ze stínu nesmí obarvit prvky na stránce — píšeš styly opravdu dovnitř stínu?');
odstavec.remove();
```

# --help--

## --tip--

Značku pro styly i selektor pro samotný prvek popisuje lekce u nadpisu [Shadow DOM: styly, které nikam neutečou](see:prohlizec-navic/web-components#shadow-dom-styly-ktere-nikam-neutecou).

## --tip--

Celý obsah stínu i s jeho styly složíš jedním zápisem do `innerHTML` kořene. Šablonový řetězec (zpětné apostrofy) umí víc řádků a dosadí do sebe spočítané hvězdy.

## --tip--

Vlastní prvek je ve výchozím stavu `display: inline` a nedá se u něj nastavit mezera mezi vnitřními prvky. Proto se `:host` skoro vždycky přepíná na některý blokový nebo flexový režim.

// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
  }

  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = Number(this.getAttribute('hodnota')) || 0;
    // 2. Slož obsah stínu i s jeho vlastními styly
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: inline-flex;
          align-items: center;
          gap: 0.4rem;
          color: #64748b;
          font-size: 1.35rem;
          line-height: 1;
        }
        .plne { color: #f59e0b; }
      </style>
      <span class="plne">${'★'.repeat(hodnota)}</span><span>${'☆'.repeat(5 - hodnota)}</span>
    `;
  }

  connectedCallback() {
    this.vykresli();
  }
}

customElements.define('hodnoceni-hvezdy', HodnoceniHvezdy);
