# --description--

Hodnocení je vidět, ale není slyšet. Odečítač obrazovky teď u každé hvězdy přečte jen „hvězdička, tlačítko" a nemá jak říct, kolikátá to je ani která je vybraná. Po tomhle kroku se skupina hvězd bude hlásit jako přepínač s pěti možnostmi — přesně jako skupina rádiových tlačítek ve formuláři.

Vlastní prvek si roli nepřinese sám: prohlížeč o tvojí komponentě nic neví, a tak si ji musíš pojmenovat. Obal hvězd dostane roli skupiny přepínačů a svůj popis, každá hvězda roli přepínače, vlastní jméno a informaci o tom, jestli je vybraná.

Ověřit se to dá ve **Zpřístupnění** v DevTools (v Chrome záložka *Accessibility* vedle *Styles*): ve stromu uvidíš, jak prvky vidí odečítač.

**Úkol:** Ve `vykresli()` dopiš přístupnost:

- obal `div.hvezdy` dostane `role="radiogroup"` a `aria-label` s popisem, například `Hodnocení filmu hvězdičkami`,
- každé tlačítko dostane `role="radio"`,
- každé tlačítko dostane `aria-checked` — `true` jen u tlačítka s aktuální hodnotou, jinak `false`,
- každé tlačítko dostane `aria-label` ve tvaru čísla a textu ` z 5 hvězd`, tedy třeba `3 z 5 hvězd`.

Pozor na rozdíl proti třídě `plna`: plných hvězd je několik, ale vybraná je právě jedna.

# --hints--

Skupina hvězd se hlásí jako přepínač s popisem.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
const skupina = prvek.shadowRoot.querySelector('[role="radiogroup"]');
assert.ok(skupina, 'obal hvězd má mít role="radiogroup"');
assert.ok(skupina.classList.contains('hvezdy'), 'roli má dostat obal .hvezdy, ne jednotlivé tlačítko');
assert.ok((skupina.getAttribute('aria-label') ?? '').trim().length > 0, 'skupina má mít neprázdný aria-label, jinak ji odečítač nepojmenuje');
```

Každá hvězda je přepínač s vlastním jménem.

```js
const prvek = document.querySelector('#filmy .film[data-id="vlny"] hodnoceni-hvezdy');
const radia = [...prvek.shadowRoot.querySelectorAll('button')];
assert.equal(radia.filter((t) => t.getAttribute('role') === 'radio').length, 5, 'všech pět tlačítek má mít role="radio"');
assert.equal(radia[2].getAttribute('aria-label'), '3 z 5 hvězd', 'třetí tlačítko má mít aria-label „3 z 5 hvězd"');
assert.equal(radia[0].getAttribute('aria-label'), '1 z 5 hvězd', 'první tlačítko má mít aria-label „1 z 5 hvězd"');
```

Vybraná je právě jedna hvězda, ta s aktuální hodnotou.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
const vybrane = [...prvek.shadowRoot.querySelectorAll('[aria-checked="true"]')];
assert.equal(vybrane.length, 1, 'aria-checked="true" má mít právě jedno tlačítko, ne všechna plná');
assert.equal(vybrane[0].dataset.hodnota, '4', 'u Baníku (hodnota 4) je vybraná čtvrtá hvězda');
assert.equal(prvek.shadowRoot.querySelectorAll('[aria-checked="false"]').length, 4, 'zbylá čtyři tlačítka mají mít aria-checked="false"');
```

Po změně hodnocení se výběr přesune.

```js
const prvek = document.querySelector('#filmy .film[data-id="zivot-k-sezrani"] hodnoceni-hvezdy');
await helpers.click(prvek.shadowRoot.querySelectorAll('button')[1]);
await helpers.flush();
const vybrane = prvek.shadowRoot.querySelectorAll('[aria-checked="true"]');
assert.equal(vybrane.length, 1, 'i po změně má být vybraná právě jedna hvězda');
assert.equal(vybrane[0].dataset.hodnota, '2', 'po kliknutí na druhou hvězdu má být vybraná druhá');
```

# --help--

## --tip--

Role a stavy se zapisují jako obyčejné atributy `role` a `aria-*`. Vlastní prvek žádnou roli sám o sobě nemá — pro odečítač je to prázdná značka, dokud mu ji nedáš.

## --tip--

Stav `aria-checked` je **text**, ne `true`/`false` z JavaScriptu. Porovnání „je tohle číslo to vybrané" převeď na řetězec, jinak ti do atributu spadne `undefined`.

## --tip--

U skupiny přepínačů platí tři pravidla: skupina má jméno, každá volba má jméno a právě jedna volba je označená jako vybraná.

// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  static observedAttributes = ['hodnota'];

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    // Posluchač patří dovnitř stínu: tady se cíl události ještě nepřepisuje.
    this.shadowRoot.addEventListener('click', (udalost) => this.naKlik(udalost));
  }

  get hodnota() {
    return Number(this.getAttribute('hodnota')) || 0;
  }

  set hodnota(nova) {
    this.setAttribute('hodnota', Math.min(5, Math.max(0, Number(nova) || 0)));
  }

  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = this.hodnota;
    // 2. Slož kostru stínu i s jeho vlastními styly
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: inline-flex;
          align-items: center;
          gap: 0.4rem;
          line-height: 1;
        }
        .hvezdy { display: flex; gap: 0.1rem; }
        button {
          padding: 0 0.05rem;
          border: 0;
          border-radius: 0.25rem;
          background: none;
          color: #64748b;
          font: inherit;
          font-size: 1.35rem;
          line-height: 1;
          cursor: pointer;
          transition: scale 0.15s ease, color 0.15s ease;
        }
        button.plna { color: #f59e0b; }
        button:hover { scale: 1.2; }
        button:focus-visible { outline: 3px solid #a5b4fc; outline-offset: 2px; }
        .popis { color: #94a3b8; font-size: 0.78rem; }
      </style>
      <div class="hvezdy"></div>
      <span class="popis"><slot>Tvoje hodnocení</slot></span>
    `;
    // 3. Doplň pět hvězd, plné podle hodnoty
    const hvezdy = this.shadowRoot.querySelector('.hvezdy');
    for (const cislo of [1, 2, 3, 4, 5]) {
      const tlacitko = document.createElement('button');
      tlacitko.type = 'button';
      tlacitko.dataset.hodnota = cislo;
      tlacitko.textContent = cislo <= hodnota ? '★' : '☆';
      tlacitko.classList.toggle('plna', cislo <= hodnota);
      hvezdy.append(tlacitko);
    }
  }

  connectedCallback() {
    this.vykresli();
  }

  attributeChangedCallback(jmeno, stara, nova) {
    if (stara !== nova) this.vykresli();
  }

  naKlik(udalost) {
    const tlacitko = udalost.target.closest('button');
    if (!tlacitko) return;
    this.hodnota = tlacitko.dataset.hodnota;
    this.ohlasZmenu();
  }

  ohlasZmenu() {
    this.dispatchEvent(new CustomEvent('zmena', {
      detail: { film: this.getAttribute('name'), hodnota: this.hodnota },
      bubbles: true,
      composed: true,
    }));
  }
}

seznam.addEventListener('zmena', () => {
  const hvezdy = seznam.querySelectorAll('hodnoceni-hvezdy');
  const soucet = [...hvezdy].reduce((celkem, prvek) => celkem + prvek.hodnota, 0);

});

for (const film of filmy) {
  seznam.append(vyrobKartu(film));

  return karta;
}

seznam.addEventListener('zmena', () => {
  const hvezdy = seznam.querySelectorAll('hodnoceni-hvezdy');
  const soucet = [...hvezdy].reduce((celkem, prvek) => celkem + prvek.hodnota, 0);
  prumer.textContent = 'Průměr tvých hodnocení: ' + (soucet / hvezdy.length).toFixed(1) + ' z 5';
});

for (const film of filmy) {
  seznam.append(vyrobKartu(film));
