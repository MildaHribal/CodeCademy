# --description--

Hodnocení jde zatím nastavit jen myší. Kdo jede po stránce tabulátorem, projde postupně pěti tlačítky a u každého musí přemýšlet, co udělá — a přitom u skupiny přepínačů čekají všichni něco jiného: do skupiny se vstoupí jednou a uvnitř se přepíná šipkami. Po tomhle kroku to tak bude fungovat i tady.

Skládá se to ze dvou věcí. Zaprvé je v celé skupině tabulátorem dosažitelné jen jedno tlačítko — to vybrané; ostatní se dají zaměřit jen programově. Zadruhé šipky doleva a nahoru hodnocení sníží, doprava a dolů zvýší, drží se v rozsahu 1 až 5 a po změně se zaměření přesune na novou hvězdu. Ostatní klávesy si komponenta nechá projít (jinak bys ve formuláři nedostal tabulátorem kurzor dál).

Změna z klávesnice je pro stránku stejná akce uživatele jako klik, takže i ona musí hlásit ven.

**Úkol:** Rozděl si práci sám a pojmenuj si podcíle — pak dopiš:

1. ve `vykresli()` zaměřitelnost tlačítek: vybrané (u hodnoty 0 první) dostane `tabindex` 0, ostatní −1,
2. metodu `naKlavesu(udalost)`, která podle stisknuté klávesy posune hodnocení o jedna nahoru nebo dolů, ořízne ho do rozsahu 1 až 5, potlačí výchozí chování klávesy, ohlásí změnu ven a zaměří tlačítko, které je nově na řadě,
3. v konstruktoru posluchače `keydown` na kořenu stínu.

# --hints--

Tabulátorem je ve skupině dosažitelné jediné tlačítko.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
assert.equal(prvek.shadowRoot.querySelectorAll('button[tabindex="0"]').length, 1, 'právě jedno tlačítko má mít tabindex="0"');
assert.equal(prvek.shadowRoot.querySelector('button[tabindex="0"]').dataset.hodnota, '4', 'u Baníku (hodnota 4) je to čtvrté tlačítko');
assert.equal(prvek.shadowRoot.querySelectorAll('button[tabindex="-1"]').length, 4, 'zbylá čtyři tlačítka mají mít tabindex="-1"');
```

Šipky hodnocení mění.

```js
const prvek = document.querySelector('#filmy .film[data-id="zivot-k-sezrani"] hodnoceni-hvezdy');
await helpers.press(prvek.shadowRoot.querySelector('button[tabindex="0"]'), 'ArrowRight');

await helpers.press(prvek.shadowRoot.querySelector('button[tabindex="0"]'), 'ArrowLeft');

assert.equal(prvek.shadowRoot.querySelector('button[tabindex="0"]').dataset.hodnota, '2', 'tabindex="0" se má přesunout na nově vybranou hvězdu');
```

Na okrajích rozsahu se nic nepokazí a cizí klávesy komponenta neřeší.


Změna z klávesnice se hlásí ven stejně jako klik.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
let detail = null;
document.querySelector('#filmy').addEventListener('zmena', (udalost) => { detail = udalost.detail; }, { once: true });
await helpers.press(prvek.shadowRoot.querySelector('button[tabindex="0"]'), 'ArrowLeft');
await helpers.flush();
assert.deepEqual(detail, { film: 'banik', hodnota: 3 }, 'i změna šipkou má vyslat událost zmena s novým hodnocením');
assert.match(document.querySelector('#prumer').textContent, /Průměr/, 'a průměr v hlavičce se má přepočítat');
```

# --help--

## --tip--

Zaměřitelnost prvku řídí atribut `tabindex`: nula znamená „v pořadí tabulátoru", minus jedna „jen programově". Prvku ho v JavaScriptu nastavíš i stejnojmennou vlastností.

## --tip--

Ze stisknuté klávesy se dá posun přečíst rovnou: `udalost.key` je text jako `ArrowLeft`. Když ho pro danou klávesu nemáš, metoda skončí a nic nedělá. Oříznutí do rozsahu už máš v zapisovači vlastnosti — tady hlídáš jen dolní mez 1.

# --explain--

Pojmenuj vlastními slovy kroky, které `naKlavesu` dělá, a řekni, proč metoda hned na začátku skončí, když klávesa není šipka.

## --model--

Metoda má čtyři kroky: **přelož klávesu na posun** (šipka nahoru a doprava plus jedna, dolů a doleva mínus jedna), **skonči, když klávesa nepatří tobě**, **zapiš novou hodnotu v rozsahu a ohlas ji ven** a **přesuň zaměření na novou hvězdu**. Brzký konec je důležitý kvůli všem ostatním klávesám: kdyby metoda pokračovala, potlačila by výchozí chování i pro tabulátor, mezerník nebo Enter — a uživatel by se z komponenty klávesnicí nedostal ven ani neodeslal formulář.

## --checklist--

- Klávesa se nejdřív přeloží na posun, teprve pak se něco mění.
- Když klávesa nepatří komponentě, metoda skončí a nechá ji projít dál.
- Nová hodnota se zapíše v rozsahu a ohlásí se ven.
- Zaměření se přesune na hvězdu, která je nově na řadě.

```js
// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  static observedAttributes = ['hodnota'];

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    // Posluchač patří dovnitř stínu: tady se cíl události ještě nepřepisuje.
    this.shadowRoot.addEventListener('click', (udalost) => this.naKlik(udalost));
  }

  get hodnota() {
    return Number(this.getAttribute('hodnota')) || 0;
  }

  set hodnota(nova) {
    this.setAttribute('hodnota', Math.min(5, Math.max(0, Number(nova) || 0)));
  }

  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = this.hodnota;
    // 2. Slož kostru stínu i s jeho vlastními styly
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: inline-flex;
          align-items: center;
          gap: 0.4rem;
          line-height: 1;
        }
        .hvezdy { display: flex; gap: 0.1rem; }
        button {
          padding: 0 0.05rem;
          border: 0;
          border-radius: 0.25rem;
          background: none;
          color: #64748b;
          font: inherit;
          font-size: 1.35rem;
          line-height: 1;
          cursor: pointer;
          transition: scale 0.15s ease, color 0.15s ease;
        }
        button.plna { color: #f59e0b; }
        button:hover { scale: 1.2; }
        button:focus-visible { outline: 3px solid #a5b4fc; outline-offset: 2px; }
        .popis { color: #94a3b8; font-size: 0.78rem; }
      </style>
      <div class="hvezdy" role="radiogroup" aria-label="Hodnocení filmu hvězdičkami"></div>
      <span class="popis"><slot>Tvoje hodnocení</slot></span>
    `;
    // 3. Doplň pět hvězd, plné podle hodnoty
    const hvezdy = this.shadowRoot.querySelector('.hvezdy');
    for (const cislo of [1, 2, 3, 4, 5]) {
      const tlacitko = document.createElement('button');
      tlacitko.type = 'button';
      tlacitko.dataset.hodnota = cislo;
      tlacitko.textContent = cislo <= hodnota ? '★' : '☆';
      tlacitko.classList.toggle('plna', cislo <= hodnota);
      tlacitko.setAttribute('role', 'radio');
      tlacitko.setAttribute('aria-checked', String(cislo === hodnota));
      tlacitko.setAttribute('aria-label', cislo + ' z 5 hvězd');
      hvezdy.append(tlacitko);
    }
  }

  connectedCallback() {
    this.vykresli();
  }

  attributeChangedCallback(jmeno, stara, nova) {
    if (stara !== nova) this.vykresli();
  }

  naKlik(udalost) {
    const tlacitko = udalost.target.closest('button');
    if (!tlacitko) return;
    this.hodnota = tlacitko.dataset.hodnota;
    this.ohlasZmenu();
  }

  ohlasZmenu() {
    this.dispatchEvent(new CustomEvent('zmena', {
      detail: { film: this.getAttribute('name'), hodnota: this.hodnota },
      bubbles: true,
      composed: true,
    }));
  }
}

customElements.define('hodnoceni-hvezdy', HodnoceniHvezdy);

// Karta jednoho filmu ze šablony #sablona-filmu.
function vyrobKartu(film) {
  const karta = document.querySelector('#sablona-filmu').content.firstElementChild.cloneNode(true);
  karta.dataset.id = film.id;
  karta.querySelector('.film__nazev').textContent = film.nazev;
  karta.querySelector('.film__rok').textContent = film.rok;
  karta.querySelector('.film__rezie').textContent = 'Režie: ' + film.rezie;
  const hvezdy = karta.querySelector('hodnoceni-hvezdy');
  hvezdy.setAttribute('hodnota', film.hodnoceni);
  hvezdy.setAttribute('name', film.id);
  hvezdy.textContent = film.hlasy + ' hlasů';
  return karta;
}

seznam.addEventListener('zmena', () => {
  const hvezdy = seznam.querySelectorAll('hodnoceni-hvezdy');
  const soucet = [...hvezdy].reduce((celkem, prvek) => celkem + prvek.hodnota, 0);
  prumer.textContent = 'Průměr tvých hodnocení: ' + (soucet / hvezdy.length).toFixed(1) + ' z 5';
});

// Start stránky: každý film dostane svoji kartu.
for (const film of filmy) {
  seznam.append(vyrobKartu(film));
}
```

```js
      <div class="hvezdy" role="radiogroup" aria-label="Hodnocení filmu hvězdičkami"></div>
      <span class="popis"><slot>Tvoje hodnocení</slot></span>
    `;
    // 3. Doplň pět hvězd, plné podle hodnoty
    const hvezdy = this.shadowRoot.querySelector('.hvezdy');
    for (const cislo of [1, 2, 3, 4, 5]) {
      const tlacitko = document.createElement('button');
      tlacitko.type = 'button';
      tlacitko.dataset.hodnota = cislo;
      tlacitko.textContent = cislo <= hodnota ? '★' : '☆';
      tlacitko.classList.toggle('plna', cislo <= hodnota);
      tlacitko.setAttribute('role', 'radio');
      tlacitko.setAttribute('aria-checked', String(cislo === hodnota));
      tlacitko.setAttribute('aria-label', cislo + ' z 5 hvězd');
      tlacitko.tabIndex = cislo === Math.max(hodnota, 1) ? 0 : -1;
      hvezdy.append(tlacitko);
    }
  }

  connectedCallback() {
    this.vykresli();
  }

  attributeChangedCallback(jmeno, stara, nova) {
    if (stara !== nova) this.vykresli();
  }

  naKlik(udalost) {
    const tlacitko = udalost.target.closest('button');
    if (!tlacitko) return;
    this.hodnota = tlacitko.dataset.hodnota;
    this.ohlasZmenu();
  }

  naKlavesu(udalost) {
    const posun = { ArrowRight: 1, ArrowUp: 1, ArrowLeft: -1, ArrowDown: -1 }[udalost.key];
    if (!posun) return;
    udalost.preventDefault();
    this.hodnota = Math.min(5, Math.max(1, this.hodnota + posun));
    this.ohlasZmenu();
    this.shadowRoot.querySelector('button[tabindex="0"]').focus();
  }

  ohlasZmenu() {
    this.dispatchEvent(new CustomEvent('zmena', {
      detail: { film: this.getAttribute('name'), hodnota: this.hodnota },
      bubbles: true,
      composed: true,
    }));
  }
```
