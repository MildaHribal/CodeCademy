# --description--

Aby šlo hodnocení měnit, musí být každá hvězda samostatný ovládací prvek. Po tomhle kroku se hvězdy zvětší pod myší a dají se zaměřit tabulátorem — klikání přijde hned potom.

Jak pět tlačítek vyrobíš, je na tobě. Testy kontrolují výsledek, ne cestu.

**Úkol:** Ve `vykresli()` nech ve stínu jen kostru: `<style>`, prázdný `<div class="hvezdy">` a `<span class="popis">` se slotem. Do `div.hvezdy` pak dopln pět tlačítek, pro čísla 1 až 5:

- každé tlačítko je `<button>` s `data-hodnota` rovným svému číslu,
- tlačítka s číslem menším nebo rovným hodnotě mají text `★` a třídu `plna`, ostatní text `☆` a třídu nemají.

Do stylů přidej:

- `.hvezdy` — `display: flex` a `gap: 0.1rem`,
- `button` — bez rámečku a pozadí, barva `#64748b`, `font: inherit`, `font-size: 1.35rem`, `line-height: 1`, `cursor: pointer` a přechod `transition: scale 0.15s ease, color 0.15s ease`,
- `button.plna` — barva `#f59e0b`,
- `button:hover` — `scale: 1.2`,
- `button:focus-visible` — viditelný obrys, například `outline: 3px solid #a5b4fc` s `outline-offset: 2px`.

Pravidlo `:host` i `.popis` nech, jak jsou; jen z `:host` můžeš vyhodit `font-size` a `color`, ty si teď řeší tlačítka sama.

# --hints--

Ve stínu je pět tlačítek se správnými `data-hodnota`.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
const tlacitka = prvek.shadowRoot.querySelectorAll('button');
assert.equal(tlacitka.length, 5, 've stínu má být pět tlačítek, jedno na každou hvězdu');
assert.equal(tlacitka[0].dataset.hodnota, '1', 'první tlačítko má mít data-hodnota="1"');
assert.equal(tlacitka[4].dataset.hodnota, '5', 'páté tlačítko má mít data-hodnota="5"');
assert.ok(prvek.shadowRoot.querySelector('.hvezdy button'), 'tlačítka mají být uvnitř prvku s třídou hvezdy');
```

Plná jsou jen tlačítka do aktuální hodnoty.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
const tlacitka = [...prvek.shadowRoot.querySelectorAll('button')];
assert.equal(tlacitka.filter((t) => t.classList.contains('plna')).length, 4, 'u Baníku (hodnota 4) mají mít třídu plna čtyři tlačítka');
assert.equal(tlacitka[3].textContent.trim(), '★', 'čtvrté tlačítko má ukazovat plnou hvězdu');
assert.equal(tlacitka[4].textContent.trim(), '☆', 'páté tlačítko má ukazovat prázdnou hvězdu');
assert.equal(tlacitka[4].classList.contains('plna'), false, 'páté tlačítko třídu plna mít nemá');
```

Tlačítka vypadají jako hvězdy, ne jako tlačítka, a plná jsou zlatá.

```js
const prvek = document.querySelector('#filmy .film[data-id="vlny"] hodnoceni-hvezdy');
const prvni = prvek.shadowRoot.querySelector('button');
const styl = getComputedStyle(prvni);
assert.equal(styl.color, 'rgb(245, 158, 11)', 'plné tlačítko má mít barvu #f59e0b');
assert.equal(styl.borderTopWidth, '0px', 'tlačítko nemá mít rámeček');
assert.equal(styl.cursor, 'pointer', 'nad tlačítkem má být kurzor pointer');
assert.equal(getComputedStyle(prvek.shadowRoot.querySelector('.hvezdy')).display, 'flex', 'obal .hvezdy má být flex');
```

Popisek ze slotu zůstal zachovaný.

```js
const prvek = document.querySelector('#filmy .film[data-id="zivot-k-sezrani"] hodnoceni-hvezdy');
assert.ok(prvek.shadowRoot.querySelector('.popis slot'), 'popisek se slotem má ve stínu zůstat');
assert.equal(prvek.shadowRoot.querySelectorAll('button.plna').length, 3, 'Život k sežrání má hodnotu 3');
```

# --help--

## --tip--

Pět stejných prvků poskládáš buď v cyklu, nebo si na ně složíš HTML jako řetězec a vložíš ho najednou. Obojí je v pořádku — vyber, co ti přijde čitelnější.

## --tip--

Číslo tlačítka porovnej s hodnotou komponenty: menší nebo rovno znamená plnou hvězdu. Rozdíl mezi plnou a prázdnou je jen ve znaku a ve třídě.

## --tip--

Kdybys šel cestou cyklu, drž se stejného tvaru jako jinde: vyrob prvek, nastav mu vlastnosti a přidej ho do obalu.

```js
// 1. vyrob prvek
// 2. nastav data-* a text
// 3. přidej ho do obalu
```

// Filmy, které redakce tenhle měsíc sleduje. Pole je jen ke čtení.
const filmy = [
  { id: 'vlny', nazev: 'Vlny', rok: 2024, rezie: 'Jiří Mádl', hodnoceni: 5, hlasy: 412 },
  { id: 'banik', nazev: 'Baník', rok: 2024, rezie: 'Ondřej Provazník', hodnoceni: 4, hlasy: 187 },
  { id: 'zivot-k-sezrani', nazev: 'Život k sežrání', rok: 2024, rezie: 'Kristina Dufková', hodnoceni: 3, hlasy: 96 },
  { id: 'bratri', nazev: 'Bratři', rok: 2023, rezie: 'Tomáš Mašín', hodnoceni: 2, hlasy: 254 },
];

// Prvky stránky, se kterými budeš pracovat.
const seznam = document.querySelector('#filmy');
const prumer = document.querySelector('#prumer');
const formular = document.querySelector('#hodnoceni');
const vystup = document.querySelector('#vystup');

// Formulář nic neodesílá, jen vypíše, co by na server poslal.
formular.addEventListener('submit', (udalost) => {
  udalost.preventDefault();
  const radky = [...new FormData(formular)].map(([klic, hodnota]) => klic + ': ' + hodnota);
  vystup.textContent = radky.join('\n');
});

// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
  }

  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = Number(this.getAttribute('hodnota')) || 0;
    // 2. Slož kostru stínu i s jeho vlastními styly
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: inline-flex;
          align-items: center;
          gap: 0.4rem;
          line-height: 1;
        }
        .hvezdy { display: flex; gap: 0.1rem; }
        button {
          padding: 0 0.05rem;
          border: 0;
          border-radius: 0.25rem;
          background: none;
          color: #64748b;
          font: inherit;
          font-size: 1.35rem;
          line-height: 1;
          cursor: pointer;
          transition: scale 0.15s ease, color 0.15s ease;
        }
        button.plna { color: #f59e0b; }
        button:hover { scale: 1.2; }
        button:focus-visible { outline: 3px solid #a5b4fc; outline-offset: 2px; }
        .popis { color: #94a3b8; font-size: 0.78rem; }
      </style>
      <div class="hvezdy"></div>
      <span class="popis"><slot>Tvoje hodnocení</slot></span>
    `;
    // 3. Doplň pět hvězd, plné podle hodnoty
    const hvezdy = this.shadowRoot.querySelector('.hvezdy');
    for (const cislo of [1, 2, 3, 4, 5]) {
      const tlacitko = document.createElement('button');
      tlacitko.type = 'button';
      tlacitko.dataset.hodnota = cislo;
      tlacitko.textContent = cislo <= hodnota ? '★' : '☆';
      tlacitko.classList.toggle('plna', cislo <= hodnota);
      hvezdy.append(tlacitko);
    }
  }

  connectedCallback() {
    this.vykresli();
  }
}

customElements.define('hodnoceni-hvezdy', HodnoceniHvezdy);
