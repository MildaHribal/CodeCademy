# --description--

Komponenta zapisuje hvězdy do obyčejného DOM stránky. To znamená, že její vnitřek může kdokoli přestylovat nebo přepsat — a ty naopak nemůžeš svoje styly napsat bez obav, že rozbijí zbytek stránky. Teď kolem vnitřku postavíš hranici.

`attachShadow` k prvku připojí [[shadow DOM|oddělený strom]]. Od té chvíle se na stránce vykresluje jen to, co je uvnitř něj, a dostaneš se tam přes `this.shadowRoot`.

Stín se zakládá **jednou**, takže patří do konstruktoru. Pozor: konstruktor je pořád jen příprava — atributy ani potomky v něm číst nesmíš.

```js
constructor() {
  super();
  this.attachShadow({ mode: 'open' });
}
```

**Úkol:** Přidej do třídy konstruktor, který zavolá `super()` a připojí otevřený stín. Ve `vykresli()` pak zapisuj hvězdy do [[shadow root|`this.shadowRoot`]] místo přímo do sebe.

# --hints--

Každá komponenta má otevřený shadow root.

```js
const prvek = document.querySelector('#filmy hodnoceni-hvezdy');
assert.ok(prvek.shadowRoot, "prvek má mít otevřený stín — zavolal jsi attachShadow({ mode: 'open' })?");
```

Hvězdy jsou ve stínu, ne ve světlém stromu.

```js
const prvek = document.querySelector('#filmy .film[data-id="vlny"] hodnoceni-hvezdy');
assert.equal(prvek.shadowRoot.textContent.trim(), '★★★★★', 'hvězdy mají být ve stínu (this.shadowRoot)');
assert.equal(prvek.textContent.trim(), '', 've světlém stromu komponenty už nemá zůstat nic');
```

Stín vznikne hned při vzniku prvku, ne až při připojení do stránky.

```js
const novy = document.createElement('hodnoceni-hvezdy');
assert.ok(novy.shadowRoot, 'shadow root má vzniknout už v konstruktoru — hned po createElement, ještě před vložením do stránky');
```

# --help--

## --tip--

Postup i pravidla hranice jsou v lekci u nadpisu [Shadow DOM: styly, které nikam neutečou](see:prohlizec-navic/web-components#shadow-dom-styly-ktere-nikam-neutecou).

## --tip--

Konstruktor musí jako úplně první věc zavolat `super()`, jinak `this` ještě neexistuje. Vrácený kořen si ukládat nemusíš — u otevřeného stínu ho prvek nabízí sám.

## --tip--

Ve `vykresli()` měníš jediné místo: cíl zápisu. Místo „zapiš na sebe" napíšeš „zapiš do svého stínu".

# --explain--

Proč komponenta po přesunu do stínu vypadá na stránce stejně, ale tvůj `document.querySelector('#filmy hodnoceni-hvezdy span')` by ji už nenašel?

## --model--

Shadow DOM je samostatný strom pověšený na prvku. Na obrazovce se vykresluje místo světlých potomků, takže vizuálně se nic nezměnilo. Hledání ze stránky ale končí na hranici stínu: `querySelector` prochází strom dokumentu a do stínu nevidí. Dovnitř se dostaneš jedině přes `element.shadowRoot`, a to ještě jen u otevřeného stínu. Stejně tak neprojdou selektory ze stylů stránky — a právě proto si komponenta může uvnitř dovolit jednoduchá jména tříd.

## --checklist--

- Stín se vykresluje místo světlých potomků, proto se obraz nezměnil.
- Hledání i selektory stránky se na hranici stínu zastaví.
- Dovnitř vede jediná cesta: `element.shadowRoot`.

// Filmy, které redakce tenhle měsíc sleduje. Pole je jen ke čtení.
const filmy = [
  { id: 'vlny', nazev: 'Vlny', rok: 2024, rezie: 'Jiří Mádl', hodnoceni: 5, hlasy: 412 },
  { id: 'banik', nazev: 'Baník', rok: 2024, rezie: 'Ondřej Provazník', hodnoceni: 4, hlasy: 187 },
  { id: 'zivot-k-sezrani', nazev: 'Život k sežrání', rok: 2024, rezie: 'Kristina Dufková', hodnoceni: 3, hlasy: 96 },
  { id: 'bratri', nazev: 'Bratři', rok: 2023, rezie: 'Tomáš Mašín', hodnoceni: 2, hlasy: 254 },
];

// Prvky stránky, se kterými budeš pracovat.
const seznam = document.querySelector('#filmy');
const prumer = document.querySelector('#prumer');
const formular = document.querySelector('#hodnoceni');
const vystup = document.querySelector('#vystup');

// Formulář nic neodesílá, jen vypíše, co by na server poslal.
formular.addEventListener('submit', (udalost) => {
  udalost.preventDefault();
  const radky = [...new FormData(formular)].map(([klic, hodnota]) => klic + ': ' + hodnota);
  vystup.textContent = radky.join('\n');
});

--edit--
// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = Number(this.getAttribute('hodnota')) || 0;
    // 2. Slož text z plných a prázdných hvězd
    this.textContent = '★'.repeat(hodnota) + '☆'.repeat(5 - hodnota);
  }

  connectedCallback() {
    this.vykresli();
  }
}

customElements.define('hodnoceni-hvezdy', HodnoceniHvezdy);

// Karta jednoho filmu ze šablony #sablona-filmu.
function vyrobKartu(film) {
  const karta = document.querySelector('#sablona-filmu').content.firstElementChild.cloneNode(true);
  karta.dataset.id = film.id;
  karta.querySelector('.film__nazev').textContent = film.nazev;
  karta.querySelector('.film__rok').textContent = film.rok;
  karta.querySelector('.film__rezie').textContent = 'Režie: ' + film.rezie;
  const hvezdy = karta.querySelector('hodnoceni-hvezdy');
  hvezdy.setAttribute('hodnota', film.hodnoceni);
  hvezdy.setAttribute('name', film.id);
  return karta;
}

// Start stránky: každý film dostane svoji kartu.
for (const film of filmy) {
  seznam.append(vyrobKartu(film));
}

// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
  }

  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = Number(this.getAttribute('hodnota')) || 0;
    // 2. Slož text z plných a prázdných hvězd
    this.shadowRoot.textContent = '★'.repeat(hodnota) + '☆'.repeat(5 - hodnota);
  }

  connectedCallback() {
    this.vykresli();
  }
}

customElements.define('hodnoceni-hvezdy', HodnoceniHvezdy);

// Karta jednoho filmu ze šablony #sablona-filmu.
function vyrobKartu(film) {
