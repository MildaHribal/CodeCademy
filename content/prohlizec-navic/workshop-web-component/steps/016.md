# --description--

Poslední díl: komponenta se přihlásí do formuláře. Zatím je pro něj neviditelná — tlačítko **Uložit hodnocení** pošle jen poznámku pro redakci. Po tomhle kroku bude ve výpisu i řádek za každý film, pojmenovaný podle atributu `name`, který karty nastavují od prvního kroku.

Prohlížeč tohle umí pro vlastní prvky sám, ale musíš si o to říct třemi věcmi:

1. statickou vlastností, kterou třída ohlásí, že se chce chovat jako formulářový prvek,
2. voláním `this.attachInternals()` v konstruktoru — vrátí objekt, přes který prvek s formulářem mluví; ulož si ho do vlastnosti,
3. voláním `setFormValue(…)` na tom objektu pokaždé, když se hodnota změní. Hodnota do formuláře jde jako text.

Krok má dvě místa, kde se hlásit: při připojení do stránky (aby formulář znal výchozí hodnotu) a při každé změně sledovaného atributu.

> [!PITFALL]
> `attachInternals()` jde na jednom prvku zavolat jen jednou a vyhodí výjimku, když se třída k formulářům nepřihlásila. Když ti v konzoli naskočí `NotSupportedError`, chybí ta statická vlastnost.

**Úkol:** Uprav třídu tak, aby se komponenta chovala jako formulářový prvek a hlásila formuláři svoje hodnocení. `vyrobKartu` ani HTML měnit nemusíš.

## Udělej po svém

Testy končí, hvězdy ne. Vyber si aspoň jedno:

- **Půlhvězdy.** Nech komponentu přijímat i hodnoty jako 3,5 a podle pozice myši nad tlačítkem vybrat půlku. Vodítko: `getBoundingClientRect()` ti řekne, kde tlačítko začíná a kde končí.
- **Náhled pod kurzorem.** Při přejetí myší ukaž, jak by hodnocení vypadalo, a po odjetí se vrať ke skutečné hodnotě. Vodítko: náhledovou hodnotu drž zvlášť od té uložené.
- **Barvy zvenčí.** Nabídni stránce dvě CSS proměnné (třeba pro barvu plné a prázdné hvězdy) a použij je uvnitř stínu se záložní hodnotou. Vodítko: dědičné vlastnosti a proměnné hranicí stínu projdou.
- **Tvoje téma.** Přepiš data na to, co sleduješ ty — deskovky, koncerty, restaurace. Komponenta zůstane stejná, mění se jen obsah pole `filmy`.

Pak si otevři poslední krok kteréhokoli dalšího workshopu s vlastní komponentou: všechno, co jsi tu napsal, se do něj dá zkopírovat beze změny, protože komponenta nezávisí na ničem kolem sebe.

```js
const data = new FormData(document.querySelector('#hodnoceni'));
```

Po změně hodnocení se mění i to, co by se odeslalo.

```js
const prvek = document.querySelector('#filmy .film[data-id="banik"] hodnoceni-hvezdy');
await helpers.click(prvek.shadowRoot.querySelectorAll('button')[0]);
```

Odeslání formuláře vypíše hodnocení i poznámku.

```js

assert.match(vypis, /zivot-k-sezrani: 3/, 'a řádek „zivot-k-sezrani: 3"');
assert.match(vypis, /poznamka: Skvělá kamera/, 'a poznámka z textového pole');
```

# --help--

## --tip--

Jak se z formuláře čtou data, si připomeň v [lekci o formulářích](see:js-dom/formulare-v-js#data-z-formulare-formdata). Ve výpisu se objeví jen prvky, které mají `name` — a ty ho komponentám nastavuješ od prvního kroku.

## --tip--

Objekt z `attachInternals()` si ulož do vlastnosti prvku hned v konstruktoru, ještě před připojením stínu. Hlášení hodnoty pak patří na dvě místa: do metody, která běží při připojení do stránky, a do té, která běží při změně sledovaného atributu.

## --tip--

Formuláři se posílá **text**. Když mu pošleš číslo, prohlížeč si ho sice převede sám, ale ve výpisu pak těžko poznáš, co přišlo z komponenty a co z textového pole.

```js
// Hvězdičkové hodnocení jako vlastní HTML značka.
class HodnoceniHvezdy extends HTMLElement {
  static observedAttributes = ['hodnota'];

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    // Posluchač patří dovnitř stínu: tady se cíl události ještě nepřepisuje.
    this.shadowRoot.addEventListener('click', (udalost) => this.naKlik(udalost));
    this.shadowRoot.addEventListener('keydown', (udalost) => this.naKlavesu(udalost));
  }

  get hodnota() {
    return Number(this.getAttribute('hodnota')) || 0;
  }

  set hodnota(nova) {
    this.setAttribute('hodnota', Math.min(5, Math.max(0, Number(nova) || 0)));
  }

  vykresli() {
    // 1. Zjisti, kolik hvězd má svítit
    const hodnota = this.hodnota;
    // 2. Slož kostru stínu i s jeho vlastními styly
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: inline-flex;
          align-items: center;
          gap: 0.4rem;
          line-height: 1;
        }
        .hvezdy { display: flex; gap: 0.1rem; }
        button {
          padding: 0 0.05rem;
          border: 0;
          border-radius: 0.25rem;
          background: none;
          color: #64748b;
          font: inherit;
          font-size: 1.35rem;
          line-height: 1;
          cursor: pointer;
          transition: scale 0.15s ease, color 0.15s ease;
        }
        button.plna { color: #f59e0b; }
        button:hover { scale: 1.2; }
        button:focus-visible { outline: 3px solid #a5b4fc; outline-offset: 2px; }
        .popis { color: #94a3b8; font-size: 0.78rem; }
      </style>
      <div class="hvezdy" role="radiogroup" aria-label="Hodnocení filmu hvězdičkami"></div>
      <span class="popis"><slot>Tvoje hodnocení</slot></span>
    `;
    // 3. Doplň pět hvězd, plné podle hodnoty
    const hvezdy = this.shadowRoot.querySelector('.hvezdy');
    for (const cislo of [1, 2, 3, 4, 5]) {
      const tlacitko = document.createElement('button');
      tlacitko.type = 'button';
      tlacitko.dataset.hodnota = cislo;
      tlacitko.textContent = cislo <= hodnota ? '★' : '☆';
      tlacitko.classList.toggle('plna', cislo <= hodnota);
      tlacitko.setAttribute('role', 'radio');
      tlacitko.setAttribute('aria-checked', String(cislo === hodnota));
      tlacitko.setAttribute('aria-label', cislo + ' z 5 hvězd');
      tlacitko.tabIndex = cislo === Math.max(hodnota, 1) ? 0 : -1;
      hvezdy.append(tlacitko);
    }
  }

  connectedCallback() {
    this.vykresli();
  }

  attributeChangedCallback(jmeno, stara, nova) {
    if (stara !== nova) this.vykresli();
  }

  naKlik(udalost) {
    const tlacitko = udalost.target.closest('button');
    if (!tlacitko) return;
    this.hodnota = tlacitko.dataset.hodnota;
    this.ohlasZmenu();
  }

  naKlavesu(udalost) {
    const posun = { ArrowRight: 1, ArrowUp: 1, ArrowLeft: -1, ArrowDown: -1 }[udalost.key];
    if (!posun) return;
    udalost.preventDefault();
    this.hodnota = Math.min(5, Math.max(1, this.hodnota + posun));
    this.ohlasZmenu();
    this.shadowRoot.querySelector('button[tabindex="0"]').focus();
  }

  ohlasZmenu() {
    this.dispatchEvent(new CustomEvent('zmena', {
      detail: { film: this.getAttribute('name'), hodnota: this.hodnota },
      bubbles: true,
      composed: true,
    }));
  }
}

// Karta jednoho filmu ze šablony #sablona-filmu.
function vyrobKartu(film) {
  const karta = document.querySelector('#sablona-filmu').content.firstElementChild.cloneNode(true);
  karta.dataset.id = film.id;
  karta.querySelector('.film__nazev').textContent = film.nazev;
  karta.querySelector('.film__rok').textContent = film.rok;
  karta.querySelector('.film__rezie').textContent = 'Režie: ' + film.rezie;
  const hvezdy = karta.querySelector('hodnoceni-hvezdy');
  hvezdy.setAttribute('hodnota', film.hodnoceni);
  hvezdy.setAttribute('name', film.id);
  hvezdy.textContent = film.hlasy + ' hlasů';
  return karta;
}

seznam.addEventListener('zmena', () => {
  const hvezdy = seznam.querySelectorAll('hodnoceni-hvezdy');
  const soucet = [...hvezdy].reduce((celkem, prvek) => celkem + prvek.hodnota, 0);
  prumer.textContent = 'Průměr tvých hodnocení: ' + (soucet / hvezdy.length).toFixed(1) + ' z 5';
});

// Start stránky: každý film dostane svoji kartu.
for (const film of filmy) {
  seznam.append(vyrobKartu(film));
}
```

```js
    for (const cislo of [1, 2, 3, 4, 5]) {
      const tlacitko = document.createElement('button');
      tlacitko.type = 'button';
      tlacitko.dataset.hodnota = cislo;
      tlacitko.textContent = cislo <= hodnota ? '★' : '☆';
      tlacitko.classList.toggle('plna', cislo <= hodnota);
      tlacitko.setAttribute('role', 'radio');
      tlacitko.setAttribute('aria-checked', String(cislo === hodnota));
      tlacitko.setAttribute('aria-label', cislo + ' z 5 hvězd');
      tlacitko.tabIndex = cislo === Math.max(hodnota, 1) ? 0 : -1;
      hvezdy.append(tlacitko);
    }
  }

  connectedCallback() {
    this.vykresli();
    this.vnitrek.setFormValue(String(this.hodnota));
  }

  attributeChangedCallback(jmeno, stara, nova) {
    if (stara === nova) return;
    this.vykresli();
    this.vnitrek.setFormValue(String(this.hodnota));
  }

  naKlik(udalost) {
    const tlacitko = udalost.target.closest('button');
    if (!tlacitko) return;
    this.hodnota = tlacitko.dataset.hodnota;
    this.ohlasZmenu();
  }

  naKlavesu(udalost) {
    const posun = { ArrowRight: 1, ArrowUp: 1, ArrowLeft: -1, ArrowDown: -1 }[udalost.key];
    if (!posun) return;
    udalost.preventDefault();
    this.hodnota = Math.min(5, Math.max(1, this.hodnota + posun));
    this.ohlasZmenu();
    this.shadowRoot.querySelector('button[tabindex="0"]').focus();
  }

  ohlasZmenu() {
    this.dispatchEvent(new CustomEvent('zmena', {
      detail: { film: this.getAttribute('name'), hodnota: this.hodnota },
      bubbles: true,
      composed: true,
    }));
  }
```
