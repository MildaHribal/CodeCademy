# --description--

Teď dáš značce `<hodnoceni-hvezdy>` chování. Prohlížeč ji do téhle chvíle jen zobrazil jako prázdný prvek; po tomhle kroku se v každé kartě samy objeví hvězdy — a to i v kartě, která do stránky přibude později.

[[vlastní prvek|Vlastní prvek]] jsou dvě věci: **třída**, která dědí z `HTMLElement`, a **registrace** jména značky. Uvnitř třídy je `connectedCallback` — metoda, kterou prohlížeč zavolá ve chvíli, kdy se prvek dostane do dokumentu.

Takhle vypadá stejný postup u úplně jiné značky:

```js
class ZnackaNovinka extends HTMLElement {
  connectedCallback() {
    this.textContent = 'NOVINKA';
  }
}

customElements.define('znacka-novinka', ZnackaNovinka);
```

**Úkol:** Nad funkci `vyrobKartu` napiš třídu `HodnoceniHvezdy`, která v `connectedCallback` nastaví svůj vlastní text na pět plných hvězd `★★★★★`, a zaregistruj ji pod jménem značky `hodnoceni-hvezdy`.

Hodnocení z atributu zatím neřeš, všechny filmy budou mít pět hvězd. Spravíš to hned v dalším kroku.

# --hints--

Značka `hodnoceni-hvezdy` je zaregistrovaná.

```js
assert.ok(customElements.get('hodnoceni-hvezdy'), "customElements.get('hodnoceni-hvezdy') má vrátit třídu — zaregistroval jsi jméno značky?");
assert.equal(Object.getPrototypeOf(customElements.get('hodnoceni-hvezdy')), HTMLElement, 'třída komponenty má dědit přímo z HTMLElement');
```

Každá ze čtyř karet ukazuje pět hvězd.

```js
const prvky = document.querySelectorAll('#filmy hodnoceni-hvezdy');
assert.equal(prvky.length, 4, 'v seznamu mají být čtyři značky <hodnoceni-hvezdy>');
assert.equal(prvky[0].textContent.trim(), '★★★★★', 'komponenta má vypsat pět plných hvězd');
assert.equal(prvky[3].textContent.trim(), '★★★★★', 'hvězdy má ukázat i poslední karta');
```

Prohlížeč oživí i prvek, který vznikne až za běhu.

```js
const novy = document.createElement('hodnoceni-hvezdy');
document.body.append(novy);
await helpers.flush();
assert.equal(novy.textContent.trim(), '★★★★★', 'i prvek vyrobený později má prohlížeč oživit sám — na to žádné volání dopisovat nemusíš');
novy.remove();
```

# --help--

## --tip--

Oba díly skládanky jsou v lekci u nadpisu [Vlastní značka: třída a `customElements.define`](see:prohlizec-navic/web-components#vlastni-znacka-trida-a-customelements-define).

## --tip--

Registrace dostane dva argumenty: jméno značky (s pomlčkou, přesně jak je v HTML) a třídu. Text si prvek nastavuje sám na sobě, takže ho zapiš na `this`.

## --tip--

Pět stejných znaků za sebou nemusíš psát ručně — řetězec umí metodu, která ho zopakuje. `'ha'.repeat(3)` vrátí `'hahaha'`.
