| Krok system designu | Co řešit |
|---|---|
| 1. Požadavky | Co se má postavit, pro koho, co to nemá dělat. |
| 2. Komponenty a data | Strom komponent, data model, struktury. |
| 3. API a stav | Komunikace se serverem, lokální stav, nástroje (např. Redux, Query). |
| 4. Zbytek | Výkon, lazy loading, chybové stavy, přístupnost. |

## Metoda STAR

- **S**ituation: Jaký byl kontext.
- **T**ask: Co jsi měl udělat nebo vyřešit.
- **A**ction: Co jsi konkrétně udělal ty.
- **R**esult: Jak to dopadlo, ideálně s čísly.
