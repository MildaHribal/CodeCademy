# Technický pohovor

:::check pretest
Je u live codingu důležitější napsat bezchybný kód, nebo ukázat, jak přemýšlíš?
:::

## Vyprávění o projektu

Budeš popisovat svůj projekt: jaký problém řeší, jaká rozhodnutí jsi udělal a co bys zpětně udělal jinak.

:::check
Jak odpovíš na otázku „Co byl nejtěžší technický problém na tvém projektu?“
:::

## Live coding nahlas

Mluv, když programuješ. Ukazuješ svůj postup a komunikaci, ne jen rychlost psaní kódu. Postupuj podle rad z `js-algoritmy`.

> [!PITFALL]
> Zaseknout se mlčky je nejhorší varianta. Popiš nahlas, v čem je problém a jaké vidíš možnosti.

:::check
Co máš udělat, když nevíš, jak v live codingu pokračovat?
:::

## Frontend system design

Postupuj ve čtyřech krocích:
1. Požadavky
2. Komponenty a data
3. API a stav
4. Výkon, přístupnost a chyby

:::check
Proč bys měl u system designu začínat požadavky a ne hned psát kód?
:::
