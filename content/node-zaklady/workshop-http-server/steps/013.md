# --description--

Frontend chce vypsat knihy jednoho autora: `GET /api/books?author=Karel%20Čapek`.
Parametry za otazníkem jsou [[query string]] — nepovinné upřesnění, **které položky
seznamu** klient chce.

**Úkol:** u `GET /api/books` v `server.js`:

- bez parametru `author` vrať všechny knihy jako dosud,
- s parametrem `author` vrať jen knihy, jejichž autor se s ním přesně shoduje,
- když žádná kniha nesedí, vrať stav `200` a prázdné pole.

Hodnotu parametru ti dá objekt `URL`, který už v handleru vytváříš — hodí se jeho
`searchParams`, nebo samostatný `URLSearchParams`. Kolega v `stats.js` jeden z nich
použil; podívej se, jak.

> [!NOTE]
> `%20` a `%C4%8C` v adrese jsou zakódovaná mezera a `Č`. Nemusíš je dekódovat,
> `searchParams.get` vrátí rovnou `Karel Čapek`.

# --hints--

Bez parametru `author` vrátí `GET /api/books` všechny knihy.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books', server.url));
assert.equal(res.status, 200, 'GET /api/books má vrátit stav 200');
assert.deepEqual(await res.json(), JSON.parse(files['books.json']), 'GET /api/books bez parametru má vrátit všechny knihy');
```

S parametrem `author` vrátí jen knihy toho autora, v pořadí ze souboru.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books?author=Karel%20%C4%8Capek', server.url));
assert.equal(res.status, 200, 'GET /api/books?author=Karel Čapek má vrátit stav 200');
const expected = JSON.parse(files['books.json']).filter((book) => book.author === 'Karel Čapek');
assert.deepEqual(await res.json(), expected, 'GET /api/books?author=Karel Čapek má vrátit jen Krakatit a Válku s mloky');
const fuks = await (await fetch(new URL('/api/books?author=Ladislav%20Fuks', server.url))).json();
assert.deepEqual(fuks.map((book) => book.id), [4], 'GET /api/books?author=Ladislav Fuks má vrátit jen knihu s id 4');
```

Když žádná kniha nesedí, vrátí stav `200` a prázdné pole.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books?author=Nikdo', server.url));
assert.equal(res.status, 200, 'GET /api/books?author=Nikdo má vrátit stav 200 — prázdný výsledek filtru není chyba');
assert.deepEqual(await res.json(), [], 'GET /api/books?author=Nikdo má vrátit prázdné pole');
const partial = await (await fetch(new URL('/api/books?author=Karel', server.url))).json();
assert.deepEqual(partial, [], 'GET /api/books?author=Karel má vrátit prázdné pole — autor se má shodovat přesně, ne jen začátkem nebo částí jména');
```

Ostatní metody na `/api/books` dál vracejí `405`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books?author=Nikdo', server.url), { method: 'DELETE' });
assert.equal(res.status, 405, 'DELETE /api/books?author=Nikdo má dál vracet stav 405');
```

# --help--

## --tip--

Parametry za otazníkem čteš z query stringu — viz
[Adresa: `req.url`, cesta a query string](see:node-zaklady/http-v-node#adresa-req-url-cesta-a-query-string).

## --tip--

Z `new URL(…)` si vedle `pathname` vezmi i `searchParams`. Jeho `get('author')`
vrátí text, nebo `null`, když parametr chybí. Knihy pak zúžíš metodou `filter`.

## --tip--

Stejný filtr nad uživateli:

```js
const city = url.searchParams.get('city');
const shown = city === null ? users : users.filter((user) => user.city === city);
```

# --explain--

Vysvětli vlastními slovy, proč `GET /api/books?author=Nikdo` vrací `200` a prázdné pole, ale `GET /api/books/99` vrací `404`.

## --model--

Adresa `/api/books` je seznam a ten existuje vždycky; query string jen říká, které
položky z něj chci. Prázdný výsledek je platná odpověď, proto `200` a `[]`. Adresa
`/api/books/99` označuje jednu konkrétní knihu, a ta neexistuje — na adrese nic není,
proto `404`.

## --checklist--

- `/api/books` je seznam, který existuje, i když filtr nic nenajde.
- Prázdný výsledek filtru je úspěch, ne chyba.
- `/api/books/99` označuje jednu konkrétní knihu, která neexistuje.
- `404` znamená, že na adrese nic není.

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

```js
// Statistiky knihovny pro GET /api/stats — dopsal kolega Tomáš.
// Nepovinný filtr ?author=… spočítá statistiky jen z knih jednoho autora.

function respond(res, code, payload) {
  res.writeHead(code, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(payload));
}

export function handleStats(req, res, allBooks) {
  const params = new URL(req.url, 'http://localhost').searchParams;
  const author = params.get('author');

  const picked = [];
  for (const b of allBooks) {
    if (author === null || b.author === author) {
      picked.push(b);
    }
  }

  if (picked.length === 0) {
    return respond(res, 404, { error: 'Tento autor v knihovně nemá žádnou knihu.' });
  }

  const years = [];
  for (const b of picked) {
    years.push(b.year);
  }

  respond(res, 200, {
    count: picked.length,
    firstYear: Math.min(...years),
    lastYear: Math.max(...years),
  });
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { findBook, loadBooks } from './library.js';
import { handleStats } from './stats.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname, searchParams } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    if (req.method === 'GET') {
      const books = await loadBooks();
      const author = searchParams.get('author');
      if (author === null) {
        return sendJson(res, 200, books);
      }
      return sendJson(res, 200, books.filter((book) => book.author === author));
    }
    res.setHeader('Allow', 'GET');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const book = findBook(await loadBooks(), id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  if (pathname === '/api/stats') {
    return handleStats(req, res, await loadBooks());
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
