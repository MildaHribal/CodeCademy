# --description--

V tomhle workshopu postavíš HTTP server malé knihovny: vrátí seznam knih, detail
jedné knihy a přijme novou. Bez frameworku, jen s tím, co má Node v sobě.

Projekt má čtyři soubory:

- `package.json` — jediný řádek, na kterém záleží, je `"type": "module"`. Díky němu
  můžeš psát `import` a `export`.
- `books.json` — data knihovny.
- `library.js` — práce s daty. Tady začneš.
- `server.js` — server. Zatím je prázdný.

Server nemá databázi, knihy si bude číst ze souboru. V souboru `library.js`
napiš a **vyexportuj** asynchronní funkci `loadBooks()`, která přečte `books.json`
a vrátí pole knih.

Soubor přečteš funkcí `readFile` z modulu `node:fs/promises`. Vrací Promise
s obsahem souboru. Když jí jako druhý argument dáš `'utf8'`, dostaneš text; ten
pak převedeš na data přes `JSON.parse`. Cesta k souboru je v konstantě `booksFile`
už připravená.

Tentýž vzor nad jiným souborem:

```js
import { readFile } from 'node:fs/promises';

const recipesFile = new URL('./recipes.json', import.meta.url);

export async function loadRecipes() {
  const text = await readFile(recipesFile, 'utf8');
  return JSON.parse(text);
}
```

Proč funkce, a ne jednou přečtená konstanta nahoře v souboru? Data se budou měnit —
později do souboru budeš zapisovat nové knihy. Funkce čte soubor **při každém
zavolání**, takže vždycky vrátí aktuální stav.

# --hints--

`library.js` exportuje funkci `loadBooks`.

```js
const library = await helpers.importFile('library.js');
assert.equal(typeof library.loadBooks, 'function', 'library.js má exportovat funkci loadBooks');
```

`loadBooks()` vrátí Promise, která se splní polem knih ze souboru `books.json`.

```js
const { loadBooks } = await helpers.importFile('library.js');
const result = loadBooks();
assert.ok(result instanceof Promise, 'loadBooks() má vracet Promise — je funkce async?');
assert.deepEqual(await result, JSON.parse(files['books.json']), 'loadBooks() má vrátit pole knih z books.json');
```

`loadBooks()` čte soubor při každém zavolání — když se `books.json` změní, vrátí nová data.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
const { loadBooks } = await helpers.importFile('library.js');
await loadBooks();
const changed = [{ id: 7, title: 'Zkušební kniha', author: 'Test', year: 2000 }];
try {
  await fs.writeFile(booksPath, JSON.stringify(changed));
  assert.deepEqual(await loadBooks(), changed, 'Po změně books.json má loadBooks() vrátit nový obsah souboru');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

# --solution--

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}
```
