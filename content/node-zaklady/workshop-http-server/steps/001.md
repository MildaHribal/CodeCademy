# --description--

V tomhle workshopu postavíš HTTP server malé knihovny. Vrátí seznam knih a detail
jedné knihy, přijme novou knihu a smaže starou. Bez frameworku, jen s tím, co má
Node v sobě.

Projekt má čtyři soubory:

- `server.js` — server. Zatím je prázdný.
- `library.js` — funkce pro práci s knihami. Tady začneš.
- `books.json` — data knihovny: pole objektů s klíči `id`, `title`, `author` a `year`.
- `package.json` — záleží na jediném řádku, `"type": "module"`. Díky němu můžeš
  psát `import` a `export`.

První krok je z JavaScriptu, který už umíš — bez návodu.

**Úkol:** v `library.js` napiš a vyexportuj funkci `findBook(books, id)`. Dostane
pole knih a číselné `id` a vrátí knihu s tímhle `id`. Když taková kniha v poli
není, vrátí `undefined`. Pole nesmí změnit.

Funkci později použije server, až mu klient pošle adresu `/api/books/2`.

# --hints--

`library.js` exportuje funkci `findBook`.

```js
const library = await helpers.importFile('library.js');
assert.equal(typeof library.findBook, 'function', 'library.js má exportovat funkci findBook — chybí před ní export?');
```

`findBook(books, id)` vrátí knihu s daným `id` — první, prostřední i poslední v poli.

```js
const { findBook } = await helpers.importFile('library.js');
const books = [
  { id: 7, title: 'Máj', author: 'Karel Hynek Mácha', year: 1836 },
  { id: 2, title: 'Krakatit', author: 'Karel Čapek', year: 1924 },
  { id: 9, title: 'Babička', author: 'Božena Němcová', year: 1855 },
];
assert.deepEqual(findBook(books, 2), books[1], 'findBook(books, 2) má vrátit knihu Krakatit, která má id 2');
assert.deepEqual(findBook(books, 7), books[0], 'findBook(books, 7) má vrátit první knihu v poli');
assert.deepEqual(findBook(books, 9), books[2], 'findBook(books, 9) má vrátit poslední knihu v poli');
```

Když kniha s tím `id` v poli není, `findBook` vrátí `undefined` — i pro prázdné pole.

```js
const { findBook } = await helpers.importFile('library.js');
const books = [{ id: 1, title: 'Saturnin', author: 'Zdeněk Jirotka', year: 1942 }];
assert.equal(findBook(books, 99), undefined, 'findBook(books, 99) má vrátit undefined, kniha s id 99 neexistuje');
assert.equal(findBook([], 1), undefined, 'findBook([], 1) má vrátit undefined');
```

`findBook` pole nezmění.

```js
const { findBook } = await helpers.importFile('library.js');
const books = [
  { id: 3, title: 'Válka s mloky', author: 'Karel Čapek', year: 1936 },
  { id: 1, title: 'Saturnin', author: 'Zdeněk Jirotka', year: 1942 },
];
const before = structuredClone(books);
findBook(books, 1);
assert.deepEqual(books, before, 'findBook(books, 1) nemá měnit pole knih (pořadí ani obsah)');
```

# --help--

## --tip--

Hledáš **první prvek pole**, který splní podmínku. Kterou metodu na to máš, připomene
[Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Stejný vzor nad jinými daty: `users.find((user) => user.email === email)` vrátí
uživatele s daným e-mailem, nebo `undefined`.

# --solution--

## --file-- library.js

```js
// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```
