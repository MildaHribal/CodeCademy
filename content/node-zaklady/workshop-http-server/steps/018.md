# --description--

## Hlášení

Kolegyně z frontendu testovala formulář na přidání knihy a omylem odeslala useknutý
JSON `{"title": `. Server na požadavek neodpověděl a od té chvíle nejde nic — ani
seznam knih. V terminálu serveru je:

```text
<anonymous_script>:1
{"title":

SyntaxError: Unexpected end of JSON input
    at JSON.parse (<anonymous>)
    at Server.<anonymous> (file:///home/eva/knihovna/server.js:28:26)
    at process.processTicksAndRejections (node:internal/process/task_queues:104:5)

Node.js v26.5.1
```

## Úkol

Oprav server tak, aby na tělo, které není platný JSON, odpověděl stavem `400`
a JSON objektem s klíčem `error` — a běžel dál. Platná kniha se musí dál vytvořit
a uložit. Změň co nejmenší kus kódu.

> [!TIP]
> V HTTP klientovi pošli `POST /api/books` s tělem `{"title": ` a sleduj výstup
> serveru. Po opravě musí přijít `400` a další požadavek musí projít.

# --hints--

Tělo, které není platný JSON, vrátí stav `400` a JSON s klíčem `error`.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
const server = await helpers.startServer('server.js');
try {
  const postBook = (body) => fetch(new URL('/api/books', server.url), {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: typeof body === 'string' ? body : JSON.stringify(body),
  });
  const res = await postBook('{"title": ').catch(() =>
    assert.fail('Server na POST /api/books s tělem {"title":  neodpověděl — spadl na výjimce z JSON.parse?'));
  assert.equal(res.status, 400, 'POST /api/books s neplatným JSON {"title":  má vrátit stav 400');
  const body = await res.json();
  assert.equal(typeof body.error, 'string', 'Tělo odpovědi 400 na neplatný JSON má mít klíč error s textem');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

Po neplatném JSON server běží dál a odpovídá.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
const server = await helpers.startServer('server.js');
try {
  await fetch(new URL('/api/books', server.url), { method: 'POST', body: 'tohle není json' }).catch(() => {});
  await helpers.wait(200);
  const res = await fetch(new URL('/api/books', server.url)).catch((error) =>
    assert.fail(`Po POST s tělem „tohle není json" server přestal odpovídat (spadl?): ${error.message}\n${server.output()}`));
  assert.equal(res.status, 200, 'Po POST s neplatným JSON má GET /api/books dál vracet stav 200');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

Platná kniha se dál vytvoří se stavem `201` a uloží.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
const server = await helpers.startServer('server.js');
try {
  const postBook = (body) => fetch(new URL('/api/books', server.url), {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: typeof body === 'string' ? body : JSON.stringify(body),
  });
  const res = await postBook({ title: 'R.U.R.', author: 'Karel Čapek', year: 1920 });
  assert.equal(res.status, 201, 'POST /api/books s platnou knihou má dál vracet stav 201');
  const saved = JSON.parse(await fs.readFile(booksPath, 'utf8'));
  assert.ok(saved.some((book) => book.title === 'R.U.R.'), 'Platná kniha R.U.R. se má dál uložit do books.json');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

# --help--

## --tip--

Rozbitý vstup je chyba klienta, tedy `400` — a nezachycená výjimka shodí server
všem. Obojí je v [Typické chyby a pasti](see:node-zaklady/http-v-node#typicke-chyby-a-pasti).

## --tip--

Výpis vede na řádek s `JSON.parse`. Výjimku z něj chytíš `try`/`catch`; v `catch`
pošli `400` s `return`. Výsledek parsování ulož do proměnné deklarované přes `let`
před `try`, jinak za blokem nebude vidět.

## --tip--

Stejná ochrana u načítání nastavení:

```js
let settings;
try {
  settings = JSON.parse(await readFile(settingsFile, 'utf8'));
} catch (error) {
  settings = { theme: 'light' };
}
```

# --explain--

Vysvětli vlastními slovy, proč jedna nezachycená výjimka v handleru shodí server všem uživatelům, a ne jen tomu, kdo poslal špatný požadavek.

## --model--

Všechny požadavky obsluhuje jeden proces Node. Když výjimku nikdo nechytí, Node
ukončí celý proces — a s ním zmizí server pro všechny, ne jen pro jeden požadavek.
Chyby, které může způsobit vstup zvenku, proto chytám v `try`/`catch` a klientovi
pošlu `400`.

## --checklist--

- Všechny požadavky obsluhuje jeden proces.
- Nezachycená výjimka ukončí celý proces.
- S procesem přestane server odpovídat všem uživatelům.
- Chyby ze vstupu zvenku se chytají a klient dostane `400`.

```js
import { createServer } from 'node:http';
import { readBody } from './body.js';
import { findBook, loadBooks, saveBooks } from './library.js';
import { handleStats } from './stats.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname, searchParams } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    if (req.method === 'GET') {
      const books = await loadBooks();
      const author = searchParams.get('author');
      if (author === null) {
        return sendJson(res, 200, books);
      }
      return sendJson(res, 200, books.filter((book) => book.author === author));
    }
    if (req.method === 'POST') {
      const input = JSON.parse(await readBody(req));
      const books = await loadBooks();
      const book = {
        id: Math.max(0, ...books.map((item) => item.id)) + 1,
        title: input.title,
        author: input.author,
        year: input.year,
      };
      books.push(book);
      await saveBooks(books);
      return sendJson(res, 201, book);
    }
    res.setHeader('Allow', 'GET, POST');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const book = findBook(await loadBooks(), id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  if (pathname === '/api/stats') {
    return handleStats(req, res, await loadBooks());
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```

## --file-- library.js

```js
import { readFile, writeFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export async function saveBooks(books) {
  await writeFile(booksFile, JSON.stringify(books, null, 2));
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

```js
// Statistiky knihovny pro GET /api/stats — dopsal kolega Tomáš.
// Nepovinný filtr ?author=… spočítá statistiky jen z knih jednoho autora.

function respond(res, code, payload) {
  res.writeHead(code, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(payload));
}

export function handleStats(req, res, allBooks) {
  const params = new URL(req.url, 'http://localhost').searchParams;
  const author = params.get('author');

  const picked = [];
  for (const b of allBooks) {
    if (author === null || b.author === author) {
      picked.push(b);
    }
  }

  if (picked.length === 0) {
    return respond(res, 404, { error: 'Tento autor v knihovně nemá žádnou knihu.' });
  }

  const years = [];
  for (const b of picked) {
    years.push(b.year);
  }

  respond(res, 200, {
    count: picked.length,
    firstYear: Math.min(...years),
    lastYear: Math.max(...years),
  });
}
```

```js
// Přečte celé tělo požadavku jako text. Tělo přichází po kouscích (proud).
export async function readBody(req) {
  const chunks = [];
  for await (const chunk of req) {
    chunks.push(chunk);
  }
  return Buffer.concat(chunks).toString('utf8');
}
```
