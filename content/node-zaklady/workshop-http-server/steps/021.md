# --description--

Poslední díra: když je `books.json` poškozený (třeba ho někdo rozbije ruční úpravou),
`loadBooks` vyhodí výjimku a server spadne všem.

**Úkol:** jakákoli nečekaná chyba při obsluze požadavku skončí odpovědí `500` a JSON
objektem s klíčem `error` — a server běží dál. Chybu vypiš do terminálu přes
`console.error`, ať o ní víš. Klientovi podrobnosti chyby neposílej: zpráva výjimky
může prozradit, jak server vypadá uvnitř.

Až bude `books.json` zase v pořádku, server musí fungovat bez restartu.

## Co jsi postavil

Server bez jediné závislosti, který umí všechno, na čem stojí každé API:

- čte data ze souboru a zapisuje je zpátky (`node:fs/promises`),
- bere nastavení z prostředí (`process.env.PORT`),
- routuje podle cesty, parametru v cestě, query stringu a metody,
- posílá JSON se správnou hlavičkou a stavovými kódy `200`, `201`, `204`, `400`,
  `404`, `405` a `500`,
- čte tělo požadavku jako proud a ověřuje ho, než mu uvěří,
- připojil cizí modul a opravil v něm chybu.

Frameworky jako Express, Fastify nebo serverová část Next.js dělají přesně tohle,
jen za tebe napíšou `readBody`, `sendJson` a routovací `if`y. Teď víš, co pod nimi
je. V labu a v projektu na konci sekce to celé napíšeš sám, bez kroků.

# --hints--

Když je `books.json` poškozený, `GET /api/books` vrátí `500` s klíčem `error` — i opakovaně.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
try {
  await fs.writeFile(booksPath, 'tohle není JSON');
  const server = await helpers.startServer('server.js');
  for (let attempt = 1; attempt <= 2; attempt++) {
    const res = await fetch(new URL('/api/books', server.url)).catch((error) =>
      assert.fail(`Pokus ${attempt}: server na GET /api/books s poškozeným books.json neodpověděl (spadl?): ${error.message}`));
    assert.equal(res.status, 500, `Pokus ${attempt}: GET /api/books s poškozeným books.json má vrátit stav 500, přišlo ${res.status}`);
    assert.equal(typeof (await res.json()).error, 'string', 'Tělo odpovědi 500 má mít klíč error');
  }
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

Po opravě `books.json` server odpovídá normálně, bez restartu.

```js
const fs = await import('node:fs/promises');

try {

  await fs.writeFile(booksPath, files['books.json']);

    assert.fail('Po opravě books.json server neodpovídá — spadl při předchozí chybě?'));
  assert.equal(res.status, 200, 'Po opravě books.json má GET /api/books vrátit stav 200');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

Ostatní odpovědi zůstanou: `404` pro neznámou adresu, `400` pro vadnou knihu, `201` pro platnou.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
const server = await helpers.startServer('server.js');
try {
  const postBook = (body) => fetch(new URL('/api/books', server.url), {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: typeof body === 'string' ? body : JSON.stringify(body),
  });
  const missing = await fetch(new URL('/api/nic', server.url));
  assert.equal(missing.status, 404, 'GET /api/nic má dál vracet stav 404');
  const invalid = await postBook({ title: '', author: 'Karel Čapek', year: 1920 });
  assert.equal(invalid.status, 400, 'POST /api/books s prázdným title má dál vracet stav 400');
  const created = await postBook({ title: 'R.U.R.', author: 'Karel Čapek', year: 1920 });
  assert.equal(created.status, 201, 'POST /api/books s platnou knihou má dál vracet stav 201');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

# --help--

## --tip--

`500` je jediný kód, kterým server přiznává vlastní chybu — viz
[Stavové kódy](see:node-zaklady/http-v-node#stavove-kody). Proč nezachycená výjimka shodí
všechny, připomene [Skript a server](see:node-zaklady/co-je-node#skript-a-server).

## --tip--

Stačí jeden `try`/`catch` kolem celé obsluhy požadavku. Nejčitelnější je přesunout
dnešní obsah handleru do vlastní `async` funkce a v handleru ji zavolat s `await`
uvnitř `try`.

## --tip--

Stejný tvar s jinými jmény:

```js
const app = createServer(async (request, response) => {
  try {
    await route(request, response);
  } catch (problem) {
    console.error(problem);
    // odpověď 500
  }
});
```

```js
import { createServer } from 'node:http';
import { readBody } from './body.js';
import { findBook, loadBooks, saveBooks } from './library.js';
import { handleStats } from './stats.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

// Vrátí popis první chyby ve vstupu, nebo null, když je kniha v pořádku.
function validateBook(input) {
  if (typeof input !== 'object' || input === null) {
    return 'Tělo požadavku musí být JSON objekt.';
  }
  if (typeof input.title !== 'string' || input.title.trim() === '') {
    return 'Kniha musí mít název (title).';
  }
  if (typeof input.author !== 'string' || input.author.trim() === '') {
    return 'Kniha musí mít autora (author).';
  }
  if (!Number.isInteger(input.year)) {
    return 'Rok vydání (year) musí být celé číslo.';
  }
  return null;
}

const server = createServer(async (req, res) => {
  const { pathname, searchParams } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    if (req.method === 'GET') {
      const books = await loadBooks();
      const author = searchParams.get('author');
      if (author === null) {
        return sendJson(res, 200, books);
      }
      return sendJson(res, 200, books.filter((book) => book.author === author));
    }
    if (req.method === 'POST') {
      let input;
      try {
        input = JSON.parse(await readBody(req));
      } catch {
        return sendJson(res, 400, { error: 'Tělo požadavku musí být platný JSON.' });
      }

      const problem = validateBook(input);
      if (problem) {
        return sendJson(res, 400, { error: problem });
      }

      const books = await loadBooks();
      const book = {
        id: Math.max(0, ...books.map((item) => item.id)) + 1,
        title: input.title,
        author: input.author,
        year: input.year,
      };
      books.push(book);
      await saveBooks(books);
      return sendJson(res, 201, book);
    }
    res.setHeader('Allow', 'GET, POST');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const books = await loadBooks();
    const book = findBook(books, id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    if (req.method === 'GET') {
      return sendJson(res, 200, book);
    }
    if (req.method === 'DELETE') {
      await saveBooks(books.filter((item) => item.id !== id));
      res.writeHead(204);
      return res.end();
    }
    res.setHeader('Allow', 'GET, DELETE');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  if (pathname === '/api/stats') {
    return handleStats(req, res, await loadBooks());
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```

```js
import { readFile, writeFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export async function saveBooks(books) {
  await writeFile(booksFile, JSON.stringify(books, null, 2));
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

```js
// Statistiky knihovny pro GET /api/stats — dopsal kolega Tomáš.
// Nepovinný filtr ?author=… spočítá statistiky jen z knih jednoho autora.

function respond(res, code, payload) {
  res.writeHead(code, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(payload));
}

export function handleStats(req, res, allBooks) {
  const params = new URL(req.url, 'http://localhost').searchParams;
  const author = params.get('author');

  const picked = [];
  for (const b of allBooks) {
    if (author === null || b.author === author) {
      picked.push(b);
    }
  }

  if (picked.length === 0) {
    return respond(res, 404, { error: 'Tento autor v knihovně nemá žádnou knihu.' });
  }

  const years = [];
  for (const b of picked) {
    years.push(b.year);
  }

  respond(res, 200, {
    count: picked.length,
    firstYear: Math.min(...years),
    lastYear: Math.max(...years),
  });
}
```

```js
// Přečte celé tělo požadavku jako text. Tělo přichází po kouscích (proud).
export async function readBody(req) {
  const chunks = [];
  for await (const chunk of req) {
    chunks.push(chunk);
  }
  return Buffer.concat(chunks).toString('utf8');
}
```

```js
import { readBody } from './body.js';
import { findBook, loadBooks, saveBooks } from './library.js';
```
