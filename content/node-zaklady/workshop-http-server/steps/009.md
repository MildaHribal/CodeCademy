# --description--

Tenhle krok je bez návodu. Všechno, co potřebuješ, už znáš z JavaScriptu i
z předchozích kroků; když si nevíš rady, podívej se do nich zpátky.

Klient chce do filtru knihovny seznam autorů.

**Úkol:** přidej do `server.js` routu `GET /api/authors`:

- odpoví stavem `200` a JSON polem jmen autorů (řetězců),
- každý autor je v poli **jen jednou**, i když napsal víc knih,
- jména jsou seřazená podle české abecedy (`Č` patří za `C`, ne až na konec).

Seznam se počítá z `books.json` při každém požadavku, ne ručně opsaný — když do
knihovny přibude kniha nového autora, musí se v seznamu objevit.

# --hints--

`GET /api/authors` vrátí stav `200` a JSON.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/authors', server.url));
assert.equal(res.status, 200, 'GET /api/authors má vrátit stav 200');
assert.match(res.headers.get('content-type') ?? '', /^application\/json/i, `GET /api/authors má vrátit JSON, Content-Type: ${res.headers.get('content-type')}`);
```

Každý autor je v seznamu právě jednou.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/authors', server.url));
const authors = await res.json();
assert.ok(Array.isArray(authors), `GET /api/authors má vrátit pole, přišlo: ${JSON.stringify(authors)}`);
assert.equal(new Set(authors).size, authors.length, `Jména v GET /api/authors se nemají opakovat: ${JSON.stringify(authors)}`);
assert.equal(authors.filter((name) => name === 'Karel Čapek').length, 1, 'Karel Čapek napsal dvě knihy, v GET /api/authors má být jednou');
```

Seznam obsahuje všechny autory ze souboru seřazené podle abecedy.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/authors', server.url));
assert.deepEqual(await res.json(), ['Božena Němcová', 'Karel Čapek', 'Ladislav Fuks', 'Zdeněk Jirotka'], 'GET /api/authors má vrátit čtyři autory z books.json podle abecedy');
```

Seznam se počítá z aktuálního `books.json`.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
try {
  const books = [...JSON.parse(files['books.json']), { id: 6, title: 'Máj', author: 'Karel Hynek Mácha', year: 1836 }];
  await fs.writeFile(booksPath, JSON.stringify(books));
  const server = await helpers.startServer('server.js');
  const authors = await (await fetch(new URL('/api/authors', server.url))).json();
  assert.ok(authors.includes('Karel Hynek Mácha'), `Po přidání knihy od Karla Hynka Máchy do books.json ho má GET /api/authors vrátit, přišlo: ${JSON.stringify(authors)}`);
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

Jména jsou seřazená podle české abecedy: autor na `Č` stojí za autorem na `C` a před autorem na `D`.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
try {
  const books = [
    { id: 1, title: 'Saturnin', author: 'Zdeněk Jirotka', year: 1942 },
    { id: 2, title: 'Kniha A', author: 'Čestmír Kovář', year: 2001 },
    { id: 3, title: 'Kniha B', author: 'Cyril Bouda', year: 1950 },
    { id: 4, title: 'Kniha C', author: 'Dana Nová', year: 2010 },
  ];
  await fs.writeFile(booksPath, JSON.stringify(books));
  const server = await helpers.startServer('server.js');
  const authors = await (await fetch(new URL('/api/authors', server.url))).json();
  assert.deepEqual(authors, ['Cyril Bouda', 'Čestmír Kovář', 'Dana Nová', 'Zdeněk Jirotka'], 'GET /api/authors pro autory Zdeněk, Čestmír, Cyril a Dana má vrátit pořadí Cyril, Čestmír, Dana, Zdeněk — řadíš podle české abecedy, nebo podle kódů znaků?');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

# --help--

## --tip--

Potřebuješ dvě věci nad polem: zbavit se duplicit a seřadit. Co která metoda vrací
a jestli mění původní pole, shrnuje
[Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Nejdřív z knih udělej pole jmen. Duplicity odstraní třeba `Set` (a zpátky na pole
ho vrátí `[...množina]`), nebo `filter` s `indexOf`. Na české řazení je nejlepší
`localeCompare` s jazykem `'cs'`.

## --tip--

Stejný postup nad jinými daty — seznam měst ze seznamu zákazníků, rozepsaný na podcíle. Kód k nim napíšeš sám:

```js
// 1. z každého zákazníka vezmi jeho město
// 2. každé město nech jen jednou
// 3. seřaď podle české abecedy a pošli jako JSON
```

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { findBook, loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    return sendJson(res, 200, await loadBooks());
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const book = findBook(await loadBooks(), id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
