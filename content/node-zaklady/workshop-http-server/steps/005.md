# --description--

HTTP odpověď nejsou jen data. Má tři části:

1. [[stavový kód]] (*status code*) — číslo, které říká, jak to dopadlo: `200`
   „tady to je", `404` „nic takového tu není", `500` „rozbil se server",
2. [[HTTP hlavička|hlavičky]] (*headers*) — popis odpovědi, například jakého typu
   jsou data,
3. **tělo** (*body*) — samotná data.

Server teď posílá jen tělo. Node doplní stav `200` sám, ale hlavičku `Content-Type`
nepošle. Klient pak musí hádat, co dostal, a u českých znaků se často splete.

**Úkol:** v handleru v `server.js` před `res.end` zavolej `res.writeHead(status, headers)`
a pošli stav `200` a hlavičku `Content-Type` s hodnotou `text/plain; charset=utf-8`.
Část `text/plain` říká „obyčejný text", `charset=utf-8` říká, jak jsou zapsané znaky.

Příklad s jiným stavem a typem:

```js
const server = createServer((req, res) => {
  res.writeHead(201, { 'Content-Type': 'text/html; charset=utf-8' });
  res.end('<p>Objednávka přijata</p>');
});
```

`writeHead` musí přijít **před** `end`. Jakmile odejde první kus těla, hlavičky už
změnit nejdou. Stejně funguje i druhý zápis, který uvidíš v cizím kódu:
`res.statusCode = 201` a `res.setHeader('Content-Type', '…')`.

> [!TIP]
> Spusť server a pošli v HTTP klientovi `GET /`. V části s hlavičkami odpovědi
> uvidíš `content-type` — před úpravou tam nebude.

# --hints--

Server odpovídá stavem `200`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.equal(res.status, 200, 'GET / má vrátit stav 200');
```

Odpověď má hlavičku `Content-Type` s typem `text/plain`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.match(res.headers.get('content-type') ?? '', /^text\/plain/i, `Content-Type odpovědi na GET / má začínat text/plain, přišlo: ${res.headers.get('content-type')}`);
```

Hlavička `Content-Type` uvádí kódování `charset=utf-8`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.match(res.headers.get('content-type') ?? '', /charset=utf-8/i, `Content-Type odpovědi na GET / má obsahovat charset=utf-8, přišlo: ${res.headers.get('content-type')}`);
```

Tělo odpovědi je pořád `Knihovna běží`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.equal(await res.text(), 'Knihovna běží', 'GET / má dál vracet text "Knihovna běží"');
```

# --help--

## --tip--

Stav a hlavičky jsou součást odpovědi před tělem — viz
[Hlavičky a `Content-Type`](see:node-zaklady/http-v-node#hlavicky-a-content-type).

## --tip--

`res.writeHead` dostane číslo stavu a objekt hlaviček, kde klíč je jméno hlavičky.
Volání patří do handleru na řádek před `res.end`.

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

const server = createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
  res.end('Knihovna běží');
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
