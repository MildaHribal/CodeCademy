# --description--

Seznam je málo — klient potřebuje i jednu konkrétní knihu. Kniha s id `2` žije na
adrese `/api/books/2`. Část adresy, která se mění, je [[parametr cesty]].

**Úkol:** přidej do `server.js` routu pro `GET /api/books/:id`:

- když kniha s tím id existuje, odpověz stavem `200` a objektem knihy,
- když neexistuje, odpověz stavem `404` a JSON objektem s klíčem `error`.

Na `pathname === …` to nepůjde, protože id může být jakékoli. Cestu musíš poznat
podle začátku a id z ní dostat — hodí se `startsWith` se `slice`, nebo `split('/')`.
Vyber si. Knihu pak najde `findBook` z prvního kroku (stačí ji přidat do importu).

> [!PITFALL]
> Z adresy je všechno text. S id `'2'` najde `findBook` jen `undefined`, protože
> `'2' === 2` je `false` — a detail by vracel vždycky `404`.

Nesmysl typu `/api/books/abc` nemusíš řešit zvlášť, skončí taky `404`. Seznam na
`/api/books` musí dál fungovat.

# --hints--

`GET /api/books/2` vrátí stav `200` a knihu s id `2`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books/2', server.url));
assert.equal(res.status, 200, 'GET /api/books/2 má vrátit stav 200 — převádíš id z adresy na číslo?');
const expected = JSON.parse(files['books.json']).find((book) => book.id === 2);
assert.deepEqual(await res.json(), expected, 'GET /api/books/2 má vrátit objekt knihy s id 2');
```

Detail funguje pro kteroukoli knihu, třeba i pro poslední.

```js
const server = await helpers.startServer('server.js');
const last = JSON.parse(files['books.json']).at(-1);
const res = await fetch(new URL(`/api/books/${last.id}`, server.url));
assert.equal(res.status, 200, `GET /api/books/${last.id} má vrátit stav 200`);
assert.deepEqual(await res.json(), last, `GET /api/books/${last.id} má vrátit poslední knihu`);
```

Neexistující kniha (`/api/books/99`, `/api/books/abc`) vrátí stav `404` a JSON s klíčem `error`.

```js
const server = await helpers.startServer('server.js');
for (const path of ['/api/books/99', '/api/books/abc']) {
  const res = await fetch(new URL(path, server.url));
  assert.equal(res.status, 404, `GET ${path} má vrátit stav 404`);
  const body = await res.json();
  assert.equal(typeof body.error, 'string', `Tělo odpovědi na GET ${path} má mít klíč error`);
}
```

`GET /api/books` dál vrací celý seznam.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books', server.url));
assert.equal(res.status, 200, 'GET /api/books má dál vracet stav 200');
assert.deepEqual(await res.json(), JSON.parse(files['books.json']), 'GET /api/books má dál vracet všechny knihy');
```

Po odeslání odpovědi handler skončí: detail, neexistující kniha a seznam jdou po sobě bez pádu serveru.

```js
const server = await helpers.startServer('server.js');
for (const path of ['/api/books/2', '/api/books/99', '/api/books', '/api/books/1']) {
  await helpers.wait(100);
  const res = await fetch(new URL(path, server.url)).catch(() =>
    assert.fail(`Na GET ${path} server neodpověděl — spadl po předchozím požadavku? Chybí return před sendJson?`));
  await res.text();
}
```

## --tip--

Id v adrese je parametr cesty — jak ho z adresy dostat, ukazuje
[Adresa: `req.url`, cesta a query string](see:node-zaklady/http-v-node#adresa-req-url-cesta-a-query-string).

## --tip--

Routa patří pod routu seznamu a nad odpověď `404`. Uvnitř: odřízni prefix
`'/api/books/'` (jeho délku dá `.length`), výsledek převeď `Number(…)` a knihu hledej
v tom, co vrátí `await loadBooks()`.

## --tip--

Stejný tvar pro filmy:

```js
if (pathname.startsWith('/api/movies/')) {
  const movieId = Number(pathname.slice('/api/movies/'.length));
  const movie = findMovie(await loadMovies(), movieId);
  // 404, když movie není, jinak 200
}
```

```js
import { createServer } from 'node:http';
import { loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    return sendJson(res, 200, await loadBooks());
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { findBook, loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    return sendJson(res, 200, await loadBooks());
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const book = findBook(await loadBooks(), id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
