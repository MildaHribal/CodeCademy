# --description--

Server bude poslouchat na **portu** — čísle, podle kterého operační systém pozná,
kterému programu patří příchozí spojení. U tebe na počítači to může být 3000,
na serveru v produkci 8080 a testy Akademie si vyberou volný port samy.

Kdyby bylo číslo portu napsané v kódu, musel bys kód pro každé prostředí měnit.
Proto se port předává [[proměnná prostředí|proměnnou prostředí]] a v Node se čte
z objektu `process.env`.

**Úkol:** v souboru `server.js` vytvoř a vyexportuj konstantu `port`:

- když je nastavená proměnná `PORT`, je `port` její hodnota **jako číslo**,
- když nastavená není, je `port` číslo `3000`.

> [!PITFALL]
> Proměnné prostředí jsou vždycky řetězce. `PORT=8080 node server.js` nastaví
> `process.env.PORT` na `'8080'`, ne na `8080`. Chybějící proměnná je `undefined`.

Stejný vzor pro jiné nastavení:

```js
// Kolik položek vrátit na stránku; bez proměnné 20.
export const pageSize = Number(process.env.PAGE_SIZE ?? 20);
```

Operátor `??` použije pravou stranu jen tehdy, když je levá `null` nebo
`undefined`. Konstantu exportuješ, aby ji mohly ověřit testy; server ji v dalším
kroku použije.

# --hints--

Když je nastavená proměnná `PORT`, `port` je její hodnota jako číslo.

```js
const { stdout, stderr } = await helpers.run(
  `PORT=4567 node --input-type=module -e "const { port } = await import('./server.js'); console.log(JSON.stringify(port))"`
);
assert.equal(stdout.trim(), '4567', `S PORT=4567 má být port číslo 4567 (ne řetězec "4567"). Vypsáno: ${stdout}${stderr}`);
```

Bez proměnné `PORT` je `port` číslo `3000`.

```js
const { stdout, stderr } = await helpers.run(
  `env -u PORT node --input-type=module -e "const { port } = await import('./server.js'); console.log(JSON.stringify(port))"`
);
assert.equal(stdout.trim(), '3000', `Bez proměnné PORT má být port číslo 3000. Vypsáno: ${stdout}${stderr}`);
```

# --help--

## --tip--

Nastavení zvenku programu čteš z proměnných prostředí — viz
[`process`: program a svět kolem něj](see:node-zaklady/co-je-node#process-program-a-svet-kolem-nej).

## --tip--

Hodnotu z `process.env` převeď na číslo přes `Number(…)`. Výchozí hodnotu doplníš
operátorem `??` ještě před převodem.

# --explain--

Vysvětli vlastními slovy, proč se port serveru bere z proměnné prostředí, a ne z čísla napsaného přímo v kódu.

## --model--

Port je vlastnost prostředí, ve kterém server běží, ne vlastnost kódu. Na mém
počítači může být 3000, na serveru jiný a testy si vyberou volný. Když ho předá ten,
kdo program spouští, běží stejný kód všude beze změny. Stejně se předávají adresa
databáze nebo tajné klíče, které do kódu (a do gitu) nepatří.

## --checklist--

- Port se liší podle prostředí, kde server běží.
- Proměnnou prostředí nastaví ten, kdo program spouští, takže se kód nemusí měnit.
- Stejně se předávají další nastavení a tajné klíče, které nepatří do kódu.

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```
