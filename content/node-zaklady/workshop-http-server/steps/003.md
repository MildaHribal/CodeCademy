# --description--

Teď server doopravdy spustíš. Potřebuješ na to dvě funkce z modulu `node:http`:

- `createServer(handler)` vytvoří server. `handler` je funkce, kterou Node zavolá
  **pro každý příchozí požadavek** a předá jí dva objekty: `req` (*request*, co
  přišlo) a `res` (*response*, co pošleš zpátky).
- `server.listen(port, callback)` začne poslouchat na portu. `callback` se zavolá,
  jakmile server spojení opravdu přijímá.

Odpověď pošleš metodou `res.end(text)`. Tím odpověď zároveň **ukončíš** — dokud
`end` nezavoláš, prohlížeč čeká.

V souboru `server.js`:

1. naimportuj `createServer` z `node:http`,
2. vytvoř server, který na **jakýkoli** požadavek odpoví textem `Knihovna běží`,
3. spusť ho na portu z konstanty `port` a po spuštění vypiš do konzole adresu,
   například `Server běží na http://localhost:3000`.

Na jiném textu to vypadá takhle:

```js
import { createServer } from 'node:http';

const server = createServer((req, res) => {
  res.end('Pong');
});

server.listen(4000, () => {
  console.log('Ping server poslouchá na http://localhost:4000');
});
```

Výpis adresy není ozdoba. Server nic neukazuje, a když ho spustíš a v terminálu je
ticho, nevíš, jestli běží, nebo na něco čeká. Na svém počítači si ho vyzkoušíš
příkazem `node server.js` a otevřením adresy v prohlížeči; ukončíš ho Ctrl+C.

# --hints--

Po spuštění `node server.js` server přijímá spojení na portu z proměnné `PORT`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.equal(res.status, 200, 'Server má odpovědět stavem 200');
```

Na jakýkoli požadavek odpoví textem `Knihovna běží`.

```js
const server = await helpers.startServer('server.js');
for (const path of ['/', '/cokoliv/jineho']) {
  const res = await fetch(new URL(path, server.url));
  assert.equal(await res.text(), 'Knihovna běží', `GET ${path} má vrátit text "Knihovna běží"`);
}
```

Po spuštění vypíše do konzole adresu serveru i s číslem portu.

```js
const server = await helpers.startServer('server.js');
try {
  await helpers.waitFor(() => server.output().includes(String(server.port)));
} catch {
  assert.fail(`Výpis serveru má obsahovat číslo portu ${server.port}. Vypsáno: "${server.output()}"`);
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

const server = createServer((req, res) => {
  res.end('Knihovna běží');
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
