# --description--

## Hlášení

Frontend ukazuje statistiky pro autora, kterého si uživatel vybere. Pro autora, který
v knihovně nic nemá, přijde na `GET /api/stats?author=Nikdo` odpověď `404`, jak má.
Jenže potom **přestane odpovídat úplně všechno** — seznam knih, autoři, statistiky.
V terminálu serveru zůstalo:

```text
node:_http_server:411
    throw new ERR_HTTP_HEADERS_SENT('write');
          ^

Error [ERR_HTTP_HEADERS_SENT]: Cannot write headers after they are sent to the client
    at ServerResponse.writeHead (node:_http_server:411:11)
    at respond (file:///home/tomas/knihovna/stats.js:5:7)
    at handleStats (file:///home/tomas/knihovna/stats.js:29:3)
    at Server.<anonymous> (file:///home/tomas/knihovna/server.js:42:12) {
  code: 'ERR_HTTP_HEADERS_SENT'
}

Node.js v26.5.1
```

## Úkol

Oprav chybu tak, aby neznámý autor dostal `404` s klíčem `error` a server běžel dál.
Statistiky celé knihovny i jednoho autora musí fungovat jako dřív. Změň co nejmenší
kus kódu.

> [!TIP]
> Chybu si nejdřív zopakuj: **Spustit**, pak v HTTP klientovi `GET /api/stats?author=Nikdo`
> a hned potom `GET /api/books`. Výpis ve výstupu ukazuje soubor a řádek, odkud se
> druhá odpověď poslala.

# --hints--

Neznámý autor (`/api/stats?author=Nikdo`) dostane stav `404` a JSON s klíčem `error`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/stats?author=Nikdo', server.url)).catch(() =>
  assert.fail('Na GET /api/stats?author=Nikdo server neodpověděl'));
assert.equal(res.status, 404, 'GET /api/stats?author=Nikdo má vrátit stav 404');
assert.equal(typeof (await res.json()).error, 'string', 'Tělo odpovědi na GET /api/stats?author=Nikdo má mít klíč error');
```

Po dotazu na neznámého autora server běží dál a odpovídá.

```js
const server = await helpers.startServer('server.js');
await fetch(new URL('/api/stats?author=Nikdo', server.url)).then((res) => res.text()).catch(() => {});
await helpers.wait(200);
const res = await fetch(new URL('/api/books', server.url)).catch(() =>
  assert.fail(`Po GET /api/stats?author=Nikdo server přestal odpovídat (spadl?). Výstup serveru:\n${server.output()}`));
assert.equal(res.status, 200, 'Po GET /api/stats?author=Nikdo má GET /api/books dál vracet stav 200');
```

Statistiky celé knihovny i jednoho autora zůstanou stejné.

```js
const server = await helpers.startServer('server.js');
const all = await fetch(new URL('/api/stats', server.url));
assert.deepEqual(await all.json(), { count: 5, firstYear: 1855, lastYear: 1967 }, 'GET /api/stats má dál vracet statistiky všech knih');
const capek = await fetch(new URL('/api/stats?author=Karel%20%C4%8Capek', server.url));
assert.equal(capek.status, 200, 'GET /api/stats?author=Karel Čapek má dál vracet stav 200');
assert.deepEqual(await capek.json(), { count: 2, firstYear: 1924, lastYear: 1936 }, 'GET /api/stats?author=Karel Čapek má dál vracet statistiky jeho dvou knih');
```

## --tip--

Výpis v hlášení vede do `stats.js`: podívej se na větev, která posílá `404`, a zjisti,
kam kód pokračuje, když se odpověď odešle.

## --tip--

Stejná chyba v jiném kódu a její oprava:
`if (!order) { return reply(response, 404, { error: 'Objednávka neexistuje.' }); }` —
bez `return` by se pod `if` poslala i druhá odpověď.

## --file-- server.js

```js
import { createServer } from 'node:http';
import { findBook, loadBooks } from './library.js';
import { handleStats } from './stats.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    if (req.method === 'GET') {
      return sendJson(res, 200, await loadBooks());
    }
    res.setHeader('Allow', 'GET');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const book = findBook(await loadBooks(), id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  if (pathname === '/api/stats') {
    return handleStats(req, res, await loadBooks());
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

## --file-- stats.js

```js
// Statistiky knihovny pro GET /api/stats — dopsal kolega Tomáš.
// Nepovinný filtr ?author=… spočítá statistiky jen z knih jednoho autora.

function respond(res, code, payload) {
  res.writeHead(code, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(payload));
}

export function handleStats(req, res, allBooks) {
  const params = new URL(req.url, 'http://localhost').searchParams;
  const author = params.get('author');

  const picked = [];
  for (const b of allBooks) {
    if (author === null || b.author === author) {
      picked.push(b);
    }
  }

  if (picked.length === 0) {
    respond(res, 404, { error: 'Tento autor v knihovně nemá žádnou knihu.' });
  }

  const years = [];
  for (const b of picked) {
    years.push(b.year);
  }

  respond(res, 200, {
    count: picked.length,
    firstYear: Math.min(...years),
    lastYear: Math.max(...years),
  });
}
```
