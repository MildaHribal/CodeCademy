# --description--

Server knihovny nemá vracet větu, ale **data**, se kterými může pracovat jiný
program — frontend, mobilní aplikace, skript. Formát, kterým si programy po HTTP
posílají data, je nejčastěji JSON. JSON odpověď má dvě pravidla:

- tělo je text vzniklý z dat přes `JSON.stringify(data)` (`res.end` umí poslat
  jen text nebo bajty, ne objekt),
- hlavička `Content-Type` je `application/json; charset=utf-8`.

**Úkol:** v `server.js`:

1. napiš funkci `sendJson(res, status, data)`, která pošle stavový kód, hlavičku
   pro JSON a data převedená na text,
2. naimportuj `loadBooks` z `./library.js` (i s příponou `.js`),
3. v handleru na **každý** požadavek odpověz stavem `200` a seznamem knih.

`loadBooks()` vrací Promise, takže handler musí být `async` a na knihy počkat přes
`await`. Odpověď odejde, až zavoláš `res.end`, klidně po čekání na soubor.

Na jiných datech:

```js
import { loadForecast } from './weather.js';

function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const forecast = await loadForecast();
  sendJson(res, 200, forecast);
});
```

> [!PITFALL]
> `res.end(books)` bez `JSON.stringify` shodí server na
> `TypeError [ERR_INVALID_ARG_TYPE]: The "chunk" argument must be of type string…`.

# --hints--

Server odpovídá stavem `200` a hlavičkou `Content-Type` s typem `application/json`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.equal(res.status, 200, 'GET / má vrátit stav 200');
assert.match(res.headers.get('content-type') ?? '', /^application\/json/i, `Content-Type odpovědi na GET / má začínat application/json, přišlo: ${res.headers.get('content-type')}`);
```

Hlavička `Content-Type` uvádí kódování `charset=utf-8`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
assert.match(res.headers.get('content-type') ?? '', /charset=utf-8/i, `Content-Type odpovědi na GET / má obsahovat charset=utf-8, přišlo: ${res.headers.get('content-type')}`);
```

Tělo odpovědi je seznam knih ze souboru `books.json` ve formátu JSON.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/', server.url));
const text = await res.text();
let data;
try {
  data = JSON.parse(text);
} catch {
  assert.fail(`Tělo odpovědi na GET / není platný JSON: ${text.slice(0, 100)}`);
}
assert.deepEqual(data, JSON.parse(files['books.json']), 'Tělo odpovědi na GET / má obsahovat všechny knihy z books.json');
```

# --help--

## --tip--

Objekt se po síti posílá jako text s hlavičkou, která říká, že je to JSON — viz
[Hlavičky a `Content-Type`](see:node-zaklady/http-v-node#hlavicky-a-content-type).

## --tip--

`sendJson` volá uvnitř `res.writeHead` a `res.end`, nic nevrací. Handler dostane před
parametry `async` a knihy si načte přes `await loadBooks()`.

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const books = await loadBooks();
  sendJson(res, 200, books);
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
