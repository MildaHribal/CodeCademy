# --description--

Server nemá databázi, knihy si bude číst ze souboru `books.json`.

**Úkol:** v `library.js` napiš a vyexportuj asynchronní funkci `loadBooks()`, která
přečte `books.json` a vrátí pole knih.

Soubor přečteš funkcí `readFile` z [[vestavěný modul|vestavěného modulu]]
`node:fs/promises`. Vrací Promise s obsahem souboru. Když jí jako druhý argument dáš
`'utf8'`, dostaneš text, a ten převedeš na data přes `JSON.parse`. Cesta k souboru
je v konstantě `booksFile` už připravená. Import patří na začátek souboru.

Tentýž vzor nad jiným souborem:

```js
import { readFile } from 'node:fs/promises';

const recipesFile = new URL('./recipes.json', import.meta.url);

export async function loadRecipes() {
  const text = await readFile(recipesFile, 'utf8');
  return JSON.parse(text);
}
```

Proč funkce, a ne jednou přečtená konstanta nahoře v souboru? Data se budou měnit —
později do souboru budeš zapisovat nové knihy. Funkce čte soubor **při každém
zavolání**, takže vždycky vrátí aktuální stav.

> [!PITFALL]
> Bez `'utf8'` vrátí `readFile` `Buffer` se surovými bajty a `JSON.parse` z něj
> neudělá pole knih.

# --hints--

`library.js` exportuje funkci `loadBooks`.

```js
const library = await helpers.importFile('library.js');
assert.equal(typeof library.loadBooks, 'function', 'library.js má exportovat funkci loadBooks');
```

`loadBooks()` vrátí Promise, která se splní polem knih ze souboru `books.json`.

```js
const { loadBooks } = await helpers.importFile('library.js');
const result = loadBooks();
assert.ok(result instanceof Promise, 'loadBooks() má vracet Promise — je funkce označená async?');
assert.deepEqual(await result, JSON.parse(files['books.json']), 'await loadBooks() má vrátit pole knih z books.json');
```

`loadBooks()` čte soubor při každém zavolání — když se `books.json` změní, vrátí nová data.

```js
const fs = await import('node:fs/promises');
const booksPath = `${helpers.dir}/books.json`;
try {
  const { loadBooks } = await helpers.importFile('library.js');
  await loadBooks();
  const changed = [{ id: 7, title: 'Máj', author: 'Karel Hynek Mácha', year: 1836 }];
  await fs.writeFile(booksPath, JSON.stringify(changed));
  assert.deepEqual(await loadBooks(), changed, 'Po změně books.json má další volání loadBooks() vrátit nový obsah souboru');
} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

`findBook` z prvního kroku dál funguje.

```js
const { findBook } = await helpers.importFile('library.js');
const books = [{ id: 4, title: 'Spalovač mrtvol', author: 'Ladislav Fuks', year: 1967 }];
assert.deepEqual(findBook(books, 4), books[0], 'findBook(books, 4) má dál vracet knihu s id 4');
```

## --tip--

Import `readFile` patří na první řádek `library.js`. Funkce dostane před `function`
slovo `async`, uvnitř počká na `readFile(booksFile, …)` a vrátí výsledek `JSON.parse`.

# --solution--

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```
