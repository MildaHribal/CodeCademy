# --description--

Server bude poslouchat na nějakém **portu** — čísle, podle kterého operační systém
pozná, kterému programu patří příchozí spojení. U tebe na počítači to může být
3000, na serveru v produkci 8080 a testy Akademie si vyberou volný port samy.

Kdyby bylo číslo portu napsané v kódu, musel bys kód pro každé prostředí měnit.
Proto se port (a všechno další, co se liší podle toho, kde program běží) předává
**proměnnou prostředí** a v Node se čte z objektu `process.env`.

V souboru `server.js` vytvoř a vyexportuj konstantu `port`:

- když je nastavená proměnná `PORT`, je `port` její hodnota **jako číslo**,
- když nastavená není, je `port` číslo `3000`.

Pozor na typ: proměnné prostředí jsou vždycky řetězce. `PORT=8080 node server.js`
nastaví `process.env.PORT` na `'8080'`, ne na `8080`. Chybějící proměnná je
`undefined`.

Stejný vzor pro jiné nastavení:

```js
// Kolik položek vrátit na stránku; bez proměnné 20.
export const pageSize = Number(process.env.PAGE_SIZE ?? 20);
```

Operátor `??` použije pravou stranu jen tehdy, když je levá `null` nebo
`undefined`. Konstantu exportuješ, aby ji mohly ověřit testy; server ji v dalším
kroku použije.

# --hints--

Když je nastavená proměnná `PORT`, `port` je její hodnota jako číslo.

```js
const { stdout, stderr } = await helpers.run(
  `PORT=4567 node --input-type=module -e "const { port } = await import('./server.js'); console.log(JSON.stringify(port))"`
);
assert.equal(stdout.trim(), '4567', `S PORT=4567 má být port číslo 4567 (ne řetězec). Vypsáno: ${stdout}${stderr}`);
```

Bez proměnné `PORT` je `port` číslo `3000`.

```js
const { stdout, stderr } = await helpers.run(
  `env -u PORT node --input-type=module -e "const { port } = await import('./server.js'); console.log(JSON.stringify(port))"`
);
assert.equal(stdout.trim(), '3000', `Bez PORT má být port číslo 3000. Vypsáno: ${stdout}${stderr}`);
```

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}
```

## --file-- server.js
