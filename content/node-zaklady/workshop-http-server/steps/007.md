# --description--

Server teď vrací knihy na jakoukoli adresu — `/`, `/api/books` i `/nesmysl`.
Skutečné API má pro každou věc **vlastní adresu** a na neznámou adresu odpoví
`404`. Rozhodování „která adresa → který kód" je [[routování]] (*routing*).

Adresa požadavku je v `req.url`. Je to celá cesta **včetně query stringu**, takže
u `GET /api/books?sort=title` je `req.url` rovno `'/api/books?sort=title'`.
Čistou cestu získáš vestavěnou třídou `URL`:

```js
const { pathname } = new URL(req.url, 'http://localhost');
```

Druhý argument je základ adresy. `req.url` obsahuje jen cestu, a `URL` potřebuje
celou adresu; jakou doménu doplníš, je jedno.

**Úkol:** v handleru v `server.js`:

- na cestu `/api/books` odpověz stavem `200` a seznamem knih,
- na jakoukoli jinou cestu odpověz stavem `404` a JSON objektem s klíčem `error`,
  ve kterém je česká zpráva, například `{ "error": "Tahle adresa neexistuje." }`.

Na jiných datech:

```js
const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/movies') {
    return sendJson(res, 200, await loadMovies());
  }

  sendJson(res, 404, { error: 'Film tu nemáme.' });
});
```

> [!PITFALL]
> Bez `return` před `sendJson` by kód pokračoval dál a poslal i odpověď `404`.
> Server by odpověděl jednou a spadl na
> `Error [ERR_HTTP_HEADERS_SENT]: Cannot write headers after they are sent to the client`.

# --hints--

`GET /api/books` vrátí stav `200` a seznam knih.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books', server.url));
assert.equal(res.status, 200, 'GET /api/books má vrátit stav 200');
assert.deepEqual(await res.json(), JSON.parse(files['books.json']), 'GET /api/books má vrátit všechny knihy z books.json');
```

`GET /api/books` s query stringem (`?sort=title`) vrátí taky seznam knih.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books?sort=title', server.url));
assert.equal(res.status, 200, 'GET /api/books?sort=title má vrátit 200 — porovnáváš pathname, nebo celé req.url?');
assert.deepEqual(await res.json(), JSON.parse(files['books.json']), 'GET /api/books?sort=title má vrátit všechny knihy');
```

Neznámá adresa (`/`, `/api/nic`) vrátí stav `404`.

```js
const server = await helpers.startServer('server.js');
for (const path of ['/', '/api/nic', '/api/books-navic']) {
  const res = await fetch(new URL(path, server.url));
  assert.equal(res.status, 404, `GET ${path} má vrátit stav 404`);
}
```

Odpověď `404` je JSON objekt s textovým klíčem `error`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/nic', server.url));
assert.match(res.headers.get('content-type') ?? '', /^application\/json/i, `Odpověď na GET /api/nic má mít Content-Type application/json, přišlo: ${res.headers.get('content-type')}`);
const body = await res.json();
assert.equal(typeof body.error, 'string', 'Tělo odpovědi na GET /api/nic má mít klíč error s textem');
assert.ok(body.error.trim().length > 0, 'Zpráva v error u GET /api/nic nemá být prázdná');
```

Po odeslání odpovědi handler skončí: server zvládne několik požadavků po sobě a nespadne.

```js
const server = await helpers.startServer('server.js');
for (const path of ['/api/books', '/api/books', '/api/nic']) {
  await helpers.wait(100);
  const res = await fetch(new URL(path, server.url)).catch(() =>
    assert.fail(`Na GET ${path} server neodpověděl — spadl po předchozím požadavku? Chybí return před sendJson?`));
  await res.text();
}
```

# --help--

## --tip--

Rozhoduješ podle cesty bez query stringu — viz
[Adresa: `req.url`, cesta a query string](see:node-zaklady/http-v-node#adresa-req-url-cesta-a-query-string).

## --tip--

Na začátku handleru si z `new URL(…)` vezmi `pathname` a porovnej ho v `if`
s `'/api/books'`. Odpověď `404` patří až pod `if`, jako poslední řádek handleru.

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url

const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    return sendJson(res, 200, await loadBooks());
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
