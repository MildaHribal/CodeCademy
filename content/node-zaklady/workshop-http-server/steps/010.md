# --description--

Než server začne přijímat nové knihy, potřebuje je umět **uložit**. Databázi
nemáme, takže data půjdou zpátky do `books.json`.

V souboru `library.js` napiš a vyexportuj asynchronní funkci `saveBooks(books)`,
která zapíše pole knih do `books.json` jako JSON **čitelně odsazený dvěma
mezerami**.

Zapisuje se funkcí `writeFile(cesta, text)` ze stejného modulu jako `readFile`
— přidej ji do importu na začátku souboru. Pozor, `writeFile` soubor **celý
přepíše**; nepřidává na konec. Proto se ukládá celé pole, ne jedna nová kniha.

Odsazení zařídí třetí argument `JSON.stringify`. Druhý argument (`null`) je filtr
klíčů, který teď nepotřebuješ:

```js
JSON.stringify({ theme: 'dark', fontSize: 16 });
// '{"theme":"dark","fontSize":16}'

JSON.stringify({ theme: 'dark', fontSize: 16 }, null, 2);
// '{\n  "theme": "dark",\n  "fontSize": 16\n}'
```

Celé to na jiných datech:

```js
import { readFile, writeFile } from 'node:fs/promises';

const settingsFile = new URL('./settings.json', import.meta.url);

export async function saveSettings(settings) {
  await writeFile(settingsFile, JSON.stringify(settings, null, 2));
}
```

Proč odsazení, když stroji je to jedno? Soubor s daty budeš číst ty, při ladění
i v gitu. Změna jedné knihy je pak v rozdílu vidět jako jeden řádek, ne jako jeden
nekonečný řádek celého souboru.

```js

  await saveBooks(books);

} finally {
  await fs.writeFile(booksPath, files['books.json']);
}
```

## --file-- server.js

```js
import { createServer } from 'node:http';
import { loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    if (req.method === 'GET') {
      return sendJson(res, 200, await loadBooks());
    }
    res.setHeader('Allow', 'GET');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const books = await loadBooks();
    const book = books.find((item) => item.id === id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
