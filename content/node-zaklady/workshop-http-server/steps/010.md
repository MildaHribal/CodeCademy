# --description--

Každý HTTP požadavek má kromě adresy i **metodu**: `GET` přečíst, `POST` vytvořit,
`PUT`/`PATCH` změnit, `DELETE` smazat. Server metodu zatím ignoruje — na
`DELETE /api/books` odpoví seznamem knih, jako by se nic nestalo. Klient, který se
pokusil knihy smazat, si pak myslí, že se to povedlo.

Metoda je v `req.method` jako řetězec velkými písmeny. Na metodu, kterou adresa
neumí, se odpovídá stavem `405 Method Not Allowed` a hlavičkou `Allow` se seznamem
metod, které adresa umí.

**Úkol:** u routy `/api/books` v `server.js`:

- na `GET` odpověz jako dosud seznamem knih,
- na jakoukoli jinou metodu odpověz stavem `405`, hlavičkou `Allow: GET`
  a JSON objektem s klíčem `error`.

Hlavičku navíc dostaneš do odpovědi dvěma způsoby: připravíš ji přes `res.setHeader`
ještě před `sendJson`, nebo `sendJson` rozšíříš o nepovinný parametr s hlavičkami.
Vyber si. Ostatní adresy (`/api/books/:id`, `/api/authors`) zatím nech, jak jsou.

# --hints--

`GET /api/books` dál vrací seznam knih.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books', server.url));
assert.equal(res.status, 200, 'GET /api/books má dál vracet stav 200');
assert.deepEqual(await res.json(), JSON.parse(files['books.json']), 'GET /api/books má dál vracet všechny knihy');
```

`DELETE /api/books` a `PUT /api/books` vrátí stav `405`.

```js
const server = await helpers.startServer('server.js');
for (const method of ['DELETE', 'PUT']) {
  const res = await fetch(new URL('/api/books', server.url), { method });
  assert.equal(res.status, 405, `${method} /api/books má vrátit stav 405`);
}
```

Odpověď `405` má hlavičku `Allow` s metodou `GET`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books', server.url), { method: 'DELETE' });
assert.match(res.headers.get('allow') ?? '', /\bGET\b/, `Hlavička Allow u DELETE /api/books má obsahovat GET, přišlo: ${res.headers.get('allow')}`);
```

Odpověď `405` je JSON objekt s klíčem `error`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/books', server.url), { method: 'DELETE' });
assert.equal(res.status, 405, 'DELETE /api/books má vrátit stav 405');
const body = await res.json();
assert.equal(typeof body.error, 'string', 'Tělo odpovědi 405 na DELETE /api/books má mít klíč error s textem');
```

# --help--

## --tip--

`405` je chyba v požadavku: adresa existuje, jen neumí tuhle metodu. Kódy a jejich
význam shrnují [Stavové kódy](see:node-zaklady/http-v-node#stavove-kody).

## --tip--

Uvnitř routy `/api/books` porovnej `req.method` s `'GET'`. Pro ostatní metody
nastav hlavičku `Allow` a pošli `405` — obojí s `return`, ať handler skončí.

## --tip--

Stejný tvar pro objednávky, jen s jinými jmény:

```js
if (pathname === '/api/orders') {
  if (request.method === 'GET') {
    return sendJson(response, 200, await loadOrders());
  }
  response.setHeader('Allow', 'GET');
  return sendJson(response, 405, { error: 'Objednávky jde jen číst.' });
}
```

## --file-- library.js

```js
import { readFile } from 'node:fs/promises';

// Funkce pro práci s knihami. Server je bude importovat.

// books.json leží vedle tohoto souboru. Cesta postavená od import.meta.url
// funguje, ať spustíš node z jakékoli složky.
const booksFile = new URL('./books.json', import.meta.url);

export async function loadBooks() {
  const text = await readFile(booksFile, 'utf8');
  return JSON.parse(text);
}

export function findBook(books, id) {
  return books.find((book) => book.id === id);
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { findBook, loadBooks } from './library.js';

// Port z prostředí. Proměnné prostředí jsou řetězce, proto Number().
export const port = Number(process.env.PORT ?? 3000);

// Pošle data jako JSON se stavovým kódem a hlavičkou, podle které klient pozná typ.
function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

const server = createServer(async (req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');

  if (pathname === '/api/books') {
    if (req.method === 'GET') {
      return sendJson(res, 200, await loadBooks());
    }
    res.setHeader('Allow', 'GET');
    return sendJson(res, 405, { error: 'Tahle metoda tu není povolená.' });
  }

  if (pathname.startsWith('/api/books/')) {
    const id = Number(pathname.slice('/api/books/'.length));
    const book = findBook(await loadBooks(), id);
    if (!book) {
      return sendJson(res, 404, { error: 'Kniha nenalezena.' });
    }
    return sendJson(res, 200, book);
  }

  if (pathname === '/api/authors') {
    const books = await loadBooks();
    const authors = [...new Set(books.map((book) => book.author))];
    authors.sort((a, b) => a.localeCompare(b, 'cs'));
    return sendJson(res, 200, authors);
  }

  sendJson(res, 404, { error: 'Tahle adresa neexistuje.' });
});

server.listen(port, () => {
  console.log(`Server běží na http://localhost:${port}`);
});
```
