# --description--

Napiš funkci `sortedByName(items)`, která vrátí nové pole seřazené podle `name` podle **české abecedy**. Původní pole se nemění.

U textů odečet nefunguje (`'Čaj' - 'Káva'` je `NaN`). A porovnání přes `<` a `>` porovnává čísla znaků v Unicode, ne abecedu: `Č` má vyšší číslo než všechna písmena bez diakritiky, takže by `Čaj` skončil až za `Zelím`. Česká abeceda navíc řadí `Ch` až za `H`.

Na tohle má text metodu **`localeCompare`**. Vrací přesně to, co porovnávací funkce potřebuje: záporné číslo, nulu nebo kladné číslo. Druhý argument je jazyk:

```js
const byTitle = books.toSorted((a, b) => a.title.localeCompare(b.title, 'cs'));
```

Jazyk `'cs'` **piš vždycky**. Bez něj se použije jazyk prohlížeče nebo systému a pořadí se bude lišit počítač od počítače — což je ta nejhorší kategorie chyb, protože u tebe to funguje.

# --hints--

`sortedByName` řadí podle české abecedy: `Cibule`, `Čaj`, `Hrách`, `Chleba`.

```js
const items = [
  { id: 1, name: 'Chleba' },
  { id: 2, name: 'Čaj' },
  { id: 3, name: 'Hrách' },
  { id: 4, name: 'Cibule' },
];
const result = sortedByName(items);
assert.ok(Array.isArray(result), 'sortedByName má vrátit pole');
assert.deepEqual(result.map((item) => item.name), ['Cibule', 'Čaj', 'Hrách', 'Chleba']);
```

Pole, které `sortedByName` dostane, zůstane v původním pořadí.

```js
const items = [{ id: 1, name: 'Mouka' }, { id: 2, name: 'Ananas' }];
const result = sortedByName(items);
assert.deepEqual(items.map((item) => item.name), ['Mouka', 'Ananas'], 'původní pole se nesmí přerovnat');
assert.notEqual(result, items, 'výsledek má být nové pole');
```

Porovnání dostává jazyk `'cs'`, aby řazení nezáviselo na nastavení počítače.

```js
const source = helpers.stripComments(sortedByName.toString(), 'js');
assert.match(source, /['"`]cs(-CZ)?['"`]/, "v sortedByName chybí jazyk 'cs' — například a.name.localeCompare(b.name, 'cs')");
```
