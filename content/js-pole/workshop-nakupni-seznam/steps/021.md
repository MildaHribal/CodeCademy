# --description--

**Úkol:** Napiš funkci `sortedByName(items)`, která vrátí nové pole seřazené podle `name` podle **české abecedy**. Původní pole se nemění.

U textů odečet nefunguje: `'Čaj' - 'Káva'` je `NaN`. Kandidáti na porovnání dvou textů:

- operátory `<` a `>` — porovnávají čísla znaků v Unicode, ne abecedu,
- metoda textu `localeCompare(jinýText, jazyk)` — vrací přesně to, co porovnávací funkce potřebuje: záporné číslo, nulu nebo kladné číslo.

> [!PITFALL]
> `<` řadí `Čaj` až za `Zelí`, protože `Č` má vyšší číslo než všechna písmena bez diakritiky. A česká abeceda navíc řadí `Ch` až za `H` — to žádné porovnání znaků neví.

Na jiných datech:

```js
// 1. názvy knih podle české abecedy
const byTitle = books.toSorted((a, b) => a.title.localeCompare(b.title, 'cs'));
```

Jazyk `'cs'` **piš vždycky**. Bez něj se použije jazyk prohlížeče nebo systému a pořadí se bude lišit počítač od počítače — což je ta nejhorší kategorie chyb, protože u tebe to funguje.

# --hints--

`sortedByName` řadí podle české abecedy: `Cibule`, `Čaj`, `Hrách`, `Chleba`.

```js
const items = [
  { id: 1, name: 'Chleba' },
  { id: 2, name: 'Čaj' },
  { id: 3, name: 'Hrách' },
  { id: 4, name: 'Cibule' },
];
const result = sortedByName(items);
assert.ok(Array.isArray(result), 'sortedByName má vrátit pole');
assert.deepEqual(
  result.map((item) => item.name),
  ['Cibule', 'Čaj', 'Hrách', 'Chleba'],
  'sortedByName pro Chleba, Čaj, Hrách, Cibule má vrátit pořadí Cibule, Čaj, Hrách, Chleba (Č za C, Ch za H)',
);
```

Pole, které `sortedByName` dostane, zůstane v původním pořadí.

```js
const items = [{ id: 1, name: 'Mouka' }, { id: 2, name: 'Ananas' }];
const result = sortedByName(items);
assert.deepEqual(items.map((item) => item.name), ['Mouka', 'Ananas'], 'sortedByName([Mouka, Ananas]) nesmí přerovnat původní pole');
assert.notEqual(result, items, 'sortedByName má vrátit nové pole, ne původní pole items');
```

Porovnání dostává jazyk `'cs'`, aby řazení nezáviselo na nastavení počítače.

```js
const source = helpers.stripComments(sortedByName.toString(), 'js');
assert.match(source, /['"`]cs(-CZ)?['"`]/, "v sortedByName chybí jazyk 'cs' — bez něj závisí pořadí na nastavení počítače");
```

# --help--

## --tip--

Jde o porovnávací funkci pro texty — viz [Řazení a porovnávací funkce](see:js-pole/metody-pole-do-hloubky#razeni-a-porovnavaci-funkce).

## --tip--

Stejná kostra jako `sortedByPrice`, jen porovnávací funkce místo odečtu zavolá na názvu první položky `localeCompare` s názvem druhé a jazykem.

## --tip--

Na jiných datech: `cities.toSorted((a, b) => a.localeCompare(b, 'cs'))` seřadí pole názvů měst.

// Nákupní seznam. Každá položka je objekt se stejnými klíči,

const groceries = [

  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}

// Popisky ve tvaru „Rohlíky (6 ks)".
function itemLabels(items) {
  return items.map((item) => `${item.name} (${item.quantity} ks)`);
}

// Položky, které ještě nejsou v košíku.
function toBuy(items) {
  return items.filter((item) => !item.bought);
}

// Vrátí nový seznam bez položky s daným id.
function removeById(items, id) {
  return items.filter((item) => item.id !== id);
}

// Položka s daným id, nebo undefined.
function findItem(items, id) {
  return items.find((item) => item.id === id);
}

// Index položky s daným id, nebo -1.
function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
}

// Od kolegy: je položka s tímhle id už v seznamu?
function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position !== -1) {
    return true;
  }
  return false;
}

// Je v seznamu aspoň jedna nekoupená položka?
function hasUnbought(items) {
  return items.some((item) => !item.bought);
}

// Jsou koupené všechny položky? U prázdného seznamu ano.
function allBought(items) {
  return items.every((item) => item.bought);
}

// Zná obchod tuhle kategorii?
function isKnownCategory(category) {
  return categories.includes(category);
}

// Cena celého nákupu v korunách.
function totalPrice(items) {
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0);
}

// Nový seznam seřazený od nejlevnější položky.
function sortedByPrice(items) {
  return items.toSorted((a, b) => a.price - b.price);
}
