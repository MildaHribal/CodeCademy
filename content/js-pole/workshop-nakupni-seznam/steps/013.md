# --description--

**Úkol:** Napiš funkci `findItem(items, id)`, která vrátí položku s daným `id`. Když taková není, vrátí `undefined`. Použij metodu **`find`**.

`find` dostává stejný predikát jako `filter`. Liší se výsledek:

- `filter` vrátí **pole všech** vyhovujících položek,
- `find` vrátí **první** vyhovující položku samotnou (ne v poli) a dál už nehledá. Když nevyhoví žádná, vrátí `undefined`.

Na jiných datech:

```js
// 1. první kniha s názvem Krakatit, nebo undefined
const krakatit = books.find((book) => book.title === 'Krakatit');
```

> [!NOTE]
> Vrácená položka je **tentýž objekt**, který je v poli, ne kopie. Kdo ji pak změní, mění ji i v poli. Ke kopiím se vrátíš v kroku o změně počtu kusů.

# --hints--

`findItem` vrátí položku se zadaným `id` (ten samý objekt, který je v poli).

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
assert.equal(findItem([coffee, tea], 8), tea, 'findItem([Káva (7), Čaj (8)], 8) má vrátit objekt Čaj — samotnou položku, ne pole');
```

S neexistujícím `id` vrátí `findItem` hodnotu `undefined`.

```js
assert.equal(findItem([{ id: 7, name: 'Káva' }], 42), undefined, 'findItem([Káva (7)], 42) má vrátit undefined');
assert.equal(findItem([], 7), undefined, 'findItem([], 7) má vrátit undefined');
```

`findItem` používá metodu `find`.

```js
const source = helpers.stripComments(findItem.toString(), 'js');
assert.match(source, /\.find\s*\(/, 'v findItem chybí volání .find(…)');
```

# --help--

## --tip--

Hledáš jednu položku, ne pole — viz řádek `find` v tabulce [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Zavolej `find` na `items` s predikátem, který porovná `id` položky se zadaným `id` přes `===`.

## --tip--

Na jiných datech: uživatel s e-mailem je `users.find((user) => user.email === email)`.
