title: Pozice přes findIndex
---

# --description--

Napiš funkci `indexById(items, id)`, která vrátí index položky s daným `id`. Když taková není, vrátí `-1`. Použij metodu **`findIndex`**.

`findIndex` je `find`, který místo položky vrací její pořadí. Pozor na jedinou nekonzistenci: nenalezený `find` vrací `undefined`, nenalezený `findIndex` vrací **`-1`**. Je to tak z historických důvodů a prostě se to musí vědět.

Nepleť si ho s `indexOf`. `indexOf` hledá **hodnotu** (`['a', 'b'].indexOf('b')` je `1`) a porovnává ji přes `===`. Na pole objektů je k ničemu, protože hledá tentýž objekt, ne objekt se stejným `id`. `findIndex` hledá podle **podmínky**, kterou si napíšeš.

```js
const position = books.findIndex((book) => book.pages > 300); // 1
```

A jedna past, kvůli které kontrola zkouší i první položku: její index je `0`, a nula je v podmínce nepravda. `if (indexById(items, id))` proto první položku „nenajde". Výsledek `findIndex` se porovnává s `-1`.

# --hints--

`indexById` vrátí index položky se zadaným `id`.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }, { id: 9, name: 'Rýže' }];
assert.equal(indexById(items, 9), 2, 'Rýže s id 9 je na indexu 2');
```

Pro první položku vrátí `indexById` číslo `0`.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
assert.equal(indexById(items, 7), 0, 'první položka má index 0');
```

S neexistujícím `id` vrátí `indexById` číslo `-1`.

```js
assert.equal(indexById([{ id: 7, name: 'Káva' }], 42), -1, 'nenalezená položka má dát -1');
assert.equal(indexById([], 7), -1, 'v prázdném poli se nic nenajde, výsledek je -1');
```
