title: map, který vrací objekty
---

# --description--

Napiš funkci `lineTotals(items)`, která z každé položky udělá **nový objekt** se dvěma klíči: `name` (název položky) a `total` (cena za všechny kusy, tedy `price * quantity`).

Z položky `{ id: 2, name: 'Mléko', price: 24, quantity: 2, … }` tak vznikne `{ name: 'Mléko', total: 48 }`.

Je to zase `map`, jen callback vrací objekt. A tady je past, na které se dá strávit půl hodiny. Šipková funkce se složenými závorkami za šipkou je **tělo funkce**, ne objekt:

```js
// ŠPATNĚ — { } je tělo funkce, nic se nevrací, výsledek je [undefined, undefined]
books.map((book) => { title: book.title });

// SPRÁVNĚ — kulaté závorky řeknou, že { } je hodnota
books.map((book) => ({ title: book.title, long: book.pages > 300 }));
```

Když objekt rovnou vracíš, obal ho kulatými závorkami. Nebo napiš tělo se složenými závorkami a `return`.

Neměň původní položky. Nepřidávej jim klíč `total`, vytvoř nový objekt.

# --hints--

`lineTotals` vrátí pro každou položku objekt s klíči `name` a `total`.

```js
const items = [
  { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false },
  { id: 8, name: 'Čaj', category: 'nápoje', price: 60, quantity: 1, bought: true },
];
assert.deepEqual(lineTotals(items), [
  { name: 'Káva', total: 300 },
  { name: 'Čaj', total: 60 },
]);
```

Pro prázdné pole vrátí `lineTotals` prázdné pole.

```js
const result = lineTotals([]);
assert.ok(Array.isArray(result), 'výsledek má být pole');
assert.equal(result.length, 0);
```

Původní položky zůstanou beze změny (nepřibude jim klíč `total`).

```js
const items = [{ id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false }];
const before = JSON.stringify(items);
lineTotals(items);
assert.equal(JSON.stringify(items), before, 'lineTotals nesmí měnit původní položky');
```

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}
```
