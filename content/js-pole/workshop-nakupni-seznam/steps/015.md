---
title: Jsou takové všechny? every
---

# --description--

Napiš funkci `allBought(items)`, která vrátí `true`, když jsou koupené **všechny** položky. Použij metodu **`every`**.

`every` je zrcadlo `some`: odpoví, jestli podmínku splňují všechny položky, a skončí u první, která ji poruší.

```js
const allShort = books.every((book) => book.pages < 500); // true
```

Teď ta zvláštní část: **nad prázdným polem vrací `every` hodnotu `true`**. Zní to divně, ale je to logické — tvrzení „všechny položky jsou koupené" platí, dokud nenajdeš položku, která koupená není. V prázdném seznamu žádnou takovou nenajdeš. Pro nákupní seznam to dává smysl: prázdný seznam je hotový.

Nepřidávej proto na začátek funkce podmínku, která u prázdného pole vrací `false`.

# --hints--

`allBought` vrátí `true`, když jsou koupené všechny položky.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: true },
];
assert.equal(allBought(items), true, 'obě položky jsou koupené, výsledek má být true');
```

`allBought` vrátí `false`, když aspoň jedna položka koupená není.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: false },
];
assert.equal(allBought(items), false, 'Čaj koupený není, výsledek má být false');
```

Pro prázdné pole vrátí `allBought` hodnotu `true`.

```js
assert.equal(allBought([]), true, 'every nad prázdným polem vrací true — nepřidávej podmínku na prázdné pole');
```
