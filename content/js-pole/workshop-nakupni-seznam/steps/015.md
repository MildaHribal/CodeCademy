# --description--

## Hlášení

Kolega přidal na konec souboru funkci `hasItem(items, id)`. Používá ji tlačítko **Přidat**: když položka se stejným `id` v seznamu už je, aplikace ji nemá přidat podruhé.

Uživatelé hlásí dvě věci:

- Chleba (id `1`, první v seznamu) jde přidat znovu, i když na seznamu je — `hasItem(groceries, 1)` vrací `false`.
- U položky, která na seznamu vůbec není, aplikace tvrdí, že tam už je — `hasItem(groceries, 42)` vrací `true`.

V konzoli žádná chyba není.

## Úkol

Oprav `hasItem` tak, aby vracela `true` právě tehdy, když položka s daným `id` v seznamu je, jinak `false`. Změň co nejmenší kus kódu.

# --hints--

`hasItem` najde i první položku seznamu.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
assert.equal(hasItem(items, 7), true, 'hasItem([Káva (7), Čaj (8)], 7) má vrátit true — Káva je v seznamu na indexu 0');
```

`hasItem` vrátí `false` pro `id`, které v seznamu není.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
assert.equal(hasItem(items, 42), false, 'hasItem([Káva (7), Čaj (8)], 42) má vrátit false');
assert.equal(hasItem([], 7), false, 'hasItem([], 7) má vrátit false');
```

`hasItem` dál najde položku uprostřed i na konci seznamu a vrací `true`, ne index.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }, { id: 9, name: 'Rýže' }];
assert.equal(hasItem(items, 8), true, 'hasItem([Káva, Čaj (8), Rýže], 8) má vrátit true');
assert.equal(hasItem(items, 9), true, 'hasItem([Káva, Čaj, Rýže (9)], 9) má vrátit true');
```

# --help--

## --tip--

Chyba je v podmínce nad výsledkem hledání pozice — viz past [`indexOf` v podmínce](see:js-pole/co-je-pole#indexof-v-podmince).

## --tip--

Podívej se na `if (position)`. Co vrací `findIndex`, když položku najde na prvním místě, a co, když ji nenajde vůbec? Jak se ty dvě hodnoty chovají v podmínce?

## --tip--

Na jiných datech by oprava vypadala takhle: `if (colors.indexOf('red') !== -1)` místo `if (colors.indexOf('red'))`.

# --explain--

Vysvětli vlastními slovy, proč `if (position)` selhalo u první položky i u položky, která v seznamu není.

## --model--

`findIndex` vrací index nalezené položky, nebo `-1`, když nic nenajde. První položka má index `0` a nula je v podmínce nepravda, takže se `if` nespustil, i když položka v seznamu je. Naopak `-1` je nenulové číslo, a tedy pravda, takže chybějící položka prošla jako nalezená. Výsledek hledání pozice se proto porovnává s `-1`, nebo se na otázku ano/ne použije `some`.

## --checklist--

- `findIndex` vrací index, nebo `-1`, když nic nenajde.
- Index `0` je v podmínce nepravda, přestože položka existuje.
- `-1` je v podmínce pravda, přestože položka neexistuje.
- Oprava je porovnat výsledek s `-1`, nebo použít metodu, která vrací rovnou `true`/`false`.

// Nákupní seznam. Každá položka je objekt se stejnými klíči,

const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },

  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}

// Popisky ve tvaru „Rohlíky (6 ks)".
function itemLabels(items) {
  return items.map((item) => `${item.name} (${item.quantity} ks)`);
}

// Položky, které ještě nejsou v košíku.
function toBuy(items) {
  return items.filter((item) => !item.bought);
}

// Vrátí nový seznam bez položky s daným id.
function removeById(items, id) {
  return items.filter((item) => item.id !== id);
}

// Položka s daným id, nebo undefined.
function findItem(items, id) {
  return items.find((item) => item.id === id);
}

// Index položky s daným id, nebo -1.
function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
}

// Od kolegy: je položka s tímhle id už v seznamu?
function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position) {
    return true;
  }
  return false;
}
