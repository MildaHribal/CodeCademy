# --description--

V souboru `script.js` je pole `groceries` — nákupní seznam, se kterým budeš celý workshop pracovat. Každá položka je objekt se stejnými klíči:

- `id` — jednoznačné číslo položky,
- `name` — název,
- `category` — kategorie,
- `price` — cena za jeden kus v korunách,
- `quantity` — kolik kusů koupit,
- `bought` — `true`, když už položka leží v košíku.

Postupně k tomuhle seznamu napíšeš sadu funkcí: přidání, odebrání, hledání, součty, řazení a nakonec výpis do stránky.

Začneš něčím, co už umíš z funkcí a objektů, a to bez návodu.

**Úkol:** Pod pole `groceries` napiš funkci `createItem(id, name, category, price)`, která vrátí **nový objekt** položky ve stejném tvaru, jaký mají položky v `groceries`: s hodnotami z parametrů, s `quantity: 1` a `bought: false`.

# --hints--

`createItem(7, 'Káva', 'nápoje', 150)` vrátí položku se zadanými hodnotami, s `quantity: 1` a `bought: false`.

```js
assert.deepEqual(
  createItem(7, 'Káva', 'nápoje', 150),
  { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 1, bought: false },
  "createItem(7, 'Káva', 'nápoje', 150) má vrátit { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 1, bought: false }",
);
```

Každé zavolání `createItem` vrátí nový objekt.

```js
const first = createItem(8, 'Čaj', 'nápoje', 60);
const second = createItem(8, 'Čaj', 'nápoje', 60);
assert.notEqual(first, second, "dvě volání createItem(8, 'Čaj', 'nápoje', 60) mají vrátit dva různé objekty, ne jeden sdílený");
```

# --help--

## --tip--

Funkce má **vrátit** objekt. Objekt zapíšeš do složených závorek jako dvojice `klíč: hodnota` oddělené čárkou; hodnotou může být i parametr funkce.

## --tip--

Klíče `id`, `name`, `category` a `price` berou hodnotu z parametrů, `quantity` a `bought` mají pevnou hodnotu. Když se jméno parametru shoduje s klíčem, stačí klíč napsat jednou.

## --tip--

Stejný tvar na jiných datech: funkce `createBook(title, pages)` by vracela `{ title, pages, read: false }`.

# --solution--

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}
```
