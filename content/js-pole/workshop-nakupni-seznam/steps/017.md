# --description--

Další krok bez návodu.

Napiš funkci `namesToBuy(items)`, která vrátí **názvy** položek, které ještě nejsou koupené, ve stejném pořadí jako v seznamu. Původní pole se nemění, prázdné pole dá prázdné pole.

Jeden tip: `filter` vrací pole, a na pole se dá zase zavolat metoda. Klidně si ale mezivýsledek ulož do proměnné, jestli se ti to tak líp čte. A možná už máš napsanou funkci, která půlku práce udělá.

# --hints--

`namesToBuy` vrátí názvy nekoupených položek ve stejném pořadí.

```js
const items = [
  { id: 7, name: 'Káva', bought: false },
  { id: 8, name: 'Čaj', bought: true },
  { id: 9, name: 'Rýže', bought: false },
];
assert.deepEqual(namesToBuy(items), ['Káva', 'Rýže']);
```

Pro prázdné pole vrátí `namesToBuy` prázdné pole.

```js
const result = namesToBuy([]);
assert.ok(Array.isArray(result), 'výsledek má být pole');
assert.equal(result.length, 0);
```

Pole, které `namesToBuy` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva', bought: false }, { id: 8, name: 'Čaj', bought: true }];
const before = JSON.stringify(items);
namesToBuy(items);
assert.equal(JSON.stringify(items), before);
```

function removeAt(items, index) {
  return items.toSpliced(index, 1);

  let total = 0;
  for (const item of items) {

function removeById(items, id) {
