# --description--

**Úkol:** Napiš funkci `allBought(items)`, která vrátí `true`, když jsou koupené **všechny** položky, jinak `false`.

Hodí se `every`, zrcadlo `some`: odpoví, jestli podmínku splňují všechny položky, a skončí u první, která ji poruší. Jde to i obráceně přes `some` — „není tam žádná nekoupená". Vyber, co se ti čte líp.

```js
// 1. mají všechny knihy méně než 500 stran?
const allShort = books.every((book) => book.pages < 500);
```

> [!PITFALL]
> **Nad prázdným polem vrací `every` hodnotu `true`.** Tvrzení „všechny položky jsou koupené" platí, dokud nenajdeš položku, která koupená není — a v prázdném seznamu žádnou nenajdeš. Pro nákupní seznam to dává smysl: prázdný seznam je hotový. Nepřidávej proto podmínku, která u prázdného pole vrací `false`.

# --hints--

`allBought` vrátí `true`, když jsou koupené všechny položky.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: true },
];
assert.equal(allBought(items), true, 'allBought([koupená Káva, koupený Čaj]) má vrátit true');
```

`allBought` vrátí `false`, když aspoň jedna položka koupená není.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: false },
];
assert.equal(allBought(items), false, 'allBought([koupená Káva, nekoupený Čaj]) má vrátit false');
```

Pro prázdné pole vrátí `allBought` hodnotu `true`.

```js
assert.equal(allBought([]), true, 'allBought([]) má vrátit true — prázdný seznam je hotový; nepřidávej podmínku na prázdné pole');
```

# --help--

## --tip--

Otázka „platí to pro všechny?" — viz řádek `some` / `every` v tabulce [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Vrať výsledek `every` s predikátem „položka je koupená". Nic víc, ani podmínku na délku pole.

## --tip--

Na jiných datech: `students.every((student) => student.passed)` odpoví, jestli prošli všichni studenti.

}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}

// Popisky ve tvaru „Rohlíky (6 ks)".
function itemLabels(items) {
  return items.map((item) => `${item.name} (${item.quantity} ks)`);
}

// Položky, které ještě nejsou v košíku.
function toBuy(items) {
  return items.filter((item) => !item.bought);
}

// Vrátí nový seznam bez položky s daným id.
function removeById(items, id) {
  return items.filter((item) => item.id !== id);
}

// Položka s daným id, nebo undefined.
function findItem(items, id) {
  return items.find((item) => item.id === id);
}

// Index položky s daným id, nebo -1.
function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
}

// Od kolegy: je položka s tímhle id už v seznamu?
function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position !== -1) {
    return true;
  }
  return false;
}

// Je v seznamu aspoň jedna nekoupená položka?
function hasUnbought(items) {
  return items.some((item) => !item.bought);
