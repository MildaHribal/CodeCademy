# --description--

Napiš funkci `addItem(items, item)`, která vrátí **nové** pole: všechny položky z `items` a na konci `item`. Pole `items` přitom nesmí změnit.

Nabízí se `items.push(item)`. Jenže `push` **mění pole na místě** — přidá položku do toho pole, které funkce dostala. A to pole patří někomu jinému. Třeba ho zrovna vykresluje stránka nebo si ho někdo drží jako „stav před změnou", aby šlo změnu vrátit. Funkce, která mu ho potichu přepíše, způsobí chybu, která se projeví úplně jinde.

Proto postav nové pole. Nejkratší cesta je **rozprostření** (*spread*): tři tečky před polem „vysypou" jeho položky do nových hranatých závorek. Na jiných datech:

```js
const playlist = ['Intro', 'Refrén'];
const longer = [...playlist, 'Outro'];

longer;   // ['Intro', 'Refrén', 'Outro']
playlist; // ['Intro', 'Refrén'] — beze změny
```

Rozprostřít jde kamkoli do závorek, takže `['Úvod', ...playlist]` přidá položku na začátek.

# --hints--

`addItem` vrátí pole, které má všechny původní položky a na konci novou položku.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const result = addItem([coffee, tea], rice);
assert.ok(Array.isArray(result), 'addItem má vrátit pole');
assert.equal(result.length, 3);
assert.equal(result[0], coffee);
assert.equal(result[1], tea);
assert.equal(result[2], rice, 'nová položka má být na konci');
```

Pole, které `addItem` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
const before = JSON.stringify(items);
addItem(items, { id: 9, name: 'Rýže' });
assert.equal(JSON.stringify(items), before, 'addItem nesmí měnit pole, které dostala');
```

`addItem` vrací nové pole, ne to, které dostala.

```js
const items = [{ id: 7, name: 'Káva' }];
const result = addItem(items, { id: 8, name: 'Čaj' });
assert.notEqual(result, items, 'výsledek má být nové pole');
```

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}
```
