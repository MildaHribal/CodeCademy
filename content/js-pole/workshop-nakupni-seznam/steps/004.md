# --description--

**Úkol:** Napiš funkci `lastItem(items)`, která vrátí poslední položku pole. Pole přitom neměň.

U první položky jsi věděl, že má index `0`. Poslední položka ale nemá pevný index — záleží na tom, jak je pole dlouhé. Délku pole najdeš ve vlastnosti **`length`**. Protože se indexy počítají od nuly, poslední položka má index `length - 1`. Na jiných datech:

```js
const genres = ['román', 'detektivka', 'poezie'];

// 1. délka pole
const count = genres.length;

// 2. poslední položka je o jedna níž než délka
const lastGenre = genres[genres.length - 1];
```

Totéž jde napsat kratší metodou `at`, která u záporného čísla počítá od konce: `genres.at(-1)`. Použij, co je ti bližší.

> [!PITFALL]
> `genres[genres.length]` vrátí `undefined`, ne poslední položku — index `length` už je za koncem pole. A `pop()` poslední položku sice vrátí, ale zároveň ji z pole **odebere**.

U prázdného pole má `lastItem` vrátit `undefined`. Rozmysli si, jestli to tvoje řešení udělá samo: `length - 1` je u prázdného pole `-1`, a co vrátí `items[-1]`?

# --hints--

`lastItem` vrátí poslední položku pole.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
assert.equal(lastItem([coffee, tea, rice]), rice, 'lastItem([Káva, Čaj, Rýže]) má vrátit položku Rýže');
```

U pole s jedinou položkou vrátí `lastItem` tu jedinou položku.

```js
const coffee = { id: 7, name: 'Káva' };
assert.equal(lastItem([coffee]), coffee, 'lastItem([Káva]) má vrátit položku Káva');
```

Pro prázdné pole vrátí `lastItem` hodnotu `undefined`.

```js
assert.equal(lastItem([]), undefined, 'lastItem([]) má vrátit undefined');
```

Pole, které `lastItem` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
lastItem(items);
assert.equal(items.length, 2, 'lastItem([Káva, Čaj]) nesmí z pole nic odebrat — po zavolání má mít pořád 2 položky');
```

# --help--

## --tip--

Poslední index závisí na délce pole — viz [Pole je očíslovaný seznam hodnot](see:js-pole/co-je-pole#pole-je-ocislovany-seznam-hodnot).

## --tip--

Vrať položku na indexu spočítaném z `items.length`, nebo použij metodu `at` se záporným číslem.

## --tip--

Na jiných datech: předposlední žánr je `genres[genres.length - 2]` nebo `genres.at(-2)`.

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}
```
