# --description--

**Úkol:** Napiš funkci `isKnownCategory(category)`, která vrátí `true`, když je `category` v poli `categories` z druhého kroku, jinak `false`. Porovnává se přesně, i velikost písmen.

`some`, `find` a `findIndex` hledají podle podmínky. Když ale hledáš **konkrétní hodnotu** v poli textů nebo čísel, stačí jednodušší nástroj. Kandidáti:

- `includes(hodnota)` — vrátí rovnou `true`/`false`,
- `indexOf(hodnota)` — vrátí index nebo `-1`, takže ho musíš porovnat.

```js
const genres = ['román', 'detektivka', 'poezie'];

// 1. je poezie mezi žánry?
const hasPoetry = genres.includes('poezie');
```

> [!PITFALL]
> `if (categories.indexOf(category))` nenajde `'pečivo'`, protože je na indexu `0` — stejná past jako v kolegově `hasItem`. Kontrola proto zkouší i první kategorii.

Tahle funkce výjimečně nedostává pole v parametru — seznam kategorií je pro celý obchod jen jeden, takže sáhni přímo do `categories`.

# --hints--

`isKnownCategory` vrátí `true` pro kategorii ze seznamu `categories`, i pro tu první.

```js
assert.equal(isKnownCategory('drogerie'), true, "isKnownCategory('drogerie') má vrátit true");
assert.equal(isKnownCategory('pečivo'), true, "isKnownCategory('pečivo') má vrátit true — 'pečivo' je v poli první, na indexu 0");
```

`isKnownCategory` vrátí `false` pro kategorii, která v seznamu není.

```js
assert.equal(isKnownCategory('maso'), false, "isKnownCategory('maso') má vrátit false — 'maso' v poli categories není");
```

`isKnownCategory` rozlišuje velká a malá písmena.

```js
assert.equal(isKnownCategory('Pečivo'), false, "isKnownCategory('Pečivo') má vrátit false — s velkým P v poli není, porovnává se přesně");
```

# --help--

## --tip--

Hledáš hodnotu, ne podmínku — a pozor na index `0`, viz [`indexOf` v podmínce](see:js-pole/co-je-pole#indexof-v-podmince).

## --tip--

Zavolej na `categories` metodu, která dostane hledanou hodnotu a vrátí `true`/`false`, a výsledek vrať.

## --tip--

Na jiných datech: `allowedColors.includes(color)` odpoví, jestli je barva povolená.

}

  return items.filter((item) => !item.bought);

function removeById(items, id) {
  return items.filter((item) => item.id !== id);

function findItem(items, id) {
  return items.find((item) => item.id === id);
}

function indexById(items, id) {
  return items.findIndex((item) => item.id === id);

  if (position !== -1) {
    return true;

  return false;

}
