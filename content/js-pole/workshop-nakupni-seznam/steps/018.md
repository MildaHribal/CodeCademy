# --description--

Napiš funkci `totalPrice(items)`, která vrátí cenu celého nákupu: součet `price * quantity` přes všechny položky. Prázdný seznam stojí `0`. Použij metodu **`reduce`**.

`map` z pole udělá pole, `filter` taky pole. `reduce` z pole udělá **jednu hodnotu** — číslo, text, objekt, cokoli. Zápis:

```js
const pages = books.reduce((sum, book) => sum + book.pages, 0);
```

- Callback dostane **akumulátor** (tady `sum`) a aktuální položku (`book`). Vrací **novou hodnotu akumulátoru**.
- `0` na konci **není součást callbacku**. Je to druhý argument `reduce` — počáteční hodnota akumulátoru. Snadno se přehlédne, protože stojí až za závorkou callbacku.

Průběh pro dvě knihy: `sum` začne na `0`, po první knize je `280`, po druhé `590`. To poslední `reduce` vrátí.

Počáteční hodnotu piš vždycky. Bez ní `reduce` vezme jako akumulátor první položku pole — u pole objektů to dá nesmysl a u prázdného pole to spadne.

# --hints--

`totalPrice` vrátí součet `price * quantity` všech položek.

```js
const items = [
  { id: 7, name: 'Káva', price: 150, quantity: 2 },
  { id: 8, name: 'Čaj', price: 60, quantity: 1 },
  { id: 9, name: 'Rýže', price: 35, quantity: 3 },
];
assert.equal(totalPrice(items), 465, '2 × 150 + 1 × 60 + 3 × 35 = 465');
```

Pro prázdné pole vrátí `totalPrice` číslo `0`.

```js
assert.equal(totalPrice([]), 0);
```

`totalPrice` používá metodu `reduce`.

```js
const source = helpers.stripComments(totalPrice.toString(), 'js');
assert.match(source, /\.reduce\s*\(/, 'v totalPrice chybí volání .reduce(…)');
```

function removeAt(items, index) {
  return items.toSpliced(index, 1);

  let total = 0;

}

function removeById(items, id) {
