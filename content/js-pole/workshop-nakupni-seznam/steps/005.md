# --description--

Napiš funkci `removeAt(items, index)`, která vrátí nové pole bez položky na indexu `index`. Původní pole zase nesmí změnit.

Na vyříznutí položky z pole existuje metoda `splice` — ale ta patří do stejné skupiny jako `push`: **mutuje**. Vyřízne položky přímo z původního pole.

Její nemutující dvojče je **`toSpliced`**. Bere stejné argumenty — index, od kterého začít, a kolik položek odebrat — ale neupravuje původní pole, vrátí upravenou kopii. Na jiných datech:

```js
const queue = ['Anna', 'Bedřich', 'Cyril', 'Dana'];

queue.toSpliced(0, 2);        // ['Cyril', 'Dana'] — bez prvních dvou
queue.toSpliced(1, 0, 'Eva'); // ['Anna', 'Eva', 'Bedřich', 'Cyril', 'Dana'] — nic neodebere, vloží
queue;                        // pořád všichni čtyři
```

Starší kód to samé dělá přes `slice`, který vrací výřez pole: `[...queue.slice(0, 1), ...queue.slice(2)]`. Taky správně, jen se to hůř čte.

# --hints--

`removeAt` vrátí pole bez položky na zadaném indexu.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const result = removeAt([coffee, tea, rice], 1);
assert.ok(Array.isArray(result), 'removeAt má vrátit pole');
assert.equal(result.length, 2);
assert.equal(result[0], coffee);
assert.equal(result[1], rice);
```

`removeAt` umí odebrat první i poslední položku.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const withoutFirst = removeAt([coffee, tea, rice], 0);
assert.equal(withoutFirst.length, 2);
assert.equal(withoutFirst[0], tea, 'po odebrání indexu 0 má být první Čaj');
const withoutLast = removeAt([coffee, tea, rice], 2);
assert.equal(withoutLast.length, 2);
assert.equal(withoutLast[1], tea, 'po odebrání indexu 2 má být poslední Čaj');
```

Pole, které `removeAt` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }, { id: 9, name: 'Rýže' }];
const before = JSON.stringify(items);
const result = removeAt(items, 1);
assert.equal(JSON.stringify(items), before, 'removeAt nesmí měnit pole, které dostala');
assert.notEqual(result, items, 'výsledek má být nové pole');
```

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}
```
