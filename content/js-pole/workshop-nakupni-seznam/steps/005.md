# --description--

**Úkol:** Napiš funkci `addItem(items, item)`, která vrátí **nové** pole: všechny položky z `items` a na konci `item`. Pole `items` přitom nesmí změnit.

Nabízí se `items.push(item)`. Jenže `push` je [[mutující metoda]] — přidá položku do toho pole, které funkce dostala. A to pole patří někomu jinému. Třeba ho zrovna vykresluje stránka nebo si ho někdo drží jako „stav před změnou", aby šlo změnu vrátit.

> [!PITFALL]
> `return items.push(item);` nevrátí pole, ale **novou délku** pole (číslo). A i `items.push(item); return items;` je špatně: vrátí správné položky, ale původní pole volajícího se změní taky.

Proto postav nové pole. Nejkratší cesta je rozprostření (*spread*): tři tečky před polem „vysypou" jeho položky do nových hranatých závorek. Na jiných datech:

```js
const playlist = ['Intro', 'Refrén'];

// 1. nové pole: položky playlistu a na konci další skladba
const longer = [...playlist, 'Outro'];
```

`playlist` po tomhle řádku zůstane, jak byl. Rozprostřít jde kamkoli do závorek, takže `['Úvod', ...playlist]` přidá položku na začátek.

# --hints--

`addItem` vrátí pole, které má všechny původní položky a na konci novou položku.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const result = addItem([coffee, tea], rice);
assert.ok(Array.isArray(result), 'addItem([Káva, Čaj], Rýže) má vrátit pole');
assert.deepEqual(result, [coffee, tea, rice], 'addItem([Káva, Čaj], Rýže) má vrátit [Káva, Čaj, Rýže] — nová položka na konci');
assert.equal(result[2], rice, 'addItem([Káva, Čaj], Rýže) má na konec dát tentýž objekt Rýže, ne jeho kopii');
```

Pole, které `addItem` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
addItem(items, { id: 9, name: 'Rýže' });
assert.equal(items.length, 2, 'addItem([Káva, Čaj], Rýže) nesmí přidávat do původního pole — to má mít pořád 2 položky');
```

`addItem` vrací nové pole, ne to, které dostala.

```js
const items = [{ id: 7, name: 'Káva' }];
const result = addItem(items, { id: 8, name: 'Čaj' });
assert.notEqual(result, items, 'addItem([Káva], Čaj) má vrátit nové pole, ne původní pole items');
```

# --help--

## --tip--

Jde o vytvoření nového pole místo změny starého — viz [Kopie pole](see:js-pole/co-je-pole#kopie-pole).

## --tip--

V `return` postav nové pole v hranatých závorkách: nejdřív do něj rozprostři položky z `items`, pak přidej `item`.

## --tip--

Na jiných datech: nový seznam hostů s hostem navíc je `[...guests, newGuest]`.

# --explain--

Vysvětli vlastními slovy, proč `addItem` nesmí použít `items.push(item)`, i když by po `push` pole obsahovalo správné položky.

## --model--

`push` mění pole, na kterém ho zavolám, a `items` je jen odkaz na pole volajícího. Funkce by tak potichu změnila cizí data, třeba seznam, který se právě vykresluje, nebo uložený stav pro tlačítko Zpět. Navíc `push` vrací novou délku, ne pole. Proto vytvořím nové pole přes `[...items, item]` a původní nechám být.

## --checklist--

- `push` mění původní pole, nevytváří nové.
- Parametr `items` ukazuje na pole volajícího, takže změna je vidět i u něj.
- `push` vrací novou délku pole, ne pole.
- Nové pole vytvoří spread `[...items, item]`.

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}
```
