# --description--

Napiš funkci `itemNames(items)`, která vrátí pole názvů všech položek ve stejném pořadí. Použij metodu **`map`**.

Tohle je nejčastější práce s polem vůbec: z každé položky udělat něco jiného a výsledky mít zase v poli. S `for…of` bys založil prázdné pole a v cyklu do něj přidával. `map` to udělá za tebe.

`map` zavoláš na poli a předáš mu **funkci**, která říká, co udělat s **jednou** položkou. `map` ji zavolá pro každou položku a to, co funkce vrátí, poskládá do nového pole. Na jiných datech:

```js
const books = [
  { title: 'Krakatit', pages: 280 },
  { title: 'Babička', pages: 310 },
];

const pageCounts = books.map((book) => book.pages);
// [280, 310]
```

Výsledek má vždycky **stejnou délku** jako původní pole a původní pole zůstane beze změny. Prázdné pole dá prázdné pole.

Funkci, kterou předáváš jiné funkci, se říká *callback*. Víc o callbackách v lekci po workshopu.

# --hints--

`itemNames` vrátí pole názvů položek ve stejném pořadí.

```js
const items = [
  { id: 7, name: 'Káva', quantity: 2 },
  { id: 8, name: 'Čaj', quantity: 3 },
];
assert.deepEqual(itemNames(items), ['Káva', 'Čaj']);
```

Pro prázdné pole vrátí `itemNames` prázdné pole.

```js
const result = itemNames([]);
assert.ok(Array.isArray(result), 'výsledek má být pole');
assert.equal(result.length, 0);
```

`itemNames` používá metodu `map`.

```js
const source = helpers.stripComments(itemNames.toString(), 'js');
assert.match(source, /\.map\s*\(/, 'v itemNames chybí volání .map(…)');
```

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}
```
