# --description--

**Úkol:** Seřaď řádky tak, aby `countByCategory(items)` vrátila objekt, kde klíčem je kategorie a hodnotou **počet položek** v ní. Ze seznamu `groceries` tak vznikne `{ 'pečivo': 2, 'mléčné výrobky': 2, 'ovoce a zelenina': 1, 'drogerie': 1 }`.

Je to `reduce`, jehož [[akumulátor]] není číslo, ale objekt, který se postupně plní. Takový vzor vidíš poprvé, proto ho tentokrát jen skládáš; v dalším kroku ho napíšeš sám.

Přetáhni řádky ve správném pořadí, odsazení nastavíš klávesou Tab a do mezery doplň počáteční hodnotu akumulátoru. Dva řádky jsou navíc — patří k typickým chybám.

# --hints--

`countByCategory` vrátí počet položek v každé kategorii.

```js
const items = [
  { id: 7, name: 'Káva', category: 'nápoje', quantity: 2 },
  { id: 8, name: 'Čaj', category: 'nápoje', quantity: 1 },
  { id: 9, name: 'Rýže', category: 'přílohy', quantity: 3 },
];
assert.deepEqual(countByCategory(items), { 'nápoje': 2, 'přílohy': 1 }, "countByCategory([Káva (nápoje), Čaj (nápoje), Rýže (přílohy)]) má vrátit { nápoje: 2, přílohy: 1 } — počítají se položky, ne kusy");
```

Pro prázdné pole vrátí `countByCategory` prázdný objekt.

```js
const result = countByCategory([]);
assert.equal(typeof result, 'object', 'countByCategory([]) má vrátit objekt');
assert.ok(result !== null, 'countByCategory([]) nemá vrátit null');
assert.deepEqual(Object.keys(result), [], 'countByCategory([]) má vrátit objekt bez klíčů');
```

# --help--

## --tip--

Jde o `reduce` s objektem jako akumulátorem — viz [Akumulátor nemusí být číslo](see:js-pole/metody-pole-do-hloubky#akumulator-nemusi-byt-cislo).

## --tip--

Callback musí akumulátor na konci **vrátit**, jinak ho další volání nedostane. Když kategorie přijde poprvé, její počet je `undefined` a `undefined + 1` je `NaN`.

# --parsons--

```js
function countByCategory(items) {
  return items.reduce((counts, item) => {
    counts[item.category] = (counts[item.category] ?? 0) + 1;
    return counts;
  }, __1__);
}
```

## --distractors--

```js
counts[item.category] = counts[item.category] + 1;
return counts[item.category];
```

function firstItem(items) {

function addItem(items, item) {

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {

function lineTotals(items) {

}

function itemLabels(items) {

function toBuy(items) {
  return items.filter((item) => !item.bought);

function removeById(items, id) {
  return items.filter((item) => item.id !== id);

function findItem(items, id) {
  return items.find((item) => item.id === id);

function indexById(items, id) {
  return items.findIndex((item) => item.id === id);

function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position !== -1) {
    return true;
  }
  return false;
}

function priciestItem(items) {
  let priciest;
  for (const item of items) {
    if (priciest === undefined || item.price * item.quantity > priciest.price * priciest.quantity) {
      priciest = item;
    }
  }
  return priciest;
