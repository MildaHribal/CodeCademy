---
title: Je tam aspoň jedna? some
---

# --description--

Napiš funkci `hasUnbought(items)`, která vrátí `true`, když je v seznamu **aspoň jedna** nekoupená položka, jinak `false`. Použij metodu **`some`**.

Na otázku „je tam aspoň jedna taková?" by šlo odpovědět přes `filter(…).length > 0`. Funguje to, ale projde to celé pole, postaví zbytečné nové pole a čtenář musí domýšlet, že tě zajímalo jen ano/ne. `some` odpoví rovnou `true` nebo `false` a zastaví se u první položky, která podmínku splní.

```js
const hasLongBook = books.some((book) => book.pages > 300); // true
```

Nad prázdným polem vrací `some` vždycky `false` — není tam žádná položka, která by podmínku splnila.

# --hints--

`hasUnbought` vrátí `true`, když je aspoň jedna položka nekoupená.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: false },
];
assert.equal(hasUnbought(items), true, 'Čaj není koupený, výsledek má být true');
```

`hasUnbought` vrátí `false`, když je všechno koupené.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: true },
];
assert.equal(hasUnbought(items), false, 'všechno je koupené, výsledek má být false');
```

Pro prázdné pole vrátí `hasUnbought` hodnotu `false`.

```js
assert.equal(hasUnbought([]), false, 'prázdný seznam nemá žádnou nekoupenou položku');
```
