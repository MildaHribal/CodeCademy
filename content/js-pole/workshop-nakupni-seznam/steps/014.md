# --description--

**Úkol:** Napiš funkci `indexById(items, id)`, která vrátí index položky s daným `id`. Když taková není, vrátí `-1`.

Nabízejí se dvě metody se skoro stejným jménem — vyber tu, která se hodí na pole objektů:

- `indexOf(hodnota)` hledá **hodnotu** a porovnává ji přes `===`. V poli objektů hledá tentýž objekt, ne objekt se stejným `id`.
- `findIndex(predikát)` je `find`, který místo položky vrací její pořadí. Hledá podle **podmínky**, kterou si napíšeš.

Pozor na jedinou nekonzistenci: nenalezený `find` vrací `undefined`, nenalezený `findIndex` vrací **`-1`**.

> [!PITFALL]
> První položka má index `0` a nula je v podmínce nepravda. `if (indexById(items, id))` proto první položku „nenajde" a chybějící (`-1`) „najde". Výsledek hledání pozice porovnávej s `-1`. Kontrola proto zkouší i první položku.

# --hints--

`indexById` vrátí index položky se zadaným `id`.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }, { id: 9, name: 'Rýže' }];
assert.equal(indexById(items, 9), 2, 'indexById([Káva (7), Čaj (8), Rýže (9)], 9) má vrátit 2');
```

Pro první položku vrátí `indexById` číslo `0`.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
assert.equal(indexById(items, 7), 0, 'indexById([Káva (7), Čaj (8)], 7) má vrátit 0 — první položka má index 0');
```

S neexistujícím `id` vrátí `indexById` číslo `-1`.

```js
assert.equal(indexById([{ id: 7, name: 'Káva' }], 42), -1, 'indexById([Káva (7)], 42) má vrátit -1');
assert.equal(indexById([], 7), -1, 'indexById([], 7) má vrátit -1 — v prázdném poli se nic nenajde');
```

# --help--

## --tip--

Hledáš pozici podle podmínky — viz řádek `findIndex` v tabulce [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

`indexOf` na pole objektů nestačí. Vrať výsledek metody, která dostane predikát a vrací index nebo `-1`.

## --tip--

Na jiných datech: pozice první nepřečtené zprávy je `messages.findIndex((message) => !message.read)`.
