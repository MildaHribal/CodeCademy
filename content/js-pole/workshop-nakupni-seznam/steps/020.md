# --description--

**Úkol:** Napiš funkci `sortedByPrice(items)`, která vrátí nové pole seřazené podle `price` od nejlevnější položky. Původní pole se nesmí změnit.

Na řazení má pole dvě metody. Starší `sort` má dvě zrádné vlastnosti:

1. **`sort` mutuje.** Přerovná přímo pole, na kterém ho zavoláš, a vrátí to samé pole. Seřazení seznamu uvnitř funkce by přeházelo pořadí i tomu, kdo funkci zavolal.
2. **Bez porovnávací funkce řadí jako text.** Čísla 9, 100 a 25 seřadí na 100, 25, 9, protože text `'100'` začíná jedničkou.

Novější `toSorted` řeší první problém: vrátí seřazenou kopii. Druhý problém řeší [[porovnávací funkce]] (*compare function*): dostane dvě položky `a` a `b` a vrátí číslo —

- **záporné**, když `a` patří před `b`,
- **kladné**, když `a` patří za `b`,
- **nulu**, když je pořadí jedno.

Na čísla to nejjednodušeji udělá odečet. Na jiných datech:

```js
// 1. nejkratší knihy první
const shortestFirst = books.toSorted((a, b) => a.pages - b.pages);

// 2. prohozené a a b = sestupně
const longestFirst = books.toSorted((a, b) => b.pages - a.pages);
```

Ve starším kódu uvidíš totéž jako `[...books].sort(…)` — nejdřív kopie, pak řazení kopie.

# --hints--

`sortedByPrice` vrátí položky seřazené podle ceny od nejnižší (čísla řadí jako čísla, ne jako text).

```js
const coffee = { id: 7, name: 'Káva', price: 9 };
const tea = { id: 8, name: 'Čaj', price: 100 };
const rice = { id: 9, name: 'Rýže', price: 25 };
const result = sortedByPrice([coffee, tea, rice]);
assert.ok(Array.isArray(result), 'sortedByPrice má vrátit pole');
assert.deepEqual(result.map((item) => item.price), [9, 25, 100], 'sortedByPrice pro ceny 9, 100 a 25 má vrátit pořadí cen 9, 25, 100');
```

Pole, které `sortedByPrice` dostane, zůstane v původním pořadí.

```js
const items = [
  { id: 7, name: 'Káva', price: 150 },
  { id: 8, name: 'Čaj', price: 60 },
  { id: 9, name: 'Rýže', price: 35 },
];
const result = sortedByPrice(items);
assert.deepEqual(items.map((item) => item.id), [7, 8, 9], 'sortedByPrice([Káva, Čaj, Rýže]) nesmí přerovnat původní pole — id mají zůstat 7, 8, 9');
assert.notEqual(result, items, 'sortedByPrice má vrátit nové pole, ne původní pole items');
```

# --help--

## --tip--

Jde o řazení s porovnávací funkcí bez mutace — viz [Řazení a porovnávací funkce](see:js-pole/metody-pole-do-hloubky#razeni-a-porovnavaci-funkce).

## --tip--

Zavolej na `items` metodu, která vrací seřazenou kopii, a předej jí porovnávací funkci, která odečte ceny dvou položek.

## --tip--

Na jiných datech: studenti od nejvíc bodů jsou `students.toSorted((a, b) => b.points - a.points)`.

# --explain--

Vysvětli vlastními slovy, proč v `sortedByPrice` nestačí `items.sort((a, b) => a.price - b.price)`, i když vrátí správně seřazené pole.

## --model--

`sort` řadí přímo pole, na kterém ho zavolám, a `items` je odkaz na pole volajícího. Funkce by tak vrátila správné pořadí, ale zároveň by přeházela i původní seznam, třeba ten, který se zobrazuje v pořadí přidání. `toSorted` vrátí seřazenou kopii a původní pole nechá být. Porovnávací funkce `a.price - b.price` vrací záporné číslo, když má levnější položka jít první.

## --checklist--

- `sort` mutuje pole, na kterém ho zavolám.
- `items` ukazuje na pole volajícího, takže by se přerovnalo i jemu.
- `toSorted` vrací seřazenou kopii.
- Porovnávací funkce vrací záporné číslo, když `a` patří před `b`.

}

function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}

// Popisky ve tvaru „Rohlíky (6 ks)".
function itemLabels(items) {
  return items.map((item) => `${item.name} (${item.quantity} ks)`);
}

// Položky, které ještě nejsou v košíku.
function toBuy(items) {
  return items.filter((item) => !item.bought);
}

// Vrátí nový seznam bez položky s daným id.
function removeById(items, id) {
  return items.filter((item) => item.id !== id);
}

// Položka s daným id, nebo undefined.
function findItem(items, id) {
  return items.find((item) => item.id === id);
}

// Index položky s daným id, nebo -1.
function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
}

// Od kolegy: je položka s tímhle id už v seznamu?
function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position !== -1) {
    return true;
  }
  return false;
}

// Je v seznamu aspoň jedna nekoupená položka?
function hasUnbought(items) {
  return items.some((item) => !item.bought);
}

// Jsou koupené všechny položky? U prázdného seznamu ano.
function allBought(items) {
  return items.every((item) => item.bought);
}

// Zná obchod tuhle kategorii?
function isKnownCategory(category) {
  return categories.includes(category);
}
