# --description--

Napiš funkci `sortedByPrice(items)`, která vrátí nové pole seřazené podle `price` od nejlevnější položky. Původní pole se nesmí změnit. Použij metodu **`toSorted`** s porovnávací funkcí.

Pole má i starší metodu `sort` a ta má dvě zrádné vlastnosti:

1. **`sort` mutuje.** Přerovná přímo pole, na kterém ho zavoláš, a vrátí to samé pole. Seřazení seznamu uvnitř funkce by tak přeházelo pořadí i tomu, kdo funkci zavolal.
2. **Bez porovnávací funkce řadí jako text.** `[9, 100, 25].sort()` vrátí `[100, 25, 9]`, protože text `'100'` začíná jedničkou.

`toSorted` řeší první problém: vrátí seřazenou kopii. Druhý problém řeší **porovnávací funkce** (*comparator*): dostane dvě položky `a` a `b` a vrátí číslo —

- **záporné**, když `a` patří před `b`,
- **kladné**, když `a` patří za `b`,
- **nulu**, když je pořadí jedno.

Na čísla to nejjednodušeji udělá odečet. Na jiných datech:

```js
const shortestFirst = books.toSorted((a, b) => a.pages - b.pages);
const longestFirst = books.toSorted((a, b) => b.pages - a.pages);
```

`a - b` je vzestupně, prohozené pořadí je sestupně. Ve starším kódu uvidíš totéž jako `[...books].sort(…)`.

# --hints--

`sortedByPrice` vrátí položky seřazené podle ceny od nejnižší (čísla řadí jako čísla, ne jako text).

```js
const items = [
  { id: 7, name: 'Káva', price: 9 },
  { id: 8, name: 'Čaj', price: 100 },
  { id: 9, name: 'Rýže', price: 25 },
];
const result = sortedByPrice(items);
assert.ok(Array.isArray(result), 'sortedByPrice má vrátit pole');
assert.deepEqual(result.map((item) => item.price), [9, 25, 100]);
```

Pole, které `sortedByPrice` dostane, zůstane v původním pořadí.

```js
const items = [
  { id: 7, name: 'Káva', price: 150 },
  { id: 8, name: 'Čaj', price: 60 },
  { id: 9, name: 'Rýže', price: 35 },
];
const result = sortedByPrice(items);
assert.deepEqual(items.map((item) => item.id), [7, 8, 9], 'původní pole se nesmí přerovnat');
assert.notEqual(result, items, 'výsledek má být nové pole');
```

function addItem(items, item) {

function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {

}

function removeById(items, id) {

function findItem(items, id) {

function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
