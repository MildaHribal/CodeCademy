# --description--

**Úkol:** Napiš funkci `firstItem(items)`, která vrátí první položku pole `items`. Pole přitom neměň.

K položkám pole se dostaneš přes [[index]] — pořadové číslo v hranatých závorkách. Indexy se počítají **od nuly**, takže první položka má index `0`, druhá `1` a tak dál. Na jiných datech:

```js
const genres = ['román', 'detektivka', 'poezie'];

// 1. druhá položka má index 1
const second = genres[1];

// 2. index, který v poli není, vrátí undefined
const missing = genres[7];
```

Proč funkce dostává pole v parametru a nesahá rovnou na `groceries`? Protože pak funguje s jakýmkoli seznamem — s nákupem na zítřek, se seznamem z jiného obchodu i s daty, na kterých ji zkouší testy. Všechny funkce v tomhle workshopu budou psané takhle.

Když je pole prázdné, index `0` v něm neexistuje a výsledek je `undefined`. S tím nemusíš nic dělat, JavaScript to udělá sám.

> [!TIP]
> Funkci si můžeš vyzkoušet: pod ni napiš `console.log(firstItem(groceries));` a podívej se do konzole. Až to uvidíš, výpis zase smaž.

# --hints--

`firstItem` vrátí první položku pole, které dostane.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
assert.equal(firstItem([coffee, tea]), coffee, 'firstItem([Káva, Čaj]) má vrátit položku Káva');
```

Pro prázdné pole vrátí `firstItem` hodnotu `undefined`.

```js
assert.equal(firstItem([]), undefined, 'firstItem([]) má vrátit undefined');
```

Pole, které `firstItem` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
firstItem(items);
assert.equal(items.length, 2, 'firstItem([Káva, Čaj]) nesmí z pole nic odebrat — po zavolání má mít pořád 2 položky');
```

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}
```
