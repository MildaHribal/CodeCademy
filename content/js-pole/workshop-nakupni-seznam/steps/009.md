# --description--

**Úkol:** Napiš funkci `lineTotals(items)`, která z každé položky udělá **nový objekt** se dvěma klíči: `name` (název položky) a `total` (cena za všechny kusy, tedy `price * quantity`).

Z položky `{ id: 2, name: 'Mléko', price: 24, quantity: 2, … }` tak vznikne `{ name: 'Mléko', total: 48 }`.

Je to zase `map`, jen callback vrací objekt. A tady je past, na které se dá strávit půl hodiny:

> [!PITFALL]
> Šipková funkce se složenými závorkami za šipkou má **tělo funkce**, ne objekt. `books.map((book) => { title: book.title })` vrátí `[undefined, undefined]` — `{ }` je tělo a nic se nevrací. Oprava: obal objekt kulatými závorkami, nebo napiš `return`.

Na jiných datech:

```js
// 1. kulaté závorky řeknou, že { } je hodnota, ne tělo funkce
const summaries = books.map((book) => ({ title: book.title, long: book.pages > 300 }));
```

Neměň původní položky. Nepřidávej jim klíč `total`, vytvoř nový objekt.

# --hints--

`lineTotals` vrátí pro každou položku objekt s klíči `name` a `total`.

```js
const items = [
  { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false },
  { id: 8, name: 'Čaj', category: 'nápoje', price: 60, quantity: 1, bought: true },
];
assert.deepEqual(
  lineTotals(items),
  [{ name: 'Káva', total: 300 }, { name: 'Čaj', total: 60 }],
  "lineTotals pro Kávu (150 Kč × 2) a Čaj (60 Kč × 1) má vrátit [{ name: 'Káva', total: 300 }, { name: 'Čaj', total: 60 }]",
);
```

Pro prázdné pole vrátí `lineTotals` prázdné pole.

```js
assert.deepEqual(lineTotals([]), [], 'lineTotals([]) má vrátit prázdné pole []');
```

Původní položky zůstanou beze změny (nepřibude jim klíč `total`).

```js
const coffee = { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false };
lineTotals([coffee]);
assert.deepEqual(
  Object.keys(coffee),
  ['id', 'name', 'category', 'price', 'quantity', 'bought'],
  'lineTotals([Káva]) nesmí měnit původní položku — Káva má mít pořád jen svých šest klíčů',
);
```

# --help--

## --tip--

Jde o `map`, jehož callback vrací objekt — viz [Zapomenutý `return` ve složených závorkách](see:js-pole/metody-pole-do-hloubky#zapomenuty-return-ve-slozenych-zavorkach).

## --tip--

Callback v `map` vrátí nový objekt s klíči `name` a `total`. Objekt za šipkou obal do kulatých závorek.

## --tip--

Na jiných datech: `students.map((student) => ({ name: student.name, passed: student.points >= 50 }))`.

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}
```
