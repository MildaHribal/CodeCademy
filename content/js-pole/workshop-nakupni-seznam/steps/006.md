title: Procházení cyklem for…of
---

# --description--

Napiš funkci `totalQuantity(items)`, která sečte `quantity` všech položek — kolik kusů je na seznamu celkem. Prázdný seznam má vrátit `0`. Pole projdi cyklem **`for…of`**.

Když potřebuješ něco udělat s každou položkou pole, můžeš psát klasický cyklus s počítadlem `for (let i = 0; i < items.length; i++)`. Má ale tři místa, kde se dá udělat chyba — začátek, podmínka a krok — a každá chyba „jen" vynechá nebo přidá jednu položku. Nic nespadne, jen vyjde jiné číslo.

`for…of` tyhle chyby udělat neumí. Projde všechny položky od první do poslední a v každém průchodu ti dá rovnou položku, žádný index. Na jiných datech — součet stran knih:

```js
let pages = 0;
for (const book of books) {
  pages += book.pages;
}
```

Průběžný součet drž v proměnné **nad** cyklem a přes `let`, protože do ní přiřazuješ. Proměnná položky v hlavičce cyklu může být `const` — v každém průchodu vzniká nová.

# --hints--

`totalQuantity` vrátí součet `quantity` všech položek.

```js
const items = [
  { id: 7, name: 'Káva', quantity: 2 },
  { id: 8, name: 'Čaj', quantity: 3 },
  { id: 9, name: 'Rýže', quantity: 1 },
];
assert.equal(totalQuantity(items), 6, 'součet 2 + 3 + 1 má být 6');
```

Pro prázdné pole vrátí `totalQuantity` číslo `0`.

```js
assert.equal(totalQuantity([]), 0);
```

`totalQuantity` prochází pole cyklem `for…of`.

```js
const source = helpers.stripComments(totalQuantity.toString(), 'js');
// Proměnná cyklu smí být i destrukturalizovaná: for (const { quantity } of items)
assert.match(source, /for\s*\(\s*(const|let|var)\s+[^;()]+?\s+of\s/, 'v totalQuantity chybí for (const … of …)');
```

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}
```
