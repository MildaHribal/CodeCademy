# --description--

**Úkol:** Napiš funkci `removeAt(items, index)`, která vrátí nové pole bez položky na indexu `index`. Původní pole nesmí změnit.

Na vyříznutí položky z pole existuje metoda `splice` — ale ta patří do stejné skupiny jako `push`: **mutuje**. Vyřízne položky přímo z původního pole a vrátí ty vyříznuté.

Její nemutující dvojče je **`toSpliced`**. Bere stejné argumenty — index, od kterého začít, a kolik položek odebrat — ale původní pole nechá být a vrátí upravenou kopii. Na jiných datech:

```js
const queue = ['Anna', 'Bedřich', 'Cyril', 'Dana'];

// 1. kopie fronty bez prvních dvou jmen
const later = queue.toSpliced(0, 2);

// 2. kopie fronty s Evou vloženou na index 1, nic se neodebere
const withEva = queue.toSpliced(1, 0, 'Eva');
```

`queue` po obou řádcích pořád obsahuje všechna čtyři jména. Starší kód to samé dělá přes `slice`, který vrací výřez pole: `[...queue.slice(0, 1), ...queue.slice(2)]`. Taky správně, jen se to hůř čte.

# --hints--

`removeAt` vrátí pole bez položky na zadaném indexu.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const result = removeAt([coffee, tea, rice], 1);
assert.ok(Array.isArray(result), 'removeAt([Káva, Čaj, Rýže], 1) má vrátit pole');
assert.deepEqual(result, [coffee, rice], 'removeAt([Káva, Čaj, Rýže], 1) má vrátit [Káva, Rýže]');
```

`removeAt` umí odebrat první i poslední položku.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
assert.deepEqual(removeAt([coffee, tea, rice], 0), [tea, rice], 'removeAt([Káva, Čaj, Rýže], 0) má vrátit [Čaj, Rýže]');
assert.deepEqual(removeAt([coffee, tea, rice], 2), [coffee, tea], 'removeAt([Káva, Čaj, Rýže], 2) má vrátit [Káva, Čaj]');
```

Pole, které `removeAt` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }, { id: 9, name: 'Rýže' }];
const result = removeAt(items, 1);
assert.equal(items.length, 3, 'removeAt([Káva, Čaj, Rýže], 1) nesmí odebírat z původního pole — to má mít pořád 3 položky');
assert.notEqual(result, items, 'removeAt má vrátit nové pole, ne původní pole items');
```

# --help--

## --tip--

Jde o rozdíl mezi mutující a nemutující metodou — viz [`slice` a `splice`](see:js-pole/co-je-pole#slice-a-splice).

## --tip--

Zavolej na `items` nemutující dvojče `splice`. První argument je `index`, druhý říká, kolik položek odebrat.

## --tip--

Na jiných datech: kopie fronty bez jména na indexu 3 je `queue.toSpliced(3, 1)`.

## --file-- script.js

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}
```
