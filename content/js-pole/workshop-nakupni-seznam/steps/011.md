---
title: Odebrání podle id
---

# --description--

Napiš funkci `removeById(items, id)`, která vrátí nové pole bez položky s daným `id`. Když taková položka v poli není, vrátí pole se všemi položkami.

`removeAt` odebírá podle indexu. To má háček: index položky se mění, kdykoli někdo seznam seřadí nebo z něj něco odebere. Kdo si index zapamatoval o chvíli dřív, smaže jinou položku. `id` se nemění nikdy, proto se v aplikacích maže podle něj.

Odebrání je jen jiný pohled na výběr: „vrať všechny položky **kromě** té jedné" je `filter` s podmínkou `!==`. Na jiných datech:

```js
const withoutKrakatit = books.filter((book) => book.title !== 'Krakatit');
```

`filter` původní pole nemění, takže o mutaci se tady starat nemusíš.

# --hints--

`removeById` vrátí pole bez položky se zadaným `id`.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const result = removeById([coffee, tea, rice], 8);
assert.ok(Array.isArray(result), 'removeById má vrátit pole');
assert.equal(result.length, 2);
assert.equal(result[0], coffee);
assert.equal(result[1], rice);
```

S neexistujícím `id` vrátí `removeById` všechny položky.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
const result = removeById(items, 42);
assert.equal(result.length, 2, 'removeById(items, 42) nemá odebrat nic — položka s id 42 v poli není');
```

Pole, které `removeById` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
const before = JSON.stringify(items);
removeById(items, 7);
assert.equal(JSON.stringify(items), before);
```
