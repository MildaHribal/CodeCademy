# --description--

**Úkol:** Napiš funkci `toBuy(items)`, která vrátí jen položky, které ještě nejsou koupené (`bought` je `false`). Použij metodu **`filter`**.

`filter` se zapisuje stejně jako `map` — dostane callback, který se zavolá pro každou položku. Rozdíl je v tom, co callback vrací a co z toho vznikne:

- callback u `map` vrací **novou položku** → výsledek má stejnou délku,
- callback u `filter` vrací **`true` nebo `false`** → položka se do výsledku buď dostane (celá a beze změny), nebo vypadne. Výsledek je stejně dlouhý nebo kratší.

Takovému callbacku, který o položce odpoví ano/ne, se říká [[predikát]]. Na jiných datech — jen dlouhé knihy:

```js
// 1. predikát: je kniha dlouhá?
const longBooks = books.filter((book) => book.pages > 300);
```

Pořadí položek zůstává, původní pole se nemění. Když podmínku nesplní nic, vyjde prázdné pole. Protože `bought` už je `true`/`false`, nemusíš ho s ničím porovnávat — stačí ho znegovat.

# --hints--

`toBuy` vrátí jen nekoupené položky ve stejném pořadí.

```js
const coffee = { id: 7, name: 'Káva', bought: false };
const tea = { id: 8, name: 'Čaj', bought: true };
const rice = { id: 9, name: 'Rýže', bought: false };
const result = toBuy([coffee, tea, rice]);
assert.ok(Array.isArray(result), 'toBuy([Káva, Čaj, Rýže]) má vrátit pole');
assert.deepEqual(result, [coffee, rice], 'toBuy([Káva, Čaj (koupený), Rýže]) má vrátit [Káva, Rýže]');
```

Když je všechno koupené, vrátí `toBuy` prázdné pole.

```js
assert.deepEqual(toBuy([{ id: 7, name: 'Káva', bought: true }]), [], 'toBuy([koupená Káva]) má vrátit prázdné pole []');
```

`toBuy` používá metodu `filter`.

```js
const source = helpers.stripComments(toBuy.toString(), 'js');
assert.match(source, /\.filter\s*\(/, 'v toBuy chybí volání .filter(…)');
```

# --help--

## --tip--

Jde o výběr položek predikátem — viz řádek `filter` v tabulce [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Zavolej `filter` na `items`. Callback má vrátit `true` pro položky, které **nejsou** koupené.

## --tip--

Na jiných datech: nepřečtené zprávy jsou `messages.filter((message) => !message.read)`.

# --explain--

Vysvětli vlastními slovy, co udělá `map` a co `filter` s hodnotou, kterou vrátí callback.

## --model--

`map` vezme, co callback vrátí, a dá to do nového pole místo původní položky, takže výsledek má stejnou délku a může obsahovat úplně jiné hodnoty. `filter` bere návratovou hodnotu jako odpověď ano/ne: když je pravdivá, dá do nového pole původní položku beze změny, když ne, položku vynechá. Proto u `filter` callback vrací podmínku a výsledek může být kratší.

## --checklist--

- `map` dá do výsledku přímo to, co callback vrátí.
- Výsledek `map` má vždy stejnou délku jako původní pole.
- `filter` bere hodnotu z callbacku jako ano/ne a do výsledku dává původní položky.
- Výsledek `filter` může být kratší, původní pole se nemění ani u jedné z metod.
