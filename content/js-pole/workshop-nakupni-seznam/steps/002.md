# --description--

Obchod zná jen čtyři kategorie. Budeš je potřebovat později, až budeš ověřovat, jestli má položka platnou kategorii.

**Úkol:** Pod funkci `createItem` založ konstantu `categories` s polem textů `'pečivo'`, `'mléčné výrobky'`, `'ovoce a zelenina'` a `'drogerie'`, přesně v tomhle pořadí.

Pole se zapisuje do hranatých závorek, položky odděluje čárka. Na jiných datech:

```js
const genres = ['román', 'detektivka', 'poezie'];
```

Pole zakládej přes `const`. Jeho obsah se tím nezamkne — `const` jen zaručí, že proměnná bude pořád ukazovat na totéž pole.

# --hints--

Existuje konstanta `categories` a je to pole.

```js
assert.ok(Array.isArray(categories), 'categories má být pole (Array.isArray(categories) vrací false)');
```

`categories` obsahuje `'pečivo'`, `'mléčné výrobky'`, `'ovoce a zelenina'` a `'drogerie'` v tomto pořadí.

```js
assert.deepEqual(
  categories,
  ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'],
  'categories má obsahovat čtyři kategorie přesně v pořadí pečivo, mléčné výrobky, ovoce a zelenina, drogerie',
);
```
