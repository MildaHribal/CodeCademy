# --description--

Napiš funkci `firstItem(items)`, která vrátí první položku pole `items`.

K položkám pole se dostaneš přes **index** — pořadové číslo v hranatých závorkách. Indexy se počítají **od nuly**, takže první položka má index `0`, druhá `1` a tak dál:

```js
const genres = ['román', 'detektivka', 'poezie'];
genres[1]; // 'detektivka'
genres[7]; // undefined — takový index neexistuje
```

Proč funkce dostává pole v parametru a nesahá rovnou na `groceries`? Protože pak funguje s jakýmkoli seznamem — s nákupem na zítřek, se seznamem z jiného obchodu i s daty, na kterých ji zkouší testy. Všechny funkce v tomhle workshopu budou psané takhle.

Když je pole prázdné, index `0` v něm neexistuje a výsledek je `undefined`. S tím nemusíš nic dělat, JavaScript to udělá sám.

Funkci si můžeš vyzkoušet: pod ni napiš `console.log(firstItem(groceries));` a podívej se do konzole. Až to uvidíš, výpis zase smaž.

# --hints--

`firstItem` vrátí první položku pole, které dostane.

```js
const items = [
  { id: 7, name: 'Káva' },
  { id: 8, name: 'Čaj' },
];
assert.equal(firstItem(items), items[0], 'firstItem má vrátit items[0]');
```

Pro prázdné pole vrátí `firstItem` hodnotu `undefined`.

```js
assert.equal(firstItem([]), undefined);
```

  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
