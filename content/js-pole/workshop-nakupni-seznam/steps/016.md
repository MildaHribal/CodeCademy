# --description--

**Úkol:** Napiš funkci `hasUnbought(items)`, která vrátí `true`, když je v seznamu **aspoň jedna** nekoupená položka, jinak `false`. Výsledek je vždy `true` nebo `false`, ne položka.

Na otázku „je tam aspoň jedna taková?" odpoví víc nástrojů:

- `filter` a délka výsledku — funguje, ale postaví zbytečné pole a projde všechny položky,
- `find` — vrátí položku nebo `undefined`, takže bys výsledek musel ještě převést na `true`/`false`,
- **`some`** — vrátí rovnou `true` nebo `false` a zastaví se u první položky, která podmínku splní.

Na jiných datech:

```js
// 1. je mezi knihami aspoň jedna dlouhá?
const hasLongBook = books.some((book) => book.pages > 300);
```

Nad prázdným polem vrací `some` vždycky `false` — není tam žádná položka, která by podmínku splnila.

# --hints--

`hasUnbought` vrátí `true`, když je aspoň jedna položka nekoupená.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: false },
];
assert.equal(hasUnbought(items), true, 'hasUnbought([koupená Káva, nekoupený Čaj]) má vrátit true — ne položku, ale přesně true');
```

`hasUnbought` vrátí `false`, když je všechno koupené.

```js
const items = [
  { id: 7, name: 'Káva', bought: true },
  { id: 8, name: 'Čaj', bought: true },
];
assert.equal(hasUnbought(items), false, 'hasUnbought([koupená Káva, koupený Čaj]) má vrátit false');
```

Pro prázdné pole vrátí `hasUnbought` hodnotu `false`.

```js
assert.equal(hasUnbought([]), false, 'hasUnbought([]) má vrátit false — prázdný seznam nemá žádnou nekoupenou položku');
```

# --help--

## --tip--

Otázka zní ano/ne — podívej se, které metody v tabulce [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci) vracejí `true`/`false`.

## --tip--

Zavolej `some` na `items` s predikátem, který je pravdivý pro nekoupenou položku, a výsledek vrať.

## --tip--

Na jiných datech: `messages.some((message) => !message.read)` odpoví, jestli je aspoň jedna zpráva nepřečtená.
