# --description--

Tenhle krok je bez návodu — všechno, co potřebuješ, už znáš.

**Úkol:** Napiš funkci `itemLabels(items)`, která vrátí pole textových popisků ve tvaru `název (počet ks)`. Z položky `{ name: 'Rohlíky', quantity: 6, … }` vznikne `'Rohlíky (6 ks)'`. Pořadí zůstává stejné, prázdné pole dá prázdné pole a původní pole se nezmění.

Až to budeš mít, porovnej to s `itemNames` a `lineTotals`. Všechny tři funkce mají stejný tvar, liší se jen tím, co callback vrací.

# --hints--

`itemLabels` vrátí popisky ve tvaru `název (počet ks)` ve stejném pořadí.

```js
const items = [
  { id: 7, name: 'Káva', quantity: 2 },
  { id: 8, name: 'Čaj', quantity: 1 },
];
assert.deepEqual(itemLabels(items), ['Káva (2 ks)', 'Čaj (1 ks)'], "itemLabels([Káva × 2, Čaj × 1]) má vrátit ['Káva (2 ks)', 'Čaj (1 ks)']");
```

Pro prázdné pole vrátí `itemLabels` prázdné pole.

```js
assert.deepEqual(itemLabels([]), [], 'itemLabels([]) má vrátit prázdné pole []');
```

Pole, které `itemLabels` dostane, zůstane beze změny.

```js
const coffee = { id: 7, name: 'Káva', quantity: 2 };
const items = [coffee];
itemLabels(items);
assert.deepEqual(items, [{ id: 7, name: 'Káva', quantity: 2 }], 'itemLabels([Káva]) nesmí měnit pole ani položku');
assert.equal(items[0], coffee, 'itemLabels([Káva]) nesmí nahradit položku v původním poli');
```

# --help--

## --tip--

Z každé položky vyrábíš jednu novou hodnotu a výsledek má stejnou délku — podívej se do tabulky [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Callback vrátí text poskládaný z `name` a `quantity`. Nejpohodlněji v šablonovém řetězci se zpětnými apostrofy a `${…}`.

## --tip--

Na jiných datech — jen jiné klíče a jiný text:

```js
const bookLabels = books.map((book) => `${book.title} (${book.pages} stran)`);
```
