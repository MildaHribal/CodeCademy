# --description--

**Úkol:** Napiš funkci `updateQuantity(items, id, quantity)`, která vrátí nové pole, ve kterém má položka s daným `id` nový počet kusů. Ostatní položky i ostatní klíče změněné položky zůstanou, jak jsou. **Nesmí se změnit původní pole ani původní objekty položek.** Když položka s `id` v seznamu není, vrátí pole se stejnými položkami.

Tohle je místo, kde se nejčastěji mutuje omylem:

> [!PITFALL]
> `findItem(items, id).quantity = quantity` vypadá nevinně, ale `find` vrací **tentýž objekt**, který leží v původním poli — přepíšeš tak cizí data. A nestačí ani nové pole: `[...items]` i `map`, který vrací původní položky, jsou mělké kopie, objekty uvnitř zůstávají sdílené. Příznak: `deepEqual` výsledku sedí, ale původní položka má nový `quantity` taky.

Změněná položka proto musí být **nový objekt**, který má všechny klíče původní položky a jiný `quantity`. Ostatní položky do nového pole klidně dej tytéž.

# --hints--

`updateQuantity` vrátí pole, ve kterém má položka se zadaným `id` nový počet kusů a ostatní klíče stejné.

```js
const items = [
  { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false },
  { id: 8, name: 'Čaj', category: 'nápoje', price: 60, quantity: 1, bought: true },
];
const result = updateQuantity(items, 8, 4);
assert.ok(Array.isArray(result), 'updateQuantity má vrátit pole');
assert.deepEqual(result, [
  { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false },
  { id: 8, name: 'Čaj', category: 'nápoje', price: 60, quantity: 4, bought: true },
], 'updateQuantity([Káva, Čaj (id 8)], 8, 4) má vrátit seznam, kde má Čaj quantity: 4 a všechno ostatní stejné');
```

Původní pole i původní objekty položek zůstanou beze změny.

```js
const coffee = { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false };
const tea = { id: 8, name: 'Čaj', category: 'nápoje', price: 60, quantity: 1, bought: true };
const items = [coffee, tea];
const result = updateQuantity(items, 8, 4);
assert.equal(tea.quantity, 1, 'updateQuantity([Káva, Čaj], 8, 4) nesmí změnit původní objekt Čaje — ten má mít pořád quantity: 1');
assert.deepEqual(items, [coffee, tea], 'updateQuantity nesmí měnit původní pole');
assert.notEqual(result, items, 'updateQuantity má vrátit nové pole, ne původní pole items');
```

S neexistujícím `id` vrátí `updateQuantity` pole se stejnými položkami.

```js
const coffee = { id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false };
const result = updateQuantity([coffee], 42, 5);
assert.deepEqual(result, [{ id: 7, name: 'Káva', category: 'nápoje', price: 150, quantity: 2, bought: false }], 'updateQuantity([Káva (id 7)], 42, 5) nemá nic změnit — položka s id 42 v seznamu není');
```

# --help--

## --tip--

Jde o to, co je nové a co sdílené po kopii — viz [Mělká kopie](see:js-pole/co-je-pole#melka-kopie).

## --tip--

Projdi pole metodou, která vrací pole stejné délky. U položky se správným `id` vrať nový objekt: rozprostři do něj klíče položky a za ně napiš nový `quantity`. U ostatních vrať položku samotnou.

## --tip--

Na jiných datech — hotový úkol v seznamu úkolů:

```js
const updatedTasks = tasks.map((task) => (task.id === doneId ? { ...task, done: true } : task));
```

# --explain--

Vysvětli vlastními slovy, proč `updateQuantity` u změněné položky vytváří nový objekt, ale u ostatních položek může vrátit ty původní.

## --model--

Nové pole z `map` je jen mělká kopie: obsahuje odkazy na tytéž objekty jako původní pole. Kdybych změněné položce přepsal `quantity` přímo, změnil bych objekt, na který ukazuje i původní seznam. Proto pro ni vytvořím nový objekt přes `{ ...item, quantity }`. Ostatní položky neměním, takže je můžu sdílet — ušetří to kopírování a nikomu to neublíží.

## --checklist--

- Nové pole z `map` obsahuje odkazy na tytéž objekty jako původní pole.
- Přepsání klíče na sdíleném objektu změní i původní seznam.
- Změněná položka potřebuje nový objekt, třeba `{ ...item, quantity }`.
- Nezměněné položky se sdílet smějí, protože je nikdo nemění.

```js
// Nákupní seznam. Každá položka je objekt se stejnými klíči,
// cena (price) je za jeden kus v korunách.
const groceries = [
  { id: 1, name: 'Chleba', category: 'pečivo', price: 45, quantity: 1, bought: false },
  { id: 2, name: 'Mléko', category: 'mléčné výrobky', price: 24, quantity: 2, bought: true },
  { id: 3, name: 'Jablka', category: 'ovoce a zelenina', price: 39, quantity: 1, bought: false },
  { id: 4, name: 'Máslo', category: 'mléčné výrobky', price: 59, quantity: 1, bought: false },
  { id: 5, name: 'Rohlíky', category: 'pečivo', price: 5, quantity: 6, bought: true },
  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },
];

// Vytvoří novou položku seznamu: jeden kus, zatím nekoupená.
function createItem(id, name, category, price) {
  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}

// Popisky ve tvaru „Rohlíky (6 ks)".
function itemLabels(items) {
  return items.map((item) => `${item.name} (${item.quantity} ks)`);
}

// Položky, které ještě nejsou v košíku.
function toBuy(items) {
  return items.filter((item) => !item.bought);
}

// Vrátí nový seznam bez položky s daným id.
function removeById(items, id) {
  return items.filter((item) => item.id !== id);
}

// Položka s daným id, nebo undefined.
function findItem(items, id) {
  return items.find((item) => item.id === id);
}

// Index položky s daným id, nebo -1.
function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
}

// Od kolegy: je položka s tímhle id už v seznamu?
function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position !== -1) {
    return true;
  }
  return false;
}

// Je v seznamu aspoň jedna nekoupená položka?
function hasUnbought(items) {
  return items.some((item) => !item.bought);
}

// Jsou koupené všechny položky? U prázdného seznamu ano.
function allBought(items) {
  return items.every((item) => item.bought);
}

// Zná obchod tuhle kategorii?
function isKnownCategory(category) {
  return categories.includes(category);
}

// Cena celého nákupu v korunách.
function totalPrice(items) {
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0);
}

// Nový seznam seřazený od nejlevnější položky.
function sortedByPrice(items) {
  return items.toSorted((a, b) => a.price - b.price);
}

// Nový seznam seřazený podle názvu podle české abecedy.
function sortedByName(items) {
  return items.toSorted((a, b) => a.name.localeCompare(b.name, 'cs'));
}

// Od kolegy: jednotkové ceny všech položek od nejnižší.
function pricesAscending(items) {
  return items.map((item) => item.price).sort((a, b) => a - b);
}

// Položka, za kterou v nákupu utratíš nejvíc; při shodě ta dřívější.
function priciestItem(items) {
  let priciest;
  for (const item of items) {
    if (priciest === undefined || item.price * item.quantity > priciest.price * priciest.quantity) {
      priciest = item;
    }
  }
  return priciest;
}

function countByCategory(items) {
  return items.reduce((counts, item) => {
    counts[item.category] = (counts[item.category] ?? 0) + 1;
    return counts;
  }, {});
}

// Kolik kusů je v které kategorii.
function quantityByCategory(items) {
  return items.reduce((quantities, item) => {
    quantities[item.category] = (quantities[item.category] ?? 0) + item.quantity;
    return quantities;
  }, {});
}

// Názvy položek, které ještě nejsou v košíku.
function namesToBuy(items) {
  return itemNames(toBuy(items));
}
```
