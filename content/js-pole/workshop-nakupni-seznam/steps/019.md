# --description--

**Úkol:** Napiš funkci `totalPrice(items)`, která vrátí cenu celého nákupu: součet `price * quantity` přes všechny položky. Prázdný seznam stojí `0`. Použij metodu **`reduce`**.

Stejný součet bys napsal cyklem `for…of` jako `totalQuantity`. Tady si vyzkoušej `reduce`: `map` z pole udělá pole, `filter` taky pole, ale `reduce` z pole udělá **jednu hodnotu** — číslo, text, objekt, cokoli. Na jiných datech:

```js
// 1. akumulátor sum, počáteční hodnota 0
const pages = books.reduce((sum, book) => sum + book.pages, 0);
```

- Callback dostane [[akumulátor]] (tady `sum`) a aktuální položku (`book`). Vrací **novou hodnotu akumulátoru**.
- `0` na konci **není součást callbacku**. Je to druhý argument `reduce` — počáteční hodnota akumulátoru. Snadno se přehlédne, protože stojí až za závorkou callbacku.

Průběh pro knihy Krakatit (280 stran) a Babička (310 stran):

| volání | `sum` na začátku | `book.pages` | callback vrátí |
|---|---|---|---|
| 1. | `0` (počáteční hodnota) | `280` | `280` |
| 2. | `280` | `310` | `590` |

`reduce` vrátí to, co vrátilo poslední volání: `590`.

> [!PITFALL]
> Bez počáteční hodnoty vezme `reduce` jako akumulátor první položku pole. U pole objektů vyjde nesmysl typu `[object Object]60` a nad prázdným polem kód spadne: `TypeError: Reduce of empty array with no initial value`.

# --hints--

`totalPrice` vrátí součet `price * quantity` všech položek.

```js
const items = [
  { id: 7, name: 'Káva', price: 150, quantity: 2 },
  { id: 8, name: 'Čaj', price: 60, quantity: 1 },
  { id: 9, name: 'Rýže', price: 35, quantity: 3 },
];
assert.equal(totalPrice(items), 465, 'totalPrice pro Kávu 2 × 150, Čaj 1 × 60 a Rýži 3 × 35 má vrátit 465');
```

Pro prázdné pole vrátí `totalPrice` číslo `0`.

```js
assert.equal(totalPrice([]), 0, 'totalPrice([]) má vrátit 0 — dostal reduce počáteční hodnotu?');
```

`totalPrice` používá metodu `reduce`.

```js
const source = helpers.stripComments(totalPrice.toString(), 'js');
assert.match(source, /\.reduce\s*\(/, 'v totalPrice chybí volání .reduce(…)');
```

# --help--

## --tip--

Z pole děláš jednu hodnotu — viz [Jak pracuje `reduce`](see:js-pole/metody-pole-do-hloubky#jak-pracuje-reduce).

## --tip--

Zavolej `reduce` na `items`. Callback k akumulátoru přičte cenu za všechny kusy položky; za callback nezapomeň počáteční hodnotu.

## --tip--

Na jiných datech: celková délka playlistu je `songs.reduce((seconds, song) => seconds + song.length, 0)`.

# --explain--

Vysvětli vlastními slovy, co dostane callback v `totalPrice` při každém volání a jak `reduce` dojde k výsledku.

## --model--

`reduce` zavolá callback postupně pro každou položku. Při prvním volání dostane jako akumulátor počáteční hodnotu `0` a první položku a vrátí `0` plus cenu za její kusy. Při každém dalším volání dostane jako akumulátor to, co vrátilo volání předtím, a přičte další položku. Výsledkem `reduce` je hodnota z posledního volání, tedy cena celého nákupu.

## --checklist--

- Callback dostane akumulátor a jednu položku.
- Při prvním volání je akumulátor počáteční hodnota `0`.
- Každé další volání dostane jako akumulátor to, co vrátilo předchozí.
- `reduce` vrátí hodnotu z posledního volání callbacku.

// Nákupní seznam. Každá položka je objekt se stejnými klíči,

  { id: 6, name: 'Zubní pasta', category: 'drogerie', price: 89, quantity: 1, bought: false },

  return { id, name, category, price, quantity: 1, bought: false };
}

const categories = ['pečivo', 'mléčné výrobky', 'ovoce a zelenina', 'drogerie'];

// Vrátí první položku seznamu, u prázdného seznamu undefined.
function firstItem(items) {
  return items[0];
}

// Vrátí poslední položku seznamu, u prázdného seznamu undefined.
function lastItem(items) {
  return items.at(-1);
}

// Vrátí nový seznam s položkou přidanou na konec.
function addItem(items, item) {
  return [...items, item];
}

// Vrátí nový seznam bez položky na daném indexu.
function removeAt(items, index) {
  return items.toSpliced(index, 1);
}

// Kolik kusů je na seznamu celkem.
function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total += item.quantity;
  }
  return total;
}

// Názvy položek ve stejném pořadí.
function itemNames(items) {
  return items.map((item) => item.name);
}

// Pro každou položku název a cenu za všechny kusy.
function lineTotals(items) {
  return items.map((item) => ({ name: item.name, total: item.price * item.quantity }));
}

// Popisky ve tvaru „Rohlíky (6 ks)".
function itemLabels(items) {
  return items.map((item) => `${item.name} (${item.quantity} ks)`);
}

// Položky, které ještě nejsou v košíku.
function toBuy(items) {
  return items.filter((item) => !item.bought);
}

// Vrátí nový seznam bez položky s daným id.
function removeById(items, id) {
  return items.filter((item) => item.id !== id);
}

// Položka s daným id, nebo undefined.
function findItem(items, id) {
  return items.find((item) => item.id === id);
}

// Index položky s daným id, nebo -1.
function indexById(items, id) {
  return items.findIndex((item) => item.id === id);
}

// Od kolegy: je položka s tímhle id už v seznamu?
function hasItem(items, id) {
  const position = items.findIndex((item) => item.id === id);
  if (position !== -1) {
    return true;
  }
  return false;
}

// Je v seznamu aspoň jedna nekoupená položka?
function hasUnbought(items) {
  return items.some((item) => !item.bought);
}

// Jsou koupené všechny položky? U prázdného seznamu ano.
function allBought(items) {
  return items.every((item) => item.bought);
}

// Zná obchod tuhle kategorii?
function isKnownCategory(category) {
  return categories.includes(category);
