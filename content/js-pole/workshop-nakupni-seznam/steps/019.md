title: Počty podle kategorie přes reduce
---

# --description--

Napiš funkci `countByCategory(items)`, která vrátí objekt: klíčem je kategorie, hodnotou počet položek v ní. Ze seznamu `groceries` vznikne:

```js
{ 'pečivo': 2, 'mléčné výrobky': 2, 'ovoce a zelenina': 1, 'drogerie': 1 }
```

Počítají se položky, ne kusy. Kategorie, které v seznamu nejsou, ve výsledku nejsou ani jako klíč. Prázdný seznam dá prázdný objekt `{}`.

Tady `reduce` ukáže, co umí: akumulátor **nemusí být číslo**. Když začne jako prázdný objekt, můžeš ho postupně plnit. Na jiných datech — počet knih od každého autora:

```js
const booksByAuthor = books.reduce((counts, book) => {
  counts[book.author] = (counts[book.author] ?? 0) + 1;
  return counts;
}, {});
```

Dvě místa, kde se tu chybuje:

- Když autor přijde poprvé, `counts[book.author]` je `undefined` a `undefined + 1` je `NaN`. Proto `?? 0` — „a když tam nic není, tak nula".
- Callback se složenými závorkami musí akumulátor **vrátit**. Bez `return` je v dalším kole akumulátor `undefined` a `reduce` spadne.

# --hints--

`countByCategory` vrátí počet položek v každé kategorii.

```js
const items = [
  { id: 7, name: 'Káva', category: 'nápoje', quantity: 2 },
  { id: 8, name: 'Čaj', category: 'nápoje', quantity: 1 },
  { id: 9, name: 'Rýže', category: 'přílohy', quantity: 3 },
];
assert.deepEqual(countByCategory(items), { 'nápoje': 2, 'přílohy': 1 });
```

Pro prázdné pole vrátí `countByCategory` prázdný objekt.

```js
const result = countByCategory([]);
assert.equal(typeof result, 'object');
assert.ok(result !== null, 'výsledek nemá být null');
assert.equal(Object.keys(result).length, 0, 'prázdný seznam nemá mít žádnou kategorii');
```

Když `countByCategory` zavoláš dvakrát, oba výsledky jsou stejné (akumulátor vzniká při každém volání znovu).

```js
const items = [{ id: 7, name: 'Káva', category: 'nápoje', quantity: 2 }];
countByCategory(items);
assert.deepEqual(countByCategory(items), { 'nápoje': 1 }, 'druhé zavolání má začít od nuly — vzniká akumulátor {} při každém volání?');
```
