# --description--

**Úkol:** Napiš funkci `removeById(items, id)`, která vrátí nové pole bez položky s daným `id`. Když taková položka v poli není, vrátí pole se všemi položkami. Původní pole se nemění.

`removeAt` odebírá podle indexu. To má háček: index položky se mění, kdykoli někdo seznam seřadí nebo z něj něco odebere. Kdo si index zapamatoval o chvíli dřív, smaže jinou položku. `id` se nemění nikdy, proto se v aplikacích maže podle něj.

Na odebrání se dá dívat dvěma způsoby — vyber si:

- „najdi pozici a vyřízni ji" — pozor na položku, která v poli není,
- „vrať všechny položky **kromě** té jedné" — výběr, který už umíš.

# --hints--

`removeById` vrátí pole bez položky se zadaným `id`.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
const rice = { id: 9, name: 'Rýže' };
const result = removeById([coffee, tea, rice], 8);
assert.ok(Array.isArray(result), 'removeById([Káva, Čaj, Rýže], 8) má vrátit pole');
assert.deepEqual(result, [coffee, rice], 'removeById([Káva (7), Čaj (8), Rýže (9)], 8) má vrátit [Káva, Rýže]');
```

S neexistujícím `id` vrátí `removeById` všechny položky.

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
assert.deepEqual(removeById([coffee, tea], 42), [coffee, tea], 'removeById([Káva (7), Čaj (8)], 42) nemá odebrat nic — položka s id 42 v poli není');
```

Pole, které `removeById` dostane, zůstane beze změny.

```js
const items = [{ id: 7, name: 'Káva' }, { id: 8, name: 'Čaj' }];
removeById(items, 7);
assert.equal(items.length, 2, 'removeById([Káva, Čaj], 7) nesmí odebírat z původního pole — to má mít pořád 2 položky');
```

# --help--

## --tip--

Jde o výběr položek, které mají zůstat — viz řádek `filter` v tabulce [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Nejkratší cesta je `filter` na `items`: predikát vrátí `true` pro každou položku, jejíž `id` se **neshoduje** se zadaným.

## --tip--

Na jiných datech: seznam bez knihy Krakatit je `books.filter((book) => book.title !== 'Krakatit')`.
