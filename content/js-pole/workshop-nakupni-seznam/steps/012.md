# --description--

Napiš funkci `findItem(items, id)`, která vrátí položku s daným `id`. Když taková není, vrátí `undefined`. Použij metodu **`find`**.

`find` se píše stejně jako `filter` — callback vrací `true`/`false`. Liší se výsledek:

- `filter` vrátí **pole všech** vyhovujících položek,
- `find` vrátí **první** vyhovující položku samotnou (ne v poli) a dál už nehledá. Když nevyhoví žádná, vrátí `undefined`.

Na jiných datech:

```js
const krakatit = books.find((book) => book.title === 'Krakatit');
// { title: 'Krakatit', pages: 280 }

const missing = books.find((book) => book.pages > 1000);
// undefined
```

Vrácená položka je **tentýž objekt**, který je v poli, ne kopie. Kdo ji pak změní, mění ji i v poli.

# --hints--

`findItem` vrátí položku se zadaným `id` (ten samý objekt, který je v poli).

```js
const coffee = { id: 7, name: 'Káva' };
const tea = { id: 8, name: 'Čaj' };
assert.equal(findItem([coffee, tea], 8), tea);
```

S neexistujícím `id` vrátí `findItem` hodnotu `undefined`.

```js
assert.equal(findItem([{ id: 7, name: 'Káva' }], 42), undefined);
assert.equal(findItem([], 7), undefined);
```

`findItem` používá metodu `find`.

```js
const source = helpers.stripComments(findItem.toString(), 'js');
assert.match(source, /\.find\s*\(/, 'v findItem chybí volání .find(…)');
```
