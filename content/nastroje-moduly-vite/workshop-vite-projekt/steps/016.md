# --description--

Poslední krok: kontroly se pustí samy, dřív než rozbitý kód vůbec vznikne jako commit.

**Cíl:**

- Soubor `.githooks/pre-commit` je [[Git hook]], který pustí všechny kontroly projektu
  jedním skriptem z minulého kroku. Když selžou, hook skončí chybou a Git commit
  nevytvoří.
- Po `npm install` si Git sám nastaví, že hooky hledá ve složce `.githooks`. Na to má
  npm skript se jménem `prepare`, který se pouští automaticky po instalaci, a Git
  nastavení `core.hooksPath`.

Na vlastním počítači musí být soubor hooku spustitelný — jednou pustíš
`chmod +x .githooks/pre-commit`. Kontrola to udělá za tebe.

Tady máš hotový projekt. Stránka ze sekce o DOM je teď rozdělená do modulů, má
`package.json` se skripty a závislostmi, styly a obrázek importuje přes Vite, nadpis
a termín bere z `.env`, sestaví se pro jakoukoli podsložku a hlídají ji ESLint,
Prettier a hook před commitem. Takhle začíná každý frontendový projekt, na kterém budeš
pracovat — i ty v Reactu a TypeScriptu, jen s pár balíčky navíc.

## Udělej po svém

- **Vzhled:** přidej do `styles.css` tmavý režim přes `prefers-color-scheme` a ověř,
  že ho `format:check` pustí dál.
- **Funkce:** ulož úkoly do `localStorage` v novém modulu `storage.js` s veřejným
  rozhraním `loadTasks` a `saveTasks`.
- **Nasazení:** vytvoř repozitář na GitHubu, pushni projekt a nasaď `dist/` na
  GitHub Pages — díky `base` poběží v podsložce.
- **Tvoje téma:** přestav seznam na něco, co řešíš ty: balení na dovolenou, přípravu
  na zkoušky, plán tréninků. Stačí změnit data a texty v `.env`.

V další části sekce postavíš sám bez kroků malý balíček s utilitami — s `exports`,
skripty, lintem a README.

# --hints--

`.githooks/pre-commit` projde, když je projekt v pořádku.

```js
const result = await helpers.run('sh .githooks/pre-commit', { timeoutMs: 80000 });
assert.equal(result.code, 0, `sh .githooks/pre-commit má nad čistým projektem projít:\n${result.stdout}${result.stderr}`);
```

`.githooks/pre-commit` skončí chybou, když kód neprojde lintem.

```js
const fs = await import('node:fs');
fs.writeFileSync(`${helpers.dir}/hook-probe.js`, 'const unusedProbe = 1;\n');
const result = await helpers.run('sh .githooks/pre-commit', { timeoutMs: 80000 });
fs.rmSync(`${helpers.dir}/hook-probe.js`, { force: true });
assert.notEqual(result.code, 0, 'S chybou lintu v hook-probe.js má hook skončit chybou');
```

Skript `prepare` nastaví Gitu složku s hooky `.githooks`.

```js
await helpers.run('rm -rf .git && git init -q .');
const prepare = await helpers.run('node --run prepare');
assert.doesNotMatch(prepare.stdout + prepare.stderr, /Missing script/i, 'package.json nemá skript prepare');
assert.equal(prepare.code, 0, `node --run prepare má projít:\n${prepare.stdout}${prepare.stderr}`);
const config = await helpers.run('git config core.hooksPath');
assert.equal(config.stdout.trim(), '.githooks', `Po node --run prepare má být core.hooksPath „.githooks", je „${config.stdout.trim()}"`);
await helpers.run('rm -rf .git');
```

Git s nastaveným hookem nevytvoří commit s chybou lintu.

```js
const fs = await import('node:fs');
await helpers.run('rm -rf .git && git init -q . && git config core.hooksPath .githooks && chmod +x .githooks/pre-commit');
fs.writeFileSync(`${helpers.dir}/hook-probe.js`, 'const unusedProbe = 1;\n');
const commit = await helpers.run('git add -A && git -c user.name=Test -c user.email=test@example.com commit -q -m "Pokus"', { timeoutMs: 80000 });
const log = await helpers.run('git log --oneline');
fs.rmSync(`${helpers.dir}/hook-probe.js`, { force: true });
await helpers.run('rm -rf .git');
assert.notEqual(commit.code, 0, 'Commit s chybou lintu má hook zastavit');
assert.equal(log.stdout.trim(), '', 'V historii nemá vzniknout žádný commit');
```

## --file-- script.js

```js
// Seznam úkolů na stěhování. Pole tasks je jediný zdroj pravdy.
import './styles.css';
import { countOpen, progressPercent } from './tasks.js';
import emptyBoxesUrl from './empty-boxes.svg';

let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

let nextId = 6;

function createTask(title) {
  const task = { id: nextId, title, room: 'ostatní', done: false };
  nextId += 1;
  return task;
}

function createTaskElement(task) {
  const template = document.querySelector('#task-template');
  const li = template.content.firstElementChild.cloneNode(true);
  li.querySelector('.task__title').textContent = task.title;
  li.querySelector('.task__room').textContent = task.room;
  li.classList.toggle('is-done', task.done);
  li.querySelector('.task__toggle').checked = task.done;
  li.querySelector('.task__delete').setAttribute('aria-label', `Smazat úkol ${task.title}`);
  li.querySelector('.task__toggle').addEventListener('change', () => toggleTask(task.id));
  li.querySelector('.task__delete').addEventListener('click', () => deleteTask(task.id));
  return li;
}

function render() {
  const items = tasks.map((task) => createTaskElement(task));
  document.querySelector('#task-list').replaceChildren(...items);
  document.querySelector('#open-count').textContent = countOpen(tasks);
  document.querySelector('#total-count').textContent = tasks.length;
  document.querySelector('#empty-state').hidden = tasks.length > 0;
  document.querySelector('#clear-done').disabled = !tasks.some((task) => task.done);
  document
    .querySelector('#progress-bar')
    .style.setProperty('--progress', `${progressPercent(tasks)}%`);
}

function toggleTask(id) {
  tasks = tasks.map((task) => (task.id === id ? { ...task, done: !task.done } : task));
  render();
}

function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
  render();
}

document.querySelector('#move-title').textContent = import.meta.env.VITE_MOVE_TITLE;
document.querySelector('#move-date').textContent = `Termín: ${import.meta.env.VITE_MOVE_DATE}`;
document.querySelector('#empty-image').src = emptyBoxesUrl;

render();

document.querySelector('#add-form').addEventListener('submit', (event) => {
  event.preventDefault();
  const title = document.querySelector('#task-title').value.trim();
  if (title === '') {
    return;
  }
  tasks = [...tasks, createTask(title)];
  render();
  event.target.reset();
});

document.querySelector('#clear-done').addEventListener('click', () => {
  tasks = tasks.filter((task) => !task.done);
  render();
});

```

## --file-- tasks.js

```js
// Čisté funkce nad seznamem úkolů. Nesahají na stránku.

export function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

export function progressPercent(items) {
  if (items.length === 0) {
    return 0;
  }
  const doneCount = items.length - countOpen(items);
  return Math.round((doneCount / items.length) * 100);
}

```
