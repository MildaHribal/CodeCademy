# --description--

## Hlášení

Klára hlásí: „Lint mi prošel, pak jsem pustila `npm run build`, abych zkontrolovala
sestavení, a když jsem pustila `npm run lint` znovu, najednou padá. Na `script.js`
jsem mezitím nesáhla." Výstup:

```text
/home/klara/stehovani/dist/assets/index-DpsktfEj.js
  1:188  error  'MutationObserver' is not defined  no-undef
  1:650  error  'fetch' is not defined             no-undef

✖ 2 problems (2 errors, 0 warnings)
```

## Úkol

Uprav nastavení tak, aby `npm run lint` procházel i po sestavení a přitom dál
kontroloval všechen kód, který v projektu píšete. Změň co nejmenší kus kódu.

# --hints--

Po `node --run build` projde i `node --run lint` a nic ve složce `dist/` nekontroluje.

```js
await helpers.run('rm -rf dist');
const build = await helpers.run('node --run build', { timeoutMs: 25000 });
assert.equal(build.code, 0, `node --run build má projít:\n${build.stdout}${build.stderr}`);
const lint = await helpers.run('node --run lint', { timeoutMs: 25000 });
assert.equal(lint.code, 0, `Po sestavení má node --run lint projít:\n${lint.stdout}${lint.stderr}`);
const fs = await import('node:fs/promises');
await fs.writeFile(`${helpers.dir}/dist/assets/chunk-extra.js`, 'const generatedValue = 1;\n');
const again = await helpers.run('node --run lint', { timeoutMs: 25000 });
assert.equal(again.code, 0, `Lint nemá kontrolovat nic ve složce dist/ — i jiný vygenerovaný soubor tam má ignorovat:\n${again.stdout}`);
```

Lint dál kontroluje zdrojový kód: chybu v novém souboru najde.

```js
const fs = await import('node:fs/promises');
await fs.mkdir(`${helpers.dir}/src-probe`, { recursive: true });
await fs.writeFile(`${helpers.dir}/src-probe/probe.js`, 'const unusedProbe = 1;\n');
const lint = await helpers.run('node --run lint', { timeoutMs: 25000 });
await fs.rm(`${helpers.dir}/src-probe`, { recursive: true, force: true });
assert.notEqual(lint.code, 0, 'Lint má dál najít chybu v novém souboru src-probe/probe.js — nevypnul jsi kontrolu celého projektu?');
assert.match(lint.stdout, /probe\.js/, `Výstup lintu má zmínit probe.js:\n${lint.stdout}`);
```

# --explain--

Vysvětli, proč lint najednou padal na souboru, který nikdo nepsal, a proč je
správné ho z kontroly vyřadit, a ne doplnit chybějící globální jména.

## --model--

Sestavení vyrobí ve `dist/` minifikovaný kód, který psal Vite, ne my. `eslint .`
kontroluje všechno ve složce, takže po sestavení kontroloval i tenhle výrobek a hlásil
v něm jména, která naše nastavení nezná. Opravovat nebo hlídat vygenerovaný kód nemá
smysl, při dalším sestavení vznikne znovu. Linter patří na zdroják, proto `dist/` patří
do `ignores`.

## --checklist--

- Chyba je v souboru, který vyrobilo sestavení, ne ve zdrojovém kódu.
- `eslint .` kontroluje všechno ve složce, i `dist/`.
- Vygenerovaný kód se při každém sestavení přepíše, opravovat ho nemá smysl.
- Složka `dist/` patří do `ignores`, ne do dalších globálních jmen.

## --file-- script.js

```js
// Seznam úkolů na stěhování. Pole tasks je jediný zdroj pravdy.
import './styles.css';
import { countOpen, progressPercent } from './tasks.js';
import emptyBoxesUrl from './empty-boxes.svg';

let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

let nextId = 6;

function createTask(title) {
  const task = { id: nextId, title, room: 'ostatní', done: false };
  nextId += 1;
  return task;
}

function createTaskElement(task) {
  const template = document.querySelector('#task-template');
  const li = template.content.firstElementChild.cloneNode(true);
  li.querySelector('.task__title').textContent = task.title;
  li.querySelector('.task__room').textContent = task.room;
  li.classList.toggle('is-done', task.done);
  li.querySelector('.task__toggle').checked = task.done;
  li.querySelector('.task__delete').setAttribute('aria-label', `Smazat úkol ${task.title}`);
  li.querySelector('.task__toggle').addEventListener('change', () => toggleTask(task.id));
  li.querySelector('.task__delete').addEventListener('click', () => deleteTask(task.id));
  return li;
}

function render() {
  const items = tasks.map((task) => createTaskElement(task));
  document.querySelector('#task-list').replaceChildren(...items);
  document.querySelector('#open-count').textContent = countOpen(tasks);
  document.querySelector('#total-count').textContent = tasks.length;
  document.querySelector('#empty-state').hidden = tasks.length > 0;
  document.querySelector('#clear-done').disabled = !tasks.some((task) => task.done);
  document
    .querySelector('#progress-bar')
    .style.setProperty('--progress', `${progressPercent(tasks)}%`);
}

function toggleTask(id) {
  tasks = tasks.map((task) => (task.id === id ? { ...task, done: !task.done } : task));
  render();
}

function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
  render();
}

document.querySelector('#move-title').textContent = import.meta.env.VITE_MOVE_TITLE;
document.querySelector('#move-date').textContent = `Termín: ${import.meta.env.VITE_MOVE_DATE}`;
document.querySelector('#empty-image').src = emptyBoxesUrl;

render();

document.querySelector('#add-form').addEventListener('submit', (event) => {
  event.preventDefault();
  const title = document.querySelector('#task-title').value.trim();
  if (title === '') {
    return;
  }
  tasks = [...tasks, createTask(title)];
  render();
  event.target.reset();
});

document.querySelector('#clear-done').addEventListener('click', () => {
  tasks = tasks.filter((task) => !task.done);
  render();
});

```

## --file-- tasks.js

```js
// Čisté funkce nad seznamem úkolů. Nesahají na stránku.

export function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

export function progressPercent(items) {
  if (items.length === 0) {
    return 0;
  }
  const doneCount = items.length - countOpen(items);
  return Math.round((doneCount / items.length) * 100);
}
```
