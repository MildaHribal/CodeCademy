# --description--

Na konci směny chce vedoucí vědět, kolik účtenek pokladna vydala. To číslo už existuje:
je to `lastNumber` z modulu číslování.

**Úkol:** na úplný konec výstupu `app.js` přidej prázdný řádek a pod něj
`Dnes vydáno účtenek: 2`. Číslo nepiš natvrdo — vezmi ho z `lastNumber`. `app.js` si ze
složky `orders/` bere věci jen přes `orders/index.js`, takže tam `lastNumber` musí
přibýt taky.

Všimni si, kde import stojí: na prvním řádku souboru, ještě než vznikla jakákoli
objednávka a `lastNumber` byla nula. Po **Spustit** přesto uvidíš dvojku. Proč, si
rozmysli v otázce po splnění kroku.

# --hints--

Poslední řádek výstupu je `Dnes vydáno účtenek: 2` a nad ním je prázdný řádek.

```js
const sameLine = (a) => a.normalize('NFC').replace(/ /g, ' ').replace(/\s+/g, ' ').trim();
const result = await helpers.run('node app.js');
assert.equal(result.code, 0, `node app.js má doběhnout bez chyby:\n${result.stderr}`);
const lines = result.stdout.split('\n').map(sameLine);

assert.equal(lines.at(-1), 'Dnes vydáno účtenek: 2', `Poslední řádek výstupu má být „Dnes vydáno účtenek: 2". Vypsalo se:\n${result.stdout}`);
assert.equal(lines.at(-2), '', 'Nad řádkem „Dnes vydáno účtenek: 2" má být prázdný řádek');
```

`orders/index.js` vystavuje `lastNumber` a ta se po založení objednávek mění.

```js
const orders = await helpers.importFile('orders/index.js');
assert.equal(orders.lastNumber, 0, 'lastNumber z orders/index.js má před první objednávkou být 0');
orders.createOrder(1);
orders.createOrder(2);
orders.createOrder(4);
assert.equal(orders.lastNumber, 3, 'po třech createOrder má lastNumber z orders/index.js být 3');
```

`app.js` bere počet z `lastNumber` importované přes `./orders/index.js`, ne z čísla napsaného natvrdo.

```js
const app = helpers.stripComments(files['app.js'], 'js');
const imports = [...app.matchAll(/import\s*\{([^}]*)\}\s*from\s*['"]\.\/orders\/index\.js['"]/g)].map((m) => m[1]).join(',');
const namespace = app.match(/import\s*\*\s*as\s+([\w$]+)\s+from\s*['"]\.\/orders\/index\.js['"]/);
const viaNamespace = namespace && new RegExp(`\\b${namespace[1]}\\.lastNumber\\b`).test(app);
assert.ok(/\blastNumber\b/.test(imports) || viaNamespace, 'app.js má importovat lastNumber z ./orders/index.js');
assert.doesNotMatch(app, /účtenek:\s*2/, 'Číslo 2 nemá být v app.js napsané natvrdo — vypiš lastNumber');
```

# --explain--

Import `lastNumber` stojí na prvním řádku `app.js`, kdy byla hodnota nula. Vysvětli,
proč se na konci vypíše 2.

## --model--

Import není kopie hodnoty z okamžiku importu, ale živá vazba na proměnnou v modulu
číslování. Každé `createOrder` zavolá `nextOrderNumber`, která proměnnou uvnitř modulu
zvýší. Když `app.js` na konci `lastNumber` čte, dívá se na aktuální hodnotu, tedy 2.
Přiřadit do ní sám nemůže, mění ji jen modul, kterému patří.

## --checklist--

- Import je živá vazba, ne kopie hodnoty.
- Hodnotu mění funkce uvnitř modulu, která se volá při založení objednávky.
- Čtení na konci vidí aktuální stav proměnné v modulu.
- Importující soubor do vazby přiřadit nesmí.

# --help--

## --tip--

Jde o [živé vazby](see:nastroje-moduly-vite/es-moduly#zive-vazby): importované jméno
ukazuje na proměnnou v modulu, ne na její starou hodnotu.

## --tip--

Změny jsou dvě: seznam re-exportů v `orders/index.js` dostane nový řádek pro soubor
s číslováním a import na začátku `app.js` jedno jméno navíc. Výpis patří na úplný konec
`app.js`.

## --tip--

Stejný princip jinde: e-shop importuje `registeredCount` z modulu registrací
a po odeslání formulářů vypíše „Přihlášeno: …" s aktuální hodnotou, ne s tou
z načtení stránky.

```js
// Objednávky: založení, položky a součty.
import { findItem } from '../menu.js';
import { nextOrderNumber } from './numbering.js';

export function createOrder(table) {
  return { number: nextOrderNumber(), table, lines: [] };
}

export function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

export function lineTotal(line) {
  return line.price * line.quantity;
}

export function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

export function itemCount(order) {
  return order.lines.reduce((sum, line) => sum + line.quantity, 0);
}
```

## --file-- orders/receipt.js

```js
// Tisk účtenky. Přestěhoval sem Tomáš z app.js.
import { formatPrice } from '../money.js';
import { format as formatDate } from '../dates.js';
import { lineTotal, orderTotal } from './order.js';

const RECEIPT_WIDTH = 32;

function padLine(left, right) {
  return left.padEnd(RECEIPT_WIDTH - right.length) + right;
}

export function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table} · ${formatDate(new Date())}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}
```
