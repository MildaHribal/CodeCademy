# --description--

Stůl 5 jsou studenti a kavárna jim dává 10 % slevu. Tomáš na ni napsal modul
`discounts.js`, ale funkci vyexportoval jako **výchozí export bez jména**. Každý, kdo
ji importuje, si jméno vymyslí sám — v jednom souboru bude `discount`, v druhém
`studentSale` a hledání v projektu ji nenajde.

**Úkol:**

1. V `discounts.js` z výchozího exportu udělej [[pojmenovaný export]] `studentDiscount`.
   Výchozí export už modul mít nebude.
2. V `app.js` si `studentDiscount` importuj a pod řádek `Kusů celkem: 5` účtenky
   stolu 5 vypiš `Studentská sleva: -39 Kč`. Sleva se počítá z celkové ceny objednávky.

Na přepis se hodí zápis `export function jméno(…)` nebo funkce bez `export` a seznam
`export { … }` na konci — vyber si. Takhle vypadá stejná úprava v jiném modulu:

```js
// před: export default function (email) { … }
export function isValidEmail(email) {
  return email.includes('@');
}
```

# --hints--

`discounts.js` exportuje pojmenovanou funkci `studentDiscount` a výchozí export nemá.

```js
const discounts = await helpers.importFile('discounts.js');
assert.equal(typeof discounts.studentDiscount, 'function', 'discounts.js má exportovat funkci studentDiscount');
assert.equal('default' in discounts, false, 'discounts.js už nemá mít výchozí export (export default)');
assert.equal(discounts.studentDiscount(385), 39, 'studentDiscount(385) má vrátit 39 (10 % zaokrouhleno)');
assert.equal(discounts.studentDiscount(200), 20, 'studentDiscount(200) má vrátit 20');
```

Pod řádkem `Kusů celkem: 5` je `Studentská sleva: -39 Kč`.

```js
const sameLine = (a) => a.normalize('NFC').replace(/ /g, ' ').replace(/\s+/g, ' ').trim();

# --explain--

Vysvětli, proč je u vlastních funkcí lepší pojmenovaný export než výchozí.

## --model--

Pojmenovaný export má jedno jméno, které musí použít každý import, takže funkci
najdu hledáním v projektu a editor ji umí přejmenovat všude najednou. Výchozí export si
každý soubor pojmenuje po svém a stejná funkce pak žije pod několika jmény. Výchozí
export nechávám tam, kde ho vyžaduje nástroj, třeba u konfiguračního souboru.

## --checklist--

- Pojmenovaný export vynutí stejné jméno ve všech importech.
- U výchozího exportu si jméno volí každý import sám.
- Jedno jméno usnadní hledání a přejmenování v celém projektu.
- Výchozí export má smysl tam, kde ho čeká nástroj nebo framework.

# --help--

## --tip--

Rozdíl mezi výchozím a pojmenovaným exportem a jak se který importuje, je
v části [Výchozí export](see:nastroje-moduly-vite/es-moduly#vychozi-export).

## --tip--

V `discounts.js` se mění jen řádek s `export default`: funkce potřebuje jméno a jiný
druh exportu. V `app.js` přibude import ve složených závorkách a jeden `console.log`
za výpisem počtu kusů stolu 5. Celkovou cenu vrací `orderTotal`, kterou vystavuje
`orders/index.js`.

## --tip--

Stejný tvar výpisu na jiných datech: ``console.log(`Záloha: -${formatPrice(deposit)}`)``
nebo s číslem, které už znaménko má, ``console.log(`Vratka: ${formatPrice(-refund)}`)``.

// Objednávky: založení, položky a součty.
import { findItem } from '../menu.js';

export function createOrder(table) {
  return { table, lines: [] };
}

export function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

export function lineTotal(line) {
  return line.price * line.quantity;
}

export function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

export function itemCount(order) {
  return order.lines.reduce((sum, line) => sum + line.quantity, 0);
}
```

## --file-- orders/receipt.js

```js
// Tisk účtenky. Přestěhoval sem Tomáš z app.js.
import { formatPrice } from '../money.js';
import { format as formatDate } from '../dates.js';
import { lineTotal, orderTotal } from './order.js';

const RECEIPT_WIDTH = 32;

function padLine(left, right) {
  return left.padEnd(RECEIPT_WIDTH - right.length) + right;
}

export function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table} · ${formatDate(new Date())}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}
```
