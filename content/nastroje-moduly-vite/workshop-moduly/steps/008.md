# --description--

Vstupní soubor složky je hotový. Teď ho začne používat `app.js` — a s tím přijde
první nová funkce pokladny. Barista chce pod každou účtenkou vidět, kolik kusů má
připravit.

**Úkol:**

- Pod řádek `Celkem` každé účtenky přidej řádek `Kusů celkem: N`, kde `N` je součet
  kusů ze všech řádků objednávky. Stůl 3 má 3 kusy, stůl 5 jich má 5.
- Po úpravě si `app.js` bere cokoli ze složky `orders/` **jen přes `./orders/index.js`**,
  nikdy přímo z `order.js` nebo `receipt.js`.
- Funkce, které používají jen soubory uvnitř `orders/` (třeba `lineTotal`), ven přes
  `index.js` nepouštěj.

Kde počet kusů spočítáš, je na tobě: může to být nová funkce ve složce objednávek,
kterou vystavíš, nebo výpočet přímo tam, kde se řádek tiskne. Rozhodni se podle toho,
kde by ho hledal kolega, který pokladnu uvidí poprvé.

# --hints--

Pod účtenkou stolu 3 je řádek `Kusů celkem: 3` a pod účtenkou stolu 5 řádek `Kusů celkem: 5`.

```js
const sameLine = (a) => a.normalize('NFC').replace(/ /g, ' ').replace(/\s+/g, ' ').trim();
const result = await helpers.run('node app.js');
assert.equal(result.code, 0, `node app.js má doběhnout bez chyby:\n${result.stderr}`);
const lines = result.stdout.split('\n').map(sameLine);
const first = lines.indexOf('Celkem 215 Kč');
const second = lines.indexOf('Celkem 385 Kč');
assert.ok(first >= 0 && second >= 0, `Obě účtenky mají dál končit součtem 215 Kč a 385 Kč. Vypsalo se:\n${result.stdout}`);
assert.equal(lines[first + 1], 'Kusů celkem: 3', 'Pod řádkem „Celkem 215 Kč" (stůl 3) má být „Kusů celkem: 3"');
assert.equal(lines[second + 1], 'Kusů celkem: 5', 'Pod řádkem „Celkem 385 Kč" (stůl 5) má být „Kusů celkem: 5"');
```

`app.js` importuje ze složky `orders/` jen přes `./orders/index.js`.

```js
const app = helpers.stripComments(files['app.js'], 'js');
const sources = [...app.matchAll(/from\s*['"]([^'"]+)['"]/g)].map((m) => m[1]);
const fromOrders = sources.filter((source) => source.startsWith('./orders/'));
assert.ok(fromOrders.length > 0, 'app.js má importovat z ./orders/index.js');
for (const source of fromOrders) {
  assert.equal(source, './orders/index.js', `app.js importuje z ${source} — ze složky orders/ má brát jen přes ./orders/index.js`);
}
```

`orders/index.js` nepouští ven vnitřní funkci `lineTotal`, ale `createOrder`, `addItem` a `renderReceipt` ano.

```js
const orders = await helpers.importFile('orders/index.js');
assert.equal('lineTotal' in orders, false, 'orders/index.js nemá vystavovat lineTotal — používají ji jen soubory uvnitř složky');
for (const name of ['createOrder', 'addItem', 'renderReceipt']) {
  assert.equal(typeof orders[name], 'function', `orders/index.js má dál vystavovat ${name}`);
}
```

# --explain--

Vysvětli, proč má `app.js` importovat z `./orders/index.js`, a ne rovnou
z `./orders/order.js`, i když by to fungovalo stejně.

## --model--

`index.js` je veřejné rozhraní složky: říká, na co smí zbytek aplikace spoléhat.
Když `app.js` importuje jen přes něj, můžu funkce uvnitř složky přesouvat mezi soubory
a stačí upravit `index.js`. Co v `index.js` není, je vnitřní věc složky a můžu to
kdykoli změnit, aniž by se něco rozbilo jinde.

## --checklist--

- `index.js` určuje veřejné rozhraní složky.
- Přesun funkce mezi soubory uvnitř složky změní jen `index.js`, ne importy jinde.
- Co `index.js` nevystavuje, se dá měnit bez rizika pro zbytek aplikace.

# --help--

## --tip--

Jde o [veřejné rozhraní a `index.js`](see:nastroje-moduly-vite/es-moduly#verejne-rozhrani-a-index-js).
Počet kusů je součet přes řádky objednávky, podobně jako cena v prvním kroku.

## --tip--

Změny se týkají importů na začátku `app.js` (kam míří), případně seznamu v
`orders/index.js`, když přidáš novou funkci. Tisk řádku patří k místu, kde se tiskne
účtenka.

## --tip--

Stejné rozhodnutí v jiném projektu: e-shop potřebuje „Zboží v košíku: 4". Buď přibude
`cartCount(cart)` vedle `cartTotal` ve složce `cart/` a `cart/index.js` ji vystaví,
nebo se počet spočítá přímo při vykreslení. Import z `./cart/items.js` mimo složku ale
nepatří nikam.

```js
// Objednávky: založení, položky a součty.
import { findItem } from '../menu.js';

export function createOrder(table) {
  return { table, lines: [] };
}

export function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

export function lineTotal(line) {
  return line.price * line.quantity;
}

export function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}
```

## --file-- orders/receipt.js

```js
// Tisk účtenky. Přestěhoval sem Tomáš z app.js.
import { formatPrice } from '../money.js';
import { format as formatDate } from '../dates.js';
import { lineTotal, orderTotal } from './order.js';

const RECEIPT_WIDTH = 32;

function padLine(left, right) {
  return left.padEnd(RECEIPT_WIDTH - right.length) + right;
}

export function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table} · ${formatDate(new Date())}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}
```
