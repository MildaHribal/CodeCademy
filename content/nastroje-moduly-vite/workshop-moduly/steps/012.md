# --description--

Účetní připravila modul `reports/daily.js` s denním přehledem tržeb. Tiskne se jen
při uzávěrce, kdy se pokladna spustí s přepínačem: `node app.js --report`. Při běžném
tisku účtenek je modul k ničemu, a proto se nemá ani načíst.

Argumenty příkazové řádky má Node v poli `process.argv`. Jestli mezi nimi přepínač je,
zjistíš stejně jako u jakéhokoli pole.

**Úkol:** když je pokladna spuštěná s `--report`, načti `reports/daily.js`
[[dynamický import|dynamickým importem]] a na úplný konec výstupu přidej prázdný řádek
a přehled, který vrátí jeho funkce `renderDailyReport` pro obě objednávky. Bez
přepínače se modul nenačte vůbec a výstup zůstane jako dřív.

Tlačítko **Spustit** pouští pokladnu bez přepínače, takže přehled v jeho výstupu
neuvidíš. Oba způsoby spuštění vyzkouší kontrola a výsledek najdeš u požadavků.


`node app.js` bez přepínače přehled nevypíše a končí řádkem `Dnes vydáno účtenek: 2`.

```js
const sameLine = (a) => a.normalize('NFC').replace(/ /g, ' ').replace(/\s+/g, ' ').trim();

assert.equal(result.code, 0, `node app.js má doběhnout bez chyby:\n${result.stderr}`);

```

`app.js` načítá `reports/daily.js` přes `import()`, ne statickým importem na začátku.

```js
const app = helpers.stripComments(files['app.js'], 'js');
assert.doesNotMatch(app, /import\s[^()]*?from\s*['"][^'"]*daily\.js['"]/, 'app.js nemá importovat reports/daily.js staticky — modul se má načíst až s přepínačem');
assert.match(app, /import\s*\(\s*['"`]\.\/reports\/daily\.js['"`]\s*\)/, "app.js má modul načíst přes import('./reports/daily.js')");
```

## --tip--

Načtení modulu až za běhu popisuje část
[Dynamický `import()`](see:nastroje-moduly-vite/es-moduly#dynamicky-import). Vrací
Promise, takže na výsledek počkáš přes `await` — v ES modulu i mimo funkci.

## --tip--

Kód patří na konec `app.js` do podmínky, která se ptá pole argumentů na přepínač.
Uvnitř podmínky modul načteš, z výsledku si vezmeš funkci a vypíšeš prázdný řádek
a přehled.

## --tip--

Stejný vzor jinde: tlačítko „Exportovat do PDF" si až po kliknutí vezme
`const { exportPdf } = await import('./pdf.js')` a teprve pak ji zavolá.

```js
// Objednávky: založení, položky a součty.
import { findItem } from '../menu.js';
import { nextOrderNumber } from './numbering.js';

export function createOrder(table) {
  return { number: nextOrderNumber(), table, lines: [] };
}

export function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

export function lineTotal(line) {
  return line.price * line.quantity;
}

export function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

export function itemCount(order) {
  return order.lines.reduce((sum, line) => sum + line.quantity, 0);
}
```

## --file-- orders/receipt.js

```js
// Tisk účtenky. Přestěhoval sem Tomáš z app.js.
import { formatPrice } from '../money.js';
import { format as formatDate } from '../dates.js';
import { lineTotal, orderTotal } from './order.js';

const RECEIPT_WIDTH = 32;

function padLine(left, right) {
  return left.padEnd(RECEIPT_WIDTH - right.length) + right;
}

export function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table} · ${formatDate(new Date())}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}
```

```js
// Denní přehled tržeb pro uzávěrku. Připravila účetní Petra.
import { orderTotal } from '../orders/index.js';
import { formatPrice } from '../money.js';

export function renderDailyReport(orders) {
  const revenue = orders.reduce((sum, order) => sum + orderTotal(order), 0);
  return ['Denní přehled', `Počet účtenek: ${orders.length}`, `Tržba celkem: ${formatPrice(revenue)}`].join('\n');
}
```
