# --description--

Kavárna Na Kopečku má pokladnu, která tiskne účtenky ke stolům. Napsal ji brigádník
za jeden víkend a všechno je v jediném souboru `app.js`: ceník, formátování cen,
objednávky i tisk účtenky. Funguje to, ale do souboru se bojí kdokoli sáhnout. V tomhle
workshopu ho rozsekáš do modulů tak, aby každý soubor dělal jednu věc a zbytek
aplikace viděl jen to, co vidět má.

Tlačítko **Spustit** pustí `node app.js` a ve výstupu uvidíš dvě účtenky. Jen jim
chybí součet — místo ceny je tam `undefined Kč`.

První krok je z JavaScriptu, který už umíš — bez návodu.

**Úkol:** v `app.js` doplň tělo funkce `orderTotal(order)`. Vrátí součet všech řádků
objednávky, tedy pro každý řádek cenu krát počet kusů. Objednávka vypadá takhle:

```js
{ table: 3, lines: [{ name: 'Flat white', price: 75, quantity: 2 }] }
```

součet začínal číslem, a ne prvním řádkem objednávky.

## --file-- app.js

```js
// Pokladna kavárny Na Kopečku. Zatím je všechno v jednom souboru.

const menu = [
  { id: 'flat-white', name: 'Flat white', price: 75 },
  { id: 'espresso', name: 'Espresso', price: 55 },
  { id: 'croissant', name: 'Croissant', price: 65 },
  { id: 'cheesecake', name: 'Cheesecake', price: 89 },
  { id: 'lemonade', name: 'Domácí limonáda', price: 69 },
];

function findItem(id) {
  return menu.find((item) => item.id === id);
}

function formatPrice(amount) {
  return `${amount} Kč`;
}

function createOrder(table) {
  return { table, lines: [] };
}

function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

function lineTotal(line) {
  return line.price * line.quantity;
}

function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

function padLine(left, right, width = 32) {
  return left.padEnd(width - right.length) + right;
}

function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}

let tableThree = createOrder(3);
tableThree = addItem(tableThree, 'flat-white', 2);
tableThree = addItem(tableThree, 'croissant');

let tableFive = createOrder(5);
tableFive = addItem(tableFive, 'lemonade', 3);
tableFive = addItem(tableFive, 'cheesecake', 2);

console.log(renderReceipt(tableThree));
console.log('');
console.log(renderReceipt(tableFive));
```
