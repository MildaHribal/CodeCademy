# --description--

Objednávky jsou největší kus pokladny a časem jich přibude: slevy, spropitné, číslování.
Dostanou proto vlastní složku `orders/`. První soubor v ní bude `orders/order.js`.

Relativní cesta v importu se počítá **od souboru, ve kterém import stojí**. Z
`orders/order.js` je `menu.js` o složku výš, takže cesta začíná `../`. Z `app.js`
v kořeni je naopak složka `orders` vedle, takže cesta začíná `./orders/`.

**Úkol:**

1. Přesuň z `app.js` do `orders/order.js` funkce `createOrder`, `addItem`, `lineTotal`
   a `orderTotal`. Každou z nich exportuj.
2. `addItem` potřebuje `findItem` — importuj ji v `orders/order.js` z `../menu.js`.
3. V `app.js` importuj všechny čtyři funkce z `./orders/order.js`. Import `findItem`
   z `app.js` už nepotřebuješ, smaž ho.

Stejný vzor v jiném projektu — soubor ve složce `pages/` si bere modul z kořene
a kořen si bere stránku ze složky:

```js
// pages/contact.js
import { sendEmail } from '../mailer.js';

// main.js
import { renderContact } from './pages/contact.js';
```

```js
// Pokladna kavárny Na Kopečku. Zatím je všechno v jednom souboru.
import { formatPrice } from './money.js';
import { findItem } from './menu.js';

function createOrder(table) {
  return { table, lines: [] };
}

function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

function lineTotal(line) {
  return line.price * line.quantity;
}

function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

function padLine(left, right, width = 32) {
  return left.padEnd(width - right.length) + right;
}

function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}

let tableThree = createOrder(3);
tableThree = addItem(tableThree, 'flat-white', 2);
tableThree = addItem(tableThree, 'croissant');

let tableFive = createOrder(5);
tableFive = addItem(tableFive, 'lemonade', 3);
tableFive = addItem(tableFive, 'cheesecake', 2);

console.log(renderReceipt(tableThree));
console.log('');
console.log(renderReceipt(tableFive));
```
