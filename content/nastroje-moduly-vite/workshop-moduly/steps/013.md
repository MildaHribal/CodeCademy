# --description--

Kavárna měla dřív jinou pokladnu a z ní zůstal věrnostní program: soubor
`legacy/loyalty.cjs`, psaný postaru v CommonJS. Tomáš ho zapojil, aby se pod účtenkou
stolu 3 ukázaly věrnostní body.

## Hlášení

Od Tomášovy úpravy se nevytiskne vůbec nic, ani účtenky. V terminálu je:

```text
file:///home/tomas/pokladna/app.js:5
const loyalty = require('./legacy/loyalty.cjs');
                ^

ReferenceError: require is not defined in ES module scope, you can use import instead
    at file:///home/tomas/pokladna/app.js:5:17

Node.js v26.5.1
```

## Úkol

Zapoj starý modul tak, aby pod řádkem `Kusů celkem: 3` bylo `Věrnostní body: 4`
a zbytek výstupu zůstal jako dřív. Soubor `legacy/loyalty.cjs` neměň, používá ho i stará
pokladna. Změň co nejmenší kus kódu.

# --help--

## --tip--

Jde o rozdíl mezi CommonJS a ES moduly. Jak se starý soubor použije z ES modulu, je
v části [CommonJS v cizím kódu](see:nastroje-moduly-vite/es-moduly#commonjs-v-cizim-kodu).

## --tip--

Hláška ukazuje na řádek 5 v `app.js`. Soubor je ES modul (`"type": "module"`), a tam
`require` neexistuje. Místo toho řádku patří import mezi ostatní importy nahoře.

## --tip--

Stejná oprava jinde: `const config = require('./old-config.cjs')` se v ES modulu píše
jako výchozí import ze stejného souboru a dál se používá `config.něco` jako předtím.

```js
// Objednávky: založení, položky a součty.
import { findItem } from '../menu.js';
import { nextOrderNumber } from './numbering.js';

export function createOrder(table) {
  return { number: nextOrderNumber(), table, lines: [] };
}

export function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

export function lineTotal(line) {
  return line.price * line.quantity;
}

export function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

export function itemCount(order) {
  return order.lines.reduce((sum, line) => sum + line.quantity, 0);
}
```

## --file-- orders/receipt.js

```js
// Tisk účtenky. Přestěhoval sem Tomáš z app.js.
import { formatPrice } from '../money.js';
import { format as formatDate } from '../dates.js';
import { lineTotal, orderTotal } from './order.js';

const RECEIPT_WIDTH = 32;

function padLine(left, right) {
  return left.padEnd(RECEIPT_WIDTH - right.length) + right;
}

export function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table} · ${formatDate(new Date())}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}
```

```js
import { orderTotal } from '../orders/index.js';

export function renderDailyReport(orders) {
  const revenue = orders.reduce((sum, order) => sum + orderTotal(order), 0);
  return ['Denní přehled', `Počet účtenek: ${orders.length}`, `Tržba celkem: ${formatPrice(revenue)}`].join('\n');
```

```js
var POINT_VALUE = 50;

module.exports = {
  pointsFor: function (total) {
    return Math.floor(total / POINT_VALUE);
  },
  tierFor: function (points) {
    return points >= 100 ? 'zlatý host' : 'host';

};
```
