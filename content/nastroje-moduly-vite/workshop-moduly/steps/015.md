# --description--

Poslední funkce pokladny: pod účtenkou doporučí spropitné. Tentokrát bez návodu —
nový modul, jeho místo ve veřejném rozhraní i výpis navrhni sám.

**Úkol:**

- V `orders/tips.js` napiš funkci `tipAmount(order, percent)`. Vrátí spropitné jako
  daný počet procent z celkové ceny objednávky, zaokrouhlené na celé koruny.
- Zbytek pokladny ji dostane přes `orders/index.js`, jako ostatní funkce objednávek.
- Pod řádek `Věrnostní body: 4` vypiš `Doporučené spropitné 10 %: 22 Kč`.

Tady máš hotovou pokladnu. Místo jednoho souboru, do kterého se nikdo neodvážil
sáhnout, má moduly s jasnou prací: peníze, ceník v JSON, složku objednávek s jedním
vstupem, sdílené číslování přes živou vazbu, přehled načítaný až na požádání a zapojený
starý modul v CommonJS. Přesně takhle vypadá složka `src/` v každém projektu ve Vite
nebo v Reactu — jen tam moduly místo textu vracejí kusy stránky.

V další lekci zjistíš, co přesně je `package.json`, který tu celou dobu tiše zapínal
`"type": "module"`, a jak si do projektu vzít cizí balíček z npm.

## Udělej po svém

- **Vzhled účtenky:** přidej do `orders/receipt.js` oddělovací čáru ze znaků `─`
  a zarovnej ji na šířku účtenky. Vnitřní konstanta šířky ti pomůže.
- **Nová funkce:** modul `orders/split.js`, který rozdělí účet stolu mezi víc lidí
  a zbytek po dělení přičte prvnímu. Vystav ho přes `orders/index.js`.
- **Denní přehled:** doplň do `reports/daily.js` nejprodávanější položku dne.
- **Tvoje téma:** přestav pokladnu na jiný podnik, který znáš — pizzerii, knihkupectví
  nebo půjčovnu kol. Stačí změnit `menu.json` a texty účtenky.

# --hints--

`tipAmount` z `orders/index.js` vrátí procenta z ceny objednávky zaokrouhlená na koruny: 10 % z 110 Kč je 11, 15 % z 385 Kč je 58.

```js
const orders = await helpers.importFile('orders/index.js');
assert.equal(typeof orders.tipAmount, 'function', 'orders/index.js má vystavovat funkci tipAmount');
const coffee = orders.addItem(orders.createOrder(1), 'espresso', 2);
assert.equal(orders.tipAmount(coffee, 10), 11, "tipAmount pro 2× espresso (110 Kč) a 10 % má vrátit 11");
let students = orders.addItem(orders.createOrder(2), 'lemonade', 3);
students = orders.addItem(students, 'cheesecake', 2);
assert.equal(orders.tipAmount(students, 15), 58, 'tipAmount pro objednávku za 385 Kč a 15 % má vrátit 58 (57,75 zaokrouhleno)');
assert.equal(orders.tipAmount(orders.createOrder(3), 10), 0, 'tipAmount pro prázdnou objednávku má vrátit 0');
```

```js
// Objednávky: založení, položky a součty.
import { findItem } from '../menu.js';
import { nextOrderNumber } from './numbering.js';

export function createOrder(table) {
  return { number: nextOrderNumber(), table, lines: [] };
}

export function addItem(order, id, quantity = 1) {
  const item = findItem(id);
  const line = { name: item.name, price: item.price, quantity };
  return { ...order, lines: [...order.lines, line] };
}

export function lineTotal(line) {
  return line.price * line.quantity;
}

export function orderTotal(order) {
  return order.lines.reduce((sum, line) => sum + lineTotal(line), 0);
}

export function itemCount(order) {
  return order.lines.reduce((sum, line) => sum + line.quantity, 0);
}
```

## --file-- orders/receipt.js

```js
// Tisk účtenky. Přestěhoval sem Tomáš z app.js.
import { formatPrice } from '../money.js';
import { format as formatDate } from '../dates.js';
import { lineTotal, orderTotal } from './order.js';

const RECEIPT_WIDTH = 32;

function padLine(left, right) {
  return left.padEnd(RECEIPT_WIDTH - right.length) + right;
}

export function renderReceipt(order) {
  const rows = order.lines.map((line) =>
    padLine(`${line.quantity}× ${line.name}`, formatPrice(lineTotal(line))),
  );
  return [
    `Kavárna Na Kopečku · stůl ${order.table} · ${formatDate(new Date())}`,
    ...rows,
    padLine('Celkem', formatPrice(orderTotal(order))),
  ].join('\n');
}
```
