# --description--

Teď přijde obsah katalogu. Nejdřív napíšeš jednu kartu ručně — ať je vidět, co se v ní vlastně opakuje, až jich bude šest.

**Úkol:** Pod hlavičku přidej seznam `<ul className="seznam">` a v něm jednu položku `<li className="karta">` s údaji první hry z pole `hry`:

- `<div className="karta__stitky">` a v něm štítek **Sleva** s druhem `sleva`,
- nadpis `h3` s třídou `karta__nazev` a názvem hry,
- odstavec `karta__meta` ve tvaru **Kooperativní · 1–4 hráčů · 90 min** (kategorie, počet hráčů, délka z dat),
- odstavec `karta__popis` s popisem,
- odstavec `cena` a v něm `<strong className="cena__aktualni">` s cenou a slovem **Kč**.

Všechny hodnoty ber z `hry[0]`, ať se karta změní, až se změní data.

# --hints--

Pod hlavičkou je seznam s jednou kartou.

```js
const seznam = document.querySelector('.stranka .seznam');
assert.ok(seznam, 'pod hlavičkou má být <ul className="seznam">');
const karty = seznam.querySelectorAll('.karta');
assert.equal(karty.length, 1, 'zatím má v seznamu být jedna karta');
assert.equal(karty[0].tagName, 'LI', 'karta má být položka seznamu <li>');
```

Karta ukazuje název, kategorii, hráče, délku a popis první hry.

```js
const { hry } = await helpers.importFile('data.js');
const prvni = hry[0];
const karta = document.querySelector('.karta');
assert.equal(karta.querySelector('.karta__nazev').textContent.trim(), prvni.nazev, 'nadpis karty má být název první hry');
const meta = karta.querySelector('.karta__meta').textContent;
assert.ok(meta.includes(prvni.kategorie), 'v metařádku má být kategorie');
assert.ok(meta.includes(prvni.hraci), 'v metařádku má být počet hráčů');
assert.ok(meta.includes(String(prvni.delka)), 'v metařádku má být délka hry');
assert.equal(karta.querySelector('.karta__popis').textContent.trim(), prvni.popis, 'v kartě má být popis hry');
```

V kartě je cena z dat a štítek se slevou.

```js
const { hry } = await helpers.importFile('data.js');
const karta = document.querySelector('.karta');
assert.match(karta.querySelector('.cena__aktualni').textContent, new RegExp(String(hry[0].cena)), 'v kartě má být cena první hry');
const stitek = karta.querySelector('.karta__stitky .stitek');
assert.ok(stitek, 'v kartě má být štítek uvnitř .karta__stitky');
assert.equal(stitek.textContent.trim(), 'Sleva', 'štítek má mít text „Sleva"');
assert.ok(stitek.classList.contains('stitek--sleva'), 'štítek má mít druh sleva');
```

# --help--

## --tip--

Hodnoty z objektu se do JSX dostávají výrazem — viz [Výrazy v `{}`](see:react-zaklady/proc-react#vyrazy-v).

## --tip--

První hru vybereš indexem z pole `hry`. Značkování karty opiš podle tříd v zadání, hodnoty ber z objektu tečkou.

## --tip--

Oddělovač `·` je obyčejný text mezi dvěma výrazy, stejně jako v programu festivalu.

## --file-- utils.js

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```
