# --description--

Postavíš katalog e-shopu s deskovými hrami: karty her se štítky, cenami, slevami a hodnocením, panel novinek a celý katalog seřazený podle ceny. Tentokrát ale nebudeš psát značkování pořád dokola — stránku složíš z komponent, kterým budeš posílat [[props]].

Data a vzhled jsou hotové. Začneš zase kouskem obyčejného JavaScriptu.

V `utils.js` je funkce `prumerneHodnoceni`, která zatím vrací nulu. V hlavičce katalogu proto svítí „průměrné hodnocení 0 z 5".

**Úkol:** Doplň `prumerneHodnoceni(hry)` tak, aby vrátila průměr vlastnosti `hodnoceni` všech her zaokrouhlený na jedno desetinné místo (u dat v `data.js` vyjde 4.2).

Součet přes pole vypadá na jiných datech takhle:

```js
// 1. sečti, co potřebuješ
const minut = filmy.reduce((celkem, film) => celkem + film.delka, 0);
// 2. zbytek je obyčejné počítání
const prumer = minut / filmy.length;
```

# --hints--

`prumerneHodnoceni(hry)` vrátí 4.2.

```js
const { prumerneHodnoceni } = await helpers.importFile('utils.js');
const { hry } = await helpers.importFile('data.js');
assert.equal(prumerneHodnoceni(hry), 4.2, 'prumerneHodnoceni(hry) má vrátit 4.2 (součet 25 hodnocení děleno šesti hrami)');
```

Funguje i na jiných datech a zaokrouhluje na jedno desetinné místo.

```js
const { prumerneHodnoceni } = await helpers.importFile('utils.js');
assert.equal(prumerneHodnoceni([{ hodnoceni: 1 }, { hodnoceni: 2 }]), 1.5, 'průměr z hodnocení 1 a 2 je 1.5');
assert.equal(prumerneHodnoceni([{ hodnoceni: 5 }, { hodnoceni: 4 }, { hodnoceni: 4 }]), 4.3, 'průměr 4.333… se má zaokrouhlit na 4.3');
```

V hlavičce katalogu je spočítaný průměr vidět.

```js
const meta = document.querySelector('.hlavicka__meta');
assert.ok(meta, 'v hlavičce má zůstat odstavec .hlavicka__meta');
assert.match(meta.textContent, /4[.,]2/, 'hlavička má ukazovat průměrné hodnocení 4.2');
assert.match(meta.textContent, /6 her/, 'hlavička má dál ukazovat počet her v katalogu');
```

# --help--

## --tip--

Jde o součet přes pole, který jsi psal v části [Jak pracuje `reduce`](see:js-pole/metody-pole-do-hloubky#jak-pracuje-reduce). Poslouží i `for…of`, na tvaru nezáleží.

## --tip--

Nejdřív součet hodnocení, pak dělení počtem her. Zaokrouhlení na jedno desetinné místo udělá `Math.round` po vynásobení deseti (a zpětném dělení).

## --tip--

```js
// 1. sečti hodnocení všech her
// 2. vyděl počtem her
// 3. zaokrouhli na jedno desetinné místo a vrať
```

# --solution--

## --file-- utils.js

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```
