# --description--

Číslo „4 z 5" nikdo nečte, hvězdičky ano. V datech má každá hra `hodnoceni` od jedné do pěti.

**Úkol:** Vytvoř soubor `Hodnoceni.jsx` s komponentou `Hodnoceni`, která dostane prop `hvezdicek` a vykreslí odstavec s třídou `hodnoceni`, ve kterém je tolik plných hvězdiček (znak ★), kolik je hodnocení, a zbytek do pěti prázdných (znak ☆). Komponentu použij v kartě mezi metařádkem a popisem.

Hvězdičky jsou obrázek pro oko, ne informace pro čtečku obrazovky: odstavci dej `aria-label` ve tvaru **Hodnocení 4 z 5** a samotné hvězdičky schovej obalem s `aria-hidden="true"`.

Řetězec se opakuje metodou `repeat`, kterou znáš z práce s textem.

# --hints--

Každá karta ukazuje pět hvězdiček podle hodnocení hry.

```js
const { hry } = await helpers.importFile('data.js');
const karty = [...document.querySelectorAll('.stranka .panel:last-of-type .karta')];
hry.forEach((hra, index) => {
  const hodnoceni = karty[index].querySelector('.hodnoceni');
  assert.ok(hodnoceni, `karta hry ${hra.nazev} má mít odstavec s třídou hodnoceni`);
  const text = hodnoceni.textContent;
  assert.equal([...text].filter((znak) => znak === '★').length, hra.hodnoceni, `u hry ${hra.nazev} má být ${hra.hodnoceni} plných hvězdiček`);
  assert.equal([...text].filter((znak) => znak === '☆').length, 5 - hra.hodnoceni, `u hry ${hra.nazev} má být ${5 - hra.hodnoceni} prázdných hvězdiček`);
});
```

Hodnocení je pro čtečku obrazovky čitelné slovy.

```js
const { hry } = await helpers.importFile('data.js');
const karty = [...document.querySelectorAll('.stranka .panel:last-of-type .karta')];
hry.forEach((hra, index) => {
  const hodnoceni = karty[index].querySelector('.hodnoceni');
  const popis = hodnoceni.getAttribute('aria-label') ?? '';
  assert.match(popis, new RegExp(`${hra.hodnoceni}\\s*z\\s*5`), `aria-label má u hry ${hra.nazev} říkat „Hodnocení ${hra.hodnoceni} z 5"`);
  assert.ok(hodnoceni.querySelector('[aria-hidden="true"]'), 'samotné hvězdičky mají být schované před čtečkou obalem s aria-hidden="true"');
});
```

Hodnocení je v kartě mezi metařádkem a popisem a komponenta je v samostatném souboru.

```js
const modul = await helpers.importFile('Hodnoceni.jsx');
assert.equal(typeof modul.default, 'function', 'Hodnoceni.jsx má mít výchozí export — komponentu Hodnoceni');
const karta = document.querySelector('.karta');
const poradi = [...karta.children].map((el) => el.className.split(' ')[0]);
assert.ok(poradi.indexOf('karta__meta') < poradi.indexOf('hodnoceni'), 'hodnocení patří pod metařádek');
assert.ok(poradi.indexOf('hodnoceni') < poradi.indexOf('karta__popis'), 'hodnocení patří nad popis');
```

## --tip--

Je to stejný tvar komponenty jako `Stitek` — jeden prop a jeden výraz, viz [Props jsou parametry komponenty](see:react-zaklady/komponenty-a-props#props-jsou-parametry-komponenty).

## --tip--

Počet prázdných hvězdiček dopočítáš z pětky. Oba kusy textu se dají spojit do jednoho výrazu.

## --tip--

Na jiných datech: `'▮'.repeat(hotovo) + '▯'.repeat(celkem - hotovo)` u ukazatele úkolů.

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```
