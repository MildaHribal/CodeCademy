# --description--

V hlavičce mají být dva štítky s obchodními podmínkami. Vypadají stejně, liší se textem — přesně případ pro komponentu s propem.

**Úkol:** Vytvoř soubor `Stitek.jsx` s komponentou `Stitek`, která dostane prop `text` a vrátí `<span className="stitek">` s tímhle textem. V `App.jsx` ji naimportuj a v hlavičce pod odstavec s počtem her přidej `<p className="hlavicka__stitky">` se dvěma štítky: **Doprava zdarma nad 1 500 Kč** a **Osobní odběr v Brně**.

Komponenta v samostatném souboru se exportuje a v jiném souboru naimportuje — jako každá jiná funkce v modulu:

```jsx
// Odznak.jsx
export default function Odznak({ pocet }) {
  return <span className="odznak">{pocet}</span>;
}

// jinde
import Odznak from './Odznak.jsx';
```

# --hints--

`Stitek.jsx` exportuje komponentu jako výchozí export.

```js
const modul = await helpers.importFile('Stitek.jsx');
assert.equal(typeof modul.default, 'function', 'Stitek.jsx má mít výchozí export — komponentu Stitek');
assert.equal(modul.default.name, 'Stitek', 'komponenta se má jmenovat Stitek (s velkým písmenem)');
```

V hlavičce jsou dva štítky se zadanými texty.

```js
const stitky = [...document.querySelectorAll('.hlavicka .stitek')];
assert.equal(stitky.length, 2, 'v hlavičce mají být dva štítky se třídou stitek');
assert.equal(stitky[0].textContent.trim(), 'Doprava zdarma nad 1 500 Kč', 'první štítek má mít text „Doprava zdarma nad 1 500 Kč"');
assert.equal(stitky[1].textContent.trim(), 'Osobní odběr v Brně', 'druhý štítek má mít text „Osobní odběr v Brně"');
```

Text přichází propem, ne z komponenty — stejná komponenta vykreslí obojí.

```js
const stitky = [...document.querySelectorAll('.hlavicka .stitek')];
assert.equal(stitky[0].tagName, 'SPAN', 'štítek má být <span>');
const kodStitku = helpers.stripComments(files['Stitek.jsx'], 'js');
assert.doesNotMatch(kodStitku, /Doprava zdarma|Osobní odběr/, 'texty patří do App.jsx jako props, ne do komponenty Stitek');
assert.match(helpers.stripComments(files['App.jsx'], 'js'), /<Stitek[^>]*text=/, 'v App.jsx má být <Stitek text="…" />');
```

# --help--

## --tip--

Props jsou parametry komponenty — viz [Props jsou parametry komponenty](see:react-zaklady/komponenty-a-props#props-jsou-parametry-komponenty).

## --tip--

Nový soubor komponenty exportuje funkci jako `export default`. Prop si rozeber rovnou v hlavičce funkce a vypiš ho ve složených závorkách.

## --tip--

Na jiných datech: `<Odznak pocet={3} />` a uvnitř `export default function Odznak({ pocet })`.

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```
