# --description--

Štítky budou v katalogu tři druhy: informační (šedý), novinka (zelený) a sleva (červená). Ve stylech jsou připravené třídy `stitek--info`, `stitek--novinka`, `stitek--sleva` a `stitek--varovani`.

**Úkol:** Přidej komponentě `Stitek` druhý prop `druh` s výchozí hodnotou `'info'` a slož z něj druhou třídu: `stitek stitek--<druh>`. Pak v hlavičce nahraď druhý štítek textem **Nové hry každý čtvrtek** s druhem `novinka`.

První štítek nech beze změny — díky výchozí hodnotě bude dál šedý, i když mu žádný druh neposíláš.

Dvě třídy z proměnné složíš šablonovým řetězcem:

```jsx
<div className={\`dlazdice dlazdice--${velikost}\`}>…</div>
```

# --hints--

Štítek bez propu `druh` má třídu `stitek--info`.

```js
const stitky = [...document.querySelectorAll('.hlavicka .stitek')];
assert.ok(stitky[0].classList.contains('stitek'), 'štítek má mít třídu stitek');
assert.ok(stitky[0].classList.contains('stitek--info'), 'bez propu druh má štítek dostat výchozí druh info');
```

Druhý štítek je zelená novinka se správným textem.

```js
const stitky = [...document.querySelectorAll('.hlavicka .stitek')];
assert.equal(stitky[1].textContent.trim(), 'Nové hry každý čtvrtek', 'druhý štítek má mít text „Nové hry každý čtvrtek"');
assert.ok(stitky[1].classList.contains('stitek--novinka'), 'druhý štítek má mít třídu stitek--novinka');
assert.equal(getComputedStyle(stitky[1]).color, 'rgb(31, 122, 77)', 'zelený štítek pozná i prohlížeč — třída stitek--novinka mění barvu textu');
```

Druh se skládá do třídy, ne natvrdo pro dvě varianty.

```js
const modul = await helpers.importFile('Stitek.jsx');
const kod = helpers.stripComments(files['Stitek.jsx'], 'js');
assert.match(kod, /druh\s*=\s*'info'|druh\s*=\s*"info"/, 'prop druh má mít výchozí hodnotu info');
assert.equal(typeof modul.default, 'function', 'Stitek.jsx má dál exportovat komponentu');
```

# --help--

## --tip--

Výchozí hodnota se píše rovnou do destrukturalizace — viz [Destrukturalizace a výchozí hodnoty](see:react-zaklady/komponenty-a-props#destrukturalizace-a-vychozi-hodnoty).

## --tip--

Třída je jeden řetězec, ve kterém se mění jen konec. Sestav ho ze dvou částí a vlož do `className`.

## --tip--

Na jiných datech: `` <button className={`tlacitko tlacitko--${varianta}`}> `` s výchozí hodnotou `varianta = 'hlavni'`.

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```
