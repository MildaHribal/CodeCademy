# --description--

Poslední věc, kterou by zákazník čekal: katalog seřazený od nejlevnější hry. Data ale seřadit nesmíš — panel novinek si je drží ve svém pořadí a pole `hry` patří „serveru".

**Úkol:** Nad komponentou `App` si připrav nové pole her seřazené vzestupně podle ceny a pošli ho seznamu v panelu s celým katalogem. Původní pole musí zůstat v pořadí, v jakém přišlo z dat.

Metoda, která řadí na místě, tady napáchá škodu; potřebuješ tu, která vrací nové pole.

## Udělej po svém

Katalog je hotový. Komponenty, které jsi napsal, se dají poskládat i jinak — vyber si aspoň jedno:

- **Panel akcí.** Přidej třetí panel jen s hrami ve slevě a do jeho hlavičky štítek „−30 %".
- **Vizuální nápad.** Dej kartě novinky jiný rámeček nebo hvězdičkám barvu podle hodnocení.
- **Dostupnost.** Ukaž u každé hry, kolik kusů je skladem, a u posledních kusů zvýrazni „poslední 2 kusy".
- **Tvoje téma.** Přepiš data na katalog, který tě baví — knihy, kytary, vinyly. Komponenty zůstanou, změní se jen obsah.

V příští lekci se katalog rozhýbe: přidáš stav, takže půjde filtrovat a přepínat panely kliknutím — a uvidíš, proč React nestačí jen vykreslovat.

# --hints--

V panelu s celým katalogem jdou hry od nejlevnější po nejdražší.

```js
const { hry } = await helpers.importFile('data.js');
const ocekavane = hry.toSorted((prvni, druha) => prvni.cena - druha.cena).map((hra) => hra.nazev);
const nazvy = [...document.querySelectorAll('.stranka .panel:last-of-type .karta .karta__nazev')].map((el) => el.textContent.trim());
assert.deepEqual(nazvy, ocekavane, 'karty v celém katalogu mají jít podle ceny od nejlevnější');
```

Původní pole zůstalo v pořadí z dat.

```js
const { hry } = await helpers.importFile('data.js');
assert.equal(hry[0].id, 'gloomhaven', 'pole hry se nesmí seřadit na místě — první hra má zůstat Gloomhaven');
assert.deepEqual(hry.map((hra) => hra.id).slice(0, 3), ['gloomhaven', 'azul', 'everdell'], 'pořadí v datech má zůstat, řazení má vrátit nové pole');
```

Panel novinek se nezměnil a katalog je pořád celý.

```js
const { hry } = await helpers.importFile('data.js');
const novinky = hry.filter((hra) => hra.novinka).map((hra) => hra.nazev);
const vNovinkach = [...document.querySelectorAll('.stranka .panel:first-of-type .karta .karta__nazev')].map((el) => el.textContent.trim());
assert.deepEqual(vNovinkach, novinky, 'panel novinek má zůstat v původním pořadí');
assert.equal(document.querySelectorAll('.stranka .panel:last-of-type .karta').length, hry.length, 'v katalogu má zůstat všech šest her');
```

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```

```jsx
import './styles.css';
import { hry } from './data.js';
import { prumerneHodnoceni } from './utils.js';
import Stitek from './Stitek.jsx';
import Panel from './Panel.jsx';
import SeznamHer from './SeznamHer.jsx';

const novinky = hry.filter((hra) => hra.novinka);
const podleCeny = hry.toSorted((prvni, druha) => prvni.cena - druha.cena);

export default function App() {
  return (
    <div className="stranka">
      <header className="hlavicka">
        <h1 className="hlavicka__nazev">Deskovky u Draka</h1>
        <p className="hlavicka__meta">
          {hry.length} her v katalogu · průměrné hodnocení {prumerneHodnoceni(hry)} z 5
        </p>
        <p className="hlavicka__stitky">
          <Stitek text="Doprava zdarma nad 1 500 Kč" />
          <Stitek text="Nové hry každý čtvrtek" druh="novinka" />
        </p>
      </header>

      <Panel nadpis="Novinky" akce={<Stitek text={`${novinky.length} nové tento měsíc`} druh="novinka" />}>
        <SeznamHer hry={novinky} />
      </Panel>

      <Panel nadpis="Celý katalog">
        <SeznamHer hry={podleCeny} />
      </Panel>
    </div>
  );
}
```
