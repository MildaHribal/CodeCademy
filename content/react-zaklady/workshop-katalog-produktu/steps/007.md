# --description--

Karta hry je dvanáct řádků značkování. Šest her by znamenalo dvaasedmdesát řádků, ve kterých se mění jen data — a jedna změna vzhledu by se opisovala šestkrát.

**Úkol:** Vytvoř soubor `KartaHry.jsx` s komponentou `KartaHry`, která dostane prop `hra` (celý objekt jedné hry) a vrátí přesně tu položku seznamu, kterou máš teď v `App.jsx`. V `App.jsx` pak ruční kartu nahraď touhle komponentou a první hru jí pošli propem.

Štítek **Sleva** i obě ceny zatím nech tak, jak jsou — podmínky na ně přijdou za dva kroky.

Komponenta, která dostane celý objekt, se používá takhle (jiná data):

```jsx
<RadekObjednavky objednavka={objednavky[0]} />
```

# --hints--

`KartaHry.jsx` exportuje komponentu a karta vypadá pořád stejně.

```js
const modul = await helpers.importFile('KartaHry.jsx');
assert.equal(typeof modul.default, 'function', 'KartaHry.jsx má mít výchozí export — komponentu KartaHry');
const { hry } = await helpers.importFile('data.js');
const karta = document.querySelector('.seznam .karta');
assert.ok(karta, 'v seznamu má být karta');
assert.equal(karta.querySelector('.karta__nazev').textContent.trim(), hry[0].nazev, 'karta má ukazovat název první hry');
assert.equal(karta.querySelector('.karta__popis').textContent.trim(), hry[0].popis, 'karta má ukazovat popis první hry');
```

Celý objekt hry přichází propem `hra`.

```js
const kodApp = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kodApp, /<KartaHry[^>]*hra=/, 'v App.jsx má být <KartaHry hra={…} />');
assert.doesNotMatch(kodApp, /karta__nazev/, 'značkování karty patří do KartaHry.jsx, v App.jsx už být nemá');
const kodKarty = helpers.stripComments(files['KartaHry.jsx'], 'js');
assert.match(kodKarty, /hra\.nazev/, 'komponenta má brát údaje z propu hra');
```

Cena i štítek v kartě zůstaly.

```js
const { hry } = await helpers.importFile('data.js');
const format = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK', maximumFractionDigits: 0 });
assert.equal(document.querySelector('.karta .cena__aktualni').textContent.trim(), format.format(hry[0].cena), 'cena má v kartě zůstat');
assert.ok(document.querySelector('.karta .cena__puvodni'), 'přeškrtnutá původní cena má zůstat');
assert.equal(document.querySelectorAll('.karta .karta__stitky .stitek').length, 1, 'štítek Sleva má v kartě zůstat');
```

# --help--

## --tip--

Komponenta dostane data jako parametr — viz [Props jsou parametry komponenty](see:react-zaklady/komponenty-a-props#props-jsou-parametry-komponenty).

## --tip--

Nový soubor exportuje komponentu stejně jako `Stitek.jsx`. Uvnitř nahraď `hry[0]` jménem propu; import `Cena` a `Stitek` přesuň tam, kde se teď používají.

## --tip--

Až bude komponenta hotová, zbude v `App.jsx` na místě dvanácti řádků jedna značka s jedním propem.

```js
// Průměrné hodnocení všech her, zaokrouhlené na jedno desetinné místo.
export function prumerneHodnoceni(hry) {
  const soucet = hry.reduce((celkem, hra) => celkem + hra.hodnoceni, 0);
  return Math.round((soucet / hry.length) * 10) / 10;
}
```

```jsx
const format = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK', maximumFractionDigits: 0 });

export default function Cena({ castka, puvodni = 0 }) {
  return (
    <p className="cena">
      <strong className="cena__aktualni">{format.format(castka)}</strong>
      {puvodni > castka && <s className="cena__puvodni">{format.format(puvodni)}</s>}
    </p>
  );
}
```
