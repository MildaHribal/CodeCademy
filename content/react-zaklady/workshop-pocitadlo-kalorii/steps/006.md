# --description--

Denní cíl je v datech (`DENNI_CIL`, 2200 kcal). Uživatele nezajímá jen, kolik snědl, ale hlavně **kolik ještě může**.

**Úkol:** Spočítej v `App`, kolik kalorií do cíle zbývá, a pod číslo v hlavičce přidej odstavec s třídou `souhrn__zbyva` a textem **Do cíle 2200 kcal zbývá 1420 kcal.** (obě čísla z výpočtu, ne napsaná ručně).

Zbývající kalorie nedávej do stavu. Je to hodnota odvozená ze zápisu — spočítá se při renderu a nemůže se s ním rozejít.

# --hints--

Na prázdný den zbývá celý cíl.

```js
const { DENNI_CIL } = await helpers.importFile('data.js');
const zbyva = document.querySelector('.souhrn__zbyva');
assert.ok(zbyva, 'v hlavičce má být odstavec s třídou souhrn__zbyva');
assert.match(zbyva.textContent, new RegExp(String(DENNI_CIL)), 'text má zmínit denní cíl');
assert.ok(zbyva.textContent.split(String(DENNI_CIL)).length >= 2, 'na prázdný den zbývá celý cíl');
```

Po zapsání guláše se zbývající kalorie přepočítají.

```js
const { DENNI_CIL } = await helpers.importFile('data.js');
const gulas = [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes('Guláš'));
await helpers.click(gulas);
await helpers.flush();
assert.match(document.querySelector('.souhrn__zbyva').textContent, new RegExp(String(DENNI_CIL - 780)), `po gulášy má zbývat ${DENNI_CIL - 780} kcal`);
```

Zbývající kalorie nejsou ve stavu, počítají se ze zápisu.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
const pocetStavu = (kod.match(/useState\s*\(/g) ?? []).length;
assert.equal(pocetStavu, 1, 've stavu má zůstat jen zápis — zbývající kalorie se dají spočítat');
assert.match(kod, /DENNI_CIL\s*-|-\s*snedeno/, 'zbývající kalorie spočítej z cíle a součtu');
```

# --help--

## --tip--

Rozdíl mezi stavem a odvozenou hodnotou je v části [Odvozená hodnota místo stavu](see:react-zaklady/stav-jako-snimek#odvozena-hodnota-misto-stavu).

## --tip--

Výpočet napiš do proměnné v těle komponenty, vedle součtu. Denní cíl máš naimportovaný z dat.

## --tip--

Text s dvěma čísly složíš šablonovým řetězcem, stejně jako jsi ve workshopu festivalu skládal třídu.

# --explain--

Vysvětli, proč zbývající kalorie (a součet dne) nepatří do stavu, i když se mění pokaždé, když uživatel něco zapíše.

## --model--

Obojí jde spočítat ze zápisu: součet je suma záznamů, zbytek je cíl mínus součet. Kdybych je držel ve stavu, měl bych dva zdroje pravdy o tomtéž — a musel bych je přepočítat na každém místě, kde se zápis mění: při přidání, mazání, změně porcí, vynulování dne. Stačí zapomenout na jedno a čísla si přestanou odpovídat. Takhle se přepočítají samy při každém renderu, protože render z dat vyrábí celou stránku znovu.

## --checklist--

- Součet i zbytek jde spočítat ze zápisu.
- Stav navíc by znamenal druhý zdroj pravdy.
- Každá cesta, kde se zápis mění, by musela přepočítávat.
- Odvozená hodnota se počítá při renderu a nemůže zestárnout.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

## --file-- App.jsx

```jsx
import './styles.css';
import { useState } from 'react';
import { DENNI_CIL, potraviny } from './data.js';
import { soucetKalorii } from './utils.js';

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);

  const snedeno = soucetKalorii(zaznamy);

  function pridej(potravina) {
    setZaznamy([...zaznamy, { ...potravina, id: crypto.randomUUID(), porce: 1 }]);
  }

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className="souhrn__cislo">{snedeno} kcal</p>
      </section>

      <section className="sekce">
        <h2 className="sekce__nadpis">Co jsem snědl</h2>
        <div className="volby">
          {potraviny.map((potravina) => (
            <button className="volba" key={potravina.id} onClick={() => pridej(potravina)}>
              {potravina.nazev} <span className="volba__kcal">{potravina.kcal} kcal</span>
            </button>
          ))}
        </div>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>

          {zaznamy.map((zaznam) => (
            <li className="zaznam" key={zaznam.id}>
              <p className="zaznam__nazev">
                {zaznam.nazev} <span className="zaznam__typ">{zaznam.typ}</span>

      </section>
    </div>
  );
}
```
