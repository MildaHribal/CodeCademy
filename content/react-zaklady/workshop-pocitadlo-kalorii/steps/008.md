# --description--

Guláš si někdo dá dvakrát. Místo zapisování dvou řádků přibude u každého záznamu ovládání porcí.

**Úkol:** V položce zápisu obal počet porcí do `span` s třídou `zaznam__porce` tak, aby před číslem bylo tlačítko `kulate` se znakem **−** a za číslem tlačítko `kulate` se znakem **+**. Obě mají přístupný popis (`aria-label` **Ubrat porci** a **Přidat porci**) a po kliknutí volají funkci `zmenPorci(id, zmena)`: minus se změnou `-1`, plus se změnou `1`.

Samotnou funkci `zmenPorci` zatím napiš s **prázdným tělem** — naplníš ji v dalším kroku. Tlačítka tedy zatím nic neudělají, ale musí být vidět a musí jít zmáčknout.

# --hints--

U každého záznamu jsou tlačítka − a + kolem počtu porcí.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
await helpers.click(najdi('Guláš'));
await helpers.flush();
const porce = document.querySelector('.zaznam .zaznam__porce');
assert.ok(porce, 'počet porcí má být v <span className="zaznam__porce">');
const tlacitka = [...porce.querySelectorAll('button.kulate')];
assert.equal(tlacitka.length, 2, 'u porcí mají být dvě kulatá tlačítka');
assert.match(tlacitka[0].textContent, /[-−]/, 'první tlačítko má ubírat');
assert.match(tlacitka[1].textContent, /\+/, 'druhé tlačítko má přidávat');
assert.match(porce.textContent, /1/, 'mezi tlačítky má zůstat počet porcí');
```

Tlačítka mají přístupný popis.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
await helpers.click(najdi('Jablko'));
await helpers.flush();
const tlacitka = [...document.querySelectorAll('.zaznam__porce button')];
assert.match(tlacitka[0].getAttribute('aria-label') ?? '', /[Uu]brat/, 'tlačítko minus má mít aria-label „Ubrat porci"');
assert.match(tlacitka[1].getAttribute('aria-label') ?? '', /[Pp]řidat/, 'tlačítko plus má mít aria-label „Přidat porci"');
```

Obě tlačítka volají `zmenPorci` se správnou změnou.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /function\s+zmenPorci\s*\(\s*id\s*,\s*zmena\s*\)/, 'v App má být funkce zmenPorci(id, zmena)');
assert.match(kod, /zmenPorci\([^)]*,\s*-1\s*\)/, 'tlačítko minus má volat zmenPorci se změnou -1');
assert.match(kod, /zmenPorci\([^)]*,\s*1\s*\)/, 'tlačítko plus má volat zmenPorci se změnou 1');
```

## --tip--

Obě tlačítka patří dovnitř `.zaznam__porce`, jedno před číslo a jedno za něj. Funkci `zmenPorci` napiš k ostatním funkcím v těle komponenty.

## --tip--

Aby obsluha věděla, o který záznam jde, obal volání do šipkové funkce — stejně jako u tlačítek v nabídce.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

## --file-- App.jsx

```jsx
import './styles.css';
import { useState } from 'react';
import { DENNI_CIL, potraviny } from './data.js';
import { soucetKalorii } from './utils.js';

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);

  const snedeno = soucetKalorii(zaznamy);
  const zbyva = DENNI_CIL - snedeno;
  const procenta = Math.min(100, Math.round((snedeno / DENNI_CIL) * 100));

  function pridej(potravina) {
    setZaznamy([...zaznamy, { ...potravina, id: crypto.randomUUID(), porce: 1 }]);
  }

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className="souhrn__cislo">{snedeno} kcal</p>
        <p className="souhrn__zbyva">{`Do cíle ${DENNI_CIL} kcal zbývá ${zbyva} kcal.`}</p>
        <div className="ukazatel" aria-hidden="true">
          <div className="ukazatel__cara" style={{ inlineSize: `${procenta}%` }} />
        </div>
      </section>

      <section className="sekce">
        <h2 className="sekce__nadpis">Co jsem snědl</h2>
        <div className="volby">
          {potraviny.map((potravina) => (
            <button className="volba" key={potravina.id} onClick={() => pridej(potravina)}>
              {potravina.nazev} <span className="volba__kcal">{potravina.kcal} kcal</span>
            </button>
          ))}
        </div>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>
        </div>
        {zaznamy.length === 0 && <p className="prazdno">Zatím nic. Klikni na jídlo nahoře.</p>}
        <ul className="zaznamy">
          {zaznamy.map((zaznam) => (
            <li className="zaznam" key={zaznam.id}>
              <p className="zaznam__nazev">
                {zaznam.nazev} <span className="zaznam__typ">{zaznam.typ}</span>
              </p>
              <span className="zaznam__porce">{zaznam.porce}×</span>
              <span className="zaznam__kcal">{zaznam.kcal * zaznam.porce} kcal</span>
            </li>
          ))}
        </ul>
      </section>
    </div>
  );
}
```
