# --description--

Ukázkový den byl jen výplň. Teď dáš komponentě paměť: zápis bude v [[stav]]u, takže se po každé změně překreslí sám.

**Úkol:** V `App.jsx` nahraď konstantu `ukazkovyDen` stavem `zaznamy` s počáteční hodnotou prázdné pole a smaž i ukázková data. Součet ať se počítá z něj.

Pod hlavičku přidej sekci s třídou `sekce`, v ní `<div className="sekce__hlavicka">` s nadpisem druhé úrovně **Dnešní zápis** (třída `sekce__nadpis`) a pod hlavičkou odstavec s třídou `prazdno` a textem **Zatím nic. Klikni na jídlo nahoře.**, který se ukáže jen tehdy, když je zápis prázdný.

Stav se zakládá hookem `useState`, který se importuje z Reactu:

```jsx
const [barva, setBarva] = useState('modrá');
```

# --hints--

Součet začíná na nule, protože zápis je prázdný.

```js
assert.match(document.querySelector('.souhrn__cislo').textContent, /\b0\b/, 'na začátku má být snědeno 0 kcal');
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.doesNotMatch(kod, /ukazkovyDen/, 'ukázková data už v souboru být nemají');
```

Zápis je ve stavu založeném přes `useState`.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /useState\s*\(\s*\[\s*\]\s*\)/, 'stav zaznamy má začínat prázdným polem');
assert.match(kod, /import\s*\{[^}]*useState[^}]*\}\s*from\s*'react'/, 'useState se importuje z Reactu');
assert.match(kod, /const\s*\[\s*zaznamy\s*,\s*set\w+\s*\]/, 'stav si rozeber destrukturalizací na hodnotu zaznamy a set funkci');
```

Prázdný zápis má vlastní hlášku.

```js
const sekce = document.querySelector('.stranka .sekce');
assert.ok(sekce, 'pod hlavičkou má být sekce se zápisem');
const nadpis = sekce.querySelector('.sekce__hlavicka .sekce__nadpis');
assert.ok(nadpis, 'sekce má mít .sekce__hlavicka a v ní nadpis .sekce__nadpis');
assert.equal(nadpis.tagName, 'H2', 'nadpis zápisu má být h2');
const prazdno = sekce.querySelector('.prazdno');
assert.ok(prazdno, 'u prázdného zápisu se má ukázat odstavec s třídou prazdno');
assert.match(prazdno.textContent, /Zatím nic/, 'hláška má říct, že zápis je prázdný');
```

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

## --file-- App.jsx

```jsx
import './styles.css';
import { useState } from 'react';
import { DENNI_CIL } from './data.js';
import { soucetKalorii } from './utils.js';

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);

  const snedeno = soucetKalorii(zaznamy);

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className="souhrn__cislo">{snedeno} kcal</p>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>
        </div>
        {zaznamy.length === 0 && <p className="prazdno">Zatím nic. Klikni na jídlo nahoře.</p>}
      </section>
    </div>
  );
}
```
