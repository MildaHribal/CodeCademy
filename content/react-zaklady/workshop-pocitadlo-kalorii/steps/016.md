# --description--

Funkce `App` má přes šedesát řádků a hlavička je z nich třetina. Hlavička přitom o zápisu nic vědět nemusí — potřebuje jen čtyři hotová čísla.

**Úkol:** Vytvoř soubor `Souhrn.jsx` s komponentou `Souhrn`, která dostane props `snedeno`, `zbyva`, `procenta` a `prekroceno` a vrátí celou hlavičku (nadpis, číslo, větu i ukazatel). V `App.jsx` ji použij místo dosavadního značkování hlavičky a pošli jí spočítané hodnoty.

Stav i výpočty zůstávají v `App` — komponenta `Souhrn` jen zobrazuje, co dostane. Náhled se nesmí změnit ani o pixel.

# --hints--

`Souhrn.jsx` exportuje komponentu a hlavička vypadá stejně.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
const modul = await helpers.importFile('Souhrn.jsx');
assert.equal(typeof modul.default, 'function', 'Souhrn.jsx má mít výchozí export — komponentu Souhrn');
await helpers.click(najdi('Guláš'));
await helpers.flush();
assert.match(document.querySelector('.souhrn .souhrn__cislo').textContent, /780/, 'v hlavičce má být součet dne');
assert.match(document.querySelector('.souhrn .souhrn__zbyva').textContent, /1420/, 'věta má dál ukazovat zbývající kalorie');
assert.ok(document.querySelector('.souhrn .ukazatel__cara'), 'ukazatel má v hlavičce zůstat');
```

Překročený cíl funguje dál.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
for (let i = 0; i < 3; i += 1) await helpers.click(najdi('Guláš'));
await helpers.flush();
assert.equal(getComputedStyle(document.querySelector('.souhrn__cislo')).color, 'rgb(180, 69, 31)', 'při překročení má číslo zčervenat');
assert.match(document.querySelector('.souhrn__zbyva').textContent, /140/, 'věta má říct, o kolik je cíl překročený');
```

Souhrn dostává hotové hodnoty, nepočítá si je sám.

```js
const kodSouhrnu = helpers.stripComments(files['Souhrn.jsx'], 'js');
assert.doesNotMatch(kodSouhrnu, /useState|soucetKalorii|zaznamy/, 'Souhrn nemá znát zápis ani stav — dostane hotová čísla v props');
const kodApp = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kodApp, /<Souhrn[^>]*snedeno=/, 'v App.jsx má být <Souhrn snedeno={…} … />');
assert.doesNotMatch(kodApp, /souhrn__cislo/, 'značkování hlavičky patří do Souhrn.jsx');
```

# --explain--

Vysvětli, proč komponenta `Souhrn` dostává spočítaná čísla, a ne rovnou celé pole záznamů, ze kterého by si je spočítala sama.

## --model--

Souhrn má jednu práci: ukázat čísla. Když dostane hotové hodnoty, nezáleží mu na tom, odkud jsou — půjde použít i na týdenní přehled nebo na cizí data z API a v testu mu stačí předat čtyři čísla. Kdyby si je počítal ze zápisu, musel by znát jeho tvar, a jakmile by se tvar dat změnil, opravuju na dvou místech. Výpočet navíc patří tam, kde je stav, protože stejná čísla potřebuje i zbytek stránky.

## --checklist--

- Komponenta má jednu práci: zobrazit, co dostane.
- Nezná tvar dat, takže jde použít i jinde.
- Výpočty zůstávají u stavu, kde je potřebuje i zbytek stránky.
- Změna dat pak znamená opravu na jednom místě.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

```jsx
import './styles.css';
import { useState } from 'react';
import { DENNI_CIL, potraviny } from './data.js';
import { soucetKalorii } from './utils.js';

const TYPY = ['Vše', 'Snídaně', 'Oběd', 'Večeře', 'Svačina'];

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);
  const [filtr, setFiltr] = useState('Vše');

  const snedeno = soucetKalorii(zaznamy);
  const zbyva = DENNI_CIL - snedeno;
  const procenta = Math.min(100, Math.round((snedeno / DENNI_CIL) * 100));
  const prekroceno = snedeno > DENNI_CIL;
  const videt = filtr === 'Vše' ? zaznamy : zaznamy.filter((zaznam) => zaznam.typ === filtr);

  function pridej(potravina) {
    setZaznamy([...zaznamy, { ...potravina, id: crypto.randomUUID(), porce: 1 }]);
  }

  function zmenPorci(id, zmena) {
    setZaznamy(
      zaznamy.map((zaznam) =>
        zaznam.id === id ? { ...zaznam, porce: Math.max(1, zaznam.porce + zmena) } : zaznam,
      ),
    );
  }

  function smaz(id) {
    setZaznamy(zaznamy.filter((zaznam) => zaznam.id !== id));
  }

  function vynulujDen() {
    setZaznamy([]);
    setFiltr('Vše');
  }

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className={prekroceno ? 'souhrn__cislo souhrn__cislo--prekroceno' : 'souhrn__cislo'}>{snedeno} kcal</p>
        <p className="souhrn__zbyva">{prekroceno ? `Cíl máš překročený o ${snedeno - DENNI_CIL} kcal.` : `Do cíle ${DENNI_CIL} kcal zbývá ${zbyva} kcal.`}</p>
        <div className="ukazatel" aria-hidden="true">
          <div className={prekroceno ? 'ukazatel__cara ukazatel__cara--prekroceno' : 'ukazatel__cara'} style={{ inlineSize: `${procenta}%` }} />
        </div>
      </section>

      <section className="sekce">
        <h2 className="sekce__nadpis">Co jsem snědl</h2>
        <div className="volby">
          {potraviny.map((potravina) => (
            <button className="volba" key={potravina.id} onClick={() => pridej(potravina)}>
              {potravina.nazev} <span className="volba__kcal">{potravina.kcal} kcal</span>
            </button>
          ))}
        </div>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>
          <div className="filtr">
            {TYPY.map((typ) => (
              <button
                className={typ === filtr ? 'filtr__tlacitko filtr__tlacitko--aktivni' : 'filtr__tlacitko'}
                key={typ}
                onClick={() => setFiltr(typ)}
              >
                {typ}
              </button>
            ))}
          </div>
        </div>
        {videt.length === 0 && (
          <p className="prazdno">{zaznamy.length === 0 ? 'Zatím nic. Klikni na jídlo nahoře.' : 'V téhle kategorii dnes nic nemáš.'}</p>
        )}
        <ul className="zaznamy">
          {videt.map((zaznam) => (
            <li className="zaznam" key={zaznam.id}>
              <p className="zaznam__nazev">
                {zaznam.nazev} <span className="zaznam__typ">{zaznam.typ}</span>
              </p>
              <span className="zaznam__porce">
                <button className="kulate" onClick={() => zmenPorci(zaznam.id, -1)} aria-label="Ubrat porci">−</button>
                {zaznam.porce}×
                <button className="kulate" onClick={() => zmenPorci(zaznam.id, 1)} aria-label="Přidat porci">+</button>
              </span>
              <span className="zaznam__kcal">{zaznam.kcal * zaznam.porce} kcal</span>
              <button className="smazat" onClick={() => smaz(zaznam.id)} aria-label="Smazat záznam">×</button>
            </li>
          ))}
        </ul>
        <button className="tise" onClick={vynulujDen}>
          Vynulovat den
        </button>
      </section>
    </div>
  );
}
```
