# --description--

## Hlášení

Kolega si všiml, že `zmenPorci` je dlouhá, a zjednodušil ji. Píše: „Najdu záznam, opravím mu porci, uložím pole. Kratší, jasnější. Jenže teď to nefunguje: kliknu na plus a **na stránce se nic nezmění**. Když ale potom smažu jiný záznam nebo přidám jídlo, porce najednou naskočí na správné číslo. Jako by se to schovávalo."

## Úkol

Vrať `zmenPorci` do stavu, kdy plus i minus fungují okamžitě. Ostatní funkce nech být.

# --hints--

Minus funguje taky a pod jednu porci nejde.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));

await helpers.flush();

await helpers.flush();

await helpers.flush();
```


# --help--

## --tip--

Proč mutace ve stavu nic nepřekreslí, rozebírá část [Pole a objekty ve stavu](see:react-zaklady/stav-jako-snimek#pole-a-objekty-ve-stavu).

## --tip--

Podívej se, jestli funkce vyrábí nové pole, nebo mění to staré. Nová hodnota musí vzniknout z pole i z toho jednoho objektu uvnitř.

## --tip--

Vzor máš o dva kroky výš — stejný tvar jsi skládal v kroku se seřazenými řádky.

# --explain--

Vysvětli, proč se po kliknutí na plus nic nepřekreslilo, i když se počet porcí v datech opravdu změnil — a proč se změna objevila až po smazání jiného záznamu.

## --model--

Kolegův kód našel objekt záznamu, který už byl ve stavu, a přepsal mu vlastnost. Pole zůstalo totéž pole: `setZaznamy(zaznamy)` tedy Reactu předal hodnotu, kterou už měl, React je porovnal identitou, neviděl žádnou změnu a komponentu nezavolal. Data v paměti přitom nová byla. Jakmile jiná akce (mazání) vyrobila opravdu nové pole, React překreslil — a v ten okamžik se ukázala i ta dávno změněná porce. Proto se stav mění jedině tak, že se vyrobí nová hodnota.

## --checklist--

- React porovnává starou a novou hodnotu stavu identitou.
- Úprava objektu nebo pole na místě identitu nemění.
- Bez nové hodnoty React komponentu nezavolá, i když data jsou nová.
- Změna se „objeví" až s příštím renderem, který vyvolá něco jiného.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

## --file-- App.jsx

```jsx
import './styles.css';
import { useState } from 'react';
import { DENNI_CIL, potraviny } from './data.js';
import { soucetKalorii } from './utils.js';

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);

  const snedeno = soucetKalorii(zaznamy);
  const zbyva = DENNI_CIL - snedeno;
  const procenta = Math.min(100, Math.round((snedeno / DENNI_CIL) * 100));

  function pridej(potravina) {
    setZaznamy([...zaznamy, { ...potravina, id: crypto.randomUUID(), porce: 1 }]);
  }

  function zmenPorci(id, zmena) {
    const zaznam = zaznamy.find((polozka) => polozka.id === id);
    zaznam.porce = Math.max(1, zaznam.porce + zmena);
    setZaznamy(zaznamy);
  }

  function smaz(id) {
    setZaznamy(zaznamy.filter((zaznam) => zaznam.id !== id));
  }

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className="souhrn__cislo">{snedeno} kcal</p>
        <p className="souhrn__zbyva">{`Do cíle ${DENNI_CIL} kcal zbývá ${zbyva} kcal.`}</p>
        <div className="ukazatel" aria-hidden="true">
          <div className="ukazatel__cara" style={{ inlineSize: `${procenta}%` }} />
        </div>
      </section>

      <section className="sekce">
        <h2 className="sekce__nadpis">Co jsem snědl</h2>
        <div className="volby">
          {potraviny.map((potravina) => (
            <button className="volba" key={potravina.id} onClick={() => pridej(potravina)}>
              {potravina.nazev} <span className="volba__kcal">{potravina.kcal} kcal</span>
            </button>
          ))}
        </div>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>
        </div>
        {zaznamy.length === 0 && <p className="prazdno">Zatím nic. Klikni na jídlo nahoře.</p>}
        <ul className="zaznamy">
          {zaznamy.map((zaznam) => (
            <li className="zaznam" key={zaznam.id}>
              <p className="zaznam__nazev">
                {zaznam.nazev} <span className="zaznam__typ">{zaznam.typ}</span>
              </p>
              <span className="zaznam__porce">
                <button className="kulate" onClick={() => zmenPorci(zaznam.id, -1)} aria-label="Ubrat porci">−</button>
                {zaznam.porce}×
                <button className="kulate" onClick={() => zmenPorci(zaznam.id, 1)} aria-label="Přidat porci">+</button>
              </span>
              <span className="zaznam__kcal">{zaznam.kcal * zaznam.porce} kcal</span>
              <button className="smazat" onClick={() => smaz(zaznam.id)} aria-label="Smazat záznam">×</button>
            </li>
          ))}
        </ul>
      </section>
    </div>
  );
}
```

```jsx
import { DENNI_CIL, potraviny } from './data.js';
```
