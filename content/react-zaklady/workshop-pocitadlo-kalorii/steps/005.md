# --description--

Součet roste, ale co se do něj počítá, uživatel nevidí.

**Úkol:** Do sekce se zápisem přidej pod hlášku seznam `<ul className="zaznamy">` a v něm položku pro každý záznam ve stavu. Položka má třídu `zaznam` a uvnitř:

- odstavec `zaznam__nazev` s názvem jídla a v něm `<span className="zaznam__typ">` s typem jídla,
- `<span className="zaznam__porce">` s počtem porcí a znakem **×**,
- `<span className="zaznam__kcal">` s kaloriemi za celý záznam (kalorie za porci krát počet porcí) a slovem **kcal**.

Jako `key` použij `id` záznamu — právě proto ho každý záznam dostal.

# --hints--

Každé zapsané jídlo má v seznamu svou položku.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
await helpers.click(najdi('Guláš'));
await helpers.click(najdi('Jablko'));
await helpers.flush();
const polozky = [...document.querySelectorAll('.zaznamy .zaznam')];
assert.equal(polozky.length, 2, 'po dvou kliknutích mají být v zápisu dvě položky');
assert.ok(polozky[0].textContent.includes('Guláš'), 'první položka má být guláš');
assert.ok(polozky[1].textContent.includes('Jablko'), 'druhá položka má být jablko');
```

Položka ukazuje typ jídla, porce i kalorie za celý záznam.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
await helpers.click(najdi('Guláš'));
await helpers.flush();
const polozka = document.querySelector('.zaznamy .zaznam');
assert.equal(polozka.querySelector('.zaznam__typ').textContent.trim(), 'Oběd', 'u guláše má být typ Oběd');
assert.match(polozka.querySelector('.zaznam__porce').textContent, /1/, 'porce mají být vidět');
assert.match(polozka.querySelector('.zaznam__kcal').textContent, /780/, 'u guláše má být 780 kcal');
```

Když je zápis prázdný, je vidět hláška a žádná položka.

```js
assert.equal(document.querySelectorAll('.zaznamy .zaznam').length, 0, 'na začátku nemá být v seznamu nic');
assert.ok(document.querySelector('.prazdno'), 'u prázdného zápisu má zůstat hláška');
assert.ok(!logs.some((zaznam) => /unique "key"/.test(zaznam.text)), 'položky potřebují key — použij id záznamu');
```

## --tip--

Vykreslení seznamu z pole je v části [Seznam z pole a `key`](see:react-zaklady/komponenty-a-props#seznam-z-pole-a-key).

## --tip--

Seznam patří pod hlášku o prázdném zápisu. Kalorie za záznam nejsou v datech — spočítáš je z kalorií za porci a počtu porcí přímo ve výrazu.

## --tip--

Na jiných datech: `<span className="radek__cena">{polozka.cena * polozka.kusy} Kč</span>`.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

import './styles.css';
import { useState } from 'react';
import { DENNI_CIL, potraviny } from './data.js';
import { soucetKalorii } from './utils.js';

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);

  const snedeno = soucetKalorii(zaznamy);

  function pridej(potravina) {
    setZaznamy([...zaznamy, { ...potravina, id: crypto.randomUUID(), porce: 1 }]);
  }

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className="souhrn__cislo">{snedeno} kcal</p>
      </section>

      <section className="sekce">
        <h2 className="sekce__nadpis">Co jsem snědl</h2>
        <div className="volby">
          {potraviny.map((potravina) => (
            <button className="volba" key={potravina.id} onClick={() => pridej(potravina)}>
              {potravina.nazev} <span className="volba__kcal">{potravina.kcal} kcal</span>
            </button>
          ))}
        </div>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>
        </div>
        {zaznamy.length === 0 && <p className="prazdno">Zatím nic. Klikni na jídlo nahoře.</p>}
        <ul className="zaznamy">
          {zaznamy.map((zaznam) => (
            <li className="zaznam" key={zaznam.id}>
              <p className="zaznam__nazev">
                {zaznam.nazev} <span className="zaznam__typ">{zaznam.typ}</span>
              </p>
              <span className="zaznam__porce">{zaznam.porce}×</span>
              <span className="zaznam__kcal">{zaznam.kcal * zaznam.porce} kcal</span>
            </li>
          ))}
        </ul>
      </section>
    </div>
  );
}
