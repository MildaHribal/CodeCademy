# --description--

Postavíš zápisník jídla: kliknutím přidáš jídlo z nabídky, u každého záznamu nastavíš porce, uvidíš součet kalorií a ukazatel k dennímu cíli, zápis půjde filtrovat podle typu jídla a večer vynulovat. Všechno se bude dít **po kliknutí**, takže potřebuješ [[stav]] — a ten je hlavní téma téhle trojice kroků.

Začneš ale funkcí, kterou stav vůbec nepotřebuje.

V `utils.js` je `soucetKalorii`, která zatím vrací nulu, takže hlavička ukazuje **0 kcal** i pro ukázkový den.

**Úkol:** Doplň `soucetKalorii(zaznamy)` tak, aby sečetla kalorie všech záznamů. Každý záznam má `kcal` za jednu porci a `porce` (počet porcí), takže se za každý záznam přičítá jejich součin. Pro ukázkový den vyjde 1100.

Součet přes pole vypadá na jiných datech takhle:

```js
// 1. co přičítám za jednu položku
// 2. z čeho začínám
const cena = kosik.reduce((celkem, polozka) => celkem + polozka.cena * polozka.kusy, 0);
```

# --hints--

Součet ukázkového dne je 1100 kcal.

```js
const { soucetKalorii } = await helpers.importFile('utils.js');
assert.equal(soucetKalorii([{ kcal: 320, porce: 1 }, { kcal: 780, porce: 1 }]), 1100, 'soucetKalorii má u kaše (320) a guláše (780) vrátit 1100');
assert.match(document.querySelector('.souhrn__cislo').textContent, /1100/, 'v hlavičce má být součet ukázkového dne');
```

Počítá i s porcemi navíc.

```js
const { soucetKalorii } = await helpers.importFile('utils.js');
assert.equal(soucetKalorii([{ kcal: 95, porce: 3 }]), 285, 'tři jablka po 95 kcal mají dát 285');
assert.equal(soucetKalorii([{ kcal: 60, porce: 2 }, { kcal: 430, porce: 1 }]), 550, 'dvě kávy (60) a salát (430) mají dát 550');
```

Prázdný den má nula kalorií.

```js
const { soucetKalorii } = await helpers.importFile('utils.js');
assert.equal(soucetKalorii([]), 0, 'prázdný zápis má mít součet 0');
```

# --help--

## --tip--

Součet přes pole je z lekce [Jak pracuje `reduce`](see:js-pole/metody-pole-do-hloubky#jak-pracuje-reduce); `for…of` poslouží stejně.

## --tip--

Za každý záznam přičti kalorie za jednu porci vynásobené počtem porcí. Počáteční hodnota součtu je nula — díky ní projde i prázdné pole.

## --tip--

```js
// 2. za každý záznam přičti kcal krát porce
// 3. vrať výsledek
```

# --solution--

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```
