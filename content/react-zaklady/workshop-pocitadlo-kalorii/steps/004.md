# --description--

Teď se zápisník poprvé rozhýbe.

**Úkol:** Napiš v `App` funkci `pridej(potravina)`, která do stavu přidá nový záznam: všechny údaje jídla, k tomu `porce: 1` a vlastní `id`, které vyrobíš pomocí `crypto.randomUUID()`. Tlačítko z nabídky ať ji po kliknutí zavolá s tím svým jídlem. Po kliknutí na guláš má součet v hlavičce skočit na 780.

Stav se nikdy nemění na místě — vyrábí se **nová hodnota**:

```jsx
setUkoly([...ukoly, { text: 'nový úkol', hotovo: false }]);
```

> [!PITFALL]
> Obsluze se předává funkce, ne její výsledek. `onClick={pridej(potravina)}` by se zavolala hned při renderu a React by skončil hláškou o příliš mnoha renderech. Potřebuješ funkci, která se zavolá až při kliknutí.

# --hints--

Kliknutí na guláš zapíše 780 kcal.

```js
const gulas = [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes('Guláš'));
await helpers.click(gulas);
await helpers.flush();
assert.match(document.querySelector('.souhrn__cislo').textContent, /780/, 'po kliknutí na guláš má být snědeno 780 kcal');
```

Každé kliknutí přidá další záznam, součty se sčítají.

```js
const najdi = (text) => [...document.querySelectorAll('.volba')].find((el) => el.textContent.includes(text));
await helpers.click(najdi('Jablko'));
await helpers.click(najdi('Jablko'));
await helpers.click(najdi('Káva'));
await helpers.flush();
assert.match(document.querySelector('.souhrn__cislo').textContent, /250/, 'dvě jablka (95) a káva (60) mají dát 250 kcal');
```

Záznam si nese údaje jídla, porci a vlastní id.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /crypto\.randomUUID\(\)/, 'id záznamu vyrob přes crypto.randomUUID()');
assert.match(kod, /porce:\s*1/, 'nový záznam má mít jednu porci');
assert.doesNotMatch(kod, /zaznamy\.push|zaznamy\[zaznamy\.length\]/, 'stav se nemění na místě — vyrob nové pole');
```

# --help--

## --tip--

Přidání do pole ve stavu je v části [Pole a objekty ve stavu](see:react-zaklady/stav-jako-snimek#pole-a-objekty-ve-stavu).

## --tip--

Funkci napiš v těle komponenty nad `return`. Nové pole vyrobíš rozbalením toho starého a přidáním objektu na konec; údaje jídla do něj rozbalíš stejným způsobem.

## --tip--

Aby tlačítko vědělo, které jídlo přidat, obal volání do šipkové funkce — `onClick={() => neco(hodnota)}`.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```

## --file-- App.jsx

```jsx
import './styles.css';
import { useState } from 'react';
import { DENNI_CIL, potraviny } from './data.js';
import { soucetKalorii } from './utils.js';

export default function App() {
  const [zaznamy, setZaznamy] = useState([]);

  const snedeno = soucetKalorii(zaznamy);
```

```jsx
  function pridej(potravina) {
    setZaznamy([...zaznamy, { ...potravina, id: crypto.randomUUID(), porce: 1 }]);
  }

  return (
    <div className="stranka">
      <section className="souhrn">
        <h1 className="souhrn__nadpis">Dnes máš snědeno</h1>
        <p className="souhrn__cislo">{snedeno} kcal</p>
      </section>

      <section className="sekce">
        <h2 className="sekce__nadpis">Co jsem snědl</h2>
        <div className="volby">
          {potraviny.map((potravina) => (
            <button className="volba" key={potravina.id} onClick={() => pridej(potravina)}>
              {potravina.nazev} <span className="volba__kcal">{potravina.kcal} kcal</span>
            </button>
          ))}
        </div>
      </section>

      <section className="sekce">
        <div className="sekce__hlavicka">
          <h2 className="sekce__nadpis">Dnešní zápis</h2>
        </div>
        {zaznamy.length === 0 && <p className="prazdno">Zatím nic. Klikni na jídlo nahoře.</p>}
      </section>
    </div>
  );
}
```
