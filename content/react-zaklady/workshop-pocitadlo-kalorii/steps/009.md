# --description--

Teď nejdůležitější vzor celé sekce: **změna jedné položky v poli ve stavu**. Nesmíš sáhnout do původního pole ani do objektu v něm — vyrobíš nové pole, ve kterém je jediná položka jiná.

**Úkol:** Seřaď řádky tak, aby `zmenPorci(id, zmena)` nastavila novou hodnotu stavu: pole, ve kterém má záznam s daným `id` počet porcí zvýšený (nebo snížený) o `zmena`, a nikdy míň než jednu porci. Ostatní záznamy zůstanou beze změny.

Do mezery doplň, kolik porcí je nejmíň. Dva řádky jsou navíc.

> [!PITFALL]
> `zaznam.porce = zaznam.porce + zmena` změní objekt, který už ve stavu je. React pak porovná staré a nové pole, uvidí totéž, a nic nepřekreslí.

## --file-- utils.js

```js
// Kolik kalorií mají všechny zapsané porce dohromady.
export function soucetKalorii(zaznamy) {
  return zaznamy.reduce((celkem, zaznam) => celkem + zaznam.kcal * zaznam.porce, 0);
}
```
