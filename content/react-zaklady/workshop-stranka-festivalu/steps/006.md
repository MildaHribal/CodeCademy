# --description--

Návštěvník má hned vidět, že se blíží vyprodáno. V datech je `kapacita` a `prodano`, ve stylech je připravený pruh: obal `.ukazatel` a barevná čára `.ukazatel__cara`, která se roztáhne podle šířky.

**Úkol:** Spočítej v `Hero` procento prodaných vstupenek (zaokrouhlené na celé) a vykresli pruh, jehož čára má tuhle šířku. Pod pruh přidej odstavec s třídou `hero__obsazenost` a textem **Prodáno 86 % vstupenek**, kde číslo pochází z výpočtu.

Šířku nastavíš vlastností `style`. Ta v JSX nebere text, ale objekt: vnější složené závorky znamenají „výraz", vnitřní jsou objekt.

```jsx
<div className="teplomer" style={{ blockSize: `${stupne}%`, opacity: 0.8 }} />
```

Obalu pruhu dej `aria-hidden="true"` — je to jen obrázek téhož čísla, čtečka ho číst nemusí. Vlastní atributy jako `aria-*` se v JSX píšou stejně jako v HTML.

# --hints--

V hlavičce je pruh `.ukazatel` a v něm čára `.ukazatel__cara`.

```js
const cara = document.querySelector('.hero .ukazatel > .ukazatel__cara');
assert.ok(cara, 'v hlavičce má být obal .ukazatel a v něm .ukazatel__cara');
```

Čára je široká 86 % obalu — tedy přesně poměr prodaných vstupenek.

```js
const cara = document.querySelector('.ukazatel__cara');
const pomer = cara.getBoundingClientRect().width / cara.parentElement.getBoundingClientRect().width;
assert.ok(Math.abs(pomer - 0.856) < 0.025, `čára má být široká 86 % ukazatele (2140 z 2500 vstupenek), je ${Math.round(pomer * 100)} %`);
```

Pod pruhem je text s procentem a číslo je spočítané z dat.

```js
const text = document.querySelector('.hero__obsazenost');
assert.ok(text, 'pod pruhem má být odstavec s třídou hero__obsazenost');
assert.match(text.textContent, /86/, 'odstavec má ukazovat spočítané procento');
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /festival\.(prodano|kapacita)/, 'procento spočítej z dat (prodano a kapacita), ne ručně');
```

# --help--

## --tip--

Vlastnost `style` bere objekt, ne text — viz tabulka v části [Atributy se jmenují jako v JavaScriptu](see:react-zaklady/proc-react#atributy-se-jmenuji-jako-v-javascriptu).

## --tip--

Výpočet si ulož do proměnné v těle komponenty, nad `return`. Šířku čáry řídí vlastnost `inlineSize` (nebo `width`) a hodnota je text končící procentem.

## --tip--

Zaokrouhlení na celé číslo dělá `Math.round`, procenta spočítáš podílem krát sto — třeba `Math.round((hotovo / celkem) * 100)` u ukazatele stahování.

```js
// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
```

## --file-- App.jsx

```jsx
import './styles.css';
import { festival } from './data.js';
import { formatDate } from './utils.js';

function MistoACas() {
  return (
    <>
      <p className="hero__datum">{formatDate(festival.datum)}</p>
      <p className="hero__misto">{festival.misto}</p>
    </>
  );
}

function Hero() {
  const procentoProdano = Math.round((festival.prodano / festival.kapacita) * 100);

  return (
    <header className="hero">
      <p className="hero__kicker">Hudební festival · 3. ročník</p>
      <h1 className="hero__nazev">{festival.nazev}</h1>
      <MistoACas />
      <div className="ukazatel" aria-hidden="true">
        <div className="ukazatel__cara" style={{ inlineSize: `${procentoProdano}%` }} />
      </div>
      <p className="hero__obsazenost">Prodáno {procentoProdano} % vstupenek</p>
      <a className="tlacitko" href="#vstupenky">Koupit vstupenku</a>
    </header>
  );
}

export default function App() {
  return (
    <div className="stranka">
      <Hero />
    </div>
  );
}
```
