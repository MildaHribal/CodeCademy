# --description--

Festival by bez partnerů nebyl; na každé takové stránce je jejich řádek dole. V `data.js` je pole `partneri`, každý má `id`, `nazev` a `role`.

**Úkol:** Na konec stránky (pod ceník) přidej patičku `footer` s třídou `patacka` s odstavcem **Festival podporují:** a pod ním seznam `ul` s třídou `partneri`, kde každý partner tvoří položku `<li className="partner">` s názvem a rolí v jednom řádku.

Jak název a roli oddělíš, je na tobě — pomlčkou, závorkou, tečkou. Test se dívá jen na to, že jsou v položce obě hodnoty z dat.

# --hints--

Na konci stránky je patička se seznamem partnerů.

```js
const patacka = document.querySelector('.stranka > .patacka');
assert.ok(patacka, 'na konci stránky má být <footer className="patacka">');
assert.equal(document.querySelector('.stranka').lastElementChild, patacka, 'patička má být úplně poslední');
assert.ok(patacka.querySelector('ul.partneri'), 'v patičce má být seznam <ul className="partneri">');
```

Položek je tolik, kolik je partnerů v datech, a každá nese název i roli.

```js
const { partneri } = await helpers.importFile('data.js');
const polozky = [...document.querySelectorAll('.patacka .partner')];
assert.equal(polozky.length, partneri.length, 'v patičce má být tolik položek, kolik je partnerů v datech');
partneri.forEach((partner, index) => {
  assert.ok(polozky[index].textContent.includes(partner.nazev), `${index + 1}. položka má obsahovat název ${partner.nazev}`);
  assert.ok(polozky[index].textContent.includes(partner.role), `${index + 1}. položka má obsahovat roli „${partner.role}"`);
});
```

Zbytek stránky zůstal celý.

```js
assert.equal(document.querySelectorAll('#program .program__radek').length, 6, 'program má zůstat');
assert.equal(document.querySelectorAll('#vstupenky .vstupenka').length, 3, 'ceník má zůstat');
assert.ok(!logs.some((zaznam) => /unique "key"/.test(zaznam.text)), 'i partneři potřebují key');
```

// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
