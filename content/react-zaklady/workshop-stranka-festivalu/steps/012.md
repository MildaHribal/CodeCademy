# --description--

V poli `lineup` má jedna kapela `headliner: true`. V programu to ale zatím nikdo nepozná — a přitom kvůli ní si lidi kupují vstupenky.

**Úkol:** Zařiď, aby řádek headlinera v programu vypadal jinak než ostatní. Jak, je na tobě: ve stylech je připravená třída `program__radek--headliner` (světlejší pozadí a žlutý proužek vlevo), ale klidně přidej štítek navíc, vlastní `style` nebo text u kapely. Ostatní řádky musí zůstat, jak jsou.

Testy kontrolují jen to, že se řádek headlinera od ostatních liší, že ostatní řádky zůstaly mezi sebou stejné a že v programu je dál všech šest kapel i s časy a scénami.

# --hints--

Řádek headlinera se od ostatních řádků liší.

```js
const { lineup } = await helpers.importFile('data.js');
const radky = [...document.querySelectorAll('#program .program__radek')];
assert.equal(radky.length, lineup.length, 'v programu má zůstat všech šest kapel');
const podpis = (el, polozka) => {
  const styl = getComputedStyle(el);
  const potomci = [...el.querySelectorAll('*')];
  const holyText = el.textContent.replace(/\s+/g, '');
  const textZDat = (polozka.cas + polozka.kapela + polozka.scena).replace(/\s+/g, '');
  return [
    el.className,
    potomci.length,
    potomci.map((potomek) => potomek.className).join(','),
    el.getAttribute('style') ?? '',
    holyText === textZDat,
    styl.backgroundColor, styl.backgroundImage, styl.color, styl.fontWeight, styl.boxShadow, styl.borderLeftColor, styl.outlineWidth, styl.outlineColor,
  ].join('|');
};
const podpisy = radky.map((radek, index) => podpis(radek, lineup[index]));
const indexHeadlinera = lineup.findIndex((polozka) => polozka.headliner);
const ostatni = podpisy.filter((_, index) => index !== indexHeadlinera);
assert.ok(!ostatni.includes(podpisy[indexHeadlinera]), `řádek headlinera (${lineup[indexHeadlinera].kapela}) se má od ostatních lišit — třídou, obsahem nebo vzhledem`);
```

Ostatní řádky zůstaly mezi sebou stejné, zvýrazněný je jen headliner.

Čas, kapela i scéna jsou v řádcích dál.

```js
const { lineup } = await helpers.importFile('data.js');
const radky = [...document.querySelectorAll('#program .program__radek')];
lineup.forEach((polozka, index) => {
  assert.ok(radky[index].textContent.includes(polozka.kapela), `${index + 1}. řádek má dál ukazovat kapelu ${polozka.kapela}`);
  assert.ok(radky[index].textContent.includes(polozka.cas), `${index + 1}. řádek má dál ukazovat čas ${polozka.cas}`);
  assert.ok(radky[index].textContent.includes(polozka.scena), `${index + 1}. řádek má dál ukazovat scénu ${polozka.scena}`);
});
```

# --help--

## --tip--

Rozhodnutí uvnitř seznamu je pořád jen výraz — vodítko je v části [Výrazy v `{}`](see:react-zaklady/proc-react#vyrazy-v).

## --tip--

Hodnotu `polozka.headliner` máš v každém průchodu po ruce. Podle ní se dá vybrat třída, přidat další prvek nebo nastavit `style`.

## --tip--

Vyber si jednu cestu a drž se jí: buď rozhoduješ o třídě řádku, nebo o tom, jestli se vedle kapely vykreslí něco navíc.

export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
