# --description--

Když zbývá pár posledních vstupenek, je dobré to říct nahlas. Když jich zbývá tisíc, je stejná hláška trapná — takže se nemá vykreslit vůbec.

**Úkol:** Pod odstavec se stavem přidej odstavec s třídou `hero__spech` a textem **Zbývá posledních 360 vstupenek** (číslo z výpočtu). Vykresli ho jen tehdy, když zbývá méně než 500 vstupenek.

Když levá strana `&&` platí, vykreslí se pravá; když neplatí, React nevykreslí nic:

```jsx
{hostuje && <p className="host">Hostuje: {host}</p>}
```

# --hints--

V hlavičce je odstavec `.hero__spech` s počtem zbývajících vstupenek.

```js
const spech = document.querySelector('.hero__spech');
assert.ok(spech, 'v hlavičce má být odstavec s třídou hero__spech');
assert.match(spech.textContent, /360/, 'odstavec má ukazovat, kolik vstupenek zbývá (360)');
```

Hláška je podmíněná — v kódu je hranice 500.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /500/, 'hlášku vykresli jen při méně než 500 zbývajících vstupenkách');
```

Odstavec se stavem prodeje zůstal nad ní.

```js
const deti = [...document.querySelector('.hero').children].map((el) => el.className);
assert.ok(deti.indexOf('hero__stav') < deti.indexOf('hero__spech'), 'hláška patří pod odstavec se stavem prodeje');
```

# --help--

## --tip--

Podmíněné vykreslení přes `&&` je popsané v části [Co se z `{}` vykreslí a co ne](see:react-zaklady/proc-react#co-se-z-vykresli-a-co-ne).

## --tip--

Vlevo dej porovnání počtu zbývajících vstupenek s hranicí, vpravo celý odstavec. Obojí patří do složených závorek přímo v hlavičce.

## --tip--

Stejný tvar jinde: `{prseloVNoci && <p className="varovani">Trať může být kluzká</p>}`.

```jsx
import './styles.css';
import { festival } from './data.js';
import { formatDate } from './utils.js';

function MistoACas() {
  return (
    <>
      <p className="hero__datum">{formatDate(festival.datum)}</p>
      <p className="hero__misto">{festival.misto}</p>
    </>
  );
}

function Hero() {
  const procentoProdano = Math.round((festival.prodano / festival.kapacita) * 100);
  const zbyva = festival.kapacita - festival.prodano;

  return (
    <header className="hero">
      <p className="hero__kicker">Hudební festival · 3. ročník</p>
      <h1 className="hero__nazev">{festival.nazev}</h1>
      <MistoACas />
      <div className="ukazatel" aria-hidden="true">
        <div className="ukazatel__cara" style={{ inlineSize: `${procentoProdano}%` }} />
      </div>
      <p className="hero__obsazenost">Prodáno {procentoProdano} % vstupenek</p>
      <p className="hero__stav">{zbyva > 0 ? 'Vstupenky v prodeji' : 'Vyprodáno'}</p>
      <a className="tlacitko" href="#vstupenky">Koupit vstupenku</a>
    </header>
  );
}

export default function App() {
  return (
    <div className="stranka">
      <Hero />
    </div>
  );
}

// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
```
