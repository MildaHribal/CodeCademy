# --description--

Šest kapel znamená šest skoro stejných řádků. Psát je ručně by byla chyba: kdykoli se program změní, přepisoval bys značkování místo dat.

Pole se v JSX vykreslí položka po položce, takže stačí pole kapel proměnit v pole řádků. Od toho je `map`.

**Úkol:** Seřaď řádky tak, aby se z pole `lineup` vykreslil seznam řádků programu. Každý řádek má být `<li className="program__radek">` s časem, kapelou a scénou v `<span>`. Do mezery doplň, co má React použít jako `key`.

Odsazení nastavíš klávesou Tab, dva řádky jsou navíc.

> [!PITFALL]
> `forEach` nic nevrací. Když ho v JSX použiješ místo `map`, seznam zůstane prázdný a žádná chyba se neobjeví.

# --hints--

V seznamu je šest řádků, jeden za každou kapelu z `lineup`.

```js
const { lineup } = await helpers.importFile('data.js');
const radky = document.querySelectorAll('#program .program__radek');
assert.equal(radky.length, lineup.length, 'v seznamu má být tolik řádků, kolik je kapel v poli lineup');
```

Řádky jdou ve stejném pořadí jako data a ukazují čas, kapelu i scénu.

```js
const { lineup } = await helpers.importFile('data.js');
const radky = [...document.querySelectorAll('#program .program__radek')];
lineup.forEach((polozka, index) => {
  const radek = radky[index];
  assert.equal(radek.querySelector('.program__cas').textContent.trim(), polozka.cas, `${index + 1}. řádek má ukazovat čas ${polozka.cas}`);
  assert.equal(radek.querySelector('.program__kapela').textContent.trim(), polozka.kapela, `${index + 1}. řádek má ukazovat kapelu ${polozka.kapela}`);
  assert.equal(radek.querySelector('.program__scena').textContent.trim(), polozka.scena, `${index + 1}. řádek má ukazovat scénu ${polozka.scena}`);
});
```

Každý řádek má `key`, takže React v konzoli nic nevytýká.

```js
assert.ok(!logs.some((zaznam) => /unique "key"/.test(zaznam.text)), 'každá položka vykreslená z pole potřebuje key — React si jinak stěžuje do konzole');
```

# --explain--

Vysvětli vlastními slovy, k čemu React potřebuje `key` u položek vykreslených z pole. Proč nestačí pořadí, ve kterém položky přišly?

## --model--

React si při každém renderu porovná nový popis seznamu se starým a potřebuje vědět, která položka je která. `key` je jméno položky mezi jejími sourozenci: podle něj React pozná, že řádek jen změnil pozici, a nechá jeho prvky být místo toho, aby je přepsal. Pořadí samo o sobě nestačí, protože po smazání nebo přeházení položek se posune a React by spároval špatné dvojice. Proto se jako `key` dává stabilní id z dat, ne index.

## --checklist--

- `key` říká Reactu, která položka seznamu je která.
- React podle něj páruje položky mezi dvěma rendery.
- Pořadí (index) se při mazání a přehazování mění, id z dat ne.
- `key` stačí jedinečný mezi sourozenci, ne v celé aplikaci.

export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
