# --description--

Název festivalu je v hlavičce napsaný natvrdo, i když je v `data.js`. Kdyby se ročník přejmenoval, opravuješ na dvou místech.

**Úkol:** V `Hero` vypiš název z objektu `festival` a pod datum přidej odstavec s místem konání (třída `hero__misto`, hodnota z týchž dat).

Do složených závorek patří jakýkoli výraz JavaScriptu:

```jsx
<p className="kontakt">{organizator.email}</p>
```

Objekt `festival` je v souboru už naimportovaný, klíče najdeš v `data.js`.

# --hints--

Nadpis v hlavičce ukazuje název z dat.

```js
const { festival } = await helpers.importFile('data.js');
assert.equal(document.querySelector('.hero__nazev').textContent.trim(), festival.nazev, 'nadpis má ukazovat festival.nazev');
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /\{\s*festival\.nazev\s*\}/, 'název dosaď výrazem, ne přepsaným textem');
```

Pod datem je odstavec `.hero__misto` s místem konání z dat.

```js
const { festival } = await helpers.importFile('data.js');
const misto = document.querySelector('.hero__misto');
assert.ok(misto, 'v hlavičce má přibýt odstavec s třídou hero__misto');
assert.equal(misto.textContent.trim(), festival.misto, 'odstavec má ukazovat festival.misto');
```

Datum zůstalo nad místem a pořád je naformátované.

```js
const deti = [...document.querySelectorAll('.hero > p')].map((p) => p.className);
assert.ok(deti.indexOf('hero__datum') < deti.indexOf('hero__misto'), 'místo patří pod datum');
assert.equal(document.querySelector('.hero__datum').textContent.trim(), '17. července 2026', 'datum má zůstat naformátované');
```

# --help--

## --tip--

Výrazy v JSX jsou popsané v části [Výrazy v `{}`](see:react-zaklady/proc-react#vyrazy-v).

## --tip--

Vlastnost objektu čteš tečkou. Celý výraz obal do složených závorek přímo v místě, kde má text být.

## --tip--

Na jiných datech: `<span className="kapacita">{sal.mistoKSezeni} míst</span>`.

```js
// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
```
