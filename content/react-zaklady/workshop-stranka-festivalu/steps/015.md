# --description--

Ceny v ceníku se čtou špatně: **1290 Kč** je shluk číslic. Česky se píše **1 290 Kč** s mezerou po tisících — a tohle se nikdy nedělá ručně.

**Úkol:** Nad komponentami v `App.jsx` si vyrob formátovač měny pro češtinu a korunu a použij ho v cenách všech tří karet. Desetinná místa nechceš.

Formátovač se vyrábí jednou (mimo komponenty), protože je to drobný, ale zbytečný výpočet — a pak se jen volá. Výsledek musí odpovídat tvaru, který dělá `Intl.NumberFormat` pro `'cs-CZ'`: testy si stejný formátovač postaví taky a porovnají výsledek.

# --hints--

Karty ukazují ceny naformátované po česku (`1 290 Kč`).

```js
const { vstupenky } = await helpers.importFile('data.js');
const format = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK', maximumFractionDigits: 0 });
const karty = [...document.querySelectorAll('#vstupenky .vstupenka')];
vstupenky.forEach((typ, index) => {
  const cena = karty[index].querySelector('.vstupenka__cena').textContent.trim();
  assert.equal(cena, format.format(typ.cena), `cena ${typ.nazev} má být ve tvaru „${format.format(typ.cena)}"`);
});
```

Cena se formátuje z dat, ne přepsaným textem.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /Intl\.NumberFormat/, 'cenu formátuj přes Intl.NumberFormat');
assert.doesNotMatch(kod, /1\s*290\s*Kč/, 'ceny nepiš do JSX ručně — ber je z pole vstupenky');
```

Názvy, popisy i zbytek stránky zůstaly beze změny.

```js
const { vstupenky } = await helpers.importFile('data.js');
const karty = [...document.querySelectorAll('#vstupenky .vstupenka')];
vstupenky.forEach((typ, index) => {
  assert.equal(karty[index].querySelector('.vstupenka__nazev').textContent.trim(), typ.nazev, 'název karty má zůstat');
});
assert.equal(document.querySelectorAll('.patacka .partner').length, 4, 'patička má zůstat');
```

# --help--

## --tip--

Formátování měny jsi psal v lekci [`Intl.NumberFormat`](see:js-retezce-cisla/intl-a-datum#intl-numberformat-ceny-procenta-a-jednotky).

## --tip--

Formátovač bere jazyk a objekt voleb: styl `currency`, měnu `CZK` a nastavení, kolik desetinných míst nejvýš chceš. Volání `format(cislo)` pak vrátí hotový text.

## --tip--

Proměnnou s formátovačem si pojmenuj podle toho, co dělá, a použij ji uvnitř `map` u každé karty.

// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}

import './styles.css';
import { festival, lineup, vstupenky, partneri } from './data.js';

function MistoACas() {
  return (
    <>
      <p className="hero__datum">{formatDate(festival.datum)}</p>
      <p className="hero__misto">{festival.misto}</p>
    </>
  );
}

function Hero() {
  const procentoProdano = Math.round((festival.prodano / festival.kapacita) * 100);
  const zbyva = festival.kapacita - festival.prodano;

  return (
    <header className="hero">
      <p className="hero__kicker">Hudební festival · 3. ročník</p>
      <h1 className="hero__nazev">{festival.nazev}</h1>
      <MistoACas />
      <div className="ukazatel" aria-hidden="true">
        <div className="ukazatel__cara" style={{ inlineSize: `${procentoProdano}%` }} />
      </div>
      <p className="hero__obsazenost">Prodáno {procentoProdano} % vstupenek</p>
      <p className="hero__stav">{zbyva > 0 ? 'Vstupenky v prodeji' : 'Vyprodáno'}</p>
      {zbyva < 500 && <p className="hero__spech">Zbývá posledních {zbyva} vstupenek</p>}

      <a className="tlacitko" href="#vstupenky">Koupit vstupenku</a>
    </header>
  );
}
