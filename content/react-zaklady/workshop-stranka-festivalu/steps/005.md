# --description--

Hlavičce chybí to hlavní — odkaz, který vede na ceník. Vzhled tlačítka je ve stylech hotový (`.tlacitko`: růžové pozadí, kulaté rohy, jemný posun při najetí myší), ty ho jen použiješ.

**Úkol:** Na konec hlavičky přidej odkaz s třídou `tlacitko`, který vede na kotvu `#vstupenky` a nese text **Koupit vstupenku**.

> [!PITFALL]
> V JSX se třída píše `className`. Napsané `class` sice v DOM skončí a styl se náhodou použije, ale React ti do konzole náhledu napíše `Invalid DOM property 'class'. Did you mean 'className'?` — a právě tenhle řádek v konzoli testy hledají.

# --hints--

Na konci hlavičky je odkaz na `#vstupenky` s textem.

```js
const odkaz = document.querySelector('.hero a');
assert.ok(odkaz, 'v hlavičce má být odkaz <a>');
assert.equal(odkaz.getAttribute('href'), '#vstupenky', 'odkaz má vést na kotvu #vstupenky');
assert.notEqual(odkaz.textContent.trim(), '', 'odkaz má mít text, aby bylo poznat, co dělá');
```

Odkaz má třídu `tlacitko`, takže vypadá jako růžové tlačítko.

```js
const odkaz = document.querySelector('.hero a');
assert.equal(getComputedStyle(odkaz).backgroundColor, 'rgb(255, 92, 122)', 'odkaz má mít třídu tlacitko — v JSX se třída zapisuje jako className');
```

V konzoli náhledu nezůstala stížnost na neznámou vlastnost `class`.

```js
assert.ok(!logs.some((zaznam) => /Invalid DOM property/.test(zaznam.text)), 'React hlásí do konzole neznámou vlastnost — v JSX se třída zapisuje jako className a odkaz jako htmlFor');
```

Odkaz je poslední v hlavičce, pod ostatními údaji.

```js
const deti = [...document.querySelector('.hero').children];
assert.equal(deti.at(-1).tagName, 'A', 'odkaz má být poslední prvek hlavičky');
```

# --help--

## --tip--

Jména vlastností v JSX se drží DOM API — viz [Atributy se jmenují jako v JavaScriptu](see:react-zaklady/proc-react#atributy-se-jmenuji-jako-v-javascriptu).

## --tip--

Odkaz je obyčejný `<a>` s `href`. Třídu mu dej vlastností, která se v JavaScriptu jmenuje jinak než v HTML.

## --tip--

Na jiném prvku: `<button className="tlacitko tlacitko--tiche" type="button">Zavřít</button>`.

```js
// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
```
