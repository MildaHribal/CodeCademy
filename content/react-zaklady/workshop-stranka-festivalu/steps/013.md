# --description--

Odkaz v hlavičce vede na kotvu `#vstupenky`, jenže žádný ceník na stránce není. V `data.js` je pole `vstupenky` se třemi typy — každý má `id`, `nazev`, `cena` a `popis`.

**Úkol:** Pod sekci programu přidej druhou sekci s identifikátorem `vstupenky`, nadpisem **Vstupenky** a seznamem `ul` s třídou `vstupenky`, ve kterém z pole vykreslíš kartu každého typu.

Karta je `<li className="vstupenka">` a uvnitř má nadpis třetí úrovně `.vstupenka__nazev` s názvem, odstavec `.vstupenka__cena` s cenou a slovem **Kč** a odstavec `.vstupenka__popis` s popisem. Vzhled karet je ve stylech hotový, včetně mřížky, která je poskládá vedle sebe.

Pole `vstupenky` nezapomeň doimportovat. Seznam vyrobíš stejně jako program — a stejně jako tam potřebuje každá položka svůj `key`.

# --hints--

Pod programem je sekce `#vstupenky` s nadpisem a seznamem karet.

```js
const sekce = document.querySelector('.stranka > #vstupenky.sekce');
assert.ok(sekce, 'pod programem má být <section className="sekce" id="vstupenky">');
assert.ok(sekce.querySelector('h2.sekce__nadpis'), 'sekce má mít nadpis h2 s třídou sekce__nadpis');
assert.ok(sekce.querySelector('ul.vstupenky'), 'v sekci má být seznam <ul className="vstupenky">');
```

Karet je tolik, kolik je typů vstupenek, a jdou ve stejném pořadí jako data.

```js
const { vstupenky } = await helpers.importFile('data.js');
const karty = [...document.querySelectorAll('#vstupenky .vstupenka')];
assert.equal(karty.length, vstupenky.length, 'karet má být tolik, kolik je typů vstupenek v datech');
vstupenky.forEach((typ, index) => {
  assert.equal(karty[index].querySelector('.vstupenka__nazev').textContent.trim(), typ.nazev, `${index + 1}. karta má mít nadpis ${typ.nazev}`);
  assert.equal(karty[index].querySelector('.vstupenka__popis').textContent.trim(), typ.popis, `${index + 1}. karta má mít popis z dat`);
});
```

Každá karta ukazuje cenu z dat a v konzoli není stížnost na chybějící `key`.

```js
const { vstupenky } = await helpers.importFile('data.js');
const karty = [...document.querySelectorAll('#vstupenky .vstupenka')];
vstupenky.forEach((typ, index) => {
  const cena = karty[index].querySelector('.vstupenka__cena').textContent;
  assert.match(cena, new RegExp(String(typ.cena)), `${index + 1}. karta má ukazovat cenu ${typ.cena}`);
  assert.match(cena, /Kč/, 'u ceny má být i měna');
});
assert.ok(!logs.some((zaznam) => /unique "key"/.test(zaznam.text)), 'i karty vstupenek potřebují key');
```

# --help--

## --tip--

Vykreslení pole je popsané v části [Co se z `{}` vykreslí a co ne](see:react-zaklady/proc-react#co-se-z-vykresli-a-co-ne); stejný tvar máš o dva kroky výš v programu.

## --tip--

Nová sekce patří do `App` za sekci programu. Uvnitř seznamu použij stejnou metodu pole jako u kapel a vracej z ní celou kartu.

## --tip--

Jako `key` se hodí `id` z dat — každý typ vstupenky ho má, stejně jako kapely.

// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}

import './styles.css';
import { festival, lineup } from './data.js';
import { formatDate } from './utils.js';

function MistoACas() {
  return (
    <>
      <p className="hero__datum">{formatDate(festival.datum)}</p>
      <p className="hero__misto">{festival.misto}</p>
    </>
  );
}

function Hero() {
  const procentoProdano = Math.round((festival.prodano / festival.kapacita) * 100);
  const zbyva = festival.kapacita - festival.prodano;

  return (
    <header className="hero">
      <p className="hero__kicker">Hudební festival · 3. ročník</p>
      <h1 className="hero__nazev">{festival.nazev}</h1>
      <MistoACas />
      <div className="ukazatel" aria-hidden="true">
        <div className="ukazatel__cara" style={{ inlineSize: `${procentoProdano}%` }} />
      </div>
      <p className="hero__obsazenost">Prodáno {procentoProdano} % vstupenek</p>
      <p className="hero__stav">{zbyva > 0 ? 'Vstupenky v prodeji' : 'Vyprodáno'}</p>
      {zbyva < 500 && <p className="hero__spech">Zbývá posledních {zbyva} vstupenek</p>}
      <p className="hero__vip">VIP vstupenky: {festival.volneVip > 0 ? <strong>{festival.volneVip} volných</strong> : 'vyprodáno'}</p>
      <a className="tlacitko" href="#vstupenky">Koupit vstupenku</a>
    </header>
  );
}

export default function App() {
  return (
    <div className="stranka">
      <Hero />
      <section className="sekce" id="program">
        <h2 className="sekce__nadpis">Program pátku</h2>
        <p className="sekce__meta">{lineup.length} kapel na dvou scénách</p>

            <li

              <span className="program__kapela">{polozka.kapela}</span>
              <span className="program__scena">{polozka.scena}</span>
            </li>
          ))}
        </ul>

  );
}
