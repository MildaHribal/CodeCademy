# --description--

Funkce `App` má přes padesát řádků a čte se hůř a hůř. Přesně v téhle chvíli se v práci stránka dělí na komponenty: každá má jedno téma a jméno, které řekne, co vykresluje.

**Úkol:** Rozděl `App` na komponenty `Program`, `Vstupenky` a `Patacka`, každá vrátí svou část stránky. Ve funkci `App` má zůstat jen obal `.stranka` a v něm čtyři značky komponent pod sebou.

Náhled se po tomhle kroku nezmění ani o pixel — a to je celá pointa. Refaktoring mění tvar kódu, ne výsledek; testy hlídají, že jsi cestou nic neztratil.

## Udělej po svém

Stránka je hotová, data v `data.js` jsou jenom začátek. Vyber si aspoň jedno:

- **Sobotní program.** Přidej do dat druhý den a vypiš dvě sekce programu pod sebou. Všimni si, jak moc se od sebe budou lišit jen daty — a přesně tenhle problém vyřeší props v další lekci.
- **Vizuální nápad.** Dej headlinerovi větší kartu, vlastní gradient nebo štítek „HEADLINER", ať to na první pohled vyskočí.
- **Odpočet.** Nad tlačítkem ukaž, kolik dní zbývá do festivalu — datum máš v datech a počítání s `Date` znáš.
- **Tvoje téma.** Přepiš data na festival, konferenci nebo turnaj, který tě zajímá. Struktura zůstane, obsah bude tvůj.

V příští lekci se stránka přestane opakovat: komponenty začnou brát props, takže jedna `Karta` zvládne kapelu, vstupenku i partnera.

## --tip--

Stavba stránky ze stromu komponent je v části [Komponenta je funkce, která vrací JSX](see:react-zaklady/proc-react#komponenta-je-funkce-ktera-vraci-jsx).

## --tip--

Postupuj po jedné: vytvoř prázdnou funkci, přesuň do jejího `return` celou jednu sekci a v `App` na její místo dej značku. Pak spusť kontrolu a pokračuj další.

## --tip--

Pomůže stejný postup jako u `Hero` v druhém kroku — jen třikrát a s většími kusy značkování.

# --explain--

Vysvětli, proč se vyplatí rozdělit jednu velkou komponentu na několik menších, když se výsledek na stránce vůbec nezmění.

## --model--

Komponenta je funkce a platí pro ni totéž co pro funkce jinde: krátkou přečtu celou naráz a poznám, co dělá. Když má `App` padesát řádků značkování, hledám v ní očima; když má čtyři značky se jmény, čtu ji jako obsah stránky. Menší komponenty jdou navíc přesouvat, používat na jiném místě a testovat zvlášť, a když se něco rozbije, vím rovnou, ve které z nich hledat.

## --checklist--

- Jméno komponenty říká, co vykresluje, takže se `App` čte jako obsah stránky.
- Malou komponentu přečtu celou naráz a najdu v ní chybu rychleji.
- Části jdou přesunout nebo použít jinde bez kopírování.
- Výsledek v prohlížeči zůstává stejný — mění se jen tvar kódu.

// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}

import './styles.css';
import { festival, lineup, vstupenky, partneri } from './data.js';
import { formatDate } from './utils.js';

const cenaFormat = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK', maximumFractionDigits: 0 });

function MistoACas() {
  return (
    <>
      <p className="hero__datum">{formatDate(festival.datum)}</p>
      <p className="hero__misto">{festival.misto}</p>
    </>
  );
}

function Hero() {
  const procentoProdano = Math.round((festival.prodano / festival.kapacita) * 100);
  const zbyva = festival.kapacita - festival.prodano;

  return (
    <header className="hero">
      <p className="hero__kicker">Hudební festival · 3. ročník</p>
      <h1 className="hero__nazev">{festival.nazev}</h1>
      <MistoACas />
      <div className="ukazatel" aria-hidden="true">
        <div className="ukazatel__cara" style={{ inlineSize: `${procentoProdano}%` }} />
      </div>
      <p className="hero__obsazenost">Prodáno {procentoProdano} % vstupenek</p>
      <p className="hero__stav">{zbyva > 0 ? 'Vstupenky v prodeji' : 'Vyprodáno'}</p>
      {zbyva < 500 && <p className="hero__spech">Zbývá posledních {zbyva} vstupenek</p>}
      <p className="hero__vip">VIP vstupenky: {festival.volneVip > 0 ? <strong>{festival.volneVip} volných</strong> : 'vyprodáno'}</p>
      <a className="tlacitko" href="#vstupenky">Koupit vstupenku</a>
    </header>
  );
}

export default function App() {
  return (
    <div className="stranka">
      <Hero />
      <section className="sekce" id="program">
        <h2 className="sekce__nadpis">Program pátku</h2>
        <p className="sekce__meta">{lineup.length} kapel na dvou scénách</p>
        <ul className="program">
          {lineup.map((polozka) => (
            <li
              className={polozka.headliner ? 'program__radek program__radek--headliner' : 'program__radek'}
              key={polozka.id}
            >
              <span className="program__cas">{polozka.cas}</span>
              <span className="program__kapela">{polozka.kapela}</span>
              <span className="program__scena">{polozka.scena}</span>
            </li>
          ))}
        </ul>
      </section>
      <section className="sekce" id="vstupenky">
        <h2 className="sekce__nadpis">Vstupenky</h2>
        <ul className="vstupenky">
          {vstupenky.map((typ) => (
            <li className="vstupenka" key={typ.id}>
              <h3 className="vstupenka__nazev">{typ.nazev}</h3>
              <p className="vstupenka__cena">{cenaFormat.format(typ.cena)}</p>
              <p className="vstupenka__popis">{typ.popis}</p>
            </li>
          ))}
        </ul>
      </section>
      <footer className="patacka">
        <p>Festival podporují:</p>
        <ul className="partneri">
          {partneri.map((partner) => (
            <li className="partner" key={partner.id}>
              {partner.nazev} — {partner.role}
            </li>
          ))}
        </ul>
      </footer>
    </div>
  );
}
