# --description--

Hlavička je hotová — kdyby ti došel čas, tohle už je kus stránky, který stojí sám. Teď k ní přidáš program.

**Úkol:** Pod `<Hero />` přidej do `App` sekci s třídou `sekce` a identifikátorem `program`. Uvnitř bude nadpis druhé úrovně **Program pátku** s třídou `sekce__nadpis`, pod ním odstavec `.sekce__meta`, který z pole `lineup` vypíše, kolik kapel hraje (text **6 kapel na dvou scénách** — číslo z délky pole), a pod ním zatím prázdný seznam `ul` s třídou `program`.

Pole `lineup` musíš do souboru doimportovat; objekt `festival` už tam naimportovaný je a přidává se za čárku.

Délka pole je obyčejný výraz, takže patří do složených závorek:

```jsx
<p className="pocet">{recepty.length} receptů k vyzkoušení</p>
```

# --hints--

Pod hlavičkou je sekce `#program` s nadpisem druhé úrovně.

```js
const sekce = document.querySelector('.stranka > #program.sekce');
assert.ok(sekce, 'pod hlavičkou má být <section className="sekce" id="program">');
const nadpis = sekce.querySelector('h2.sekce__nadpis');
assert.ok(nadpis, 'sekce má mít nadpis h2 s třídou sekce__nadpis');
assert.match(nadpis.textContent, /Program/, 'nadpis sekce má mluvit o programu');
```

Odstavec `.sekce__meta` vypíše počet kapel z pole `lineup`.

```js
const { lineup } = await helpers.importFile('data.js');
const meta = document.querySelector('#program .sekce__meta');
assert.ok(meta, 'v sekci má být odstavec s třídou sekce__meta');
assert.match(meta.textContent, new RegExp(String(lineup.length)), 'odstavec má vypsat počet kapel z délky pole lineup');
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /lineup\.length/, 'počet kapel ber z pole (lineup.length), ne z prstu');
```

V sekci je zatím prázdný seznam `ul.program`.

```js
const seznam = document.querySelector('#program ul.program');
assert.ok(seznam, 'v sekci má být seznam <ul className="program">');
assert.equal(seznam.children.length, 0, 'seznam zůstane zatím prázdný — naplníš ho v dalším kroku');
```

## --tip--

Jde o výraz v JSX a o import dat — viz [Výrazy v `{}`](see:react-zaklady/proc-react#vyrazy-v).

## --tip--

Import z `data.js` je na začátku souboru; jména se do složených závorek píšou za sebou oddělená čárkou. Sekci vlož do `App` hned za značku hlavičky.

## --tip--

Na jiných datech: `<section className="sekce" id="kontakt">` s nadpisem a odstavcem `{tymy.length} týmů v lize`.

## --file-- App.jsx

```jsx
import './styles.css';
import { festival } from './data.js';
import { formatDate } from './utils.js';

function MistoACas() {
  return (
    <>
      <p className="hero__datum">{formatDate(festival.datum)}</p>
      <p className="hero__misto">{festival.misto}</p>
    </>
  );
}

function Hero() {
  const procentoProdano = Math.round((festival.prodano / festival.kapacita) * 100);
  const zbyva = festival.kapacita - festival.prodano;

  return (
    <header className="hero">
      <p className="hero__kicker">Hudební festival · 3. ročník</p>
      <h1 className="hero__nazev">{festival.nazev}</h1>
      <MistoACas />
      <div className="ukazatel" aria-hidden="true">
        <div className="ukazatel__cara" style={{ inlineSize: `${procentoProdano}%` }} />
      </div>
      <p className="hero__obsazenost">Prodáno {procentoProdano} % vstupenek</p>
      <p className="hero__stav">{zbyva > 0 ? 'Vstupenky v prodeji' : 'Vyprodáno'}</p>
      {zbyva < 500 && <p className="hero__spech">Zbývá posledních {zbyva} vstupenek</p>}
      <a className="tlacitko" href="#vstupenky">Koupit vstupenku</a>
    </header>
  );
}

export default function App() {
  return (
    <div className="stranka">
      <Hero />
    </div>
  );
}
```

```js
// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
```
