# --description--

## Hlášení

Kolega přidal do hlavičky řádek o VIP vstupenkách. Píše: „Když je volných VIP míst pět, ukáže se *VIP vstupenky: 5 volných*. Jenže teď je vyprodáno, `volneVip` je nula — a místo aby se nenapsalo nic, svítí v hlavičce osamocená nula: **VIP vstupenky: 0**. Nechápu to, vždyť nula je nepravdivá."

## Úkol

Oprav řádek tak, aby při nule volných VIP vstupenek stálo v odstavci **VIP vstupenky: vyprodáno**, a při kladném počtu zůstalo tučné číslo s textem *volných*. Změň co nejmenší kus kódu; zbytek hlavičky nech být.

# --hints--

Při nule volných VIP vstupenek stojí v odstavci „VIP vstupenky: vyprodáno".

```js
const vip = document.querySelector('.hero__vip');
assert.ok(vip, 'odstavec .hero__vip má v hlavičce zůstat');
assert.equal(vip.textContent.replace(/\s+/g, ' ').trim(), 'VIP vstupenky: vyprodáno', 'při nule volných VIP vstupenek má odstavec hlásit „vyprodáno"');
assert.doesNotMatch(vip.textContent, /0/, 'v odstavci nesmí zůstat osamocená nula');
```

Kladný počet se pořád ukáže tučně: v kódu zůstal `<strong>` s počtem.

```js
const kod = helpers.stripComments(files['App.jsx'], 'js');
assert.match(kod, /<strong>\{festival\.volneVip\}[^<]*<\/strong>/, 'tučný počet volných VIP vstupenek má v kódu zůstat pro případ, že se nějaké uvolní');
```

Zbytek hlavičky i program fungují dál.


# --help--

## --tip--

Stejnou past rozebírá část [Nula, která se vykreslí](see:react-zaklady/proc-react#nula-ktera-se-vykresli).

## --tip--

Chyba je v tom, co se do složených závorek dostane, když je počet nula. Uprav jediný výraz uvnitř odstavce `.hero__vip`.

## --tip--

Na jiných datech: `{nepreectenych > 0 ? <strong>{nepreectenych}</strong> : 'vše přečteno'}`.

# --explain--

Vysvětli, proč se na stránce objevila nula, i když je nula nepravdivá hodnota.

## --model--

Operátor `&&` nevrací `true` nebo `false`, ale jednu ze svých stran: když je levá strana nepravdivá, vrátí rovnou ji a pravé se ani nedotkne. Levá strana tady byla číslo `0`, takže z celého výrazu vypadla nula. A React čísla vykresluje — schová jen `null`, `undefined` a logické hodnoty. Proto se do stránky napsala nula místo ničeho.

## --checklist--

- `&&` vrací levou hodnotu, když je nepravdivá, ne `false`.
- Nula je nepravdivá, ale pořád je to číslo.
- React nevykreslí `null`, `undefined`, `true` ani `false` — čísla ano.
- Opravou je porovnání (`> 0`) nebo ternární operátor s druhou větví.

```js
// Datum ve tvaru „17. července 2026".
export function formatDate(iso) {
  const format = new Intl.DateTimeFormat('cs-CZ', { day: 'numeric', month: 'long', year: 'numeric' });
  return format.format(new Date(iso));
}
```
