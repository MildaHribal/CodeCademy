# --description--

Modul `kosik.js` v tomhle projektu napsal model. Spusť ho tlačítkem **Spustit** —
v konzoli uvidíš, že na ukázkovém košíku počítá správně. Přesně proto ho nikdo
nekontroloval.

Tvoje práce v tomhle workshopu je najít v něm sedm chyb, a to v pořadí, které má
smysl i mimo Akademii: **nejdřív chybu dokázat konkrétními daty, teprve pak ji opravit.**
Dokud nemáš vstup, na kterém se kód prokazatelně plete, máš jen podezření — a podezření
se nedá opravit ani zkontrolovat.

První otázka z lekce zní „co se stane, když nic nepřijde?". Zákazník si může z košíku
všechno odebrat a pak kliknout na přepočet.

**Úkol:** do vyznačeného místa napiš funkci `protipriklad1()`, která vrátí takový obsah
košíku, na kterém dnešní `soucetPolozek` vyhodí výjimku. Nic jiného zatím neopravuj.

Na jiných datech: kdybys dokazoval chybu ve funkci pro průměr známek, protipříklad by
byl prázdný seznam známek.

# --hints--

`protipriklad1()` vrátí pole položek košíku.

```js
const kosik = protipriklad1();
assert.ok(Array.isArray(kosik), 'protipriklad1() má vrátit pole položek košíku');
```

Na tom, co `protipriklad1()` vrátí, dnešní `soucetPolozek` spadne — tím je chyba dokázaná.

```js
let spadlo = false;
try {
  soucetPolozek(protipriklad1());
} catch (chyba) {
  spadlo = true;
}
assert.ok(spadlo, 'soucetPolozek(protipriklad1()) má vyhodit výjimku — protipříklad musí chybu prokázat');
```

# --help--

## --tip--

Jde o okrajový případ vstupu. Které tři vstupy se ptáš u každé funkce, je v [Tři otázky, které najdou nejvíc](see:prace-s-ai/review-kodu-z-ai#3-tri-otazky-ktere-najdou-nejvic).

## --tip--

Podívej se na `soucetPolozek` a projdi si očima, co udělá `reduce`, když v poli není ani jedna položka.

## --tip--

Stejný protipříklad by rozbil i funkci, která počítá průměrnou dobu doručení ze seznamu objednávek: seznam bez jediné objednávky.

## --file-- script.js

```js
// kosik.js — tenhle soubor napsal model ze zadání:
// "Modul pro košík e-shopu Cyklo Ráže: součet položek, slevový kód,
//  doprava zdarma od 1500 Kč, popis objednávky do e-mailu."
// Nikdo ho pak nečetl. Prošel, protože na ukázkovém košíku vrací správná čísla.

const SLEVOVE_KODY = [
  { kod: 'JARO10', typ: 'procenta', hodnota: 10 },
  { kod: 'VIP500', typ: 'castka', hodnota: 500 },
  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet);
}

function cenaDopravy(soucet) {
  return soucet > DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + jmeno + ': ' + poznamka + '</p>';
}

function pouzijSlevu(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return soucet - zaznam.hodnota;
}

function celkovaCena(polozky, kod) {
  const poSleve = pouzijSlevu(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}

// --- Tvoje protipříklady ---
// Každá chyba se nejdřív dokáže konkrétními daty, teprve pak se opravuje.

--edit--
--edit--

console.log('Součet ukázkového košíku: ' + soucetPolozek(UKAZKOVY_KOSIK) + ' Kč');
```
