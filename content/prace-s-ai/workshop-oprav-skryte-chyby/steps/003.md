# --description--

Druhá chyba je z jiného soudku: nic nespadne, jen se účtuje o 99 Kč víc, než má. Takové
chybě se říká tichá — nikde se neozve a najde ji až zákazník.

V ceníku e-shopu stojí: **doprava zdarma od 1500 Kč**. „Od" znamená, že objednávka přesně
za 1500 Kč už dopravu neplatí.

**Úkol:** napiš funkci `protipriklad2()`, která vrátí takovou částku v korunách, u níž
dnešní `cenaDopravy` pořád účtuje 99 Kč, přestože podle ceníku má být doprava zdarma.

Pozor, tohle je past na rychlé čtení: funkce `cenaDopravy` vypadá na první pohled
správně a na částce 2000 Kč se chová podle ceníku.

# --hints--

`protipriklad2()` vrátí částku, která podle ceníku už na dopravu zdarma dosáhne.

```js
const soucet = protipriklad2();
assert.equal(typeof soucet, 'number', 'protipriklad2() má vrátit částku v korunách jako číslo');
assert.ok(soucet >= 1500, 'protipriklad2() má vrátit částku, u které podle ceníku doprava neplatí, tedy 1500 Kč nebo víc');
```

Dnešní `cenaDopravy` na té částce pořád účtuje 99 Kč.

```js
assert.equal(cenaDopravy(protipriklad2()), 99, 'cenaDopravy(protipriklad2()) má s dnešním kódem vrátit 99 — tím je chyba dokázaná');
```

# --help--

## --tip--

Chyby na hranici intervalu jsou nejčastější tiché chyby vůbec. Co všechno hlídat v revizi, je v [Checklistu pro review](see:prace-s-ai/review-kodu-z-ai#2-checklist-pro-review).

## --tip--

Porovnej větu z ceníku („od 1500 Kč") s porovnáním, které je ve funkci `cenaDopravy`. Patří částka přesně 1500 podle kódu do dopravy zdarma?

## --tip--

Stejná past jinde: „vstup zdarma od 65 let" zapsané jako `vek > 65` nechá pětašedesátníky platit.

// kosik.js — tenhle soubor napsal model ze zadání:
// "Modul pro košík e-shopu Cyklo Ráže: součet položek, slevový kód,
//  doprava zdarma od 1500 Kč, popis objednávky do e-mailu."
// Nikdo ho pak nečetl. Prošel, protože na ukázkovém košíku vrací správná čísla.

const SLEVOVE_KODY = [
  { kod: 'JARO10', typ: 'procenta', hodnota: 10 },
  { kod: 'VIP500', typ: 'castka', hodnota: 500 },
  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet, 0);
}

function cenaDopravy(soucet) {
  return soucet > DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + jmeno + ': ' + poznamka + '</p>';
}

function pouzijSlevu(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return soucet - zaznam.hodnota;
}

function celkovaCena(polozky, kod) {
  const poSleve = pouzijSlevu(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}
