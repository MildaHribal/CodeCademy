# --description--

## Hlášení

Z provozu:

> Nasadili jsme `cenaPoSleve` a ověřili jsme ji testy, ale zákazníci pořád hlásí bílou
> stránku, když zadají starý kód z letáku. Objednávka za 300 Kč s kódem VIP500 se navíc
> pořád tváří, že máme zaplatit zákazníkovi.

## Úkol

Modul má teď dvě funkce, které počítají totéž — jednu opravenou a jednu původní. Najdi,
která z nich se doopravdy používá při výpočtu objednávky, a přepni ji na tu ověřenou.
Starou funkci, kterou už nikdo nevolá, z modulu odstraň: mrtvý kód, který se tváří jako
živý, je sám o sobě chyba.

# --hints--

Celková cena projde i s neznámým kódem.

```js
assert.equal(celkovaCena(UKAZKOVY_KOSIK, protipriklad3()), 1790, 'celkovaCena s neznámým kódem má vrátit 1790 (doprava zdarma), ne spadnout');
assert.equal(celkovaCena([{ nazev: 'Bidon', cena: 200, pocet: 1 }], protipriklad3()), 299, 'objednávka za 200 Kč s neznámým kódem má vyjít na 299 Kč včetně dopravy');
```

Celková cena počítá správně obě slevy a nespadne pod nulu.

```js
assert.equal(celkovaCena(UKAZKOVY_KOSIK, 'JARO10'), 1611, "celkovaCena(UKAZKOVY_KOSIK, 'JARO10') má vrátit 1611");
assert.equal(celkovaCena(UKAZKOVY_KOSIK, 'VIP500'), 1389, "celkovaCena(UKAZKOVY_KOSIK, 'VIP500') má vrátit 1290 + 99 za dopravu = 1389");
assert.equal(celkovaCena([{ nazev: 'Bidon', cena: 300, pocet: 1 }], 'VIP500'), 99, 'objednávka za 300 Kč s kódem VIP500 má vyjít na 99 Kč za dopravu, ne na záporné číslo');
```

Stará funkce už v modulu není.

```js
assert.equal(typeof pouzijSlevu, 'undefined', 'starou funkci pouzijSlevu už modul nemá obsahovat — nikdo ji nevolá');
```

# --help--

## --tip--

Nejdřív najdi volající: projdi modul a hledej, odkud se stará funkce volá. Postup je v [Checklistu pro review](see:prace-s-ai/review-kodu-z-ai#2-checklist-pro-review).

## --tip--

V `celkovaCena` je jediné volání, které počítá slevu. To je to místo, které se mění.

## --tip--

Stejná situace jinde: po přepsání `formatujDatum` na novou verzi zbude stará funkce v souboru a někdo ji za měsíc omylem použije.

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet, 0);
}

function cenaDopravy(soucet) {
  return soucet >= DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {

}

function pouzijSlevu(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (zaznam.typ === 'procenta') {

}

function celkovaCena(polozky, kod) {

  if (!zaznam) {

    return soucet - (soucet * zaznam.hodnota) / 100;
