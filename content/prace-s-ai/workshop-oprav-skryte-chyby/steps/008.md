# --description--

Pátá chyba je nejtišší ze všech: nic nespadne, nic se nespočítá špatně, jen se u volajícího
potichu změní data, o která se opírá něco jiného. V e-shopu se to projeví tak, že po
kliknutí na „seřadit podle ceny" se přeskládá i seznam v košíku a tlačítko Zpět už nemá
kam se vrátit.

**Úkol:** napiš funkci `protipriklad4()`, která vrátí pole položek košíku **neseřazené
podle ceny** (aspoň dvě položky). Na takových datech půjde ukázat, že `seradPodleCeny`
sáhne i na pole, které dostala.

Neseřazenost je tady podstatná: kdybys vrátil položky už seřazené, řazení by s nimi nic
neudělalo a mutace by nebyla vidět. Protipříklad musí rozdíl vyrobit, ne ho schovat.

# --hints--

`protipriklad4()` vrátí aspoň dvě položky s číselnou cenou.

```js
const polozky = protipriklad4();
assert.ok(Array.isArray(polozky), 'protipriklad4() má vrátit pole');
assert.ok(polozky.length >= 2, 'protipriklad4() má vrátit aspoň dvě položky');
assert.ok(polozky.every((p) => typeof p.cena === 'number'), 'každá položka má mít cenu jako číslo');
```

Položky nejsou seřazené podle ceny, takže na nich jde rozdíl poznat.

```js
const ceny = protipriklad4().map((p) => p.cena);
const serazene = [...ceny].sort((a, b) => a - b);
assert.notEqual(ceny.join(','), serazene.join(','), 'protipriklad4() má vrátit položky, které podle ceny seřazené NEJSOU');
```

Po zavolání `seradPodleCeny` se pole, které funkce dostala, prokazatelně změní.

```js
const polozky = protipriklad4();
const pred = polozky.map((p) => p.cena).join(',');
seradPodleCeny(polozky);
assert.notEqual(polozky.map((p) => p.cena).join(','), pred, 'po seradPodleCeny(polozky) se má původní pole prokazatelně změnit — tím je mutace doložená');
```

# --help--

## --tip--

Která metoda pole mění původní pole a která vrací nové, je v [Mutace pole z parametru](see:js-pole/co-je-pole#mutace-pole-z-parametru).

## --tip--

Stačí vrátit tři položky, kde ta nejdražší nebude poslední. Tvar položky si opiš z ukázkového košíku nahoře.

## --tip--

Stejný důkaz jinde: seznam jmen v pořadí „Zuzana, Adam, Marek" ukáže, že řazení sáhlo na původní pole. Seznam „Adam, Marek, Zuzana" neukáže nic.

```js
// kosik.js — tenhle soubor napsal model ze zadání:
// "Modul pro košík e-shopu Cyklo Ráže: součet položek, slevový kód,
//  doprava zdarma od 1500 Kč, popis objednávky do e-mailu."
// Nikdo ho pak nečetl. Prošel, protože na ukázkovém košíku vrací správná čísla.

const SLEVOVE_KODY = [
  { kod: 'JARO10', typ: 'procenta', hodnota: 10 },
  { kod: 'VIP500', typ: 'castka', hodnota: 500 },
  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet, 0);
}

function cenaDopravy(soucet) {
  return soucet >= DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + jmeno + ': ' + poznamka + '</p>';
}

function celkovaCena(polozky, kod) {
  const poSleve = cenaPoSleve(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}

function cenaPoSleve(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (!zaznam) {
    return soucet;
  }
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return Math.max(0, soucet - zaznam.hodnota);
}

// --- Tvoje protipříklady ---
// Každá chyba se nejdřív dokáže konkrétními daty, teprve pak se opravuje.

function protipriklad1() {
  return [];
}

function protipriklad2() {
  return 1500;
}

function protipriklad3() {
  return 'PODZIM20';
}

--edit--
```
