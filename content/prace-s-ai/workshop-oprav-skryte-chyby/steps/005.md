# --description--

Třetí otázka z lekce zní „co se stane, když to selže?". Do políčka pro slevový kód může
zákazník napsat cokoli — starý kód z loňského letáku, překlep, nebo úplnou hloupost.

**Úkol:** napiš funkci `protipriklad3()`, která vrátí takový slevový kód (jako text),
na kterém dnešní `pouzijSlevu` vyhodí výjimku.

Až budeš mít protipříklad, podívej se do `pouzijSlevu` a `najdiKod` a všimni si, kde
přesně se to stane. Tenhle vzor — funkce vrátí `undefined` a o řádek dál na něm někdo
čte vlastnost — je nejčastější způsob, jak vygenerovaný kód spadne v provozu.

# --hints--

`protipriklad3()` vrátí slevový kód jako text, a to kód, který v modulu není.

```js
const kod = protipriklad3();
assert.equal(typeof kod, 'string', 'protipriklad3() má vrátit slevový kód jako text');
assert.ok(!SLEVOVE_KODY.some((zaznam) => zaznam.kod === kod), 'protipriklad3() má vrátit kód, který v SLEVOVE_KODY není');
```

Na tom kódu dnešní `pouzijSlevu` spadne.

```js
let spadlo = false;
try {
  pouzijSlevu(1000, protipriklad3());
} catch (chyba) {
  spadlo = true;
}
assert.ok(spadlo, 'pouzijSlevu(1000, protipriklad3()) má s dnešním kódem vyhodit výjimku');
```

# --help--

## --tip--

Jde o chybějící ošetření stavu „nenašlo se". Proč tenhle stav v generovaném kódu chybí, je v [Šťastné cestě](see:prace-s-ai/jak-llm-selhava#4-stastna-cesta-bez-osetrenych-stavu).

## --tip--

Funkce `najdiKod` používá `find`. Rozmysli si, co `find` vrátí, když v poli žádný záznam nesedí — a co se pak stane o řádek níž.

## --tip--

Stejný vzor jinde: `uzivatele.find(u => u.id === id).email` spadne u každého id, které v seznamu není.

// kosik.js — tenhle soubor napsal model ze zadání:
// "Modul pro košík e-shopu Cyklo Ráže: součet položek, slevový kód,
//  doprava zdarma od 1500 Kč, popis objednávky do e-mailu."
// Nikdo ho pak nečetl. Prošel, protože na ukázkovém košíku vrací správná čísla.

const SLEVOVE_KODY = [
  { kod: 'JARO10', typ: 'procenta', hodnota: 10 },
  { kod: 'VIP500', typ: 'castka', hodnota: 500 },
  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet, 0);
}

function cenaDopravy(soucet) {
  return soucet >= DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + jmeno + ': ' + poznamka + '</p>';
}

function pouzijSlevu(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return soucet - zaznam.hodnota;
}

function celkovaCena(polozky, kod) {
  const poSleve = pouzijSlevu(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}

function protipriklad1() {
  return [];
}

function protipriklad2() {
  return 1500;
}
