# --description--

## Hlášení

Z podpory přišel přepis hovoru:

> Zákaznice si dala do košíku tři věci, pak si to rozmyslela a všechny je odebrala.
> Místo prázdného košíku se jí ukázala bílá stránka. V konzoli prohlížeče je
> `TypeError: Reduce of empty array with no initial value`.

## Úkol

Oprav `soucetPolozek` tak, aby prázdný košík vyšel na `0` Kč, a udělej to co nejmenší
změnou. Ukázkový košík musí vycházet pořád stejně — to je ta část, kterou nesmíš rozbít.

Protipříklad z předchozího kroku v souboru nech. Je to tvůj důkaz, že chyba byla
skutečná, a po opravě se z něj stane kontrola, že se nevrátila.

# --hints--

Prázdný košík vyjde na nulu.

```js
assert.equal(soucetPolozek([]), 0, 'soucetPolozek([]) má vrátit 0');
assert.equal(soucetPolozek(protipriklad1()), 0, 'soucetPolozek(protipriklad1()) už nemá padat, ale vrátit 0');
```

Běžný košík se počítá pořád stejně.

```js
assert.equal(soucetPolozek(UKAZKOVY_KOSIK), 1790, 'soucetPolozek(UKAZKOVY_KOSIK) má pořád vrátit 1790 (1290 + 2 × 250)');
assert.equal(soucetPolozek([{ nazev: 'Bidon', cena: 99, pocet: 3 }]), 297, 'soucetPolozek jedné položky po 99 Kč třikrát má vrátit 297');
```

# --help--

## --tip--

Metoda `reduce` umí dostat kromě funkce ještě jednu věc. Jak se chová bez ní, je v [Reduce bez počáteční hodnoty](see:js-pole/metody-pole-do-hloubky#reduce-bez-pocatecni-hodnoty).

## --tip--

Chybí druhý argument `reduce` — hodnota, se kterou má sčítání začít. Patří za uzavírací závorku funkce, ještě uvnitř volání `reduce`.

## --tip--

Na jiných datech: `hlasy.reduce((soucet, hlas) => soucet + hlas.body, 0)` spočítá nulu i pro hlasování, kam nikdo nepřišel.

# --explain--

Vysvětli vlastními slovy, proč tuhle chybu neodhalil ani model, který kód napsal, ani člověk, který ho na ukázkovém košíku vyzkoušel.

## --model--

Model psal kód podle zadání, a v zadání nikdo nenapsal, co se má stát s prázdným
košíkem — takže ten stav vůbec neexistoval. Kdo pak kód zkoušel, zkoušel ho na datech, která
měl po ruce, a ta byla vždycky neprázdná. Chyba se přitom neprojeví jako špatný výsledek, ale
jen v jediném okamžiku, který v ukázkových datech nenastane. Odhalí ji tedy až vstup, který si
schválně vymyslím jako nepříjemný, ne další průchod tou samou šťastnou cestou.

## --checklist--

- Zadání ten stav nevyjmenovalo, takže ho model neměl odkud vzít.
- Ukázková data prázdný košík neobsahovala.
- Chybu odhalí jen schválně nepříjemný vstup, ne opakování šťastné cesty.

// kosik.js — tenhle soubor napsal model ze zadání:
// "Modul pro košík e-shopu Cyklo Ráže: součet položek, slevový kód,
//  doprava zdarma od 1500 Kč, popis objednávky do e-mailu."
// Nikdo ho pak nečetl. Prošel, protože na ukázkovém košíku vrací správná čísla.

const SLEVOVE_KODY = [
  { kod: 'JARO10', typ: 'procenta', hodnota: 10 },
  { kod: 'VIP500', typ: 'castka', hodnota: 500 },
  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

--edit--
function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet);
}
--edit--

function cenaDopravy(soucet) {
  return soucet > DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + jmeno + ': ' + poznamka + '</p>';
}

function pouzijSlevu(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return soucet - zaznam.hodnota;
}

function celkovaCena(polozky, kod) {
  const poSleve = pouzijSlevu(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}

}
