# --description--

## Hlášení

„Nad košíkem nám naskočil nový banner se slevou. Na plném košíku ukazuje správně
*Ušetřili jste 10 %*, ale když si zákazník košík vysype do prázdna, stojí tam
**Ušetřili jste NaN %**. Screenshot posílám." — zpráva z podpory, dnes ráno.

Funkci `procentaSlevy` přidal do modulu model včera večer, když někdo doplňoval banner.
Do repozitáře se dostala bez review, protože „je to tři řádky".

## Úkol

Zopakuj si chybu, najdi místo, kde se výpočet rozchází s očekáváním, a oprav ho tak, aby
prázdný košík hlásil slevu `0 %`. Na plném košíku se nesmí změnit nic. Měň co nejmenší
kus kódu — zbytek modulu už je zrevidovaný a funguje.

Tímhle krokem je modul hotový. Prošel sis přitom celý postup, který na vygenerovaný kód
používáš i mimo Akademii: přečti, najdi podezřelé místo, dokaž chybu daty, oprav a nech
si po sobě kontrolu. A jak je vidět, ten postup se nespouští jednou — spouští se u každé
další funkce, kterou někdo do projektu přidá. V kvízu na konci sekce si vyzkoušíš, jestli
tyhle typy chyb poznáš i mimo tenhle košík.

## Udělej po svém

Testy dál nic nekontrolují, tyhle tři věci jsou na tobě:

- **Doprava podle hmotnosti.** Přidej položkám hmotnost a spočítej dopravu podle ní
  místo pevných 99 Kč. Nezapomeň na košík bez jediné položky.
- **Slevový kód s platností.** Dej kódům datum, do kdy platí, a nech prošlý kód chovat
  se jako neznámý. Než začneš, napiš si protipříklad: kód, který měl včera skončit.
- **Vlastní doména.** Přepiš modul na něco, co znáš — rozpis srážek z výplaty, objednávky
  v kavárně, poplatky v půjčovně. Stejné chyby, jiná data.

# --hints--

Prázdný košík hlásí nulovou slevu, ne `NaN`.

```js
assert.equal(procentaSlevy(0, 0), 0, 'procentaSlevy(0, 0) má vrátit 0, ne NaN');
```

Na plném košíku počítá `procentaSlevy` dál to, co počítala.

```js
assert.equal(procentaSlevy(1000, 900), 10, 'z 1000 Kč na 900 Kč je sleva 10 %');
assert.equal(procentaSlevy(1790, 1611), 10, 'z 1790 Kč na 1611 Kč je sleva 10 %');
assert.equal(procentaSlevy(2000, 1500), 25, 'z 2000 Kč na 1500 Kč je sleva 25 %');
```

Zbytek modulu zůstal beze změny.

```js
assert.equal(shrnutiKosiku(UKAZKOVY_KOSIK, 'JARO10').celkem, 1611, 'shrnutiKosiku má na ukázkovém košíku s JARO10 vyjít 1611');
assert.equal(radekFaktury({ nazev: 'Bidon 0,7 l', cena: 99, pocet: 3 }), '3× Bidon 0,7 l — 297 Kč', "radekFaktury má vrátit '3× Bidon 0,7 l — 297 Kč'");
```

# --help--

## --tip--

Dosaď si do výpočtu čísla z hlášení. Prázdný košík znamená `soucet` i `poSleve` rovné nule
— co v JavaScriptu vyjde z `0 / 0`?

## --tip--

Problém je dělení, ne zaokrouhlení. Ošetři ten jediný vstup, na kterém dělení nedává
smysl, dřív, než se k dělení vůbec dostaneš.

## --tip--

Stejný tvar má průměrná známka: `soucet / pocet` se počítá, až když víš, že je z čeho
počítat. Bez žáků není průměr nula ze vzorce, ale z rozhodnutí, které do kódu napíšeš ty.

// kosik.js — tenhle soubor napsal model ze zadání:
// "Modul pro košík e-shopu Cyklo Ráže: součet položek, slevový kód,
//  doprava zdarma od 1500 Kč, popis objednávky do e-mailu."
// Nikdo ho pak nečetl. Prošel, protože na ukázkovém košíku vrací správná čísla.

const SLEVOVE_KODY = [
  { kod: 'JARO10', typ: 'procenta', hodnota: 10 },
  { kod: 'VIP500', typ: 'castka', hodnota: 500 },
  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => {
    if (typeof polozka.cena !== 'number' || typeof polozka.pocet !== 'number') {
      throw new Error('Položka "' + polozka.nazev + '" nemá platnou cenu nebo počet.');
    }
    return soucet + polozka.cena * polozka.pocet;
  }, 0);
}

function cenaDopravy(soucet) {
  return soucet >= DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi !== -1) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return [...polozky].sort((a, b) => a.cena - b.cena);
}

function escapujHtml(text) {
  return String(text)
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;');
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + escapujHtml(jmeno) + ': ' + escapujHtml(poznamka) + '</p>';
}

function celkovaCena(polozky, kod) {
  const poSleve = cenaPoSleve(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}

function cenaPoSleve(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (!zaznam) {
    return soucet;
  }
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return Math.max(0, soucet - zaznam.hodnota);
}

function shrnutiKosiku(polozky, kod) {
  const soucet = soucetPolozek(polozky);
  const poSleve = cenaPoSleve(soucet, kod);
  const doprava = cenaDopravy(poSleve);
  return { soucet, sleva: soucet - poSleve, doprava, celkem: poSleve + doprava };
}

function radekFaktury(polozka) {
  return polozka.pocet + '× ' + polozka.nazev + ' — ' + polozka.cena * polozka.pocet + ' Kč';
}

// Přidáno na poslední chvíli: banner „Ušetřili jste X %" nad shrnutím košíku.
// Text zadání zněl „spočítej, kolik procent zákazník ušetřil". Kód přišel z modelu
// a do repozitáře se dostal bez review.
--edit--
function procentaSlevy(soucet, poSleve) {
  return Math.round(((soucet - poSleve) / soucet) * 100);
}
