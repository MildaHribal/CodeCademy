# --description--

## Hlášení

E-mail od vedoucí prodejny:

> Máme na webu i na letáku napsáno „doprava zdarma od 1500 Kč". Zákazník si dal do košíku
> zboží přesně za 1500 Kč a systém mu stejně naúčtoval 99 Kč za dopravu. Za 1501 Kč už
> to bylo v pořádku. Stěžoval si oprávněně, museli jsme mu poštovné vracet.

## Úkol

Oprav `cenaDopravy` tak, aby odpovídala ceníku, a změň co nejmíň. Objednávky pod hranicí
musí dopravu platit dál.

# --hints--

Na hranici i nad ní je doprava zdarma.

```js
assert.equal(cenaDopravy(1500), 0, 'cenaDopravy(1500) má vrátit 0 — doprava zdarma je od 1500 Kč');
assert.equal(cenaDopravy(protipriklad2()), 0, 'cenaDopravy(protipriklad2()) už má vrátit 0');
assert.equal(cenaDopravy(3200), 0, 'cenaDopravy(3200) má vrátit 0');
```

Pod hranicí se doprava účtuje dál.

```js
assert.equal(cenaDopravy(1499), 99, 'cenaDopravy(1499) má vrátit 99');
assert.equal(cenaDopravy(0), 99, 'cenaDopravy(0) má vrátit 99');
```

# --help--

## --tip--

Jde o hraniční hodnotu intervalu — viz [Checklist pro review](see:prace-s-ai/review-kodu-z-ai#2-checklist-pro-review), bod o okrajových případech.

## --tip--

Ve funkci `cenaDopravy` je jediné porovnání. Rozhodni, jestli má být ostré, nebo má zahrnovat i samotnou hranici.

## --tip--

Na jiných datech: „sleva pro nákup od 10 kusů" se zapisuje jako `kusy >= 10`, ne `kusy > 10`.

const SLEVOVE_KODY = [

  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },
];

const DOPRAVA_ZDARMA_OD = 1500;
const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },
  { nazev: 'Blikačka zadní', cena: 250, pocet: 2 },
];

function soucetPolozek(polozky) {
  return polozky.reduce((soucet, polozka) => soucet + polozka.cena * polozka.pocet, 0);
}

--edit--
function cenaDopravy(soucet) {
  return soucet > DOPRAVA_ZDARMA_OD ? 0 : CENA_DOPRAVY;
}
--edit--

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);
}

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return polozky.sort((a, b) => a.cena - b.cena);
}

function popisObjednavky(jmeno, poznamka) {
  return '<p>Objednávka pro ' + jmeno + ': ' + poznamka + '</p>';
}

function pouzijSlevu(soucet, kod) {
  const zaznam = najdiKod(kod);
  if (zaznam.typ === 'procenta') {
    return soucet - (soucet * zaznam.hodnota) / 100;
  }
  return soucet - zaznam.hodnota;
}

function celkovaCena(polozky, kod) {
  const poSleve = pouzijSlevu(soucetPolozek(polozky), kod);
  return poSleve + cenaDopravy(poSleve);
}
