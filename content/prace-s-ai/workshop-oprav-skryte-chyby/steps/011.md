# --description--

## Hlášení

Z marketingu:

> Rozeslali jsme na jaře leták s kódem JARO10. Zákazníci píšou, že jim ho formulář hlásí
> jako neplatný. Kódy VIP500 a DOPRAVA přitom projdou normálně. Zkoušeli jsme to
> i s velkými písmeny, chová se to pořád stejně.

## Úkol

Oprav `maKod` tak, aby jako platný uznala každý kód ze seznamu a neznámý kód odmítla.
Nejdřív si rozmysli, proč zlobí právě ten první kód v seznamu, a teprve pak měň kód —
až budeš vědět proč, je oprava na jedno slovo.

# --hints--

Všechny kódy ze seznamu projdou jako platné.

```js
assert.equal(maKod('JARO10'), true, "maKod('JARO10') má vrátit true — je to první kód v seznamu");
assert.equal(maKod('VIP500'), true, "maKod('VIP500') má vrátit true");
assert.equal(maKod('DOPRAVA'), true, "maKod('DOPRAVA') má vrátit true");
```

Neznámý kód se odmítne.

```js
assert.equal(maKod(protipriklad3()), false, 'maKod(protipriklad3()) má vrátit false');
assert.equal(maKod(''), false, "maKod('') má vrátit false");
```

# --help--

## --tip--

Jde o starou známou past s návratovou hodnotou hledání v poli — viz [indexOf v podmínce](see:js-pole/co-je-pole#indexof-v-podmince).

## --tip--

Podívej se, jakou hodnotu dostane proměnná `poradi` pro první kód v seznamu, a jak se tahle hodnota chová v podmínce `if`.

## --tip--

Na jiných datech: `if (jmena.indexOf(jmeno))` se u prvního jména v seznamu chová, jako by tam nebylo. Porovnání musí být proti hodnotě, kterou hledání vrací při neúspěchu.

  { kod: 'DOPRAVA', typ: 'doprava', hodnota: 0 },

const CENA_DOPRAVY = 99;

const UKAZKOVY_KOSIK = [
  { nazev: 'Helma Ráže Air', cena: 1290, pocet: 1 },

function cenaDopravy(soucet) {

function najdiKod(kod) {
  return SLEVOVE_KODY.find((zaznam) => zaznam.kod === kod);

function maKod(kod) {
  const poradi = SLEVOVE_KODY.findIndex((zaznam) => zaznam.kod === kod);
  if (poradi !== -1) {
    return true;
  }
  return false;
}

function seradPodleCeny(polozky) {
  return [...polozky].sort((a, b) => a.cena - b.cena);
}

    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
