---
title: Jemný rámeček s průhledností
---

# --description--

Bílá karta na světlém pozadí potřebuje hranu. Plná šedá čára by působila tvrdě, a proto se na moderních webech dělá rámeček z černé (tady břidlicové) barvy, která je skoro celá průhledná.

**Úkol:** do pravidla `.card` přidej `border: 1px solid rgb(15 23 42 / 0.08)`.

Dvě nové věci:

- **Zkratka `border`** nastaví najednou tloušťku, styl a barvu rámečku na všech čtyřech stranách. Styl (`solid`, `dashed`, `dotted`…) je povinný — bez něj má rámeček styl `none` a není vidět.
- **Funkce `rgb()`** zapisuje stejné tři složky jako hex, jen desítkově od 0 do 255: `rgb(15 23 42)` je totéž co `#0f172a`. Za lomítkem je **průhlednost** (*alpha*) od `0` (neviditelná) po `1` (plná). `0.08` znamená 8 % barvy a 92 % toho, co je pod ní.

Průhledná hrana má výhodu: na jakémkoli pozadí vypadá jako o kousek tmavší okraj téhož pozadí.

> [!NOTE]
> Starší zápis `rgba(15, 23, 42, 0.08)` s čárkami funguje dál a v cizím kódu ho uvidíš často. Nový zápis s mezerami a lomítkem je kratší a stejný tvar mají i `hsl()` a `oklch()`.

Příklad na jiných datech — pole formuláře s chybou:

```css
.field--error {
  border: 2px dashed rgb(220 38 38 / 0.6);
}
```

# --hints--

Karta má plný rámeček široký 1 px na všech stranách.

```js
const style = getComputedStyle(document.querySelector('.card'));
for (const side of ['Top', 'Right', 'Bottom', 'Left']) {
  assert.equal(style[`border${side}Style`], 'solid', `getComputedStyle(.card).border${side}Style má být solid`);
  assert.equal(style[`border${side}Width`], '1px', `getComputedStyle(.card).border${side}Width má být 1px`);
}
```

Barva rámečku je `rgb(15 23 42 / 0.08)`.

```js
assert.equal(getComputedStyle(document.querySelector('.card')).borderTopColor, 'rgba(15, 23, 42, 0.08)', 'getComputedStyle(.card).borderTopColor má být rgba(15, 23, 42, 0.08)');
```
