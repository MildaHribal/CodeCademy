# --description--

Kontakty jsou modré a podtržené, přestože karta má vlastní barvu textu. Proč, víš z lekce Jak CSS funguje. Tenhle krok je bez návodu.

**Úkol:** odkazy `.contact` mají barvu textu karty (`#1e293b`) a nejsou podtržené. Popisky „E-mail", „Telefon" a „LinkedIn" uvnitř odkazů se změní s nimi.

# --hints--

Odkazy v kontaktech mají barvu textu karty.

```js
document.querySelectorAll('.contact').forEach((link, i) => {
  assert.equal(getComputedStyle(link).color, 'rgb(30, 41, 59)', `getComputedStyle(${i + 1}. .contact).color má být rgb(30, 41, 59)`);
});
```

Odkazy v kontaktech nejsou podtržené.

```js
document.querySelectorAll('.contact').forEach((link, i) => {
  assert.equal(getComputedStyle(link).textDecorationLine, 'none', `getComputedStyle(${i + 1}. .contact).textDecorationLine má být none`);
});
```

# --help--

## --tip--

Modrou barvu a podtržení dávají odkazům [výchozí styly prohlížeče](see:css-zaklady/jak-css-funguje#vychozi-styly-prohlizece) přímo, a proto odkaz barvu karty nezdědí.

## --tip--

Obě deklarace patří do pravidla `.contact`. Barvu můžeš napsat hodnotou, nebo odkazu říct, ať barvu zdědí od rodiče.

## --tip--

Stejný problém řeší menu v hlavičce e-shopu: pravidlo `.menu a` mu nastaví barvu `inherit` a podtržení vypne hodnotou `none` ve vlastnosti pro dekoraci textu.
