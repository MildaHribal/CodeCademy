title: Stín s hloubkou

# --description--

Teď efekt, který udělá z plochého obdélníku kartu, jako by ležela nad stránkou: vrstvený stín.

**Úkol:** do pravidla `.card` přidej

`box-shadow: 0 1px 2px rgb(15 23 42 / 0.06), 0 16px 40px rgb(15 23 42 / 0.12)`

Jeden stín má čtyři části: posun vodorovně, posun svisle, rozmazání a barvu. `0 16px 40px` znamená „nikam do strany, 16 px dolů, rozmazat do 40 px". Stínů může být víc, oddělených čárkou:

1. malý ostrý stín těsně pod hranou (`0 1px 2px`) dá kartě kontaktní linku s podkladem,
2. velký rozmazaný stín níž (`0 16px 40px`) dá pocit výšky.

Oba jsou z průhledné tmavé barvy, takže se na pozadí jen jemně ztmaví. Čistě černý neprůhledný stín vypadá jako z roku 2005.

Příklad na jiných datech — vyskakovací nabídka, která leží výš než karta, a má proto delší a tmavší stín:

```css
.dropdown {
  box-shadow: 0 2px 4px rgb(0 0 0 / 0.08), 0 24px 48px rgb(0 0 0 / 0.2);
}
```

Po uložení si změnu prohlédni: přepni náhled na „Panel" nebo si zkus v kódu na chvíli zvětšit `40px` na `80px` a vrátit to zpátky.

# --hints--

Karta má dva stíny: `0 1px 2px rgb(15 23 42 / 0.06)` a `0 16px 40px rgb(15 23 42 / 0.12)`.

```js
const shadow = getComputedStyle(document.querySelector('.card')).boxShadow;
assert.equal(shadow, 'rgba(15, 23, 42, 0.06) 0px 1px 2px 0px, rgba(15, 23, 42, 0.12) 0px 16px 40px 0px', 'getComputedStyle(.card).boxShadow má obsahovat oba stíny v zadaném pořadí');
```
