# --description--

Avatary na sociálních sítích bývají kulaté. Čtverec s iniciálami je 96 × 96 px (`6rem`).

**Úkol:** udělej z avataru kruh.

Kruh je čtverec, jehož rohy mají poloměr zaoblení aspoň polovinu strany. Máš tři rozumné cesty:

- `border-radius` v pixelech nebo `rem` — spočítej si, kolik je polovina strany,
- `border-radius` v procentech — procenta se počítají z rozměrů samotného prvku,
- „nekonečné" zaoblení velkým číslem, jako má kolegův štítek o kus níž v `styles.css`.

Vyber tu, která zůstane kruhem, i kdyby designérka později avatar zvětšila na `8rem`. Testy přijmou každou, která dá kruh teď.

# --hints--

Avatar je kruh: poloměr zaoblení všech rohů je aspoň polovina strany.

```js
const avatar = document.querySelector('.card__avatar');
const style = getComputedStyle(avatar);
const half = avatar.getBoundingClientRect().width / 2;
for (const corner of ['borderTopLeftRadius', 'borderTopRightRadius', 'borderBottomRightRadius', 'borderBottomLeftRadius']) {
  const value = style[corner].split(' ')[0];
  const radius = value.endsWith('%') ? (parseFloat(value) / 100) * avatar.getBoundingClientRect().width : parseFloat(value);
  assert.ok(radius >= half - 0.5, `getComputedStyle(.card__avatar).${corner} je ${style[corner]} — na kruh je potřeba aspoň ${half} px`);
}
```

Avatar zůstává čtverec 96 × 96 px s přechodem na pozadí.

```js
const avatar = document.querySelector('.card__avatar');
const box = avatar.getBoundingClientRect();
assert.ok(Math.abs(box.width - 96) <= 0.5 && Math.abs(box.height - 96) <= 0.5, `Avatar má rozměry ${box.width} × ${box.height} px, čekám 96 × 96`);
assert.match(getComputedStyle(avatar).backgroundImage, /linear-gradient/, 'Avatar má dál mít přechod v background-image');
```

# --help--

## --tip--

Zaoblení rohů jsi nastavoval kartě ve [čtvrtém kroku](see:css-zaklady/workshop-vizitka/004). Kruh je jen hodně zaoblený čtverec.

## --tip--

Deklarace patří do pravidla `.card__avatar`. Procenta v `border-radius` se počítají ze šířky a výšky prvku, pixely platí pevně.

## --tip--

Kulatá fotka v komentáři velká 40 × 40 px by potřebovala poloměr aspoň 20 px — nebo stejné procento, jaké by fungovalo pro jakoukoli velikost.
