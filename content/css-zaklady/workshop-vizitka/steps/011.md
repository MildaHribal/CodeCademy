# --description--

Řádek „UX designérka · Brno" je stejně tmavý jako jméno, a tak s ním soupeří o pozornost. Doplňující text se na webu píše tlumenou barvou: čte se dobře, ale oko ho vezme až druhý.

**Úkol:** dej textu `.card__role` šedomodrou barvu `#64748b`.

Zapsat ji můžeš hex zápisem, přes `rgb()` (100, 116, 139) nebo přes `hsl()` (215°, 16 %, 47 %). Hex a `rgb()` dají přesně tutéž barvu, `hsl()` se zaokrouhlenými procenty se liší o jednotku v některé složce, což oko nepozná a test přijme. Vyber zápis, který se ti v kódu bude nejlíp číst — a drž se ho v celém souboru.

> [!TIP]
> Tlumený text nesmí být moc světlý. Tahle šedá má na bílé kontrast 4,76 : 1, což splňuje minimum 4,5 : 1 pro běžný text. Kontrast ti spočítá DevTools, až u barvy klikneš na čtvereček s ní.

# --hints--

Role má barvu `#64748b`.

```js
const color = getComputedStyle(document.querySelector('.card__role')).color;
const channels = color.match(/[\d.]+/g).slice(0, 3).map(Number);
const close = [100, 116, 139].every((value, i) => Math.abs(channels[i] - value) <= 2);
assert.ok(close, `getComputedStyle(.card__role).color je ${color}, čekám rgb(100, 116, 139), tedy #64748b`);
```

Jméno si ponechává tmavou barvu stránky.

```js
assert.equal(getComputedStyle(document.querySelector('.card__name')).color, 'rgb(30, 41, 59)', 'getComputedStyle(.card__name).color má zůstat rgb(30, 41, 59)');
```

# --help--

## --tip--

Barvu textu jsi nastavoval stránce ve [třetím kroku](see:css-zaklady/workshop-vizitka/003), tam je i vysvětlení hex zápisu.

## --tip--

Deklarace patří do pravidla `.card__role`, ne do `body` — jinak by zešedlo všechno.

## --tip--

Datum pod článkem by stejným způsobem dostalo vlastní barvu ve svém pravidle, třeba `.article__date` s odstínem `#6b7280`.
