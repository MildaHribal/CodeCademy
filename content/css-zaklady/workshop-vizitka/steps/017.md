# --description--

Karta vypadá hotově, ale nereaguje. Když uživatel najede myší na kontakt, nic se nestane. A kdo stránku ovládá klávesnicí (klávesou Tab), nevidí na světlých dlaždicích skoro žádný obrys, podle kterého by poznal, kde je.

Na obojí má CSS [[pseudotřída|pseudotřídy]] (*pseudo-classes*): část selektoru za dvojtečkou, která prvek vybere jen **v určitém stavu**.

- `:hover` — ukazatel myši je nad prvkem,
- `:focus-visible` — prvek má fokus a prohlížeč usoudil, že je potřeba ho ukázat (typicky při ovládání klávesnicí, ne po kliknutí myší).

Stav se píše hned za selektor bez mezery: `.contact:hover`. Pravidlo se stavem obsahuje jen to, co se **změní**; zbytek si prvek nese ze základního pravidla. Víc pseudotříd je v lekci [Selektory](see:css-zaklady/selektory-zaklad#pseudotridy-stav-prvku).

Obrys pro klávesnici se dělá vlastností `outline`: kreslí se kolem prvku, nezabírá místo a nic neodsune. `outline-offset` ho odsadí od hrany.

**Úkol:** seřaď řádky do dvou pravidel. Při najetí myší dostane kontakt tmavší pozadí `hsl(245 100% 93%)` a fialový text, při ovládání klávesnicí fialový obrys 3 px. Doplň odsazení obrysu **2 px** (v `px` nebo `rem`). Pořadí měníš šipkami, odsazení klávesou Tab. Dva řádky jsou navíc.

> [!PITFALL]
> `outline: none` bez náhrady je jedna z nejčastějších chyb přístupnosti. Obrys vypadá „ošklivě", a tak ho někdo smaže — a člověk s klávesnicí přestane vidět, kde na stránce je.

# --hints--

Pro odkaz `.contact` existuje pravidlo se stavem `:hover`, které změní barvu pozadí na `hsl(245 100% 93%)`.

```js
const link = document.querySelector('.contact');
const found = [];
const walk = (rules) => {
  for (const rule of rules) {
    if (rule.selectorText) {
      for (const part of rule.selectorText.split(',')) {
        if (!part.includes(':hover')) continue;
        try {
          if (link.matches(part.replace(/:hover/g, '').trim() || '*')) found.push(rule);
        } catch {}
      }
    }
    if (rule.cssRules) walk(rule.cssRules);
  }
};
for (const sheet of document.styleSheets) walk(sheet.cssRules);
assert.ok(found.length > 0, 'Chybí pravidlo se stavem :hover, které vybere .contact');
const probe = document.createElement('div');
document.body.append(probe);
probe.style.backgroundColor = found.at(-1).style.backgroundColor;
const color = getComputedStyle(probe).backgroundColor;
probe.remove();
assert.equal(color, 'rgb(222, 219, 255)', 'Pozadí v pravidle .contact:hover má být hsl(245 100% 93%)');
```

Při ovládání klávesnicí má kontakt obrys široký 3 px, odsazený o 2 px.

```js
const link = document.querySelector('.contact');
link.focus({ focusVisible: true });
const style = getComputedStyle(link);
assert.equal(style.outlineStyle, 'solid', 'Při :focus-visible má mít .contact plný obrys (outline-style: solid)');
assert.equal(style.outlineWidth, '3px', 'Při :focus-visible má mít .contact obrys široký 3px');
assert.equal(style.outlineOffset, '2px', 'Při :focus-visible má mít .contact obrys odsazený o 2px');
```

Bez fokusu a bez najetí myší vypadá kontakt jako dřív: světlé pozadí a žádný obrys.

```js
const style = getComputedStyle(document.querySelector('.contact'));
assert.equal(style.backgroundColor, 'rgb(241, 240, 255)', 'getComputedStyle(.contact).backgroundColor má bez najetí zůstat rgb(241, 240, 255)');
assert.equal(style.outlineStyle, 'none', 'Bez fokusu nemá mít .contact obrys');
```

# --parsons--

```css
.contact:hover {
  background-color: hsl(245 100% 93%);
  color: hsl(262 83% 45%);
}
.contact:focus-visible {
  outline: 3px solid hsl(262 83% 58%);
  outline-offset: __1__;
}
```
