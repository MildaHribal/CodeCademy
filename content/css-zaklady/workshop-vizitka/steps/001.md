# --description--

Digitální vizitku znáš z profilů na LinkedInu, z odkazů v podpisu e-mailu nebo ze stránek typu „link in bio": jedna karta se jménem, fotkou nebo iniciálami, pár kontaktů a výrazné tlačítko. V tomhle workshopu ji postavíš pro UX designérku Kláru.

HTML je hotové a v `styles.css` je hotové i rozvržení: kde co leží a jak je to velké. Ty napíšeš vzhled — barvy, písmo, rámečky, stín a stavy odkazů při najetí myší a při ovládání klávesnicí.

První krok je bez návodu, zvládneš ho z lekce [Jak CSS funguje](see:css-zaklady/jak-css-funguje#kam-css-napsat-link-style-a-atribut-style).

**Úkol:** stránka zatím soubor `styles.css` vůbec nepoužívá. Připoj ho v `index.html` tak, jak se to dělá na skutečném webu. Až se to povede, karta se v náhledu přesune doprostřed stránky.

# --hints--

Stránka používá styly ze souboru `styles.css`: `body` nemá výchozí okraj a obsah je vycentrovaný.

```js
const body = getComputedStyle(document.body);
assert.equal(body.marginTop, '0px', 'getComputedStyle(body).marginTop má být 0px — načetl se styles.css?');
assert.equal(body.display, 'grid', 'getComputedStyle(body).display má být grid (pravidlo ze styles.css)');
```

Styly jsou připojené prvkem `<link>` v hlavičce dokumentu, ne vložené do stránky.

```js
const html = helpers.stripComments(files['index.html'], 'html');
const head = html.split(/<body/i)[0];
assert.match(head, /<link\b[^>]*rel=["']?stylesheet/i, 'V <head> chybí <link rel="stylesheet" …>');
assert.match(head, /<link\b[^>]*href=["']?(\.\/)?styles\.css/i, 'Prvek <link> v <head> má odkazovat na styles.css');
assert.doesNotMatch(html, /<style[\s>]/i, 'Styly nepiš do bloku <style>, připoj soubor styles.css');
```

## --file-- styles.css

```css
/* Rozvržení (rozměry, odsazení, centrování) je hotové.
   Dostaneš se k němu v sekcích o box modelu a flexboxu.
   Ty píšeš vzhled: barvy, písmo, rámečky a stavy. */

*,
*::before,
*::after {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  display: grid;
  place-items: center;
  padding: 1.5rem;
}

.card {
  width: 100%;
  max-width: 24rem;
  padding: 2rem;
}

.card__avatar {
  display: grid;
  place-items: center;
  width: 6rem;
  height: 6rem;
  margin: 0 auto 1rem;
  color: white;
  font-size: 2rem;
  font-weight: 700;
}

.card__name {
  margin: 0;
  line-height: 1.2;
}

.card__role {
  margin: 0.25rem 0 1rem;
}

/* Štítek dostupnosti — napsal kolega */
.status {
  display: inline-block;
  margin: 0 0 1rem;
  padding: 0.25rem 0.75rem;
  border-radius: 999px;
  font-size: 0.875rem;
  font-weight: 600;
}

.status--avaliable {
  background-color: #dcfce7;
  color: #166534;
}

.card__bio {
  margin: 0 0 1.5rem;
}

.contacts {
  display: grid;
  gap: 0.5rem;
  margin: 0 0 1.5rem;
  padding: 0;
  list-style: none;
}

.contact {
  display: block;
  padding: 0.625rem 0.875rem;
  /* Plynulá změna barev při najetí myší. Vlastnost transition se naučíš v sekci o přechodech a animacích. */
  transition: background-color 150ms ease, color 150ms ease;
}

.contact__label {
  display: block;
}

.card__button {
  display: block;
  padding: 0.75rem 1rem;
  transition: background-color 150ms ease, box-shadow 150ms ease;
}
```
