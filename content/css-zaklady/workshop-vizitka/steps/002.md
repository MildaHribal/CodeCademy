# --description--

Stránka je vysázená písmem Times New Roman. To je výchozí písmo prohlížeče a na moderním webu působí jako rozbitá stránka.

**Úkol:** do pravidla `body` přidej deklaraci

`font-family: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`

Vlastnost `font-family` nebere jedno písmo, ale **seznam** oddělený čárkami. Prohlížeč jde zleva a použije první písmo, které v počítači najde:

- `system-ui` je písmo operačního systému — ve Windows Segoe UI, v macOS San Francisco, v Linuxu třeba Cantarell nebo Ubuntu. Stránka tak vypadá jako aplikace, kterou uživatel zná, a nic se nestahuje.
- `-apple-system`, `"Segoe UI"`, `Roboto`… jsou pojistka pro starší systémy. Jména s mezerou patří do uvozovek.
- `sans-serif` na konci je **obecná rodina** (*generic family*): „jakékoli bezpatkové písmo". Když nesedí nic z předchozího, prohlížeč aspoň nesáhne po patkovém Times.

`font-family` stačí nastavit na `body`. Písmo se **dědí**: nadpis, odstavce i odkazy uvnitř ho převezmou, dokud jim ho něco nepřepíše.

Příklad na jiných datech — citát v článku vysázený patkovým písmem:

```css
.quote {
  font-family: Georgia, "Times New Roman", serif;
}
```

> [!NOTE]
> Tlačítka a formulářová pole písmo nedědí, mají vlastní z výchozích stylů prohlížeče. Na vizitce je „tlačítko" odkaz `<a>`, takže to tady řešit nemusíš.

# --hints--

Seznam písem v `body` začíná `system-ui`.

```js
const families = getComputedStyle(document.body).fontFamily.split(',').map((name) => name.trim().replace(/["']/g, ''));
assert.equal(families[0], 'system-ui', `První písmo v seznamu je ${families[0]}, čekám system-ui`);
```

Seznam písem končí obecnou rodinou `sans-serif`.

```js
const families = getComputedStyle(document.body).fontFamily.split(',').map((name) => name.trim().replace(/["']/g, ''));
assert.equal(families.at(-1), 'sans-serif', `Poslední písmo v seznamu je ${families.at(-1)}, čekám sans-serif`);
```

Nadpis se jménem písmo zdědil a nemá vlastní.

```js
const body = getComputedStyle(document.body).fontFamily;
const name = getComputedStyle(document.querySelector('.card__name')).fontFamily;
assert.equal(name, body, 'getComputedStyle(.card__name).fontFamily má být stejné jako u body');
```

# --explain--

Vysvětli vlastními slovy, proč se do `font-family` píše seznam písem zakončený obecnou rodinou jako `sans-serif`, a ne jedno konkrétní písmo.

## --model--

Prohlížeč může použít jen písmo, které je v počítači uživatele (nebo které stránka stáhne). Každý systém má jiná písma, a tak píšu seznam: prohlížeč vezme první, které najde. Obecná rodina na konci je poslední pojistka — když nesedí žádné jméno, použije aspoň nějaké bezpatkové písmo místo výchozího patkového.

## --checklist--

- Prohlížeč použije jen písmo, které má k dispozici.
- Ze seznamu vezme první písmo, které najde.
- Obecná rodina na konci je záchrana, když nesedí žádné jméno.
- `system-ui` znamená písmo operačního systému, nic se nestahuje.
