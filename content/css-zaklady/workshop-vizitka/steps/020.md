# --description--

Zkus v náhledu kliknout do stránky a mačkat Tab: fokus projde kontakty s fialovým obrysem a skončí na tlačítku, kde je vidět jen tenký výchozí obrys prohlížeče, na fialové ploše skoro neviditelný.

**Úkol:** když uživatel přejde na tlačítko klávesnicí, má mít výrazný plný obrys široký aspoň 2 px a odsazený od hrany tlačítka aspoň o 2 px, aby nesplýval s pozadím. Po kliknutí myší se obrys ukazovat nemusí.

# --hints--

Při ovládání klávesnicí má tlačítko plný obrys široký aspoň 2 px.

```js
const button = document.querySelector('.card__button');
button.focus({ focusVisible: true });
const style = getComputedStyle(button);
assert.equal(style.outlineStyle, 'solid', `Tlačítko s fokusem z klávesnice má obrys ve stylu ${style.outlineStyle}, čekám solid`);
assert.ok(parseFloat(style.outlineWidth) >= 2, `Obrys tlačítka je široký ${style.outlineWidth}, čekám aspoň 2px`);
```

Obrys je od hrany tlačítka odsazený aspoň o 2 px.

```js
const button = document.querySelector('.card__button');
button.focus({ focusVisible: true });
const offset = parseFloat(getComputedStyle(button).outlineOffset);
assert.ok(offset >= 2, `outline-offset tlačítka s fokusem je ${offset}px, čekám aspoň 2px`);
```

Obrys patří jen ke stavu fokusu: bez fokusu tlačítko obrys nemá.

```js
assert.equal(getComputedStyle(document.querySelector('.card__button')).outlineStyle, 'none', 'Bez fokusu nemá mít tlačítko obrys — patří do pravidla se stavem');
```

# --help--

## --tip--

Viditelný fokus z klávesnice jsi skládal pro kontakty v [sedmnáctém kroku](see:css-zaklady/workshop-vizitka/017). Proč `:focus-visible`, a ne `:focus`, vysvětluje lekce [Selektory](see:css-zaklady/selektory-zaklad#pseudotridy-stav-prvku).

## --tip--

Pravidlo patří tlačítku se stavem fokusu viditelného z klávesnice a obsahuje obrys a jeho odsazení.

# --explain--

Vysvětli vlastními slovy, proč obrys pro klávesnici nepíšeš do stavu `:focus`, ale do `:focus-visible`, a proč ho nikdy jen nesmažeš.

## --model--

Lidé, kteří ovládají stránku klávesnicí, podle obrysu poznají, na kterém prvku jsou. Kdyby obrys zmizel, nevědí, co zmáčkne Enter. `:focus` platí i po kliknutí myší, kde obrys mnoho lidí ruší, a proto se ho pak někdo pokusí smazat. `:focus-visible` platí jen tehdy, když prohlížeč usoudí, že je obrys potřeba, typicky při ovládání klávesnicí — takže obrys může být výrazný a myši nepřekáží.

## --checklist--

- Obrys ukazuje uživateli klávesnice, kde na stránce je.
- Smazaný obrys bez náhrady je chyba přístupnosti.
- `:focus` platí i po kliknutí myší.
- `:focus-visible` platí, když je fokus potřeba ukázat, typicky z klávesnice.
