# --description--

Poslední prvek karty je odkaz „Napiš mi". Má být hlavní akcí vizitky, takže musí vypadat jako tlačítko, ne jako odkaz. Všechno potřebné už znáš.

**Úkol:** tlačítko `.card__button` má

- fialové pozadí `hsl(262 83% 58%)` — stejné jako avatar,
- bílý text bez podtržení,
- tloušťku písma 600,
- plně zaoblené konce jako pilulka.

# --hints--

Tlačítko má fialové pozadí `hsl(262 83% 58%)` a bílý text.

```js
const style = getComputedStyle(document.querySelector('.card__button'));
// Tolerance jako u avataru: hex zápis téhož odstínu se může lišit o jednotku.
const channels = style.backgroundColor.match(/[\d.]+/g).slice(0, 3).map(Number);
const close = [124, 59, 237].every((value, i) => Math.abs(channels[i] - value) <= 2);
assert.ok(close, `getComputedStyle(.card__button).backgroundColor je ${style.backgroundColor}, čekám rgb(124, 59, 237), tedy hsl(262 83% 58%)`);
assert.equal(style.color, 'rgb(255, 255, 255)', 'getComputedStyle(.card__button).color má být rgb(255, 255, 255)');
```

Text tlačítka není podtržený a má tloušťku písma 600.

```js
const style = getComputedStyle(document.querySelector('.card__button'));
assert.equal(style.textDecorationLine, 'none', 'getComputedStyle(.card__button).textDecorationLine má být none');
assert.equal(style.fontWeight, '600', 'getComputedStyle(.card__button).fontWeight má být 600');
```

Tlačítko má konce plně zaoblené: poloměr rohů je aspoň polovina jeho výšky.

```js
const button = document.querySelector('.card__button');
const half = button.getBoundingClientRect().height / 2;
const value = getComputedStyle(button).borderTopLeftRadius;
const radius = value.endsWith('%') ? null : parseFloat(value);
assert.ok(radius !== null && radius >= half - 0.5, `getComputedStyle(.card__button).borderTopLeftRadius je ${value} — na pilulku je potřeba aspoň ${half.toFixed(1)} px (procenta z šířky by udělala elipsu)`);
```

# --help--

## --tip--

Pozadí, barvu a zaoblení jsi dal kontaktům v [patnáctém kroku](see:css-zaklady/workshop-vizitka/015), podtržení jsi rušil ve [čtrnáctém](see:css-zaklady/workshop-vizitka/014).

## --tip--

Všechno patří do pravidla `.card__button`. Na pilulku se hodí „nekonečný" poloměr v pixelech, jaký má kolegův štítek — procenta by u širokého tlačítka udělala elipsu.

## --tip--

Tlačítko „Do košíku" v e-shopu by mělo ve svém pravidle pozadí, barvu textu, vypnuté podtržení, tloušťku písma a zaoblení — pět deklarací, každá na jednu věc ze zadání.
