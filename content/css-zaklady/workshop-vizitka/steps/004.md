---
title: Bílá karta se zaoblenými rohy
---

# --description--

Karta zatím splývá s pozadím stránky. Dej jí vlastní plochu a zaobli jí rohy.

**Úkol:** do pravidla `.card` přidej `background-color: white` a `border-radius: 1.5rem`.

Barvu jde místo hex zápisu napsat i **jménem**: `white`, `black`, `crimson`, `transparent`… Jmen je přes sto, ale na skutečném webu je uvidíš hlavně u `white`, `black` a `transparent`. Přesné odstíny z návrhu se píšou čísly.

`border-radius` zaoblí rohy prvku. Hodnota je poloměr zaoblení. Jednotka `rem` znamená násobek velikosti písma kořene stránky, a ta je ve výchozím stavu 16 px — `1.5rem` jsou tedy 24 px. Proč se na webu píše `rem` místo `px`, rozebere lekce [Jednotky a hodnoty](see:css-zaklady/jednotky-a-hodnoty#rem-nasobek-korene-stranky). Teď stačí přepočet `1rem = 16 px`.

Příklad na jiných datech — fotka v příspěvku s jemně zaoblenými rohy:

```css
.post__photo {
  background-color: black;
  border-radius: 0.5rem;
}
```

# --hints--

Karta má bílé pozadí.

```js
assert.equal(getComputedStyle(document.querySelector('.card')).backgroundColor, 'rgb(255, 255, 255)', 'getComputedStyle(.card).backgroundColor má být rgb(255, 255, 255)');
```

Rohy karty jsou zaoblené s poloměrem 24 px (`1.5rem`).

```js
const style = getComputedStyle(document.querySelector('.card'));
for (const corner of ['borderTopLeftRadius', 'borderTopRightRadius', 'borderBottomRightRadius', 'borderBottomLeftRadius']) {
  assert.equal(style[corner], '24px', `getComputedStyle(.card).${corner} má být 24px`);
}
```
