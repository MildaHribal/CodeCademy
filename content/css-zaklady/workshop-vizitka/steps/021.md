# --description--

## Hlášení

Kolega chtěl, aby stránka kolem karty nebyla jednobarevná, a do pravidla `body` přidal jemný přechod od světle modré k světle růžové. Pozadí stránky ale zůstalo stejné jako předtím, jednobarevné `#eef2ff`. Kolega píše: „Barvy v přechodu jsou správně, zkontroloval jsem je dvakrát. Asi to prohlížeč nepodporuje."

## Úkol

Najdi, proč se přechod na pozadí stránky nezobrazí, a oprav to tak, aby jednobarevné `#eef2ff` zůstalo pod přechodem jako záloha. Změň co nejmenší kus kódu.

# --hints--

Stránka má jako obrázek pozadí barevný přechod.

```js
const image = getComputedStyle(document.body).backgroundImage;
assert.match(image, /gradient\(/, `getComputedStyle(body).backgroundImage je ${image} — čekám přechod (…-gradient)`);
```

Pod přechodem zůstává barva pozadí `#eef2ff`.

```js
assert.equal(getComputedStyle(document.body).backgroundColor, 'rgb(238, 242, 255)', 'getComputedStyle(body).backgroundColor má zůstat rgb(238, 242, 255)');
```

Karta zůstává bílá se stínem a text stránky tmavý.

```js
const card = getComputedStyle(document.querySelector('.card'));
assert.equal(card.backgroundColor, 'rgb(255, 255, 255)', 'getComputedStyle(.card).backgroundColor má zůstat bílá');
assert.notEqual(card.boxShadow, 'none', 'Karta má dál mít stín');
assert.equal(getComputedStyle(document.body).color, 'rgb(30, 41, 59)', 'getComputedStyle(body).color má zůstat rgb(30, 41, 59)');
```

# --help--

## --tip--

Přechod podporují všechny dnešní prohlížeče. Podívej se, **do které vlastnosti** ho kolega napsal, a porovnej to s [osmým krokem](see:css-zaklady/workshop-vizitka/008). Co prohlížeč udělá s hodnotou, které u dané vlastnosti nerozumí, připomene [Neplatná deklarace se tiše zahodí](see:css-zaklady/jak-css-funguje#neplatna-deklarace-se-tise-zahodi).

## --tip--

Barva pozadí bere jen barvu. Přechod je obrázek, který prohlížeč kreslí sám, a má vlastní vlastnost pro obrázek pozadí.
