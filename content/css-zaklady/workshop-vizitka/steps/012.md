# --description--

Avatar je uprostřed (to zařizuje hotové rozvržení), ale jméno, role a popis začínají vlevo. Vizitka působí vyváženěji, když je text pod avatarem na střed.

**Úkol:** vycentruj vodorovně všechen text v kartě.

Kandidáti:

- `text-align` na celé kartě `.card`,
- `text-align` zvlášť na jménu, roli, popisu, kontaktech a tlačítku,
- automatický `margin`, který má avatar.

Jeden kandidát text nevycentruje vůbec, jeden funguje, ale znamená pět pravidel místo jednoho. Než napíšeš první řádek, rozmysli si, který je který.

Vlastnost `text-align` zarovnává **řádky textu uvnitř** prvku a dědí se, stejně jako `color`.

# --hints--

Jméno, role a tlačítko mají text vodorovně uprostřed karty.

```js
const card = document.querySelector('.card').getBoundingClientRect();
const cardMiddle = card.left + card.width / 2;
for (const selector of ['.card__name', '.card__role', '.card__button']) {
  const range = document.createRange();
  range.selectNodeContents(document.querySelector(selector));
  const text = range.getBoundingClientRect();
  const middle = text.left + text.width / 2;
  assert.ok(Math.abs(middle - cardMiddle) <= 2, `Střed textu ${selector} je na ${Math.round(middle)} px, střed karty na ${Math.round(cardMiddle)} px`);
}
```

Každý řádek popisu je vycentrovaný.

```js
const card = document.querySelector('.card').getBoundingClientRect();
const cardMiddle = card.left + card.width / 2;
const range = document.createRange();
range.selectNodeContents(document.querySelector('.card__bio'));
const rows = [...range.getClientRects()];
const lines = new Map();
for (const rect of rows) {
  const key = Math.round(rect.top);
  const line = lines.get(key) ?? { left: Infinity, right: -Infinity };
  lines.set(key, { left: Math.min(line.left, rect.left), right: Math.max(line.right, rect.right) });
}
for (const line of lines.values()) {
  const middle = (line.left + line.right) / 2;
  assert.ok(Math.abs(middle - cardMiddle) <= 3, `Řádek popisu má střed na ${Math.round(middle)} px, karta na ${Math.round(cardMiddle)} px`);
}
```

# --help--

## --tip--

Zarovnání textu v řádku řídí `text-align` a dědí se na potomky, stejně jako barva textu a písmo. Popis najdeš v MDN pod [text-align](https://developer.mozilla.org/en-US/docs/Web/CSS/text-align).

## --tip--

Když vlastnost dědí všichni potomci, stačí ji dát společnému rodiči. Rodičem jména, role, popisu, kontaktů i tlačítka je `.card`.

## --tip--

Patička webu, kde má být copyright i odkazy uprostřed, dostane zarovnání jen jednou ve svém pravidle `.site-footer`, ne každý odstavec zvlášť.
