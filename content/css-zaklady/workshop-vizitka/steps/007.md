# --description--

V horní části karty jsou iniciály „KS", jenže bílé na bílém nejsou vidět. Avatar potřebuje barevnou plochu.

**Úkol:** do pravidla `.card__avatar` přidej `background-color: hsl(262 83% 58%)`.

Hex i `rgb()` popisují barvu složkami světla, a z `#7c3aed` nikdo nepozná, že je to fialová. Funkce `hsl()` popisuje barvu tak, jak o ní mluví lidé:

- **odstín** (*hue*) jako úhel na barevném kole: `0` červená, `120` zelená, `240` modrá, `262` fialová,
- **sytost** (*saturation*) v procentech: `0%` šedá, `100%` nejsytější,
- **světlost** (*lightness*) v procentech: `0%` černá, `50%` čistá barva, `100%` bílá.

Tmavší odstín té samé barvy pro najetí myší pak uděláš změnou jednoho čísla: `hsl(262 83% 48%)`.

> [!NOTE]
> Moderní CSS má i `oklch()`, která je postavená podle toho, jak oko vnímá jas: dvě barvy se stejnou světlostí v `oklch()` vypadají opravdu stejně světlé, v `hsl()` ne (žlutá při 50 % září, modrá je tmavá). Víc o ní v sekci o designu. Pro tuhle vizitku stačí `hsl()`.

Příklad na jiných datech — zelený odznak „Skladem" a jeho světlá varianta:

```css
.stock {
  background-color: hsl(142 71% 45%);
}

.stock--light {
  background-color: hsl(142 71% 92%);
}
```

# --hints--

Avatar má pozadí `hsl(262 83% 58%)`.

```js
// Hex a hsl se stejným odstínem se můžou lišit o jednotku v některé složce, proto tolerance.
const color = getComputedStyle(document.querySelector('.card__avatar')).backgroundColor;
const channels = color.match(/[\d.]+/g).slice(0, 3).map(Number);
const close = [124, 59, 237].every((value, i) => Math.abs(channels[i] - value) <= 2);
assert.ok(close, `getComputedStyle(.card__avatar).backgroundColor je ${color}, čekám rgb(124, 59, 237), tedy hsl(262 83% 58%)`);
```
