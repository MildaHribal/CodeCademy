# --description--

Tlačítko zatím na myš nereaguje. Uživatel by měl po najetí poznat, že na něj jde kliknout.

**Úkol:** zařiď, aby se tlačítko „Napiš mi" při najetí myší viditelně změnilo. Jak přesně, je na tobě: tmavší nebo světlejší pozadí, stín, jiná barva textu… Testy přijmou jakoukoli změnu vzhledu, bez najetí ale musí tlačítko zůstat takové, jaké je teď.

Hotové pravidlo `.card__button` má v seedu `transition` pro barvu pozadí a stín, takže tyhle dvě změny proběhnou plynule.

# --hints--

Pro tlačítko `.card__button` existuje pravidlo se stavem `:hover`, které změní aspoň jednu vlastnost vzhledu.

```js
const button = document.querySelector('.card__button');
const found = [];
const walk = (rules, parent = '') => {
  for (const rule of rules) {
    let selector = rule.selectorText ?? '';
    if (selector && parent) selector = selector.includes('&') ? selector.replace(/&/g, parent) : `${parent} ${selector}`;
    if (selector) {
      for (const part of selector.split(',')) {
        if (!part.includes(':hover')) continue;
        try {
          if (button.matches(part.replace(/:hover/g, '').trim() || '*')) found.push(rule);
        } catch {}
      }
    }
    if (rule.cssRules) walk(rule.cssRules, selector || parent);
  }
};
for (const sheet of document.styleSheets) walk(sheet.cssRules);
assert.ok(found.length > 0, 'Chybí pravidlo se stavem :hover, které vybere tlačítko .card__button');
const base = getComputedStyle(button);
const changes = [];
for (const rule of found) {
  for (const property of rule.style) {
    const probe = document.createElement('a');
    probe.className = 'card__button';
    probe.style.visibility = 'hidden';
    button.parentElement.append(probe);
    probe.style.setProperty(property, rule.style.getPropertyValue(property));
    if (getComputedStyle(probe).getPropertyValue(property) !== base.getPropertyValue(property)) changes.push(property);
    probe.remove();
  }
}
assert.ok(changes.length > 0, 'Pravidlo s :hover pro .card__button nemění nic, co by bylo vidět — všechny jeho hodnoty jsou stejné jako bez najetí');
```

Bez najetí myší má tlačítko dál fialové pozadí a bílý text.

```js
const style = getComputedStyle(document.querySelector('.card__button'));
assert.equal(style.backgroundColor, 'rgb(124, 59, 237)', 'getComputedStyle(.card__button).backgroundColor má bez najetí zůstat rgb(124, 59, 237)');
assert.equal(style.color, 'rgb(255, 255, 255)', 'getComputedStyle(.card__button).color má bez najetí zůstat bílá');
```

# --help--

## --tip--

Stav „ukazatel myši je nad prvkem" vybírá pseudotřída, kterou jsi použil u kontaktů v [sedmnáctém kroku](see:css-zaklady/workshop-vizitka/017).

## --tip--

Nové pravidlo má selektor tlačítka se stavem a obsahuje jen vlastnost, která se změní. Tmavší odstín fialové dostaneš snížením světlosti v `hsl()`.

## --tip--

Tvůj vzor jsou řádky, které jsi v sedmnáctém kroku skládal pro `.contact` — stejný tvar, jiný selektor a jiná změna.
