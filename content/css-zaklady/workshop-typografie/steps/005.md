# --description--

Článek potřebuje několik velikostí písma: malé popisky, běžný text, perex, mezititulky a titulek. Kdyby každé pravidlo mělo vlastní číslo, za měsíc je jich na webu patnáct a žádné spolu neladí. Proto se velikosti drží **stupnice** — pár pojmenovaných kroků, ze kterých se vybírá.

Stupnici zapíšeš jako tokeny na `:root`, stejně jako barvy a rozestupy nahoře v `styles.css`:

| token | velikost | pro co |
|---|---|---|
| `--font-size-sm` | 14 px | popisky, datum |
| `--font-size-base` | 18 px | text článku |
| `--font-size-lg` | 22 px | perex, citace |
| `--font-size-xl` | 28 px | mezititulky |
| `--font-size-2xl` | 40 px | titulek |

**Úkol:** seřaď řádky do druhého bloku `:root` pod tokeny rozestupů a doplň hodnotu tokenu pro mezititulky v `rem`. Pořadí měníš šipkami, odsazení klávesou Tab. Dva řádky jsou navíc.

Po tomhle kroku se v náhledu nic nezmění — tokeny zatím nikdo nečte. V dalším kroku je použiješ.

> [!PITFALL]
> Token musí obsahovat celou hodnotu i s jednotkou. `--font-size-base: 18` a pak `var(--font-size-base)px` je neplatné, jak ukazuje lekce [Vlastní vlastnosti](see:css-zaklady/vlastni-vlastnosti#typicke-chyby-a-pasti).

# --hints--

Na `:root` jsou definované tokeny `--font-size-sm`, `--font-size-base`, `--font-size-lg`, `--font-size-xl` a `--font-size-2xl`.

```js
const root = getComputedStyle(document.documentElement);
for (const name of ['--font-size-sm', '--font-size-base', '--font-size-lg', '--font-size-xl', '--font-size-2xl']) {
  assert.notEqual(root.getPropertyValue(name).trim(), '', `Token ${name} není na :root definovaný`);
}
```

Tokeny dávají velikosti 14, 18, 22, 28 a 40 px.

```js
const expected = { '--font-size-sm': '14px', '--font-size-base': '18px', '--font-size-lg': '22px', '--font-size-xl': '28px', '--font-size-2xl': '40px' };
for (const [name, size] of Object.entries(expected)) {
  // Obal s písmem 7 px: neplatný token by jinak tiše zdědil velikost stránky.
  const wrapper = document.createElement('div');
  wrapper.style.fontSize = '7px';
  const probe = document.createElement('span');
  probe.style.fontSize = `var(${name})`;
  wrapper.append(probe);
  document.body.append(wrapper);
  const actual = getComputedStyle(probe).fontSize;
  wrapper.remove();
  assert.equal(actual, size, `Prvek s font-size: var(${name}) má ${actual}, čekám ${size}`);
}
```

# --parsons--

```css
:root {
  --font-size-sm: 0.875rem;
  --font-size-base: 1.125rem;
  --font-size-lg: 1.375rem;
  --font-size-xl: __1__;
  --font-size-2xl: 2.5rem;
}
```

```css
--font-size-base: 18;
font-size-lg: 1.375rem;
```
