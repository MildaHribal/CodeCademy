# --description--

Odkazy v textu na myš nereagují. Na redakčních webech se při najetí podtržení zesílí nebo změní barvu — jemný, ale jasný signál, že na text jde kliknout.

**Úkol:** když uživatel najede myší na odkaz v článku, podtržení viditelně zesílí. Bez najetí zůstane tenké.

Hotové pravidlo `.article a` má tloušťku podtržení 1 px a `transition`, takže změna tloušťky proběhne plynule. `transition` se naučíš v sekci o přechodech a animacích.

# --hints--

Pro odkazy v článku existuje pravidlo se stavem `:hover`, které podtržení zesílí.

```js
const link = document.querySelector('.article a');
const found = [];
const walk = (rules, parent = '') => {
  for (const rule of rules) {
    let selector = rule.selectorText ?? '';
    if (selector && parent) selector = selector.includes('&') ? selector.replace(/&/g, parent) : `${parent} ${selector}`;
    if (selector) {
      for (const part of selector.split(',')) {
        if (!part.includes(':hover')) continue;
        try {
          if (link.matches(part.replace(/:hover/g, '').trim() || '*')) found.push(rule);
        } catch {}
      }
    }
    if (rule.cssRules) walk(rule.cssRules, selector || parent);
  }
};
for (const sheet of document.styleSheets) walk(sheet.cssRules);
assert.ok(found.length > 0, 'Chybí pravidlo se stavem :hover, které vybere odkaz v článku');
const thickness = (el) => parseFloat(getComputedStyle(el).textDecorationThickness) || 0;
const base = thickness(link);
let thicker = false;
for (const rule of found) {
  const value = rule.style.getPropertyValue('text-decoration-thickness');
  if (!value) continue;
  const probe = link.cloneNode(true);
  link.parentElement.append(probe);
  probe.style.setProperty('text-decoration-thickness', value);
  if (thickness(probe) > base) thicker = true;
  probe.remove();
}
assert.ok(thicker, 'Pravidlo s :hover pro odkaz v článku nezesiluje podtržení (text-decoration-thickness)');
```

Bez najetí myší má odkaz dál tenké podtržení 1 px.

```js
assert.equal(getComputedStyle(document.querySelector('.article a')).textDecorationThickness, '1px', 'Odkaz bez najetí má mít podtržení 1px');
```

# --help--

## --tip--

Stav „ukazatel myši je nad prvkem" vybírá pseudotřída z části [Pseudotřídy: stav prvku](see:css-zaklady/selektory-zaklad#pseudotridy-stav-prvku).

## --tip--

Nové pravidlo má selektor odkazů v článku se stavem a obsahuje jen tloušťku podtržení, kterou vidíš v hotovém pravidle `.article a`, jen větší.

## --tip--

Tlačítko ve vizitce ztmavlo při najetí pravidlem se selektorem tlačítka a stavem, které obsahovalo jen jednu změněnou vlastnost. Stejný tvar, jiný selektor a jiná vlastnost.
