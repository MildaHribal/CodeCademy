# --description--

Mezititulek „Den druhý" má nad sebou i pod sebou skoro stejnou mezeru. Oko pak neví, jestli patří k odstavci nad ním, nebo pod ním. Věci, které k sobě patří, mají být blízko u sebe — nadpis tedy u textu, který uvádí.

Pravidelným mezerám mezi odstavci, nadpisy a bloky, které se na stránce opakují, se říká [[vertikální rytmus]] (*vertical rhythm*).

**Úkol:** mezititulky `.article h2` mají nad sebou velkou mezeru z tokenu `--space-xl` a pod sebou malou z tokenu `--space-s`.

Kandidáti jsou stejní jako u odstavců: `margin` s více hodnotami, samostatné `margin-top` a `margin-bottom`, nebo `margin-block`.

Po uložení sleduj „Den druhý": teď je jasně vidět, že uvádí odstavec pod sebou.

> [!NOTE]
> Nad mezititulkem se potká spodní okraj odstavce (`--space-m`) s horním okrajem nadpisu (`--space-xl`). Svislé okraje dvou sousedů se v normálním toku nesčítají, použije se ten větší. Tomu se říká slévání okrajů a podrobně ho vysvětlí sekce o box modelu.

# --hints--

Nad mezititulkem je mezera z tokenu `--space-xl`.

```js
document.documentElement.style.setProperty('--space-xl', '70px');
const heading = document.querySelectorAll('.article h2')[1];
const above = heading.getBoundingClientRect().top - heading.previousElementSibling.getBoundingClientRect().bottom;
assert.ok(Math.abs(above - 70) <= 1, `Po změně --space-xl na 70px je nad 2. mezititulkem ${Math.round(above)} px`);
```

Pod mezititulkem je mezera z tokenu `--space-s`.

```js
document.documentElement.style.setProperty('--space-s', '9px');
const heading = document.querySelectorAll('.article h2')[1];
const below = heading.nextElementSibling.getBoundingClientRect().top - heading.getBoundingClientRect().bottom;
assert.ok(Math.abs(below - 9) <= 1, `Po změně --space-s na 9px je pod 2. mezititulkem ${Math.round(below)} px`);
```

Mezera nad mezititulkem je aspoň dvakrát větší než pod ním.

```js
const heading = document.querySelectorAll('.article h2')[1];
const box = heading.getBoundingClientRect();
const above = box.top - heading.previousElementSibling.getBoundingClientRect().bottom;
const below = heading.nextElementSibling.getBoundingClientRect().top - box.bottom;
assert.ok(above >= 2 * below, `Nad mezititulkem je ${Math.round(above)} px a pod ním ${Math.round(below)} px — nahoře má být aspoň dvakrát víc`);
```

# --help--

## --tip--

Okraje odstavcům jsi nastavoval v [jedenáctém kroku](see:css-zaklady/workshop-typografie/011). Mezititulek potřebuje totéž, jen s jinými tokeny nahoře a dole.

## --tip--

Deklarace patří do pravidla `.article h2`. Horní hodnota čte `--space-xl`, dolní `--space-s`, vlevo a vpravo zůstává nula.

## --tip--

Nadpis sekce na úvodní stránce s velkým odstupem od předchozí sekce a malým od obsahu by měl `margin` se třemi hodnotami: `var()` s velkým tokenem, nulu a `var()` s malým tokenem.

# --explain--

Vysvětli vlastními slovy, proč má mezititulek nad sebou větší mezeru než pod sebou.

## --model--

Oko vnímá prvky, které jsou blízko u sebe, jako skupinu. Mezititulek uvádí text pod sebou, a proto má být k němu blíž než k předchozímu odstavci. Velká mezera nahoře ukončí předchozí část, malá dole spojí nadpis s jeho textem. Když jsou obě mezery stejné, nadpis „visí" mezi dvěma částmi a čtenář neví, ke které patří.

## --checklist--

- Prvky blízko u sebe vnímá oko jako skupinu.
- Mezititulek patří k textu pod sebou, proto je blíž k němu.
- Velká mezera nad nadpisem odděluje předchozí část.
- Stejné mezery nahoře i dole nechají nadpis viset mezi částmi.
