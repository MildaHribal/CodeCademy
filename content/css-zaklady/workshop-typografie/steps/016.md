# --description--

Přepni náhled na **375**. Titulek má i na telefonu 40 px a zabírá půlku obrazovky, ještě než čtenář uvidí perex. Na velkém monitoru by naopak mohl být o kus větší.

**Úkol:** změň token `--font-size-2xl` tak, aby titulek rostl plynule s šířkou okna, **bez media dotazu**:

- na telefonu široký 375 px má titulek nejvýš 34 px a ani na nejužším telefonu (320 px) nespadne pod 32 px,
- na testovací šířce 1024 px má aspoň 44 px a ani na širokém monitoru (1600 px) nepřeroste 48 px,
- mezi tím se velikost mění plynule, ne skokem,
- velikost reaguje i na písmo nastavené v prohlížeči.

Testy měří i šířky 320, 600 a 1600 px, které přepínač náhledu nenabízí.

# --hints--

Na šířce 375 px má titulek nejvýš 34 px a na 320 px aspoň 32 px.

```js
const title = document.querySelector('.article__title');
await helpers.resize(375);
const phone = parseFloat(getComputedStyle(title).fontSize);
await helpers.resize(320);
const small = parseFloat(getComputedStyle(title).fontSize);
assert.ok(phone <= 34, `Na šířce 375 px má titulek ${phone} px, čekám nejvýš 34 px`);
assert.ok(small >= 31.5, `Na šířce 320 px má titulek ${small} px, čekám aspoň 32 px`);
```

Na šířce 1024 px má titulek aspoň 44 px a na 1600 px nejvýš 48 px.

```js
const title = document.querySelector('.article__title');
const desktop = parseFloat(getComputedStyle(title).fontSize);
await helpers.resize(1600);
const wide = parseFloat(getComputedStyle(title).fontSize);
assert.ok(desktop >= 44, `Na šířce 1024 px má titulek ${desktop} px, čekám aspoň 44 px`);
assert.ok(wide <= 48.5, `Na šířce 1600 px má titulek ${wide} px, čekám nejvýš 48 px`);
```

Velikost se mezi telefonem a počítačem mění plynule: na šířce 600 px je titulek větší než na 375 px a menší než na 1024 px, a v CSS není media dotaz.

```js
const title = document.querySelector('.article__title');
const size = async (width) => { await helpers.resize(width); return parseFloat(getComputedStyle(title).fontSize); };
const phone = await size(375);
const middle = await size(600);
const desktop = await size(1024);
assert.ok(middle > phone && middle < desktop, `Titulek má na 375 px ${phone} px, na 600 px ${middle} px a na 1024 px ${desktop} px — na 600 px má být mezi`);
assert.doesNotMatch(helpers.stripComments(files['styles.css'], 'css'), /@media/, 'V styles.css je media dotaz — velikost má růst plynule bez něj');
```

Velikost titulku reaguje na písmo nastavené v prohlížeči: s kořenovým písmem 20 px je na šířce 375 px větší.

```js
const title = document.querySelector('.article__title');
await helpers.resize(375);
const before = parseFloat(getComputedStyle(title).fontSize);
document.documentElement.style.fontSize = '20px';
const after = parseFloat(getComputedStyle(title).fontSize);
assert.ok(after > before, `Titulek má na 375 px ${before} px a po zvětšení kořenového písma na 20 px pořád ${after} px — hranice a základ piš v rem`);
```

# --help--

## --tip--

Hodnotu s minimem, ideálem a maximem vysvětluje část [min(), max() a clamp()](see:css-zaklady/jednotky-a-hodnoty#min-max-a-clamp) — i proč se k `vw` přičítá `rem`.

## --tip--

Měníš jen hodnotu tokenu `--font-size-2xl` na `:root`. Minimum a maximum spočítej z 32 a 48 px v `rem`, prostřední hodnota sečte `rem` a `vw` přes `+`.

## --tip--

Číslo v přehledu statistik, které má růst od 24 do 40 px, by mělo hodnotu `clamp(1.5rem, 1rem + 2vw, 2.5rem)` — ověř si na papíře, jak velké je při šířce 1024 px.

# --explain--

Vysvětli vlastními slovy, proč se plynulá velikost titulku píše jako `clamp()` s `rem` a `vw`, a ne jen jako `vw`.

## --model--

Samotné `vw` roste s oknem bez hranic, takže na úzkém telefonu by byl titulek nečitelně malý a na širokém monitoru obří. `clamp()` přidá minimum a maximum, mezi kterými se velikost pohybuje. Přičtené `rem` k `vw` zajistí, že velikost reaguje i na písmo nastavené uživatelem, což samotné `vw` ignoruje. A protože se všechno počítá průběžně, nepotřebuju media dotazy.

## --checklist--

- Samotné `vw` nemá hranice a na krajních šířkách je moc malé nebo moc velké.
- `clamp()` drží velikost mezi minimem a maximem.
- Přičtené `rem` zařídí, že velikost reaguje na nastavení písma v prohlížeči.
- Plynulá hodnota nahradí skoky media dotazů.
