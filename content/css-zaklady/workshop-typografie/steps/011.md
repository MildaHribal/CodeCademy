# --description--

Odstavce mají mezi sebou výchozí okraj prohlížeče `1em`. Rytmus stránky ale mají určovat tokeny rozestupů, aby mezery v článku ladily s mezerami v kartách, formulářích a patičce.

**Úkol:** v pravidle `.article > p` nastav odstavcům mezeru **pod** sebou z tokenu `--space-m` a nahoře žádnou.

Mezeru kolem prvku dělá vnější okraj `margin`. Do podrobností ho rozebere sekce o box modelu. Teď stačí, že zkratka se čtyřmi hodnotami jde po směru hodinových ručiček (nahoře, vpravo, dole, vlevo) a se třemi hodnotami znamená nahoře, vlevo i vpravo, dole. Kandidáti:

- `margin` se třemi hodnotami,
- samostatné `margin-top` a `margin-bottom`,
- logická `margin-block` se dvěma hodnotami (začátek a konec bloku, v češtině nahoře a dole).

Když okraje nastavuješ jen **pod** prvky, nemusíš řešit, co se stane, když se horní a dolní okraj dvou sousedů potkají.

# --hints--

Mezera mezi dvěma odstavci článku se bere z tokenu `--space-m`.

```js
document.documentElement.style.setProperty('--space-m', '33px');
const first = [...document.querySelectorAll('.article > p')].find((paragraph) => paragraph.nextElementSibling?.matches('p'));
const gap = first.nextElementSibling.getBoundingClientRect().top - first.getBoundingClientRect().bottom;
assert.ok(Math.abs(gap - 33) <= 1, `Po změně --space-m na 33px je mezi odstavci „Za Veselím…" a „Ve Strážnici…" ${Math.round(gap)} px — čte margin token?`);
```

Odstavce nemají horní okraj a dolní okraj mají z tokenu `--space-m`.

```js
document.documentElement.style.setProperty('--space-m', '33px');
const style = getComputedStyle(document.querySelectorAll('.article > p')[1]);
assert.equal(style.marginTop, '0px', `Odstavec má margin-top ${style.marginTop}, čekám 0px`);
assert.equal(style.marginBottom, '33px', `Odstavec má margin-bottom ${style.marginBottom}, čekám hodnotu tokenu --space-m`);
```

# --help--

## --tip--

Rozestupy jsou v `styles.css` hotové jako tokeny, jak je popisuje část [Design tokeny: pojmenování a škála](see:css-zaklady/vlastni-vlastnosti#design-tokeny-pojmenovani-a-skala).

## --tip--

Deklarace patří do pravidla `.article > p`. Hodnota dole čte token funkcí `var()`, nahoře je nula.

## --tip--

Položky v seznamu notifikací s mezerou jen pod sebou z tokenu `--space-s` by měly v pravidle `margin` se třemi hodnotami: nulu, nulu a `var()` s tím tokenem.
