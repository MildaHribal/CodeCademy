# --description--

Na testovací šířce 1024 px se odstavce táhnou přes celou stránku. Oko musí na konci dlouhého řádku přeskočit daleko doleva a snadno se ztratí.

**Úkol:** do pravidla `.article` přidej `max-width: 65ch`.

[[délka řádku|Délka řádku]] (*measure*) se v typografii počítá ve znacích: pohodlně se čte zhruba 45 až 75 znaků na řádek. Jednotka `ch` je šířka znaku „0" v písmu prvku, takže `65ch` drží šířku kolem 65 znaků i po změně velikosti písma. `max-width` místo `width` znamená „nejvýš": na úzkém telefonu je článek užší a nepřeteče.

Hotové `margin-inline: auto` v pravidle článek vycentruje. K automatickým okrajům se dostaneš v sekci o box modelu.

Příklad na jiných datech — popisek pod grafem v aplikaci, který má zůstat úzký:

```css
.chart__note {
  max-width: 40ch;
}
```

Po uložení přepni náhled na **375** a zpátky: na telefonu je článek přes celou šířku, na počítači se zastaví.

# --hints--

Článek je na šířce 1024 px široký 65 znaků (`65ch`).

```js
const article = document.querySelector('.article');
const probe = document.createElement('span');
probe.style.cssText = 'display: inline-block; width: 1ch;';
article.append(probe);
const ch = probe.getBoundingClientRect().width;
probe.remove();
const chars = article.getBoundingClientRect().width / ch;
assert.ok(Math.abs(chars - 65) < 1, `Článek je široký ${chars.toFixed(1)} znaků (ch), čekám 65`);
```

Na telefonu (šířka 375 px) se článek zúží a stránka nejde posouvat do strany.

```js
await helpers.resize(375);
const root = document.documentElement;
assert.ok(root.scrollWidth <= root.clientWidth, `Při šířce 375 px je obsah široký ${root.scrollWidth} px, okno ${root.clientWidth} px — použil jsi width místo max-width?`);
```

# --explain--

Vysvětli vlastními slovy, proč se šířka textového sloupce píše v `ch` a přes `max-width`, a ne pevně v pixelech přes `width`.

## --model--

Pohodlnost čtení závisí na počtu znaků na řádku, ne na pixelech. `ch` je šířka znaku písma, takže `65ch` drží kolem 65 znaků, i když se písmo zvětší. `max-width` sloupec jen omezí shora: na širokém okně se zastaví, na úzkém telefonu je užší a nepřeteče, což by pevná `width` nezvládla.

## --checklist--

- Čitelnost řádku se měří počtem znaků, ideálně kolem 45–75.
- `ch` je šířka znaku, takže sloupec roste s písmem.
- `max-width` omezí šířku jen shora, na úzkém displeji je sloupec užší.
- Pevná `width` by na telefonu přetekla.
