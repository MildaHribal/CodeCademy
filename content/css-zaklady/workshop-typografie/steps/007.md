# --description--

Titulek na tři řádky vypadá rozvolněně, jako by každý řádek byl samostatný nadpis. Zdědil totiž řádkování textu 1,6. U 40px písma to dělá 64px řádky a mezery mezi nimi jsou skoro tak velké jako písmena.

**Pravidlo typografů:** čím větší písmo, tím menší násobek řádkování. Běžný text 1,5–1,7, nadpisy 1,1–1,3.

**Úkol:** do pravidla `.article__title` i `.article h2` přidej `line-height: 1.2`.

Číslo bez jednotky jsi psal u textu stránky: každý prvek si ho vynásobí svým písmem, takže titulek dostane 48px řádky a mezititulek 33,6 px. Napiš ho i tady bez jednotky — testy zkoušejí i to, jak řádkování dopadne, když se velikost titulku změní.

Příklad na jiných datech — velké číslo v přehledu statistik:

```css
.stat__value {
  line-height: 1.1;
}
```

# --hints--

Titulek má řádkování 1,2násobek svého písma.

```js
const title = document.querySelector('.article__title');
const ratio = () => {
  const style = getComputedStyle(title);
  return { line: style.lineHeight, size: style.fontSize, value: parseFloat(style.lineHeight) / parseFloat(style.fontSize) };
};
const now = ratio();
assert.ok(Math.abs(now.value - 1.2) < 0.01, `Titulek má řádkování ${now.line} při písmu ${now.size} (${now.value.toFixed(2)}×), čekám 1,2×`);
// Násobek musí platit i po změně velikosti písma — pevné pixely by zůstaly stejné.
document.documentElement.style.setProperty('--font-size-2xl', '20px');
const smaller = ratio();
assert.ok(Math.abs(smaller.value - 1.2) < 0.01, `Po zmenšení titulku na 20 px má řádkování ${smaller.line} (${smaller.value.toFixed(2)}×) — napiš ho jako číslo bez jednotky, ať si ho každé písmo přepočítá`);
```

Mezititulky mají řádkování 1,2násobek svého písma.

```js
const ratio = (el) => parseFloat(getComputedStyle(el).lineHeight) / parseFloat(getComputedStyle(el).fontSize);
document.querySelectorAll('.article h2').forEach((heading, i) => {
  const style = getComputedStyle(heading);
  assert.ok(Math.abs(ratio(heading) - 1.2) < 0.01, `${i + 1}. mezititulek má řádkování ${style.lineHeight} při písmu ${style.fontSize} (${ratio(heading).toFixed(2)}×), čekám 1,2×`);
});
// Násobek musí platit i po změně velikosti písma — pevné pixely by zůstaly stejné.
document.documentElement.style.setProperty('--font-size-xl', '20px');
document.querySelectorAll('.article h2').forEach((heading, i) => {
  assert.ok(Math.abs(ratio(heading) - 1.2) < 0.01, `Po zmenšení ${i + 1}. mezititulku na 20 px má řádkování ${getComputedStyle(heading).lineHeight} — napiš ho jako číslo bez jednotky`);
});
```

Odstavce si ponechávají řádkování 1,6.

```js
const style = getComputedStyle(document.querySelectorAll('.article > p')[1]);
const ratio = parseFloat(style.lineHeight) / parseFloat(style.fontSize);
assert.ok(Math.abs(ratio - 1.6) < 0.01, `Odstavec má řádkování ${ratio.toFixed(2)}×, má zůstat 1,6×`);
```
