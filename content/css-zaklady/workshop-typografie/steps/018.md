# --description--

Odkazy v článku jsou pořád výchozí modré a podtržení se dotýká spodních částí písmen jako „p" nebo „y". Redakční weby mají odkazy v barvě webu a podtržení kousek pod textem, aby šlo číst.

**Úkol:** odkazy v článku (`.article a`) mají

- barvu z tokenu `--color-accent`,
- podtržení odsazené od textu o pětinu velikosti písma odkazu — v perexu s větším písmem tedy víc než v odstavci.

Odsazení podtržení nastavuje vlastnost `text-underline-offset`. Její popis najdeš v MDN pod [text-underline-offset](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-underline-offset).

# --hints--

Odkazy v článku mají barvu z tokenu `--color-accent`.

```js
document.documentElement.style.setProperty('--color-accent', 'rgb(7, 8, 9)');
document.querySelectorAll('.article a').forEach((link, i) => {
  assert.equal(getComputedStyle(link).color, 'rgb(7, 8, 9)', `Po změně --color-accent se barva ${i + 1}. odkazu v článku nezměnila`);
});
```

Podtržení je odsazené o pětinu velikosti písma: při písmu 18 px o 3,6 px, při písmu 40 px o 8 px.

```js
const link = document.querySelector('.article a');
const offset = () => {
  const value = getComputedStyle(link).textUnderlineOffset;
  return value.endsWith('%') ? (parseFloat(value) / 100) * parseFloat(getComputedStyle(link).fontSize) : parseFloat(value);
};
link.style.fontSize = '18px';
const small = offset();
link.style.fontSize = '40px';
const big = offset();
assert.ok(Math.abs(small - 3.6) < 0.1, `Při písmu 18 px je podtržení odsazené o ${small} px, čekám 3.6 px`);
assert.ok(Math.abs(big - 8) < 0.1, `Při písmu 40 px je podtržení odsazené o ${big} px, čekám 8 px — odsazení má růst s písmem`);
```

# --help--

## --tip--

Hodnota, která roste s písmem prvku, je v jednotce popsané v části [em: násobek písma prvku](see:css-zaklady/jednotky-a-hodnoty#em-nasobek-pisma-prvku).

## --tip--

Obě deklarace patří do hotového pravidla `.article a`. Barva čte token, odsazení je pětina `em` zapsaná desetinným číslem.

## --tip--

Tlačítko, jehož vnitřní odsazení má být polovina písma, by mělo `padding` s hodnotou `0.5em` — stejný vzor, jiná vlastnost a jiné číslo.

# --explain--

Vysvětli vlastními slovy, proč je odsazení podtržení v `em`, a ne v pixelech nebo v `rem`.

## --model--

Odsazení podtržení má odpovídat velikosti písmen, pod kterými leží. `em` se u ostatních vlastností než `font-size` počítá z písma prvku samotného, takže odkaz v perexu s větším písmem dostane větší odsazení a odkaz v malém popisku menší. Pixely i `rem` by daly všude stejné číslo: u velkého textu by podtržení lepilo na písmena, u malého by bylo moc daleko.

## --checklist--

- Odsazení podtržení má odpovídat velikosti písma odkazu.
- `em` se u ostatních vlastností počítá z písma prvku samotného.
- Pixely a `rem` dávají stejnou hodnotu bez ohledu na písmo odkazu.
