# --description--

V bistru U Modré kotvy má kuchyň nad výdejním pultem obrazovku. Dnes na ni číšník
musí mačkat F5, a když to zapomene, guláš pro stůl 7 se dělá o deset minut později.
V tomhle workshopu postavíš server, který **objednávku pošle do kuchyně sám**,
v okamžiku, kdy ji číšník zapíše. Stejně fungují doručovací appky, sledování
zásilky i burzovní tabule.

Projekt má tři soubory:

- `objednavky.js` — seznam objednávek v paměti a funkce nad ním. Tady začneš.
- `server.js` — kostra HTTP serveru. Umí poslat JSON, přečíst tělo požadavku
  a odpovědět na `GET /`. Zkus **Spustit**.
- `package.json` — důležitý je jediný řádek, `"type": "module"`.

První krok je z JavaScriptu, který už umíš — bez návodu.

**Úkol:** v `objednavky.js` napiš a vyexportuj dvě funkce:

- `dalsiId(seznam)` vrátí číslo o jedna větší, než je největší `id` v seznamu.
  Pro prázdný seznam vrátí `1`.
- `pridejObjednavku(seznam, stul, polozky)` přidá na konec seznamu novou
  objednávku a **vrátí ji**. Nová objednávka má `id` z `dalsiId`, zadaný stůl
  a položky, stav `'nova'` a čas přijetí z funkce `cas()`.

Číslování si bistro řídí samo, protože číšník žádné `id` neposílá — zapisuje jen
stůl a jídlo.

`objednavky.js` vyexportuje funkce `dalsiId` a `pridejObjednavku`.

```js
const modul = await helpers.importFile('objednavky.js');

```

`dalsiId(seznam)` vrátí o jedna víc, než je největší `id` — i když seznam není seřazený a i když je prázdný.

```js
const { dalsiId } = await helpers.importFile('objednavky.js');
assert.equal(dalsiId([]), 1, 'dalsiId([]) má vrátit 1 — první objednávka dne');
assert.equal(dalsiId([{ id: 3 }, { id: 9 }, { id: 5 }]), 10, 'dalsiId([{ id: 3 }, { id: 9 }, { id: 5 }]) má vrátit 10, největší id je 9');
assert.equal(dalsiId([{ id: 41 }]), 42, 'dalsiId([{ id: 41 }]) má vrátit 42');
```

`pridejObjednavku(seznam, stul, polozky)` vrátí novou objednávku se stavem `nova` a časem přijetí.

```js
const { pridejObjednavku } = await helpers.importFile('objednavky.js');
const seznam = [{ id: 1, stul: 2, polozky: ['Čaj'], stav: 'hotova', prijato: '10:00' }];
const nova = pridejObjednavku(seznam, 5, ['Řízek', 'Bramborový salát']);
assert.equal(nova.id, 2, 'pridejObjednavku má nové objednávce dát id 2, když je v seznamu id 1');
assert.equal(nova.stul, 5, 'pridejObjednavku(seznam, 5, …) má do objednávky uložit stůl 5');
assert.deepEqual(nova.polozky, ['Řízek', 'Bramborový salát'], 'pridejObjednavku má uložit položky tak, jak přišly');
assert.equal(nova.stav, 'nova', "Nová objednávka má mít stav 'nova' — kuchyň ji teprve uvidí");
assert.match(nova.prijato, /^\d{2}:\d{2}$/, `Čas přijetí má být ve tvaru HH:MM z funkce cas(), přišlo: ${nova.prijato}`);
```

`pridejObjednavku` přidá objednávku na konec seznamu a nic jiného v něm nezmění.

```js
const { pridejObjednavku } = await helpers.importFile('objednavky.js');
const seznam = [
  { id: 4, stul: 2, polozky: ['Čaj'], stav: 'hotova', prijato: '10:00' },
  { id: 8, stul: 6, polozky: ['Polévka'], stav: 'nova', prijato: '10:20' },
];
const prvni = structuredClone(seznam[0]);
const nova = pridejObjednavku(seznam, 1, ['Palačinka']);
assert.equal(seznam.length, 3, 'Po pridejObjednavku má mít seznam o jednu objednávku víc');
assert.equal(seznam.at(-1), nova, 'pridejObjednavku má novou objednávku přidat na konec seznamu a tutéž vrátit');
assert.deepEqual(seznam[0], prvni, 'pridejObjednavku nemá sahat na objednávky, které už v seznamu byly');
assert.equal(pridejObjednavku(seznam, 9, ['Espresso']).id, 10, 'Druhé volání má dát id 10 — id se počítá z aktuálního seznamu');
```

# --help--

## --tip--

Největší číslo v poli objektů hledáš přes jednu z metod, která z pole udělá **jedinou hodnotu** — připomene to [Co která metoda vrací](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci). Na prázdném poli musí vyjít nula, aby první objednávka dostala `1`.

## --tip--

Stejný tvar nad jinými daty: `mereni.reduce((nej, zaznam) => Math.max(nej, zaznam.teplota), -100)` najde nejvyšší naměřenou teplotu.

## --tip--

`pridejObjednavku` si objednávku nejdřív postaví do proměnné, pak ji uloží do seznamu a **tu samou** proměnnou vrátí — volající s ní hned pracuje dál.

## --file-- server.js

```js
import { createServer } from 'node:http';
import { objednavky } from './objednavky.js';

const port = Number(process.env.PORT ?? 3000);

// Každá JSON odpověď serveru jde přes tuhle funkci.
function posliJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí null.
async function prectiJson(req) {
  const kousky = [];
  for await (const kousek of req) kousky.push(kousek);
  if (kousky.length === 0) return {};
  try {
    return JSON.parse(Buffer.concat(kousky).toString('utf8'));
  } catch {
    return null;
  }
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url, 'http://localhost');

  if (req.method === 'GET' && url.pathname === '/') {
    posliJson(res, 200, { bistro: 'U Modré kotvy', objednavek: objednavky.length });
    return;
  }

  posliJson(res, 404, { chyba: `Cesta ${req.method} ${url.pathname} tady není.` });
});

server.listen(port, () => {
  console.log(`Kuchyň bistra běží na http://localhost:${port}`);
});
```

## --file-- objednavky.js

```js
// Objednávky bistra U Modré kotvy. Držíme je v paměti — po restartu serveru
// se seznam vrátí do tohohle stavu, databáze tu není potřeba.
export const objednavky = [
  { id: 1, stul: 3, polozky: ['Svíčková', 'Kofola'], stav: 'nova', prijato: '11:42' },
  { id: 2, stul: 7, polozky: ['Guláš', 'Pivo', 'Štrúdl'], stav: 'hotova', prijato: '11:45' },
  { id: 3, stul: 1, polozky: ['Smažený sýr', 'Limonáda'], stav: 'nova', prijato: '11:51' },
];

// Čas ve tvaru HH:MM, jak ho kuchyň čte z lístku.
export function cas(ted = new Date()) {
  return ted.toTimeString().slice(0, 5);
}

export function dalsiId(seznam) {
  return seznam.reduce((nejvyssi, objednavka) => Math.max(nejvyssi, objednavka.id), 0) + 1;
}

export function pridejObjednavku(seznam, stul, polozky) {
  const objednavka = { id: dalsiId(seznam), stul, polozky, stav: 'nova', prijato: cas() };
  seznam.push(objednavka);
  return objednavka;
}
```
