# --description--

## Hlášení

Kolega úklid registru dopsal, ale něco je špatně. V bistru mají dvě obrazovky,
a přesto metriky po obědě hlásí tohle:

```text
$ curl http://localhost:3000/api/metriky
{"klientu":47}
```

Číslo jen roste. Stačí kuchyňskou obrazovku obnovit (F5) a přibude další klient;
ten starý v registru zůstane napořád. Server po hodině provozu posílá každou
objednávku do desítek spojení, která už dávno nikdo nečte.

## Úkol

Oprav v `server.js` úklid tak, aby se odpojená obrazovka z registru
**doopravdy** ztratila. Rozesílání zbylým obrazovkám musí fungovat dál.
Změň co nejmenší kus kódu.

> [!TIP]
> Chybu si nejdřív zopakuj: **Spustit**, pak v terminálu
> `curl -N http://localhost:3000/api/udalosti`, Ctrl+C a hned
> `curl http://localhost:3000/api/metriky`.

```js
const otevriProud = async (adresa, hlavicky = {}) => {
  const stop = new AbortController();
  const res = await fetch(adresa, { headers: hlavicky, signal: stop.signal });
  const ctecka = res.body.getReader();
  const dekoder = new TextDecoder();
  let text = '';
  const dalsi = async ({ limit = 4000, komentare = false } = {}) => {
    for (;;) {
      const konec = text.indexOf('\n\n');
      if (konec !== -1) {
        const kus = text.slice(0, konec);
        text = text.slice(konec + 2);
        if (!komentare && kus.split('\n').every((radek) => radek.startsWith(':'))) continue;
        return kus;
      }
      const kousek = await Promise.race([ctecka.read(), helpers.wait(limit).then(() => 'cas')]);
      if (kousek === 'cas' || kousek.done) return null;
      text += dekoder.decode(kousek.value, { stream: true });
    }
  };
  const rozloz = (ramec) => {
    const pole = { data: [] };
    for (const radek of (ramec ?? '').split('\n')) {
      const dvojtecka = radek.indexOf(':');
      if (dvojtecka <= 0) continue;
      const klic = radek.slice(0, dvojtecka);
      const hodnota = radek.slice(dvojtecka + 1).replace(/^ /, '');
      if (klic === 'data') pole.data.push(hodnota);
      else pole[klic] = hodnota;
    }
    return { ...pole, data: pole.data.join('\n') };
  };
  return { res, dalsi, rozloz, zavri: () => stop.abort() };
};
const server = await helpers.startServer('server.js');
const prvni = await otevriProud(new URL('/api/udalosti', server.url));
const druhy = await otevriProud(new URL('/api/udalosti', server.url));
try {
  await prvni.dalsi();
  await druhy.dalsi();
  const pred = await (await fetch(new URL('/api/metriky', server.url))).json();
  assert.equal(pred.klientu, 2, 'Před odpojením mají být v registru dva klienti');
  prvni.zavri();
  const po = await helpers.waitFor(async () => {
    const metriky = await (await fetch(new URL('/api/metriky', server.url))).json();
    return metriky.klientu === 1 ? metriky : false;
  }, 3000).catch(() => null);
  assert.ok(po, `Po odpojení jedné obrazovky má registr hlásit jednoho klienta. Výstup serveru:\n${server.output()}`);
} finally {
  druhy.zavri();
}
```

# --help--

## --tip--

Událost `finish` na odpovědi znamená „tuhle odpověď jsem dopsal a ukončil". Zeptej se sama sebe, kdy takový okamžik u nikdy nekončícího proudu nastane.

## --tip--

Hledáš událost, která se ozve, když **spojení skončí** — ať ho ukončí kdokoli. Nese ji jak požadavek `req`, tak odpověď `res`; jméno má podle toho, co se stalo s připojením.

# --explain--

Proud je otevřená odpověď a obrazovka ji může zavřít kdykoli — zavřením karty, uspáním tabletu, výpadkem wifi. Vysvětli vlastními slovy, proč se o takové spojení musí server starat sám a co se stane, když na úklid zapomene.

## --model--

Server o odpojení klienta nemá jak vědět předem. Dozví se ho až z události, kterou
vyvolá zavřené spojení — a jen tehdy, když ji poslouchá. Do té doby drží odkaz na
odpověď v registru a považuje ji za živou.

Bez úklidu registr roste s každým obnovením stránky. Každé rozeslání pak píše i do
spojení, která nikdo nečte: server plýtvá pamětí i časem a v logu se začnou objevovat
chyby zápisu. Je to stejná past jako neodebraný posluchač událostí v prohlížeči —
paměť drží něco, co už nikdo nepotřebuje.

## --checklist--

- Server se o odpojení dozví jen z události na spojení.
- Bez odebrání z registru zůstane odkaz na mrtvou odpověď.
- Důsledkem je rostoucí paměť a zápisy do zavřených spojení.

```js
// Objednávky bistra U Modré kotvy. Držíme je v paměti — po restartu serveru
// se seznam vrátí do tohohle stavu, databáze tu není potřeba.
export const objednavky = [
  { id: 1, stul: 3, polozky: ['Svíčková', 'Kofola'], stav: 'nova', prijato: '11:42' },
  { id: 2, stul: 7, polozky: ['Guláš', 'Pivo', 'Štrúdl'], stav: 'hotova', prijato: '11:45' },
  { id: 3, stul: 1, polozky: ['Smažený sýr', 'Limonáda'], stav: 'nova', prijato: '11:51' },
];

// Čas ve tvaru HH:MM, jak ho kuchyň čte z lístku.
export function cas(ted = new Date()) {
  return ted.toTimeString().slice(0, 5);
}

export function dalsiId(seznam) {
  return seznam.reduce((nejvyssi, objednavka) => Math.max(nejvyssi, objednavka.id), 0) + 1;
}

export function pridejObjednavku(seznam, stul, polozky) {
  const objednavka = { id: dalsiId(seznam), stul, polozky, stav: 'nova', prijato: cas() };
  seznam.push(objednavka);
  return objednavka;
}
```

```js
// Jeden rámec Server-Sent Events: řádky s klíčem a prázdný řádek na konci.
export function formatujUdalost({ id, typ, data }) {
  let ramec = '';
  if (id !== undefined) ramec += `id: ${id}\n`;
  if (typ) ramec += `event: ${typ}\n`;
  ramec += `data: ${JSON.stringify(data)}\n`;
  return ramec + '\n';
}
```

```js
import { createServer } from 'node:http';
import { objednavky, pridejObjednavku } from './objednavky.js';
import { formatujUdalost } from './sse.js';

const port = Number(process.env.PORT ?? 3000);

// Otevřené proudy kuchyňských obrazovek. Do každého z nich server píše události.
const klienti = new Set();

// Každá JSON odpověď serveru jde přes tuhle funkci.
function posliJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

// Pošle jednu událost všem obrazovkám, které zrovna poslouchají.
function rozesli(typ, data) {
  const ramec = formatujUdalost({ typ, data });
  for (const klient of klienti) {
    klient.write(ramec);
  }
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí null.
async function prectiJson(req) {
  const kousky = [];
  for await (const kousek of req) kousky.push(kousek);
  if (kousky.length === 0) return {};
  try {
    return JSON.parse(Buffer.concat(kousky).toString('utf8'));
  } catch {
    return null;
  }
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url, 'http://localhost');

  if (req.method === 'GET' && url.pathname === '/api/objednavky') {
```
