# --description--

Místo osmi otázek stačí jedno spojení, do kterého server sám píše, když má co
říct. Tomu se říká [[Server-Sent Events]] a je to obyčejné HTTP — jen odpověď
nikdy neskončí.

Obrat je v hlavičkách a v tom, co **neuděláš**: nezavoláš `res.end`.

**Úkol:** v `server.js` obsluž `GET /api/udalosti`. Odpověz stavem `200`
a třemi hlavičkami:

| hlavička | hodnota | proč |
|---|---|---|
| `Content-Type` | `text/event-stream; charset=utf-8` | podle ní klient pozná proud událostí |
| `Cache-Control` | `no-cache` | proxy ani prohlížeč nesmí odpověď schovat do keše |
| `Connection` | `keep-alive` | spojení zůstává otevřené |

Hned po hlavičkách zavolej `res.flushHeaders()` — tím je pošleš na cestu, i když
zatím nemáš žádná data. Pak z obsluhy odejdi, **bez `res.end`**.

Na jiných datech:

```js
// 1. hlavičky napřed, tělo až potom
res.writeHead(200, {
  'Content-Type': 'text/plain; charset=utf-8',
  'Cache-Control': 'no-store',
});
// 2. pošli je na cestu, i když data ještě nemáš
res.flushHeaders();
```

> [!PITFALL]
> Bez `res.flushHeaders()` (nebo bez prvního zápisu) hlavičky zůstanou ve
> frontě a klient visí, dokud nepřijde první událost.

# --hints--

`GET /api/udalosti` odpoví stavem `200` a hlavičkou `Content-Type: text/event-stream`.

```js
const server = await helpers.startServer('server.js');
const stop = new AbortController();
try {
  const res = await fetch(new URL('/api/udalosti', server.url), { signal: stop.signal });
  assert.equal(res.status, 200, `GET /api/udalosti má vrátit stav 200, přišlo ${res.status}. Výstup serveru:\n${server.output()}`);
  assert.match(res.headers.get('content-type') ?? '', /^text\/event-stream/i, `Content-Type má začínat text/event-stream, přišlo: ${res.headers.get('content-type')}`);
} finally {
  stop.abort();
}
```

Odpověď nese `Cache-Control: no-cache` a `Connection: keep-alive`.

```js
const server = await helpers.startServer('server.js');
const stop = new AbortController();

  assert.match(res.headers.get('cache-control') ?? '', /no-cache/i, `Hlavička Cache-Control má být no-cache, přišlo: ${res.headers.get('cache-control')}`);
  assert.match(res.headers.get('connection') ?? '', /keep-alive/i, `Hlavička Connection má být keep-alive, přišlo: ${res.headers.get('connection')}`);
} finally {
  stop.abort();
}
```

Server spojení nezavře — po půl sekundě proud pořád běží.

```js
const server = await helpers.startServer('server.js');
const stop = new AbortController();
try {
  const res = await fetch(new URL('/api/udalosti', server.url), { signal: stop.signal });
  const ctecka = res.body.getReader();
  const konec = ctecka.read().then((kus) => (kus.done ? 'zavreno' : 'data'));
  const vysledek = await Promise.race([konec, helpers.wait(500).then(() => 'otevreno')]);
  assert.notEqual(vysledek, 'zavreno', 'Server odpověď na /api/udalosti nesmí ukončit — na proudu se nevolá res.end');
} finally {
  stop.abort();
}
```

Ostatní routy fungují dál.

```js
const server = await helpers.startServer('server.js');
const seznam = await fetch(new URL('/api/objednavky', server.url));
assert.equal(seznam.status, 200, 'GET /api/objednavky má dál vracet stav 200');
const nikde = await fetch(new URL('/api/udalost', server.url));
assert.equal(nikde.status, 404, 'GET /api/udalost (bez „i“ na konci) má vrátit 404 — routa má sedět přesně');
```

# --help--

## --tip--

Routa vypadá stejně jako ta na seznam objednávek, liší se jen cestou a tím, co uvnitř děláš. Hlavičky proudu jsou popsané v [Server-Sent Events: jednosměrný proud](see:api-soubory-realtime/realtime-prehled#server-sent-events-jednosmerny-proud).

## --tip--

`posliJson` tady nepoužiješ — ta odpověď rovnou ukončuje. Hlavičky nastav přímo přes `res.writeHead(200, { … })` a odpověď nech otevřenou.

## --tip--

Když si chceš ověřit, že proud opravdu visí, pusť **Spustit** a v terminálu zavolej `curl -N http://localhost:3000/api/udalosti`. Přepínač `-N` vypne buffer a `curl` se nevrátí zpátky do příkazové řádky.

```js
// Objednávky bistra U Modré kotvy. Držíme je v paměti — po restartu serveru
// se seznam vrátí do tohohle stavu, databáze tu není potřeba.
export const objednavky = [
  { id: 1, stul: 3, polozky: ['Svíčková', 'Kofola'], stav: 'nova', prijato: '11:42' },
  { id: 2, stul: 7, polozky: ['Guláš', 'Pivo', 'Štrúdl'], stav: 'hotova', prijato: '11:45' },
  { id: 3, stul: 1, polozky: ['Smažený sýr', 'Limonáda'], stav: 'nova', prijato: '11:51' },
];

// Čas ve tvaru HH:MM, jak ho kuchyň čte z lístku.
export function cas(ted = new Date()) {
  return ted.toTimeString().slice(0, 5);
}

export function dalsiId(seznam) {
  return seznam.reduce((nejvyssi, objednavka) => Math.max(nejvyssi, objednavka.id), 0) + 1;
}

export function pridejObjednavku(seznam, stul, polozky) {
  const objednavka = { id: dalsiId(seznam), stul, polozky, stav: 'nova', prijato: cas() };
  seznam.push(objednavka);
  return objednavka;
}
```

## --file-- server.js

```js
import { createServer } from 'node:http';
import { objednavky, pridejObjednavku } from './objednavky.js';

const port = Number(process.env.PORT ?? 3000);

// Každá JSON odpověď serveru jde přes tuhle funkci.
function posliJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí null.
async function prectiJson(req) {
  const kousky = [];
  for await (const kousek of req) kousky.push(kousek);
  if (kousky.length === 0) return {};
  try {
    return JSON.parse(Buffer.concat(kousky).toString('utf8'));
  } catch {
    return null;
  }
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url, 'http://localhost');

  if (req.method === 'GET' && url.pathname === '/api/objednavky') {
    posliJson(res, 200, objednavky);
    return;
  }

  if (req.method === 'POST' && url.pathname === '/api/objednavky') {
    const telo = await prectiJson(req);
    if (!telo || typeof telo.stul !== 'number' || !Array.isArray(telo.polozky) || telo.polozky.length === 0) {
      posliJson(res, 400, { chyba: 'Objednávka potřebuje číslo stolu a aspoň jednu položku.' });
      return;
    }
    posliJson(res, 201, pridejObjednavku(objednavky, telo.stul, telo.polozky));
    return;
  }

  if (req.method === 'GET' && url.pathname === '/') {
    posliJson(res, 200, { bistro: 'U Modré kotvy', objednavek: objednavky.length });
    return;
  }

  if (req.method === 'GET' && url.pathname === '/api/udalosti') {
    res.writeHead(200, {
      'Content-Type': 'text/event-stream; charset=utf-8',
      'Cache-Control': 'no-cache',
      Connection: 'keep-alive',
    });
    res.flushHeaders();
    return;
  }

  posliJson(res, 404, { chyba: `Cesta ${req.method} ${url.pathname} tady není.` });
});

server.listen(port, () => {
  console.log(`Kuchyň bistra běží na http://localhost:${port}`);
});
```
