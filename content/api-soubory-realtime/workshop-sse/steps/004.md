# --description--

Server objednávky přijímá i vydává, ale kuchyňská obrazovka o nové objednávce
nemá jak vědět. Nejjednodušší řešení je [[dotazování]]: ptát se pořád dokola.
Než ho zavrhneme, změř, co stojí — čísla přesvědčí líp než tvrzení.

**Úkol:** v `scripts/dotazuj.js` napiš skript, který `pokusu`-krát za sebou
stáhne `/api/objednavky`, mezi dotazy počká `pauza` milisekund a počítá,
kolikrát přišla **úplně stejná odpověď jako minule**. Na konci vypíše jediný
řádek:

```text
{"pozadavku":8,"zbytecnych":7}
```

Odpovědi porovnávej jako text, ne jako rozbalený objekt — dva různé objekty se
nikdy nerovnají. Adresu API máš v proměnné `api`, konstanty `pokusu` a `pauza`
jsou nahoře v souboru.

Pauzu vyrobíš z `setTimeout` obalené Promise:

```js
await new Promise((hotovo) => setTimeout(hotovo, 250));
```

Skript spustíš z terminálu: `node scripts/dotazuj.js`. Sedm z osmi požadavků
přineslo přesně to, co obrazovka už měla — a to je při jednom klientovi. Při
dvaceti obrazovkách a intervalu jedné sekundy to je 1200 požadavků za minutu
skoro nazmar.

# --help--

## --tip--

Potřebuješ obyčejný cyklus s počítadlem, který běží `pokusu`-krát, a dvě proměnné, co si pamatují stav mezi koly: poslední odpověď a počet shod.

## --tip--

Tělo odpovědi si vyžádej jako text (`await odpoved.text()`), ne jako objekt. Text jde porovnat `===`, dva objekty ze dvou `JSON.parse` nikdy.

## --tip--

Vzor nad jinými daty: `let minule = null; for (let i = 0; i < 5; i += 1) { const teplota = await zmer(); if (teplota === minule) stejnych += 1; minule = teplota; }`

```js
// Objednávky bistra U Modré kotvy. Držíme je v paměti — po restartu serveru
// se seznam vrátí do tohohle stavu, databáze tu není potřeba.
export const objednavky = [
  { id: 1, stul: 3, polozky: ['Svíčková', 'Kofola'], stav: 'nova', prijato: '11:42' },
  { id: 2, stul: 7, polozky: ['Guláš', 'Pivo', 'Štrúdl'], stav: 'hotova', prijato: '11:45' },
  { id: 3, stul: 1, polozky: ['Smažený sýr', 'Limonáda'], stav: 'nova', prijato: '11:51' },
];

// Čas ve tvaru HH:MM, jak ho kuchyň čte z lístku.
export function cas(ted = new Date()) {
  return ted.toTimeString().slice(0, 5);
}

export function dalsiId(seznam) {
  return seznam.reduce((nejvyssi, objednavka) => Math.max(nejvyssi, objednavka.id), 0) + 1;
}

export function pridejObjednavku(seznam, stul, polozky) {
  const objednavka = { id: dalsiId(seznam), stul, polozky, stav: 'nova', prijato: cas() };
  seznam.push(objednavka);
  return objednavka;
}
```

## --file-- server.js

```js
import { createServer } from 'node:http';
import { objednavky, pridejObjednavku } from './objednavky.js';

const port = Number(process.env.PORT ?? 3000);

// Každá JSON odpověď serveru jde přes tuhle funkci.
function posliJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí null.
async function prectiJson(req) {
  const kousky = [];
  for await (const kousek of req) kousky.push(kousek);
  if (kousky.length === 0) return {};
  try {
    return JSON.parse(Buffer.concat(kousky).toString('utf8'));
  } catch {
    return null;
  }
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url, 'http://localhost');

  if (req.method === 'GET' && url.pathname === '/api/objednavky') {
    posliJson(res, 200, objednavky);
    return;
  }

  if (req.method === 'POST' && url.pathname === '/api/objednavky') {
    const telo = await prectiJson(req);
    if (!telo || typeof telo.stul !== 'number' || !Array.isArray(telo.polozky) || telo.polozky.length === 0) {
      posliJson(res, 400, { chyba: 'Objednávka potřebuje číslo stolu a aspoň jednu položku.' });
      return;
    }
    posliJson(res, 201, pridejObjednavku(objednavky, telo.stul, telo.polozky));
    return;
  }

  if (req.method === 'GET' && url.pathname === '/') {
    posliJson(res, 200, { bistro: 'U Modré kotvy', objednavek: objednavky.length });
    return;
  }

  posliJson(res, 404, { chyba: `Cesta ${req.method} ${url.pathname} tady není.` });
});

server.listen(port, () => {
  console.log(`Kuchyň bistra běží na http://localhost:${port}`);
});
```

## --file-- scripts/dotazuj.js

```js
// Kuchyňská obrazovka zatím nic živého nemá. Tenhle skript dělá to, co by musela:
// ptá se pořád dokola, jestli nepřibyla objednávka.
const api = process.env.API_URL ?? 'http://localhost:3000';
const pokusu = 8;
const pauza = 50;

let predchozi = null;
let zbytecnych = 0;

for (let pokus = 0; pokus < pokusu; pokus += 1) {
  const odpoved = await fetch(`${api}/api/objednavky`);
  const telo = await odpoved.text();
  if (telo === predchozi) zbytecnych += 1;
  predchozi = telo;
  await new Promise((hotovo) => setTimeout(hotovo, pauza));
}

console.log(JSON.stringify({ pozadavku: pokusu, zbytecnych }));
```
