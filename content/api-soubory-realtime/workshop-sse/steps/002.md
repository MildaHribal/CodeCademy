# --description--

Kuchyňská obrazovka si musí odněkud vzít objednávky, které už v bistru jsou.
Než se pustíme do čehokoli živého, dej serveru adresu, ze které se seznam dá
přečíst — z ní bude obrazovka žít při každém načtení.

**Úkol:** v `server.js` odpověz na `GET /api/objednavky` stavem `200`
a seznamem `objednavky` ve formátu JSON. Na odesílání použij funkci
`posliJson`, která už v souboru je: nastaví stav, hlavičku
`Content-Type: application/json; charset=utf-8` a pošle tělo.

Kontrola cesty patří **před** poslední řádek s odpovědí `404`. Ten je záchytný:
platí pro všechno, co se do žádné routy netrefilo.

Na jiných datech:

```js
// 1. poznej požadavek
if (req.method === 'GET' && url.pathname === '/api/pokoje') {
  // 2. odpověz a skonči
  posliJson(res, 200, pokoje);
  return;
}
```

Po **Spustit** si adresu otevři v HTTP klientovi — uvidíš tři objednávky.

# --hints--

`GET /api/objednavky` vrátí stav `200` a hlavičku `Content-Type` s typem `application/json`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/objednavky', server.url));
assert.equal(res.status, 200, `GET /api/objednavky má vrátit stav 200, přišlo ${res.status}. Výstup serveru:\n${server.output()}`);
assert.match(res.headers.get('content-type') ?? '', /^application\/json/i, `Content-Type odpovědi má začínat application/json, přišlo: ${res.headers.get('content-type')}`);
```

Tělo odpovědi je celý seznam objednávek z `objednavky.js`.

```js
const server = await helpers.startServer('server.js');
const data = await (await fetch(new URL('/api/objednavky', server.url))).json();
const { objednavky } = await helpers.importFile('objednavky.js');
assert.ok(Array.isArray(data), 'GET /api/objednavky má vrátit pole objednávek');
assert.deepEqual(data, objednavky, 'GET /api/objednavky má vrátit všechny objednávky ze souboru objednavky.js');
```

Cesta, kterou server nezná, dál vrací `404` — nová routa ji nesmí spolknout.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(new URL('/api/kava', server.url));
assert.equal(res.status, 404, 'GET /api/kava má pořád vracet stav 404');
assert.equal(typeof (await res.json()).chyba, 'string', 'Odpověď 404 má mít v těle klíč chyba');
const uvod = await fetch(new URL('/', server.url));
assert.equal(uvod.status, 200, 'GET / má dál vracet stav 200');
```

# --help--

## --tip--

Routa je jen podmínka nad dvěma hodnotami z požadavku: metodou a cestou. Cestu bez query stringu máš v proměnné `url` — viz [Adresa: `req.url`, cesta a query string](see:node-zaklady/http-v-node#adresa-req-url-cesta-a-query-string).

## --tip--

Po odeslání odpovědi z obsluhy odejdi, ať se nepokračuje k záchytné odpovědi. Server jinak pošle na jeden požadavek dvě odpovědi — viz [Jedna odpověď na každý požadavek](see:node-zaklady/http-v-node#jedna-odpoved-na-kazdy-pozadavek).

export const objednavky = [
  { id: 1, stul: 3, polozky: ['Svíčková', 'Kofola'], stav: 'nova', prijato: '11:42' },
  { id: 2, stul: 7, polozky: ['Guláš', 'Pivo', 'Štrúdl'], stav: 'hotova', prijato: '11:45' },
  { id: 3, stul: 1, polozky: ['Smažený sýr', 'Limonáda'], stav: 'nova', prijato: '11:51' },
];

// Čas ve tvaru HH:MM, jak ho kuchyň čte z lístku.
export function cas(ted = new Date()) {
  return ted.toTimeString().slice(0, 5);
}

export function dalsiId(seznam) {
  return seznam.reduce((nejvyssi, objednavka) => Math.max(nejvyssi, objednavka.id), 0) + 1;
}

export function pridejObjednavku(seznam, stul, polozky) {
  const objednavka = { id: dalsiId(seznam), stul, polozky, stav: 'nova', prijato: cas() };
  seznam.push(objednavka);
  return objednavka;
}

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { objednavky } from './objednavky.js';

const port = Number(process.env.PORT ?? 3000);

// Každá JSON odpověď serveru jde přes tuhle funkci.
function posliJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí null.
async function prectiJson(req) {
  const kousky = [];
  for await (const kousek of req) kousky.push(kousek);
  if (kousky.length === 0) return {};
  try {
    return JSON.parse(Buffer.concat(kousky).toString('utf8'));
  } catch {
    return null;
  }
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url, 'http://localhost');

  if (req.method === 'GET' && url.pathname === '/api/objednavky') {
    posliJson(res, 200, objednavky);
    return;
  }

  if (req.method === 'GET' && url.pathname === '/') {
    posliJson(res, 200, { bistro: 'U Modré kotvy', objednavek: objednavky.length });
    return;
  }

  posliJson(res, 404, { chyba: `Cesta ${req.method} ${url.pathname} tady není.` });
});

server.listen(port, () => {
  console.log(`Kuchyň bistra běží na http://localhost:${port}`);
});
```
