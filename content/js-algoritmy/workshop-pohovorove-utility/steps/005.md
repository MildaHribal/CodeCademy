# --description--

## Hlášení

Kolega přidal do modulu `groupBy` a v adminu s ní rozdělil štítky produktů. Přišlo
tohle hlášení:

> Rozdělení do skupin funguje, ale u dvou štítků spadne celý výpis. Jeden z nich se
> jmenuje `constructor`, druhý `toString`. Chyba: *skupiny[klic].push is not a function*.

## Úkol

Oprav `groupBy` tak, aby fungovala pro **libovolný** řetězcový klíč, a vrať skupiny
jako `Map`:

- `groupBy(items, keyFn)` vrátí `Map`, kde klíč je výsledek `keyFn(item)` a hodnota
  pole položek v pořadí, v jakém přišly,
- klíče jako `constructor`, `toString` nebo `__proto__` se chovají stejně jako
  kterékoli jiné,
- prázdný vstup dá prázdnou `Map`.

Nejdřív si ale pojmenuj příčinu: proč zrovna `constructor`?

# --hints--

Skupiny se vrací jako `Map` a rozdělení sedí.

```js
const podleMesta = groupBy(objednavky, (o) => o.mesto);
assert.ok(podleMesta instanceof Map, 'groupBy má vracet Map');
assert.equal(podleMesta.size, 3, 'Města jsou tři: Brno, Praha, Ostrava');
assert.deepEqual(podleMesta.get('Brno').map((o) => o.id), ['o1', 'o3'], 'Brno má objednávky o1 a o3 v původním pořadí');
assert.deepEqual(podleMesta.get('Ostrava').map((o) => o.id), ['o4'], 'Ostrava má jednu objednávku');
```

Zrádné klíče už nic nerozbijí.

```js
const stitky = [
  { nazev: 'A', stitek: 'constructor' },
  { nazev: 'B', stitek: 'toString' },
  { nazev: 'C', stitek: '__proto__' },
  { nazev: 'D', stitek: 'constructor' },
];
const podleStitku = groupBy(stitky, (p) => p.stitek);
assert.equal(podleStitku.size, 3, 'Tři různé štítky jsou tři skupiny');
assert.deepEqual(podleStitku.get('constructor').map((p) => p.nazev), ['A', 'D'], 'Klíč constructor musí fungovat jako každý jiný');
assert.deepEqual(podleStitku.get('__proto__').map((p) => p.nazev), ['C'], 'Klíč __proto__ musí fungovat jako každý jiný');
```

Prázdný vstup dá prázdnou `Map`.

```js
const prazdne = groupBy([], (x) => x);
assert.ok(prazdne instanceof Map, 'I pro prázdný vstup se vrací Map');
assert.equal(prazdne.size, 0, 'Prázdný vstup nemá žádnou skupinu');
```

Funkce z předchozích kroků zůstaly.

```js
let volani = 0;
const druha = memoize((n) => { volani += 1; return n * n; });
druha(3); druha(3);
assert.equal(volani, 1, 'memoize ze čtvrtého kroku musí dál fungovat');
assert.equal(once(() => 0)(), 0, 'once ze třetího kroku musí dál fungovat');
```

# --help--

## --tip--

Obyčejný objekt není prázdný — dědí vlastnosti z `Object.prototype`. Zkus si
v konzoli, co vrátí `({}).constructor` a `({}).toString`.

## --tip--

Podmínka `if (!skupiny[klic])` se proto u takového klíče netrefí: hodnota už „existuje",
jenže to není pole. Datová struktura, která tenhle problém nemá vůbec, se učila
v [Kdy Map a kdy objekt](see:js-tridy-kolekce/map-a-set#kdy-map-a-kdy-objekt).

## --tip--

Druhá možná oprava je `Object.create(null)` — objekt bez prototypu. `Map` je ale
přímočařejší: má `has`, `get`, `set` a zachovává pořadí vkládání.

const objednavky = [
  { id: 'o1', mesto: 'Brno', castka: 1290, stav: 'nova' },
  { id: 'o2', mesto: 'Praha', castka: 890, stav: 'odeslana' },
  { id: 'o3', mesto: 'Brno', castka: 2450, stav: 'odeslana' },
  { id: 'o4', mesto: 'Ostrava', castka: 640, stav: 'nova' },
  { id: 'o5', mesto: 'Praha', castka: 1790, stav: 'nova' },

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}

/**
 * Pustí `fn` nejvýš jednou za `limit` ms. První volání projde hned.
 * Debounce čeká na klid, throttle drží tempo.
 */
function throttle(fn, limit) {
  let naposledy = 0;
  return (...args) => {
    const ted = Date.now();
    if (ted - naposledy < limit) return;
    naposledy = ted;
    fn(...args);
  };
}

/**
 * Zavolá `fn` jen při prvním volání, další volání vrací uložený výsledek.
 * Příznak je oddělený od výsledku — jinak by funkce vracející 0 běžela pořád.
 */
function once(fn) {
  let hotovo = false;
  let vysledek;
  return (...args) => {
    if (!hotovo) {
      vysledek = fn(...args);
      hotovo = true;
    }
    return vysledek;
  };
}

/**
 * Uloží výsledky `fn` podle klíče z `keyFn`.
 * Map + has se ptá na existenci záznamu, ne na jeho pravdivost.
 */
function memoize(fn, keyFn = (prvni) => prvni) {
  const cache = new Map();
  return (...args) => {
    const klic = keyFn(...args);
    if (!cache.has(klic)) cache.set(klic, fn(...args));
    return cache.get(klic);
  };
}

/**
 * Rozdělí položky do skupin podle klíče. (Přidal kolega, ještě nebylo v review.)
 */
function groupBy(items, keyFn) {
  const skupiny = {};
  for (const item of items) {
    const klic = keyFn(item);
    if (!skupiny[klic]) skupiny[klic] = [];
    skupiny[klic].push(item);
  }
  return skupiny;
}
