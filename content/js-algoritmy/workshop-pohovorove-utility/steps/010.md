# --description--

Poslední kousek do modulu. Tabulky v administraci se skoro nikdy neřadí podle jednoho
sloupce — nejdřív podle města, a uvnitř města podle částky sestupně.

**Úkol:** Napiš `sortBy(items, ...kriteria)`. Vrátí **nové** seřazené pole (vstup nechá
být). Každé kritérium je buď funkce vracející hodnotu k porovnání, nebo dvojice
`[funkce, 'desc']` pro sestupné pořadí. Při shodě rozhoduje další kritérium v pořadí;
když se shodnou všechna, zůstane původní pořadí.

Řetězce porovnávej česky přes `localeCompare`, čísla odčítáním.

# --hints--

Řadí podle jednoho kritéria a vstup nechá být.

```js
const podleCastky = sortBy(objednavky, (o) => o.castka);
assert.deepEqual(podleCastky.map((o) => o.id), ['o4', 'o2', 'o1', 'o5', 'o3'], 'Vzestupně podle částky');
assert.equal(objednavky[0].id, 'o1', 'Vstupní pole se nesmí seřadit na místě');
assert.notEqual(podleCastky, objednavky, 'sortBy má vrátit nové pole');
```

Sestupné pořadí přes dvojici s `desc`.

```js
const nejdrazsi = sortBy(objednavky, [(o) => o.castka, 'desc']);
assert.deepEqual(nejdrazsi.map((o) => o.id), ['o3', 'o5', 'o1', 'o2', 'o4'], 'Sestupně podle částky');
```

Druhé kritérium rozhoduje při shodě prvního.

```js
const radek = sortBy(objednavky, (o) => o.mesto, [(o) => o.castka, 'desc']);
assert.deepEqual(
  radek.map((o) => `${o.mesto} ${o.castka}`),
  ['Brno 2450', 'Brno 1290', 'Ostrava 640', 'Praha 1790', 'Praha 890'],
  'Nejdřív město vzestupně, uvnitř města částka sestupně',
);
```

Řetězce se porovnávají česky a shoda zachová původní pořadí.

```js
const mesta = [{ n: 'Žatec' }, { n: 'Cheb' }, { n: 'Česká Lípa' }, { n: 'Domažlice' }];
assert.deepEqual(sortBy(mesta, (m) => m.n).map((m) => m.n), ['Česká Lípa', 'Domažlice', 'Cheb', 'Žatec'], 'Česky: Č hned za C, ale CH až za H — tedy Cheb za Domažlicemi');

const stejne = [{ id: 'a', v: 1 }, { id: 'b', v: 1 }, { id: 'c', v: 1 }];
assert.deepEqual(sortBy(stejne, (x) => x.v).map((x) => x.id), ['a', 'b', 'c'], 'Při úplné shodě zůstane původní pořadí');
assert.deepEqual(sortBy([], (x) => x), [], 'Prázdné pole projde');
```

Celý modul drží pohromadě.

```js
const podleMesta = groupBy(objednavky, (o) => o.mesto);
assert.equal(podleMesta.get('Praha').length, 2, 'groupBy dál funguje');
assert.equal(deepClone({ a: { b: 1 } }).a.b, 1, 'deepClone dál funguje');
assert.equal(await retry(async () => 'ok'), 'ok', 'retry dál funguje');
assert.deepEqual(await mapLimit([1, 2], 2, async (n) => n * 2), [2, 4], 'mapLimit dál funguje');
```

# --help--

## --tip--

Porovnávací funkce vrací záporné číslo, nulu, nebo kladné číslo. Pro víc kritérií
je projdi po pořadí a vrať první nenulový výsledek.

## --tip--

Kritérium může přijít ve dvou tvarech. Rozliš je podle toho, jestli je to pole —
a z pole si vytáhni funkci i směr.

## --tip--

`Array.prototype.sort` je od ES2019 stabilní, takže při shodě zůstane původní pořadí
samo. Kopii pole před řazením ale musíš udělat ty: `[...items]` nebo `items.toSorted()`.

## Co jsi postavil

Malý modul, ve kterém je pohromadě většina toho, na co se na juniorském pohovoru
z JavaScriptu ptají:

- **uzávěry v praxi** — `debounce`, `throttle`, `once`, `memoize`,
- **datové struktury** — `Map` v mezipaměti, `Map` místo objektu v `groupBy`,
  `WeakMap` u hluboké kopie,
- **rekurze** — `deepClone` včetně cyklů,
- **asynchronní vzory** — opakování po chybě a omezený souběh,
- **řazení** — stabilní, podle víc kritérií, bez mutace vstupu.

A hlavně: každou z nich umíš odvodit, ne odrecitovat. To je přesně ten rozdíl, který
u tabule poznají.

## Udělej po svém

- **Trailing debounce:** uprav `throttle` tak, aby na konci okna ještě pustil poslední
  zahozené volání. Kde se to hodí víc než současná varianta?
- **Omezená mezipaměť:** dej `memoize` maximální počet záznamů a při překročení zahoď
  ten nejdéle nepoužitý.
- **Zrušení:** přidej `mapLimit` podporu `AbortSignal`, aby se rozdělaná práce dala
  zastavit.
- **Vlastní přírůstek:** co v každém projektu píšeš znovu ty? Přidej to do modulu
  i s testy.

// utils.js — malá knihovna pomocných funkcí pro tým.
// Každá z nich se zároveň ptá na pohovorech: nejde o to je znát nazpaměť,
// ale umět je na místě odvodit a říct, kdy se hodí která.

// Ukázková data, na kterých si funkce zkoušíš.
const objednavky = [
  { id: 'o1', mesto: 'Brno', castka: 1290, stav: 'nova' },
  { id: 'o2', mesto: 'Praha', castka: 890, stav: 'odeslana' },
  { id: 'o3', mesto: 'Brno', castka: 2450, stav: 'odeslana' },
  { id: 'o4', mesto: 'Ostrava', castka: 640, stav: 'nova' },
  { id: 'o5', mesto: 'Praha', castka: 1790, stav: 'nova' },
];

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}

/**
 * Pustí `fn` nejvýš jednou za `limit` ms. První volání projde hned.
 * Debounce čeká na klid, throttle drží tempo.
 */
function throttle(fn, limit) {
  let naposledy = 0;
  return (...args) => {
    const ted = Date.now();
    if (ted - naposledy < limit) return;
    naposledy = ted;
    fn(...args);
  };
}

/**
 * Zavolá `fn` jen při prvním volání, další volání vrací uložený výsledek.
 * Příznak je oddělený od výsledku — jinak by funkce vracející 0 běžela pořád.
 */
function once(fn) {
  let hotovo = false;
  let vysledek;
  return (...args) => {
    if (!hotovo) {
      vysledek = fn(...args);
      hotovo = true;
    }
    return vysledek;
  };
}

/**
 * Uloží výsledky `fn` podle klíče z `keyFn`.
 * Map + has se ptá na existenci záznamu, ne na jeho pravdivost.
 */
function memoize(fn, keyFn = (prvni) => prvni) {
  const cache = new Map();
  return (...args) => {
    const klic = keyFn(...args);
    if (!cache.has(klic)) cache.set(klic, fn(...args));
    return cache.get(klic);
  };
}

/**
 * Rozdělí položky do skupin podle klíče.
 * Map, ne objekt: klíč „constructor" ani „__proto__" pak nic nerozbije.
 */
function groupBy(items, keyFn) {
  const skupiny = new Map();
  for (const item of items) {
    const klic = keyFn(item);
    if (!skupiny.has(klic)) skupiny.set(klic, []);
    skupiny.get(klic).push(item);
  }
  return skupiny;
}

/**
 * Hluboká kopie, která zvládne i cykly.
 * Kopie se do paměti ukládá PŘED kopírováním vlastností — jinak se rekurze zacyklí.
 */
function deepClone(hodnota, videne = new WeakMap()) {
  if (hodnota === null || typeof hodnota !== 'object') return hodnota;
  if (hodnota instanceof Date) return new Date(hodnota);
  if (videne.has(hodnota)) return videne.get(hodnota);

  if (Array.isArray(hodnota)) {
    const kopie = [];
    videne.set(hodnota, kopie);
    for (const polozka of hodnota) kopie.push(deepClone(polozka, videne));
    return kopie;
  }

  const kopie = {};
  videne.set(hodnota, kopie);
  for (const [klic, vnorena] of Object.entries(hodnota)) {
    kopie[klic] = deepClone(vnorena, videne);
  }
  return kopie;
}

/** Počká zadaný počet milisekund. */
function pockej(ms) {
  return new Promise((hotovo) => setTimeout(hotovo, ms));
}

/**
 * Zkusí `fn` až `pokusy`krát, mezi pokusy počká `prodleva` ms.
 * Po vyčerpání pokusů vyhodí poslední chybu — jinak volající neví, na čem to stálo.
 */
async function retry(fn, { pokusy = 3, prodleva = 100 } = {}) {
  let posledni;
  for (let pokus = 1; pokus <= pokusy; pokus++) {
    try {
      return await fn();
    } catch (chyba) {
      posledni = chyba;
      if (pokus < pokusy) await pockej(prodleva);
    }
  }
  throw posledni;
}

/**
 * Zpracuje všechny položky s nejvýš `limit` souběžnými voláními.
 * Výsledky se ukládají na index vstupu, takže pořadí odpovídá vstupu.
 */
async function mapLimit(items, limit, fn) {
  const vysledky = new Array(items.length);
  let dalsi = 0;

  async function pracovnik() {
    while (dalsi < items.length) {
      const index = dalsi;
      dalsi += 1;
      vysledky[index] = await fn(items[index], index);
    }
  }

  const pocet = Math.min(limit, items.length);
  await Promise.all(Array.from({ length: pocet }, () => pracovnik()));
  return vysledky;
}

/**
 * Vrátí nové pole seřazené podle víc kritérií.
 * Kritérium je funkce, nebo dvojice [funkce, 'desc'] pro sestupné pořadí.
 */
function sortBy(items, ...kriteria) {
  const rozbal = (kriterium) => (Array.isArray(kriterium) ? kriterium : [kriterium, 'asc']);

  return [...items].sort((a, b) => {
    for (const kriterium of kriteria) {
      const [klic, smer] = rozbal(kriterium);
      const prvni = klic(a);
      const druha = klic(b);
      const rozdil = typeof prvni === 'string' && typeof druha === 'string'
        ? prvni.localeCompare(druha, 'cs')
        : Number(prvni) - Number(druha);
      if (rozdil !== 0) return smer === 'desc' ? -rozdil : rozdil;
    }
    return 0;
  });
}
