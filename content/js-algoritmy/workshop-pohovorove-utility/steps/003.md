# --description--

Inicializace mapy, souhlas s cookies, odeslání objednávky — spousta věcí se smí stát
právě jednou, i když se obsluha zavolá desetkrát.

**Úkol:** Napiš `once(fn)`. Vrácená funkce zavolá `fn` jen při prvním volání a její
výsledek si zapamatuje. Každé další volání vrátí **ten samý výsledek**, aniž by `fn`
zavolala znovu.

Pozor na past: podmínka „už mám výsledek?" se nesmí ptát na pravdivost výsledku.
Funkce, která vrátí `0`, `''` nebo `false`, by se pak volala pořád dokola.

# --hints--

`fn` se zavolá jen jednou a výsledek se vrací dál.

```js
let volani = 0;
const pripoj = once(() => { volani += 1; return 'připojeno'; });
assert.equal(pripoj(), 'připojeno', 'První volání vrátí výsledek fn');
assert.equal(pripoj(), 'připojeno', 'Druhé volání vrátí ten samý výsledek');
assert.equal(pripoj(), 'připojeno', 'A třetí taky');
assert.equal(volani, 1, 'fn se má zavolat právě jednou');
```

Funguje i pro nepravdivé návratové hodnoty.

```js
let volani = 0;
const nula = once(() => { volani += 1; return 0; });
nula(); nula(); nula();
assert.equal(volani, 1, 'Výsledek 0 je taky výsledek — fn se nesmí volat znovu');

let prazdne = 0;
const text = once(() => { prazdne += 1; return ''; });
text(); text();
assert.equal(prazdne, 1, "Prázdný řetězec je taky výsledek");
```

Argumenty prvního volání se předají `fn`.

```js
const soucet = once((a, b) => a + b);
assert.equal(soucet(2, 3), 5, 'fn má dostat argumenty prvního volání');
assert.equal(soucet(10, 10), 5, 'Další volání vrací uložený výsledek, ne nový výpočet');
```

# --help--

## --tip--

Potřebuješ dvě věci v uzávěru: jestli už funkce běžela, a co vrátila. Ta první se
nedá odvodit z té druhé.

## --tip--

Drž si příznak „už proběhlo" odděleně od uložené hodnoty. Podmínka se pak ptá na ten
příznak, ne na hodnotu — a `0` i `false` projdou správně.

## --tip--

Ve stejném duchu se dělá „lazy init": hodnota se spočítá až při prvním použití a pak
se jen vrací.

# --solution--

## --file-- script.js

```js
// utils.js — malá knihovna pomocných funkcí pro tým.
// Každá z nich se zároveň ptá na pohovorech: nejde o to je znát nazpaměť,
// ale umět je na místě odvodit a říct, kdy se hodí která.

// Ukázková data, na kterých si funkce zkoušíš.
const objednavky = [
  { id: 'o1', mesto: 'Brno', castka: 1290, stav: 'nova' },
  { id: 'o2', mesto: 'Praha', castka: 890, stav: 'odeslana' },
  { id: 'o3', mesto: 'Brno', castka: 2450, stav: 'odeslana' },
  { id: 'o4', mesto: 'Ostrava', castka: 640, stav: 'nova' },
  { id: 'o5', mesto: 'Praha', castka: 1790, stav: 'nova' },
];

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}

/**
 * Pustí `fn` nejvýš jednou za `limit` ms. První volání projde hned.
 * Debounce čeká na klid, throttle drží tempo.
 */
function throttle(fn, limit) {
  let naposledy = 0;
  return (...args) => {
    const ted = Date.now();
    if (ted - naposledy < limit) return;
    naposledy = ted;
    fn(...args);
  };
}

/**
 * Zavolá `fn` jen při prvním volání, další volání vrací uložený výsledek.
 * Příznak je oddělený od výsledku — jinak by funkce vracející 0 běžela pořád.
 */
function once(fn) {
  let hotovo = false;
  let vysledek;
  return (...args) => {
    if (!hotovo) {
      vysledek = fn(...args);
      hotovo = true;
    }
    return vysledek;
  };
}
```
