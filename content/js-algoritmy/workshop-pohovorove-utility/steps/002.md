# --description--

Debounce se hodí, když chceš počkat na konec. Při scrollování ale na konec čekat nejde —
potřebuješ průběžné hodnoty, jen ne šedesátkrát za vteřinu.

**Úkol:** Napiš `throttle(fn, limit)`. Vrácená funkce zavolá `fn` **hned** při prvním
volání a pak ji po dobu `limit` milisekund nezavolá znovu, ať se volá jakkoli často.
Po uplynutí okna další volání zase projde okamžitě.

Rozdíl proti debounce je v jedné větě: **debounce čeká na klid, throttle drží tempo.**

# --hints--

První volání projde hned, zbytek okna ne.

```js
let volani = 0;
const posun = throttle(() => { volani += 1; }, 50);
posun();
assert.equal(volani, 1, 'Throttle má první volání pustit okamžitě');
posun(); posun(); posun();
assert.equal(volani, 1, 'Další volání ve stejném okně se mají zahodit');
```

Po uplynutí okna projde další volání.

```js
let volani = 0;
const posun = throttle(() => { volani += 1; }, 40);
posun();
await helpers.wait(90);
posun();
assert.equal(volani, 2, 'Po uplynutí limitu má další volání projít');
```

`fn` dostane argumenty volání, které prošlo.

```js
const zaznam = [];
const posun = throttle((y) => zaznam.push(y), 40);
posun(0); posun(120); posun(340);
await helpers.wait(90);
posun(900);
assert.deepEqual(zaznam, [0, 900], 'Projít mají jen volání, která nespadla do okna');
```

Debounce z minulého kroku pořád funguje.

```js
let volani = 0;
const hledej = debounce(() => { volani += 1; }, 30);
hledej(); hledej();
await helpers.wait(90);
assert.equal(volani, 1, 'debounce z prvního kroku musí zůstat funkční');
```

# --help--

## --tip--

Nepotřebuješ časovač. Stačí si pamatovat, **kdy naposledy** funkce prošla, a porovnat
to s aktuálním časem.

## --tip--

Aktuální čas v milisekundách dá `Date.now()`. Na začátku nastav zapamatovaný čas tak,
aby první volání vždy prošlo.

## --tip--

Existuje i varianta, která na konci okna ještě dopustí poslední zahozené volání
(*trailing*). Tady stačí ta jednodušší, *leading*.

# --solution--

## --file-- script.js

```js
// utils.js — malá knihovna pomocných funkcí pro tým.
// Každá z nich se zároveň ptá na pohovorech: nejde o to je znát nazpaměť,
// ale umět je na místě odvodit a říct, kdy se hodí která.

// Ukázková data, na kterých si funkce zkoušíš.
const objednavky = [
  { id: 'o1', mesto: 'Brno', castka: 1290, stav: 'nova' },
  { id: 'o2', mesto: 'Praha', castka: 890, stav: 'odeslana' },
  { id: 'o3', mesto: 'Brno', castka: 2450, stav: 'odeslana' },
  { id: 'o4', mesto: 'Ostrava', castka: 640, stav: 'nova' },
  { id: 'o5', mesto: 'Praha', castka: 1790, stav: 'nova' },
];

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}

/**
 * Pustí `fn` nejvýš jednou za `limit` ms. První volání projde hned.
 * Debounce čeká na klid, throttle drží tempo.
 */
function throttle(fn, limit) {
  let naposledy = 0;
  return (...args) => {
    const ted = Date.now();
    if (ted - naposledy < limit) return;
    naposledy = ted;
    fn(...args);
  };
}
```
