# --description--

V týmu vzniká `utils.js` — hrstka funkcí, které v každém projektu píšete znovu. Začneš
tou nejpoužívanější: našeptávač nemá volat API po každém písmenu.

**Úkol:** Napiš `debounce(fn, delay)`. Vrátí novou funkci, která zavolá `fn` teprve
tehdy, když od posledního volání uplyne `delay` milisekund. Každé další volání
předchozí čekání zruší. `fn` dostane argumenty z **posledního** volání.

Tohle je uzávěr v čisté podobě: vrácená funkce si musí mezi voláními pamatovat
identifikátor svého časovače.

# --hints--

Rychlá série volání skončí jedním zavoláním.

```js
let volani = 0;
const hledej = debounce(() => { volani += 1; }, 40);
hledej(); hledej(); hledej();
assert.equal(volani, 0, 'Debounce nesmí zavolat fn hned při volání');
await helpers.wait(120);
assert.equal(volani, 1, 'Po odmlce se má fn zavolat právě jednou');
```

Projdou argumenty posledního volání.

```js
const zaznam = [];
const hledej = debounce((text) => zaznam.push(text), 30);
hledej('k'); hledej('ka'); hledej('kav');
await helpers.wait(100);
assert.deepEqual(zaznam, ['kav'], 'fn má dostat argumenty posledního volání');
```

Po odmlce začíná nové okno.

```js
let volani = 0;
const ulozit = debounce(() => { volani += 1; }, 30);
ulozit();
await helpers.wait(80);
ulozit();
await helpers.wait(80);
assert.equal(volani, 2, 'Dvě volání oddělená odmlkou jsou dvě zavolání fn');
```

# --help--

## --tip--

Vrácená funkce potřebuje proměnnou, která přežije mezi voláními. Taková proměnná se
deklaruje **vně** vrácené funkce, ale uvnitř `debounce`.

## --tip--

`setTimeout` vrací identifikátor, kterým se dá čekání zrušit přes `clearTimeout`.
Začni tedy každé volání zrušením toho předchozího.

## --tip--

Stejný vzor u ukládání rozepsaného textu:

```js
const ulozKoncept = debounce(() => odesliNaServer(pole.value), 800);
pole.addEventListener('input', ulozKoncept);
```

## --file-- script.js

```js
// utils.js — malá knihovna pomocných funkcí pro tým.
// Každá z nich se zároveň ptá na pohovorech: nejde o to je znát nazpaměť,
// ale umět je na místě odvodit a říct, kdy se hodí která.

// Ukázková data, na kterých si funkce zkoušíš.
const objednavky = [
  { id: 'o1', mesto: 'Brno', castka: 1290, stav: 'nova' },
  { id: 'o2', mesto: 'Praha', castka: 890, stav: 'odeslana' },
  { id: 'o3', mesto: 'Brno', castka: 2450, stav: 'odeslana' },
  { id: 'o4', mesto: 'Ostrava', castka: 640, stav: 'nova' },
  { id: 'o5', mesto: 'Praha', castka: 1790, stav: 'nova' },
];

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}
```
