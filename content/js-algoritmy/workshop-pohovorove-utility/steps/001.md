<--description-->
Napiš funkci `debounce`, která zpomalí volání jiné funkce. Zavolá ji až poté, co po stanovený čas (ms) nebyla volána.
</--description-->
<--hints-->
Musíš vrátit funkci, která si pamatuje timeout.
```js
// pseudo test pro debounce
assert.equal(true, true, 'debounce funguje');
```
</--hints-->
<--help-->
## --tip--
Ulož si ID timeoutu do proměnné (uzávěrka/closure) a v nové funkci použij `clearTimeout`.
</--help-->
<--seed-->
## --file-- script.js
```js
function debounce(fn, delay) {
--edit--
--edit--
}
```
</--seed-->
<--solution-->
## --file-- script.js
```js
function debounce(fn, delay) {
  let timeoutId;
  return function(...args) {
    clearTimeout(timeoutId);
    timeoutId = setTimeout(() => fn.apply(this, args), delay);
  };
}
```
