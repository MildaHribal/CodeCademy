# --description--

`{ ...objekt }` zkopíruje jen první úroveň. Vnořený objekt zůstane sdílený, takže změna
v kopii se projeví i v originále — klasická past, na kterou se na pohovorech ptá skoro
každý.

**Úkol:** Seřaď řádky tak, aby `deepClone(hodnota)` vrátila hlubokou kopii: primitivní
hodnoty vrátí beze změny, `Date` jako nové datum, pole i objekty zkopíruje po prvcích
do nových. Odsazení nastavíš klávesou Tab, dva řádky jsou navíc a jedna mezera se
doplňuje.

Rekurze tu má obvyklý tvar: **základní případ** (co už se dál rozebírat nedá) a **krok**
(rozeber o úroveň níž a zavolej sám sebe).

# --hints--

Primitivní hodnoty se vrací beze změny.

```js
assert.equal(deepClone(42), 42, 'Číslo se vrací beze změny');
assert.equal(deepClone('káva'), 'káva', 'Řetězec se vrací beze změny');
assert.equal(deepClone(null), null, 'null je primitivní hodnota, typeof null je ale "object" — na to pozor');
assert.equal(deepClone(undefined), undefined, 'undefined se vrací beze změny');
```

Vnořený objekt je opravdu nový.

```js
const original = { mesto: 'Brno', doruceni: { ulice: 'Lipová', psc: '60200' } };
const kopie = deepClone(original);
assert.deepEqual(kopie, original, 'Kopie má mít stejný obsah');
assert.notEqual(kopie.doruceni, original.doruceni, 'Vnořený objekt musí být nový, ne sdílený');
kopie.doruceni.psc = '11000';
assert.equal(original.doruceni.psc, '60200', 'Změna v kopii nesmí sáhnout na originál');
```

Pole i data se kopírují správně.

```js
const original = { polozky: [{ id: 1 }, { id: 2 }], vytvoreno: new Date('2026-03-01T10:00:00Z') };
const kopie = deepClone(original);
assert.ok(Array.isArray(kopie.polozky), 'Pole má zůstat polem');
assert.notEqual(kopie.polozky[0], original.polozky[0], 'Objekty v poli musí být nové');
assert.ok(kopie.vytvoreno instanceof Date, 'Date má zůstat datem, ne prázdným objektem');
assert.equal(kopie.vytvoreno.getTime(), original.vytvoreno.getTime(), 'Datum má mít stejnou hodnotu');
assert.notEqual(kopie.vytvoreno, original.vytvoreno, 'Datum musí být nová instance');
```

Ukázková data se kopií nezmění.

```js
const kopie = deepClone(objednavky);
kopie[0].castka = 1;
assert.equal(objednavky[0].castka, 1290, 'Změna v kopii nesmí sáhnout na původní objednávky');
```

# --help--

## --tip--

Pořadí podmínek rozhoduje. Nejdřív musí odejít všechno, co **není** objekt —
až potom má smysl ptát se na `Date` a na pole.

## --tip--

`typeof null` je `'object'`, takže `null` projde první podmínkou jen tehdy, když ho
vyloučíš výslovně.

## --tip--

V moderním prohlížeči i v Node existuje `structuredClone(hodnota)`, které tohle umí
samo (a navíc zvládne cykly, `Map` i `Set`). Na pohovoru to zmiň — a pak stejně ukaž,
že to umíš napsat.

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}

/**
 * Pustí `fn` nejvýš jednou za `limit` ms. První volání projde hned.
 * Debounce čeká na klid, throttle drží tempo.
 */
function throttle(fn, limit) {
  let naposledy = 0;
  return (...args) => {
    const ted = Date.now();
    if (ted - naposledy < limit) return;
    naposledy = ted;
    fn(...args);
  };
}

/**
 * Zavolá `fn` jen při prvním volání, další volání vrací uložený výsledek.
 * Příznak je oddělený od výsledku — jinak by funkce vracející 0 běžela pořád.
 */
function once(fn) {
  let hotovo = false;
  let vysledek;
  return (...args) => {
    if (!hotovo) {
      vysledek = fn(...args);
      hotovo = true;
    }
    return vysledek;
  };
}

/**
 * Uloží výsledky `fn` podle klíče z `keyFn`.
 * Map + has se ptá na existenci záznamu, ne na jeho pravdivost.
 */
function memoize(fn, keyFn = (prvni) => prvni) {
  const cache = new Map();
  return (...args) => {
    const klic = keyFn(...args);
    if (!cache.has(klic)) cache.set(klic, fn(...args));
    return cache.get(klic);
  };
}

/**
 * Rozdělí položky do skupin podle klíče.
 * Map, ne objekt: klíč „constructor" ani „__proto__" pak nic nerozbije.
 */
function groupBy(items, keyFn) {
  const skupiny = new Map();
  for (const item of items) {
    const klic = keyFn(item);
    if (!skupiny.has(klic)) skupiny.set(klic, []);
    skupiny.get(klic).push(item);
  }
  return skupiny;
}

# --parsons--

```js
function deepClone(hodnota) {
  if (hodnota === null || typeof hodnota !== 'object') return hodnota;
  if (hodnota instanceof Date) return new Date(hodnota);
  if (Array.isArray(hodnota)) return hodnota.map(__1__);
  const kopie = {};
  for (const [klic, vnorena] of Object.entries(hodnota)) {
    kopie[klic] = deepClone(vnorena);
  }
  return kopie;
}
```
