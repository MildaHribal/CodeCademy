# --description--

Stejný vstup, stejný výsledek — a přesto se počítá pořád dokola. To je přesně situace
pro mezipaměť.

**Úkol:** Napiš `memoize(fn, keyFn)`. Vrácená funkce spočítá výsledek jen pro vstup,
který ještě neviděla, a uloží si ho. `keyFn(...args)` vyrobí klíč mezipaměti; když ho
nedostaneš, použij první argument.

Klíč musí být hodnota, kterou lze porovnat — proto se u víc argumentů obvykle skládá
řetězec, třeba `` `${mesto}|${stav}` ``.

# --hints--

Stejný vstup se počítá jen jednou.

```js
let volani = 0;
const druha = memoize((n) => { volani += 1; return n * n; });
assert.equal(druha(12), 144, 'Výsledek musí být správný');
assert.equal(druha(12), 144, 'Opakovaný vstup vrátí uložený výsledek');
assert.equal(volani, 1, 'Pro stejný vstup se fn volá jen jednou');
assert.equal(druha(5), 25, 'Nový vstup se spočítá');
assert.equal(volani, 2, 'Nový vstup znamená nové zavolání fn');
```

Vlastní `keyFn` umí složit klíč z víc argumentů.

```js
let volani = 0;
const filtr = memoize(
  (mesto, stav) => { volani += 1; return objednavky.filter((o) => o.mesto === mesto && o.stav === stav); },
  (mesto, stav) => `${mesto}|${stav}`,
);
assert.equal(filtr('Brno', 'odeslana').length, 1, 'Brno + odeslaná je jedna objednávka');
filtr('Brno', 'odeslana');
assert.equal(volani, 1, 'Stejná dvojice argumentů se počítá jen jednou');
assert.equal(filtr('Praha', 'nova').length, 1, 'Praha + nová je jedna objednávka');
assert.equal(volani, 2, 'Jiná dvojice argumentů je jiný klíč');
```

Uložit se musí i nepravdivý výsledek.

```js
let volani = 0;
const nula = memoize(() => { volani += 1; return 0; }, () => 'stejny-klic');
nula(); nula(); nula();
assert.equal(volani, 1, 'Výsledek 0 se má uložit stejně jako každý jiný');
```

# --help--

## --tip--

Na mezipaměť se hodí `Map` — umí libovolné klíče a má `has`, které se ptá na existenci
záznamu, ne na jeho pravdivost. Viz
[Map: slovník s libovolnými klíči](see:js-tridy-kolekce/map-a-set#map-slovnik-s-libovolnymi-klici).

## --tip--

Výchozí hodnotu parametru napíšeš rovnou v hlavičce funkce. Pro klíč z prvního
argumentu se hodí funkce, která ze svých argumentů vrátí ten první.

## --tip--

Mezipaměť v paměti roste donekonečna. V produkci se proto omezuje počtem záznamů
(LRU) nebo časem platnosti — tady to neřeš, ale na pohovoru to zmínit umíš.

## --file-- script.js

```js
// utils.js — malá knihovna pomocných funkcí pro tým.
// Každá z nich se zároveň ptá na pohovorech: nejde o to je znát nazpaměť,
// ale umět je na místě odvodit a říct, kdy se hodí která.

// Ukázková data, na kterých si funkce zkoušíš.
const objednavky = [
  { id: 'o1', mesto: 'Brno', castka: 1290, stav: 'nova' },
  { id: 'o2', mesto: 'Praha', castka: 890, stav: 'odeslana' },
  { id: 'o3', mesto: 'Brno', castka: 2450, stav: 'odeslana' },
  { id: 'o4', mesto: 'Ostrava', castka: 640, stav: 'nova' },
  { id: 'o5', mesto: 'Praha', castka: 1790, stav: 'nova' },
];

/**
 * Zavolá `fn` až po `delay` ms bez dalšího volání.
 * Vrácená funkce si v uzávěru pamatuje běžící časovač.
 */
function debounce(fn, delay) {
  let cekani;
  return (...args) => {
    clearTimeout(cekani);
    cekani = setTimeout(() => fn(...args), delay);
  };
}

/**
 * Pustí `fn` nejvýš jednou za `limit` ms. První volání projde hned.
 * Debounce čeká na klid, throttle drží tempo.
 */
function throttle(fn, limit) {
  let naposledy = 0;
  return (...args) => {
    const ted = Date.now();
    if (ted - naposledy < limit) return;
    naposledy = ted;
    fn(...args);
  };
}

/**
 * Zavolá `fn` jen při prvním volání, další volání vrací uložený výsledek.
 * Příznak je oddělený od výsledku — jinak by funkce vracející 0 běžela pořád.
 */
function once(fn) {
  let hotovo = false;
  let vysledek;
  return (...args) => {
    if (!hotovo) {
      vysledek = fn(...args);
      hotovo = true;
    }
    return vysledek;
  };
}

/**
 * Uloží výsledky `fn` podle klíče z `keyFn`.
 * Map + has se ptá na existenci záznamu, ne na jeho pravdivost.
 */
function memoize(fn, keyFn = (prvni) => prvni) {
  const cache = new Map();
  return (...args) => {
    const klic = keyFn(...args);
    if (!cache.has(klic)) cache.set(klic, fn(...args));
    return cache.get(klic);
  };
}
```
