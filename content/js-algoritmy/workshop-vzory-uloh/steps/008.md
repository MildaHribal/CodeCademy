# --description--

Šéf chce vědět, kolik se vydělalo v nejlepší třídenní sérii — kvůli plánování akcí. Naivní řešení by pro každý začátek sečetlo tři hodnoty znovu; ty použiješ [[klouzavé okno]] a každou hodnotu sečteš jen jednou.

**Úkol:** Seřaď řádky tak, aby `bestWindow(sales, size)` vrátila nejvyšší součet `size` po sobě jdoucích hodnot. Když je hodnot míň než `size`, vrátí `0`.

Do mezery doplň, o kolik pozic zpátky sahá hodnota, která z okna vypadla. Dva řádky jsou navíc.

# --hints--

`bestWindow` najde nejlepší třídenní součet.

```js
assert.equal(bestWindow(dailySales, 3), 46600, 'bestWindow(dailySales, 3) má vrátit 46600 — součet posledních tří dnů');
```

Okno přes všechna data je součet všeho.

```js
assert.equal(bestWindow(dailySales, 7), 91300, 'bestWindow(dailySales, 7) má vrátit 91300 — součet celého týdne');
```

Když je hodnot míň než šířka okna, vrátí `bestWindow` nulu.

```js
assert.equal(bestWindow([100, 200], 3), 0, 'bestWindow([100, 200], 3) má vrátit 0, protože třídenní okno se do dat nevejde');
```

Okno šířky jedna najde největší hodnotu.

```js
assert.equal(bestWindow(dailySales, 1), 18900, 'bestWindow(dailySales, 1) má vrátit 18900 — nejsilnější jednotlivý den');
```

## --tip--

Posun okna má dvě části: přičti hodnotu, která do okna vstoupila, a odečti tu, která z něj vypadla. Ta druhá leží o šířku okna zpátky.

# --parsons--

```js
function bestWindow(sales, size) {
  if (sales.length < size) return 0;
  let sum = 0;
  for (let i = 0; i < size; i++) sum += sales[i];
  let best = sum;
  for (let i = size; i < sales.length; i++) {
    sum = sum + sales[i] - sales[i - __1__];
    if (sum > best) best = sum;
  }
  return best;
}
```

## --distractors--

```js
sum = sum + sales[i];
best = best + sales[i];
```
