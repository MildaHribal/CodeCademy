# --description--

Přehled začne tím nejjednodušším číslem, které po tobě šéf bude chtít: kolik **různých** lidí web navštívilo. V záznamech je jeden člověk klidně pětkrát, takže `views.length` odpověď nedává.

**Úkol:** Napiš funkci `uniqueVisitorCount(records)`, která vrátí počet různých hodnot `visitorId` v záznamech. U prázdného pole vrátí `0`.

Tohle už umíš z dřívějška, proto teď žádný návod nedostaneš. Až budeš hotový, mrkni do konzole — hodnota se dá vypsat přes `console.log(uniqueVisitorCount(views))`.

# --hints--

`uniqueVisitorCount` vrátí počet různých návštěvníků.

```js
assert.equal(uniqueVisitorCount(views), 4, 'uniqueVisitorCount(views) má vrátit 4 — v záznamech jsou u7, u3, u9 a u1');
```

Opakovaná návštěva téhož člověka se počítá jednou.

```js
const repeated = [
  { visitorId: 'a', path: '/x', seconds: 1 },
  { visitorId: 'a', path: '/y', seconds: 2 },
  { visitorId: 'a', path: '/z', seconds: 3 },
];
assert.equal(uniqueVisitorCount(repeated), 1, 'uniqueVisitorCount() se třemi zobrazeními od jednoho člověka má vrátit 1');
```

Pro prázdné pole vrátí `uniqueVisitorCount` nulu.

```js
assert.equal(uniqueVisitorCount([]), 0, 'uniqueVisitorCount([]) má vrátit 0');
```

# --help--

## --tip--

Potřebuješ strukturu, která si každou hodnotu pamatuje jen jednou — viz [Set: každá hodnota jednou](see:js-tridy-kolekce/map-a-set#set-kazda-hodnota-jednou).

## --tip--

Počet uložených hodnot se u téhle struktury nečte přes `length`, ale přes jinou vlastnost. Najdeš ji v MDN u `Set`.

# --solution--

## --file-- script.js

```js
// Záznamy o zobrazení stránek z malého e-shopu s čajem a kávou.
// Jeden řádek = jedno zobrazení, seconds = čas strávený na stránce.
const views = [
  { visitorId: 'u7', path: '/kosik', seconds: 42 },
  { visitorId: 'u3', path: '/produkt/kava', seconds: 118 },
  { visitorId: 'u7', path: '/produkt/kava', seconds: 35 },
  { visitorId: 'u9', path: '/kosik', seconds: 12 },
  { visitorId: 'u3', path: '/kontakt', seconds: 64 },
  { visitorId: 'u7', path: '/kosik', seconds: 27 },
  { visitorId: 'u1', path: '/produkt/caj', seconds: 205 },
];

// Tržby za posledních sedm dní, v korunách.
const dailySales = [12400, 9800, 15300, 7200, 18900, 11100, 16600];

// Ceník, vzestupně seřazený. Dárkové poukázky se skládají ze dvou položek.
const sortedPrices = [49, 129, 249, 349, 499, 899, 1290];

// Kolik různých návštěvníků je v záznamech.
function uniqueVisitorCount(records) {
  const ids = new Set();
  for (const record of records) {
    ids.add(record.visitorId);
  }
  return ids.size;
}
```
