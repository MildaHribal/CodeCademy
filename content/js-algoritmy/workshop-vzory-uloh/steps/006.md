# --description--

## Hlášení

Kolega z marketingu si k přehledu přidal vlastní funkci `viewsByVisitor(records)`, která má spočítat, kolik stránek si který návštěvník prohlédl. Čekal `{ u7: 3, u3: 2, u9: 1, u1: 1 }`, ale v konzoli má u každého člověka `NaN`. Funkce nespadne, jen vrací nesmysly.

## Úkol

Oprav `viewsByVisitor` tak, aby vracela správné počty. Změň co nejmenší kus kódu — celou funkci nepřepisuj.

# --hints--

`viewsByVisitor` vrátí počty zobrazení podle návštěvníka.

```js
assert.deepEqual(viewsByVisitor(views), { u7: 3, u3: 2, u9: 1, u1: 1 }, 'viewsByVisitor(views) má vrátit { u7: 3, u3: 2, u9: 1, u1: 1 }');
```

Pro prázdné pole vrátí `viewsByVisitor` objekt bez klíčů.

```js
const empty = viewsByVisitor([]);
assert.deepEqual(Object.keys(empty), [], 'viewsByVisitor([]) má vrátit objekt bez klíčů');
```

Zbytek přehledu funguje dál.

```js
assert.equal(viewsByPath(views).get('/kosik'), 3, 'viewsByPath(views) má po opravě pořád vracet 3 zobrazení košíku');
assert.equal(topPath(viewsByPath(views)), '/kosik', 'topPath() má po opravě pořád vracet /kosik');
```

# --help--

## --tip--

Pusť si funkci v konzoli a podívej se, u které hodnoty `NaN` poprvé vznikne — viz [Frekvenční mapa](see:js-algoritmy/datove-struktury#frekvencni-mapa-nejcastejsi-vzor-z-pohovoru).

## --tip--

Když klíč v objektu ještě není, čtení vrátí `undefined`. Přičtení jedničky k `undefined` dá `NaN` a od té chvíle už se to nespraví.
