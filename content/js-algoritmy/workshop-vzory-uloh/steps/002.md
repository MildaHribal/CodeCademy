# --description--

Druhé číslo do přehledu je celkový čas: součet všech `seconds`. Z něj se pak spočítá průměr na návštěvníka.

**Úkol:** Napiš funkci `totalSeconds(records)`, která vrátí součet hodnot `seconds`. U prázdného pole vrátí `0` a vstupní pole nechá beze změny.

Zase bez návodu — tohle je vzor, který jsi psal v sekci o polích.

# --hints--

`totalSeconds` sečte vteřiny ze všech záznamů.

```js
assert.equal(totalSeconds(views), 503, 'totalSeconds(views) má vrátit 503 — součet všech hodnot seconds');
```

Pro prázdné pole vrátí `totalSeconds` nulu.

```js
assert.equal(totalSeconds([]), 0, 'totalSeconds([]) má vrátit 0, ne chybu');
```

Vstupní pole zůstane beze změny.

```js
const input = [{ visitorId: 'a', path: '/x', seconds: 5 }];
totalSeconds(input);
assert.equal(input.length, 1, 'totalSeconds() nesmí ze vstupního pole nic odebrat');
assert.equal(input[0].seconds, 5, 'totalSeconds() nesmí měnit hodnoty ve vstupních datech');
```

# --solution--

## --file-- script.js

```js
// Záznamy o zobrazení stránek z malého e-shopu s čajem a kávou.
// Jeden řádek = jedno zobrazení, seconds = čas strávený na stránce.
const views = [
  { visitorId: 'u7', path: '/kosik', seconds: 42 },
  { visitorId: 'u3', path: '/produkt/kava', seconds: 118 },
  { visitorId: 'u7', path: '/produkt/kava', seconds: 35 },
  { visitorId: 'u9', path: '/kosik', seconds: 12 },
  { visitorId: 'u3', path: '/kontakt', seconds: 64 },
  { visitorId: 'u7', path: '/kosik', seconds: 27 },
  { visitorId: 'u1', path: '/produkt/caj', seconds: 205 },
];

// Tržby za posledních sedm dní, v korunách.
const dailySales = [12400, 9800, 15300, 7200, 18900, 11100, 16600];

// Ceník, vzestupně seřazený. Dárkové poukázky se skládají ze dvou položek.
const sortedPrices = [49, 129, 249, 349, 499, 899, 1290];

// Kolik různých návštěvníků je v záznamech.
function uniqueVisitorCount(records) {
  const ids = new Set();
  for (const record of records) {
    ids.add(record.visitorId);
  }
  return ids.size;
}

// Součet všech vteřin strávených na webu.
function totalSeconds(records) {
  return records.reduce((total, record) => total + record.seconds, 0);
}
```
