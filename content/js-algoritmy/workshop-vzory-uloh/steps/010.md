# --description--

E-shop chystá dárkové poukázky a v košíku má být hláška „za tuhle poukázku si můžeš koupit dvě položky přesně". Ceník `sortedPrices` je vzestupně seřazený, což je přesně ta podmínka, za které se dvojice hledá jedním průchodem.

**Úkol:** Napiš funkci `hasPairWithSum(sortedValues, target)`, která vrátí `true`, když ve vzestupně seřazeném poli existují **dvě různé položky** se součtem `target`. Jinak vrátí `false`.

Hrubá síla by zkusila všechny dvojice. Použij [[dva ukazatele]]: jeden na začátku, druhý na konci, a podle toho, jestli je součet moc malý nebo moc velký, posuň ten správný.

# --hints--

`hasPairWithSum` najde dvojici z prostředka ceníku.

```js
assert.equal(hasPairWithSum(sortedPrices, 598), true, 'hasPairWithSum(sortedPrices, 598) má vrátit true — 249 + 349 je 598');
```

Najde i dvojici z obou konců ceníku.

```js
assert.equal(hasPairWithSum(sortedPrices, 1339), true, 'hasPairWithSum(sortedPrices, 1339) má vrátit true — 49 + 1290 je 1339');
```

Když dvojice neexistuje, vrátí `hasPairWithSum` hodnotu `false`.

```js
assert.equal(hasPairWithSum(sortedPrices, 100), false, 'hasPairWithSum(sortedPrices, 100) má vrátit false — takový součet z ceníku nesložíš');
```

Jedna položka se nesmí použít dvakrát.

```js
assert.equal(hasPairWithSum([50], 100), false, 'hasPairWithSum([50], 100) má vrátit false — jedna položka se nesmí spárovat sama se sebou');
assert.equal(hasPairWithSum([], 0), false, 'hasPairWithSum([], 0) má vrátit false');
```

## --tip--

Cyklus běží, dokud se ukazatele nepotkají. Rovnost mezi nimi znamená jedinou položku, a ta se párovat nesmí.

## --tip--

Na jiných datech: hledání dvou termínů, které dohromady dají osm hodin, funguje úplně stejně — seřazené délky, jeden ukazatel zleva, druhý zprava.

// Existuje ve vzestupně seřazeném poli dvojice různých položek se součtem target?
function hasPairWithSum(sortedValues, target) {
  let left = 0;
  let right = sortedValues.length - 1;
  while (left < right) {
    const sum = sortedValues[left] + sortedValues[right];
    if (sum === target) return true;
    if (sum < target) left++;
    else right--;
  }
  return false;
}
