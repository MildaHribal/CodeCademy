# --description--

Marketing má seznam id zákazníků z věrnostního programu a chce vidět jen jejich pohyb po webu. V ostrých datech je záznamů třicet tisíc a VIP zákazníků dva tisíce, takže na tom, jak se hledá, hodně záleží.

**Úkol:** Napiš funkci `vipViews(records, vipIds)`, která vrátí **nové pole** záznamů, jejichž `visitorId` je v poli `vipIds`. Vstupní pole nechá beze změny.

Nejjednodušší zápis by uvnitř průchodu hledal v poli `vipIds`, a to je přesně ta [[kvadratická složitost]], o které byla řeč. Hodí se ti `Array.prototype.includes`, `Set` s metodou `has`, nebo `Map` — vyber, co hledání zrychlí, a postav to **před** cyklem, ne uvnitř.

# --hints--

`vipViews` vrátí jen zobrazení od VIP návštěvníků.

```js
assert.equal(vipViews(views, ['u3', 'u1']).length, 3, 'vipViews(views, [\'u3\', \'u1\']) má vrátit 3 záznamy — dva od u3 a jeden od u1');
```

Ve výsledku jsou opravdu záznamy těch správných lidí.

```js
const result = vipViews(views, ['u9']);
assert.equal(result.length, 1, 'vipViews(views, [\'u9\']) má vrátit jediný záznam');
assert.equal(result[0].path, '/kosik', 'jediný záznam návštěvníka u9 je zobrazení /kosik');
```

Prázdný seznam VIP znamená prázdný výsledek.

```js
assert.deepEqual(vipViews(views, []), [], 'vipViews(views, []) má vrátit prázdné pole');
```

Vstupní pole zůstane beze změny.

```js
const before = views.length;
vipViews(views, ['u7']);
assert.equal(views.length, before, 'vipViews() nesmí ze vstupního pole nic odebrat');
```

function viewsByVisitor(records) {
  const counts = {};
  for (const record of records) {
    counts[record.visitorId] = (counts[record.visitorId] ?? 0) + 1;
  }
  return counts;
}

// Zobrazení od návštěvníků, kteří jsou ve věrnostním programu.
function vipViews(records, vipIds) {
  const vip = new Set(vipIds);
  return records.filter((record) => vip.has(record.visitorId));
}
