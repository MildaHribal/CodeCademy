# --description--

Mapu počtů máš, teď z ní potřebuješ vítěze — cestu s nejvyšším číslem. Hledání maxima v mapě je druhá půlka vzoru s frekvenční mapou a na pohovoru přijde hned po ní.

**Úkol:** Seřaď řádky tak, aby `topPath(counts)` vrátila cestu s nejvyšším počtem. Pro prázdnou mapu vrátí `null`.

Tenhle vzor teď jen skládáš; o dva kroky dál napíšeš podobný sám. Odsazení nastavíš klávesou Tab, do mezery doplň počáteční hodnotu nejlepšího počtu. Dva řádky jsou navíc — odpovídají typickým chybám.

# --hints--

`topPath` vrátí nejčastější cestu.

```js
assert.equal(topPath(viewsByPath(views)), '/kosik', 'topPath(viewsByPath(views)) má vrátit /kosik — ta má tři zobrazení');
```

Pro prázdnou mapu vrátí `topPath` hodnotu `null`.

```js
assert.equal(topPath(new Map()), null, 'topPath(new Map()) má vrátit null, protože žádná cesta neexistuje');
```

Při shodě počtů vyhraje ta cesta, která je v mapě dřív.

```js
const tie = new Map([['/a', 2], ['/b', 2]]);
assert.equal(topPath(tie), '/a', 'topPath() má při shodném počtu vrátit dřívější klíč, tedy /a');
```

# --help--

## --tip--

Hledání maxima je jeden průchod, při kterém si pamatuješ dosud nejlepší výsledek — viz [Frekvenční mapa](see:js-algoritmy/datove-struktury#frekvencni-mapa-nejcastejsi-vzor-z-pohovoru).

## --tip--

Mapa se dá procházet přes `for…of` a každá položka je dvojice, kterou jde rovnou rozbalit do dvou proměnných.

# --parsons--

```js
function topPath(counts) {
  let bestPath = null;
  let bestCount = __1__;
  for (const [path, count] of counts) {
    if (count > bestCount) {
      bestPath = path;
      bestCount = count;
    }
  }
  return bestPath;
}
```

## --distractors--

```js
return bestCount;
bestPath = count;
```

// Kolikrát se která stránka zobrazila. Klíč = cesta, hodnota = počet.
function viewsByPath(records) {
  const counts = new Map();
  for (const record of records) {
    counts.set(record.path, (counts.get(record.path) ?? 0) + 1);
  }
  return counts;
