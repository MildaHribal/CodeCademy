# --description--

Stejná mapa počtů odpoví i na opačnou otázku: které stránky mají jediné zobrazení. To jsou kandidáti na smazání nebo na lepší odkazy v navigaci.

**Úkol:** Napiš funkci `onlyOnce(counts)`, která z mapy počtů vrátí **pole cest**, jejichž počet je přesně `1`. Pořadí zachovej podle mapy, u prázdné mapy vrať prázdné pole.

Stejný průchod mapou jako u hledání vítěze, jen místo porovnávání sbíráš. Na jiných datech vypadá sbírání takhle:

```js
// 1. Připrav si pole na výsledky.
const singleUse = [];

// 2. Do pole přidej jen to, co splní podmínku.
for (const [coupon, used] of couponUsage) {
  if (used === 1) singleUse.push(coupon);
}
```

# --hints--

`onlyOnce` vrátí cesty s jediným zobrazením.

```js
assert.deepEqual(onlyOnce(viewsByPath(views)), ['/kontakt', '/produkt/caj'], 'onlyOnce(viewsByPath(views)) má vrátit [\'/kontakt\', \'/produkt/caj\']');
```

Cesty s víc než jedním zobrazením se do výsledku nedostanou.

```js
const counts = new Map([['/a', 1], ['/b', 5], ['/c', 1]]);
assert.deepEqual(onlyOnce(counts), ['/a', '/c'], 'onlyOnce() má vynechat /b, které má pět zobrazení');
```

Pro prázdnou mapu vrátí `onlyOnce` prázdné pole.

```js
assert.deepEqual(onlyOnce(new Map()), [], 'onlyOnce(new Map()) má vrátit prázdné pole');
```

# --help--

## --tip--

Je to jeden průchod mapou s podmínkou — stejný tvar, jaký jsi skládal u hledání vítěze.

## --tip--

Mapa vrací dvojice klíč a hodnota. Do výsledku patří jen klíč, hodnota rozhoduje o tom, jestli se přidá.

# --explain--

Proč se počty zobrazení sbírají do `Map` a ne do obyčejného objektu? Zkus popsat, kdy se rozdíl doopravdy projeví.

## --model--

Obyčejný objekt dědí vlastnosti z prototypu, takže klíč jako `constructor` nebo `toString` se tváří, že v datech už je, a počítání se rozbije. Mapa žádné zděděné klíče nemá. Navíc objekt převádí všechny klíče na text, takže se mu smíchá číslo `1` s textem `'1'`, zatímco mapa typ klíče zachová. U cest to nevadí, ale u dat od uživatele nebo u číselných id to rozbije výsledek.

## --checklist--

- Objekt má zděděné klíče z prototypu, mapa ne.
- Objekt převádí klíče na text, mapa typ zachovává.
- Projeví se to až na datech, která obsahují taková jména nebo čísla.
