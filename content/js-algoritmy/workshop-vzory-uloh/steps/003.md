# --description--

Teď přijde jádro celého přehledu: kolikrát se která stránka zobrazila. Z toho pak půjde vyčíst nejnavštěvovanější stránka i stránky, na které nikdo nechodí.

**Úkol:** Napiš funkci `viewsByPath(records)`, která vrátí `Map`, kde klíč je `path` a hodnota počet jeho výskytů.

Je to [[frekvenční mapa]] — vzor, který v úlohách na pohovoru potkáš nejčastěji ze všech. Na jiných datech (objednávky podle města) vypadá takhle:

```js
// 1. Připrav prázdnou mapu počtů.
const perCity = new Map();

// 2. U každé položky zvyš počet o jedna.
for (const order of orders) {
  const current = perCity.get(order.city) ?? 0;
  perCity.set(order.city, current + 1);
}
```

`?? 0` je tam proto, že při prvním výskytu klíče vrátí `get` hodnotu `undefined` — a `undefined + 1` je `NaN`.

# --hints--

`viewsByPath` vrátí `Map`.

```js
assert.ok(viewsByPath(views) instanceof Map, 'viewsByPath(views) má vrátit Map, ne obyčejný objekt ani pole');
```

Počet zobrazení stránky `/kosik` je 3.

```js
assert.equal(viewsByPath(views).get('/kosik'), 3, 'viewsByPath(views).get(\'/kosik\') má vrátit 3 — košík je v datech třikrát');
```

V mapě je tolik klíčů, kolik je různých stránek.

```js
assert.equal(viewsByPath(views).size, 4, 'viewsByPath(views).size má být 4 — tolik různých cest v datech je');
```

Pro prázdné pole vrátí `viewsByPath` prázdnou mapu.

```js
const empty = viewsByPath([]);
assert.ok(empty instanceof Map, 'viewsByPath([]) má vrátit Map');
assert.equal(empty.size, 0, 'viewsByPath([]) má vrátit mapu bez klíčů');
```

## --tip--

Jde o frekvenční mapu — viz [Frekvenční mapa](see:js-algoritmy/datove-struktury#frekvencni-mapa-nejcastejsi-vzor-z-pohovoru).

## --tip--

Postupuj po dvou podcílech: 1. založ prázdnou mapu před cyklem, 2. v cyklu přepiš hodnotu u klíče na „co tam je, nebo nula, plus jedna".

## --tip--

Na jiných datech: počty hodnocení podle hvězdiček se sbírají stejně — klíčem je počet hvězdiček, hodnotou počet recenzí.

# --solution--

## --file-- script.js

```js
// Záznamy o zobrazení stránek z malého e-shopu s čajem a kávou.
// Jeden řádek = jedno zobrazení, seconds = čas strávený na stránce.
const views = [
  { visitorId: 'u7', path: '/kosik', seconds: 42 },
  { visitorId: 'u3', path: '/produkt/kava', seconds: 118 },
  { visitorId: 'u7', path: '/produkt/kava', seconds: 35 },
  { visitorId: 'u9', path: '/kosik', seconds: 12 },
  { visitorId: 'u3', path: '/kontakt', seconds: 64 },
  { visitorId: 'u7', path: '/kosik', seconds: 27 },
  { visitorId: 'u1', path: '/produkt/caj', seconds: 205 },
];

// Tržby za posledních sedm dní, v korunách.
const dailySales = [12400, 9800, 15300, 7200, 18900, 11100, 16600];

// Ceník, vzestupně seřazený. Dárkové poukázky se skládají ze dvou položek.
const sortedPrices = [49, 129, 249, 349, 499, 899, 1290];

// Kolik různých návštěvníků je v záznamech.
function uniqueVisitorCount(records) {
  const ids = new Set();
  for (const record of records) {
    ids.add(record.visitorId);
  }
  return ids.size;
}

// Součet všech vteřin strávených na webu.
function totalSeconds(records) {
  return records.reduce((total, record) => total + record.seconds, 0);
}

// Kolikrát se která stránka zobrazila. Klíč = cesta, hodnota = počet.
function viewsByPath(records) {
  const counts = new Map();
  for (const record of records) {
    counts.set(record.path, (counts.get(record.path) ?? 0) + 1);
  }
  return counts;
}
```
