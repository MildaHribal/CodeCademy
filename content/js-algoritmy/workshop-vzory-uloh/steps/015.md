# --description--

Poslední krok udělá z čísel něco, co jde poslat do chatu: pět řádků textu. Až to spustíš, uvidíš celý přehled v konzoli pod editorem.

**Úkol:** Napiš funkci `buildReportLines(records, sales)`, která vrátí **pole pěti řádků** textu se shrnutím. Na řádcích musí být počet návštěvníků, počet zobrazení, celkový čas, nejčastější cesta a nejlepší třídenní tržba. Formulace jsou na tobě.

Pod funkci přidej cyklus, který každý řádek vypíše přes `console.log`, ať je report vidět hned po spuštění.

## Udělej po svém

Tenhle přehled je kostra, na které se dá stavět dál. Vyber si jedno rozšíření a dopiš ho bez testů:

- Přidej do shrnutí průměrný čas na zobrazení a zaokrouhli ho na celé vteřiny.
- Doplň řádek „stránky k zamyšlení" ze seznamu cest s jediným zobrazením.
- Nahraď data vlastními: záznamy z herního serveru, návštěvy v posilovně, poslechy podcastu. Funkce zůstanou stejné, změní se jen jména klíčů.
- Seřaď výpis podle počtu zobrazení sestupně a přidej pořadí před každou cestu.

Příště si stejné vzory napíšeš sám nad jinou doménou — v labu s deseti klasickými úlohami z pohovorů.

# --hints--

`buildReportLines` vrátí pět řádků.

```js
const lines = buildReportLines(views, dailySales);
assert.ok(Array.isArray(lines), 'buildReportLines() má vrátit pole');
assert.equal(lines.length, 5, 'buildReportLines() má vrátit pět řádků reportu');
```

V reportu jsou všechna čísla ze shrnutí.

```js
const text = buildReportLines(views, dailySales).join('\n');
assert.match(text, /4/, 'v reportu má být počet návštěvníků 4');
assert.match(text, /503/, 'v reportu má být celkový čas 503');
assert.match(text, /46600/, 'v reportu má být nejlepší třídenní tržba 46600');
```

V reportu je nejčastější cesta.

```js
const text = buildReportLines(views, dailySales).join('\n');
assert.match(text, /\/kosik/, 'v reportu má být nejčastější cesta /kosik');
```

Report se po spuštění vypíše do konzole.

```js
assert.ok(logs.length >= 5, 'po spuštění skriptu má být v konzoli aspoň pět řádků reportu');
```

# --help--

## --tip--

Hodnoty neskládej znovu — vezmi je z hotového shrnutí, které vrací objekt s pěti klíči.

## --tip--

Text s vloženou hodnotou se píše šablonovým řetězcem ve zpětných apostrofech, do kterého se hodnota vloží zápisem s dolarem a složenými závorkami.

## --tip--

Výpis pole po řádcích je obyčejný `for…of` cyklus nad výsledkem funkce.

// Záznamy o zobrazení stránek z malého e-shopu s čajem a kávou.
// Jeden řádek = jedno zobrazení, seconds = čas strávený na stránce.
const views = [
  { visitorId: 'u7', path: '/kosik', seconds: 42 },
  { visitorId: 'u3', path: '/produkt/kava', seconds: 118 },

  { visitorId: 'u3', path: '/kontakt', seconds: 64 },
  { visitorId: 'u7', path: '/kosik', seconds: 27 },
  { visitorId: 'u1', path: '/produkt/caj', seconds: 205 },
];

// Tržby za posledních sedm dní, v korunách.
const dailySales = [12400, 9800, 15300, 7200, 18900, 11100, 16600];

// Ceník, vzestupně seřazený. Dárkové poukázky se skládají ze dvou položek.
const sortedPrices = [49, 129, 249, 349, 499, 899, 1290];

// Kolik různých návštěvníků je v záznamech.
function uniqueVisitorCount(records) {
  const ids = new Set();
  for (const record of records) {
    ids.add(record.visitorId);
  }
  return ids.size;
}

// Součet všech vteřin strávených na webu.
function totalSeconds(records) {
  return records.reduce((total, record) => total + record.seconds, 0);
}

// Kolikrát se která stránka zobrazila. Klíč = cesta, hodnota = počet.
function viewsByPath(records) {
  const counts = new Map();
  for (const record of records) {
    counts.set(record.path, (counts.get(record.path) ?? 0) + 1);
  }
  return counts;
}

function topPath(counts) {
  let bestPath = null;
  let bestCount = 0;
  for (const [path, count] of counts) {
    if (count > bestCount) {
      bestPath = path;
      bestCount = count;
    }
  }
  return bestPath;
}

// Cesty, které se v záznamech objevily právě jednou.
function onlyOnce(counts) {
  const paths = [];
  for (const [path, count] of counts) {
    if (count === 1) {
      paths.push(path);
    }
  }
  return paths;
}

// Kolik stránek si který návštěvník prohlédl. Napsal kolega z marketingu.
function viewsByVisitor(records) {
  const counts = {};
  for (const record of records) {
    counts[record.visitorId] = (counts[record.visitorId] ?? 0) + 1;
  }
  return counts;
}

// Zobrazení od návštěvníků, kteří jsou ve věrnostním programu.
function vipViews(records, vipIds) {
  const vip = new Set(vipIds);
  return records.filter((record) => vip.has(record.visitorId));
}

function bestWindow(sales, size) {
  if (sales.length < size) return 0;
  let sum = 0;
  for (let i = 0; i < size; i++) sum += sales[i];
  let best = sum;
  for (let i = size; i < sales.length; i++) {
    sum = sum + sales[i] - sales[i - size];
    if (sum > best) best = sum;
  }
  return best;
}

// Index dne, kterým začíná nejlepší okno délky size. -1, když se okno nevejde.
function bestWindowStart(sales, size) {
  if (sales.length < size) return -1;
  let sum = 0;
  for (let i = 0; i < size; i++) sum += sales[i];
  let best = sum;
  let bestStart = 0;
  for (let i = size; i < sales.length; i++) {
    sum = sum + sales[i] - sales[i - size];
    if (sum > best) {
      best = sum;
      bestStart = i - size + 1;
    }
  }
  return bestStart;
}

// Existuje ve vzestupně seřazeném poli dvojice různých položek se součtem target?
function hasPairWithSum(sortedValues, target) {
  let left = 0;
  let right = sortedValues.length - 1;
  while (left < right) {
    const sum = sortedValues[left] + sortedValues[right];
    if (sum === target) return true;
    if (sum < target) left++;
    else right--;
  }
  return false;
}

// Záznam s nejdelším časem na stránce, u prázdných dat null.
function longestVisit(records) {
  let best = null;
  for (const record of records) {
    if (best === null || record.seconds > best.seconds) {
      best = record;
    }
  }
  return best;
}

// Různé cesty ze záznamů, seřazené podle české abecedy.
function uniquePathsSorted(records) {
  const paths = new Set();
  for (const record of records) {
    paths.add(record.path);
  }
  return [...paths].sort((a, b) => a.localeCompare(b, 'cs'));
}

// Dvojice hodnot se součtem target, od menší k větší. Vstup je vzestupně seřazený.
function pairForVoucher(sortedValues, target) {
  let left = 0;
  let right = sortedValues.length - 1;
  while (left < right) {
    const sum = sortedValues[left] + sortedValues[right];
    if (sum === target) return [sortedValues[left], sortedValues[right]];
    if (sum < target) left++;
    else right--;
  }
  return null;
}

// Shrnutí pro poradu, složené z hotových funkcí.
function trafficSummary(records, sales) {
  return {
    visitors: uniqueVisitorCount(records),
    views: records.length,
    seconds: totalSeconds(records),
    topPath: topPath(viewsByPath(records)),
    bestThreeDays: bestWindow(sales, 3),
  };
}
