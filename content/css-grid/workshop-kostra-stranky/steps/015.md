# --description--

## Hlášení

Kolega přidal na konec `styles.css` media dotaz pro monitory od `80rem` (1280 px): vpravo se má ukázat fronta `.queue` ve sloupci širokém `18rem`, hlavička a přehrávač mají vést přes všechny tři sloupce.

Na okně širokém 1400 px to ale vypadá takhle: vpravo od obsahu zůstává prázdný pruh široký skoro 600 px, hlavička i přehrávač končí 824 px od levého okraje a fronta se objevila až úplně dole v pravém rohu, níž než přehrávač. Chybová hláška nikde.

## Úkol

Najdi, proč prohlížeč kolegovu šablonu oblastí nepoužil, a oprav ji. Změň co nejmenší kus kódu.

> [!TIP]
> Testy měří na šířce 1400 px, takovou šířku přepínač náhledu nemá. Otevři náhled tlačítkem „Nová karta" a podívej se v DevTools do panelu Styles na pravidlo `.app` uvnitř media dotazu.

# --hints--

Na šířce 1400 px je fronta vpravo vedle obsahu, pod hlavičkou, široká 288 px.

```js
await helpers.resize(1400);
const header = document.querySelector('.app-header').getBoundingClientRect();
const main = document.querySelector('.main').getBoundingClientRect();
const queue = document.querySelector('.queue').getBoundingClientRect();
assert.ok(Math.abs(queue.width - 288) <= 1, `Na šířce 1400 px je fronta široká ${Math.round(queue.width)} px, čekám 288 px`);
assert.ok(queue.left >= main.right - 1 && Math.abs(queue.top - header.bottom) <= 1, `Na šířce 1400 px má fronta stát vpravo vedle obsahu hned pod hlavičkou (začíná na ${Math.round(queue.left)} × ${Math.round(queue.top)} px)`);
```

Na šířce 1400 px vedou hlavička i přehrávač přes celou šířku okna.

```js
await helpers.resize(1400);
const width = document.documentElement.clientWidth;
for (const selector of ['.app-header', '.player']) {
  const rect = document.querySelector(selector).getBoundingClientRect();
  assert.ok(Math.abs(rect.width - width) <= 1, `Na šířce 1400 px je ${selector} široký ${Math.round(rect.width)} px, okno ${width} px`);
}
```

Na šířce 1024 px fronta vidět není a obsah vede až k pravému okraji.

```js
const queue = document.querySelector('.queue').getBoundingClientRect();
const main = document.querySelector('.main').getBoundingClientRect();
assert.equal(queue.width, 0, 'Na šířce 1024 px nemá být fronta vidět (šířka 0)');
assert.ok(Math.abs(main.right - document.documentElement.clientWidth) <= 1, `Na šířce 1024 px končí obsah na ${Math.round(main.right)} px`);
```

# --help--

## --tip--

Když prohlížeč šablonu oblastí tiše ignoruje, bývá neplatná. Podmínky platné šablony najdeš v části [Pojmenované oblasti](see:css-grid/uvod-do-gridu#pojmenovane-oblasti-grid-template-areas).

## --tip--

Spočítej buňky v každém řetězci kolegovy šablony. Neplatná deklarace se zahodí celá a dál platí šablona z hlavního pravidla `.app`, která frontu nezná.

# --explain--

Vysvětli vlastními slovy, proč se po kolegově úpravě nezobrazila žádná chyba a proč hlavička nevedla přes celou šířku.

## --model--

Kolegova šablona měla v posledním řetězci jen dvě buňky, zatímco ostatní tři, a taková šablona je neplatná. CSS neplatnou deklaraci bez hlášky zahodí celou, takže dál platila šablona z hlavního pravidla `.app` se dvěma sloupci oblastí. Sloupce se ale změnily na tři, a hlavička i přehrávač tak zabraly jen první dva. Fronta neměla svou oblast, a proto ji grid dal do automaticky přidaného sloupce a řádku na konci mřížky.

## --checklist--

- Všechny řetězce šablony musí mít stejný počet buněk.
- Neplatnou deklaraci prohlížeč bez hlášky zahodí celou.
- Po zahození platí předchozí hodnota z kaskády.
- Položka s názvem oblasti, která neexistuje, skončí v automaticky přidaných stopách.
