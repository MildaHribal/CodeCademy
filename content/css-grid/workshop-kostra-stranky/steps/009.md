# --description--

Obsah `.main` má po stranách `padding` 2rem. Blok epizody s barevným přechodem proto končí 2rem před okraji a vypadá jako vlepená karta. Moderní weby dávají barevný pás přes celou šířku a text nechávají zarovnaný s ostatním obsahem.

Na to se hodí [[čára mřížky|čáry]] s vlastními jmény. Jméno napíšeš do hranatých závorek mezi stopy a pak na něj odkazuješ v `grid-column`. Čáry `název-start` a `název-end` spolu tvoří oblast, takže `grid-column: název` znamená „od `název-start` do `název-end`".

**Úkol:**

- `.main` bude grid se třemi sloupci: krajní po `2rem` místo bočního paddingu a mezi nimi obsah. Čáry pojmenuj `full-start`, `content-start`, `content-end` a `full-end`. Padding nech jen dole (`3rem`).
- Všechny přímé potomky `.main` pošli do `content`.
- Blok `.hero` pošli do `full`.

Kandidáti na zápisy: `padding-block-end`, `grid-column` a selektor přímých potomků `.main > *`. Šablonu sloupců sestav podle příkladu na jiných datech — fotogalerie, kde fotka může přesahovat text:

```css
.article {
  display: grid;
  grid-template-columns: [wide-start] 1rem [text-start] 1fr [text-end] 1rem [wide-end];
}
```

> [!TIP]
> Tady máš hotovou kostru na počítači. Jestli potřebuješ, dej si pauzu — další kroky řeší telefon, přehrávač a dvě chyby od kolegy.

# --hints--

Blok epizody `.hero` sahá od levého do pravého okraje obsahu.

```js
const main = document.querySelector('.main');
const box = main.getBoundingClientRect();
const hero = document.querySelector('.hero').getBoundingClientRect();
assert.ok(Math.abs(hero.left - box.left) <= 1, `Blok epizody začíná na ${Math.round(hero.left)} px, obsah na ${Math.round(box.left)} px`);
assert.ok(Math.abs(hero.right - (box.left + main.clientWidth)) <= 1, `Blok epizody končí na ${Math.round(hero.right)} px, obsah na ${Math.round(box.left + main.clientWidth)} px`);
```

Nadpisy a obsah ostatních sekcí zůstávají 32 px od levého i pravého okraje obsahu.

```js
const main = document.querySelector('.main');
const box = main.getBoundingClientRect();
for (const section of main.querySelectorAll('.continue, .episodes, .similar')) {
  const rect = section.getBoundingClientRect();
  assert.ok(Math.abs(rect.left - box.left - 32) <= 1, `Sekce .${section.className} začíná ${Math.round(rect.left - box.left)} px od okraje obsahu, čekám 32 px`);
  assert.ok(Math.abs(box.left + main.clientWidth - rect.right - 32) <= 1, `Sekce .${section.className} končí ${Math.round(box.left + main.clientWidth - rect.right)} px před okrajem obsahu, čekám 32 px`);
}
```

Text epizody začíná na stejné svislé čáře jako nadpisy ostatních sekcí.

```js
const cover = document.querySelector('.hero__cover').getBoundingClientRect();
const title = document.querySelector('#continue-title').getBoundingClientRect();
assert.ok(Math.abs(cover.left - title.left) <= 1, `Obal epizody začíná na ${Math.round(cover.left)} px, nadpis „Pokračuj v poslechu" na ${Math.round(title.left)} px`);
```

Obsah `.main` používá pojmenované čáry `content` a `full`.

```js
const css = helpers.stripComments(files['styles.css'], 'css');
assert.match(css, /\[\s*content-start\s*\]/, 'Šablona sloupců .main má obsahovat čáru [content-start]');
assert.match(css, /\[\s*full-start\s*\]/, 'Šablona sloupců .main má obsahovat čáru [full-start]');
assert.match(css, /grid-column\s*:\s*full(-start\s*\/\s*full-end)?\s*[;}]/, 'Blok epizody se má do celé šířky dostat přes grid-column: full');
```

# --help--

## --tip--

Umístění podle čar a `span` vysvětluje část [Umístění podle čar](see:css-grid/uvod-do-gridu#umisteni-podle-car-grid-column-grid-row-a-span). Pojmenovaná čára funguje stejně jako číslo, jen se neposune, když přidáš sloupec.

## --tip--

Šablona patří do pravidla `.main` spolu s `display: grid`; boční padding tam nahradí krajní sloupce. `grid-column` s jménem `content` dej pravidlu pro přímé potomky, `full` pravidlu `.hero`, které je v souboru níž a má přednost.

## --tip--

V článku z příkladu by fotka přes celou šířku dostala `grid-column: wide` a odstavce `grid-column: text`.
