# --description--

Obal epizody `.hero__cover` je čtverec s číslem 147, které trčí v levém horním rohu.

**Úkol:** vycentruj číslo v obalu vodorovně i svisle. Do pravidla `.hero__cover` přidej `display: grid` a `place-items: center`.

Obal se tím stane grid kontejnerem s jedinou buňkou přes celý čtverec. `place-items` je zkratka pro `align-items` (svisle) a `justify-items` (vodorovně), s jednou hodnotou platí pro obě osy. Text uvnitř je taky položka, takže se vycentruje.

Stejný vzor na jiných datech — iniciály v kulatém odznaku:

```css
.initials {
  display: grid;
  place-items: center;
  inline-size: 3rem;
  aspect-ratio: 1;
}
```

# --hints--

Číslo je v obalu vodorovně uprostřed.

```js
const cover = document.querySelector('.hero__cover');
const box = cover.getBoundingClientRect();
const range = document.createRange();
range.selectNodeContents(cover);
const text = range.getBoundingClientRect();
const offset = (text.left + text.width / 2) - (box.left + box.width / 2);
assert.ok(Math.abs(offset) <= 1.5, `Střed čísla je vodorovně ${offset.toFixed(1)} px od středu obalu`);
```

Číslo je v obalu svisle uprostřed.

```js
const cover = document.querySelector('.hero__cover');

```
