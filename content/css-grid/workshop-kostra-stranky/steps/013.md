# --description--

Přepni náhled na **375**. Tři sloupce přehrávače jsou na telefonu tak úzké, že název skladby zmizí za třemi tečkami skoro celý.

Na telefonu chceme dva řádky: nahoře vlevo skladba a vpravo ovládání jen tak široké, jak potřebuje, pod nimi časová osa přes celou šířku. Posuvník hlasitosti na telefonu schováme, hlasitost se tam ovládá tlačítky.

**Úkol:** v existujícím media dotazu pro telefon nakresli přehrávači nové oblasti a sloupce a hlasitost schovej. Stejný postup jako u kostry aplikace o dva kroky dřív.

# --hints--

Na šířce 375 px je skladba vlevo a ovládání vpravo ve stejném řádku.

```js
await helpers.resize(375);
const player = document.querySelector('.player');
const style = getComputedStyle(player);
const contentRight = player.getBoundingClientRect().right - parseFloat(style.paddingRight);
const track = document.querySelector('.player__track').getBoundingClientRect();
const controls = document.querySelector('.player__controls').getBoundingClientRect();
assert.ok(controls.left >= track.right - 1 && controls.top < track.bottom, 'Na šířce 375 px má být ovládání vpravo vedle skladby');
assert.ok(Math.abs(controls.right - contentRight) <= 1, `Na šířce 375 px končí ovládání na ${Math.round(controls.right)} px, obsah přehrávače na ${Math.round(contentRight)} px`);
```

Na šířce 375 px je ovládání jen tak široké jako jeho tlačítka.

```js
await helpers.resize(375);
const controls = document.querySelector('.player__controls');
const buttons = [...controls.querySelectorAll('button')].map((button) => button.getBoundingClientRect());
const width = controls.getBoundingClientRect().width;
const content = buttons.at(-1).right - buttons[0].left;
assert.ok(width <= content + 1, `Na šířce 375 px je ovládání široké ${Math.round(width)} px, tlačítka zaberou ${Math.round(content)} px`);
```

Na šířce 375 px je časová osa pod skladbou přes celou šířku přehrávače a hlasitost není vidět.

```js
await helpers.resize(375);
const player = document.querySelector('.player');
const style = getComputedStyle(player);
const inner = player.clientWidth - parseFloat(style.paddingLeft) - parseFloat(style.paddingRight);
const track = document.querySelector('.player__track').getBoundingClientRect();
const progress = document.querySelector('.player__progress').getBoundingClientRect();
assert.ok(progress.top >= track.bottom - 1, 'Na šířce 375 px má být časová osa pod skladbou');
assert.ok(Math.abs(progress.width - inner) <= 1, `Na šířce 375 px je časová osa široká ${Math.round(progress.width)} px, přehrávač má uvnitř ${Math.round(inner)} px`);
assert.equal(document.querySelector('.player__volume').getBoundingClientRect().width, 0, 'Na šířce 375 px nemá být hlasitost vidět (šířka 0)');
```

Na šířce 375 px nejde stránka posouvat do strany a na šířce 1024 px zůstává hlasitost vpravo.

```js
await helpers.resize(375);
assert.ok(document.documentElement.scrollWidth <= document.documentElement.clientWidth, `Na šířce 375 px je dokument široký ${document.documentElement.scrollWidth} px`);
await helpers.resize(1024);
const volume = document.querySelector('.player__volume').getBoundingClientRect();
assert.ok(volume.width > 0 && volume.left > 700, 'Na šířce 1024 px má hlasitost zůstat vidět vpravo');
```

# --help--

## --tip--

Jde o nové nakreslení oblastí v media dotazu, stejně jako u kostry v kroku [Kostra na telefonu](see:css-grid/workshop-kostra-stranky/011).

## --tip--

Pravidlo `.player` a pravidlo hlasitosti patří dovnitř bloku `@media`, za pravidlo `.app`. Sloupec podle obsahu je `auto`; u sloupce se skladbou nezapomeň na minimum, název se nezalamuje.

## --tip--

Hlavička e-mailu z minulého kroku by na telefonu měla nahoře avatar a jméno, vpravo datum a pod nimi předmět přes celou šířku — dvě slova v prvním řetězci, jedno dvakrát ve druhém.
