# --description--

## Hlášení

Kolega upravil šablonu `.prints`, aby „karty vždycky vyplnily celý řádek". S plnou nabídkou to vypadá stejně jako předtím. Když ale zákazník vybere filtr, po kterém zbude jediný plakát, je karta přes celou šířku stránky (976 px) a obrázek plakátu je vysoký skoro 1 200 px — na notebooku se nevejde ani na dvě obrazovky.

Filtry zatím jen vypadají, zkus to v DevTools: plakátům kromě jednoho nastav `display: none`.

## Úkol

Oprav šablonu tak, aby osamělý plakát zůstal stejně široký jako v plném řádku. Změň co nejmenší kus kódu.

Testy kontrolují i šířku 320 px, kterou přepínač náhledu nemá; na **375** uvidíš skoro totéž.

# --hints--

Když je vidět jediný plakát, je široký jako jeden sloupec plné nabídky.

```js
const card = document.querySelector('.print:nth-child(2)');
const fullWidth = card.getBoundingClientRect().width;
document.querySelectorAll('.prints > li').forEach((item) => {
  if (item !== card) item.style.display = 'none';
});
const alone = card.getBoundingClientRect().width;
assert.ok(Math.abs(alone - fullWidth) <= 1, `S plnou nabídkou je plakát široký ${Math.round(fullWidth)} px, osamělý ${Math.round(alone)} px`);
```

S plnou nabídkou jsou na šířce 1024 px tři sloupce a doporučený plakát vede přes dva.

```js
const columns = getComputedStyle(document.querySelector('.prints')).gridTemplateColumns.split(' ').map(parseFloat);
assert.equal(columns.length, 3, `Na šířce 1024 px čekám tři sloupce, mřížka má ${columns.length}`);
const featured = document.querySelector('.print--featured').getBoundingClientRect();
assert.ok(Math.abs(featured.width - (columns[0] + columns[1] + 24)) <= 1, 'Doporučený plakát má dál vést přes dva sloupce');
```

Na šířce 320 px nejde stránka posouvat do strany.

```js
await helpers.resize(320);
const root = document.documentElement;
assert.ok(root.scrollWidth <= root.clientWidth, `Na šířce 320 px je obsah široký ${root.scrollWidth} px, okno ${root.clientWidth} px`);
```

# --help--

## --tip--

Rozdíl mezi dvěma klíčovými slovy v `repeat()` se ukáže, jen když je položek míň, než kolik se vejde sloupců. Viz [auto-fill, nebo auto-fit](see:css-grid/mrizka-bez-media-queries#auto-fill-nebo-auto-fit).

## --tip--

Podívej se na první argument `repeat()` v pravidle `.prints` a na to, co dělá s prázdnými sloupci.

# --explain--

Vysvětli vlastními slovy, proč se kolegova změna projevila až po filtru a proč je pro výpis produktů lepší `auto-fill`.

## --model--

`auto-fit` i `auto-fill` spočítají sloupce stejně, liší se jen v prázdných sloupcích. S plnou nabídkou žádné prázdné nejsou, a tak obě vypadají stejně. Když zbude jeden plakát, `auto-fit` prázdné sloupce sbalí a karta s `1fr` si vezme celou šířku. `auto-fill` prázdné sloupce nechá, takže karta zůstane široká jako v plném řádku, což u výpisu s měnícím se počtem položek chceme.

## --checklist--

- `auto-fill` a `auto-fit` počítají počet sloupců stejně.
- Rozdíl je jen u prázdných sloupců, když je položek málo.
- `auto-fit` prázdné sloupce sbalí a položky roztáhne.
- Pro výpis s proměnlivým počtem položek se hodí `auto-fill`.
