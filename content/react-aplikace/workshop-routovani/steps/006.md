# --description--

Hlavička s názvem půjčovny je teď jen v katalogu. Na detailu kola není nic, čeho
by se uživatel chytil. To vyřeší **layout**: komponenta, kterou vykreslí
rodičovská trasa a která má v sobě díru na obsah vnořené trasy.

**Úkol:** Seřaď řádky tak, aby `Layout` vrátil obal se záhlavím a s místem pro
vnořenou trasu. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc.

V mezeře `__1__` má být jméno komponenty, která označí místo pro vnořenou trasu.

Náhled se po tomhle kroku nezmění — layout teprve vznikl a v dalším kroku ho
zapojíš do tras.

const { default: Layout } = await helpers.importFile('Layout.jsx');

const misto = document.createElement('div');
document.body.append(misto);
createRoot(misto).render(createElement(MemoryRouter, {}, createElement(Layout)));

assert.ok(misto.querySelector('.hlavicka'), 'Layout má vykreslit <header className="hlavicka">');
assert.match(misto.querySelector('.hlavicka').textContent, /Půjčovna Na Kolech/, 'v záhlaví má být název půjčovny v nadpisu');
misto.remove();
```

import { Link } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Katalog() {
  return (
    <main className="obal">
      <h1>Půjčovna Na Kolech</h1>
      <p className="podnadpis">Kola na den, na víkend nebo na celý týden.</p>
      <ul className="katalog">
        {kola.map((kolo) => (
          <li key={kolo.id}>
            <Link className="karta" to={'/kola/' + kolo.id}>
              <h2>{kolo.nazev}</h2>
              <p className="typ">{popisekTypu(kolo.typ)}</p>
              <p className="cena">{kolo.cenaDen} Kč / den</p>
            </Link>
          </li>
        ))}
      </ul>
    </main>
  );
}
```

```jsx
import { Link, useParams } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Detail() {
  const { id } = useParams();
  const kolo = kola.find((polozka) => polozka.id === Number(id));

  if (!kolo) {
    return (
      <article className="detail">
        <h1>Tohle kolo nemáme</h1>
        <p>Kolo číslo {id} v katalogu není. Možná už ho někdo vyřadil.</p>
        <Link className="zpet" to="/">← Zpět na katalog</Link>
      </article>
    );
  }

  return (
    <article className="detail">
      <h1>{kolo.nazev}</h1>
      <p className="typ">{popisekTypu(kolo.typ)}</p>
      <p>{kolo.popis}</p>
      <dl>
        <dt>Rám</dt>
        <dd>{kolo.ram}</dd>
        <dt>Hmotnost</dt>
        <dd>{kolo.hmotnost} kg</dd>
      </dl>
      <p className="cena-velka">{kolo.cenaDen} Kč / den</p>
      <Link className="zpet" to="/">← Zpět na katalog</Link>
    </article>
  );
}
```
