# --description--

Layout máš, teď ho postav nad všechny stránky. V seedu je navíc nová stránka
`Pujcovna.jsx` s otevírací dobou a kontaktem.

**Úkol:**

1. V `Trasy.jsx` obal všechny trasy jednou rodičovskou trasou `path="/"`
   s `element={<Layout />}`. Katalog bude její **index** trasa, detail dostane
   cestu `kola/:id` a nová stránka o půjčovně cestu `pujcovna`.
2. V `Katalog.jsx` zruš `<main className="obal">`, nadpis a podnadpis — záhlaví
   teď kreslí layout. Komponenta vrátí rovnou `<ul className="katalog">`.

Cesty vnořených tras se píšou **bez lomítka na začátku**: skládají se k cestě
rodiče.

Po tomhle kroku uvidíš záhlaví i na detailu kola — a přesně o to jde.

# --hints--

Katalog je pořád na adrese `/` a kreslí se uvnitř layoutu.

```js
assert.ok(document.querySelector('.hlavicka'), 'na adrese / má být vidět záhlaví z layoutu');
assert.equal(document.querySelectorAll('.katalog li').length, 8, 'na adrese / má být pod záhlavím katalog — použij index trasu');
```

Záhlaví zůstane i na detailu kola a hlavička se v katalogu neopakuje dvakrát.

```js
await helpers.click(document.querySelectorAll('.katalog a')[0]);
await helpers.flush();
assert.ok(document.querySelector('.hlavicka'), 'na detailu kola má zůstat záhlaví z layoutu');
assert.ok(document.querySelector('.detail'), 'na detailu kola má být vidět detail');
assert.equal(document.querySelectorAll('h1').length, 2, 'na stránce mají být přesně dva nadpisy h1 — jeden v záhlaví a jeden v detailu; katalog už svůj nadpis kreslit nemá');
```

Stránka o půjčovně je na adrese `/pujcovna`, taky v layoutu.

```js
const { default: Trasy } = await helpers.importFile('Trasy.jsx');
const { MemoryRouter } = await import('react-router');
const { createElement } = await import('react');
const { createRoot } = await import('react-dom/client');
const misto = document.createElement('div');
document.body.append(misto);
createRoot(misto).render(createElement(MemoryRouter, { initialEntries: ['/pujcovna'] }, createElement(Trasy)));
await helpers.flush();
assert.match(misto.textContent, /Veslařská 12/, 'na adrese /pujcovna má být vidět stránka Pujcovna s adresou půjčovny');
assert.ok(misto.querySelector('.hlavicka'), 'i stránka o půjčovně má být uvnitř layoutu');
misto.remove();
```

# --help--

## --tip--

Jde o vnořené trasy a `Outlet` — viz [Vnořený layout a Outlet](see:react-aplikace/routovani#vnoreny-layout-a-outlet).

## --tip--

Rodičovská trasa má `element` s layoutem a potomky zapsané mezi otevírací
a zavírací značkou. Trasa pro adresu rodiče samotného se pozná podle `index`.

## --tip--

Na jiné aplikaci: trasa `/ucet` by vykreslila layout účtu a mezi jejími potomky
by byla index trasa s přehledem a trasa `platby` s výpisem plateb. Cesty
potomků se píšou bez lomítka na začátku.

# --explain--

Proč se společné záhlaví v routované aplikaci řeší vnořenou trasou a `Outlet`em,
a ne tím, že bych layout obalil kolem každé stránky zvlášť?

## --model--

Kdybych layout napsal do každé stránky, byl by na pěti místech stejný kód a při
každé změně bych musel projít všechny. Horší je, že by se při přechodu mezi
trasami celé záhlaví odmontovalo a namontovalo znovu — ztratil by se jeho stav
(rozbalená nabídka, pozice scrollu) a blikalo by to. Vnořená trasa říká
routeru, že rodič zůstává a mění se jen to, co je v `Outlet`u.

## --checklist--

- Layout je na jednom místě, ne zkopírovaný v každé stránce.
- Rodičovská trasa zůstane namontovaná, mění se jen obsah `Outlet`u.
- Díky tomu se neztrácí stav záhlaví ani pozice scrollu.
- `Outlet` označuje místo, kam router vnořenou trasu vykreslí.

```jsx
import { Link } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Katalog() {
  return (
    <main className="obal">
      <h1>Půjčovna Na Kolech</h1>
      <p className="podnadpis">Kola na den, na víkend nebo na celý týden.</p>
      <ul className="katalog">
        {kola.map((kolo) => (
          <li key={kolo.id}>
            <Link className="karta" to={'/kola/' + kolo.id}>
              <h2>{kolo.nazev}</h2>
              <p className="typ">{popisekTypu(kolo.typ)}</p>
              <p className="cena">{kolo.cenaDen} Kč / den</p>
            </Link>
          </li>
        ))}
      </ul>
    </main>
  );
}
```

```jsx
import { Link, useParams } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Detail() {
  const { id } = useParams();
  const kolo = kola.find((polozka) => polozka.id === Number(id));

  if (!kolo) {
    return (
      <article className="detail">
        <h1>Tohle kolo nemáme</h1>
        <p>Kolo číslo {id} v katalogu není. Možná už ho někdo vyřadil.</p>
        <Link className="zpet" to="/">← Zpět na katalog</Link>
      </article>
    );
  }

  return (
    <article className="detail">
      <h1>{kolo.nazev}</h1>
      <p className="typ">{popisekTypu(kolo.typ)}</p>
      <p>{kolo.popis}</p>
      <dl>
        <dt>Rám</dt>
        <dd>{kolo.ram}</dd>
        <dt>Hmotnost</dt>
        <dd>{kolo.hmotnost} kg</dd>
      </dl>
      <p className="cena-velka">{kolo.cenaDen} Kč / den</p>
      <Link className="zpet" to="/">← Zpět na katalog</Link>
    </article>
  );
}
```

```jsx
import { Routes, Route } from 'react-router';
import Layout from './Layout';
import Katalog from './Katalog';
import Detail from './Detail';
import Pujcovna from './Pujcovna';

export default function Trasy() {
  return (
    <Routes>
      <Route path="/" element={<Layout />}>
        <Route index element={<Katalog />} />
        <Route path="kola/:id" element={<Detail />} />
        <Route path="pujcovna" element={<Pujcovna />} />
      </Route>
    </Routes>
  );
}
```
