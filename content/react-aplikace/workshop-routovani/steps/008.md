# --description--

Stránka o půjčovně existuje, ale nikdo se na ni nedostane — chybí nabídka.
`NavLink` je `Link`, který navíc ví, jestli je jeho cíl právě otevřený, a sám si
přidá třídu `active`. Styl pro `.nabidka a.active` je v `styles.css` připravený.

**Úkol:** V `Layout.jsx` přidej do záhlaví pod nadpis prvek `nav` s třídou
`nabidka` a v něm dva odkazy: **Katalog** na `/` a **O půjčovně** na `/pujcovna`. Odkaz na `/`
potřebuje `end`, jinak zůstane zvýrazněný pořád.

Proč `end`? Bez něj je odkaz zvýrazněný i tehdy, když aktuální adresa cíl jen
**začíná** — a `/` je začátek úplně každé adresy.

# --hints--

V záhlaví je nabídka se dvěma odkazy.

```js
const odkazy = document.querySelectorAll('.hlavicka .nabidka a');
assert.equal(odkazy.length, 2, 'v záhlaví má být <nav className="nabidka"> se dvěma odkazy');
assert.match(odkazy[0].textContent, /Katalog/, 'první odkaz v nabídce má být Katalog');
assert.match(odkazy[1].getAttribute('href'), /\/pujcovna$/, 'druhý odkaz má vést na /pujcovna');
```

Kliknutí na „O půjčovně" přepne obsah pod záhlavím.

```js
const odkazy = document.querySelectorAll('.nabidka a');
await helpers.click(odkazy[1]);
await helpers.flush();
assert.match(document.body.textContent, /Veslařská 12/, 'po kliknutí na „O půjčovně" má být vidět stránka o půjčovně');
assert.equal(document.querySelectorAll('.katalog li').length, 0, 'katalog už na stránce o půjčovně vidět být nemá');
```

Zvýrazněný je vždycky jen ten odkaz, na jehož stránce uživatel je.

```js
const odkazy = document.querySelectorAll('.nabidka a');
assert.ok(odkazy[0].classList.contains('active'), 'na adrese / má mít odkaz Katalog třídu active — tu přidává NavLink sám');
assert.ok(!odkazy[1].classList.contains('active'), 'na adrese / nemá být zvýrazněný odkaz O půjčovně');
await helpers.click(odkazy[1]);
await helpers.flush();
const poKliknuti = document.querySelectorAll('.nabidka a');
assert.ok(poKliknuti[1].classList.contains('active'), 'na adrese /pujcovna má být zvýrazněný odkaz O půjčovně');
assert.ok(!poKliknuti[0].classList.contains('active'), 'na adrese /pujcovna už nemá být zvýrazněný Katalog — odkaz na / potřebuje end');
```

# --help--

## --tip--

Rozdíl mezi `Link` a `NavLink` je v [Odkazy: Link a NavLink](see:react-aplikace/routovani#odkazy-link-a-navlink).

## --tip--

Nabídka patří do `<header className="hlavicka">` pod nadpis. Odkaz na kořenovou
adresu potřebuje atribut, který vypne porovnávání podle předpony.

## --tip--

Jinde by nabídka vypadala takhle:

```jsx
<nav className="zalozky">
  <NavLink to="/blog" end>Články</NavLink>
  <NavLink to="/blog/archiv">Archiv</NavLink>
</nav>
```

## --file-- Detail.jsx

```jsx
import { Link, useParams } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Detail() {
  const { id } = useParams();
  const kolo = kola.find((polozka) => polozka.id === Number(id));

  if (!kolo) {
    return (
      <article className="detail">
        <h1>Tohle kolo nemáme</h1>
        <p>Kolo číslo {id} v katalogu není. Možná už ho někdo vyřadil.</p>
        <Link className="zpet" to="/">← Zpět na katalog</Link>
      </article>
    );
  }

  return (
    <article className="detail">
      <h1>{kolo.nazev}</h1>
      <p className="typ">{popisekTypu(kolo.typ)}</p>
      <p>{kolo.popis}</p>
      <dl>
        <dt>Rám</dt>
        <dd>{kolo.ram}</dd>
        <dt>Hmotnost</dt>
        <dd>{kolo.hmotnost} kg</dd>
      </dl>
      <p className="cena-velka">{kolo.cenaDen} Kč / den</p>
      <Link className="zpet" to="/">← Zpět na katalog</Link>
    </article>
  );
}
```
