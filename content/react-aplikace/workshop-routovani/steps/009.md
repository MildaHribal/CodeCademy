# --description--

Zkus si v hlavě adresu `/kola/42/recenze`. Žádná trasa ji nematchne, takže se
nevykreslí **nic** — uživatel uvidí prázdnou bílou plochu bez jediné chyby
v konzoli. To je jedna z nejhůř hledaných chyb v routovaných aplikacích.

V seedu je nový soubor `Nenalezeno.jsx` s hláškou a odkazem zpátky.

**Úkol:** V `Trasy.jsx` přidej jako poslední vnořenou trasu takovou, která
matchne jakoukoli adresu, kterou nechytila žádná trasa před ní, a vykreslí
`<Nenalezeno />`. Nech ji uvnitř layoutu, ať má uživatel pořád nabídku.

# --hints--

Neznámá adresa ukáže hlášku místo prázdné stránky.

```js
const { default: Trasy } = await helpers.importFile('Trasy.jsx');
const { MemoryRouter } = await import('react-router');
const { createElement } = await import('react');
const { createRoot } = await import('react-dom/client');
const misto = document.createElement('div');
document.body.append(misto);
createRoot(misto).render(createElement(MemoryRouter, { initialEntries: ['/kola/42/recenze'] }, createElement(Trasy)));
await helpers.flush();
assert.match(misto.textContent, /Taková stránka u nás není/, 'adresa /kola/42/recenze má spadnout na trasu pro neznámé adresy');
misto.remove();
```

Hláška je uvnitř layoutu, takže nabídka zůstane po ruce.

```js
const { default: Trasy } = await helpers.importFile('Trasy.jsx');

const { createRoot } = await import('react-dom/client');

document.body.append(misto);
createRoot(misto).render(createElement(MemoryRouter, { initialEntries: ['/uplne-jina-adresa'] }, createElement(Trasy)));
await helpers.flush();
assert.ok(misto.querySelector('.hlavicka'), 'stránka „nenalezeno" má být uvnitř layoutu, ať má uživatel pořád nabídku');

```

Trasy, které existovaly, fungují dál — nová trasa je nepřebila.

```js
const { default: Trasy } = await helpers.importFile('Trasy.jsx');

const { createElement } = await import('react');
const { createRoot } = await import('react-dom/client');
const misto = document.createElement('div');
document.body.append(misto);
createRoot(misto).render(createElement(MemoryRouter, { initialEntries: ['/pujcovna'] }, createElement(Trasy)));

assert.match(misto.textContent, /Veslařská 12/, 'adresa /pujcovna má dál ukazovat stránku o půjčovně');
assert.equal(misto.querySelector('.prazdno'), null, 'na známé adrese se nesmí ukázat hláška o neexistující stránce');

```

## --tip--

Past „zapomenutá trasa" je popsaná v [Typické chyby a pasti](see:react-aplikace/routovani#typicke-chyby-a-pasti).

## --tip--

Cesta takové trasy se nepíše jménem, ale jediným zástupným znakem. Pořadí
rozhoduje: dej ji jako poslední mezi potomky layoutu.

## --tip--

V jiné aplikaci by to vypadalo takhle:

```jsx
<Route path="*" element={<ChybejiciStranka />} />
```

```jsx
import { Link, useParams } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Detail() {
  const { id } = useParams();
  const kolo = kola.find((polozka) => polozka.id === Number(id));

  if (!kolo) {
    return (
      <article className="detail">
        <h1>Tohle kolo nemáme</h1>
        <p>Kolo číslo {id} v katalogu není. Možná už ho někdo vyřadil.</p>
        <Link className="zpet" to="/">← Zpět na katalog</Link>
      </article>
    );
  }

  return (
    <article className="detail">
      <h1>{kolo.nazev}</h1>
      <p className="typ">{popisekTypu(kolo.typ)}</p>
      <p>{kolo.popis}</p>
      <dl>
        <dt>Rám</dt>
        <dd>{kolo.ram}</dd>
        <dt>Hmotnost</dt>
        <dd>{kolo.hmotnost} kg</dd>
      </dl>
      <p className="cena-velka">{kolo.cenaDen} Kč / den</p>
      <Link className="zpet" to="/">← Zpět na katalog</Link>
    </article>
  );
}
```
