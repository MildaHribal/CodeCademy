# --description--

Půjčovna kol z Brna má osm kol a jednu stránku, kde je všechny ukazuje. Za
čtrnáct kroků z ní bude aplikace, ve které má každé kolo vlastní adresu, dá se
v ní filtrovat a odkaz na filtr jde poslat kamarádce.

Začneš tím, co už umíš z komponent a seznamů — bez návodu.

V `data.js` je pole `kola`. Každé kolo je objekt s klíči `id`, `nazev`, `typ`,
`cenaDen`, `ram`, `hmotnost` a `popis`. Funkce `popisekTypu('horske')` vrátí
lidský popisek `'Horská'`.

**Úkol:** V `Katalog.jsx` vypiš do `<ul className="katalog">` pro každé kolo
jednu položku `<li className="karta">` s názvem v `<h2>`, popiskem typu
v `<p className="typ">` a cenou v `<p className="cena">` ve tvaru `420 Kč / den`.

Stejný tvar na jiných datech vypadá takhle:

```jsx
<ul className="koncerty">
  {koncerty.map((koncert) => (
    <li key={koncert.id} className="listek">
      <h2>{koncert.kapela}</h2>
      <p className="misto">{nazevKlubu(koncert.klub)}</p>
    </li>
  ))}
</ul>
```

# --hints--

V katalogu je osm karet, pro každé kolo z pole `kola` jedna.

```js
const karty = document.querySelectorAll('.katalog li');
assert.equal(karty.length, 8, 'v seznamu .katalog má být 8 položek — pro každé kolo z pole kola jedna');
```

Na kartě je název kola, lidský popisek typu a cena za den.

```js
const prvni = document.querySelector('.katalog li');
assert.ok(prvni, 'v .katalog zatím není žádná položka');
assert.match(prvni.textContent, /Author Vertigo 29/, 'první karta má obsahovat název kola „Author Vertigo 29"');
assert.match(prvni.textContent, /Horská/, 'první karta má ukazovat popisek typu „Horská" — projdi typ přes popisekTypu');
assert.match(prvni.textContent, /420 Kč \/ den/, 'první karta má ukazovat cenu ve tvaru „420 Kč / den"');
```

Název kola je v nadpisu `<h2>`, ne v obyčejném odstavci.

```js
const nadpisy = document.querySelectorAll('.katalog li h2');
assert.equal(nadpisy.length, 8, 'každá karta má mít název kola v nadpisu <h2>');
assert.equal(nadpisy[3].textContent.trim(), 'Favorit Praha', 'čtvrtá karta má mít v <h2> název „Favorit Praha" — vypisuj kola v pořadí, v jakém jsou v poli');
```

Každá položka seznamu má `key`, takže React nic nevytýká.

```js
assert.ok(
  !logs.some((zapis) => /unique "key"/.test(zapis.text)),
  'React hlásí v konzoli chybějící key — každá položka vzniklá z map potřebuje key s id kola',
);
```
