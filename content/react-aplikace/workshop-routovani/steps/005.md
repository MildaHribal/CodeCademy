# --description--

Adresu píše uživatel, ne ty. `/kola/999` je úplně platná adresa — jen v datech
takové kolo není, takže `find` vrátí `undefined` a detail spadne na
`TypeError: Cannot read properties of undefined (reading 'nazev')`.

**Úkol:** V `Detail.jsx` přidej hned pod `find` podmínku pro případ, že se kolo
nenašlo: vrať `<article className="detail">` s nadpisem `Tohle kolo nemáme`,
větou, která zmíní číslo z adresy, a odkazem `<Link className="zpet" to="/">`
zpátky na katalog. Zbytek komponenty zůstane, jak je.

Je to **guard clause**: nejdřív odbav výjimečný případ a vrať se, pak teprve piš
běžnou větev.

```jsx
// stejný vzor, jiná data
if (!objednavka) {
  return <p>Objednávku s tímhle číslem nemáme.</p>;
}
```

# --help--

## --tip--

Jde o past „parametry z adresy jsou text a mohou být cokoli" —
viz [Typické chyby a pasti](see:react-aplikace/routovani#typicke-chyby-a-pasti).

## --tip--

Podmínka patří mezi `find` a `return` s běžným JSX. Když se nic nenašlo, `find`
vrátí `undefined`, což je nepravdivá hodnota.

## --tip--

Číslo z adresy máš v proměnné z `useParams` — vypiš ho do textu ve složených
závorkách, stejně jako vypisuješ cenu.

# --explain--

Proč se detail musí bránit sám, i když trasa `/kola/:id` v aplikaci existuje?

## --model--

Trasa se rozhoduje jen podle **tvaru** adresy: `/kola/999` má dvě části, takže
`/kola/:id` matchne a router detail vykreslí. O tom, jestli takové kolo v datech
existuje, router nic neví — to zjistí až `find` uvnitř komponenty. Adresu navíc
píše uživatel, může tam být i `/kola/abc`. Proto je podmínka „nenašlo se" součást
komponenty, ne routeru.

## --checklist--

- Trasa se matchuje podle tvaru adresy, ne podle dat.
- Parametr z adresy může být jakýkoli text, i nesmysl.
- `find` vrátí `undefined`, když nic nesedí.
- Komponenta musí případ „nenašlo se" ošetřit sama.

## --file-- Detail.jsx

```jsx
import { Link, useParams } from 'react-router';
import { kola, popisekTypu } from './data';

export default function Detail() {
  const { id } = useParams();
  const kolo = kola.find((polozka) => polozka.id === Number(id));

  if (!kolo) {
    return (
      <article className="detail">
        <h1>Tohle kolo nemáme</h1>
        <p>Kolo číslo {id} v katalogu není. Možná už ho někdo vyřadil.</p>
        <Link className="zpet" to="/">← Zpět na katalog</Link>
      </article>
    );
  }

  return (
    <article className="detail">
      <h1>{kolo.nazev}</h1>
      <p className="typ">{popisekTypu(kolo.typ)}</p>
      <p>{kolo.popis}</p>
      <dl>
        <dt>Rám</dt>
        <dd>{kolo.ram}</dd>
        <dt>Hmotnost</dt>
        <dd>{kolo.hmotnost} kg</dd>
      </dl>
      <p className="cena-velka">{kolo.cenaDen} Kč / den</p>
      <Link className="zpet" to="/">← Zpět na katalog</Link>
    </article>
  );
}
```
