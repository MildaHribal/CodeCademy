# --description--

Katalog je hotový, ale celá aplikace je pořád jedna obrazovka. Než přidáš detail
kola, potřebuje aplikace **router**: ten podle adresy rozhodne, co se vykreslí.

V seedu je nový soubor `Trasy.jsx` — zatím jen s odstavcem místo tras.

**Úkol:** Zapoj router do aplikace.

1. V `App.jsx` obal obsah komponentou `MemoryRouter` a dovnitř dej `<Trasy />`.
2. V `Trasy.jsx` vrať `<Routes>` s jedinou trasou: adresa `/` vykreslí `<Katalog />`.

Náhled po tomhle kroku vypadá skoro stejně jako předtím — změna je v tom, že
katalog už nevisí v aplikaci napevno, ale patří k adrese `/`. Bez toho by nešlo
přidat druhou obrazovku.

```jsx
// stejný tvar, jiná aplikace
<MemoryRouter>
  <Routes>
    <Route path="/" element={<Nastenka />} />
  </Routes>
</MemoryRouter>
```

> [!NOTE]
> V Akademii běží stránka v sandboxu bez vlastního adresního řádku, proto
> `MemoryRouter` — adresu drží router v paměti. Ve svém projektu napíšeš
> `BrowserRouter` a adresa se objeví v prohlížeči. Všechno ostatní je stejné.

# --hints--

Na adrese `/` vykreslí `Trasy` katalog s osmi kartami.

```js
const { default: Trasy } = await helpers.importFile('Trasy.jsx');
const { MemoryRouter } = await import('react-router');
const { createElement } = await import('react');
const { createRoot } = await import('react-dom/client');
const misto = document.createElement('div');
document.body.append(misto);
createRoot(misto).render(createElement(MemoryRouter, { initialEntries: ['/'] }, createElement(Trasy)));
await helpers.flush();
assert.equal(misto.querySelectorAll('.katalog li').length, 8, 'na adrese / má trasa vykreslit katalog s 8 kartami');
misto.remove();
```

Trasy jsou napsané přes `Routes` a `Route`, ne podmínkou ve stavu.

```js
const zdroj = helpers.stripComments(files['Trasy.jsx'], 'js');
assert.match(zdroj, /<Routes>/, 'Trasy.jsx má vrátit <Routes> …');
assert.match(zdroj, /<Route\s[^>]*path=["']\/["']/, '… a v nich trasu <Route path="/" element={…} />');
```

`App.jsx` obaluje aplikaci routerem a vykresluje `Trasy`.

```js
const zdroj = helpers.stripComments(files['App.jsx'], 'js');
assert.match(zdroj, /<MemoryRouter/, 'App.jsx má obsah obalit komponentou <MemoryRouter>');
assert.match(zdroj, /<Trasy\s*\/?>/, 'App.jsx má uvnitř routeru vykreslit <Trasy />');
assert.equal(document.querySelectorAll('.katalog li').length, 8, 'v aplikaci má být pořád vidět katalog s 8 kartami');
```
