# --description--

Filtr podle typu je hrubé síto. Přidej k němu vyhledávací pole, které hledá
v názvu kola a **kombinuje se** s vybraným typem.

Hledání se píše po písmenkách, a tady číhá past: kdyby každý znak založil nový
záznam v historii, uživatel by se po napsání osmi písmen musel osmkrát vracet,
než se dostane zpátky na katalog. Druhý argument funkce, která zapisuje
parametry, umí poslední záznam místo toho **přepsat**.

**Úkol:** V `Katalog.jsx`:

1. Čti z adresy i parametr `hledani`; když chybí, ber prázdný text.
2. Pod filtr typů dej `label` s třídou `hledani`, v něm popisek *Hledat kolo*
   a pole `input` typu `search`. Pole je řízené — jeho hodnota je to, co je
   v adrese.
3. Při psaní zapiš text do parametru `hledani`, a to tak, aby se poslední záznam
   v historii přepsal. Prázdný text parametr z adresy smaž, ať tam nezůstane
   `?hledani=` naprázdno.
4. Seznam filtruj podle typu **i** podle hledaného textu. Velikost písmen ať
   nehraje roli.

Ostatní parametry přitom musí zůstat — takže nová hodnota se přidává
k dosavadním, ne místo nich.

## --tip--

Past s historií je popsaná v [Stav v URL](see:react-aplikace/routovani#stav-v-url-usesearchparams),
v odrážkách pod ukázkou.

## --tip--

Aby ostatní parametry zůstaly, nezapisuj holý objekt s jediným klíčem. Z toho, co
`useSearchParams` vrátilo, si udělej kopii, v ní klíč nastav nebo smaž a kopii
zapiš. Druhý argument zápisu bere volby.

## --tip--

Kopie parametrů a mazání klíče se dělá takhle:

```js
const dalsi = new URLSearchParams(puvodni);
dalsi.delete('strana');
```

import { Link, useSearchParams } from 'react-router';
import { kola, popisekTypu, typy } from './data';

export default function Katalog() {
  const [parametry, setParametry] = useSearchParams();
  const typ = parametry.get('typ') ?? 'vse';
  const videt = typ === 'vse' ? kola : kola.filter((kolo) => kolo.typ === typ);

  return (
    <>
      <div className="filtr">
        <button
          type="button"
          className={typ === 'vse' ? 'zvolene' : ''}
          onClick={() => setParametry({})}
        >
          Vše
        </button>
        {typy.map((moznost) => (
          <button
            key={moznost.hodnota}
            type="button"
            className={typ === moznost.hodnota ? 'zvolene' : ''}
            onClick={() => setParametry({ typ: moznost.hodnota })}
          >
            {moznost.popisek}
          </button>
        ))}
      </div>
      <ul className="katalog">
        {videt.map((kolo) => (
          <li key={kolo.id}>
            <Link className="karta" to={'/kola/' + kolo.id}>
              <h2>{kolo.nazev}</h2>
              <p className="typ">{popisekTypu(kolo.typ)}</p>
              <p className="cena">{kolo.cenaDen} Kč / den</p>
            </Link>
          </li>
        ))}
      </ul>
    </>
  );
}

## --file-- Katalog.jsx

```jsx
import { Link, useSearchParams } from 'react-router';
import { kola, popisekTypu, typy } from './data';

export default function Katalog() {
  const [parametry, setParametry] = useSearchParams();
  const typ = parametry.get('typ') ?? 'vse';
  const hledani = parametry.get('hledani') ?? '';

  const videt = kola
    .filter((kolo) => typ === 'vse' || kolo.typ === typ)
    .filter((kolo) => kolo.nazev.toLowerCase().includes(hledani.toLowerCase()));

  function zmenHledani(text) {
    const dalsi = new URLSearchParams(parametry);
    if (text === '') dalsi.delete('hledani');
    else dalsi.set('hledani', text);
    setParametry(dalsi, { replace: true });
  }

  return (
    <>
      <div className="filtr">
        <button
          type="button"
          className={typ === 'vse' ? 'zvolene' : ''}
          onClick={() => setParametry({})}
        >
          Vše
        </button>
        {typy.map((moznost) => (
          <button
            key={moznost.hodnota}
            type="button"
            className={typ === moznost.hodnota ? 'zvolene' : ''}
            onClick={() => setParametry({ typ: moznost.hodnota })}
          >
            {moznost.popisek}
          </button>
        ))}
      </div>
      <label className="hledani">
        <span>Hledat kolo</span>
        <input
          type="search"
          value={hledani}
          placeholder="název kola"
          onChange={(udalost) => zmenHledani(udalost.target.value)}
        />
      </label>
      <ul className="katalog">
        {videt.map((kolo) => (
          <li key={kolo.id}>
            <Link className="karta" to={'/kola/' + kolo.id}>
              <h2>{kolo.nazev}</h2>
              <p className="typ">{popisekTypu(kolo.typ)}</p>
              <p className="cena">{kolo.cenaDen} Kč / den</p>
            </Link>
          </li>
        ))}
      </ul>
    </>
  );
}
```
