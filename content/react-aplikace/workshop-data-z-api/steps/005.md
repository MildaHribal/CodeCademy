# --description--

Směna má pět úkolů, ale barista chce vidět jen to, co ještě zbývá. `nactiUkoly`
umí filtrovat — bere `'vse'`, `'zbyva'` nebo `'hotove'`.

Filtr je UI stav (na odkaz ho tady posílat nepotřebuješ), takže bydlí
v `useState`. Důležité je, co se stane s dotazem: **klíč se musí měnit spolu
s filtrem**, jinak by se data tří různých dotazů schovala pod jeden klíč.

**Úkol:**

1. V `App.jsx` přidej stav `filtr` s výchozí hodnotou `'vse'` a nad `<Ukoly />`
   vykresli `div` s třídou `filtr` a třemi tlačítky: **Vše** (`vse`),
   **Zbývá** (`zbyva`) a **Hotové** (`hotove`). Zvolené tlačítko má třídu
   `zvolene`. Hodnotu filtru předej do `Ukoly` propsou `filtr`.
2. V `Ukoly.jsx` dej filtr do klíče dotazu i do volání `nactiUkoly`.

```jsx
// jinde: klíč, který se mění s vybraným městem
useQuery({ queryKey: ['pobocky', mesto], queryFn: () => nactiPobocky(mesto) });
```

Filtr „Hotové" ukáže jen hotové úkoly.


Každý filtr má v cache vlastní záznam, takže návrat k dřívějšímu filtru je okamžitý.

```js
await helpers.waitFor(() => document.querySelectorAll('.ukoly li').length === 5);
await helpers.click(document.querySelectorAll('.filtr button')[1]);
await helpers.waitFor(() => document.querySelectorAll('.ukoly li').length === 3, 3000);
await helpers.click(document.querySelectorAll('.filtr button')[0]);
await helpers.flush();
assert.equal(document.querySelectorAll('.ukoly li').length, 5, 'návrat na filtr Vše má data vzít z cache a ukázat je hned — s filtrem v klíči se nečeká na server');
```

# --help--

## --tip--

Proč filtr patří do klíče, je v části
[Klíč musí obsahovat všechno](see:react-aplikace/tanstack-query#klic-musi-obsahovat-vsechno-na-cem-data-zavisi).

## --tip--

Klíč je pole. Kromě jména dotazu do něj přidej hodnotu, na které data závisí —
tu samou, kterou posíláš do `nactiUkoly`.

## --tip--

Tlačítka filtru vzniknou z pole možností stejně jako kterýkoli jiný seznam:
dvojice hodnota a popisek, `map` a `key`.

# --explain--

Proč nestačí předat filtr jen do `queryFn` a klíč nechat být?

## --model--

Klíč je adresa dat v cache. Když ho nechám pořád stejný, mají všechny tři filtry
jedno místo v cache a přepisují si data navzájem: po přepnutí filtru se nejdřív
ukážou stará data, teprve pak dorazí nová. Když navíc přijdou odpovědi v jiném
pořadí, než jsem je poslal, zůstane v cache ta pomalejší — tedy špatná. S filtrem
v klíči je každý filtr vlastní záznam, návrat k dřívějšímu filtru je okamžitý
a žádný závod nemůže nastat.

## --checklist--

- Klíč je adresa dat v cache.
- Se stejným klíčem si různé filtry přepisují data.
- Odpovědi můžou dorazit v jiném pořadí, než byly odeslané.
- Filtr v klíči dává každému filtru vlastní záznam a cache se dá využít.

## --file-- Ukoly.jsx

```jsx
import { useQuery } from '@tanstack/react-query';
import { nactiUkoly } from './api';
import { souhrn } from './pomocne';

export default function Ukoly() {
  const { data, status, error, refetch } = useQuery({
    queryKey: ['ukoly'],
    queryFn: () => nactiUkoly(),
  });

  if (status === 'pending') {
    return <p className="hlaska">Načítám úkoly směny…</p>;
  }

  if (status === 'error') {
    return (
      <div className="chyba" role="alert">
        <span>Úkoly se nepodařilo načíst: {error.message}</span>
        <button type="button" onClick={() => refetch()}>Zkusit znovu</button>
      </div>
    );
  }

  const prehled = souhrn(data);

  return (
    <>
      <p className="souhrn">
        Hotovo <strong>{prehled.hotovo} z {prehled.celkem}</strong> · důležité a nehotové: {prehled.dulezite}
      </p>
      <ul className="ukoly">
        {data.map((ukol) => (
          <li key={ukol.id} className={ukol.hotovo ? 'hotovo' : ''}>
            <span className="text">{ukol.text}</span>
            {ukol.dulezite && <span className="stitek">důležité</span>}
          </li>
        ))}
      </ul>
    </>
  );
}
```

```js
// Náhrada skutečného API: data žijí v paměti stránky a odpovědi mají zpoždění,
// aby byly vidět stavy načítání. Ve svém projektu tyhle funkce nahradíš fetchem.
// Objekt rezim je tu jen pro tenhle workshop — dá se jím vynutit chyba serveru.
export const rezim = { selhatNacteni: false, selhatZapis: false, zpozdeni: 120 };

let ukoly = [
  { id: 1, text: 'Umýt pákový kávovar', hotovo: false, dulezite: true },
  { id: 2, text: 'Doplnit zrnka do mlýnku', hotovo: true, dulezite: false },
  { id: 3, text: 'Objednat ovesné mléko', hotovo: false, dulezite: true },
  { id: 4, text: 'Přepsat nabídku na tabuli', hotovo: false, dulezite: false },
  { id: 5, text: 'Spočítat kasu', hotovo: true, dulezite: false },
];
let dalsiId = 6;

function odpoved(vyrob, selhat, zprava) {
  return new Promise((splnit, odmitnout) => {
    setTimeout(() => {
      if (selhat) odmitnout(new Error(zprava));
      else splnit(vyrob());
    }, rezim.zpozdeni);
  });
}

/** Úkoly směny. Filtr je 'vse', 'zbyva' nebo 'hotove'. */
export function nactiUkoly(filtr = 'vse') {
  return odpoved(
    () => ukoly
      .filter((ukol) => filtr === 'vse' || (filtr === 'hotove' ? ukol.hotovo : !ukol.hotovo))
      .map((ukol) => ({ ...ukol })),
    rezim.selhatNacteni,
    'Server neodpovídá',
  );
}

export function pridejUkol(text) {
  return odpoved(() => {
    const novy = { id: dalsiId, text, hotovo: false, dulezite: false };
    dalsiId += 1;
    ukoly = [...ukoly, novy];
    return { ...novy };
  }, rezim.selhatZapis, 'Úkol se nepodařilo uložit');
}

export function prepniHotovo(id) {
  return odpoved(() => {
    ukoly = ukoly.map((ukol) => (ukol.id === id ? { ...ukol, hotovo: !ukol.hotovo } : ukol));
    return { ...ukoly.find((ukol) => ukol.id === id) };
  }, rezim.selhatZapis, 'Změnu se nepodařilo uložit');
}

export function prepniDulezite(id) {
  return odpoved(() => {
    ukoly = ukoly.map((ukol) => (ukol.id === id ? { ...ukol, dulezite: !ukol.dulezite } : ukol));
    return { ...ukoly.find((ukol) => ukol.id === id) };
  }, rezim.selhatZapis, 'Změnu se nepodařilo uložit');
}

export function smazUkol(id) {
  return odpoved(() => {
    ukoly = ukoly.filter((ukol) => ukol.id !== id);
    return { id };
  }, rezim.selhatZapis, 'Úkol se nepodařilo smazat');
}

const dodavatele = [
  { id: 1, nazev: 'Pražírna Kolonial', stav: 'objednano' },
  { id: 2, nazev: 'Mlékárna Valašsko', stav: 'ceka' },
  { id: 3, nazev: 'Pekárna U Nádraží', stav: 'objednano' },
  { id: 4, nazev: 'Ovesná farma Brdy', stav: 'ceka' },
];

/** Dodavatelé směny. Stav je 'vse', 'objednano' nebo 'ceka'. */
export function nactiDodavatele(stav = 'vse') {
  return odpoved(
    () => dodavatele.filter((polozka) => stav === 'vse' || polozka.stav === stav).map((polozka) => ({ ...polozka })),
    rezim.selhatNacteni,
    'Server neodpovídá',
  );
}
```

## --file-- pomocne.js

```js
/**
 * Souhrn směny: kolik úkolů je hotových, kolik jich je celkem
 * a kolik nehotových je označených jako důležité.
 * @param {{ hotovo: boolean, dulezite: boolean }[]} ukoly
 * @returns {{ hotovo: number, celkem: number, dulezite: number }}
 */
export function souhrn(ukoly) {
  return {
    hotovo: ukoly.filter((ukol) => ukol.hotovo).length,
    celkem: ukoly.length,
    dulezite: ukoly.filter((ukol) => ukol.dulezite && !ukol.hotovo).length,
  };
}
```

## --file-- App.jsx

```jsx
import { useState } from 'react';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import Ukoly from './Ukoly';
import './styles.css';

const filtry = [
  { hodnota: 'vse', popisek: 'Vše' },
  { hodnota: 'zbyva', popisek: 'Zbývá' },
  { hodnota: 'hotove', popisek: 'Hotové' },
];

export default function App() {
  const [klient] = useState(() => new QueryClient({
    defaultOptions: { queries: { retry: false } },
  }));
  const [filtr, setFiltr] = useState('vse');

  return (
    <QueryClientProvider client={klient}>
      <main className="obal">
        <header className="zahlavi">
          <h1>Kavárna Zrnko — směna</h1>
        </header>
        <div className="filtr">
          {filtry.map((moznost) => (
            <button
              key={moznost.hodnota}
              type="button"
              className={filtr === moznost.hodnota ? 'zvolene' : ''}
              onClick={() => setFiltr(moznost.hodnota)}
            >
              {moznost.popisek}
            </button>
          ))}
        </div>
        <Ukoly filtr={filtr} />
      </main>
    </QueryClientProvider>
  );
}
```
