# --description--

Kavárna Zrnko má na každou směnu seznam úkolů: co umýt, co doobjednat, co
přepsat na tabuli. Za patnáct kroků z něj bude aplikace, která si data bere ze
serveru, umí je měnit a nečeká na odpověď, když nemusí.

Nejdřív ale něco, co už umíš z polí — bez návodu.

Každý úkol je objekt s klíči `id`, `text`, `hotovo` a `dulezite`.

**Úkol:**

1. V `pomocne.js` doplň funkci `souhrn(ukoly)`. Vrátí objekt se třemi čísly:
   `hotovo` (kolik úkolů je hotových), `celkem` (kolik jich je dohromady)
   a `dulezite` (kolik **nehotových** úkolů je označených jako důležité).
2. V `Ukoly.jsx` nad seznam přidej `<p className="souhrn">` s textem
   `Hotovo 2 z 5 · důležité a nehotové: 2`, kde čísla bereš ze `souhrn`.
   Dvojici „2 z 5" dej do `<strong>`.

```jsx
// stejný tvar na jiných datech
const prehled = statistika(zapasy);
<p>Vyhráno <strong>{prehled.vyhry} z {prehled.celkem}</strong></p>
```

# --hints--

`souhrn` spočítá hotové úkoly, všechny úkoly i nehotové důležité.

```js
const { souhrn } = await helpers.importFile('pomocne.js');
const ukoly = [
  { id: 1, text: 'a', hotovo: true, dulezite: true },
  { id: 2, text: 'b', hotovo: false, dulezite: true },
  { id: 3, text: 'c', hotovo: false, dulezite: false },
];
assert.deepEqual(souhrn(ukoly), { hotovo: 1, celkem: 3, dulezite: 1 }, 'souhrn tří úkolů (jeden hotový, jeden nehotový důležitý) má vrátit { hotovo: 1, celkem: 3, dulezite: 1 }');
```

Hotový úkol se do `dulezite` nepočítá, i když je označený jako důležitý.

```js
const { souhrn } = await helpers.importFile('pomocne.js');
const ukoly = [
  { id: 1, text: 'a', hotovo: true, dulezite: true },
  { id: 2, text: 'b', hotovo: true, dulezite: true },
];
assert.equal(souhrn(ukoly).dulezite, 0, 'souhrn dvou hotových důležitých úkolů má mít dulezite: 0 — hotové úkoly už nikoho netlačí');
```

Prázdná směna nespadne a vrátí samé nuly.

```js
const { souhrn } = await helpers.importFile('pomocne.js');
assert.deepEqual(souhrn([]), { hotovo: 0, celkem: 0, dulezite: 0 }, 'souhrn([]) má vrátit { hotovo: 0, celkem: 0, dulezite: 0 }');
```

Nad seznamem je věta se souhrnem směny.

```js
const souhrnPrvek = document.querySelector('.souhrn');
assert.ok(souhrnPrvek, 'nad seznamem má být odstavec s třídou souhrn');
assert.match(souhrnPrvek.textContent, /Hotovo\s*2 z 5/, 'souhrn má začínat „Hotovo 2 z 5"');
assert.match(souhrnPrvek.textContent, /důležité a nehotové:\s*2/, 'souhrn má končit „důležité a nehotové: 2"');
assert.match(souhrnPrvek.querySelector('strong').textContent, /2 z 5/, 'dvojice „2 z 5" má být v prvku strong');
```

/** Úkoly směny. Filtr je 'vse', 'zbyva' nebo 'hotove'. */
export function nactiUkoly(filtr = 'vse') {
  return odpoved(
    () => ukoly
      .filter((ukol) => filtr === 'vse' || (filtr === 'hotove' ? ukol.hotovo : !ukol.hotovo))
      .map((ukol) => ({ ...ukol })),
    rezim.selhatNacteni,
    'Server neodpovídá',

export function pridejUkol(text) {
  return odpoved(() => {
    const novy = { id: dalsiId, text, hotovo: false, dulezite: false };
    dalsiId += 1;
    ukoly = [...ukoly, novy];
    return { ...novy };
  }, rezim.selhatZapis, 'Úkol se nepodařilo uložit');
}

export function prepniHotovo(id) {
  return odpoved(() => {
    ukoly = ukoly.map((ukol) => (ukol.id === id ? { ...ukol, hotovo: !ukol.hotovo } : ukol));
    return { ...ukoly.find((ukol) => ukol.id === id) };

export function prepniDulezite(id) {

}

    return { id };
  }, rezim.selhatZapis, 'Úkol se nepodařilo smazat');
}

## --file-- pomocne.js

```js
/**
 * Souhrn směny: kolik úkolů je hotových, kolik jich je celkem
 * a kolik nehotových je označených jako důležité.
 * @param {{ hotovo: boolean, dulezite: boolean }[]} ukoly
 * @returns {{ hotovo: number, celkem: number, dulezite: number }}
 */
export function souhrn(ukoly) {
  return {
    hotovo: ukoly.filter((ukol) => ukol.hotovo).length,
    celkem: ukoly.length,
    dulezite: ukoly.filter((ukol) => ukol.dulezite && !ukol.hotovo).length,
  };
}
```
