# --description--
Když uživatel stránku znovu načte, chceme použít jeho předchozí nastavení.

Při startu skriptu (ne v události) se podívej do `localStorage` pro klíč `"appSettings"`. Pokud tam něco je, pomocí `JSON.parse` načti data do proměnné `userSettings`. Poté aktualizuj `currentSettings` a zavolej `applySettings`.

Zkus zavřít a otevřít stránku, nastavení by mělo vydržet.
# --hints--

Zkontroluj:

```javascript
const savedSettings = localStorage.getItem('appSettings');
if (savedSettings) {
  userSettings = JSON.parse(savedSettings);
}

currentSettings = { ...defaultSettings, ...userSettings };
applySettings(currentSettings);
```




Zkontroluj, zda procházejí testy:
```javascript
assert(typeof savedSettings !== 'undefined' || typeof userSettings !== 'undefined', "Při načítání stránky musíme otestovat přečtení z localStorage.");
```
