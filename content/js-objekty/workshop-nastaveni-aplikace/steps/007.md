# --description--

Druhá strana importu: tlačítko **Exportovat** dá uživateli text ke zkopírování. Má být čitelný pro člověka a nemá v něm být `lastSynced` — datum poslední synchronizace patří zařízení, ne nastavení.

**Úkol:** Napiš funkci `exportSettings(settings)`, která vrátí JSON text nastavení bez vlastnosti `lastSynced`, odsazený **dvěma mezerami**. Objekt `settings` se nezmění.

Vynechání vlastnosti znáš ze zbytku vlastností v destrukturalizaci. Odsazení nastaví třetí argument `JSON.stringify`, druhý pak může být `null`. Na jiných datech:

```js
const { password, ...safeUser } = user;
const pretty = JSON.stringify(safeUser, null, 2);
```

# --hints--

`exportSettings` vrátí JSON odsazený dvěma mezerami bez `lastSynced`.

```js
const settings = { ...DEFAULT_SETTINGS, theme: 'dark', lastSynced: new Date('2026-09-14T10:00:00Z') };
const { lastSynced, ...expected } = settings;
assert.equal(exportSettings(settings), JSON.stringify(expected, null, 2), 'exportSettings má vrátit JSON.stringify nastavení bez lastSynced s odsazením 2 mezery');
```

Z exportu jde nastavení zase importovat a vstup se nezmění.

```js
const settings = { ...DEFAULT_SETTINGS, lastSynced: new Date('2026-09-14T10:00:00Z') };
const text = exportSettings(settings);
assert.equal(text.includes('lastSynced'), false, 'text z exportSettings nemá obsahovat lastSynced');
assert.equal(importSettings(text).playback.speed, 1, 'importSettings(exportSettings(…)) má vrátit nastavení');
assert.equal(settings.lastSynced instanceof Date, true, 'exportSettings nesmí z původního nastavení odstranit lastSynced');
```

# --help--

## --tip--

Třetí argument `JSON.stringify` je v části [JSON: data jako text](see:js-objekty/kopie-a-json#json-data-jako-text), zbytek vlastností v lekci o objektech.

## --tip--

Nejdřív destrukturalizací vytáhni `lastSynced` a zbytek do nové proměnné. Tu převeď na text s druhým argumentem `null` a třetím `2`.

## --tip--

Na jiných datech: `const { internalId, ...publicOrder } = order;` a pak `JSON.stringify(publicOrder, null, 2)`.

// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}

// Uloží nastavení do localStorage jako JSON.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(settings));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}

// Úplné nastavení při startu: uložené hodnoty doplněné výchozími.
function loadSettings() {
  return mergeSettings(DEFAULT_SETTINGS, readSaved());
}

// Nastavení z vloženého textu, nebo null, když to nastavení není.
function importSettings(text) {
  let parsed;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  if (typeof parsed !== 'object' || parsed === null) {
    return null;
  }
  return mergeSettings(DEFAULT_SETTINGS, parsed);
}
