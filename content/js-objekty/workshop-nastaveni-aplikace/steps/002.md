# --description--
Nyní vytvoříme soubor `main.js`. V něm si definujeme výchozí nastavení naší aplikace.

Vytvoř objekt `defaultSettings`, který bude obsahovat `theme` nastavené na `'light'` a `notifications` na `false`. Zároveň si připrav prázdný objekt `userSettings` a třetí objekt `currentSettings`, do kterého budeme později slučovat výsledky.
# --hints--

Zkontroluj, zda procházejí testy:

```javascript
const defaultSettings = {
  theme: 'light',
  notifications: false
};

let userSettings = {};
let currentSettings = {};
```


Zkontroluj, zda procházejí testy:
```javascript
assert(typeof defaultSettings === 'object', "Měl by existovat objekt `defaultSettings`.");
assert(defaultSettings.theme === 'light', "Výchozí téma v `defaultSettings` by mělo být 'light'.");
```
