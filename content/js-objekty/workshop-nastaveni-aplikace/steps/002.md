# --description--

Uživatel si uloží jen to, co změnil, třeba `{ playback: { speed: 1.5 } }`. Aplikace ale potřebuje úplné nastavení: co uživatel nezměnil, vezme z výchozího.

> [!PITFALL]
> `{ ...DEFAULT_SETTINGS, ...saved }` je [[mělká kopie|mělké]] sloučení. Skupina `playback` z uloženého nastavení nahradí **celou** výchozí skupinu, a `skipSeconds` i `autoplay` zmizí.

**Úkol:** Napiš funkci `mergeSettings(defaults, saved)`, která vrátí úplné nastavení: v prvním patře hodnoty z `saved` přes `defaults` a každou ze tří skupin sloučí zvlášť — `playback`, `downloads` i `notifications` jsou **nové** objekty s výchozími hodnotami přepsanými uloženými. Žádný ze vstupů se nezmění.

Vzor na jiných datech — objednávka s výchozí adresou, sloučená po patrech:

```js
const order = {
  ...defaultOrder,
  ...savedOrder,
  address: { ...defaultOrder.address, ...savedOrder.address },
};
```

Rozprostřít `undefined` nevadí: `{ ...undefined }` je prázdný objekt, takže skupina, kterou uživatel nezměnil, nic nerozbije.

# --hints--

Uložená rychlost přepíše výchozí a ostatní hodnoty skupiny zůstanou.

```js
const result = mergeSettings(DEFAULT_SETTINGS, { playback: { speed: 1.5 } });
assert.deepEqual(result.playback, { speed: 1.5, skipSeconds: 15, autoplay: true }, 'mergeSettings(DEFAULT_SETTINGS, { playback: { speed: 1.5 } }).playback má být { speed: 1.5, skipSeconds: 15, autoplay: true }');
assert.deepEqual(result.downloads, DEFAULT_SETTINGS.downloads, 'mergeSettings má u nezměněné skupiny downloads vzít výchozí hodnoty');
```

Hodnoty prvního patra z uloženého nastavení přepíší výchozí.

```js
const result = mergeSettings(DEFAULT_SETTINGS, { theme: 'dark', notifications: { weeklySummary: true } });
assert.equal(result.theme, 'dark', "mergeSettings(…, { theme: 'dark' }).theme má být 'dark'");
assert.deepEqual(result.notifications, { newEpisodes: true, weeklySummary: true }, 'mergeSettings(…, { notifications: { weeklySummary: true } }).notifications má být { newEpisodes: true, weeklySummary: true }');
```

Skupiny ve výsledku jsou nové objekty a vstupy se nezmění.

```js
const saved = { playback: { speed: 2 } };
const result = mergeSettings(DEFAULT_SETTINGS, saved);
assert.equal(DEFAULT_SETTINGS.playback.speed, 1, 'mergeSettings nesmí změnit DEFAULT_SETTINGS.playback');
assert.deepEqual(saved, { playback: { speed: 2 } }, 'mergeSettings nesmí změnit uložené nastavení');
for (const group of ['playback', 'downloads', 'notifications']) {
  assert.notEqual(result[group], DEFAULT_SETTINGS[group], `skupina ${group} ve výsledku mergeSettings má být nový objekt, ne ten z DEFAULT_SETTINGS`);
}
```

# --help--

## --tip--

Jde o kopii po patrech — viz [Kopie po patrech](see:js-objekty/kopie-a-json#kopie-po-patrech).

## --tip--

V `return` rozprostři nejdřív `defaults`, pak `saved`, a za ně napiš tři vlastnosti skupin. Každá dostane nový objekt, do kterého rozprostřeš výchozí a pak uloženou skupinu.

## --tip--

Na jiných datech: `filters: { ...defaultFilters.filters, ...urlFilters.filters }` sloučí jednu vnořenou skupinu filtrů.

# --explain--

Vysvětli vlastními slovy, proč `{ ...DEFAULT_SETTINGS, ...saved }` na sloučení nastavení nestačí.

## --model--

Spread kopíruje jen první patro. Když má uložené nastavení skupinu `playback` jen s rychlostí, přepíše tahle skupina výchozí `playback` celou, a hodnoty jako `skipSeconds` zmizí. Proto slučuju každou skupinu zvlášť: nový objekt, do kterého rozprostřu výchozí skupinu a přes ni uloženou. Nové skupiny navíc znamenají, že výsledek nesdílí objekty s výchozím nastavením.

## --checklist--

- Spread slučuje jen první patro.
- Uložená skupina nahradí výchozí skupinu celou.
- Každou skupinu je potřeba sloučit zvlášť do nového objektu.
- Výsledek pak nesdílí vnořené objekty s výchozím nastavením.

# --solution--

## --file-- script.js

```js
// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}
```
