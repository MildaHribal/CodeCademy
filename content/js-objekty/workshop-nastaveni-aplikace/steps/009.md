# --description--
Sestav kód tak, abychom při načítání `userSettings` převedli řetězec `lastUpdated` zpět na skutečný objekt `Date`. Předpokládáme, že JSON z `localStorage` už byl načten do proměnné `parsedData`.

Chceme vytvořit hlubokou kopii (nebo ručně obnovit vlastnost), abychom měli funkční datum. Seřaď bloky do správného pořadí.
# --parsons--

```javascript
if (parsedData.lastUpdated) {
  parsedData.lastUpdated = new Date(parsedData.lastUpdated);
}
userSettings = { ...parsedData };
```
