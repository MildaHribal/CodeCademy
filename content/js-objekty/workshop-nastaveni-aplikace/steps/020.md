# --description--

Poslední krok. Přibyly soubory `index.html`, `styles.css` a `ui.js` a náhled ukazuje panel nastavení. Soubor `ui.js` načte uložené nastavení, vyrobí z něj koncept přes tvůj `draftFrom` a do konceptu rovnou zapisuje — díky hluboké kopii to nevadí. Uložení, Zrušit, Obnovit vše, předvolba i patička stojí na tvých funkcích. Jak se pracuje se stránkou a událostmi, probere sekce DOM, události a prohlížeč.

Chybí jediná věc: zelený řádek se souhrnem nahoře.

**Úkol:** Napiš ve `script.js` funkci `settingsSummary(settings)`, která vrátí souhrn ve tvaru `'1,5× · přeskočit o 30 s · stahování jen přes Wi-Fi'`. Rychlost je číslo s desetinnou čárkou podle češtiny, a když stahování není jen přes Wi-Fi, konec zní `stahování i přes mobilní data`.

Až testy projdou, změň v náhledu rychlost a téma, zkus **Zrušit**, pak **Uložit** a otevři „Co je uložené v prohlížeči": uvidíš JSON jen se změnami. Úložiště náhledu žije jen do obnovení náhledu.

Tím je workshop hotový. Za sebou máš:

- sloučení nastavení s výchozím po patrech a uložení jen rozdílů,
- `JSON.stringify` s odsazením a bez citlivých údajů, bezpečné `JSON.parse` a import,
- migraci starého formátu a past s `undefined` ve spreadu,
- datum, které po JSON zůstane textem, a koncept přes `structuredClone`,
- porovnání nastavení přes JSON se srovnaným pořadím klíčů,
- opravu dvou kolegových chyb: `Object.assign` do výchozích hodnot a datum po načtení.

Stejně pracuje nastavení v každé webové aplikaci, od e-shopu po editor kódu. Příště z objektů uděláš seznamy: v sekci Pole v JavaScriptu přijdou `map`, `filter` a `reduce` nad poli objektů.

## Udělej po svém

- **Vzhled:** přidej plynulé přepnutí barev při změně tématu i pro tlačítka a pole, nebo třetí barevné téma „sépie".
- **Funkce:** přidej tlačítka Exportovat a Importovat s textovým polem — `exportSettings` a `importSettings` už máš.
- **Tvoje téma:** přeměň panel na nastavení čehokoli, co používáš — herní ovládání, čtečku e-knih, chytrý termostat.

# --hints--

Po načtení stránky je v souhrnu výchozí nastavení.

```js
assert.equal(document.querySelector('#summary').textContent.trim(), '1× · přeskočit o 15 s · stahování jen přes Wi-Fi', "#summary má po načtení ukazovat '1× · přeskočit o 15 s · stahování jen přes Wi-Fi'");
```

Po změně rychlosti v náhledu se souhrn změní.

```js
const select = document.querySelector('#speed');
select.value = '1.5';
select.dispatchEvent(new Event('change'));
assert.equal(document.querySelector('#summary').textContent.trim(), '1,5× · přeskočit o 15 s · stahování jen přes Wi-Fi', "po výběru rychlosti 1,5× má #summary ukazovat '1,5× · přeskočit o 15 s · stahování jen přes Wi-Fi'");
```

`settingsSummary` popíše i stahování přes mobilní data a jiné hodnoty.

```js
const settings = mergeSettings(DEFAULT_SETTINGS, { playback: { speed: 0.8, skipSeconds: 30 }, downloads: { wifiOnly: false } });
assert.equal(settingsSummary(settings), '0,8× · přeskočit o 30 s · stahování i přes mobilní data', "settingsSummary pro rychlost 0.8, 30 s a wifiOnly: false má vrátit '0,8× · přeskočit o 30 s · stahování i přes mobilní data'");
```

Po uložení je v úložišti JSON jen se změnami.

```js
const select = document.querySelector('#skip');
select.value = '30';
select.dispatchEvent(new Event('change'));
await helpers.click(document.querySelector('#save'));
const stored = JSON.parse(localStorage.getItem(STORAGE_KEY));
assert.deepEqual(stored.playback, { skipSeconds: 30 }, 'po uložení s přeskočením 30 s má být v úložišti playback { skipSeconds: 30 }');
assert.equal(document.querySelector('#unsaved').hidden, true, 'po uložení nemá svítit štítek Neuložené změny');
```

# --help--

## --tip--

Čísla podle češtiny formátuje `toLocaleString` s jazykem `'cs-CZ'` nebo [`Intl.NumberFormat`](see:js-retezce-cisla/intl-a-datum#intl-numberformat-ceny-procenta-a-jednotky); hodnoty čteš ze skupin jako v [Kopie po patrech](see:js-objekty/kopie-a-json#kopie-po-patrech).

## --tip--

Přečti `speed`, `skipSeconds` a `wifiOnly` ze skupin (klidně destrukturalizací), rychlost naformátuj a konec souhrnu vyber podle `wifiOnly`. Tři části spoj mezerou, tečkou `·` a mezerou.

## --tip--

Podcíle na jiných datech — souhrn termostatu:

```js
// 1. vytáhni teplotu a režim ze skupin
// 2. teplotu naformátuj česky, třeba '21,5 °C'
// 3. spoj části ' · ' a podle režimu vyber konec
```

```js
// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign({}, DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${new Date(settings.lastSynced).toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}

// Uloží do localStorage jako JSON jen to, čím se nastavení liší od výchozího.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(changedSettings(DEFAULT_SETTINGS, settings)));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}

// Úplné nastavení při startu: uložené hodnoty doplněné výchozími.
function loadSettings() {
  return mergeSettings(DEFAULT_SETTINGS, readSaved());
}

// Nastavení z vloženého textu, nebo null, když to nastavení není.
function importSettings(text) {
  let parsed;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  if (typeof parsed !== 'object' || parsed === null) {
    return null;
  }
  return mergeSettings(DEFAULT_SETTINGS, parsed);
}

// JSON k exportu: bez data synchronizace, odsazený pro čtení.
function exportSettings(settings) {
  const { lastSynced, ...exportable } = settings;
  return JSON.stringify(exportable, null, 2);
}

// Nastavení ze starého plochého formátu (verze 1) do formátu se skupinami.
function migrateV1(saved) {
  const { speed, wifiOnly, ...rest } = saved;
  const playback = {};
  if (speed !== undefined) {
    playback.speed = speed;
  }
  const downloads = {};
  if (wifiOnly !== undefined) {
    downloads.wifiOnly = wifiOnly;
  }
  return { ...rest, playback, downloads };
}

// Nové nastavení s datem synchronizace, bez data aktuální čas.
function markSynced(settings, now = new Date()) {
  return { ...settings, lastSynced: now };
}

// Koncept nastavení: hluboká kopie, do které jde zapisovat.
function draftFrom(settings) {
  return structuredClone(settings);
}

// Krátký JSON ke sdílení: jen téma a přehrávání.
function shareableSettings(settings) {
  return JSON.stringify({ theme: settings.theme, playback: settings.playback });
}

// Liší se koncept od uloženého nastavení? Pořadí klíčů nerozhoduje.
function hasUnsavedChanges(saved, draft) {
  const savedText = JSON.stringify(mergeSettings(DEFAULT_SETTINGS, saved));
  const draftText = JSON.stringify(mergeSettings(DEFAULT_SETTINGS, draft));
  return savedText !== draftText;
}

// Jen hodnoty, kterými se nastavení liší od výchozího.
function changedSettings(defaults, settings) {
  const changes = {};
  for (const [key, defaultValue] of Object.entries(defaults)) {
    const value = settings[key];
    if (typeof defaultValue === 'object' && defaultValue !== null) {
      const groupChanges = {};
      for (const [name, defaultGroupValue] of Object.entries(defaultValue)) {
        if (value[name] !== defaultGroupValue) {
          groupChanges[name] = value[name];
        }
      }
      if (Object.keys(groupChanges).length > 0) {
        changes[key] = groupChanges;
      }
    } else if (value !== defaultValue) {
      changes[key] = value;
    }
  }
  return changes;
}

// Nové nastavení s otočenou notifikací.
function toggleNotification(settings, name) {
  return { ...settings, notifications: { ...settings.notifications, [name]: !settings.notifications[name] } };
}

// Nové nastavení, ve kterém má jedna skupina výchozí hodnoty.
function resetGroup(settings, group) {
  return { ...settings, [group]: { ...DEFAULT_SETTINGS[group] } };
}

// Smaže uložené nastavení a vrátí čerstvé výchozí.
function resetAll() {
  localStorage.removeItem(STORAGE_KEY);
  return loadSettings();
}
```

```js
// Propojení s HTML. Práci se stránkou a událostmi probere sekce DOM, události a prohlížeč.
// saved = uložené nastavení, draft = koncept, do kterého panel zapisuje.
let saved = loadSettings();
let draft = draftFrom(saved);
const byId = (id) => document.querySelector(`#${id}`);

function fillForm() {
  byId('speed').value = String(draft.playback.speed);
  byId('skip').value = String(draft.playback.skipSeconds);
  byId('wifi-only').checked = draft.downloads.wifiOnly;
  byId('theme').value = draft.theme;
}

function render() {
  document.documentElement.dataset.theme = draft.theme;
  byId('summary').textContent = typeof settingsSummary === 'function' ? settingsSummary(draft) : 'Doplň funkci settingsSummary ve script.js.';
  byId('unsaved').hidden = !hasUnsavedChanges(saved, draft);
  byId('synced').textContent = syncedLabel(saved);
  byId('stored').textContent = localStorage.getItem(STORAGE_KEY) ?? '(nic)';
}

byId('speed').addEventListener('change', (event) => {
  draft.playback.speed = Number(event.target.value);
  render();
});
byId('skip').addEventListener('change', (event) => {
  draft.playback.skipSeconds = Number(event.target.value);
  render();
});
byId('wifi-only').addEventListener('change', (event) => {
  draft.downloads.wifiOnly = event.target.checked;
  render();
});
byId('theme').addEventListener('change', (event) => {
  draft = withTheme(draft, event.target.value);
  render();
});
byId('preset-data-saver').addEventListener('click', () => {
  draft = mergeSettings(draft, PRESETS.dataSaver);
  fillForm();
  render();
});
byId('save').addEventListener('click', () => {
  saveSettings(markSynced(draft));
  saved = loadSettings();
  draft = draftFrom(saved);
  render();
});
byId('cancel').addEventListener('click', () => {
  draft = draftFrom(saved);
  fillForm();
  render();
});
byId('reset').addEventListener('click', () => {
  saved = resetAll();
  draft = draftFrom(saved);
  fillForm();
  render();
});

fillForm();
render();
```

```js
  if (speed !== undefined) {
    playback.speed = speed;
  }
  const downloads = {};
  if (wifiOnly !== undefined) {
    downloads.wifiOnly = wifiOnly;
  }
  return { ...rest, playback, downloads };
}

// Nové nastavení s datem synchronizace, bez data aktuální čas.
function markSynced(settings, now = new Date()) {
  return { ...settings, lastSynced: now };
}

// Koncept nastavení: hluboká kopie, do které jde zapisovat.
function draftFrom(settings) {
  return structuredClone(settings);
}

// Krátký JSON ke sdílení: jen téma a přehrávání.
function shareableSettings(settings) {
  return JSON.stringify({ theme: settings.theme, playback: settings.playback });
}

// Liší se koncept od uloženého nastavení? Pořadí klíčů nerozhoduje.
function hasUnsavedChanges(saved, draft) {
  const savedText = JSON.stringify(mergeSettings(DEFAULT_SETTINGS, saved));
  const draftText = JSON.stringify(mergeSettings(DEFAULT_SETTINGS, draft));
  return savedText !== draftText;
}

// Jen hodnoty, kterými se nastavení liší od výchozího.
function changedSettings(defaults, settings) {
  const changes = {};
  for (const [key, defaultValue] of Object.entries(defaults)) {
    const value = settings[key];
    if (typeof defaultValue === 'object' && defaultValue !== null) {
      const groupChanges = {};
      for (const [name, defaultGroupValue] of Object.entries(defaultValue)) {
        if (value[name] !== defaultGroupValue) {
          groupChanges[name] = value[name];
        }
      }
      if (Object.keys(groupChanges).length > 0) {
        changes[key] = groupChanges;
      }
    } else if (value !== defaultValue) {
      changes[key] = value;
    }
  }
  return changes;
}

// Nové nastavení s otočenou notifikací.
function toggleNotification(settings, name) {
  return { ...settings, notifications: { ...settings.notifications, [name]: !settings.notifications[name] } };
}

// Nové nastavení, ve kterém má jedna skupina výchozí hodnoty.
function resetGroup(settings, group) {
  return { ...settings, [group]: { ...DEFAULT_SETTINGS[group] } };
}

// Smaže uložené nastavení a vrátí čerstvé výchozí.
function resetAll() {
  localStorage.removeItem(STORAGE_KEY);
  return loadSettings();
}

// Souhrn nastavení do horní části panelu, třeba '1,5× · přeskočit o 30 s · stahování jen přes Wi-Fi'.
function settingsSummary(settings) {
  const { speed, skipSeconds } = settings.playback;
  const network = settings.downloads.wifiOnly ? 'stahování jen přes Wi-Fi' : 'stahování i přes mobilní data';
  return `${speed.toLocaleString('cs-CZ')}× · přeskočit o ${skipSeconds} s · ${network}`;
}
```
