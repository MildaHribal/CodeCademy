# --description--

První verze aplikace ukládala nastavení naplocho, bez skupin: `{ theme: 'dark', speed: 1.5, wifiOnly: false }`. Uživatelé, kteří si ho tehdy uložili, nesmějí po aktualizaci o nastavení přijít.

**Úkol:** Napiš funkci `migrateV1(saved)`, která ze starého formátu vrátí nový: `speed` přesune do skupiny `playback`, `wifiOnly` do skupiny `downloads` a ostatní vlastnosti nechá v prvním patře. Výsledek musí jít předat do `mergeSettings` — to, co ve starém formátu chybí, tam doplní výchozí nastavení.

> [!PITFALL]
> Spread kopíruje i vlastnost s hodnotou `undefined`. Když starý záznam `speed` nemá a ty přesto vytvoříš skupinu `{ speed }`, přepíše sloučení výchozí rychlost na `undefined`. `JSON.stringify` takovou vlastnost navíc potichu vynechá, takže v uloženém textu chybu neuvidíš.

Kandidáti: zbytek vlastností v destrukturalizaci, podmínka nad `undefined`, nebo nový objekt skupiny, do kterého vlastnost zapíšeš jen tehdy, když existuje. Do nového objektu, který sis sám vytvořil, zapisovat smíš.

# --hints--

`migrateV1` přesune `speed` a `wifiOnly` do skupin a ostatní nechá.

```js
const result = mergeSettings(DEFAULT_SETTINGS, migrateV1({ theme: 'dark', speed: 1.5, wifiOnly: false }));
assert.equal(result.theme, 'dark', "po migraci má zůstat theme 'dark'");
assert.equal(result.playback.speed, 1.5, 'po migraci má být playback.speed 1.5');
assert.equal(result.downloads.wifiOnly, false, 'po migraci má být downloads.wifiOnly false');
assert.equal(Object.hasOwn(result, 'speed'), false, 'po migraci nemá v prvním patře zůstat speed');
assert.equal(Object.hasOwn(result, 'wifiOnly'), false, 'po migraci nemá v prvním patře zůstat wifiOnly');
```

Chybějící údaje starého formátu doplní výchozí nastavení, ne `undefined`.

```js
const result = mergeSettings(DEFAULT_SETTINGS, migrateV1({ theme: 'light' }));
assert.equal(result.playback.speed, 1, "po migraci { theme: 'light' } má být playback.speed výchozí 1, ne undefined");
assert.equal(result.downloads.wifiOnly, true, "po migraci { theme: 'light' } má být downloads.wifiOnly výchozí true, ne undefined");
```

Starý záznam se nezmění.

```js
const old = { theme: 'dark', speed: 2 };
migrateV1(old);
assert.deepEqual(old, { theme: 'dark', speed: 2 }, 'migrateV1 nesmí změnit starý záznam');
```

# --help--

## --tip--

Jak spread slučuje skupiny, ukazuje [Kopie po patrech](see:js-objekty/kopie-a-json#kopie-po-patrech); vytažení vlastností a zbytku znáš z lekce o objektech.

## --tip--

Destrukturalizací vytáhni `speed`, `wifiOnly` a zbytek. Pro každou skupinu si založ prázdný objekt a vlastnost do něj zapiš, jen když není `undefined`. Vrať zbytek rozprostřený s oběma skupinami.

## --tip--

Podcíle na jiných datech — starý formát adresy:

```js
// 1. vytáhni street, city a zbytek zákazníka
// 2. prázdný objekt address; ulici a město do něj zapiš, jen když nejsou undefined
// 3. vrať zbytek zákazníka s novou skupinou address
```

```js
// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}

// Uloží nastavení do localStorage jako JSON.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(settings));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}

// Úplné nastavení při startu: uložené hodnoty doplněné výchozími.
function loadSettings() {
  return mergeSettings(DEFAULT_SETTINGS, readSaved());
}

// Nastavení z vloženého textu, nebo null, když to nastavení není.
function importSettings(text) {
  let parsed;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  if (typeof parsed !== 'object' || parsed === null) {
    return null;
  }
  return mergeSettings(DEFAULT_SETTINGS, parsed);
}

// JSON k exportu: bez data synchronizace, odsazený pro čtení.
function exportSettings(settings) {
  const { lastSynced, ...exportable } = settings;
  return JSON.stringify(exportable, null, 2);
}

// Nastavení ze starého plochého formátu (verze 1) do formátu se skupinami.
function migrateV1(saved) {
  const { speed, wifiOnly, ...rest } = saved;
  const playback = {};
  if (speed !== undefined) {
    playback.speed = speed;

  if (wifiOnly !== undefined) {
```
