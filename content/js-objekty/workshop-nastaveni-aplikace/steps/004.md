# --description--
Přidej posluchač události na formulář (na událost `submit`). Zruš výchozí chování formuláře a ulož nové hodnoty do objektu `userSettings`. Poté tyto hodnoty vypiš do konzole.
# --hints--

Zkontroluj, zda procházejí testy:

```javascript
const form = document.getElementById('settingsForm');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  
  userSettings = {
    theme: document.getElementById('theme').value,
    notifications: document.getElementById('notifications').checked
  };
  
  console.log("Nové uživatelské nastavení:", userSettings);
});
```




Zkontroluj, zda procházejí testy:
```javascript
// Test the form behavior
const form = document.getElementById('settingsForm');
const themeInput = document.getElementById('theme');
themeInput.value = 'dark';
form.dispatchEvent(new Event('submit'));
assert(userSettings.theme === 'dark', "Po odeslání formuláře by se `userSettings.theme` mělo aktualizovat podle inputu.");
```
