# --description--

Po kliknutí na **Uložit** se nastavení zapíše do prohlížeče, aby přežilo obnovení stránky. Úložiště `localStorage` ale umí jen text.

**Úkol:** Napiš funkci `saveSettings(settings)`, která nastavení převede na [[JSON]] a uloží do `localStorage` pod klíčem z konstanty `STORAGE_KEY`. Nic nevrací.

Převod na text dělá `JSON.stringify` a zápis `localStorage.setItem(klíč, text)`. Na jiných datech:

```js
localStorage.setItem('cart', JSON.stringify(cart));
```

> [!PITFALL]
> Bez `JSON.stringify` se uloží text `[object Object]` a zpátky už data nedostaneš.

# --hints--

Po `saveSettings` je v `localStorage` pod `STORAGE_KEY` nastavení jako JSON.

```js
const settings = mergeSettings(DEFAULT_SETTINGS, { theme: 'dark' });
saveSettings(settings);
const text = localStorage.getItem(STORAGE_KEY);
assert.equal(typeof text, 'string', "po saveSettings má být v localStorage pod klíčem 'poslech:settings' text");
assert.deepEqual(JSON.parse(text), settings, 'uložený text má být JSON s celým nastavením');
```

Další uložení přepíše předchozí.

```js
saveSettings(DEFAULT_SETTINGS);
saveSettings(withTheme(DEFAULT_SETTINGS, 'light'));
assert.equal(JSON.parse(localStorage.getItem(STORAGE_KEY)).theme, 'light', "po druhém saveSettings s theme 'light' má být uložené theme 'light'");
```

# --help--

## --tip--

Proč text a jak na něj — viz [JSON: data jako text](see:js-objekty/kopie-a-json#json-data-jako-text).

## --tip--

Do `localStorage.setItem` dej jako první argument konstantu `STORAGE_KEY` a jako druhý nastavení převedené přes `JSON.stringify`.

## --tip--

Na jiných datech: `localStorage.setItem('wishlist', JSON.stringify(wishlist))`.

// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}
