# --description--
Aby uživatel nemusel nastavovat aplikaci při každé návštěvě znovu, uložíme `userSettings` do úložiště prohlížeče (`localStorage`).

V obsluze formuláře (po úpravě `currentSettings`) převeď objekt `userSettings` na JSON řetězec pomocí `JSON.stringify` a ulož ho do `localStorage` pod klíčem `"appSettings"`.
# --hints--

Zkontroluj:

```javascript
  // ... uvnitř event listeneru
  currentSettings = { ...defaultSettings, ...userSettings };
  applySettings(currentSettings);
  
  localStorage.setItem('appSettings', JSON.stringify(userSettings));
```




Zkontroluj, zda procházejí testy:
```javascript
const saved = localStorage.getItem('appSettings');
assert(saved, "V `localStorage` by měla být uložena hodnota pod klíčem 'appSettings'.");
const parsed = JSON.parse(saved);
assert(typeof parsed === 'object', "Uložená data musí být platný JSON (objekt).");
```
