# --description--
Přidej do `main.js` posluchač události pro kliknutí na tlačítko reset. 

Když uživatel klikne, odstraň klíč `"appSettings"` z `localStorage`, vyprázdni objekt `userSettings`, sestav znovu `currentSettings` (což nyní bude rovno výchozímu nastavení) a aplikuj je.
# --hints--
Budete potřebovat `localStorage.removeItem('appSettings')` a `userSettings = {}`. Pak jen znovu `currentSettings = { ...defaultSettings }` a `applySettings(currentSettings)`.




Zkontroluj, zda procházejí testy:
```javascript
const resetBtn = document.getElementById('resetBtn');
resetBtn.dispatchEvent(new Event('click'));
assert(localStorage.getItem('appSettings') === null, "Po kliknutí na reset by měla být data z localStorage vymazána.");
```
