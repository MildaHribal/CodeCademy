# --description--
Přidej do `index.html` nový element, kam vypíšeme datum poslední změny, například `<p id="lastUpdatedText"></p>`.

V HTML ho připrav, a následně ho v JS (ve funkci `applySettings`) naplň textem, který bude datum v čitelném formátu zobrazovat. Použij třeba metodu `.toLocaleString()`.
Pokud nastavení ještě uloženo nebylo, text nech prázdný.
# --hints--

Zkontroluj:

```html
<!-- Přidej do index.html někam pod formulář -->
<p id="lastUpdatedText"></p>
```
```javascript
// Do applySettings:
const dateElement = document.getElementById('lastUpdatedText');
if (settings.lastUpdated) {
  dateElement.textContent = "Poslední úprava: " + settings.lastUpdated.toLocaleString('cs-CZ');
} else {
  dateElement.textContent = "";
}
```




Zkontroluj, zda procházejí testy:
```javascript
assert(document.getElementById('lastUpdatedText') !== null, "HTML (index.html) by mělo obsahovat element s id 'lastUpdatedText'.");
```
