# --description--

Panel se otevírá nad **konceptem** nastavení. Uživatel v něm může změnit cokoli v libovolné skupině a tlačítko **Zrušit** koncept zahodí. Starší kód panelu, který zatím nikdo nepřepsal, do konceptu zapisuje přímo, třeba `draft.playback.speed = 2`.

**Úkol:** Napiš funkci `draftFrom(settings)`, která vrátí kopii nastavení, do které jde zapisovat v jakémkoli patře, aniž by se změnil originál.

- Skupiny `playback`, `downloads` a `notifications` musí být v konceptu nové objekty.
- `lastSynced` musí zůstat datem (`Date`), a to vlastním: změna data v konceptu nesmí změnit datum v originálu.
- `lastSynced: null` zůstane `null`.

Nástroj si vyber sám. Až budeš mít hotovo, rozmysli si, proč některá kopie z lekce neprojde.

# --hints--

Zápis do skupiny konceptu nezmění originál.

```js
const settings = loadSettings();
const draft = draftFrom(settings);
draft.playback.speed = 2;
draft.downloads.quality = 'nízká';
assert.equal(settings.playback.speed, 1, 'po zápisu draft.playback.speed = 2 má mít originál pořád rychlost 1');
assert.equal(settings.downloads.quality, 'vysoká', "po zápisu do draft.downloads má mít originál pořád kvalitu 'vysoká'");
assert.deepEqual(draftFrom(settings), settings, 'draftFrom(settings) má mít stejné hodnoty jako settings');
```

Datum synchronizace zůstane v konceptu vlastním datem.

```js
const settings = markSynced(loadSettings(), new Date('2026-09-14T10:00:00Z'));
const draft = draftFrom(settings);
assert.equal(draft.lastSynced instanceof Date, true, 'draftFrom má lastSynced nechat datem (Date), ne textem');
assert.equal(draft.lastSynced.getTime(), settings.lastSynced.getTime(), 'draftFrom má zachovat stejný okamžik synchronizace');
draft.lastSynced.setFullYear(2020);
assert.equal(settings.lastSynced.getFullYear(), 2026, 'změna data v konceptu nesmí změnit datum v originálu');
```

Bez synchronizace zůstane `lastSynced` `null`.

```js
assert.equal(draftFrom(loadSettings()).lastSynced, null, 'draftFrom pro nastavení bez synchronizace má nechat lastSynced: null');
```

# --help--

## --tip--

Porovnej tabulku [Kterou kopii vybrat](see:js-objekty/kopie-a-json#kterou-kopii-vybrat) s tím, co koncept potřebuje.

## --tip--

Mělká kopie nevytvoří nové skupiny a JSON z data udělá text. Zbývá vestavěná funkce na hlubokou kopii, nebo ruční kopie po patrech včetně nového data.

## --tip--

Podcíle na jiných datech — koncept objednávky s datem doručení:

```js
// 1. kopie, ve které je nový objekt v každém patře
// 2. datum doručení jako nový Date se stejným časem (null nech null)
```

# --explain--

Vysvětli vlastními slovy, proč na koncept nastavení nestačí `{ ...settings }` ani `JSON.parse(JSON.stringify(settings))`.

## --model--

Spread vytvoří nový jen vnější objekt, skupiny v konceptu by byly tytéž objekty jako v originálu, a zápis `draft.playback.speed` by změnil uložené nastavení. Kopie přes JSON sice vytvoří nové objekty ve všech patrech, ale datum převede na text, takže `lastSynced` přestane být datem. `structuredClone` zkopíruje všechna patra a datum nechá datem, proto je na koncept správná volba.

## --checklist--

- Mělká kopie sdílí vnořené skupiny s originálem.
- Kopie přes JSON převede datum na text.
- `structuredClone` vytvoří nové objekty ve všech patrech.
- `structuredClone` zachová datum jako `Date`.

## --file-- script.js

```js
// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${new Date(settings.lastSynced).toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}

// Uloží nastavení do localStorage jako JSON.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(settings));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}

// Úplné nastavení při startu: uložené hodnoty doplněné výchozími.
function loadSettings() {
  return mergeSettings(DEFAULT_SETTINGS, readSaved());
}

// Nastavení z vloženého textu, nebo null, když to nastavení není.
function importSettings(text) {
  let parsed;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  if (typeof parsed !== 'object' || parsed === null) {
    return null;
  }
  return mergeSettings(DEFAULT_SETTINGS, parsed);
}

// JSON k exportu: bez data synchronizace, odsazený pro čtení.
function exportSettings(settings) {
  const { lastSynced, ...exportable } = settings;
  return JSON.stringify(exportable, null, 2);
}

// Nastavení ze starého plochého formátu (verze 1) do formátu se skupinami.
function migrateV1(saved) {
  const { speed, wifiOnly, ...rest } = saved;
  const playback = {};
  if (speed !== undefined) {
    playback.speed = speed;
  }
  const downloads = {};
  if (wifiOnly !== undefined) {
    downloads.wifiOnly = wifiOnly;
  }
  return { ...rest, playback, downloads };
}

// Nové nastavení s datem synchronizace, bez data aktuální čas.
function markSynced(settings, now = new Date()) {
  return { ...settings, lastSynced: now };
}
```
