# --description--
Začneme přípravou uživatelského rozhraní pro nastavení naší aplikace. Vytvoř jednoduchý formulář v HTML a přidej trochu CSS.

Vytvoř soubor `index.html` a vlož do něj základní kostru s formulářem, který obsahuje inputy pro "Téma" (světlé/tmavé), "Notifikace" (checkbox) a tlačítko "Uložit". Přidej také `style.css`.
# --hints--

Zkontroluj:

```html
<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <title>Nastavení</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="settings-panel">
    <h2>Nastavení aplikace</h2>
    <form id="settingsForm">
      <label>
        Téma:
        <select id="theme" name="theme">
          <option value="light">Světlé</option>
          <option value="dark">Tmavé</option>
        </select>
      </label>
      <label>
        <input type="checkbox" id="notifications" name="notifications">
        Povolit notifikace
      </label>
      <button type="submit">Uložit</button>
    </form>
  </div>
  <script src="main.js"></script>
</body>
</html>
```
```css
body {
  font-family: sans-serif;
  padding: 20px;
}
.settings-panel {
  max-width: 400px;
  border: 1px solid #ccc;
  padding: 20px;
  border-radius: 8px;
}
label {
  display: block;
  margin-bottom: 10px;
}
```

```javascript
const html = document.body.innerHTML;
assert(html.includes('id="settingsForm"'), "HTML (index.html) by mělo obsahovat formulář s id 'settingsForm'.");
assert(html.includes('id="theme"'), "HTML by mělo obsahovat input/select s id 'theme'.");
```
