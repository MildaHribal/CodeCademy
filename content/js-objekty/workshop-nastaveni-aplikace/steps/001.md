# --description--

Každá aplikace má panel **Nastavení**: rychlost přehrávání, stahování jen přes Wi-Fi, tmavé téma. Nastavení musí přežít obnovení stránky, tlačítko **Zrušit** má vrátit, co bylo uložené, a nová verze aplikace nesmí rozbít, co si uživatel uložil loni. V tomhle workshopu postavíš panel nastavení přehrávače podcastů, který tohle všechno umí.

V souboru `script.js` jsou výchozí nastavení `DEFAULT_SETTINGS` se třemi skupinami (`playback`, `downloads`, `notifications`), klíč pro úložiště a dvě funkce od kolegy, ke kterým se ještě vrátíš.

Začneš tím, co znáš z minulého workshopu, a to bez návodu.

**Úkol:** Napiš funkci `withTheme(settings, theme)`, která vrátí nové nastavení s tématem `theme`. Objekt `settings` se nesmí změnit.

# --hints--

`withTheme` vrátí nastavení s novým tématem a ostatními údaji stejnými.

```js
const result = withTheme(DEFAULT_SETTINGS, 'dark');
assert.equal(result.theme, 'dark', "withTheme(DEFAULT_SETTINGS, 'dark').theme má být 'dark'");
assert.deepEqual(result.playback, DEFAULT_SETTINGS.playback, 'withTheme má zachovat hodnoty skupiny playback');
```

Výchozí nastavení se nezmění.

```js
const result = withTheme(DEFAULT_SETTINGS, 'dark');
assert.equal(DEFAULT_SETTINGS.theme, 'system', "po withTheme(DEFAULT_SETTINGS, 'dark') má mít DEFAULT_SETTINGS pořád theme 'system'");
assert.notEqual(result, DEFAULT_SETTINGS, 'withTheme má vrátit nový objekt');
```


```js
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}
```

# --solution--

## --file-- script.js

```js
// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}
```
