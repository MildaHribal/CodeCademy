# --description--

Nad tlačítky panelu svítí „Neuložené změny", když se koncept liší od uloženého nastavení. Koncept ale vzniká jinak než uložené nastavení (z formuláře, z importu, z předvolby), takže klíče nemusí být ve stejném pořadí.

**Úkol:** Napiš funkci `hasUnsavedChanges(saved, draft)`, která vrátí `true`, když se hodnoty konceptu liší od uloženého nastavení, jinak `false`.

- Pořadí klíčů nerozhoduje: stejné hodnoty v jiném pořadí nejsou změna.
- Dva různé objekty `Date` se stejným okamžikem nejsou změna.

Kandidáti: `===`, porovnání JSON textů, nebo porovnání JSON textů až po sloučení s výchozím nastavením. Než vybereš, rozmysli si, v jakém pořadí klíčů vrací objekt `mergeSettings`.

# --hints--

Stejné hodnoty v jiném objektu a v jiném pořadí klíčů nejsou změna.

```js
const saved = loadSettings();
const draft = {
  notifications: { weeklySummary: false, newEpisodes: true },
  playback: { autoplay: true, skipSeconds: 15, speed: 1 },
  downloads: { keepEpisodes: 5, quality: 'vysoká', wifiOnly: true },
  lastSynced: null,
  theme: 'system',
};
assert.equal(hasUnsavedChanges(saved, draft), false, 'hasUnsavedChanges má vrátit false — koncept má stejné hodnoty, jen klíče v jiném pořadí');
assert.equal(hasUnsavedChanges(saved, draftFrom(saved)), false, 'hasUnsavedChanges(saved, draftFrom(saved)) má vrátit false');
```

Změněná hodnota je změna.

```js
const saved = loadSettings();
const draft = draftFrom(saved);
draft.playback.speed = 1.5;
assert.equal(hasUnsavedChanges(saved, draft), true, 'hasUnsavedChanges má vrátit true po změně rychlosti v konceptu');
assert.equal(hasUnsavedChanges(saved, withTheme(saved, 'dark')), true, "hasUnsavedChanges má vrátit true po změně tématu");
```

Stejný okamžik synchronizace v jiném objektu `Date` není změna.

```js
const saved = markSynced(loadSettings(), new Date('2026-09-14T10:00:00Z'));
const draft = markSynced(loadSettings(), new Date('2026-09-14T10:00:00Z'));
assert.equal(hasUnsavedChanges(saved, draft), false, 'hasUnsavedChanges má vrátit false pro dvě data se stejným okamžikem');
```

# --help--

## --tip--

Proč na pořadí klíčů záleží, ukazuje past [Porovnání objektů přes JSON](see:js-objekty/kopie-a-json#porovnani-objektu-pres-json).

## --tip--

`===` porovná identitu, JSON text pořadí klíčů. `mergeSettings` ale staví výsledek vždycky v pořadí klíčů výchozího nastavení — sluč s ním obě strany a teprve pak porovnej jejich JSON.

## --tip--

Podcíle na jiných datech — změněný filtr produktů:

```js
// 1. obě strany sluč s výchozím filtrem (stejné pořadí klíčů)
// 2. porovnej jejich JSON texty
```

# --explain--

Vysvětli vlastními slovy, proč `hasUnsavedChanges` nejdřív obě nastavení slučuje s výchozím a teprve pak porovnává jejich JSON.

## --model--

`===` u objektů říká jen to, jestli jde o tentýž objekt, a koncept je vždycky jiný objekt. JSON text porovná hodnoty, ale vypíše klíče v pořadí, v jakém v objektu vznikly, takže stejná data v jiném pořadí dají jiný text. Sloučení s výchozím nastavením postaví obě strany ve stejném pořadí klíčů, a teprve pak se dají texty spolehlivě porovnat. Datum se v JSON změní na text se stejným okamžikem, takže dvě stejná data vyjdou stejně.

## --checklist--

- `===` u objektů porovnává identitu, ne hodnoty.
- `JSON.stringify` vypisuje klíče v pořadí jejich vzniku.
- Sloučení s výchozím nastavením srovná pořadí klíčů obou stran.
- Dvě data se stejným okamžikem dají v JSON stejný text.

// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign({}, DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${new Date(settings.lastSynced).toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}

// Uloží nastavení do localStorage jako JSON.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(settings));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}

// Úplné nastavení při startu: uložené hodnoty doplněné výchozími.
function loadSettings() {
  return mergeSettings(DEFAULT_SETTINGS, readSaved());
}

// Nastavení z vloženého textu, nebo null, když to nastavení není.
function importSettings(text) {
  let parsed;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  if (typeof parsed !== 'object' || parsed === null) {
    return null;
  }
  return mergeSettings(DEFAULT_SETTINGS, parsed);
}

// JSON k exportu: bez data synchronizace, odsazený pro čtení.
function exportSettings(settings) {
  const { lastSynced, ...exportable } = settings;
  return JSON.stringify(exportable, null, 2);
}

// Nastavení ze starého plochého formátu (verze 1) do formátu se skupinami.
function migrateV1(saved) {
  const { speed, wifiOnly, ...rest } = saved;
  const playback = {};
  if (speed !== undefined) {
    playback.speed = speed;
  }
  const downloads = {};
  if (wifiOnly !== undefined) {
    downloads.wifiOnly = wifiOnly;
  }
  return { ...rest, playback, downloads };
}

// Nové nastavení s datem synchronizace, bez data aktuální čas.
function markSynced(settings, now = new Date()) {
  return { ...settings, lastSynced: now };
}

// Koncept nastavení: hluboká kopie, do které jde zapisovat.
function draftFrom(settings) {
  return structuredClone(settings);
}

// Krátký JSON ke sdílení: jen téma a přehrávání.
function shareableSettings(settings) {
  return JSON.stringify({ theme: settings.theme, playback: settings.playback });
}
