# --description--
Když se aplikace načte a nebo když uživatel změní nastavení, musíme vytvořit konečnou podobu nastavení (`currentSettings`). 

Ta vznikne sloučením `defaultSettings` a `userSettings`. K tomu využij operátor `spread` (tři tečky). 
Zavolej sloučení a `applySettings(currentSettings)` rovnou v obsluze formuláře po odeslání.

# --hints--

Zkontroluj:

```javascript
form.addEventListener('submit', (e) => {
  e.preventDefault();
  
  userSettings = {
    theme: document.getElementById('theme').value,
    notifications: document.getElementById('notifications').checked
  };
  
  currentSettings = { ...defaultSettings, ...userSettings };
  applySettings(currentSettings);
});
```




Zkontroluj, zda procházejí testy:
```javascript
userSettings = { theme: 'dark' };
currentSettings = { ...defaultSettings, ...userSettings };
assert(currentSettings.theme === 'dark', "V `currentSettings` by měla převážit hodnota z `userSettings` (theme: 'dark').");
assert(currentSettings.notifications === false, "V `currentSettings` by měla zůstat defaultní hodnota tam, kde chybí v uživatelském (notifications).");
```
