# --description--

Teď už máš všechny kousky pro start aplikace: přečíst, co je uložené, a doplnit to výchozím nastavením.

**Úkol:** Napiš funkci `loadSettings()`, která vrátí úplné nastavení: výchozí nastavení sloučené s tím, co vrátí `readSaved()`. Nový kód skoro nepíšeš, skládáš dvě hotové funkce.

Volání jedné funkce jde rovnou předat jako argument druhé. Na jiných datech:

```js
const cart = mergeCart(EMPTY_CART, readCart());
```

# --hints--

Bez uloženého nastavení vrátí `loadSettings` výchozí hodnoty v novém objektu.

```js
const result = loadSettings();
assert.deepEqual(result, DEFAULT_SETTINGS, 'loadSettings() bez uloženého nastavení má vrátit stejné hodnoty jako DEFAULT_SETTINGS');
assert.notEqual(result, DEFAULT_SETTINGS, 'loadSettings() má vrátit nový objekt, ne DEFAULT_SETTINGS');
```

S uloženou rychlostí vrátí `loadSettings` úplné nastavení.

```js
localStorage.setItem(STORAGE_KEY, '{"playback":{"speed":2}}');
const result = loadSettings();
assert.deepEqual(result.playback, { speed: 2, skipSeconds: 15, autoplay: true }, 'loadSettings() s uloženým { playback: { speed: 2 } } má vrátit playback { speed: 2, skipSeconds: 15, autoplay: true }');
assert.equal(result.theme, 'system', "loadSettings() má theme doplnit z výchozího nastavení");
```

S poškozeným textem vrátí `loadSettings` výchozí hodnoty.

```js
localStorage.setItem(STORAGE_KEY, 'nesmysl');
assert.deepEqual(loadSettings(), DEFAULT_SETTINGS, "loadSettings() s poškozeným textem má vrátit výchozí hodnoty");
```

# --help--

## --tip--

Skládáš sloučení z [Kopie po patrech](see:js-objekty/kopie-a-json#kopie-po-patrech) a bezpečné načtení z minulého kroku.

## --tip--

Vrať výsledek `mergeSettings`: jako výchozí dej `DEFAULT_SETTINGS`, jako uložené výsledek volání `readSaved`.

## --tip--

Na jiných datech: `return mergeFilters(DEFAULT_FILTERS, readFilters());`

// Výchozí nastavení přehrávače podcastů. Uživatel si mění jen část, zbytek se bere odsud.
const DEFAULT_SETTINGS = {
  theme: 'system',
  lastSynced: null,
  playback: { speed: 1, skipSeconds: 15, autoplay: true },
  downloads: { wifiOnly: true, quality: 'vysoká', keepEpisodes: 5 },
  notifications: { newEpisodes: true, weeklySummary: false },
};

// Klíč, pod kterým se nastavení ukládá do localStorage.
const STORAGE_KEY = 'poslech:settings';

// Od kolegy: předvolby, které jde zapnout jedním tlačítkem.
const PRESETS = {
  dataSaver: { downloads: { wifiOnly: true, quality: 'nízká', keepEpisodes: 2 } },
  nightOwl: { theme: 'dark', notifications: { newEpisodes: false, weeklySummary: false } },
};

// Od kolegy: nastavení se zapnutou předvolbou, třeba applyPreset('dataSaver').
function applyPreset(presetName) {
  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);
}

// Od kolegy: text do patičky panelu, třeba 'Synchronizováno 14. 9. 2026'.
function syncedLabel(settings) {
  if (settings.lastSynced === null) {
    return 'Zatím nesynchronizováno';
  }
  return `Synchronizováno ${settings.lastSynced.toLocaleDateString('cs-CZ')}`;
}

// Nové nastavení s jiným tématem.
function withTheme(settings, theme) {
  return { ...settings, theme };
}

// Úplné nastavení: uložené hodnoty přes výchozí, každá skupina sloučená zvlášť.
function mergeSettings(defaults, saved) {
  return {
    ...defaults,
    ...saved,
    playback: { ...defaults.playback, ...saved.playback },
    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },
  };
}

// Uloží nastavení do localStorage jako JSON.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(settings));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}
