# --description--
Použij znalost z předchozího kroku a uprav část, kde nastavuješ `userSettings` (jak při uložení, tak při načtení).

Při ukládání přidej aktuální datum do `userSettings.lastUpdated`. 
Při načítání ze `localStorage` zkontroluj, jestli existuje `userSettings.lastUpdated`, a pokud ano, přehoď jej zpět na instanci objektu `Date`.
# --hints--

Zkontroluj:

```javascript
// Ukládání:
userSettings = {
  theme: document.getElementById('theme').value,
  notifications: document.getElementById('notifications').checked,
  lastUpdated: new Date()
};

// Načítání:
const savedSettings = localStorage.getItem('appSettings');
if (savedSettings) {
  userSettings = JSON.parse(savedSettings);
  if (userSettings.lastUpdated) {
    userSettings.lastUpdated = new Date(userSettings.lastUpdated);
  }
}
```




Zkontroluj, zda procházejí testy:
```javascript
userSettings.lastUpdated = new Date();
assert(userSettings.lastUpdated instanceof Date, "Atribut `lastUpdated` v userSettings musí být typu Date.");
```
