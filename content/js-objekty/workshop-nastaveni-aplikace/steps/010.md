# --description--

## Hlášení

V patičce panelu je text z kolegovy funkce `syncedLabel(settings)`. Hned po synchronizaci funguje: `syncedLabel(markSynced(settings))` vrátí třeba `'Synchronizováno 14. 9. 2026'`.

Když ale uživatel nastavení uloží a obnoví stránku, panel se nevykreslí a v konzoli je:

```text
TypeError: settings.lastSynced.toLocaleDateString is not a function
```

Postup, jak chybu zopakovat: `saveSettings(markSynced(DEFAULT_SETTINGS))` a pak `syncedLabel(loadSettings())`.

## Úkol

Oprav `syncedLabel` tak, aby fungovala s nastavením hned po synchronizaci i s nastavením načteným z úložiště. Změň co nejmenší kus kódu.

# --hints--

`syncedLabel` funguje s nastavením načteným z úložiště.

```js
saveSettings(markSynced(DEFAULT_SETTINGS, new Date('2026-09-14T10:00:00Z')));
assert.equal(syncedLabel(loadSettings()), 'Synchronizováno 14. 9. 2026', "syncedLabel(loadSettings()) po uložení synchronizovaného nastavení má vrátit 'Synchronizováno 14. 9. 2026'");
```

`syncedLabel` dál funguje s datem i bez synchronizace.

```js
assert.equal(syncedLabel(markSynced(DEFAULT_SETTINGS, new Date('2026-03-02T10:00:00Z'))), 'Synchronizováno 2. 3. 2026', "syncedLabel s lastSynced jako Date má vrátit 'Synchronizováno 2. 3. 2026'");
assert.equal(syncedLabel(DEFAULT_SETTINGS), 'Zatím nesynchronizováno', "syncedLabel(DEFAULT_SETTINGS) má vrátit 'Zatím nesynchronizováno'");
```

# --help--

## --tip--

Chyba odpovídá pasti [Datum po JSON](see:js-objekty/kopie-a-json#datum-po-json).

## --tip--

Co je v `lastSynced` po `JSON.stringify` a `JSON.parse`? Z čeho jde postavit datum, když máš jen text — a co udělá stejné volání, když dostane datum?

## --tip--

Na jiných datech: `new Date(order.createdAt).getFullYear()` funguje, ať je `createdAt` datum, nebo text ve formátu ISO.

# --explain--

Vysvětli vlastními slovy, proč `syncedLabel` fungovala hned po synchronizaci, ale po obnovení stránky spadla.

## --model--

Hned po synchronizaci je v `lastSynced` objekt `Date`, který má metodu `toLocaleDateString`. JSON ale data neumí: `JSON.stringify` z data udělá text ve formátu ISO a `JSON.parse` z něj datum zpátky nevyrobí, zůstane text. Text metodu `toLocaleDateString` nemá, a proto volání spadlo. Oprava je postavit datum přes `new Date(…)`, které funguje s textem i s datem.

## --checklist--

- Hned po synchronizaci je v `lastSynced` objekt `Date`.
- `JSON.stringify` převede datum na text.
- `JSON.parse` z textu datum nevyrobí.
- `new Date(…)` postaví datum z textu i z jiného data.

const DEFAULT_SETTINGS = {

};

  return Object.assign(DEFAULT_SETTINGS, PRESETS[presetName]);

    ...saved,

    downloads: { ...defaults.downloads, ...saved.downloads },
    notifications: { ...defaults.notifications, ...saved.notifications },

// Uloží nastavení do localStorage jako JSON.
function saveSettings(settings) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(settings));
}

function readSaved() {
  const text = localStorage.getItem(STORAGE_KEY);
  if (text === null) {
    return {};
  }
  try {
    return JSON.parse(text);
  } catch {
    return {};
  }
}

// Úplné nastavení při startu: uložené hodnoty doplněné výchozími.
function loadSettings() {
  return mergeSettings(DEFAULT_SETTINGS, readSaved());
}

// Nastavení z vloženého textu, nebo null, když to nastavení není.
function importSettings(text) {
  let parsed;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  if (typeof parsed !== 'object' || parsed === null) {
    return null;
  }
  return mergeSettings(DEFAULT_SETTINGS, parsed);
}

// JSON k exportu: bez data synchronizace, odsazený pro čtení.
function exportSettings(settings) {
  const { lastSynced, ...exportable } = settings;
  return JSON.stringify(exportable, null, 2);
}

// Nastavení ze starého plochého formátu (verze 1) do formátu se skupinami.
function migrateV1(saved) {
  const { speed, wifiOnly, ...rest } = saved;
  const playback = {};
  if (speed !== undefined) {
    playback.speed = speed;
  }
  const downloads = {};
  if (wifiOnly !== undefined) {
    downloads.wifiOnly = wifiOnly;
  }
  return { ...rest, playback, downloads };
}

// Nové nastavení s datem synchronizace, bez data aktuální čas.
function markSynced(settings, now = new Date()) {
  return { ...settings, lastSynced: now };
