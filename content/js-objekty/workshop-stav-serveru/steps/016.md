# --description--

Poslední krok. Přibyly soubory `index.html`, `styles.css` a `ui.js` a náhled teď ukazuje hotovou kartu serveru. Soubor `ui.js` volá tvoje funkce a jejich výsledky vypisuje do stránky — jak se to dělá, probere sekce DOM, události a prohlížeč. Na kartě chybí jediná věc: text pod výběrem regionu.

**Úkol:** Ve `script.js` napiš funkci `regionInfo(server, region)`, která vrátí text pro vybraný region ve tvaru `'us: 131 ms, dobrý'`. Když server pro region měření nemá, vrátí `'sa: bez údaje'`. Pozor na server v místní síti: region s odezvou `0` ms měření **má**.

Až testy projdou, vyber v náhledu jiný region a sleduj, jak se text i barva změní hned. Barvu podle hodnocení nastavuje `ui.js` přes tvoje `qualityByRegion`.

Tím je workshop hotový. Za sebou máš:

- čtení vlastností tečkou, do vnořeného objektu i hranatými závorkami,
- vypočítaný klíč a metodu v objektu,
- chybějící hodnoty přes `?.` a `??` a existenci klíče přes `Object.hasOwn`,
- procházení objektu přes `Object.keys`, `Object.values`, `Object.entries` a skládání nového přes `Object.fromEntries`,
- destrukturalizaci v parametru a opravu kolegovy chyby s tečkou místo závorek.

Stejné funkce najdeš za každou kartou, která ukazuje data z API: profil hráče, stav objednávky, počasí podle města. Mění se jen jména klíčů. V další lekci zjistíš, proč se objekt někdy „sám" změní i jinde, a pak podle toho postavíš úpravy profilu uživatele bez rozbitých dat.

## Udělej po svém

- **Vzhled:** když je server plný z víc než 90 %, obarvi pruh s hráči červeně — stačí přidat třídu v `ui.js` a pravidlo v `styles.css`.
- **Funkce:** přidej do dat druhý server a nad kartu tlačítka, která mezi servery přepínají; tvoje funkce dostávají server v parametru, takže je nemusíš měnit.
- **Tvoje téma:** přeměň kartu na stav čehokoli, co tě zajímá — stav vlaků podle stanice, obsazenost posiloven podle poboček, počasí podle měst.

# --hints--

Po načtení stránky je pod výběrem text pro první region: `'eu: 24 ms, výborný'`.

```js
const info = document.querySelector('#region-info');
assert.equal(info.textContent.trim(), 'eu: 24 ms, výborný', "#region-info má po načtení ukazovat 'eu: 24 ms, výborný' — vrací regionInfo(kostkov, 'eu') tenhle text?");
```

Po výběru jiného regionu se text změní.

```js
const select = document.querySelector('#region-select');
select.value = 'asia';
select.dispatchEvent(new Event('change'));
assert.equal(document.querySelector('#region-info').textContent.trim(), 'asia: 248 ms, slabý', "po výběru Asie má #region-info ukazovat 'asia: 248 ms, slabý'");
```

Pro region bez měření vrátí `regionInfo` text `bez údaje`.

```js
assert.equal(regionInfo(kostkov, 'sa'), 'sa: bez údaje', "regionInfo(kostkov, 'sa') má vrátit 'sa: bez údaje' — region sa v ping není");
```

Region s odezvou `0` ms má měření.

```js
const lan = { ping: { lan: 0, eu: 70 } };
assert.equal(regionInfo(lan, 'lan'), 'lan: 0 ms, výborný', "regionInfo({ ping: { lan: 0 } }, 'lan') má vrátit 'lan: 0 ms, výborný' — nula je platná odezva, ne chybějící údaj");
assert.equal(regionInfo(lan, 'eu'), 'eu: 70 ms, dobrý', "regionInfo({ ping: { eu: 70 } }, 'eu') má vrátit 'eu: 70 ms, dobrý'");
```

# --help--

## --tip--

Existenci měření zjistíš stejně jako u pravidel — viz [Existuje ta vlastnost?](see:js-objekty/objekty#existuje-ta-vlastnost).

## --tip--

Nejdřív ověř, jestli `server.ping` má klíč `region`; když ne, vrať text s `bez údaje`. Jinak odezvu přečti přes `pingFor` a hodnocení vezmi z metody `pingQuality.label`.

## --tip--

Podcíle na jiných datech — obsazenost pobočky:

```js
// 1. pobočka v objektu occupancy není → 'Brno: bez údaje'
// 2. jinak přečti počet (i 0 je platný) a vrať 'Brno: 12 lidí, klid'
```

// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules[ruleName];
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}

// Hranice odezvy a jejich slovní hodnocení.
const pingQuality = {
  goodLimit: 60,
  okLimit: 150,
  label(ms) {
    if (ms <= pingQuality.goodLimit) {
      return 'výborný';
    }
    if (ms <= pingQuality.okLimit) {
      return 'dobrý';
    }
    return 'slabý';
  },
};

// Jméno majitele, nebo 'bez majitele'.
function ownerName(server) {
  return server.owner?.name ?? 'bez majitele';
}

// Uvádí server pravidlo se zadaným jménem (i s hodnotou false)?
function hasRule(server, rule) {
  return Object.hasOwn(server.rules, rule);
}

// Z kolika regionů se měří odezva.
function regionCount(server) {
  return Object.keys(server.ping).length;
}

// Průměrná odezva zaokrouhlená na celé ms, bez měření null.
function averagePing(server) {
  const values = Object.values(server.ping);
  if (values.length === 0) {
    return null;
  }
  let total = 0;
  for (const ms of values) {
    total += ms;
  }
  return Math.round(total / values.length);
}

// Popisky odezvy s jednotkou, třeba { eu: '24 ms' }.
function pingLabels(server) {
  const pairs = [];
  for (const [region, ms] of Object.entries(server.ping)) {
    pairs.push([region, `${ms} ms`]);
  }
  return Object.fromEntries(pairs);
}

// Slovní hodnocení odezvy pro každý region.
function qualityByRegion(server) {
  const pairs = [];
  for (const [region, ms] of Object.entries(server.ping)) {
    pairs.push([region, pingQuality.label(ms)]);
  }
  return Object.fromEntries(pairs);
}

// Region s nejnižší odezvou; při shodě ten dřívější, bez měření undefined.
function bestRegion(server) {
  let best;
  let bestPing;
  for (const [region, ms] of Object.entries(server.ping)) {
    if (best === undefined || ms < bestPing) {
      best = region;
      bestPing = ms;
    }
  }
  return best;
}

// Řádek stavu do záhlaví, třeba 'Kostkov Survival · online · 37 z 100 hráčů'.
function statusLine({ name, online, players }) {
  if (!online) {
    return `${name} · offline`;
  }
  return `${name} · online · ${playersText(players.online, players.max)}`;
}

```js
// Propojení s HTML. Práci se stránkou a událostmi probere sekce DOM, události a prohlížeč.
const regionNames = { eu: 'Evropa', us: 'Severní Amerika', asia: 'Asie', sa: 'Jižní Amerika' };
const byId = (id) => document.querySelector(`#${id}`);

byId('status-line').textContent = statusLine(kostkov);
byId('server-title').textContent = serverTitle(kostkov);
byId('server-address').textContent = kostkov.address;
byId('server-motd').textContent = kostkov.motd;
byId('players-label').textContent = playersLabel(kostkov);
byId('owner').textContent = ownerName(kostkov);
byId('average-ping').textContent = `${averagePing(kostkov)} ms`;
byId('best-region').textContent = regionNames[bestRegion(kostkov)];
requestAnimationFrame(() => {
  byId('players-fill').style.width = `${(kostkov.players.online / kostkov.players.max) * 100}%`;
});

const rulesList = byId('rules');
for (const rule of ['pvp', 'whitelist', 'difficulty', 'fly']) {
  if (hasRule(kostkov, rule)) {
    const badge = document.createElement('li');
    badge.textContent = `${rule}: ${ruleValue(kostkov, rule)}`;
    rulesList.append(badge);
  }
}

const select = byId('region-select');
for (const [code, label] of Object.entries(regionNames)) {
  select.append(new Option(label, code));
}

function showRegion() {
  const info = byId('region-info');
  if (typeof regionInfo !== 'function') {
    info.textContent = 'Doplň funkci regionInfo ve script.js.';
    return;
  }
  info.textContent = regionInfo(kostkov, select.value);
  info.dataset.quality = qualityByRegion(kostkov)[select.value] ?? '';
}

select.addEventListener('change', showRegion);
showRegion();
```
