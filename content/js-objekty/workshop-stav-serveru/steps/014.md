# --description--

Vedle popisku odezvy chce karta u každého regionu slovní hodnocení.

**Úkol:** Napiš funkci `qualityByRegion(server)`, která vrátí nový objekt: klíče jsou regiony z `server.ping`, hodnoty slovní hodnocení jejich odezvy z metody `pingQuality.label`. Pro Kostkov tedy objekt s hodnocením `výborný`, `dobrý` a `slabý`. Objekt `ping` se nesmí změnit.

Vzor znáš z minulého kroku, tentokrát ho napíšeš sám.

# --hints--

`qualityByRegion(kostkov)` vrátí hodnocení pro všechny tři regiony.

```js
assert.deepEqual(qualityByRegion(kostkov), { eu: 'výborný', us: 'dobrý', asia: 'slabý' }, "qualityByRegion(kostkov) má vrátit { eu: 'výborný', us: 'dobrý', asia: 'slabý' }");
```

`qualityByRegion` pracuje se serverem z parametru a nemění jeho `ping`.

```js
const lobby = { ping: { sa: 90, oc: 400 } };
assert.deepEqual(qualityByRegion(lobby), { sa: 'dobrý', oc: 'slabý' }, "qualityByRegion({ ping: { sa: 90, oc: 400 } }) má vrátit { sa: 'dobrý', oc: 'slabý' }");
assert.deepEqual(lobby.ping, { sa: 90, oc: 400 }, 'qualityByRegion nesmí změnit původní objekt ping');
```

# --help--

## --tip--

Vzor „rozlož na dvojice, uprav, slož" je v [Procházení objektu](see:js-objekty/objekty#prochazeni-objektu-object-keys-values-a-entries) a v minulém kroku.

## --tip--

Postup je stejný jako v `pingLabels`, mění se jen druhá položka každé dvojice: místo textu s jednotkou do ní patří výsledek metody `label`.

## --tip--

Podcíle na jiných datech — známky slovy:

```js
// 1. prázdné pole dvojic
// 2. pro každou dvojici [předmět, známka] z objektu grades přidej [předmět, slovní hodnocení známky]
// 3. z dvojic slož objekt a vrať ho
```

# --explain--

Vysvětli vlastními slovy, proč funkce `qualityByRegion` sestavuje nový objekt přes dvojice, místo aby do objektu `server.ping` rovnou zapsala hodnocení.

## --model--

Objekt `ping` patří datům serveru a může ho používat i jiná část stránky, třeba průměrná odezva. Kdyby funkce do něj zapsala texty, přepsala by čísla a průměr by se rozbil. Proto si z objektu vezmu dvojice klíč a hodnota, každou upravím a přes `Object.fromEntries` z nich složím nový objekt. Původní data zůstanou, jak byla.

## --checklist--

- Zápis do `server.ping` by změnil data, která používají i jiné funkce.
- `Object.entries` rozloží objekt na dvojice klíč a hodnota.
- Upravené dvojice složí do nového objektu `Object.fromEntries`.
- Původní objekt zůstane beze změny.

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules[ruleName];
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}

// Od kolegy: jedno měření pro graf odezvy, třeba measurement('eu', 24).
const measurement = (region, ms) => ({ region, ms });

// Hranice odezvy a jejich slovní hodnocení.
const pingQuality = {
  goodLimit: 60,
  okLimit: 150,
  label(ms) {
    if (ms <= pingQuality.goodLimit) {
      return 'výborný';
    }
    if (ms <= pingQuality.okLimit) {
      return 'dobrý';
    }
    return 'slabý';
  },
};

// Jméno majitele, nebo 'bez majitele'.
function ownerName(server) {
  return server.owner?.name ?? 'bez majitele';
}

// Uvádí server pravidlo se zadaným jménem (i s hodnotou false)?
function hasRule(server, rule) {
  return Object.hasOwn(server.rules, rule);
}

// Z kolika regionů se měří odezva.
function regionCount(server) {
  return Object.keys(server.ping).length;
}

// Průměrná odezva zaokrouhlená na celé ms, bez měření null.
function averagePing(server) {
  const values = Object.values(server.ping);
  if (values.length === 0) {
    return null;
  }
  let total = 0;
  for (const ms of values) {
    total += ms;
  }
  return Math.round(total / values.length);
}

// Popisky odezvy s jednotkou, třeba { eu: '24 ms' }.
function pingLabels(server) {
  const pairs = [];
  for (const [region, ms] of Object.entries(server.ping)) {
    pairs.push([region, `${ms} ms`]);
  }
  return Object.fromEntries(pairs);
}
```
