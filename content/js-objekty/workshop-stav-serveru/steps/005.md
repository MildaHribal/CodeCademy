# --description--

Monitorovací služba posílá nové měření jako malý objekt, ve kterém je klíčem region a hodnotou odezva: `{ asia: 231 }`. Takový objekt budeš umět vyrobit.

**Úkol:** Napiš funkci `pingEntry(region, ms)`, která vrátí objekt s jedinou vlastností: klíčem je text z `region`, hodnotou `ms`. Třeba `pingEntry('asia', 231)` vrátí `{ asia: 231 }`.

Klíč, který se má vyhodnotit z proměnné, napiš do zápisu objektu v hranatých závorkách. Na jiných datech:

```js
function translation(lang, text) {
  return { [lang]: text };
}
```

# --hints--

`pingEntry('asia', 231)` vrátí `{ asia: 231 }`.

```js
assert.deepEqual(pingEntry('asia', 231), { asia: 231 }, "pingEntry('asia', 231) má vrátit { asia: 231 }");
```

Klíč se bere z hodnoty parametru, ne ze jména `region`.

```js
const entry = pingEntry('eu', 18);
assert.deepEqual(entry, { eu: 18 }, "pingEntry('eu', 18) má vrátit { eu: 18 } — objekt nemá mít klíč region");
assert.equal(Object.hasOwn(entry, 'region'), false, "pingEntry('eu', 18) nesmí vytvořit klíč region");
```

## --tip--

## --tip--

Bez hranatých závorek vznikne objekt s klíčem, který se doslova jmenuje `region`. Klíč obal do `[ ]`.

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}
```
