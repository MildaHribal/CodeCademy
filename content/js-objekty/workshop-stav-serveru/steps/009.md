# --description--

Pod kartou jsou štítky s pravidly serveru. Štítek se má ukázat pro každé pravidlo, které server **uvádí** — i když je jeho hodnota `false`. `pvp: false` je důležitá informace („tady se nebojuje"), ne chybějící údaj.

**Úkol:** Napiš funkci `hasRule(server, rule)`, která vrátí `true`, když objekt `server.rules` má vlastní klíč se jménem `rule`, jinak `false`.

Kandidáti: podmínka na hodnotu `server.rules[rule]`, operátor `in`, nebo `Object.hasOwn`. Než vybereš, projdi si data serveru Kostkov a rozmysli, co každý z nich udělá s `pvp` a s textem `'toString'`.

# --hints--

`hasRule(kostkov, 'pvp')` vrátí `true`, i když je hodnota pravidla `false`.

```js
assert.equal(hasRule(kostkov, 'pvp'), true, "hasRule(kostkov, 'pvp') má vrátit true — pravidlo pvp v datech je, jen má hodnotu false");
```

`hasRule(kostkov, 'difficulty')` vrátí `true` a `hasRule(kostkov, 'fly')` vrátí `false`.

```js
assert.equal(hasRule(kostkov, 'difficulty'), true, "hasRule(kostkov, 'difficulty') má vrátit true");
assert.equal(hasRule(kostkov, 'fly'), false, "hasRule(kostkov, 'fly') má vrátit false — pravidlo fly v datech není");
```

`hasRule` nepočítá zděděné vlastnosti jako pravidla.

```js
assert.equal(hasRule(kostkov, 'toString'), false, "hasRule(kostkov, 'toString') má vrátit false — toString objekt jen zdědil, pravidlo to není");
```

# --help--

## --tip--

Ptáš se na existenci klíče, ne na hodnotu — viz [Existuje ta vlastnost?](see:js-objekty/objekty#existuje-ta-vlastnost).

## --tip--

Podmínka na hodnotu selže u `pvp: false`, operátor `in` najde i zděděné `toString`. Zbývá funkce, která dostane objekt `server.rules` a jméno klíče.

## --tip--

Stejný vzor na jiných datech — rozepsaný na podcíle:

```js
// 1. funkce hasAnswer(answers, question)
// 2. vrátí, jestli objekt answers má vlastní klíč question (odpověď 0 nebo '' se počítá)
```

# --explain--

Vysvětli vlastními slovy, proč `if (server.rules[rule])` ani `rule in server.rules` na otázku „uvádí server tohle pravidlo?" nestačí a co dělá `Object.hasOwn` jinak.

## --model--

Podmínka `if (server.rules[rule])` se ptá na hodnotu, ne na existenci, a hodnoty `false`, `0` nebo `''` jsou v podmínce nepravda, takže existující pravidlo `pvp: false` by se tvářilo jako chybějící. Operátor `in` se ptá na existenci klíče, ale počítá i vlastnosti, které objekt zdědil, třeba `toString`. `Object.hasOwn` se dívá jen na vlastní klíče objektu a hodnota nerozhoduje.

## --checklist--

- Podmínka na hodnotu selže u existujících hodnot `false`, `0` a `''`.
- Operátor `in` najde i zděděné vlastnosti jako `toString`.
- `Object.hasOwn` se dívá jen na vlastní klíče objektu.
- U `Object.hasOwn` nerozhoduje, jakou hodnotu klíč má.

// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}

// Od kolegy: jedno měření pro graf odezvy, třeba measurement('eu', 24).

// Hranice odezvy a jejich slovní hodnocení.
const pingQuality = {
  goodLimit: 60,
  okLimit: 150,
  label(ms) {
    if (ms <= pingQuality.goodLimit) {
      return 'výborný';
    }
    if (ms <= pingQuality.okLimit) {
      return 'dobrý';
    }
    return 'slabý';
  },
};

// Jméno majitele, nebo 'bez majitele'.
function ownerName(server) {
  return server.owner?.name ?? 'bez majitele';
}

// Uvádí server pravidlo se zadaným jménem (i s hodnotou false)?
function hasRule(server, rule) {
  return Object.hasOwn(server.rules, rule);
}
