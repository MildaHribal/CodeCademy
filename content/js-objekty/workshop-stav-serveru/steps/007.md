# --description--

Hráče číslo `131` moc nezajímá. Chce vědět, jestli se bude hrát dobře. Hodnocení odezvy patří k jejím hranicím, a proto ho uložíš do jednoho objektu: hranice jako vlastnosti a výpočet jako metodu.

**Úkol:** Založ konstantu `pingQuality` s objektem, který má vlastnosti `goodLimit: 60` a `okLimit: 150` a metodu `label(ms)`. Metoda vrátí `'výborný'`, když je `ms` nejvýš `goodLimit`, `'dobrý'`, když je nejvýš `okLimit`, a jinak `'slabý'`. Hranice čti z vlastností objektu, ne jako čísla v podmínkách.

Metodu zapíšeš zkráceně jako `jméno(parametry) { … }` a vlastnosti objektu přečteš přes jméno konstanty. Na jiných datech:

```js
const temperature = {
  hotLimit: 30,
  describe(celsius) {
    return celsius >= temperature.hotLimit ? 'horko' : 'příjemně';
  },
};
```

# --hints--

`pingQuality.label` je funkce a hranice jsou `goodLimit: 60` a `okLimit: 150`.

```js
assert.equal(typeof pingQuality.label, 'function', 'pingQuality.label má být metoda (funkce ve vlastnosti label)');
assert.equal(pingQuality.goodLimit, 60, 'pingQuality.goodLimit má být 60');
assert.equal(pingQuality.okLimit, 150, 'pingQuality.okLimit má být 150');
```

`pingQuality.label` vrátí `'výborný'` do 60 ms včetně.

```js
assert.equal(pingQuality.label(24), 'výborný', "pingQuality.label(24) má vrátit 'výborný'");
assert.equal(pingQuality.label(60), 'výborný', "pingQuality.label(60) má vrátit 'výborný' — hranice 60 ms ještě patří k výborné odezvě");
```

`pingQuality.label` vrátí `'dobrý'` od 61 do 150 ms a `'slabý'` nad 150 ms.

```js
assert.equal(pingQuality.label(61), 'dobrý', "pingQuality.label(61) má vrátit 'dobrý'");
assert.equal(pingQuality.label(150), 'dobrý', "pingQuality.label(150) má vrátit 'dobrý' — hranice 150 ms ještě patří k dobré odezvě");
assert.equal(pingQuality.label(248), 'slabý', "pingQuality.label(248) má vrátit 'slabý'");
```

Metoda bere hranice z vlastností objektu.

```js
pingQuality.goodLimit = 30;
assert.equal(pingQuality.label(45), 'dobrý', "po změně pingQuality.goodLimit na 30 má label(45) vrátit 'dobrý' — čte metoda hranici z vlastnosti goodLimit?");
```

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}

// Od kolegy: jedno měření pro graf odezvy, třeba measurement('eu', 24).
const measurement = (region, ms) => ({ region, ms });

// Hranice odezvy a jejich slovní hodnocení.
const pingQuality = {
  goodLimit: 60,
  okLimit: 150,
  label(ms) {
    if (ms <= pingQuality.goodLimit) {
      return 'výborný';
    }
    if (ms <= pingQuality.okLimit) {
      return 'dobrý';
    }
    return 'slabý';
  },
};
```
