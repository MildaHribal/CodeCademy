# --description--

Karta ukazuje, kdo server provozuje. Údaj `owner` ale není vždycky vyplněný: u serveru Kostkov je `null`, jiné servery ho v datech nemají vůbec, a když ho mají, je to objekt, třeba `{ name: 'Tonda77', since: 2021 }`.

**Úkol:** Napiš funkci `ownerName(server)`, která vrátí jméno majitele, a když majitel chybí nebo je `null`, vrátí text `'bez majitele'`. Funkce nesmí spadnout.

Vybírej ze tří nástrojů z lekce: volitelné řetězení `?.`, operátor `??`, nebo podmínka `if`. Některé z nich se dají spojit.

# --hints--

Pro server s `owner: null` vrátí `ownerName` text `'bez majitele'`.

```js
assert.equal(ownerName(kostkov), 'bez majitele', "ownerName(kostkov) má vrátit 'bez majitele' — owner je null");
```

Pro server bez vlastnosti `owner` vrátí `ownerName` text `'bez majitele'`.

```js
assert.equal(ownerName({ name: 'Lobby' }), 'bez majitele', "ownerName({ name: 'Lobby' }) má vrátit 'bez majitele' — owner v objektu vůbec není");
```

Pro server s majitelem vrátí `ownerName` jeho jméno.

```js
const craft = { name: 'CraftCZ', owner: { name: 'Tonda77', since: 2021 } };
assert.equal(ownerName(craft), 'Tonda77', "ownerName({ owner: { name: 'Tonda77' } }) má vrátit 'Tonda77'");
```

# --help--

## --tip--

Jde o čtení z hodnoty, která může chybět — viz [Volitelné řetězení `?.`](see:js-objekty/objekty#volitelne-retezeni).

## --tip--

`server.owner.name` spadne, když je `owner` `null` nebo `undefined`. Na místo té tečky, která padá, patří `?.` a náhradní text doplní `??`.

## --tip--

Stejný vzor na jiných datech: kurýr u objednávky, která ho nemusí mít, rozepsaný na podcíle:

```js
// 1. přečti order.courier a jeho name tak, aby chybějící kurýr nespadl
// 2. když výsledek chybí, vrať 'zatím nepřiřazen'
```

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}

// Hranice odezvy a jejich slovní hodnocení.
const pingQuality = {
  goodLimit: 60,
  okLimit: 150,
  label(ms) {
    if (ms <= pingQuality.goodLimit) {
      return 'výborný';
    }
    if (ms <= pingQuality.okLimit) {
      return 'dobrý';
    }
    return 'slabý';
  },
};

// Jméno majitele, nebo 'bez majitele'.
function ownerName(server) {
  return server.owner?.name ?? 'bez majitele';
}
```
