# --description--

Počet hráčů je ve vnořeném objektu `players`: `{ online: 37, max: 100 }`.

**Úkol:** Napiš funkci `playersLabel(server)`, která vrátí text o hráčích, třeba `'37 z 100 hráčů'`. Nepiš text znovu — zavolej `playersText` z prvního kroku a předej jí `online` a `max` z objektu `players`.

Do vnořeného objektu vedou tečky za sebou. Na jiných datech:

```js
function cityOf(order) {
  return order.address.city;
}
```

# --hints--

`playersLabel(kostkov)` vrátí `'37 z 100 hráčů'`.

```js
assert.equal(playersLabel(kostkov), '37 z 100 hráčů', "playersLabel(kostkov) má vrátit '37 z 100 hráčů'");
```

`playersLabel` čte `online` a `max` z objektu `players` serveru v parametru.

```js
const lobby = { name: 'Lobby', players: { online: 4, max: 20 } };
assert.equal(playersLabel(lobby), '4 z 20 hráčů', "playersLabel({ players: { online: 4, max: 20 } }) má vrátit '4 z 20 hráčů'");
```

# --help--

## --tip--

Jde o vnořený objekt a tečky za sebou — viz [Objekt a tečka](see:js-objekty/objekty#objekt-a-tecka).

## --tip--

Funkce vrátí výsledek volání `playersText`; jako argumenty jí dej `server.players` a za tečkou jméno vlastnosti.

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}
```
