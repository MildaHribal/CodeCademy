# --description--

V seznamu regionů má každý region u sebe odezvu i s jednotkou. Z objektu `{ eu: 24, us: 131 }` tedy potřebuješ **nový objekt** `{ eu: '24 ms', us: '131 ms' }`.

Tohle je vzor, který v práci s objekty potkáš pořád: rozlož objekt na dvojice, každou dvojici uprav a z upravených dvojic slož nový objekt.

**Úkol:** Seřaď řádky tak, aby funkce `pingLabels(server)` vrátila nový objekt s popisky a objekt `server.ping` nechala beze změny. Odsazení nastavíš klávesou Tab. Doplň chybějící volání a pozor, dva řádky jsou navíc.

# --hints--

`pingLabels(kostkov)` vrátí `{ eu: '24 ms', us: '131 ms', asia: '248 ms' }`.

```js
assert.deepEqual(pingLabels(kostkov), { eu: '24 ms', us: '131 ms', asia: '248 ms' }, "pingLabels(kostkov) má vrátit { eu: '24 ms', us: '131 ms', asia: '248 ms' }");
```

`pingLabels` nemění objekt `ping` a pro prázdný `ping` vrátí prázdný objekt.

```js
const lobby = { ping: { sa: 190 } };
assert.deepEqual(pingLabels(lobby), { sa: '190 ms' }, "pingLabels({ ping: { sa: 190 } }) má vrátit { sa: '190 ms' }");
assert.deepEqual(lobby.ping, { sa: 190 }, 'pingLabels nesmí změnit původní objekt ping');
assert.deepEqual(pingLabels({ ping: {} }), {}, 'pingLabels({ ping: {} }) má vrátit {}');
```

```js
  goodLimit: 60,

// Uvádí server pravidlo se zadaným jménem (i s hodnotou false)?
function hasRule(server, rule) {

// Z kolika regionů se měří odezva.
function regionCount(server) {
  return Object.keys(server.ping).length;

// Průměrná odezva zaokrouhlená na celé ms, bez měření null.
function averagePing(server) {
  const values = Object.values(server.ping);
  if (values.length === 0) {
    return null;
  }
  let total = 0;
  for (const ms of values) {
    total += ms;
  }
  return Math.round(total / values.length);
}
```

# --parsons--

```js
// Popisky odezvy s jednotkou, třeba { eu: '24 ms' }.
function pingLabels(server) {
  const pairs = [];
  for (const [region, ms] of __1__(server.ping)) {
    pairs.push([region, `${ms} ms`]);
  }
  return Object.fromEntries(pairs);
}
```
