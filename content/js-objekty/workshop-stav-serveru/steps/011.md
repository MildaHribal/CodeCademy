# --description--

Vedle počtu regionů karta ukazuje průměrnou odezvu zaokrouhlenou na celé milisekundy.

**Úkol:** Napiš funkci `averagePing(server)`, která vrátí průměr všech hodnot v `server.ping` zaokrouhlený na celé číslo. Když server nemá žádné měření, vrátí `null` (nula milisekund by lhala).

Potřebuješ jen hodnoty, klíče ne. Vyber mezi `Object.values` a `Object.entries`, projdi pole cyklem `for…of` a sčítej. Na zaokrouhlení máš `Math.round`.

# --hints--

`averagePing(kostkov)` vrátí `134`.

```js
assert.equal(averagePing(kostkov), 134, 'averagePing(kostkov) má vrátit 134 — (24 + 131 + 248) / 3 = 134,33 po zaokrouhlení');
```

`averagePing` zaokrouhlí průměr na celé číslo.

```js
assert.equal(averagePing({ ping: { eu: 10, us: 15 } }), 13, 'averagePing({ ping: { eu: 10, us: 15 } }) má vrátit 13 — průměr 12,5 zaokrouhlený nahoru');
```

Pro server bez měření vrátí `averagePing` hodnotu `null`.

```js
assert.equal(averagePing({ ping: {} }), null, 'averagePing({ ping: {} }) má vrátit null, ne NaN ani 0');
```

# --help--

## --tip--

Hodnoty objektu jako pole vrátí jedna ze tří funkcí v [Procházení objektu](see:js-objekty/objekty#prochazeni-objektu-object-keys-values-a-entries).

## --tip--

Nejdřív si pole hodnot ulož do proměnné. Když má délku `0`, vrať hned `null`. Jinak sečti hodnoty v `for…of` do proměnné `let` a součet vyděl délkou pole.

## --tip--

Stejný postup na jiných datech — průměrné hodnocení receptu, rozepsaný na podcíle:

```js
// 1. pole hodnot z objektu ratings
// 2. prázdné pole → null
// 3. součet hodnot cyklem, pak Math.round(součet / počet)
```

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules[ruleName];
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}

// Jedno měření odezvy jako objekt, třeba { asia: 231 }.
function pingEntry(region, ms) {
  return { [region]: ms };
}

// Hranice odezvy a jejich slovní hodnocení.
const pingQuality = {
  goodLimit: 60,
  okLimit: 150,
  label(ms) {
    if (ms <= pingQuality.goodLimit) {
      return 'výborný';
    }
    if (ms <= pingQuality.okLimit) {
      return 'dobrý';
    }
    return 'slabý';
  },
};

// Jméno majitele, nebo 'bez majitele'.
function ownerName(server) {
  return server.owner?.name ?? 'bez majitele';
}

// Uvádí server pravidlo se zadaným jménem (i s hodnotou false)?
function hasRule(server, rule) {
  return Object.hasOwn(server.rules, rule);
}

// Z kolika regionů se měří odezva.
function regionCount(server) {
  return Object.keys(server.ping).length;
}

// Průměrná odezva zaokrouhlená na celé ms, bez měření null.
function averagePing(server) {
  const values = Object.values(server.ping);
  if (values.length === 0) {
    return null;
  }
  let total = 0;
  for (const ms of values) {
    total += ms;
  }
  return Math.round(total / values.length);
}
```
