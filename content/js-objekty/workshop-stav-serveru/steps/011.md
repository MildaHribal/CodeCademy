# --description--

Horní část karty má hotová všechna data: název, hráče, majitele i pravidla. Klidně si tu dej pauzu — dál přijde spodní část s regiony.

Pod výběrem regionu karta píše, z kolika regionů se odezva měří. Objekt `ping` ale nemá `length`.

**Úkol:** Napiš funkci `regionCount(server)`, která vrátí počet regionů v objektu `server.ping`. Pro server bez měření (`ping: {}`) vrátí `0`.

Z objektu nejdřív udělej pole — hodí se `Object.keys`, `Object.values` nebo `Object.entries` — a pak si vezmi jeho délku.

# --hints--

`regionCount(kostkov)` vrátí `3`.

```js
assert.equal(regionCount(kostkov), 3, 'regionCount(kostkov) má vrátit 3 — regiony eu, us a asia');
```

`regionCount` počítá regiony serveru v parametru, prázdný `ping` dá `0`.

```js
assert.equal(regionCount({ ping: { eu: 10, us: 90, sa: 150, oc: 300 } }), 4, 'regionCount pro ping se čtyřmi regiony má vrátit 4');
assert.equal(regionCount({ ping: {} }), 0, 'regionCount({ ping: {} }) má vrátit 0');
```

# --help--

## --tip--

Jde o převod objektu na pole — viz [Procházení objektu](see:js-objekty/objekty#prochazeni-objektu-object-keys-values-a-entries).

## --tip--

Kterákoli ze tří funkcí vrátí pole se stejným počtem položek, kolik má objekt vlastností. Předej jí `server.ping` a za volání připiš délku pole.

## --tip--

Na jiných datech: `Object.keys(cart.items).length` říká, kolik různých produktů je v košíku.
