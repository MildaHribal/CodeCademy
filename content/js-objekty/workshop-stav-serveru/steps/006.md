# --description--

## Hlášení

Pod kartou má být malý graf odezvy. Graf dostává jednotlivá měření z funkce `measurement(region, ms)`, kterou kolega přidal na konec souboru, a čeká objekt ve tvaru `{ region: 'eu', ms: 24 }`.

Graf ale zůstává prázdný. Když si výsledek vypíšeš, `measurement('eu', 24)` vrací `undefined`. V konzoli žádná chyba není.

## Úkol

Oprav `measurement` tak, aby vracela objekt s vlastnostmi `region` a `ms`. Změň co nejmenší kus kódu.

# --hints--

`measurement('eu', 24)` vrátí `{ region: 'eu', ms: 24 }`.

```js
assert.deepEqual(measurement('eu', 24), { region: 'eu', ms: 24 }, "measurement('eu', 24) má vrátit { region: 'eu', ms: 24 }");
assert.deepEqual(measurement('asia', 248), { region: 'asia', ms: 248 }, "measurement('asia', 248) má vrátit { region: 'asia', ms: 248 }");
```

Každé volání `measurement` vrátí nový objekt.

```js
assert.notEqual(measurement('us', 131), measurement('us', 131), "dvě volání measurement('us', 131) mají vrátit dva různé objekty");
```

Ostatní funkce fungují dál.

```js
assert.deepEqual(pingEntry('asia', 231), { asia: 231 }, "pingEntry('asia', 231) má dál vracet { asia: 231 }");
assert.equal(pingFor(kostkov, 'us'), 131, "pingFor(kostkov, 'us') má dál vracet 131");
```

# --help--

## --tip--

Chyba odpovídá pasti [Šipková funkce, která má vrátit objekt](see:js-objekty/objekty#sipkova-funkce-ktera-ma-vratit-objekt).

## --tip--

Podívej se, co stojí hned za `=>`. Jak JavaScript pozná, jestli složená závorka začíná tělo funkce, nebo zápis objektu?

## --tip--

Na jiných datech: `const toCoords = (lat, lng) => ({ lat, lng });` vrátí objekt, protože je obalený kulatými závorkami.

# --explain--

Vysvětli vlastními slovy, proč `(region, ms) => { region, ms }` vrací `undefined`, a ne objekt.

## --model--

Složená závorka hned za šipkou znamená tělo funkce, ne objekt. Uvnitř je jen výraz `region, ms`, se kterým se nic nestane, a funkce bez `return` vrací `undefined`. Chyba se neukáže v konzoli, protože je to platný kód. Když má šipková funkce vrátit objekt bez `return`, obalím ho kulatými závorkami: `=> ({ region, ms })`.

## --checklist--

- Složená závorka hned za `=>` začíná tělo funkce.
- Tělo bez `return` vrací `undefined`.
- Kód je platný, a proto konzole žádnou chybu nehlásí.
- Objekt vrácený bez `return` se obalí kulatými závorkami.

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },

  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').

  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.

  return `${server.name} (${server.version})`;
}

  return playersText(server.players.online, server.players.max);
}
```
