# --description--

Stránky se seznamem herních serverů ukazují u každého serveru kartičku: název, kolik hráčů je online, jakou odezvu budeš mít. Přesně takovou kartu v tomhle workshopu postavíš. Na konci si na ní vybereš region a odezva se přepočítá hned.

V `script.js` je objekt `kostkov` se stavem jednoho serveru a pod ním funkce, kterou napsal kolega. Všechny tvoje funkce dostanou stav serveru v parametru, takže půjdou použít pro jakýkoli server.

Začneš funkcí bez objektů, kterou už napsat umíš.

**Úkol:** Pod kolegovu funkci napiš funkci `playersText(online, max)`, která vrátí text ve tvaru `'37 z 100 hráčů'`.

# --hints--

`playersText(37, 100)` vrátí `'37 z 100 hráčů'`.

```js
assert.equal(playersText(37, 100), '37 z 100 hráčů', "playersText(37, 100) má vrátit '37 z 100 hráčů'");
```

`playersText(0, 20)` vrátí `'0 z 20 hráčů'`.

```js
assert.equal(playersText(0, 20), '0 z 20 hráčů', "playersText(0, 20) má vrátit '0 z 20 hráčů' — i nula hráčů je platný počet");
```

# --help--

## --tip--

Funkce dostane dvě čísla a **vrátí** text. Čísla do textu vložíš šablonovým řetězcem (*template literal*) se zpětnými apostrofy.

## --tip--

Stejný tvar na jiných datech, rozepsaný na podcíle:

```js
// 1. funkce seatsText(taken, total)
// 2. vrátí text, do kterého vloží obě čísla, třeba '12 z 40 míst'
```

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}
```
