# --description--

Na kartě je nahoře název serveru a v závorce verze hry, aby hráč věděl, jakým klientem se připojit.

**Úkol:** Napiš funkci `serverTitle(server)`, která vrátí název a verzi ve tvaru `'Kostkov Survival (26.1)'`.

Vlastnost objektu přečteš tečkou za jménem objektu — tady za parametrem `server`, ne za `kostkov`, aby funkce fungovala pro každý server. Na jiných datech:

```js
function bookTitle(book) {
  return `${book.title} – ${book.author}`;
}
```

# --hints--

`serverTitle(kostkov)` vrátí `'Kostkov Survival (26.1)'`.

```js
assert.equal(serverTitle(kostkov), 'Kostkov Survival (26.1)', "serverTitle(kostkov) má vrátit 'Kostkov Survival (26.1)'");
```

`serverTitle` pracuje s objektem z parametru, ne s `kostkov`.

```js
const lobby = { name: 'Lobby', version: '25.4' };
assert.equal(serverTitle(lobby), 'Lobby (25.4)', "serverTitle({ name: 'Lobby', version: '25.4' }) má vrátit 'Lobby (25.4)' — čteš vlastnosti z parametru server?");
```

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}
```
