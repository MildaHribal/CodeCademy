# --description--

Hráč si na kartě vybere, odkud se připojuje, a karta mu ukáže odezvu pro jeho region. Jméno regionu (`'eu'`, `'us'`, `'asia'`) tedy znáš až za běhu — je v parametru.

**Úkol:** Napiš funkci `pingFor(server, region)`, která vrátí odezvu v milisekundách pro zadaný region, třeba `pingFor(kostkov, 'us')` vrátí `131`.

Když je jméno klíče v proměnné, tečka nestačí. Použij hranaté závorky: `objekt[proměnná]`. Na jiných datech:

```js
function priceIn(product, currency) {
  return product.prices[currency];
}
```

> [!PITFALL]
> `server.ping.region` hledá klíč, který se doslova jmenuje `region`, a vrátí `undefined` pro jakýkoli region.

# --hints--

`pingFor(kostkov, 'us')` vrátí `131`.

```js
assert.equal(pingFor(kostkov, 'us'), 131, "pingFor(kostkov, 'us') má vrátit 131");
```

`pingFor` funguje pro každý region v objektu `ping`.

```js
const lobby = { ping: { eu: 12, sa: 190 } };
assert.equal(pingFor(lobby, 'sa'), 190, "pingFor({ ping: { eu: 12, sa: 190 } }, 'sa') má vrátit 190");
assert.equal(pingFor(lobby, 'eu'), 12, "pingFor({ ping: { eu: 12, sa: 190 } }, 'eu') má vrátit 12");
```

# --help--

## --tip--

Klíč v proměnné čtou hranaté závorky — viz [Hranaté závorky: klíč v proměnné](see:js-objekty/objekty#hranate-zavorky-klic-v-promenne).

## --tip--

Nejdřív se dostaň k objektu `ping` tečkou, pak z něj přečti klíč z parametru `region` hranatými závorkami.

# --explain--

Vysvětli vlastními slovy, proč `server.ping.region` vrátí `undefined`, zatímco `server.ping[region]` vrátí odezvu.

## --model--

Tečka bere jméno za sebou doslova, takže `server.ping.region` hledá klíč, který se jmenuje `region`, a ten v objektu není. Hranaté závorky nejdřív vyhodnotí výraz uvnitř: proměnná `region` obsahuje třeba text `'us'`, a teprve ten se použije jako klíč. Závorky proto potřebuju vždycky, když jméno klíče znám až za běhu.

## --checklist--

- Tečka bere jméno klíče doslova, `.region` hledá klíč `region`.
- Chybějící klíč vrátí `undefined`, ne chybu.
- Výraz v hranatých závorkách se nejdřív vyhodnotí na text a ten je klíč.
- Klíč, který znám až za běhu, čtu hranatými závorkami.

# --solution--

## --file-- script.js

```js
// Stav herního serveru, jak ho vrací monitorovací služba.
// ping = odezva v milisekundách podle regionu, ze kterého se hráč připojuje.
const kostkov = {
  name: 'Kostkov Survival',
  address: 'mc.kostkov.cz',
  version: '26.1',
  online: true,
  motd: 'Nová mapa od pátku!',
  players: { online: 37, max: 100 },
  ping: { eu: 24, us: 131, asia: 248 },
  rules: { pvp: false, whitelist: true, difficulty: 'normal' },
  owner: null,
};

// Od kolegy: hodnota jednoho pravidla, třeba ruleValue(kostkov, 'difficulty').
function ruleValue(server, ruleName) {
  return server.rules.ruleName;
}

// Text s počtem hráčů, třeba '37 z 100 hráčů'.
function playersText(online, max) {
  return `${online} z ${max} hráčů`;
}

// Název a verze, třeba 'Kostkov Survival (26.1)'.
function serverTitle(server) {
  return `${server.name} (${server.version})`;
}

// Text o hráčích serveru, třeba '37 z 100 hráčů'.
function playersLabel(server) {
  return playersText(server.players.online, server.players.max);
}

// Odezva v ms pro zadaný region, třeba pingFor(kostkov, 'us').
function pingFor(server, region) {
  return server.ping[region];
}
```
