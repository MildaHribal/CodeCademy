# --description--
Někdy uživatel nemá vyplněné všechny údaje nebo potřebujeme proměnné přejmenovat, aby nekolidovaly s existujícími názvy.
Sestav tělo funkce `getProfileDisplay`, která získá vlastnost `username` pod názvem `handle` a `role` s výchozí hodnotou `'guest'`.


```javascript
export function getProfileDisplay(user) {
  // [
  const { 
    username: handle, 
    role = 'guest' 
  } = user;
  // ]
  return `${handle} (${role})`;
}
```
