# --description--

Ve formuláři přepíše uživatel popis pod jménem. Formulář ukazuje náhled, ale uložený profil se smí změnit až po kliknutí na **Uložit**. Funkce, která popis mění, proto nesmí sáhnout do profilu, který dostala.

> [!PITFALL]
> `profile.headline = headline; return profile;` vrátí správný popis, ale je to [[mutace]]: parametr ukazuje na objekt volajícího, takže se změní i uložený profil.

**Úkol:** Napiš funkci `withHeadline(profile, headline)`, která vrátí **nový** objekt se všemi údaji profilu a novým `headline`. Objekt `profile` nechá beze změny.

Nový objekt s jednou změnou vyrobí [[rozprostření]] (*spread*): vysype vlastnosti do nových složených závorek a za ním přepíšeš, co se mění. Na jiných datech:

```js
const ticket = { seat: 'A12', owner: 'Ondra' };
const renamed = { ...ticket, owner: 'Klára' };
```

# --hints--

`withHeadline` vrátí profil s novým popisem a ostatními údaji stejnými.

```js
const result = withHeadline(savedProfile, 'Fullstack vývojářka');
assert.equal(result.headline, 'Fullstack vývojářka', "withHeadline(savedProfile, 'Fullstack vývojářka').headline má být 'Fullstack vývojářka'");
assert.equal(result.fullName, 'Jana Dvořáková', 'withHeadline má zachovat fullName');
assert.equal(result.location, savedProfile.location, 'withHeadline má nechat location tentýž objekt — nezměněné části profilu se nekopírují, jen se převezmou spreadem');
```

Původní profil zůstane beze změny.

```js
withHeadline(savedProfile, 'Fullstack vývojářka');
assert.equal(savedProfile.headline, 'Frontend vývojářka', "po withHeadline(savedProfile, 'Fullstack vývojářka') má mít savedProfile pořád headline 'Frontend vývojářka'");
```

`withHeadline` vrací nový objekt, ne ten, který dostala.

```js
const profile = { username: 'eva', headline: 'Testerka' };
assert.notEqual(withHeadline(profile, 'QA inženýrka'), profile, 'withHeadline má vrátit nový objekt, ne původní profil');
```

# --help--

## --tip--

Jde o úpravu bez mutace — viz [Úprava bez mutace: nový objekt](see:js-objekty/reference-a-mutace#uprava-bez-mutace-novy-objekt).

## --tip--

V `return` postav nový objekt: nejdřív do něj rozprostři `profile`, za tím napiš `headline`.

## --tip--

Na jiných datech: `{ ...booking, seats: 4 }` je nová rezervace se čtyřmi místy.

# --explain--

Vysvětli vlastními slovy, proč `withHeadline` nesmí napsat `profile.headline = headline`, i když by vrátila správný popis.

## --model--

Parametr `profile` dostane odkaz na objekt volajícího, ne jeho kopii. Zápis `profile.headline = …` je mutace toho sdíleného objektu, takže by se změnil i uložený profil, a tlačítko Zrušit by nemělo co vrátit. Proto vytvořím nový objekt `{ ...profile, headline }`, ve kterém je nový popis, a původní profil zůstane, jak byl.

## --checklist--

- Parametr ukazuje na tentýž objekt jako proměnná volajícího.
- Zápis do vlastnosti parametru změní objekt i volajícímu.
- Spread vytvoří nový objekt, do kterého se zkopírují vlastnosti.
- Vlastnost napsaná za spreadem přepíše zkopírovanou hodnotu.

## --file-- script.js

```js
// Uložený profil vývojářky na pracovním portálu, jak ho vrací API.
const savedProfile = {
  id: 481,
  username: 'jana-dev',
  fullName: 'Jana Dvořáková',
  headline: 'Frontend vývojářka',
  email: 'jana.dvorakova@example.cz',
  location: { city: 'Brno', remote: true },
  links: { github: 'github.com/jana-dev', linkedin: null, website: 'jana-dev.example.cz' },
  privacy: { showEmail: false, showCity: true },
  skills: ['HTML', 'CSS', 'JavaScript'],

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
```

```js
  const privacy = profile.privacy;
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

// Profil z tvaru, který posílá starší API (snake_case), do tvaru aplikace.
function fromApi(apiUser) {
  const { user_name: username, full_name: fullName = null, job_title: headline = 'Vývojář' } = apiUser;
  return { username, fullName, headline };
}

// Nový profil s jiným popisem, původní zůstane beze změny.
function withHeadline(profile, headline) {
  return { ...profile, headline };
}
```
