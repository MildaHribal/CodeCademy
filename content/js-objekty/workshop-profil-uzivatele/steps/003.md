# --description--

Starší API u čerstvě založených účtů `full_name` a `job_title` vůbec neposílá. Aplikace pak ukazuje „undefined" místo popisu.

**Úkol:** Uprav `fromApi` tak, aby chybějící `full_name` dal `fullName: null` a chybějící `job_title` dal `headline: 'Vývojář'`.

Přejmenování a výchozí hodnota jdou zapsat najednou: nejdřív dvojtečka a nové jméno, pak rovnítko a výchozí hodnota. Na jiných datech:

```js
const { delivery_note: note = 'bez poznámky' } = apiOrder;
```

> [!PITFALL]
> Výchozí hodnota zabere jen na `undefined`. Když API pošle `job_title: null`, zůstane `headline` `null`.

# --hints--

Bez `full_name` a `job_title` vrátí `fromApi` hodnoty `fullName: null` a `headline: 'Vývojář'`.

```js
assert.deepEqual(fromApi({ user_name: 'novy-ucet' }), { username: 'novy-ucet', fullName: null, headline: 'Vývojář' }, "fromApi({ user_name: 'novy-ucet' }) má vrátit { username: 'novy-ucet', fullName: null, headline: 'Vývojář' }");
```

S vyplněnými údaji vrátí `fromApi` hodnoty z API.

```js
const apiUser = { user_name: 'petr-k', full_name: 'Petr Král', job_title: 'Backend vývojář' };
assert.deepEqual(fromApi(apiUser), { username: 'petr-k', fullName: 'Petr Král', headline: 'Backend vývojář' }, "fromApi pro vyplněný účet Petra Krále má vrátit jeho údaje, ne výchozí hodnoty");
```

Když chybí jen jeden údaj, doplní se jen ten.

```js
assert.deepEqual(fromApi({ user_name: 'eva', full_name: 'Eva Malá' }), { username: 'eva', fullName: 'Eva Malá', headline: 'Vývojář' }, "fromApi({ user_name: 'eva', full_name: 'Eva Malá' }) má doplnit jen headline: 'Vývojář'");
```

# --help--

## --tip--

Výchozí hodnota v destrukturalizaci je v části [Destrukturalizace](see:js-objekty/objekty#destrukturalizace-vlastnosti-rovnou-do-promennych).

## --tip--

Za nové jméno proměnné (za dvojtečku) připiš rovnítko a výchozí hodnotu. Výchozí `null` napiš stejně jako `'Vývojář'`.

## --tip--

Na jiných datech: `const { zip_code: zip = '000 00' } = apiAddress;` přejmenuje i doplní najednou.

// Uložený profil vývojářky na pracovním portálu, jak ho vrací API.
const savedProfile = {

  username: 'jana-dev',
  fullName: 'Jana Dvořáková',

  email: 'jana.dvorakova@example.cz',

  const privacy = profile.privacy;
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
