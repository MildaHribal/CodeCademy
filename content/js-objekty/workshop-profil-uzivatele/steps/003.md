# --description--
Nyní zobrazíme profil na obrazovce.
Vytvoř soubor `index.html` s elementem `<div id="app"></div>`.
V souboru `main.js` naimportuj `userProfile` a `getFullName`.
Poté najdi element `app` a nastav jeho `innerHTML` tak, aby zobrazoval nadpis s celým jménem uživatele a odstavcem s jeho uživatelským jménem (`username`).

Tím získáme první vizuální výsledek naší práce.

# --hints--

Zkontroluj, zda procházejí testy:
```javascript
import './main.js';

describe('Vykreslení profilu', () => {
  it('Zobrazí jméno v nadpisu', () => {
    const app = document.getElementById('app');
    assert.isNotNull(app, 'Dokument musí obsahovat element s id "app"');
    assert.match(app.innerHTML, /<h1.*>.*<\/h1>/i, 'Uvnitř #app musí být nadpis H1');
  });
});
```
