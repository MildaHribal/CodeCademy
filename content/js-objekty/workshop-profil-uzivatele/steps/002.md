# --description--

Portál přebírá profily ze staršího API, které píše klíče s podtržítkem: `{ user_name: 'jana-dev', full_name: 'Jana Dvořáková', job_title: 'Frontend vývojářka' }`. Aplikace ale všude používá `username`, `fullName` a `headline`. Na hranici mezi API a aplikací proto klíče přejmenuješ — jednou, na jednom místě.

**Úkol:** Napiš funkci `fromApi(apiUser)`, která vrátí nový objekt s klíči `username`, `fullName` a `headline`. Hodnoty si vytáhni **destrukturalizací s přejmenováním** a objekt pak slož zkráceným zápisem.

V destrukturalizaci je nalevo od dvojtečky klíč, který v objektu je, a napravo jméno nové proměnné. Na jiných datech:

```js
const apiOrder = { order_id: 381, total_price: 870 };
const { order_id: orderId, total_price: totalPrice } = apiOrder;
const order = { orderId, totalPrice };
```

Proměnné `order_id` a `total_price` přitom nevzniknou.

# --hints--

`fromApi` vrátí objekt s klíči `username`, `fullName` a `headline`.

```js
const apiUser = { user_name: 'petr-k', full_name: 'Petr Král', job_title: 'Backend vývojář' };
assert.deepEqual(fromApi(apiUser), { username: 'petr-k', fullName: 'Petr Král', headline: 'Backend vývojář' }, "fromApi({ user_name: 'petr-k', full_name: 'Petr Král', job_title: 'Backend vývojář' }) má vrátit { username: 'petr-k', fullName: 'Petr Král', headline: 'Backend vývojář' }");
```

Výsledek nemá žádný klíč s podtržítkem.

```js
const result = fromApi({ user_name: 'eva', full_name: 'Eva Malá', job_title: 'Testerka' });
assert.deepEqual(Object.keys(result).sort(), ['fullName', 'headline', 'username'], 'fromApi má vrátit jen klíče username, fullName a headline');
```

`fromApi` přejmenovává klíče v destrukturalizaci.

```js
const source = helpers.stripComments(fromApi.toString(), 'js');
assert.match(source, /\{[^{}]*\b(?:user_name|full_name|job_title)\s*:\s*[A-Za-z_$]/, 'fromApi má přejmenovat klíče v destrukturalizaci, třeba { user_name: username }');
```

# --help--

## --tip--

Přejmenování je v lekci v části [Destrukturalizace](see:js-objekty/objekty#destrukturalizace-vlastnosti-rovnou-do-promennych).

## --tip--

Na prvním řádku těla funkce napiš složené závorky s dvojicemi `starý_klíč: noveJmeno` a za ně `= apiUser`. V `return` pak stačí vyjmenovat nová jména.

## --tip--

Stejný tvar na jiných datech: `const { first_name: firstName } = apiPerson;` vytvoří proměnnou `firstName`.

## --file-- script.js

```js
// Uložený profil vývojářky na pracovním portálu, jak ho vrací API.
const savedProfile = {
  id: 481,
  username: 'jana-dev',
  fullName: 'Jana Dvořáková',
  headline: 'Frontend vývojářka',
  email: 'jana.dvorakova@example.cz',
  location: { city: 'Brno', remote: true },
  links: { github: 'github.com/jana-dev', linkedin: null, website: 'jana-dev.example.cz' },
  privacy: { showEmail: false, showCity: true },
  skills: ['HTML', 'CSS', 'JavaScript'],
};

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
function updatePrivacy(profile, changes) {
  const privacy = profile.privacy;
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

// Profil z tvaru, který posílá starší API (snake_case), do tvaru aplikace.
function fromApi(apiUser) {
  const { user_name: username, full_name: fullName, job_title: headline } = apiUser;
  return { username, fullName, headline };
}
```
