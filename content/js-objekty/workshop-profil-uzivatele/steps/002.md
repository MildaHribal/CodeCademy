# --description--
Vytvoř soubor `utils.js` a v něm funkci `getFullName`. Tato funkce bude přijímat jako argument objekt uživatele.
Použij destrukturalizaci přímo v parametru funkce k získání `firstName` a `lastName`.
Funkce vrátí celé jméno jako jeden řetězec spojený mezerou.

Exportuj tuto funkci z modulu.

# --hints--

Zkontroluj, zda procházejí testy:
```javascript
import { getFullName } from './utils.js';

describe('getFullName', () => {
  it('Vrátí spojené jméno a příjmení', () => {
    const user = { firstName: 'Jan', lastName: 'Novák' };
    const result = getFullName(user);
    assert.equal(result, 'Jan Novák', `Pro uživatele {firstName: 'Jan', lastName: 'Novák'} musí vrátit 'Jan Novák', ale vráceno bylo '${result}'`);
  });
});
```
