# --description--

Formulář je jen HTML v prohlížeči uživatele a kdokoli si do něj může připsat políčko navíc. Když pošle `{ id: 1 }`, profil by se tvářil jako cizí účet. `id` a `username` se proto přes formulář měnit nesmí.

**Úkol:** Uprav `updateProfile` tak, aby `id` a `username` ve výsledku zůstaly vždy z původního profilu, i když je `changes` obsahuje. Ostatní změny se použijí jako dřív.

Rozhoduje pořadí: vlastnost napsaná později přepíše dřívější. Na jiných datech:

```js
const post = { ...draft, ...edits, authorId: draft.authorId };
```

> [!PITFALL]
> Když napíšeš `id: profile.id` **před** `...changes`, spread ho hned zase přepíše hodnotou z formuláře.

# --hints--

`updateProfile` nezmění `id` ani `username`, i když jsou v `changes`.

```js
const result = updateProfile(savedProfile, { id: 1, username: 'admin', headline: 'Tech lead' });
assert.equal(result.id, 481, 'updateProfile(savedProfile, { id: 1, … }).id má zůstat 481');
assert.equal(result.username, 'jana-dev', "updateProfile(savedProfile, { username: 'admin', … }).username má zůstat 'jana-dev'");
```

Ostatní změny se dál použijí.

```js
const result = updateProfile(savedProfile, { id: 1, headline: 'Tech lead' });
assert.equal(result.headline, 'Tech lead', "updateProfile(savedProfile, { id: 1, headline: 'Tech lead' }).headline má být 'Tech lead'");
assert.equal(savedProfile.headline, 'Frontend vývojářka', 'updateProfile nesmí změnit původní profil');
```

# --help--

## --tip--

Jde o pořadí vlastností ve spreadu — viz [Úprava bez mutace: nový objekt](see:js-objekty/reference-a-mutace#uprava-bez-mutace-novy-objekt).

## --tip--

Za `...changes` připiš ještě `id` a `username` s hodnotami z `profile`. Co je v závorkách později, vyhraje.

## --tip--

Na jiných datech: `{ ...order, ...changes, createdAt: order.createdAt }` nedovolí změnit datum vytvoření.

// Uložený profil vývojářky na pracovním portálu, jak ho vrací API.
const savedProfile = {
  id: 481,
  username: 'jana-dev',
  fullName: 'Jana Dvořáková',
  headline: 'Frontend vývojářka',
  email: 'jana.dvorakova@example.cz',
  location: { city: 'Brno', remote: true },
  links: { github: 'github.com/jana-dev', linkedin: null, website: 'jana-dev.example.cz' },
  privacy: { showEmail: false, showCity: true },
  skills: ['HTML', 'CSS', 'JavaScript'],
};

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
function updatePrivacy(profile, changes) {
  const privacy = profile.privacy;
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

// Profil z tvaru, který posílá starší API (snake_case), do tvaru aplikace.
function fromApi(apiUser) {
  const { user_name: username, full_name: fullName = null, job_title: headline = 'Vývojář' } = apiUser;
  return { username, fullName, headline };
}

// Nový profil s jiným popisem, původní zůstane beze změny.
function withHeadline(profile, headline) {
  return { ...profile, headline };
}

--edit--
// Profil se změnami z formuláře.
function updateProfile(profile, changes) {
  return { ...profile, ...changes };
}

  for (const [network, url] of Object.entries(copy.links)) {

function withHeadline(profile, headline) {

// Profil se změnami z formuláře; id a username změnit nejde.
function updateProfile(profile, changes) {
