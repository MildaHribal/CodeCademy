# --description--
Nyní vytvoř funkci `updateProfile` v souboru `utils.js`.
Tato funkce přijme původní objekt profilu a objekt s novými vlastnostmi. Pomocí spread operátoru `...` vytvoř a vrať nový objekt profilu, který kombinuje původní profil a upravené údaje. Původní objekt nesmí být změněn.

# --hints--

Zkontroluj, zda procházejí testy:
```javascript
import { updateProfile } from './utils.js';

describe('updateProfile', () => {
  it('Správně aktualizuje profil pomocí spread operátoru', () => {
    const orig = { id: 1, username: 'pavel' };
    const result = updateProfile(orig, { username: 'karel' });
    assert.equal(result.username, 'karel', `Očekáváme nové jméno karel, ale máme ${result.username}`);
    assert.equal(orig.username, 'pavel', 'Původní profil nesmí být upraven.');
  });
});
```
