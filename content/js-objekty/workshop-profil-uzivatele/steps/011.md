# --description--

Úpravy profilu v prvním i druhém patře máš hotové a kolegova chyba se soukromím je opravená — klidně si tu dej pauzu. Dál přijdou odkazy, dovednosti a veřejný profil pro firmy.

V editoru odkazů je jedno políčko a vedle něj výběr sítě: GitHub, LinkedIn, nebo web. Jméno sítě tedy znáš až za běhu.

**Úkol:** Napiš funkci `setLink(profile, network, url)`, která vrátí nový profil, ve kterém má objekt `links` pod klíčem z `network` hodnotu `url`. Ostatní odkazy zůstanou a původní profil ani jeho `links` se nezmění.

Všechno potřebné znáš: klíč z proměnné i úpravu o patro níž.

# --hints--

`setLink` nastaví odkaz pro síť z parametru a ostatní odkazy nechá.

```js
const result = setLink(savedProfile, 'linkedin', 'linkedin.com/in/jana-dev');
assert.deepEqual(result.links, { github: 'github.com/jana-dev', linkedin: 'linkedin.com/in/jana-dev', website: 'jana-dev.example.cz' }, "setLink(savedProfile, 'linkedin', …).links má mít nový linkedin a stejný github i website");
```

`setLink` nepřidá klíč `network` a nezmění uložený profil.

```js
const result = setLink(savedProfile, 'website', 'jana.example.cz');
assert.equal(Object.hasOwn(result.links, 'network'), false, "setLink nemá vytvořit klíč network — klíč se má vzít z hodnoty parametru");
assert.equal(savedProfile.links.website, 'jana-dev.example.cz', 'setLink nesmí změnit savedProfile.links');
assert.notEqual(result.links, savedProfile.links, 'výsledek setLink má mít nový objekt links');
```

# --help--

## --tip--

Kombinuješ [vypočítaný klíč](see:js-objekty/objekty#vypocitany-klic-v-literalu) a úpravu o patro níž z kroku s městem.

## --tip--

Postup je stejný jako u `withCity`, jen vnořený objekt je `links` a klíč uvnitř nového `links` se bere z proměnné.

## --tip--

Podcíle na jiných datech — cena v měně, kterou si vybral uživatel:

```js
// 1. nový produkt ze starého
// 2. v něm nový objekt prices ze starých cen
// 3. v novém prices klíč z proměnné currency s novou cenou
```

  const privacy = { ...profile.privacy };
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}
