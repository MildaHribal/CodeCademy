# --description--
Jak jsme viděli v předchozím kroku, obyčejný spread operátor vytváří pouze mělkou (shallow) kopii. Zanořené objekty stále odkazují na původní.
Vytvoř funkci `updateTheme`, která přijme celý objekt profilu a nový řetězec pro téma (`theme`).
Funkce musí vrátit nový profil a uvnitř nového profilu i úplně nový objekt `settings` s aktualizovaným tématem, aby nedošlo k mutaci původního objektu `settings`.

# --hints--

Zkontroluj, zda procházejí testy:
```javascript
import { updateTheme } from './utils.js';

describe('updateTheme', () => {
  it('Nevytváří mutace zanořeného objektu', () => {
    const user = { id: 1, settings: { theme: 'dark', notifications: true } };
    const result = updateTheme(user, 'light');
    assert.equal(result.settings.theme, 'light', 'Nové téma musí být light');
    assert.equal(user.settings.theme, 'dark', 'Původní téma musí zůstat dark');
    assert.equal(result.settings.notifications, true, 'Ostatní nastavení musí zůstat zachována');
  });
});
```
