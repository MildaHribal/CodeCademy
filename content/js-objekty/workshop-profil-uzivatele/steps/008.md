# --description--

Registrační formulář má i nepovinná políčka pro odkazy. Profil ale potřebuje všechny tři klíče, aby šablona věděla, které ikonky zašednout.

**Úkol:** Napiš funkci `normalizeLinks(form)`, která vrátí objekt s klíči `github`, `linkedin` a `website`. Chybějící odkaz má hodnotu `null`, jiné klíče z formuláře (třeba `twitter`) se do výsledku nedostanou a `normalizeLinks()` bez argumentu nespadne.

Použij stejný tvar jako v minulém kroku, tentokrát ho napíšeš sám.

# --hints--

`normalizeLinks` doplní chybějící odkazy hodnotou `null`.

```js
assert.deepEqual(normalizeLinks({ github: 'github.com/eva' }), { github: 'github.com/eva', linkedin: null, website: null }, "normalizeLinks({ github: 'github.com/eva' }) má vrátit { github: 'github.com/eva', linkedin: null, website: null }");
```

Klíče mimo tři odkazy se do výsledku nedostanou.

```js
const result = normalizeLinks({ website: 'eva.example.cz', twitter: '@eva' });
assert.deepEqual(result, { github: null, linkedin: null, website: 'eva.example.cz' }, "normalizeLinks({ website: …, twitter: '@eva' }) má vrátit jen github, linkedin a website");
```

`normalizeLinks()` bez argumentu vrátí tři odkazy s `null`.

```js
assert.deepEqual(normalizeLinks(), { github: null, linkedin: null, website: null }, 'normalizeLinks() bez argumentu má vrátit { github: null, linkedin: null, website: null }');
```

# --help--

## --tip--

Tvar je stejný jako v kroku se `createProfile` — viz [Destrukturalizace z `undefined`](see:js-objekty/objekty#destrukturalizace-z-undefined).

## --tip--

Do parametru napiš složené závorky se třemi jmény odkazů, každé s výchozí hodnotou, a celému parametru dej výchozí prázdný objekt. V `return` pak stačí zkrácený zápis.

## --tip--

Na jiných datech: `function normalizeSize({ width = 0, height = 0 } = {})` vrátí `{ width, height }`.
