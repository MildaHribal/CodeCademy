# --description--
Občas chceme získat z objektu vše kromě určitých citlivých údajů. V `utils.js` napiš funkci `extractPublicInfo`.
Tato funkce přijme objekt profilu a pomocí rest operátoru `...` oddělí `settings` a `id`. Všechny zbývající vlastnosti se uloží do nového objektu, který funkce vrátí.

# --hints--

Zkontroluj, zda procházejí testy:
```javascript
import { extractPublicInfo } from './utils.js';

describe('extractPublicInfo', () => {
  it('Odstraní id a settings z profilu', () => {
    const user = { id: 1, username: 'tester', firstName: 'Test', settings: {} };
    const publicData = extractPublicInfo(user);
    assert.isUndefined(publicData.id, 'Veřejná data nesmí obsahovat id');
    assert.isUndefined(publicData.settings, 'Veřejná data nesmí obsahovat settings');
    assert.equal(publicData.username, 'tester', 'Ostatní data musí být zachována');
  });
});
```
