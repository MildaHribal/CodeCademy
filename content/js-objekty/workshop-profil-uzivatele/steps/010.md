# --description--
Přidej do `index.html` v elementu `#app` tlačítko pro přepnutí tématu.
V `main.js` naimportuj funkci `updateTheme`.
Navěs na tlačítko událost `click`, která po stisknutí vytvoří nový profil (z původního `userProfile`) s opačným tématem (pokud je `dark`, nastaví `light` a naopak). Nový profil pak vypiš do konzole.

Tím aplikuješ nezmutovanou kopii zanořeného objektu do praxe.

# --hints--

Zkontroluj, zda procházejí testy:
```javascript
import './main.js';

describe('Změna tématu', () => {
  it('Tlačítko musí být v DOM', () => {
    const btn = document.querySelector('#app button');
    assert.isNotNull(btn, 'V #app chybí element button.');
  });
});
```
