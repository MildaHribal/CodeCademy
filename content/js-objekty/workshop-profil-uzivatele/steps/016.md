# --description--

Nad formulářem je řádek „Neuložené změny: popis, město". Počítá se z uloženého profilu a konceptu, který vznikl tvými funkcemi.

**Úkol:** Napiš funkci `changedFields(saved, draft)`, která vrátí pole jmen vlastností prvního patra, jejichž hodnota se v `draft` liší od `saved`, v pořadí klíčů objektu `saved`.

- Koncept vzniká jen tvými funkcemi, které mění profil bez mutace. Vnořený objekt, který se nezměnil, je proto v obou profilech **tentýž** objekt; změněný je nový.
- Když se nic nezměnilo, vrátí prázdné pole.

Nástroj si vyber sám. Až budeš mít hotovo, rozmysli si, proč to jde tak jednoduše.

# --hints--

Po změně popisu vrátí `changedFields` jen `headline`.

```js
const draft = withHeadline(savedProfile, 'Tech lead');
assert.deepEqual(changedFields(savedProfile, draft), ['headline'], "changedFields(savedProfile, withHeadline(savedProfile, 'Tech lead')) má vrátit ['headline']");
```

Po změně města a dovednosti vrátí `changedFields` jejich vlastnosti v pořadí profilu.

```js
const draft = addSkill(withCity(savedProfile, 'Praha'), 'React');
assert.deepEqual(changedFields(savedProfile, draft), ['location', 'skills'], "changedFields po withCity a addSkill má vrátit ['location', 'skills']");
```

Beze změn vrátí `changedFields` prázdné pole.

```js
assert.deepEqual(changedFields(savedProfile, { ...savedProfile }), [], 'changedFields(savedProfile, { ...savedProfile }) má vrátit [] — nic se nezměnilo');
assert.deepEqual(changedFields(savedProfile, addSkill(savedProfile, 'CSS')), [], "changedFields po addSkill(savedProfile, 'CSS') má vrátit [] — CSS už v profilu bylo");
```

# --help--

## --tip--

Rozhoduje, co porovnává `===` u objektů — viz [Porovnání `===` se ptá na identitu](see:js-objekty/reference-a-mutace#porovnani-se-pta-na-identitu).

## --tip--

Projdi klíče uloženého profilu a u každého porovnej hodnotu v obou objektech operátorem `!==`. Jména, u kterých se liší, sbírej do pole.

## --tip--

Podcíle na jiných datech — které položky objednávky kurýr změnil:

```js
// 1. prázdné pole změn
// 2. pro každý klíč původní objednávky: liší se hodnota v nové? přidej klíč
// 3. vrať pole
```

# --explain--

Vysvětli vlastními slovy, proč `changedFields` pozná změněné město obyčejným `!==`, i když porovnává objekty.

## --model--

`===` u objektů neporovnává obsah, ale jestli jde o tentýž objekt. Moje funkce profil nemutují: změněná část dostane nový objekt, nezměněné části zůstanou sdílené. Změna města proto vytvoří nový `location`, a `!==` vrátí `true`, zatímco `links` je v obou profilech tentýž objekt. Kdyby funkce mutovaly, ukazovaly by oba profily na jeden objekt a změnu by nešlo poznat.

## --checklist--

- `===` u objektů porovnává identitu, ne obsah.
- Úprava bez mutace dá změněné části nový objekt.
- Nezměněné části zůstávají v obou profilech tentýž objekt.
- Při mutaci by oba profily sdílely změněný objekt a změna by nebyla vidět.

const savedProfile = {
  id: 481,
  username: 'jana-dev',
  fullName: 'Jana Dvořáková',
  headline: 'Frontend vývojářka',
  email: 'jana.dvorakova@example.cz',
  location: { city: 'Brno', remote: true },
  links: { github: 'github.com/jana-dev', linkedin: null, website: 'jana-dev.example.cz' },
  privacy: { showEmail: false, showCity: true },
  skills: ['HTML', 'CSS', 'JavaScript'],
};

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
function updatePrivacy(profile, changes) {
  const privacy = { ...profile.privacy };
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile, links: { ...profile.links } };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

// Profil z tvaru, který posílá starší API (snake_case), do tvaru aplikace.
function fromApi(apiUser) {
  const { user_name: username, full_name: fullName = null, job_title: headline = 'Vývojář' } = apiUser;
  return { username, fullName, headline };
}

// Nový profil s jiným popisem, původní zůstane beze změny.
function withHeadline(profile, headline) {
  return { ...profile, headline };
}

// Profil se změnami z formuláře; id a username změnit nejde.
function updateProfile(profile, changes) {
  return { ...profile, ...changes, id: profile.id, username: profile.username };
}

function createProfile({
  username,
  fullName = null,
  headline = 'Vývojář',
  city = null,
  remote = false,
} = {}) {
  return { username, fullName, headline, location: { city, remote }, skills: [] };
}

// Tři odkazy profilu, chybějící mají null.
function normalizeLinks({ github = null, linkedin = null, website = null } = {}) {
  return { github, linkedin, website };
}

// Nový profil s jiným městem, původní i jeho location zůstanou.
function withCity(profile, city) {
  return { ...profile, location: { ...profile.location, city } };
}

// Nový profil s odkazem pro zadanou síť.
function setLink(profile, network, url) {
  return { ...profile, links: { ...profile.links, [network]: url } };
}

// Nový profil s dovedností navíc; dovednost, která už v profilu je, se nepřidá.
function addSkill(profile, skill) {
  if (profile.skills.includes(skill)) {
    return profile;
  }
  return { ...profile, skills: [...profile.skills, skill] };
}

// Veřejný profil podle nastavení soukromí.
function publicProfile(profile) {
  const { email, privacy, ...visible } = profile;
  let result = visible;
  if (privacy.showEmail) {
    result = { ...result, email };
  }
  if (!privacy.showCity) {
    result = { ...result, location: { ...result.location, city: null } };
  }
  return result;
}

function changedFields(saved, draft) {
