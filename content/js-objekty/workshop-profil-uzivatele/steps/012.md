# --description--

Pod profilem jsou štítky dovedností. Tlačítko **Přidat** přidá novou, ale stejnou dovednost podruhé přidat nejde. Pole je taky objekt, takže platí totéž co u `location`: `push` by změnil pole uloženého profilu.

**Úkol:** Napiš funkci `addSkill(profile, skill)`, která vrátí nový profil s novým polem `skills`, v němž je `skill` na konci. Když profil dovednost už má, vrátí **tentýž** profil, který dostala. Původní pole se nesmí změnit.

Hodí se `includes` (u pole funguje stejně jako u textu) a nové pole přes spread, nebo `push`. Vyber, co nezmění pole volajícího.

# --hints--

`addSkill` přidá dovednost na konec pole.

```js
const result = addSkill(savedProfile, 'React');
assert.deepEqual(result.skills, ['HTML', 'CSS', 'JavaScript', 'React'], "addSkill(savedProfile, 'React').skills má být ['HTML', 'CSS', 'JavaScript', 'React']");
```

Původní pole dovedností se nezmění a výsledek má pole nové.

```js
const result = addSkill(savedProfile, 'React');
assert.deepEqual(savedProfile.skills, ['HTML', 'CSS', 'JavaScript'], "addSkill nesmí přidat 'React' do pole uloženého profilu");
assert.notEqual(result.skills, savedProfile.skills, 'výsledek addSkill má mít nové pole skills');
assert.notEqual(result, savedProfile, 'addSkill má pro novou dovednost vrátit nový profil');
```

Dovednost, kterou profil už má, se nepřidá a vrátí se tentýž profil.

```js
assert.equal(addSkill(savedProfile, 'CSS'), savedProfile, "addSkill(savedProfile, 'CSS') má vrátit tentýž profil — CSS už v něm je");
```

# --help--

## --tip--

Pole se mění stejně jako objekt — viz [Úprava bez mutace: nový objekt](see:js-objekty/reference-a-mutace#uprava-bez-mutace-novy-objekt).

## --tip--

Nejdřív guard clause: když `profile.skills` dovednost obsahuje, vrať rovnou `profile`. Jinak vrať nový profil, v němž `skills` je nové pole s rozprostřenými starými dovednostmi a novou na konci.

## --tip--

Na jiných datech: `{ ...post, tags: [...post.tags, 'akce'] }` je příspěvek se štítkem navíc.

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
function updatePrivacy(profile, changes) {
  const privacy = { ...profile.privacy };
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
