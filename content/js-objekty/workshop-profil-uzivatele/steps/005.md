# --description--

Formulář neposílá jednu změnu, ale objekt se vším, co uživatel přepsal, třeba `{ fullName: 'Jana Nová', headline: 'Tech lead' }`. Místo funkce na každý údaj stačí jedna.

**Úkol:** Napiš funkci `updateProfile(profile, changes)`, která vrátí nový profil: všechny údaje z `profile` a přes ně hodnoty z `changes`. Žádný z obou objektů se nesmí změnit.

Do jedněch složených závorek můžeš rozprostřít víc objektů za sebou. Při shodě klíčů vyhraje ten, který stojí později. Na jiných datech:

```js
const defaults = { size: 'M', color: 'černá' };
const chosen = { color: 'modrá' };
const variant = { ...defaults, ...chosen };
```

# --hints--

`updateProfile` přepíše údaje ze `changes` a ostatní nechá.

```js
const result = updateProfile(savedProfile, { fullName: 'Jana Nová', headline: 'Tech lead' });
assert.equal(result.fullName, 'Jana Nová', "updateProfile(savedProfile, { fullName: 'Jana Nová', … }).fullName má být 'Jana Nová'");
assert.equal(result.headline, 'Tech lead', "updateProfile(…, { headline: 'Tech lead' }).headline má být 'Tech lead'");
assert.equal(result.email, 'jana.dvorakova@example.cz', 'updateProfile má zachovat e-mail, který se neměnil');
```

Původní profil ani objekt změn se nezmění.

```js
const changes = { headline: 'Tech lead' };
const result = updateProfile(savedProfile, changes);
assert.equal(savedProfile.headline, 'Frontend vývojářka', 'updateProfile nesmí změnit původní profil');
assert.deepEqual(changes, { headline: 'Tech lead' }, 'updateProfile nesmí změnit objekt changes');
assert.notEqual(result, savedProfile, 'updateProfile má vrátit nový objekt');
assert.notEqual(result, changes, 'updateProfile nemá vracet objekt changes');
```

S prázdnými změnami vrátí `updateProfile` profil se stejnými údaji.

```js
const profile = { id: 7, username: 'eva', headline: 'Testerka' };
assert.deepEqual(updateProfile(profile, {}), { id: 7, username: 'eva', headline: 'Testerka' }, 'updateProfile(profile, {}) má vrátit profil se stejnými údaji');
```

# --help--

## --tip--

Jde o nový objekt ze dvou objektů — viz [Úprava bez mutace: nový objekt](see:js-objekty/reference-a-mutace#uprava-bez-mutace-novy-objekt).

## --tip--

V `return` rozprostři do nových složených závorek nejdřív `profile`, pak `changes`. Na pořadí záleží.

## --tip--

Na jiných datech: `{ ...savedFilter, ...urlFilter }` dá přednost filtru z adresy.
