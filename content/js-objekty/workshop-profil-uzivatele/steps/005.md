## Úkol

Následující kód má za úkol aktualizovat nastavení uživatele, ale způsobuje problémy, protože upravuje původní objekt (mutuje ho). V moderním vývoji se často snažíme vytvářet nové kopie dat.
Oprav funkci tak, aby vracela úplně nový objekt `settings` s novými hodnotami a neupravovala ten původní.


```javascript
export function updateSettings(settings, newSettings) {
  // Původní kód:
  // Object.assign(settings, newSettings);
  // return settings;
  return { ...settings, ...newSettings };
}
```

describe('updateSettings', () => {

    const orig = { theme: 'light' };
    const result = updateSettings(orig, { theme: 'dark' });
    assert.notStrictEqual(result, orig, 'Funkce musí vrátit nový objekt, ne upravovat původní');

    assert.equal(result.theme, 'dark', 'Nový objekt musí obsahovat změny');
  });
});
