# --description--

## Hlášení

Tlačítko **Náhled pro firmy** ukazuje profil bez nevyplněných odkazů. Počítá ho kolegova funkce `withoutEmptyLinks(profile)`, druhá z horní části souboru; `delete` v ní smaže vlastnost z objektu.

Náhled vypadá dobře. Jenže když se uživatelka vrátí do editoru, zmizelo z formuláře políčko LinkedIn: `savedProfile.links` klíč `linkedin` už vůbec nemá, a uložit odkaz na LinkedIn tak nejde. V konzoli žádná chyba není.

## Úkol

Oprav `withoutEmptyLinks` tak, aby vracela profil bez odkazů s hodnotou `null` a uložený profil ani jeho `links` neměnila. Změň co nejmenší kus kódu.

# --hints--

`withoutEmptyLinks` vrátí profil bez odkazů s hodnotou `null`.

```js
const result = withoutEmptyLinks(savedProfile);
assert.deepEqual(result.links, { github: 'github.com/jana-dev', website: 'jana-dev.example.cz' }, "withoutEmptyLinks(savedProfile).links má být { github: …, website: … } bez linkedin");
```

Uložený profil má dál všechny tři klíče odkazů.

```js
withoutEmptyLinks(savedProfile);
assert.deepEqual(Object.keys(savedProfile.links), ['github', 'linkedin', 'website'], 'po withoutEmptyLinks má mít savedProfile.links pořád klíče github, linkedin a website');
```

Ostatní funkce fungují dál.

```js
assert.equal(Object.hasOwn(publicProfile(savedProfile), 'privacy'), false, 'publicProfile má dál vynechat privacy');
assert.deepEqual(updatePrivacy(savedProfile, { showCity: false }).privacy, { showEmail: false, showCity: false }, 'updatePrivacy má dál fungovat');
```
