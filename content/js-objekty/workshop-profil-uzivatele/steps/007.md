# --description--

Nový účet se zakládá z registračního formuláře, ve kterém je povinná jen přezdívka. Všechno ostatní dostane výchozí hodnotu.

**Úkol:** Seřaď řádky tak, aby `createProfile(form)` vrátila nový profil ve stejném tvaru jako `savedProfile`. Vlastnosti formuláře se vytahují **destrukturalizací v parametru s výchozími hodnotami** a celý parametr má výchozí prázdný objekt, aby `createProfile()` nespadla. Tenhle tvar vidíš poprvé, proto ho jen skládáš; v dalším kroku ho napíšeš sám.

Odsazení nastavíš klávesou Tab, do mezery doplň výchozí hodnotu celého parametru. Dva řádky jsou navíc — patří k typickým chybám.

# --hints--

`createProfile` doplní chybějícím údajům výchozí hodnoty.

```js
assert.deepEqual(createProfile({ username: 'novak' }), {
  username: 'novak',
  fullName: null,
  headline: 'Vývojář',
  location: { city: null, remote: false },
  skills: [],
}, "createProfile({ username: 'novak' }) má vrátit profil s výchozím fullName: null, headline: 'Vývojář', location: { city: null, remote: false } a skills: []");
```

Vyplněné údaje z formuláře se použijí.

```js
assert.deepEqual(createProfile({ username: 'eva', fullName: 'Eva Malá', city: 'Plzeň', remote: true }), {
  username: 'eva',
  fullName: 'Eva Malá',
  headline: 'Vývojář',
  location: { city: 'Plzeň', remote: true },
  skills: [],
}, "createProfile({ username: 'eva', fullName: 'Eva Malá', city: 'Plzeň', remote: true }) má použít údaje z formuláře");
```

`createProfile()` bez argumentu nespadne.

```js
const empty = createProfile();
assert.equal(empty.username, undefined, 'createProfile() má vrátit profil s username undefined, ne spadnout');
assert.equal(empty.headline, 'Vývojář', "createProfile().headline má být 'Vývojář'");
```

# --help--

## --tip--

Tvar je v lekci v pasti [Destrukturalizace z `undefined`](see:js-objekty/objekty#destrukturalizace-z-undefined): výchozí hodnoty jednotlivých vlastností patří do složených závorek, výchozí hodnota celého parametru za ně.

## --tip--

Uvnitř destrukturalizace se výchozí hodnota píše rovnítkem, ne dvojtečkou. Dvojtečka by vlastnost přejmenovala.

// Uložený profil vývojářky na pracovním portálu, jak ho vrací API.
const savedProfile = {
  id: 481,
  username: 'jana-dev',
  fullName: 'Jana Dvořáková',
  headline: 'Frontend vývojářka',
  email: 'jana.dvorakova@example.cz',
  location: { city: 'Brno', remote: true },
  links: { github: 'github.com/jana-dev', linkedin: null, website: 'jana-dev.example.cz' },
  privacy: { showEmail: false, showCity: true },
  skills: ['HTML', 'CSS', 'JavaScript'],
};

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
function updatePrivacy(profile, changes) {
  const privacy = profile.privacy;
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

// Profil z tvaru, který posílá starší API (snake_case), do tvaru aplikace.
function fromApi(apiUser) {
  const { user_name: username, full_name: fullName = null, job_title: headline = 'Vývojář' } = apiUser;
  return { username, fullName, headline };
}

// Nový profil s jiným popisem, původní zůstane beze změny.
function withHeadline(profile, headline) {
  return { ...profile, headline };
}

// Profil se změnami z formuláře; id a username změnit nejde.
function updateProfile(profile, changes) {
  return { ...profile, ...changes, id: profile.id, username: profile.username };
}
