# --description--
Začneme definicí uživatelského profilu v souboru `profile.js`.
Vytvoř objekt `userProfile`, který bude obsahovat základní informace o uživateli.

Požadavky na objekt:
- `id`: unikátní identifikátor (např. 1)
- `username`: přihlašovací jméno (např. 'jnovak')
- `firstName`: křestní jméno
- `lastName`: příjmení
- `settings`: objekt s nastavením (`theme`: 'dark', `notifications`: true)

Exportuj tento objekt jako výchozí (default export).

# --hints--

Ověř to:

```javascript
import profile from './profile.js';

describe('userProfile', () => {
  it('Exportuje objekt se základními vlastnostmi', () => {
    assert.typeOf(profile, 'object', 'Exportovaný modul musí být objekt.');
    assert.property(profile, 'username', 'Objekt musí obsahovat vlastnost username.');
    assert.property(profile, 'settings', 'Objekt musí obsahovat vlastnost settings.');
    assert.typeOf(profile.settings, 'object', 'Vlastnost settings musí být objekt.');
  });
});
```
