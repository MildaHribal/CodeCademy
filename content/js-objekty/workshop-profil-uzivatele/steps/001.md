# --description--

Na pracovním portálu má každý vývojář profil: jméno, krátký popis, město, odkazy a dovednosti. Firmy si ho prohlížejí a vývojář ho upravuje ve formuláři s náhledem. Přesně takový editor na konci workshopu rozchodíš: budeš psát do formuláře, uvidíš, co se změnilo, a tlačítko **Zrušit** vrátí uložený profil — i s pořádnými daty pod ním.

V souboru `script.js` je objekt `savedProfile` s uloženým profilem a pod ním dvě funkce od kolegy. K nim se ještě vrátíš. Všechny tvoje funkce dostanou profil v parametru.

Začneš něčím, co znáš z lekce o objektech, a to bez návodu.

Testy výpisy nekontrolují: každou novou funkci si pod ní klidně vyzkoušej přes `console.log(…)` a výsledek uvidíš hned v konzoli. Editor s kartou profilu uvidíš v náhledu v posledním kroku, až ho tvoje funkce naplní daty.

**Úkol:** Napiš funkci `displayName(profile)`, která vrátí celé jméno z `fullName`. Když `fullName` chybí nebo je `null`, vrátí přezdívku se zavináčem, třeba `'@petr-k'`.

# --hints--

`displayName(savedProfile)` vrátí `'Jana Dvořáková'`.

```js
assert.equal(displayName(savedProfile), 'Jana Dvořáková', "displayName(savedProfile) má vrátit 'Jana Dvořáková'");
```

Bez celého jména vrátí `displayName` přezdívku se zavináčem.

```js
assert.equal(displayName({ username: 'petr-k', fullName: null }), '@petr-k', "displayName({ username: 'petr-k', fullName: null }) má vrátit '@petr-k'");
assert.equal(displayName({ username: 'ota' }), '@ota', "displayName({ username: 'ota' }) má vrátit '@ota' — fullName v objektu vůbec není");
```

# --help--

## --tip--

Chybějící vlastnost i `null` se nahrazují stejným operátorem — viz [Volitelné řetězení `?.`](see:js-objekty/objekty#volitelne-retezeni).

## --tip--

Přečti `fullName` z parametru a náhradu doplň operátorem, který zabere na `null` i `undefined`. Přezdívku se zavináčem slož v šablonovém řetězci.

## --tip--

Podcíle na jiných datech — jméno autora článku:

```js
// 1. přečti author.name
// 2. když chybí nebo je null, vrať 'anonym'
```

# --solution--

## --file-- script.js

```js
// Uložený profil vývojářky na pracovním portálu, jak ho vrací API.
const savedProfile = {
  id: 481,
  username: 'jana-dev',
  fullName: 'Jana Dvořáková',
  headline: 'Frontend vývojářka',
  email: 'jana.dvorakova@example.cz',
  location: { city: 'Brno', remote: true },
  links: { github: 'github.com/jana-dev', linkedin: null, website: 'jana-dev.example.cz' },
  privacy: { showEmail: false, showCity: true },
  skills: ['HTML', 'CSS', 'JavaScript'],
};

// Od kolegy: profil s novým nastavením soukromí, třeba updatePrivacy(savedProfile, { showEmail: true }).
function updatePrivacy(profile, changes) {
  const privacy = profile.privacy;
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}
```
