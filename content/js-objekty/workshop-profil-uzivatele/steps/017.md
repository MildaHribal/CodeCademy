# --description--

Portál motivuje k vyplnění profilu ukazatelem „Profil vyplněný z 67 %". Počítá se ze šesti údajů: `fullName`, `headline`, město v `location`, `github` a `linkedin` v `links` a aspoň jedna dovednost ve `skills`.

**Úkol:** Napiš funkci `completeness(profile)`, která vrátí procento vyplněných údajů zaokrouhlené na celé číslo.

- Údaj je vyplněný, když není `null`, `undefined` ani prázdný text.
- Profil může přijít neúplný: bez `location`, bez `links` nebo bez `skills`. Funkce nesmí spadnout, chybějící údaj je prostě nevyplněný.

# --hints--

`completeness(savedProfile)` vrátí `83`.

```js
assert.equal(completeness(savedProfile), 83, 'completeness(savedProfile) má vrátit 83 — vyplněných je 5 ze 6 údajů, chybí linkedin');
```

Prázdný text se počítá jako nevyplněný.

```js
const profile = { fullName: 'Eva Malá', headline: '', location: { city: 'Plzeň' }, links: { github: '', linkedin: null }, skills: ['SQL'] };
assert.equal(completeness(profile), 50, "completeness pro profil s prázdným headline a github má vrátit 50 — vyplněné jsou 3 ze 6");
```

Neúplný profil nespadne.

```js
assert.equal(completeness({ fullName: 'Ota' }), 17, "completeness({ fullName: 'Ota' }) má vrátit 17 — bez location, links i skills");
assert.equal(completeness({}), 0, 'completeness({}) má vrátit 0');
```

# --help--

## --tip--

Chybějící vnořené objekty ohlídá [volitelné řetězení](see:js-objekty/objekty#volitelne-retezeni).

## --tip--

Šest hodnot si přečti do proměnných, u vnořených přes `?.`. Pak spočítej, kolik z nich je vyplněných (pomocná funkce `isFilled` se hodí), a výsledek převeď na procenta s `Math.round`. U dovedností kontroluj délku pole.

## --tip--

Podcíle na jiných datech — vyplněnost inzerátu bytu:

```js
// 1. hodnoty title, price, address?.city, photos?.length
// 2. spočítej vyplněné (ne null, undefined ani '')
// 3. Math.round(vyplněné / počet * 100)
```

    privacy[key] = value;
  }
  return { ...profile, privacy };
}

  const copy = { ...profile, links: { ...profile.links } };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

  return { username, fullName, headline };
}

  username,
  fullName = null,

function normalizeLinks({ github = null, linkedin = null, website = null } = {}) {
  return { github, linkedin, website };
}

// Nový profil s jiným městem, původní i jeho location zůstanou.
function withCity(profile, city) {
  return { ...profile, location: { ...profile.location, city } };
}

// Nový profil s odkazem pro zadanou síť.
function setLink(profile, network, url) {
  return { ...profile, links: { ...profile.links, [network]: url } };
}

// Nový profil s dovedností navíc; dovednost, která už v profilu je, se nepřidá.
function addSkill(profile, skill) {
  if (profile.skills.includes(skill)) {
    return profile;
  }
  return { ...profile, skills: [...profile.skills, skill] };
}

// Veřejný profil podle nastavení soukromí.
function publicProfile(profile) {
  const { email, privacy, ...visible } = profile;
  let result = visible;
  if (privacy.showEmail) {
    result = { ...result, email };
  }
  if (!privacy.showCity) {
    result = { ...result, location: { ...result.location, city: null } };
  }
  return result;
}

  const changed = [];
  for (const key of Object.keys(saved)) {
    if (saved[key] !== draft[key]) {
      changed.push(key);
    }
  }
  return changed;

// Údaj je vyplněný, když není null, undefined ani prázdný text.
function isFilled(value) {
  return value !== null && value !== undefined && value !== '';
}

// Procento vyplněných údajů profilu (6 údajů), zaokrouhlené.
function completeness(profile) {
  const values = [
    profile.fullName,
    profile.headline,
    profile.location?.city,
    profile.links?.github,
    profile.links?.linkedin,
  ];
  let filled = 0;
  for (const value of values) {
    if (isFilled(value)) {
      filled += 1;
    }
  }
  if ((profile.skills?.length ?? 0) > 0) {
    filled += 1;
  }
  return Math.round((filled / 6) * 100);
}
