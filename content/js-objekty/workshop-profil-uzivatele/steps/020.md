# --description--

Poslední krok. Přibyly soubory `index.html`, `styles.css` a `ui.js` a náhled ukazuje editor profilu: vlevo formulář, vpravo profil tak, jak ho uvidí firmy. Soubor `ui.js` drží dvě proměnné, uložený profil a koncept, a koncept mění **jen tvými funkcemi** — jak se pracuje se stránkou a událostmi, probere sekce DOM, události a prohlížeč. Chybí jediná věc: text v odznaku nahoře.

**Úkol:** Napiš ve `script.js` funkci `changesLabel(saved, draft)`, která vrátí `'Bez změn'`, když se koncept od uloženého profilu neliší, a jinak počet změněných vlastností ve správném tvaru: `'1 neuložená změna'`, `'2 neuložené změny'`, `'5 neuložených změn'`. Tvary podle čísla ti vybere `Intl.PluralRules` z lekce o formátování.

Až testy projdou, piš v náhledu do políček a sleduj odznak i kartu. Pak klikni na **Zrušit**: koncept se vrátí na uložený profil, protože ho nic nezmutovalo. Tlačítko **Uložit** jen řekne „uložený je teď koncept".

Tím je workshop hotový. Za sebou máš:

- destrukturalizaci s přejmenováním, výchozími hodnotami, v parametru i se zbytkem vlastností,
- úpravu profilu bez mutace přes spread, i o patro níž a v poli,
- pořadí vlastností ve spreadu, které ochrání `id`,
- opravu dvou kolegových funkcí, které mutovaly sdílený vnořený objekt,
- poznání změny přes `!==`, které funguje právě díky úpravám bez mutace.

Přesně takhle pracuje se stavem React: nový stav je nový objekt a změnu pozná podle identity. V další lekci zjistíš, kdy mělká kopie nestačí a jak data uložit do JSON, a pak postavíš panel nastavení, které přežije obnovení stránky.

## Udělej po svém

- **Vzhled:** zvýrazni v kartě údaje, které se od uloženého profilu liší — `changedFields` ti řekne které.
- **Funkce:** přidej ke štítkům dovedností křížek, který zavolá `removeSkill`, a políčko pro odkaz na LinkedIn přes `setLink`.
- **Tvoje téma:** přeměň editor na profil čehokoli, co tě zajímá — hráčský profil v klanu, profil kavárny na mapě, profil kapely na festivalu.

# --hints--

Po načtení stránky je v odznaku `Bez změn`.

```js
assert.equal(document.querySelector('#changes').textContent.trim(), 'Bez změn', "#changes má po načtení ukazovat 'Bez změn' — vrací changesLabel(saved, saved) tenhle text?");
```

Po změně popisu ve formuláři ukáže odznak jednu změnu.

```js
const input = document.querySelector('#headline-input');
input.value = 'Tech lead';
input.dispatchEvent(new Event('input'));
assert.equal(document.querySelector('#changes').textContent.trim(), '1 neuložená změna', "po přepsání popisu má #changes ukazovat '1 neuložená změna'");
```

`changesLabel` vybere správný tvar pro 2 a 5 změn.

```js
const two = withCity(withHeadline(savedProfile, 'Tech lead'), 'Praha');
assert.equal(changesLabel(savedProfile, two), '2 neuložené změny', "changesLabel pro změněný popis a město má vrátit '2 neuložené změny'");
const five = { ...savedProfile, fullName: 'A', headline: 'B', email: 'c@example.cz', location: { city: 'D' }, skills: [] };
assert.equal(changesLabel(savedProfile, five), '5 neuložených změn', "changesLabel pro pět změněných vlastností má vrátit '5 neuložených změn'");
```

Po kliknutí na Zrušit je v odznaku zase `Bez změn` a uložený profil se nezměnil.

```js
const input = document.querySelector('#city-input');
input.value = 'Ostrava';
input.dispatchEvent(new Event('input'));
await helpers.click(document.querySelector('#cancel'));
assert.equal(document.querySelector('#changes').textContent.trim(), 'Bez změn', "po kliknutí na Zrušit má #changes ukazovat 'Bez změn'");
assert.equal(savedProfile.location.city, 'Brno', "po úpravě města a Zrušit má mít savedProfile.location.city pořád 'Brno'");
```

# --help--

## --tip--

Počet změn ti dá `changedFields` a tvar podle čísla `Intl.PluralRules` s jazykem `'cs'` — jeho metoda `select` vrací kategorie jako `one`, `few` a `other`. Porovnání konceptu stojí na [identitě objektů](see:js-objekty/reference-a-mutace#porovnani-se-pta-na-identitu).

## --tip--

Nejdřív guard clause pro nulu. Pak si připrav objekt, kde klíčem je kategorie a hodnotou slova, a tvar vyber hranatými závorkami podle výsledku `select`.

## --tip--

Podcíle na jiných datech — počet nepřečtených zpráv:

```js
// 1. žádná zpráva → 'Vše přečteno'
// 2. objekt tvarů { one: 'nepřečtená zpráva', few: 'nepřečtené zprávy', other: 'nepřečtených zpráv' }
// 3. vrať počet a tvar podle new Intl.PluralRules('cs').select(počet)
```

function updatePrivacy(profile, changes) {
  const privacy = { ...profile.privacy };
  for (const [key, value] of Object.entries(changes)) {
    privacy[key] = value;
  }
  return { ...profile, privacy };
}

// Od kolegy: profil pro náhled firmám, bez odkazů, které nejsou vyplněné (delete smaže vlastnost).
function withoutEmptyLinks(profile) {
  const copy = { ...profile, links: { ...profile.links } };
  for (const [network, url] of Object.entries(copy.links)) {
    if (url === null) {
      delete copy.links[network];
    }
  }
  return copy;
}

// Jméno na profilu, bez celého jména přezdívka se zavináčem.
function displayName(profile) {
  return profile.fullName ?? `@${profile.username}`;
}

// Profil z tvaru, který posílá starší API (snake_case), do tvaru aplikace.
function fromApi(apiUser) {
  const { user_name: username, full_name: fullName = null, job_title: headline = 'Vývojář' } = apiUser;
  return { username, fullName, headline };
}

// Nový profil s jiným popisem, původní zůstane beze změny.
function withHeadline(profile, headline) {
  return { ...profile, headline };
}

// Profil se změnami z formuláře; id a username změnit nejde.
function updateProfile(profile, changes) {
  return { ...profile, ...changes, id: profile.id, username: profile.username };
}

function createProfile({
  username,
  fullName = null,
  headline = 'Vývojář',
  city = null,
  remote = false,
} = {}) {
  return { username, fullName, headline, location: { city, remote }, skills: [] };
}

// Tři odkazy profilu, chybějící mají null.
function normalizeLinks({ github = null, linkedin = null, website = null } = {}) {
  return { github, linkedin, website };
}

// Nový profil s jiným městem, původní i jeho location zůstanou.
function withCity(profile, city) {
  return { ...profile, location: { ...profile.location, city } };
}

// Nový profil s odkazem pro zadanou síť.
function setLink(profile, network, url) {
  return { ...profile, links: { ...profile.links, [network]: url } };
}

// Nový profil s dovedností navíc; dovednost, která už v profilu je, se nepřidá.
function addSkill(profile, skill) {
  if (profile.skills.includes(skill)) {
    return profile;
  }
  return { ...profile, skills: [...profile.skills, skill] };
}

// Veřejný profil podle nastavení soukromí.
function publicProfile(profile) {
  const { email, privacy, ...visible } = profile;
  let result = visible;
  if (privacy.showEmail) {
    result = { ...result, email };
  }
  if (!privacy.showCity) {
    result = { ...result, location: { ...result.location, city: null } };
  }
  return result;
}

// Jména vlastností prvního patra, které se v konceptu liší od uloženého profilu.
function changedFields(saved, draft) {
  const changed = [];
  for (const key of Object.keys(saved)) {
    if (saved[key] !== draft[key]) {
      changed.push(key);
    }
  }
  return changed;
}

// Údaj je vyplněný, když není null, undefined ani prázdný text.
function isFilled(value) {
  return value !== null && value !== undefined && value !== '';
}

// Procento vyplněných údajů profilu (6 údajů), zaokrouhlené.
function completeness(profile) {
  const values = [
    profile.fullName,
    profile.headline,
    profile.location?.city,
    profile.links?.github,
    profile.links?.linkedin,
  ];
  let filled = 0;
  for (const value of values) {
    if (isFilled(value)) {
      filled += 1;
    }
  }
  if ((profile.skills?.length ?? 0) > 0) {
    filled += 1;
  }
  return Math.round((filled / 6) * 100);
}

// Nový profil s otočeným nastavením soukromí.
function togglePrivacy(profile, setting) {
  return { ...profile, privacy: { ...profile.privacy, [setting]: !profile.privacy[setting] } };
}

// Nový profil bez zadané dovednosti; chybějící dovednost nic nezmění.
function removeSkill(profile, skill) {
  if (!profile.skills.includes(skill)) {
    return profile;
  }
  const skills = [];
  for (const current of profile.skills) {
    if (current !== skill) {
      skills.push(current);
    }
  }
  return { ...profile, skills };
}

## --file-- ui.js

```js
// Propojení s HTML. Práci se stránkou a událostmi probere sekce DOM, události a prohlížeč.
// Stav: uložený profil a koncept. Koncept se mění jen tvými funkcemi, nikdy zápisem do objektu.
let saved = savedProfile;
let draft = saved;
const byId = (id) => document.querySelector(`#${id}`);

function render() {
  const visible = publicProfile(draft);
  byId('card-name').textContent = displayName(visible);
  byId('card-headline').textContent = visible.headline;
  const city = visible.location.city ?? 'město skryté';
  const email = visible.email ? ` · ${visible.email}` : '';
  byId('card-meta').textContent = `${city}${visible.location.remote ? ' · i na dálku' : ''}${email}`;

  const list = byId('card-skills');
  list.replaceChildren();
  for (const skill of draft.skills) {
    const item = document.createElement('li');
    item.textContent = skill;
    list.append(item);
  }

  const percent = completeness(draft);
  byId('meter-label').textContent = `Profil vyplněný z ${percent} %`;
  byId('meter-fill').style.width = `${percent}%`;
  byId('saved-headline').textContent = saved.headline;

  const changes = byId('changes');
  changes.textContent = typeof changesLabel === 'function' ? changesLabel(saved, draft) : 'Doplň funkci changesLabel ve script.js.';
  changes.dataset.dirty = String(changedFields(saved, draft).length > 0);
}

function fillForm() {
  byId('headline-input').value = draft.headline;
  byId('city-input').value = draft.location.city;
  byId('email-toggle').checked = draft.privacy.showEmail;
}

byId('headline-input').addEventListener('input', (event) => {
  draft = withHeadline(draft, event.target.value);
  render();
});
byId('city-input').addEventListener('input', (event) => {
  draft = withCity(draft, event.target.value);
  render();
});
byId('email-toggle').addEventListener('change', () => {
  draft = togglePrivacy(draft, 'showEmail');
  render();
});
byId('skill-add').addEventListener('click', () => {
  const input = byId('skill-input');
  if (input.value.trim() !== '') {
    draft = addSkill(draft, input.value.trim());
    input.value = '';
    render();
  }
});
byId('cancel').addEventListener('click', () => {
  draft = saved;
  fillForm();
  render();
});
byId('save').addEventListener('click', () => {
  saved = draft;
  render();
});

fillForm();
render();
```

function addSkill(profile, skill) {
  if (profile.skills.includes(skill)) {
    return profile;
  }
  return { ...profile, skills: [...profile.skills, skill] };
}

// Veřejný profil podle nastavení soukromí.
function publicProfile(profile) {
  const { email, privacy, ...visible } = profile;
  let result = visible;
  if (privacy.showEmail) {
    result = { ...result, email };
  }
  if (!privacy.showCity) {
    result = { ...result, location: { ...result.location, city: null } };
  }
  return result;
}

// Jména vlastností prvního patra, které se v konceptu liší od uloženého profilu.
function changedFields(saved, draft) {
  const changed = [];
  for (const key of Object.keys(saved)) {
    if (saved[key] !== draft[key]) {
      changed.push(key);
    }
  }
  return changed;
}

// Údaj je vyplněný, když není null, undefined ani prázdný text.
function isFilled(value) {
  return value !== null && value !== undefined && value !== '';
}

// Procento vyplněných údajů profilu (6 údajů), zaokrouhlené.
function completeness(profile) {
  const values = [
    profile.fullName,
    profile.headline,
    profile.location?.city,
    profile.links?.github,
    profile.links?.linkedin,
  ];
  let filled = 0;
  for (const value of values) {
    if (isFilled(value)) {
      filled += 1;
    }
  }
  if ((profile.skills?.length ?? 0) > 0) {
    filled += 1;
  }
  return Math.round((filled / 6) * 100);
}

// Nový profil s otočeným nastavením soukromí.
function togglePrivacy(profile, setting) {
  return { ...profile, privacy: { ...profile.privacy, [setting]: !profile.privacy[setting] } };
}

// Nový profil bez zadané dovednosti; chybějící dovednost nic nezmění.
function removeSkill(profile, skill) {
  if (!profile.skills.includes(skill)) {
    return profile;
  }
  const skills = [];
  for (const current of profile.skills) {
    if (current !== skill) {
      skills.push(current);
    }
  }
  return { ...profile, skills };
}

// Text odznaku s počtem neuložených změn ve správném tvaru.
function changesLabel(saved, draft) {
  const count = changedFields(saved, draft).length;
  if (count === 0) {
    return 'Bez změn';
  }
  const forms = { one: 'neuložená změna', few: 'neuložené změny', other: 'neuložených změn' };
  const category = new Intl.PluralRules('cs').select(count);
  return `${count} ${forms[category] ?? forms.other}`;
}
