# --description--

Poslední rámeček obepíná celou kartu. Na teplém podkladu stránky ho nahradí stín, který kartu zvedne jako skutečný papír. Stín se skládá ze dvou vrstev a patří do tokenu, aby šel použít i u dalších karet.

**Úkol:** seřaď řádky tak, aby vznikl token `--shadow-card` se dvěma vrstvami stínu a pravidlo, které kartě odebere rámeček a dá jí stín z tokenu. Doplň chybějící roztažení velké vrstvy tak, aby stín nevylézal do stran. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc.

Nové pravidlo `.booking` přijde pod původní, takže `border` v něm přepíše rámeček z původního pravidla.

# --hints--

Karta nemá rámeček.

```js
const style = getComputedStyle(document.querySelector('.booking'));
assert.equal(style.borderTopWidth, '0px', 'getComputedStyle(.booking).borderTopWidth má být 0px');
assert.equal(style.borderLeftWidth, '0px', 'getComputedStyle(.booking).borderLeftWidth má být 0px');
```

Karta má stín ze dvou vrstev a velká vrstva má záporné roztažení.

```js
const shadow = getComputedStyle(document.querySelector('.booking')).boxShadow;
const layers = shadow.split(/,(?![^(]*\))/).map((layer) => layer.trim());
assert.equal(layers.length, 2, `Stín karty má ${shadow === 'none' ? 0 : layers.length} vrstev (${shadow}), čekám 2`);
const lengths = layers[1].replace(/oklch\([^)]*\)|rgba?\([^)]*\)/, '').trim().split(/\s+/).map(parseFloat);
assert.ok(lengths[3] < 0, `Roztažení druhé vrstvy stínu je ${lengths[3]}px, má být záporné`);
```

Stín karty je uložený v tokenu `--shadow-card` na `:root`.

```js
const token = getComputedStyle(document.documentElement).getPropertyValue('--shadow-card').trim();
assert.ok(token.length > 0, 'Na :root má být definovaný token --shadow-card');
```

# --explain--

Vysvětli vlastními slovy, proč se stín karty skládá ze dvou vrstev a proč jsou obě průhledné.

## --model--

Malá ostrá vrstva těsně pod hranou napodobí místo, kde se karta dotýká podkladu, a velká rozmazaná vrstva posunutá dolů napodobí světlo shora. Teprve spolu působí jako předmět nad podkladem. Průhlednost zajistí, že stín jen ztmaví podklad, ať má jakoukoli barvu, místo aby na něm vytvořil šedou šmouhu.

## --checklist--

- Malá vrstva ukazuje kontakt s podkladem.
- Velká rozmazaná vrstva posunutá dolů dělá dojem výšky.
- Průhledná barva stínu jen ztmaví podklad pod sebou.
- Záporné roztažení drží velký stín pod kartou.
