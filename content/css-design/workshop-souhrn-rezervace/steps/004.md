# --description--

V části „Pobyt" je popisek (třeba „Odjezd") 16 px od své hodnoty a stejně daleko od hodnoty nad sebou. Nevíš, ke kterému údaji patří.

**Úkol:** popisek `dt` a hodnota `dd` v každé skupině `.detail` mají být od sebe jen 4 px (`--space-1`). Smaž pravidlo s `padding-block: 8px` a místo něj udělej z `.detail` flex kontejner ve sloupci s `gap: var(--space-1)`.

Na jiném prvku by to vypadalo takhle:

```css
.field {
  display: flex;
  flex-direction: column;
  gap: var(--space-2);
}
```

Mezery mezi skupinami přijdou na řadu v dalším kroku. Už teď ale uvidíš, že se údaje rozpadly na tři dvojice.

# --hints--

V každé skupině `.detail` je mezi popiskem a hodnotou 4 px.

```js
document.querySelectorAll('.detail').forEach((detail, i) => {
  const dt = detail.querySelector('dt').getBoundingClientRect();
  const dd = detail.querySelector('dd').getBoundingClientRect();
  assert.ok(Math.abs(dd.top - dt.bottom - 4) <= 1, `Ve ${i + 1}. skupině je mezi popiskem a hodnotou ${Math.round(dd.top - dt.bottom)} px, čekám 4 px`);
});
```

Popisek ani hodnota nemají vlastní svislé odsazení, které by mezeru zvětšilo.

```js
document.querySelectorAll('.detail dt, .detail dd').forEach((el) => {
  const style = getComputedStyle(el);
  assert.equal(style.paddingTop, '0px', `<${el.localName}> „${el.textContent}" má paddingTop ${style.paddingTop}, má být 0px`);
  assert.equal(style.paddingBottom, '0px', `<${el.localName}> „${el.textContent}" má paddingBottom ${style.paddingBottom}, má být 0px`);
});
```

# --help--

## --tip--

Jde o [princip blízkosti](see:css-design/hierarchie-a-rozestupy#blizkost-a-seskupeni): dvojice k sobě, skupiny od sebe.

## --tip--

Text popisku a hodnoty od sebe vzdaluje `gap` i svislý padding obou prvků. Když test hlásí padding, zůstal na `dt` a `dd` ze starého pravidla.

# --explain--

Vysvětli vlastními slovy, proč se popisky přestaly „plést" s cizími hodnotami, i když jsi nezměnil barvu ani velikost písma.

## --model--

Oko spojuje věci, které jsou u sebe. Předtím byl popisek stejně daleko od své hodnoty jako od hodnoty nad sebou, takže k žádné nepatřil. Teď je mezera ve dvojici 4 px a mezi dvojicemi víc, takže vzdálenost sama řekne, co k sobě patří.

## --checklist--

- Oko seskupuje prvky podle vzdálenosti.
- Stejná mezera nahoru i dolů nechá popisek viset mezi dvěma hodnotami.
- Mezera uvnitř skupiny musí být menší než mezi skupinami.
