# --description--

Název chaty je stejně velký jako všechno ostatní. Na stránce potvrzení je to přitom první věc, kterou má člověk přečíst.

**Úkol:** nadpis `.booking__title` má mít největší stupeň stupnice písma (31,25 px), výšku řádku 1,2násobek velikosti písma a mírně záporné prostrkání, aby velké písmo nepůsobilo řídce.

Hodí se tokeny `--text-xl` nebo `--text-2xl`, výška řádku bez jednotky a `letter-spacing` v `em` — vyber ty správné hodnoty podle zadání. Výška řádku bez jednotky se násobí velikostí písma prvku, takže při změně velikosti sedí dál.

> [!PITFALL]
> Když výšku řádku nenastavíš, nadpis zdědí `line-height: 1.5` z `body`. Na dvou řádcích se pak rozpadne na dva samostatné nápisy.

# --hints--

Nadpis `.booking__title` má velikost písma 31,25 px.

```js
const size = parseFloat(getComputedStyle(document.querySelector('.booking__title')).fontSize);
assert.ok(Math.abs(size - 31.25) <= 0.3, `getComputedStyle(.booking__title).fontSize je ${size}px, čekám 31.25px (--text-2xl)`);
```

Výška řádku nadpisu je 1,2násobek velikosti písma.

```js
const style = getComputedStyle(document.querySelector('.booking__title'));
const ratio = parseFloat(style.lineHeight) / parseFloat(style.fontSize);
assert.ok(Math.abs(ratio - 1.2) <= 0.02, `Výška řádku nadpisu je ${style.lineHeight} při písmu ${style.fontSize}, tedy ${ratio.toFixed(2)}×, čekám 1.2×`);
```

Nadpis má mírně záporné prostrkání (mezi −0,03em a −0,005em).

```js
const style = getComputedStyle(document.querySelector('.booking__title'));
const em = (style.letterSpacing.endsWith('%') ? parseFloat(style.letterSpacing) / 100 : parseFloat(style.letterSpacing) / parseFloat(style.fontSize));
assert.ok(style.letterSpacing !== 'normal' && em <= -0.005 && em >= -0.03, `Prostrkání nadpisu je ${style.letterSpacing}, čekám mezi −0.03em a −0.005em`);
```

# --help--

## --tip--

Velikost, výšku řádku a prostrkání u nadpisů shrnuje [Typografická stupnice](see:css-design/barvy-a-typografie#typograficka-stupnice) a proč právě velikost rozhoduje o pořadí čtení, [Velikost, váha a barva](see:css-design/hierarchie-a-rozestupy#velikost-vaha-a-barva).

## --tip--

Všechny tři deklarace patří do pravidla `.booking__title`. Tokeny písma jsou na `:root`, nejvyšší stupeň má 31,25 px.

## --tip--

U nadpisu produktu s tokenem `--text-xl` by to byly deklarace pro velikost přes `var()`, výšku řádku `1.25` a prostrkání `-0.02em`.
