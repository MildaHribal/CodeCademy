# --description--

Řádek „Celkem" je teď stejný jako položky nad ním. Přitom je to číslo, kvůli kterému člověk rozpis čte.

**Úkol:** řádek `.price__row--total` odděl od položek **jedinou tenkou čarou** v barvě `--color-border` nahoře, mezi čárou a textem nech aspoň 8 px a text součtu dej o stupeň větší (20 px) a tučný. Položky nad ním se nemění.

Tohle je místo, kde čára dává smysl: odděluje výsledek od sčítanců, a je na kartě jediná.

# --hints--

Řádek „Celkem" má nahoře čáru 1 px, ostatní řádky rozpisu žádnou nemají.

```js
document.querySelectorAll('.price__row').forEach((row) => {
  const width = getComputedStyle(row).borderTopWidth;
  const isTotal = row.classList.contains('price__row--total');
  assert.equal(width, isTotal ? '1px' : '0px', `Řádek „${row.firstElementChild.textContent}" má borderTopWidth ${width}, čekám ${isTotal ? '1px' : '0px'}`);
});
```

Mezi čarou a textem součtu je aspoň 8 px.

```js
const row = document.querySelector('.price__row--total');
const text = row.firstElementChild.getBoundingClientRect();
const lineBottom = row.getBoundingClientRect().top + 1;
assert.ok(text.top - lineBottom >= 7.5, `Mezi čarou a textem součtu je ${Math.round(text.top - lineBottom)} px, čekám aspoň 8 px`);
```

Součet má velikost písma 20 px a je tučný, položky mají dál 16 px a normální váhu.

```js
const totalStyle = getComputedStyle(document.querySelector('.price__row--total .price__amount'));
assert.equal(totalStyle.fontSize, '20px', `Částka součtu má fontSize ${totalStyle.fontSize}, čekám 20px`);
assert.ok(Number(totalStyle.fontWeight) >= 700, `Částka součtu má fontWeight ${totalStyle.fontWeight}, čekám aspoň 700`);
const itemStyle = getComputedStyle(document.querySelector('.price__row .price__amount'));
assert.equal(itemStyle.fontSize, '16px', 'Částka první položky má zůstat 16px');
assert.equal(itemStyle.fontWeight, '400', 'Částka první položky má zůstat v normální váze');
```

# --help--

## --tip--

Kdy je čára na místě, shrnuje pořadí nástrojů v [Méně rámečků, víc rozestupů](see:css-design/hierarchie-a-rozestupy#mene-ramecku-vic-rozestupu).

## --tip--

Všechno patří do nového pravidla pro modifikátor `.price__row--total`. Mezera mezi čarou a textem je vnitřní odsazení nahoře, velikost bere token písma o stupeň nad základem.

## --tip--

Řádek s mezisoučtem v košíku e-shopu by vypadal podobně: horní rámeček v barvě hranice, `padding-top` ze stupnice a písmo o stupeň větší a tučné.
