# --description--

Tlačítka „Stáhnout potvrzení" a „Zrušit rezervaci" vypadají úplně stejně. Zrušení je přitom akce, kterou chce málokdo a kterou nechceš omylem zdůraznit.

**Úkol:** nech „Stáhnout potvrzení" jako výrazné tlačítko s plným pozadím a „Zrušit rezervaci" uprav tak, aby ustoupilo:

- nemá plné barevné pozadí (je průhledné nebo stejné jako karta),
- jeho text je s kartou dobře čitelný (kontrast aspoň 4,5 : 1),
- obě tlačítka zůstanou vedle sebe a stejně vysoká.

Jak vedlejší akci ztlumíš, je na tobě. V tokenech najdeš i barvu `--color-danger` pro nevratné akce.

# --hints--

„Stáhnout potvrzení" má plné pozadí s kontrastem s kartou aspoň 3 : 1 a čitelný text.

```js
const rgba = (color) => { const c = document.createElement('canvas'); c.width = c.height = 1; const x = c.getContext('2d', { willReadFrequently: true }); x.fillStyle = color; x.fillRect(0, 0, 1, 1); return [...x.getImageData(0, 0, 1, 1).data]; };
const luminance = ([r, g, b]) => [r, g, b].map((v) => { v /= 255; return v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; }).reduce((sum, v, i) => sum + v * [0.2126, 0.7152, 0.0722][i], 0);
const contrast = (a, b) => { const [hi, lo] = [luminance(rgba(a)), luminance(rgba(b))].sort((p, q) => q - p); return (hi + 0.05) / (lo + 0.05); };
const surface = getComputedStyle(document.querySelector('.booking')).backgroundColor;
const style = getComputedStyle(document.querySelector('.button--primary'));
assert.ok(contrast(style.backgroundColor, surface) >= 3, `Pozadí hlavního tlačítka má s kartou kontrast ${contrast(style.backgroundColor, surface).toFixed(2)} : 1, čekám aspoň 3 : 1`);
assert.ok(contrast(style.color, style.backgroundColor) >= 4.5, `Text hlavního tlačítka má s jeho pozadím kontrast ${contrast(style.color, style.backgroundColor).toFixed(2)} : 1, čekám aspoň 4.5 : 1`);
```

„Zrušit rezervaci" nemá plné barevné pozadí.

```js
const rgba = (color) => { const c = document.createElement('canvas'); c.width = c.height = 1; const x = c.getContext('2d', { willReadFrequently: true }); x.fillStyle = color; x.fillRect(0, 0, 1, 1); return [...x.getImageData(0, 0, 1, 1).data]; };
const luminance = ([r, g, b]) => [r, g, b].map((v) => { v /= 255; return v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; }).reduce((sum, v, i) => sum + v * [0.2126, 0.7152, 0.0722][i], 0);
const contrast = (a, b) => { const [hi, lo] = [luminance(rgba(a)), luminance(rgba(b))].sort((p, q) => q - p); return (hi + 0.05) / (lo + 0.05); };
const surface = rgba(getComputedStyle(document.querySelector('.booking')).backgroundColor);
const bg = rgba(getComputedStyle(document.querySelector('.button--secondary')).backgroundColor);
const alpha = bg[3] / 255;
const shown = [0, 1, 2].map((i) => bg[i] * alpha + surface[i] * (1 - alpha));
const diff = Math.max(...shown.map((v, i) => Math.abs(v - surface[i])));
assert.ok(diff <= 8, `Pozadí tlačítka „Zrušit rezervaci" se liší od karty (rgba ${bg.join(', ')}) — má být průhledné nebo stejné jako karta`);
```

Text „Zrušit rezervaci" má s kartou kontrast aspoň 4,5 : 1.

```js
const rgba = (color) => { const c = document.createElement('canvas'); c.width = c.height = 1; const x = c.getContext('2d', { willReadFrequently: true }); x.fillStyle = color; x.fillRect(0, 0, 1, 1); return [...x.getImageData(0, 0, 1, 1).data]; };
const luminance = ([r, g, b]) => [r, g, b].map((v) => { v /= 255; return v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; }).reduce((sum, v, i) => sum + v * [0.2126, 0.7152, 0.0722][i], 0);
const contrast = (a, b) => { const [hi, lo] = [luminance(rgba(a)), luminance(rgba(b))].sort((p, q) => q - p); return (hi + 0.05) / (lo + 0.05); };
const surface = getComputedStyle(document.querySelector('.booking')).backgroundColor;
const color = getComputedStyle(document.querySelector('.button--secondary')).color;
assert.ok(contrast(color, surface) >= 4.5, `Text tlačítka „Zrušit rezervaci" má s kartou kontrast ${contrast(color, surface).toFixed(2)} : 1, čekám aspoň 4.5 : 1`);
```

Obě tlačítka jsou vedle sebe a stejně vysoká.

```js
const [primary, secondary] = [document.querySelector('.button--primary'), document.querySelector('.button--secondary')].map((el) => el.getBoundingClientRect());
assert.ok(Math.abs(primary.top - secondary.top) <= 1, 'Tlačítka mají být ve stejném řádku');
assert.ok(Math.abs(primary.height - secondary.height) <= 1, `Tlačítka jsou vysoká ${Math.round(primary.height)} a ${Math.round(secondary.height)} px — mají být stejně`);
```

# --help--

## --tip--

Jde o hierarchii akcí: jedna vyčnívá, druhá ustoupí. Nástroje najdeš ve [Velikost, váha a barva](see:css-design/hierarchie-a-rozestupy#velikost-vaha-a-barva) a v [Méně rámečků, víc rozestupů](see:css-design/hierarchie-a-rozestupy#mene-ramecku-vic-rozestupu).

## --tip--

Obě tlačítka teď sdílí jedno pravidlo s pozadím. Rozděl ho, nebo vedlejšímu tlačítku pozadí přepiš v samostatném pravidle. Ověř i stav `:hover`, ať po najetí myší nedostane zpátky plné pozadí.

## --tip--

Na e-shopu stojí vedle „Do košíku" odkaz „Přidat do oblíbených": bez pozadí, jen barevný text, případně s tenkou hranicí.
