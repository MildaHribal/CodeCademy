# --description--

V tomhle workshopu přestavíš potvrzení rezervace chaty v Krkonoších. HTML i barvy, rozestupy a písmo v tokenech na `:root` jsou hotové. Karta ale vypadá jako první verze od vývojáře bez návrhu: všechno je stejně daleko, stejně velké a v rámečku. Krok za krokem z ní uděláš souhrn, který se čte na první pohled, jako na webech s ubytováním.

Začneš něčím, co už umíš z flexboxu. Tenhle krok je bez návodu.

**Úkol:** v hlavičce karty `.booking__header` má být blok s názvem chaty vlevo a štítek „Potvrzeno" u pravého okraje, oba ve stejném řádku. Štítek je zarovnaný k horní hraně hlavičky a je jen tak vysoký jako jeho text. Mezi blokem a štítkem nech aspoň 16 px.

> [!TIP]
> Tokeny rozestupů jsou na začátku `styles.css`: `--space-4` je 16 px. Používej je místo čísel, ať všechny mezery zůstanou na stupnici.

# --hints--

Štítek „Potvrzeno" je u pravého okraje hlavičky, ve stejném řádku jako název chaty.

```js
const header = document.querySelector('.booking__header').getBoundingClientRect();
const badge = document.querySelector('.badge').getBoundingClientRect();
const heading = document.querySelector('.booking__heading').getBoundingClientRect();
assert.ok(Math.abs(badge.right - header.right) <= 1, `Štítek končí na ${Math.round(badge.right)} px, hlavička na ${Math.round(header.right)} px`);
assert.ok(badge.top < heading.bottom && badge.bottom > heading.top, 'Štítek má být ve stejném řádku jako blok s názvem chaty');
```

Štítek je zarovnaný k horní hraně hlavičky a není natažený do výšky celého bloku.

```js
const heading = document.querySelector('.booking__heading').getBoundingClientRect();
const badge = document.querySelector('.badge').getBoundingClientRect();
assert.ok(Math.abs(badge.top - heading.top) <= 1, `Štítek začíná na ${Math.round(badge.top)} px, blok s názvem na ${Math.round(heading.top)} px`);
assert.ok(badge.height < heading.height / 2, `Štítek je vysoký ${Math.round(badge.height)} px, blok s názvem ${Math.round(heading.height)} px — štítek nemá být natažený`);
```

Mezi blokem s názvem a štítkem je aspoň 16 px.

```js
const heading = document.querySelector('.booking__heading').getBoundingClientRect();
const badge = document.querySelector('.badge').getBoundingClientRect();
assert.ok(badge.left - heading.right >= 15.5, `Mezi blokem s názvem a štítkem je ${Math.round(badge.left - heading.right)} px, čekám aspoň 16 px`);
```
