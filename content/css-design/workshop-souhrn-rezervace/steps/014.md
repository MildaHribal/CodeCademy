---
title: Viditelný fokus (zopakuj sám)
kind: recall
---

# --description--

Potvrzení rezervace musí jít ovládat i klávesnicí. Když se na tlačítko dostaneš klávesou Tab, prohlížeč teď ukáže jen tenký výchozí rámeček, na barevném tlačítku skoro neviditelný.

**Úkol:** všechna tlačítka `.button` mají při fokusu z klávesnice obrys (`outline`) aspoň 2 px silný, odsazený od tlačítka a v barvě, která má s kartou kontrast aspoň 3 : 1. Při kliknutí myší se obrys ukazovat nemá.

Tohle znáš ze základů CSS, krok je bez návodu.

# --hints--

Stylopis používá pro fokus tlačítek pseudotřídu `:focus-visible` (obrys se neukáže po kliknutí myší).

```js
const selectors = [...document.styleSheets].flatMap((sheet) => [...sheet.cssRules]).flatMap(function walk(rule) { return [rule.selectorText ?? '', ...[...(rule.cssRules ?? [])].flatMap(walk)]; });
assert.ok(selectors.some((selector) => selector.includes('.button') && selector.includes(':focus-visible')), 'V CSS má být pravidlo se selektorem tlačítka a :focus-visible');
```

Tlačítko s fokusem má obrys aspoň 2 px, odsazený od tlačítka.

```js
const button = document.querySelector('.button--primary');
button.focus();
const style = getComputedStyle(button);
assert.ok(style.outlineStyle !== 'none' && style.outlineStyle !== 'auto', `Obrys tlačítka s fokusem má styl ${style.outlineStyle}, čekám vlastní obrys (třeba solid)`);
assert.ok(parseFloat(style.outlineWidth) >= 2, `Obrys tlačítka s fokusem je silný ${style.outlineWidth}, čekám aspoň 2px`);
assert.ok(parseFloat(style.outlineOffset) >= 1, `Odsazení obrysu je ${style.outlineOffset}, čekám aspoň 1px`);
```

Obrys má s kartou kontrast aspoň 3 : 1.

```js
const rgba = (color) => { const c = document.createElement('canvas'); c.width = c.height = 1; const x = c.getContext('2d', { willReadFrequently: true }); x.fillStyle = color; x.fillRect(0, 0, 1, 1); return [...x.getImageData(0, 0, 1, 1).data]; };
const luminance = ([r, g, b]) => [r, g, b].map((v) => { v /= 255; return v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; }).reduce((sum, v, i) => sum + v * [0.2126, 0.7152, 0.0722][i], 0);
const contrast = (a, b) => { const [hi, lo] = [luminance(rgba(a)), luminance(rgba(b))].sort((p, q) => q - p); return (hi + 0.05) / (lo + 0.05); };
const button = document.querySelector('.button--secondary');
button.focus();
const surface = getComputedStyle(document.querySelector('.booking')).backgroundColor;
const outline = getComputedStyle(button).outlineColor;
assert.ok(contrast(outline, surface) >= 3, `Obrys tlačítka „Zrušit rezervaci" má s kartou kontrast ${contrast(outline, surface).toFixed(2)} : 1, čekám aspoň 3 : 1`);
```

# --help--

## --tip--

Kontrast 3 : 1 pro fokus a ovládací prvky je v tabulce v části [Kontrast podle WCAG](see:css-design/barvy-a-typografie#kontrast-podle-wcag).

## --tip--

Jedno pravidlo pro všechna tlačítka: selektor třídy tlačítka s pseudotřídou pro fokus z klávesnice, v něm obrys a jeho odsazení.

## --tip--

Stejný vzor má odkaz v navigaci: pravidlo s `:focus-visible`, obrys v barvě akcentu a odsazení pár pixelů.
