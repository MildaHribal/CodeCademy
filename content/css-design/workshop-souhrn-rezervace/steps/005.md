# --description--

Příjezd a odjezd k sobě patří a lidé je porovnávají. Na kartách ubytování proto stojí vedle sebe a počet hostů pod nimi.

**Úkol:** seznam `.details` rozvrhni do mřížky se dvěma stejně širokými sloupci. Mezi řádky dej 16 px (`--space-4`) a mezi sloupci 24 px (`--space-6`) — mezery mezi skupinami jsou tak čtyřikrát a šestkrát větší než 4 px uvnitř dvojice.

Stejný zápis s jinými hodnotami:

```css
.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: var(--space-2) var(--space-3);
}
```

První hodnota `gap` je mezera mezi řádky, druhá mezi sloupci.

# --hints--

Odjezd stojí vedle příjezdu ve stejném řádku, 24 px od něj.

```js
const [arrival, departure] = [...document.querySelectorAll('.detail')].map((el) => el.getBoundingClientRect());
assert.ok(Math.abs(departure.top - arrival.top) <= 1, 'Odjezd má začínat na stejné výšce jako příjezd');
assert.ok(Math.abs(departure.left - arrival.right - 24) <= 1, `Mezi příjezdem a odjezdem je ${Math.round(departure.left - arrival.right)} px, čekám 24 px`);
```

Oba sloupce jsou stejně široké.

```js
const [arrival, departure] = [...document.querySelectorAll('.detail')].map((el) => el.getBoundingClientRect());
assert.ok(Math.abs(departure.width - arrival.width) <= 1, `Sloupce jsou široké ${Math.round(arrival.width)} a ${Math.round(departure.width)} px — mají být stejné`);
```

Hosté jsou pod příjezdem, 16 px pod ním.

```js
const details = [...document.querySelectorAll('.detail')].map((el) => el.getBoundingClientRect());
assert.ok(Math.abs(details[2].left - details[0].left) <= 1, 'Hosté mají začínat na stejné levé hraně jako příjezd');
assert.ok(Math.abs(details[2].top - details[0].bottom - 16) <= 1, `Mezi příjezdem a hosty je ${Math.round(details[2].top - details[0].bottom)} px, čekám 16 px`);
```

# --help--

## --tip--

Mřížku se sloupci znáš ze sekce CSS Grid. Proč mají být mezery mezi skupinami větší než uvnitř, připomene [Blízkost a seskupení](see:css-design/hierarchie-a-rozestupy#blizkost-a-seskupeni).
