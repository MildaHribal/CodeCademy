# --description--

Části karty jsou teď oddělené 32 px, a přesto má každá kolem sebe rámeček s vnitřním odsazením 10 px. Rámečky už nic neoddělují, jen přidávají čáry a posouvají obsah sekcí o 11 px dovnitř, takže texty karty nezačínají na jedné hraně.

**Úkol:** sekcím `.booking__section` odeber rámeček i vnitřní odsazení. Obsah všech částí pak začne na stejné levé hraně jako hlavička.

Hodí se smazat celé pravidlo, nebo v něm nastavit rámeček a odsazení na nulu. Vyber, co je v kódu přehlednější.

# --hints--

Sekce karty nemají rámeček.

```js
document.querySelectorAll('.booking__section').forEach((section, i) => {
  const style = getComputedStyle(section);
  for (const side of ['Top', 'Right', 'Bottom', 'Left']) {
    assert.equal(style[`border${side}Width`], '0px', `${i + 1}. sekce má border${side}Width ${style[`border${side}Width`]}, má být 0px`);
  }
});
```

Obsah sekcí začíná na stejné levé hraně jako hlavička karty.

```js
const headerLeft = document.querySelector('.booking__header').getBoundingClientRect().left;
for (const selector of ['.details', '.price', '.host__avatar']) {
  const left = document.querySelector(selector).getBoundingClientRect().left;
  assert.ok(Math.abs(left - headerLeft) <= 1, `${selector} začíná na ${Math.round(left)} px, hlavička na ${Math.round(headerLeft)} px`);
}
```

Mezi částmi karty zůstává 32 px.

```js
const parts = [...document.querySelector('.booking').children].map((part) => part.getBoundingClientRect());
for (let i = 1; i < parts.length; i++) {
  const space = parts[i].top - parts[i - 1].bottom;
  assert.ok(Math.abs(space - 32) <= 1, `Mezi ${i}. a ${i + 1}. částí karty je ${Math.round(space)} px, čekám 32 px`);
}
```

# --help--

## --tip--

Proč rámečky u každé části škodí, rozebírá [Méně rámečků, víc rozestupů](see:css-design/hierarchie-a-rozestupy#mene-ramecku-vic-rozestupu). Zarovnání k jedné hraně je v části [Zarovnání a bílé místo](see:css-design/hierarchie-a-rozestupy#zarovnani-a-bile-misto).

## --tip--

Rámeček i odsazení sekcí nastavuje jediné pravidlo `.booking__section`. Hostitelka je taky sekce, takže se změna projeví i u avataru.

## --tip--

U jiné komponenty by šlo o totéž: položky seznamu notifikací s `border` a `padding` ztratí obojí a oddělí je jen `gap` seznamu.
