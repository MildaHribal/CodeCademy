# --description--

Poslední kus je hlavička. V návrhu je rámec *Horizontal* s logem vlevo a skupinou navigace a přepínače motivu vpravo. Mezi logem a navigací návrh ukazuje 612 px, ale rámec má *Gap: Auto*. Odkazy v navigaci jsou *Horizontal*, *Gap 24*. Mezi navigací a přepínačem je 16 px a všechno je svisle na středu.

**Úkol:** přelož hlavičku. Na šířce 1024 px je logo u levého okraje obsahu, přepínač u pravého, navigace těsně před ním. Na šířce 375 px nic nepřetéká do strany a položky, které se nevejdou, přejdou na další řádek.

## Co jsi v tomhle workshopu použil

- **Auto layout jako flexbox:** *Horizontal/Vertical*, *Gap*, *Padding*, *Wrap*, *Gap: Auto* jako rozestoupení.
- **Hug, Fill, Fixed:** nic, `flex: 1`, pevná velikost s `flex: none`.
- **Textové styly:** px na `rem`, výška řádku jako poměr, prostrkání v `em`, plynulé písmo mezi dvěma nakreslenými šířkami.
- **Tokeny z proměnných:** paleta z jedné barvy relativními barvami, sémantické tokeny s `light-dark()`, varianty komponenty přes atribut a proměnné.
- **Kontrola návrhu:** tlumený text a hranice tlačítka s nedostatečným kontrastem, hloubka v tmavém motivu, dlouhý text, se kterým návrh nepočítal.

Takhle vypadá většina práce frontend vývojáře v týmu s návrhářem. V další lekci přidáš ikony: jak SVG z Dev Mode vložit, aby se barvilo s textem a bylo přístupné.

## Udělej po svém

- **Vzhled:** přidej kartám řečníků při najetí myší zvednutí se stínem a posunem, v tmavém motivu místo stínu světlejší rámeček.
- **Obsah:** doplň do programu přestávku na oběd jako řádek bez štítku a rozhodni, jak ho odlišit bez rámečku.
- **Funkce:** zvýrazni v programu přednášku, která právě probíhá — porovnej čas v `datetime` s aktuálním časem a přidej řádku atribut `data-now`.
- **Tvoje téma:** přeměň stránku na akci, kterou znáš: hackathon ve škole, turnaj ve hře nebo festival v tvém městě.

# --hints--

Na šířce 1024 px je logo u levého a přepínač motivu u pravého okraje obsahu hlavičky.

```js
const header = document.querySelector('.site-header');
const style = getComputedStyle(header);
const box = header.getBoundingClientRect();
const logo = header.querySelector('.logo').getBoundingClientRect();
const toggle = header.querySelector('.theme-toggle').getBoundingClientRect();
assert.ok(Math.abs(logo.left - (box.left + parseFloat(style.paddingLeft))) <= 1, `Logo začíná na ${Math.round(logo.left)} px, obsah hlavičky na ${Math.round(box.left + parseFloat(style.paddingLeft))} px`);
assert.ok(Math.abs(toggle.right - (box.right - parseFloat(style.paddingRight))) <= 1, `Přepínač končí na ${Math.round(toggle.right)} px, obsah hlavičky na ${Math.round(box.right - parseFloat(style.paddingRight))} px`);
```

Na šířce 1024 px je navigace 16 px před přepínačem, odkazy jsou od sebe 24 px a všechno je v jednom řádku svisle na středu.

```js
const header = document.querySelector('.site-header');
const toggle = header.querySelector('.theme-toggle').getBoundingClientRect();
const links = [...header.querySelectorAll('.nav a')].map((link) => link.getBoundingClientRect());
assert.ok(Math.abs(toggle.left - links.at(-1).right - 16) <= 1, `Mezi navigací a přepínačem je ${Math.round(toggle.left - links.at(-1).right)} px, čekám 16 px`);
for (let i = 1; i < links.length; i++) {
  assert.ok(Math.abs(links[i].left - links[i - 1].right - 24) <= 1, `Mezi ${i}. a ${i + 1}. odkazem je ${Math.round(links[i].left - links[i - 1].right)} px, čekám 24 px`);
}
const middle = (box) => box.top + box.height / 2;
for (const el of [header.querySelector('.logo'), header.querySelector('.nav a')]) {
  assert.ok(Math.abs(middle(el.getBoundingClientRect()) - middle(toggle)) <= 2, 'Logo, odkazy a přepínač mají být svisle na středu jednoho řádku');
}
```

Na šířce 375 px nejde stránka posouvat do strany a mezi logem a navigací není pevná mezera.

```js
await helpers.resize(375);
const root = document.documentElement;
assert.ok(root.scrollWidth <= root.clientWidth, `Na šířce 375 px je obsah široký ${root.scrollWidth} px, okno ${root.clientWidth} px`);
const gap = parseFloat(getComputedStyle(document.querySelector('.site-header')).columnGap);
assert.ok(!(gap > 100), `Hlavička má gap ${gap}px — Gap: Auto není pevná mezera`);
```

Jak přeložit *Gap: Auto* a proč ne jako číslo, je v pasti v [Typické chyby a pasti](see:css-design/cteni-navrhu#typicke-chyby-a-pasti).

## --tip--

Hlavička je flex kontejner se zalamováním, mezera 16 px v ní platí mezi všemi položkami. Navigaci od loga odtlačí automatický margin a navigace sama je další flex řádek.

## --tip--

Lišta aplikace s názvem vlevo a ikonami vpravo: flex řádek s `gap`, u první ikony automatický margin na začátku řádku.

// Přepínač motivu: nastaví color-scheme (a data-theme) na <html>.
const toggle = document.querySelector('.theme-toggle');

toggle.addEventListener('click', () => {
  const dark = document.documentElement.dataset.theme !== 'dark';
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
  document.documentElement.style.colorScheme = dark ? 'dark' : 'light';
  toggle.setAttribute('aria-pressed', String(dark));
  toggle.textContent = dark ? 'Světlý motiv' : 'Tmavý motiv';
