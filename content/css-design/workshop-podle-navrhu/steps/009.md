# --description--

Návrh ukazuje řečníky na šířce 1440 ve **třech sloupcích** a na šířce 375 v **jednom**. Mezera mezi kartami je v obou 24 px. Co se děje mezi tím, návrh neříká — rozhodni sám.

**Úkol:** zařiď, aby

- na šířce 1024 px byly tři karty vedle sebe, stejně široké, s mezerou 24 px,
- na šířce 375 px byly karty pod sebou přes celou šířku obsahu, s mezerou 24 px,
- na žádné šířce nic nepřetékalo.

Nástroj nechám na tobě.

# --hints--

Na šířce 1024 px jsou tři karty vedle sebe, stejně široké, s mezerou 24 px.

```js
const cards = [...document.querySelectorAll('.speaker')].map((el) => el.getBoundingClientRect());
assert.ok(cards.every((card) => Math.abs(card.top - cards[0].top) <= 1), 'Na šířce 1024 px mají být všechny tři karty ve stejném řádku');
for (let i = 1; i < cards.length; i++) {
  assert.ok(Math.abs(cards[i].width - cards[0].width) <= 1, `Karty jsou široké ${cards.map((c) => Math.round(c.width)).join(', ')} px — mají být stejně`);
  assert.ok(Math.abs(cards[i].left - cards[i - 1].right - 24) <= 1, `Mezi ${i}. a ${i + 1}. kartou je ${Math.round(cards[i].left - cards[i - 1].right)} px, čekám 24 px`);
}
```

Na šířce 375 px jsou karty pod sebou přes celou šířku obsahu s mezerou 24 px.

```js
await helpers.resize(375);
const list = document.querySelector('.speakers').getBoundingClientRect();
const cards = [...document.querySelectorAll('.speaker')].map((el) => el.getBoundingClientRect());
cards.forEach((card, i) => {
  assert.ok(Math.abs(card.width - list.width) <= 1, `Na šířce 375 px je ${i + 1}. karta široká ${Math.round(card.width)} px, seznam ${Math.round(list.width)} px`);
  if (i > 0) assert.ok(Math.abs(card.top - cards[i - 1].bottom - 24) <= 1, `Na šířce 375 px je mezi kartami ${Math.round(card.top - cards[i - 1].bottom)} px, čekám 24 px`);
});
```

Na šířkách 375, 768 a 1024 px nic nepřetéká do strany.

```js
for (const width of [375, 768, 1024]) {
  await helpers.resize(width);
  const root = document.documentElement;
  assert.ok(root.scrollWidth <= root.clientWidth, `Na šířce ${width} px je obsah široký ${root.scrollWidth} px, okno ${root.clientWidth} px`);
}
```

# --help--

## --tip--

Jak z dvou nakreslených šířek odvodit pravidlo, je v části [Rámce bez auto layoutu a různé šířky](see:css-design/cteni-navrhu#ramce-bez-auto-layoutu-a-ruzne-sirky).

## --tip--

Rozvržení patří na seznam `.speakers`. Rozhodni, jestli chceš počet sloupců řídit media dotazem, nebo nejmenší šířkou karty, při které se sloupce samy přeskládají.

## --tip--

Galerie fotek, která má na počítači čtyři sloupce a na telefonu jeden, se dá napsat jedním řádkem mřížky s `auto-fit`, nebo mřížkou s jedním sloupcem a media dotazem pro širší obrazovky.

// Přepínač motivu: nastaví color-scheme (a data-theme) na <html>.
const toggle = document.querySelector('.theme-toggle');

toggle.addEventListener('click', () => {
  const dark = document.documentElement.dataset.theme !== 'dark';
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
  document.documentElement.style.colorScheme = dark ? 'dark' : 'light';
  toggle.setAttribute('aria-pressed', String(dark));
  toggle.textContent = dark ? 'Světlý motiv' : 'Tmavý motiv';
});
