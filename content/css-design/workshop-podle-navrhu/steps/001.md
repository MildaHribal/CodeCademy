# --description--

V tomhle workshopu postavíš podle návrhu stránku frontendové konference Kódovna 2026: hero s datem a čísly, řečníky, program a vstupenku. HTML je hotové, v `styles.css` jsou tokeny z návrhu (primitivy a sémantické tokeny se světlou i tmavou hodnotou) a styly, které s návrhem nesouvisí. Ty budeš převádět hodnoty z návrhu na CSS: spočítat je, přeložit auto layout a ohlídat kontrast, na který návrh zapomněl.

Tady je výtah ze specifikace, ke které se budeš vracet:

| prvek | z návrhu |
|---|---|
| obsah stránky | *Fixed max 1152*, *Padding* 0 24 |
| hero | pozadí `color/hero`, *Vertical*, *Gap* 24 |
| nadpis hero | styl *Display*: 56 / 60, prostrkání −2 %; na mobilu *Display/Mobile*: 36 / 40 |
| perex | styl *Body L*: 20 / 32, `color/text-muted`, *Max W* 576 |
| tlačítka | *Horizontal*, *Gap* 12, *Wrap* |
| čísla | *Horizontal*, *Gap* 32, každé číslo *Fill*, uvnitř *Vertical*, *Gap* 4 |
| nadpis sekce | styl *H2*: 36 / 44, prostrkání −1 % |
| karta řečníka | *Vertical*, *Gap* 16, *Padding* 24, *Radius* 16, *Stroke* 1 `color/border`, pozadí `color/raised` |
| řádek programu | *Horizontal*, *Gap* 24, čas *Fixed* 80, obsah *Fill*, štítek *Hug* |
| sekce | *Padding* nahoře a dole 96 na 1440, 64 na 375 |

Návrh nemáš ve Figmě, takže hodnoty jsou přepsané z panelu Dev Mode. Tlačítko v hlavičce přepíná tmavý motiv, zkoušej ho průběžně.

**Úkol:** obsahová šířka `.container` je nejvýš 1152 px, na stránce vycentrovaná a má vlevo a vpravo vnitřní odsazení 24 px. Bez návodu, tohle znáš.

# --hints--

Na šířce 1024 px je `.container` přes celou šířku okna a má vlevo i vpravo vnitřní odsazení 24 px.

```js
const container = document.querySelector('.hero .container');
const style = getComputedStyle(container);
assert.equal(style.paddingLeft, '24px', `.container má paddingLeft ${style.paddingLeft}, čekám 24px`);
assert.equal(style.paddingRight, '24px', `.container má paddingRight ${style.paddingRight}, čekám 24px`);
assert.ok(Math.abs(container.getBoundingClientRect().width - document.documentElement.clientWidth) <= 1, 'Na šířce 1024 px má .container vyplnit celou šířku okna');
```

Na šířce 1400 px je `.container` široký 1152 px a vycentrovaný.

```js
await helpers.resize(1400);
const box = document.querySelector('.hero .container').getBoundingClientRect();
const width = document.documentElement.clientWidth;
assert.ok(Math.abs(box.width - 1152) <= 1, `Na šířce 1400 px je .container široký ${Math.round(box.width)} px, čekám 1152 px`);
assert.ok(Math.abs(box.left - (width - box.right)) <= 1, `Na šířce 1400 px je .container vlevo ${Math.round(box.left)} px a vpravo ${Math.round(width - box.right)} px od okraje — má být uprostřed`);
```

## --file-- script.js

```js
// Přepínač motivu: nastaví color-scheme (a data-theme) na <html>.
const toggle = document.querySelector('.theme-toggle');

toggle.addEventListener('click', () => {
  const dark = document.documentElement.dataset.theme !== 'dark';
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
  document.documentElement.style.colorScheme = dark ? 'dark' : 'light';
  toggle.setAttribute('aria-pressed', String(dark));
  toggle.textContent = dark ? 'Světlý motiv' : 'Tmavý motiv';
});
```
