# --description--

Poslední pohyb, který při omezeném pohybu zbývá, je přelet fotky přes půl obrazovky do detailu a zpátky. Přechod ale nezahazuj celý. Prolnutí žádný pohyb neobsahuje a pomáhá pochopit, že se otevřel detail.

**Úkol:** V `styles.css` zařiď, aby při zapnutém omezení pohybu skupiny přechodu neanimovaly polohu ani velikost a skočily rovnou na cíl. Snímky uvnitř skupin se dál prolnou. Běžný přelet pro ostatní zůstane beze změny.

## Co ses naučil

Postavil jsi galerii, jakou mají portfolia fotografů a studií, a víš, proč každá část funguje:

- přeskupení prvků přes **Flip**: stav, změna DOM, `Flip.from` s `absolute`, `onEnter`, `onLeave` a `stagger`,
- past s `Flip.getState` zavolaným až po změně a jak ji poznat,
- gesta `hover` a `press` z Motion, která fungují myší, dotykem i klávesnicí,
- **View Transitions** se sdíleným prvkem oběma směry, úklid jména, varianta bez podpory a vlastní křivka přeletu,
- srdíčko na pružině, kurzor přes `quickTo` a kopírování s potvrzením v `role="status"`,
- omezený pohyb v JavaScriptu i v CSS: výsledek hned, prolnutí místo přeletu.

Stejné vzory použiješ u každého katalogu, e-shopu s filtrem, nástěnky úkolů nebo seznamu, který se řadí. V další lekci se podíváš, jak animace udržet na 60 snímcích za sekundu a jak je změřit.

## Udělej po svém

- **Vizuálně:** při zavření detailu nech ostatní karty galerie krátce ztlumit. Vodítko: skupina `root` má vlastní pseudoprvky `::view-transition-old(root)` a `::view-transition-new(root)`.
- **Funkčně:** zavírej detail i klávesou Escape stejným přeletem. Vodítko: `<dialog>` při Escape vyvolá událost `cancel`, kterou jde zrušit.
- **Filtr v adrese:** ulož vybranou kategorii do `?kategorie=` a po načtení ji obnov. Vodítko: `URLSearchParams` a `history.replaceState`.
- **Tvoje téma:** přeměň galerii na portfolio svých projektů, katalog vín nebo kolekci desek a vymysli vlastní kategorie.

# --hints--

Při omezeném pohybu mají skupiny přechodu nulovou délku animace.

```js
const collect = (list, out = []) => {
  for (const rule of list) {
    if (rule.cssRules) collect(rule.cssRules, out);
    if (rule.selectorText) out.push(rule);
  }
  return out;
};
const rules = [...document.styleSheets].flatMap((sheet) => collect(sheet.cssRules));
const reduced = rules.filter((rule) => {
  const media = rule.parentRule?.conditionText ?? rule.parentRule?.media?.mediaText ?? '';
  return /prefers-reduced-motion:\s*reduce/.test(media) && /::view-transition-group\(\s*(\*|photo)\s*\)/.test(rule.selectorText);
});
assert.ok(reduced.length > 0, 'styles.css má obsahovat ::view-transition-group(*) nebo ::view-transition-group(photo) uvnitř @media (prefers-reduced-motion: reduce)');
const stopped = reduced.some((rule) => {
  const duration = rule.style.animationDuration;
  return rule.style.animationName === 'none' || rule.style.animation === 'none' || (duration !== '' && parseFloat(duration) === 0);
});
assert.ok(stopped, 'skupina přechodu má při omezeném pohybu mít animation-duration: 0s (nebo animation: none)');
```

Bez omezení pohybu fotka dál přelétá s vlastní křivkou.

```js
const collect = (list, out = []) => {
  for (const rule of list) {
    if (rule.cssRules) collect(rule.cssRules, out);
    if (rule.selectorText) out.push(rule);
  }
  return out;
};
const plain = [...document.styleSheets].flatMap((sheet) => collect(sheet.cssRules))
  .filter((rule) => !rule.parentRule && /::view-transition-group\(\s*photo\s*\)/.test(rule.selectorText));
const duration = plain.map((rule) => rule.style.animationDuration).filter(Boolean).at(-1) ?? '';
assert.ok(parseFloat(duration) > 0, `pravidlo ::view-transition-group(photo) mimo @media má dál mít nenulovou animation-duration, teď má „${duration}"`);
```

import gsap from 'gsap';
import { Flip } from 'gsap/Flip';
import { animate, hover, press } from 'motion';

gsap.registerPlugin(Flip);

const filters = document.querySelector('.filters');
const gallery = document.querySelector('.gallery');
const works = gsap.utils.toArray('.work');
const filterStatus = document.querySelector('.filters__status');
const lightbox = document.querySelector('.lightbox');
const lightboxPhoto = lightbox.querySelector('.lightbox__photo');
let openedWork = null;

function animationDuration(seconds) {
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches ? 0 : seconds;
}

filters.addEventListener('click', (event) => {
  const button = event.target.closest('button');
  if (!button) return;
  filters.querySelectorAll('button').forEach((item) => {
    item.setAttribute('aria-pressed', String(item === button));
  });
  showCategory(button.dataset.category);
});

function showCategory(category) {
  const state = Flip.getState(works);
  works.forEach((work) => {
    work.hidden = category !== 'vse' && work.dataset.category !== category;
  });
  Flip.from(state, {
    duration: animationDuration(0.6),
    ease: 'power2.inOut',
    absolute: true,
    stagger: animationDuration(0.04),
    onLeave: (elements) => gsap.to(elements, { autoAlpha: 0, scale: 0.8, duration: animationDuration(0.3) }),
    onEnter: (elements) => gsap.fromTo(elements, { autoAlpha: 0, scale: 0.8 }, { autoAlpha: 1, scale: 1, duration: animationDuration(0.4) }),
  });
  const visibleCount = works.filter((work) => !work.hidden).length;
  filterStatus.textContent = `Zobrazeno ${visibleCount} z ${works.length} zakázek`;
}

const sortButton = document.querySelector('.sort');

sortButton.addEventListener('click', () => {
  const newestFirst = sortButton.getAttribute('aria-pressed') !== 'true';
  sortButton.setAttribute('aria-pressed', String(newestFirst));
  const ordered = newestFirst
    ? [...works].sort((a, b) => b.dataset.date.localeCompare(a.dataset.date))
    : works;
  const state = Flip.getState(works);
  gallery.append(...ordered);
  Flip.from(state, { duration: animationDuration(0.6), ease: 'power2.inOut' });
});

hover('.work', (work) => {
  const photo = work.querySelector('.work__photo');
  animate(photo, { scale: 1.06 }, { duration: 0.4, ease: 'easeOut' });
  return () => animate(photo, { scale: 1 }, { duration: 0.3 });
});

press('.work__open', (button) => {
  animate(button, { scale: 0.96 }, { duration: 0.1 });
  return () => animate(button, { scale: 1 }, { type: 'spring', stiffness: 500, damping: 18 });
});

async function swapPhoto(from, to, change) {
  if (!document.startViewTransition) {
    change();
    return;
  }
  from.style.viewTransitionName = 'photo';
  const transition = document.startViewTransition(() => {
    from.style.viewTransitionName = '';
    to.style.viewTransitionName = 'photo';
    change();
  });
  await transition.finished;
  to.style.viewTransitionName = '';
}

gallery.addEventListener('click', (event) => {
  const openButton = event.target.closest('.work__open');
  if (!openButton) return;
  const work = openButton.closest('.work');
  swapPhoto(work.querySelector('.work__photo'), lightboxPhoto, () => openDetail(work));
});

function openDetail(work) {
  openedWork = work;
  lightboxPhoto.dataset.photo = work.querySelector('.work__photo').dataset.photo;
  lightbox.querySelector('.lightbox__title').textContent = work.querySelector('.work__title').textContent;
  lightbox.querySelector('.lightbox__meta').textContent = work.querySelector('.work__meta').textContent;
  lightbox.showModal();
}

lightbox.querySelector('.lightbox__close').addEventListener('click', () => {
  swapPhoto(lightboxPhoto, openedWork.querySelector('.work__photo'), () => lightbox.close());
});

gallery.addEventListener('click', (event) => {
  const like = event.target.closest('.like');
  if (!like) return;
  const liked = like.getAttribute('aria-pressed') !== 'true';
  like.setAttribute('aria-pressed', String(liked));
  const count = like.querySelector('.like__count');
  count.textContent = Number(count.textContent) + (liked ? 1 : -1);
  if (liked) {
    animate(like.querySelector('svg'), { scale: [0.5, 1] }, { type: 'spring', stiffness: 600, damping: 12 });
  }
});

const cursor = document.querySelector('.cursor');
const cursorX = gsap.quickTo(cursor, 'x', { duration: 0.3, ease: 'power3.out' });
const cursorY = gsap.quickTo(cursor, 'y', { duration: 0.3, ease: 'power3.out' });

gallery.addEventListener('pointerenter', () => {
  gsap.to(cursor, { autoAlpha: 1, duration: 0.2 });
});

gallery.addEventListener('pointerleave', () => {
  gsap.to(cursor, { autoAlpha: 0, duration: 0.2 });
});

gallery.addEventListener('pointermove', (event) => {
  cursorX(event.clientX);
  cursorY(event.clientY);
});

const SITE_URL = 'https://vondrova-foto.cz/portfolio';
const shareStatus = lightbox.querySelector('.share__status');

lightbox.querySelector('.share').addEventListener('click', async () => {
  const link = `${SITE_URL}#${openedWork.id}`;
  try {
    await navigator.clipboard.writeText(link);
    shareStatus.textContent = 'Odkaz je ve schránce.';
  } catch {
    shareStatus.textContent = `Kopírování se nepovedlo. Odkaz: ${link}`;
  }
});
