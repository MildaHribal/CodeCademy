# --description--

Klikni v menu na „Recenze": stránka zastaví o kus dřív, než by měla, a „Barvy" taky nesedí. Než jsi přidal přišpendlení, fungovalo to.

Lenis si délku stránky změří při vytvoření a znovu ji měří jen při změně velikosti, s prodlevou. Přišpendlení ale stránku prodloužilo o dvě výšky okna (`pin-spacer`) až ve chvíli, kdy ScrollTrigger poprvé přepočítal pozice, a Lenis se o tom nemusí dozvědět: v náhledu zůstane u staré délky a dál nescrolluje. Spolehlivé je říct mu to přímo.

ScrollTrigger dává vědět, kdy přepočítal pozice: statická metoda `addEventListener` s událostí `'refresh'`. Lenis má metodu `resize()`, která délku stránky změří znovu.

**Úkol:** Pod napojení Lenisu na ticker přidej posluchač, který po každém přepočtu ScrollTriggeru nechá Lenis přeměřit stránku.

# --hints--

Lenis zná skutečnou délku stránky i s přišpendlením.

```js
const { lenis } = await helpers.importFile('main.js');
assert.ok(lenis, 'main.js má exportovat lenis');
const realLimit = document.documentElement.scrollHeight - window.innerHeight;
assert.ok(Math.abs(lenis.limit - realLimit) < 2, `Lenis má znát délku stránky ${realLimit} px, zná ${Math.round(lenis.limit)} px — po přepočtu ScrollTriggeru zavolej lenis.resize()`);
```

Klik na „Recenze" dojede přesně pod hlavičku.

```js
const header = document.querySelector('.site-header');
await helpers.click(document.querySelector('.site-nav a[href="#recenze"]'));
const expected = document.querySelector('#recenze').getBoundingClientRect().top + window.scrollY - header.offsetHeight;
await helpers.waitFor(async () => { const y = window.scrollY; await helpers.wait(200); return y > 0 && y === window.scrollY; }, 4500).catch(() => {});
assert.ok(Math.abs(window.scrollY - expected) < 4, `po kliknutí na Recenze má stránka dojet na ${Math.round(expected)} px, je na ${Math.round(window.scrollY)} px`);
```

Když se obsah změní a ScrollTrigger přepočítá pozice, Lenis se přizpůsobí znovu.

```js
const { ScrollTrigger } = await import('gsap/ScrollTrigger');
const { lenis } = await helpers.importFile('main.js');
assert.ok(lenis, 'main.js má exportovat lenis');
const extra = document.createElement('div');
extra.style.height = '1500px';
document.querySelector('main').append(extra);
ScrollTrigger.refresh();
await helpers.wait(50);
const realLimit = document.documentElement.scrollHeight - window.innerHeight;
assert.ok(Math.abs(lenis.limit - realLimit) < 2, 'po ScrollTrigger.refresh() má Lenis znát novou délku stránky');
```

# --help--

## --tip--

Změna rozměrů po vytvoření je popsaná v části [Rozměry se mění](see:css-efekty-animace/scroll-efekty#rozmery-se-meni-refresh-a-invalidateonrefresh) a jako past v [Typických chybách](see:css-efekty-animace/scroll-efekty#typicke-chyby-a-pasti).

## --tip--

`ScrollTrigger.addEventListener` dostane jméno události a funkci. Ve funkci zavolej metodu Lenisu, která přeměří stránku.

## --tip--

Stejný vzor u vlastní mapy stránky, která si pamatuje pozice sekcí:

```js
ScrollTrigger.addEventListener('refresh', () => minimap.measure());
```

import gsap from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import Lenis from 'lenis';

gsap.registerPlugin(ScrollTrigger);

export const lenis = new Lenis();

lenis.on('scroll', ScrollTrigger.update);
gsap.ticker.add((time) => {
  lenis.raf(time * 1000);
});
gsap.ticker.lagSmoothing(0);

const header = document.querySelector('.site-header');

document.querySelector('.site-nav').addEventListener('click', (event) => {
  const link = event.target.closest('a[href^="#"]');
  if (!link) return;
  event.preventDefault();
  lenis.scrollTo(link.getAttribute('href'), { offset: -header.offsetHeight });
});
