# --description--

## Hlášení

Grafička festivalu testovala stránku na mobilních datech: „Menu i tlačítko už neproblikávají, ale nadpis se na chvilku ukáže celý, pak zmizí a teprve potom vyjede po řádcích. Vypadá to jako chyba."

Nadpis v pravidle pro třídu `js` chybí. Jenže jeho řádky se vysouvají přes `yPercent`, ne zprůhledňují, takže samotné skrytí v CSS nestačí: nadpis by zůstal skrytý i po animaci.

## Úkol

1. Přidej `.hero__title` do pravidla pod třídou `js`.
2. V `main.js` nadpis zviditelni ve chvíli, kdy začne vysouvání řádků: do `intro` přidej na pozici `0.3` okamžité nastavení `autoAlpha: 1` (metoda `set` funguje i na timeline). Řádky jsou v tu chvíli ještě schované ve štěrbinách, takže nic neproblikne.

# --hints--

Nadpis je pod třídou `js` před animací skrytý přes `visibility: hidden`.

```js
const rules = [];
const collect = (list) => {
  for (const rule of list) {
    if (rule.cssRules) collect(rule.cssRules);
    if (rule.selectorText) rules.push(rule);
  }
};
for (const sheet of document.styleSheets) collect(sheet.cssRules);
const title = document.querySelector('.hero__title');
assert.ok(rules.some((rule) => rule.style.visibility === 'hidden' && title.matches(rule.selectorText)), '.hero__title má mít pod třídou js visibility: hidden');
document.documentElement.classList.remove('js');
assert.equal(rules.some((rule) => rule.style.visibility === 'hidden' && title.matches(rule.selectorText)), false, 'bez třídy js má nadpis zůstat vidět');
```

Na začátku intra je nadpis skrytý a od začátku vysouvání řádků (0,3 s) je vidět.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const title = document.querySelector('.hero__title');
intro.progress(0).pause();
assert.equal(getComputedStyle(title).visibility, 'hidden', 'na začátku intra má být nadpis skrytý');
intro.time(0.31);
assert.equal(getComputedStyle(title).visibility, 'visible', 'v 0.3 s, kdy začnou vyjíždět řádky, má být nadpis vidět (intro.set(…, { autoAlpha: 1 }, 0.3))');
intro.time(0.25);
assert.equal(getComputedStyle(title).visibility, 'hidden', 'před 0.3 s má nadpis zůstat skrytý, jinak problikne');
```

Zbytek intra funguje dál: na konci jsou řádky nadpisu na místě a všechno je vidět.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
intro.progress(1);
const title = document.querySelector('.hero__title');
const line = title.querySelector('div div');
assert.ok(line, 'nadpis má být dál rozdělený na řádky');
assert.equal(gsap.getProperty(line, 'yPercent'), 0, 'na konci intra mají být řádky nadpisu na místě');
for (const selector of ['.hero__title', '.site-header', '.hero__cta', '.artist']) {
  assert.equal(getComputedStyle(document.querySelector(selector)).visibility, 'visible', `${selector} má být po intru vidět`);
}
```

# --help--

## --tip--

Jde o skrytí obsahu do startu animace, které jsi psal v minulém kroku. Proč nestačí samo CSS, vysvětluje past `from` na prvek skrytý v CSS v části [Typické chyby a pasti](see:css-efekty-animace/gsap-zaklady#typicke-chyby-a-pasti).

## --tip--

Selektor nadpisu patří do stejného seznamu jako ostatní prvky pod `.js`. V `main.js` stačí jedno volání metody timeline, která nastaví hodnotu bez animace, s pozicí jako třetím argumentem.

## --tip--

Stejně by se na jiné timeline zviditelnil ceník ve 2 s:

```js
checkout.set('.pricing', { autoAlpha: 1 }, 2);
```

## --file-- main.js

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', { type: 'lines, words', mask: 'lines' });

intro.from(titleSplit.lines, {
  yPercent: 100,
  duration: 0.9,
  ease: 'expo.out',
  stagger: 0.12,
}, 0.3);
```
