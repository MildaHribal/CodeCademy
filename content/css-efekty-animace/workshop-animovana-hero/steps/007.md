# --description--

Hlavní nadpis je teď jediná věc, která se nehýbe. Efekt, který uvidíš na webech agentur: každý řádek nadpisu vyjede zespodu z neviditelné „štěrbiny", jako by ho někdo vysunul zpod podlahy.

Na to je plugin `SplitText`. Rozdělí text na řádky, slova nebo písmena (každý kus obalí do `<div>`) a s `mask: 'lines'` obalí každý řádek ještě jednou prvkem s `overflow: clip`. Stačí pak řádek posunout o 100 % jeho výšky dolů a štěrbina ho schová. Čtečka obrazovky přitom přečte nadpis celý: SplitText nadpisu dá `aria-label` s původním textem a kousky skryje přes `aria-hidden`.

```js
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

const quoteSplit = SplitText.create('.quote', { type: 'lines, words', mask: 'lines' });
gsap.from(quoteSplit.lines, { yPercent: 100, stagger: 0.1 });
```

Nadpis se musí odhalit brzy, ještě během menu. Proto dostane pozici jako **číslo**: čas v sekundách od začátku timeline.

**Úkol:**

1. Naimportuj `SplitText` z `'gsap/SplitText'` a zaregistruj ho.
2. Rozděl `.hero__title` do konstanty `titleSplit` s `type: 'lines, words'` (slova se hodí, kdybys později chtěl animovat i po nich) a `mask: 'lines'`.
3. Za karty interpretů přidej do `intro` tween řádků `titleSplit.lines`: z `yPercent: 100`, `duration: 0.9`, `ease: 'expo.out'`, `stagger: 0.12`, na pozici `0.3`.

# --hints--

`SplitText` rozdělil nadpis na řádky schované ve štěrbinách a čtečka pořád dostane celý text.

```js
const title = document.querySelector('.hero__title');
const lines = [...title.querySelectorAll('div')].filter((element) => getComputedStyle(element.parentElement).overflow === 'clip' && element.parentElement.parentElement === title);
assert.ok(lines.length >= 1, 'nadpis .hero__title má být rozdělený na řádky s maskou (SplitText.create s type: \'lines, words\' a mask: \'lines\')');
assert.equal(title.getAttribute('aria-label'), 'Léto, které zní od řeky až na Letnou', 'nadpis má mít aria-label s celým textem, aby ho čtečka přečetla najednou');
```

V `intro` je od 0,3 s tween, který řádky vysune zespodu s rozestupem 0,12 s.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const title = document.querySelector('.hero__title');
const tweens = intro.getChildren(true, true, false);
const titleTween = tweens.find((tween) => tween.targets().length && tween.targets().every((element) => title.contains(element) && element !== title));
assert.ok(titleTween, 'intro má obsahovat tween, který animuje řádky nadpisu (titleSplit.lines)');
assert.equal(titleTween.startTime(), 0.3, 'tween řádků má začínat v 0.3 s (pozice 0.3)');
const lineCount = titleTween.targets().length;
assert.ok(Math.abs(titleTween.duration() - (0.9 + 0.12 * (lineCount - 1))) < 0.001, `každý řádek má trvat 0.9 s a začínat 0.12 s po předchozím (celkem ${(0.9 + 0.12 * (lineCount - 1)).toFixed(2)} s pro ${lineCount} řádky), tween trvá ${titleTween.duration().toFixed(2)} s`);
assert.equal(titleTween.vars.ease, 'expo.out', 'tween řádků má mít ease: \'expo.out\'');
const firstLine = titleTween.targets()[0];
intro.progress(0).pause();
assert.equal(gsap.getProperty(firstLine, 'yPercent'), 100, 'na začátku intra má být řádek posunutý o 100 % dolů (yPercent: 100)');
intro.progress(1);
assert.equal(gsap.getProperty(firstLine, 'yPercent'), 0, 'na konci intra má být řádek na svém místě');
```

## --file-- main.js

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', { type: 'lines, words', mask: 'lines' });

intro.from(titleSplit.lines, {
  yPercent: 100,
  duration: 0.9,
  ease: 'expo.out',
  stagger: 0.12,
}, 0.3);
```
