# --description--

Tlačítko na vstupenky je nejdůležitější prvek stránky. [[magnetické tlačítko|Magnetické tlačítko]] na něj přitáhne pozornost: když nad ním pohybuješ myší, kousek se posune směrem ke kurzoru, jako by ho přitahoval magnet.

Výpočet má tři podcíle:

1. zjistit střed tlačítka (`getBoundingClientRect()` vrátí `left`, `top`, `width`, `height`),
2. spočítat, jak daleko je kurzor od středu ve vodorovném a svislém směru (`event.clientX`, `event.clientY`),
3. posunout tlačítko o **zlomek** té vzdálenosti, třeba o třetinu. Celou vzdálenost ne: tlačítko by skočilo pod kurzor.

Posun udělej tweenem na `x` a `y`, s krátkou délkou (kolem 0,4 s) a křivkou, která na konci zpomalí. Událost `pointermove` z [js-dom](see:js-dom/udalosti#mys-prst-a-pero-pointer-udalosti) funguje pro myš i pero.

**Úkol:** Na konec `main.js` ulož tlačítko `.hero__cta` do konstanty `cta` a v posluchači `pointermove` ho posuň směrem ke kurzoru o zhruba třetinu vzdálenosti od středu.

# --hints--

Když je kurzor vpravo dole od středu tlačítka, tlačítko se posune doprava dolů o zlomek vzdálenosti.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
intro.progress(1);
const cta = document.querySelector('.hero__cta');
const rect = cta.getBoundingClientRect();
const centerX = rect.left + rect.width / 2;
const centerY = rect.top + rect.height / 2;
const move = (dx, dy) => cta.dispatchEvent(new PointerEvent('pointermove', { bubbles: true, clientX: centerX + dx, clientY: centerY + dy, pointerType: 'mouse' }));
move(40, 20);
await helpers.waitFor(() => gsap.getProperty(cta, 'x') > 3 && gsap.getProperty(cta, 'y') > 1, 2000).catch(() => {});
assert.ok(gsap.getProperty(cta, 'x') > 3, 'po pohybu myši vpravo od středu se má tlačítko posunout doprava (kladné x)');
assert.ok(gsap.getProperty(cta, 'y') > 1, 'po pohybu myši pod středem se má tlačítko posunout dolů (kladné y)');
await helpers.wait(600);
const x = gsap.getProperty(cta, 'x');
assert.ok(x >= 4 && x <= 28, `tlačítko se má posunout jen o zlomek vzdálenosti kurzoru (40 px → zhruba 8–20 px), posunulo se o ${x.toFixed(1)} px`);
```

Když kurzor přejede doleva nahoru, tlačítko ho následuje na druhou stranu.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
intro.progress(1);
const cta = document.querySelector('.hero__cta');
const rect = cta.getBoundingClientRect();
cta.dispatchEvent(new PointerEvent('pointermove', { bubbles: true, clientX: rect.left + rect.width / 2 - 50, clientY: rect.top + rect.height / 2 - 20, pointerType: 'mouse' }));
await helpers.waitFor(() => gsap.getProperty(cta, 'x') < -3 && gsap.getProperty(cta, 'y') < -1, 2000).catch(() => {});
assert.ok(gsap.getProperty(cta, 'x') < -3, 'po pohybu myši vlevo od středu se má tlačítko posunout doleva (záporné x)');
assert.ok(gsap.getProperty(cta, 'y') < -1, 'po pohybu myši nad středem se má tlačítko posunout nahoru (záporné y)');
```

# --help--

## --tip--

Posun přes `x` a `y` je tween jako každý jiný, viz [gsap.to, from, fromTo a set](see:css-efekty-animace/gsap-zaklady#gsap-to-from-fromto-a-set). Posluchač a souřadnice ukazatele jsou v části [Myš, prst a pero](see:js-dom/udalosti#mys-prst-a-pero-pointer-udalosti).

## --tip--

V posluchači spočítej `offsetX` jako `event.clientX` minus vodorovný střed tlačítka (levý okraj plus polovina šířky), `offsetY` obdobně svisle. Do `gsap.to` pak dej `x` a `y` jako zlomek těch vzdáleností.

## --tip--

Stejný výpočet pro obrázek, který se natáčí za myší:

```js
card.addEventListener('pointermove', (event) => {
  const box = card.getBoundingClientRect();
  const fromCenterX = event.clientX - (box.left + box.width / 2);
  gsap.to(card, { rotationY: fromCenterX / 20, duration: 0.5 });
});
```

import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
      stagger: 0.12,
    });
    intro.add(reveal, 0.3);
    return reveal;
  },
});

intro.set('.hero__title', { autoAlpha: 1 }, 0.3);

gsap.to('.shape', {
  y: -24,
  rotation: 8,
  duration: 4,
  ease: 'sine.inOut',
  repeat: -1,
  yoyo: true,
  stagger: { each: 0.6, from: 'random' },
});

intro.from('.shape', {
  autoAlpha: 0,
  scale: 0.6,
  duration: 1.2,
  ease: 'power3.out',
  stagger: 0.15,
}, 0);
