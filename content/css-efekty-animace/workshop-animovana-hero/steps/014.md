# --description--

Magnet funguje, ale `pointermove` přichází desítkykrát za sekundu a každé volání `gsap.to` vytvoří nový tween. Při rychlém pohybu myší jich běží naráz desítky a všechny přepisují stejné `x` a `y`. Na slabším telefonu nebo notebooku na baterii to je znát.

`gsap.quickTo(prvek, 'vlastnost', nastavení)` vytvoří tween **jednou** a vrátí funkci. Když ji zavoláš s novou cílovou hodnotou, tween jen plynule změní směr k novému cíli, žádný nový nevzniká. Pro dvě vlastnosti potřebuješ dvě funkce.

**Úkol:** Nad posluchačem vytvoř dvě funkce přes `gsap.quickTo`, jednu pro `x` a jednu pro `y`, se stejnou délkou a křivkou, jakou má teď tween. V posluchači místo `gsap.to` zavolej obě funkce s novými hodnotami.

# --hints--

Ani při rychlé sérii pohybů myší neběží na tlačítku víc než pár tweenů.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
intro.progress(1);
const cta = document.querySelector('.hero__cta');
const rect = cta.getBoundingClientRect();
for (let i = 0; i < 30; i++) {
  cta.dispatchEvent(new PointerEvent('pointermove', { bubbles: true, clientX: rect.left + rect.width / 2 + i * 2, clientY: rect.top + rect.height / 2 + i, pointerType: 'mouse' }));
}
await helpers.wait(50);
const running = gsap.getTweensOf(cta, true).length;
assert.ok(running <= 3, `po 30 pohybech myší běží na tlačítku ${running} tweenů — použij gsap.quickTo, které tween vytvoří jen jednou`);
```

Magnet funguje dál: tlačítko se posune směrem ke kurzoru o zlomek vzdálenosti.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
intro.progress(1);
const cta = document.querySelector('.hero__cta');
const rect = cta.getBoundingClientRect();
cta.dispatchEvent(new PointerEvent('pointermove', { bubbles: true, clientX: rect.left + rect.width / 2 + 40, clientY: rect.top + rect.height / 2 - 20, pointerType: 'mouse' }));
await helpers.waitFor(() => gsap.getProperty(cta, 'x') > 3 && gsap.getProperty(cta, 'y') < -1, 2000).catch(() => {});
assert.ok(gsap.getProperty(cta, 'x') > 3, 'tlačítko se má posunout doprava za kurzorem');
assert.ok(gsap.getProperty(cta, 'y') < -1, 'tlačítko se má posunout nahoru za kurzorem');
await helpers.wait(600);
assert.ok(gsap.getProperty(cta, 'x') <= 28, 'tlačítko se má posunout jen o zlomek vzdálenosti kurzoru');
```

# --help--

## --tip--

Jde o znovupoužití jednoho tweenu místo vytváření nových. Proč na počtu tweenů záleží, souvisí s pastí o dvou tweenech na stejnou vlastnost v [Typických chybách a pastech](see:css-efekty-animace/gsap-zaklady#typicke-chyby-a-pasti).

## --tip--

`gsap.quickTo` dostane prvek, jméno jedné vlastnosti v uvozovkách a objekt s `duration` a `ease`. Výsledek ulož do konstanty mimo posluchač, protože vzniknout má jen jednou. V posluchači ji zavoláš jako funkci s číslem.

## --tip--

Stejný vzor pro kolečko, které sleduje posuvník hlasitosti:

```js
const knobTo = gsap.quickTo(knob, 'rotation', { duration: 0.2, ease: 'power1.out' });
slider.addEventListener('input', () => knobTo(slider.value * 2.7));
```

# --explain--

Vysvětli, proč je pro magnetické tlačítko lepší `gsap.quickTo` než nové `gsap.to` v každém `pointermove`.

## --model--
`pointermove` přichází desítkykrát za sekundu a každé `gsap.to` by vytvořilo nový tween. Staré tweeny by dál běžely a přepisovaly stejné `x` a `y`, takže prohlížeč dělá zbytečnou práci a pohyb může cukat. `quickTo` vytvoří tween jednou a při každém volání mu jen změní cíl, takže běží pořád jen jeden tween na vlastnost a pohyb plynule mění směr.

## --checklist--
- `pointermove` se volá mnohokrát za sekundu.
- Každé `gsap.to` vytvoří nový tween a staré běží dál.
- `quickTo` vytvoří tween jednou a mění mu jen cílovou hodnotu.
- Méně tweenů znamená méně práce v každém snímku a plynulejší změnu směru.

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
      stagger: 0.12,
    });
    intro.add(reveal, 0.3);
    return reveal;
  },
});

intro.set('.hero__title', { autoAlpha: 1 }, 0.3);

gsap.to('.shape', {
  y: -24,
  rotation: 8,
  duration: 4,
  ease: 'sine.inOut',
  repeat: -1,
  yoyo: true,
  stagger: { each: 0.6, from: 'random' },
});

intro.from('.shape', {
  autoAlpha: 0,
  scale: 0.6,
  duration: 1.2,
  ease: 'power3.out',
  stagger: 0.15,
}, 0);
```
