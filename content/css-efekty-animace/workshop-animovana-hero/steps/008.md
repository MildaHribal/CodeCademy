# --description--

Obnov náhled a dívej se pozorně: na zlomek sekundy uvidíš celou hotovou stránku, pak všechno zmizí a teprve potom přijede. Prohlížeč vykreslí HTML se styly hned, ale `main.js` je modul, který se spustí až po načtení dokumentu a knihoven. Mezi tím je obsah vidět ve výchozím stavu. Tomu se říká [[probliknutí obsahu]].

Oprava má dvě části:

1. **Třída `js` na `<html>`** přidaná malým skriptem přímo v `<head>`. Ten se spustí dřív, než se cokoli vykreslí. Když JavaScript neběží (vypnutý, spadl, nenačetl se), třída chybí a obsah zůstane vidět.
2. **CSS, které pod třídou `js` animované prvky skryje** přes `visibility: hidden`. Ne přes `opacity: 0`: `autoAlpha` na konci animace nastaví `visibility` zpátky, kdežto průhlednost z CSS by `from` převzal jako cílovou hodnotu.

Na jiném webu by to vypadalo takhle:

```html
<script>document.documentElement.classList.add('js');</script>
```

```css
.js .pricing-card {
  visibility: hidden;
}
```

**Úkol:**

1. V `index.html` přidej do `<head>` (před odkaz na styly) inline skript, který na `<html>` přidá třídu `js`.
2. Na konec `styles.css` přidej jedno pravidlo, které pod třídou `js` skryje `.site-header`, `.hero__eyebrow`, `.hero__meta`, `.hero__cta` a `.artist`. Nadpis zatím vynech, jeho řádky se nezprůhledňují, ale vysouvají.

# --hints--

Hned v `<head>` je skript, který na `<html>` přidá třídu `js`.

```js
const head = files['index.html'].split(/<\/head>/i)[0];
assert.match(helpers.stripComments(head, 'html'), /<script>[\s\S]*classList\.add\(\s*['"]js['"]\s*\)[\s\S]*<\/script>/, 'v <head> má být <script>, který zavolá document.documentElement.classList.add(\'js\')');
assert.ok(document.documentElement.classList.contains('js'), 'element <html> má mít třídu js');
```

Pod třídou `js` jsou hlavička, nadpisek, datum, tlačítko i karty interpretů před animací skryté přes `visibility: hidden`.

```js
const rules = [];
const collect = (list) => {
  for (const rule of list) {
    if (rule.cssRules) collect(rule.cssRules);
    if (rule.selectorText) rules.push(rule);
  }
};
for (const sheet of document.styleSheets) collect(sheet.cssRules);
const hides = (element) => rules.some((rule) => rule.style.visibility === 'hidden' && element.matches(rule.selectorText));
for (const selector of ['.site-header', '.hero__eyebrow', '.hero__meta', '.hero__cta', '.artist']) {
  const element = document.querySelector(selector);
  assert.ok(hides(element), `${selector} má mít v CSS visibility: hidden pod třídou js`);
  assert.equal(rules.some((rule) => rule.style.opacity === '0' && element.matches(rule.selectorText)), false, `${selector} neskrývej přes opacity: 0 — from by průhlednost převzal jako cíl`);
}
document.documentElement.classList.remove('js');
for (const selector of ['.site-header', '.hero__meta', '.artist']) {
  assert.equal(hides(document.querySelector(selector)), false, `bez třídy js (když JavaScript neběží) má být ${selector} vidět — skrývací pravidlo patří pod .js`);
}
```

Po skončení intra je všechno zase vidět.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
intro.progress(1);
for (const selector of ['.site-header', '.site-nav a', '.hero__eyebrow', '.hero__meta', '.hero__cta', '.artist']) {
  for (const element of document.querySelectorAll(selector)) {
    assert.equal(getComputedStyle(element).visibility, 'visible', `${selector} má být po skončení intra vidět`);
  }
}
```

# --explain--

Vysvětli, proč se obsah před animací skrývá třídou `js` přidanou skriptem v `<head>`, a ne rovnou pravidlem `.hero__meta { visibility: hidden; }`.

## --model--
Skript v hlavičce se spustí dřív, než se stránka poprvé vykreslí, takže třída je na `<html>` od začátku a obsah neprobliká. Když JavaScript neběží, třída chybí a obsah je normálně vidět. Kdybych skryl prvky rovnou v CSS, zůstaly by bez JavaScriptu nebo při chybě v modulu navždy neviditelné. Animace je vylepšení, obsah na ní nesmí záviset.

## --checklist--
- Skript v `<head>` přidá třídu dřív, než se stránka vykreslí.
- Bez JavaScriptu třída chybí a obsah zůstane vidět.
- Pravidlo bez třídy by obsah schovalo i tam, kde animace nikdy neproběhne.

import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', { type: 'lines, words', mask: 'lines' });

intro.from(titleSplit.lines, {
  yPercent: 100,
  duration: 0.9,
  ease: 'expo.out',
  stagger: 0.12,
}, 0.3);
