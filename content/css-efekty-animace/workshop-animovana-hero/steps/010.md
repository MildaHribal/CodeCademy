# --description--

Otoč telefon nebo zúži okno: nadpis má najednou jiné zalomení, ale `SplitText` ho rozdělil jednou, při načtení. „Řádky" z široké obrazovky se teď lámou uvnitř sebe a štěrbina masky jim ořezává kusy textu. Přepni náhled na šířku 375 a zpátky a v DevTools uvidíš, že řádků je pořád stejně.

`SplitText` umí text po změně šířky rozdělit znovu: volba `autoSplit: true`. Nové řádky jsou ale nové prvky, takže animace starých řádků by na ně nemířila. Proto se animace píše do funkce `onSplit(self)`, která dostane čerstvě rozdělený text a **vrátí** animaci. SplitText pak po každém novém rozdělení starou animaci vrátí a novou posune do stejného místa, kde byla stará.

```js
SplitText.create('.quote', {
  type: 'lines',
  autoSplit: true, // po změně šířky rozděl znovu
  onSplit: (self) => gsap.from(self.lines, { autoAlpha: 0, stagger: 0.1 }),
});
```

**Úkol:** Uprav `titleSplit` tak, aby se nadpis po změně šířky rozdělil znovu. Tween řádků vytvoř uvnitř `onSplit` jako samostatný `gsap.from` se stejnými hodnotami, přidej ho do `intro` na pozici `0.3` metodou pro vložení hotové animace do timeline a vrať ho.

# --hints--

Po změně šířky okna na 375 px je nadpis rozdělený do víc řádků než na široké obrazovce a text zůstal celý.

```js
const title = document.querySelector('.hero__title');
const lineCount = () => [...title.children].length;
const wide = lineCount();
assert.ok(title.querySelector('div div'), 'nadpis má být rozdělený na řádky');
await helpers.resize(375);
await helpers.waitFor(() => lineCount() > wide, 3000).catch(() => {});
assert.ok(lineCount() > wide, `na 375 px má mít nadpis víc řádků než na široké obrazovce (${wide}) — přidej autoSplit: true`);
assert.equal(title.textContent.replace(/\s+/g, ' ').trim(), 'Léto, které zní od řeky až na Letnou', 'po novém rozdělení má text nadpisu zůstat celý');
```

Když se šířka změní uprostřed vysouvání, nové řádky pokračují v animaci z místa, kde byly staré.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const title = document.querySelector('.hero__title');
const wide = title.children.length;
intro.pause();
intro.time(0.35);
await helpers.resize(375);
await helpers.waitFor(() => title.children.length > wide, 3000).catch(() => {});
assert.ok(title.children.length > wide, 'po změně šířky se má nadpis rozdělit znovu (autoSplit: true)');
const lastLine = [...title.children].at(-1).firstElementChild;
const offset = gsap.getProperty(lastLine, 'yPercent');
assert.ok(offset > 5, `nové řádky mají pokračovat v animaci (poslední řádek má být ještě posunutý dolů), má yPercent ${offset} — animaci řádků vytvoř v onSplit a přidej ji do intro`);
```

Tween řádků je v `intro` od 0,3 s a na konci intra jsou řádky na místě.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const title = document.querySelector('.hero__title');
const titleTween = intro.getChildren(true, true, false).find((tween) => tween.targets().length && tween.targets().every((element) => title.contains(element)) && tween.duration() > 0);
assert.ok(titleTween, 'intro má obsahovat tween řádků nadpisu (přidej ho přes intro.add(…, 0.3))');
assert.equal(titleTween.startTime(), 0.3, 'tween řádků má být v intro na pozici 0.3');
intro.progress(1);
assert.equal(gsap.getProperty(titleTween.targets()[0], 'yPercent'), 0, 'na konci intra mají být řádky na místě');
assert.equal(getComputedStyle(title).visibility, 'visible', 'na konci intra má být nadpis vidět');
```

# --help--

## --tip--

Jde o nové rozdělení textu po změně šířky. Popis `autoSplit` a `onSplit` je v části [Text po řádcích: SplitText](see:css-efekty-animace/gsap-zaklady#text-po-radcich-splittext).

## --tip--

Do objektu `SplitText.create` patří `autoSplit` a metoda `onSplit(self)`. Uvnitř vytvoř tween nad `self.lines` (ne nad `titleSplit.lines`, ten při prvním volání ještě neexistuje), vlož ho do `intro` přes `add` s pozicí a na konci ho vrať. Původní `intro.from(titleSplit.lines, …)` smaž.

## --tip--

Vzor na jiném prvku a jiné timeline:

```js
SplitText.create('.promo', {
  type: 'words',
  autoSplit: true, // znovu po změně šířky
  onSplit: (self) => {
    const wave = gsap.from(self.words, { y: 20, autoAlpha: 0, stagger: 0.05 });
    checkout.add(wave, 1.2);
    return wave;
  },
});
```

# --explain--

Vysvětli, proč animace rozdělených řádků patří do `onSplit` a proč ji odtud vracíš.

## --model--
Po změně šířky SplitText text rozdělí znovu a vzniknou úplně nové prvky řádků, takže animace vytvořená jednou při načtení by mířila na staré, už odpojené prvky. Funkce `onSplit` se zavolá po každém rozdělení, takže animace vznikne pro aktuální řádky. Když ji vrátím, SplitText při dalším rozdělení starou animaci vrátí a novou posune na stejné místo, takže se nic nerozskočí ani uprostřed animace.

## --checklist--
- Nové rozdělení vytvoří nové prvky, stará animace míří na odpojené řádky.
- `onSplit` se volá po každém rozdělení, animace vznikne pro aktuální řádky.
- Vrácenou animaci SplitText při dalším rozdělení vrátí a nahradí.
- Nová animace pokračuje z místa, kde byla stará.

## --file-- main.js

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
      stagger: 0.12,
    });
    intro.add(reveal, 0.3);
    return reveal;
  },
});

intro.set('.hero__title', { autoAlpha: 1 }, 0.3);
```
