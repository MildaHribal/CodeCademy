# --description--

Tvary se teď vlní, ale objeví se naráz s načtením stránky, ještě před menu. Navrhni jim vlastní vstup, který zapadne do intra.

Rozhodni sám: jestli se tvary objeví na začátku, nebo až pod nadpisem, jestli se zvětší, prolnou, nebo přiletí, v jakém pořadí a s jakou křivkou. Jediné omezení: vlnění z minulého kroku animuje `y` a `rotation`, takže vstup postav na jiných vlastnostech, jinak se oba tweeny poperou o stejnou hodnotu.

Až bude hotovo, pusť si náhled několikrát a zeptej se: odvádí vstup tvarů pozornost od nadpisu? Pokud ano, zkrať ho nebo zjemni.

Tady je úvodní obrazovka hotová: menu, nadpis po řádcích, datum, tlačítko, interpreti i živé pozadí. Klidně si dej pauzu, další část přidá tlačítku magnetismus.

**Úkol:** Přidej do `intro` vstup všech tří tvarů `.shape` podle svého návrhu.

# --hints--

Všechny tři tvary mají v `intro` vstupní animaci, takže na začátku intra vypadají jinak než na konci.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const tweens = intro.getChildren(true, true, false);
const snapshot = (shape) => {
  const style = getComputedStyle(shape);
  return [style.opacity, style.visibility, style.transform, style.scale, style.filter, style.clipPath].join('|');
};
for (const shape of document.querySelectorAll('.shape')) {
  assert.ok(tweens.some((tween) => tween.targets().includes(shape)), `tvar ${shape.className} má mít v intro vstupní animaci`);
  intro.progress(1).pause();
  const end = snapshot(shape);
  intro.progress(0);
  assert.notEqual(snapshot(shape), end, `tvar ${shape.className} má na začátku intra vypadat jinak než na konci (neviditelný, menší, jinde…)`);
}
```

Po skončení intra jsou tvary vidět a dál se vlní.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
intro.progress(1);
for (const shape of document.querySelectorAll('.shape')) {
  const style = getComputedStyle(shape);
  assert.equal(style.visibility, 'visible', `${shape.className} má být po intru vidět`);
  assert.ok(Number(style.opacity) >= 0.5, `${shape.className} má být po intru dobře vidět (opacity aspoň 0.5)`);
}
const sun = document.querySelector('.shape--sun');
const before = gsap.getProperty(sun, 'y');
await helpers.waitFor(() => Math.abs(gsap.getProperty(sun, 'y') - before) > 0.5, 3000).catch(() => {});
assert.ok(Math.abs(gsap.getProperty(sun, 'y') - before) > 0.5, 'po intru se mají tvary dál vlnit — vstup nesmí animovat y a rotation');
```

# --help--

## --tip--

Vstup je další tween v timeline, stejně jako karty interpretů. Pozice a jejich význam jsou v části [Timeline: sekvence bez počítání delay](see:css-efekty-animace/gsap-zaklady#timeline-sekvence-bez-pocitani-delay).

## --tip--

Kandidáti na vlastnosti, které se s vlněním nepoperou: `autoAlpha`, `scale`, `filter` (třeba rozostření), `x`. Pozice může být číslo (čas od začátku), `'<'` vůči předchozímu tweenu, nebo odkaz na konec s přesahem.

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
      stagger: 0.12,
    });
    intro.add(reveal, 0.3);
    return reveal;
  },
});

intro.set('.hero__title', { autoAlpha: 1 }, 0.3);

gsap.to('.shape', {
  y: -24,
  rotation: 8,
  duration: 4,
  ease: 'sine.inOut',
  repeat: -1,
  yoyo: true,
  stagger: { each: 0.6, from: 'random' },
});
```

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
      stagger: 0.12,
    });
    intro.add(reveal, 0.3);
    return reveal;
  },
});

intro.set('.hero__title', { autoAlpha: 1 }, 0.3);

gsap.to('.shape', {
  y: -24,
  rotation: 8,
  duration: 4,
  ease: 'sine.inOut',
  repeat: -1,
  yoyo: true,
  stagger: { each: 0.6, from: 'random' },
});

intro.from('.shape', {
  autoAlpha: 0,
  scale: 0.6,
  duration: 1.2,
  ease: 'power3.out',
  stagger: 0.15,
}, 0);
```
