# --description--

`mm.revert()` vrátí animace, jenže posluchače `pointermove` a `pointerleave` na tlačítku zůstanou. Když dotaz přestane platit (uživatel zapne omezení pohybu), magnet by po dalším pohybu myší ožil, a když dotaz začne platit znovu, přidaly by se druhé posluchače k prvním.

GSAP o posluchačích neví, protože nejsou animace. Proto funkce v `mm.add` smí **vrátit úklidovou funkci**. GSAP ji zavolá pokaždé, když dotaz přestane platit, a ty v ní posluchače odebereš. Odebrat jde jen posluchač, na který máš odkaz, takže anonymní šipky nahraď pojmenovanými funkcemi.

**Úkol:** Posluchače magnetu přepiš na pojmenované funkce (třeba `handleMove` a `handleLeave`) a z funkce v `mm.add` vrať funkci, která oba posluchače z tlačítka odebere.

# --hints--

Po `mm.revert()` magnet nereaguje: tlačítko zůstane na místě, ani když se nad ním pohne myš.

```js
const gsap = (await import('gsap')).default;
const { intro, mm } = await helpers.importFile('main.js');
assert.ok(mm, 'main.js má exportovat mm');
intro.progress(1);
mm.revert();
const cta = document.querySelector('.hero__cta');
const rect = cta.getBoundingClientRect();
cta.dispatchEvent(new PointerEvent('pointermove', { bubbles: true, clientX: rect.right - 2, clientY: rect.bottom - 2, pointerType: 'mouse' }));
await helpers.wait(400);
assert.ok(Math.abs(gsap.getProperty(cta, 'x')) < 0.5, `po mm.revert() se tlačítko nemá hýbat, posunulo se na x = ${gsap.getProperty(cta, 'x').toFixed(1)} — vrať z mm.add funkci, která odebere posluchače`);
```

Když dotaz platí, magnet funguje: přitáhne tlačítko a po odjetí ho vrátí.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
intro.progress(1);
const cta = document.querySelector('.hero__cta');
const rect = cta.getBoundingClientRect();
cta.dispatchEvent(new PointerEvent('pointermove', { bubbles: true, clientX: rect.left + 2, clientY: rect.bottom - 2, pointerType: 'mouse' }));
await helpers.waitFor(() => gsap.getProperty(cta, 'x') < -5, 2000).catch(() => {});
assert.ok(gsap.getProperty(cta, 'x') < -5, 'magnet má tlačítko posunout ke kurzoru');
cta.dispatchEvent(new PointerEvent('pointerleave', { bubbles: false, pointerType: 'mouse' }));
await helpers.waitFor(() => Math.abs(gsap.getProperty(cta, 'x')) < 0.5, 2000).catch(() => {});
assert.ok(Math.abs(gsap.getProperty(cta, 'x')) < 0.5, 'po odjetí kurzoru se má tlačítko vrátit');
```

# --help--

## --tip--

Jde o úklid všeho, co v kontextu vzniklo a není animace. Obecný princip je v části [Úklid: gsap.context() a revert()](see:css-efekty-animace/gsap-zaklady#uklid-gsap-context-a-revert).

## --tip--

Posluchače ulož do konstant s funkcemi a do `addEventListener` předávej jejich jména. Na konci funkce v `mm.add` napiš `return` s šipkou, která zavolá `removeEventListener` se stejnou událostí a stejnou funkcí.

## --tip--

Stejný úklid u posluchače změny velikosti okna:

```js
media.add('(min-width: 1024px)', () => {
  const handleResize = () => layoutTo(window.innerWidth);
  window.addEventListener('resize', handleResize);
  return () => window.removeEventListener('resize', handleResize);
});
```

# --explain--

Vysvětli, proč funkce v `mm.add` vrací úklid, když GSAP po `revert()` animace vrací sám.

## --model--
GSAP si pamatuje jen animace, které ve funkci vznikly, a ty umí vrátit. Posluchače událostí nejsou animace, takže by po změně media dotazu zůstaly na tlačítku a magnet by fungoval i tam, kde nemá, a při dalším zapnutí by se posluchače zdvojily. Vrácená funkce je místo, kde GSAPu řeknu, co dalšího uklidit; zavolá ji pokaždé, když dotaz přestane platit.

## --checklist--
- `revert()` vrací jen animace vzniklé v kontextu.
- Posluchače událostí po změně dotazu zůstanou, když je sám neodebereš.
- Bez úklidu se posluchače při dalším zapnutí zdvojí.
- GSAP zavolá vrácenou funkci pokaždé, když dotaz přestane platit.

```js
intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })

  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
```

```js
import gsap from 'gsap';
import { SplitText } from 'gsap/SplitText';

gsap.registerPlugin(SplitText);

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });

intro
  .from('.hero__meta', { autoAlpha: 0, y: 16 }, '-=0.3')
  .from('.hero__cta', {
    autoAlpha: 0,
    scale: 0.8,
    ease: 'back.out(1.7)',
  }, '<0.15')
  .from('.artist', {
    autoAlpha: 0,
    y: 40,
    stagger: { each: 0.08, from: 'center' },
  }, '-=0.2');

const titleSplit = SplitText.create('.hero__title', {
  type: 'lines, words',
  mask: 'lines',
  autoSplit: true,
  onSplit(self) {
    const reveal = gsap.from(self.lines, {
      yPercent: 100,
      duration: 0.9,
      ease: 'expo.out',
      stagger: 0.12,
    });
    intro.add(reveal, 0.3);
    return reveal;
  },
});

intro.set('.hero__title', { autoAlpha: 1 }, 0.3);

gsap.to('.shape', {
  y: -24,
  rotation: 8,
  duration: 4,
  ease: 'sine.inOut',
  repeat: -1,
  yoyo: true,
  stagger: { each: 0.6, from: 'random' },
});

intro.from('.shape', {
  autoAlpha: 0,
  scale: 0.6,
  duration: 1.2,
  ease: 'power3.out',
  stagger: 0.15,
}, 0);

export const mm = gsap.matchMedia();

mm.add('(hover: hover) and (prefers-reduced-motion: no-preference)', () => {
  const cta = document.querySelector('.hero__cta');
  const moveX = gsap.quickTo(cta, 'x', { duration: 0.4, ease: 'power3.out' });
  const moveY = gsap.quickTo(cta, 'y', { duration: 0.4, ease: 'power3.out' });

  const handleMove = (event) => {
    const rect = cta.getBoundingClientRect();
    const offsetX = event.clientX - (rect.left + rect.width / 2);
    const offsetY = event.clientY - (rect.top + rect.height / 2);
    moveX(offsetX * 0.35);
    moveY(offsetY * 0.35);
  };

  const handleLeave = () => {
    moveX(0);
    moveY(0);
  };

  cta.addEventListener('pointermove', handleMove);
  cta.addEventListener('pointerleave', handleLeave);

  return () => {
    cta.removeEventListener('pointermove', handleMove);
    cta.removeEventListener('pointerleave', handleLeave);
  };
});
```
