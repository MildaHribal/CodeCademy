# --description--

Menu teď přijede jako jeden blok s hlavičkou. Působí to ztuha: čtyři odkazy by měly naskočit jeden po druhém, jako vlna.

Když tween dostane selektor, který najde víc prvků, `stagger` je rozestaví v čase: každý další začne o zadaný počet sekund později. Na jiných prvcích:

```js
checkout.from('.payment-method', { autoAlpha: 0, x: -12, stagger: 0.05 });
```

**Úkol:** Do `intro` přidej **mezi** hlavičku a nadpisek tween pro odkazy `.site-nav a`: přijedou z `autoAlpha: 0` a `y: -12` a mezi začátky dvou sousedních odkazů bude `0.05` s. Tween vlož do řetězu na správné místo, pozici zatím nepiš.

# --hints--

Odkazy v menu jsou v `intro` hned za hlavičkou a začínají postupně po 0,05 s.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const links = [...document.querySelectorAll('.site-nav a')];
const header = document.querySelector('.site-header');
const tweens = intro.getChildren(true, true, false);
const headerTween = tweens.find((tween) => tween.targets().includes(header));
const navTween = tweens.find((tween) => tween.targets().includes(links[1]));
assert.ok(navTween, 'intro má obsahovat tween pro odkazy .site-nav a');
assert.equal(navTween.targets().length, 4, 'tween menu má animovat všechny 4 odkazy najednou (jeden selektor .site-nav a)');
assert.ok(Math.abs(navTween.startTime() - headerTween.endTime()) < 0.001, `menu má začít po konci hlavičky (${headerTween.endTime()} s), začíná v ${navTween.startTime()} s`);
intro.pause();
intro.time(navTween.startTime() + 0.1);
const firstOpacity = Number(getComputedStyle(links[0]).opacity);
const lastOpacity = Number(getComputedStyle(links[3]).opacity);
assert.ok(firstOpacity > 0, '0.1 s po začátku menu má být první odkaz už částečně vidět');
assert.equal(lastOpacity, 0, '0.1 s po začátku menu má být čtvrtý odkaz ještě skrytý — odkazy mají začínat postupně přes stagger');
intro.time(navTween.startTime() + 0.15 + 0.02);
assert.ok(Number(getComputedStyle(links[3]).opacity) > 0, 'čtvrtý odkaz má začít 3 × 0.05 = 0.15 s po prvním');
```

Nadpisek `.hero__eyebrow` přijede až po posledním odkazu a na konci je všechno vidět.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const links = [...document.querySelectorAll('.site-nav a')];
const eyebrow = document.querySelector('.hero__eyebrow');
const tweens = intro.getChildren(true, true, false);
const navTween = tweens.find((tween) => tween.targets().includes(links[0]));
const eyebrowTween = tweens.find((tween) => tween.targets().includes(eyebrow));
assert.ok(navTween && eyebrowTween, 'intro má obsahovat tween menu i nadpisku');
assert.ok(Math.abs(eyebrowTween.startTime() - navTween.endTime()) < 0.001, `nadpisek má začít po posledním odkazu (${navTween.endTime().toFixed(2)} s), začíná v ${eyebrowTween.startTime().toFixed(2)} s`);
intro.progress(1);
for (const link of links) {
  assert.equal(getComputedStyle(link).visibility, 'visible', `odkaz „${link.textContent}" má být na konci intra vidět`);
}
```

## --file-- main.js

```js
import gsap from 'gsap';

export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

intro
  .from('.site-header', { autoAlpha: 0, y: -24 })
  .from('.site-nav a', { autoAlpha: 0, y: -12, stagger: 0.05 })
  .from('.hero__eyebrow', { autoAlpha: 0, y: 16 });
```
