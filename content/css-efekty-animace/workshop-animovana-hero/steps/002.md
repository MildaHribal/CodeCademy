# --description--

Teď první animace z JavaScriptu. Hlavička s logem a menu má při načtení sjet shora a zároveň se objevit.

Pro vstup prvku na stránku se hodí `gsap.from`: v objektu napíšeš, **odkud** prvek přijede, a GSAP ho dovede do stavu, který má podle CSS. Průhlednost animuj přes `autoAlpha`, ne přes `opacity` — na nule prvek zároveň skryje přes `visibility`, takže nejde kliknout ani nafokusovat odkaz, který ještě není vidět.

Stejný vzor na jiném prvku:

```js
gsap.from('.cookie-bar', { autoAlpha: 0, y: 40, duration: 0.5 });
```

**Úkol:** V `main.js` pod importem nech `.site-header` přijet z `y: -24` a z `autoAlpha: 0`, s délkou `0.6` sekundy.

# --hints--

Hlavička na začátku animace není vidět a je posunutá nahoru.

```js
const gsap = (await import('gsap')).default;
const header = document.querySelector('.site-header');
const tween = gsap.getTweensOf(header)[0];
assert.ok(tween, 'na .site-header nemíří žádná animace GSAPu — zavolej gsap.from(\'.site-header\', { … })');
tween.progress(0).pause();
assert.equal(getComputedStyle(header).visibility, 'hidden', 'na začátku animace má být hlavička skrytá (autoAlpha: 0 nastaví visibility: hidden)');
assert.ok(gsap.getProperty(header, 'y') < 0, `na začátku má být hlavička posunutá nahoru (záporné y), teď má y = ${gsap.getProperty(header, 'y')}`);
```

Na konci animace je hlavička vidět na svém místě a animace trvá 0,6 s.

```js
const gsap = (await import('gsap')).default;
const header = document.querySelector('.site-header');
const tween = gsap.getTweensOf(header)[0];
assert.ok(tween, 'na .site-header nemíří žádná animace GSAPu');
tween.progress(1);
assert.equal(getComputedStyle(header).opacity, '1', 'na konci animace má mít hlavička opacity 1');
assert.equal(getComputedStyle(header).visibility, 'visible', 'na konci animace má být hlavička viditelná');
assert.equal(gsap.getProperty(header, 'y'), 0, 'na konci animace má být hlavička na svém místě (y = 0)');
assert.equal(tween.duration(), 0.6, 'animace hlavičky má trvat 0.6 s');
```
