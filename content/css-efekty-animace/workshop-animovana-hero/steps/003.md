# --description--

Po hlavičce má přijít drobný nadpisek nad titulkem (`.hero__eyebrow`). Místo dalšího tweenu s ručně spočítaným `delay` založ [[timeline]], která tweeny řadí za sebe sama.

Timeline si pojmenuj `intro` a **vyexportuj** ji (`export const intro = …`). Bude se hodit: celou úvodní animaci tak půjde ovládat jako jeden objekt. Všechny její tweeny budou mít stejnou délku a křivku, a ty patří do `defaults`, ne do každého tweenu zvlášť.

Stejný vzor na jiných prvcích:

```js
export const checkout = gsap.timeline({ defaults: { duration: 0.4, ease: 'power1.out' } });

checkout
  .from('.summary', { autoAlpha: 0, x: 30 })
  .from('.pay-button', { autoAlpha: 0, y: 10 });
```

**Úkol:** V `main.js` nahraď samostatný tween hlavičky timelinou:

1. `export const intro = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });`
2. Do `intro` přidej hlavičku (`autoAlpha: 0`, `y: -24`, bez vlastní délky).
3. Za ni přidej `.hero__eyebrow` z `autoAlpha: 0` a `y: 16`.

# --hints--

`main.js` exportuje timeline `intro`, jejíž tweeny mají výchozí délku 0,5 s a křivku `power2.out`.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro && typeof intro.getChildren === 'function', 'main.js má exportovat intro vytvořenou přes gsap.timeline(…)');
const tweens = intro.getChildren(true, true, false);
assert.ok(tweens.length >= 2, `intro má obsahovat aspoň 2 tweeny, obsahuje ${tweens.length}`);
for (const tween of tweens) {
  assert.equal(tween.duration(), 0.5, `tween na ${tween.targets()[0]?.className} má mít délku 0.5 s z defaults`);
}
assert.equal(intro.vars.defaults?.ease, 'power2.out', 'defaults timeline mají obsahovat ease: \'power2.out\'');
```

Hlavička je v `intro` první a nadpisek `.hero__eyebrow` přijede až po jejím konci.

```js
const { intro } = await helpers.importFile('main.js');
assert.ok(intro, 'main.js má exportovat intro');
const header = document.querySelector('.site-header');
const eyebrow = document.querySelector('.hero__eyebrow');
const tweens = intro.getChildren(true, true, false);
const headerTween = tweens.find((tween) => tween.targets().includes(header));
const eyebrowTween = tweens.find((tween) => tween.targets().includes(eyebrow));
assert.ok(headerTween, 'intro má obsahovat tween hlavičky .site-header');
assert.ok(eyebrowTween, 'intro má obsahovat tween nadpisku .hero__eyebrow');
assert.equal(headerTween.startTime(), 0, 'hlavička má v intro začínat v čase 0');
assert.ok(Math.abs(eyebrowTween.startTime() - headerTween.endTime()) < 0.001, `nadpisek má začít, až hlavička skončí (v ${headerTween.endTime()} s), začíná v ${eyebrowTween.startTime()} s`);
intro.progress(0).pause();
assert.equal(getComputedStyle(eyebrow).visibility, 'hidden', 'na začátku intra má být nadpisek skrytý (autoAlpha: 0)');
intro.progress(1);
assert.equal(getComputedStyle(eyebrow).opacity, '1', 'na konci intra má být nadpisek plně vidět');
const gsap = (await import('gsap')).default;
assert.equal(gsap.getProperty(eyebrow, 'y'), 0, 'na konci intra má být nadpisek na svém místě (y = 0)');
```

Na hlavičku nemíří žádný další tween mimo `intro`.

```js
const gsap = (await import('gsap')).default;
const { intro } = await helpers.importFile('main.js');
const header = document.querySelector('.site-header');
const outside = gsap.getTweensOf(header).filter((tween) => tween.parent !== intro);
assert.equal(outside.length, 0, 'samostatný gsap.from na .site-header z minulého kroku má zmizet — hlavička patří jen do intro');
```
