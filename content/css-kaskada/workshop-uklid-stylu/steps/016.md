# --description--

Poslední zbytek kolegova boje se šablonou jsou dvě pravidla ve `styles.css`, která mají v selektoru id: velký nadpis úvodu a nadpis sekce Pokoje. Dnes nevadí, ale kdo bude chtít nadpisy jednou upravit pravidlem s třídou, prohraje stejně, jako jsi prohrával se šablonou na začátku.

**Úkol:** ve `styles.css` nesmí být žádný selektor s id. Nadpisy si přitom zachovají vzhled, který mají teď (velikost, proložení, okraje).

# --hints--

Žádné pravidlo ve `styles.css` nemá v selektoru id.

```js
const sheet = [...document.styleSheets].find((s) => helpers.cssRules('.hero__eyebrow').some((rule) => rule.parentStyleSheet === s));
assert.ok(sheet, 'Nenašel jsem styly ze styles.css (pravidlo .hero__eyebrow)');
const withId = [];
const visit = (rules) => {
  for (const rule of rules) {
    if (rule.selectorText?.includes('#')) withId.push(rule.selectorText);
    if (rule.cssRules) visit(rule.cssRules);
  }
};
visit(sheet.cssRules);
assert.deepEqual(withId, [], `Selektory s id ve styles.css: ${withId.join(', ')}`);
```

Nadpisy si zachovaly vzhled: nadpis úvodu je velký kolem 51 px s proložením −0,02em, nadpis sekce má 28 px a pod sebou okraj 24 px.

```js
const hero = getComputedStyle(document.querySelector('.hero__title'));
assert.ok(Math.abs(parseFloat(hero.fontSize) - 51.2) < 1, `Nadpis úvodu má font-size ${hero.fontSize}, čekám clamp(2rem, 5vw, 3.25rem) = 51.2px`);
assert.ok(Math.abs(parseFloat(hero.letterSpacing) + 0.02 * parseFloat(hero.fontSize)) < 0.1, `Nadpis úvodu má letter-spacing ${hero.letterSpacing}, čekám -0.02em`);
const section = getComputedStyle(document.querySelector('.section-title'));
assert.equal(section.fontSize, '28px', 'Nadpis sekce .section-title má mít font-size 1.75rem (28px)');
assert.equal(section.marginBottom, '24px', 'Nadpis sekce .section-title má mít margin-bottom 1.5rem (24px)');
```

Nadpisy jde upravit pravidlem s jednou třídou na konci vrstvy komponent.

```js
const probe = document.createElement('style');
probe.textContent = '@layer components { .hero__title, .section-title { color: rgb(1, 2, 3); } }';
document.head.append(probe);
for (const selector of ['.hero__title', '.section-title']) {
  assert.equal(getComputedStyle(document.querySelector(selector)).color, 'rgb(1, 2, 3)', `Pravidlo ${selector} na konci vrstvy components se neprojevilo — některý selektor pro nadpis je silnější než jedna třída`);
}
```

# --help--

## --tip--

Id ve sloupci A přebije libovolný počet tříd, viz [Specificita: trojice (A, B, C)](see:css-kaskada/kaskada#specificita-trojice-a-b-c).

## --tip--

Oba nadpisy mají v HTML vlastní třídu, takže id z jejich selektorů můžeš prostě vynechat. Šablona je ve vrstvě a nepřebije je.

## --tip--

Pravidlo pro odkaz v patičce by šlo zjednodušit stejně: z řetězce s id patičky zbude jen třída odkazu.
