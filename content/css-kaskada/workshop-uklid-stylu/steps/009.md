# --description--

## Hlášení

Majitel volal, že termín 12.–14. prosince v pokoji Sněžka je obsazený. Kolega proto přidal do vrstvy `utilities` utilitu `.u-hidden` (skryje prvek) a dal ji štítku „Poslední volný termín" v první kartě. Napsal: „Hotovo, štítek je skrytý."

Není. Štítek je v náhledu pořád vidět. Kolega zkusil v DevTools, že `.u-hidden` se na štítek použije, ale deklarace `display: none` je přeškrtnutá.

## Úkol

Zjisti, proč utilita ve vrstvě `utilities` prohrává, a oprav to v `styles.css` tak, aby utility vyhrávaly nad všemi komponentami, ne jen nad štítkem. Utilitám nepřidávej `!important`. Změň co nejmenší kus kódu.

# --hints--

Štítek „Poslední volný termín" v první kartě je skrytý.

```js
const note = document.querySelector('.room__note.u-hidden');
assert.ok(note, 'Štítek .room__note s třídou u-hidden v HTML chybí — HTML neměň');
assert.equal(getComputedStyle(note).display, 'none', 'Štítek s u-hidden má mít display: none');
```

Štítek „Vyprodáno do března" ve třetí kartě je dál vidět.

```js
const note = [...document.querySelectorAll('.room__note')].find((el) => el.textContent.includes('Vyprodáno'));
assert.notEqual(getComputedStyle(note).display, 'none', 'Štítek „Vyprodáno do března" nemá u-hidden a má zůstat vidět');
```

Utilita ve vrstvě `utilities` přebije kteroukoli komponentu, i bez `!important`.

```js
const probe = document.createElement('style');
probe.textContent = '@layer utilities { .room__title, .room__price, .btn--primary { outline: 3px solid rgb(1, 2, 3); color: rgb(1, 2, 3); } }';
document.head.append(probe);
for (const selector of ['.room__title', '.room__price', '.btn--primary']) {
  assert.equal(getComputedStyle(document.querySelector(selector)).color, 'rgb(1, 2, 3)', `Barva z @layer utilities se na ${selector} neprojevila — komponenta ${selector} je silnější než vrstva utilities`);
}
assert.equal(helpers.cssRules('.u-hidden').at(-1)?.style.getPropertyPriority('display'), '', '.u-hidden nemá mít !important');
```

Komponenty dál přebíjejí šablonu: tlačítka jsou oranžová a úvod vycentrovaný.

```js
assert.equal(getComputedStyle(document.querySelector('.site-header .btn')).backgroundColor, 'rgb(245, 158, 11)', 'Tlačítko v hlavičce má mít dál pozadí tokenu --color-sun');
assert.equal(getComputedStyle(document.querySelector('.hero')).textAlign, 'center', 'Úvod má být dál vycentrovaný');
```

# --help--

## --tip--

Podívej se, kde leží pravidlo, které vyhrálo. Jak dopadne souboj stylu mimo vrstvy s vrstvou, popisuje past [Prodlužování selektoru proti vrstvě](see:css-kaskada/kaskada#typicke-chyby-a-pasti).

## --tip--

Pravidla komponent (od komentáře Hlavička až po patičku) nejsou v žádné vrstvě, a proto přebijí všechny vrstvy včetně utilit. Potřebují vlastní vrstvu, která bude mezi šablonou a utilitami.

## --tip--

Stejně bys do vrstvy `layout` vložil pravidla rozvržení: nad první z nich otevření bloku se jménem vrstvy, pod poslední zavírací závorka. Blok utilit musí zůstat až pod ním.

# --explain--

Vysvětli vlastními slovy, proč utilita ve vrstvě `utilities` prohrála s pravidlem `.room__note`, a proč by nepomohlo zesílit její selektor.

## --model--

Pravidla komponent nebyla v žádné vrstvě a styly mimo vrstvy se chovají jako poslední, nejsilnější vrstva. Kaskáda porovnává vrstvy dřív než specificitu, takže `.room__note` vyhrál už na vrstvách a silnější selektor utility by nic nezměnil. Když komponenty dám do vrstvy `components` před `utilities`, vyhraje utilita díky pozdější vrstvě.

## --checklist--

- Styl mimo vrstvy přebije běžné deklarace ve všech vrstvách.
- Vrstvy se porovnávají dřív než specificita.
- Silnější selektor utility by souboj s nevrstveným stylem nevyhrál.
- Komponenty patří do vrstvy před utilitami.
