# --description--

Máš za sebou většinu úklidu — šablona je ve vrstvě a nic nového už nepřebije. Než se pustíš do posledních oprav, zkus stránku projít klávesou Tab. Fokus na odkazech a tlačítkách skoro není vidět: šablona ho kdysi vypnula a výchozí obrys prohlížeče na tmavé hlavičce zaniká. Pro lidi, kteří web ovládají klávesnicí, je to jako myš bez kurzoru.

Tenhle krok je bez návodu, zvládneš ho z lekce [Selektory](see:css-zaklady/selektory-zaklad).

**Úkol:** když se na tlačítko `.btn` nebo odkaz v navigaci `.nav__link` dostane fokus z klávesnice, má obrys (`outline`) 3 px, plnou čarou, v barvě tokenu `--color-sun`, odsazený od prvku o 3 px. Při kliknutí myší se obrys ukazovat nemusí. Pravidlo patří mezi komponenty.

# --hints--

Tlačítko v hlavičce má při fokusu obrys 3 px plnou čarou v barvě `--color-sun`, odsazený o 3 px.

```js
const button = document.querySelector('.site-header .btn');
button.focus();
const style = getComputedStyle(button);
assert.equal(style.outlineStyle, 'solid', 'Tlačítko s fokusem má mít outline-style solid');
assert.equal(style.outlineWidth, '3px', 'Tlačítko s fokusem má mít outline-width 3px');
assert.equal(style.outlineColor, 'rgb(245, 158, 11)', 'Tlačítko s fokusem má mít obrys v barvě tokenu --color-sun');
assert.equal(style.outlineOffset, '3px', 'Tlačítko s fokusem má mít outline-offset 3px');
```

Odkaz v navigaci má při fokusu stejný obrys.

```js
const link = document.querySelector('.nav__link');
link.focus();
const style = getComputedStyle(link);
assert.equal(`${style.outlineStyle} ${style.outlineWidth} ${style.outlineColor} ${style.outlineOffset}`, 'solid 3px rgb(245, 158, 11) 3px', 'Odkaz .nav__link s fokusem má mít obrys solid 3px --color-sun s odsazením 3px');
```

Obrys se ukazuje jen pro fokus z klávesnice (pseudotřída `:focus-visible`).

```js
const sheet = [...document.styleSheets].find((s) => helpers.cssRules('.hero__eyebrow').some((rule) => rule.parentStyleSheet === s));
const outlineSelectors = [];
const visit = (rules, parent = '') => {
  for (const rule of rules) {
    const selector = rule.selectorText ? rule.selectorText.replaceAll('&', parent ? `:is(${parent})` : '') : parent;
    if (rule.selectorText && ['outline', 'outline-style', 'outline-width', 'outline-color'].some((property) => rule.style.getPropertyValue(property))) outlineSelectors.push(selector);
    if (rule.cssRules) visit(rule.cssRules, selector);
  }
};
visit(sheet.cssRules);
const focusOnly = outlineSelectors.filter((selector) => /:focus(?![-\w])/.test(selector));
assert.deepEqual(focusOnly, [], `Obrys je v pravidle s :focus, které platí i po kliknutí myší: ${focusOnly.join(', ')}`);
for (const target of ['.site-header .btn', '.nav__link']) {
  const el = document.querySelector(target);
  const covered = outlineSelectors.some((selector) => {
    if (!selector.includes(':focus-visible')) return false;
    try { return el.matches(selector.replaceAll(':focus-visible', ':is(*)')); } catch { return false; }
  });
  assert.ok(covered, `Prvek ${target} nemá ve styles.css pravidlo s :focus-visible, které nastavuje obrys`);
}
```

Tlačítko bez fokusu obrys nemá.

```js
const style = getComputedStyle(document.querySelector('.room .btn'));
assert.notEqual(style.outlineStyle, 'solid', 'Tlačítko v kartě bez fokusu nemá mít obrys — obrys patří jen do :focus-visible');
```

# --help--

## --tip--

Pseudotřída pro fokus z klávesnice je v základních selektorech. Obrys kolem prvku bez vlivu na rozměry dělá vlastnost `outline`.

## --tip--

Jedno pravidlo se dvěma selektory oddělenými čárkou, uvnitř vrstvy `components`. Odsazení obrysu má vlastní vlastnost.

## --tip--

Pole formuláře by to měla stejně: selektor `.field:focus-visible`, obrys 2 px čárkovaně v barvě tokenu `--color-accent`.
