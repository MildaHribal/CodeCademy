# --description--

Odkazy v navigaci mají být bílé a bez podtržení. Pravidlo `.nav__link` v `styles.css` to říká, soubor se teď načítá až po šabloně, a odkazy jsou pořád šedé a podtržené.

V `sablona.css` najdi pravidlo, které odkazy stylují:

```css
#header #nav ul li a { … }
```

Jeho [[specificita]] je (2, 0, 3): dvě id a tři typy prvků. Tvoje `.nav__link` má (0, 1, 0). Sloupec A rozhodne hned, takže na pořadí souborů se vůbec nedojde.

Máš dvě možnosti. Zesílit vlastní selektor na něco jako `#header #nav .nav__link` by fungovalo — a každá další úprava odkazů by musela mít dvě id taky. Lepší je **snížit specificitu šablony**, aby ji přebilo obyčejné pravidlo s jednou třídou. Stejný zásah u jiného prvku by vypadal takhle:

```css
/* šablona předtím */
#footer #social ul li a { color: gray; }

/* šablona potom */
.social__link { color: gray; }
```

**Úkol:** v `sablona.css` přepiš selektor pravidla `#header #nav ul li a` na jedinou třídu odkazů v navigaci. Deklarace uvnitř nech, jak jsou.

# --hints--

Odkazy v navigaci jsou bílé (token `--color-snow`) a bez podtržení.

```js
const style = getComputedStyle(document.querySelector('.nav__link'));
assert.equal(style.color, 'rgb(248, 250, 252)', 'Odkaz v navigaci má mít barvu tokenu --color-snow z styles.css');
assert.equal(style.textDecorationLine, 'none', 'Odkaz v navigaci nemá být podtržený');
```

Styl odkazů v navigaci jde přepsat pravidlem s jednou třídou napsaným na konec stylů — šablona ani `styles.css` nepoužívají silnější selektor nebo `!important`.

```js
const probe = document.createElement('style');
probe.textContent = '.nav__link { color: rgb(1, 2, 3); }';
document.head.append(probe);
const color = getComputedStyle(document.querySelector('.nav__link')).color;
assert.equal(color, 'rgb(1, 2, 3)', 'Pravidlo .nav__link { color: … } připsané na konec stylů se neprojevilo — některé pravidlo pro odkazy v navigaci je silnější než jedna třída');
```

# --explain--

Vysvětli vlastními slovy, proč pravidlo `.nav__link` v `styles.css` prohrávalo, přestože se soubor načítal až po šabloně, a proč je lepší snížit specificitu šablony než zvýšit vlastní.

## --model--

Specificita se v kaskádě porovnává dřív než pořadí ve zdroji. `#header #nav ul li a` má dvě id, takže vyhrál ve sloupci A a pořadí souborů už nerozhodovalo. Kdybych zesílil vlastní selektor, musela by každá další úprava odkazů taky obsahovat dvě id. Po snížení šablony na jednu třídu stačí obyčejné pravidlo s jednou třídou napsané později.

## --checklist--

- Specificita rozhoduje dřív než pořadí ve zdroji.
- Id ve sloupci A přebije libovolný počet tříd.
- Zesílený selektor nutí zesilovat i všechny další úpravy.
- Po snížení specificity rozhoduje čitelné pořadí souborů.
