# --description--

V HTML úvodu jsou už od začátku připravené pomocné třídy: sekce `.hero` má třídu `u-center` a odstavec pod nadpisem `u-muted`. Takovým malým třídám s jedním úkolem se říká [[utility třída|utility třídy]] (*utility classes*). Mají vyhrát nad styly komponent, proto patří do vlastní vrstvy `utilities`, která bude poslední.

**Úkol:** seřaď řádky do bloku vrstvy `utilities` se dvěma utilitami:

- `.u-center` zarovná text na střed,
- `.u-muted` dá textu barvu z tokenu `--color-muted`.

Blok přijde na konec `styles.css`. Pořadí měníš šipkami nahoru a dolů, odsazení klávesou Tab. Dva řádky jsou navíc — utilita ve vrstvě, která je později než všechno ostatní, žádnou pomoc navíc nepotřebuje.

Po kontrole se úvod vycentruje a text pod nadpisem zešedne. Nadpisek a nadpis se vycentrují taky, přestože utilitu nemají: zarovnání textu se dědí z rodiče. K dědičnosti se dostaneš v lekci [Dědičnost a výchozí hodnoty](see:css-kaskada/dedicnost).

# --hints--

Úvod `.hero` má text zarovnaný na střed.

```js
assert.equal(getComputedStyle(document.querySelector('.hero')).textAlign, 'center', 'getComputedStyle(.hero).textAlign má být center (třída u-center)');
```

Odstavec `.hero__text` má barvu tokenu `--color-muted`.

```js
assert.equal(getComputedStyle(document.querySelector('.hero__text')).color, 'rgb(100, 116, 139)', 'getComputedStyle(.hero__text).color má být barva tokenu --color-muted (třída u-muted)');
```

Utility jsou ve vrstvě `utilities` a nemají `!important`.

```js
for (const [selector, property] of [['.u-center', 'text-align'], ['.u-muted', 'color']]) {
  const rule = helpers.cssRules(selector).at(-1);
  assert.ok(rule, `Pravidlo ${selector} chybí`);
  assert.ok(rule.parentRule instanceof CSSLayerBlockRule && rule.parentRule.name === 'utilities', `Pravidlo ${selector} má být uvnitř @layer utilities`);
  assert.equal(rule.style.getPropertyPriority(property), '', `${property} v ${selector} nemá mít !important`);
}
```

# --parsons--

```css
@layer utilities {
  .u-center {
    text-align: center;
  }
  .u-muted {
    color: var(--color-muted);
  }
}
```

## --distractors--

```css
text-align: center !important;
color: var(--color-muted) !important;
```
