# --description--

Každá karta má štítek se stavem serveru, třeba `<span class="badge" data-status="online">Online</span>`. Stav je v atributu `data-status`, protože ho do HTML zapisuje systém, který servery hlídá — a atribut se na rozdíl od třídy nedá splést s jinou komponentou.

Pravidlo `.badge` už v `styles.css` je. Barvu pozadí a textu ale nebere napřímo, nýbrž z **vlastních vlastností komponenty** s výchozí hodnotou:

```css
background: var(--badge-bg, var(--color-surface-2));
```

Varianta proto nemusí přepisovat `background` ani `color`. Stačí, když nastaví `--badge-bg` a `--badge-fg`, a základní pravidlo se postará o zbytek. Stejný vzor u upozornění s typem v atributu:

```css
.alert[data-type="warning"] {
  --alert-bg: #fef3c7;
  --alert-fg: #92400e;
}
```

**Úkol:** pod pravidlo `.badge` napiš pravidlo pro štítek s `data-status="online"`, které nastaví:

- `--badge-bg: rgb(74 222 128 / 0.15)` (průhledná zelená),
- `--badge-fg: var(--color-success)`.

# --hints--

Štítek s `data-status="online"` má průhledně zelené pozadí a zelený text.

```js
const style = getComputedStyle(document.querySelector('.badge[data-status="online"]'));
assert.equal(style.backgroundColor, 'rgba(74, 222, 128, 0.15)', 'Štítek online má mít pozadí rgb(74 222 128 / 0.15)');
assert.equal(style.color, 'rgb(74, 222, 128)', 'Štítek online má mít text v barvě tokenu --color-success');
```

Štítky s jiným stavem zůstaly ve výchozích barvách.

```js
const style = getComputedStyle(document.querySelector('.badge[data-status="full"]'));
assert.equal(style.backgroundColor, 'rgb(31, 41, 55)', 'Štítek full má mít zatím výchozí pozadí --color-surface-2');
```

Varianta nastavuje vlastní vlastnosti komponenty, ne `background` a `color` napřímo.

```js
const rule = helpers.cssRules('.badge[data-status="online"]').at(-1);
assert.ok(rule, 'Pravidlo .badge[data-status="online"] chybí');
assert.ok(rule.style.getPropertyValue('--badge-bg').trim(), 'Pravidlo .badge[data-status="online"] má nastavit --badge-bg');
assert.ok(rule.style.getPropertyValue('--badge-fg').trim(), 'Pravidlo .badge[data-status="online"] má nastavit --badge-fg');
```
