# --description--

Z workshopu s horskou chatou víš, jak styly chránit před budoucími střety. Tenhle krok je bez návodu.

**Úkol:** rozděl `styles.css` do dvou vrstev:

- `base` — tokeny na `:root`, pravidlo pro `box-sizing` a `body`,
- `components` — všechno ostatní, od hlavičky stránky až po oblíbené.

Pořadí vrstev napiš na jeden řádek na začátek souboru. Náhled se nezmění — mění se jen to, **proč** pravidla vyhrávají: kdo sem jednou přidá vrstvu utilit, nebude muset nic přebíjet.

# --hints--

Ve `styles.css` není žádné pravidlo mimo vrstvy.

```js
const sheet = [...document.styleSheets].find((s) => helpers.cssRules('.server-card__name').some((rule) => rule.parentStyleSheet === s));
for (const rule of sheet.cssRules) {
  const layered = rule instanceof CSSLayerBlockRule || rule instanceof CSSLayerStatementRule;
  assert.ok(layered, `Ve styles.css je pravidlo mimo vrstvy: ${rule.cssText.split('{')[0].trim()}`);
}
```

Tokeny a `body` jsou ve vrstvě `base`, komponenty ve vrstvě `components`.

```js
const layerOf = (selector) => {
  let rule = helpers.cssRules(selector)[0];
  while (rule && !(rule instanceof CSSLayerBlockRule)) rule = rule.parentRule;
  return rule?.name;
};
assert.equal(layerOf(':root'), 'base', 'Pravidlo :root má být ve vrstvě base');
assert.equal(layerOf('body'), 'base', 'Pravidlo body má být ve vrstvě base');
for (const selector of ['.page-header', '.server-card', '.badge', '.btn', '.favorite']) {
  assert.equal(layerOf(selector), 'components', `Pravidlo ${selector} má být ve vrstvě components`);
}
```

Vrstva `components` je za `base` a vzhled se nezměnil.

```js
const probe = document.createElement('style');
probe.textContent = '@layer base { .btn { color: rgb(1, 2, 3); } }';
document.head.append(probe);
assert.notEqual(getComputedStyle(document.querySelector('.btn[data-variant="secondary"]')).color, 'rgb(1, 2, 3)', 'Pravidlo z vrstvy base přebilo komponentu — base má být v pořadí před components');
assert.equal(getComputedStyle(document.querySelector('#top-server .btn[data-variant="primary"]')).backgroundColor, 'rgb(34, 211, 238)', 'Tlačítko primary má mít dál tyrkysové pozadí');
assert.equal(getComputedStyle(document.querySelector('.badge[data-status="online"]')).color, 'rgb(74, 222, 128)', 'Štítek online má mít dál zelený text');
```

# --help--

## --tip--

Postup je stejný jako v posledním kroku [úklidu stylů horské chaty](see:css-kaskada/workshop-uklid-stylu/018) a v části [Vrstvy @layer](see:css-kaskada/kaskada#vrstvy-layer).

## --tip--

Hranice mezi vrstvami je komentář „Hlavička stránky": všechno nad ním patří do `base`, všechno od něj dolů do `components`.

## --tip--

Kostra souboru: 1. řádek s pořadím vrstev, 2. blok první vrstvy s tokeny a základem, 3. blok druhé vrstvy s komponentami.
