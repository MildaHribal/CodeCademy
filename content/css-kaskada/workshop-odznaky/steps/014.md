# --description--

Server Hardcore Tatry je offline. Hráč by si toho měl všimnout dřív, než dočte kartu až ke štítku.

**Úkol:** karta, ve které je štítek se stavem `offline`, je poloprůhledná (`0.6`) a černobílá (`filter: grayscale(1)`). Jakmile systém změní stav serveru v HTML, karta se sama vrátí do barev. Ostatní karty se nezmění.

# --hints--

Karta se štítkem offline má poloprůhlednost 0.6 a filtr `grayscale(1)`.

```js
const style = document.createElement('style');
style.textContent = '* { transition: none !important; }';
document.head.append(style);
const card = document.querySelector('.badge[data-status="offline"]').closest('.server-card');
const computed = getComputedStyle(card);
assert.equal(computed.opacity, '0.6', 'Karta offline serveru má mít opacity 0.6');
assert.equal(computed.filter, 'grayscale(1)', 'Karta offline serveru má mít filter: grayscale(1)');
```

Ostatní karty jsou neprůhledné a barevné.

```js
const style = document.createElement('style');
style.textContent = '* { transition: none !important; }';
document.head.append(style);
document.querySelectorAll('.server-card').forEach((card) => {
  if (card.querySelector('[data-status="offline"]')) return;
  const computed = getComputedStyle(card);
  assert.equal(`${computed.opacity} ${computed.filter}`, '1 none', `Karta ${card.querySelector('.server-card__name').textContent} nemá být ztlumená`);
});
```

Když se stav serveru změní na online, karta se vrátí do barev.

```js
const style = document.createElement('style');
style.textContent = '* { transition: none !important; }';
document.head.append(style);
const badge = document.querySelector('.badge[data-status="offline"]');
badge.dataset.status = 'online';
const computed = getComputedStyle(badge.closest('.server-card'));
assert.equal(`${computed.opacity} ${computed.filter}`, '1 none', 'Po změně data-status na online nemá být karta ztlumená — řídí se vzhled stavem štítku?');
```

# --help--

## --tip--

Kartu vybíráš podle štítku, který obsahuje. Stejný nástroj jako u oblíbeného serveru, viz [:has()](see:css-kaskada/moderni-selektory#has-styl-rodice-podle-obsahu).

## --tip--

Uvnitř `:has()` stačí atributový selektor s hodnotou stavu. Pravidlo patří ke kartě.

## --tip--

Objednávka, ve které je položka se stavem „vyprodáno", by se ztlumila stejně: rodič, `:has()` a atribut stavu s hodnotou.
