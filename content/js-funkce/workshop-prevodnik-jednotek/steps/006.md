# --description--

Uživatel potřebuje vidět číslo i jednotku: `42,2 km`, `176,7 °C`.

**Úkol:** Napiš funkci `formatResult(value, unit, decimals = 1)`, která vrátí číslo naformátované funkcí `formatNumber` na `decimals` míst, mezeru a jednotku. `formatResult(42.1648128, 'km')` vrátí `'42,2 km'`.

Parametr `decimals` si funkce nenechá pro sebe, jen ho **předá dál** do `formatNumber`. Argumenty se k parametrům přiřazují podle pořadí, ne podle jména. Na jiných datech:

```js
function priceLabel(amount, currency, decimals = 0) {
  return `${formatNumber(amount, decimals)} ${currency}`;
}
```

# --hints--

`formatResult(42.1648128, 'km')` vrátí `'42,2 km'`.

```js
assert.equal(formatResult(42.1648128, 'km'), '42,2 km', "formatResult(42.1648128, 'km') má vrátit '42,2 km' — výchozí je 1 desetinné místo");
```

`formatResult(2.26796185, 'kg', 2)` vrátí `'2,27 kg'` a `formatResult(176.666, '°C', 0)` vrátí `'177 °C'`.

```js
assert.equal(formatResult(2.26796185, 'kg', 2), '2,27 kg', "formatResult(2.26796185, 'kg', 2) má vrátit '2,27 kg'");
assert.equal(formatResult(176.666, '°C', 0), '177 °C', "formatResult(176.666, '°C', 0) má vrátit '177 °C'");
```

// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.

function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;

function kgToPounds(kg) {
  return kg / KG_PER_POUND;

function roundTo(value, decimals) {
