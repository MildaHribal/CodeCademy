# --description--

Maraton v USA je 26,2 mile. Kolik je to kilometrů?

**Úkol:** Pod `roundTo` napiš deklaraci funkce `milesToKm(miles)`, která vrátí počet kilometrů: míle vynásobené konstantou `KM_PER_MILE`. Nezaokrouhluj — zaokrouhlování přijde na řadu až při zobrazení.

Deklarace má klíčové slovo `function`, jméno, parametry v závorkách a tělo s `return`. Na jiných datech:

```js
function hoursToMinutes(hours) {
  return hours * 60;
}
```

Každou novou funkci si pod ní vyzkoušej výpisem, třeba `console.log(milesToKm(26.2))`, ať vidíš výsledek v konzoli. Testy výpisy nekontrolují, ty jsou pro tebe.

# --hints--

`milesToKm(26.2)` vrátí `42.1648128`.

```js
assert.ok(Math.abs(milesToKm(26.2) - 42.1648128) < 1e-9, 'milesToKm(26.2) má vrátit 42.1648128 (26.2 × 1.609344)');
```

`milesToKm(1)` vrátí přesně `KM_PER_MILE` a `milesToKm(0)` vrátí `0`.

```js
assert.equal(milesToKm(1), 1.609344, 'milesToKm(1) má vrátit 1.609344');
assert.equal(milesToKm(0), 0, 'milesToKm(0) má vrátit 0');
```

`milesToKm` je deklarace funkce (`function milesToKm`).

```js
const source = helpers.stripComments(files['script.js'], 'js');
assert.match(source, /function\s+milesToKm\s*\(/, 'v script.js má být deklarace function milesToKm(…)');
```

## --file-- script.js

```js
// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

function kgToPounds(kg) {
  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

console.log(roundTo(poundsToKg(5), 2));

function milesToKm(miles) {
  return miles * KM_PER_MILE;
}

console.log(milesToKm(26.2));
```
