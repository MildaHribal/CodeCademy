# --description--

Stránka převodníku bude mít výběr převodu s hodnotami jako `'mi-km'` nebo `'f-c'`. Potřebuješ jednu funkci, která podle téhle hodnoty zavolá správnou převodní funkci.

**Úkol:** Napiš funkci `convert(value, conversion)`, která vrátí převedenou hodnotu (nezaokrouhlenou) pro tyto převody:

| `conversion` | převod | funkce |
|---|---|---|
| `'mi-km'` | míle na kilometry | `milesToKm` |
| `'km-mi'` | kilometry na míle | `kmToMiles` |
| `'lb-kg'` | libry na kilogramy | `poundsToKg` |
| `'kg-lb'` | kilogramy na libry | `kgToPounds` |
| `'f-c'` | °F na °C | `fahrenheitToCelsius` |
| `'c-f'` | °C na °F | `celsiusToFahrenheit` |

Pro neznámý převod vrátí `null` — ne `undefined`, aby bylo jasné, že funkce na tenhle případ myslí.

Na rozhodnutí podle hodnoty se hodí řada `if`, z nichž každý hned vrací, nebo `switch`, kde `return` v každé větvi nahradí `break`. Vyber si.

# --hints--

`convert` převede míle a kilometry oběma směry.

```js
assert.ok(Math.abs(convert(26.2, 'mi-km') - 42.1648128) < 1e-9, "convert(26.2, 'mi-km') má vrátit 42.1648128");
assert.ok(Math.abs(convert(42.195, 'km-mi') - 42.195 / 1.609344) < 1e-9, "convert(42.195, 'km-mi') má vrátit asi 26.219");
```

`convert` převede libry a kilogramy oběma směry.

```js
assert.ok(Math.abs(convert(5, 'lb-kg') - 2.26796185) < 1e-9, "convert(5, 'lb-kg') má vrátit 2.26796185");
assert.ok(Math.abs(convert(1, 'kg-lb') - 1 / 0.45359237) < 1e-9, "convert(1, 'kg-lb') má vrátit asi 2.2046");
```

`convert` převede teploty oběma směry.

```js
assert.equal(convert(212, 'f-c'), 100, "convert(212, 'f-c') má vrátit 100");
assert.equal(convert(100, 'c-f'), 212, "convert(100, 'c-f') má vrátit 212");
```

`convert` vrátí `null` pro neznámý převod.

```js
assert.equal(convert(5, 'yd-m'), null, "convert(5, 'yd-m') má vrátit null — takový převod převodník nezná");
assert.equal(convert(5, ''), null, "convert(5, '') má vrátit null");
```

# --help--

## --tip--

Víc `return` v jedné funkci popisuje část [Předčasný `return` (guard clause)](see:js-funkce/funkce#predcasny-return-guard-clause): funkce skončí na prvním, na který narazí.

## --tip--

Pro každý převod jedna podmínka, která porovná `conversion` s textem a vrátí výsledek odpovídající funkce. Úplně na konci funkce, za všemi podmínkami, vrať `null`.

## --tip--

Stavba na podcíle, kód k nim napíšeš sám:

```js
// 1. pro každý známý převod: když se conversion shoduje, vrať výsledek jeho funkce
// 2. za všemi podmínkami: žádná neplatila, vrať null
```

// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

function milesToKm(miles) {
  return miles * KM_PER_MILE;
}

console.log(milesToKm(26.2));

const kmToMiles = (km) => km / KM_PER_MILE;

console.log(kmToMiles(42.195));

function formatNumber(value, decimals = 2) {
  return String(roundTo(value, decimals)).replace('.', ',');
}

console.log(formatNumber(milesToKm(26.2)));
console.log(formatNumber(milesToKm(26.2), 0));

  return `${formatNumber(value, decimals)} ${unit}`;
}

function convert(value, conversion) {
  if (conversion === 'mi-km') {
    return milesToKm(value);

  if (conversion === 'km-mi') {
    return kmToMiles(value);

  if (conversion === 'lb-kg') {
    return poundsToKg(value);

    return kgToPounds(value);

    return fahrenheitToCelsius(value);
