# --description--

## Hlášení

Kolega na konec souboru přidal převody teplot pro recepty z USA. Americký recept na brownies říká „pečte na 350 °F". Převodník ukáže `NaN °C` — v konzoli to vidíš na posledním řádku. Žádná chybová hláška.

Převod opačným směrem, `celsiusToFahrenheit`, funguje.

## Úkol

Oprav kolegův kód tak, aby `fahrenheitToCelsius(350)` vrátila přibližně `176.67`. Změň co nejmenší kus kódu.

# --hints--

`fahrenheitToCelsius(350)` vrátí přibližně `176.67`.

```js
assert.ok(Math.abs(fahrenheitToCelsius(350) - 176.6666666) < 0.001, 'fahrenheitToCelsius(350) má vrátit asi 176.67, ne NaN');
```

`fahrenheitToCelsius(212)` vrátí `100` a `fahrenheitToCelsius(32)` vrátí `0`.

```js
assert.equal(fahrenheitToCelsius(212), 100, 'fahrenheitToCelsius(212) má vrátit 100 — voda se vaří');
assert.equal(fahrenheitToCelsius(32), 0, 'fahrenheitToCelsius(32) má vrátit 0 — voda mrzne');
```

`degreesAboveFreezing(50)` vrátí `18`.

```js
assert.equal(degreesAboveFreezing(50), 18, 'degreesAboveFreezing(50) má vrátit 18 (50 − 32)');
```

`celsiusToFahrenheit(100)` dál vrací `212`.

```js
assert.equal(celsiusToFahrenheit(100), 212, 'celsiusToFahrenheit(100) má dál vracet 212');
```

# --help--

## --tip--

`NaN` z výpočtu, který vypadá správně, typicky znamená, že některá funkce vrací `undefined` — viz past [Chybějící `return`](see:js-funkce/funkce#chybejici-return).

## --tip--

Vypiš si mezivýsledky: co vrací `degreesAboveFreezing(350)` a co pak vznikne z `undefined * 5 / 9`?

## --tip--

Stejná chyba na jiných datech: `function double(n) { n * 2; }` vrací `undefined`, protože výsledek výrazu nikam neposílá.

# --explain--

Vysvětli vlastními slovy, proč chyba v pomocné funkci `degreesAboveFreezing` skončila `NaN` až ve funkci `fahrenheitToCelsius`, a to bez chybové hlášky.

## --model--

`degreesAboveFreezing` výraz `fahrenheit - 32` spočítala, ale bez `return` ho zahodila, a funkce bez `return` vrací `undefined`. `fahrenheitToCelsius` pak s touhle hodnotou počítala dál: `undefined * 5 / 9` je `NaN`. JavaScript při počítání s `undefined` nespadne, jen vyrobí `NaN`, a proto se chyba ukázala až o funkci dál a bez hlášky. Hledat se proto musí od místa, kde se `NaN` objevilo, zpátky k funkci, která nic nevrací.

## --checklist--

- Funkce bez `return` vrací `undefined`.
- Počítání s `undefined` dá `NaN`, ne chybu.
- Chyba se proto projeví až ve funkci, která výsledek použije.
- Hledám zpětně od místa, kde se `NaN` objevilo, k funkci bez `return`.

// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

function kgToPounds(kg) {
  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

console.log(roundTo(poundsToKg(5), 2));

function milesToKm(miles) {
  return miles * KM_PER_MILE;
}

console.log(milesToKm(26.2));

const kmToMiles = (km) => km / KM_PER_MILE;

console.log(kmToMiles(42.195));

function formatNumber(value, decimals = 2) {
  return String(roundTo(value, decimals)).replace('.', ',');
}

console.log(formatNumber(milesToKm(26.2)));
console.log(formatNumber(milesToKm(26.2), 0));

function formatResult(value, unit, decimals = 1) {
  return `${formatNumber(value, decimals)} ${unit}`;
}

console.log(formatResult(milesToKm(26.2), 'km'));

// Teploty poslal kolega: recepty z USA uvádějí teplotu trouby ve °F.

function fahrenheitToCelsius(fahrenheit) {
