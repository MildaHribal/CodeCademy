# --description--

Náš kód obsahuje skrytou chybu, kterou `console.log` nenajde tak snadno. Pro tento krok **vyžadujeme**, abys použil DevTools v prohlížeči.

1. Otevři Vývojářské nástroje (F12).
2. Přejdi do záložky `Sources`, najdi kód a klikni na číslo řádku pro vložení breakpointu.
3. Zjisti hodnotu `mezivysledek` těsně před returnem.

Až to zjistíš, uprav kód tak, aby funkce vracela přímo tento `mezivysledek`.

:::check predict
Jakou hodnotu měla proměnná `mezivysledek` při krokování přes DevTools?
### --expected--
25
### --why--
Těsně před returnem se do ní uložila hodnota 25 (10 * 2 + 5).
:::

# --hints--

`komplexniPrevod(10)` musí vrátit 25.
```js
assert.equal(komplexniPrevod(10), 25, "Funkce vrací mezivýsledek");
```


# --help--

## --tip--
Podívej se na lekci [Funkce](see:js-funkce/funkce#return-jak-funkce-vraci-vysledek). Zkontroluj, zda nechybí `return`.

## --tip--
Funkce musí vrátit vypočítanou hodnotu. Pokud výpočet uložíš do proměnné, musíš tu proměnnou následně vrátit pomocí `return promenna;`.

## --tip--
Stejný vzor na jiných datech:
```js
function secti(a, b) {
  const soucet = a + b;
  return soucet;
}
```
