# --description--

Americké e-shopy, recepty a závody uvádějí míle, libry a stupně Fahrenheita. V tomhle workshopu postavíš **převodník jednotek**: sadu malých funkcí, které nakonec pohánějí skutečnou stránku s políčkem, výběrem převodu a tabulkou. Každou funkci budeš psát zvlášť a skládat je dohromady — přesně tak se funkce používají v praxi.

V `script.js` jsou konstanty pro převody a kolegovy funkce pro libry. V konzoli vpravo už vidíš, kolik kilogramů je 5 liber, jen s nesmyslným počtem desetinných míst.

Začneš něčím, co znáš ze sekce o číslech, a to bez návodu.

**Úkol:** Pod kolegův kód napiš funkci `roundTo(value, decimals)`, která vrátí `value` zaokrouhlené na `decimals` desetinných míst. Výsledek musí být **číslo**, ne text.

# --hints--

`roundTo(2.26796185, 2)` vrátí číslo `2.27`.

```js
assert.equal(roundTo(2.26796185, 2), 2.27, 'roundTo(2.26796185, 2) má vrátit číslo 2.27');
```

`roundTo(42.1648128, 1)` vrátí `42.2` a `roundTo(3.7, 0)` vrátí `4`.

```js
assert.equal(roundTo(42.1648128, 1), 42.2, 'roundTo(42.1648128, 1) má vrátit 42.2');
assert.equal(roundTo(3.7, 0), 4, 'roundTo(3.7, 0) má vrátit 4 — nula desetinných míst znamená celé číslo');
```

`roundTo` vrací číslo, ne text.

```js
assert.equal(typeof roundTo(1.234, 1), 'number', "typeof roundTo(1.234, 1) má být 'number' — toFixed vrací text");
```

# --help--

## --tip--

Zopakuj si, proč `toFixed` na výpočty nestačí, v části [`toFixed` vrací řetězec](see:js-retezce-cisla/cisla#tofixed-vraci-retezec).

## --tip--

Funkce má jeden `return` s výpočtem. `Math.round` zaokrouhluje jen na celá čísla, takže číslo nejdřív posuň o desetinná místa, zaokrouhli a posuň zpátky.

## --tip--

Postup rozepsaný na podcíle, kód k nim napíšeš sám:

```js
// 1. spočítej, čím násobit: 10 na počet desetinných míst
// 2. vynásob, zaokrouhli na celé číslo
// 3. vyděl stejným číslem a výsledek vrať
```

# --solution--

## --file-- script.js

```js
// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

function kgToPounds(kg) {
  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

console.log(roundTo(poundsToKg(5), 2));
```
