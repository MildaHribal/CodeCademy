# --description--

Na stránce nechceš ukazovat `42.1648128`, ale `42,16` — dvě desetinná místa a českou desetinnou čárku. Zaokrouhlovat už umíš funkcí `roundTo`, tak ji použij znovu.

**Úkol:** Napiš funkci `formatNumber(value)`, která číslo zaokrouhlí na **2 desetinná místa** funkcí `roundTo`, převede ho na text a tečku nahradí čárkou. Vrátí text, třeba `'42,16'`.

Funkce smí volat jinou funkci a pracovat s její návratovou hodnotou. Na jiných datech:

```js
function formatMinutes(hours) {
  const minutes = hoursToMinutes(hours);
  return `${minutes} min`;
}
```

Text z čísla udělá `String(číslo)` a tečku v textu nahradí `.replace('.', ',')`.

# --hints--

`formatNumber(42.1648128)` vrátí text `'42,16'`.

```js
assert.equal(formatNumber(42.1648128), '42,16', "formatNumber(42.1648128) má vrátit '42,16'");
```

`formatNumber(5)` vrátí `'5'` a `formatNumber(2.26796185)` vrátí `'2,27'`.

```js
assert.equal(formatNumber(5), '5', "formatNumber(5) má vrátit '5' — celé číslo bez desetinné čárky");
assert.equal(formatNumber(2.26796185), '2,27', "formatNumber(2.26796185) má vrátit '2,27'");
```

`formatNumber` vrací text, ne číslo.

```js
assert.equal(typeof formatNumber(1.5), 'string', "typeof formatNumber(1.5) má být 'string'");
```

# --help--

## --tip--

Návratová hodnota jedné funkce může být vstupem druhé — viz [return: jak funkce vrací výsledek](see:js-funkce/funkce#return-jak-funkce-vraci-vysledek).

## --tip--

V těle zavolej `roundTo` s hodnotou a počtem míst, výsledek převeď na text a v textu nahraď tečku. Celý výraz pošli ven přes `return`.

```js
// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

function kgToPounds(kg) {
  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

console.log(roundTo(poundsToKg(5), 2));

function milesToKm(miles) {
  return miles * KM_PER_MILE;
}

console.log(milesToKm(26.2));

const kmToMiles = (km) => km / KM_PER_MILE;

console.log(kmToMiles(42.195));

function formatNumber(value) {
  return String(roundTo(value, 2)).replace('.', ',');
}

console.log(formatNumber(milesToKm(26.2)));
```
