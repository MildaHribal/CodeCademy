# --description--

Teď stejný vzor napíšeš sám, pro vzdálenost.

**Úkol:** Napiš funkci `distanceLabel(miles)`, která vrátí:

- `'Zadej číslo'`, když `miles` není běžné číslo,
- `'Vzdálenost nemůže být záporná'`, když je `miles` menší než nula,
- jinak míle převedené na kilometry s jednotkou, třeba `'42,2 km'`.

Na kontrolu „je to číslo?" se hodí `Number.isFinite`, nebo `Number.isNaN` doplněné o kontrolu typu. Pozor na nulu: `0` mil je platná vzdálenost a musí dát `'0 km'`.

# --hints--

`distanceLabel(26.2)` vrátí `'42,2 km'`.

```js
assert.equal(distanceLabel(26.2), '42,2 km', "distanceLabel(26.2) má vrátit '42,2 km'");
```

`distanceLabel(-3)` vrátí `'Vzdálenost nemůže být záporná'`.

```js
assert.equal(distanceLabel(-3), 'Vzdálenost nemůže být záporná', "distanceLabel(-3) má vrátit 'Vzdálenost nemůže být záporná'");
```

`distanceLabel(NaN)` vrátí `'Zadej číslo'`.

```js
assert.equal(distanceLabel(NaN), 'Zadej číslo', "distanceLabel(NaN) má vrátit 'Zadej číslo'");
```

`distanceLabel(0)` vrátí `'0 km'`.

```js
assert.equal(distanceLabel(0), '0 km', "distanceLabel(0) má vrátit '0 km' — nula je platná vzdálenost; když dostaneš 'Zadej číslo', podmínka bere nulu jako nepravdu");
```

# --help--

## --tip--

Stejný vzor jsi skládal v minulém kroku — viz [Předčasný `return` (guard clause)](see:js-funkce/funkce#predcasny-return-guard-clause).

## --tip--

Dvě kontroly nahoře, každá s vlastním `return`, a na konci jeden `return` s `formatResult` a převodem mil. Kontrolu čísla napiš tak, aby nulu nepovažovala za chybu: `!miles` je pro nulu pravda.

## --tip--

Na jiných datech: funkce `ageLabel(age)` by nejdřív vrátila text pro nečíslo, pak pro zápornou hodnotu a nakonec `` `${age} let` ``.

# --explain--

Vysvětli vlastními slovy, proč se kontroly vstupu píšou jako guard clauses na začátku funkce, a ne jako zanořené `if` / `else`.

## --model--

Guard clause vyřídí nesmyslný vstup hned na začátku a funkce skončí. Každá kontrola je jeden krátký `if` s `return` a čtou se shora jako seznam podmínek. Hlavní výpočet pak stojí na konci bez zanoření, takže je jasně vidět, co funkce dělá v běžném případě. Se zanořenými `else` by hlavní logika skončila hluboko uvnitř a při přidání další kontroly by se zanoření ještě zhoršilo.

## --checklist--

- Guard clause při nesmyslném vstupu hned vrátí výsledek a funkce skončí.
- Kontroly se čtou shora jako seznam, bez zanoření.
- Hlavní výpočet zůstane na konci funkce mimo `if`.
- Další kontrola se přidá jako nový `if`, bez přepisování zbytku.

// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

function kgToPounds(kg) {
  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

console.log(roundTo(poundsToKg(5), 2));

function milesToKm(miles) {
  return miles * KM_PER_MILE;
}

console.log(milesToKm(26.2));

const kmToMiles = (km) => km / KM_PER_MILE;

console.log(kmToMiles(42.195));

function formatNumber(value, decimals = 2) {
  return String(roundTo(value, decimals)).replace('.', ',');
}

console.log(formatNumber(milesToKm(26.2)));
console.log(formatNumber(milesToKm(26.2), 0));

function formatResult(value, unit, decimals = 1) {
  return `${formatNumber(value, decimals)} ${unit}`;
}

console.log(formatResult(milesToKm(26.2), 'km'));

// Teploty poslal kolega: recepty z USA uvádějí teplotu trouby ve °F.
const ABSOLUTE_ZERO_F = -459.67;
const ABSOLUTE_ZERO_C = -273.15;

function degreesAboveFreezing(fahrenheit) {
  return fahrenheit - 32;
}

function fahrenheitToCelsius(fahrenheit) {
  return degreesAboveFreezing(fahrenheit) * 5 / 9;
}

function celsiusToFahrenheit(celsius) {
  return celsius * 9 / 5 + 32;
}

console.log(formatResult(fahrenheitToCelsius(350), '°C'));

function temperatureLabel(fahrenheit) {
  if (!Number.isFinite(fahrenheit)) {
    return 'Zadej číslo';
  }
  if (fahrenheit < ABSOLUTE_ZERO_F) {
    return 'Pod absolutní nulou';
  }
  return formatResult(fahrenheitToCelsius(fahrenheit), '°C');
}
