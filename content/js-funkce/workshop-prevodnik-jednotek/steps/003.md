# --description--

Opačný převod je krátký výpočet na jeden řádek. Takové funkce se často píšou jako šipkové.

**Úkol:** Pod `milesToKm` ulož do konstanty `kmToMiles` šipkovou funkci s parametrem `km`, která vrátí kilometry vydělené `KM_PER_MILE`. Použij šipku **bez složených závorek**, s výrazem místo těla.

Na jiných datech:

```js
const minutesToHours = (minutes) => minutes / 60;
```

Výraz za šipkou se vrátí sám. Se složenými závorkami by to bylo tělo funkce a `return` bys musel napsat.

# --hints--

`kmToMiles(42.195)` vrátí přibližně `26.219`.

```js
assert.ok(Math.abs(kmToMiles(42.195) - 42.195 / 1.609344) < 1e-9, 'kmToMiles(42.195) má vrátit 42.195 / 1.609344 ≈ 26.219');
```

`kmToMiles(milesToKm(10))` vrátí zpátky `10`.

```js
assert.ok(Math.abs(kmToMiles(milesToKm(10)) - 10) < 1e-9, 'kmToMiles(milesToKm(10)) má vrátit 10 — převod tam a zpět');
```

`kmToMiles` je šipková funkce uložená v `const`.

```js
const source = helpers.stripComments(files['script.js'], 'js');
assert.match(source, /const\s+kmToMiles\s*=\s*\(?\s*\w+\s*\)?\s*=>/, 'kmToMiles má být const se šipkovou funkcí: const kmToMiles = (…) => …');
```

## --tip--

Zápisy šipek jsou v části [Výraz a šipková funkce](see:js-funkce/funkce#vyraz-a-sipkova-funkce).

## --tip--

Za `=>` napiš jen výpočet. Když se v konzoli objeví `undefined`, máš za šipkou složené závorky bez `return`.

// Převodník jednotek pro nákupy, recepty a závody ze zahraničí.
// Americké weby uvádějí míle, libry, palce a stupně Fahrenheita.
const KM_PER_MILE = 1.609344;
const KG_PER_POUND = 0.45359237;
const CM_PER_INCH = 2.54;

// Převody liber už napsal kolega.
function poundsToKg(pounds) {
  return pounds * KG_PER_POUND;
}

function kgToPounds(kg) {
  return kg / KG_PER_POUND;
}

console.log(poundsToKg(5));

function roundTo(value, decimals) {
  const factor = 10 ** decimals;
  return Math.round(value * factor) / factor;
}

console.log(roundTo(poundsToKg(5), 2));

function milesToKm(miles) {
  return miles * KM_PER_MILE;
}

console.log(milesToKm(26.2));

const kmToMiles = (km) => km / KM_PER_MILE;

console.log(kmToMiles(42.195));
