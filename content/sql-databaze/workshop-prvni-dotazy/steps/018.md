# --description--

Nad katalogem je rozbalovací seznam „Řadit podle": název, rok, délka. Adresa pak vypadá
`/api/movies?sort=year`.

Tady narazíš na hranici vázaných parametrů. Otazník nese **hodnotu**, ne jméno sloupce.
Když napíšeš `ORDER BY ?` a pošleš `'year'`, databáze řadí podle textu `'year'`, který je
pro všechny řádky stejný — dotaz nespadne, jen neřadí. A vložit `sort` přímo do textu SQL
nesmíš, to už znáš z kolegova hledání podle režiséra.

Řešení je **seznam povolených hodnot** (*allowlist*): jméno sloupce do dotazu vložíš jen
tehdy, když je to jedno z těch, které jsi dopředu povolil sám. Cokoli jiného odmítneš
chybou, ze které server udělá `400`.

**Úkol:** napiš a vyexportuj `sortedMovies(db, sort)`. Vrátí `title`, `year` a `minutes`
všech filmů seřazené vzestupně podle sloupce `sort`. Povolené hodnoty jsou jen `title`,
`year` a `minutes`. Pro jakoukoli jinou hodnotu funkce vyhodí chybu (`throw new Error(…)`)
a dotaz se nespustí.


# --help--

## --tip--

Otazník umí nést jen hodnotu. Proč, a proč hodnota nesmí do textu SQL, připomene krok
[Filmy podle žánru: vázaný parametr](see:sql-databaze/workshop-prvni-dotazy/006).

## --tip--

Nejdřív zkontroluj `sort` proti poli nebo množině povolených jmen a při neshodě vyhoď
chybu. Teprve potom vlož `sort` do šablonového řetězce za `ORDER BY`.

## --tip--

Stejný vzor u objednávek: `const allowedStatuses = new Set(['nová', 'odeslaná'])`, pak
`if (!allowedStatuses.has(status)) throw new Error('Neznámý stav')`.

# --explain--

Vysvětli vlastními slovy, proč u řazení nestačí vázaný parametr `ORDER BY ?` a jak allowlist zabrání SQL injection, i když jméno sloupce vkládáš do textu dotazu.

## --model--

Vázaný parametr nese hodnotu, ne jméno sloupce, takže `ORDER BY ?` řadí podle stejného
textu u všech řádků a pořadí se nezmění. Jméno sloupce proto musí být přímo v textu SQL.
Bezpečné to je jen tehdy, když do textu jde jedna z hodnot, které jsem předem povolil
v kódu. Cokoli jiného odmítnu dřív, než se dotaz sestaví, takže uživatel do SQL nedostane
nic, co jsem nenapsal sám.

## --checklist--

- Vázaný parametr nese hodnotu, ne jméno sloupce nebo klíčové slovo.
- `ORDER BY ?` nespadne, ale řadí podle konstanty, takže neřadí.
- Do textu SQL smí jen hodnota ze seznamu, který napsal programátor.
- Neznámou hodnotu je potřeba odmítnout dřív, než se dotaz sestaví.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

```js
// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}

export function moviesBetween(db, fromYear, toYear) {
  return db
    .prepare('SELECT title, year FROM movies WHERE year >= ? AND year <= ? ORDER BY year')
    .all(fromYear, toYear);
}

export function searchTitles(db, text) {
  return db.prepare('SELECT title, year FROM movies WHERE title LIKE ? ORDER BY title').all(`%${text}%`);
}

export function moviesInGenres(db, genres) {
  const placeholders = genres.map(() => '?').join(', ');
  return db
    .prepare(`SELECT title, genre FROM movies WHERE genre IN (${placeholders}) ORDER BY title`)
    .all(...genres);
}

// Doplnil kolega Petr: filmy, které ještě nikdo nehodnotil, a dlouhé filmy.
export function unratedMovies(db) {
  return db.prepare('SELECT title, year FROM movies WHERE rating IS NULL ORDER BY year').all();
}

export function longMovies(db, minMinutes) {
  return db
    .prepare('SELECT title, minutes FROM movies WHERE minutes >= ? ORDER BY minutes DESC')
    .all(minMinutes);
}

export function pageOfMovies(db, page, pageSize) {
  const offset = (page - 1) * pageSize;
  return db
    .prepare('SELECT id, title FROM movies ORDER BY title LIMIT ? OFFSET ?')
    .all(pageSize, offset);
}

export function addMovie(db, movie) {
  const result = db
    .prepare('INSERT INTO movies (title, year, genre, director, minutes, rating) VALUES (?, ?, ?, ?, ?, ?)')
    .run(movie.title, movie.year, movie.genre, movie.director, movie.minutes, movie.rating ?? null);
  return result.lastInsertRowid;
}

export function rateMovie(db, id, rating) {
  const result = db.prepare('UPDATE movies SET rating = ? WHERE id = ?').run(rating, id);
  return result.changes > 0;
}

export function deleteMovie(db, id) {
  const result = db.prepare('DELETE FROM movies WHERE id = ?').run(id);
  return result.changes > 0;
}

// Doplnil kolega Petr: filmy jednoho režiséra pro stránku „Filmy režiséra".
export function searchByDirector(db, director) {
  return db
    .prepare('SELECT title, year FROM movies WHERE director = ? ORDER BY year')
    .all(director);
}

export function oldestMovie(db) {
  return db.prepare('SELECT title, year FROM movies ORDER BY year LIMIT 1').get();
}

export function movieDetail(db, id) {
  const movie = db
    .prepare('SELECT id, title, year, director, minutes AS durationMinutes FROM movies WHERE id = ?')
    .get(id);
  return movie ?? null;
}
```
