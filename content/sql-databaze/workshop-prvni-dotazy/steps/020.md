# --description--

Poslední kus datové vrstvy. Tabulka `movies` má omezení `UNIQUE (title, year)`: dva filmy
se stejným názvem a rokem v katalogu být nesmí. Když redaktor omylem přidá Kolju z roku
1996 podruhé, `addMovie` spadne na výjimce
`UNIQUE constraint failed: movies.title, movies.year` a server odpoví `500`. Přitom nejde
o chybu serveru, ale o běžnou situaci, na kterou má formulář odpovědět „Tenhle film už
v katalogu je".

Kontrolu předem („existuje už takový film?") nepiš. Mezi kontrolou a zápisem může stejný
film zapsat jiný požadavek. Spolehni se na omezení v databázi a jeho chybu zachyť.
Výjimka z `node:sqlite` nese text hlášky v `message` a číselný kód v `errcode`.

Pozor na to, co zachytíš. Chyba `CHECK` (třeba délka filmu `0`) je chyba v datech, kterou
měla odchytit validace. Tu nespolkni, ať ji server ohlásí.

**Úkol:** napiš a vyexportuj `tryAddMovie(db, movie)`. Když se film uloží, vrátí
`{ ok: true, id }` s novým `id`. Když stejný název a rok v katalogu už je, vrátí
`{ ok: false, error: 'duplicate' }`. Jakoukoli jinou chybu nechá vyletět dál.

## Co máš hotové

Datová vrstva katalogu je kompletní: čteš (`SELECT` se sloupci, `WHERE`, `LIKE`, `IN`,
`IS NULL`), řadíš a stránkuješ (`ORDER BY`, `LIMIT`, `OFFSET`), zapisuješ (`INSERT`,
`UPDATE`, `DELETE` s kontrolou `changes`) a každou hodnotu od uživatele posíláš jako vázaný
parametr. Tyhle funkce by v API stály za routami: `GET /api/movies?genre=…` zavolá
`findMovies`, `POST /api/movies` zavolá `tryAddMovie` a z `ok: false` udělá `409`.

Příště přidáš druhou a třetí tabulku: recenze a uživatele. Dotazy se naučí spojovat
tabulky a počítat průměry.

## Udělej po svém

- **Vzhled výpisu:** v `index.js` vypiš katalog jako seznam s hodnocením v hvězdičkách
  místo `console.table` — `formatMovie` ti k tomu dá základ.
- **Stránkování s počtem:** přidej funkci, která ke stránce vrátí i celkový počet filmů,
  aby frontend věděl, kolik stránek ukázat.
- **Hledání bez ohledu na diakritiku:** zkus, jestli `searchTitles(db, 'pelisky')` najde
  Pelíšky, a vymysli, jaký sloupec navíc by to umožnil.
- **Tvoje téma:** přepiš `movies.sql` na knihovnu her, desek nebo receptů a ověř, že dotazy
  po přejmenování sloupců fungují.

# --help--

## --tip--

`UNIQUE` a proč patří do databáze, i když kód kontroluje předem, je v lekci
[Omezení](see:sql-databaze/relacni-databaze#omezeni-not-null-unique-check-default).

## --tip--

Zápis obal do `try`/`catch`. V `catch` rozhodni podle textu hlášky (nebo kódu chyby), jestli
jde o porušení `UNIQUE`; jinak chybu znovu vyhoď. Uložit film umí už tvoje `addMovie`.

## --tip--

Stejný vzor u registrace: v `catch` podmínka `error.message.includes('UNIQUE constraint failed')`
vrátí `{ ok: false, error: 'email-taken' }` a každá jiná chyba jde dál přes `throw error`.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}

export function moviesBetween(db, fromYear, toYear) {
  return db
    .prepare('SELECT title, year FROM movies WHERE year >= ? AND year <= ? ORDER BY year')
    .all(fromYear, toYear);
}

export function searchTitles(db, text) {
  return db.prepare('SELECT title, year FROM movies WHERE title LIKE ? ORDER BY title').all(`%${text}%`);
}

export function moviesInGenres(db, genres) {
  const placeholders = genres.map(() => '?').join(', ');
  return db
    .prepare(`SELECT title, genre FROM movies WHERE genre IN (${placeholders}) ORDER BY title`)
    .all(...genres);
}

// Doplnil kolega Petr: filmy, které ještě nikdo nehodnotil, a dlouhé filmy.
export function unratedMovies(db) {
  return db.prepare('SELECT title, year FROM movies WHERE rating IS NULL ORDER BY year').all();
}

export function longMovies(db, minMinutes) {
  return db
    .prepare('SELECT title, minutes FROM movies WHERE minutes >= ? ORDER BY minutes DESC')
    .all(minMinutes);
}

export function pageOfMovies(db, page, pageSize) {
  const offset = (page - 1) * pageSize;
  return db
    .prepare('SELECT id, title FROM movies ORDER BY title LIMIT ? OFFSET ?')
    .all(pageSize, offset);
}

export function addMovie(db, movie) {
  const result = db
    .prepare('INSERT INTO movies (title, year, genre, director, minutes, rating) VALUES (?, ?, ?, ?, ?, ?)')
    .run(movie.title, movie.year, movie.genre, movie.director, movie.minutes, movie.rating ?? null);
  return result.lastInsertRowid;
}

export function rateMovie(db, id, rating) {
  const result = db.prepare('UPDATE movies SET rating = ? WHERE id = ?').run(rating, id);
  return result.changes > 0;
}

export function deleteMovie(db, id) {
  const result = db.prepare('DELETE FROM movies WHERE id = ?').run(id);
  return result.changes > 0;
}
