# --description--

Redakce přidává filmy formulářem. Nový řádek zapíše `INSERT INTO`: jméno tabulky, v závorce
sloupce a za `VALUES` hodnoty ve stejném pořadí. Hodnoty zase jako vázané parametry:

```js
const result = db
  .prepare('INSERT INTO customers (name, city) VALUES (?, ?)')
  .run(customer.name, customer.city);
```

`INSERT` žádné řádky nevrací, proto `.run()` místo `.all()`. Výsledek nese
`lastInsertRowid` — `id`, které databáze novému řádku právě přidělila. Klient ho potřebuje,
aby mohl na nový film hned odkázat. Sloupec `id` do `INSERT` nepiš, přidělí ho databáze.

> [!PITFALL]
> Hodnotu `undefined` SQLite uložit neumí. Když ve formuláři chybí nepovinné pole, `.run()`
> spadne na `Provided value cannot be bound to SQLite parameter 6.` Chybějící hodnotu předej
> jako `null`.

**Úkol:** napiš a vyexportuj `addMovie(db, movie)`. Objekt `movie` má klíče `title`, `year`,
`genre`, `director`, `minutes` a nepovinný `rating`. Funkce film uloží a vrátí jeho nové `id`.
Když `rating` chybí, uloží se `NULL`.

# --hints--

`addMovie` vrátí `id` nového filmu (v katalogu je 20 filmů, takže 21) a film jde přečíst.

```js
const { openDb } = await helpers.importFile('db.js');
const { addMovie } = await helpers.importFile('queries.js');
assert.equal(typeof addMovie, 'function', 'queries.js má exportovat funkci addMovie');
const db = openDb();
const id = addMovie(db, { title: 'Úsměvy smutných mužů', year: 2018, genre: 'drama', director: 'Dan Svátek', minutes: 98, rating: 7.1 });
assert.equal(id, 21, 'addMovie(db, …) má vrátit id nového filmu, tedy 21 — vracíš lastInsertRowid?');
const saved = db.prepare('SELECT * FROM movies WHERE id = ?').get(21);
assert.deepEqual({ ...saved }, { id: 21, title: 'Úsměvy smutných mužů', year: 2018, genre: 'drama', director: 'Dan Svátek', minutes: 98, rating: 7.1 }, 'v tabulce má být nový film se všemi hodnotami, které addMovie dostala');
```

Film bez `rating` se uloží s hodnocením `NULL`.

```js
const { openDb } = await helpers.importFile('db.js');
const { addMovie } = await helpers.importFile('queries.js');
const db = openDb();
let id;
try {
  id = addMovie(db, { title: 'Bratři', year: 2023, genre: 'drama', director: 'Tomáš Mašín', minutes: 136 });
} catch (error) {
  assert.fail(`addMovie(db, film bez rating) spadl na chybě „${error.message}" — chybějící hodnotu předej jako null`);
}
const saved = db.prepare('SELECT title, rating FROM movies WHERE id = ?').get(id);
assert.deepEqual({ ...saved }, { title: 'Bratři', rating: null }, 'film Bratři bez rating má mít v tabulce rating NULL');
```

Dvě volání za sebou vrátí dvě různá `id` a v katalogu pak je 22 filmů.

```js
const { openDb } = await helpers.importFile('db.js');
const { addMovie } = await helpers.importFile('queries.js');
const db = openDb();
const first = addMovie(db, { title: 'Bratři', year: 2023, genre: 'drama', director: 'Tomáš Mašín', minutes: 136, rating: 7.3 });
const second = addMovie(db, { title: 'Karel', year: 2024, genre: 'dokument', director: 'Olga Malířová Špátová', minutes: 124, rating: 7.6 });
assert.deepEqual([first, second], [21, 22], 'dvě volání addMovie mají vrátit id 21 a 22');
assert.equal(db.prepare('SELECT * FROM movies').all().length, 22, 'po dvou voláních addMovie má být v tabulce 22 filmů');
```

# --help--

## --tip--

Zápis nového řádku, `.run()` a `lastInsertRowid` jsou v tabulce metod v lekci
[node:sqlite: databáze v Node](see:sql-databaze/relacni-databaze#node-sqlite-databaze-v-node).

## --tip--

Dotaz potřebuje šest sloupců a šest otazníků. Hodnoty předej do `.run()` ve stejném pořadí
jako sloupce a u hodnocení nahraď chybějící hodnotu `null` operátorem `??`.

## --tip--

Stejný vzor u objednávky s nepovinnou poznámkou: `.run(order.customerId, order.note ?? null)`
a z výsledku `result.lastInsertRowid`.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

  return `${movie.title} (${movie.year}): ${rating}`;

// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}

export function moviesBetween(db, fromYear, toYear) {
  return db
    .prepare('SELECT title, year FROM movies WHERE year >= ? AND year <= ? ORDER BY year')
    .all(fromYear, toYear);
}

export function searchTitles(db, text) {
  return db.prepare('SELECT title, year FROM movies WHERE title LIKE ? ORDER BY title').all(`%${text}%`);
}

export function moviesInGenres(db, genres) {
  const placeholders = genres.map(() => '?').join(', ');
  return db
    .prepare(`SELECT title, genre FROM movies WHERE genre IN (${placeholders}) ORDER BY title`)
    .all(...genres);
}

// Doplnil kolega Petr: filmy, které ještě nikdo nehodnotil, a dlouhé filmy.

  return db
