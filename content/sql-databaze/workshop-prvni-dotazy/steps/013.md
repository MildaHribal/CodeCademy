# --description--

Když film dostane hodnocení, změní se existující řádek. To dělá `UPDATE`: tabulka, za `SET`
sloupce s novými hodnotami a za `WHERE`, **kterých řádků se změna týká**.

```sql
UPDATE customers SET city = ?, phone = ? WHERE id = ?;
```

> [!PITFALL]
> `UPDATE` bez `WHERE` je platný příkaz. Změní **všechny** řádky tabulky a databáze se nezeptá,
> jestli to myslíš vážně.

Jak poznáš, že film s daným `id` vůbec existoval? `UPDATE`, který nenajde žádný řádek, není
chyba. Výsledek `.run()` ale nese `changes` — počet změněných řádků. Když je `0`, API vrátí
`404`.

**Úkol:** napiš a vyexportuj `rateMovie(db, id, rating)`, která filmu s daným `id` nastaví
hodnocení. Vrátí `true`, když se film změnil, a `false`, když takový film není.

# --hints--

`rateMovie(db, 11, 8.1)` vrátí `true` a Vlny mají hodnocení 8.1.

```js
const { openDb } = await helpers.importFile('db.js');
const { rateMovie } = await helpers.importFile('queries.js');
assert.equal(typeof rateMovie, 'function', 'queries.js má exportovat funkci rateMovie');
const db = openDb();
assert.equal(rateMovie(db, 11, 8.1), true, 'rateMovie(db, 11, 8.1) má vrátit true — film s id 11 existuje');
assert.equal(db.prepare('SELECT rating FROM movies WHERE id = 11').get().rating, 8.1, 'po rateMovie(db, 11, 8.1) mají mít Vlny hodnocení 8.1');
```

Ostatní filmy zůstanou beze změny.

```js
const { openDb } = await helpers.importFile('db.js');
const { rateMovie } = await helpers.importFile('queries.js');
const db = openDb();
rateMovie(db, 12, 7.2);
const rated = db.prepare('SELECT title FROM movies WHERE rating = 7.2').all().map((row) => row.title);
assert.deepEqual(rated, ['Arvéd'], 'po rateMovie(db, 12, 7.2) má mít hodnocení 7.2 jen Arvéd — nechybí ve WHERE podmínka na id?');
assert.equal(db.prepare('SELECT rating FROM movies WHERE id = 1').get().rating, 8.4, 'Pelíšky mají po rateMovie(db, 12, 7.2) dál hodnocení 8.4');
```

Pro neexistující film vrátí `false`.

```js
const { openDb } = await helpers.importFile('db.js');
const { rateMovie } = await helpers.importFile('queries.js');
assert.equal(rateMovie(openDb(), 999, 5), false, 'rateMovie(db, 999, 5) má vrátit false — film s id 999 neexistuje');
```

# --help--

## --tip--

Počet změněných řádků vrací `.run()` ve vlastnosti `changes`, viz tabulka v lekci
[node:sqlite: databáze v Node](see:sql-databaze/relacni-databaze#node-sqlite-databaze-v-node).

## --tip--

Dotaz má dva otazníky: nové hodnocení za `SET` a `id` ve `WHERE`. Návratová hodnota je
porovnání `changes` s nulou.

## --tip--

Stejný vzor u zboží: `UPDATE products SET stock = ? WHERE id = ?` a pak
`return result.changes === 1`.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}

export function moviesBetween(db, fromYear, toYear) {
  return db
    .prepare('SELECT title, year FROM movies WHERE year >= ? AND year <= ? ORDER BY year')
    .all(fromYear, toYear);
}

export function searchTitles(db, text) {
  return db.prepare('SELECT title, year FROM movies WHERE title LIKE ? ORDER BY title').all(`%${text}%`);
}

export function moviesInGenres(db, genres) {
  const placeholders = genres.map(() => '?').join(', ');
  return db
    .prepare(`SELECT title, genre FROM movies WHERE genre IN (${placeholders}) ORDER BY title`)
    .all(...genres);
}

// Doplnil kolega Petr: filmy, které ještě nikdo nehodnotil, a dlouhé filmy.
export function unratedMovies(db) {
  return db.prepare('SELECT title, year FROM movies WHERE rating IS NULL ORDER BY year').all();
}

export function longMovies(db, minMinutes) {
  return db
    .prepare('SELECT title, minutes FROM movies WHERE minutes >= ? ORDER BY minutes DESC')
    .all(minMinutes);
}

export function pageOfMovies(db, page, pageSize) {
  const offset = (page - 1) * pageSize;
  return db
    .prepare('SELECT id, title FROM movies ORDER BY title LIMIT ? OFFSET ?')
    .all(pageSize, offset);
}

export function addMovie(db, movie) {
  const result = db
    .prepare('INSERT INTO movies (title, year, genre, director, minutes, rating) VALUES (?, ?, ?, ?, ?, ?)')
    .run(movie.title, movie.year, movie.genre, movie.director, movie.minutes, movie.rating ?? null);
  return result.lastInsertRowid;
}
