# --description--

Stránka „Klasika, kterou musíš vidět" chce jen filmy s vysokým hodnocením. Řádky filtruje
`WHERE`. Stojí mezi `FROM` a `ORDER BY` a propustí jen řádky, pro které je podmínka
pravdivá:

```sql
SELECT name, price FROM products WHERE price < 500 ORDER BY price DESC;
```

Porovnávat můžeš přes `=`, `!=` (nebo `<>`), `<`, `<=`, `>`, `>=`. Pozor, rovnost je v SQL
jedno `=`, žádné `===`. Text se píše do **jednoduchých** uvozovek (`'komedie'`); dvojité
uvozovky znamenají v SQL jméno sloupce.

**Úkol:** napiš a vyexportuj `topRated(db)`, která vrátí `title` a `rating` filmů
s hodnocením **aspoň** 8.3, od nejlépe hodnoceného.

# --hints--

Řádky mají klíče `title` a `rating` a jdou od nejvyššího hodnocení.

```js
const { openDb } = await helpers.importFile('db.js');
const { topRated } = await helpers.importFile('queries.js');
const rows = topRated(openDb());
assert.deepEqual(Object.keys(rows[0] ?? {}), ['title', 'rating'], 'řádky topRated(db) mají mít klíče title a rating');
assert.equal(rows[0].title, 'Vesničko má středisková', 'první má být nejlépe hodnocený film, Vesničko má středisková (8.6)');
const ratings = rows.map((row) => row.rating);
assert.deepEqual(ratings, [...ratings].sort((a, b) => b - a), `hodnocení mají jít od nejvyššího, přišlo: ${ratings.join(', ')}`);
```

# --help--

## --tip--

„Aspoň 8.3" znamená, že 8.3 do výsledku patří. Který porovnávací operátor to říká?

## --tip--

`WHERE` s podmínkou patří za `FROM movies`, `ORDER BY` až za ni.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

// Formátování filmů pro výpis.

export function formatMovie(movie) {
  const rating = movie.rating ?? 'bez hodnocení';
  return `${movie.title} (${movie.year}): ${rating}`;
}

## --file-- queries.js

```js
// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}
```
