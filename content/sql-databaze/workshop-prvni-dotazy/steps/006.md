# --description--

Filtr žánru dostane hodnotu od uživatele: `/api/movies?genre=komedie`. Hodnotu, která
přijde zvenku, **nikdy nevkládej do textu SQL**. Místo ní napiš otazník a hodnotu předej
až při spuštění dotazu:

```js
export function customersInCity(db, city) {
  return db.prepare('SELECT name FROM customers WHERE city = ? ORDER BY name').all(city);
}
```

Otazník je [[vázaný parametr]]. Databáze dostane text dotazu a hodnotu **zvlášť**, takže
hodnota zůstane hodnotou, ať obsahuje cokoli — apostrof, středník i kus SQL. Parametrů
může být víc; hodnoty se k otazníkům přiřadí v pořadí argumentů `.all(první, druhý)`.

> [!PITFALL]
> Šablonový řetězec `` `… WHERE city = '${city}'` `` vypadá stejně a pro `Brno` funguje.
> Hodnota `Brno' OR '1'='1` ale z podmínky udělá „vždycky pravda" a dotaz vrátí všechny
> zákazníky. Takovému útoku se říká SQL injection.

**Úkol:** napiš a vyexportuj `moviesByGenre(db, genre)`, která vrátí `title` a `year`
filmů daného žánru, od nejstaršího. Žánr předej jako vázaný parametr.

# --hints--

`moviesByGenre(db, 'pohádka')` vrátí tři pohádky od nejstarší.

```js
const { openDb } = await helpers.importFile('db.js');
const { moviesByGenre } = await helpers.importFile('queries.js');
assert.equal(typeof moviesByGenre, 'function', 'queries.js má exportovat funkci moviesByGenre');
const rows = moviesByGenre(openDb(), 'pohádka').map((row) => ({ ...row }));
assert.deepEqual(rows, [
  { title: 'Tři oříšky pro Popelku', year: 1973 },
  { title: 'Kytice', year: 2000 },
  { title: 'Kuky se vrací', year: 2010 },
], 'moviesByGenre(db, "pohádka") má vrátit title a year tří pohádek od nejstarší');
```

Pro jiný žánr vrátí jeho filmy od nejstaršího, pro neexistující žánr prázdné pole.

```js
const { openDb } = await helpers.importFile('db.js');
const { moviesByGenre } = await helpers.importFile('queries.js');
const db = openDb();
assert.deepEqual(moviesByGenre(db, 'dokument').map((row) => row.title), ['Svět podle Daliborka'], 'moviesByGenre(db, "dokument") má vrátit jen Svět podle Daliborka');
const comedyYears = moviesByGenre(db, 'komedie').map((row) => row.year);
assert.deepEqual(comedyYears, [1976, 1976, 1985, 1991, 1999], 'moviesByGenre(db, "komedie") má vrátit komedie od nejstarší (roky 1976, 1976, 1985, 1991, 1999)');
assert.deepEqual(moviesByGenre(db, 'western'), [], 'moviesByGenre(db, "western") má vrátit prázdné pole');
```

Hodnota s apostrofem nebo kusem SQL se bere jako obyčejný text: nic nenajde a nespadne.

```js
const { openDb } = await helpers.importFile('db.js');
const { moviesByGenre } = await helpers.importFile('queries.js');
const db = openDb();
let rows;
try {
  rows = moviesByGenre(db, "komedie' OR '1'='1");
} catch (error) {
  assert.fail(`moviesByGenre(db, "komedie' OR '1'='1") spadl na chybě „${error.message}" — žánr patří do dotazu jako vázaný parametr ?, ne do textu SQL`);
}
assert.deepEqual(rows, [], 'moviesByGenre(db, "komedie\' OR \'1\'=\'1") má vrátit prázdné pole — takový žánr neexistuje, dotaz nesmí vrátit všechny filmy');
try {
  moviesByGenre(db, "d'Artagnan");
} catch (error) {
  assert.fail(`moviesByGenre(db, "d'Artagnan") spadl na chybě „${error.message}" — apostrof v hodnotě nesmí rozbít dotaz`);
}
```

# --explain--

Vysvětli vlastními slovy, proč je `WHERE genre = ?` s hodnotou v `.all(genre)` bezpečné a `` WHERE genre = '${genre}' `` ne.

## --model--

U šablonového řetězce se hodnota od uživatele stane součástí textu SQL, takže apostrof
v ní ukončí řetězec a zbytek se provede jako příkaz. S otazníkem pošle aplikace databázi
text dotazu a hodnotu odděleně. Databáze nejdřív dotaz přeloží a hodnotu do něj dosadí až
jako data, takže z ní nikdy nemůže být kód.

## --checklist--

- V šablonovém řetězci se hodnota stane součástí textu SQL.
- Apostrof v hodnotě ukončí řetězec a zbytek se vykoná jako SQL.
- Vázaný parametr posílá hodnotu odděleně od textu dotazu.
- Hodnota v parametru zůstane daty, nikdy se neprovede jako kód.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

export function formatMovie(movie) {

  return `${movie.title} (${movie.year}): ${rating}`;
}

// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}
