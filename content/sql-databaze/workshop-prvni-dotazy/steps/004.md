# --description--

Bez `ORDER BY` databáze nic neslibuje. Řádky teď chodí v pořadí, v jakém se zapsaly, ale
jakmile přibude index nebo se tabulka přestaví, pořadí se změní. **Když na pořadí
záleží, napiš ho.**

```sql
SELECT name, city FROM customers ORDER BY city DESC, name;
```

`ORDER BY` řadí podle prvního sloupce; řádky se stejnou hodnotou pak podle druhého.
`DESC` znamená sestupně, bez něj (nebo s `ASC`) se řadí vzestupně. Směr platí jen pro
sloupec, za kterým stojí — v ukázce se města řadí od Z a jména ve stejném městě od A.

**Úkol:** napiš a vyexportuj `moviesByYear(db)`, která vrátí `title`, `year` a `director` všech filmů
od nejnovějšího. Filmy ze stejného roku seřaď podle názvu vzestupně.

# --hints--

`moviesByYear(db)` začíná nejnovějšími filmy: `Vlny` (2024), pak dva filmy z roku 2022 podle abecedy.

```js
const { openDb } = await helpers.importFile('db.js');
const { moviesByYear } = await helpers.importFile('queries.js');
assert.equal(typeof moviesByYear, 'function', 'queries.js má exportovat funkci moviesByYear');
const rows = moviesByYear(openDb()).map((row) => `${row.title} ${row.year}`);
assert.deepEqual(rows.slice(0, 3), ['Vlny 2024', 'Arvéd 2022', 'Il Boemo 2022'], 'moviesByYear(db) má začínat Vlny 2024, Arvéd 2022, Il Boemo 2022');
```

Filmy ze stejného roku jsou podle názvu a na konci je nejstarší film.

```js
const { openDb } = await helpers.importFile('db.js');
const { moviesByYear } = await helpers.importFile('queries.js');
const rows = moviesByYear(openDb());
const from2000 = rows.filter((row) => row.year === 2000).map((row) => row.title);
assert.deepEqual(from2000, ['Kytice', 'Musíme si pomáhat', 'Samotáři'], 'filmy z roku 2000 mají být seřazené podle názvu: Kytice, Musíme si pomáhat, Samotáři');
assert.equal(rows.length, 20, 'moviesByYear(db) má vrátit všech 20 filmů');
assert.equal(rows.at(-1).title, 'Ostře sledované vlaky', 'poslední má být nejstarší film, Ostře sledované vlaky z roku 1966');
```

## --tip--

bez směru.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

// Formátování filmů pro výpis.

export function formatMovie(movie) {
  const rating = movie.rating ?? 'bez hodnocení';
  return `${movie.title} (${movie.year}): ${rating}`;
}

## --file-- queries.js

```js
// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}
```
