# --description--

Vyhledávací pole na webu hledá kus názvu: kdo napíše `svět`, má dostat _Tmavomodrý svět_
i _Svět podle Daliborka_. Rovnost `=` hledá jen celý text. Na vzor je operátor `LIKE`,
ve kterém `%` znamená „cokoli, i nic" a `_` právě jeden znak:

```sql
SELECT name FROM streets WHERE name LIKE 'Na %';
```

Najde ulice, které začínají `Na `. Vzor `'%ova'` by našel ty, které končí na `ova`.

Tvoje funkce dostane jen hledaný text a znaky `%` k němu musíš přidat. Máš dvě možnosti:
přidat je v JavaScriptu k hodnotě parametru, nebo je v SQL spojit s otazníkem operátorem
`||` (v SQL spojuje texty, ne logické hodnoty).

> [!PITFALL]
> `LIKE` v SQLite nerozlišuje velikost písmen **jen u anglické abecedy**. Hledání `svět`
> najde `Svět`, ale `čas` nenajde `Čas` — pro SQLite jsou `č` a `Č` dva různé znaky.
> PostgreSQL má na hledání bez ohledu na velikost operátor `ILIKE`.

**Úkol:** napiš a vyexportuj `searchTitles(db, text)`, která vrátí `title` a `year` filmů,
jejichž název obsahuje `text` kdekoli, seřazené podle názvu. Hledaný text předej jako
vázaný parametr.

```js

assert.deepEqual(titles, ['Svět podle Daliborka', 'Tmavomodrý svět'], 'searchTitles(db, "svět") má najít Svět podle Daliborka a Tmavomodrý svět, seřazené podle názvu');
```

Hledání najde text i uprostřed názvu a vrací `title` a `year`.

```js
const { openDb } = await helpers.importFile('db.js');
const { searchTitles } = await helpers.importFile('queries.js');
const rows = searchTitles(openDb(), 'sledované').map((row) => ({ ...row }));
assert.deepEqual(rows, [{ title: 'Ostře sledované vlaky', year: 1966 }], 'searchTitles(db, "sledované") má vrátit [{ title: "Ostře sledované vlaky", year: 1966 }]');
```

Text, který v žádném názvu není, vrátí prázdné pole — i když obsahuje apostrof.

```js
const { openDb } = await helpers.importFile('db.js');
const { searchTitles } = await helpers.importFile('queries.js');
const db = openDb();
assert.deepEqual(searchTitles(db, 'Batman'), [], 'searchTitles(db, "Batman") má vrátit prázdné pole');
let rows;
try {
  rows = searchTitles(db, "d'Artagnan");
} catch (error) {
  assert.fail(`searchTitles(db, "d'Artagnan") spadl na chybě „${error.message}" — hledaný text patří do vázaného parametru`);
}
assert.deepEqual(rows, [], 'searchTitles(db, "d\'Artagnan") má vrátit prázdné pole');
```

# --help--

## --tip--

Hledáš vzor, ne celou shodu. Vzor „obsahuje" má znak `%` na obou stranách.

## --tip--

Ve `WHERE` použij `LIKE ?` a `%` přidej k hodnotě parametru v šablonovém řetězci, nebo
nech otazník holý a v SQL napiš `'%' || ? || '%'`.

## --tip--

Stejný vzor pro e-maily končící doménou: dotaz `WHERE email LIKE ?` a volání
``.all(`%@${domain}`)``.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}

export function moviesBetween(db, fromYear, toYear) {
  return db
    .prepare('SELECT title, year FROM movies WHERE year >= ? AND year <= ? ORDER BY year')
    .all(fromYear, toYear);
}

export function searchTitles(db, text) {
  return db.prepare('SELECT title, year FROM movies WHERE title LIKE ? ORDER BY title').all(`%${text}%`);
}
