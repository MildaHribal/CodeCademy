# --description--

Filtr na webu umí zaškrtnout víc žánrů: `?genre=pohádka&genre=animovaný`. Místo řady
`genre = ? OR genre = ? OR …` má SQL operátor `IN`:

```sql
SELECT name FROM orders WHERE status IN ('nová', 'zaplacená');
```

Háček je v parametrech. Jeden otazník nese **jednu** hodnotu, pole do něj předat nejde.
Když funkce dostane pole o třech žánrech, dotaz potřebuje tři otazníky `IN (?, ?, ?)`
a hodnoty rozložené do tří argumentů. Počet otazníků tedy vyrobíš podle délky pole
v JavaScriptu — z metod pole se hodí `map` a `join`, pro argumenty spread `...`.

Do textu SQL tak vkládáš jen otazníky, které jsi vyrobil sám. Hodnoty od uživatele dál jdou
jako parametry.

**Úkol:** napiš a vyexportuj `moviesInGenres(db, genres)`. Dostane pole žánrů a vrátí
`title` a `genre` filmů, které mají některý z nich, seřazené podle názvu. Pro prázdné pole
vrátí prázdné pole.

Prázdné pole žánrů vrátí prázdné pole a nespadne.

```js
const { openDb } = await helpers.importFile('db.js');
const { moviesInGenres } = await helpers.importFile('queries.js');
let rows;
try {
  rows = moviesInGenres(openDb(), []);
} catch (error) {
  assert.fail(`moviesInGenres(db, []) spadl na chybě „${error.message}"`);
}
assert.deepEqual(rows, [], 'moviesInGenres(db, []) má vrátit prázdné pole');
```

# --help--

## --tip--

Jeden otazník = jedna hodnota. Kolik otazníků potřebuje pole se třemi žánry?

## --tip--

Z pole žánrů vyrob pole otazníků přes `map`, spoj ho čárkami přes `join` a vlož do
šablonového řetězce s dotazem. Hodnoty předej do `.all()` rozložené spreadem.

## --tip--

Stejný vzor pro objednávky podle id: `ids.map(() => '?').join(', ')` dá pro tři id
text `?, ?, ?` a volání pak dostane `.all(...ids)`.

# --explain--

Vysvětli vlastními slovy, proč `WHERE genre IN (?)` s `.all(genres.join(','))` nevrátí nic, i když žánry v tabulce jsou.

## --model--

Jeden otazník nese jednu hodnotu. `genres.join(',')` z pole udělá jeden text
`pohádka,dokument` a databáze hledá film, jehož žánr je přesně tenhle text — takový není.
Pro tři žánry potřebuje dotaz tři otazníky a tři samostatné argumenty.

## --checklist--

- Jeden vázaný parametr nese právě jednu hodnotu.
- Spojené pole je jeden text, se kterým se porovná celý žánr.
- Počet otazníků musí odpovídat počtu hodnot v poli.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

export function formatMovie(movie) {

// Dotazy nad katalogem filmů. Každá funkce dostane otevřenou databázi db.

export function listMovies(db) {
  return db.prepare('SELECT * FROM movies').all();
}

export function listTitles(db) {
  return db.prepare('SELECT title, year FROM movies').all();
}

export function moviesByYear(db) {
  return db.prepare('SELECT title, year, director FROM movies ORDER BY year DESC, title').all();
}

export function topRated(db) {
  return db.prepare('SELECT title, rating FROM movies WHERE rating >= 8.3 ORDER BY rating DESC').all();
}

export function moviesByGenre(db, genre) {
  return db.prepare('SELECT title, year FROM movies WHERE genre = ? ORDER BY year').all(genre);
}

export function moviesBetween(db, fromYear, toYear) {
  return db
    .prepare('SELECT title, year FROM movies WHERE year >= ? AND year <= ? ORDER BY year')
    .all(fromYear, toYear);
}

export function searchTitles(db, text) {
  return db.prepare('SELECT title, year FROM movies WHERE title LIKE ? ORDER BY title').all(`%${text}%`);
}

export function moviesInGenres(db, genres) {
  const placeholders = genres.map(() => '?').join(', ');
  return db
    .prepare(`SELECT title, genre FROM movies WHERE genre IN (${placeholders}) ORDER BY title`)
    .all(...genres);
}
