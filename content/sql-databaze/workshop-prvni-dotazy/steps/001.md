# --description--

V tomhle workshopu napíšeš datovou vrstvu filmového katalogu, jaký znáš z ČSFD: výpis
filmů, řazení, filtry podle žánru a roku, hledání v názvech, stránkování a přidání,
úpravu i smazání filmu. Každá funkce dostane otevřenou databázi a vrátí data, která by
server poslal jako JSON.

Projekt má pět souborů:

- `movies.sql` — tabulka `movies` a dvacet filmů. Přečti si ji, ať víš, jaké sloupce máš.
- `db.js` — funkce `openDb()`, která založí databázi v paměti a naplní ji z `movies.sql`.
  Každé spuštění začíná se stejnými daty.
- `queries.js` — tvoje dotazy. Zatím prázdný.
- `format.js` — formátování pro výpis. Tady začneš.
- `index.js` — tlačítko **Spustit** zavolá každou funkci, kterou už máš, a vypíše výsledek.

První krok je čistý JavaScript bez návodu.

**Úkol:** v `format.js` napiš a vyexportuj funkci `formatMovie(movie)`. Dostane objekt
s klíči `title`, `year` a `rating` a vrátí text `Pelíšky (1999): 8.4`. Film, který ještě
nikdo nehodnotil, má `rating` rovno `null` a funkce pro něj vrátí
`Vlny (2024): bez hodnocení`. Hodnocení `0` je platné hodnocení.

# --hints--

`format.js` exportuje funkci `formatMovie`.

```js
const format = await helpers.importFile('format.js');
assert.equal(typeof format.formatMovie, 'function', 'format.js má exportovat funkci formatMovie — chybí před ní export?');
```

`formatMovie` vypíše název, rok a hodnocení ve tvaru `Pelíšky (1999): 8.4`.

```js
const { formatMovie } = await helpers.importFile('format.js');
assert.equal(formatMovie({ title: 'Pelíšky', year: 1999, rating: 8.4 }), 'Pelíšky (1999): 8.4', 'formatMovie({ title: "Pelíšky", year: 1999, rating: 8.4 }) má vrátit "Pelíšky (1999): 8.4"');
assert.equal(formatMovie({ title: 'Kolja', year: 1996, rating: 8.3 }), 'Kolja (1996): 8.3', 'formatMovie({ title: "Kolja", year: 1996, rating: 8.3 }) má vrátit "Kolja (1996): 8.3"');
```

Film s `rating: null` dostane text `bez hodnocení`, film s hodnocením `0` ukáže nulu.

```js
const { formatMovie } = await helpers.importFile('format.js');
assert.equal(formatMovie({ title: 'Vlny', year: 2024, rating: null }), 'Vlny (2024): bez hodnocení', 'formatMovie({ title: "Vlny", year: 2024, rating: null }) má vrátit "Vlny (2024): bez hodnocení"');
assert.equal(formatMovie({ title: 'Kytice', year: 2000, rating: 0 }), 'Kytice (2000): 0', 'formatMovie({ …, rating: 0 }) má vrátit "Kytice (2000): 0" — nula je platné hodnocení, ne chybějící');
```

# --help--

## --tip--

Chybějící hodnotu (`null`) od nuly odliší jiný operátor než `||`. Připomeň si
[výchozí hodnotu přes ??](see:js-zaklady/porovnani-a-logika#vychozi-hodnota-misto).

## --tip--

Stejný problém v jiném kódu: `const stock = product.stock ?? 'neznámý počet'` nechá
`0` být nulou, kdežto `product.stock || 'neznámý počet'` by z nuly udělalo text.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

// Založí databázi v paměti a naplní ji z movies.sql.
// Každé volání začíná se stejnými daty, takže testy i Spustit vidí totéž.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(readFileSync(new URL('./movies.sql', import.meta.url), 'utf8'));
  return db;
}
```

## --file-- index.js

```js
import { openDb } from './db.js';
import * as format from './format.js';
import * as queries from './queries.js';

// Spustit: zavolá každou funkci, kterou už máš napsanou, a vypíše, co vrátila.
const db = openDb();
const examples = {
  formatMovie: () => format.formatMovie({ title: 'Vlny', year: 2024, rating: null }),
  listMovies: () => queries.listMovies(db),
  listTitles: () => queries.listTitles(db),
  moviesByYear: () => queries.moviesByYear(db),
  topRated: () => queries.topRated(db),
  moviesByGenre: () => queries.moviesByGenre(db, 'komedie'),
  moviesBetween: () => queries.moviesBetween(db, 1990, 1999),
  searchTitles: () => queries.searchTitles(db, 'svět'),
  moviesInGenres: () => queries.moviesInGenres(db, ['pohádka', 'animovaný']),
  unratedMovies: () => queries.unratedMovies(db),
  longMovies: () => queries.longMovies(db, 120),
  pageOfMovies: () => queries.pageOfMovies(db, 2, 5),
  searchByDirector: () => queries.searchByDirector(db, 'Jiří Menzel'),
  oldestMovie: () => queries.oldestMovie(db),
  sortedMovies: () => queries.sortedMovies(db, 'year'),
  findMovies: () => queries.findMovies(db, { genre: 'drama', minYear: 2000 }),
  movieDetail: () => queries.movieDetail(db, 1),
  addMovie: () => queries.addMovie(db, { title: 'Úsměvy smutných mužů', year: 2018, genre: 'drama', director: 'Dan Svátek', minutes: 98, rating: 7.1 }),
  tryAddMovie: () => queries.tryAddMovie(db, { title: 'Kolja', year: 1996, genre: 'drama', director: 'Jan Svěrák', minutes: 105, rating: 8.3 }),
  rateMovie: () => queries.rateMovie(db, 11, 8.1),
  deleteMovie: () => queries.deleteMovie(db, 20),
};

for (const [name, run] of Object.entries(examples)) {
  if (typeof format[name] !== 'function' && typeof queries[name] !== 'function') continue;
  console.log(`\n${name}:`);
  const result = run();
  if (Array.isArray(result)) console.table(result);
  else console.log(result);
}
```

## --file-- format.js

```js
// Formátování filmů pro výpis.

export function formatMovie(movie) {
  const rating = movie.rating ?? 'bez hodnocení';
  return `${movie.title} (${movie.year}): ${rating}`;
}
```
