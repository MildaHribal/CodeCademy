# --description--

Jeden uživatel má k podniku napsat nejvýš jednu recenzi. Když ho hodnotí znovu, starou
recenzi přepíše — jinak by si majitel podniku mohl průměr vylepšit dvaceti pětihvězdičkovými
recenzemi z jednoho účtu.

`UNIQUE` u jednoho sloupce by tu nestačilo: uživatel smí hodnotit víc podniků a podnik má
recenze od víc uživatelů. Jedinečná má být **dvojice** sloupců. Takové omezení se píše na
konec definice tabulky, za čárku po posledním sloupci:

```sql
CREATE TABLE enrollments (
  student_id INTEGER NOT NULL REFERENCES students (id),
  course_id INTEGER NOT NULL REFERENCES courses (id),
  UNIQUE (student_id, course_id)
) STRICT;
```

**Úkol:** v `schema.sql` přidej tabulce `reviews` omezení, které nedovolí dvě recenze od
stejného uživatele pro stejný podnik.

# --hints--

Druhá recenze stejného uživatele ke stejnému podniku skončí chybou `UNIQUE constraint failed`.

```js
const { openDb } = await helpers.importFile('db.js');
const db = openDb();
const insert = db.prepare('INSERT INTO reviews (restaurant_id, user_id, rating, comment, created_at) VALUES (?, ?, ?, ?, ?)');
assert.throws(() => insert.run(1, 1, 1, 'Druhá recenze od Jany', '2026-07-01T12:00:00.000Z'), /UNIQUE constraint failed/, 'Jana (uživatel 1) už U Zlatého soudku (podnik 1) hodnotila, druhá recenze má skončit chybou UNIQUE');
```

Stejný uživatel smí hodnotit jiný podnik a jiný uživatel stejný podnik.

```js
const { openDb } = await helpers.importFile('db.js');
const db = openDb();
const insert = db.prepare('INSERT INTO reviews (restaurant_id, user_id, rating, comment, created_at) VALUES (?, ?, ?, ?, ?)');
assert.doesNotThrow(() => insert.run(9, 1, 5, 'Skvělá káva', '2026-07-01T12:00:00.000Z'), 'Jana (uživatel 1) smí hodnotit Kavárnu Obrys (podnik 9), kterou ještě nehodnotila');
assert.doesNotThrow(() => insert.run(1, 6, 4, 'Dobrý guláš', '2026-07-01T12:00:00.000Z'), 'Martin (uživatel 6) smí hodnotit U Zlatého soudku, i když ho už hodnotili jiní');
assert.equal(db.prepare('SELECT COUNT(*) AS count FROM reviews').get().count, 27, 'po dvou nových recenzích má být v tabulce 27 recenzí');
```

```js
const { openDb } = await helpers.importFile('db.js');
```

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

const read = (name) => readFileSync(new URL(name, import.meta.url), 'utf8');

// Založí databázi v paměti: schéma, podniky a uživatele.
// Recenze z reviews.sql nahraje, jakmile ve schématu existuje tabulka reviews.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(read('./schema.sql'));
  db.exec(read('./data.sql'));
  const hasReviews = db
    .prepare("SELECT 1 FROM sqlite_schema WHERE type = 'table' AND name = 'reviews'")
    .get();
  if (hasReviews) db.exec(read('./reviews.sql'));
  return db;
}
```

```js
import { openDb } from './db.js';
```

## --file-- schema.sql

```sql
CREATE TABLE restaurants (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  city TEXT NOT NULL,
  cuisine TEXT NOT NULL,
  price_level INTEGER NOT NULL CHECK (price_level BETWEEN 1 AND 3)
) STRICT;

CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE
) STRICT;

CREATE TABLE reviews (
  id INTEGER PRIMARY KEY,
  restaurant_id INTEGER NOT NULL REFERENCES restaurants (id),
  user_id INTEGER NOT NULL REFERENCES users (id),
  rating INTEGER NOT NULL CHECK (rating BETWEEN 1 AND 5),
  comment TEXT NOT NULL,
  created_at TEXT NOT NULL,
  UNIQUE (restaurant_id, user_id)
) STRICT;
```
