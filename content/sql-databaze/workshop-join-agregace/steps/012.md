# --description--

Žebříček „Nejlépe hodnocené" má problém: podnik s jedinou pětihvězdičkovou recenzí by
porazil podnik s dvaceti recenzemi za 4,8. Do žebříčku proto pustíš jen podniky, které
mají aspoň daný počet recenzí.

`WHERE` na to nestačí. Filtruje **jednotlivé řádky před seskupením** — v tu chvíli ještě
žádný počet recenzí neexistuje. Podmínka nad výsledkem agregace patří do `HAVING`, které
filtruje **hotové skupiny**:

```sql
SELECT customer_id, SUM(total) AS spent
FROM orders
GROUP BY customer_id
HAVING SUM(total) >= ?
ORDER BY spent DESC;
```

Pořadí částí dotazu je pevné: `SELECT … FROM … JOIN … WHERE … GROUP BY … HAVING … ORDER BY … LIMIT`.

**Úkol:** napiš a vyexportuj `popularRestaurants(db, minReviews)`, která vrátí
`{ name, reviewCount, averageRating }` podniků s aspoň `minReviews` recenzemi, od nejlépe
hodnoceného a při shodě podle názvu. Průměr zaokrouhli na jedno místo.

# --help--

## --tip--

Filtr nad počtem ve skupině je rozdíl mezi `WHERE` a `HAVING`, viz vzor v popisu a
[počty po skupinách](see:sql-databaze/workshop-join-agregace/008).

## --tip--

Spoj podniky s recenzemi, seskup podle podniku a za `GROUP BY` přidej podmínku na
`COUNT(…)` s vázaným parametrem. `ORDER BY` až za ni.

## --tip--

U zákazníků by to bylo „jen zákazníci s aspoň pěti objednávkami":
`GROUP BY customers.id HAVING COUNT(orders.id) >= ?`.

# --explain--

Vysvětli vlastními slovy, proč podmínka na počet recenzí nemůže být ve `WHERE` a patří do `HAVING`.

## --model--

`WHERE` se vyhodnotí pro každý řádek před seskupením, kdy ještě žádný počet recenzí
neexistuje, a agregační funkce v něm databáze odmítne. `HAVING` se vyhodnotí až po
`GROUP BY` pro každou skupinu, takže vidí výsledky `COUNT` a `AVG`. Do `WHERE` patří
podmínky na jednotlivé řádky, třeba město podniku nebo datum recenze.

## --checklist--

- `WHERE` filtruje jednotlivé řádky před seskupením.
- `HAVING` filtruje hotové skupiny po `GROUP BY`.
- Agregační funkce jako `COUNT` ve `WHERE` použít nejde.
- Podmínky na obyčejné sloupce patří do `WHERE`.

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

const read = (name) => readFileSync(new URL(name, import.meta.url), 'utf8');

// Založí databázi v paměti: schéma, podniky a uživatele.
// Recenze z reviews.sql nahraje, jakmile ve schématu existuje tabulka reviews.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(read('./schema.sql'));
  db.exec(read('./data.sql'));
  const hasReviews = db
    .prepare("SELECT 1 FROM sqlite_schema WHERE type = 'table' AND name = 'reviews'")
    .get();
  if (hasReviews) db.exec(read('./reviews.sql'));
  return db;
}
```

// Dotazy nad recenzemi podniků. Každá funkce dostane otevřenou databázi db.

export function restaurantsInCity(db, city) {
  return db.prepare('SELECT name, cuisine FROM restaurants WHERE city = ? ORDER BY name').all(city);
}

export function reviewsForRestaurant(db, restaurantId) {
  return db
    .prepare(`
      SELECT users.name AS author, reviews.rating, reviews.comment
      FROM reviews
      JOIN users ON users.id = reviews.user_id
      WHERE reviews.restaurant_id = ?
      ORDER BY reviews.created_at DESC
    `)
    .all(restaurantId);
}

export function latestReviews(db, limit) {
  return db
    .prepare(`
      SELECT r.name AS restaurant, u.name AS author, v.rating
      FROM reviews AS v
      JOIN restaurants AS r ON r.id = v.restaurant_id
      JOIN users AS u ON u.id = v.user_id
      ORDER BY v.created_at DESC
      LIMIT ?
    `)
    .all(limit);
}

export function restaurantStats(db, restaurantId) {
  return db
    .prepare(`
      SELECT COUNT(*) AS reviewCount, ROUND(AVG(rating), 1) AS averageRating
      FROM reviews
      WHERE restaurant_id = ?
    `)
    .get(restaurantId);
}

export function cuisineCounts(db) {
  return db
    .prepare(`
      SELECT cuisine, COUNT(*) AS restaurantCount
      FROM restaurants
      GROUP BY cuisine
      ORDER BY restaurantCount DESC, cuisine
    `)
    .all();
}

export function restaurantRatings(db) {
  const sql = `
    SELECT restaurants.name, COUNT(reviews.id) AS reviewCount, ROUND(AVG(reviews.rating), 1) AS averageRating
    FROM restaurants
    LEFT JOIN reviews ON reviews.restaurant_id = restaurants.id
    GROUP BY restaurants.id
    ORDER BY averageRating DESC, restaurants.name`;
  return db.prepare(sql).all();
}

export function userActivity(db) {
  return db
    .prepare(`
      SELECT users.name, COUNT(reviews.id) AS reviewCount
      FROM users
      LEFT JOIN reviews ON reviews.user_id = users.id
      GROUP BY users.id
      ORDER BY reviewCount DESC, users.name
    `)
    .all();
}
