# --description--

Recenze patří jednomu podniku a napsal ji jeden uživatel. Podnik i uživatel mají recenzí
mnoho, takže jde o dva vztahy [[vztah 1:N|1:N]] a tabulka `reviews` dostane dva
[[cizí klíč|cizí klíče]].

Stejný vzor na objednávkách, kde každá patří zákazníkovi:

```sql
CREATE TABLE orders (
  id INTEGER PRIMARY KEY,
  customer_id INTEGER NOT NULL REFERENCES customers (id),
  total INTEGER NOT NULL CHECK (total >= 0),
  created_at TEXT NOT NULL
) STRICT;
```

`REFERENCES customers (id)` říká, že `customer_id` musí být `id` existujícího zákazníka.
`node:sqlite` to hlídá od začátku, zápis neexistujícího zákazníka skončí chybou
`FOREIGN KEY constraint failed`.

**Úkol:** na konec `schema.sql` přidej tabulku `reviews` (typy hlídané přes `STRICT`) se
sloupci:

| sloupec | typ | pravidlo |
|---|---|---|
| `id` | `INTEGER` | primární klíč |
| `restaurant_id` | `INTEGER` | povinný, odkazuje na `restaurants (id)` |
| `user_id` | `INTEGER` | povinný, odkazuje na `users (id)` |
| `rating` | `INTEGER` | povinný, jen 1 až 5 |
| `comment` | `TEXT` | povinný |
| `created_at` | `TEXT` | povinný |

Pak klikni na **Spustit**: tabulka `reviews` by měla mít 25 řádků.

# --hints--

Tabulka `reviews` existuje, má všech šest sloupců a nahraje se do ní 25 recenzí.

```js
const { openDb } = await helpers.importFile('db.js');
let db;
try {
  db = openDb();
} catch (error) {
  assert.fail(`openDb() spadl při nahrávání recenzí: „${error.message}" — sedí jména sloupců a cizí klíče v tabulce reviews?`);
}
const columns = db.prepare('PRAGMA table_info(reviews)').all().map((column) => column.name).sort();
assert.deepEqual(columns, ['comment', 'created_at', 'id', 'rating', 'restaurant_id', 'user_id'], 'tabulka reviews má mít sloupce id, restaurant_id, user_id, rating, comment a created_at');
assert.equal(db.prepare('SELECT COUNT(*) AS count FROM reviews').get().count, 25, 'po openDb() má být v tabulce reviews 25 recenzí z reviews.sql');
```

`restaurant_id` a `user_id` jsou cizí klíče na `restaurants` a `users`.

```js
const { openDb } = await helpers.importFile('db.js');
const db = openDb();
const keys = db.prepare('PRAGMA foreign_key_list(reviews)').all().map((key) => `${key.from} -> ${key.table}.${key.to ?? 'id'}`).sort();
assert.deepEqual(keys, ['restaurant_id -> restaurants.id', 'user_id -> users.id'], 'reviews má mít cizí klíče restaurant_id -> restaurants (id) a user_id -> users (id)');
assert.throws(
  () => db.prepare("INSERT INTO reviews (restaurant_id, user_id, rating, comment, created_at) VALUES (999, 1, 4, 'Test', '2026-07-01T12:00:00.000Z')").run(),
  /FOREIGN KEY constraint failed/,
  'recenze podniku 999, který neexistuje, má skončit chybou FOREIGN KEY constraint failed',
);
```

Hodnocení mimo 1 až 5 a chybějící hodnoty databáze odmítne.

```js
const { openDb } = await helpers.importFile('db.js');
const db = openDb();
const insert = db.prepare('INSERT INTO reviews (restaurant_id, user_id, rating, comment, created_at) VALUES (?, ?, ?, ?, ?)');
assert.throws(() => insert.run(11, 6, 6, 'Šest hvězd', '2026-07-01T12:00:00.000Z'), /CHECK constraint failed/, 'rating 6 má databáze odmítnout (CHECK)');
assert.throws(() => insert.run(11, 6, 0, 'Nula', '2026-07-01T12:00:00.000Z'), /CHECK constraint failed/, 'rating 0 má databáze odmítnout (CHECK)');
assert.throws(() => insert.run(11, 6, 4, null, '2026-07-01T12:00:00.000Z'), /NOT NULL constraint failed/, 'comment NULL má databáze odmítnout (NOT NULL)');
assert.equal(db.prepare("PRAGMA table_list('reviews')").get()?.strict, 1, 'tabulka reviews má být STRICT, aby hlídala typy');
assert.doesNotThrow(() => insert.run(11, 6, 5, 'Skvělý čaj', '2026-07-01T12:00:00.000Z'), 'platnou recenzi (podnik 11, uživatel 6, hodnocení 5) má databáze uložit');
```

## --file-- db.js

```js
import { readFileSync } from 'node:fs';
import { DatabaseSync } from 'node:sqlite';

const read = (name) => readFileSync(new URL(name, import.meta.url), 'utf8');

// Založí databázi v paměti: schéma, podniky a uživatele.
// Recenze z reviews.sql nahraje, jakmile ve schématu existuje tabulka reviews.
export function openDb() {
  const db = new DatabaseSync(':memory:');
  db.exec(read('./schema.sql'));
  db.exec(read('./data.sql'));
  const hasReviews = db
    .prepare("SELECT 1 FROM sqlite_schema WHERE type = 'table' AND name = 'reviews'")
    .get();
  if (hasReviews) db.exec(read('./reviews.sql'));
  return db;
}
```

import { openDb } from './db.js';
import * as queries from './queries.js';

// Spustit: vypíše, co je v databázi, a zavolá každou funkci, kterou už máš napsanou.

# --solution--

## --file-- schema.sql

```sql
CREATE TABLE restaurants (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  city TEXT NOT NULL,
  cuisine TEXT NOT NULL,
  price_level INTEGER NOT NULL CHECK (price_level BETWEEN 1 AND 3)
) STRICT;

CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE
) STRICT;

CREATE TABLE reviews (
  id INTEGER PRIMARY KEY,
  restaurant_id INTEGER NOT NULL REFERENCES restaurants (id),
  user_id INTEGER NOT NULL REFERENCES users (id),
  rating INTEGER NOT NULL CHECK (rating BETWEEN 1 AND 5),
  comment TEXT NOT NULL,
  created_at TEXT NOT NULL
) STRICT;
```
