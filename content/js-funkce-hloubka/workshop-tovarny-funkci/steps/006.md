# --description--

## Hlášení

Kolega přidal na konec souboru funkci `createShortcuts(names)`. Stránka oblíbených stanic podle ní nastaví klávesové zkratky: klávesa 1 vyplní první oblíbenou stanici, klávesa 2 druhou a tak dál. Každá zkratka je funkce, která vrátí svou stanici.

Uživatel má oblíbené `['Brno hl. n.', 'Cheb', 'Kolín']`. Po stisku kterékoli klávesy se do pole vyplní `undefined`. Zkratky jsou tři, jak mají být, a v konzoli žádná chyba není.

## Úkol

Oprav `createShortcuts` tak, aby každá zkratka vracela svou stanici. Změň co nejmenší kus kódu.

# --hints--

Každá zkratka vrátí stanici na své pozici.

```js
const shortcuts = createShortcuts(['Brno hl. n.', 'Cheb', 'Kolín']);
assert.equal(shortcuts[0](), 'Brno hl. n.', "createShortcuts(['Brno hl. n.', 'Cheb', 'Kolín'])[0]() má vrátit 'Brno hl. n.'");
assert.equal(shortcuts[2](), 'Kolín', "createShortcuts(['Brno hl. n.', 'Cheb', 'Kolín'])[2]() má vrátit 'Kolín'");
```

`createShortcuts` dál vrací jednu funkci za každou stanici.

```js
const shortcuts = createShortcuts(['Jihlava', 'Liberec']);
assert.equal(shortcuts.length, 2, "createShortcuts(['Jihlava', 'Liberec']) má vrátit dvě zkratky");
assert.equal(typeof shortcuts[1], 'function', 'každá zkratka má být funkce');
assert.equal(shortcuts[1](), 'Liberec', "druhá zkratka pro ['Jihlava', 'Liberec'] má vrátit 'Liberec'");
```

# --help--

## --tip--

Chyba odpovídá pasti [`var` v cyklu](see:js-funkce-hloubka/closures#var-v-cyklu-se-settimeout).

## --tip--

Kolik proměnných `i` v cyklu vznikne? A jakou hodnotu v ní najdou zkratky, když je zavoláš až po doběhnutí cyklu?

## --tip--

Na jiných datech by oprava vypadala takhle: `for (let lap = 1; lap <= 3; lap++)` místo `for (var lap = 1; lap <= 3; lap++)`.

// Stanice pro našeptávač, seřazené podle počtu cestujících.
const stations = [
  'Praha hl. n.',
  'Brno hl. n.',
  'Ostrava hl. n.',
  'Plzeň hl. n.',
  'Olomouc hl. n.',
  'Pardubice hl. n.',
  'Praha-Smíchov',
  'České Budějovice',
  'Hradec Králové hl. n.',
  'Ústí nad Labem hl. n.',
  'Liberec',
  'Zlín střed',
  'Česká Třebová',
  'Kolín',
  'Jihlava',
  'Cheb',
  'Chomutov',
  'Děčín hl. n.',
];

// Pomocné funkce pro pozdější kroky. Počítadla ukazují, kolikrát se opravdu spustily.
let timetableLoads = 0;
let travelCalls = 0;

// Načte jízdní řád (ve skutečné aplikaci by ho stahovala ze serveru).
function loadTimetable() {
  timetableLoads += 1;
  console.log('Načítám jízdní řád…');
  return { updated: '14. 9. 2026', trains: 1840 };
}

// Doba jízdy v minutách, zjednodušeně podle vzdálenosti od Prahy
// (ve skutečné aplikaci pomalý výpočet trasy).
const kmFromPrague = {
  'Praha hl. n.': 0,
  Kolín: 62,
  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);
}

// Cena jízdenky v Kč: 1,60 Kč za kilometr a sleva podle tarifu.
function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));

// Vyrobí funkci, která pozná, jestli název stanice obsahuje dotaz.
function matchesQuery(query) {
  const needle = query.toLowerCase();
  return (name) => name.toLowerCase().includes(needle);
}

console.log(stations.filter(matchesQuery('praha')));

// Počítadlo: každé zavolání přičte jedničku a vrátí nový stav.
function createCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const countSearches = createCounter();
countSearches();
console.log('Hledání:', countSearches());

// Historie hledání: nejnovější dotaz první, nejvýš limit dotazů.
function createSearchHistory(limit) {
  let queries = [];
  return {
    add(query) {
      queries = [query, ...queries].slice(0, limit);
    },
    list() {
      return [...queries];
    },
  };
}

const recentSearches = createSearchHistory(3);
recentSearches.add('Brno');
recentSearches.add('Cheb');
console.log(recentSearches.list());

--edit--
// Od kolegy: klávesové zkratky 1, 2, 3… pro oblíbené stanice.
// Každá zkratka je funkce, která vrátí svou stanici.
function createShortcuts(names) {
  const shortcuts = [];
  for (var i = 0; i < names.length; i++) {
    shortcuts.push(() => names[i]);
  }
  return shortcuts;
}
