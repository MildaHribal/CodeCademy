# --description--

`travelMinutes` má dva argumenty, odkud a kam. Tvoje `memoize` si ale všímá jen prvního, takže trasa Kolín–Cheb by vrátila uložený výsledek trasy Kolín–Olomouc.

**Úkol:** Uprav `memoize` tak, aby fungovala pro funkce s **libovolným počtem** argumentů. Výsledek se znovu použije jen tehdy, když jsou všechny argumenty stejné a ve stejném pořadí. Volání `('Kolín', 'Cheb')` a `('Cheb', 'Kolín')` jsou dvě různé trasy. A pozor: `('ab', 'c')` a `('a', 'bc')` jsou taky dva různé dotazy, i když po spojení dají stejný text.

Jak z argumentů udělat klíč, je na tobě. Všechno potřebné znáš a rozumných cest je víc.

Tady máš hotovou polovinu knihovny: počítadla, historii, `once`, `partial` a mezipaměť. Klidně si dej pauzu.

# --hints--

Stejná trasa se spočítá jen jednou, obrácená trasa zvlášť.

```js
const fastTravel = memoize(travelMinutes);
const before = travelCalls;
assert.equal(fastTravel('Kolín', 'Cheb'), travelMinutes('Kolín', 'Cheb'), "memoize(travelMinutes)('Kolín', 'Cheb') má vrátit stejné minuty jako travelMinutes('Kolín', 'Cheb')");
const afterFirst = travelCalls;
fastTravel('Kolín', 'Cheb');
assert.equal(travelCalls, afterFirst, "druhé zavolání se stejnou trasou Kolín–Cheb nemá travelMinutes volat znovu");
fastTravel('Cheb', 'Kolín');
assert.equal(travelCalls, afterFirst + 1, 'obrácená trasa Cheb–Kolín je jiný dotaz a má se spočítat');
assert.equal(fastTravel('Kolín', 'Olomouc hl. n.'), 119, "memoize(travelMinutes)('Kolín', 'Olomouc hl. n.') má vrátit 119 — jiná cílová stanice je jiný dotaz");
assert.ok(before < afterFirst, 'první dotaz na trasu se má spočítat');
```

Klíč rozliší argumenty, které po spojení dávají stejný text.

```js
const joinParts = memoize((first, second) => `${first}+${second}`);
assert.equal(joinParts('ab', 'c'), 'ab+c', "memoize(join)('ab', 'c') má vrátit 'ab+c'");
assert.equal(joinParts('a', 'bc'), 'a+bc', "memoize(join)('a', 'bc') má vrátit 'a+bc', ne uložený výsledek pro ('ab', 'c')");
```

Funkce s jedním argumentem dál používá mezipaměť, i pro výsledek `0`.

```js
let calls = 0;
const zeroFor = memoize(() => {
  calls += 1;
  return 0;
});
zeroFor('Praha hl. n.');
zeroFor('Praha hl. n.');
assert.equal(calls, 1, "po dvou zavoláních s 'Praha hl. n.' má fn proběhnout jen jednou");
```

# --help--

## --tip--

Mezipaměť má jeden klíč, argumentů je víc. Potřebuješ z nich udělat jeden klíč, který se pro různé argumenty nikdy neshoduje — viz [Closure a paměť](see:js-funkce-hloubka/closures#closure-a-pamet).

## --tip--

Argumenty obal přijme jako pole. Z pole jde udělat text tak, aby hranice mezi argumenty zůstala poznat: spojit s oddělovačem, který v názvech stanic není, nebo převést celé pole do JSON. Funkci pak zavolej s rozprostřenými argumenty.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. obal přijme libovolné argumenty
// 2. z argumentů sestav klíč, který zachová jejich hranice a pořadí
// 3. zbytek je stejný jako dosud, jen s klíčem místo jednoho argumentu
```

```js
// Stanice pro našeptávač, seřazené podle počtu cestujících.
const stations = [
  'Praha hl. n.',
  'Brno hl. n.',
  'Ostrava hl. n.',
  'Plzeň hl. n.',
  'Olomouc hl. n.',
  'Pardubice hl. n.',
  'Praha-Smíchov',
  'České Budějovice',
  'Hradec Králové hl. n.',
  'Ústí nad Labem hl. n.',
  'Liberec',
  'Zlín střed',
  'Česká Třebová',
  'Kolín',
  'Jihlava',
  'Cheb',
  'Chomutov',
  'Děčín hl. n.',
];

// Pomocné funkce pro pozdější kroky. Počítadla ukazují, kolikrát se opravdu spustily.
let timetableLoads = 0;
let travelCalls = 0;

// Načte jízdní řád (ve skutečné aplikaci by ho stahovala ze serveru).
function loadTimetable() {
  timetableLoads += 1;
  console.log('Načítám jízdní řád…');
  return { updated: '14. 9. 2026', trains: 1840 };
}

// Doba jízdy v minutách, zjednodušeně podle vzdálenosti od Prahy
// (ve skutečné aplikaci pomalý výpočet trasy).
const kmFromPrague = {
  'Praha hl. n.': 0,
  Kolín: 62,
  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);
}

// Cena jízdenky v Kč: 1,60 Kč za kilometr a sleva podle tarifu.
function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));

// Vyrobí funkci, která pozná, jestli název stanice obsahuje dotaz.
function matchesQuery(query) {
  const needle = query.toLowerCase();
  return (name) => name.toLowerCase().includes(needle);
}

console.log(stations.filter(matchesQuery('praha')));

// Počítadlo: každé zavolání přičte jedničku a vrátí nový stav.
function createCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const countSearches = createCounter();
countSearches();
console.log('Hledání:', countSearches());

// Historie hledání: nejnovější dotaz první, nejvýš limit dotazů.
function createSearchHistory(limit) {
  let queries = [];
  return {
    add(query) {
      queries = [query, ...queries].slice(0, limit);
    },
    list() {
      return [...queries];
    },
  };
}

const recentSearches = createSearchHistory(3);
recentSearches.add('Brno');
recentSearches.add('Cheb');
console.log(recentSearches.list());

// Od kolegy: klávesové zkratky 1, 2, 3… pro oblíbené stanice.
// Každá zkratka je funkce, která vrátí svou stanici.
function createShortcuts(names) {
  const shortcuts = [];
  for (let i = 0; i < names.length; i++) {
    shortcuts.push(() => names[i]);
  }
  return shortcuts;
}

// Obal, který zavolá fn jen poprvé a potom vrací uložený výsledek.
function once(fn) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      called = true;
      result = fn(...args);
    }
    return result;
  };
}

const getTimetable = once(loadTimetable);
getTimetable();
console.log(getTimetable(), 'načteno:', timetableLoads);

// Částečná aplikace: předvyplní první argumenty funkce.
function partial(fn, ...presetArgs) {
  return (...laterArgs) => fn(...presetArgs, ...laterArgs);
}

const studentPrice = partial(ticketPrice, 'student');
console.log('Student Praha–Brno:', studentPrice(255), 'Kč');

// Čísla rezervací: prefix a pořadové číslo doplněné nulami na tři místa.
function createIdGenerator(prefix) {
  let lastNumber = 0;
  return () => {
    lastNumber += 1;
    return `${prefix}-${String(lastNumber).padStart(3, '0')}`;
  };
}

const nextReservation = createIdGenerator('R');
console.log(nextReservation(), nextReservation());

--edit--
// Mezipaměť: pro každý argument spočítá výsledek jen jednou.
function memoize(fn) {
  const cache = new Map();
  return (arg) => {
    if (!cache.has(arg)) {
      cache.set(arg, fn(arg));
    }
    return cache.get(arg);
  };
}

const minutesFromPrague = memoize((station) => travelMinutes('Praha hl. n.', station));
minutesFromPrague('Olomouc hl. n.');
console.log(minutesFromPrague('Olomouc hl. n.'), 'min, výpočtů:', travelCalls);
--edit--
```

function memoize(fn) {
  const cache = new Map();

    const key = JSON.stringify(args);

      cache.set(key, fn(...args));
