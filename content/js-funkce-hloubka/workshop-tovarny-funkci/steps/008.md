# --description--

`once` zatím funguje jen pro funkce bez argumentů. Aplikace ale potřebuje třeba jednou nastavit domovskou stanici: `setHomeStation('Kolín', 2)`.

**Úkol:** Uprav `once` tak, aby argumenty **prvního** zavolání obalu předala funkci `fn`. Další zavolání `fn` nevolají a vracejí uložený výsledek, i když dostanou jiné argumenty.

Obal nemusí vědět, kolik argumentů `fn` potřebuje. V lekci jsi to viděl u `countCalls`: zbytkový parametr `...args` v obalu sbalí všechny argumenty do pole a rozprostření `fn(...args)` je zase rozbalí. Na jiných datech:

```js
function withTiming(fn) {
  // 1. obal přijme libovolné argumenty
  return (...args) => {
    const start = performance.now();
    // 2. předá je dál a výsledek vrátí
    const result = fn(...args);
    console.log(`Trvalo ${performance.now() - start} ms`);
    return result;
  };
}
```

# --hints--

Obal předá `fn` argumenty prvního zavolání.

```js
const setHome = once((station, platform) => `${station}, nástupiště ${platform}`);
assert.equal(setHome('Kolín', 2), 'Kolín, nástupiště 2', "once(fn)('Kolín', 2) má předat oba argumenty a vrátit 'Kolín, nástupiště 2'");
```

Další zavolání s jinými argumenty vrátí první výsledek a `fn` nezavolají.

```js
let calls = 0;
const setHome = once((station) => {
  calls += 1;
  return station;
});
setHome('Kolín');
assert.equal(setHome('Cheb'), 'Kolín', "po setHome('Kolín') má setHome('Cheb') vrátit pořád 'Kolín'");
assert.equal(calls, 1, 'fn má proběhnout jen jednou');
```

Funkce bez argumentů dál proběhne jen jednou.

```js
let calls = 0;
const notify = once(() => {
  calls += 1;
});
notify();
notify();
assert.equal(calls, 1, 'once pro funkci bez argumentů a bez návratové hodnoty má fn zavolat jen jednou');
```

# --help--

## --tip--

Jde o obal, který předává argumenty — viz [Funkce, která obalí jinou funkci](see:js-funkce-hloubka/closures#funkce-ktera-obali-jinou-funkci).

## --tip--

Změny jsou dvě: obal přijme zbytkový parametr a při prvním zavolání ho rozprostře do volání `fn`.

## --tip--

Na jiných datech: `const logged = (...parts) => console.log(...parts);` přijme i předá libovolný počet argumentů.

# --explain--

Vysvětli vlastními slovy, proč si `once` pamatuje příznak `called` a nestačí jí zjišťovat, jestli už má nějaký `result`.

## --model--

Funkce, kterou `once` obaluje, může vrátit `undefined`, `0` nebo prázdný text. Kdyby obal jen kontroloval, jestli už výsledek má, považoval by takovou hodnotu za „ještě nic" a zavolal by funkci znovu. Příznak `called` říká přímo to, co potřebuju vědět: jestli už funkce proběhla. Obě proměnné jsou v prostředí volání `once`, takže každý obal má vlastní příznak i vlastní výsledek.

## --checklist--

- Obalená funkce může vrátit `undefined` nebo jinou nepravdivou hodnotu.
- Kontrola výsledku by takovou funkci zavolala znovu.
- Příznak odpovídá na otázku, jestli už funkce proběhla.
- Příznak i výsledek leží v prostředí konkrétního obalu.

```js
// Stanice pro našeptávač, seřazené podle počtu cestujících.
const stations = [
  'Praha hl. n.',
  'Brno hl. n.',
  'Ostrava hl. n.',
  'Plzeň hl. n.',
  'Olomouc hl. n.',
  'Pardubice hl. n.',
  'Praha-Smíchov',
  'České Budějovice',
  'Hradec Králové hl. n.',
  'Ústí nad Labem hl. n.',
  'Liberec',
  'Zlín střed',
  'Česká Třebová',
  'Kolín',
  'Jihlava',
  'Cheb',
  'Chomutov',
  'Děčín hl. n.',
];

// Pomocné funkce pro pozdější kroky. Počítadla ukazují, kolikrát se opravdu spustily.
let timetableLoads = 0;
let travelCalls = 0;

// Načte jízdní řád (ve skutečné aplikaci by ho stahovala ze serveru).
function loadTimetable() {
  timetableLoads += 1;
  console.log('Načítám jízdní řád…');
  return { updated: '14. 9. 2026', trains: 1840 };
}

// Doba jízdy v minutách, zjednodušeně podle vzdálenosti od Prahy
// (ve skutečné aplikaci pomalý výpočet trasy).
const kmFromPrague = {
  'Praha hl. n.': 0,
  Kolín: 62,
  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);
}

// Cena jízdenky v Kč: 1,60 Kč za kilometr a sleva podle tarifu.
function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));

// Vyrobí funkci, která pozná, jestli název stanice obsahuje dotaz.
function matchesQuery(query) {
  const needle = query.toLowerCase();
  return (name) => name.toLowerCase().includes(needle);
}

console.log(stations.filter(matchesQuery('praha')));

// Počítadlo: každé zavolání přičte jedničku a vrátí nový stav.
function createCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const countSearches = createCounter();
countSearches();
console.log('Hledání:', countSearches());

// Historie hledání: nejnovější dotaz první, nejvýš limit dotazů.
function createSearchHistory(limit) {
  let queries = [];
  return {
    add(query) {
      queries = [query, ...queries].slice(0, limit);
    },
    list() {
      return [...queries];
    },
  };
}

const recentSearches = createSearchHistory(3);
recentSearches.add('Brno');
recentSearches.add('Cheb');
console.log(recentSearches.list());

// Od kolegy: klávesové zkratky 1, 2, 3… pro oblíbené stanice.
// Každá zkratka je funkce, která vrátí svou stanici.
function createShortcuts(names) {
  const shortcuts = [];
  for (let i = 0; i < names.length; i++) {
    shortcuts.push(() => names[i]);
  }
  return shortcuts;
}

--edit--
// Obal, který zavolá fn jen poprvé a potom vrací uložený výsledek.
function once(fn) {
  let called = false;
  let result;
  return () => {
    if (!called) {
      called = true;
      result = fn();
    }
    return result;
  };
}

const getTimetable = once(loadTimetable);
getTimetable();
console.log(getTimetable(), 'načteno:', timetableLoads);
--edit--
```
