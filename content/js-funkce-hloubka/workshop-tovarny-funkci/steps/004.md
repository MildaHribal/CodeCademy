# --description--

Aplikace chce vědět, kolikrát uživatel hledal. Počet musí přežít mezi voláními, ale nesmí být v globální proměnné, kterou může kdokoli přepsat.

**Úkol:** Napiš funkci `createCounter()`, která vrátí novou funkci. Každé zavolání vrácené funkce přičte jedničku a vrátí nový počet: `1`, `2`, `3`… Každé počítadlo počítá samo za sebe.

Stav patří do prostředí továrny: proměnná deklarovaná přes `let` **uvnitř** `createCounter`, kterou vrácená funkce mění. Na jiných datech:

```js
function createPiggyBank() {
  // 1. stav žije v prostředí továrny
  let saved = 0;
  // 2. vrácená funkce ho mění a vrací
  return (coins) => {
    saved += coins;
    return saved;
  };
}
```

Pod funkci si vyrob `const countSearches = createCounter();`, dvakrát ho zavolej a druhý výsledek vypiš.

# --hints--

Vrácená funkce při každém zavolání vrátí o jedna větší číslo, začíná jedničkou.

```js
const counter = createCounter();
assert.equal(typeof counter, 'function', 'createCounter() má vrátit funkci');
assert.equal(counter(), 1, 'první zavolání počítadla má vrátit 1');
assert.equal(counter(), 2, 'druhé zavolání počítadla má vrátit 2');
assert.equal(counter(), 3, 'třetí zavolání počítadla má vrátit 3');
```

Dvě počítadla se navzájem neovlivňují.

```js
const first = createCounter();
const second = createCounter();
first();
first();
assert.equal(second(), 1, 'po dvou zavoláních prvního počítadla má druhé počítadlo začít od 1 — je stav uvnitř createCounter?');
assert.equal(first(), 3, 'první počítadlo má pokračovat číslem 3');
```
