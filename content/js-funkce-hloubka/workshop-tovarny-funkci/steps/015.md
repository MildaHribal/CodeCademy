# --description--

Seřazený `debounce` zavolá `fn` bez argumentů. Hledání ale potřebuje vědět, **co** uživatel napsal, a to z posledního zavolání: z „Brno", ne z „B".

**Úkol:** Napiš `debounce` znovu sám, tentokrát tak, aby `fn` po čekání dostala argumenty **posledního** zavolání obalu. Chování se jinak nemění: `fn` proběhne až po `delay` ms klidu a každé zavolání obalu odpočet zruší a začne znovu.

Argumenty sbalíš stejně jako v `once`. Do časovače ale nestačí předat `fn`. `setTimeout` ji zavolá bez argumentů, takže mu potřebuješ dát funkci, která `fn` zavolá s nimi. Kandidáti na tu funkci: šipková funkce, nebo `fn.bind` (k té se dostaneš v lekci o `this`).

Pod funkci si vyzkoušej `debounce((query) => console.log('Hledám:', query), 300)` a rychle ho zavolej s `'P'`, `'Pra'` a `'Praha'`.

# --hints--

Po rychlých zavoláních dostane `fn` argument posledního z nich.

```js
const seen = [];
const search = debounce((query) => seen.push(query), 60);
search('P');
search('Pra');
search('Praha');
await helpers.wait(300);
assert.deepEqual(seen, ['Praha'], "po search('P'), search('Pra'), search('Praha') má fn proběhnout jednou s 'Praha'");
```

`fn` dostane všechny argumenty posledního zavolání.

```js
let received = null;
const choose = debounce((station, platform) => {
  received = [station, platform];
}, 60);
choose('Kolín', 2);
await helpers.wait(300);
assert.deepEqual(received, ['Kolín', 2], "choose('Kolín', 2) má po čekání zavolat fn('Kolín', 2)");
```

Zavolání během čekání odpočet prodlouží.

```js
const seen = [];
const search = debounce((query) => seen.push(query), 300);
search('Br');
await helpers.wait(100);
search('Brno');
await helpers.wait(180);
assert.deepEqual(seen, [], 'zavolání obalu po 100 ms má odpočet začít znovu — 280 ms od prvního zavolání se ještě nemá nic spustit');
await helpers.wait(450);
assert.deepEqual(seen, ['Brno'], "po chvíli klidu má fn proběhnout jednou s 'Brno'");
```

Dva obaly mají každý svůj časovač.

```js
const seen = [];
const from = debounce((query) => seen.push(`odkud ${query}`), 60);
const to = debounce((query) => seen.push(`kam ${query}`), 60);
from('Kolín');
to('Cheb');
await helpers.wait(300);
assert.deepEqual(seen.toSorted(), ['kam Cheb', 'odkud Kolín'], 'dva debounce obaly mají proběhnout oba');
```

# --help--

## --tip--

Argumenty předává dál [obalující funkce](see:js-funkce-hloubka/closures#funkce-ktera-obali-jinou-funkci).

## --tip--

Obal přijme zbytkový parametr. `setTimeout` dostane šipkovou funkci, která `fn` zavolá s rozprostřenými argumenty — proměnnou s argumenty si ta šipková funkce pamatuje přes closure.

## --tip--

Na jiných datech: `setTimeout(() => showToast(message, 'info'), 2000)` zavolá funkci s argumenty až za dvě sekundy.

# --explain--

Vysvětli vlastními slovy, proč `debounce` spustí hledání jen jednou, i když obal zavoláš po každém písmenu.

## --model--

Obal si v prostředí `debounce` pamatuje číslo posledního časovače. Při každém zavolání nejdřív ten časovač zruší přes `clearTimeout` a pak naplánuje nový. Dokud uživatel píše rychleji, než je `delay`, žádný časovač nedoběhne, protože ho další písmeno zruší. Proběhne až ten poslední, po chvíli klidu, a dostane argumenty posledního zavolání, třeba celé „Brno".

## --checklist--

- Číslo časovače je v prostředí `debounce`, sdílené mezi voláními obalu.
- Každé zavolání obalu zruší předchozí časovač.
- Každé zavolání naplánuje nový časovač.
- Proběhne jen poslední časovač, po `delay` ms klidu.
- `fn` dostane argumenty posledního zavolání.

// Stanice pro našeptávač, seřazené podle počtu cestujících.
const stations = [
  'Praha hl. n.',
  'Brno hl. n.',
  'Ostrava hl. n.',
  'Plzeň hl. n.',
  'Olomouc hl. n.',
  'Pardubice hl. n.',
  'Praha-Smíchov',
  'České Budějovice',
  'Hradec Králové hl. n.',
  'Ústí nad Labem hl. n.',
  'Liberec',
  'Zlín střed',
  'Česká Třebová',
  'Kolín',
  'Jihlava',
  'Cheb',
  'Chomutov',
  'Děčín hl. n.',
];

// Pomocné funkce pro pozdější kroky. Počítadla ukazují, kolikrát se opravdu spustily.
let timetableLoads = 0;
let travelCalls = 0;

// Načte jízdní řád (ve skutečné aplikaci by ho stahovala ze serveru).
function loadTimetable() {
  timetableLoads += 1;
  console.log('Načítám jízdní řád…');
  return { updated: '14. 9. 2026', trains: 1840 };
}

// Doba jízdy v minutách, zjednodušeně podle vzdálenosti od Prahy
// (ve skutečné aplikaci pomalý výpočet trasy).
const kmFromPrague = {
  'Praha hl. n.': 0,
  Kolín: 62,
  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);
}

// Cena jízdenky v Kč: 1,60 Kč za kilometr a sleva podle tarifu.
function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));

// Vyrobí funkci, která pozná, jestli název stanice obsahuje dotaz.
function matchesQuery(query) {
  const needle = query.toLowerCase();
  return (name) => name.toLowerCase().includes(needle);
}

console.log(stations.filter(matchesQuery('praha')));

// Počítadlo: každé zavolání přičte jedničku a vrátí nový stav.
function createCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const countSearches = createCounter();
countSearches();
console.log('Hledání:', countSearches());

// Historie hledání: nejnovější dotaz první, nejvýš limit dotazů.
function createSearchHistory(limit) {
  let queries = [];
  return {
    add(query) {
      queries = [query, ...queries].slice(0, limit);
    },
    list() {
      return [...queries];
    },
  };
}

const recentSearches = createSearchHistory(3);
recentSearches.add('Brno');
recentSearches.add('Cheb');
console.log(recentSearches.list());

// Od kolegy: klávesové zkratky 1, 2, 3… pro oblíbené stanice.
// Každá zkratka je funkce, která vrátí svou stanici.
function createShortcuts(names) {
  const shortcuts = [];
  for (let i = 0; i < names.length; i++) {
    shortcuts.push(() => names[i]);
  }
  return shortcuts;
}

// Obal, který zavolá fn jen poprvé a potom vrací uložený výsledek.
function once(fn) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      called = true;
      result = fn(...args);
    }
    return result;
  };
}

const getTimetable = once(loadTimetable);
getTimetable();
console.log(getTimetable(), 'načteno:', timetableLoads);

// Částečná aplikace: předvyplní první argumenty funkce.
function partial(fn, ...presetArgs) {
  return (...laterArgs) => fn(...presetArgs, ...laterArgs);
}

const studentPrice = partial(ticketPrice, 'student');
console.log('Student Praha–Brno:', studentPrice(255), 'Kč');

// Čísla rezervací: prefix a pořadové číslo doplněné nulami na tři místa.
function createIdGenerator(prefix) {
  let lastNumber = 0;
  return () => {
    lastNumber += 1;
    return `${prefix}-${String(lastNumber).padStart(3, '0')}`;
  };
}

const nextReservation = createIdGenerator('R');
console.log(nextReservation(), nextReservation());

// Mezipaměť: pro stejné argumenty spočítá výsledek jen jednou.
function memoize(fn) {
  const cache = new Map();
  return (...args) => {
    const key = JSON.stringify(args);
    if (!cache.has(key)) {
      cache.set(key, fn(...args));
    }
    return cache.get(key);
  };
}

const minutesFromPrague = memoize((station) => travelMinutes('Praha hl. n.', station));
minutesFromPrague('Olomouc hl. n.');
console.log(minutesFromPrague('Olomouc hl. n.'), 'min, výpočtů:', travelCalls);

// Od kolegy: doba jízdy pro tabuli spojení, má se počítat jen jednou.
const travelCache = memoize(travelMinutes);

function cachedTravelMinutes(from, to) {
  return travelCache(from, to);
}

  return () => {

  };
}
