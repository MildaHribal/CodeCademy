# --description--

Našeptávač bude s dotazem pracovat na několika místech: při filtrování, v historii, při zvýraznění. Místo abys dotaz posílal do každé funkce znovu, vyrobíš si funkci, která si ho **zapamatuje**.

**Úkol:** Napiš funkci `matchesQuery(query)`, která vrátí **novou funkci**. Ta dostane název stanice `name` a vrátí `true`, když název obsahuje `query` (bez ohledu na velikost písmen), jinak `false`.

Vrácenou funkci pak můžeš rovnou předat do `filter`: `stations.filter(matchesQuery('praha'))`.

Funguje to díky [[closure]]: vrácená funkce vznikla uvnitř `matchesQuery`, takže vidí její parametr `query` i po tom, co `matchesQuery` skončila. Na jiných datech:

```js
// 1. továrna dostane nejmenší délku slova
function longerThan(minLength) {
  // 2. vrácená funkce si minLength pamatuje
  return (word) => word.length > minLength;
}

const longWords = ['vlak', 'lokomotiva', 'kupé'].filter(longerThan(4));
```

Vypiš si, co najde `stations.filter(matchesQuery('praha'))`.

# --hints--

`matchesQuery('praha')` vrátí funkci.

```js
assert.equal(typeof matchesQuery('praha'), 'function', "matchesQuery('praha') má vrátit funkci, ne true/false");
```

Vrácená funkce odpoví `true` pro název s dotazem a `false` pro ostatní, bez ohledu na velikost písmen.

```js
const isPrague = matchesQuery('praha');
assert.equal(isPrague('Praha-Smíchov'), true, "matchesQuery('praha')('Praha-Smíchov') má vrátit true");
assert.equal(isPrague('Brno hl. n.'), false, "matchesQuery('praha')('Brno hl. n.') má vrátit false");
assert.equal(matchesQuery('HL. N.')('Olomouc hl. n.'), true, "matchesQuery('HL. N.')('Olomouc hl. n.') má vrátit true — na velikosti písmen nezáleží");
```

Vrácená funkce jde předat do `filter`.

```js
assert.deepEqual(['Cheb', 'Kolín', 'Chomutov'].filter(matchesQuery('ch')), ['Cheb', 'Chomutov'], "['Cheb', 'Kolín', 'Chomutov'].filter(matchesQuery('ch')) má vrátit ['Cheb', 'Chomutov']");
```

Každá vrácená funkce si pamatuje svůj vlastní dotaz.

```js
const isBrno = matchesQuery('brno');
const isCheb = matchesQuery('cheb');
assert.equal(isBrno('Brno hl. n.'), true, "matchesQuery('brno')('Brno hl. n.') má vrátit true i poté, co vznikla matchesQuery('cheb')");
assert.equal(isCheb('Brno hl. n.'), false, "matchesQuery('cheb')('Brno hl. n.') má vrátit false");
```
