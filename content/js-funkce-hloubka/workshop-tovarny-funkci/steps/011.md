# --description--

`travelMinutes(from, to)` představuje pomalý výpočet trasy a proměnná `travelCalls` počítá, kolikrát proběhl. Tabule spojení se ale ptá na stejné trasy pořád dokola. Výsledek, který už znáš, není potřeba počítat znovu. Uložit si ho do [[mezipaměť|mezipaměti]] a vracet hotový se říká [[memoizace]].

**Úkol:** Napiš funkci `memoize(fn)` pro funkce s **jedním** argumentem. Vrátí obal, který:

- pro argument, který ještě neviděl, zavolá `fn`, výsledek si uloží a vrátí,
- pro argument, který už viděl, vrátí uložený výsledek a `fn` nevolá — i když je výsledek `0`, prázdný text nebo `false`.

Každý obal má vlastní mezipaměť.

Kam výsledky ukládat? Kandidáti jsou dva:

- obyčejný objekt, klíč je argument a hodnota výsledek,
- `Map` s metodami `has`, `get` a `set`.

Oba projdou. `Map` je na mezipaměť vhodnější: klíčem může být cokoli, ne jen text, a nemá zděděné klíče. Obyčejný objekt „zná" klíč `'constructor'` dřív, než do něj cokoli uložíš. Mezipaměť jsi viděl v lekci u `createSearch`.

Vypiš si, kolikrát proběhl výpočet, když se memoizovaná funkce zeptá dvakrát na tutéž stanici.

# --hints--

Pro stejný argument proběhne `fn` jen jednou, pro nový argument znovu.

```js
let calls = 0;
const slowDouble = (n) => {
  calls += 1;
  return n * 2;
};
const fastDouble = memoize(slowDouble);
assert.equal(fastDouble(21), 42, 'memoize(slowDouble)(21) má vrátit 42');
assert.equal(fastDouble(21), 42, 'druhé zavolání s 21 má vrátit 42');
assert.equal(calls, 1, 'pro dvakrát stejný argument má slowDouble proběhnout jen jednou');
assert.equal(fastDouble(5), 10, 'memoize(slowDouble)(5) má vrátit 10');
assert.equal(calls, 2, 'pro nový argument 5 má slowDouble proběhnout znovu');
```

Uložený výsledek se použije, i když je to `0`.

```js
let calls = 0;
const minutesTo = memoize(() => {
  calls += 1;
  return 0;
});
minutesTo('Praha hl. n.');
minutesTo('Praha hl. n.');
assert.equal(calls, 1, "výsledek 0 se má uložit — po dvou zavoláních s 'Praha hl. n.' má fn proběhnout jen jednou");
```

Dva memoizované obaly mají každý svou mezipaměť.

```js
const withA = memoize((x) => `A${x}`);
const withB = memoize((x) => `B${x}`);
assert.equal(withA(1), 'A1', 'withA(1) má vrátit A1');
assert.equal(withB(1), 'B1', 'withB(1) má vrátit B1, ne výsledek z mezipaměti jiného obalu');
```

# --help--

## --tip--

Mezipaměť v prostředí továrny ukazuje lekce v části [Closure a paměť](see:js-funkce-hloubka/closures#closure-a-pamet).

## --tip--

Mezipaměť vytvoř uvnitř `memoize`. Obal se nejdřív zeptá, jestli klíč v mezipaměti **je** (ne jestli je hodnota pravdivá), a teprve když není, zavolá `fn` a výsledek uloží.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. mezipaměť vznikne jednou, při zavolání memoize
// 2. obal: když argument v mezipaměti ještě není, spočítej výsledek a ulož ho
// 3. obal: vrať výsledek z mezipaměti
```

# --explain--

Vysvětli vlastními slovy, proč je mezipaměť deklarovaná uvnitř `memoize` a co by se stalo, kdyby byla nad ní.

## --model--

Každé zavolání `memoize` vytvoří nové prostředí a v něm novou mezipaměť, kterou drží jen obal z tohoto zavolání. Díky tomu má každá memoizovaná funkce svoje výsledky. Kdyby mezipaměť byla nad `memoize`, sdílely by ji všechny obaly. Dvě různé funkce by pak pro stejný argument vracely výsledek té, která se ptala první. Mezipaměť navíc žije v paměti, dokud existuje obal, takže roste s každým novým argumentem.

## --checklist--

- Každé zavolání `memoize` vytvoří vlastní mezipaměť.
- Mezipaměť drží jen obal, který v tom zavolání vznikl.
- Sdílená mezipaměť nad továrnou by míchala výsledky různých funkcí.
- Mezipaměť zůstává v paměti, dokud existuje obal.

// Doba jízdy v minutách, zjednodušeně podle vzdálenosti od Prahy

const kmFromPrague = {
  'Praha hl. n.': 0,
  Kolín: 62,
  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);
}

// Cena jízdenky v Kč: 1,60 Kč za kilometr a sleva podle tarifu.
function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));

// Vyrobí funkci, která pozná, jestli název stanice obsahuje dotaz.
function matchesQuery(query) {
  const needle = query.toLowerCase();
  return (name) => name.toLowerCase().includes(needle);
}

console.log(stations.filter(matchesQuery('praha')));

// Počítadlo: každé zavolání přičte jedničku a vrátí nový stav.
function createCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const countSearches = createCounter();
countSearches();
console.log('Hledání:', countSearches());

// Historie hledání: nejnovější dotaz první, nejvýš limit dotazů.
function createSearchHistory(limit) {
  let queries = [];
  return {
    add(query) {
      queries = [query, ...queries].slice(0, limit);
    },
    list() {
      return [...queries];
    },
  };
}

const recentSearches = createSearchHistory(3);
recentSearches.add('Brno');
recentSearches.add('Cheb');
console.log(recentSearches.list());

// Od kolegy: klávesové zkratky 1, 2, 3… pro oblíbené stanice.
// Každá zkratka je funkce, která vrátí svou stanici.
function createShortcuts(names) {
  const shortcuts = [];
  for (let i = 0; i < names.length; i++) {
    shortcuts.push(() => names[i]);
  }
  return shortcuts;
}

// Obal, který zavolá fn jen poprvé a potom vrací uložený výsledek.
function once(fn) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      called = true;
      result = fn(...args);
    }
    return result;
  };
}

const getTimetable = once(loadTimetable);
getTimetable();
console.log(getTimetable(), 'načteno:', timetableLoads);

// Částečná aplikace: předvyplní první argumenty funkce.
function partial(fn, ...presetArgs) {
  return (...laterArgs) => fn(...presetArgs, ...laterArgs);
}

const studentPrice = partial(ticketPrice, 'student');
console.log('Student Praha–Brno:', studentPrice(255), 'Kč');

// Čísla rezervací: prefix a pořadové číslo doplněné nulami na tři místa.
function createIdGenerator(prefix) {
  let lastNumber = 0;
  return () => {
    lastNumber += 1;
    return `${prefix}-${String(lastNumber).padStart(3, '0')}`;
  };
}

const nextReservation = createIdGenerator('R');
console.log(nextReservation(), nextReservation());

// Mezipaměť: pro každý argument spočítá výsledek jen jednou.
function memoize(fn) {
  const cache = new Map();
  return (arg) => {
    if (!cache.has(arg)) {
      cache.set(arg, fn(arg));
    }
    return cache.get(arg);
  };
}

const minutesFromPrague = memoize((station) => travelMinutes('Praha hl. n.', station));
minutesFromPrague('Olomouc hl. n.');
