# --description--

Tlačítko **Obnovit odjezdy** si uživatelé rádi „proklikají" desetkrát za sekundu. Tady `debounce` nepomůže: čekal by, až klikání přestane, a do té doby by se nic neobnovilo. Potřebuješ [[throttle]]: první zavolání proběhne **hned** a další se až do uplynutí intervalu zahodí.

| | `debounce` | `throttle` |
|---|---|---|
| kdy `fn` proběhne | až po chvíli klidu | hned, pak nejvýš jednou za interval |
| hodí se na | psaní do pole, změnu velikosti okna | klikání, posouvání stránky |

**Úkol:** Napiš funkci `throttle(fn, interval)`, která vrátí obal:

- první zavolání obalu zavolá `fn` hned, s argumenty obalu,
- zavolání během `interval` ms od posledního **skutečného** spuštění `fn` se zahodí (nic se neodloží na později),
- po uplynutí intervalu zase první zavolání `fn` spustí.

Každý obal má vlastní stav. Jak poznat, že interval uplynul? Kandidáti:

- čas posledního spuštění z `Date.now()` (milisekundy) a porovnání s aktuálním časem,
- příznak „čekám", který nastaví spuštění a po `interval` ms ho zruší `setTimeout`.

Vyzkoušej si obal, který vypíše „Obnovuji odjezdy", a zavolej ho dvakrát rychle po sobě.

# --hints--

První zavolání proběhne hned, další rychlá zavolání se zahodí.

```js
const calls = [];
const refresh = throttle((source) => calls.push(source), 400);
refresh('tlačítko');
refresh('druhé kliknutí');
refresh('třetí kliknutí');
assert.deepEqual(calls, ['tlačítko'], "po třech rychlých zavoláních má fn proběhnout hned jednou, s argumentem 'tlačítko'");
```

Po uplynutí intervalu proběhne další zavolání.

```js
const calls = [];
const refresh = throttle((source) => calls.push(source), 100);
refresh('první');
await helpers.wait(300);
refresh('po chvíli');
assert.deepEqual(calls, ['první', 'po chvíli'], 'zavolání po uplynutí intervalu 100 ms má fn spustit znovu');
```

Interval se měří od posledního skutečného spuštění, zahozená zavolání ho neprodlužují.

```js
const calls = [];
const refresh = throttle((source) => calls.push(source), 800);
refresh('a');
await helpers.wait(300);
refresh('b');
await helpers.wait(600);
refresh('c');
assert.deepEqual(calls, ['a', 'c'], "zahozené zavolání 'b' po 300 ms nemá interval 800 ms prodloužit — 'c' po 900 ms od spuštění 'a' má proběhnout");
```

Dva obaly mají každý svůj stav.

```js
const calls = [];
const refreshTrains = throttle(() => calls.push('vlaky'), 400);
const refreshBuses = throttle(() => calls.push('autobusy'), 400);
refreshTrains();
refreshBuses();
assert.deepEqual(calls, ['vlaky', 'autobusy'], 'dva throttle obaly zavolané hned po sobě mají proběhnout oba');
```

# --help--

## --tip--

Stav mezi voláními drží prostředí továrny — viz [Closure: prostředí přežije návrat funkce](see:js-funkce-hloubka/closures#closure-prostredi-prezije-navrat-funkce).

## --tip--

Nad obalem si pamatuj čas posledního spuštění. Obal porovná aktuální čas s uloženým: když uplynul aspoň interval, uloží nový čas a zavolá `fn`, jinak neudělá nic.

## --tip--

Druhá cesta bez hodin: příznak „čekám" v prostředí továrny. Obal ho při spuštění `fn` nastaví a časovač ho po `interval` ms zase zruší. Dokud je nastavený, obal nic nedělá.

# --explain--

Vysvětli vlastními slovy rozdíl mezi `debounce` a `throttle` a ke každému řekni jednu situaci, kde ho použiješ.

## --model--

`debounce` čeká na klid: každé zavolání odpočet zruší a funkce proběhne jednou až po skončení série, třeba když uživatel dopíše text do vyhledávání. `throttle` pustí první zavolání hned a pak funkci spustí nejvýš jednou za interval, bez ohledu na to, kolikrát se volá. Hodí se na opakované akce, které mají reagovat průběžně, třeba na klikání na tlačítko nebo posouvání stránky. Oba si svůj stav, časovač nebo čas posledního spuštění, drží v prostředí továrny.

## --checklist--

- `debounce` spustí funkci až po chvíli klidu, jednou za sérii zavolání.
- `throttle` spustí funkci hned a pak nejvýš jednou za interval.
- `debounce` se hodí na psaní do vyhledávacího pole.
- `throttle` se hodí na opakované kliknutí nebo posouvání.
- Oba drží stav v prostředí továrny.

  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,

  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);

function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));

// Vyrobí funkci, která pozná, jestli název stanice obsahuje dotaz.
function matchesQuery(query) {
  const needle = query.toLowerCase();
  return (name) => name.toLowerCase().includes(needle);
}

console.log(stations.filter(matchesQuery('praha')));

// Počítadlo: každé zavolání přičte jedničku a vrátí nový stav.
function createCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const countSearches = createCounter();
countSearches();
console.log('Hledání:', countSearches());

function createSearchHistory(limit) {
  let queries = [];
  return {
    add(query) {
      queries = [query, ...queries].slice(0, limit);
    },
    list() {
      return [...queries];
    },
  };
}

const recentSearches = createSearchHistory(3);
recentSearches.add('Brno');
recentSearches.add('Cheb');
console.log(recentSearches.list());

function createShortcuts(names) {
  const shortcuts = [];
  for (let i = 0; i < names.length; i++) {
    shortcuts.push(() => names[i]);
  }
  return shortcuts;
}

// Obal, který zavolá fn jen poprvé a potom vrací uložený výsledek.
function once(fn) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      called = true;
      result = fn(...args);
    }
    return result;
  };
}

const getTimetable = once(loadTimetable);
getTimetable();
console.log(getTimetable(), 'načteno:', timetableLoads);

// Částečná aplikace: předvyplní první argumenty funkce.
function partial(fn, ...presetArgs) {
  return (...laterArgs) => fn(...presetArgs, ...laterArgs);
}

const studentPrice = partial(ticketPrice, 'student');
console.log('Student Praha–Brno:', studentPrice(255), 'Kč');

// Čísla rezervací: prefix a pořadové číslo doplněné nulami na tři místa.
function createIdGenerator(prefix) {
  let lastNumber = 0;
  return () => {
    lastNumber += 1;
    return `${prefix}-${String(lastNumber).padStart(3, '0')}`;
  };
}

const nextReservation = createIdGenerator('R');
console.log(nextReservation(), nextReservation());

// Mezipaměť: pro stejné argumenty spočítá výsledek jen jednou.
function memoize(fn) {
  const cache = new Map();
  return (...args) => {
    const key = JSON.stringify(args);
    if (!cache.has(key)) {
      cache.set(key, fn(...args));
    }
    return cache.get(key);
  };
}

const minutesFromPrague = memoize((station) => travelMinutes('Praha hl. n.', station));
minutesFromPrague('Olomouc hl. n.');
console.log(minutesFromPrague('Olomouc hl. n.'), 'min, výpočtů:', travelCalls);

const travelCache = memoize(travelMinutes);

function cachedTravelMinutes(from, to) {
  return travelCache(from, to);
}

// Debounce: zavolá fn až po delay ms klidu, s argumenty posledního zavolání.
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

const logSearch = debounce((query) => console.log('Hledám:', query), 300);
logSearch('P');
logSearch('Pra');
logSearch('Praha');

  return (query) => {
    clearTimeout(searchTimer);
    searchTimer = setTimeout(() => search(query), delay);
  };
}

function throttle(fn, interval) {

    const now = Date.now();
    if (now - lastRun >= interval) {
      lastRun = now;
      fn(...args);
    }
