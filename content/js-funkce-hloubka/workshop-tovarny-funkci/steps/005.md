# --description--

Pod polem se mají ukázat poslední hledané dotazy. Historii chceš mít pod kontrolou: přidávat do ní jde jen přes k tomu určenou funkci a nikdo zvenku ji omylem nepřepíše.

**Úkol:** Napiš funkci `createSearchHistory(limit)`, která vrátí objekt se dvěma metodami:

- `add(query)` uloží dotaz do historie,
- `list()` vrátí pole dotazů od **nejnovějšího**, nejvýš `limit` posledních.

Pole, které `list()` vrátí, musí být **nové**. Kdyby vracelo přímo pole z prostředí, kdokoli by ho mohl zvenku změnit a o soukromí by bylo po všem.

Tomu, co historie drží, se říká [[soukromý stav]]: data v prostředí továrny, ke kterým vede cesta jen přes vrácené funkce. Na jiných datech:

```js
function createPlaylist() {
  // 1. soukromé pole v prostředí továrny
  const songs = [];
  // 2. ven jdou jen funkce, které s ním pracují
  return {
    add(song) {
      songs.push(song);
    },
    count() {
      return songs.length;
    },
  };
}
```

Vyrob si historii pro tři dotazy, přidej `'Brno'` a `'Cheb'` a vypiš `list()`.

# --hints--

`list()` vrátí přidané dotazy od nejnovějšího.

```js
const recent = createSearchHistory(5);
recent.add('Brno');
recent.add('Cheb');
assert.deepEqual(recent.list(), ['Cheb', 'Brno'], "po add('Brno') a add('Cheb') má list() vrátit ['Cheb', 'Brno']");
```

Historie drží nejvýš `limit` nejnovějších dotazů.

```js
const recent = createSearchHistory(2);
recent.add('Brno');
recent.add('Cheb');
recent.add('Kolín');
assert.deepEqual(recent.list(), ['Kolín', 'Cheb'], "createSearchHistory(2) po add('Brno'), add('Cheb'), add('Kolín') má v list() vrátit ['Kolín', 'Cheb']");
```

Změna pole, které vrátí `list()`, historii nezmění.

```js
const recent = createSearchHistory(3);
recent.add('Brno');
const listed = recent.list();
listed.push('Podvržená stanice');
assert.deepEqual(recent.list(), ['Brno'], "list().push(…) nesmí změnit historii — list() má vracet nové pole");
```

Dvě historie se navzájem neovlivňují.

```js
const ema = createSearchHistory(3);
const petr = createSearchHistory(3);
ema.add('Olomouc hl. n.');
assert.deepEqual(petr.list(), [], "po ema.add('Olomouc hl. n.') má petr.list() vrátit [] — má každá historie vlastní pole?");
```

# --help--

## --tip--

Jde o soukromý stav — viz [Soukromý stav](see:js-funkce-hloubka/closures#soukromy-stav).

## --tip--

Pole s dotazy deklaruj uvnitř `createSearchHistory`. `add` ho nahradí novým polem s dotazem na začátku a zkráceným na `limit`, `list` vrátí jeho kopii.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. add: nové pole, ve kterém je dotaz první a za ním dosavadní dotazy
// 2. add: z nového pole nech jen prvních limit položek a ulož ho
// 3. list: vrať kopii, ne pole z prostředí
```

# --explain--

Vysvětli vlastními slovy, co drží metody `add` a `list` a proč se historie Emy a Petra navzájem neovlivňují.

## --model--

Metody `add` a `list` vznikly uvnitř jednoho zavolání `createSearchHistory`, a proto drží jeho prostředí i s polem dotazů a s parametrem `limit`. To prostředí zůstává v paměti, dokud existuje objekt s metodami. Každé další zavolání továrny vytvoří nové prostředí s novým polem, takže Ema a Petr mají každý svou historii. Zvenku se k poli dostanu jen přes `add` a `list`, a protože `list` vrací kopii, nikdo ho nezmění omylem.

## --checklist--

- Metody drží prostředí volání `createSearchHistory`, ve kterém vznikly.
- Prostředí zůstává v paměti, dokud existují funkce, které na něj ukazují.
- Každé zavolání továrny vytvoří nové prostředí s vlastním polem.
- K poli se dá dostat jen přes vrácené metody.
- `list` vrací kopii, takže vrácené pole nejde použít ke změně historie.

function createSearchHistory(limit) {

    add(query) {
