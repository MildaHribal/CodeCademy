# --description--

Našeptávač znáš z každého webu s jízdenkami nebo s mapou: začneš psát „bre" a pod polem se objeví Břeclav i Brno. Za takovým polem je víc práce, než je vidět. Aplikace si pamatuje historii hledání, nepočítá stejnou věc dvakrát a nehledá po každém písmenu, ale až dopíšeš.

V tomhle workshopu si na to postavíš **knihovničku malých utilit**: počítadla, historii, `once`, mezipaměť, `debounce` a `throttle`. Všechny stojí na closures. V posledních krocích z nich složíš živé vyhledávací pole se stanicemi.

V souboru `script.js` je pole `stations` a pod ním pomocné funkce pro pozdější kroky, zatím si jich nevšímej. Začneš něčím, co už umíš ze sekce o polích, a to bez návodu.

**Úkol:** Pod pomocné funkce napiš funkci `findStations(names, query)`, která vrátí nové pole stanic z `names`, jejichž název obsahuje text `query`. Na velikosti písmen nezáleží: `'praha'` najde `'Praha hl. n.'`. Pořadí zůstává stejné jako v `names` a původní pole se nemění.

Pod funkci si ji zavolej, třeba `console.log(findStations(stations, 'praha'));`, a sleduj konzoli.

# --hints--

`findStations` vrátí stanice, které obsahují dotaz, ve stejném pořadí.

```js
const names = ['Praha hl. n.', 'Brno hl. n.', 'Praha-Smíchov'];
assert.deepEqual(findStations(names, 'Praha'), ['Praha hl. n.', 'Praha-Smíchov'], "findStations(['Praha hl. n.', 'Brno hl. n.', 'Praha-Smíchov'], 'Praha') má vrátit ['Praha hl. n.', 'Praha-Smíchov']");
```

Na velikosti písmen v dotazu ani v názvu nezáleží.

```js
assert.deepEqual(findStations(['Cheb', 'Kolín', 'Chomutov'], 'CH'), ['Cheb', 'Chomutov'], "findStations(['Cheb', 'Kolín', 'Chomutov'], 'CH') má vrátit ['Cheb', 'Chomutov']");
assert.deepEqual(findStations(['Praha hl. n.', 'Brno hl. n.'], 'brno'), ['Brno hl. n.'], "findStations(['Praha hl. n.', 'Brno hl. n.'], 'brno') má vrátit ['Brno hl. n.']");
```

Když nic neodpovídá, `findStations` vrátí prázdné pole a původní pole nezmění.

```js
const names = ['Cheb', 'Kolín'];
assert.deepEqual(findStations(names, 'xyz'), [], "findStations(['Cheb', 'Kolín'], 'xyz') má vrátit []");
assert.deepEqual(names, ['Cheb', 'Kolín'], 'findStations nesmí měnit pole, které dostane');
```

## --file-- script.js

```js
// Stanice pro našeptávač, seřazené podle počtu cestujících.
const stations = [
  'Praha hl. n.',
  'Brno hl. n.',
  'Ostrava hl. n.',
  'Plzeň hl. n.',
  'Olomouc hl. n.',
  'Pardubice hl. n.',
  'Praha-Smíchov',
  'České Budějovice',
  'Hradec Králové hl. n.',
  'Ústí nad Labem hl. n.',
  'Liberec',
  'Zlín střed',
  'Česká Třebová',
  'Kolín',
  'Jihlava',
  'Cheb',
  'Chomutov',
  'Děčín hl. n.',
];

// Pomocné funkce pro pozdější kroky. Počítadla ukazují, kolikrát se opravdu spustily.
let timetableLoads = 0;
let travelCalls = 0;

// Načte jízdní řád (ve skutečné aplikaci by ho stahovala ze serveru).
function loadTimetable() {
  timetableLoads += 1;
  console.log('Načítám jízdní řád…');
  return { updated: '14. 9. 2026', trains: 1840 };
}

// Doba jízdy v minutách, zjednodušeně podle vzdálenosti od Prahy
// (ve skutečné aplikaci pomalý výpočet trasy).
const kmFromPrague = {
  'Praha hl. n.': 0,
  Kolín: 62,
  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);
}

// Cena jízdenky v Kč: 1,60 Kč za kilometr a sleva podle tarifu.
function ticketPrice(tariff, km) {
  const discounts = { adult: 0, student: 0.25, senior: 0.5 };
  return Math.round(km * 1.6 * (1 - discounts[tariff]));
}

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));
```
