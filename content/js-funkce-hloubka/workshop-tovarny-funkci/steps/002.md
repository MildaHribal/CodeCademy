# --description--

Našeptávač bude nabízet stanice podle abecedy. A to podle **české** abecedy: „Č" patří za „C" a „Ch" až za „H".

**Úkol:** Napiš funkci `sortStations(names)`, která vrátí nové pole stanic seřazené podle české abecedy. Původní pole se nesmí změnit.

Výsledek si vypiš, třeba stanice s „hl. n." v názvu: `console.log(sortStations(findStations(stations, 'hl. n.')));`.

# --hints--

`sortStations` řadí podle české abecedy: C před Č a Ch až za H.

```js
const names = ['Cheb', 'Hradec Králové hl. n.', 'České Budějovice', 'Cvikov', 'Děčín hl. n.'];
assert.deepEqual(
  sortStations(names),
  ['Cvikov', 'České Budějovice', 'Děčín hl. n.', 'Hradec Králové hl. n.', 'Cheb'],
  "sortStations(['Cheb', 'Hradec Králové hl. n.', 'České Budějovice', 'Cvikov', 'Děčín hl. n.']) má vrátit pořadí Cvikov, České Budějovice, Děčín hl. n., Hradec Králové hl. n., Cheb",
);
```

`sortStations` vrátí nové pole a původní pole nechá v původním pořadí.

```js
const names = ['Kolín', 'Brno hl. n.', 'Cheb'];
const result = sortStations(names);
assert.deepEqual(names, ['Kolín', 'Brno hl. n.', 'Cheb'], "sortStations(['Kolín', 'Brno hl. n.', 'Cheb']) nesmí přerovnat původní pole");
assert.notEqual(result, names, 'sortStations má vrátit nové pole, ne původní');
```

Porovnání dostává jazyk `'cs'`, aby pořadí nezáviselo na nastavení počítače.

```js
const source = helpers.stripComments(sortStations.toString(), 'js');
assert.match(source, /['"`]cs(-CZ)?['"`]/, "v sortStations chybí jazyk 'cs' — bez něj závisí pořadí na nastavení počítače");
```

// Stanice pro našeptávač, seřazené podle počtu cestujících.
const stations = [
  'Praha hl. n.',
  'Brno hl. n.',
  'Ostrava hl. n.',
  'Plzeň hl. n.',
  'Olomouc hl. n.',
  'Pardubice hl. n.',
  'Praha-Smíchov',
  'České Budějovice',
  'Hradec Králové hl. n.',
  'Ústí nad Labem hl. n.',
  'Liberec',
  'Zlín střed',
  'Česká Třebová',
  'Kolín',
  'Jihlava',
  'Cheb',
  'Chomutov',
  'Děčín hl. n.',
];

// Pomocné funkce pro pozdější kroky. Počítadla ukazují, kolikrát se opravdu spustily.
let timetableLoads = 0;
let travelCalls = 0;

  timetableLoads += 1;

  'Praha hl. n.': 0,

  'Pardubice hl. n.': 104,
  'Česká Třebová': 164,
  'Olomouc hl. n.': 252,
  'Ostrava hl. n.': 356,
  'Plzeň hl. n.': 114,
  Cheb: 220,
};

function travelMinutes(from, to) {
  travelCalls += 1;
  const km = Math.abs(kmFromPrague[from] - kmFromPrague[to]);
  return Math.round((km / 96) * 60);

// Stanice, které obsahují dotaz, bez ohledu na velikost písmen.
function findStations(names, query) {
  const needle = query.toLowerCase();
  return names.filter((name) => name.toLowerCase().includes(needle));
}

console.log(findStations(stations, 'praha'));

// Nové pole stanic seřazené podle české abecedy.
function sortStations(names) {
  return names.toSorted((a, b) => a.localeCompare(b, 'cs'));
}

console.log(sortStations(findStations(stations, 'hl. n.')));
