# --description--

Přehrávač se bude ovládat i klávesnicí. Každá klávesa dostane funkci, kterou stránka zavolá, když ji uživatel stiskne. Stránka zavolá funkci **samotnou**, třeba `handler()`, ne přes objekt přehrávače.

**Úkol:** Pod objekt `player` založ konstantu `shortcuts`, objekt se třemi klíči:

- `ArrowRight` — funkce, která přepne na další díl,
- `ArrowLeft` — funkce, která přepne na předchozí díl,
- `k` — funkce, která přepne přehrávání.

Funkce musí fungovat i tehdy, když je stránka vytáhne z objektu a zavolá bez tečky. Jak to zařídíš, je na tobě.

# --hints--

Zkratky přepínají díly přehrávače.

```js
player.current = 0;
shortcuts.ArrowRight();
assert.equal(player.current, 1, 'po shortcuts.ArrowRight() má být player.current 1');
shortcuts.ArrowLeft();
shortcuts.ArrowLeft();
assert.equal(player.current, 3, 'po dvou shortcuts.ArrowLeft() z pozice 1 má být player.current 3');
```

Zkratka `k` přepne přehrávání.

```js
player.playing = false;
shortcuts.k();
assert.equal(player.playing, true, 'po shortcuts.k() má přehrávač hrát');
```

Zkratky fungují i vytažené z objektu a zavolané bez tečky.

```js
player.current = 0;
player.playing = false;
const { ArrowRight, k } = shortcuts;
ArrowRight();
k();
assert.equal(player.current, 1, 'ArrowRight zavolaná samostatně má přepnout na další díl — neztrácí se this?');
assert.equal(player.playing, true, 'k zavolaná samostatně má spustit přehrávání');
```

# --help--

## --tip--

Stránka funkci zavolá bez objektu — viz [Ztracené `this` v callbacku](see:js-funkce-hloubka/this#ztracene-this-v-callbacku).

## --tip--

Hodnotou klíče nesmí být samotná metoda přehrávače. Potřebuješ funkci, která metodu zavolá přes tečku na `player`, nebo funkci s natrvalo přivázaným `this`.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. objekt shortcuts se třemi klíči
// 2. každý klíč: funkce, která zavolá správnou metodu přehrávače
// 3. ověř: vytáhni funkci z objektu a zavolej ji samotnou
```

'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.

  current: 1,
};

const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  previous() {
    this.current = (this.current - 1 + this.episodes.length) % this.episodes.length;
    return this;
  },

    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
  // Od kolegy: přepne přehrávání a vrátí nový stav.
  toggle() {
    this.playing = !this.playing;
    return this.playing;
  },
  episodeTitles() {
    return this.episodes.map((episode, index) => (index === this.current ? `▶ ${episode.title}` : episode.title));
  },
  startSleepTimer(ms) {

    this.sleepTimer = setTimeout(() => {
      this.pause();
    }, ms);
    return this;
  },
};

console.log(player.episodeTitles());
