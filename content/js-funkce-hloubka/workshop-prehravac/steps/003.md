# --description--

Podívej se na metody `play` a `pause`. Nemění `player.playing`, ale `this.playing`. Když zavoláš `player.play()`, stojí před tečkou `player`, a proto je `this` uvnitř právě `player`.

**Úkol:** Do objektu `player` přidej metodu `currentEpisode()`, která vrátí díl z pole `episodes` přehrávače na pozici `current`. Používej `this`, ne jméno `player`.

Proč na tom záleží? Metodu pak jde použít i pro jiný objekt se stejnými klíči, třeba pro oblíbené díly jiného posluchače. Na jiných datech:

```js
const quiz = {
  questions: ['Hlavní město?', 'Nejvyšší hora?'],
  position: 1,
  // 1. metoda čte data objektu, na kterém ji voláš
  currentQuestion() {
    return this.questions[this.position];
  },
};
```

Pod objekt si vypiš `player.currentEpisode()`.

# --hints--

`player.currentEpisode()` vrátí díl na pozici `player.current`.

```js
player.current = 0;
assert.equal(player.currentEpisode(), episodes[0], 'při current 0 má player.currentEpisode() vrátit první díl');
player.current = 2;
assert.equal(player.currentEpisode(), episodes[2], 'při current 2 má player.currentEpisode() vrátit díl Tajemství kávy');
```

Metoda čte data objektu, na kterém ji voláš, ne natvrdo z `player`.

```js
const other = { episodes: [episodes[3], episodes[1]], current: 1, currentEpisode: player.currentEpisode };
assert.equal(other.currentEpisode(), episodes[1], 'currentEpisode volaná přes jiný objekt má vrátit díl z jeho pole — používáš this?');
```

# --explain--

Vysvětli vlastními slovy, co je `this` při volání `player.currentEpisode()` a proč metoda s `this` funguje i pro jiný objekt.

## --model--

`this` se určí při volání podle objektu před tečkou. Při `player.currentEpisode()` je to `player`, takže `this.episodes` a `this.current` čtou data přehrávače. Kdybych napsal přímo `player.episodes`, metoda by pro jiný objekt pořád četla přehrávač. S `this` vrátí díl z objektu, na kterém ji zavolám, třeba z oblíbených dílů.

## --checklist--

- `this` se určuje při volání podle objektu před tečkou.
- Při `player.currentEpisode()` je `this` objekt `player`.
- Jméno `player` v metodě by ji natvrdo přivázalo k jednomu objektu.
- S `this` metoda čte data objektu, na kterém ji zavolám.

## --file-- script.js

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
  },
  pause() {
    this.playing = false;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
};

console.log(player.currentEpisode());

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));
```
