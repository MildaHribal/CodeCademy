# --description--

Tlačítko Další bude chtít díl přepnout a hned ho pustit. Bylo by hezké napsat to na jeden řádek: `player.next().play().nowPlaying()`.

**Úkol:** Uprav metody `play`, `pause` a `next` tak, aby vracely **objekt, na kterém je voláš**. Tomu se říká řetězení metod: každé další volání pak stojí zase na tom objektu.

Stačí na konec metody přidat `return this;`. Na jiných datech:

```js
const order = {
  items: [],
  add(item) {
    this.items.push(item);
    // 1. vrácený objekt umožní další .add(…)
    return this;
  },
};

order.add('káva').add('croissant');
```

Vypiš si výsledek `player.next().play().nowPlaying()`.

# --hints--

`play`, `pause` a `next` vracejí objekt, na kterém je voláš.

```js
assert.equal(player.play(), player, 'player.play() má vrátit player');
assert.equal(player.pause(), player, 'player.pause() má vrátit player');
assert.equal(player.next(), player, 'player.next() má vrátit player');
```

Metody jde řetězit a pořád pracují s přehrávačem.

```js
player.current = 0;
player.playing = false;
assert.equal(player.next().play().nowPlaying(), 'Hraje: Jak se staví most (43:35)', "player.next().play().nowPlaying() z prvního dílu má vrátit 'Hraje: Jak se staví most (43:35)'");
```

Metody vracejí objekt, na kterém je voláš, i když je to jiný objekt.

```js
const other = { episodes: [episodes[0], episodes[1]], current: 0, playing: false, next: player.next, play: player.play };
assert.equal(other.next().play(), other, 'next a play volané přes jiný objekt mají vrátit ten objekt — vracíš this?');
assert.equal(other.playing, true, 'other.next().play() má nastavit other.playing na true');
```

# --explain--

Vysvětli vlastními slovy, proč v `player.next().play()` pracuje `play` se stejným přehrávačem jako `next`.

## --model--

`next` na konci vrací `this`, a protože se volá přes tečku na `player`, vrátí právě objekt `player`. Výraz `player.next()` má tedy hodnotu `player` a `.play()` se volá na něm, takže i v `play` je `this` přehrávač. Kdyby `next` nic nevracela, výraz by byl `undefined` a volání `.play()` by spadlo.

## --checklist--

- `next` vrací `this`, tedy objekt, na kterém byla zavolaná.
- Výsledek `player.next()` je znovu objekt `player`.
- Další metoda se volá přes tečku na vráceném objektu, takže má stejné `this`.
- Bez `return this` by výsledek byl `undefined` a řetězení by spadlo.

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.

  episodes,
  current: 0,
  playing: false,
  queue: [],

    this.current = (this.current + 1) % this.episodes.length;

'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },

    const state = this.playing ? 'Hraje' : 'Pozastaveno';
