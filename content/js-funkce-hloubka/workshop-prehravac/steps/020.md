# --description--

Poslední krok. Pod tlačítky je `Usnout za 2 s`.

**Úkol:** Kliknutí na `#sleep` spustí přehrávání, stránku hned překreslí a nastaví časovač usínání na 2 sekundy. Když časovač doběhne, přehrávač se pozastaví **a stránka to ukáže**: nadpis začne `Pozastaveno:` a tlačítko `#toggle` ukáže `Přehrát`.

Časovač už máš v `startSleepTimer`. Zatím jen mění stav, stránku nepřekreslí.

Tím je přehrávač hotový. Za sebou máš:

- metody, které čtou a mění objekt přes `this`, a řetězení přes `return this`,
- šipkové funkce jako callbacky uvnitř metod (`map`, `setTimeout`),
- tři kolegovy pasti: šipkovou funkci jako metodu, metodu předanou `forEach` a metodu předanou posluchači,
- `call` pro vypůjčenou metodu,
- tlačítka a klávesové zkratky, které `this` neztratí.

Stejné pasti potkáš v každé knihovně s objekty a třídami. V Reactu ve starších třídních komponentách je `this.handleClick = this.handleClick.bind(this)` přesně oprava z tohoto workshopu.

## Udělej po svém

- **Průběh dílu:** přidej pod nadpis pruh, který se po spuštění plynule plní (`transition` na šířce) a při pauze se zastaví.
- **Hlasitost:** přidej `<input type="range">` a metodu `setVolume(value)`, která hlasitost omezí na 0–1 a vrátí `this`.
- **Fronta v seznamu:** vedle každého dílu tlačítko „Později", které zavolá `enqueue`, a díly ve frontě označ.
- **Jiné téma:** přeměň přehrávač na prohlížeč fotek, kvíz nebo rádio se stanicemi. Metody s `this` zůstanou stejné.

Příště funkcionální styl: jak skládat malé čisté funkce a jak projít strom dat rekurzí.

# --hints--

Kliknutí na `#sleep` spustí přehrávání a hned překreslí stránku.

```js
player.current = 0;
player.playing = false;
player.render();
await helpers.click(document.querySelector('#sleep'));
assert.equal(player.playing, true, 'po kliknutí na #sleep má přehrávač hrát');
assert.equal(document.querySelector('#now-playing').textContent, 'Hraje: Proč nás baví hudba (30:40)', "hned po kliknutí na #sleep má #now-playing začínat 'Hraje:'");
```

Po dvou sekundách se přehrávač pozastaví a stránka to ukáže.

```js
player.current = 0;
player.playing = false;
player.render();
await helpers.click(document.querySelector('#sleep'));
await helpers.wait(2400);
assert.equal(player.playing, false, 'po 2 sekundách má být přehrávač pozastavený');
assert.equal(document.querySelector('#now-playing').textContent, 'Pozastaveno: Proč nás baví hudba (30:40)', "po doběhnutí časovače má #now-playing začínat 'Pozastaveno:'");
assert.equal(document.querySelector('#toggle').textContent.trim(), 'Přehrát', "po doběhnutí časovače má #toggle ukazovat 'Přehrát'");
```

# --help--

## --tip--

Časovač volá šipkovou funkci, která má `this` přehrávače — viz [Šipková funkce nemá vlastní `this`](see:js-funkce-hloubka/this#sipkova-funkce-nema-vlastni-this).

## --tip--

Ve funkci, kterou časovač v `startSleepTimer` zavolá, po pozastavení překresli stránku (`pause` vrací přehrávač). Posluchač tlačítka zavolá `play`, `render` a `startSleepTimer`.

## --tip--

Porovnej s tlačítkem Další: posluchač zase jen skládá metody přehrávače přes tečku.

const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },

  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  previous() {
    this.current = (this.current - 1 + this.episodes.length) % this.episodes.length;
    return this;
  },
  nowPlaying() {
    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
  // Od kolegy: přepne přehrávání a vrátí nový stav.
  toggle() {
    this.playing = !this.playing;
    return this.playing;
  },
  episodeTitles() {
    return this.episodes.map((episode, index) => (index === this.current ? `▶ ${episode.title}` : episode.title));
  },
  startSleepTimer(ms) {
    clearTimeout(this.sleepTimer);
    this.sleepTimer = setTimeout(() => {
      this.pause();
    }, ms);
    return this;
  },
  enqueue(id) {
    if (!this.queue.includes(id)) {
      this.queue.push(id);
    }
    return this;
  },
  render() {
    document.querySelector('#now-playing').textContent = this.nowPlaying();
    const items = this.episodeTitles().map((title, index) => {
      const item = document.createElement('li');
      item.textContent = title;
      item.classList.toggle('is-current', index === this.current);
      return item;
    });
    document.querySelector('#episode-list').replaceChildren(...items);
    document.querySelector('#toggle').textContent = this.playing ? 'Pauza' : 'Přehrát';
    return this;
  },
};
