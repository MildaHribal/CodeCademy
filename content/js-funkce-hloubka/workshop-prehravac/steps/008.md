# --description--

Pod přehrávačem bude seznam všech dílů a aktuální díl v něm bude označený.

**Úkol:** Přidej metodu `episodeTitles()`, která vrátí pole názvů všech dílů přehrávače ve stejném pořadí. Název aktuálního dílu začíná znakem `▶` a mezerou: `'▶ Tajemství kávy'`. Ostatní názvy zůstanou beze změny.

Pole názvů vyrobí `map` nad `this.episodes`. Jenže callback uvnitř potřebuje znát `this.current`, a to je `this` metody, ne callbacku. Kandidáti na callback:

- obyčejná funkce `function (episode, index) { … }`,
- šipková funkce `(episode, index) => …`.

Jen jedna z nich uvidí `this` přehrávače. Znak `▶` si zkopíruj ze zadání.

# --hints--

`episodeTitles()` vrátí názvy dílů a aktuální označí znakem `▶`.

```js
player.current = 1;
assert.deepEqual(
  player.episodeTitles(),
  ['Proč nás baví hudba', '▶ Jak se staví most', 'Tajemství kávy', 'Život v Antarktidě'],
  "při current 1 má episodeTitles() vrátit názvy všech dílů s '▶ ' před Jak se staví most",
);
```

`episodeTitles()` pracuje s objektem, na kterém ji voláš.

```js
const other = { episodes: [episodes[3], episodes[1]], current: 0, episodeTitles: player.episodeTitles };
assert.deepEqual(other.episodeTitles(), ['▶ Život v Antarktidě', 'Jak se staví most'], 'episodeTitles() přes jiný objekt má označit jeho aktuální díl');
```

# --help--

## --tip--

Callback uvnitř metody potřebuje `this` metody — viz [Šipková funkce nemá vlastní `this`](see:js-funkce-hloubka/this#sipkova-funkce-nema-vlastni-this).

## --tip--

V `map` dostane callback díl i jeho index. Když se index shoduje s `this.current`, vrať název s předponou, jinak samotný název.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. metoda vrátí výsledek map nad díly přehrávače
// 2. callback dostane díl a index a this převezme z metody
// 3. u indexu aktuálního dílu přidej předponu, jinak vrať samotný název
```

# --explain--

Vysvětli vlastními slovy, proč callback v `map` uvnitř `episodeTitles` vidí `this.current`, jen když je to šipková funkce.

## --model--

`this` se u obyčejné funkce určuje při každém volání. `map` volá callback sám, bez objektu před tečkou, takže obyčejná `function` by měla `this` `undefined` a čtení `this.current` by spadlo. Šipková funkce vlastní `this` nemá a vezme ho z místa, kde vznikla — z metody `episodeTitles`, která se volá přes tečku na přehrávači. Proto v ní `this.current` patří přehrávači.

## --checklist--

- `map` volá callback bez objektu před tečkou.
- Obyčejná funkce má vlastní `this`, které by tu bylo `undefined`.
- Šipková funkce nemá vlastní `this` a bere ho z místa vzniku.
- Místo vzniku je metoda volaná přes tečku na přehrávači.

## --file-- script.js

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  nowPlaying() {
    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
  // Od kolegy: přepne přehrávání a vrátí nový stav.
  toggle() {
    this.playing = !this.playing;
    return this.playing;
  },
  episodeTitles() {
    return this.episodes.map((episode, index) => (index === this.current ? `▶ ${episode.title}` : episode.title));
  },
};

console.log(player.episodeTitles());

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));
```
