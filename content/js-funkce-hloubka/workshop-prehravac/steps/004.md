# --description--

**Úkol:** Přidej metodu `next()`, která posune `current` na další díl. Po posledním dílu se vrátí na první.

Návrat na začátek zařídí zbytek po dělení: `(číslo + 1) % délka` dá postupně `1`, `2`, `3` a po poslední pozici zase `0`. Na jiných datech:

```js
const carousel = {
  slides: ['Léto', 'Podzim', 'Zima'],
  index: 0,
  // 1. posune se o jednu, za koncem začne od nuly
  forward() {
    this.index = (this.index + 1) % this.slides.length;
  },
};
```

Metoda mění data přes `this`, takže ji zkus v konzoli: `player.next()` a pak `player.currentEpisode().title`.

# --hints--

`next()` posune `current` o jedna.

```js
player.current = 0;
player.next();
assert.equal(player.current, 1, 'po player.next() z pozice 0 má být current 1');
player.next();
assert.equal(player.current, 2, 'po dalším player.next() má být current 2');
```

Po posledním dílu se `next()` vrátí na první.

```js
player.current = 3;
player.next();
assert.equal(player.current, 0, 'po player.next() z posledního dílu (current 3) má být current 0');
```

`next()` pracuje s objektem, na kterém ji voláš.

```js
const other = { episodes: [episodes[0], episodes[1]], current: 1, next: player.next };
other.next();
assert.equal(other.current, 0, 'next() volaná na objektu se dvěma díly má z pozice 1 přejít na 0 — počítá s this.episodes.length?');
assert.equal(player.current !== undefined, true, 'player.current má zůstat číslo');
```

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
  },
  pause() {
    this.playing = false;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
  },
};

console.log(player.currentEpisode());

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));
```
