# --description--

**Úkol:** Napiš funkci `totalDuration(list)`, která vrátí součet délek (`duration`) všech dílů v poli. Prázdné pole má délku `0`.

Vypiš si celkovou délku podcastu ve tvaru z minulého kroku.

# --hints--

`totalDuration` sečte délky dílů.

```js
const list = [{ title: 'A', duration: 600 }, { title: 'B', duration: 125 }];
assert.equal(totalDuration(list), 725, 'totalDuration pro díly 600 s a 125 s má vrátit 725');
```

Prázdné pole má délku `0`.

```js
assert.equal(totalDuration([]), 0, 'totalDuration([]) má vrátit 0');
```

# --help--

## --tip--

Z pole děláš jednu hodnotu — viz [Jak pracuje `reduce`](see:js-pole/metody-pole-do-hloubky#jak-pracuje-reduce).

## --tip--

Nezapomeň na počáteční hodnotu akumulátoru. Bez ní spadne prázdné pole.

## --tip--

Porovnej s cenou nákupu z nákupního seznamu: stejný tvar, jen jiný klíč.

# --solution--

## --file-- script.js

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
  },
  pause() {
    this.playing = false;
  },
};

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));
```
