# --description--

Posluchač si může díly přidat do fronty „Přehrát později".

**Úkol:** Přidej metodu `enqueue(id)`, která přidá `id` dílu na konec pole `queue` přehrávače. Když už ve frontě je, nepřidá ho podruhé. Metoda vrací objekt, na kterém ji voláš, aby šla řetězit.

Pole `queue` už v objektu je. Kandidáti na kontrolu duplicity: `includes`, `indexOf`, nebo `some`.

# --hints--

`enqueue` přidá id na konec fronty a jde řetězit.

```js
player.queue = [];
assert.equal(player.enqueue(3), player, 'player.enqueue(3) má vrátit player');
player.enqueue(1);
assert.deepEqual(player.queue, [3, 1], 'po enqueue(3) a enqueue(1) má být fronta [3, 1]');
```

Id, které ve frontě už je, se nepřidá znovu.

```js
player.queue = [];
player.enqueue(2).enqueue(2).enqueue(4);
assert.deepEqual(player.queue, [2, 4], 'po enqueue(2), enqueue(2), enqueue(4) má být fronta [2, 4]');
```

`enqueue` pracuje s frontou objektu, na kterém ji voláš.

```js
player.queue = [];
const other = { queue: [], enqueue: player.enqueue };
other.enqueue(9);
assert.deepEqual(other.queue, [9], 'enqueue(9) přes jiný objekt má přidat do jeho fronty');
assert.deepEqual(player.queue, [], 'fronta přehrávače se nemá změnit');
```

# --help--

## --tip--

Frontu čteš i měníš přes objekt před tečkou — viz [`this` je objekt před tečkou](see:js-funkce-hloubka/this#this-je-objekt-pred-teckou).

## --tip--

Když fronta id ještě neobsahuje, přidej ho na konec. V každém případě vrať `this`.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. zjisti, jestli fronta objektu před tečkou id už obsahuje
// 2. když ne, přidej ho na konec
// 3. vrať objekt, na kterém metodu voláš
```

const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },

  episodes,
  current: 0,
  playing: false,
  queue: [],

    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  previous() {
    this.current = (this.current - 1 + this.episodes.length) % this.episodes.length;
    return this;
  },
  nowPlaying() {
    const episode = this.currentEpisode();

  },
  episodeTitles() {

  },
  startSleepTimer(ms) {
    clearTimeout(this.sleepTimer);
    this.sleepTimer = setTimeout(() => {
      this.pause();
    }, ms);
    return this;
  },
  enqueue(id) {
    if (!this.queue.includes(id)) {
      this.queue.push(id);
    }
    return this;
  },
};

console.log(player.episodeTitles());
