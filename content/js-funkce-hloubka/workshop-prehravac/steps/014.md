# --description--

Na začátku souboru je objekt `favorites`: oblíbené díly jiného posluchače. Má stejné klíče `episodes` a `current` jako přehrávač, ale žádné metody. Metodu `currentEpisode` kvůli němu nechceš kopírovat.

**Úkol:** Napiš funkci `favoriteEpisode()`, která vrátí aktuální díl z objektu `favorites`. Použij k tomu metodu `currentEpisode` přehrávače, ale s `this` nastaveným na `favorites`. Přehrávač se přitom nesmí změnit.

Kandidáti, jak metodě určit `this`: `call`, `apply`, nebo `bind`. Dva z nich funkci rovnou zavolají, třetí vrátí novou funkci, kterou musíš ještě zavolat.

Tím je hotová logika přehrávače. Klidně si dej pauzu, v dalším kroku přibude stránka.

# --hints--

`favoriteEpisode()` vrátí aktuální díl oblíbených.

```js
favorites.current = 1;
assert.equal(favoriteEpisode(), episodes[1], 'při favorites.current 1 má favoriteEpisode() vrátit díl Jak se staví most');
favorites.current = 0;
assert.equal(favoriteEpisode(), episodes[3], 'při favorites.current 0 má favoriteEpisode() vrátit díl Život v Antarktidě');
```

`favoriteEpisode()` nemění přehrávač a nepřidává oblíbeným metody.

```js
player.current = 2;
favoriteEpisode();
assert.equal(player.current, 2, 'favoriteEpisode() nesmí změnit player.current');
assert.equal('currentEpisode' in favorites, false, 'favoriteEpisode() nemá do favorites přidávat metodu currentEpisode');
```

`favoriteEpisode()` používá metodu `currentEpisode` přehrávače.

```js
const source = helpers.stripComments(favoriteEpisode.toString(), 'js');
assert.match(source, /currentEpisode/, 'favoriteEpisode má použít metodu player.currentEpisode');
```

# --help--

## --tip--

Jde o určení `this` ručně — viz [`call`, `apply` a `bind`](see:js-funkce-hloubka/this#call-apply-a-bind-this-natvrdo).

## --tip--

Metodu vezmi z přehrávače bez závorek a zavolej ji přes `call` s `favorites` jako prvním argumentem.

## --tip--

Na jiných datech: `quiz.currentQuestion.call(otherQuiz)` vrátí otázku z druhého kvízu.

'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  previous() {
    this.current = (this.current - 1 + this.episodes.length) % this.episodes.length;
    return this;
  },
  nowPlaying() {
    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
  // Od kolegy: přepne přehrávání a vrátí nový stav.
  toggle() {
    this.playing = !this.playing;
    return this.playing;
  },
  episodeTitles() {
    return this.episodes.map((episode, index) => (index === this.current ? `▶ ${episode.title}` : episode.title));
  },
  startSleepTimer(ms) {
    clearTimeout(this.sleepTimer);
    this.sleepTimer = setTimeout(() => {
      this.pause();
    }, ms);
    return this;
  },
  enqueue(id) {
    if (!this.queue.includes(id)) {
      this.queue.push(id);
    }
    return this;
  },
};

console.log(player.episodeTitles());

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));

  ArrowRight: () => player.next(),
  ArrowLeft: () => player.previous(),
  k: () => player.toggle(),
};

// Od kolegy: přidá do fronty celou sérii dílů.
function enqueueAll(ids) {
  ids.forEach((id) => player.enqueue(id));
}
