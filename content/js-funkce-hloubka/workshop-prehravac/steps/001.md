# --description--

Přehrávač podcastů má každá streamovací služba: název dílu, tlačítka Předchozí, Přehrát a Další, seznam dílů a klávesové zkratky. Uvnitř je to typicky **objekt s metodami**, které pracují s `this`. V tomhle workshopu takový přehrávač postavíš, nejdřív v konzoli, v posledních krocích i se stránkou, tlačítky a klávesnicí.

V `script.js` jsou díly podcastu, objekt `favorites` pro pozdější krok a objekt `player` s prvními dvěma metodami. Soubor začíná řádkem `'use strict'`, takže se chová jako moderní modul: ztracené `this` je `undefined`.

Začneš něčím, co už umíš, a bez návodu.

**Úkol:** Pod objekt `player` napiš funkci `formatTime(seconds)`, která vrátí čas ve tvaru minuty, dvojtečka a sekundy doplněné na dvě číslice: `1840` → `'30:40'`, `65` → `'1:05'`. Minuty se na hodiny nepřevádějí.

Pod funkci si vypiš `formatTime(1840)`.

# --hints--

`formatTime` vrátí minuty a dvoumístné sekundy.

```js
assert.equal(formatTime(1840), '30:40', "formatTime(1840) má vrátit '30:40'");
assert.equal(formatTime(65), '1:05', "formatTime(65) má vrátit '1:05' — sekundy vždy dvoumístné");
```

Minuty nad šedesát zůstávají minutami a nula má tvar `0:00`.

```js
assert.equal(formatTime(3005), '50:05', "formatTime(3005) má vrátit '50:05'");
assert.equal(formatTime(7260), '121:00', "formatTime(7260) má vrátit '121:00' — hodiny se nepřevádějí");
assert.equal(formatTime(0), '0:00', "formatTime(0) má vrátit '0:00'");
```

# --help--

## --tip--

Celé minuty spočítá dělení se zaokrouhlením dolů, zbytek sekund operátor `%` — viz [Zaokrouhlení](see:js-retezce-cisla/cisla#zaokrouhleni-round-floor-ceil-a-trunc).

## --tip--

Sekundy převeď na text a doplň zleva nulou na dvě místa metodou řetězce `padStart`.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. celé minuty
// 2. zbylé sekundy jako text se dvěma číslicemi
// 3. vrať minuty, dvojtečku a sekundy
```

# --solution--

## --file-- script.js

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
  },
  pause() {
    this.playing = false;
  },
};

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));
```
