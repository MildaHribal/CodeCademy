# --description--

Tenhle krok je bez návodu.

**Úkol:** Přidej metodu `previous()`, která posune `current` na předchozí díl. Z prvního dílu přejde na poslední. Stejně jako `next` vrací objekt, na kterém ji voláš.

# --hints--

`previous()` posune `current` o jedna zpět.

```js
player.current = 2;
player.previous();
assert.equal(player.current, 1, 'po player.previous() z pozice 2 má být current 1');
```

Z prvního dílu přejde `previous()` na poslední.

```js
player.current = 0;
player.previous();
assert.equal(player.current, 3, 'po player.previous() z prvního dílu má být current 3');
```

`previous()` vrací objekt, na kterém ji voláš, a pracuje s jeho díly.

```js
const other = { episodes: [episodes[0], episodes[1]], current: 0, previous: player.previous };
assert.equal(other.previous(), other, 'previous() má vrátit objekt, na kterém ji voláš');
assert.equal(other.current, 1, 'previous() na objektu se dvěma díly má z pozice 0 přejít na 1');
```

# --help--

## --tip--

Stejně jako `next` — viz [`this` je objekt před tečkou](see:js-funkce-hloubka/this#this-je-objekt-pred-teckou).

## --tip--

Zbytek po dělení záporného čísla je v JavaScriptu záporný: `-1 % 4` je `-1`. Než ho spočítáš, přičti k pozici délku pole.

## --tip--

Porovnej zadání se svou metodou `next`: liší se jen směrem posunu.

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

--edit--
// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  nowPlaying() {
    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
  // Od kolegy: přepne přehrávání a vrátí nový stav.
  toggle() {
    this.playing = !this.playing;
    return this.playing;
  },
  episodeTitles() {
    return this.episodes.map((episode, index) => (index === this.current ? `▶ ${episode.title}` : episode.title));
  },
};

console.log(player.episodeTitles());
--edit--

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));
```

```js
const player = {
  episodes,

  playing: false,

    return this.episodes[this.current];
```
