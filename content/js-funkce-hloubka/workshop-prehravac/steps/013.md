# --description--

## Hlášení

Kolega přidal na konec souboru funkci `enqueueAll(ids)` pro tlačítko „Přidat celou sérii do fronty". Po kliknutí se do fronty nepřidá nic a konzole hlásí:

`TypeError: Cannot read properties of undefined (reading 'queue')`

Když stejná id přidáš ručně přes `player.enqueue(2)`, všechno funguje.

## Úkol

Oprav `enqueueAll` tak, aby přidala do fronty přehrávače všechna id z pole. Změň co nejmenší kus kódu.

# --hints--

`enqueueAll` přidá do fronty přehrávače všechna id.

```js
player.queue = [];
enqueueAll([2, 3, 4]);
assert.deepEqual(player.queue, [2, 3, 4], 'po enqueueAll([2, 3, 4]) má být fronta přehrávače [2, 3, 4]');
```

Duplicity se dál nepřidávají.

```js
player.queue = [1];
enqueueAll([1, 2, 2]);
assert.deepEqual(player.queue, [1, 2], 'po enqueueAll([1, 2, 2]) nad frontou [1] má být fronta [1, 2]');
```

# --help--

## --tip--

Chyba odpovídá pasti [Metoda předaná jako callback](see:js-funkce-hloubka/this#metoda-predana-jako-callback).

## --tip--

Jak `forEach` volá funkci, kterou dostal? Stojí při tom volání před tečkou nějaký objekt?

## --tip--

Na jiných datech by oprava vypadala takhle: `names.forEach((name) => guestbook.sign(name))` místo `names.forEach(guestbook.sign)`.

# --explain--

Vysvětli vlastními slovy, proč `ids.forEach(player.enqueue)` skončilo chybou `Cannot read properties of undefined (reading 'queue')`.

## --model--

`player.enqueue` bez závorek předá `forEach` jen samotnou funkci, bez přehrávače. `forEach` ji pak volá pro každé id jako obyčejnou funkci, bez objektu před tečkou. Soubor běží ve strict mode, takže `this` je v tu chvíli `undefined` a čtení `this.queue` spadne. Oprava je předat šipkovou funkci, která `enqueue` zavolá přes tečku na `player`.

## --checklist--

- `player.enqueue` bez závorek předá jen funkci, ne objekt.
- `forEach` volá callback bez objektu před tečkou.
- Ve strict mode je pak `this` `undefined`.
- Čtení `this.queue` z `undefined` vyhodí `TypeError`.
- Oprava je šipková funkce, nebo `bind`.

'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
    return this;
  },
  pause() {
    this.playing = false;
    return this;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
    return this;
  },
  previous() {
    this.current = (this.current - 1 + this.episodes.length) % this.episodes.length;
    return this;
  },
  nowPlaying() {
    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
  // Od kolegy: přepne přehrávání a vrátí nový stav.
  toggle() {
    this.playing = !this.playing;
    return this.playing;
  },
  episodeTitles() {
    return this.episodes.map((episode, index) => (index === this.current ? `▶ ${episode.title}` : episode.title));
  },
  startSleepTimer(ms) {
    clearTimeout(this.sleepTimer);
    this.sleepTimer = setTimeout(() => {
      this.pause();
    }, ms);
    return this;
  },
  enqueue(id) {
    if (!this.queue.includes(id)) {
      this.queue.push(id);
    }
    return this;
  },
};

console.log(player.episodeTitles());

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));

// Klávesové zkratky: stránka zavolá funkci samotnou, bez objektu.
const shortcuts = {
  ArrowRight: () => player.next(),
  ArrowLeft: () => player.previous(),
  k: () => player.toggle(),
};

// Od kolegy: přidá do fronty celou sérii dílů.
function enqueueAll(ids) {
  ids.forEach(player.enqueue);
}
