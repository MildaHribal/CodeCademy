# --description--

Nad tlačítky bude text, co právě hraje.

**Úkol:** Přidej metodu `nowPlaying()`, která vrátí text podle stavu přehrávače:

- když hraje: `'Hraje: Tajemství kávy (22:05)'`,
- když nehraje: `'Pozastaveno: Tajemství kávy (22:05)'`.

V závorce je délka dílu ve tvaru z `formatTime`. Díl si metoda vezme z `currentEpisode()`. **Metoda může volat jinou metodu téhož objektu přes `this`**: když se `nowPlaying` volá přes tečku na přehrávači, je `this` přehrávač, a tak `this.currentEpisode()` je zase volání přes tečku. Na jiných datech:

```js
const quiz = {
  questions: ['Hlavní město?', 'Nejvyšší hora?'],
  position: 0,
  currentQuestion() {
    return this.questions[this.position];
  },
  // 1. jiná metoda téhož objektu přes this
  headline() {
    return `Otázka ${this.position + 1}: ${this.currentQuestion()}`;
  },
};
```

Vypiš si `player.nowPlaying()`.

# --hints--

`nowPlaying()` vrátí název a délku aktuálního dílu s popisem stavu.

```js
player.current = 2;
player.playing = true;
assert.equal(player.nowPlaying(), 'Hraje: Tajemství kávy (22:05)', "při current 2 a playing true má nowPlaying() vrátit 'Hraje: Tajemství kávy (22:05)'");
player.playing = false;
assert.equal(player.nowPlaying(), 'Pozastaveno: Tajemství kávy (22:05)', "při playing false má nowPlaying() vrátit 'Pozastaveno: Tajemství kávy (22:05)'");
```

`nowPlaying()` pracuje s objektem, na kterém ji voláš.

```js
const other = {
  episodes: [{ id: 9, title: 'Bonus', duration: 65 }],
  current: 0,
  playing: true,
  currentEpisode: player.currentEpisode,
  nowPlaying: player.nowPlaying,
};
assert.equal(other.nowPlaying(), 'Hraje: Bonus (1:05)', "nowPlaying() volaná přes jiný objekt s dílem Bonus (65 s) má vrátit 'Hraje: Bonus (1:05)'");
```

## --file-- script.js

```js
'use strict';

// Díly podcastu Svět kolem nás. Délka (duration) je v sekundách.
const episodes = [
  { id: 1, title: 'Proč nás baví hudba', duration: 1840 },
  { id: 2, title: 'Jak se staví most', duration: 2615 },
  { id: 3, title: 'Tajemství kávy', duration: 1325 },
  { id: 4, title: 'Život v Antarktidě', duration: 3005 },
];

// Oblíbené díly jiného posluchače: stejné klíče jako přehrávač, ale žádné metody.
const favorites = {
  episodes: [episodes[3], episodes[1]],
  current: 1,
};

// Přehrávač. Metody play a pause už fungují, další přidáš v krocích.
const player = {
  episodes,
  current: 0,
  playing: false,
  queue: [],
  play() {
    this.playing = true;
  },
  pause() {
    this.playing = false;
  },
  currentEpisode() {
    return this.episodes[this.current];
  },
  next() {
    this.current = (this.current + 1) % this.episodes.length;
  },
  nowPlaying() {
    const episode = this.currentEpisode();
    const state = this.playing ? 'Hraje' : 'Pozastaveno';
    return `${state}: ${episode.title} (${formatTime(episode.duration)})`;
  },
};

console.log(player.nowPlaying());

// Čas v sekundách jako minuty:sekundy, třeba 1840 → 30:40.
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const rest = String(seconds % 60).padStart(2, '0');
  return `${minutes}:${rest}`;
}

console.log(formatTime(1840));

// Celková délka dílů v sekundách.
function totalDuration(list) {
  return list.reduce((sum, episode) => sum + episode.duration, 0);
}

console.log('Celkem:', formatTime(totalDuration(episodes)));
```
