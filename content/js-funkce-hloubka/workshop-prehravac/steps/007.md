# --description--

## Hlášení

Kolega přidal do přehrávače metodu `toggle` pro tlačítko Přehrát/Pauza. Má přepnout `playing` na opak a vrátit nový stav.

`player.toggle()` vrátí poprvé `true`, podruhé `false`, jako by fungovala. Jenže `player.playing` zůstává pořád `false` a nápis „Pozastaveno" se nezmění. V konzoli žádná chyba není.

## Úkol

Oprav `toggle` tak, aby přepínala stav přehrávače, na kterém ji voláš, a vracela nový stav. Změň co nejmenší kus kódu.

# --hints--

`toggle()` přepne `playing` přehrávače a vrátí nový stav.

```js
player.playing = false;
assert.equal(player.toggle(), true, 'první player.toggle() má vrátit true');
assert.equal(player.playing, true, 'po player.toggle() má být player.playing true');
assert.equal(player.toggle(), false, 'druhé player.toggle() má vrátit false');
assert.equal(player.playing, false, 'po druhém toggle má být player.playing zase false');
```

Ostatní metody fungují dál.

```js
player.current = 0;
player.playing = false;
assert.equal(player.next().play().nowPlaying(), 'Hraje: Jak se staví most (43:35)', 'player.next().play().nowPlaying() má dál fungovat');
```

## --tip--

Odkud si šipková funkce bere `this`? A co je `this` přímo ve skriptu, mimo jakoukoli metodu?

## --tip--

Ověř hypotézu: pod objekt dočasně připiš `console.log(player.toggle(), player.playing, window.playing);`. Stav se zapsal jinam než do přehrávače. Zápis metody, ve kterém `this` určí objekt před tečkou, máš o kus výš u `play` a `pause`.

const player = {
  episodes,
  current: 0,
  playing: false,
