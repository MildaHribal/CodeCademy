# --description--

Než diskusi vykreslíš na stránku, vypiš ji do konzole jako odsazený text. Každá úroveň odpovědí je o dvě mezery dál:

```text
Jana Nováková: Podle tohohle receptu…
  Petr Svoboda: Dáváš do omáčky i brusinky?
    Jana Nováková: Brusinky jen na talíř…
```

Funkce potřebuje vědět, jak hluboko právě je. Dostane proto druhý parametr `depth` s výchozí hodnotou `0` a každé rekurzivní volání dostane `depth + 1`. Každé volání má svůj vlastní `depth`, takže když se vrátíš z odpovědí, jsi zase na správné úrovni.

**Úkol:** Napiš funkci `toLines(nodes, depth = 0)`, která vrátí **pole řádků**: pro každý uzel řádek `autor: text` odsazený `2 × depth` mezerami a hned za ním řádky jeho odpovědí. Vypiš si `toLines(thread).join('\n')`.

Hodí se `for…of` s `push`, nebo `flatMap` — funguje jako `map`, ale pole, která callback vrátí, slepí do jednoho. Na jiných datech — obsah knihy s kapitolami a podkapitolami:

```js
function outline(chapters, level = 0) {
  return chapters.flatMap((chapter) => [
    `${'#'.repeat(level + 1)} ${chapter.title}`,
    ...outline(chapter.sections, level + 1),
  ]);
}
```

# --hints--

`toLines` vrátí řádky stromu v pořadí vlákna, odsazené o dvě mezery na úroveň.

```js
const tree = [
  { author: 'Hana', text: 'Ahoj', replies: [
    { author: 'Ivo', text: 'Čau', replies: [{ author: 'Lea', text: 'Nazdar', replies: [] }] },
  ] },
  { author: 'Ota', text: 'Dobrý den', replies: [] },
];
assert.deepEqual(toLines(tree), ['Hana: Ahoj', '  Ivo: Čau', '    Lea: Nazdar', 'Ota: Dobrý den'], 'toLines(Hana > Ivo > Lea, Ota) má vrátit čtyři řádky s odsazením 0, 2, 4 a 0 mezer');
```

Zadaná hloubka posune odsazení všech řádků.

```js
const tree = [{ author: 'Ivo', text: 'Čau', replies: [{ author: 'Lea', text: 'Nazdar', replies: [] }] }];
assert.deepEqual(toLines(tree, 1), ['  Ivo: Čau', '    Lea: Nazdar'], 'toLines(Ivo > Lea, 1) má začít odsazením dvou mezer');
```

Prázdný strom vrátí prázdné pole.

```js
assert.deepEqual(toLines([]), [], 'toLines([]) má vrátit []');
```

# --explain--

Vysvětli vlastními slovy, proč se po výpisu hluboké odpovědi další komentář pod receptem vypíše zase bez odsazení, i když `depth` mezitím vyrostlo.

## --model--

Proměnná `depth` se nikde nemění. Každé volání `toLines` dostane vlastní parametr `depth` a rekurzivní volání pro odpovědi dostane novou hodnotu `depth + 1` ve svém vlastním rámci. Když vnořené volání doběhne a zmizí ze zásobníku volání, pokračuje vnější volání se svým původním `depth`. Proto další uzel na stejné úrovni dostane stejné odsazení jako předchozí.

## --checklist--

- Každé volání funkce má vlastní parametr `depth`.
- Rekurzivní volání dostane `depth + 1`, ale `depth` volajícího se nezmění.
- Po doběhnutí vnořeného volání pokračuje vnější volání se svou hodnotou.
- Rozpracovaná volání čekají v zásobníku volání.
