# --description--

Diskuse odsazuje odpovědi podle toho, jak hluboko ve vlákně jsou. Komentář pod receptem má hloubku `0`, odpověď na něj `1`, odpověď na odpověď `2`. Kolik to je, zjistíš jen tak, že půjdeš po rodičích nahoru — a nevíš předem, kolikrát.

Na to je [[rekurze]]: hloubka komentáře je o jedna větší než hloubka jeho rodiče. Rodič se hledá stejnou funkcí, dokud nedojdeš ke komentáři bez rodiče. To je [[základní případ]] — tam odpověď znáš hned.

**Úkol:** Napiš funkci `depthOf(comment, index)`, kde `index` je objekt komentářů podle `id` (jako tvůj `byId`). Komentář s `parentId: null` má hloubku `0`, jinak vrať `1 +` hloubku jeho rodiče. Vypiš si `depthOf(byId[8], byId)`.

Stejný vzor na jiných datech — úroveň kategorie v e-shopu:

```js
function levelOf(category, categoriesById) {
  // 1. základní případ: kategorie nejvyšší úrovně nemá rodiče
  if (category.parentId === null) {
    return 0;
  }
  // 2. rekurzivní případ: o jednu víc než rodič
  return 1 + levelOf(categoriesById[category.parentId], categoriesById);
}
```

# --hints--

Komentář přímo pod receptem má hloubku `0`.

```js
const index = { 5: { id: 5, parentId: null } };
assert.equal(depthOf(index[5], index), 0, 'depthOf(komentář s parentId null) má vrátit 0');
```

Odpověď má hloubku o jedna větší než její rodič, na libovolném počtu úrovní.

```js
const index = {
  1: { id: 1, parentId: null },
  2: { id: 2, parentId: 1 },
  3: { id: 3, parentId: 2 },
  4: { id: 4, parentId: 3 },
};
assert.equal(depthOf(index[2], index), 1, 'depthOf(odpověď na komentář 1) má vrátit 1');
assert.equal(depthOf(index[4], index), 3, 'depthOf(komentář 4 → 3 → 2 → 1) má vrátit 3');
```

V diskusi pod svíčkovou má komentář 8 hloubku 3.

```js
assert.equal(depthOf(byId[8], byId), 3, 'depthOf(byId[8], byId) má vrátit 3 — komentář 8 odpovídá na 3, ten na 2 a ten na 1');
```
