# --description--

Teď hlavní kus workshopu: z plochého seznamu uděláš **strom**. Každý uzel stromu je kopie komentáře s novou vlastností `replies` — polem uzlů jeho odpovědí, které mají zase svoje `replies`:

```js
{ id: 1, author: 'Jana Nováková', …, replies: [
  { id: 2, author: 'Petr Svoboda', …, replies: [
    { id: 3, …, replies: [] },
  ] },
] }
```

Postup: vezmi komentáře s daným `parentId` (to umí tvoje `repliesTo`) a z každého udělej uzel, jehož `replies` jsou **strom postavený stejnou funkcí** pro jeho `id`. Základní případ tu není napsaný v `if`: komentář bez odpovědí dostane z filtru prázdné pole a rekurze se zastaví sama.

**Úkol:** Seřaď řádky tak, aby `buildTree(list, parentId)` vrátila strom. Když `parentId` nezadáš, začne od komentářů přímo pod receptem — do mezery doplň výchozí hodnotu. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc.

# --hints--

`buildTree(list)` vrátí komentáře pod receptem a v `replies` jejich odpovědi na všech úrovních.

```js
const list = [
  { id: 1, parentId: null, author: 'Hana' },
  { id: 2, parentId: 1, author: 'Ivo' },
  { id: 3, parentId: 2, author: 'Lea' },
  { id: 4, parentId: null, author: 'Ota' },
];
assert.deepEqual(buildTree(list), [
  { id: 1, parentId: null, author: 'Hana', replies: [
    { id: 2, parentId: 1, author: 'Ivo', replies: [
      { id: 3, parentId: 2, author: 'Lea', replies: [] },
    ] },
  ] },
  { id: 4, parentId: null, author: 'Ota', replies: [] },
], 'buildTree([Hana, Ivo → Hana, Lea → Ivo, Ota]) má vrátit strom Hana > Ivo > Lea a Ota bez odpovědí');
```

`buildTree(list, id)` vrátí strom odpovědí na komentář s tím `id`.

```js
const list = [
  { id: 1, parentId: null },
  { id: 2, parentId: 1 },
  { id: 3, parentId: 1 },
];
assert.deepEqual(buildTree(list, 1).map((node) => node.id), [2, 3], 'buildTree(list, 1) má vrátit uzly 2 a 3');
```

Původní komentáře zůstanou beze změny, bez vlastnosti `replies`.

```js
const list = [{ id: 1, parentId: null }, { id: 2, parentId: 1 }];
buildTree(list);
assert.equal('replies' in list[0], false, 'buildTree nesmí přidat replies do původního komentáře — uzel má být kopie');
```

## --tip--

Jde o rekurzi nad stromem — viz [Rekurze: funkce, která volá sama sebe](see:js-funkce-hloubka/funkcionalni-styl#rekurze-funkce-ktera-vola-sama-sebe).

## --tip--

Odpovědi uzlu jsou komentáře, jejichž `parentId` je `id` tohoto komentáře. Kdyby rekurzivní volání dostalo pořád stejné `parentId`, nikdy by neskončilo.

# --parsons--

```js
function buildTree(list, parentId = __1__) {
  return list
    .filter((comment) => comment.parentId === parentId)
    .map((comment) => ({
      ...comment,
      replies: buildTree(list, comment.id),
    }));
}
```

## --distractors--

```js
replies: buildTree(list, parentId),
.filter((comment) => comment.id === parentId)
```
