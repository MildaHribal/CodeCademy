# --description--

Strom diskuse se staví z jednoduché otázky: **které komentáře odpovídají na komentář s daným `id`?** Komentáře přímo pod receptem mají `parentId: null`, takže stejná otázka s `null` vrátí první úroveň diskuse.

**Úkol:** Napiš funkci `repliesTo(list, parentId)`, která vrátí komentáře, jejichž `parentId` se rovná zadanému `parentId`, ve stejném pořadí jako v `list`. Pak si vypiš autory komentářů přímo pod receptem.

Stejný tvar na jiných datech — produkty v kategorii:

```js
function productsIn(products, categoryId) {
  return products.filter((product) => product.categoryId === categoryId);
}
```

# --hints--

`repliesTo(list, id)` vrátí přímé odpovědi na komentář s tím `id`.

```js
const list = [
  { id: 1, parentId: null },
  { id: 2, parentId: 1 },
  { id: 3, parentId: 2 },
  { id: 4, parentId: 1 },
];
assert.deepEqual(repliesTo(list, 1).map((comment) => comment.id), [2, 4], 'repliesTo(list, 1) má vrátit komentáře 2 a 4 — komentář 3 odpovídá na 2, ne na 1');
```

`repliesTo(list, null)` vrátí komentáře přímo pod receptem.

```js
const list = [
  { id: 1, parentId: null },
  { id: 2, parentId: 1 },
  { id: 5, parentId: null },
];
assert.deepEqual(repliesTo(list, null).map((comment) => comment.id), [1, 5], 'repliesTo(list, null) má vrátit komentáře 1 a 5');
```

Komentář bez odpovědí dostane prázdné pole.

```js
assert.deepEqual(repliesTo([{ id: 1, parentId: null }], 1), [], 'repliesTo([komentář 1], 1) má vrátit []');
```
