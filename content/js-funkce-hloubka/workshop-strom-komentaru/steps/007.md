# --description--

U každého komentáře bude tlačítko „Skrýt 3 odpovědi". Počítají se **všechny** odpovědi ve vlákně pod komentářem, i odpovědi na odpovědi — ne jen `replies.length`.

Stejný vzor jako `buildTree`, jen napíšeš sám: pro každou odpověď připočítej `1` za ni a k tomu **její** počet odpovědí, spočítaný stejnou funkcí. List stromu (uzel s prázdným `replies`) vrátí `0`.

**Úkol:** Napiš funkci `countReplies(node)`, která vrátí počet všech odpovědí pod uzlem stromu. Pod funkci `buildTree` si ulož strom diskuse do konstanty `thread` (`buildTree(comments)`) a vypiš si `countReplies` pro první uzel `thread`.

Stejný vzor na jiných datech — počet souborů ve složce i ve všech podsložkách:

```js
function countFiles(folder) {
  // 1. soubory přímo v téhle složce
  let count = folder.files.length;
  // 2. k tomu soubory každé podsložky, spočítané stejnou funkcí
  for (const subfolder of folder.subfolders) {
    count += countFiles(subfolder);
  }
  return count;
}
```

# --hints--

Konstanta `thread` obsahuje strom diskuse z `comments`.

```js
assert.ok(Array.isArray(thread), 'thread má být pole uzlů stromu');
assert.deepEqual(thread.map((node) => node.id), [11, 9, 4, 1], 'thread má pod receptem obsahovat komentáře 11, 9, 4, 1 v pořadí serveru');
```

Uzel bez odpovědí má `0` odpovědí.

```js
const leaf = { id: 1, replies: [] };
assert.equal(countReplies(leaf), 0, 'countReplies(uzel s replies: []) má vrátit 0');
```

`countReplies` počítá i odpovědi na odpovědi.

```js
const root = { id: 1, replies: [
  { id: 2, replies: [
    { id: 4, replies: [] },
    { id: 5, replies: [{ id: 6, replies: [] }] },
  ] },
  { id: 3, replies: [] },
] };
assert.equal(countReplies(root), 5, 'countReplies(1 > [2 > [4, 5 > 6], 3]) má vrátit 5 — nejen dvě přímé odpovědi');
assert.equal(countReplies(root.replies[0]), 3, 'countReplies(uzel 2 > [4, 5 > 6]) má vrátit 3');
```
