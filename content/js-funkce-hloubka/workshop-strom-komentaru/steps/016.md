# --description--

Velké diskuse ukážou jen pár úrovní a hlubší odpovědi schovají za odkaz „Pokračovat ve vlákně (2 odpovědi)".

**Úkol:** Napiš funkci `limitDepth(nodes, levels)`, která vrátí nový strom s nejvýš `levels` úrovněmi (`levels` je aspoň `1`):

- uzly na poslední ponechané úrovni mají `replies: []` a ve vlastnosti `hiddenReplies` počet všech odpovědí, které se schovaly,
- všechny ostatní uzly mají `hiddenReplies: 0`,
- vstupní strom se nezmění.

Kandidáti: parametr, který se s každou úrovní zmenšuje (jako `depth` v `toLines`, jen obráceně), a tvoje `countReplies`.

# --hints--

S `levels` 1 zůstanou jen uzly první úrovně a u každého počet schovaných odpovědí.

```js
const tree = [
  { id: 1, replies: [{ id: 2, replies: [{ id: 3, replies: [] }] }] },
  { id: 4, replies: [] },
];
assert.deepEqual(limitDepth(tree, 1), [
  { id: 1, replies: [], hiddenReplies: 2 },
  { id: 4, replies: [], hiddenReplies: 0 },
], 'limitDepth(strom, 1) má nechat uzly 1 a 4 bez odpovědí; uzel 1 schovává 2 odpovědi');
```

S `levels` 2 zůstane druhá úroveň a schovají se až odpovědi pod ní.

```js
const tree = [
  { id: 1, replies: [
    { id: 2, replies: [{ id: 3, replies: [{ id: 5, replies: [] }] }] },
    { id: 4, replies: [] },
  ] },
];
assert.deepEqual(limitDepth(tree, 2), [
  { id: 1, hiddenReplies: 0, replies: [
    { id: 2, replies: [], hiddenReplies: 2 },
    { id: 4, replies: [], hiddenReplies: 0 },
  ] },
], 'limitDepth(strom, 2) má uzel 1 nechat s hiddenReplies 0 a u uzlu 2 schovat 2 odpovědi (3 a 5)');
```

Když je strom mělčí než `levels`, zůstane celý a všechny uzly mají `hiddenReplies: 0`.

```js
const tree = [{ id: 1, replies: [{ id: 2, replies: [] }] }];
assert.deepEqual(limitDepth(tree, 5), [{ id: 1, hiddenReplies: 0, replies: [{ id: 2, hiddenReplies: 0, replies: [] }] }], 'limitDepth(dvouúrovňový strom, 5) má nechat obě úrovně');
```

Vstupní strom zůstane beze změny.

```js
const tree = [{ id: 1, replies: [{ id: 2, replies: [] }] }];
limitDepth(tree, 1);
assert.equal(tree[0].replies.length, 1, 'limitDepth nesmí vyprázdnit replies v původním stromu');
assert.equal('hiddenReplies' in tree[0], false, 'limitDepth nesmí přidat hiddenReplies do původního uzlu');
```

# --help--

## --tip--

Rekurze s parametrem, který určuje, kde přestat — základní případ je poslední ponechaná úroveň. Viz [Rekurze a zásobník volání](see:js-funkce-hloubka/funkcionalni-styl#rekurze-a-zasobnik-volani).

## --tip--

Když je `levels` rovno `1`, uzel už odpovědi nedostane a počet schovaných spočítá `countReplies`. Jinak uzel dostane odpovědi zpracované stejnou funkcí s o jedna menším `levels`.

## --tip--

Na jiných datech: menu, které ukáže jen dvě úrovně a u třetí napíše „a další": `showMenu(categories, levels)` volá sama sebe s `levels - 1`.
