# --description--

Výpis z minulého kroku skládá čtyři úpravy do sebe a čte se pozpátku, zevnitř ven. Stránka bude diskusi potřebovat na několika místech, takže si zpracování zabalíš do jediné funkce.

**Úkol:** Založ `discussion` — funkci, která dostane plochý seznam komentářů ze serveru a vrátí hotovou diskusi: seřazenou od nejstaršího, jako strom, bez smazaných komentářů bez odpovědí a se zbylými smazanými zamaskovanými. Vstupní pole se nesmí přerovnat. Výpis z minulého kroku nahraď výpisem odsazených řádků `discussion(comments)`.

Rozmysli si pořadí: které úpravy pracují s plochým seznamem a které až se stromem?

Tady máš hotové zpracování dat. Jestli potřebuješ, dej si pauzu — další krok staví na stejném stromu.

# --hints--

`discussion(comments)` vrátí seřazenou diskusi bez spamu a se zamaskovaným smazaným komentářem.

```js
assert.equal(typeof discussion, 'function', 'discussion má být funkce');
const tree = discussion(comments);
assert.deepEqual(tree.map((node) => node.id), [1, 4, 9], 'discussion(comments) má pod receptem vrátit komentáře 1, 4, 9 od nejstaršího — smazaný spam 11 bez odpovědí zmizí');
assert.deepEqual(tree[1].replies.map((node) => node.text), ['Půl litru stačí, víc je zbytečně těžké.', '[smazaný komentář]'], 'odpovědi na komentář 4 mají být Eva a zamaskovaný smazaný komentář 6');
assert.equal(tree[1].replies[1].replies[0].author, 'Tomáš Dvořák', 'odpověď Tomáše pod smazaným komentářem 6 má zůstat');
```

`discussion` funguje pro jakýkoli seznam a vstupní pole nechá v pořadí serveru.

```js
const list = [
  { id: 3, parentId: 1, author: 'Lea', text: 'Díky', likes: 0, createdAt: '2026-09-02T10:00', deleted: false },
  { id: 2, parentId: null, author: 'Ota', text: 'Spam', likes: 0, createdAt: '2026-09-01T12:00', deleted: true },
  { id: 1, parentId: null, author: 'Hana', text: 'Ahoj', likes: 0, createdAt: '2026-09-01T09:00', deleted: false },
];
const tree = discussion(list);
assert.deepEqual(tree.map((node) => node.id), [1], 'discussion([Lea → Hana, smazaný Ota, Hana]) má pod receptem nechat jen Hanu — smazaný Ota bez odpovědí zmizí');
assert.deepEqual(tree[0].replies.map((node) => node.id), [3], 'pod Hanou má zůstat odpověď Ley');
assert.deepEqual(list.map((comment) => comment.id), [3, 2, 1], 'discussion nesmí přerovnat vstupní pole');
```

# --help--

## --tip--

Skládáš hotové funkce za sebe — viz [Kompozice](see:js-funkce-hloubka/funkcionalni-styl#kompozice-vystup-jedne-funkce-je-vstupem-dalsi).

## --tip--

Do `pipe` dej čtyři funkce v pořadí, v jakém mají proběhnout. Řazení patří před stavbu stromu, obě čisticí funkce pracují až se stromem.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. která funkce dostane plochý seznam jako první
// 2. která z něj udělá strom
// 3. které dvě pak strom čistí
```

# --explain--

Vysvětli vlastními slovy, proč `pipe(buildTree, oldestFirst, pruneDeleted, maskDeleted)` seřadí jen komentáře přímo pod receptem, ale odpovědi ne.

## --model--

`pipe` volá funkce zleva doprava a každá dostane výsledek té předchozí. Když je `buildTree` první, dostane `oldestFirst` už hotový strom, tedy jen pole komentářů pod receptem, a seřadí jen ho. Odpovědi jsou schované v `replies` a řazení se jich nedotkne. `buildTree` zachová pořadí seznamu, který dostane, takže když seřadím plochý seznam dřív, jsou seřazené všechny úrovně.

## --checklist--

- `pipe` předává výsledek jedné funkce jako vstup další, zleva doprava.
- Po `buildTree` dostane `oldestFirst` jen první úroveň stromu.
- `oldestFirst` do `replies` nevidí, řadí jen pole, které dostane.
- `buildTree` zachová pořadí vstupního seznamu na všech úrovních.
