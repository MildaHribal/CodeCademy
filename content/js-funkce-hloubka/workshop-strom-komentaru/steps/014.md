# --description--

Odkaz z e-mailové notifikace vede na konkrétní komentář, třeba `#komentar-8`. Aplikace ho musí najít ve stromu, ať je v jakékoli hloubce, a zvýraznit.

**Úkol:** Napiš funkci `findComment(nodes, id)`, která ve stromu najde uzel s daným `id` a vrátí **ten uzel** (ne jeho kopii). Když ve stromu není, vrátí `undefined`.

Nástroj si vyber sám, rozumných cest je víc. Až budeš mít hotovo, rozmysli si, jak by vypadalo řešení bez rekurze.

# --hints--

`findComment` najde uzel v libovolné hloubce a vrátí přímo ten uzel.

```js
const deep = { id: 6, replies: [] };
const tree = [
  { id: 1, replies: [{ id: 2, replies: [] }] },
  { id: 3, replies: [{ id: 4, replies: [{ id: 5, replies: [deep] }] }] },
];
assert.equal(findComment(tree, 6), deep, 'findComment(strom, 6) má vrátit uzel 6 ze čtvrté úrovne druhého vlákna');
assert.equal(findComment(tree, 3), tree[1], 'findComment(strom, 3) má vrátit uzel 3 pod receptem');
```

Když uzel ve stromu není, vrátí `undefined`.

```js
const tree = [{ id: 1, replies: [{ id: 2, replies: [] }] }];
assert.equal(findComment(tree, 42), undefined, 'findComment(strom, 42) má vrátit undefined');
assert.equal(findComment([], 1), undefined, 'findComment([], 1) má vrátit undefined');
```

# --help--

## --tip--

Hledáš ve stromu neznámé hloubky. Porovnej [Rekurze: funkce, která volá sama sebe](see:js-funkce-hloubka/funkcionalni-styl#rekurze-funkce-ktera-vola-sama-sebe) a past [Zapomenutý `return` u rekurzivního volání](see:js-funkce-hloubka/funkcionalni-styl#zapomenuty-return-u-rekurzivniho-volani).

## --tip--

Dvě cesty: projdi uzly a u každého se zeptej stejnou funkcí jeho odpovědí — výsledek vnořeného hledání musíš vrátit dál. Nebo nejdřív strom rozlož na ploché pole všech uzlů a hledej v něm.

## --tip--

Podcíle pro rekurzivní cestu, kód k nim napíšeš sám:

```js
// 1. pro každý uzel: je to on? vrať ho
// 2. jinak hledej v jeho odpovědích a nalezený uzel vrať
// 3. když nic nenajdeš v žádném uzlu, vrať undefined
```
