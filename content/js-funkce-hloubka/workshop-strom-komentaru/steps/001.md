# --description--

Pod každým receptem, článkem nebo videem je diskuse: komentáře, odpovědi na ně, odpovědi na odpovědi. Server je ale pošle jako **plochý seznam** a každý komentář jen řekne, na který odpovídá. V tomhle workshopu z něj postavíš strom diskuse, spočítáš odpovědi, schováš smazané komentáře a nakonec diskusi vykreslíš na stránku s tlačítky pro sbalení vláken a řazením.

V `script.js` je pole `comments` s diskusí pod receptem na svíčkovou. Každý komentář má:

- `id` — číslo komentáře,
- `parentId` — `id` komentáře, na který odpovídá, nebo `null`, když je přímo pod receptem,
- `author`, `text`, `likes` (počet srdíček) a `createdAt` (čas vložení),
- `deleted` — `true`, když ho autor smazal.

Začneš něčím, co už umíš, a bez návodu.

**Úkol:** Pod pole napiš funkci `indexById(list)`, která vrátí **objekt**, kde klíčem je `id` komentáře a hodnotou celý komentář. Pod funkci založ konstantu `byId` s výsledkem pro `comments` a vypiš si `byId[3].text`.

# --hints--

`indexById` vrátí objekt, ve kterém pod každým `id` najdeš původní komentář.

```js
const eva = { id: 7, parentId: null, author: 'Eva' };
const ota = { id: 9, parentId: 7, author: 'Ota' };
const result = indexById([eva, ota]);
assert.deepEqual(Object.keys(result).sort(), ['7', '9'], 'indexById([Eva (7), Ota (9)]) má mít klíče 7 a 9');
assert.equal(result[7], eva, 'indexById(…)[7] má být původní objekt Evy, ne jeho kopie');
assert.equal(result[9], ota, 'indexById(…)[9] má být původní objekt Oty');
```

Pro prázdný seznam vrátí `indexById` prázdný objekt.

```js
assert.deepEqual(indexById([]), {}, 'indexById([]) má vrátit {}');
```

Konstanta `byId` obsahuje komentáře z `comments` podle `id`.

```js
assert.equal(byId[3], comments.find((comment) => comment.id === 3), 'byId[3] má být komentář s id 3 z pole comments');
assert.equal(Object.keys(byId).length, comments.length, `byId má mít ${comments.length} klíčů, jeden na každý komentář`);
```

# --help--

## --tip--

Z pole potřebuješ jeden objekt — viz [Akumulátor nemusí být číslo](see:js-pole/metody-pole-do-hloubky#akumulator-nemusi-byt-cislo).

## --tip--

Hodí se `reduce` s prázdným objektem jako počáteční hodnotou, nebo `Object.fromEntries` nad polem dvojic `[klíč, hodnota]`.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. začni prázdným objektem
// 2. pro každý komentář: pod klíč jeho id ulož celý komentář
// 3. vrať objekt
```
