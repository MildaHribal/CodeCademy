# --description--

Když autor komentář smaže, odpovědi pod ním mají zůstat — jinak by zmizel celý rozhovor. Diskuse proto místo smazaného komentáře ukáže jen `[smazaný komentář]` a jméno autora skryje.

**Úkol:** Napiš funkci `maskDeleted(nodes)`, která vrátí **nový** strom:

- uzel s `deleted: true` má `author: null` a `text: '[smazaný komentář]'`, ostatní vlastnosti i odpovědi mu zůstanou,
- ostatní uzly zůstanou, jak jsou,
- platí to na všech úrovních stromu,
- vstupní strom se nezmění.

Kandidáti: rekurze přes `map` nebo `for…of`, nový objekt přes spread. Rozmysli si, kde se zpracují odpovědi.

# --hints--

Smazaný uzel dostane `author: null` a text `[smazaný komentář]`, ostatní vlastnosti mu zůstanou.

```js
const tree = [{ id: 1, author: 'Hana', text: 'Spam', likes: 2, deleted: true, replies: [] }];
assert.deepEqual(maskDeleted(tree), [{ id: 1, author: null, text: '[smazaný komentář]', likes: 2, deleted: true, replies: [] }], 'maskDeleted([smazaný komentář Hany]) má skrýt autora a text, ostatní ponechat');
```

Maskuje se i smazaná odpověď hluboko ve vlákně a odpovědi smazaného komentáře zůstanou.

```js
const tree = [
  { id: 1, author: 'Hana', text: 'Ahoj', deleted: false, replies: [
    { id: 2, author: 'Ivo', text: 'Smazáno', deleted: true, replies: [
      { id: 3, author: 'Lea', text: 'Díky', deleted: false, replies: [] },
    ] },
  ] },
];
const result = maskDeleted(tree);
assert.equal(result[0].author, 'Hana', 'nesmazaný uzel 1 má mít autora Hana');
assert.equal(result[0].replies[0].text, '[smazaný komentář]', 'smazaná odpověď 2 ve druhé úrovni má mít text [smazaný komentář]');
assert.equal(result[0].replies[0].author, null, 'smazaná odpověď 2 má mít author null');
assert.equal(result[0].replies[0].replies[0].author, 'Lea', 'odpověď 3 pod smazaným komentářem má zůstat i s autorkou Lea');
```

Vstupní strom zůstane beze změny.

```js
const tree = [{ id: 1, author: 'Hana', text: 'Ahoj', deleted: false, replies: [
  { id: 2, author: 'Ivo', text: 'Smazáno', deleted: true, replies: [] },
] }];
maskDeleted(tree);
assert.equal(tree[0].replies[0].author, 'Ivo', 'maskDeleted nesmí přepsat autora v původním stromu');
assert.equal(tree[0].replies[0].text, 'Smazáno', 'maskDeleted nesmí přepsat text v původním stromu');
```

# --help--

## --tip--

Úprava stromu bez mutace je rekurze, která vrací nové uzly — viz [„Čistá" funkce, která mění vstup](see:js-funkce-hloubka/funkcionalni-styl#cista-funkce-ktera-meni-vstup).

## --tip--

Každý nový uzel potřebuje v `replies` výsledek téže funkce pro jeho odpovědi. Smazaný uzel navíc přepíše dvě vlastnosti. Do původního uzlu nezapisuj.

## --tip--

Na jiných datech: `categories.map((category) => ({ ...category, name: category.name.toUpperCase(), subcategories: upperNames(category.subcategories) }))`.

// Nová kopie seřazená od nejstaršího komentáře. Časy ve formátu ISO jdou porovnat jako text.
function oldestFirst(list) {
  return list.toSorted((a, b) => a.createdAt.localeCompare(b.createdAt));

function depthOf(comment, index) {
  if (comment.parentId === null) {
    return 0;
  }
  return 1 + depthOf(index[comment.parentId], index);

// Autoři vlákna od komentáře pod receptem až po zadaný komentář.
function threadAuthors(comment, index) {
  if (comment.parentId === null) {
    return [comment.author];
  }
  return [...threadAuthors(index[comment.parentId], index), comment.author];
}

function buildTree(list, parentId = null) {
  return list
    .filter((comment) => comment.parentId === parentId)
    .map((comment) => ({
      ...comment,
      replies: buildTree(list, comment.id),
    }));
}

// Strom diskuse v pořadí serveru: uzel = kopie komentáře a v replies strom jeho odpovědí.
const thread = buildTree(comments);

// Počet všech odpovědí pod uzlem, včetně odpovědí na odpovědi.
function countReplies(node) {
  return node.replies.reduce((sum, reply) => sum + 1 + countReplies(reply), 0);
}

console.log(`${thread[0].author}: ${countReplies(thread[0])}`);

// Odsazený výpis: každá úroveň odpovědí o dvě mezery dál.
function toLines(nodes, depth = 0) {
  return nodes.flatMap((node) => [
    `${'  '.repeat(depth)}${node.author}: ${node.text}`,
    ...toLines(node.replies, depth + 1),
  ]);
}

console.log(toLines(thread).join('\n'));

// Složí funkce zleva doprava: výstup jedné je vstupem další.
const pipe = (...fns) => (value) => fns.reduce((result, fn) => fn(result), value);

// Strom přímo z dat serveru: nejdřív seřadit od nejstaršího, pak postavit strom.
const threadFromApi = pipe(oldestFirst, buildTree);

console.log(toLines(threadFromApi(comments)).join('\n'));

function maskDeleted(nodes) {
  return nodes.map((node) => {
    const replies = maskDeleted(node.replies);
    if (node.deleted) {
      return { ...node, author: null, text: '[smazaný komentář]', replies };
