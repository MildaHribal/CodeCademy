# --description--

`thread` je postavený z komentářů v pořadí serveru, takže na každé úrovni jde od nejnovějšího. Diskuse má jít od nejstaršího — pod receptem i ve všech odpovědích.

Nemusíš psát nic nového: `buildTree` zachová pořadí seznamu, který dostane. Stačí jí dát seznam, který už je seřazený.

**Úkol:** Založ `threadFromApi` — funkci, která dostane plochý seznam komentářů v libovolném pořadí a vrátí strom, ve kterém jsou uzly na každé úrovni od nejstaršího. Vstupní pole se nesmí přerovnat. Vypiš si odsazené řádky stromu pro `comments`.

Složit to můžeš přes `pipe`, nebo jako funkci, která volání vnoří. Rozmysli si, ve kterém zápisu je lépe vidět pořadí kroků.

# --hints--

`threadFromApi` vrátí strom seřazený od nejstaršího na každé úrovni.

```js
const list = [
  { id: 4, parentId: 1, createdAt: '2026-09-03T10:00' },
  { id: 3, parentId: null, createdAt: '2026-09-02T10:00' },
  { id: 2, parentId: 1, createdAt: '2026-09-01T12:00' },
  { id: 1, parentId: null, createdAt: '2026-09-01T09:00' },
];
const tree = threadFromApi(list);
assert.deepEqual(tree.map((node) => node.id), [1, 3], 'threadFromApi má pod receptem vrátit uzly 1 a 3 od nejstaršího');
assert.deepEqual(tree[0].replies.map((node) => node.id), [2, 4], 'odpovědi uzlu 1 mají jít od nejstarší: 2, 4');
```

Vstupní pole zůstane v pořadí serveru.

```js
const list = [
  { id: 2, parentId: null, createdAt: '2026-09-02T10:00' },
  { id: 1, parentId: null, createdAt: '2026-09-01T09:00' },
];
threadFromApi(list);
assert.deepEqual(list.map((comment) => comment.id), [2, 1], 'threadFromApi nesmí přerovnat vstupní pole');
```

# --help--

## --tip--

Skládáš dvě hotové funkce — viz [Kompozice](see:js-funkce-hloubka/funkcionalni-styl#kompozice-vystup-jedne-funkce-je-vstupem-dalsi).

## --tip--

Na pořadí záleží: nejdřív seřadit plochý seznam, pak z něj stavět strom. `buildTree` se dá zavolat s jedním argumentem, takže do `pipe` sedí.

## --tip--

Na jiných datech: `const cleanName = pipe(trimText, capitalize);` — funkce se předávají bez závorek, zavolá je až `pipe`.

// Nová kopie seřazená od nejstaršího komentáře. Časy ve formátu ISO jdou porovnat jako text.
function oldestFirst(list) {
  return list.toSorted((a, b) => a.createdAt.localeCompare(b.createdAt));

  if (comment.parentId === null) {
    return 0;
  }
  return 1 + depthOf(index[comment.parentId], index);

// Autoři vlákna od komentáře pod receptem až po zadaný komentář.
function threadAuthors(comment, index) {
  if (comment.parentId === null) {
    return [comment.author];
  }
  return [...threadAuthors(index[comment.parentId], index), comment.author];

function buildTree(list, parentId = null) {
  return list
    .filter((comment) => comment.parentId === parentId)
    .map((comment) => ({
      ...comment,
      replies: buildTree(list, comment.id),
    }));
}

// Strom diskuse v pořadí serveru: uzel = kopie komentáře a v replies strom jeho odpovědí.
const thread = buildTree(comments);

// Počet všech odpovědí pod uzlem, včetně odpovědí na odpovědi.
function countReplies(node) {
  return node.replies.reduce((sum, reply) => sum + 1 + countReplies(reply), 0);
}

// Odsazený výpis: každá úroveň odpovědí o dvě mezery dál.
function toLines(nodes, depth = 0) {
  return nodes.flatMap((node) => [
    `${'  '.repeat(depth)}${node.author}: ${node.text}`,
    ...toLines(node.replies, depth + 1),
  ]);
}

console.log(toLines(thread).join('\n'));

const pipe = (...fns) => (value) => fns.reduce((result, fn) => fn(result), value);
