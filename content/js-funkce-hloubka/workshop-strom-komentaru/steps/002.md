# --description--

Server posílá komentáře od nejnovějšího. Diskuse se ale čte jako rozhovor, od nejstaršího.

Čas `createdAt` je text ve formátu ISO (`'2026-09-01T18:20'`): rok, měsíc, den, hodina a minuta, vždy stejně dlouhé a doplněné nulami. Takový text se řadí správně i jako obyčejný řetězec.

**Úkol:** Napiš funkci `oldestFirst(list)`, která vrátí **nové** pole komentářů seřazené od nejstaršího `createdAt` po nejnovější. Původní pole nechá v původním pořadí. Vypiš si autora posledního komentáře v seřazeném poli.

# --hints--

`oldestFirst` vrátí komentáře od nejstaršího.

```js
const list = [
  { id: 3, createdAt: '2026-09-02T09:05' },
  { id: 1, createdAt: '2026-08-30T21:40' },
  { id: 2, createdAt: '2026-09-01T07:15' },
];
assert.deepEqual(oldestFirst(list).map((comment) => comment.id), [1, 2, 3], 'oldestFirst([2. 9., 30. 8., 1. 9.]) má vrátit id 1, 2, 3');
```

`oldestFirst` vrátí nové pole a původní nechá v původním pořadí.

```js
const list = [
  { id: 2, createdAt: '2026-09-01T07:15' },
  { id: 1, createdAt: '2026-08-30T21:40' },
];
const result = oldestFirst(list);
assert.deepEqual(list.map((comment) => comment.id), [2, 1], 'oldestFirst nesmí přerovnat původní pole');
assert.notEqual(result, list, 'oldestFirst má vrátit nové pole');
```

# --help--

## --tip--

Řadíš bez změny vstupu — viz [Řazení a porovnávací funkce](see:js-pole/metody-pole-do-hloubky#razeni-a-porovnavaci-funkce).

## --tip--

Metoda, která vrací seřazenou kopii, dostane porovnávací funkci dvou komentářů. Dva řetězce porovná `localeCompare`, nebo operátory `<` a `>`.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. seřazená kopie, ne řazení na místě
// 2. porovnávací funkce: záporné číslo, když je a starší než b
```
