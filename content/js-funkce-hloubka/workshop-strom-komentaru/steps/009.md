# --description--

Data z API teď projdou několika úpravami za sebou: seřadit, postavit strom, vyčistit smazané komentáře. Na skládání funkcí za sebe máš z lekce nástroj.

**Úkol:** Napiš funkci `pipe(...fns)`, která vrátí novou funkci. Ta dostane hodnotu a pošle ji přes všechny funkce zleva doprava: výstup jedné je vstupem další. Bez funkcí vrátí hodnotu beze změny.

# --hints--

`pipe` vrátí funkci, která volá funkce zleva doprava.

```js
const addOne = (n) => n + 1;
const double = (n) => n * 2;
assert.equal(typeof pipe(addOne, double), 'function', 'pipe(addOne, double) má vrátit funkci');
assert.equal(pipe(addOne, double)(3), 8, 'pipe(addOne, double)(3) má vrátit 8 — nejdřív + 1, pak × 2');
assert.equal(pipe(double, addOne)(3), 7, 'pipe(double, addOne)(3) má vrátit 7');
```

`pipe()` bez funkcí vrátí hodnotu beze změny.

```js
assert.equal(pipe()('svíčková'), 'svíčková', "pipe()('svíčková') má vrátit 'svíčková'");
```

Složenou funkci jde zavolat opakovaně.

```js
const shout = pipe((text) => text.trim(), (text) => text.toUpperCase());
assert.equal(shout(' knedlík '), 'KNEDLÍK', "první volání má vrátit 'KNEDLÍK'");
assert.equal(shout('omáčka'), 'OMÁČKA', "druhé volání téže funkce má vrátit 'OMÁČKA'");
```

# --help--

## --tip--

Tohle je `pipe` z části [Kompozice](see:js-funkce-hloubka/funkcionalni-styl#kompozice-vystup-jedne-funkce-je-vstupem-dalsi).

## --tip--

Funkce sbalíš zbytkovým parametrem. Vrácená funkce z pole funkcí vyrobí jedinou hodnotu: [[akumulátor]] začne vstupní hodnotou a každá funkce z něj udělá další.

## --tip--

Podcíle, kód k nim napíšeš sám:

```js
// 1. pipe přijme libovolný počet funkcí
// 2. vrátí funkci s jedním parametrem value
// 3. ta projde funkce zleva doprava a průběžný výsledek předává dál
```

function buildTree(list, parentId = null) {

    .filter((comment) => comment.parentId === parentId)

      ...comment,
      replies: buildTree(list, comment.id),
    }));

// Počet všech odpovědí pod uzlem, včetně odpovědí na odpovědi.
function countReplies(node) {
  return node.replies.reduce((sum, reply) => sum + 1 + countReplies(reply), 0);
}

// Odsazený výpis: každá úroveň odpovědí o dvě mezery dál.
function toLines(nodes, depth = 0) {

    `${'  '.repeat(depth)}${node.author}: ${node.text}`,
    ...toLines(node.replies, depth + 1),
  ]);
}

console.log(toLines(thread).join('\n'));
