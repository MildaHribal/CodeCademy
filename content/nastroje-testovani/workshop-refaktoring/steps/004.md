# --description--

Po tomhle kroku bude výpočet poplatku za jednu výpůjčku stát samostatně — půjde
zavolat z webu, z e-mailu i z testu, aniž by kolem něj vznikal text upomínky.
Síť máš upletenou, takže můžeš začít řezat.

Vytknutí funkce má vždycky stejné čtyři kroky. Drž se jich a po každém spusť testy:

1. **Vyber kus kódu, který má jeden účel.** Tady je to celá kaskáda podle druhu
   výpůjčky, která končí částkou.
2. **Dej funkci jméno podle toho, co vrací**, a pojmenuj parametr podle toho, co dostane.
3. **Nahraď původní kód voláním.** Zatím jen ten kus, nic dalšího nepřepisuj.
4. **Spusť testy.** Zelené = chování se nezměnilo.

**Úkol:** vytkni z `vypisUpominky` výpočet poplatku do vyvezené funkce
`poplatekZaVypujcku(vypujcka)`, která dostane jednu výpůjčku a vrátí částku v korunách.
Počítání bodů do klubu zatím nech tam, kde je.

Hotovo poznáš tak, že se strop 300 Kč objevuje v `poplatky.js` jen na jednom místě —
výpočet nesmí zůstat opsaný na dvou.

## --tip--

Testy hlídají chování, ne vnitřek — proto smíš kód uvnitř libovolně přeskládat, viz [Testuj chování, ne implementaci](see:nastroje-testovani/proc-testovat#testuj-chovani-ne-implementaci).

## --tip--

Nejbezpečnější postup: nejdřív celou kaskádu zkopíruj do nové funkce, nahraď v ní `vypujcka` a nech ji vrátit částku. Teprve pak v cyklu smaž původní řádky a zavolej ji.

## --tip--

Stejný řez na jiných datech: z funkce, která skládá fakturu, vytkneš `cenaPolozky(polozka)` a ve faktuře po ní zůstane jediný řádek s voláním.

// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

export function vypisUpominky(ctenar) {
  let text = 'Upomínka — Městská knihovna Kutná Hora\n';
  text += `Čtenář: ${ctenar.jmeno} (${ctenar.kategorie})\n`;
  let celkem = 0;
  let body = 0;
  for (const vypujcka of ctenar.vypujcky) {
    let poplatek = 0;
    if (vypujcka.druh === 'kniha') {
      if (vypujcka.dniPoTerminu > 3) {
        poplatek = (vypujcka.dniPoTerminu - 3) * 5;
      }
      if (poplatek > 300) {
        poplatek = 300;
      }
      body += 1;
    } else if (vypujcka.druh === 'časopis') {
      if (vypujcka.dniPoTerminu > 0) {
        poplatek = vypujcka.dniPoTerminu * 8;
      }
      if (poplatek > 200) {
        poplatek = 200;
      }
      body += 1;
    } else if (vypujcka.druh === 'audiokniha') {
      if (vypujcka.dniPoTerminu > 1) {
        poplatek = (vypujcka.dniPoTerminu - 1) * 12;
      }
      if (poplatek > 400) {
        poplatek = 400;
      }
      body += 2;
    } else {
      if (vypujcka.dniPoTerminu > 0) {
        poplatek = vypujcka.dniPoTerminu * 10;
      }
      if (poplatek > 250) {
        poplatek = 250;
      }
      body += 1;
    }
    text += `  ${vypujcka.nazev} (${vypujcka.druh}): ${poplatek} Kč, po termínu ${tvarDnu(vypujcka.dniPoTerminu)}\n`;
    celkem += poplatek;
  }
  if (ctenar.kategorie === 'student') {
    celkem = Math.round(celkem * 0.5);
  }
  if (ctenar.kategorie === 'senior') {
    celkem = Math.round(celkem * 0.5);
  }
  text += `Celkem k zaplacení: ${celkem} Kč\n`;
  text += `Body do čtenářského klubu: ${body}\n`;
  return text;
}

function tvarDnu(pocet) {
  if (pocet === 1) {
    return '1 den';
  }
  if (pocet >= 2 && pocet <= 4) {
    return `${pocet} dny`;
  }
  return `${pocet} dní`;
}

// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

export function vypisUpominky(ctenar) {
  let text = 'Upomínka — Městská knihovna Kutná Hora\n';
  text += `Čtenář: ${ctenar.jmeno} (${ctenar.kategorie})\n`;
  let celkem = 0;
  let body = 0;
  for (const vypujcka of ctenar.vypujcky) {
    const poplatek = poplatekZaVypujcku(vypujcka);
    if (vypujcka.druh === 'kniha') {
      body += 1;
    } else if (vypujcka.druh === 'časopis') {
      body += 1;
    } else if (vypujcka.druh === 'audiokniha') {
      body += 2;
    } else {
      body += 1;
    }
    text += `  ${vypujcka.nazev} (${vypujcka.druh}): ${poplatek} Kč, po termínu ${tvarDnu(vypujcka.dniPoTerminu)}\n`;
    celkem += poplatek;
  }
  if (ctenar.kategorie === 'student') {
    celkem = Math.round(celkem * 0.5);
  }
  if (ctenar.kategorie === 'senior') {
    celkem = Math.round(celkem * 0.5);
  }
  text += `Celkem k zaplacení: ${celkem} Kč\n`;
  text += `Body do čtenářského klubu: ${body}\n`;
  return text;
}

export function poplatekZaVypujcku(vypujcka) {
  let poplatek = 0;
  if (vypujcka.druh === 'kniha') {
    if (vypujcka.dniPoTerminu > 3) {
      poplatek = (vypujcka.dniPoTerminu - 3) * 5;
    }
    if (poplatek > 300) {
      poplatek = 300;
    }
  } else if (vypujcka.druh === 'časopis') {
    if (vypujcka.dniPoTerminu > 0) {
      poplatek = vypujcka.dniPoTerminu * 8;
    }
    if (poplatek > 200) {
      poplatek = 200;
    }
  } else if (vypujcka.druh === 'audiokniha') {
    if (vypujcka.dniPoTerminu > 1) {
      poplatek = (vypujcka.dniPoTerminu - 1) * 12;
    }
    if (poplatek > 400) {
      poplatek = 400;
    }
  } else {
    if (vypujcka.dniPoTerminu > 0) {
      poplatek = vypujcka.dniPoTerminu * 10;
    }
    if (poplatek > 250) {
      poplatek = 250;
    }
  }
  return poplatek;
}

function tvarDnu(pocet) {

    return '1 den';
  }
