# --description--

Hotová funkce je k ničemu, dokud ji nikdo nevolá. Po tomhle kroku zmizí z `poplatky.js`
poslední místo, kde se rozhoduje podle kategorie čtenáře — a přidání jarní slevy
pro brigádníky bude znamenat jeden řádek v `slevy.js`.

**Úkol:** naimportuj do `poplatky.js` funkci `slevaProKategorii` ze souboru `slevy.js`
a nahraď obě podmínky na konci `vypisUpominky` jediným výpočtem, který celkovou částku
vynásobí koeficientem a zaokrouhlí ji stejně jako dnes.

Po tomhle kroku máš hotový první kus: výpočet poplatku, bodů i slevy stojí samostatně.
Je to dobré místo na pauzu.

## --tip--

Import pojmenovaného exportu z vedlejšího souboru vypadá stejně jako v `ukazka.js` v prvním kroku.

## --tip--

Obě podmínky dělaly totéž: braly polovinu. Jejich náhrada je jeden řádek, ve kterém se celková částka vynásobí koeficientem a zaokrouhlí.

## --tip--

Zaokrouhlení nech tam, kde bylo — kdybys ho posunul jinam, změní se haléře a testy zčervenají.

```js
// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

export const SAZEBNIK = {
  kniha: { zaDen: 5, odklad: 3, strop: 300, body: 1 },
  'časopis': { zaDen: 8, odklad: 0, strop: 200, body: 1 },
  audiokniha: { zaDen: 12, odklad: 1, strop: 400, body: 2 },
};

// Co v sazebníku není (deskové hry, mapy, stolní hry), počítá se takhle.
export const VYCHOZI_SAZBA = { zaDen: 10, odklad: 0, strop: 250, body: 1 };

export function vypisUpominky(ctenar) {
  let text = 'Upomínka — Městská knihovna Kutná Hora\n';
  text += `Čtenář: ${ctenar.jmeno} (${ctenar.kategorie})\n`;
  let celkem = 0;
  let body = 0;
  for (const vypujcka of ctenar.vypujcky) {
    const poplatek = poplatekZaVypujcku(vypujcka);
    body += bodyZaVypujcku(vypujcka);
    text += `  ${vypujcka.nazev} (${vypujcka.druh}): ${poplatek} Kč, po termínu ${tvarDnu(vypujcka.dniPoTerminu)}\n`;
    celkem += poplatek;
  }
--edit--
  if (ctenar.kategorie === 'student') {
    celkem = Math.round(celkem * 0.5);
  }
  if (ctenar.kategorie === 'senior') {
    celkem = Math.round(celkem * 0.5);
  }
--edit--
  text += `Celkem k zaplacení: ${celkem} Kč\n`;
  text += `Body do čtenářského klubu: ${body}\n`;
  return text;
}

export function poplatekZaVypujcku(vypujcka) {
  const sazba = SAZEBNIK[vypujcka.druh] ?? VYCHOZI_SAZBA;
  const dniNavic = vypujcka.dniPoTerminu - sazba.odklad;
  if (dniNavic <= 0) {
    return 0;
  }
  return Math.min(dniNavic * sazba.zaDen, sazba.strop);
}

export function bodyZaVypujcku(vypujcka) {
  const sazba = SAZEBNIK[vypujcka.druh] ?? VYCHOZI_SAZBA;
  return sazba.body;
}

function tvarDnu(pocet) {
  if (pocet === 1) {
    return '1 den';
  }
  if (pocet >= 2 && pocet <= 4) {
    return `${pocet} dny`;
  }
  return `${pocet} dní`;
}
```

```js
// Slevy čtenářského klubu. Mění se ze všeho nejčastěji, proto mají vlastní soubor.

const SLEVY = {
  student: 0.5,
  senior: 0.5,
};

export function slevaProKategorii(kategorie) {
  return SLEVY[kategorie] ?? 1;
}
```
