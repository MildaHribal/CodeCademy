# --description--

Než začneme starý kód přepisovat (refaktorovat), musíme jeho současné chování „zabetonovat" charakterizačními testy. Tak budeme mít jistotu, že jsme ho refaktoringem nerozbili.

Máme tu jednoduchou (i když špatně napsanou) funkci `zpracujData(data)`. Tvým úkolem je napsat testy s `node:test`, které potvrdí, co momentálně dělá.

**Úkol:** Doplň testy do `script.test.js` tak, aby jeden test ověřil platný řetězec a druhý neplatný (např. `null`).

# --hints--

Ověř, že testy projdou.
```js
const result = await helpers.run('node --test script.test.js');
assert.equal(result.code, 0, `Testy musí projít:\n${result.stdout}${result.stderr}`);
const count = Number(/tests (\d+)/.exec(result.stdout)?.[1] ?? 0);
assert.ok(count >= 2, `Očekávám aspoň 2 testy, našel jsem jich ${count}`);
```

# --help--

## --tip--

Při charakterizačním testu netestujeme, jestli kód dává smysl, testujeme to, co *momentálně* dělá. V node:test se test definuje funkcí `test('popis', () => { ... })`.

# --solution--

## --file-- script.js

```js
function zpracujData(data) {
  if (!data) return 'Chyba';
  return data.toUpperCase();
}
module.exports = { zpracujData };
```

## --file-- script.test.js

```js
const { test } = require('node:test');
const assert = require('node:assert/strict');
const { zpracujData } = require('./script.js');

test('charakterizace: správná data', () => {
  assert.equal(zpracujData('ahoj'), 'AHOJ', 'Platný vstup vrátí velká písmena');
});

test('charakterizace: chybějící data', () => {
  assert.equal(zpracujData(null), 'Chyba', 'Null vrátí text Chyba');
});
```
