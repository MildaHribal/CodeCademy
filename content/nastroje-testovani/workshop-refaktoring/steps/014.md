# --description--

Poslední věc, kterou knihovna chtěla: posílat upomínky e-mailem. E-mail potřebuje
HTML, ne text s mezerami. Kdybys ho psal do původní funkce, byla by v ní další
podmínka „a když chceš HTML, tak jinak". Dneska stačí přidat druhý formátovač
vedle toho textového — oba dostanou stejná data.

Pro čtenářku s jednou výpůjčkou má vzniknout zhruba tohle:

```html
  <h1>Upomínka pro Eva Marková</h1>
  <ul>
    <li>Hobit (kniha): 15 Kč</li>
  </ul>
  <p>Celkem k zaplacení: <strong>15 Kč</strong></p>
```

**Úkol:** vyveze z `poplatky.js` funkci `formatujUpominkuHtml(souhrn)`, která dostane
stejný objekt jako textový formátovač a vrátí HTML: nadpis `h1` se jménem čtenáře,
seznam `ul` s jednou položkou `li` za každou výpůjčku (název, druh a poplatek)
a odstavec `p` s celkovou částkou v `strong`. Nic nedopočítávej. V `ukazka.js`
pak výsledek vypiš pro Janu.

Odsazení a přesné mezery jsou na tobě — kontrola se dívá na značky a hodnoty.

## Udělej po svém

Testy pro tyhle věci nejsou, výsledek je tvůj:

- **Sleva, která platí jen do konce měsíce.** Přidej do `slevy.js` jarní akci
  s datem platnosti a rozmysli, kde se vezme „dnešek“, aby šel test napsat.
- **Upomínka jako SMS do 160 znaků.** Třetí formátovač, stejná data, jiná pravidla
  zkracování.
- **Vlastní téma.** Vyměň knihovnu za něco, co tě baví: pokuty v autopůjčovně,
  storno poplatky na chatě, penále za pozdní odevzdání úkolů. Sazebník, slevy
  a formáty zůstanou, změní se jen jména.

Příště tenhle postup — síť z testů, malé kroky, zelená po každém — použiješ na cizí
validátor v labu, kde budeš mít jen zadání a kód, který nesedí.

# --help--

## --tip--

Nový formátovač je sourozenec toho textového: stejný vstup, jiné řádky. Klidně si ho vedle něj zkopíruj a přepiš.

## --tip--

Položky seznamu vzniknou z pole výpůjček stejně jako textové řádky — jen s jinými značkami kolem.

## --tip--

Ověř si ho rovnou v ukázce: **Spustit** ti HTML vypíše a je hned vidět, jestli se nezapomnělo na uzavírací značku.

# --explain--

Kdyby knihovna zítra chtěla ještě třetí podobu upomínky — SMS do 160 znaků — co bys musel udělat dneska a co by to stálo před refaktoringem?

## --model--

Dneska přidám vedle textového a HTML formátovače třetí funkci, která dostane
stejný souhrn a vrátí krátký řetězec. Výpočtu se nedotknu, takže se nemůže rozbít,
a testy na částky platí dál. Před refaktoringem by byl výpočet zapletený do skládání
textu: musel bych buď celou funkci zkopírovat a mít pravidla na dvou místech, nebo do
ní přidat podmínku podle formátu a otestovat všechny kombinace znovu. Rozdíl nedělá
to, že je kódu míň, ale že má každá část jeden účel a jedno místo, kde se mění.

## --checklist--

- Nová podoba výstupu je další formátovač nad stejnými daty.
- Výpočtu se změna nedotkne, takže testy na částky platí dál.
- Bez rozdělení by pravidla skončila zkopírovaná nebo obalená podmínkami.

// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

import { slevaProKategorii } from './slevy.js';

export const SAZEBNIK = {
  kniha: { zaDen: 5, odklad: 3, strop: 300, body: 1 },
  'časopis': { zaDen: 8, odklad: 0, strop: 200, body: 1 },
  audiokniha: { zaDen: 12, odklad: 1, strop: 400, body: 2 },
  'desková hra': { zaDen: 10, odklad: 0, strop: 250, body: 1 },
};

// Co v sazebníku není (mapy, stolní hry), počítá se takhle.
export const VYCHOZI_SAZBA = { zaDen: 10, odklad: 0, strop: 250, body: 1 };

export function spoctiUpominku(ctenar) {
  const polozky = ctenar.vypujcky.map((vypujcka) => ({
    nazev: vypujcka.nazev,
    druh: vypujcka.druh,
    dniPoTerminu: vypujcka.dniPoTerminu,
    poplatek: poplatekZaVypujcku(vypujcka),
    body: bodyZaVypujcku(vypujcka),
  }));
  const poplatky = polozky.reduce((soucet, polozka) => soucet + polozka.poplatek, 0);
  return {
    jmeno: ctenar.jmeno,
    kategorie: ctenar.kategorie,
    polozky,
    celkem: Math.round(poplatky * slevaProKategorii(ctenar.kategorie)),
    body: polozky.reduce((soucet, polozka) => soucet + polozka.body, 0),
  };
}

export function formatujUpominku(souhrn) {
  const radky = [
    'Upomínka — Městská knihovna Kutná Hora',
    `Čtenář: ${souhrn.jmeno} (${souhrn.kategorie})`,
    ...souhrn.polozky.map(
      (polozka) =>
        `  ${polozka.nazev} (${polozka.druh}): ${polozka.poplatek} Kč, po termínu ${tvarDnu(polozka.dniPoTerminu)}`,
    ),
    `Celkem k zaplacení: ${souhrn.celkem} Kč`,
    `Body do čtenářského klubu: ${souhrn.body}`,
    '',
  ];
  return radky.join('\n');
}

export function vypisUpominky(ctenar) {
  return formatujUpominku(spoctiUpominku(ctenar));
}

export function upominkaProWeb(ctenar) {
  const souhrn = spoctiUpominku(ctenar);
  return {
    jmeno: souhrn.jmeno,
    celkemHaleru: souhrn.celkem * 100,
    dluzneVypujcky: souhrn.polozky
      .filter((polozka) => polozka.poplatek > 0)
      .map((polozka) => ({ nazev: polozka.nazev, poplatek: polozka.poplatek })),
  };
}

export function poplatekZaVypujcku(vypujcka) {
  const sazba = SAZEBNIK[vypujcka.druh] ?? VYCHOZI_SAZBA;
  const dniNavic = vypujcka.dniPoTerminu - sazba.odklad;
  if (dniNavic <= 0) {
    return 0;
  }
  return Math.min(dniNavic * sazba.zaDen, sazba.strop);
}

export function bodyZaVypujcku(vypujcka) {
  const sazba = SAZEBNIK[vypujcka.druh] ?? VYCHOZI_SAZBA;
  return sazba.body;
}

function tvarDnu(pocet) {
  if (pocet === 1) {
    return '1 den';
  }
  if (pocet >= 2 && pocet <= 4) {
    return `${pocet} dny`;
  }
  return `${pocet} dní`;
}
