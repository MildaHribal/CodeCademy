# --description--

## Hlášení

Kolega Tomáš doplnil do sazebníku deskové hry, aby nepadaly do výchozí sazby. Hned
ráno píše knihovnice Věra:

> Marii Kratochvílové systém počítá za Osadníky z Katanu 400 Kč, ale u deskových her
> je strop 250 Kč. Celkem jí to napsalo 350 Kč místo 275 Kč. U ostatních čtenářů
> se nic nezměnilo.

Tvoje testy z minulých kroků na to svítí červeně, takže přesně víš, co se rozbilo.

## Úkol

Najdi v `poplatky.js` chybu, kterou Tomáš přidal, a oprav ji tak, aby byly upomínky
zase stejné jako předtím. Změň co nejmenší kus kódu — deskové hry v sazebníku nech.

## --tip--

Hlášení mluví o jediném druhu výpůjčky a o jediném čísle. Porovnej řádek deskových her s tím, co je v zadání sazebníku.

## --tip--

Chyba z kopírování řádku bývá v hodnotě, ne ve struktuře — projdi čísla zleva doprava a ptej se, odkud se vzala.

```js
// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

import { slevaProKategorii } from './slevy.js';

--edit--
export const SAZEBNIK = {
  kniha: { zaDen: 5, odklad: 3, strop: 300, body: 1 },
  'časopis': { zaDen: 8, odklad: 0, strop: 200, body: 1 },
  audiokniha: { zaDen: 12, odklad: 1, strop: 400, body: 2 },
  'desková hra': { zaDen: 10, odklad: 0, strop: 400, body: 1 },
};

// Co v sazebníku není (mapy, stolní hry), počítá se takhle.
export const VYCHOZI_SAZBA = { zaDen: 10, odklad: 0, strop: 250, body: 1 };
--edit--

export function vypisUpominky(ctenar) {
  let text = 'Upomínka — Městská knihovna Kutná Hora\n';
  text += `Čtenář: ${ctenar.jmeno} (${ctenar.kategorie})\n`;
  let celkem = 0;
  let body = 0;
  for (const vypujcka of ctenar.vypujcky) {
    const poplatek = poplatekZaVypujcku(vypujcka);
    body += bodyZaVypujcku(vypujcka);
    text += `  ${vypujcka.nazev} (${vypujcka.druh}): ${poplatek} Kč, po termínu ${tvarDnu(vypujcka.dniPoTerminu)}\n`;
    celkem += poplatek;
  }
  celkem = Math.round(celkem * slevaProKategorii(ctenar.kategorie));
  text += `Celkem k zaplacení: ${celkem} Kč\n`;
  text += `Body do čtenářského klubu: ${body}\n`;
  return text;
}

export function poplatekZaVypujcku(vypujcka) {
  const sazba = SAZEBNIK[vypujcka.druh] ?? VYCHOZI_SAZBA;
  const dniNavic = vypujcka.dniPoTerminu - sazba.odklad;
  if (dniNavic <= 0) {
    return 0;
  }
  return Math.min(dniNavic * sazba.zaDen, sazba.strop);
}

export function bodyZaVypujcku(vypujcka) {
  const sazba = SAZEBNIK[vypujcka.druh] ?? VYCHOZI_SAZBA;
  return sazba.body;
}

function tvarDnu(pocet) {
  if (pocet === 1) {
    return '1 den';
  }
  if (pocet >= 2 && pocet <= 4) {
    return `${pocet} dny`;
  }
  return `${pocet} dní`;
}
```

```js
// Slevy čtenářského klubu. Mění se ze všeho nejčastěji, proto mají vlastní soubor.

const SLEVY = {
  student: 0.5,
  senior: 0.5,
};

export function slevaProKategorii(kategorie) {
  return SLEVY[kategorie] ?? 1;
}
```
