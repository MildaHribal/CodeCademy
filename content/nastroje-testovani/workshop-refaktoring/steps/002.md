# --description--

Teď kolem kódu postavíš záchytnou síť. Charakterizační test netvrdí, že je chování
správné — tvrdí, že **tohle je chování, které dnes čtenáři dostávají**. Až budeš
za chvíli kód přepisovat, červený test ti hned řekne, že sis něco rozbil.

Nejjednodušší charakterizační test porovná celý výstup, tedy i text, který ti přijde
divný. Očekávanou hodnotu neopisuj z hlavy: vezmi ji z toho, co ti vypsalo **Spustit**
v minulém kroku.

**Úkol:** v `poplatky.test.js` napiš test, který zavolá `vypisUpominky(jana)`
a porovná výsledek s celým dnešním textem upomínky. Všech sedm řádků, včetně toho
posledního prázdného — text končí koncem řádku.

Test vypadá stejně jako každý jiný, jen očekávaná hodnota je delší:

```js
test('sazba dopravy vrací dnešní číslo', () => {
  assert.equal(dopravne(1200), 79, 'Cena dopravy se změnila');
});
```

Spustíš je příkazem `node --test poplatky.test.js` v terminálu — a kontrola tady
dělá totéž.

# --hints--

`node --test poplatky.test.js` projde a spustí aspoň jeden test.

```js
const beh = await helpers.run('node --test poplatky.test.js');
assert.equal(beh.code, 0, `Tvoje testy z minulých kroků musí projít:\n${beh.stdout}${beh.stderr}`);
const pocet = Number(/^(?:#|\u2139)\s*tests\s+(\d+)/m.exec(beh.stdout)?.[1] ?? 0);
assert.ok(pocet >= 1, `Soubor poplatky.test.js má obsahovat testy, ale spustilo se jich ${pocet}`);
```

# --help--

## --tip--

Jde o charakterizační test, viz [Test je kód, který volá tvůj kód](see:nastroje-testovani/proc-testovat#test-je-kod-ktery-vola-tvuj-kod). Zamyká dnešek, ne ideál.

## --tip--

Víceřádkový text se dobře skládá z pole řádků spojeného znakem konce řádku. Poslední položka pole je prázdný řetězec, protože text končí odřádkováním.

## --tip--

Stejný tvar na jiných datech: `const ocekavano = ['Objednávka 4021', 'Doprava: 79 Kč', ''].join('\n');` a pak jedna aserce na rovnost.

```js
// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

export function vypisUpominky(ctenar) {
  let text = 'Upomínka — Městská knihovna Kutná Hora\n';
  text += `Čtenář: ${ctenar.jmeno} (${ctenar.kategorie})\n`;
  let celkem = 0;
  let body = 0;
  for (const vypujcka of ctenar.vypujcky) {
    let poplatek = 0;
    if (vypujcka.druh === 'kniha') {
      if (vypujcka.dniPoTerminu > 3) {
        poplatek = (vypujcka.dniPoTerminu - 3) * 5;
      }
      if (poplatek > 300) {
        poplatek = 300;
      }
      body += 1;
    } else if (vypujcka.druh === 'časopis') {
      if (vypujcka.dniPoTerminu > 0) {
        poplatek = vypujcka.dniPoTerminu * 8;
      }
      if (poplatek > 200) {
        poplatek = 200;
      }
      body += 1;
    } else if (vypujcka.druh === 'audiokniha') {
      if (vypujcka.dniPoTerminu > 1) {
        poplatek = (vypujcka.dniPoTerminu - 1) * 12;
      }
      if (poplatek > 400) {
        poplatek = 400;
      }
      body += 2;
    } else {
      if (vypujcka.dniPoTerminu > 0) {
        poplatek = vypujcka.dniPoTerminu * 10;
      }
      if (poplatek > 250) {
        poplatek = 250;
      }
      body += 1;
    }
    text += `  ${vypujcka.nazev} (${vypujcka.druh}): ${poplatek} Kč, po termínu ${tvarDnu(vypujcka.dniPoTerminu)}\n`;
    celkem += poplatek;
  }
  if (ctenar.kategorie === 'student') {
    celkem = Math.round(celkem * 0.5);
  }
  if (ctenar.kategorie === 'senior') {
    celkem = Math.round(celkem * 0.5);
  }
  text += `Celkem k zaplacení: ${celkem} Kč\n`;
  text += `Body do čtenářského klubu: ${body}\n`;
  return text;
}

function tvarDnu(pocet) {
  if (pocet === 1) {
    return '1 den';
  }
  if (pocet >= 2 && pocet <= 4) {
    return `${pocet} dny`;
  }
  return `${pocet} dní`;
}
```

## --file-- poplatky.test.js

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';

import { vypisUpominky } from './poplatky.js';
import { jana, petr, marie } from './ctenari.js';

test('upomínka pro Janu Novákovou (student) vypadá přesně takhle', () => {
  const ocekavano = [
    'Upomínka — Městská knihovna Kutná Hora',
    'Čtenář: Jana Nováková (student)',
    '  Alchymista (kniha): 55 Kč, po termínu 14 dní',
    '  Respekt 12/2026 (časopis): 24 Kč, po termínu 3 dny',
    '  Šifra mistra Leonarda (audiokniha): 0 Kč, po termínu 0 dní',
    'Celkem k zaplacení: 40 Kč',
    'Body do čtenářského klubu: 4',
    '',
  ].join('\n');

  assert.equal(vypisUpominky(jana), ocekavano, 'Upomínka pro Janu se změnila proti dnešnímu stavu');
});
```
