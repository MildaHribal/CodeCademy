# --description--

Jeden čtenář ti síť neuplete. Jana má poplatek, ale nenarazí na žádnou hranici —
a přesně na hranicích se při přepisování kódu láme nejvíc věcí. Po tomhle kroku budeš
mít zamčené i okraje, takže se do přepisování můžeš pustit bez strachu.

V `ctenari.js` jsou připravení další dva čtenáři:

| čtenář | čím je zajímavý |
|---|---|
| `petr` | nedluží nic: kniha je 2 dny po termínu (odklad u knih je delší), audiokniha přesně 1 den |
| `marie` | seniorka, jejíž obě výpůjčky narazily na strop poplatku |

**Úkol:** doplň do `poplatky.test.js` dva testy stejného tvaru jako ten první — jeden
pro Petra, jeden pro Marii. Očekávaný text si nech vypsat: v `ukazka.js` dočasně
vyměň čtenáře, zmáčkni **Spustit** a výstup zkopíruj. Na konci `ukazka.js` vrať zpátky
na Janu.

# --help--

## --tip--

Okrajový případ je hodnota těsně na hranici pravidla, viz [Okrajové případy](see:nastroje-testovani/proc-testovat#okrajove-pripady). Tady jsou hranice tři: odklad, strop a sleva.

## --tip--

Oba testy mají stejnou kostru jako ten pro Janu. Liší se jménem testu, čtenářem v importu a řádky očekávaného textu.

## --tip--

Pozor na čtenáře, který nedluží nic: i jeho upomínka má řádky s výpůjčkami a body — jen s nulami.

# --explain--

Proč charakterizační test porovnává celý text upomínky, i když v něm některá čísla vypadají jako chyba?

## --model--

Charakterizační test nepopisuje, jak se má kód chovat, ale jak se chová dnes.
Kdybych do testu psal jen to, co považuju za správné, neměl bych po přepsání s čím
porovnávat — a každý rozdíl bych musel posuzovat znovu. Porovnáním celého textu chytím
i změny, které bych nečekal (počet bodů, hlavičku, tvar slova „den“). Pokud je některé
dnešní číslo opravdu chyba, opravím ji zvlášť, jako vědomou změnu chování, a test v tu
chvíli přepíšu.

## --checklist--

- Test zamyká dnešní chování, ne to správné.
- Porovnání celého textu chytí i změny, které bych dopředu nevyjmenoval.
- Oprava skutečné chyby je samostatná změna, při které se test mění schválně.

## --file-- poplatky.js

```js
// Upomínky Městské knihovny Kutná Hora.
// První verzi napsal Ivan Sýkora v roce 2019, od té doby sem každý přidal svoje pravidlo.

export function vypisUpominky(ctenar) {
  let text = 'Upomínka — Městská knihovna Kutná Hora\n';
  text += `Čtenář: ${ctenar.jmeno} (${ctenar.kategorie})\n`;
  let celkem = 0;
  let body = 0;
  for (const vypujcka of ctenar.vypujcky) {
    let poplatek = 0;
    if (vypujcka.druh === 'kniha') {
      if (vypujcka.dniPoTerminu > 3) {
        poplatek = (vypujcka.dniPoTerminu - 3) * 5;
      }
      if (poplatek > 300) {
        poplatek = 300;
      }
      body += 1;
    } else if (vypujcka.druh === 'časopis') {
      if (vypujcka.dniPoTerminu > 0) {
        poplatek = vypujcka.dniPoTerminu * 8;
      }
      if (poplatek > 200) {
        poplatek = 200;
      }
      body += 1;
    } else if (vypujcka.druh === 'audiokniha') {
      if (vypujcka.dniPoTerminu > 1) {
        poplatek = (vypujcka.dniPoTerminu - 1) * 12;
      }
      if (poplatek > 400) {
        poplatek = 400;
      }
      body += 2;
    } else {
      if (vypujcka.dniPoTerminu > 0) {
        poplatek = vypujcka.dniPoTerminu * 10;
      }
      if (poplatek > 250) {
        poplatek = 250;
      }
      body += 1;
    }
    text += `  ${vypujcka.nazev} (${vypujcka.druh}): ${poplatek} Kč, po termínu ${tvarDnu(vypujcka.dniPoTerminu)}\n`;
    celkem += poplatek;
  }
  if (ctenar.kategorie === 'student') {
    celkem = Math.round(celkem * 0.5);
  }
  if (ctenar.kategorie === 'senior') {
    celkem = Math.round(celkem * 0.5);
  }
  text += `Celkem k zaplacení: ${celkem} Kč\n`;
  text += `Body do čtenářského klubu: ${body}\n`;
  return text;
}

function tvarDnu(pocet) {
  if (pocet === 1) {
    return '1 den';
  }
  if (pocet >= 2 && pocet <= 4) {
    return `${pocet} dny`;
  }
  return `${pocet} dní`;
}
```
