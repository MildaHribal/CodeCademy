## --term-- devtools
en: Developer Tools
aliases: DevTools, vývojářských nástrojích, vývojářskými nástroji
mdn: https://developer.mozilla.org/en-US/docs/Learn/Common_questions/Tools_and_setup/What_are_browser_developer_tools

Sada nástrojů zabudovaná přímo v prohlížeči (např. Chrome, Firefox), která umožňuje prozkoumávat a ladit HTML, CSS, JavaScript i síťové požadavky.

## --term-- core-web-vitals
en: Core Web Vitals
aliases: CWV
mdn: https://developer.mozilla.org/en-US/docs/Web/Performance
lekce: core-web-vitals#core-web-vitals
Tři hlavní výkonové metriky (LCP, INP, CLS) definované společností Google, které reprezentují uživatelský zážitek a ovlivňují SEO.

## --term-- lcp
en: Largest Contentful Paint
aliases: Largest Contentful Paint
mdn: https://developer.mozilla.org/en-US/docs/Glossary/Largest_contentful_paint
lekce: core-web-vitals#lcp-largest-contentful-paint
Metrika, která měří čas od začátku načítání po chvíli, kdy je na obrazovce vykreslen největší vizuální blok (např. hero obrázek nebo velký nadpis).

## --term-- cls
en: Cumulative Layout Shift
aliases: Cumulative Layout Shift
mdn: https://developer.mozilla.org/en-US/docs/Glossary/CLS
lekce: core-web-vitals#cls-cumulative-layout-shift
Metrika měřící vizuální stabilitu stránky, tedy nakolik prvky na stránce neočekávaně poskakují (například při dočítání obrázků bez rozměrů).

## --term-- inp
en: Interaction to Next Paint
aliases: Interaction to Next Paint
lekce: core-web-vitals#inp-interaction-to-next-paint
Metrika určující, jak rychle dokáže web reagovat na uživatelskou interakci (např. kliknutí), což často ovlivňují dlouhé JavaScriptové úlohy.

## --term-- memory-leak
en: Memory Leak
aliases: únik paměti, únikům paměti
mdn: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Memory_management
lekce: devtools-mapa#uniky-pameti
Chyba v kódu, kdy aplikace trvale udržuje reference na nepoužívaná data, a brání tak garbage collectoru v jejich smazání. Aplikace tím postupně zpomaluje a může spadnout.
