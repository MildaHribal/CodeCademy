<--description-->
Naše nová galerie má stovky obrázků. V `app.js` jsme ke každému obrázku přidali posluchač události pro zvětšení (click).

Když uživatel stránku používá dlouho a v galerii neustále načítá další tisíce obrázků, spotřeba paměti roste a stránka tuhne. Přidávat posluchač na každý tag není efektivní. Pojďme použít vzor zvaný **Event delegation** (delegace událostí).
</--description-->
<--hints-->
Místo cyklu naslouchajícího na každém `.item` přidej jeden posluchač na rodičovský prvek `#gallery`. Událost `click` bublá. Zjisti, jestli uživatel kliknul na prvek se třídou `item` pomocí `event.target.closest()`.
```js
assert.equal(getEventListeners(document.querySelector('#gallery')).click.length, 1, '#gallery musí mít jeden click listener');
```
</--hints-->
<--help-->
## --tip--
Místo `items.forEach` vlož posluchač přímo na `gallery`.
## --tip--
Použij `event.target.closest('.item')`, a pokud vrátí `null`, nic nedělej.
</--help-->
<--seed-->
## --file-- app.js
```js
const gallery = document.querySelector('#gallery');
const items = document.querySelectorAll('.item');

--edit--
items.forEach((item) => {
  item.addEventListener('click', () => {
    item.classList.toggle('zoomed');
  });
});
--edit--
```
</--seed-->
<--solution-->
## --file-- app.js
```js
const gallery = document.querySelector('#gallery');

gallery.addEventListener('click', (event) => {
  const item = event.target.closest('.item');
  if (!item) return;

  item.classList.toggle('zoomed');
});
```
</--solution-->
