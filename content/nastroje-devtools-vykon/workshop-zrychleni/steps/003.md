# --description--

Obrázků na stránce přibývá. Chtěli bychom optimalizovat, jak se načítají.

Hlavní ilustrační fotka ovlivňuje metriku LCP. Zbylé fotky (v galerii dole) nejsou na první pohled vidět. Uživatel na ně musí teprve doscrollovat.

# --hints--

Řekni prohlížeči, že má hlavní ilustraci načíst s co největší prioritou. Naopak fotku `gallery.jpg` ať prohlížeč naopak odloží a stáhne až ve chvíli, kdy se k ní uživatel blíží.
```js
const hero = document.querySelector('img[alt="Ilustrace k článku"]');
const gallery = document.querySelector('img[src="gallery.jpg"]');
assert.equal(hero.getAttribute('fetchpriority'), 'high', 'Hlavní obrázek musí mít vysokou prioritu');
assert.equal(gallery.getAttribute('loading'), 'lazy', 'Obrázek galerie se má načítat líně');
```

# --help--

## --tip--
Pro hlavní obrázek využij `fetchpriority`, pro podružné se hodí líné načítání.
