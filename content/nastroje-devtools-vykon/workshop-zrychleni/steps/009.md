# --description--

Napiš do hledání rychle „elektronika" a sleduj měřicí panel: program se překreslí po každém písmenu, jedenáctkrát za sebou, a každé vykreslení na telefonu zabere přes sto milisekund. Písmena v poli se objevují se zpožděním, protože hlavní vlákno je pořád zaměstnané vykreslováním výsledků, které nikdo neuvidí.

Stačí vykreslit jednou, až uživatel na chvíli přestane psát. Tenhle obal funkce jsi už psal, zkus to bez návodu.

**Úkol:** V `script.js` zařiď, aby se program při hledání vykreslil až **300 ms** po posledním napsaném znaku (smíš zvolit 200–500 ms). Měření s popiskem `Hledání` v panelu zůstane.

# --hints--

Během rychlého psaní se program nevykresluje, po dopsání se vykreslí právě jednou.

```js
const search = document.querySelector('#search');
const before = renderCount;
await helpers.type(search, 'folk');
assert.equal(renderCount, before, `během psaní „folk" se program vykreslil ${renderCount - before}× — má počkat, až uživatel přestane psát`);
await helpers.waitFor(() => renderCount > before, 2000);
await helpers.wait(600);
assert.equal(renderCount - before, 1, `po napsání „folk" se má program vykreslit právě jednou, vykreslil se ${renderCount - before}×`);
assert.equal(document.querySelectorAll('.concert').length, 5, 'hledání „folk" má najít 5 koncertů');
assert.match(document.querySelector('#hud-render').textContent, /^Hledání: /, 'panel má po hledání ukazovat měření s popiskem „Hledání"');
```

Výsledky se objeví nejpozději půl sekundy po posledním znaku.

```js
const search = document.querySelector('#search');
const before = renderCount;
await helpers.type(search, 'jazz');
await helpers.waitFor(() => renderCount > before, 700);
assert.equal(document.querySelectorAll('.concert').length, 2, 'hledání „jazz" má najít 2 koncerty');
```

Každé další psaní po pauze vykreslí nový výsledek.

```js
const search = document.querySelector('#search');
await helpers.type(search, 'pop');
await helpers.waitFor(() => document.querySelectorAll('.concert').length === 6, 2000);
search.value = '';
const before = renderCount;
await helpers.type(search, 'hip hop');
await helpers.waitFor(() => renderCount > before, 2000);
await helpers.wait(600);
assert.equal(renderCount - before, 1, 'druhé hledání „hip hop" má program vykreslit právě jednou');
assert.equal(document.querySelectorAll('.concert').length, 2, 'hledání „hip hop" má najít 2 koncerty');
```

# --help--

## --tip--

Obal, který funkci zavolá až po chvíli klidu, je [[debounce]] z [workshopu o továrnách funkcí](see:js-funkce-hloubka/workshop-tovarny-funkci/014).

## --tip--

Obal si drží id časovače v closure, při každém zavolání předchozí časovač zruší a naplánuje nový. Posluchač `input` na `searchInput` pak dostane místo své šipkové funkce obalenou verzi.

## --tip--

```js
// 1. funkce debounce(fn, delay) si pamatuje časovač
// 2. vrátí obal, který starý časovač zruší
// 3. a naplánuje fn za delay ms
// 4. posluchač input dostane obal místo původní funkce
```

```js
// Chat podpory od externího dodavatele. Skutečný soubor má 380 kB minifikovaného kódu.
(function initChatWidget() {
  // Simulace: stažení a zpracování velkého skriptu trvá na telefonu ~150 ms.
  const end = performance.now() + 150;
  while (performance.now() < end) {}

  function mount() {
    const button = document.createElement('button');
    button.type = 'button';
    button.className = 'chat-button';
    button.textContent = 'Napište nám';
    button.addEventListener('click', () => console.info('Chat podpory: okno otevřeno'));
    document.body.append(button);
  }

  if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', mount);
  else mount();
})();
```
