# --description--

Naše redakce si stěžuje, že když čtou článek a načte se hlavní obrázek, celá stránka jim poskočí a ztratí řádek, kde zrovna četli.

Tvým úkolem je zastavit toto nepříjemné chování, které zhoršuje **CLS** metriku.

# --hints--

Přidej k hlavnímu obrázku fyzické rozměry tak, aby prohlížeč vyhradil místo dřív, než se obrázek stáhne. Šířka je 800, výška 400.
```js
const img = document.querySelector('img');
assert.equal(img.getAttribute('width'), '800', 'Obrázek má mít atribut width roven 800');
assert.equal(img.getAttribute('height'), '400', 'Obrázek má mít atribut height roven 400');
```

# --help--

## --tip--
Prohlížeč před načtením obrázku neví, jak je velký. Můžeš mu to říct atributy.
## --tip--
Přidej do tagu `<img>` atributy `width` a `height`.

# --seed--

## --file-- index.html
```html
<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <title>Článek</title>
</head>
<body>
  <h1>Jak zrychlit web</h1>
  --edit--
  <img src="https://picsum.photos/800/400" alt="Ilustrace k článku">
  --edit--
  <p>Zde je spousta textu, který si lidé čtou...</p>
</body>
</html>
```

# --solution--

## --file-- index.html
```html
<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <title>Článek</title>
</head>
<body>
  <h1>Jak zrychlit web</h1>
  <img src="https://picsum.photos/800/400" width="800" height="400" alt="Ilustrace k článku">
  <p>Zde je spousta textu, který si lidé čtou...</p>
</body>
</html>
```
