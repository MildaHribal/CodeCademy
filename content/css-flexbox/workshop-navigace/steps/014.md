---
title: Karty rostou do volného místa
---

# --description--

Napravo od karet zbývá v každém řádku prázdné místo.

**Úkol:** do pravidla `.card` přidej `flex-grow: 1`.

`flex-grow` říká, jestli a jakým dílem si položka vezme **volné místo** v řádku. Výchozí hodnota je `0` — položka nebere nic. Když mají všechny karty `1`, rozdělí se o volné místo rovným dílem a vyplní celý řádek.

Dvě věci, na které se často zapomíná:

- Číslo určuje podíl na **volném místě**, ne na celkové šířce. Položka s `flex-grow: 2` dostane dvakrát víc volného místa než sousedka s `1`, ale nebude dvakrát širší.
- Každý řádek se počítá zvlášť. Karty ve druhém řádku si dělí volné místo svého řádku. Kdyby tam zbyla jediná karta, roztáhne se přes celou šířku.

Příklad na jiných datech — pole pro zprávu, které vyplní všechno místo vedle tlačítka:

```css
.chat-bar__input {
  flex-grow: 1;
}
```

# --hints--

Karty v prvním řádku vyplní celou šířku seznamu.

```js
const list = document.querySelector('.cards').getBoundingClientRect();
const cards = [...document.querySelectorAll('.card')].map((card) => card.getBoundingClientRect());
const firstRow = cards.filter((card) => Math.abs(card.top - cards[0].top) <= 1);
const right = firstRow.at(-1).right;
assert.ok(Math.abs(right - list.right) <= 1, `Poslední karta v řádku končí na ${right} px, seznam na ${list.right} px`);
```

Karty jsou širší než výchozích 240 px.

```js
const width = document.querySelector('.card').getBoundingClientRect().width;
assert.ok(width > 241, `První karta je široká ${width} px`);
```
