# --description--

Hlavička je hotová. Teď karty s kávou — zatím leží pod sebou přes celou šířku stránky.

Tenhle krok zvládneš bez návodu, všechno potřebné už znáš z hlavičky.

**Úkol:** postav karty ze seznamu `.cards` vedle sebe do řádku s mezerou `1.5rem` mezi kartami.

Po uložení se všech šest karet namačká do jednoho řádku a vyleze ze stránky doprava. To je v pořádku, zatím tak mají vypadat. Než budeš pokračovat, zkus si odpovědět, **proč se karty nezmenší víc** a nevejdou se. Odpověď přijde v dalším kroku.

# --hints--

Seznam `.cards` je flex kontejner.

```js
const cards = document.querySelector('.cards');
assert.equal(getComputedStyle(cards).display, 'flex', 'getComputedStyle(.cards).display má být flex');
```

Karty stojí vedle sebe v jednom řádku s mezerou 24 px (`1.5rem`).

```js
const [first, second] = [...document.querySelectorAll('.card')].map((card) => card.getBoundingClientRect());
assert.ok(Math.abs(first.top - second.top) <= 1, 'Druhá karta má být ve stejném řádku jako první');
const space = second.left - first.right;
assert.ok(Math.abs(space - 24) <= 1, `Mezera mezi první a druhou kartou je ${Math.round(space)} px, čekám 24 px`);
```

# --help--

## --tip--

Karty jsou přímí potomci seznamu, takže rozvrhovat je musí seznam. Připomeň si [Flex kontejner a flex položky](see:css-flexbox/uvod-do-flexboxu#flex-kontejner-a-flex-polozky).

## --tip--

Obě deklarace patří do pravidla `.cards`, ne do `.card`: jedna udělá ze seznamu flex kontejner, druhá nastaví mezeru mezi položkami.

## --tip--

Úplně stejně jsi v pátém kroku rozvrhl odkazy v `.nav-list`, jen s menší mezerou.
