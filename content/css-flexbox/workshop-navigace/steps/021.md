# --description--

Ceny karet v jednom řádku jsou každá jinak vysoko — podle toho, jak dlouhý má karta popis.

**Úkol:** přitlač patičku `.card__footer` (cenu s tlačítkem) ke spodnímu okraji každé karty, aby se ceny v řádku srovnaly na jednu linku.

Kandidáti: automatický margin nad patičkou, nebo růst popisu `.card__text`, který zabere všechno volné místo v kartě. Obojí je správně; první je obvyklejší, protože nezávisí na tom, jaké prvky jsou nad patičkou.

Proč mají karty vůbec volné místo? Seznam `.cards` má výchozí `align-items: stretch`, takže **všechny karty v řádku jsou stejně vysoké jako ta nejvyšší**. Kratší karty mají dole prázdno a to teď připadne patičce.

> [!REMEMBER]
> **Celý řetěz funguje, jen když nikde nechybí článek:** karty v řádku se natáhnou (`stretch` na `.cards`), karta je sloupec a patička je její přímá položka, nad kterou se hromadí volné místo.

# --hints--

Patička je u spodního okraje každé karty.

```js
document.querySelectorAll('.card').forEach((card, i) => {
  const style = getComputedStyle(card);
  const contentBottom = card.getBoundingClientRect().bottom - parseFloat(style.borderBottomWidth) - parseFloat(style.paddingBottom);
  const footer = card.querySelector('.card__footer').getBoundingClientRect();
  assert.ok(Math.abs(footer.bottom - contentBottom) <= 1, `Patička karty ${i + 1} končí na ${Math.round(footer.bottom)} px, obsah karty až na ${Math.round(contentBottom)} px`);
});
```

Ceny karet v prvním řádku leží na stejné výšce.

```js
const cards = [...document.querySelectorAll('.card')];
const top = (card) => card.getBoundingClientRect().top;
const firstRow = cards.filter((card) => Math.abs(top(card) - top(cards[0])) <= 1);
const prices = firstRow.map((card) => card.querySelector('.card__price').getBoundingClientRect().top);
for (const price of prices) {
  assert.ok(Math.abs(price - prices[0]) <= 1, `Ceny v prvním řádku začínají na ${prices.map(Math.round).join(', ')} px — mají být na stejné výšce`);
}
```

Obsah karty nad patičkou zůstává nahoře: barevný pruh začíná u horního okraje karty a popis leží hned pod nadpisem.

```js
const card = document.querySelectorAll('.card')[3];
const style = getComputedStyle(card);
const contentTop = card.getBoundingClientRect().top + parseFloat(style.borderTopWidth) + parseFloat(style.paddingTop);
const origin = card.querySelector('.card__origin').getBoundingClientRect();
const title = card.querySelector('.card__title');
const text = card.querySelector('.card__text').getBoundingClientRect();
const titleGap = text.top - title.getBoundingClientRect().bottom;
const expectedGap = parseFloat(getComputedStyle(title).marginBottom);
assert.ok(Math.abs(origin.top - contentTop) <= 1, `Pruh se zemí ve 4. kartě začíná na ${Math.round(origin.top)} px, obsah karty na ${Math.round(contentTop)} px — obsah se nemá posunout dolů`);
assert.ok(Math.abs(titleGap - expectedGap) <= 1, `Mezi nadpisem a popisem 4. karty je ${Math.round(titleGap)} px, čekám ${expectedGap} px — volné místo patří nad patičku, ne mezi ostatní prvky`);
```

# --help--

## --tip--

Stejný trik jako u tlačítka v hlavičce, jen na svislé ose. Připomeň si [Automatický margin: jedna položka stranou](see:css-flexbox/uvod-do-flexboxu#automaticky-margin-jedna-polozka-stranou).

## --tip--

V kartě vede hlavní osa shora dolů, takže volné místo je **nad** patičkou. Automatický margin na začátku bloku (`margin-block-start`) patří do pravidla `.card__footer`.

## --tip--

V postranním panelu ve sloupci, kde má odkaz „Odhlásit" být vždy úplně dole, dostane `.sidebar__logout` automatický margin na začátku bloku, stejně jako tlačítko v hlavičce dostalo automatický margin na začátku řádku.
