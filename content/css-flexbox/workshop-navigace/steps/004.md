# --description--

Logo, navigace a tlačítko se teď dotýkají.

**Úkol:** do pravidla `.site-header` přidej `gap: 1.5rem`.

Vlastnost `gap` vloží mezeru jen **mezi** položky — ne před první a ne za poslední. Dřív se mezery dělaly marginem na každé položce a pak se musel poslední položce zase odebrat (`li:not(:last-child)`). S `gap` nic takového řešit nemusíš a mezera je nastavená na jednom místě: u kontejneru.

Příklad na jiných datech — řádek štítků u článku:

```css
.tags {
  display: flex;
  gap: 0.5rem; /* mezera jen mezi štítky, na krajích žádná */
}
```

# --hints--

Mezi logem a navigací je mezera 24 px (`1.5rem`).

```js
const logo = document.querySelector('.logo').getBoundingClientRect();
const nav = document.querySelector('.main-nav').getBoundingClientRect();
const space = nav.left - logo.right;
assert.ok(Math.abs(space - 24) <= 1, `Mezera mezi logem a navigací je ${Math.round(space)} px, čekám 24 px`);
```

Mezi navigací a tlačítkem je mezera 24 px (`1.5rem`).

```js
const nav = document.querySelector('.main-nav').getBoundingClientRect();
const button = document.querySelector('.button').getBoundingClientRect();
const space = button.left - nav.right;
assert.ok(Math.abs(space - 24) <= 1, `Mezera mezi navigací a tlačítkem je ${Math.round(space)} px, čekám 24 px`);
```
