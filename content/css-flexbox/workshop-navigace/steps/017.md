# --description--

Podívej se na druhou kartu. Je širší než její sousedky, a přestože má nadpis `.card__title` nastavené oříznutí třemi tečkami (`white-space: nowrap`, `overflow: hidden`, `text-overflow: ellipsis`), dlouhý název „Finca La Esperanza Pink Bourbon" se neořízne. Přepni náhled na **375**: karta přeteče ze stránky a stránka jde posouvat do strany.

**Proč:** flex položka má výchozí `min-width: auto`. U flex položek to znamená „nikdy mě nezmenšuj pod [[nejmenší šířka obsahu|nejmenší šířku mého obsahu]]" (*min-content*). V kartě je nadpis, který se nesmí zalomit, takže nejmenší možná šířka karty je šířka celého názvu. `flex-shrink` ani `flex-basis` s tím nic nenadělají: zmenšování se zastaví na minimu.

**Úkol:** dovol kartám zmenšit se pod šířku jejich obsahu, aby byly všechny karty v řádku stejně široké, oříznutí nadpisu začalo fungovat a na úzké obrazovce nic nepřetékalo.

Kandidáti: větší `flex-shrink`, `min-width` na kartě, nebo `min-width` na nadpisu uvnitř karty. Rozmysli si, **co** zmenšování zastavuje a **kterého prvku** se to týká — jen jedna kombinace dává smysl.

> [!PITFALL]
> Tuhle past potkáš často: dlouhá URL, blok kódu `<pre>`, tabulka nebo text s `nowrap` uvnitř flex položky. Kdykoli se položka „odmítá zmenšit", podívej se nejdřív na její `min-width`.

# --hints--

Karty v prvním řádku jsou stejně široké.

```js
const cards = [...document.querySelectorAll('.card')].map((card) => card.getBoundingClientRect());
const firstRow = cards.filter((card) => Math.abs(card.top - cards[0].top) <= 1);
assert.ok(firstRow.length > 1, 'V prvním řádku mají být aspoň dvě karty');
for (const card of firstRow) {
  assert.ok(Math.abs(card.width - firstRow[0].width) <= 1, `Karty v prvním řádku mají šířky ${firstRow.map((c) => Math.round(c.width)).join(', ')} px — mají být stejné`);
}
```

Při šířce stránky 320 px nic nepřetéká do strany (stránka nejde posouvat vodorovně).

```js
await helpers.resize(320);
const root = document.documentElement;
assert.ok(root.scrollWidth <= root.clientWidth, `Při šířce 320 px je obsah široký ${root.scrollWidth} px, okno jen ${root.clientWidth} px`);
```

# --help--

## --tip--

Zmenšování flex položky zastavuje její minimum, ne malý `flex-shrink`. Přečti si [Proč se položka nezmenší: min-width: auto](see:css-flexbox/flex-do-hloubky#proc-se-polozka-nezmensi-min-width-auto).

## --tip--

Minimum patří flex položce, tedy kartě `.card` — ne nadpisu, ten flex položkou seznamu není. Výchozí hodnota minima je `auto`.

## --tip--

Stejná oprava v jiném rozvržení: postranní panel `.sidebar` ve sloupcovém flexu, který se nechce zmenšit do výšky, dostane ve svém pravidle `min-height: 0`.

# --explain--

Vysvětli vlastními slovy, proč se druhá karta nezmenšila, i když měla `flex-shrink: 1`, a proč pomohla deklarace na kartě, a ne na nadpisu.

## --model--

Flex položka má výchozí `min-width: auto`, takže se nesmí zmenšit pod nejmenší šířku svého obsahu. Nadpis v kartě se nesmí zalomit, a tak minimum karty byla šířka celého názvu; `flex-shrink` zmenšuje jen do té hranice. `min-width: 0` hranici zruší. Patří na kartu, protože flex položkou seznamu je karta, ne nadpis — nadpis se pak ořízne třemi tečkami.

## --checklist--

- Flex položka má výchozí `min-width: auto`.
- `auto` znamená „ne pod nejmenší šířku obsahu" a nezalomitelný nadpis ji zvětší.
- `flex-shrink` zmenšuje jen do hranice minima.
- `min-width: 0` patří na flex položku (kartu), ne na nadpis.
