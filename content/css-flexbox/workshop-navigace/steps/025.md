# --description--

Poslední úkol je samostatná práce na tom, co už umíš. Patička stránky `.site-footer` obsahuje copyright a seznam odkazů `.footer-links`, které teď stojí vedle sebe.

**Úkol:** zařiď, aby

- copyright byl u levého okraje patičky a odkazy u pravého, oboje ve stejném řádku,
- na telefonu (šířka 360 px) nic nepřetékalo a texty se nelámaly uprostřed — když se copyright a odkazy nevejdou vedle sebe, celé přejdou na další řádek, a totéž platí pro jednotlivé odkazy.

## Co jsi v tomhle workshopu použil

- `display: flex` dělá z rodiče [[flex kontejner]]; rozvržení se týká jen jeho přímých potomků.
- Hlavní osa (`flex-direction`) určuje směr řazení, `justify-content` rozděluje volné místo na ní, `align-items` a `align-self` zarovnávají na vedlejší ose.
- `gap` dělá mezery jen mezi položkami, i mezi řádky.
- `flex-wrap: wrap` dovolí položkám přejít na další řádek místo přetečení.
- `flex: <grow> <shrink> <basis>` řídí, z jaké velikosti položka vychází, jestli roste a jestli se zmenšuje — a `flex: 1` tiše nuluje basis.
- Automatický margin odtlačí jednu položku od ostatních, na hlavní i na vedlejší ose.
- `min-width: 0` odemkne zmenšení položky pod šířku jejího obsahu.
- `order` mění jen vizuální pořadí — klávesnice a čtečky jdou podle HTML.

Tyhle vzory najdeš skoro na každém webu: hlavičky, lišty nástrojů, řádky formulářů, vnitřek karet a patičky. Pro mřížku, kde se mají řádky **i** sloupce srovnat najednou, je lepší CSS Grid — jak se rozhodnout, ukáže lekce [Flex do hloubky](see:css-flexbox/flex-do-hloubky#flexbox-nebo-grid).

# --hints--

Copyright je u levého okraje patičky a odkazy u pravého, ve stejném řádku.

```js
const footer = document.querySelector('.site-footer');
const style = getComputedStyle(footer);
const box = footer.getBoundingClientRect();
const contentLeft = box.left + parseFloat(style.paddingLeft);
const contentRight = box.right - parseFloat(style.paddingRight);
const copy = footer.querySelector('.site-footer__copy').getBoundingClientRect();
const links = [...footer.querySelectorAll('.footer-links li')].map((li) => li.getBoundingClientRect());
assert.ok(Math.abs(copy.left - contentLeft) <= 1, `Copyright začíná na ${Math.round(copy.left)} px, obsah patičky na ${Math.round(contentLeft)} px`);
assert.ok(Math.abs(links.at(-1).right - contentRight) <= 1, `Poslední odkaz končí na ${Math.round(links.at(-1).right)} px, obsah patičky na ${Math.round(contentRight)} px`);
assert.ok(links[0].top < copy.bottom && links[0].bottom > copy.top, 'Odkazy mají být ve stejném řádku jako copyright');
```

Odkazy stojí vedle sebe s mezerou.

```js
const links = [...document.querySelectorAll('.footer-links li')].map((li) => li.getBoundingClientRect());
for (let i = 1; i < links.length; i++) {
  assert.ok(Math.abs(links[i].top - links[0].top) <= 1, `Odkaz ${i + 1} není ve stejném řádku jako první`);
  assert.ok(links[i].left - links[i - 1].right >= 8, `Mezera před odkazem ${i + 1} je ${Math.round(links[i].left - links[i - 1].right)} px, čekám aspoň 8 px`);
}
```

Při šířce stránky 360 px nic z patičky nepřetéká přes okraj stránky.

```js
await helpers.resize(360);
const limit = document.documentElement.clientWidth;
document.querySelectorAll('.site-footer__copy, .footer-links li').forEach((part) => {
  const right = part.getBoundingClientRect().right;
  assert.ok(right <= limit, `Při šířce 360 px končí „${part.textContent.trim()}" na ${Math.round(right)} px, stránka je široká ${limit} px`);
});
assert.ok(document.documentElement.scrollWidth <= limit, `Při šířce 360 px je obsah široký ${document.documentElement.scrollWidth} px — stránka jde posouvat do strany`);
```

Při šířce stránky 360 px zůstává copyright i každý odkaz na jednom řádku — zalamují se celé položky, ne text v nich.

```js
await helpers.resize(360);
const lineCount = (el) => {
  const range = document.createRange();
  range.selectNodeContents(el);
  return new Set([...range.getClientRects()].map((rect) => Math.round(rect.top))).size;
};
document.querySelectorAll('.site-footer__copy, .footer-links a').forEach((part) => {
  const lines = lineCount(part);
  assert.equal(lines, 1, `Při šířce 360 px je „${part.textContent.trim()}" rozlámané do ${lines} řádků — zalomit se mají celé položky (počet řádků)`);
});
```

# --help--

## --tip--

Patička je řádek dvou položek, které se mají rozestoupit a při nedostatku místa zalomit; odkazy uvnitř jsou další řádek položek. Zalamování shrnuje [Zalamování: flex-wrap, gap a align-content](see:css-flexbox/uvod-do-flexboxu#zalamovani-flex-wrap-gap-a-align-content).

## --tip--

Kontejnery jsou dva: `.site-footer` (copyright a seznam) a `.footer-links` (jednotlivé odkazy). Oba potřebují zalamování; rozestoupení ke krajům patří jen `.site-footer`.

## --tip--

Hlavička stránky ze začátku workshopu řeší totéž — rozestoupení, mezeru i zalamování — jen se třemi položkami.
