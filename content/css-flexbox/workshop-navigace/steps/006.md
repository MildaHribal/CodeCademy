# --description--

Všechny prvky hlavičky jsou natlačené vlevo a napravo zbývá hodně [[volné místo|volného místa]].

**Úkol:** rozděl volné místo na hlavní ose tak, aby logo stálo u levého okraje hlavičky, tlačítko u pravého a navigace přesně mezi nimi, se stejnou mezerou na obou stranách.

Rozdělení volného místa na hlavní ose řídí vlastnost `justify-content` na kontejneru. Výchozí `flex-start` nechá položky na začátku osy a všechno volné místo zůstane za nimi. Do úvahy přicházejí tyhle hodnoty — rozmysli si, která odpovídá zadání, a pak ji vyzkoušej:

| hodnota | co udělá s volným místem |
|---|---|
| `center` | rozdělí ho napůl před první a za poslední položku |
| `space-between` | rozdělí ho rovným dílem **mezi** položky, na kraje nedá nic |
| `space-around` | dá každé položce stejný kus místa z obou stran, takže na krajích zůstane polovina mezery |

`gap` přitom zůstává nejmenší mezerou — volné místo se k ní přičítá.

Příklad na jiných datech — přepínač stránek pod galerií, který má stát uprostřed:

```css
.gallery-pager {
  display: flex;
  justify-content: center;
}
```

# --hints--

Tlačítko „Objednat" je přisunuté k pravému okraji hlavičky (až k vnitřnímu odsazení).

```js
const header = document.querySelector('.site-header');
const contentRight = header.getBoundingClientRect().right - parseFloat(getComputedStyle(header).paddingRight);
const button = document.querySelector('.button').getBoundingClientRect();
assert.ok(Math.abs(button.right - contentRight) <= 1, `Pravý okraj tlačítka je na ${Math.round(button.right)} px, obsah hlavičky končí na ${Math.round(contentRight)} px`);
```

Logo je u levého okraje a navigace je uprostřed: mezera mezi logem a navigací je stejná jako mezi navigací a tlačítkem.

```js
const header = document.querySelector('.site-header');
const contentLeft = header.getBoundingClientRect().left + parseFloat(getComputedStyle(header).paddingLeft);
const logo = document.querySelector('.logo').getBoundingClientRect();
const nav = document.querySelector('.main-nav').getBoundingClientRect();
const button = document.querySelector('.button').getBoundingClientRect();
const left = nav.left - logo.right;
const right = button.left - nav.right;
assert.ok(Math.abs(logo.left - contentLeft) <= 1, `Logo začíná na ${Math.round(logo.left)} px, obsah hlavičky na ${Math.round(contentLeft)} px`);
assert.ok(left > 24, `Mezera mezi logem a navigací je jen ${Math.round(left)} px — navigace nemá stát hned u loga`);
assert.ok(Math.abs(left - right) <= 1, `Mezera vlevo od navigace je ${Math.round(left)} px, vpravo ${Math.round(right)} px`);
```
