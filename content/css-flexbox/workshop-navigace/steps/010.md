# --description--

Na úzké obrazovce se hlavička teď zalamuje podle toho, co se kam zrovna vejde. Chceme pevné pravidlo: na úzké obrazovce dostane navigace vlastní řádek přes celou šířku hlavičky.

Potřebuješ k tomu dvě nové věci:

- **Media dotaz.** Pravidla uvnitř bloku `@media (…) { … }` platí jen tehdy, když okno splňuje podmínku v závorce. Podmínka `max-width: 40rem` znamená „okno široké nejvýš 40rem (640 px)". Media dotazům se podrobně věnuje sekce o responzivním designu; teď stačí vědět, že pravidla pro úzké obrazovky se píšou dovnitř takového bloku.
- **`flex-basis`** — výchozí velikost položky na hlavní ose, ze které flexbox vychází, než začne volné místo přidávat nebo ubírat. Hodnota v procentech se počítá z velikosti kontejneru. Vedle položky, která chce celou šířku, se nic nevejde, takže se díky `flex-wrap: wrap` z minulého kroku zalomí na vlastní řádek.

**Úkol:** seřaď řádky do bloku media dotazu s pravidlem pro `.main-nav` a doplň hodnotu `flex-basis` tak, aby navigace chtěla celou šířku hlavičky. Pořadí měníš šipkami nahoru a dolů, odsazení klávesou Tab. Dva řádky jsou navíc.

Výsledek uvidíš, když přepneš náhled na **375**: logo nahoře, pod ním navigace přes celou šířku a tlačítko až pod ní. S tlačítkem se vypořádáš v příštím kroku.

> [!PITFALL]
> `min-width` a `max-width` v media dotazu se pletou snadno. `max-width: 40rem` platí pro ==úzká== okna (do 40rem), `min-width: 40rem` pro ==široká== (od 40rem výš).

# --hints--

Při šířce stránky 375 px má navigace vlastní řádek přes celou šířku hlavičky.

```js
await helpers.resize(375);
const header = document.querySelector('.site-header');
const style = getComputedStyle(header);
const box = header.getBoundingClientRect();
const contentWidth = box.width - parseFloat(style.paddingLeft) - parseFloat(style.paddingRight);
const nav = document.querySelector('.main-nav').getBoundingClientRect();
const logo = document.querySelector('.logo').getBoundingClientRect();
assert.ok(Math.abs(nav.width - contentWidth) <= 1, `Při šířce 375 px je navigace široká ${Math.round(nav.width)} px, hlavička má uvnitř ${Math.round(contentWidth)} px`);
assert.ok(nav.top >= logo.bottom, 'Při šířce 375 px má být navigace pod logem');
```

Při šířce stránky 1024 px zůstává navigace hned vedle loga.

```js
const logo = document.querySelector('.logo').getBoundingClientRect();
const nav = document.querySelector('.main-nav').getBoundingClientRect();
const space = nav.left - logo.right;
assert.ok(nav.top < logo.bottom, 'Při šířce 1024 px má navigace stát ve stejném řádku jako logo — platí pravidlo jen pro úzká okna?');
assert.ok(Math.abs(space - 24) <= 1, `Při šířce 1024 px je mezera mezi logem a navigací ${Math.round(space)} px, čekám 24 px`);
```

# --help--

## --tip--

Výchozí velikost položky na hlavní ose je `flex-basis`, víc v části [Tři čísla: basis, grow, shrink](see:css-flexbox/flex-do-hloubky#tri-cisla-basis-grow-shrink). Procenta se počítají ze šířky kontejneru, tedy hlavičky.

## --tip--

Nejvíc chybí na tom, který z obou `@media` řádků platí pro úzká okna. Pravidlo pro navigaci patří **dovnitř** bloku media dotazu, proto je o úroveň odsazené.
