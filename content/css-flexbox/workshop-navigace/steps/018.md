---
title: Jedna položka jinak — align-self
---

# --description--

Štítek „Nová sklizeň" je zelený pruh přes celou šířku karty. V kartě je vedlejší osa vodorovná a výchozí `align-items: stretch` roztáhne každou položku na celou šířku kontejneru.

Pro nadpis a popis je to přesně, co chceme. Jen štítek má být malý. Vlastnost `align-self` na položce přepíše `align-items` kontejneru **jen pro tuhle jednu položku**. Hodnoty jsou stejné: `stretch`, `flex-start`, `center`, `flex-end`…

**Úkol:** do pravidla `.card__badge` přidej `align-self: flex-start`. Štítek bude jen tak široký jako jeho text a zůstane na začátku vedlejší osy, tedy vlevo.

Příklad na jiných datech — formulář ve sloupci, kde pole jsou přes celou šířku, ale odesílací tlačítko je vpravo:

```css
.signup-form {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}

.signup-form__submit {
  align-self: flex-end;
}
```

# --hints--

Štítek „Nová sklizeň" je jen tak široký jako jeho text a zůstává u levého okraje karty.

```js
const card = document.querySelector('.card');
const cardBox = card.getBoundingClientRect();
const cardStyle = getComputedStyle(card);
const contentLeft = cardBox.left + parseFloat(cardStyle.borderLeftWidth) + parseFloat(cardStyle.paddingLeft);
const contentWidth = card.clientWidth - parseFloat(cardStyle.paddingLeft) - parseFloat(cardStyle.paddingRight);
const badge = card.querySelector('.card__badge').getBoundingClientRect();
assert.ok(badge.width < contentWidth / 2, `Štítek je široký ${badge.width} px, karta má uvnitř ${contentWidth} px`);
assert.ok(Math.abs(badge.left - contentLeft) <= 1, 'Štítek má začínat u levého okraje obsahu karty');
```

Nadpis karty zůstává přes celou šířku karty.

```js
const card = document.querySelector('.card');
const cardStyle = getComputedStyle(card);
const contentWidth = card.clientWidth - parseFloat(cardStyle.paddingLeft) - parseFloat(cardStyle.paddingRight);
const title = card.querySelector('.card__title').getBoundingClientRect();
assert.ok(Math.abs(title.width - contentWidth) <= 1, `Nadpis je široký ${title.width} px, karta má uvnitř ${contentWidth} px`);
```
