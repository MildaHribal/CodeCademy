# --description--

Na široké obrazovce to není vidět, ale na telefonu se hlavička rozbije. Nad náhledem přepni šířku na **375** (menší telefon): logo „Pražírna Zrno" se zlomí na dva řádky a odkazy se namačkají na sebe. Pak můžeš přepnout zpátky na „Jako testy".

**Proč se to děje:** když se položky do řádku nevejdou, flexbox je zmenšuje. Každá položka má výchozí `flex-shrink: 1`, takže se smršťuje spolu s ostatními — až k nejmenší šířce, kterou její obsah dovolí. U textu je to šířka nejdelšího slova, proto se víceslovné logo zalomí.

Logo se ale zmenšovat nemá. Vlastnost `flex-shrink` říká, jestli a jakým dílem se položka podílí na zmenšování, když místo chybí. Hodnota `0` znamená „mě nezmenšuj".

**Úkol:** do pravidla `.logo` přidej `flex-shrink: 0`.

Až to uděláš a znovu přepneš náhled na 375, uvidíš, že logo drží na jednom řádku, ale tlačítko teď vyčuhuje z hlavičky ven. To vyřešíš v příštím kroku.

Příklad na jiných datech — cena v řádku nákupního košíku se nikdy nesmí zalomit, zatímco dlouhý název zboží ano:

```css
.cart-row {
  display: flex;
  gap: 1rem;
}

.cart-row__price {
  flex-shrink: 0;
}
```

# --hints--

Při šířce stránky 375 px je logo „Pražírna Zrno" na jednom řádku.

```js
await helpers.resize(375);
const range = document.createRange();
range.selectNodeContents(document.querySelector('.logo'));
const lineTops = new Set([...range.getClientRects()].map((rect) => Math.round(rect.top)));
assert.equal(lineTops.size, 1, 'Při šířce 375 px má být text loga na jednom řádku (počet řádků)');
```

Při šířce stránky 1024 px zůstává hlavička v jednom řádku: logo, navigace, tlačítko.

```js
const logo = document.querySelector('.logo').getBoundingClientRect();
const nav = document.querySelector('.main-nav').getBoundingClientRect();
const button = document.querySelector('.button').getBoundingClientRect();
assert.ok(nav.left >= logo.right && button.left >= nav.right, 'Při šířce 1024 px má být pořadí v řádku logo, navigace, tlačítko');
assert.ok(nav.top < logo.bottom && button.top < logo.bottom, `Všechny tři prvky mají být ve stejném řádku (logo ${Math.round(logo.top)}–${Math.round(logo.bottom)} px, navigace od ${Math.round(nav.top)} px, tlačítko od ${Math.round(button.top)} px)`);
```

# --help--

## --tip--

Když se položky do řádku nevejdou, flexbox je zmenšuje, dokud mu to obsah dovolí. Jak se ztráta dělí mezi položky, ukazuje část [Zmenšování v číslech](see:css-flexbox/flex-do-hloubky#zmensovani-v-cislech).

## --tip--

Zmenšování jedné položky vypneš vlastností `flex-shrink`. Patří do pravidla loga, ne do pravidla hlavičky — týká se jen té jedné položky.

## --tip--

Stejný vzor jinde: ikona v řádku seznamu, která se nikdy nemá smrsknout, dostane ve svém pravidle `flex-shrink` s hodnotou nula, zatímco text vedle ní se zmenšovat smí.
