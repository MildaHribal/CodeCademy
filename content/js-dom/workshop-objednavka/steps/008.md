# --description--

Zákazník by ani neměl mít možnost objednávku odeslat, dokud není formulář správně vyplněn. Přidáme tedy JavaScriptu logiku, která bude tlačítko povolovat a zakazovat v reálném čase.

**Úkol:** V posluchači `input` zjisti přes `form.checkValidity()`, jestli jsou data validní. Tlačítku uvnitř formuláře pak nastav vlastnost `disabled` na `true`, pokud formulář validní *není*, a na `false`, pokud *je*. Tlačítko měj předem připravené do proměnné. Do HTML jsme mu pro tebe rovnou přidali výchozí atribut `disabled`, aby ho uživatel nemohl zmáčknout, dokud něco nenapíše.

# --hints--

Povolí se tlačítko, když jsou pole vyplněná?
```js
const form = document.getElementById('order');
const btn = document.querySelector('form button');

form.querySelector('input[name="name"]').value = 'Jan';
form.querySelector('input[name="email"]').value = 'jan@example.com';
form.dispatchEvent(new Event('input', { bubbles: true }));

assert.equal(btn.disabled, false, 'Když je formulář validní, disabled má být false');

form.querySelector('input[name="email"]').value = 'jan'; // Nevalidní email
form.dispatchEvent(new Event('input', { bubbles: true }));

assert.equal(btn.disabled, true, 'Když formulář validní není, disabled má být true');
```

# --help--

## --tip--

Zakázat tlačítko se dá vlastností `disabled`. Pozor na rozdíl mezi atributem v HTML
a vlastností v JavaScriptu — tady nastavuješ vlastnost.

## --tip--

Hodnota je pravý opak toho, co vrací kontrola platnosti formuláře: když je formulář
platný, tlačítko zakázané **není**.

## --tip--

Stejný vzor u souhlasu s podmínkami: `odeslat.disabled = !souhlas.checked;`.

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');
const summaryName = document.getElementById('summary-name');
const btn = document.querySelector('form button');

form.addEventListener('input', () => {
  const data = new FormData(form);
  summaryName.textContent = data.get('name');
  btn.disabled = !form.checkValidity();
});

form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    errorDiv.textContent = 'Zkontroluj prosím zvýrazněná pole.';
  } else {
    errorDiv.textContent = 'Všechno v pořádku.';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
  } else {
    companyInfo.style.display = 'none';
  }
});
```
