# --description--

Někdy chceme, aby se část formuláře ukázala, jen když si uživatel vybere určitou možnost. Do HTML jsme připravili zaškrtávací pole "Nakupuji na firmu" a zatím skrytý div s polem pro IČO (má `style="display: none"`).

**Úkol:** V události `change` na checkboxu `is-company` ukaž, nebo skryj element s id `company-info`. Pokud je checkbox zaškrtnutý (`checked`), nastav stylu `display` hodnotu `block`, v opačném případě hodnotu `none`.

# --hints--

Přepíná se zobrazení podle checkboxu?
```js
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');

checkbox.checked = true;
checkbox.dispatchEvent(new Event('change'));
assert.equal(companyInfo.style.display, 'block', 'Pokud je checkbox zaškrtnutý, div musí mít display: block');

checkbox.checked = false;
checkbox.dispatchEvent(new Event('change'));
assert.equal(companyInfo.style.display, 'none', 'Pokud se checkbox odškrtne, div musí mít opět display: none');
```

# --solution--

## --file-- index.html
```html
<form id="order" novalidate>
  <div id="error" style="color: red;"></div>
  <input type="text" name="name" required placeholder="Jméno">
  <input type="email" name="email" required placeholder="E-mail">
  
  <label>
    <input type="checkbox" id="is-company"> Nakupuji na firmu
  </label>
  <div id="company-info" style="display: none;">
    <input type="text" name="ico" placeholder="IČO">
  </div>
  
  <button>Objednat</button>
</form>
```

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  const data = new FormData(form);
  if (data.get('name').length === 0) {
    errorDiv.textContent = 'Chybí jméno';
  } else {
    errorDiv.textContent = '';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
  } else {
    companyInfo.style.display = 'none';
  }
});
```
