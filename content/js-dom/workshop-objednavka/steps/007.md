# --description--

Zpráva "Zkontroluj prosím zvýrazněná pole" nedává smysl, pokud pole zvýrazněná nejsou. Místo toho, abychom přes JavaScript hledali všechna vadná pole a přidávali jim třídu `.error`, využijeme CSS pseudo-třídu pro validaci. 

Chceme ale uživatele na chybu upozornit až ve chvíli, kdy tam něco zkusí napsat, nebo až když se pokusí formulář odeslat.

**Úkol:** V souboru `style.css` vytvoř pravidlo pro `input` (text i e-mail), které obarví rámeček načerveno (`border-color: red`), když obsahuje chybu, ale *jen pokud* s ním uživatel interagoval.

# --hints--

Má input obarvený rámeček v nesprávném stavu?
```js
assert.match(files['style.css'], /input:user-invalid/, 'CSS musí používat pseudo-třídu :user-invalid pro tag input');
assert.match(files['style.css'], /border-color:\s*red/, 'Rámeček (border-color) má být red');
```

# --help--

## --tip--

Pseudotřídy, které se týkají platnosti pole, jsou v části
[CSS a validace](see:html-formulare/validace-v-prohlizeci#css-a-validace-pseudotridy).

## --tip--

`:invalid` platí od načtení stránky, takže by prázdný formulář svítil červeně hned.
Potřebuješ tu druhou — tu, která začne platit až poté, co uživatel do pole sáhl nebo
zkusil odeslat.

## --tip--

Stejně se obarvuje platné pole: `input:user-valid { border-color: green; }`.

## --file-- index.html
```html
<form id="order" novalidate>
  <div id="error" style="color: red;"></div>
  <input type="text" name="name" required placeholder="Jméno">
  <input type="email" name="email" required placeholder="E-mail">
  
  <label>
    <input type="checkbox" id="is-company"> Nakupuji na firmu
  </label>
  <div id="company-info" style="display: none;">
    <input type="text" name="ico" placeholder="IČO">
  </div>
  
  <button>Objednat</button>
</form>

<div class="summary">
  Vytváříme objednávku pro: <strong id="summary-name"></strong>
</div>
```

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');
const summaryName = document.getElementById('summary-name');

form.addEventListener('input', () => {
  const data = new FormData(form);
  summaryName.textContent = data.get('name');
});

form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    errorDiv.textContent = 'Zkontroluj prosím zvýrazněná pole.';
  } else {
    errorDiv.textContent = 'Všechno v pořádku.';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
  } else {
    companyInfo.style.display = 'none';
  }
});
```

## --file-- style.css
```css
input {
  border: 1px solid #ccc;
  padding: 5px;
}
input:user-invalid {
  border-color: red;
}
```
