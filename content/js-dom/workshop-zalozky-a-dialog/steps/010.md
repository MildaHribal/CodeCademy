# --description--

## Hlášení

Kolega mezitím připojil tlačítka **Detail** na kartách: jeden posluchač na `<main class="tabs">` a volání `openDetail` s `data-id` tlačítka. „U mě to funguje," napsal.

Tester hlásí: „Detail se otevře, jen když kliknu úplně na okraj tlačítka. Když kliknu na slovo Detail nebo na ikonu, nestane se nic a v konzoli žádná chyba není."

## Úkol

Oprav kolegův posluchač tak, aby se detail otevřel po kliknutí kamkoli do tlačítka **Detail**. Změň co nejmenší kus kódu.

# --hints--

Kliknutí na slovo **Detail** u kapely Sestry Novákovy otevře její detail.

```js
await helpers.click(document.querySelector('[data-id="sestry-novakovy"] .act__detail span'));
assert.equal(document.querySelector('#detail').open, true, 'po kliknutí na <span>Detail</span> v tlačítku má být dialog otevřený');
assert.equal(document.querySelector('#detail-name').textContent, 'Sestry Novákovy', 'v dialogu má být jméno Sestry Novákovy');
```

Kliknutí na ikonu v tlačítku otevře detail.

```js
await helpers.click(document.querySelector('[data-id="ticha-dohoda"] .act__icon path'));
assert.equal(document.querySelector('#detail').open, true, 'po kliknutí na ikonu (svg) v tlačítku má být dialog otevřený');
assert.equal(document.querySelector('#detail-name').textContent, 'Tichá dohoda', 'v dialogu má být jméno Tichá dohoda');
```

Kliknutí na kartu mimo tlačítko a záložky fungují dál.

```js
await helpers.click(document.querySelector('[data-id="ticha-dohoda"] .act__name'));
assert.equal(document.querySelector('#detail').open, false, 'kliknutí na jméno kapely mimo tlačítko nemá detail otevřít');
await helpers.click(document.querySelector('#tab-sobota'));
assert.equal(document.querySelector('#panel-sobota').hidden, false, 'záložky mají fungovat dál');
assert.equal(errors.length, 0, 'kliknutí mimo tlačítko Detail nemá vyhodit chybu: ' + errors.join('; '));
```

# --help--

## --tip--

Porovnej, na který prvek ukazuje `event.target`, když klik trefí ikonu — [target a currentTarget](see:js-dom/udalosti#target-a-currenttarget).

## --tip--

Tlačítko s `data-action` je předek prvku, na který se kliklo. V delegaci ho najde metoda, kterou jsi použil u záložek.

# --explain--

Vysvětli, proč kolegův posluchač fungoval jen při kliknutí na okraj tlačítka.

## --model--

Posluchač je na předkovi a četl `event.target`, což je nejhlubší prvek, na který uživatel klikl. Při kliknutí na okraj tlačítka je to tlačítko s `data-action`, ale při kliknutí na text nebo ikonu je to `span` nebo `path`, které atributy nemají, a podmínka neplatí. `event.target.closest('[data-action="detail"]')` najde tlačítko nad jakýmkoli vnitřním prvkem.

## --checklist--

- `event.target` je nejhlubší prvek, na který se kliklo.
- Při kliknutí na ikonu nebo text je cílem vnitřní prvek bez `data-action`.
- `closest` najde nejbližšího předka, který odpovídá selektoru.

```js
// Vybere záložku: nastaví atributy všech záložek a ukáže její panel.
function selectTab(tab) {
  for (const other of tablist.querySelectorAll('[role="tab"]')) {
    const isSelected = other === tab;
    other.setAttribute('aria-selected', String(isSelected));
    document.getElementById(other.getAttribute('aria-controls')).hidden = !isSelected;
    other.tabIndex = isSelected ? 0 : -1;
  }
}

// Zapíše údaje vystupujícího do dialogu s detailem.
function fillDetail(performer) {
  document.querySelector('#detail-name').textContent = performer.name;
  document.querySelector('#detail-meta').textContent = `${performer.time} · ${performer.stage}`;
  document.querySelector('#detail-genre').textContent = performer.genre;
  document.querySelector('#detail-description').textContent = performer.description;
}

// Otevře modální detail vystupujícího podle id.
function openDetail(id) {
  const performer = lineup.find((item) => item.id === id);
  if (!performer) return;
  fillDetail(performer);
  dialog.showModal();
}
```

```js
// Vybere záložku: nastaví atributy všech záložek a ukáže její panel.
function selectTab(tab) {
  for (const other of tablist.querySelectorAll('[role="tab"]')) {
    const isSelected = other === tab;
    other.setAttribute('aria-selected', String(isSelected));
    document.getElementById(other.getAttribute('aria-controls')).hidden = !isSelected;
    other.tabIndex = isSelected ? 0 : -1;
  }
}
```
