# --description--

Kdo stránku používá se čtečkou obrazovky, slyší u každého úkolu „tlačítko, krát". Pět stejných tlačítek bez jména a netuší, které smaže který úkol.

**Úkol:** V `createTaskElement` dej tlačítku `.task__delete` přístupný název ve tvaru **Smazat úkol** a za mezerou název úkolu, například „Smazat úkol Rozebrat postel". Viditelný křížek zůstane.

Přístupný název tlačítka bez textu se zapisuje do atributu `aria-label`. Atribut, ne text uvnitř tlačítka — ten by se ukázal i vidícím.

# --hints--

Tlačítko × u každého úkolu má `aria-label` „Smazat úkol" a název úkolu.

```js
const labels = [...document.querySelectorAll('#task-list .task__delete')].map((button) => button.getAttribute('aria-label'));
assert.deepEqual(labels, tasks.map((task) => 'Smazat úkol ' + task.title), 'tlačítka .task__delete mají mít aria-label ve tvaru „Smazat úkol <název>"');
```

Na tlačítku je dál vidět jen křížek.

```js
const button = createTaskElement({ id: 80, title: 'Předat klíče', room: 'úřady', done: false }).querySelector('.task__delete');
assert.equal(button.textContent.trim(), '×', 'viditelný text tlačítka má zůstat ×');
assert.equal(button.getAttribute('aria-label'), 'Smazat úkol Předat klíče', 'createTaskElement(Předat klíče) má tlačítku dát aria-label „Smazat úkol Předat klíče"');
```

# --help--

## --tip--

Atribut nastavíš metodou prvku — tabulka je v části [Atributy a vlastnosti](see:js-dom/strom-dom#atributy-a-vlastnosti-classlist-dataset-a-spol).

## --tip--

Hodnota atributu je text složený z pevného začátku a `task.title`; template literal se hodí.

## --tip--

Stejně u tlačítka s ikonou srdce: `aria-label` „Přidat do oblíbených" a za ním název produktu.

// Úkoly ke stěhování. Tohle pole je jediný zdroj pravdy: stránka se z něj vykresluje.
let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

// Id, které dostane příští nový úkol.
let nextId = 6;

// Kolik úkolů ještě není hotových.
function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

// Vypíše do hlavičky, kolik úkolů zbývá a kolik jich je celkem.
function renderCounts() {
  document.querySelector('#open-count').textContent = countOpen(tasks);

  li.querySelector('.task__room').textContent = task.room;
  li.classList.toggle('is-done', task.done);
  li.querySelector('.task__toggle').checked = task.done;

  const task = { id: nextId, title, room: 'ostatní', done: false };
  nextId += 1;
  return task;
}

// Přepne úkolu s daným id hotovo/nehotovo a překreslí stránku.
function toggleTask(id) {
  tasks = tasks.map((task) => (task.id === id ? { ...task, done: !task.done } : task));
  render();
}

// Smaže úkol s daným id a překreslí stránku.
function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
  render();

  const title = document.querySelector('#task-title').value.trim();

    return;
  }
  tasks = [...tasks, createTask(title)];
  render();
  event.target.reset();
  document.querySelector('#task-title').focus();
});

document.querySelector('#clear-done').addEventListener('click', () => {
  tasks = tasks.filter((task) => !task.done);
  render();
