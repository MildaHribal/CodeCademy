# --description--

Teď z celého pole `tasks` uděláš prvky a vložíš je do `#task-list`. Tohle je nejdůležitější vzor celé sekce, proto ho tentokrát jen skládáš a v dalších workshopech ho napíšeš sám:

1. najdi kontejner,
2. z každé položky dat vyrob prvek (`map` s funkcí z minulého kroku),
3. **nahraď** obsah kontejneru novými prvky.

Na třetí bod slouží `container.replaceChildren(a, b, c)`: smaže všechno, co v kontejneru bylo, a vloží tam předané uzly. Dostává uzly jako samostatné argumenty, ne pole — pole na argumenty rozloží spread.

**Úkol:** Seřaď řádky tak, aby funkce `renderTasks()` vykreslila všechny úkoly z `tasks` do `#task-list` a hned se zavolala. Odsazení nastavíš klávesou Tab a do mezery doplň, co dostane `replaceChildren`. Dva řádky jsou navíc.

# --hints--

Po načtení stránky je v `#task-list` pět prvků `<li>` s názvy úkolů v pořadí z `tasks`.

```js
const items = [...document.querySelectorAll('#task-list > li')];
assert.equal(items.length, 5, '#task-list má mít po načtení 5 prvků <li>, má ' + items.length);
assert.deepEqual(items.map((li) => li.textContent.trim()), tasks.map((task) => task.title), 'prvky v #task-list mají mít názvy úkolů ve stejném pořadí jako tasks');
```

Druhé zavolání `renderTasks()` obsah seznamu nahradí, nepřidá k němu.

```js
tasks = [{ id: 30, title: 'Předat klíče', room: 'úřady', done: false }];
renderTasks();
renderTasks();
const items = document.querySelectorAll('#task-list > li');
assert.equal(items.length, 1, 'po tasks = [jeden úkol] a dvou voláních renderTasks() má být v seznamu 1 prvek, je ' + items.length);
```

# --parsons--

```js
function renderTasks() {
  const list = document.querySelector('#task-list');
  const items = tasks.map((task) => createTaskElement(task));
  list.replaceChildren(__1__);
}

renderTasks();
```

## --file-- script.js

```js
// Úkoly ke stěhování. Tohle pole je jediný zdroj pravdy: stránka se z něj vykresluje.
let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

// Id, které dostane příští nový úkol.
let nextId = 6;

// Kolik úkolů ještě není hotových.
function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

// Vypíše do hlavičky, kolik úkolů zbývá a kolik jich je celkem.
function renderCounts() {
  document.querySelector('#open-count').textContent = countOpen(tasks);
  document.querySelector('#total-count').textContent = tasks.length;
}

// Vytvoří prvek <li> pro jeden úkol. Do stránky ho nevkládá.
function createTaskElement(task) {
  const li = document.createElement('li');
  li.classList.add('task');
  li.textContent = task.title;
  return li;
}

--edit--

// Start aplikace

renderCounts();
```
