# --description--

## Hlášení

Kolega chtěl, aby šlo v názvu úkolu zvýraznit slovo, a v `createTaskElement` změnil jeden řádek. Eva si hned přidala úkol `Koupit <b>krabice</b>` a slovo „krabice" bylo tučně.

Pak jí bratr ze žertu přidal úkol:

```text
<img src="x" onerror="document.querySelector('h1').textContent = 'Hacknuto'">
```

Úkol se v seznamu zobrazil jako prázdný řádek a nadpis stránky se změnil na „Hacknuto". Kdyby seznam sdílelo víc lidí, stejný kód by se spustil u každého z nich a mohl by třeba mazat jejich úkoly.

## Úkol

Oprav `createTaskElement` tak, aby se název úkolu vždycky zobrazil jako obyčejný text a žádný kód z něj nespustil. Změň co nejmenší kus kódu. Zvýraznění slov se vzdáš — bezpečnost má přednost.

# --hints--

Název s HTML značkou se zobrazí jako text a nevznikne z něj žádný element.

```js
let prevented = null;
document.addEventListener('submit', (event) => {
  prevented = event.defaultPrevented;
  event.preventDefault();
});
const attack = '<img src="x" onerror="document.querySelector(\'h1\').textContent = \'Hacknuto\'">';
document.querySelector('#task-title').value = attack;
document.querySelector('#add-form').requestSubmit();
await helpers.wait(300);
const title = document.querySelectorAll('#task-list .task__title')[5];
assert.ok(title, 'po přidání úkolu má být v seznamu šestý úkol');
assert.equal(title.querySelector('img'), null, 'z názvu úkolu nesmí vzniknout element <img> — název patří do stránky jako text');
assert.equal(title.textContent, attack, 'v .task__title má být celý název doslova, i se značkou');
assert.equal(document.querySelector('h1').textContent, 'Co ještě zbývá', 'nadpis stránky se nesmí změnit — kód z názvu úkolu se nemá spustit');
```

Běžné úkoly se vykreslují dál s názvem a místností.

```js
const titles = [...document.querySelectorAll('#task-list .task__title')].map((el) => el.textContent);
assert.deepEqual(titles, tasks.map((task) => task.title), 'po načtení mají být v seznamu názvy všech úkolů');
assert.equal(document.querySelector('#task-list .task__room').textContent, 'obývák', 'první úkol má dál ukazovat místnost obývák');
```

# --help--

## --tip--

Tohle je útok XSS: text od uživatele se vložil jako HTML. Přečti si [Text a HTML: textContent a innerHTML](see:js-dom/strom-dom#text-a-html-textcontent-a-innerhtml).

## --tip--

Chyba je na jediném řádku v `createTaskElement` — tam, kde se do `.task__title` zapisuje název. Stejnou vlastnost už používá řádek pro místnost hned pod ním.

# --explain--

Vysvětli, proč název úkolu nesmí jít do stránky přes `innerHTML`, i když ho píše „jen" uživatel aplikace.

## --model--

`innerHTML` bere řetězec jako HTML: prohlížeč z něj postaví značky a spustí i obslužný kód v atributech jako `onerror`. Název úkolu napsal člověk, takže v něm může být cokoli, a u sdíleného seznamu se kód spustí každému, kdo seznam otevře. Tomu se říká XSS. `textContent` vloží řetězec jako text, značky se jen zobrazí a nic se nespustí.

## --checklist--

- `innerHTML` řetězec rozebere na HTML značky.
- Z atributů jako `onerror` se spustí kód.
- Text od uživatele může obsahovat cokoli, i cizí skript.
- `textContent` vloží řetězec jako text a nic nespustí.

// Úkoly ke stěhování. Tohle pole je jediný zdroj pravdy: stránka se z něj vykresluje.
let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

// Id, které dostane příští nový úkol.
let nextId = 6;

// Kolik úkolů ještě není hotových.
function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

// Vypíše do hlavičky, kolik úkolů zbývá a kolik jich je celkem.
function renderCounts() {
  document.querySelector('#open-count').textContent = countOpen(tasks);
  document.querySelector('#total-count').textContent = tasks.length;
}

// Vytvoří prvek <li> pro jeden úkol. Do stránky ho nevkládá.
--edit--
function createTaskElement(task) {
  const template = document.querySelector('#task-template');
  const li = template.content.firstElementChild.cloneNode(true);
  // Kolega: innerHTML, ať jde v názvu psát <b>tučně</b>.
  li.querySelector('.task__title').innerHTML = task.title;
  li.querySelector('.task__room').textContent = task.room;
  li.classList.toggle('is-done', task.done);
  li.querySelector('.task__toggle').checked = task.done;
  return li;
}
--edit--

function renderTasks() {
  const list = document.querySelector('#task-list');
  const items = tasks.map((task) => createTaskElement(task));
  list.replaceChildren(...items);
}

// Uvede celou stránku do souladu s daty v tasks.
function render() {
  renderTasks();
  renderCounts();
  document.querySelector('#empty-state').hidden = tasks.length > 0;
}

// Vytvoří nový nehotový úkol s jedinečným id. Do tasks ho nevkládá.

  const task = { id: nextId, title, room: 'ostatní', done: false };
  nextId += 1;
  return task;
}

render();

document.querySelector('#add-form').addEventListener('submit', (event) => {
  event.preventDefault();
  const title = document.querySelector('#task-title').value.trim();
  if (title === '') {

  render();
  event.target.reset();
  document.querySelector('#task-title').focus();
});
