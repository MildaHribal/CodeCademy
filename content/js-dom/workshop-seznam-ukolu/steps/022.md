# --description--

Poslední krok. Pod nadpisem je pruh `#progress-bar`. Jeho šířku v CSS řídí custom property `--progress` a změna šířky je plynulá díky `transition` — k přechodům se dostaneš v sekci CSS animace.

**Úkol:** Zařiď, aby `#progress-bar` měl po každé změně dat nastavenou custom property `--progress` na **procento hotových úkolů** zaokrouhlené na celé číslo, s jednotkou `%` (třeba `20%`). Když v seznamu žádný úkol není, je to `0%`.

Custom property se na prvek zapisuje metodou `style.setProperty`. Pozor na prázdný seznam: dělení nulou dá `NaN` a `NaN%` prohlížeč zahodí.

## Co umíš

Aplikace je hotová. Za sebou máš:

- vyhledání prvků a zápis textu přes `textContent`,
- vytvoření prvků přes `createElement` a `<template>` s `cloneNode(true)`,
- vykreslení pole dat přes `map` a `replaceChildren`,
- třídy, vlastnosti (`checked`, `hidden`, `disabled`) a atributy (`aria-label`),
- posluchače `submit`, `change` a `click` a `preventDefault()`,
- pravidlo „změň data, pak `render()`" a obranu proti XSS.

Na stejném vzoru stojí košík, seznam notifikací i tabulka v administraci. V lekci [Události](see:js-dom/udalosti) zjistíš, co se při kliknutí děje ve stromu, a v dalším workshopu z toho postavíš záložky a modální okno.

## Udělej po svém

- **Vzhled:** dej úkolům podle místnosti jinou barvu štítku — stačí třída z `task.room` a pár pravidel v CSS.
- **Funkce:** přidej do formuláře `<select>` s místností, ať nový úkol nemá vždycky „ostatní".
- **Funkce:** hotové úkoly řaď na konec seznamu. Data neměň, řaď až při vykreslení.
- **Klávesnice:** odškrtni úkol mezerníkem a stiskni Tab — fokus je pryč, protože `render()` políčko nahradilo novým. Po překreslení ho vrať na políčko stejného úkolu (vodítko: `data-id` na `li`).
- **Tvoje téma:** přeměň aplikaci na něco, co opravdu potřebuješ — seznam na výlet, přípravu na zkoušky nebo správu úkolů v domácnosti.

# --hints--

Po načtení má `#progress-bar` custom property `--progress` rovnou `20%`.

```js
assert.equal(document.querySelector('#progress-bar').style.getPropertyValue('--progress').trim(), '20%', 'po načtení (1 z 5 hotových) má mít #progress-bar --progress: 20%');
```

Po odškrtnutí úkolu se `--progress` změní na `40%`.

```js
await helpers.click(document.querySelectorAll('#task-list .task__toggle')[1]);
assert.equal(document.querySelector('#progress-bar').style.getPropertyValue('--progress').trim(), '40%', 'po odškrtnutí druhého úkolu (2 z 5) má být --progress: 40%');
```

Procento je zaokrouhlené na celé číslo.

```js
tasks = [
  { id: 90, title: 'Předat klíče', room: 'úřady', done: true },
  { id: 91, title: 'Umýt okna', room: 'obývák', done: true },
  { id: 92, title: 'Odnést krabice', room: 'sklep', done: false },
];
render();
assert.equal(document.querySelector('#progress-bar').style.getPropertyValue('--progress').trim(), '67%', 'při 2 hotových ze 3 úkolů má být --progress: 67% (66,67 zaokrouhleno na celé číslo)');
```

Bez úkolů je `--progress` rovno `0%`.

```js
tasks = [];
render();
assert.equal(document.querySelector('#progress-bar').style.getPropertyValue('--progress').trim(), '0%', 'při prázdném tasks má být --progress: 0% (ne NaN%)');
```

# --help--

## --tip--

Hodnota se odvozuje z dat, takže patří tam, kde se překresluje všechno ostatní — [krok 8](see:js-dom/workshop-seznam-ukolu/008). Zápis custom property je v tabulce v části [Atributy a vlastnosti](see:js-dom/strom-dom#atributy-a-vlastnosti-classlist-dataset-a-spol).

## --tip--

Procento je počet hotových děleno počtem všech, krát 100, zaokrouhlené. Prázdný seznam ošetři podmínkou dřív, než dělíš.

## --tip--

Stejný tvar u nahrávání souboru: `uploadBar.style.setProperty('--progress', ...)` s hodnotou z odeslaných a celkových bajtů.

// Úkoly ke stěhování. Tohle pole je jediný zdroj pravdy: stránka se z něj vykresluje.
let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

// Id, které dostane příští nový úkol.
let nextId = 6;

// Kolik úkolů ještě není hotových.
function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

// Vypíše do hlavičky, kolik úkolů zbývá a kolik jich je celkem.
function renderCounts() {
  document.querySelector('#open-count').textContent = countOpen(tasks);
  document.querySelector('#total-count').textContent = tasks.length;
}

// Vytvoří prvek <li> pro jeden úkol. Do stránky ho nevkládá.
function createTaskElement(task) {
  const template = document.querySelector('#task-template');
  const li = template.content.firstElementChild.cloneNode(true);
  li.querySelector('.task__title').textContent = task.title;
  li.querySelector('.task__room').textContent = task.room;
  li.classList.toggle('is-done', task.done);
  li.querySelector('.task__toggle').checked = task.done;
  li.querySelector('.task__delete').setAttribute('aria-label', `Smazat úkol ${task.title}`);
  li.querySelector('.task__toggle').addEventListener('change', () => toggleTask(task.id));
  li.querySelector('.task__delete').addEventListener('click', () => deleteTask(task.id));
  return li;
}

function renderTasks() {
  const list = document.querySelector('#task-list');
  const items = tasks.map((task) => createTaskElement(task));
  list.replaceChildren(...items);
}

// Uvede celou stránku do souladu s daty v tasks.
function render() {
  renderTasks();
  renderCounts();
  document.querySelector('#empty-state').hidden = tasks.length > 0;
  document.querySelector('#clear-done').disabled = !tasks.some((task) => task.done);
  const doneCount = tasks.length - countOpen(tasks);
  const percent = tasks.length === 0 ? 0 : Math.round((doneCount / tasks.length) * 100);
  document.querySelector('#progress-bar').style.setProperty('--progress', `${percent}%`);
}

// Vytvoří nový nehotový úkol s jedinečným id. Do tasks ho nevkládá.
function createTask(title) {
  const task = { id: nextId, title, room: 'ostatní', done: false };
  nextId += 1;
  return task;
}

// Přepne úkolu s daným id hotovo/nehotovo a překreslí stránku.
function toggleTask(id) {
  tasks = tasks.map((task) => (task.id === id ? { ...task, done: !task.done } : task));
  render();
}

// Smaže úkol s daným id a překreslí stránku.
function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
  render();
}
