# --description--

V hlavičce je věta „– z – úkolů zbývá udělat". Pomlčky jsou prvky `#open-count` a `#total-count` a teď do nich dostaneš čísla z dat.

**Úkol:** Nad komentář `// Start aplikace` napiš funkci `renderCounts()`, která:

- najde `#open-count` a nastaví mu `textContent` na výsledek `countOpen(tasks)`,
- najde `#total-count` a nastaví mu `textContent` na počet všech úkolů.

Pod komentář `// Start aplikace` pak napiš `renderCounts();`, aby se funkce zavolala hned po načtení stránky.

Prvek najdeš přes `document.querySelector` stejným selektorem jako v CSS a text do něj zapíšeš přes `textContent`. Na jiných datech:

```js
function renderCartBadge() {
  // 1. najdi prvek
  const badge = document.querySelector('#cart-badge');
  // 2. zapiš do něj text spočítaný z dat
  badge.textContent = cartItems.length;
}
```

Číslo se do `textContent` převede na text samo. Skript se načítá s `defer`, takže ve chvíli spuštění už prvky v hlavičce existují.

# --hints--

Po načtení stránky ukazuje `#open-count` číslo `4` a `#total-count` číslo `5`.

```js
assert.equal(document.querySelector('#open-count').textContent.trim(), '4', '#open-count má po načtení ukazovat 4 — zavoláš renderCounts() pod komentářem // Start aplikace?');
assert.equal(document.querySelector('#total-count').textContent.trim(), '5', '#total-count má po načtení ukazovat 5 (počet úkolů v tasks)');
```

`renderCounts()` počty spočítá z aktuálního obsahu `tasks`, i když se pole změní.

```js
tasks = [{ id: 20, title: 'Předat klíče', room: 'úřady', done: false }, { id: 21, title: 'Umýt okna', room: 'obývák', done: true }];
renderCounts();
assert.equal(document.querySelector('#open-count').textContent.trim(), '1', 'po změně tasks na [nehotový, hotový] a zavolání renderCounts() má #open-count ukazovat 1');
assert.equal(document.querySelector('#total-count').textContent.trim(), '2', 'po změně tasks na dva úkoly a zavolání renderCounts() má #total-count ukazovat 2');
```

## --file-- script.js

```js
// Úkoly ke stěhování. Tohle pole je jediný zdroj pravdy: stránka se z něj vykresluje.
let tasks = [
  { id: 1, title: 'Zabalit knihy', room: 'obývák', done: true },
  { id: 2, title: 'Odhlásit elektřinu', room: 'úřady', done: false },
  { id: 3, title: 'Objednat stěhovací auto', room: 'úřady', done: false },
  { id: 4, title: 'Rozebrat postel', room: 'ložnice', done: false },
  { id: 5, title: 'Vyklidit lednici', room: 'kuchyň', done: false },
];

// Id, které dostane příští nový úkol.
let nextId = 6;

// Kolik úkolů ještě není hotových.
function countOpen(items) {
  return items.filter((task) => !task.done).length;
}

// Vypíše do hlavičky, kolik úkolů zbývá a kolik jich je celkem.
function renderCounts() {
  document.querySelector('#open-count').textContent = countOpen(tasks);
  document.querySelector('#total-count').textContent = tasks.length;
}

// Start aplikace

renderCounts();
```
