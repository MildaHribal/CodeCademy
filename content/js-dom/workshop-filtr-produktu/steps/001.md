# --description--

Postavíš katalog e-shopu s pokojovými rostlinami, jaký znáš z každého velkého obchodu: živé hledání, kategorie, řazení, srdíčka oblíbených a filtr, který si pamatuje adresa stránky. Pošleš odkaz „kapradiny bezpečné pro kočku" a kamarádka uvidí přesně ten výběr. Obnovíš stránku a nic se neztratí.

HTML, vzhled a data jsou hotové. V `script.js` je pole `products`, popisky kategorií `categoryLabels`, formát ceny `priceFormat` a na konci `index.html` šablona karty `#product-template`.

Začneš tím, co umíš z prvního workshopu, bez návodu.

**Úkol:** Nad komentář `// Start aplikace` napiš funkci `createCard(product)`, která zkopíruje `<li>` ze šablony `#product-template`, doplní do něj údaje rostliny a vrátí ho:

- `data-id` karty je `id` rostliny,
- `.product__name` obsahuje název, `.product__category` popisek kategorie z `categoryLabels`,
- `.product__price` obsahuje cenu naformátovanou přes `priceFormat.format`,
- štítek `.product__pets` je vidět jen u rostliny s `petSafe: true`.

# --hints--

`createCard(products[0])` vrátí `<li class="product">` s `data-id="monstera"`.

```js
const card = createCard(products[0]);
assert.ok(card instanceof HTMLLIElement, 'createCard(products[0]) má vrátit prvek <li>, vrací ' + String(card));
assert.ok(card.classList.contains('product'), 'vrácené <li> má mít třídu product — kopíruješ šablonu #product-template?');
assert.equal(card.dataset.id, 'monstera', 'karta Monstery má mít data-id="monstera"');
```

Karta ukazuje název, popisek kategorie a naformátovanou cenu.

```js
const card = createCard(products[1]);
assert.equal(card.querySelector('.product__name').textContent, 'Čínský penízovník', '.product__name má u products[1] obsahovat „Čínský penízovník"');
assert.equal(card.querySelector('.product__category').textContent, 'Listové rostliny', ".product__category má obsahovat popisek z categoryLabels, ne klíč 'listove'");
assert.equal(card.querySelector('.product__price').textContent, priceFormat.format(259), '.product__price má obsahovat cenu přes priceFormat.format(259)');
```

Štítek „Bezpečná pro zvířata" je vidět jen u rostlin s `petSafe: true`.

```js
assert.equal(createCard(products[1]).querySelector('.product__pets').hidden, false, 'u Čínského penízovníku (petSafe: true) má být .product__pets vidět');
assert.equal(createCard(products[0]).querySelector('.product__pets').hidden, true, 'u Monstery (petSafe: false) má zůstat .product__pets skrytý');
```

Každé volání vrátí novou kopii, text jde do karty jako text a šablona zůstane prázdná.

```js
const card = createCard({ id: 'fikus', name: 'Fíkus <b>velký</b>', category: 'listove', price: 500, petSafe: false });
assert.equal(card.querySelector('b'), null, 'z názvu nesmí vzniknout element <b> — cizí text vkládej přes textContent');
assert.notEqual(createCard(products[0]), createCard(products[0]), 'dvě volání createCard mají vrátit dvě různé kopie šablony');
assert.equal(document.querySelector('#product-template').content.querySelector('.product__name').textContent, '', 'do samotné šablony se nemá nic psát, jen do kopie');
```

# --help--

## --tip--

Kopii šablony, doplnění textu a třídu podle dat jsi psal v [seznamu úkolů](see:js-dom/workshop-seznam-ukolu/006).

## --tip--

Šablona má obsah ve vlastnosti `content` a první prvek zkopíruješ i s potomky. Popisek kategorie je hodnota v objektu `categoryLabels` pod klíčem `product.category`.


```js
// Karta jedné rostliny ze šablony.
function createCard(product) {
  const card = document.querySelector('#product-template').content.firstElementChild.cloneNode(true);
  card.dataset.id = product.id;
  card.querySelector('.product__name').textContent = product.name;

  card.querySelector('.product__pets').hidden = !product.petSafe;
```
