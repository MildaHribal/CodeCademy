# --description--

Teď filtr do adresy opravdu zapíšeš. Přiřazení do `location.search` by stránku znovu načetlo, takže přichází na řadu History API. Při psaní do hledání chceš adresu **přepsat**, ne přidat nový záznam do historie za každé písmeno.

Novou adresu slož z aktuální: `new URL(location.href)` a do jejího `search` dosaď výsledek `filtersToSearch`. Zápis relativní adresy by v některých prostředích (třeba v náhledu Akademie, který běží na `about:srcdoc`) skončil chybou `SecurityError`.

**Úkol:**

1. Nad komentář `// Start aplikace` napiš funkci `writeUrl()`, která zapíše aktuální `filters` do adresy stránky bez znovunačtení a bez nového záznamu v historii.
2. Zavolej ji po každé změně filtru: v posluchači formuláře i po **Zrušit filtry**.

Náhled adresní řádek nemá. Změnu uvidíš, když si na konec posluchače formuláře dočasně přidáš `console.log(location.search)` a budeš psát do hledání.

# --hints--

Po napsání „aloe" je v adrese parametr `q=aloe`.

```js
await helpers.type(form.elements.q, 'aloe');
assert.equal(new URLSearchParams(location.search).get('q'), 'aloe', 'po napsání „aloe" má být v adrese q=aloe, location.search je ' + JSON.stringify(location.search));
```

Po výběru kategorie je v adrese i `category`.

```js
const select = form.elements.category;
select.value = 'kapradiny';
select.dispatchEvent(new Event('input', { bubbles: true }));
select.dispatchEvent(new Event('change', { bubbles: true }));
const params = new URLSearchParams(location.search);
assert.equal(params.get('category'), 'kapradiny', 'po výběru Kapradiny má být v adrese category=kapradiny');
assert.equal(params.has('q'), false, 'prázdné hledání do adresy nepatří');
```

Po **Zrušit filtry** je adresa bez parametrů.

```js
await helpers.type(form.elements.q, 'kaktus');
await helpers.click(document.querySelector('#reset-filters'));
assert.equal(location.search, '', 'po Zrušit filtry má být adresa bez parametrů, location.search je ' + JSON.stringify(location.search));
```

Psaní do hledání nepřidává záznamy do historie a stránku znovu nenačte.

```js
window.pageMarker = 'stejná stránka';
const before = history.length;
await helpers.type(form.elements.q, 'monst');
assert.equal(history.length, before, 'napsání pěti písmen nemá přidat záznamy do historie — přepisuješ adresu, nebo přidáváš?');
assert.equal(window.pageMarker, 'stejná stránka', 'stránka se nemá znovu načíst');
```

# --help--

## --tip--

Změna adresy bez načtení a rozdíl mezi přidáním a přepsáním záznamu jsou v části [Historie: pushState, replaceState a popstate](see:js-dom/prohlizecova-api#historie-pushstate-replacestate-a-popstate).

## --tip--

Ve `writeUrl` vytvoř objekt `URL` z aktuální adresy, nastav mu `search` a předej ho metodě `history`, která záznam přepisuje. Volání `writeUrl()` patří za `render()` v obou posluchačích.

## --tip--

Stejně u stránkování: z aktuální adresy vyrobíš objekt `URL`, na něm zavoláš `searchParams.set('strana', page)` a hotovou adresu předáš History API. Tady jen místo jednoho parametru nastavuješ celé `search`.

# --explain--

Vysvětli, proč filtr zapisuješ přes History API a ne přiřazením do `location.search`, a proč při psaní adresu přepisuješ místo přidání záznamu.

## --model--

Přiřazení do `location.search` stránku znovu načte a všechno, co je jen v proměnných, se ztratí. History API adresu změní bez načtení, takže aplikace běží dál. Při psaní do hledání vzniká změna po každém písmenu; kdybych pokaždé přidal záznam do historie, tlačítko Zpět by uživatele vracelo písmeno po písmenu. Přepsání aktuálního záznamu nechá v historii jen výsledek.

## --checklist--

- Přiřazení do `location.search` stránku znovu načte.
- History API změní adresu bez načtení stránky.
- Přidání záznamu po každém písmenu by rozbilo tlačítko Zpět.
- Při psaní se aktuální záznam přepisuje.

const categoryLabels = {
  listove: 'Listové rostliny',
  sukulenty: 'Sukulenty a kaktusy',
  kapradiny: 'Kapradiny',
  popinave: 'Popínavé',
  bylinky: 'Bylinky',
};

// Povolené hodnoty řazení (value v selectu #sort).
const sortOptions = ['recommended', 'price-asc', 'price-desc', 'name'];

// Cena v korunách, třeba „1 290 Kč".
const priceFormat = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK', maximumFractionDigits: 0 });

// Výchozí filtr: nic nehledá, nic neskrývá, doporučené pořadí.
const defaultFilters = { query: '', category: 'all', pets: false, sort: 'recommended' };

// Aktuální filtr. Stránka se vykresluje z něj.
let filters = { ...defaultFilters };

// Prvky, se kterými budeš pracovat.
const form = document.querySelector('#filters');
const list = document.querySelector('#product-list');

// Enter v poli hledání formulář neodešle, filtr běží živě.
form.addEventListener('submit', (event) => event.preventDefault());


// Karta jedné rostliny ze šablony.
function createCard(product) {
  const card = document.querySelector('#product-template').content.firstElementChild.cloneNode(true);
  card.dataset.id = product.id;
  card.querySelector('.product__name').textContent = product.name;
  card.querySelector('.product__category').textContent = categoryLabels[product.category];
  card.querySelector('.product__price').textContent = priceFormat.format(product.price);
  card.querySelector('.product__pets').hidden = !product.petSafe;
  return card;
}

// Vykreslí karty rostlin do seznamu.
function renderProducts(items) {
  list.replaceChildren(...items.map((product) => createCard(product)));
}

// Přečte filtr z formuláře.
function readFilters() {
  const data = new FormData(form);
  return {
    query: data.get('q').trim(),
    category: data.get('category'),
    pets: data.has('pets'),
    sort: data.get('sort'),
  };
}

// Obsahuje název rostliny hledaný text? Velikost písmen nerozhoduje.
function matchesQuery(product, query) {
  return product.name.toLocaleLowerCase('cs').includes(query.toLocaleLowerCase('cs'));
}

// Rostliny, které odpovídají filtru, v pořadí podle řazení.
function getVisibleProducts() {
  const found = products.filter((product) => matchesQuery(product, filters.query)
    && (filters.category === 'all' || product.category === filters.category)
    && (!filters.pets || product.petSafe));
  return sortProducts(found, filters.sort);
}

// Seřazená kopie podle volby v selectu; původní pole zůstane.
function sortProducts(items, sort) {
  if (sort === 'price-asc') return items.toSorted((a, b) => a.price - b.price);
  if (sort === 'price-desc') return items.toSorted((a, b) => b.price - a.price);
  if (sort === 'name') return items.toSorted((a, b) => a.name.localeCompare(b.name, 'cs'));
  return items;
}

// Uvede stránku do souladu s filtrem.
function render() {
  const visible = getVisibleProducts();
  renderProducts(visible);
  document.querySelector('#result-count').textContent = `Výsledky: ${visible.length} z ${products.length}`;
  document.querySelector('#empty-state').hidden = visible.length > 0;
}

// Filtr → parametry adresy. Výchozí hodnoty do adresy nepatří.
function filtersToSearch(currentFilters) {
  const params = new URLSearchParams();
  if (currentFilters.query !== '') params.set('q', currentFilters.query);
  if (currentFilters.category !== 'all') params.set('category', currentFilters.category);
  if (currentFilters.pets) params.set('pets', '1');
  if (currentFilters.sort !== 'recommended') params.set('sort', currentFilters.sort);
  const search = params.toString();
  return search === '' ? '' : `?${search}`;
}

// Výchozí filtr: nic nehledá, nic neskrývá, doporučené pořadí.
const defaultFilters = { query: '', category: 'all', pets: false, sort: 'recommended' };

// Aktuální filtr. Stránka se vykresluje z něj.
let filters = { ...defaultFilters };

// Prvky, se kterými budeš pracovat.
const form = document.querySelector('#filters');
const list = document.querySelector('#product-list');

// Enter v poli hledání formulář neodešle, filtr běží živě.
form.addEventListener('submit', (event) => event.preventDefault());


// Karta jedné rostliny ze šablony.
function createCard(product) {
  const card = document.querySelector('#product-template').content.firstElementChild.cloneNode(true);
  card.dataset.id = product.id;
  card.querySelector('.product__name').textContent = product.name;
  card.querySelector('.product__category').textContent = categoryLabels[product.category];
  card.querySelector('.product__price').textContent = priceFormat.format(product.price);
  card.querySelector('.product__pets').hidden = !product.petSafe;
  return card;
}

// Vykreslí karty rostlin do seznamu.
function renderProducts(items) {
  list.replaceChildren(...items.map((product) => createCard(product)));
}

// Přečte filtr z formuláře.
function readFilters() {
  const data = new FormData(form);
  return {
    query: data.get('q').trim(),
    category: data.get('category'),
    pets: data.has('pets'),
    sort: data.get('sort'),
  };
}

// Obsahuje název rostliny hledaný text? Velikost písmen nerozhoduje.
function matchesQuery(product, query) {
  return product.name.toLocaleLowerCase('cs').includes(query.toLocaleLowerCase('cs'));
}

// Rostliny, které odpovídají filtru, v pořadí podle řazení.
function getVisibleProducts() {
  const found = products.filter((product) => matchesQuery(product, filters.query)
    && (filters.category === 'all' || product.category === filters.category)
    && (!filters.pets || product.petSafe));
  return sortProducts(found, filters.sort);
}

// Seřazená kopie podle volby v selectu; původní pole zůstane.
function sortProducts(items, sort) {
  if (sort === 'price-asc') return items.toSorted((a, b) => a.price - b.price);
  if (sort === 'price-desc') return items.toSorted((a, b) => b.price - a.price);
  if (sort === 'name') return items.toSorted((a, b) => a.name.localeCompare(b.name, 'cs'));
  return items;
}

// Uvede stránku do souladu s filtrem.
function render() {
  const visible = getVisibleProducts();
  renderProducts(visible);
  document.querySelector('#result-count').textContent = `Výsledky: ${visible.length} z ${products.length}`;
  document.querySelector('#empty-state').hidden = visible.length > 0;
}

// Filtr → parametry adresy. Výchozí hodnoty do adresy nepatří.
function filtersToSearch(currentFilters) {
  const params = new URLSearchParams();
  if (currentFilters.query !== '') params.set('q', currentFilters.query);
  if (currentFilters.category !== 'all') params.set('category', currentFilters.category);
  if (currentFilters.pets) params.set('pets', '1');
  if (currentFilters.sort !== 'recommended') params.set('sort', currentFilters.sort);
  const search = params.toString();
  return search === '' ? '' : `?${search}`;
}

// Zapíše filtr do adresy bez znovunačtení a bez nového záznamu v historii.
function writeUrl() {
  const url = new URL(location.href);
  url.search = filtersToSearch(filters);
  history.replaceState(null, '', url);
}

// Start aplikace

render();

form.addEventListener('input', () => {
  filters = readFilters();
  render();
  writeUrl();
});

document.querySelector('#reset-filters').addEventListener('click', () => {
  form.reset();
  filters = readFilters();
  render();
  writeUrl();
  form.elements.q.focus();
});
