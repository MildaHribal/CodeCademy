# --description--

`App` má dneska přes padesát řádků a náhled je zamotaný uvnitř `map`. Za chvíli k němu budeš přidávat efekty — a hooky se v `map` volat nedají. Čas ho osamostatnit.

**Úkol:** Vytvoř v `App.jsx` komponentu `Nahled` s props `vstupenka` a `onZavrit`, která vrátí překryv i s oknem náhledu; zavírací tlačítko volá `onZavrit`. Vyexportuj ji (`export function Nahled`), ať se dá otestovat zvlášť. V `App` pak místo celého bloku JSX vykresli `<Nahled vstupenka={vstupenka} onZavrit={…} />`.

# --help--

## --tip--

Komponenta je obyčejná funkce, která dostane props a vrátí JSX — přesně ten JSX, který teď máš uvnitř podmínky.

## --tip--

Data, která náhled potřebuje, mu pošli jako props; funkci na zavření taky (prop, jejíž hodnotou je funkce).

## --tip--

Na jiných datech: `export function Rada({ recept, onSmazat }) { … }` a v rodiči `<Rada recept={recept} onSmazat={() => smazat(recept.id)} />`.

```jsx
import { useState } from 'react';
import { vstupenky } from './vstupenky';

export default function App() {
  const [otevrena, setOtevrena] = useState(null);

  return (
    <div className="stranka">
      <h1 className="stranka__nadpis">Moje vstupenky</h1>
      <p className="stranka__popis">Koncerty, na které už máš koupeno.</p>

      <ul className="seznam">
        {vstupenky.map((vstupenka) => (
          <li key={vstupenka.id} className={`vstupenka vstupenka--${vstupenka.odstin}`}>
            <p className="vstupenka__pas">{vstupenka.datum}</p>
            <div className="vstupenka__telo">
              <h2 className="vstupenka__kapela">{vstupenka.kapela}</h2>
              <p className="vstupenka__radek">{vstupenka.misto}</p>
              <p className="vstupenka__radek">{vstupenka.sektor}</p>
              <p className="vstupenka__cena">{vstupenka.cena} Kč</p>
              <button
                type="button"
                className="tlacitko tlacitko--auto"
                onClick={() => setOtevrena(vstupenka.id)}
              >
                Detail
              </button>
            </div>
            {otevrena === vstupenka.id && (
              <div className="prekryv">
                <div className="nahled">
                  <h3 className="nahled__nadpis">{vstupenka.kapela}</h3>
                  <p className="nahled__radek">{vstupenka.datum}</p>
                  <p className="nahled__radek">{vstupenka.misto}</p>
                  <p className="nahled__radek">{vstupenka.sektor}</p>
                  <p className="nahled__kod">{vstupenka.kod}</p>
                  <div className="nahled__ovladani">
                    <button
                      type="button"
                      className="tlacitko tlacitko--tichy"
                      onClick={() => setOtevrena(null)}
                    >
                      Zavřít
                    </button>
                  </div>
                </div>
              </div>
            )}
          </li>
        ))}
      </ul>
    </div>
  );
}
```
