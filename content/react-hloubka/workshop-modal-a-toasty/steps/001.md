# --description--

Stavíš stránku **Moje vstupenky** — přehled koncertů, na které už má uživatel koupeno. Takovou obrazovku má každá aplikace, která něco prodává: z karty se dá otevřít detail s kódem vstupenky, vstupenku jde vrátit a o každé akci se v rohu objeví oznámení, které samo zmizí.

Data jsou hotová v `vstupenky.js` — pole objektů s klíči `id`, `kapela`, `misto`, `datum`, `sektor`, `cena`, `kod` a `odstin`. Vzhled (barevné pásy, stíny, tlačítka) je hotový v `styles.css`.

Začneš tím, co už z Reactu umíš, a bez návodu.

**Úkol:** V `App.jsx` vykresli do `<ul className="seznam">` jednu položku `<li>` za každou vstupenku. Každá `<li>` má `key` a třídu `vstupenka vstupenka--<odstin>`; uvnitř je datum v `<p className="vstupenka__pas">` a dál `<div className="vstupenka__telo">` s kapelou v `<h2 className="vstupenka__kapela">`, místem a sektorem v `<p className="vstupenka__radek">` a cenou v `<p className="vstupenka__cena">` ve tvaru `590 Kč`.

# --help--

## --tip--

Ze seznamu dat uděláš seznam prvků metodou, která z každé položky pole vyrobí jednu novou hodnotu — a v Reactu tou hodnotou bývá kus JSX.

## --tip--

Třída karty se skládá ze dvou částí: pevné `vstupenka` a proměnné podle `odstin`. Hodí se na to šablonový řetězec ve složených závorkách.

## --tip--

Na jiných datech: `{knihy.map((kniha) => <li key={kniha.isbn} className={`kniha kniha--${kniha.zanr}`}>{kniha.nazev}</li>)}`.

# --hints--

Seznam má čtyři vstupenky ve stejném pořadí jako data.

```js
const karty = document.querySelectorAll('.seznam .vstupenka');
assert.equal(karty.length, 4, 'V seznamu čekám 4 vstupenky (jednu za každý koncert v datech)');
const kapely = [...karty].map((karta) => karta.querySelector('.vstupenka__kapela').textContent.trim());
assert.deepEqual(kapely, ['Zrní', 'Vltava', 'Lake Malawi', 'Please the Trees'], 'Kapely mají jít v pořadí Zrní, Vltava, Lake Malawi, Please the Trees');
```

Každá karta ukazuje datum, místo, sektor a cenu v korunách.

```js
const prvni = document.querySelector('.seznam .vstupenka');
assert.match(prvni.textContent, /14\. října 2026/, 'První karta (Zrní) má ukazovat datum 14. října 2026');
assert.match(prvni.textContent, /Lucerna Music Bar, Praha/, 'První karta (Zrní) má ukazovat místo Lucerna Music Bar, Praha');
assert.match(prvni.textContent, /Stání u pódia/, 'První karta (Zrní) má ukazovat sektor Stání u pódia');
assert.match(prvni.textContent, /590\s*Kč/, 'První karta (Zrní) má ukazovat cenu 590 Kč');
```

Každá položka seznamu má stabilní `key` — React v konzoli nic nevytýká.

```js
assert.ok(!logs.some((zapis) => /unique "key"/.test(zapis.text)), 'React hlásí do konzole, že položce seznamu chybí key — dej mu id vstupenky');
```

## --file-- App.jsx

```jsx
import { vstupenky } from './vstupenky';

export default function App() {
  return (
    <div className="stranka">
      <h1 className="stranka__nadpis">Moje vstupenky</h1>
      <p className="stranka__popis">Koncerty, na které už máš koupeno.</p>

      <ul className="seznam">
        {vstupenky.map((vstupenka) => (
          <li key={vstupenka.id} className={`vstupenka vstupenka--${vstupenka.odstin}`}>
            <p className="vstupenka__pas">{vstupenka.datum}</p>
            <div className="vstupenka__telo">
              <h2 className="vstupenka__kapela">{vstupenka.kapela}</h2>
              <p className="vstupenka__radek">{vstupenka.misto}</p>
              <p className="vstupenka__radek">{vstupenka.sektor}</p>
              <p className="vstupenka__cena">{vstupenka.cena} Kč</p>
            </div>
          </li>
        ))}
      </ul>
    </div>
  );
}
```
