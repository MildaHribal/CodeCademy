# --description--

Tmavý překryv se drží uvnitř karty, přestože má `position: fixed`. Za to může jediná deklarace v `styles.css`: karta má `filter: drop-shadow(…)`. **Prvek s `transform`, `filter` nebo `contain` se stane kotvou i pro `position: fixed` uvnitř sebe** — a celé modální okno se tak zavře do karty velké 280 px.

Ve skutečné aplikaci se tohle stává pořád: modal je zamotaný v komponentě, která má stín přes `filter`, animaci přes `transform` nebo `overflow: hidden`. Řešení je vždycky stejné — vykreslit okno **mimo** ten kus stromu, rovnou do `<body>`. React na to má `createPortal(jsx, cíl)` z `react-dom`: v Reactu zůstane prvek na svém místě (props i události chodí normálně), ale v DOMu skončí tam, kam ukážeš.

```jsx
// vzor na jiném prvku: nápověda u pole formuláře
return createPortal(<div className="bublina">{text}</div>, document.body);
```

**Úkol:** V komponentě `Nahled` vrať překryv přes `createPortal(…, document.body)`.

# --help--

## --tip--

Funkce se jmenuje `createPortal` a importuje se z `react-dom` (ne z `react`).

## --tip--

Bere dva argumenty: co vykreslit a kam. Cílem je `document.body`.

## --tip--

Na jiných datech: `return createPortal(<p className="hlaska">Uloženo</p>, document.body);`.

# --explain--

Vysvětli vlastními slovy, proč modální okno patří do portálu, i když by se `position: fixed` mělo o polohu postarat samo.

## --model--

`position: fixed` se normálně vztahuje k oknu prohlížeče, ale jakmile má některý předek `transform`, `filter` nebo `contain`, stane se kotvou on — a okno se zavře do něj. Modální okno navíc soupeří o pořadí vykreslení s okolím: stačí předek s `overflow: hidden` nebo `z-index` a okno se ořízne nebo schová pod hlavičku. Portál tyhle problémy neřeší obcházením CSS, ale tím, že prvek vůbec nenechá vzniknout uvnitř problematického stromu. V Reactu přitom zůstane tam, kde ho píšu, takže props, stav i události fungují úplně stejně.

## --checklist--

- `position: fixed` se váže k předkovi s `transform`, `filter` nebo `contain`, ne vždy k oknu.
- Předek s `overflow: hidden` nebo `z-index` umí okno oříznout nebo schovat.
- `createPortal` vykreslí prvek do jiného místa v DOMu, typicky do `document.body`.
- Ve stromu Reactu zůstává prvek na svém místě, takže props a události chodí jako předtím.

import { useState } from 'react';
import { vstupenky } from './vstupenky';

export function Nahled({ vstupenka, onZavrit }) {
  return (
    <div className="prekryv">
      <div className="nahled">
        <h3 className="nahled__nadpis">{vstupenka.kapela}</h3>
        <p className="nahled__radek">{vstupenka.datum}</p>
        <p className="nahled__radek">{vstupenka.misto}</p>
        <p className="nahled__radek">{vstupenka.sektor}</p>
        <p className="nahled__kod">{vstupenka.kod}</p>
        <div className="nahled__ovladani">
          <button type="button" className="tlacitko tlacitko--tichy" onClick={onZavrit}>
            Zavřít
          </button>
        </div>
      </div>
    </div>
  );
}

export default function App() {
  const [otevrena, setOtevrena] = useState(null);

  return (
    <div className="stranka">
      <h1 className="stranka__nadpis">Moje vstupenky</h1>
      <p className="stranka__popis">Koncerty, na které už máš koupeno.</p>

      <ul className="seznam">
        {vstupenky.map((vstupenka) => (
          <li key={vstupenka.id} className={`vstupenka vstupenka--${vstupenka.odstin}`}>
            <p className="vstupenka__pas">{vstupenka.datum}</p>
            <div className="vstupenka__telo">
              <h2 className="vstupenka__kapela">{vstupenka.kapela}</h2>
              <p className="vstupenka__radek">{vstupenka.misto}</p>
              <p className="vstupenka__radek">{vstupenka.sektor}</p>
              <p className="vstupenka__cena">{vstupenka.cena} Kč</p>
              <button
                type="button"
                className="tlacitko tlacitko--auto"
                onClick={() => setOtevrena(vstupenka.id)}
              >
                Detail
              </button>
            </div>
            {otevrena === vstupenka.id && (
              <Nahled vstupenka={vstupenka} onZavrit={() => setOtevrena(null)} />
            )}
          </li>
        ))}
      </ul>
    </div>
  );
}
