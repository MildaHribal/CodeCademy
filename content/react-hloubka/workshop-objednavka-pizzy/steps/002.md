# --description--

Objednávka je přesně ten případ, kdy si stav zaslouží reducer: hodnot je pět, mění se podle pravidel a za chvíli k nim přibude průvodce po krocích.

**Úkol:** V `App.jsx` napiš nad komponentou počáteční stav `VYCHOZI` s klíči `krok: 1`, `pizza: null`, `velikost: 'stredni'`, `prilohy: []` a `doruceni: 'vyzvednuti'`. Pod něj napiš `objednavkaReducer(stav, akce)`, který zvládne akci `{ typ: 'pizza', id }` (uloží `id` do klíče `pizza`) a u neznámé akce vyhodí chybu. V `App` pak `const [stav, poslat] = useReducer(objednavkaReducer, VYCHOZI)`. Tlačítko pizzy tu akci pošle a dostane `aria-pressed` podle toho, jestli je ta pizza vybraná.

```jsx
// vzor na jiném stavu: přepnutí jazyka
case 'jazyk':
  return { ...stav, jazyk: akce.kod };
```

# --help--

## --tip--

Reducer je čistá funkce mimo komponentu — viz [useReducer](see:react-hloubka/reducer-a-context#usereducer-akce-jako-jmeno-udalosti).

## --tip--

Uvnitř se hodí `switch` podle `akce.typ`. Každá větev vrací **nový** objekt stavu, nikdy neupravuje ten starý.

## --tip--

`aria-pressed` čeká `true` nebo `false` — porovnej hodnotu ve stavu s `id` té pizzy, kterou právě vykresluješ.

## --file-- App.jsx

```jsx
import { useReducer } from 'react';
import { pizzy } from './menu';

const VYCHOZI = {
  krok: 1,
  pizza: null,
  velikost: 'stredni',
  prilohy: [],
  doruceni: 'vyzvednuti',
};

function objednavkaReducer(stav, akce) {
  switch (akce.typ) {
    case 'pizza':
      return { ...stav, pizza: akce.id };
    default:
      throw new Error('Neznámá akce: ' + akce.typ);
  }
}

export default function App() {
  const [stav, poslat] = useReducer(objednavkaReducer, VYCHOZI);

  return (
    <div className="objednavka">
      <h1 className="objednavka__nadpis">Pizzeria Na Rohu</h1>
      <p className="objednavka__popis">Objednávka ve třech krocích: pizza, velikost a doručení.</p>

      <section className="sekce">
        <h2 className="sekce__nadpis">Vyber si pizzu</h2>
        <ul className="nabidka">
          {pizzy.map((pizza) => (
            <li key={pizza.id}>
              <button
                type="button"
                className="polozka"
                aria-pressed={stav.pizza === pizza.id}
                onClick={() => poslat({ typ: 'pizza', id: pizza.id })}
              >
                {pizza.stitek && <span className="polozka__stitek">{pizza.stitek}</span>}
                <p className="polozka__nazev">{pizza.nazev}</p>
                <p className="polozka__popis">{pizza.popis}</p>
                <p className="polozka__cena">{pizza.cena} Kč</p>
              </button>
            </li>
          ))}
        </ul>
      </section>

      <div className="lista">
        <div className="lista__obsah">
          <p className="lista__cena">Zatím nic nevybráno</p>
        </div>
      </div>
    </div>
  );
}
```
