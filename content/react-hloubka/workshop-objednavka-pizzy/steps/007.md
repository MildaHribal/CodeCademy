# --description--

Cena je spočítaná, ale nikdo ji nevidí. Patří do spodní lišty, kde ji má uživatel na očích po celou objednávku.

**Úkol:** V `App.jsx` naimportuj `spocitejCenu` z `./cena` a v komponentě `Lista` nech odstavec s třídou `lista__cena` ukázat `Celkem 219 Kč` (tedy slovo, číslo a `Kč`), jakmile je vybraná pizza. Dokud vybraná není, zůstane text `Zatím nic nevybráno`.

# --help--

## --tip--

Cena je odvozená hodnota — spočítá se při renderu ze stavu a nikam se neukládá. Viz [Kdy efekt nepotřebuješ](see:react-hloubka/useeffect-spravne#kdy-efekt-nepotrebujes).

## --tip--

V odstavci se rozhoduje mezi dvěma texty, takže se hodí ternární operátor a šablonový řetězec.

## --tip--

Na jiných datech: `<p>{kosik.length > 0 ? `V košíku: ${spocitejKusy(kosik)} ks` : 'Košík je prázdný'}</p>`.

# --explain--

Vysvětli vlastními slovy, proč cena objednávky není ve stavu, přestože se po každém kliknutí mění.

## --model--

Cena je vždycky jednoznačně spočítaná z toho, co už ve stavu je: z vybrané pizzy, velikosti, příloh a dopravy. Kdybych ji držel ve stavu, měl bych dva zdroje pravdy — a stačilo by zapomenout ji přepočítat v jedné akci reduceru a obrazovka by lhala. Odvozená hodnota se počítá při renderu, takže je vždycky v souladu se stavem a nemůže zastarat. Navíc odpadá efekt, který by ji dopočítával, a s ním i render navíc.

## --checklist--

- Cena se dá kdykoli spočítat ze stavu.
- Hodnota, kterou lze odvodit, do stavu nepatří.
- Dvě uložené podoby téhož se dřív nebo později rozejdou.
- Výpočet při renderu je vždycky v souladu se stavem.

import { pizzy, prilohy, velikosti, zpusobyDoruceni } from './menu';

/**
 * Spočítá celkovou cenu objednávky: pizzu přepočtenou na vybranou velikost,
 * přílohy a dopravu. Dokud není vybraná pizza, vrací nulu.
 */
export function spocitejCenu(stav) {
const pizza = pizzy.find((p) => p.id === stav.pizza);
if (!pizza) return 0;
const velikost = velikosti.find((v) => v.id === stav.velikost);
const doprava = zpusobyDoruceni.find((z) => z.id === stav.doruceni);
const priplatky = stav.prilohy.reduce((soucet, id) => soucet + prilohy.find((p) => p.id === id).cena, 0);
return Math.round(pizza.cena * velikost.koeficient) + priplatky + doprava.cena;
}

import { pizzy, prilohy, velikosti, zpusobyDoruceni } from './menu';

/**
 * Spočítá celkovou cenu objednávky: pizzu přepočtenou na vybranou velikost,
 * přílohy a dopravu. Dokud není vybraná pizza, vrací nulu.
 */
export function spocitejCenu(stav) {
const pizza = pizzy.find((p) => p.id === stav.pizza);
if (!pizza) return 0;
const velikost = velikosti.find((v) => v.id === stav.velikost);
const doprava = zpusobyDoruceni.find((z) => z.id === stav.doruceni);
const priplatky = stav.prilohy.reduce((soucet, id) => soucet + prilohy.find((p) => p.id === id).cena, 0);
return Math.round(pizza.cena * velikost.koeficient) + priplatky + doprava.cena;
}
