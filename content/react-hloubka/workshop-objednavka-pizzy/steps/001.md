# --description--

Objednávkový průvodce je jedna z nejčastějších věcí, které budeš v práci stavět: pár obrazovek za sebou, mezi nimi se dá chodit tam a zpět a na konci je rekapitulace s cenou. Postavíš takový průvodce pro pizzerii — výběr pizzy, velikost s přílohami, doručení.

Nabídka je v `menu.js` (`pizzy`, `velikosti`, `prilohy`, `zpusobyDoruceni`), vzhled v `styles.css`. Ceny jsou za střední velikost.

Začneš bez návodu tím, co už umíš.

**Úkol:** V `App.jsx` vypiš do `<ul className="nabidka">` jednu `<li>` za každou pizzu. Uvnitř `<li>` je `<button type="button" className="polozka">`, v něm štítek v `<span className="polozka__stitek">` (jen když pizza štítek má), název v `<p className="polozka__nazev">`, popis v `<p className="polozka__popis">` a cena v `<p className="polozka__cena">` ve tvaru `179 Kč`.

# --help--

## --tip--

Ze seznamu dat uděláš seznam prvků metodou, která z každé položky pole vyrobí jednu novou hodnotu.

## --tip--

Štítek se má objevit jen u některých pizz. V JSX se na to hodí operátor `&&`: vlevo podmínka, vpravo JSX.

## --tip--

Na jiných datech: `{filmy.map((film) => <li key={film.id}><button type="button">{film.nazev}</button></li>)}`.

# --hints--

Nabídka má čtyři pizzy ve stejném pořadí jako data.

```js
const polozky = document.querySelectorAll('.nabidka li');
assert.equal(polozky.length, 4, 'V nabídce čekám 4 pizzy');
const nazvy = [...document.querySelectorAll('.polozka__nazev')].map((n) => n.textContent.trim());
assert.deepEqual(nazvy, ['Margherita', 'Diavola', 'Quattro formaggi', 'Prosciutto e funghi'], 'Pizzy mají jít v pořadí Margherita, Diavola, Quattro formaggi, Prosciutto e funghi');
```

Každá pizza má popis, cenu v korunách a dá se na ni kliknout.

```js
const prvni = document.querySelector('.nabidka li');
assert.ok(prvni.querySelector('button.polozka'), 'Každá pizza má být tlačítko s třídou polozka');
assert.match(prvni.textContent, /Rajčatový základ/, 'První položka (Margherita) má ukazovat svůj popis');
assert.match(prvni.textContent, /179\s*Kč/, 'První položka (Margherita) má ukazovat cenu 179 Kč');
```

Štítek se ukáže jen u pizz, které ho v datech mají.

```js
const stitky = [...document.querySelectorAll('.polozka__stitek')].map((s) => s.textContent.trim());
assert.deepEqual(stitky, ['vegetariánská', 'pálivá', 'sýrová'], 'Štítek mají mít jen tři pizzy — Prosciutto e funghi ho v datech nemá');
assert.ok(!logs.some((zapis) => /unique "key"/.test(zapis.text)), 'React hlásí, že položce seznamu chybí key — dej jí id pizzy');
```

# --solution--

## --file-- App.jsx

```jsx
import { pizzy } from './menu';

export default function App() {
  return (
    <div className="objednavka">
      <h1 className="objednavka__nadpis">Pizzeria Na Rohu</h1>
      <p className="objednavka__popis">Objednávka ve třech krocích: pizza, velikost a doručení.</p>

      <section className="sekce">
        <h2 className="sekce__nadpis">Vyber si pizzu</h2>
        <ul className="nabidka">
          {pizzy.map((pizza) => (
            <li key={pizza.id}>
              <button type="button" className="polozka">
                {pizza.stitek && <span className="polozka__stitek">{pizza.stitek}</span>}
                <p className="polozka__nazev">{pizza.nazev}</p>
                <p className="polozka__popis">{pizza.popis}</p>
                <p className="polozka__cena">{pizza.cena} Kč</p>
              </button>
            </li>
          ))}
        </ul>
      </section>

      <div className="lista">
        <div className="lista__obsah">
          <p className="lista__cena">Zatím nic nevybráno</p>
        </div>
      </div>
    </div>
  );
}
```
