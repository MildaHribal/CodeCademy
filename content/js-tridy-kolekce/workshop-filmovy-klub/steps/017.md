# --description--

**Úkol:** Přidej do `FilmClub` metodu `mostSimilarTo(member)`, která vrátí jméno **jiného** člena s nejvyšší podobností vkusu. Při shodě vyhraje ten, kdo je v `members` dřív. Když v klubu nikdo jiný není, vrátí `null`.

Kandidáty ti dá `members` a skóre `similarity`. Pozor, sám se sebou má každý podobnost `1`.

# --hints--

`mostSimilarTo` vrátí člena s nejvyšší podobností.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
]);
assert.equal(club.mostSimilarTo('Eva'), 'Bára', "club.mostSimilarTo('Eva') má vrátit 'Bára' (podobnost 0.67), ne Jana (0) ani Evu samotnou");
assert.equal(club.mostSimilarTo('Bára'), 'Eva', "club.mostSimilarTo('Bára') má vrátit 'Eva'");
```

Při shodě vyhraje člen, který je v `members` dřív.

```js
const club = new FilmClub([
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Bára', film: 'Kulový blesk', stars: 3 },
]);
assert.equal(club.mostSimilarTo('Ondřej'), 'Bára', "club.mostSimilarTo('Ondřej') má vrátit 'Bára' (1)");
assert.equal(club.mostSimilarTo('Petra'), 'Jan', "club.mostSimilarTo('Petra') pro neznámou členku má při samých nulách vrátit prvního člena 'Jan'");
```

V klubu s jediným členem vrátí `mostSimilarTo` hodnotu `null`.

```js
const club = new FilmClub([{ member: 'Eva', film: 'Pelíšky', stars: 5 }]);
assert.equal(club.mostSimilarTo('Eva'), null, "club.mostSimilarTo('Eva') v klubu jen s Evou má vrátit null");
```

# --help--

## --tip--

Hledáš maximum podle skóre, jako nejlepšího studenta ve [statistice známek](see:js-pole/lab-statistika-znamek) — tady se skóre počítá přes [množinové operace](see:js-tridy-kolekce/map-a-set#mnozinove-operace).

## --tip--

Projdi `members`, člena samotného přeskoč. Pamatuj si dosud nejlepšího kandidáta a jeho skóre; přepiš ho jen při skóre **ostře** vyšším, tak při shodě zůstane ten dřívější. Začni s kandidátem `null` a skóre, které každé skutečné skóre překoná.

// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();
  #stars = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film, stars } of ratings) {
      addToGroup(this.#watched, member, film);
      this.#stars.set(film, [...(this.#stars.get(film) ?? []), stars]);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];
  }

  // Všechny filmy, které kdo v klubu viděl.
  get allFilms() {
    return new Set(this.#ratings.map((rating) => rating.film));
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }

  // Od kolegy: viděl člen tenhle film?
  hasSeen(member, film) {
    return this.#watched.get(member)?.has(film) ?? false;
  }

  // Filmy, které viděli oba členové.
  commonFilms(first, second) {
    return this.watchedBy(first).intersection(this.watchedBy(second));
  }

  // Filmy, které viděl kamarád a člen zatím ne.
  recommendFor(member, friend) {
    return this.watchedBy(friend).difference(this.watchedBy(member));
  }

  // Filmy, které viděli úplně všichni členové.
  seenByEveryone() {
    return this.members
      .map((member) => this.watchedBy(member))
      .reduce((common, films) => common.intersection(films), this.allFilms);
  }

  // Průměrné hodnocení filmu na jedno desetinné místo; neznámý film null.
  averageRating(film) {
    const stars = this.#stars.get(film);
    if (!stars) {
      return null;
    }
    const sum = stars.reduce((total, value) => total + value, 0);
    return Math.round((sum / stars.length) * 10) / 10;
  }

  // Nejlépe hodnocené filmy: od nejvyššího průměru, při shodě podle názvu.
  topFilms(count) {
    return [...this.allFilms]
      .map((film) => ({ film, average: this.averageRating(film) }))
      .toSorted((a, b) => b.average - a.average || a.film.localeCompare(b.film, 'cs'))
      .slice(0, count);
  }

  // Podobnost vkusu dvou členů: společné filmy / všechny jejich filmy, na dvě místa.
  similarity(first, second) {
    const a = this.watchedBy(first);
    const b = this.watchedBy(second);
    const all = a.union(b);
    if (all.size === 0) {
      return 0;
    }
    return Math.round((a.intersection(b).size / all.size) * 100) / 100;
  }

  // Od kolegy: filmy z klubu, které člen ještě neviděl.
  unseenBy(member) {
    return this.allFilms.difference(this.watchedBy(member));
  }

    let bestScore = -1;
    for (const other of this.members) {
      const score = this.similarity(member, other);
