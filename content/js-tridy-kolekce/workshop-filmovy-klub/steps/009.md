# --description--

Když se dva členové domlouvají, o čem si popovídají, hodí se vědět, co viděli oba.

**Úkol:** Přidej do `FilmClub` metodu `commonFilms(first, second)`, která vrátí množinu filmů, které viděli **oba** členové.

Z množinových operací se nabízí `union`, `intersection` nebo `difference` — vyber tu, která nechá jen společné hodnoty. Množiny obou členů ti dá `watchedBy`.

# --hints--

`commonFilms` vrátí množinu filmů, které viděli oba.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
]);
const common = club.commonFilms('Eva', 'Jan');
assert.ok(common instanceof Set, "club.commonFilms('Eva', 'Jan') má vrátit Set");
assert.deepEqual([...common].sort(), ['Pelíšky', 'Samotáři'], "club.commonFilms('Eva', 'Jan') má obsahovat právě 'Pelíšky' a 'Samotáři'");
```

S neznámým členem nemá nikdo nic společného.

```js
const club = new FilmClub([{ member: 'Eva', film: 'Pelíšky', stars: 5 }]);
assert.equal(club.commonFilms('Eva', 'Ondřej').size, 0, "club.commonFilms('Eva', 'Ondřej') má být prázdná množina");
```

function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }

  watchedBy(member) {
    return new Set(this.#watched.get(member));

  // Od kolegy: viděl člen tenhle film?
  hasSeen(member, film) {
    return this.#watched.get(member)?.has(film) ?? false;

  constructor(ratings) {

    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }

  commonFilms(first, second) {
    return this.watchedBy(first).intersection(this.watchedBy(second));
