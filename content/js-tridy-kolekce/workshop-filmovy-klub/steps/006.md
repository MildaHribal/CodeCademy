# --description--

**Úkol:** Přidej do `FilmClub` soukromé pole `#watched` s novou mapou. V konstruktoru projdi hodnocení a každé přidej přes `addToGroup` do `#watched`: klíč je člen, hodnota film. Pak napiš metodu `watchedBy(member)`, která vrátí **kopii** množiny filmů člena. Člen, kterého klub nezná, dostane prázdnou množinu.

Kopii množiny vyrobí `new Set(množina)`. A když jí místo množiny dáš `undefined`, vrátí prázdnou množinu — o neznámého člena se tak postará sama:

```js
const tags = new Set(['akce', 'novinka']);
const copy = new Set(tags);
const nothing = new Set(undefined);
```

# --hints--

`watchedBy` vrátí množinu filmů člena v pořadí hodnocení.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
]);
const films = club.watchedBy('Eva');
assert.ok(films instanceof Set, "club.watchedBy('Eva') má vrátit Set");
assert.deepEqual([...films], ['Pelíšky', 'Samotáři'], "club.watchedBy('Eva') má obsahovat 'Pelíšky' a 'Samotáři'");
```

Neznámý člen dostane prázdnou množinu.

```js
const club = new FilmClub([{ member: 'Eva', film: 'Pelíšky', stars: 5 }]);
const films = club.watchedBy('Ondřej');
assert.ok(films instanceof Set, "club.watchedBy('Ondřej') pro neznámého člena má vrátit Set");
assert.equal(films.size, 0, "club.watchedBy('Ondřej') má být prázdná množina");
```

Změna vrácené množiny se klubu nedotkne.

```js
const club = new FilmClub([{ member: 'Eva', film: 'Pelíšky', stars: 5 }]);
club.watchedBy('Eva').add('Kolja');
assert.equal(club.watchedBy('Eva').size, 1, "club.watchedBy('Eva').add('Kolja') nesmí přidat film do klubu — vracíš kopii?");
```

# --help--

## --tip--

Mapa množin, kterou plní `addToGroup` — viz [`Map`: slovník s libovolnými klíči](see:js-tridy-kolekce/map-a-set#map-slovnik-s-libovolnymi-klici).

## --tip--

Soukromé pole s mapou deklaruj vedle `#ratings`. V konstruktoru stačí cyklus přes hodnocení s destrukturalizací `member` a `film`. V `watchedBy` vytáhni množinu z mapy a obal ji do nové množiny.

## --tip--

Na jiných datech — kopie štítků článku z mapy „článek → množina štítků": `new Set(tagsByPost.get(postId))`. Neznámý článek dá prázdnou množinu.

# --explain--

Vysvětli vlastními slovy, proč `watchedBy` vrací `new Set(…)`, a ne rovnou množinu z mapy `#watched`.

## --model--

Množina je objekt a mapa v sobě drží odkaz na ni. Kdybych ji vrátil přímo, volající by dostal odkaz na vnitřní data klubu a třeba `add` nebo `delete` by potichu změnilo, co člen viděl, i když je `#watched` soukromé. `new Set(…)` vytvoří novou množinu se stejnými filmy, takže změny kopie klub neovlivní, a navíc z `undefined` udělá prázdnou množinu pro neznámého člena.

## --checklist--

- Mapa drží odkaz na množinu, ne její kopii.
- Vrácená původní množina by pustila ven vnitřní data klubu.
- `new Set(množina)` vytvoří nezávislou kopii.
- `new Set(undefined)` je prázdná množina pro neznámého člena.

## --file-- script.js

```js
// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }
}
```
