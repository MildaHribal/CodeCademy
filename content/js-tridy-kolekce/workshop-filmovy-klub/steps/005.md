# --description--

Klub se bude pořád ptát „které filmy viděla Eva?". Na to se hodí mapa, kde klíčem je člen a hodnotou **množina** jeho filmů: `'Eva' => Set { 'Pelíšky', 'Kolja' }`.

Plnit takovou mapu má jeden háček: když člen přijde poprvé, jeho množina ještě neexistuje a `get` vrátí `undefined`. Proto napíšeš pomocnou funkci, která chybějící množinu nejdřív založí.

**Úkol:** Nad třídu `FilmClub` seřaď řádky funkce `addToGroup(groups, key, value)`, která do mapy `groups` přidá `value` do množiny pod klíčem `key`. Do mezery doplň, co se pod nový klíč uloží. Tento vzor vidíš poprvé, v dalším kroku ho použiješ. Dva řádky jsou navíc.

# --hints--

`addToGroup` založí pro nový klíč množinu a hodnotu do ní přidá.

```js
const groups = new Map();
addToGroup(groups, 'Eva', 'Pelíšky');
assert.ok(groups.get('Eva') instanceof Set, "po addToGroup(groups, 'Eva', 'Pelíšky') má groups.get('Eva') být Set");
assert.deepEqual([...groups.get('Eva')], ['Pelíšky'], "množina pod 'Eva' má obsahovat 'Pelíšky'");
```

Další hodnoty pod stejným klíčem se přidají do téže množiny, duplicity ne.

```js
const groups = new Map();
addToGroup(groups, 'Eva', 'Pelíšky');
addToGroup(groups, 'Eva', 'Kolja');
addToGroup(groups, 'Eva', 'Pelíšky');
addToGroup(groups, 'Jan', 'Kolja');
assert.deepEqual([...groups.get('Eva')], ['Pelíšky', 'Kolja'], "pod 'Eva' mají být 'Pelíšky' a 'Kolja', každý jednou");
assert.deepEqual([...groups.get('Jan')], ['Kolja'], "pod 'Jan' má být jen 'Kolja'");
assert.equal(groups.size, 2, 'mapa má mít dva klíče, Eva a Jan');
```

# --help--

## --tip--

Mapa, jejíž hodnoty jsou množiny — viz [`Map`: slovník s libovolnými klíči](see:js-tridy-kolekce/map-a-set#map-slovnik-s-libovolnymi-klici) a [`Set`](see:js-tridy-kolekce/map-a-set#set-kazda-hodnota-jednou).

## --tip--

Nejdřív se zeptej, jestli klíč v mapě je, a když ne, ulož pod něj prázdnou množinu. Teprve pak si množinu vyzvedni a přidej do ní hodnotu.

# --parsons--

```js
function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, __1__);
  }
  groups.get(key).add(value);
}
```

## --distractors--

```js
groups[key].add(value);
groups.set(key, value);
```

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}
