# --description--

Jádro doporučovače: kamarád viděl něco, co ty ještě ne.

**Úkol:** Přidej do `FilmClub` metodu `recommendFor(member, friend)`, která vrátí množinu filmů, které viděl `friend` a `member` zatím **ne**.

Tentokrát záleží na pořadí: u jedné z operací z minulého kroku dá `a.metoda(b)` jiný výsledek než `b.metoda(a)`. Rozmysli si, na čí množině ji zavoláš.

# --hints--

`recommendFor('Eva', 'Jan')` vrátí filmy, které viděl Jan a Eva ne.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
]);
const films = club.recommendFor('Eva', 'Jan');
assert.ok(films instanceof Set, "club.recommendFor('Eva', 'Jan') má vrátit Set");
assert.deepEqual([...films], ['Kulový blesk', 'Černí baroni'], "club.recommendFor('Eva', 'Jan') má obsahovat 'Kulový blesk' a 'Černí baroni' — filmy Jana, které Eva neviděla");
```

Obrácené pořadí doporučí Janovi filmy od Evy.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
]);
assert.deepEqual([...club.recommendFor('Jan', 'Eva')], ['Kolja'], "club.recommendFor('Jan', 'Eva') má obsahovat jen 'Kolja'");
```

# --help--

## --tip--

Jde o rozdíl množin — viz [Množinové operace](see:js-tridy-kolekce/map-a-set#mnozinove-operace).

## --tip--

Výsledek má obsahovat filmy kamaráda, takže metodu volej na množině `friend` a odečti od ní množinu `member`.

## --tip--

Na jiných datech: co ještě chybí do požadavků inzerátu, je `required.difference(skills)`.

# --explain--

Vysvětli vlastními slovy, proč v `recommendFor` záleží na tom, na čí množině zavoláš `difference`.

## --model--

`a.difference(b)` nechá hodnoty z `a`, které v `b` nejsou. Doporučení mají být filmy kamaráda, které člen neviděl, takže začínám množinou kamaráda a odečítám množinu člena. Obráceně bych dostal filmy člena, které neviděl kamarád, tedy doporučení pro kamaráda. Průnik ani sjednocení na pořadí nezáleží, rozdílu ano.

## --checklist--

- `a.difference(b)` vrací hodnoty z `a`, které nejsou v `b`.
- Doporučení jsou filmy kamaráda, proto se začíná jeho množinou.
- Prohozené pořadí dá doporučení opačným směrem.
- U průniku a sjednocení na pořadí nezáleží.

function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }

  // Počet hodnocení v klubu.
  get size() {
