# --description--

Klub chce vědět, kolik různých filmů jeho členové viděli. Pelíšky jsou v `filmTitles` čtyřikrát, ale jsou to pořád jedny Pelíšky.

**Úkol:** Napiš funkci `uniqueFilms(ratings)`, která vrátí **množinu** `Set` s názvy filmů, každý jednou. Použij funkci `filmTitles`, kterou už máš.

`new Set(pole)` vytvoří množinu z pole a duplicity zahodí. Na jiných datech:

```js
const visitors = ['Eva', 'Jan', 'Eva', 'Bára'];
const uniqueVisitors = new Set(visitors);
```

Zkus si pod funkci napsat `console.log(uniqueFilms(ratings))` a pak `console.log(uniqueFilms(ratings).size)`.

# --hints--

`uniqueFilms` vrátí `Set`.

```js
assert.ok(uniqueFilms([]) instanceof Set, 'uniqueFilms([]) má vrátit Set, ne pole');
```

`uniqueFilms` obsahuje každý hodnocený film jednou, v pořadí prvního výskytu.

```js
const sample = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 3 },
];
const films = uniqueFilms(sample);
assert.equal(films.size, 2, 'uniqueFilms([Pelíšky, Kolja, Pelíšky]) má mít size 2');
assert.deepEqual([...films], ['Pelíšky', 'Kolja'], "uniqueFilms([Pelíšky, Kolja, Pelíšky]) má obsahovat 'Pelíšky' a 'Kolja' v tomto pořadí");
```

# --help--

## --tip--

Jde o `Set` — viz [`Set`: každá hodnota jednou](see:js-tridy-kolekce/map-a-set#set-kazda-hodnota-jednou).

## --tip--

Předej do `new Set(…)` pole z `filmTitles(ratings)` a množinu vrať.

# --explain--

Vysvětli vlastními slovy, proč `uniqueFilms` vrací `Set`, a ne pole bez duplicit.

## --model--

`Set` hlídá jedinečnost sám: film v něm je nejvýš jednou, ať ho přidám kolikrát chci, takže nemusím psát vlastní kontrolu duplicit. Navíc `has` odpoví rychle, jestli tam film je, a množina má hotové operace jako průnik nebo rozdíl, které budu potřebovat pro doporučení. Když potřebuju pole, udělám ho spreadem.

## --checklist--

- `Set` drží každou hodnotu nejvýš jednou bez vlastní kontroly.
- `has` rychle odpoví, jestli hodnota v množině je.
- `Set` má množinové operace pro průnik a rozdíl.
- Pole z množiny vyrobí spread.

## --file-- script.js

```js
// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}
```
