# --description--

Doporučení bez hvězdiček nikoho nepřesvědčí. Klub potřebuje průměrné hodnocení každého filmu.

**Úkol:** Přidej do `FilmClub` soukromé pole `#stars` s mapou „film → pole hvězdiček" a naplň ho v konstruktoru ve stejném cyklu jako `#watched`. Pak napiš metodu `averageRating(film)`, která vrátí průměr hvězdiček zaokrouhlený na jedno desetinné místo. Film, který nikdo nehodnotil, vrátí `null`.

Hodnotou mapy teď není množina, ale pole — hvězdičky se opakovat smějí (dvě pětky jsou dvě hodnocení). Chybějící pole musíš založit stejně jako v `addToGroup`: buď podmínkou `has`, nebo přes `get(…) ?? []`. Zaokrouhlení na jedno místo je `Math.round(x * 10) / 10`.

# --hints--

`averageRating` vrátí průměr hvězdiček na jedno desetinné místo.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
]);
assert.equal(club.averageRating('Pelíšky'), 4.7, "averageRating('Pelíšky') pro hvězdičky 5, 4 a 5 má vrátit 4.7");
assert.equal(club.averageRating('Kolja'), 4, "averageRating('Kolja') pro jediné hodnocení 4 má vrátit 4");
```

Stejné hvězdičky od různých členů se počítají všechny.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Bára', film: 'Samotáři', stars: 2 },
]);
assert.equal(club.averageRating('Samotáři'), 4, "averageRating('Samotáři') pro 5, 5 a 2 má vrátit 4 — nezahazuješ opakované hvězdičky?");
```

Nehodnocený film vrátí `null`.

```js
const club = new FilmClub([{ member: 'Eva', film: 'Pelíšky', stars: 5 }]);
assert.equal(club.averageRating('Kulový blesk'), null, "averageRating('Kulový blesk') má vrátit null — film nikdo nehodnotil");
```

# --help--

## --tip--

Mapa s poli jako hodnotami, obdoba mapy množin — viz [`Map`: slovník s libovolnými klíči](see:js-tridy-kolekce/map-a-set#map-slovnik-s-libovolnymi-klici).

## --tip--

V cyklu konstruktoru si z hodnocení vytáhni i `stars` a pod klíč filmu ulož pole hvězdiček rozšířené o novou hodnotu. V `averageRating` pole vyzvedni, chybějící vrať jako `null`, jinak sečti a vyděl délkou.

## --tip--

Na jiných datech — body hráčů, kde hodnotou mapy je pole:

```js
// 1. v konstruktoru: pole hráče z mapy, chybějící jako prázdné
// 2. pod klíč hráče ulož pole rozšířené o nové body
// 3. v metodě: pole vyzvedni; když chybí, vrať null
// 4. součet přes reduce, vyděl délkou, zaokrouhli
```

# --explain--

Vysvětli vlastními slovy, proč hvězdičky filmů ukládáš do pole, když filmy člena ukládáš do množiny.

## --model--

U filmů člena nechci duplicity: když by se hodnocení stejného filmu objevilo dvakrát, pořád ho viděl jednou, a množina to pohlídá sama. U hvězdiček je každá hodnota samostatné hodnocení jiného člena, takže dvě pětky jsou dvě hodnocení a obě se musí započítat do průměru. Množina by druhou pětku zahodila a průměr by vyšel špatně.

## --checklist--

- Množina drží každou hodnotu nejvýš jednou.
- Film viděný dvakrát je pořád jeden film, proto množina.
- Stejné hvězdičky od různých členů jsou různá hodnocení.
- Množina by opakované hvězdičky zahodila a zkreslila průměr.

// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();
  #stars = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film, stars } of ratings) {
      addToGroup(this.#watched, member, film);
      this.#stars.set(film, [...(this.#stars.get(film) ?? []), stars]);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];
  }

  // Všechny filmy, které kdo v klubu viděl.
  get allFilms() {
    return new Set(this.#ratings.map((rating) => rating.film));
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }

  // Od kolegy: viděl člen tenhle film?
  hasSeen(member, film) {
    return this.#watched.get(member)?.has(film) ?? false;
  }

  // Filmy, které viděli oba členové.
  commonFilms(first, second) {
    return this.watchedBy(first).intersection(this.watchedBy(second));
  }

  // Filmy, které viděl kamarád a člen zatím ne.
  recommendFor(member, friend) {
    return this.watchedBy(friend).difference(this.watchedBy(member));
  }

  // Filmy, které viděli úplně všichni členové.
  seenByEveryone() {
    return this.members
      .map((member) => this.watchedBy(member))
      .reduce((common, films) => common.intersection(films), this.allFilms);
  }

  // Průměrné hodnocení filmu na jedno desetinné místo; neznámý film null.
  averageRating(film) {
    const stars = this.#stars.get(film);
    if (!stars) {
      return null;
    }
    const sum = stars.reduce((total, value) => total + value, 0);
    return Math.round((sum / stars.length) * 10) / 10;
  }
}
