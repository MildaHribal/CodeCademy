# --description--

Streamovací služby i filmové weby ukazují „Diváci s podobným vkusem viděli…". V tomhle workshopu takový doporučovač postavíš pro filmový klub. Kdo co viděl, co mají dva členové společného a co jeden viděl a druhý ne, jsou přesně otázky pro `Map` a `Set`. Na konci ho zapojíš do stránky, kde si vybereš člena a doporučení se hned přepočítají.

V `script.js` je pole `ratings`: každé hodnocení říká, který člen (`member`) viděl který film (`film`) a kolik mu dal hvězdiček (`stars`). Začneš něčím, co umíš ze sekce o polích.

**Úkol:** Napiš funkci `filmTitles(ratings)`, která vrátí pole názvů filmů ze všech hodnocení ve stejném pořadí. Filmy, které hodnotilo víc členů, v něm budou víckrát.

# --hints--

`filmTitles` vrátí názvy filmů v pořadí hodnocení, i opakované.

```js
const sample = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 3 },
];
assert.deepEqual(filmTitles(sample), ['Pelíšky', 'Kolja', 'Pelíšky'], "filmTitles([Eva: Pelíšky, Jan: Kolja, Jan: Pelíšky]) má vrátit ['Pelíšky', 'Kolja', 'Pelíšky']");
```

Pro prázdné pole hodnocení vrátí `filmTitles` prázdné pole.

```js
assert.deepEqual(filmTitles([]), [], 'filmTitles([]) má vrátit []');
```

# --solution--

## --file-- script.js

```js
// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}
```
