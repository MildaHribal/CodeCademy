# --description--

Klub chce na výroční večer pustit film, který viděli **všichni** — ať se o něm dá mluvit.

**Úkol:** Přidej do `FilmClub` metodu `seenByEveryone()`, která vrátí množinu filmů, které viděl každý člen. Klub bez členů vrátí prázdnou množinu.

Průnik dvou množin už umíš. Průnik víc množin je průnik prvních dvou, pak s třetí, pak se čtvrtou… Z pole množin tak děláš jednu hodnotu. Jako výchozí bod se hodí `allFilms`: průnik s ní nic neubere.

# --hints--

`seenByEveryone` vrátí filmy, které viděli všichni členové.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Kolja', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
]);
const films = club.seenByEveryone();
assert.ok(films instanceof Set, 'club.seenByEveryone() má vrátit Set');
assert.deepEqual([...films], ['Kolja'], "club.seenByEveryone() má obsahovat jen 'Kolja' — Pelíšky neviděla Bára");
```

Když nemají všichni nic společného, vrátí prázdnou množinu.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
]);
assert.equal(club.seenByEveryone().size, 0, 'club.seenByEveryone() má být prázdná, když Eva a Jan nemají společný film');
```

Klub bez členů vrátí prázdnou množinu.

```js
const films = new FilmClub([]).seenByEveryone();
assert.ok(films instanceof Set, 'new FilmClub([]).seenByEveryone() má vrátit Set');
assert.equal(films.size, 0, 'klub bez členů má vrátit prázdnou množinu');
```

# --help--

## --tip--

Průnik z [Množinových operací](see:js-tridy-kolekce/map-a-set#mnozinove-operace), opakovaný přes celé pole — to je úloha pro [`reduce`](see:js-pole/metody-pole-do-hloubky#jak-pracuje-reduce).

## --tip--

Z `members` udělej pole množin přes `watchedBy`. Pak ho zredukuj: akumulátor začne jako `allFilms` a každá další množina ho zúží průnikem.

## --tip--

Postup v těle metody:

```js
// 1. ze jmen členů pole jejich množin filmů
// 2. reduce: akumulátor je dosavadní průnik, začíná všemi filmy klubu
// 3. v každém kroku ho zúži množina dalšího člena
// 4. výsledek vrať
```

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];
  }

  // Všechny filmy, které kdo v klubu viděl.
  get allFilms() {
    return new Set(this.#ratings.map((rating) => rating.film));
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }

  // Od kolegy: viděl člen tenhle film?
  hasSeen(member, film) {
    return this.#watched.get(member)?.has(film) ?? false;

    return this.watchedBy(friend).difference(this.watchedBy(member));

  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];
  }

  // Všechny filmy, které kdo v klubu viděl.
  get allFilms() {
    return new Set(this.#ratings.map((rating) => rating.film));
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }

  // Od kolegy: viděl člen tenhle film?
  hasSeen(member, film) {
    return this.#watched.get(member)?.has(film) ?? false;
  }

  // Filmy, které viděli oba členové.
  commonFilms(first, second) {
    return this.watchedBy(first).intersection(this.watchedBy(second));
  }

  // Filmy, které viděl kamarád a člen zatím ne.
  recommendFor(member, friend) {
    return this.watchedBy(friend).difference(this.watchedBy(member));
  }

  // Filmy, které viděli úplně všichni členové.
  seenByEveryone() {
    return this.members
      .map((member) => this.watchedBy(member))
      .reduce((common, films) => common.intersection(films), this.allFilms);
  }
}
