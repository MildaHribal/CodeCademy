# --description--

## Hlášení

Kolega přidal do `FilmClub` metodu `hasSeen(member, film)` pro ikonku „už jsi viděl" u filmu. Ikonka ale nesvítí nikdy: `club.hasSeen('Eva', 'Pelíšky')` vrací `false`, přestože Eva Pelíšky hodnotila. Konzole žádnou chybu nehlásí.

## Úkol

Oprav `hasSeen`, aby vracela `true` pro filmy, které člen viděl, a `false` pro ostatní i pro neznámého člena. Změň co nejmenší kus kódu.

# --hints--

`hasSeen` vrátí `true` pro film, který člen hodnotil.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
]);
assert.equal(club.hasSeen('Eva', 'Pelíšky'), true, "club.hasSeen('Eva', 'Pelíšky') má vrátit true — Eva Pelíšky hodnotila");
```

`hasSeen` vrátí `false` pro film, který člen neviděl, i pro neznámého člena.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
]);
assert.equal(club.hasSeen('Eva', 'Kolja'), false, "club.hasSeen('Eva', 'Kolja') má vrátit false");
assert.equal(club.hasSeen('Ondřej', 'Pelíšky'), false, "club.hasSeen('Ondřej', 'Pelíšky') pro neznámého člena má vrátit false");
```

`watchedBy` funguje dál.

```js
const club = new FilmClub([{ member: 'Eva', film: 'Pelíšky', stars: 5 }]);
assert.deepEqual([...club.watchedBy('Eva')], ['Pelíšky'], "club.watchedBy('Eva') má dál vracet množinu s 'Pelíšky'");
```

# --help--

## --tip--

Chyba odpovídá pasti [Hranaté závorky místo `set`](see:js-tridy-kolekce/map-a-set#hranate-zavorky-misto-set) — tady u čtení.

## --tip--

`this.#watched[member]` hledá obyčejnou vlastnost objektu mapy, ne dvojici ve slovníku, a vždycky vrátí `undefined`. Hodnotu pod klíčem mapy vrací její metoda.

## --tip--

Na jiných datech: `this.#tagsByPost.get(postId)?.has('akce') ?? false`.

const ratings = [

  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }
--edit--

  // Od kolegy: viděl člen tenhle film?
  hasSeen(member, film) {
    return this.#watched[member]?.has(film) ?? false;
  }
--edit--
}
