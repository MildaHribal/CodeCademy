# --description--

**Úkol:** Přidej do `FilmClub` getter `allFilms`, který vrátí množinu všech filmů, které kdo v klubu hodnotil, každý jednou.

Cest je víc: data máš v `#ratings` i v mapě `#watched`, a na obojí se hodí jiné nástroje. Vyber si.

# --hints--

`allFilms` vrátí množinu všech hodnocených filmů bez duplicit.

```js
const club = new FilmClub([
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
]);
const films = club.allFilms;
assert.ok(films instanceof Set, 'club.allFilms má být Set');
assert.deepEqual([...films].sort(), ['Kolja', 'Obecná škola', 'Pelíšky'], "club.allFilms má obsahovat 'Pelíšky', 'Kolja' a 'Obecná škola', každý jednou");
```

Klub bez hodnocení nemá žádné filmy.

```js
const films = new FilmClub([]).allFilms;
assert.ok(films instanceof Set, 'new FilmClub([]).allFilms má být Set');
assert.equal(films.size, 0, 'new FilmClub([]).allFilms má být prázdná množina');
```

# --help--

## --tip--

Množina bez duplicit — viz [`Set`: každá hodnota jednou](see:js-tridy-kolekce/map-a-set#set-kazda-hodnota-jednou); sjednocení najdeš v [Množinových operacích](see:js-tridy-kolekce/map-a-set#mnozinove-operace).

## --tip--

Buď z hodnocení vytáhni názvy filmů a dej je do nové množiny, nebo postupně sjednoť množiny všech členů.

## --tip--

Postup pro první cestu:

```js
// 1. z každého hodnocení jen název filmu
// 2. výsledné pole předej do nové množiny
```

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());

  groups.get(key).add(value);

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }
  }

  // Počet hodnocení v klubu.

    return this.#ratings.length;

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];

  // Všechny filmy, které kdo v klubu viděl.
  get allFilms() {
    return new Set(this.#ratings.map((rating) => rating.film));
