# --description--

Víc funkcí nad jedním polem hodnocení se časem špatně udržuje. Klub dostane vlastní třídu, která si hodnocení schová a bude nad nimi odpovídat na otázky. Třídy se soukromými poli a gettery umíš z bankovního účtu, tentokrát bez návodu.

**Úkol:** Napiš třídu `FilmClub`. Konstruktor dostane pole hodnocení a uloží si jeho **kopii** do soukromého pole `#ratings`. Getter `size` vrátí počet hodnocení. Když někdo původní pole později změní, klub se to nedozví.

# --hints--

`new FilmClub(ratings).size` vrátí počet hodnocení.

```js
const sample = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
];
const club = new FilmClub(sample);
assert.equal(club.size, 2, 'new FilmClub([2 hodnocení]).size má být 2');
assert.equal(new FilmClub([]).size, 0, 'new FilmClub([]).size má být 0');
```

Klub si drží kopii pole: pozdější `push` do původního pole ho nezmění.

```js
const sample = [{ member: 'Eva', film: 'Pelíšky', stars: 5 }];
const club = new FilmClub(sample);
sample.push({ member: 'Jan', film: 'Kolja', stars: 4 });
assert.equal(club.size, 1, 'po push do původního pole má club.size zůstat 1 — ukládá konstruktor kopii?');
```

Hodnocení jsou v soukromém poli.

```js
const club = new FilmClub([]);
assert.deepEqual(Object.keys(club), [], 'instance FilmClub nemá mít veřejné vlastnosti — hodnocení patří do #ratings');
```

## --file-- script.js

```js
// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

class FilmClub {
  #ratings = [];

  constructor(ratings) {
    this.#ratings = [...ratings];
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }
}
```
