# --description--

Výběr člena na stránce potřebuje seznam jmen. Ten už v mapě `#watched` je — jsou to její klíče.

**Úkol:** Přidej do `FilmClub` getter `members`, který vrátí **pole** jmen členů v pořadí, v jakém poprvé hodnotili.

`map.keys()` vrátí klíče mapy, ale ne jako pole: je to iterátor, který jde projít `for…of` nebo rozprostřít do pole. Na jiných datech:

```js
const cart = new Map([[101, 2], [205, 1]]);
const productIds = [...cart.keys()];
```

# --hints--

`members` vrátí pole jmen v pořadí prvního hodnocení, každé jméno jednou.

```js
const club = new FilmClub([
  { member: 'Jan', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
]);
assert.ok(Array.isArray(club.members), 'club.members má být pole');
assert.deepEqual(club.members, ['Jan', 'Eva'], "club.members má být ['Jan', 'Eva'] — Jan hodnotil první");
```

Klub bez hodnocení nemá žádné členy.

```js
assert.deepEqual(new FilmClub([]).members, [], 'new FilmClub([]).members má být []');
```

## --tip--

Klíče mapy — viz [`Map`: slovník s libovolnými klíči](see:js-tridy-kolekce/map-a-set#map-slovnik-s-libovolnymi-klici).

## --tip--

V getteru vezmi klíče z `#watched` a rozprostři je do nového pole.

const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}

function addToGroup(groups, key, value) {
  if (!groups.has(key)) {
    groups.set(key, new Set());
  }
  groups.get(key).add(value);
}

class FilmClub {
  #ratings = [];
  #watched = new Map();

  constructor(ratings) {
    this.#ratings = [...ratings];
    for (const { member, film } of ratings) {
      addToGroup(this.#watched, member, film);
    }
  }

  // Počet hodnocení v klubu.
  get size() {
    return this.#ratings.length;
  }

  // Jména členů v pořadí, v jakém poprvé hodnotili.
  get members() {
    return [...this.#watched.keys()];
  }

  // Kopie množiny filmů, které člen viděl; neznámý člen nic neviděl.
  watchedBy(member) {
    return new Set(this.#watched.get(member));
  }
}
