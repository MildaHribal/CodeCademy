# --description--

Pro žebříček oblíbenosti potřebuješ ke každému filmu počet členů, kteří ho viděli.

**Úkol:** Napiš funkci `countViews(ratings)`, která vrátí `Map`, kde klíčem je název filmu a hodnotou počet hodnocení. Filmy jsou v mapě v pořadí prvního výskytu.

Vzor počítání s mapou: `get` vrátí dosavadní počet (nebo `undefined`), `?? 0` z něj udělá nulu a `set` uloží nový. Na jiných datech:

```js
// 1. prázdná mapa
const visits = new Map();
// 2. pro každou stránku přičti jedničku
for (const page of pages) {
  visits.set(page, (visits.get(page) ?? 0) + 1);
}
```

# --hints--

`countViews` vrátí `Map` s počtem hodnocení každého filmu.

```js
const sample = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Jan', film: 'Kolja', stars: 4 },
  { member: 'Bára', film: 'Pelíšky', stars: 3 },
];
const views = countViews(sample);
assert.ok(views instanceof Map, 'countViews(…) má vrátit Map, ne objekt');
assert.deepEqual([...views], [['Pelíšky', 2], ['Kolja', 1]], "countViews([Pelíšky, Kolja, Pelíšky]) má obsahovat 'Pelíšky' => 2 a 'Kolja' => 1");
```

Pro prázdné pole vrátí `countViews` prázdnou mapu.

```js
const views = countViews([]);
assert.ok(views instanceof Map, 'countViews([]) má vrátit Map');
assert.equal(views.size, 0, 'countViews([]) má vrátit mapu se size 0');
```

## --tip--

Jde o `Map` jako počítadlo — viz [`Map`: slovník s libovolnými klíči](see:js-tridy-kolekce/map-a-set#map-slovnik-s-libovolnymi-klici).

## --tip--

Mapu založ uvnitř funkce, projdi hodnocení a pro každý film ulož počet o jedna vyšší. Na konci mapu vrať.

# --solution--

## --file-- script.js

```js
// Filmový klub: kdo co viděl a kolik dal hvězdiček (1–5).
const ratings = [
  { member: 'Eva', film: 'Pelíšky', stars: 5 },
  { member: 'Eva', film: 'Kolja', stars: 4 },
  { member: 'Eva', film: 'Vratné lahve', stars: 3 },
  { member: 'Eva', film: 'Samotáři', stars: 4 },
  { member: 'Jan', film: 'Pelíšky', stars: 4 },
  { member: 'Jan', film: 'Samotáři', stars: 5 },
  { member: 'Jan', film: 'Kulový blesk', stars: 5 },
  { member: 'Jan', film: 'Černí baroni', stars: 3 },
  { member: 'Bára', film: 'Kolja', stars: 5 },
  { member: 'Bára', film: 'Pelíšky', stars: 5 },
  { member: 'Bára', film: 'Obecná škola', stars: 4 },
  { member: 'Bára', film: 'Vratné lahve', stars: 4 },
  { member: 'Ondřej', film: 'Kulový blesk', stars: 4 },
  { member: 'Ondřej', film: 'Černí baroni', stars: 5 },
  { member: 'Ondřej', film: 'Samotáři', stars: 3 },
  { member: 'Ondřej', film: 'Pelíšky', stars: 3 },
];

// Názvy filmů ze všech hodnocení, v pořadí hodnocení.
function filmTitles(ratings) {
  return ratings.map((rating) => rating.film);
}

// Množina všech hodnocených filmů, každý jednou.
function uniqueFilms(ratings) {
  return new Set(filmTitles(ratings));
}

// Kolik členů který film hodnotilo.
function countViews(ratings) {
  const counts = new Map();
  for (const { film } of ratings) {
    counts.set(film, (counts.get(film) ?? 0) + 1);
  }
  return counts;
}
```
