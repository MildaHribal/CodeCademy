# --description--

Když se uživatel vrátí do aplikace, pohyby přijdou z databáze jako obyčejná data: `[{ type: 'deposit', amount: 32000 }, …]`. Zůstatek se v databázi neukládá — účet ho spočítá tak, že pohyby znovu „přehraje".

**Úkol:** Napiš statickou metodu `fromTransactions(owner, transactions)`, která založí účet a postupně na něm provede všechny pohyby: typ `'deposit'` jako vklad, typ `'withdrawal'` jako výběr. Vrátí hotový účet. Když data obsahují výběr, na který nejsou peníze, vyhodí `RangeError` — přehrávání přes `deposit` a `withdraw` to zajistí samo.

Na průchod pohyby se hodí `for…of`, `forEach` nebo `reduce` — vyber si. Pozor: v `forEach` s obyčejnou funkcí `function` by ses vrátil k chybě z předchozího kroku.

> [!TIP]
> Tady máš hotový účet: vklady, výběry, kontroly, historii s id i dvě tovární metody. Klidně si dej pauzu. Dál přijde spořicí účet.

# --hints--

`fromTransactions` přehraje vklady a výběry a vrátí účet se správným zůstatkem.

```js
const account = BankAccount.fromTransactions('Eva Dvořáková', [
  { type: 'deposit', amount: 32000 },
  { type: 'withdrawal', amount: 1200 },
  { type: 'deposit', amount: 4500 },
]);
assert.ok(account instanceof BankAccount, 'fromTransactions má vrátit instanci BankAccount');
assert.equal(account.owner, 'Eva Dvořáková', "fromTransactions('Eva Dvořáková', …).owner má být 'Eva Dvořáková'");
assert.equal(account.balance, 35300, 'po vkladu 32000, výběru 1200 a vkladu 4500 má být zůstatek 35300');
```

Přehrané pohyby jsou v historii s novými id.

```js
const account = BankAccount.fromTransactions('Jan Novák', [
  { type: 'deposit', amount: 800 },
  { type: 'withdrawal', amount: 300 },
]);
assert.deepEqual(account.transactions, [
  { id: 'TX-1', type: 'deposit', amount: 800 },
  { id: 'TX-2', type: 'withdrawal', amount: 300 },
], 'fromTransactions(…, [vklad 800, výběr 300]) má zapsat pohyby TX-1 a TX-2');
```

Výběr bez peněz v datech vyhodí `RangeError`.

```js
assert.throws(
  () => BankAccount.fromTransactions('Jan Novák', [{ type: 'withdrawal', amount: 100 }]),
  { name: 'RangeError', message: 'Nedostatek prostředků' },
  "fromTransactions(…, [výběr 100]) na prázdném účtu má vyhodit RangeError 'Nedostatek prostředků'",
);
```

Prázdný seznam pohybů vrátí účet se zůstatkem `0`.

```js
const account = BankAccount.fromTransactions('Jan Novák', []);
assert.equal(account.balance, 0, "fromTransactions('Jan Novák', []) má vrátit účet se zůstatkem 0");
```

## --tip--

Stejný druh metody jako `open` — viz [Statické členy `static`](see:js-tridy-kolekce/tridy#staticke-cleny-static).

## --tip--

Po založení instance projdi pole pohybů a podle `type` zavolej na instanci `deposit`, nebo `withdraw`. Instanci vrať až po průchodu.

## --tip--

Na jiných datech — obnovení přehrávače z uložených akcí:

```js
static replay(actions) {
  const player = new Player();
  for (const { name, seconds } of actions) {
    // podle name zavolej odpovídající metodu přehrávače
  }
  return player;
}
```

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  // Založí účet a rovnou na něj vloží první částku.
  static open(owner, initialDeposit) {
    const account = new BankAccount(owner);
    account.deposit(initialDeposit);
    return account;
  }

  // Obnoví účet z uložených pohybů, třeba z databáze.
  static fromTransactions(owner, transactions) {
    const account = new BankAccount(owner);
    for (const { type, amount } of transactions) {
      if (type === 'deposit') {
        account.deposit(amount);
      } else {
        account.withdraw(amount);
      }
    }
    return account;
  }

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
      .filter((transaction) => transaction.type === 'deposit')
      .reduce((sum, transaction) => sum + transaction.amount, 0);
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  // Od kolegy: vloží víc částek najednou, třeba výplatu a vratku.
  depositAll(amounts) {
    amounts.forEach((amount) => {
      this.deposit(amount);
    });
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}
```
