# --description--

Banka zakládá účty vždycky s prvním vkladem. Místo dvou řádků (`new` a `deposit`) na každém místě aplikace se hodí jedna funkce, která patří k účtům jako celku — ne ke konkrétnímu účtu.

**Úkol:** Přidej do `BankAccount` [[statická metoda|statickou metodu]] `open(owner, initialDeposit)`, která založí nový účet, vloží na něj `initialDeposit` a účet vrátí. Neplatný první vklad vyhodí stejnou chybu jako `deposit`.

Statickou metodu zapíšeš slovem `static` před jménem a voláš ji na třídě: `BankAccount.open(…)`. Uvnitř vytvoř instanci přes `new` a na ní použij metody, které už máš.

# --hints--

`BankAccount.open('Eva Dvořáková', 1000)` vrátí účet Evy se zůstatkem `1000` a jedním pohybem.

```js
const account = BankAccount.open('Eva Dvořáková', 1000);
assert.ok(account instanceof BankAccount, "BankAccount.open('Eva Dvořáková', 1000) má vrátit instanci BankAccount");
assert.equal(account.owner, 'Eva Dvořáková', "BankAccount.open('Eva Dvořáková', 1000).owner má být 'Eva Dvořáková'");
assert.equal(account.balance, 1000, "BankAccount.open('Eva Dvořáková', 1000).balance má být 1000");
assert.deepEqual(account.transactions, [{ id: 'TX-1', type: 'deposit', amount: 1000 }], 'první vklad se má zapsat jako pohyb TX-1');
```

Neplatný první vklad vyhodí `RangeError`.

```js
assert.throws(() => BankAccount.open('Jan Novák', 0), { name: 'RangeError', message: 'Částka musí být kladné číslo' }, "BankAccount.open('Jan Novák', 0) má vyhodit RangeError 'Částka musí být kladné číslo'");
```

`open` je statická metoda, instance ji nemá.

```js
assert.equal(typeof BankAccount.open, 'function', 'BankAccount.open má být funkce na třídě');
assert.equal(typeof new BankAccount('Jan Novák').open, 'undefined', 'instance účtu nemá mít metodu open — patří třídě, ne účtu');
```

## --tip--

## --tip--

V těle statické metody zavolej `new BankAccount(…)`, uloženou instanci použij pro vklad a na konci ji vrať.

## --tip--

Na jiných datech:

```js
static trial(email) {
  // 1. nová instance
  // 2. nastav zkušební měsíc metodou instance
  // 3. vrať instanci
}
```

# --explain--

Vysvětli vlastními slovy, proč je `open` statická metoda a ne obyčejná metoda účtu.

## --model--

Obyčejnou metodu můžu zavolat jen na účtu, který už existuje, ale `open` teprve účet vytváří. Patří proto k třídě jako celku a volá se `BankAccount.open(…)`. Uvnitř vytvoří instanci přes `new`, použije na ní obyčejné metody a vrátí ji, takže zbytek aplikace nemusí opakovat dva řádky a nezapomene na první vklad.

## --checklist--

- Obyčejnou metodu jde zavolat jen na existující instanci.
- `open` účet teprve vytváří, proto patří třídě.
- Statická metoda se volá na třídě, ne na instanci.
- Tovární metoda schová opakované kroky založení na jedno místo.

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  // Založí účet a rovnou na něj vloží první částku.
  static open(owner, initialDeposit) {
    const account = new BankAccount(owner);
    account.deposit(initialDeposit);
    return account;
  }

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
      .filter((transaction) => transaction.type === 'deposit')
      .reduce((sum, transaction) => sum + transaction.amount, 0);
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;

    }
  }

  #record(type, amount) {

  }
}
```
