# --description--

Kdokoli v aplikaci teď může napsat `account.balance = 1000000` a peníze jsou na světě. Zůstatek se má měnit **jen** vkladem a výběrem. Zvenku ho půjde číst, ale ne přepsat.

**Úkol:** Zůstatek schovej do [[soukromé pole|soukromého pole]] `#balance` a zvenku ho zpřístupni jen ke čtení [[getter|getterem]] `balance`:

1. Nahoru do těla třídy přidej pole `#balance = 0;` a smaž z konstruktoru řádek `this.balance = 0;`.
2. V `deposit` a `withdraw` pracuj s `this.#balance`.
3. Přidej getter `balance`, který vrátí `this.#balance`.

Kód, který čte `account.balance`, pak funguje dál beze změny — jen zápis do `balance` už nic neudělá. Na jiných datech:

```js
class Subscription {
  #months = 0;

  get months() {
    return this.#months;
  }
}
```

> [!PITFALL]
> Když v konstruktoru zůstane `this.balance = 0`, narazí zápis na getter bez setteru: `TypeError: Cannot set property balance of #<BankAccount> which has only a getter`.

# --hints--

Getter `balance` vrací zůstatek po vkladu a výběru.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
account.withdraw(300);
assert.equal(account.balance, 700, 'po deposit(1000) a withdraw(300) má getter balance vrátit 700');
```

Přiřazení do `account.balance` zůstatek nezmění.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(200);
account.balance = 1000000;
assert.equal(account.balance, 200, 'po account.balance = 1000000 má zůstatek zůstat 200 — balance má mít jen getter');
```

Zůstatek je v soukromém poli `#balance`, ne ve veřejné vlastnosti.

```js
const account = new BankAccount('Eva Dvořáková');
assert.deepEqual(Object.keys(account), ['owner'], "Object.keys(new BankAccount('Eva Dvořáková')) má vrátit jen ['owner'] — balance nemá být veřejná vlastnost");
const source = helpers.stripComments(BankAccount.toString(), 'js');
assert.match(source, /#balance\b/, 've třídě BankAccount chybí soukromé pole #balance');
```

# --help--

## --tip--

Jde o soukromé pole a getter — viz [Soukromá pole `#`](see:js-tridy-kolekce/tridy#soukroma-pole) a [Gettery a settery](see:js-tridy-kolekce/tridy#gettery-a-settery).

## --tip--

Getter je metoda se slovem `get` před jménem; čte se bez závorek. Pole `#balance` deklaruj v těle třídy, jinak ho metody nesmí použít.

# --explain--

Vysvětli vlastními slovy, proč je zůstatek v soukromém poli `#balance` a ne v obyčejné vlastnosti `balance`.

## --model--

Obyčejnou vlastnost může přepsat jakýkoli kód v aplikaci, třeba omylem `account.balance = 0`, a účet se dostane do stavu, který nevznikl žádným vkladem ani výběrem. K soukromému poli se dostane jen kód uvnitř třídy, takže zůstatek mění jen `deposit` a `withdraw` a ty můžou hlídat pravidla. Zvenku ho jde číst přes getter, ale zápis do `balance` nic neudělá.

## --checklist--

- Obyčejnou vlastnost může přepsat kdokoli zvenku.
- K soukromému poli `#` má přístup jen kód v těle třídy.
- Zůstatek se tak mění jen metodami, které hlídají pravidla.
- Getter dovolí hodnotu číst, ale ne přepsat.

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  deposit(amount) {
    this.#balance += amount;
  }

  withdraw(amount) {
    this.#balance -= amount;
  }
}
```
