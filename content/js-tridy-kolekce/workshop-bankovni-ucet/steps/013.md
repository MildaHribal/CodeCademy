# --description--

## Hlášení

Kolega přidal do třídy metodu `depositAll(amounts)`, aby šlo najednou připsat výplatu a vratku z e-shopu. Jenže `account.depositAll([32000, 4500])` spadne hned na první částce:

`TypeError: Cannot read properties of undefined (reading 'deposit')`

Zůstatek se nezmění a do historie se nic nezapíše.

## Úkol

Oprav `depositAll` tak, aby vložila všechny částky a dál odmítala neplatné. Změň co nejmenší kus kódu.

# --hints--

`depositAll([32000, 4500])` vloží obě částky a zapíše dva pohyby.

```js
const account = new BankAccount('Eva Dvořáková');
account.depositAll([32000, 4500]);
assert.equal(account.balance, 36500, 'po depositAll([32000, 4500]) má být zůstatek 36500');
assert.equal(account.transactions.length, 2, 'po depositAll([32000, 4500]) mají být v historii 2 pohyby');
```

`depositAll` dál odmítá neplatnou částku.

```js
const account = new BankAccount('Eva Dvořáková');
assert.throws(() => account.depositAll([100, -50]), { name: 'RangeError', message: 'Částka musí být kladné číslo' }, "depositAll([100, -50]) má vyhodit RangeError 'Částka musí být kladné číslo'");
```

Obyčejný vklad a výběr fungují dál.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(800);
account.withdraw(300);
assert.equal(account.balance, 500, 'po deposit(800) a withdraw(300) má být zůstatek 500');
```

# --help--

## --tip--

Hláška říká, že `this` je `undefined`. Tahle past je popsaná v [Obyčejná funkce jako callback uvnitř metody](see:js-tridy-kolekce/tridy#obycejna-funkce-jako-callback-uvnitr-metody).

## --tip--

Callback předaný do `forEach` je zapsaný přes `function`, a ten má vlastní `this`. Stačí změnit zápis callbacku, tělo nech být.

## --tip--

Který druh funkce vlastní `this` nemá a převezme ho z metody, ve které vznikl? Ten použij pro callback.

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
      .filter((transaction) => transaction.type === 'deposit')
      .reduce((sum, transaction) => sum + transaction.amount, 0);
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  // Od kolegy: vloží víc částek najednou, třeba výplatu a vratku.
  depositAll(amounts) {
    amounts.forEach((amount) => {
      this.deposit(amount);
    });
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}
```
