# --description--

`account.deposit(-5000)` teď potichu sníží zůstatek a `account.deposit(NaN)` z něj udělá `NaN`. Prázdné políčko formuláře přitom dá přesně `NaN`. Účet má takový vklad odmítnout.

**Úkol:** Na začátku metody `deposit` vyhoď `RangeError` se zprávou `'Částka musí být kladné číslo'`, když `amount` není konečné číslo větší než nula. Zůstatek se pak nezmění.

Chybu vyhodí příkaz `throw`: zastaví metodu a chyba doletí k tomu, kdo metodu zavolal. Podrobně se k chybám dostaneš v sekci o chybách a ladění. Na jiných datech:

```js
extend(months) {
  if (!Number.isInteger(months) || months < 1) {
    throw new RangeError('Prodloužit jde aspoň o jeden měsíc');
  }
  this.#months += months;
}
```

Konečné číslo pozná `Number.isFinite(amount)`: pro `NaN` i text vrátí `false`.

# --hints--

`deposit(0)`, `deposit(-100)` i `deposit(NaN)` vyhodí `RangeError` se zprávou `'Částka musí být kladné číslo'`.

```js
const account = new BankAccount('Eva Dvořáková');
for (const amount of [0, -100, NaN]) {
  assert.throws(
    () => account.deposit(amount),
    { name: 'RangeError', message: 'Částka musí být kladné číslo' },
    `deposit(${amount}) má vyhodit RangeError se zprávou 'Částka musí být kladné číslo'`,
  );
}
```

Odmítnutý vklad nezmění zůstatek a platný vklad funguje dál.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
try {
  account.deposit(-5000);
} catch {
  // chyba je tu v pořádku
}
assert.equal(account.balance, 1000, 'po deposit(1000) a odmítnutém deposit(-5000) má zůstatek zůstat 1000');
```

# --help--

## --tip--

Kontrolu napiš jako první řádky metody, ještě před změnou `#balance`. Když podmínka platí, `throw` metodu ukončí.

## --tip--

Podmínka má platit, když číslo **není** konečné, **nebo** je menší či rovno nule.

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  deposit(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
    this.#balance += amount;
  }

  withdraw(amount) {
    this.#balance -= amount;
  }
}
```
