# --description--

Historie je připravená, teď do ní budou vklady a výběry zapisovat.

**Úkol:** Napiš soukromou metodu `#record(type, amount)`, která na konec `#transactions` přidá objekt `{ type, amount }`. Zavolej ji na konci `deposit` s typem `'deposit'` a na konci `withdraw` s typem `'withdrawal'`. Odmítnutý vklad nebo výběr se nezapíše.

Zápis dáváš **na konec** metod záměrně: když kontrola vyhodí chybu, metoda skončí dřív a k zápisu se nedostane. Kam `#record` umístit v těle třídy, je jedno — zvyk je dávat soukromé metody dolů.

# --hints--

Vklad a výběr se zapíšou do historie v pořadí, v jakém proběhly.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
account.withdraw(300);
assert.deepEqual(account.transactions, [
  { type: 'deposit', amount: 1000 },
  { type: 'withdrawal', amount: 300 },
], "po deposit(1000) a withdraw(300) má historie být [{ type: 'deposit', amount: 1000 }, { type: 'withdrawal', amount: 300 }]");
```

Odmítnutý vklad ani výběr se do historie nezapíše.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(500);
for (const action of [() => account.withdraw(5000), () => account.deposit(0)]) {
  try {
    action();
  } catch {
    // chyba je tu v pořádku
  }
}
assert.equal(account.transactions.length, 1, 'po deposit(500) a odmítnutých withdraw(5000) a deposit(0) má historie mít 1 pohyb');
```

Zápis dělá soukromá metoda `#record`.

```js
const source = helpers.stripComments(BankAccount.toString(), 'js');
assert.match(source, /this\s*\.\s*#record\s*\(/, 'deposit a withdraw mají volat this.#record(…)');
```

# --help--

## --tip--

Soukromou metodu už máš (`#assertPositive`), tahle je stejného druhu — viz [Soukromá pole `#`](see:js-tridy-kolekce/tridy#soukroma-pole).

## --tip--

V `#record` přidej objekt do soukromého pole metodou, která přidává na konec. V `deposit` a `withdraw` ji zavolej jako poslední řádek, až po změně zůstatku.

## --tip--

Na jiných datech: soukromá metoda `#log(action)` by dělala `this.#entries.push({ action, at: Date.now() })`.

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ type, amount });
  }
}
```
