# --description--

Z účtu s 500 Kč teď jde vybrat 2000 a zůstatek spadne do mínusu. Kontokorent náš účet nemá.

**Úkol:** V `withdraw` vyhoď `RangeError` se zprávou `'Nedostatek prostředků'`, když je `amount` větší než zůstatek. Vybrat přesně celý zůstatek jde.

Kontrolu dej za volání `#assertPositive` a před změnu zůstatku. Stejně by předplatné odmítlo zrušit víc měsíců, než kolik jich zbývá:

```js
if (months > this.#months) {
  throw new RangeError('Tolik měsíců předplatné nemá');
}
```

# --hints--

Výběr většího obnosu, než je na účtu, vyhodí `RangeError` se zprávou `'Nedostatek prostředků'` a zůstatek nezmění.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(500);
assert.throws(() => account.withdraw(2000), { name: 'RangeError', message: 'Nedostatek prostředků' }, "withdraw(2000) z účtu s 500 Kč má vyhodit RangeError 'Nedostatek prostředků'");
assert.equal(account.balance, 500, 'odmítnutý withdraw(2000) nesmí změnit zůstatek 500');
```

Celý zůstatek vybrat jde.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(500);
account.withdraw(500);
assert.equal(account.balance, 0, 'withdraw(500) z účtu s 500 Kč má projít a nechat zůstatek 0');
```

Nekladná částka hlásí dál `'Částka musí být kladné číslo'`.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(500);
assert.throws(() => account.withdraw(-2000), { name: 'RangeError', message: 'Částka musí být kladné číslo' }, "withdraw(-2000) má hlásit 'Částka musí být kladné číslo', ne nedostatek prostředků");
```

## --tip--

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }
}
```
