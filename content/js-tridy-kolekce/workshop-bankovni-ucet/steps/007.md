# --description--

Výběr má stejnou díru: `withdraw(-500)` peníze přidá. Kontrolu z `deposit` bys mohl zkopírovat, ale dvě kopie se časem rozejdou. Lepší je dát ji do jedné metody. A protože ji zvenku nikdo volat nemá, bude soukromá.

**Úkol:** Kontrolu částky přesuň do soukromé metody `#assertPositive(amount)` a zavolej ji na začátku `deposit` **i** `withdraw`.

Soukromá metoda má před jménem `#` stejně jako soukromé pole a volá se přes `this`. Na jiných datech:

```js
class Subscription {
  #months = 0;

  extend(months) {
    this.#assertMonths(months);
    this.#months += months;
  }

  #assertMonths(months) {
    if (!Number.isInteger(months) || months < 1) {
      throw new RangeError('Počet měsíců musí být kladné celé číslo');
    }
  }
}
```

# --hints--

`withdraw(0)`, `withdraw(-500)` i `withdraw(NaN)` vyhodí `RangeError` se zprávou `'Částka musí být kladné číslo'` a zůstatek nezmění.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
for (const amount of [0, -500, NaN]) {
  assert.throws(
    () => account.withdraw(amount),
    { name: 'RangeError', message: 'Částka musí být kladné číslo' },
    `withdraw(${amount}) má vyhodit RangeError se zprávou 'Částka musí být kladné číslo'`,
  );
}
assert.equal(account.balance, 1000, 'odmítnuté výběry nesmí změnit zůstatek 1000');
```

`deposit` kontroluje částku dál.

```js
const account = new BankAccount('Eva Dvořáková');
assert.throws(() => account.deposit(-1), { name: 'RangeError', message: 'Částka musí být kladné číslo' }, "deposit(-1) má dál vyhodit RangeError 'Částka musí být kladné číslo'");
account.deposit(300);
assert.equal(account.balance, 300, 'platný deposit(300) má dál fungovat');
```

Třída `BankAccount` má soukromou metodu.

```js
const source = helpers.stripComments(BankAccount.toString(), 'js');
assert.match(source, /^\s*#[A-Za-z_$][\w$]*\s*\([^)]*\)\s*\{/m, 've třídě BankAccount chybí soukromá metoda (#jméno(parametry) { … })');
```

# --help--

## --tip--

Soukromé mohou být i metody — viz [Soukromá pole `#`](see:js-tridy-kolekce/tridy#soukroma-pole).

## --tip--

Podmínku i `throw` z `deposit` přestěhuj do těla nové metody. V `deposit` a `withdraw` zbude na jejich místě jen její zavolání přes `this`.

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    this.#balance -= amount;
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }
}
```
