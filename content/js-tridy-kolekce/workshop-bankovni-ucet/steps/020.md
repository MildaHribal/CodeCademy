# --description--

Eva má běžný i spořicí účet a na úvodní obrazovce chce vidět, kolik má dohromady.

**Úkol:** Přidej do `BankAccount` statickou metodu `totalBalance(accounts)`, která dostane pole účtů (běžných, spořicích i firemních) a vrátí součet jejich zůstatků. Prázdné pole vrátí `0`.

Jak zůstatky sečteš, je na tobě.

# --hints--

`BankAccount.totalBalance` sečte zůstatky různých druhů účtů.

```js
const current = new BankAccount('Eva Dvořáková');
current.deposit(12500);
const savings = new SavingsAccount('Eva Dvořáková', 0.02);
savings.deposit(80000);
const business = new BusinessAccount('Eva Dvořáková', 'Keramika Dvořáková');
business.deposit(4300);
assert.equal(BankAccount.totalBalance([current, savings, business]), 96800, 'totalBalance([12500, 80000, 4300]) má vrátit 96800');
```

Pro prázdné pole vrátí `totalBalance` nulu.

```js
assert.equal(BankAccount.totalBalance([]), 0, 'BankAccount.totalBalance([]) má vrátit 0');
```

`totalBalance` je statická metoda.

```js
assert.equal(typeof new BankAccount('Jan Novák').totalBalance, 'undefined', 'totalBalance má patřit třídě BankAccount, ne instanci — chybí static?');
```

# --help--

## --tip--

Statická metoda na třídě — viz [Statické členy `static`](see:js-tridy-kolekce/tridy#staticke-cleny-static). Součet přes pole je úloha ze sekce o polích.

## --tip--

Každý účet v poli, ať je jakéhokoli druhu, má getter `balance`. Stačí projít pole a zůstatky sečíst.

## --tip--

Postup v těle metody:

```js
// 1. začni od nuly
// 2. přičti balance každého účtu
// 3. vrať součet
```

  #withdrawalsLeft = 3;

  constructor(owner, rate) {
    super(owner);
    this.rate = rate;

  // Připíše úrok z aktuálního zůstatku, zaokrouhlený na celé koruny.
  addInterest() {
    const interest = Math.round(this.balance * this.rate);
    if (interest > 0) {
      this.deposit(interest);

    return interest;

  withdraw(amount) {
    if (this.#withdrawalsLeft === 0) {
      throw new Error('Limit výběrů vyčerpán');

    super.withdraw(amount);
    this.#withdrawalsLeft -= 1;
