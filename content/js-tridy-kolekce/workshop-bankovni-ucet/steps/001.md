# --description--

Každá bankovní aplikace stojí na modelu účtu: kolik na něm je, kdo ho vlastní, jaké pohyby proběhly a co se s ním smí dělat. V tomhle workshopu takový model postavíš jako třídu — s ochranou zůstatku, historií pohybů a spořicím účtem. Na konci ho zapojíš do stránky s výpisem, kde půjde vkládat a vybírat.

Každý pohyb na účtu bude mít jednoznačné id `TX-1`, `TX-2`… Začneš funkcí, která taková id vydává. Umíš ji z lekce o closures v předchozí sekci, tentokrát bez návodu.

**Úkol:** Napiš funkci `createIdGenerator(prefix)`, která vrátí **funkci**. Každé zavolání vrácené funkce vydá další id ve tvaru `prefix-číslo`, počínaje jedničkou: `TX-1`, `TX-2`, `TX-3`… Dva generátory počítají každý zvlášť.

# --hints--

Funkce vrácená z `createIdGenerator('TX')` vydá postupně `'TX-1'`, `'TX-2'` a `'TX-3'`.

```js
const next = createIdGenerator('TX');
assert.equal(typeof next, 'function', "createIdGenerator('TX') má vrátit funkci");
assert.equal(next(), 'TX-1', "první zavolání generátoru z createIdGenerator('TX') má vrátit 'TX-1'");
assert.equal(next(), 'TX-2', "druhé zavolání má vrátit 'TX-2'");
assert.equal(next(), 'TX-3', "třetí zavolání má vrátit 'TX-3'");
```

Dva generátory počítají nezávisle na sobě.

```js
const payments = createIdGenerator('PAY');
const cards = createIdGenerator('CARD');
payments();
payments();
assert.equal(cards(), 'CARD-1', "po dvou zavoláních generátoru PAY má generátor CARD začít na 'CARD-1' — má každý generátor vlastní počítadlo?");
assert.equal(payments(), 'PAY-3', "třetí zavolání generátoru PAY má vrátit 'PAY-3'");
```

# --help--

## --tip--

Jde o closure: vrácená funkce si pamatuje proměnnou z funkce, ve které vznikla, i když ta už doběhla.

## --tip--

Počítadlo založ jako `let` uvnitř `createIdGenerator`, ne mimo ni. Vrácená funkce ho zvýší a vrátí text složený z `prefix` a čísla.

## --tip--

Stejná kostra na jiných datech:

```js
function createTicketCounter(hall) {
  // 1. proměnná, kterou si vrácená funkce pamatuje
  // 2. vrácená funkce: změní ji a vrátí popisek
}
```

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}
```
