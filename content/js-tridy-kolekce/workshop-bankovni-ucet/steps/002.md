# --description--

Účtů bude v aplikaci hodně a všechny mají stejný tvar i chování. Proto je nebudeš skládat z objektových literálů, ale napíšeš pro ně šablonu — [[třída|třídu]].

**Úkol:** Pod funkci `createIdGenerator` napiš třídu `BankAccount`. Její `constructor(owner)` uloží jméno majitele do `this.owner` a nastaví `this.balance` na `0`.

Na jiných datech — třída pro předplatné, kde konstruktor nastaví e-mail z argumentu a počet měsíců na nulu:

```js
class Subscription {
  constructor(email) {
    this.email = email;
    this.months = 0;
  }
}

const eva = new Subscription('eva@example.cz');
```

Pod třídu si zkus napsat `console.log(new BankAccount('Eva Dvořáková'))` a sleduj konzoli.

# --hints--

`new BankAccount('Eva Dvořáková')` vytvoří instanci `BankAccount` s majitelem `'Eva Dvořáková'`.

```js
const account = new BankAccount('Eva Dvořáková');
assert.ok(account instanceof BankAccount, "new BankAccount('Eva Dvořáková') má vytvořit instanci BankAccount");
assert.equal(account.owner, 'Eva Dvořáková', "new BankAccount('Eva Dvořáková').owner má být 'Eva Dvořáková'");
```

Nový účet má zůstatek `0`.

```js
const account = new BankAccount('Jan Novák');
assert.equal(account.balance, 0, "new BankAccount('Jan Novák').balance má být 0");
```

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  constructor(owner) {
    this.owner = owner;
    this.balance = 0;
  }
}
```
