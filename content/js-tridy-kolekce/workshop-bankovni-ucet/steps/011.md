# --description--

Pohyby potřebují id, aby na ně šlo odkazovat (reklamace, storno). Generátor id už máš z prvního kroku.

**Úkol:** Každý zapsaný pohyb dostane klíč `id` z generátoru `createIdGenerator('TX')`. **Každý účet čísluje od `TX-1`**, nezávisle na ostatních účtech.

Kde generátor vytvořit? Nabízejí se dvě místa:

- jedna konstanta nad třídou, kterou použijí všechny účty,
- [[pole třídy]] `#nextId`, které dostane každá instance zvlášť.

Rozmysli si, které z nich splní „každý účet od `TX-1`", a to použij. V `#record` pak do objektu přidej `id` z generátoru.

# --hints--

Pohyby jednoho účtu mají id `TX-1`, `TX-2`… v pořadí zápisu.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
account.withdraw(300);
assert.deepEqual(account.transactions, [
  { id: 'TX-1', type: 'deposit', amount: 1000 },
  { id: 'TX-2', type: 'withdrawal', amount: 300 },
], "po deposit(1000) a withdraw(300) mají pohyby být { id: 'TX-1', type: 'deposit', amount: 1000 } a { id: 'TX-2', type: 'withdrawal', amount: 300 }");
```

Druhý účet čísluje znovu od `TX-1`.

```js
const eva = new BankAccount('Eva Dvořáková');
const jan = new BankAccount('Jan Novák');
eva.deposit(1000);
eva.deposit(200);
jan.deposit(50);
assert.equal(jan.transactions[0].id, 'TX-1', 'první pohyb Janova účtu má mít id TX-1, i když Eva už má TX-1 a TX-2 — má každý účet vlastní generátor?');
```

# --help--

## --tip--

Pole třídy se vyhodnotí pro každou instanci znovu — viz [Pole třídy](see:js-tridy-kolekce/tridy#pole-tridy).

## --tip--

Soukromé pole s generátorem deklaruj nahoře v těle třídy a přiřaď mu výsledek `createIdGenerator('TX')`. V `#record` ho zavolej se závorkami, protože obsahuje funkci.

## --tip--

Na jiných datech: `#nextTicket = createTicketCounter('Sál 1');` a pak `this.#nextTicket()`.

# --explain--

Vysvětli vlastními slovy, proč generátor id patří do pole třídy `#nextId`, a ne do jedné konstanty nad třídou.

## --model--

Pole třídy se vyhodnotí pro každou novou instanci znovu, takže každý účet zavolá `createIdGenerator` a dostane vlastní closure s vlastním počítadlem. Konstanta nad třídou by vznikla jen jednou a všechny účty by sdílely jedno počítadlo, takže druhý účet by začal třeba na `TX-3`.

## --checklist--

- Pole třídy se vyhodnotí pro každou instanci zvlášť.
- Každý účet tak dostane vlastní generátor s vlastním počítadlem.
- Konstanta mimo třídu vznikne jednou a všechny účty by ji sdílely.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}
```
