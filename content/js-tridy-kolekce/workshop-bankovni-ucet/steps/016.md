# --description--

Spořicí účet umí všechno co běžný účet — vklad, výběr, historii — a navíc má úrokovou sazbu. Je to **druh** bankovního účtu, takže tady se hodí [[dědičnost]].

**Úkol:** Pod třídu `BankAccount` seřaď řádky třídy `SavingsAccount`, která rozšiřuje `BankAccount`. Její konstruktor dostane majitele a sazbu (`0.02` znamená 2 %): majitele předá rodičovskému konstruktoru, sazbu uloží do `this.rate`. Do mezery doplň, co konstruktor předá rodiči.

Vzor `extends` + `super` vidíš poprvé, proto ho tentokrát jen skládáš. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc a patří k typickým chybám.

# --hints--

`new SavingsAccount('Eva Dvořáková', 0.02)` je spořicí i bankovní účet s majitelem a sazbou.

```js
const savings = new SavingsAccount('Eva Dvořáková', 0.02);
assert.ok(savings instanceof SavingsAccount, "new SavingsAccount('Eva Dvořáková', 0.02) má být instance SavingsAccount");
assert.ok(savings instanceof BankAccount, 'spořicí účet má být zároveň instance BankAccount — rozšiřuje ji přes extends?');
assert.equal(savings.owner, 'Eva Dvořáková', "new SavingsAccount('Eva Dvořáková', 0.02).owner má být 'Eva Dvořáková'");
assert.equal(savings.rate, 0.02, "new SavingsAccount('Eva Dvořáková', 0.02).rate má být 0.02");
```

Spořicí účet zdědil vklad, výběr a historii.

```js
const savings = new SavingsAccount('Eva Dvořáková', 0.02);
savings.deposit(1000);
savings.withdraw(400);
assert.equal(savings.balance, 600, 'spořicí účet má po deposit(1000) a withdraw(400) mít zůstatek 600');
assert.equal(savings.transactions.length, 2, 'spořicí účet má zapisovat pohyby do historie');
```

# --help--

## --tip--

Jde o `extends` a `super` — viz [Dědičnost: `extends` a `super`](see:js-tridy-kolekce/tridy#dedicnost-extends-a-super).

## --tip--

V konstruktoru potomka musí `super(…)` proběhnout dřív než jakékoli `this`. A rodičovský konstruktor potřebuje jméno majitele.

# --parsons--

```js
class SavingsAccount extends BankAccount {
  constructor(owner, rate) {
    super(__1__);
    this.rate = rate;
  }
}
```

# --seed--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  // Založí účet a rovnou na něj vloží první částku.
  static open(owner, initialDeposit) {
    const account = new BankAccount(owner);
    account.deposit(initialDeposit);
    return account;
  }

  // Obnoví účet z uložených pohybů, třeba z databáze.
  static fromTransactions(owner, transactions) {
    const account = new BankAccount(owner);
    for (const { type, amount } of transactions) {
      if (type === 'deposit') {
        account.deposit(amount);
      } else {
        account.withdraw(amount);
      }
    }
    return account;
  }

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
      .filter((transaction) => transaction.type === 'deposit')
      .reduce((sum, transaction) => sum + transaction.amount, 0);
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  // Od kolegy: vloží víc částek najednou, třeba výplatu a vratku.
  depositAll(amounts) {
    amounts.forEach((amount) => {
      this.deposit(amount);
    });
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}
```
