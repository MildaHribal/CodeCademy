# --description--

Jednou za měsíc banka připíše na spořicí účet úrok.

**Úkol:** Přidej do `SavingsAccount` metodu `addInterest()`, která spočítá úrok jako zůstatek krát `rate`, zaokrouhlí ho na celé koruny, připíše ho na účet jako **vklad** (ať je v historii) a vrátí jeho výši. Když vyjde úrok `0`, nic nepřipisuje, nic nevyhodí a vrátí `0`.

Zůstatek i vklad máš zděděné od `BankAccount` — spořicí účet je používá, jako by byly jeho vlastní.

> [!PITFALL]
> Soukromé pole `#balance` patří třídě `BankAccount`, ne potomkovi. Zápis `this.#balance` v těle `SavingsAccount` je syntaktická chyba: `Private field '#balance' must be declared in an enclosing class`. Potomek pracuje se zůstatkem přes veřejné `balance` a `deposit`.

# --hints--

Na účtu s `10000` Kč a sazbou `0.02` vrátí `addInterest()` hodnotu `200` a připíše ji jako vklad.

```js
const savings = new SavingsAccount('Eva Dvořáková', 0.02);
savings.deposit(10000);
assert.equal(savings.addInterest(), 200, 'addInterest() na účtu s 10000 Kč a sazbou 0.02 má vrátit 200');
assert.equal(savings.balance, 10200, 'po addInterest() má být zůstatek 10200');
assert.deepEqual(savings.transactions.at(-1), { id: 'TX-2', type: 'deposit', amount: 200 }, 'úrok se má zapsat jako vklad TX-2 s částkou 200');
```

Úrok se zaokrouhlí na celé koruny.

```js
const savings = new SavingsAccount('Jan Novák', 0.02);
savings.deposit(1234);
assert.equal(savings.addInterest(), 25, 'úrok z 1234 Kč při sazbě 0.02 je 24.68 a má se zaokrouhlit na 25');
assert.equal(savings.balance, 1259, 'po připsání úroku 25 má být zůstatek 1259');
```

Na prázdném účtu vrátí `addInterest()` nulu, nic nevyhodí a nic nezapíše.

```js
const savings = new SavingsAccount('Jan Novák', 0.02);
assert.equal(savings.addInterest(), 0, 'addInterest() na prázdném účtu má vrátit 0 (a nevyhodit RangeError z deposit)');
assert.equal(savings.transactions.length, 0, 'nulový úrok se nemá zapsat do historie');
```

# --help--

## --tip--

Potomek dědí metody i gettery rodiče — viz [Dědičnost: `extends` a `super`](see:js-tridy-kolekce/tridy#dedicnost-extends-a-super).

## --tip--

Úrok spočítej z `this.balance` a `this.rate`, zaokrouhli přes `Math.round`. Připsat ho pomůže zděděný `deposit` — jen ho nevolej s nulou, ten nulu odmítne.

# --explain--

Vysvětli vlastními slovy, proč `addInterest` v `SavingsAccount` nemůže číst `this.#balance`, a jak se k zůstatku dostane.

## --model--

Soukromé pole je vidět jen v těle třídy, která ho deklaruje, a potomek je jiná třída. Proto `this.#balance` v `SavingsAccount` není vůbec platný kód. Spořicí účet ale dědí veřejné rozhraní rodiče, takže zůstatek přečte getterem `balance` a úrok připíše zděděnou metodou `deposit`, která zároveň zkontroluje částku a zapíše pohyb.

## --checklist--

- Soukromé pole vidí jen třída, která ho deklaruje, ne potomek.
- `this.#balance` v potomkovi je syntaktická chyba.
- Potomek používá zděděný getter `balance` a metodu `deposit`.
- Přes `deposit` se úrok zároveň zkontroluje a zapíše do historie.

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  // Založí účet a rovnou na něj vloží první částku.
  static open(owner, initialDeposit) {
    const account = new BankAccount(owner);
    account.deposit(initialDeposit);
    return account;
  }

  // Obnoví účet z uložených pohybů, třeba z databáze.
  static fromTransactions(owner, transactions) {
    const account = new BankAccount(owner);
    for (const { type, amount } of transactions) {
      if (type === 'deposit') {
        account.deposit(amount);
      } else {
        account.withdraw(amount);
      }
    }
    return account;
  }

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
      .filter((transaction) => transaction.type === 'deposit')
      .reduce((sum, transaction) => sum + transaction.amount, 0);
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  // Od kolegy: vloží víc částek najednou, třeba výplatu a vratku.
  depositAll(amounts) {
    amounts.forEach((amount) => {
      this.deposit(amount);
    });
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}

class SavingsAccount extends BankAccount {

  constructor(owner, rate) {
    super(owner);
    this.rate = rate;
```

```js
        account.deposit(amount);
      } else {

    this.owner = owner;

    return this.#balance;

      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  // Od kolegy: vloží víc částek najednou, třeba výplatu a vratku.
  depositAll(amounts) {
    amounts.forEach((amount) => {
      this.deposit(amount);

  }

  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}

class SavingsAccount extends BankAccount {

  constructor(owner, rate) {
    super(owner);
    this.rate = rate;
  }

  // Připíše úrok z aktuálního zůstatku, zaokrouhlený na celé koruny.
  addInterest() {
    const interest = Math.round(this.balance * this.rate);
    if (interest > 0) {
      this.deposit(interest);
    }
    return interest;
  }
}
```
