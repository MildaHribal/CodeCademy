# --description--

Výpis z účtu ukazuje, kolik se na účet za celou dobu vložilo. Tuhle hodnotu nikam neukládej — spočítej ji z historie. Tentokrát bez návodu, metody pole znáš ze sekce o polích.

**Úkol:** Přidej do třídy getter `totalDeposited`, který vrátí součet částek všech vkladů v historii. Výběry se nepočítají. Účet bez vkladů vrátí `0`.

# --hints--

`totalDeposited` sečte jen vklady.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
account.withdraw(200);
account.deposit(500);
assert.equal(account.totalDeposited, 1500, 'po vkladech 1000 a 500 a výběru 200 má totalDeposited vrátit 1500');
```

Nový účet má `totalDeposited` rovno `0`.

```js
assert.equal(new BankAccount('Jan Novák').totalDeposited, 0, 'nový účet má mít totalDeposited 0');
```

`totalDeposited` je getter, čte se bez závorek.

```js
const descriptor = Object.getOwnPropertyDescriptor(BankAccount.prototype, 'totalDeposited');
assert.ok(descriptor && typeof descriptor.get === 'function', 'totalDeposited má být getter (get totalDeposited() { … }), ne metoda ani vlastnost');
```

# --help--

## --tip--

Getter spočítaný z jiných dat — viz [Gettery a settery](see:js-tridy-kolekce/tridy#gettery-a-settery). Výběr položek a součet znáš z [Metod pole do hloubky](see:js-pole/metody-pole-do-hloubky#co-ktera-metoda-vraci).

## --tip--

Pracuj se soukromou historií. Nejdřív z ní vyber vklady, pak sečti jejich částky; u součtu nezapomeň na počáteční hodnotu.

## --tip--

Postup v těle getteru:

```js
// 1. z historie jen pohyby typu vklad
// 2. součet jejich částek, prázdný seznam dá 0
// 3. výsledek vrať
```

# --solution--

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
      .filter((transaction) => transaction.type === 'deposit')
      .reduce((sum, transaction) => sum + transaction.amount, 0);
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
    this.#record('deposit', amount);
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
    this.#record('withdrawal', amount);
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }

  #record(type, amount) {
    this.#transactions.push({ id: this.#nextId(), type, amount });
  }
}
```
