# --description--

Výpis z účtu potřebuje historii: každý vklad a výběr. Historie bude soukromé pole se seznamem pohybů a zvenku půjde jen číst.

**Úkol:** Přidej do třídy soukromé pole `#transactions` s prázdným polem a getter `transactions`, který vrátí **kopii** tohoto pole. Pohyby do něj zatím nic nezapisuje — to přijde v dalším kroku.

Proč kopii? Pole je objekt a getter by jinak vrátil odkaz na to soukromé. Kdo by pak napsal `account.transactions.length = 0`, smazal by historii uvnitř účtu, i když je pole soukromé.

Kopii pole umíš vyrobit několika způsoby — spread, `slice()` nebo `Array.from`. Vyber si.

# --hints--

Nový účet vrátí přes `transactions` prázdné pole.

```js
const account = new BankAccount('Eva Dvořáková');
assert.ok(Array.isArray(account.transactions), "new BankAccount('Eva Dvořáková').transactions má být pole");
assert.deepEqual(account.transactions, [], 'nový účet má mít prázdnou historii []');
```

Změna pole vráceného z `transactions` historii účtu nezmění.

```js
const account = new BankAccount('Eva Dvořáková');
account.transactions.push({ type: 'deposit', amount: 1000000 });
const copy = account.transactions;
copy.length = 0;
assert.equal(account.transactions.length, 0, 'account.transactions.push(…) nesmí přidat pohyb do historie účtu — getter má vracet kopii');
assert.notEqual(account.transactions, account.transactions, 'každé čtení transactions má vrátit novou kopii, ne soukromé pole');
```

Historie není veřejná vlastnost.

```js
const account = new BankAccount('Eva Dvořáková');
assert.deepEqual(Object.keys(account), ['owner'], "Object.keys(účtu) má vrátit jen ['owner'] — historie patří do soukromého pole");
```

# --help--

## --tip--

Jde o past s getterem, který vrací soukromé pole — viz [Getter vrací soukromé pole ven](see:js-tridy-kolekce/tridy#getter-vraci-soukrome-pole-ven).

## --tip--

Pole deklaruj nahoře v těle třídy vedle `#balance`. Getter vrátí nové pole se stejnými položkami, ne `this.#transactions` samotné.

## --tip--

Na jiných datech: getter `tags` třídy s polem `#tags` by vracel `this.#tags.slice()`.

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  deposit(amount) {
    this.#assertPositive(amount);
    this.#balance += amount;
  }

  withdraw(amount) {
    this.#assertPositive(amount);
    if (amount > this.#balance) {
      throw new RangeError('Nedostatek prostředků');
    }
    this.#balance -= amount;
  }

  #assertPositive(amount) {
    if (!Number.isFinite(amount) || amount <= 0) {
      throw new RangeError('Částka musí být kladné číslo');
    }
  }
}
```
