# --description--

**Úkol:** Pod metodu `deposit` přidej metodu `withdraw(amount)`, která sníží `this.balance` o `amount`.

Stejný tvar jako vklad, jen opačný směr. Na jiných datech by to byla metoda `cancel(months)`, která od `this.months` odečte.

Zkus pod třídou vložit 1000, vybrat 300 a vypsat zůstatek. Pak zkus `account.balance = 1000000` — a přečti si další krok.

# --hints--

Po vkladu `1000` a výběru `300` má účet zůstatek `700`.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(1000);
account.withdraw(300);
assert.equal(account.balance, 700, 'po deposit(1000) a withdraw(300) má být balance 700');
```

Výběr z jednoho účtu nezmění jiný účet.

```js
const eva = new BankAccount('Eva Dvořáková');
const jan = new BankAccount('Jan Novák');
jan.deposit(500);
eva.withdraw(100);
assert.equal(jan.balance, 500, 'eva.withdraw(100) nesmí změnit zůstatek Janova účtu');
```

## --file-- script.js

```js
// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  constructor(owner) {
    this.owner = owner;
    this.balance = 0;
  }

  deposit(amount) {
    this.balance += amount;
  }

  withdraw(amount) {
    this.balance -= amount;
  }
}
```
