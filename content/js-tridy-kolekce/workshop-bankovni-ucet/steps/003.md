# --description--

Účet zatím jen stojí. Teď na něj půjde vkládat.

**Úkol:** Do třídy `BankAccount` pod konstruktor přidej metodu `deposit(amount)`, která zvýší `this.balance` o `amount`.

[[metoda|Metodu]] zapíšeš do těla třídy bez slova `function`. Uvnitř je `this` ten účet, na kterém ji zavoláš. Na jiných datech:

```js
class Subscription {
  constructor(email) {
    this.email = email;
    this.months = 0;
  }

  extend(months) {
    this.months += months;
  }
}
```

Zkus pod třídou založit účet, dvakrát vložit a vypsat `account.balance`.

# --hints--

Po `deposit(500)` a `deposit(250)` má účet zůstatek `750`.

```js
const account = new BankAccount('Eva Dvořáková');
account.deposit(500);
account.deposit(250);
assert.equal(account.balance, 750, 'po deposit(500) a deposit(250) má být balance 750');
```

Vklad na jeden účet nezmění zůstatek jiného účtu.

```js
const eva = new BankAccount('Eva Dvořáková');
const jan = new BankAccount('Jan Novák');
eva.deposit(1000);
assert.equal(jan.balance, 0, 'eva.deposit(1000) nesmí změnit zůstatek Janova účtu');
```

Metoda patří do těla třídy, za uzavírací závorku konstruktoru. K zůstatku se v ní dostaneš přes `this`.

// Bankovní účet. Všechny částky jsou v celých korunách.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  constructor(owner) {
    this.owner = owner;
    this.balance = 0;
  }

  deposit(amount) {
    this.balance += amount;
  }
