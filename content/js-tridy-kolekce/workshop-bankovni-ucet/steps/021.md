# --description--

Zkus si pod třídy napsat ``console.log(`${BankAccount.open('Eva Dvořáková', 1500)}`)``. V konzoli uvidíš `[object Object]`. Když JavaScript potřebuje z objektu text (šablonový řetězec, `String(…)`), zavolá jeho metodu `toString`. Každý objekt ji má — odkud, ukáže příští lekce o prototypech. Výchozí verze ale vrací jen `[object Object]`.

**Úkol:** Přidej do `BankAccount` metodu `toString()`, která vrátí majitele, dvojtečku, mezeru a zůstatek s `Kč`, třeba `'Eva Dvořáková: 1500 Kč'`. Spořicí i firemní účty ji zdědí.

# --hints--

Účet vložený do šablonového řetězce se vypíše jako `'Eva Dvořáková: 1500 Kč'`.

```js
const account = BankAccount.open('Eva Dvořáková', 1500);
assert.equal(`${account}`, 'Eva Dvořáková: 1500 Kč', "`${account}` pro účet Evy s 1500 Kč má dát 'Eva Dvořáková: 1500 Kč'");
assert.equal(String(account), 'Eva Dvořáková: 1500 Kč', "String(account) má dát 'Eva Dvořáková: 1500 Kč'");
```

Text odpovídá aktuálnímu zůstatku a dědí ho i spořicí účet.

```js
const savings = new SavingsAccount('Jan Novák', 0.02);
savings.deposit(900);
savings.withdraw(250);
assert.equal(`${savings}`, 'Jan Novák: 650 Kč', "spořicí účet Jana s 650 Kč se má vypsat jako 'Jan Novák: 650 Kč'");
```

# --help--

## --tip--

`toString` je obyčejná metoda třídy a pracuje s `this` — viz [Metody a `this`](see:js-tridy-kolekce/tridy#metody-a-this).

## --tip--

Metoda nic nemění, jen vrátí šablonový řetězec z majitele a zůstatku. Protože je v `BankAccount`, spořicí účet ji dostane automaticky.

// Vrátí funkci, která při každém zavolání vydá další id: TX-1, TX-2…
function createIdGenerator(prefix) {
  let count = 0;
  return () => {
    count += 1;
    return `${prefix}-${count}`;
  };
}

class BankAccount {
  #balance = 0;
  #transactions = [];
  #nextId = createIdGenerator('TX');

  // Založí účet a rovnou na něj vloží první částku.
  static open(owner, initialDeposit) {
    const account = new BankAccount(owner);
    account.deposit(initialDeposit);
    return account;
  }

  // Obnoví účet z uložených pohybů, třeba z databáze.
  static fromTransactions(owner, transactions) {
    const account = new BankAccount(owner);
    for (const { type, amount } of transactions) {
      if (type === 'deposit') {
        account.deposit(amount);
      } else {
        account.withdraw(amount);
      }
    }
    return account;
  }

  // Součet zůstatků všech účtů.
  static totalBalance(accounts) {
    return accounts.reduce((sum, account) => sum + account.balance, 0);
  }

  constructor(owner) {
    this.owner = owner;
  }

  get balance() {
    return this.#balance;
  }

  // Kopie historie: kdo ji dostane, nezmění pohyby uvnitř účtu.
  get transactions() {
    return [...this.#transactions];
  }

  // Kolik se na účet celkem vložilo.
  get totalDeposited() {
    return this.#transactions
