# --description--

Poslední krok. Otevřený našeptávač přes předpověď překáží a uživatel s klávesnicí ho chce zavřít jako každé vyskakovací okno.

**Úkol:** Zařiď, aby stisk klávesy Escape v poli `#search-input` zavřel (vyprázdnil) našeptávač a zrušil hledání, které ještě běží. Jiné klávesy našeptávač nechají být.

Tím je aplikace hotová. Za sebou máš:

- `fetch` s kontrolou `response.ok` a parametry přes `URLSearchParams`,
- stavy načítání, chyby, prázdna a nový pokus, s `role="status"` a `aria-busy`,
- našeptávač s `debounce` a zrušením starších hledání,
- rychlé přepínání míst bez souběhu odpovědí a časový limit přes `AbortSignal.timeout`,
- opravu kolegova kódu, který výpadek služby vydával za „Bez výstrah",
- místo v adrese stránky a tlačítko Zpět.

Stejné vzory potkáš v každém vyhledávání, filtru, košíku a v aplikacích nad API. Příště je použiješ samostatně v galerii s nekonečným scrollováním.

## Udělej po svém

- **Vzhled:** podle `condition` přidej kartě dne barevný pruh nebo ikonu v CSS a aktuální počasí podbarvi podle teploty.
- **Funkce:** ovládání našeptávače šipkami nahoru a dolů s `aria-activedescendant`.
- **Funkce:** poslední tři hledaná místa jako rychlé volby pod polem.
- **Tvoje téma:** přeměň aplikaci na vyhledávání spojů, knih v knihovně nebo stavu sjezdovek.

# --hints--

Escape v poli zavře našeptávač.

```js
renderSuggestions([{ id: 'brno', name: 'Brno', region: 'Jihomoravský kraj' }], 'brn');
const input = document.querySelector('#search-input');
await helpers.press(input, 'Escape');
assert.equal(document.querySelectorAll('#suggestions > li').length, 0, 'po stisku Escape v poli má být našeptávač prázdný');
```

Escape zruší hledání, které ještě běží.

```js
mockApi.delay.places = () => 300;
mockApi.requests.length = 0;
const input = document.querySelector('#search-input');
input.value = 'Brno';
input.dispatchEvent(new Event('input', { bubbles: true }));
await helpers.waitFor(() => mockApi.requests.some((request) => request.path === '/api/places'), 1500);
await helpers.press(input, 'Escape');
await helpers.wait(500);
assert.equal(document.querySelectorAll('#suggestions > li').length, 0, 'hledání, které běželo při stisku Escape, nemá našeptávač znovu otevřít');
assert.equal(mockApi.requests.find((request) => request.path === '/api/places')?.aborted, true, 'Escape má běžící hledání zrušit');
```

Jiná klávesa našeptávač nezavře.

```js
renderSuggestions([{ id: 'brno', name: 'Brno', region: 'Jihomoravský kraj' }], 'brn');
await helpers.press(document.querySelector('#search-input'), 'ArrowLeft');
assert.equal(document.querySelectorAll('#suggestions .suggestion').length, 1, 'jiná klávesa než Escape nemá našeptávač zavřít');
```

      }, delay);

    });
  };
