# --description--

Když uživatel napíše „Kolín", API vrátí prázdné pole a našeptávač se tváří, jako by nic nehledal. Prázdný výsledek je samostatný stav a má vlastní text.

**Úkol:** Uprav `renderSuggestions` na `renderSuggestions(places, query)`. Když je `places` prázdné, dá do `#suggestions` jedinou položku `li.suggestions__empty` s textem `Pro „Kolín“ jsme nic nenašli.` (s dotazem v českých uvozovkách „“). Jinak funguje jako dosud.

Dotaz napsal uživatel, takže do stránky nesmí jako HTML. Hodí se `textContent`, `innerHTML` se šablonou, nebo `createElement` s textem — vyber to, co nepustí značky z dotazu do stránky.

Na konci souboru si prázdný stav vyzkoušej hledáním `Kolín`.

# --hints--

Prázdný výsledek ukáže `li.suggestions__empty` s dotazem.

```js
renderSuggestions([], 'Kolín');
const items = document.querySelectorAll('#suggestions > li');
assert.equal(items.length, 1, 'u prázdného výsledku má být v #suggestions právě jedna položka');
assert.ok(items[0].classList.contains('suggestions__empty'), 'položka prázdného výsledku má mít třídu suggestions__empty');
assert.equal(items[0].textContent.trim(), 'Pro „Kolín“ jsme nic nenašli.', 'text má znít: Pro „Kolín“ jsme nic nenašli.');
```

Dotaz se vloží jako text, ne jako HTML.

```js
renderSuggestions([], '<img src=x onerror="window.hacked = true">');
assert.equal(document.querySelector('#suggestions img'), null, 'dotaz od uživatele se nesmí vložit jako HTML — v #suggestions nemá vzniknout img');
assert.match(document.querySelector('#suggestions').textContent, /<img src=x/, 'dotaz se má ukázat doslova jako text');
```

Nalezená místa se vykreslí jako dosud.

```js
renderSuggestions([], 'Kolín');
renderSuggestions([{ id: 'brno', name: 'Brno', region: 'Jihomoravský kraj' }], 'brn');
assert.equal(document.querySelectorAll('#suggestions .suggestion').length, 1, 'renderSuggestions s jedním místem má ukázat jedno tlačítko');
assert.equal(document.querySelector('#suggestions .suggestions__empty'), null, 'když je co ukázat, nemá tam být položka prázdného výsledku');
```

# --help--

## --tip--

Prázdno je jeden ze stavů v části [Stavy: načítání, chyba a prázdno](see:js-async/fetch#stavy-nacitani-chyba-a-prazdno).

## --tip--

Na začátek funkce patří podmínka na prázdné pole: vyrob jednu položku s textem, nahraď jí obsah seznamu a skonči. Zbytek funkce zůstane.

## --tip--

Na jiných datech: prázdný košík nahradí seznam jedinou položkou `li.cart__empty` s textem „Košík je prázdný" přes `textContent`.

    });
  };
