# --description--

## Hlášení

Kolega pod tvůj odpočet vložil druhý: do uzávěrky doručení na zítřek (`updateDelivery`). Den po nasazení napsala zákaznice na podporu: nechala stránku výprodeje otevřenou v kartě na pozadí a šla vařit. Po návratu jí stránka tvrdila, že do uzávěrky doručení zbývá ještě 31 minut, ale ve skutečnosti zbývalo 12. Objednávku odeslala a zboží přišlo o den později.

Kolega se hájí, že u něj na monitoru odpočet ubývá přesně po sekundách.

## Úkol

Oprav `updateDelivery` tak, aby ukazovala skutečně zbývající čas do `deliveryDeadline`, ať se spustí kdykoli a kolikrát chce. Změň co nejmenší kus kódu.

# --hints--

`updateDelivery()` ukáže čas zbývající do `deliveryDeadline` podle aktuálního času.

```js
const setClock = (time) => {
  const RealDate = Date;
  window.Date = class extends RealDate {
    constructor(...args) { super(...(args.length ? args : [time])); }
    static now() { return time; }
  };
};
setClock(deliveryDeadline - 30 * 60 * 1000);
updateDelivery();
assert.equal(document.querySelector('#delivery').textContent.trim(), '00:30:00', 'když do uzávěrky zbývá 30 minut, updateDelivery() má do #delivery napsat 00:30:00');
```

Dvě volání `updateDelivery()` ve stejném okamžiku ukážou stejný čas.

```js
const setClock = (time) => {

    constructor(...args) { super(...(args.length ? args : [time])); }
    static now() { return time; }
  };

updateDelivery();
updateDelivery();
assert.equal(document.querySelector('#delivery').textContent.trim(), '00:12:00', 'třikrát zavolaná updateDelivery() ve stejném okamžiku má pořád ukazovat 00:12:00 — zbývající čas se nemá odečítat za každé volání');
```

Odpočet výprodeje funguje dál.


# --help--

## --tip--

Chyba odpovídá pasti [Časovač v kartě na pozadí](see:js-async/event-loop#casovac-v-karte-na-pozadi): prohlížeč v neaktivní kartě spouští časovače méně často.

## --tip--

Kolegova funkce předpokládá, že se spustí přesně jednou za sekundu, a při každém spuštění odečte jednu sekundu. Porovnej ji s tvou `updateCountdown`: odkud bere čas ona?

## --tip--

Na jiných datech: odpočet do odjezdu vlaku se nepočítá jako `secondsLeft--`, ale pokaždé znovu jako `departureAt - Date.now()`.

# --explain--

Vysvětli vlastními slovy, proč kolegův odpočet po návratu do karty ukazoval víc času, než skutečně zbývalo.

## --model--

Kolegův odpočet počítal tiky: při každém spuštění odečetl jednu sekundu. Interval ale nezaručuje, že se spustí každou sekundu. Je to jen nejkratší čekání a v kartě na pozadí prohlížeč časovače zpomaluje, takže tiků proběhlo méně, než uběhlo sekund. Oprava počítá zbývající čas pokaždé znovu z hodin, a proto je správně bez ohledu na to, kolikrát a kdy se funkce spustí.

## --checklist--

- Kolegův odpočet počítal tiky, ne skutečný čas.
- Interval není přesný, druhý argument je jen nejkratší čekání.
- V kartě na pozadí prohlížeč časovače zpomaluje.
- Správný odpočet počítá zbývající čas pokaždé z hodin (`deadline - Date.now()`).

## --file-- script.js

```js
// Horská výbava v bleskovém výprodeji. Ceny jsou v korunách.
const products = [
  { id: 1, name: 'Stan Hory 2', price: 3490, oldPrice: 4990 },
  { id: 2, name: 'Spacák Sněžka −5 °C', price: 1890, oldPrice: 2690 },
  { id: 3, name: 'Čelovka 400 lm', price: 490, oldPrice: 790 },
  { id: 4, name: 'Batoh Šumava 35 l', price: 1990, oldPrice: 2890 },
  { id: 5, name: 'Trekové hole Jizera', price: 890, oldPrice: 1290 },
  { id: 6, name: 'Karimatka Krkonoše', price: 690, oldPrice: 990 },
  { id: 7, name: 'Vařič Beskydy', price: 1190, oldPrice: 1590 },
  { id: 8, name: 'Termoska 0,75 l', price: 590, oldPrice: 890 },
];

// V ukázce končí výprodej 2 h 15 min po načtení stránky
// a uzávěrka doručení na zítřek je za 47 minut.
const saleEndsAt = Date.now() + (2 * 60 + 15) * 60 * 1000;
const deliveryDeadline = Date.now() + 47 * 60 * 1000;

const priceFormat = new Intl.NumberFormat('cs-CZ', { style: 'currency', currency: 'CZK', maximumFractionDigits: 0 });

// Nejnižší cena za posledních 30 dní, kterou musí e-shop u slevy ukázat.
// Prochází celou historii cen, a proto u jednoho produktu trvá pár milisekund.
function lowestPrice30Days(product) {
  let lowest = product.oldPrice;
  for (let record = 0; record < 60000; record++) {
    const price = product.oldPrice - ((record * 7919) % 11) * 10;
    if (price < lowest && price >= product.price) lowest = price;
  }
  return lowest;
}

// Karta jednoho produktu (prvek li, zatím mimo stránku).
function createProductCard(product) {
  const card = document.createElement('li');
  card.className = 'product';
  card.dataset.id = product.id;

  const badge = document.createElement('span');
  badge.className = 'product__badge';
  badge.textContent = `−${Math.round((1 - product.price / product.oldPrice) * 100)} %`;

  const name = document.createElement('h2');
  name.className = 'product__name';
  name.textContent = product.name;

  const price = document.createElement('p');
  price.className = 'product__price';
  price.textContent = priceFormat.format(product.price);

  const note = document.createElement('p');
  note.className = 'product__note';
  note.textContent = `Nejnižší cena za 30 dní: ${priceFormat.format(lowestPrice30Days(product))}`;

  const button = document.createElement('button');
  button.type = 'button';
  button.className = 'button product__add';
  button.textContent = 'Do košíku';

  card.append(badge, name, price, note, button);
  return card;
}

// Celý katalog: 600 variant velikostí a barev.
const fullCatalog = Array.from({ length: 600 }, (_, index) => {
  const base = products[index % products.length];
  return { ...base, id: 100 + index, name: `${base.name} · varianta ${index + 1}` };
});

// Vykreslí karty produktů a nahradí předchozí obsah seznamu.
function renderProducts(items) {
  const list = document.querySelector('#products');
  list.replaceChildren(...items.map(createProductCard));
}

renderProducts(products);

// Zbývající čas v ms jako hh:mm:ss, záporný čas jako 00:00:00.
function formatRemaining(ms) {
  const totalSeconds = Math.max(0, Math.floor(ms / 1000));
  const hours = Math.floor(totalSeconds / 3600);
  const minutes = Math.floor((totalSeconds % 3600) / 60);
  const seconds = totalSeconds % 60;
  return [hours, minutes, seconds].map((part) => String(part).padStart(2, '0')).join(':');
}

// Přepíše odpočet podle aktuálního času.
function updateCountdown() {
  const remaining = saleEndsAt - Date.now();
  document.querySelector('#countdown').textContent = formatRemaining(remaining);
}

updateCountdown();

const countdownTimer = setInterval(updateCountdown, 1000);

// Od kolegy: odpočet do uzávěrky doručení na zítřek.
let deliverySecondsLeft = Math.round((deliveryDeadline - Date.now()) / 1000);

function updateDelivery() {
  deliverySecondsLeft--;
  document.querySelector('#delivery').textContent = formatRemaining(deliverySecondsLeft * 1000);
}

updateDelivery();
const deliveryTimer = setInterval(updateDelivery, 1000);
```
