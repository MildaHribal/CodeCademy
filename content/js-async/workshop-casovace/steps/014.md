# --description--

**Úkol:** Pod `loadOrCache` napiš `async` funkci `showStop(stop)`, kterou tabule volá při každém výběru zastávky:

- zruší načítání, které spustilo předchozí volání `showStop` a ještě běží,
- načte odjezdy zastávky přes `loadAll` a vrátí je,
- když ji zrušilo novější volání, vrátí `null` místo chyby,
- jiné chyby (třeba výpadek serveru) propustí dál.

Ovladač posledního načítání si musíš pamatovat **mezi voláními**, tedy v proměnné mimo funkci. Na „bylo to zrušení, nebo porucha?" se hodí `error.name`, `error.message`, nebo `signal.aborted` — jen jedno z toho neplete dohromady zrušení a výpadek.

V ukázce pak zavolej `showStop` dvakrát hned za sebou, jako by uživatel přepnul zastávku, a vypiš oba výsledky.

# --hints--

Samotné volání `showStop` vrátí odjezdy zastávky.

```js
const departures = await showStop('Mendlovo náměstí');
assert.equal(departures?.length, 4, "await showStop('Mendlovo náměstí') má vrátit 4 odjezdy");
```

Když se `showStop` zavolá znovu, první volání vrátí `null` a druhé odjezdy nové zastávky.

```js
const first = showStop('Hlavní nádraží');
const second = showStop('Mendlovo náměstí');
let firstResult;
try {
  firstResult = await first;
} catch (error) {
  assert.fail(`zrušené první volání showStop se nemá zamítnout, zamítlo se chybou „${error.name}: ${error.message}"`);
}
assert.equal(firstResult, null, 'první volání showStop, které přebilo druhé, má vrátit null');
assert.deepEqual((await second).map((item) => item.line), ['44', '6', '1', '67'], "druhé volání showStop('Mendlovo náměstí') má vrátit její odjezdy");
```

Zrušené načítání opravdu přestane běžet.

```js
await networkIdle();
showStop('Hlavní nádraží');
await sleep(5);
const second = showStop('Mendlovo náměstí');
assert.ok(network.active <= 3, `po přepnutí zastávky mají běžet jen 3 nové požadavky, běží jich ${network.active} — zrušil jsi předchozí načítání?`);
await second;
```

Výpadek serveru `showStop` nezamlčí.

```js
servers.trains.down = true;
let caught = null;
await showStop('Hlavní nádraží').catch((error) => {
  caught = error;
});
assert.equal(caught?.message, 'Server vlaky neodpovídá', 'když neodpovídá server vlaků, showStop se má zamítnout jeho chybou, ne vrátit null');
```

# --help--

## --tip--

Jde o [zrušení](see:js-async/async-await#zruseni-abortcontroller-a-signal) a o past [Zrušení hlášené jako chyba](see:js-async/async-await#zruseni-hlasene-jako-chyba).

## --tip--

Nad funkcí proměnná na poslední ovladač. Ve funkci nejdřív zruš ten starý (když existuje), založ a ulož nový a jeho signal předej do `loadAll`. Kolem čekání `try`/`catch`, v `catch` rozhodni podle jména chyby.

## --tip--

Stejný tvar na jiných datech má našeptávač, který ruší hledání „Pra", když uživatel dopíše „Praha": proměnná `searchController` mimo funkci, uvnitř `searchController?.abort()` a nový ovladač.

# --explain--

Vysvětli vlastními slovy, proč tabule při přepnutí zastávky staré načítání ruší, a nejen ignoruje jeho výsledek.

## --model--

Staré načítání už nikoho nezajímá, ale bez zrušení by dál zabíralo síť a server, a kdyby odpovědělo později než nové, mohlo by na tabuli přepsat novější zastávku starými odjezdy. Zrušení požadavky zastaví a jejich Promise se zamítne chybou `AbortError`. Tu musím v `catch` poznat a tiše ukončit, protože nejde o poruchu, kterou by měl uživatel vidět. Skutečné chyby, jako výpadek serveru, musím propustit dál.

## --checklist--

- Staré načítání zbytečně zabírá síť a server.
- Pozdější odpověď staré zastávky by mohla přepsat novější výsledek.
- Zrušená Promise se zamítne chybou `AbortError`.
- Zrušení se tiše ukončí, skutečné chyby jdou dál.

// ===== Simulace serverů dopravců (neměň) =====

// Jízdní řády dvou brněnských zastávek. Čas odjezdu je text „HH:MM".
const timetable = {
  'Hlavní nádraží': [
    { provider: 'trains', line: 'R 11', destination: 'Praha hl. n.', time: '14:18' },
    { provider: 'trams', line: '4', destination: 'Obřany', time: '14:02' },
    { provider: 'buses', line: '401', destination: 'Mikulov', time: '14:10' },
    { provider: 'trains', line: 'Os 4908', destination: 'Břeclav', time: '14:05' },
    { provider: 'trams', line: '12', destination: 'Komárov', time: '14:09' },
    { provider: 'buses', line: '109', destination: 'Blansko', time: '14:25' },
    { provider: 'trains', line: 'R 17', destination: 'Olomouc', time: '14:32' },
    { provider: 'trams', line: '9', destination: 'Lesná', time: '14:07' },
  ],
  'Mendlovo náměstí': [
    { provider: 'buses', line: '67', destination: 'Líšeň', time: '14:12' },
    { provider: 'trams', line: '1', destination: 'Bystrc', time: '14:06' },
    { provider: 'buses', line: '44', destination: 'Bystrc', time: '14:03' },
    { provider: 'trams', line: '6', destination: 'Starý Lískovec', time: '14:04' },
  ],
};

// Servery dopravců. Testy si je přepínají: delay = odezva v ms,
// failures = kolikrát za sebou server selže, než odpoví, down = neodpovídá vůbec.
const servers = {
  trains: { label: 'vlaky', delay: 60, failures: 0, down: false },
  buses: { label: 'autobusy', delay: 40, failures: 0, down: false },
  trams: { label: 'tramvaje', delay: 20, failures: 0, down: false },
};

// Statistika sítě: kolik požadavků proběhlo a kolik jich běželo naráz.
const network = { calls: 0, active: 0, maxActive: 0 };

// Odjezdy jednoho dopravce ze zastávky. Vrací Promise a umí se zrušit přes signal.
function fetchDepartures(provider, stop, { signal } = {}) {
  const server = servers[provider];
  network.calls++;
  network.active++;
  network.maxActive = Math.max(network.maxActive, network.active);
  return new Promise((resolve, reject) => {
    const finish = () => {
      network.active--;
      signal?.removeEventListener('abort', onAbort);
    };
    const onAbort = () => {
      clearTimeout(timer);
      finish();
      reject(signal.reason);
    };
    const timer = setTimeout(() => {
      finish();
      if (server.down) return reject(new Error(`Server ${server.label} neodpovídá`));
      if (server.failures > 0) {
        server.failures--;
        return reject(new Error(`Server ${server.label} je přetížený`));
      }
      if (!timetable[stop]) return reject(new Error(`Zastávka ${stop} neexistuje`));
      resolve(timetable[stop].filter((item) => item.provider === provider).map((item) => ({ ...item })));
    }, server.delay);
    if (signal?.aborted) return onAbort();
    signal?.addEventListener('abort', onAbort);
  });
}

// Počká, až doběhnou všechny požadavky (používají testy).
function networkIdle() {
  return new Promise((resolve) => {
    const check = () => (network.active === 0 ? resolve() : setTimeout(check, 5));
    check();
  });
}

// Jeden řádek tabule, třeba „14:05  Os 4908  Břeclav".
function formatDeparture(departure) {
  return `${departure.time}  ${departure.line.padEnd(7)} ${departure.destination}`;
}

// Vypíše tabule do konzole.
function showBoard(stop, departures) {
  console.log(`Odjezdy — ${stop}`);
  for (const departure of departures) {
    console.log(formatDeparture(departure));
  }
}

// ===== Tvůj kód =====

// Nový seznam odjezdů seřazený od nejbližšího.
function sortByTime(departures) {
  return departures.toSorted((a, b) => a.time.localeCompare(b.time));
}

// Počká zadaný počet milisekund.
function sleep(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

// Odjezdy jednoho dopravce seřazené od nejbližšího.
async function loadProvider(provider, stop) {
  const departures = await fetchDepartures(provider, stop);
  return sortByTime(departures);
}

// Odjezdy všech tří dopravců, načtené jeden po druhém.
async function loadAllSequential(stop) {
  const trains = await fetchDepartures('trains', stop);
  const buses = await fetchDepartures('buses', stop);
  const trams = await fetchDepartures('trams', stop);
  return sortByTime([...trains, ...buses, ...trams]);
}

// Odjezdy všech tří dopravců, načtené souběžně; signal načítání zruší.
async function loadAll(stop, { signal } = {}) {
  const [trains, buses, trams] = await Promise.all([
    fetchDepartures('trains', stop, { signal }),
    fetchDepartures('buses', stop, { signal }),
    fetchDepartures('trams', stop, { signal }),
  ]);
  return sortByTime([...trains, ...buses, ...trams]);
}

// Od kolegy: nadpis tabule s počtem odjezdů.
async function countDepartures(stop) {
  const departures = await loadAll(stop);
  return departures.length;
}

async function headline(stop) {
  const count = await countDepartures(stop);
  return `${stop} · odjezdů: ${count}`;
}

// Odjezdy dopravců, kteří odpověděli, a seznam těch, kteří ne.
async function loadAvailable(stop) {
  const providers = ['trains', 'buses', 'trams'];
  const results = await Promise.allSettled(providers.map((provider) => fetchDepartures(provider, stop)));
  const departures = [];
  const failed = [];
  results.forEach((result, index) => {
    if (result.status === 'fulfilled') {
      departures.push(...result.value);
    } else {
      failed.push(providers[index]);
    }
  });
  return { departures: sortByTime(departures), failed };
}

// Zamítne se, když promise nedoběhne do ms milisekund.
function withTimeout(promise, ms) {
  const timeout = sleep(ms).then(() => {
    throw new Error(`Vypršel čas ${ms} ms`);
  });
  return Promise.race([promise, timeout]);
}

// Nejbližší odjezdy od zadaného času, nejvýš count.
function nextDepartures(departures, fromTime, count) {
  return sortByTime(departures.filter((departure) => departure.time >= fromTime)).slice(0, count);
}

async function retry(fn, attempts) {
  let lastError;
  for (let attempt = 1; attempt <= attempts; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error;
    }
  }
  throw lastError;
}

// Opakuje fn po chybě a před každým dalším pokusem čeká dvakrát déle.
async function retryWithBackoff(fn, { attempts = 3, baseDelay = 100 } = {}) {
  for (let attempt = 1; ; attempt++) {
    try {
      return await fn();
    } catch (error) {
      if (attempt >= attempts) throw error;
      await sleep(baseDelay * 2 ** (attempt - 1));
    }
  }
}

// Od kolegy: odjezdy dopravce, a když server selže, poslední známé.
const lastKnown = {};

async function loadOrCache(provider, stop) {
  const key = `${provider}|${stop}`;
  try {
    return await fetchDepartures(provider, stop).then((departures) => {
      lastKnown[key] = departures;
      return departures;
    });
  } catch (error) {
    return lastKnown[key] ?? [];
  }
}

--edit--
// ===== Ukázka: výsledek uvidíš v konzoli =====
async function demo() {
  const stop = 'Hlavní nádraží';
  const started = performance.now();
  const { departures, failed } = await loadAvailable(stop);
  showBoard(stop, departures);
  if (failed.length) console.log(`Nedostupné: ${failed.join(', ')}`);
  console.log(`Načteno za ${Math.round(performance.now() - started)} ms`);
}

demo();
--edit--
