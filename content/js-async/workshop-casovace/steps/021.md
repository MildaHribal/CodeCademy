# --description--

Poslední krok. Pod tabuli patří jedna věta, ze které cestující pozná, jestli vidí všechno.

**Úkol:** Pod `startAutoRefresh` napiš funkci `boardSummary(result)`, která z výsledku `loadBoard` vrátí text:

- `Načtené odjezdy: 8.`, když odpověděli všichni,
- `Načtené odjezdy: 5. Nedostupné: vlaky, tramvaje.`, když někdo chybí — dopravce ve `failed` pojmenuj českým názvem z `servers[…].label`, v pořadí z `failed`, oddělené čárkou a mezerou.

V ukázce na konci pak vypiš jen pět nejbližších odjezdů od 14:05, pod ně souhrn a statistiku dopravců.

Tím je workshop hotový. Za sebou máš:

- postupné a souběžné čekání a změřený rozdíl,
- `Promise.all` a `Promise.allSettled`, když jeden zdroj vypadne,
- časový limit přes `Promise.race` a přes `AbortSignal.timeout`,
- opakování s rostoucím čekáním a dvě kolegovy chyby se zapomenutým `await`,
- zrušení přes `AbortController`, přepnutí zastávky a obnovování bez překrývání.

Stejné vzory potkáš v každé aplikaci, která čeká na síť: našeptávač, nekonečný seznam, platby, chat. Příště je použiješ se skutečným `fetch` a HTTP odpověďmi.

## Udělej po svém

- **Vzhled:** vypiš tabuli přes `console.table` s dopravcem jako sloupcem a nedostupné řádky zvýrazni přes `console.warn`.
- **Funkce:** přidej do výsledku `loadBoard` i `slow` — dopravce, kteří odpověděli až na druhý nebo třetí pokus.
- **Funkce:** když dopravce selže, ukaž jeho poslední známé odjezdy přes `loadOrCache` s poznámkou „neaktuální".
- **Tvoje téma:** přeměň tabuli na přehled cen letenek od tří aerolinek nebo stavů tří herních serverů.

# --hints--

Když odpověděli všichni, `boardSummary` vrátí jen počet odjezdů.

```js
const departures = Array.from({ length: 8 }, (_, index) => ({ line: String(index), time: '14:00' }));
assert.equal(boardSummary({ departures, failed: [] }), 'Načtené odjezdy: 8.', "boardSummary s 8 odjezdy a prázdným failed má vrátit 'Načtené odjezdy: 8.'");
```

Když někdo chybí, `boardSummary` připojí české názvy nedostupných dopravců.

```js
const departures = Array.from({ length: 5 }, (_, index) => ({ line: String(index), time: '14:00' }));
assert.equal(
  boardSummary({ departures, failed: ['trains', 'trams'] }),
  'Načtené odjezdy: 5. Nedostupné: vlaky, tramvaje.',
  "boardSummary s 5 odjezdy a failed ['trains', 'trams'] má vrátit 'Načtené odjezdy: 5. Nedostupné: vlaky, tramvaje.'",
);
assert.equal(
  boardSummary({ departures: [], failed: ['buses'] }),
  'Načtené odjezdy: 0. Nedostupné: autobusy.',
  "boardSummary bez odjezdů a s failed ['buses'] má vrátit 'Načtené odjezdy: 0. Nedostupné: autobusy.'",
);
```

# --help--

## --tip--

Nic asynchronního: text poskládáš z pole a objektu `servers`. Tvar výsledku `loadBoard` je stejný jako v [souběžném načítání](see:js-async/async-await#postupne-nebo-soubezne) s `allSettled`.

## --tip--

Nejdřív první větu, a když `failed` není prázdné, převeď id na názvy a spoj je čárkou.

// Jízdní řády dvou brněnských zastávek. Čas odjezdu je text „HH:MM".
const timetable = {
  'Hlavní nádraží': [
    { provider: 'trains', line: 'R 11', destination: 'Praha hl. n.', time: '14:18' },
    { provider: 'trams', line: '4', destination: 'Obřany', time: '14:02' },
    { provider: 'buses', line: '401', destination: 'Mikulov', time: '14:10' },
    { provider: 'trains', line: 'Os 4908', destination: 'Břeclav', time: '14:05' },
    { provider: 'trams', line: '12', destination: 'Komárov', time: '14:09' },
    { provider: 'buses', line: '109', destination: 'Blansko', time: '14:25' },
    { provider: 'trains', line: 'R 17', destination: 'Olomouc', time: '14:32' },
    { provider: 'trams', line: '9', destination: 'Lesná', time: '14:07' },
  ],
  'Mendlovo náměstí': [
    { provider: 'buses', line: '67', destination: 'Líšeň', time: '14:12' },
    { provider: 'trams', line: '1', destination: 'Bystrc', time: '14:06' },
    { provider: 'buses', line: '44', destination: 'Bystrc', time: '14:03' },
    { provider: 'trams', line: '6', destination: 'Starý Lískovec', time: '14:04' },
  ],
};

// Servery dopravců. Testy si je přepínají: delay = odezva v ms,
// failures = kolikrát za sebou server selže, než odpoví, down = neodpovídá vůbec.
const servers = {
  trains: { label: 'vlaky', delay: 60, failures: 0, down: false },
  buses: { label: 'autobusy', delay: 40, failures: 0, down: false },
  trams: { label: 'tramvaje', delay: 20, failures: 0, down: false },
};

// Statistika sítě: kolik požadavků proběhlo a kolik jich běželo naráz.
const network = { calls: 0, active: 0, maxActive: 0 };

// Odjezdy jednoho dopravce ze zastávky. Vrací Promise a umí se zrušit přes signal.
function fetchDepartures(provider, stop, { signal } = {}) {
  const server = servers[provider];
  network.calls++;
  network.active++;
  network.maxActive = Math.max(network.maxActive, network.active);
  return new Promise((resolve, reject) => {
    const finish = () => {
      network.active--;
      signal?.removeEventListener('abort', onAbort);
    };
    const onAbort = () => {
      clearTimeout(timer);
      finish();
      reject(signal.reason);
    };
    const timer = setTimeout(() => {
      finish();
      if (server.down) return reject(new Error(`Server ${server.label} neodpovídá`));
      if (server.failures > 0) {
        server.failures--;
        return reject(new Error(`Server ${server.label} je přetížený`));
      }
      if (!timetable[stop]) return reject(new Error(`Zastávka ${stop} neexistuje`));
      resolve(timetable[stop].filter((item) => item.provider === provider).map((item) => ({ ...item })));
    }, server.delay);
    if (signal?.aborted) return onAbort();
    signal?.addEventListener('abort', onAbort);
  });
}

// Počká, až doběhnou všechny požadavky (používají testy).
function networkIdle() {
  return new Promise((resolve) => {
    const check = () => (network.active === 0 ? resolve() : setTimeout(check, 5));
    check();
  });
}

// Jeden řádek tabule, třeba „14:05  Os 4908  Břeclav".
function formatDeparture(departure) {
  return `${departure.time}  ${departure.line.padEnd(7)} ${departure.destination}`;
}

// Vypíše tabule do konzole.
function showBoard(stop, departures) {
  console.log(`Odjezdy — ${stop}`);
  for (const departure of departures) {
    console.log(formatDeparture(departure));
  }
}

// ===== Tvůj kód =====

// Nový seznam odjezdů seřazený od nejbližšího.
function sortByTime(departures) {
  return departures.toSorted((a, b) => a.time.localeCompare(b.time));
}

// Počká zadaný počet milisekund.
function sleep(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

// Odjezdy jednoho dopravce seřazené od nejbližšího.
async function loadProvider(provider, stop) {
  const departures = await fetchDepartures(provider, stop);
  return sortByTime(departures);
}

// Odjezdy všech tří dopravců, načtené jeden po druhém.
async function loadAllSequential(stop) {
  const trains = await fetchDepartures('trains', stop);
  const buses = await fetchDepartures('buses', stop);
  const trams = await fetchDepartures('trams', stop);
  return sortByTime([...trains, ...buses, ...trams]);
}

// Odjezdy všech tří dopravců, načtené souběžně; signal načítání zruší.
async function loadAll(stop, { signal } = {}) {
  const [trains, buses, trams] = await Promise.all([
    fetchDepartures('trains', stop, { signal }),
    fetchDepartures('buses', stop, { signal }),
    fetchDepartures('trams', stop, { signal }),
  ]);
  return sortByTime([...trains, ...buses, ...trams]);
}

// Od kolegy: nadpis tabule s počtem odjezdů.
async function countDepartures(stop) {
  const departures = await loadAll(stop);
  return departures.length;
}

async function headline(stop) {
  const count = await countDepartures(stop);
  return `${stop} · odjezdů: ${count}`;
}

// Odjezdy dopravců, kteří odpověděli, a seznam těch, kteří ne.
async function loadAvailable(stop) {
  const providers = ['trains', 'buses', 'trams'];
  const results = await Promise.allSettled(providers.map((provider) => fetchDepartures(provider, stop)));
  const departures = [];
  const failed = [];
  results.forEach((result, index) => {
    if (result.status === 'fulfilled') {
      departures.push(...result.value);
    } else {
      failed.push(providers[index]);
    }
  });
  return { departures: sortByTime(departures), failed };
}

// Zamítne se, když promise nedoběhne do ms milisekund.
function withTimeout(promise, ms) {
  const timeout = sleep(ms).then(() => {
    throw new Error(`Vypršel čas ${ms} ms`);
  });
  return Promise.race([promise, timeout]);
}

// Nejbližší odjezdy od zadaného času, nejvýš count.
function nextDepartures(departures, fromTime, count) {
  return sortByTime(departures.filter((departure) => departure.time >= fromTime)).slice(0, count);
}

async function retry(fn, attempts) {
  let lastError;
  for (let attempt = 1; attempt <= attempts; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error;
    }
  }
  throw lastError;
}

// Opakuje fn po chybě a před každým dalším pokusem čeká dvakrát déle.
async function retryWithBackoff(fn, { attempts = 3, baseDelay = 100 } = {}) {
  for (let attempt = 1; ; attempt++) {
    try {
      return await fn();
    } catch (error) {
      if (attempt >= attempts) throw error;
      await sleep(baseDelay * 2 ** (attempt - 1));
    }
  }
}

// Od kolegy: odjezdy dopravce, a když server selže, poslední známé.
const lastKnown = {};

async function loadOrCache(provider, stop) {
  const key = `${provider}|${stop}`;
  try {
    return await fetchDepartures(provider, stop).then((departures) => {
      lastKnown[key] = departures;
      return departures;
    });
  } catch (error) {
    return lastKnown[key] ?? [];
  }
}

// Tabule ukazuje jen poslední vybranou zastávku; starší načítání zruší.
let currentLoad = null;

async function showStop(stop) {
  currentLoad?.abort();
  const controller = new AbortController();
  currentLoad = controller;
  try {
    return await loadAll(stop, { signal: controller.signal });
  } catch (error) {
    if (error.name === 'AbortError') return null;
    throw error;
  }
}

// Odjezdy dopravce s časovým limitem; zrušit je jde i zvenku přes signal.
function fetchWithDeadline(provider, stop, { signal, timeoutMs = 1000 } = {}) {
  const deadline = AbortSignal.timeout(timeoutMs);
  const combined = signal ? AbortSignal.any([signal, deadline]) : deadline;
  return fetchDepartures(provider, stop, { signal: combined });
}

// Celá tabule: každý dopravce s limitem a opakováním, výpadek jednoho nevadí.
async function loadBoard(stop, { signal } = {}) {
  const providers = ['trains', 'buses', 'trams'];
  const results = await Promise.allSettled(
    providers.map((provider) =>
      retryWithBackoff(() => {
        signal?.throwIfAborted();
        return fetchWithDeadline(provider, stop, { signal, timeoutMs: 150 });
      }, { attempts: 3, baseDelay: 50 }),
    ),
  );
  signal?.throwIfAborted();
  const departures = [];
  const failed = [];
  results.forEach((result, index) => {
    if (result.status === 'fulfilled') {
      departures.push(...result.value);
    } else {
      failed.push(providers[index]);
    }
  });
  return { departures: sortByTime(departures), failed };
}

// Kolik odjezdů má který dopravce.
function countByProvider(departures) {
  const counts = {};
  for (const departure of departures) {
    counts[departure.provider] = (counts[departure.provider] ?? 0) + 1;
  }
  return counts;
}

// Obnovuje tabuli dokola; další načtení začne až po dokončení předchozího.
function startAutoRefresh(stop, { intervalMs, onUpdate }) {
  const controller = new AbortController();
  async function refresh() {
    while (!controller.signal.aborted) {
      try {
        onUpdate(await loadBoard(stop, { signal: controller.signal }));
      } catch (error) {
        if (error.name === 'AbortError') return;
        throw error;
      }
      await sleep(intervalMs);
    }
  }
  refresh();
  return () => controller.abort();
}

--edit--
// ===== Ukázka: výsledek uvidíš v konzoli =====
function demo() {
  let rounds = 0;
  const stopRefresh = startAutoRefresh('Hlavní nádraží', {
    intervalMs: 5000,
    onUpdate: ({ departures }) => {
      rounds++;
      console.log(`Obnoveno (${rounds}.): ${departures.length} odjezdů`);
      if (rounds === 2) stopRefresh();
    },
  });
}

demo();

    counts[departure.provider] = (counts[departure.provider] ?? 0) + 1;
  }
  return counts;
}

// Obnovuje tabuli dokola; další načtení začne až po dokončení předchozího.
function startAutoRefresh(stop, { intervalMs, onUpdate }) {
  const controller = new AbortController();
  async function refresh() {
    while (!controller.signal.aborted) {
      try {
        onUpdate(await loadBoard(stop, { signal: controller.signal }));
      } catch (error) {
        if (error.name === 'AbortError') return;
        throw error;
      }
      await sleep(intervalMs);
    }
  }
  refresh();
  return () => controller.abort();
}

// Věta pod tabulí: kolik odjezdů se načetlo a kteří dopravci chybí.
function boardSummary({ departures, failed }) {
  const summary = `Načtené odjezdy: ${departures.length}.`;
  if (failed.length === 0) return summary;
  const labels = failed.map((provider) => servers[provider].label);
  return `${summary} Nedostupné: ${labels.join(', ')}.`;
}
