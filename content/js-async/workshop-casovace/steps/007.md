# --description--

`loadAll` je „všechno, nebo nic": když vypadne server autobusů, uživatel neuvidí ani vlaky a tramvaje, přestože dorazily. Na tabuli je lepší ukázat, co přišlo, a napsat, kdo chybí.

**Úkol:** Pod `headline` napiš `async` funkci `loadAvailable(stop)`, která souběžně načte všechny tři dopravce a vrátí objekt:

- `departures` — odjezdy od dopravců, kteří odpověděli, seřazené podle času,
- `failed` — pole id dopravců, kteří neodpověděli, v pořadí `trains`, `buses`, `trams`.

Nezamítne se ani tehdy, když neodpoví nikdo.

Na tohle je `Promise.allSettled`: počká na všechny Promise a u každé vrátí `{ status: 'fulfilled', value }`, nebo `{ status: 'rejected', reason }` — v pořadí pole, ne v pořadí, jak doběhly. Na jiných datech:

```js
const sources = ['weather', 'news'];
// 1. počkej, až se usadí všechny
const results = await Promise.allSettled(sources.map((source) => loadWidget(source)));
// 2. index výsledku = index zdroje
results.forEach((result, index) => {
  if (result.status === 'rejected') console.log(`${sources[index]} nejde načíst`);
});
```

V ukázce pak místo `loadAll` a nadpisu použij `loadAvailable` a nedostupné dopravce vypiš pod tabuli.

# --hints--

Když odpoví všichni, `loadAvailable` vrátí všech osm odjezdů seřazených a prázdné `failed`.

```js
const result = await loadAvailable('Hlavní nádraží');
assert.deepEqual(
  result.departures.map((item) => item.time),
  ['14:02', '14:05', '14:07', '14:09', '14:10', '14:18', '14:25', '14:32'],
  "loadAvailable('Hlavní nádraží').departures má obsahovat všech 8 odjezdů seřazených podle času",
);
assert.deepEqual(result.failed, [], 'když odpoví všichni, failed má být prázdné pole');
```

Když neodpoví autobusy, `loadAvailable` vrátí vlaky a tramvaje a v `failed` autobusy.

```js
servers.buses.down = true;
const result = await loadAvailable('Hlavní nádraží');
assert.deepEqual(result.departures.map((item) => item.line), ['4', 'Os 4908', '9', '12', 'R 11', 'R 17'], 'bez autobusů má departures obsahovat vlaky a tramvaje seřazené podle času');
assert.deepEqual(result.failed, ['buses'], "bez autobusů má být failed ['buses']");
```

Když neodpoví nikdo, `loadAvailable` se nezamítne a vrátí prázdné odjezdy a všechny tři dopravce ve `failed`.

```js
servers.trains.down = true;
servers.buses.down = true;
servers.trams.down = true;
let result;
try {
  result = await loadAvailable('Hlavní nádraží');
} catch (error) {
  assert.fail(`loadAvailable se nemá zamítnout, zamítla se chybou „${error.message}"`);
}
assert.deepEqual(result, { departures: [], failed: ['trains', 'buses', 'trams'] }, "když neodpoví nikdo, loadAvailable má vrátit { departures: [], failed: ['trains', 'buses', 'trams'] }");
```

Všichni tři dopravci se načítají naráz.

```js
await networkIdle();
network.maxActive = 0;
await loadAvailable('Mendlovo náměstí');
assert.equal(network.maxActive, 3, `při loadAvailable mají běžet tři požadavky naráz, nejvíc jich běželo ${network.maxActive}`);
```

# --explain--

Vysvětli vlastními slovy, kdy na tabuli sáhneš po `Promise.all` a kdy po `Promise.allSettled`.

## --model--

`Promise.all` počká na všechny Promise a vrátí jejich hodnoty, ale jakmile jedna selže, zamítne se a hotové výsledky zahodí. Hodí se, když bez jedné části nemá výsledek smysl, třeba když objednávka potřebuje cenu i dopravu. `Promise.allSettled` počká, až se usadí všechny, nikdy se nezamítne a u každé řekne, jestli se splnila, nebo proč selhala. Na tabuli jsou dopravci nezávislí, takže chci ukázat, co přišlo, a proto `allSettled`.

## --checklist--

- `Promise.all` se zamítne při první chybě a hotové výsledky zahodí.
- `Promise.allSettled` počká na všechny a nikdy se nezamítne.
- Výsledek `allSettled` říká u každé Promise `status` a `value` nebo `reason`.
- `all` pro závislé části, `allSettled` pro nezávislé zdroje.

```js
// ===== Simulace serverů dopravců (neměň) =====

// Jízdní řády dvou brněnských zastávek. Čas odjezdu je text „HH:MM".
const timetable = {
  'Hlavní nádraží': [
    { provider: 'trains', line: 'R 11', destination: 'Praha hl. n.', time: '14:18' },
    { provider: 'trams', line: '4', destination: 'Obřany', time: '14:02' },
    { provider: 'buses', line: '401', destination: 'Mikulov', time: '14:10' },
    { provider: 'trains', line: 'Os 4908', destination: 'Břeclav', time: '14:05' },
    { provider: 'trams', line: '12', destination: 'Komárov', time: '14:09' },
    { provider: 'buses', line: '109', destination: 'Blansko', time: '14:25' },
    { provider: 'trains', line: 'R 17', destination: 'Olomouc', time: '14:32' },
    { provider: 'trams', line: '9', destination: 'Lesná', time: '14:07' },
  ],
  'Mendlovo náměstí': [
    { provider: 'buses', line: '67', destination: 'Líšeň', time: '14:12' },
    { provider: 'trams', line: '1', destination: 'Bystrc', time: '14:06' },
    { provider: 'buses', line: '44', destination: 'Bystrc', time: '14:03' },
    { provider: 'trams', line: '6', destination: 'Starý Lískovec', time: '14:04' },
  ],
};

// Servery dopravců. Testy si je přepínají: delay = odezva v ms,
// failures = kolikrát za sebou server selže, než odpoví, down = neodpovídá vůbec.
const servers = {
  trains: { label: 'vlaky', delay: 60, failures: 0, down: false },
  buses: { label: 'autobusy', delay: 40, failures: 0, down: false },
  trams: { label: 'tramvaje', delay: 20, failures: 0, down: false },
};

// Statistika sítě: kolik požadavků proběhlo a kolik jich běželo naráz.
const network = { calls: 0, active: 0, maxActive: 0 };

// Odjezdy jednoho dopravce ze zastávky. Vrací Promise a umí se zrušit přes signal.
function fetchDepartures(provider, stop, { signal } = {}) {
  const server = servers[provider];
  network.calls++;
  network.active++;
  network.maxActive = Math.max(network.maxActive, network.active);
  return new Promise((resolve, reject) => {
    const finish = () => {
      network.active--;
      signal?.removeEventListener('abort', onAbort);
    };
    const onAbort = () => {
      clearTimeout(timer);
      finish();
      reject(signal.reason);
    };
    const timer = setTimeout(() => {
      finish();
      if (server.down) return reject(new Error(`Server ${server.label} neodpovídá`));
      if (server.failures > 0) {
        server.failures--;
        return reject(new Error(`Server ${server.label} je přetížený`));
      }
      if (!timetable[stop]) return reject(new Error(`Zastávka ${stop} neexistuje`));
      resolve(timetable[stop].filter((item) => item.provider === provider).map((item) => ({ ...item })));
    }, server.delay);
    if (signal?.aborted) return onAbort();
    signal?.addEventListener('abort', onAbort);
  });
}

// Počká, až doběhnou všechny požadavky (používají testy).
function networkIdle() {
  return new Promise((resolve) => {
    const check = () => (network.active === 0 ? resolve() : setTimeout(check, 5));
    check();
  });
}

// Jeden řádek tabule, třeba „14:05  Os 4908  Břeclav".
function formatDeparture(departure) {
  return `${departure.time}  ${departure.line.padEnd(7)} ${departure.destination}`;
}

// Vypíše tabule do konzole.
function showBoard(stop, departures) {
  console.log(`Odjezdy — ${stop}`);
  for (const departure of departures) {
    console.log(formatDeparture(departure));
  }
}

// ===== Tvůj kód =====

// Nový seznam odjezdů seřazený od nejbližšího.
function sortByTime(departures) {
  return departures.toSorted((a, b) => a.time.localeCompare(b.time));
}

// Počká zadaný počet milisekund.
function sleep(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

// Odjezdy jednoho dopravce seřazené od nejbližšího.
async function loadProvider(provider, stop) {
  const departures = await fetchDepartures(provider, stop);
  return sortByTime(departures);
}

// Odjezdy všech tří dopravců, načtené jeden po druhém.
async function loadAllSequential(stop) {
  const trains = await fetchDepartures('trains', stop);
  const buses = await fetchDepartures('buses', stop);
  const trams = await fetchDepartures('trams', stop);
  return sortByTime([...trains, ...buses, ...trams]);
}

// Odjezdy všech tří dopravců, načtené souběžně.
async function loadAll(stop) {
  const [trains, buses, trams] = await Promise.all([
    fetchDepartures('trains', stop),
    fetchDepartures('buses', stop),
    fetchDepartures('trams', stop),
  ]);
  return sortByTime([...trains, ...buses, ...trams]);
}

// Od kolegy: nadpis tabule s počtem odjezdů.
async function countDepartures(stop) {
  const departures = await loadAll(stop);
  return departures.length;
}

async function headline(stop) {
  const count = await countDepartures(stop);
  return `${stop} · odjezdů: ${count}`;
}

--edit--
// ===== Ukázka: výsledek uvidíš v konzoli =====
async function demo() {
  const started = performance.now();
  const departures = await loadAll('Hlavní nádraží');
  console.log(await headline('Hlavní nádraží'));
  showBoard('Hlavní nádraží', departures);
  console.log(`Načteno za ${Math.round(performance.now() - started)} ms`);
}

demo();
--edit--
```

```js
// Odjezdy dopravců, kteří odpověděli, a seznam těch, kteří ne.
async function loadAvailable(stop) {
  const providers = ['trains', 'buses', 'trams'];
  const results = await Promise.allSettled(providers.map((provider) => fetchDepartures(provider, stop)));
  const departures = [];
  const failed = [];
  results.forEach((result, index) => {
    if (result.status === 'fulfilled') {
      departures.push(...result.value);
    } else {
      failed.push(providers[index]);
    }
  });
  return { departures: sortByTime(departures), failed };
}

  const stop = 'Hlavní nádraží';

  showBoard(stop, departures);
  if (failed.length) console.log(`Nedostupné: ${failed.join(', ')}`);
  console.log(`Načteno za ${Math.round(performance.now() - started)} ms`);
}
```
