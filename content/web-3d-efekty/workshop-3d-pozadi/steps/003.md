# --description--

Zkus v náhledu najet na tlačítko „Koupit vstupenku". Nezvýrazní se a kliknutí nic neudělá. Canvas je v HTML **za** obsahem sekce, a protože je absolutně pozicovaný přes celou sekci, leží nad nadpisem i tlačítkem. Je průhledný, takže text vidíš, ale myš trefuje canvas.

Pozadí nemá kliknutí přijímat vůbec. CSS vlastnost `pointer-events` s hodnotou `none` udělá z prvku „ducha": vidět je, ale ukazatel myši i kliknutí jím projdou k prvku pod ním. Pohyb myši pro natáčení scény pak budeš číst z celého okna, ne z canvasu.

Na jiných datech, dekorativní vrstva šumu přes fotku:

```css
.photo__grain {
  position: absolute;
  inset: 0;
  pointer-events: none;
}
```

**Úkol:** V `styles.css` nastav plátnu `.hero__canvas` hodnotu `pointer-events: none`.

# --hints--

Tlačítko „Koupit vstupenku" je pod myší navrchu — kliknutí na jeho střed trefí tlačítko, ne canvas.

```js
const button = document.querySelector('.hero .button');
const rect = button.getBoundingClientRect();
const hit = document.elementFromPoint(rect.left + rect.width / 2, rect.top + rect.height / 2);
assert.ok(button.contains(hit), `na středu tlačítka je navrchu ${hit?.tagName.toLowerCase()}.${hit?.className} místo tlačítka — plátno musí propouštět kliknutí`);
```

Canvas pořád pokrývá celou hero sekci.

```js
const canvas = document.querySelector('.hero__canvas').getBoundingClientRect();
const hero = document.querySelector('.hero').getBoundingClientRect();
assert.ok(Math.abs(canvas.width - hero.width) < 2 && Math.abs(canvas.height - hero.height) < 2, 'canvas má dál zabírat celou hero sekci');
assert.equal(getComputedStyle(document.querySelector('.hero__canvas')).pointerEvents, 'none', '.hero__canvas má mít pointer-events: none');
```

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

function tick() {
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(hero);
```
