# --description--

Na starém firemním počítači nebo v prohlížeči s vypnutou hardwarovou akcelerací WebGL není. `new THREE.WebGLRenderer()` pak vyhodí chybu a návštěvník uvidí černou sekci. Nadpis a tlačítko tam naštěstí jsou, ale pozadí vypadá rozbitě.

3D je vylepšení. `main.js` má nejdřív zjistit, jestli WebGL 2 funguje, a scénu načíst jen tehdy. Jinak hero sekci přidá třídu `hero--static` a CSS ukáže statické pozadí. Three.js má na zjištění podpory doplněk `WebGL` v `three/addons/capabilities/WebGL.js` s metodou `isWebGL2Available()`. Scénu načteš dynamickým importem jen ve větvi, kde WebGL je — statický `import` nahoře souboru by ji načetl vždycky.

**Úkol:**

1. V `main.js` zjisti podporu WebGL 2. Když je, načti `./scene.js`, když není, přidej `.hero` třídu `hero--static`.
2. V `styles.css` dej `.hero--static` pozadí s radiálním gradientem (barvy vesmíru si vyber) a skryj v ní canvas.

## Co ses naučil

Postavil jsi 3D pozadí, jaké potkáš na webech produktů, her i konferencí: průhledný renderer za obsahem, texturu z canvasu, skupiny, částice, pohyb za myší a scrollem s dojížděním — a hlavně všechno kolem, co dělá rozdíl mezi ukázkou a produkcí: strop pixel ratio, méně hvězd na telefonu, pauzu mimo obrazovku a na skryté kartě, úklid paměti, omezený pohyb a zálohu bez WebGL.

Příště se podíváš pod kapotu materiálů: napíšeš vlastní shader s gradientem a šumem.

## Udělej po svém

- **Vzhled:** přidej Saturnu měsíc Titan, který obíhá ve vlastní skupině, a nech prstenec vrhat jemný stín na planetu.
- **Chování:** při najetí na tlačítko „Koupit vstupenku" nech hvězdy o chvilku zrychlit (tlačítko je nad plátnem, pohyb přenes do proměnné).
- **Výkon:** vypiš si do rohu stránky `renderer.info.render.calls` a zkus scénu udržet pod deset draw callů.
- **Tvoje téma:** vyměň Saturn za Zemi s mraky nebo za molekulu pro stránku laboratoře.

# --hints--

S třídou `hero--static` má hero sekce radiální gradient a canvas je skrytý.

```js
const hero = document.querySelector('.hero');
hero.classList.add('hero--static');
const style = getComputedStyle(hero);
assert.match(style.backgroundImage, /radial-gradient/, `.hero--static má mít pozadí s radial-gradient, má ${style.backgroundImage}`);
assert.equal(getComputedStyle(document.querySelector('.hero__canvas')).display, 'none', 'v .hero--static má být canvas skrytý (display: none)');
```

S WebGL se scéna načte a hero sekce třídu `hero--static` nemá.

```js
const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');
await helpers.waitFor(() => canvas.width > 300, 3000).catch(() => {});
assert.ok(canvas.width > 300, 'když WebGL funguje, má main.js načíst scénu a canvas se má zvětšit na hero sekci');
assert.ok(!hero.classList.contains('hero--static'), 'když WebGL funguje, nemá mít hero sekce třídu hero--static');
```

Bez WebGL `main.js` scénu nenačte a přidá hero sekci třídu `hero--static`.

```js
const hero = document.querySelector('.hero');
const source = helpers.stripComments(files['main.js'], 'js');
assert.doesNotMatch(source, /^\s*import\s+['"]\.\/scene\.js['"]/m, 'main.js nesmí načítat scene.js statickým importem nahoře — ten se provede vždycky, i bez WebGL');
const originalGetContext = HTMLCanvasElement.prototype.getContext;
HTMLCanvasElement.prototype.getContext = function getContext(type, ...rest) {
  return /webgl/i.test(type) ? null : originalGetContext.call(this, type, ...rest);
};
hero.classList.remove('hero--static');
let failure = null;
try {
  await import(`data:text/javascript;charset=utf-8,${encodeURIComponent(`${source}\n// ${Math.random()}`)}`);
} catch (error) {
  failure = error;
} finally {
  HTMLCanvasElement.prototype.getContext = originalGetContext;
}
assert.equal(failure, null, `main.js bez WebGL spadl: ${failure?.message}`);
assert.ok(hero.classList.contains('hero--static'), 'když WebGL není, má main.js přidat .hero třídu hero--static');
```

## --tip--

Zjištění podpory a záloha jsou v části [Bez WebGL a s omezeným pohybem](see:web-3d-efekty/interakce-a-castice#bez-webgl-a-s-omezenym-pohybem).

## --tip--

V `main.js` import doplňku `WebGL` nahoře, pak `if` na `isWebGL2Available()`. V první větvi `await import('./scene.js')`, ve druhé `classList.add`. V CSS nové pravidlo pro `.hero--static` a pro canvas uvnitř ní.

## --tip--

Stejná větev u mapy: když prohlížeč nepodporuje WebGL, místo interaktivní mapy se ukáže obrázek s adresou a odkaz „Otevřít v Mapy.cz".

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);
const reducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)');

// Slunce
scene.add(new THREE.AmbientLight('#ffffff', 0.15));
const sun = new THREE.DirectionalLight('#fff4e0', 3);
sun.position.set(-5, 3, 4);
scene.add(sun);

// Pruhy na povrchu planety nakreslené do 2D canvasu
function createBandsTexture() {
  const bands = document.createElement('canvas');
  bands.width = 512;
  bands.height = 256;
  const context = bands.getContext('2d');
  const colors = ['#e8d3a6', '#d9b77e', '#c49a5c', '#e3c796', '#b88a4f', '#d6b27a'];
  let y = 0;
  let index = 0;
  while (y < bands.height) {
    const bandHeight = 6 + ((index * 7) % 5) * 6;
    context.fillStyle = colors[index % colors.length];
    context.fillRect(0, y, bands.width, bandHeight);
    y += bandHeight;
    index += 1;
  }
  const texture = new THREE.CanvasTexture(bands);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
}

// Saturn: planeta a prstenec ve skloněné skupině
export const saturn = new THREE.Group();
saturn.position.set(2.4, 0.4, 0);
saturn.rotation.set(0.45, 0, 0.3);
scene.add(saturn);

export const planet = new THREE.Mesh(
  new THREE.SphereGeometry(1.1, 64, 32),
  new THREE.MeshStandardMaterial({ map: createBandsTexture(), roughness: 0.9 }),
);
planet.name = 'planet';
saturn.add(planet);

const ring = new THREE.Mesh(
  new THREE.RingGeometry(1.5, 2.5, 128),
  new THREE.MeshStandardMaterial({ color: '#cbb48a', roughness: 1, side: THREE.DoubleSide, transparent: true, opacity: 0.75 }),
);
ring.name = 'ring';
ring.rotation.x = -Math.PI / 2;
saturn.add(ring);
const starPositions = new Float32Array(4000 * 3);
for (let i = 0; i < 4000; i++) {
  const star = new THREE.Vector3().randomDirection();
  star.multiplyScalar(THREE.MathUtils.randFloat(20, 60));
  star.toArray(starPositions, i * 3);
}
const starGeometry = new THREE.BufferGeometry();
starGeometry.setAttribute('position', new THREE.BufferAttribute(starPositions, 3));
const stars = new THREE.Points(
  starGeometry,
  new THREE.PointsMaterial({ size: 0.25, color: '#dbeafe', transparent: true, blending: THREE.AdditiveBlending, depthWrite: false }),
);
scene.add(stars);

// Poloha myši od -1 do 1
export const pointer = { x: 0, y: 0 };
window.addEventListener('pointermove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
});

const timer = new THREE.Timer();
timer.connect(document);

function tick(time) {
  timer.update(time);
  const delta = timer.getDelta();

  if (!reducedMotion.matches) {
    planet.rotation.y += 0.15 * delta;
    camera.position.x += (pointer.x * 1.5 - camera.position.x) * 0.05;
    camera.position.y += (pointer.y - camera.position.y) * 0.05;
    camera.position.z = 7 + Math.min(window.scrollY / hero.offsetHeight, 1) * 5;
  }
  camera.lookAt(0, 0, 0);
  renderer.render(scene, camera);
}

// Kreslit, jen když je hero sekce vidět
const visibility = new IntersectionObserver(([entry]) => {
  renderer.setAnimationLoop(entry.isIntersecting ? tick : null);
});
visibility.observe(hero);

// Úklid při odchodu ze stránky
window.addEventListener('pagehide', () => {
  visibility.disconnect();
  renderer.setAnimationLoop(null);
  scene.traverse((object) => {
    object.geometry?.dispose();
    object.material?.map?.dispose();
    object.material?.dispose();
  });
  renderer.dispose();
});

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
  starGeometry.setDrawRange(0, width < 600 ? 1500 : Infinity);
}
new ResizeObserver(resize).observe(hero);
```

```js
import WebGL from 'three/addons/capabilities/WebGL.js';

// 3D je vylepšení: bez WebGL zůstane statické pozadí z CSS.
if (WebGL.isWebGL2Available()) {
  await import('./scene.js');
} else {
  document.querySelector('.hero').classList.add('hero--static');
}
```
