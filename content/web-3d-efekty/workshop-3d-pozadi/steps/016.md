# --description--

Návštěvník odscrolluje k programu a vstupenkám a hero sekce zmizí nahoře. Scéna ale dál kreslí 60 snímků za sekundu do plátna, které nikdo nevidí. Na telefonu to znamená teplejší ruku a rychleji prázdnou baterii.

Render smyčka se má zastavit, když hero sekce opustí okno, a znovu spustit, když se vrátí. Funkci `tick` máš pojmenovanou, takže ji můžeš rendereru předat znovu.

**Úkol:** Kresli scénu jen tehdy, když je aspoň kousek hero sekce v okně. Když sekce z okna odjede, smyčka se zastaví, když se vrátí, znovu se spustí.

# --hints--

Na začátku stránky se scéna kreslí.

```js
const { renderer } = await helpers.importFile('scene.js');
const start = renderer.info.render.frame;
await helpers.waitFor(() => renderer.info.render.frame >= start + 3).catch(() => {});
assert.ok(renderer.info.render.frame >= start + 3, 'když je hero sekce v okně, má se scéna kreslit');
```

Když stránka odjede ke vstupenkám, scéna přestane kreslit.

```js
const { renderer } = await helpers.importFile('scene.js');
document.querySelector('.tickets').scrollIntoView();
const stopped = async () => {
  const before = renderer.info.render.frame;
  await helpers.wait(150);
  return renderer.info.render.frame === before;
};
await helpers.waitFor(stopped, 3000).catch(() => {});
assert.ok(await stopped(), 'když hero sekce není v okně, render smyčka se má zastavit');
```

Po návratu nahoru scéna kreslí znovu.

```js
const { renderer } = await helpers.importFile('scene.js');
document.querySelector('.tickets').scrollIntoView();
await helpers.wait(400);
window.scrollTo(0, 0);
const start = renderer.info.render.frame;
await helpers.waitFor(() => renderer.info.render.frame >= start + 3, 3000).catch(() => {});
assert.ok(renderer.info.render.frame >= start + 3, 'po návratu hero sekce do okna se má scéna zase kreslit');
```

# --help--

## --tip--

Hotový vzor je v části [Výkon: kreslit méně a jen když je na co koukat](see:web-3d-efekty/interakce-a-castice#vykon-kreslit-mene-a-jen-kdyz-je-na-co-koukat), sledování prvku znáš z [lekce o API prohlížeče](see:js-dom/prohlizecova-api#sledovani-prvku-intersectionobserver-a-resizeobserver).

## --tip--

`IntersectionObserver` nad `.hero`. V jeho callbacku podle `isIntersecting` předej rendereru buď `tick`, nebo nic. Původní spuštění smyčky na konci pak nepotřebuješ — observer zavolá callback hned na začátku sám.

## --tip--

Stejné přepínání u videa na pozadí: když sekce odjede, `video.pause()`, když se vrátí, `video.play()`.

# --explain--

Vysvětli vlastními slovy, proč 3D pozadí zastavuješ, když ho nikdo nevidí, a proč stačí zastavit smyčku, a ne scénu zahodit.

## --model--

Render smyčka kreslí každý snímek bez ohledu na to, jestli je plátno vidět, takže mimo obrazovku jen zatěžuje grafiku a baterii. Když smyčku zastavím, objekty scény zůstanou v paměti a po návratu se kreslení hned rozjede. Zahodit scénu má smysl, až když ze stránky odcházím, jinak bych ji po návratu musel stavět znovu.

## --checklist--

- Smyčka kreslí, i když plátno není vidět.
- Zastavení smyčky šetří grafiku a baterii.
- Scéna po zastavení zůstane v paměti a hned se rozjede.
- Uvolnění paměti patří až k odchodu ze stránky.

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

// Slunce
scene.add(new THREE.AmbientLight('#ffffff', 0.15));
const sun = new THREE.DirectionalLight('#fff4e0', 3);
sun.position.set(-5, 3, 4);
scene.add(sun);

// Pruhy na povrchu planety nakreslené do 2D canvasu
function createBandsTexture() {
  const bands = document.createElement('canvas');
  bands.width = 512;
  bands.height = 256;
  const context = bands.getContext('2d');
  const colors = ['#e8d3a6', '#d9b77e', '#c49a5c', '#e3c796', '#b88a4f', '#d6b27a'];
  let y = 0;
  let index = 0;
  while (y < bands.height) {
    const bandHeight = 6 + ((index * 7) % 5) * 6;
    context.fillStyle = colors[index % colors.length];
    context.fillRect(0, y, bands.width, bandHeight);
    y += bandHeight;
    index += 1;
  }
  const texture = new THREE.CanvasTexture(bands);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
}

// Saturn: planeta a prstenec ve skloněné skupině
export const saturn = new THREE.Group();
saturn.position.set(2.4, 0.4, 0);
saturn.rotation.set(0.45, 0, 0.3);
scene.add(saturn);

export const planet = new THREE.Mesh(
  new THREE.SphereGeometry(1.1, 64, 32),
  new THREE.MeshStandardMaterial({ map: createBandsTexture(), roughness: 0.9 }),
);
planet.name = 'planet';
saturn.add(planet);

const ring = new THREE.Mesh(
  new THREE.RingGeometry(1.5, 2.5, 128),
  new THREE.MeshStandardMaterial({ color: '#cbb48a', roughness: 1, side: THREE.DoubleSide, transparent: true, opacity: 0.75 }),
);
ring.name = 'ring';
ring.rotation.x = -Math.PI / 2;
saturn.add(ring);
const starPositions = new Float32Array(4000 * 3);
for (let i = 0; i < 4000; i++) {
  const star = new THREE.Vector3().randomDirection();
  star.multiplyScalar(THREE.MathUtils.randFloat(20, 60));
  star.toArray(starPositions, i * 3);
}
const starGeometry = new THREE.BufferGeometry();
starGeometry.setAttribute('position', new THREE.BufferAttribute(starPositions, 3));
const stars = new THREE.Points(
  starGeometry,
  new THREE.PointsMaterial({ size: 0.25, color: '#dbeafe', transparent: true, blending: THREE.AdditiveBlending, depthWrite: false }),
);
scene.add(stars);

// Poloha myši od -1 do 1
export const pointer = { x: 0, y: 0 };
window.addEventListener('pointermove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
});

const timer = new THREE.Timer();

function tick(time) {
  timer.update(time);
  const delta = timer.getDelta();

  planet.rotation.y += 0.15 * delta;
  camera.position.x += (pointer.x * 1.5 - camera.position.x) * 0.05;
  camera.position.y += (pointer.y - camera.position.y) * 0.05;
  camera.position.z = 7 + Math.min(window.scrollY / hero.offsetHeight, 1) * 5;
  camera.lookAt(0, 0, 0);
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
  starGeometry.setDrawRange(0, width < 600 ? 1500 : Infinity);
}
new ResizeObserver(resize).observe(hero);
```
