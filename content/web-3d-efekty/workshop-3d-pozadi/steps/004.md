# --description--

Na telefonu nebo MacBooku je jeden CSS pixel složený ze 2 nebo 3 fyzických bodů (`window.devicePixelRatio`). Renderer ale kreslí s poměrem 1, takže hrany planety tam budou rozmazané. Poměr nastavíš metodou `renderer.setPixelRatio(…)`.

Poměr 3 by znamenal devětkrát víc pixelů než poměr 1. Telefon by se zahřál a baterie by mizela, přitom rozdíl mezi 2 a 3 okem skoro nevidíš. Proto se dává strop 2.

Hustota se může změnit i za běhu — přetažením okna na jiný monitor. Nastav ji proto ve funkci `resize`. `setPixelRatio` si velikost plátna přepočítá sama, na pořadí vůči `setSize` nezáleží.

Na jiných datech, strop 1,5 pro slabší zařízení:

```js
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.5));
```

**Úkol:** Ve funkci `resize` nastav rendereru poměr pixelů podle `window.devicePixelRatio`, ale nejvýš 2.

# --hints--

Na displeji s `devicePixelRatio` 3 kreslí renderer s poměrem 2 (po změně velikosti okna).

```js
const { renderer } = await helpers.importFile('scene.js');
Object.defineProperty(window, 'devicePixelRatio', { configurable: true, get: () => 3 });
await helpers.resize(900, 700);
await helpers.waitFor(() => renderer.getPixelRatio() === 2).catch(() => {});
assert.equal(renderer.getPixelRatio(), 2, 'při devicePixelRatio 3 má renderer kreslit s poměrem 2 (strop)');
```

Na displeji s `devicePixelRatio` 1,5 kreslí renderer s poměrem 1,5 a plátno má o polovinu víc pixelů než CSS velikost.

```js
const { renderer } = await helpers.importFile('scene.js');
const canvas = document.querySelector('.hero__canvas');
const hero = document.querySelector('.hero');
Object.defineProperty(window, 'devicePixelRatio', { configurable: true, get: () => 1.5 });
await helpers.resize(800, 700);
await helpers.waitFor(() => renderer.getPixelRatio() === 1.5 && Math.abs(canvas.width - hero.clientWidth * 1.5) <= 1).catch(() => {});
assert.equal(renderer.getPixelRatio(), 1.5, 'při devicePixelRatio 1,5 má renderer kreslit s poměrem 1,5');
assert.ok(Math.abs(canvas.width - hero.clientWidth * 1.5) <= 1, `plátno má mít ${hero.clientWidth * 1.5} bodů na šířku, má ${canvas.width}`);
```

# --explain--

Vysvětli vlastními slovy, proč se poměr pixelů omezuje na 2, i když telefon hlásí 3.

## --model--

Poměr platí pro šířku i výšku, takže 3 znamená devětkrát víc pixelů než 1 a 2 jen čtyřikrát víc. Grafika telefonu by u poměru 3 počítala o víc než dvakrát víc práce na každý snímek, zahřívala by se a vybíjela baterii. Rozdíl v ostrosti mezi 2 a 3 přitom na malém displeji skoro není vidět.

## --checklist--

- Počet pixelů roste s druhou mocninou poměru.
- Víc pixelů znamená víc práce grafiky v každém snímku.
- Rozdíl mezi 2 a 3 okem skoro nevidíš.

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

function tick() {
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(hero);
```

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

function tick() {
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(hero);
```
