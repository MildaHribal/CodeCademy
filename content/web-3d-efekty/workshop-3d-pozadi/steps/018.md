# --description--

Web planetária poběží časem jako aplikace, kde se mezi stránkami přechází bez načtení nové stránky. Kdyby hero sekce při odchodu nechala v paměti grafické karty geometrie, materiály a texturu, každá další návštěva by přidala další — až prohlížeč začne ztrácet WebGL kontexty.

Zatím uklidíš při události `pagehide` na `window`, kterou prohlížeč pošle, když uživatel stránku opouští. Stejná funkce se pak dá zavolat i z routeru.

**Úkol:** Při `pagehide` přestaň sledovat hero sekci, zastav render smyčku, uvolni geometrie, materiály i texturu všech objektů ve scéně a nakonec uvolni renderer.

# --hints--

Po `pagehide` se scéna přestane kreslit.

```js
const { renderer } = await helpers.importFile('scene.js');
await helpers.waitFor(() => renderer.info.render.frame > 2).catch(() => {});
window.dispatchEvent(new PageTransitionEvent('pagehide', { persisted: false }));
await helpers.wait(50);
const before = renderer.info.render.frame;
await helpers.wait(250);
assert.equal(renderer.info.render.frame, before, 'po pagehide se render smyčka má zastavit');
```

Po `pagehide` nezůstane v paměti grafiky žádná geometrie a uvolní se materiály i textura planety.

```js
const { renderer, scene, planet } = await helpers.importFile('scene.js');
await helpers.waitFor(() => renderer.info.memory.geometries > 0).catch(() => {});
assert.ok(renderer.info.memory.geometries > 0, 'před odchodem mají být geometrie scény v paměti');
const disposed = new Set();
const materials = new Set();
scene.traverse((object) => { if (object.material) materials.add(object.material); });
for (const material of materials) material.addEventListener('dispose', () => disposed.add(material));
const texture = planet?.material?.map;
let textureDisposed = false;
texture?.addEventListener('dispose', () => { textureDisposed = true; });
window.dispatchEvent(new PageTransitionEvent('pagehide', { persisted: false }));
await helpers.wait(50);
assert.equal(renderer.info.memory.geometries, 0, `po pagehide má být počet geometrií v paměti 0, je ${renderer.info.memory.geometries}`);
assert.equal(disposed.size, materials.size, `po pagehide se má uvolnit všech ${materials.size} materiálů scény, uvolnilo se ${disposed.size}`);
assert.ok(textureDisposed, 'po pagehide se má uvolnit i textura planety (material.map)');
```

Po `pagehide` se smyčka nerozjede ani po scrollu nahoru a dolů.

```js
const { renderer } = await helpers.importFile('scene.js');
await helpers.waitFor(() => renderer.info.render.frame > 2).catch(() => {});
window.dispatchEvent(new PageTransitionEvent('pagehide', { persisted: false }));
document.querySelector('.tickets').scrollIntoView();
await helpers.wait(200);
window.scrollTo(0, 0);
await helpers.wait(200);
const before = renderer.info.render.frame;
await helpers.wait(250);
assert.equal(renderer.info.render.frame, before, 'po pagehide nesmí sledování hero sekce smyčku znovu spustit — odpoj observer');
```

# --help--

## --tip--

Úklid je popsaný v části [Výkon: kreslit méně a jen když je na co koukat](see:web-3d-efekty/interakce-a-castice#vykon-kreslit-mene-a-jen-kdyz-je-na-co-koukat) i s pastí o příliš mnoha WebGL kontextech.

## --tip--

Pořadí: `disconnect` na observeru, zastavení smyčky, `scene.traverse` s `dispose` na `geometry`, `material.map` a `material` (ne každý objekt je má, hodí se `?.`), nakonec `renderer.dispose()`. Observer si kvůli tomu musíš uložit do proměnné.

## --tip--

Stejný úklid u mapy v dialogu: při zavření `map.remove()`, `resizeObserver.disconnect()` a zrušení posluchačů.

# --explain--

Vysvětli vlastními slovy, proč musíš geometrie a materiály uvolňovat ručně, když JavaScript má garbage collector.

## --model--

Geometrie, materiály a textury mají data i v paměti grafické karty. Garbage collector uklízí jen objekty v paměti JavaScriptu a o bufferech na grafice nic neví, takže bez `dispose()` tam data zůstanou. Při opakovaném vytváření scény pak paměť grafiky roste, až prohlížeč začne ztrácet WebGL kontexty.

## --checklist--

- Data geometrií a textur leží i v paměti grafické karty.
- Garbage collector paměť grafiky neuvolní.
- `dispose()` ji uvolní ručně.
- Bez úklidu paměť roste s každým vytvořením scény.

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

// Slunce
scene.add(new THREE.AmbientLight('#ffffff', 0.15));
const sun = new THREE.DirectionalLight('#fff4e0', 3);
sun.position.set(-5, 3, 4);
scene.add(sun);

// Pruhy na povrchu planety nakreslené do 2D canvasu
function createBandsTexture() {
  const bands = document.createElement('canvas');
  bands.width = 512;
  bands.height = 256;
  const context = bands.getContext('2d');
  const colors = ['#e8d3a6', '#d9b77e', '#c49a5c', '#e3c796', '#b88a4f', '#d6b27a'];
  let y = 0;
  let index = 0;
  while (y < bands.height) {
    const bandHeight = 6 + ((index * 7) % 5) * 6;
    context.fillStyle = colors[index % colors.length];
    context.fillRect(0, y, bands.width, bandHeight);
    y += bandHeight;
    index += 1;
  }
  const texture = new THREE.CanvasTexture(bands);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
}

// Saturn: planeta a prstenec ve skloněné skupině
export const saturn = new THREE.Group();
saturn.position.set(2.4, 0.4, 0);
saturn.rotation.set(0.45, 0, 0.3);
scene.add(saturn);

export const planet = new THREE.Mesh(
  new THREE.SphereGeometry(1.1, 64, 32),
  new THREE.MeshStandardMaterial({ map: createBandsTexture(), roughness: 0.9 }),
);
planet.name = 'planet';
saturn.add(planet);

const ring = new THREE.Mesh(
  new THREE.RingGeometry(1.5, 2.5, 128),
  new THREE.MeshStandardMaterial({ color: '#cbb48a', roughness: 1, side: THREE.DoubleSide, transparent: true, opacity: 0.75 }),
);
ring.name = 'ring';
ring.rotation.x = -Math.PI / 2;
saturn.add(ring);
const starPositions = new Float32Array(4000 * 3);
for (let i = 0; i < 4000; i++) {
  const star = new THREE.Vector3().randomDirection();
  star.multiplyScalar(THREE.MathUtils.randFloat(20, 60));
  star.toArray(starPositions, i * 3);
}
const starGeometry = new THREE.BufferGeometry();
starGeometry.setAttribute('position', new THREE.BufferAttribute(starPositions, 3));
const stars = new THREE.Points(
  starGeometry,
  new THREE.PointsMaterial({ size: 0.25, color: '#dbeafe', transparent: true, blending: THREE.AdditiveBlending, depthWrite: false }),
);
scene.add(stars);

// Poloha myši od -1 do 1
export const pointer = { x: 0, y: 0 };
window.addEventListener('pointermove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
});

const timer = new THREE.Timer();
timer.connect(document);

function tick(time) {
  timer.update(time);
  const delta = timer.getDelta();

  planet.rotation.y += 0.15 * delta;
  camera.position.x += (pointer.x * 1.5 - camera.position.x) * 0.05;
  camera.position.y += (pointer.y - camera.position.y) * 0.05;
  camera.position.z = 7 + Math.min(window.scrollY / hero.offsetHeight, 1) * 5;
  camera.lookAt(0, 0, 0);
  renderer.render(scene, camera);
}

// Kreslit, jen když je hero sekce vidět
const visibility = new IntersectionObserver(([entry]) => {
  renderer.setAnimationLoop(entry.isIntersecting ? tick : null);
});
visibility.observe(hero);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
  starGeometry.setDrawRange(0, width < 600 ? 1500 : Infinity);
}
new ResizeObserver(resize).observe(hero);
```
