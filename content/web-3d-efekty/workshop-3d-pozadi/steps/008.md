# --description--

Saturn bez prstence není Saturn. `RingGeometry(innerRadius, outerRadius, thetaSegments)` vyrobí plochý mezikruží. Leží ale ve svislé rovině xy, čelem ke kameře, kdežto prstenec obíhá kolem rovníku planety — musíš ho položit do vodorovné roviny.

Skutečný Saturn má osu skloněnou. Kdybys naklonil zvlášť planetu a zvlášť prstenec, musel bys hlídat, aby se kryly. Jednodušší je dát obojí do jedné skupiny a naklonit skupinu. Kandidáti na naklonění jsou `rotation.x` (k divákovi, aby byl prstenec vidět shora) a `rotation.z` (do strany).

Prstenec je tenká plocha, uvidíš ji zespodu i shora — a má být trochu průhledný.

**Úkol:**

1. Vytvoř a vyexportuj skupinu `saturn` na pozici `(2.4, 0.4, 0)`, nakloněnou o `0.45` kolem osy x a `0.3` kolem osy z, a přidej ji do scény.
2. Planetu přidej do `saturn` místo do scény (její vlastní pozice je teď zbytečná).
3. Do `saturn` přidej prstenec s `name` `'ring'`: poloměry 1.5 a 2.5, 128 segmentů, `MeshStandardMaterial` barvy `#cbb48a`, `roughness` 1, oboustranný a průhledný s `opacity` 0.75, položený do roviny rovníku planety.

# --hints--

`scene.js` exportuje skupinu `saturn` ve scéně na `(2.4, 0.4, 0)` a planeta je v ní.

```js
const { scene, saturn, planet } = await helpers.importFile('scene.js');
assert.ok(saturn?.isGroup, 'scene.js má exportovat saturn (THREE.Group)');
assert.equal(saturn.parent, scene, 'skupina saturn má být ve scéně');
assert.deepEqual(saturn.position.toArray(), [2.4, 0.4, 0], 'skupina saturn má stát na (2.4, 0.4, 0)');
assert.equal(planet?.parent, saturn, 'planeta má být v skupině saturn');
assert.deepEqual(planet.position.toArray(), [0, 0, 0], 'planeta má být uprostřed skupiny (pozici nese skupina)');
```

Skupina je nakloněná o 0.45 kolem osy x a 0.3 kolem osy z.

```js
const { saturn } = await helpers.importFile('scene.js');
assert.ok(saturn, 'scene.js má exportovat saturn');
assert.ok(Math.abs(saturn.rotation.x - 0.45) < 0.001 && Math.abs(saturn.rotation.z - 0.3) < 0.001, `skupina saturn má mít rotation.x = 0.45 a rotation.z = 0.3, má ${saturn.rotation.x.toFixed(2)} a ${saturn.rotation.z.toFixed(2)}`);
```

V `saturn` je prstenec `ring` z `RingGeometry(1.5, 2.5, 128)` s oboustranným průhledným materiálem.

```js
const THREE = await import('three');
const { saturn } = await helpers.importFile('scene.js');
const ring = saturn?.getObjectByName('ring');
assert.ok(ring?.isMesh, 've skupině saturn má být mesh s name = "ring"');
assert.equal(ring.geometry.type, 'RingGeometry', 'prstenec má mít geometrii RingGeometry');
const { innerRadius, outerRadius } = ring.geometry.parameters;
assert.deepEqual([innerRadius, outerRadius], [1.5, 2.5], 'prstenec má mít poloměry 1.5 a 2.5');
assert.equal(ring.material.side, THREE.DoubleSide, 'prstenec má být vidět z obou stran (side: THREE.DoubleSide)');
assert.ok(ring.material.transparent && ring.material.opacity < 1, 'prstenec má být průhledný (transparent: true, opacity 0.75)');
```

Prstenec leží v rovině rovníku planety.

```js
const { saturn, planet } = await helpers.importFile('scene.js');
const ring = saturn?.getObjectByName('ring');
assert.ok(ring && planet, 've skupině saturn má být planeta i prstenec');
saturn.updateWorldMatrix(true, true);
const ringNormal = planet.up.clone().set(0, 0, 1).transformDirection(ring.matrixWorld);
const planetAxis = planet.up.clone().set(0, 1, 0).transformDirection(planet.matrixWorld);
assert.ok(Math.abs(ringNormal.dot(planetAxis)) > 0.99, 'prstenec má ležet kolmo na osu planety — RingGeometry leží v rovině xy, polož ho otočením kolem osy x o čtvrt otáčky');
```

# --help--

## --tip--

Skupina a naklonění celku jsou v části [Skupiny: rodič nese své děti](see:web-3d-efekty/threejs-zaklady#skupiny-rodic-nese-sve-deti).

## --tip--

Naklonění skupiny nastavíš jedním voláním `rotation.set(x, y, z)`. Prstenec položíš otočením kolem osy x o `-Math.PI / 2`. Průhlednost potřebuje dvě vlastnosti materiálu: `transparent` a `opacity`.

## --tip--

Stejné složení u stolu s deskou: `const desk = new THREE.Group(); desk.rotation.set(0, 0.2, 0);` a v něm deska `top.rotation.x = -Math.PI / 2`, protože `PlaneGeometry` taky leží ve svislé rovině.

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

// Slunce
scene.add(new THREE.AmbientLight('#ffffff', 0.15));
const sun = new THREE.DirectionalLight('#fff4e0', 3);
sun.position.set(-5, 3, 4);
scene.add(sun);

// Pruhy na povrchu planety nakreslené do 2D canvasu
function createBandsTexture() {
  const bands = document.createElement('canvas');
  bands.width = 512;
  bands.height = 256;
  const context = bands.getContext('2d');
  const colors = ['#e8d3a6', '#d9b77e', '#c49a5c', '#e3c796', '#b88a4f', '#d6b27a'];
  let y = 0;
  let index = 0;
  while (y < bands.height) {
    const bandHeight = 6 + ((index * 7) % 5) * 6;
    context.fillStyle = colors[index % colors.length];
    context.fillRect(0, y, bands.width, bandHeight);
    y += bandHeight;
    index += 1;
  }
  const texture = new THREE.CanvasTexture(bands);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
}

export const planet = new THREE.Mesh(
  new THREE.SphereGeometry(1.1, 64, 32),
  new THREE.MeshStandardMaterial({ map: createBandsTexture(), roughness: 0.9 }),
);
planet.name = 'planet';
planet.position.set(2.4, 0.4, 0);
scene.add(planet);

const timer = new THREE.Timer();

function tick(time) {
  timer.update(time);
  const delta = timer.getDelta();

  planet.rotation.y += 0.15 * delta;
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(hero);
```
