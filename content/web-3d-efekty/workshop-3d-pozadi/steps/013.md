# --description--

Když se kamera kousek posune za kurzorem a přitom se pořád dívá do středu scény, vznikne hloubka: Saturn vpředu se posune viditelně víc než vzdálené hvězdy. Posun ale nesmí být skokový — kamera má ke kurzoru **dojíždět**.

Cíl kamery je `x = pointer.x * 1.5` a `y = pointer.y`. V každém snímku ujde 5 % zbývající cesty k cíli. Kandidáti: ruční zápis `hodnota += (cíl - hodnota) * podíl`, nebo `THREE.MathUtils.lerp`. Po posunu kameru znovu natoč do bodu `(0, 0, 0)`.

**Úkol:** Ve funkci `tick` před vykreslením posuň kameru na ose x a y o 5 % zbývající cesty k cíli podle `pointer` a natoč ji do středu scény.

# --hints--

Myš u pravého okraje okna posune kameru doprava až k `x ≈ 1.5`.

```js
const { camera } = await helpers.importFile('scene.js');
document.body.dispatchEvent(new PointerEvent('pointermove', { clientX: window.innerWidth - 1, clientY: window.innerHeight / 2, bubbles: true }));
await helpers.waitFor(() => camera.position.x > 1.4, 4000).catch(() => {});
assert.ok(camera.position.x > 1.4 && camera.position.x < 1.6, `kamera má dojet k x ≈ 1.5, je na ${camera.position.x.toFixed(2)}`);
```

Kamera dojíždí plynule: dva snímky po pohybu myši je teprve na začátku cesty.

```js
const { camera } = await helpers.importFile('scene.js');
document.body.dispatchEvent(new PointerEvent('pointermove', { clientX: window.innerWidth - 1, clientY: 0, bubbles: true }));
await new Promise((resolve) => requestAnimationFrame(() => requestAnimationFrame(resolve)));
assert.ok(camera.position.x < 1.2, `dva snímky po pohybu myši je kamera na x = ${camera.position.x.toFixed(2)} — má k cíli 1.5 dojíždět, ne skočit`);
await helpers.waitFor(() => camera.position.x > 0.5 && camera.position.y > 0.3, 3000).catch(() => {});
assert.ok(camera.position.x > 0.5 && camera.position.y > 0.3, 'kamera se má za myší v pravém horním rohu posunout doprava i nahoru');
```

Kamera se i po posunu dívá do středu scény.

```js
const { camera } = await helpers.importFile('scene.js');
document.body.dispatchEvent(new PointerEvent('pointermove', { clientX: 0, clientY: 0, bubbles: true }));
await helpers.waitFor(() => camera.position.x < -1, 4000).catch(() => {});
const direction = camera.getWorldDirection(camera.position.clone());
const toCenter = camera.position.clone().negate().normalize();
assert.ok(camera.position.x < -1, 'kamera se má za myší v levém horním rohu posunout doleva');
assert.ok(direction.dot(toCenter) > 0.999, 'kamera se má po posunu dívat do bodu (0, 0, 0)');
```

# --help--

## --tip--

Dojíždění je [lineární interpolace](see:web-3d-efekty/interakce-a-castice#plynule-natoceni-linearni-interpolace).

## --tip--

Ve `tick` přičti k `camera.position.x` rozdíl mezi cílem a současnou hodnotou krát 0.05, totéž pro `y`. Pak `camera.lookAt` se středem scény.

## --tip--

Stejné dojíždění pro kurzor-kolečko v HTML: v každém snímku `ring.x += (mouse.x - ring.x) * 0.1`, totéž pro `y`, a pak kolečko přesuneš na nové souřadnice.

# --explain--

Vysvětli vlastními slovy, proč se při posunu kamery Saturn posune na obrazovce víc než vzdálené hvězdy.

## --model--

Kamera se posune o stejný kus vůči všem objektům, ale na obrazovce se posun projeví podle vzdálenosti. Saturn je od kamery asi 7 jednotek, hvězdy 20 až 60, takže stejný posun u nich znamená mnohem menší úhel. Tomu se říká paralaxa a díky ní scéna působí hloubkou.

## --checklist--

- Posun kamery je pro všechny objekty stejný.
- Na obrazovce je vidět úhel, a ten je u vzdálených objektů menší.
- Rozdílný posun blízkých a vzdálených věcí vytváří dojem hloubky.

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

// Slunce
scene.add(new THREE.AmbientLight('#ffffff', 0.15));
const sun = new THREE.DirectionalLight('#fff4e0', 3);
sun.position.set(-5, 3, 4);
scene.add(sun);

// Pruhy na povrchu planety nakreslené do 2D canvasu
function createBandsTexture() {
  const bands = document.createElement('canvas');
  bands.width = 512;
  bands.height = 256;
  const context = bands.getContext('2d');
  const colors = ['#e8d3a6', '#d9b77e', '#c49a5c', '#e3c796', '#b88a4f', '#d6b27a'];
  let y = 0;
  let index = 0;
  while (y < bands.height) {
    const bandHeight = 6 + ((index * 7) % 5) * 6;
    context.fillStyle = colors[index % colors.length];
    context.fillRect(0, y, bands.width, bandHeight);
    y += bandHeight;
    index += 1;
  }
  const texture = new THREE.CanvasTexture(bands);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
}

// Saturn: planeta a prstenec ve skloněné skupině
export const saturn = new THREE.Group();
saturn.position.set(2.4, 0.4, 0);
saturn.rotation.set(0.45, 0, 0.3);
scene.add(saturn);

export const planet = new THREE.Mesh(
  new THREE.SphereGeometry(1.1, 64, 32),
  new THREE.MeshStandardMaterial({ map: createBandsTexture(), roughness: 0.9 }),
);
planet.name = 'planet';
saturn.add(planet);

const ring = new THREE.Mesh(
  new THREE.RingGeometry(1.5, 2.5, 128),
  new THREE.MeshStandardMaterial({ color: '#cbb48a', roughness: 1, side: THREE.DoubleSide, transparent: true, opacity: 0.75 }),
);
ring.name = 'ring';
ring.rotation.x = -Math.PI / 2;
saturn.add(ring);
const starPositions = new Float32Array(4000 * 3);
for (let i = 0; i < 4000; i++) {
  const star = new THREE.Vector3().randomDirection();
  star.multiplyScalar(THREE.MathUtils.randFloat(20, 60));
  star.toArray(starPositions, i * 3);
}
const starGeometry = new THREE.BufferGeometry();
starGeometry.setAttribute('position', new THREE.BufferAttribute(starPositions, 3));
const stars = new THREE.Points(
  starGeometry,
  new THREE.PointsMaterial({ size: 0.25, color: '#dbeafe', transparent: true, blending: THREE.AdditiveBlending, depthWrite: false }),
);
scene.add(stars);

// Poloha myši od -1 do 1
export const pointer = { x: 0, y: 0 };
window.addEventListener('pointermove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
});

const timer = new THREE.Timer();

function tick(time) {
  timer.update(time);
  const delta = timer.getDelta();

  planet.rotation.y += 0.15 * delta;
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(hero);
```
