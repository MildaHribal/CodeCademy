# --description--

Canvas zabírá celou hero sekci (styl je hotový), ale kreslí v rozlišení 300 × 150 bodů a kamera počítá s poměrem stran 1 : 1. Na širokém monitoru i na telefonu na výšku je obraz rozmazaný a zdeformovaný.

**Úkol:** Napiš funkci `resize`, která podle šířky a výšky `.hero` nastaví velikost plátna rendereru (styly nech na CSS), poměr stran kamery a přepočítá projekci. Zavolej ji po prvním rozvržení a při každé změně velikosti `.hero`.

# --hints--

Plátno kreslí ve stejném rozlišení, jako je velikost `.hero`, i po změně okna na 700 × 900 px.

```js
await helpers.importFile('scene.js');
const canvas = document.querySelector('.hero__canvas');
const hero = document.querySelector('.hero');
const fits = () => Math.abs(canvas.width - hero.clientWidth) <= 1 && Math.abs(canvas.height - hero.clientHeight) <= 1;
await helpers.waitFor(fits).catch(() => {});
assert.ok(fits(), `plátno má kreslit v rozlišení ${hero.clientWidth} × ${hero.clientHeight} jako .hero, kreslí ${canvas.width} × ${canvas.height}`);
await helpers.resize(700, 900);
await helpers.waitFor(fits).catch(() => {});
assert.ok(fits(), `po změně okna na 700 × 900 px má plátno kreslit v rozlišení ${hero.clientWidth} × ${hero.clientHeight}, kreslí ${canvas.width} × ${canvas.height}`);
```

Po změně okna má kamera poměr stran `.hero` a přepočítanou projekci.

```js
const { camera } = await helpers.importFile('scene.js');
const hero = document.querySelector('.hero');
await helpers.resize(700, 900);
const expected = hero.clientWidth / hero.clientHeight;
await helpers.waitFor(() => Math.abs(camera.aspect - expected) < 0.02).catch(() => {});
assert.ok(Math.abs(camera.aspect - expected) < 0.02, `po změně okna na 700 × 900 px má camera.aspect být ${expected.toFixed(2)}, je ${camera.aspect.toFixed(2)}`);
const matrix = camera.projectionMatrix.elements;
assert.ok(Math.abs(matrix[5] / matrix[0] - expected) < 0.02, 'kamera nový poměr stran nepoužívá — po změně aspect přepočítej projekci');
```

# --help--

## --tip--

Totéž jsi psal pro `.viewer` v konfigurátoru lampy. Připomenutí: [Změna velikosti plátna](see:web-3d-efekty/threejs-zaklady#zmena-velikosti-platna).

## --tip--

Rozměry ber z `hero.clientWidth` a `hero.clientHeight`, funkci předej `ResizeObserver` nad `.hero` (nebo posluchači `resize` na okně s prvním zavoláním hned).

## --tip--

Podcíle:

```text
// 2. velikost rendereru bez změny stylů

// 4. zavolej při každé změně velikosti
```

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

function tick() {
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);

// Velikost plátna podle hero sekce
function resize() {
  const width = hero.clientWidth;
  const height = hero.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(hero);
```
