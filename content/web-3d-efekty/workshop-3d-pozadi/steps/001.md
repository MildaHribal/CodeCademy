# --description--

Planetárium Zenit uvádí nový pořad o Saturnu. Postavíš jeho úvodní sekci: za nadpisem a tlačítkem se točí planeta s prstencem, kolem jsou tisíce hvězd, scéna se jemně natáčí za myší a při scrollu kamera odjíždí. Celé to bude šetrné k telefonu i k lidem, kterým pohyb vadí.

HTML a vzhled stránky jsou hotové. `main.js` jen načte `scene.js` a tam budeš psát. `scene.js` exportuje hlavní objekty stejně jako v konfigurátoru lampy.

**Úkol:** V `scene.js` vytvoř a vyexportuj bez návodu:

- `renderer`, který kreslí do `.hero__canvas`, s vyhlazováním, průhledným pozadím a `preserveDrawingBuffer: true`,
- `scene`,
- `camera` se zorným úhlem 50°, `near` 0.1 a `far` **200** (hvězdy budou až 60 jednotek daleko), postavenou na `(0, 0, 7)`.

Render smyčku napiš jako pojmenovanou funkci `tick`, kterou předáš rendereru. Pojmenovaná funkce se bude hodit, až budeš smyčku zastavovat a znovu spouštět.

# --hints--

`scene.js` exportuje `renderer`, který kreslí do `.hero__canvas` s průhledným pozadím a `preserveDrawingBuffer`.

```js
const { renderer } = await helpers.importFile('scene.js');
assert.ok(renderer?.isWebGLRenderer, 'scene.js má exportovat renderer vytvořený přes new THREE.WebGLRenderer(…)');
assert.equal(renderer.domElement, document.querySelector('.hero__canvas'), 'renderer má kreslit do canvasu .hero__canvas');
assert.equal(renderer.getClearAlpha(), 0, 'renderer potřebuje alpha: true, aby prosvítalo pozadí stránky');
assert.equal(renderer.getContext().getContextAttributes().preserveDrawingBuffer, true, 'renderer potřebuje preserveDrawingBuffer: true');
```

`scene.js` exportuje `scene` a kameru se zorným úhlem 50°, `far` 200 na `(0, 0, 7)`.

```js
const { scene, camera } = await helpers.importFile('scene.js');
assert.ok(scene?.isScene, 'scene.js má exportovat scene');
assert.ok(camera?.isPerspectiveCamera, 'scene.js má exportovat camera (PerspectiveCamera)');
assert.equal(camera.fov, 50, 'kamera má mít zorný úhel 50');
assert.equal(camera.far, 200, 'kamera má mít far 200, jinak vzdálené hvězdy nevykreslí');
assert.deepEqual(camera.position.toArray(), [0, 0, 7], 'kamera má stát na (0, 0, 7)');
```

Render smyčka vykresluje scénu pořád dokola.

```js
const { renderer } = await helpers.importFile('scene.js');
const start = renderer.info.render.frame;
await helpers.waitFor(() => renderer.info.render.frame >= start + 3).catch(() => {});
assert.ok(renderer.info.render.frame >= start + 3, 'renderer má scénu vykreslovat v každém snímku — předej funkci tick do setAnimationLoop');
```

# --help--

## --tip--

Stejné tři objekty jsi psal v prvním kroku konfigurátoru lampy. Připomenutí je v části [Scéna, kamera a renderer](see:web-3d-efekty/threejs-zaklady#scena-kamera-a-renderer).

## --tip--

Pojmenovaná funkce se píše `function tick() { … }` a do `setAnimationLoop` ji předáš jménem, bez závorek.

## --tip--

Kostra v podcílech:

```text
// 1. export renderer s nastavením (canvas, antialias, alpha, preserveDrawingBuffer)
// 2. export scene, export camera + její pozice
// 3. function tick: vykresli scénu kamerou
// 4. předej tick rendereru jako render smyčku
```

# --solution--

## --file-- scene.js

```js
import * as THREE from 'three';

const hero = document.querySelector('.hero');
const canvas = document.querySelector('.hero__canvas');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(0, 0, 7);

function tick() {
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick);
```
