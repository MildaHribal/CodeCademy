# --description--

Tlačítko „Rozsvítit lampu" zatím nic nedělá. Pod stínidlo patří žárovka — světlo, které svítí z jednoho bodu do všech stran a na vzdálenost pár jednotek slábne. Ze světel z lekce se na to hodí jen jedno.

Žárovka musí jít s ramenem a stínidlem stejně jako stínidlo. Kam ji tedy přidáš?

**Úkol:** Pod stínidlo (kousek pod jeho středem) přidej zhasnuté světlo teplé barvy `#ffd89b` s dosahem 6. Tlačítko `.switch` ho po kliknutí rozsvítí (intenzita větší než 0) a nastaví `aria-pressed="true"`, další kliknutí ho zhasne a vrátí `aria-pressed="false"`.

Po rozsvícení se vnitřek stínidla a podstava prosvětlí teplým světlem.

# --hints--

V lampě je bodové světlo pod stínidlem, po načtení zhasnuté.

```js
const { lamp } = await helpers.importFile('main.js');
const bulbs = [];
lamp?.traverse((object) => { if (object.isPointLight) bulbs.push(object); });
assert.equal(bulbs.length, 1, 'v lampě má být jedno PointLight');
const [bulb] = bulbs;
assert.ok(bulb.intensity === 0 || !bulb.visible, 'po načtení má být lampa zhasnutá (intenzita 0)');
lamp.updateWorldMatrix(true, true);
const shade = lamp.getObjectByName('shade');
const distance = bulb.getWorldPosition(bulb.position.clone()).distanceTo(shade.getWorldPosition(shade.position.clone()));
assert.ok(distance < 0.6, `žárovka má být pod stínidlem, je od jeho středu ${distance.toFixed(2)}`);
```

Kliknutí na vypínač lampu rozsvítí a nastaví `aria-pressed="true"`.

```js
const { lamp } = await helpers.importFile('main.js');
let bulb = null;
lamp?.traverse((object) => { if (object.isPointLight) bulb = object; });
assert.ok(bulb, 'v lampě má být PointLight');
const lightSwitch = document.querySelector('.switch');
await helpers.click(lightSwitch);
assert.ok(bulb.visible && bulb.intensity > 0, 'po kliknutí na vypínač má mít žárovka intenzitu větší než 0');
assert.equal(lightSwitch.getAttribute('aria-pressed'), 'true', 'po rozsvícení má mít vypínač aria-pressed="true"');
```

Druhé kliknutí lampu zhasne a vrátí `aria-pressed="false"`.

```js
const { lamp } = await helpers.importFile('main.js');
let bulb = null;
lamp?.traverse((object) => { if (object.isPointLight) bulb = object; });
assert.ok(bulb, 'v lampě má být PointLight');
const lightSwitch = document.querySelector('.switch');
await helpers.click(lightSwitch);
await helpers.click(lightSwitch);
assert.ok(bulb.intensity === 0 || !bulb.visible, 'po druhém kliknutí má být žárovka zhasnutá');
assert.equal(lightSwitch.getAttribute('aria-pressed'), 'false', 'po zhasnutí má mít vypínač aria-pressed="false"');
```

# --help--

## --tip--

Druhy světel jsou vyjmenované v části [Světla](see:web-3d-efekty/threejs-zaklady#svetla).

## --tip--

Hodí se `PointLight(barva, intenzita, dosah)`. Patří do `armPivot` těsně pod výšku stínidla. Stav vypínače si můžeš číst přímo z jeho `aria-pressed` — jeden zdroj pravdy.

## --tip--

Stejný přepínač u zvuku přehrávače: `const isMuted = muteButton.getAttribute('aria-pressed') !== 'true'; audio.volume = isMuted ? 0 : 1;` a potom zápis nového stavu do `aria-pressed`.

## --file-- main.js

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Prostředí, které odráží kov
scene.environment = new THREE.PMREMGenerator(renderer).fromScene(new RoomEnvironment()).texture;

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

// Lampa
export const lamp = new THREE.Group();
lamp.position.set(-0.4, -1.4, 0);
scene.add(lamp);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632', roughness: 0.35, metalness: 1 }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
lamp.add(base);

const armPivot = new THREE.Group();
armPivot.name = 'armPivot';
armPivot.position.y = 0.2;
armPivot.rotation.z = -0.35;
lamp.add(armPivot);

const arm = new THREE.Mesh(
  new THREE.CylinderGeometry(0.06, 0.06, 2.4, 16),
  new THREE.MeshStandardMaterial({ color: '#3a3632', roughness: 0.35, metalness: 1 }),
);
arm.name = 'arm';
arm.userData.label = 'Ohýbané rameno';
arm.position.y = 1.2;
armPivot.add(arm);

const shade = new THREE.Mesh(
  new THREE.SphereGeometry(0.7, 48, 24, 0, Math.PI * 2, 0, Math.PI / 2),
  new THREE.MeshStandardMaterial({ color: '#e0a526', roughness: 0.6, side: THREE.DoubleSide }),
);
shade.name = 'shade';
shade.userData.label = 'Hliníkové stínidlo';
shade.position.y = 2.4;
armPivot.add(shade);

// Otáčení myší
export const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;
controls.enablePan = false;
controls.minDistance = 4;
controls.maxDistance = 12;
controls.maxPolarAngle = Math.PI / 2;

// Barva stínidla
const swatches = document.querySelectorAll('.swatch');
for (const swatch of swatches) {
  swatch.addEventListener('click', () => {
    shade.material.color.set(swatch.dataset.color);
    for (const other of swatches) {
      other.setAttribute('aria-pressed', String(other === swatch));
    }
  });
}

// Velikost plátna podle prohlížeče (sjednotil Tomáš)
function fitToViewer() {
  const { width, height } = viewer.getBoundingClientRect();
  renderer.setSize(Math.round(width), Math.round(height), false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(fitToViewer).observe(viewer);

renderer.setAnimationLoop(() => {
  controls.update();
  renderer.render(scene, camera);
});
```
