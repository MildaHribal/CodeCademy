# --description--

Čtečka obrazovky v canvasu nevidí nic, pro ni je to prázdná plocha. Zákazník, který nevidí, se ale o lampě potřebuje dozvědět totéž: jakou barvu stínidla právě vybral a jestli je rozsvícená. Canvas proto dostane roli obrázku a textový popis, který se mění s konfigurací.

**Úkol:** Canvas náhledu má roli obrázku a popisek (`aria-label`), ve kterém je název vybrané barvy stínidla (stejný text jako na tlačítku) a slovo „rozsvícená", nebo „zhasnutá". Popisek odpovídá stavu hned po načtení i po každé změně barvy a po každém přepnutí vypínače.

## Co ses naučil

Postavil jsi konfigurátor produktu jen z primitiv: skupiny a klouby pro hierarchii částí, materiály s kovem a prostředím, světla včetně žárovky, otáčení s omezením, napojení scény na HTML tlačítka, `Raycaster` pro kliknutí a najetí myší a popis pro čtečky. Stejnou skladbu použiješ u konfigurátoru nábytku, kola nebo tenisky — jen místo primitiv načteš hotový model.

Příště se naučíš scénu napojit na pohyb myši a scroll celé stránky, vytvořit tisíce částic a udržet 3D plynulé i na telefonu.

## Udělej po svém

- **Vzhled:** přidej volbu povrchu podstavy (matná černá × leštěná ocel) přes `roughness` a `metalness`.
- **Chování:** po rozsvícení nech stínidlo zevnitř jemně svítit (`emissive` na materiálu) a přechod rozsvícení rozlož do půl sekundy.
- **Funkce:** ulož vybranou barvu do adresy (`?barva=zelena`), aby šel odkaz poslat kamarádovi.
- **Tvoje téma:** vyměň lampu za produkt, který tě zajímá — hrnek, reproduktor, kolo — složený z primitiv.

# --hints--

Canvas náhledu má `role="img"`.

```js
await helpers.importFile('main.js');
assert.equal(document.querySelector('.viewer__canvas').getAttribute('role'), 'img', 'canvas .viewer__canvas má mít role="img"');
```

Po načtení popisek canvasu obsahuje „hořčicová" a „zhasnutá", po kliknutí na „Lahvově zelená" obsahuje „lahvově zelená".

```js
await helpers.importFile('main.js');
const canvas = document.querySelector('.viewer__canvas');
const text = () => (canvas.getAttribute('aria-label') ?? '').normalize('NFC').toLowerCase();
assert.match(text(), /hořčicová/, 'po načtení má aria-label canvasu obsahovat vybranou barvu „Hořčicová"');
assert.match(text(), /zhasnutá/, 'po načtení má aria-label canvasu říkat, že lampa je „zhasnutá"');
await helpers.click(document.querySelector('[data-color="#2f6f5e"]'));
assert.match(text(), /lahvově zelená/, 'po kliknutí na Lahvově zelená má aria-label canvasu obsahovat „Lahvově zelená"');
assert.doesNotMatch(text(), /hořčicová/, 'po změně barvy už aria-label nemá obsahovat starou barvu „Hořčicová"');
```

Po rozsvícení popisek obsahuje „rozsvícená", po zhasnutí znovu „zhasnutá".

```js
await helpers.importFile('main.js');
const canvas = document.querySelector('.viewer__canvas');
const text = () => (canvas.getAttribute('aria-label') ?? '').normalize('NFC').toLowerCase();
const lightSwitch = document.querySelector('.switch');
await helpers.click(lightSwitch);
assert.match(text(), /rozsvícená/, 'po rozsvícení má aria-label canvasu obsahovat „rozsvícená"');

assert.match(text(), /zhasnutá/, 'po zhasnutí má aria-label canvasu obsahovat „zhasnutá"');
```

## --tip--

Proč obsah canvasu nikdo nepřečte, je v části [Kdy 3D na web patří](see:web-3d-efekty/threejs-zaklady#kdy-3d-na-web-patri). Role a popisky znáš z `html-pristupnost`.

## --tip--

Napiš jednu funkci, která popisek složí ze dvou zdrojů pravdy: textu tlačítka s `aria-pressed="true"` a `aria-pressed` vypínače. Zavolej ji po načtení a na konci obou obsluh kliknutí.

## --tip--

Stejný vzor u grafu v canvasu: funkce `describeChart()` přečte vybraný měsíc a součet tržeb, zapíše je do `aria-label` grafu a volá se po načtení i po každé změně filtru.

## --file-- main.js

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Prostředí, které odráží kov
scene.environment = new THREE.PMREMGenerator(renderer).fromScene(new RoomEnvironment()).texture;

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

// Lampa
export const lamp = new THREE.Group();
lamp.position.set(-0.4, -1.4, 0);
scene.add(lamp);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632', roughness: 0.35, metalness: 1 }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
lamp.add(base);

const armPivot = new THREE.Group();
armPivot.name = 'armPivot';
armPivot.position.y = 0.2;
armPivot.rotation.z = -0.35;
lamp.add(armPivot);

const arm = new THREE.Mesh(
  new THREE.CylinderGeometry(0.06, 0.06, 2.4, 16),
  new THREE.MeshStandardMaterial({ color: '#3a3632', roughness: 0.35, metalness: 1 }),
);
arm.name = 'arm';
arm.userData.label = 'Ohýbané rameno';
arm.position.y = 1.2;
armPivot.add(arm);

const shade = new THREE.Mesh(
  new THREE.SphereGeometry(0.7, 48, 24, 0, Math.PI * 2, 0, Math.PI / 2),
  new THREE.MeshStandardMaterial({ color: '#e0a526', roughness: 0.6, side: THREE.DoubleSide }),
);
shade.name = 'shade';
shade.userData.label = 'Hliníkové stínidlo';
shade.position.y = 2.4;
armPivot.add(shade);

const bulb = new THREE.PointLight('#ffd89b', 0, 6);
bulb.position.y = 2.25;
armPivot.add(bulb);

// Otáčení myší
export const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;
controls.enablePan = false;
controls.minDistance = 4;
controls.maxDistance = 12;
controls.maxPolarAngle = Math.PI / 2;

// Barva stínidla
const swatches = document.querySelectorAll('.swatch');
for (const swatch of swatches) {
  swatch.addEventListener('click', () => {
    shade.material.color.set(swatch.dataset.color);
    for (const other of swatches) {
      other.setAttribute('aria-pressed', String(other === swatch));
    }
  });
}

// Vypínač
const lightSwitch = document.querySelector('.switch');
lightSwitch.addEventListener('click', () => {
  const isOn = lightSwitch.getAttribute('aria-pressed') !== 'true';
  bulb.intensity = isOn ? 4 : 0;
  lightSwitch.setAttribute('aria-pressed', String(isOn));
});

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();
const label = document.querySelector('.viewer__label');
canvas.addEventListener('click', (event) => {
  const rect = canvas.getBoundingClientRect();
  pointer.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
  pointer.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const [hit] = raycaster.intersectObjects(lamp.children, true);
  label.textContent = hit ? hit.object.userData.label : '';
});

// Zvýraznění části pod myší
let hovered = null;
canvas.addEventListener('pointermove', (event) => {
  const rect = canvas.getBoundingClientRect();
  pointer.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
  pointer.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const [hit] = raycaster.intersectObjects(lamp.children, true);
  const part = hit ? hit.object : null;
  if (part === hovered) return;
  if (hovered) hovered.material.emissive.set('#000000');
  if (part) part.material.emissive.set('#3a2a10');
  hovered = part;
  canvas.style.cursor = part ? 'pointer' : '';
});

// Velikost plátna podle prohlížeče (sjednotil Tomáš)
function fitToViewer() {
  const { width, height } = viewer.getBoundingClientRect();
  renderer.setSize(Math.round(width), Math.round(height), false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(fitToViewer).observe(viewer);

renderer.setAnimationLoop(() => {
  controls.update();
  renderer.render(scene, camera);
});
```
