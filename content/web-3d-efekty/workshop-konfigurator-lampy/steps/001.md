# --description--

Postavíš 3D náhled stolní lampy Oblouk pro e-shop studia Světlárna. Zákazník si lampu otočí myší, vybere barvu stínidla, rozsvítí ji a kliknutím na část zjistí, z čeho je. Stránka s popisem, cenou a tlačítky je hotová v `index.html` a `styles.css`. Ty píšeš jen `main.js`.

Celý workshop bude `main.js` **exportovat** hlavní objekty (`export const scene = …`). Hodí se to i v praxi: jiný modul (třeba ovládání nebo analytika) si scénu naimportuje, a v konzoli DevTools ji prozkoumáš přes `await import('./main.js')`. Kontrola kroku přes export zjistí, co ve scéně je.

Začneš tím, co znáš z lekce, bez návodu.

**Úkol:** V `main.js` vytvoř a vyexportuj:

- `renderer` — `WebGLRenderer`, který kreslí do canvasu `.viewer__canvas`, s vyhlazováním hran, **průhledným pozadím** (ať prosvítá přechod z CSS) a s `preserveDrawingBuffer: true`,
- `scene` — prázdnou scénu,
- `camera` — `PerspectiveCamera` se zorným úhlem 35°, `near` 0.1 a `far` 100, postavenou na `(4, 3, 7)` a otočenou do středu scény.

Nakonec spusť render smyčku, která scénu vykresluje pořád dokola.

> [!NOTE]
> `preserveDrawingBuffer: true` nech v kódu po celý workshop. Díky němu jde obsah plátna přečíst i po vykreslení, což potřebuje kontrola kroků. Na produkčním webu ho vynecháš.

Náhled se v tomhle kroku nezmění: prázdná scéna s průhledným pozadím vypadá stejně jako žádná. Lampa se objeví ve třetím kroku.

# --hints--

`main.js` exportuje `renderer`, který kreslí do canvasu `.viewer__canvas`.

```js
const app = await helpers.importFile('main.js');
assert.ok(app.renderer?.isWebGLRenderer, 'main.js má exportovat renderer vytvořený přes new THREE.WebGLRenderer(…)');
assert.equal(app.renderer.domElement, document.querySelector('.viewer__canvas'), 'renderer má kreslit do canvasu .viewer__canvas — předej ho v nastavení jako canvas');
```

Renderer má průhledné pozadí a zachovává obsah plátna (`alpha` a `preserveDrawingBuffer`).

```js
const { renderer } = await helpers.importFile('main.js');
assert.ok(renderer?.isWebGLRenderer, 'main.js má exportovat renderer');
assert.equal(renderer.getClearAlpha(), 0, 'renderer potřebuje alpha: true, aby prosvítalo pozadí .viewer');
assert.equal(renderer.getContext().getContextAttributes().preserveDrawingBuffer, true, 'renderer potřebuje preserveDrawingBuffer: true');
```

`main.js` exportuje `scene` a perspektivní `camera` se zorným úhlem 35°, která stojí na `(4, 3, 7)`.

```js
const { scene, camera } = await helpers.importFile('main.js');
assert.ok(scene?.isScene, 'main.js má exportovat scene vytvořenou přes new THREE.Scene()');
assert.ok(camera?.isPerspectiveCamera, 'main.js má exportovat camera vytvořenou přes new THREE.PerspectiveCamera(…)');
assert.equal(camera.fov, 35, 'kamera má mít zorný úhel (fov) 35');
assert.deepEqual(camera.position.toArray(), [4, 3, 7], 'kamera má stát na souřadnicích (4, 3, 7)');
```

Kamera se dívá do středu scény.

```js
const { camera } = await helpers.importFile('main.js');
const direction = camera.getWorldDirection(camera.position.clone());
const toCenter = camera.position.clone().negate().normalize();
assert.ok(direction.dot(toCenter) > 0.99, 'kamera se má dívat do bodu (0, 0, 0) — natoč ji přes lookAt');
```

Render smyčka vykresluje scénu pořád dokola.

```js
const { renderer } = await helpers.importFile('main.js');
const start = renderer.info.render.frame;
await helpers.waitFor(() => renderer.info.render.frame >= start + 3).catch(() => {});
assert.ok(renderer.info.render.frame >= start + 3, 'renderer má scénu vykreslovat v každém snímku — spusť render smyčku přes setAnimationLoop');
```

# --help--

## --tip--

Všechno potřebné je v části [Scéna, kamera a renderer](see:web-3d-efekty/threejs-zaklady#scena-kamera-a-renderer) a [Render loop a čas snímku](see:web-3d-efekty/threejs-zaklady#render-loop-a-cas-snimku).

## --tip--

Nastavení rendereru se předává jedním objektem: kromě `canvas` v něm budou `antialias`, `alpha` a `preserveDrawingBuffer`. Kameru natočíš metodou `lookAt` s bodem, na který se má dívat.

## --tip--

Kostra, kterou doplníš jmény a hodnotami z úkolu:

```text
// 1. export renderer = nový WebGLRenderer s nastavením
// 2. export scene = nová scéna
// 3. export camera = nová perspektivní kamera, posunutá a natočená
// 4. render smyčka: v každém snímku renderer.render(scéna, kamera)
```

# --solution--

## --file-- main.js

```js
import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```
