# --description--

První část lampy je těžká ocelová podstava — nízký válec, který je dole o kousek širší než nahoře.

Válec vyrobí `CylinderGeometry(radiusTop, radiusBottom, height, radialSegments)`. Poslední číslo je počet stěn po obvodu: 8 dá osmiboký hranol, 48 vypadá jako hladký kruh. Válec má střed uprostřed své výšky, takže když má stát na podlaze (`y = 0`), posuneš ho o půl výšky nahoru.

Každé části dáš `name` a do `userData.label` popisek pro zákazníka. `userData` je prázdný objekt, který Three.js nijak nepoužívá — je tam pro tvoje data. Jméno poslouží k nalezení části v kódu a v konzoli, popisek ukážeš později, až zákazník na část klikne.

Na jiných datech, deska stolu:

```js
const tableTop = new THREE.Mesh(
  new THREE.BoxGeometry(2, 0.08, 1),
  new THREE.MeshStandardMaterial({ color: '#8b5a2b' }),
);
tableTop.name = 'tableTop';
tableTop.userData.label = 'Dubová deska';
tableTop.position.y = 0.04; // polovina výšky
scene.add(tableTop);
```

**Úkol:** Mezi kameru a změnu velikosti přidej mesh podstavy:

- geometrie `CylinderGeometry` s poloměrem 0.9 nahoře, 1 dole, výškou 0.2 a 48 segmenty,
- materiál `MeshStandardMaterial` v barvě `#3a3632`,
- `name` `'base'` a popisek `'Ocelová podstava'`,
- posun nahoru o polovinu výšky, aby stál na `y = 0`,
- přidaný do scény.

> [!PITFALL]
> Podstava bude v náhledu **černá**. Není to chyba v kódu — `MeshStandardMaterial` potřebuje světlo a to přidáš v dalším kroku.

# --hints--

Ve scéně je mesh s `name` `'base'` a geometrií `CylinderGeometry`.

```js
const { scene } = await helpers.importFile('main.js');
const base = scene?.getObjectByName('base');
assert.ok(base?.isMesh, 've scéně má být mesh s name = "base"');
assert.equal(base.geometry.type, 'CylinderGeometry', 'podstava má mít geometrii CylinderGeometry');
const { radiusTop, radiusBottom, height } = base.geometry.parameters;
assert.deepEqual([radiusTop, radiusBottom, height], [0.9, 1, 0.2], 'válec podstavy má mít poloměr 0.9 nahoře, 1 dole a výšku 0.2');
```

Podstava má materiál `MeshStandardMaterial` v barvě `#3a3632`.

```js
const { scene } = await helpers.importFile('main.js');
const base = scene?.getObjectByName('base');
assert.ok(base?.material?.isMeshStandardMaterial, 'podstava má mít materiál MeshStandardMaterial');
assert.equal(base.material.color.getHexString(), '3a3632', 'podstava má mít barvu #3a3632');
```

Podstava stojí na `y = 0` (spodní plocha válce) a má popisek `'Ocelová podstava'`.

```js
const { scene } = await helpers.importFile('main.js');
const base = scene?.getObjectByName('base');
assert.ok(base, 've scéně má být mesh s name = "base"');
const bottom = base.position.y - base.geometry.parameters.height / 2;
assert.ok(Math.abs(bottom) < 0.001, `spodní plocha podstavy má být na y = 0, je na y = ${bottom.toFixed(2)} — posuň válec o polovinu výšky nahoru`);
assert.equal(String(base.userData.label ?? '').normalize('NFC').trim(), 'Ocelová podstava', 'podstava má mít userData.label = "Ocelová podstava"');
```

```js
import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```

## --file-- main.js

```js
import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632' }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
scene.add(base);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```
