# --description--

Stínidlo je polokoule otevřená dolů. `SphereGeometry` umí i výseč koule: posledních pět argumentů jsou úhly `phiStart, phiLength, thetaStart, thetaLength`. `phi` jde kolem svislé osy (celý obvod je `Math.PI * 2`), `theta` shora dolů (od vrcholu po rovník je `Math.PI / 2`).

Otevřená plocha má háček: stěny se standardně kreslí jen z vnější strany. Když se zákazník podívá pod stínidlo, vnitřek by zmizel. Materiál proto potřebuje `side: THREE.DoubleSide`.

Stínidlo musí jít s ramenem. Kam ho přidáš, aby se naklánělo s ním, a kam ho uvnitř posuneš, aby sedělo na horním konci ramene?

**Úkol:** Přidej mesh stínidla:

- polokoule s poloměrem 0.7, 48 × 24 segmenty, otevřená dolů,
- `MeshStandardMaterial` v hořčicové barvě `#e0a526` s `roughness` 0.6 a oboustrannými stěnami,
- `name` `'shade'` a popisek `'Hliníkové stínidlo'`,
- umístěné na horní konec ramene tak, aby se s ramenem naklánělo.

# --hints--

V lampě je mesh `shade` s geometrií `SphereGeometry` o poloměru 0.7, materiálem v barvě `#e0a526` a popiskem `'Hliníkové stínidlo'`.

```js
const { lamp } = await helpers.importFile('main.js');
const shade = lamp?.getObjectByName('shade');
assert.ok(shade?.isMesh, 'v lampě má být mesh s name = "shade"');
assert.equal(shade.geometry.type, 'SphereGeometry', 'stínidlo má mít geometrii SphereGeometry');
assert.equal(shade.geometry.parameters.radius, 0.7, 'stínidlo má mít poloměr 0.7');
assert.equal(shade.material?.color?.getHexString(), 'e0a526', 'stínidlo má mít barvu #e0a526');
assert.equal(String(shade.userData.label ?? '').normalize('NFC').trim(), 'Hliníkové stínidlo', 'stínidlo má mít userData.label = "Hliníkové stínidlo"');
```

Stínidlo je polokoule otevřená dolů.

```js
const { lamp } = await helpers.importFile('main.js');
const shade = lamp?.getObjectByName('shade');
assert.ok(shade, 'v lampě má být mesh s name = "shade"');
const { thetaStart, thetaLength } = shade.geometry.parameters;
assert.ok(thetaStart === 0 && Math.abs(thetaLength - Math.PI / 2) < 0.001, 'stínidlo má být horní polokoule: thetaStart 0 a thetaLength Math.PI / 2');
```

Stínidlo je v větvi `armPivot` a sedí na horním konci ramene.

```js
const { lamp } = await helpers.importFile('main.js');
const pivot = lamp?.getObjectByName('armPivot');
const arm = lamp?.getObjectByName('arm');
const shade = lamp?.getObjectByName('shade');
assert.ok(pivot && arm && shade, 'v lampě má být armPivot, arm i shade');
let node = shade.parent;
while (node && node !== pivot) node = node.parent;
assert.equal(node, pivot, 'stínidlo má být uvnitř skupiny armPivot, aby se naklánělo s ramenem');
lamp.updateWorldMatrix(true, true);
const top = arm.localToWorld(arm.position.clone().set(0, arm.geometry.parameters.height / 2, 0));
const center = shade.getWorldPosition(shade.position.clone());
assert.ok(top.distanceTo(center) < 0.05, `stínidlo je ${top.distanceTo(center).toFixed(2)} od horního konce ramene — v armPivot patří na y = délka ramene`);
```

Materiál stínidla kreslí stěny z obou stran.

```js
const THREE = await import('three');
const { lamp } = await helpers.importFile('main.js');
const shade = lamp?.getObjectByName('shade');
assert.equal(shade?.material?.side, THREE.DoubleSide, 'stínidlo je zespodu otevřené — materiál potřebuje side: THREE.DoubleSide');
```

# --help--

## --tip--

Kam dát stínidlo, vysvětluje [Skupiny: rodič nese své děti](see:web-3d-efekty/threejs-zaklady#skupiny-rodic-nese-sve-deti) — hledáš rodiče, který nese naklonění.

## --tip--

Stínidlo patří do `armPivot`. V souřadnicích `armPivot` začíná rameno v počátku a končí ve výšce své délky. Úhly polokoule: celý obvod, od vrcholu po rovník.

## --tip--

Stejná úvaha u hodin: kulička na konci ručičky dlouhé 0.8 by byla v `handPivot` na `y = 0.8` — `new THREE.SphereGeometry(0.05, 16, 8)` s `position.y` rovnou délce ručičky.

# --explain--

Vysvětli vlastními slovy, proč se stínidlo nakloní s ramenem, i když jsi jeho `rotation` nikde nenastavil.

## --model--

Stínidlo je potomek skupiny `armPivot`, která nese naklonění ramene. Pozice a rotace potomka se počítají v souřadnicích rodiče, takže otočení skupiny otočí celý její souřadnicový systém. Stínidlo tak zůstane na konci ramene a nakloní se s ním, i když jeho vlastní rotace je nulová.

## --checklist--

- Stínidlo je potomek skupiny, která nese naklonění.
- Potomek se počítá v souřadnicích rodiče.
- Otočení rodiče pohne pozicí i natočením potomka.

```js
import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

// Lampa
export const lamp = new THREE.Group();
lamp.position.set(-0.4, -1.4, 0);
scene.add(lamp);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632' }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
lamp.add(base);

const armPivot = new THREE.Group();
armPivot.name = 'armPivot';
armPivot.position.y = 0.2;
armPivot.rotation.z = -0.35;
lamp.add(armPivot);

const arm = new THREE.Mesh(
  new THREE.CylinderGeometry(0.06, 0.06, 2.4, 16),
  new THREE.MeshStandardMaterial({ color: '#3a3632' }),
);
arm.name = 'arm';
arm.userData.label = 'Ohýbané rameno';
arm.position.y = 1.2;
armPivot.add(arm);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```
