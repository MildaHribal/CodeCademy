# --description--

Když zákazník klikne na část lampy, nahoře v náhledu se ukáže její popisek z `userData.label`. Kliknutí do prázdna popisek schová.

Jak zjistit, na co myš v 3D scéně ukazuje? Prohlížeč zná jen pixel na canvasu. Three.js na to má **`Raycaster`**: z kamery vystřelí paprsek skrz bod na obrazovce a vrátí seznam objektů, které paprsek protne, seřazený od nejbližšího. Paprsek potřebuje pozici myši v souřadnicích, kde levý okraj canvasu je −1, pravý 1, **spodní −1 a horní 1** — osa y jde nahoru, kdežto `clientY` v prohlížeči dolů.

Seřaď řádky: nejdřív si připrav `raycaster`, vektor `pointer` pro pozici myši a prvek `label`, pak obsluhu kliknutí. Doplň chybějící hodnotu: druhý argument `intersectObjects` říká, jestli se mají prohledat i potomci skupin. Lampa má části zanořené v `armPivot`. Dva řádky jsou navíc.

Kliknutí na stínidlo ukáže popisek „Hliníkové stínidlo".

```js
const { camera, lamp } = await helpers.importFile('main.js');
const canvas = document.querySelector('.viewer__canvas');
const clickAt = (object, x, y, z) => {
  lamp.updateWorldMatrix(true, true);
  const point = object.localToWorld(object.position.clone().set(x, y, z)).project(camera);
  const rect = canvas.getBoundingClientRect();
  const init = { clientX: rect.left + ((point.x + 1) / 2) * rect.width, clientY: rect.top + ((1 - point.y) / 2) * rect.height, bubbles: true, button: 0, pointerId: 1, isPrimary: true };
  canvas.dispatchEvent(new PointerEvent('pointerdown', init));
  canvas.dispatchEvent(new PointerEvent('pointerup', init));
  canvas.dispatchEvent(new MouseEvent('click', init));
};
const shade = lamp?.getObjectByName('shade');
assert.ok(shade, 'v lampě má být stínidlo');
clickAt(shade, 0, 0.5, 0);
await helpers.flush();
assert.equal(document.querySelector('.viewer__label').textContent.trim(), 'Hliníkové stínidlo', 'po kliknutí na stínidlo má .viewer__label ukázat „Hliníkové stínidlo"');
```

Kliknutí do prázdna popisek vymaže.

```js
const { camera, lamp } = await helpers.importFile('main.js');
const canvas = document.querySelector('.viewer__canvas');
const label = document.querySelector('.viewer__label');
const rect = canvas.getBoundingClientRect();
const fire = (clientX, clientY) => {
  const init = { clientX, clientY, bubbles: true, button: 0, pointerId: 1, isPrimary: true };
  canvas.dispatchEvent(new PointerEvent('pointerdown', init));
  canvas.dispatchEvent(new PointerEvent('pointerup', init));
  canvas.dispatchEvent(new MouseEvent('click', init));
};
const shade = lamp?.getObjectByName('shade');
assert.ok(shade, 'v lampě má být stínidlo');
lamp.updateWorldMatrix(true, true);
const point = shade.localToWorld(shade.position.clone().set(0, 0.5, 0)).project(camera);
fire(rect.left + ((point.x + 1) / 2) * rect.width, rect.top + ((1 - point.y) / 2) * rect.height);
await helpers.flush();
assert.notEqual(label.textContent.trim(), '', 'po kliknutí na stínidlo má být popisek vidět');
fire(rect.left + 10, rect.top + 10);
await helpers.flush();
assert.equal(label.textContent.trim(), '', 'po kliknutí do prázdného rohu náhledu má být .viewer__label prázdný');
```

import * as THREE from 'three';

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();
const label = document.querySelector('.viewer__label');
canvas.addEventListener('click', (event) => {
  const rect = canvas.getBoundingClientRect();
  pointer.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
  pointer.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const [hit] = raycaster.intersectObjects(lamp.children, __1__);
  label.textContent = hit ? hit.object.userData.label : '';
});
