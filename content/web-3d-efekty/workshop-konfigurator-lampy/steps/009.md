# --description--

Zákazník si chce lampu prohlédnout ze všech stran. `OrbitControls` z doplňků Three.js obíhá kamerou kolem bodu, na který se dívá: tažením myší otáčí, kolečkem přibližuje, dvěma prsty na telefonu totéž.

Aby otáčení působilo jemně, zapneš setrvačnost (tlumení). Ta ale funguje, jen když ovládání v každém snímku dostane šanci dopočítat pohyb.

Vyber si, kde co bude: import patří nahoru, vytvoření ovládání za lampu a jeho aktualizace tam, kde se kreslí každý snímek. `OrbitControls` potřebuje kameru a prvek, na kterém poslouchá myš.

**Úkol:** Přidej a vyexportuj `controls` — `OrbitControls` pro kameru, které poslouchá na canvasu náhledu — se zapnutým tlumením (`enableDamping`) a aktualizuj je v render smyčce.

Po splnění zkus v náhledu lampu táhnout myší a pustit: dojede plynule.

# --hints--

Tažení myší po canvasu otočí kameru kolem lampy.

```js
const { camera } = await helpers.importFile('main.js');
const canvas = document.querySelector('.viewer__canvas');
const rect = canvas.getBoundingClientRect();
const before = camera.position.clone();
const pointer = (x) => ({ pointerId: 1, pointerType: 'mouse', isPrimary: true, button: 0, buttons: 1, clientX: rect.left + x, clientY: rect.top + 200, bubbles: true });
canvas.dispatchEvent(new PointerEvent('pointerdown', pointer(200)));
for (let step = 1; step <= 5; step++) canvas.dispatchEvent(new PointerEvent('pointermove', pointer(200 + step * 30)));
canvas.dispatchEvent(new PointerEvent('pointerup', pointer(350)));
await helpers.waitFor(() => camera.position.distanceTo(before) > 0.1).catch(() => {});
assert.ok(camera.position.distanceTo(before) > 0.1, 'po tažení myší po canvasu se má kamera posunout kolem lampy — vytvoř OrbitControls pro kameru a canvas');
```

`main.js` exportuje `controls`, které poslouchají na canvasu náhledu a mají zapnuté tlumení.

```js
const { controls } = await helpers.importFile('main.js');
assert.ok(controls, 'main.js má exportovat controls vytvořené přes new OrbitControls(…)');
assert.ok([document.querySelector('.viewer__canvas'), document.querySelector('.viewer')].includes(controls.domElement), 'controls mají poslouchat myš na canvasu náhledu, ne na celé stránce');
assert.equal(controls.enableDamping, true, 'controls mají mít zapnuté tlumení: enableDamping = true');
```

Po puštění myši kamera ještě chvíli dojíždí (ovládání se aktualizuje v každém snímku).

```js
const { camera } = await helpers.importFile('main.js');
const canvas = document.querySelector('.viewer__canvas');
const rect = canvas.getBoundingClientRect();
const pointer = (x) => ({ pointerId: 1, pointerType: 'mouse', isPrimary: true, button: 0, buttons: 1, clientX: rect.left + x, clientY: rect.top + 200, bubbles: true });
canvas.dispatchEvent(new PointerEvent('pointerdown', pointer(200)));
for (let step = 1; step <= 5; step++) canvas.dispatchEvent(new PointerEvent('pointermove', pointer(200 + step * 30)));
canvas.dispatchEvent(new PointerEvent('pointerup', pointer(350)));
await helpers.wait(50);
const afterRelease = camera.position.clone();
await helpers.waitFor(() => camera.position.distanceTo(afterRelease) > 0.01).catch(() => {});
assert.ok(camera.position.distanceTo(afterRelease) > 0.01, 'po puštění myši má kamera plynule dojet — v render smyčce volej controls.update()');
```

# --help--

## --tip--

Ukázku s `OrbitControls` najdeš v části [Canvas za obsahem a otáčení myší](see:web-3d-efekty/threejs-zaklady#canvas-za-obsahem-a-otaceni-mysi).

## --tip--

Import je z `three/addons/controls/OrbitControls.js`. Konstruktor bere kameru a canvas `.viewer__canvas` (proměnná `canvas`). Tlumení je vlastnost na hotovém objektu. Do funkce v `setAnimationLoop` přidej volání metody `update` před `render`.

## --tip--

Stejná skladba u ovládání pro létání kamerou: `const fly = new FlyControls(camera, canvas); fly.movementSpeed = 5;` a ve smyčce `fly.update(delta)`.

## --file-- main.js

```js
import * as THREE from 'three';
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Prostředí, které odráží kov
scene.environment = new THREE.PMREMGenerator(renderer).fromScene(new RoomEnvironment()).texture;

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

// Lampa
export const lamp = new THREE.Group();
lamp.position.set(-0.4, -1.4, 0);
scene.add(lamp);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632', roughness: 0.35, metalness: 1 }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
lamp.add(base);

const armPivot = new THREE.Group();
armPivot.name = 'armPivot';
armPivot.position.y = 0.2;
armPivot.rotation.z = -0.35;
lamp.add(armPivot);

const arm = new THREE.Mesh(
  new THREE.CylinderGeometry(0.06, 0.06, 2.4, 16),
  new THREE.MeshStandardMaterial({ color: '#3a3632', roughness: 0.35, metalness: 1 }),
);
arm.name = 'arm';
arm.userData.label = 'Ohýbané rameno';
arm.position.y = 1.2;
armPivot.add(arm);

const shade = new THREE.Mesh(
  new THREE.SphereGeometry(0.7, 48, 24, 0, Math.PI * 2, 0, Math.PI / 2),
  new THREE.MeshStandardMaterial({ color: '#e0a526', roughness: 0.6, side: THREE.DoubleSide }),
);
shade.name = 'shade';
shade.userData.label = 'Hliníkové stínidlo';
shade.position.y = 2.4;
armPivot.add(shade);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```
