# --description--

Rameno je tenký a dlouhý válec, který se má naklánět **v kloubu** na podstavě. Mesh se ale otáčí kolem svého středu — kdybys otočil přímo válec ramene, zhoupl by se kolem své poloviny a spodní konec by vyjel z podstavy.

Řešení je kloub ze skupiny:

1. skupina `armPivot` stojí přesně v místě kloubu (na horní ploše podstavy) a nese naklonění,
2. válec ramene je uvnitř skupiny posunutý o **polovinu své délky nahoru** — jeho spodní konec tak leží v počátku skupiny, tedy v kloubu.

Na jiných datech, ručička hodin, která se točí kolem středu ciferníku:

```js
const handPivot = new THREE.Group();
handPivot.position.z = 0.05;     // střed ciferníku
handPivot.rotation.z = -Math.PI / 3;
clock.add(handPivot);

const hand = new THREE.Mesh(new THREE.BoxGeometry(0.04, 0.8, 0.02), handMaterial);
hand.position.y = 0.4;           // polovina délky ručičky
handPivot.add(hand);
```

**Úkol:** Za podstavu přidej:

1. skupinu `armPivot` s `name` `'armPivot'`, postavenou na horní plochu podstavy (`y = 0.2`), nakloněnou o `rotation.z = -0.35` a přidanou do `lamp`,
2. mesh ramene s geometrií `CylinderGeometry(0.06, 0.06, 2.4, 16)`, materiálem `MeshStandardMaterial` v barvě `#3a3632`, `name` `'arm'`, popiskem `'Ohýbané rameno'` a posunem o polovinu délky nahoru, přidaný do `armPivot`.

Z podstavy vyroste šikmé rameno. Zkus pak dočasně změnit `rotation.z` skupiny a sleduj, že spodní konec zůstává na místě.

# --hints--

V lampě je skupina `armPivot` postavená na horní ploše podstavy (`y = 0.2`) a nakloněná o `rotation.z = -0.35`.

```js
const { lamp } = await helpers.importFile('main.js');
const pivot = lamp?.getObjectByName('armPivot');
assert.ok(pivot?.isGroup, 'v lampě má být skupina s name = "armPivot"');
assert.equal(pivot.parent, lamp, 'skupina armPivot má být přidaná přímo do lamp');
assert.ok(Math.abs(pivot.position.y - 0.2) < 0.001, 'skupina armPivot má stát na horní ploše podstavy, na y = 0.2');
assert.ok(Math.abs(pivot.rotation.z + 0.35) < 0.001, 'skupina armPivot má být nakloněná o rotation.z = -0.35');
```

Rameno je válec `CylinderGeometry(0.06, 0.06, 2.4, 16)` s popiskem `'Ohýbané rameno'` uvnitř `armPivot`.

```js
const { lamp } = await helpers.importFile('main.js');
const pivot = lamp?.getObjectByName('armPivot');
const arm = lamp?.getObjectByName('arm');
assert.ok(arm?.isMesh, 'v lampě má být mesh s name = "arm"');
assert.equal(arm.parent, pivot, 'rameno má být přidané do skupiny armPivot');
assert.equal(arm.geometry.type, 'CylinderGeometry', 'rameno má mít geometrii CylinderGeometry');
assert.deepEqual([arm.geometry.parameters.radiusTop, arm.geometry.parameters.height], [0.06, 2.4], 'rameno má mít poloměr 0.06 a délku 2.4');
assert.ok(arm.material?.isMeshStandardMaterial, 'rameno má mít materiál MeshStandardMaterial');
assert.equal(String(arm.userData.label ?? '').normalize('NFC').trim(), 'Ohýbané rameno', 'rameno má mít userData.label = "Ohýbané rameno"');
```

Spodní konec ramene leží přesně v kloubu, i když je rameno nakloněné.

```js
const { lamp } = await helpers.importFile('main.js');
const pivot = lamp?.getObjectByName('armPivot');
const arm = lamp?.getObjectByName('arm');
assert.ok(pivot && arm, 'v lampě má být skupina armPivot a v ní rameno arm');
lamp.updateWorldMatrix(true, true);
const bottom = arm.localToWorld(arm.position.clone().set(0, -arm.geometry.parameters.height / 2, 0));
const joint = pivot.getWorldPosition(pivot.position.clone());
assert.ok(bottom.distanceTo(joint) < 0.01, `spodní konec ramene je ${bottom.distanceTo(joint).toFixed(2)} od kloubu — posuň rameno uvnitř armPivot o polovinu délky nahoru`);
```

## --file-- main.js

```js
import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

// Lampa
export const lamp = new THREE.Group();
lamp.position.set(-0.4, -1.4, 0);
scene.add(lamp);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632' }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
lamp.add(base);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```
