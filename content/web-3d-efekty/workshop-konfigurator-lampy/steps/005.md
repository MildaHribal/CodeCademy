# --description--

Lampa bude mít podstavu, rameno, stínidlo a žárovku. Kdyby byla každá část přímo ve scéně, musel bys při posunu lampy posunout každou zvlášť. Proto celou lampu zabalíš do skupiny `THREE.Group` a části budeš přidávat do ní. Skupina je neviditelná, jen drží děti a předává jim svou pozici a rotaci.

Lampa je zatím v náhledu nízko nad středem. Celá bude vysoká skoro 3 jednotky, takže ji posuneš dolů a trochu doleva, aby se vešla doprostřed.

Na jiných datech, židle ze dvou částí:

```js
export const chair = new THREE.Group();
chair.position.set(0, -1, 0);
scene.add(chair);

seat.position.y = 0.45;
chair.add(seat); // sedák patří židli, ne scéně
```

**Úkol:**

1. Před podstavou vytvoř a vyexportuj skupinu `lamp`, posuň ji na `(-0.4, -1.4, 0)` a přidej ji do scény.
2. Podstavu přidej do `lamp` místo do scény.

Podstava v náhledu klesne dolů.

# --hints--

`main.js` exportuje skupinu `lamp`, která je přímo ve scéně.

```js
const { scene, lamp } = await helpers.importFile('main.js');
assert.ok(lamp?.isGroup, 'main.js má exportovat lamp vytvořenou přes new THREE.Group()');
assert.equal(lamp.parent, scene, 'skupina lamp má být přidaná do scény');
```

Skupina `lamp` stojí na `(-0.4, -1.4, 0)`.

```js
const { lamp } = await helpers.importFile('main.js');
assert.ok(lamp?.isGroup, 'main.js má exportovat skupinu lamp');
assert.deepEqual(lamp.position.toArray(), [-0.4, -1.4, 0], 'skupina lamp má být posunutá na (-0.4, -1.4, 0)');
```

Podstava je v skupině `lamp`, ne přímo ve scéně.

```js
const { scene, lamp } = await helpers.importFile('main.js');
const base = scene?.getObjectByName('base');
assert.ok(base, 've scéně má být podstava s name = "base"');
assert.equal(base.parent, lamp, 'podstava má být přidaná do skupiny lamp (lamp.add), ne do scény');
```

# --explain--

Vysvětli vlastními slovy, proč podstavu přidáváš do skupiny `lamp`, a ne rovnou do scény.

## --model--

Pozice a rotace potomka se počítají vůči rodiči. Když jsou všechny části lampy v jedné skupině, posunu nebo otočím celou lampu jedním řádkem na skupině a části zůstanou na sobě tak, jak mají. Kdyby byly přímo ve scéně, musel bych každou část posouvat zvlášť a hlídat, aby se nerozjely.

## --checklist--

- Pozice potomka se počítá vůči rodiči.
- Posun nebo otočení skupiny pohne všemi jejími částmi.
- Bez skupiny by se každá část musela posouvat zvlášť.

## --file-- main.js

```js
import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632' }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
scene.add(base);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```

import * as THREE from 'three';

const canvas = document.querySelector('.viewer__canvas');
const viewer = document.querySelector('.viewer');

export const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true });
export const scene = new THREE.Scene();
export const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 100);
camera.position.set(4, 3, 7);
camera.lookAt(0, 0, 0);

// Světla
scene.add(new THREE.AmbientLight('#ffffff', 0.4));
const sun = new THREE.DirectionalLight('#ffffff', 1.5);
sun.position.set(3, 6, 4);
scene.add(sun);

// Lampa
export const lamp = new THREE.Group();
lamp.position.set(-0.4, -1.4, 0);
scene.add(lamp);

const base = new THREE.Mesh(
  new THREE.CylinderGeometry(0.9, 1, 0.2, 48),
  new THREE.MeshStandardMaterial({ color: '#3a3632' }),
);
base.name = 'base';
base.userData.label = 'Ocelová podstava';
base.position.y = 0.1;
lamp.add(base);

// Velikost plátna podle prohlížeče
function resize() {
  const width = viewer.clientWidth;
  const height = viewer.clientHeight;
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}
new ResizeObserver(resize).observe(viewer);

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
