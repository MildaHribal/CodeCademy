# --description--

Poslední kus: pod formulář přibude přehled dne — kolik porcí sis zapsal a jaký mají průměr. Zajímavé na něm je, odkud bere data. Nic mu nikdo nepředává; sáhne si do store sám, a přesto ukazuje pořád totéž co seznam nad ním. Tím máš hotové celé počítadlo.

**Úkol:** zaregistruj komponentu `DaySummary`, použij ji v `index.html` jako `<day-summary>` a nech ji vypsat odstavec s třídami `draft summary` ve tvaru `Porcí dnes: 3 · průměr 417 kcal`. Průměr zaokrouhli na celé kalorie, u prázdného dne ať je nula.

Komponenta tentokrát nedostane žádné props. Data si vezme ze store stejnou funkcí jako aplikace — v tom je celý rozdíl proti `MealRow`, které jedno jídlo dostává shora.

## Udělej po svém

Testy skončily, teď je počítadlo tvoje. Nabízí se:

- **Zvýrazni těžká jídla.** V souboru se styly už na to čeká třída `meal--heavy`; zbývá rozhodnout, od kolika kalorií ji řádek dostane.
- **Ulož den do prohlížeče**, ať po obnovení stránky nezmizí. Hodí se na to hlídač, který se spustí po každé změně seznamu, a `localStorage`.
- **Seřaď jídla od nejtěžšího**, nebo si přidej přepínač mezi pořadím zápisu a pořadím podle kalorií.
- **Přeměň to na téma, které tě zajímá** — výdaje za den s měsíčním rozpočtem, ujeté kilometry, odehrané hodiny. Data i popisky změníš, kostra zůstane.

Odsud vede cesta rovnou do labu: tam postavíš košík e-shopu, kde ti seznam, odvozený součet i sdílený store poslouží znovu — jen bez návodu.

Registrace druhé komponenty vypadá přesně jako ta první z kroku 013. Liší se jen tím, co komponenta dostává zvenčí.

## --tip-- 1

Komponenta má taky `setup()`. Co v něm vrátíš, to uvidí její šablona — a sáhnout si do store v něm můžeš stejně jako v aplikaci.

## --tip-- 2

Dělení nulou dá `NaN`, takže prázdný den potřebuje vlastní větev. Zaokrouhlení obstará `Math.round`.

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';
import { useMeals } from './store.js';

let nextId = 4;

const app = createApp({
  setup() {
    const { meals, total } = useMeals();

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

    const remainingLabel = computed(() =>
      isOver.value
        ? `Překročeno o ${total.value - limit.value} kcal`
        : `Zbývá ${limit.value - total.value} kcal`,
    );

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, remainingLabel, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
});

app.component('MealRow', {
  props: { meal: { type: Object, required: true } },
  emits: ['remove'],
  template: `
    <li class="meal">
      <span class="meal__name">{{ meal.name }}</span>
      <span class="meal__kcal">{{ meal.kcal }} kcal</span>
      <button
        class="meal__remove"
        type="button"
        :aria-label="'Smazat ' + meal.name"
        @click="$emit('remove', meal.id)"
      >×</button>
    </li>
  `,
});

--edit--
--edit--
app.mount('#app');
```

## --file-- store.js

```js
import { computed, ref } from 'vue';

// Jídla dnešního dne. Store je obyčejný modul: co v něm vznikne, žije mimo komponenty,
// takže se k tomu dostane kdokoli, kdo si o to řekne.
const dnesniJidla = [
  { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
  { id: 2, name: 'Kuřecí salát', kcal: 530 },
  { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
];

const meals = ref(dnesniJidla);
export function useMeals() {
  const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));
  return { meals, total };
}
```

      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, remainingLabel, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },

app.component('MealRow', {
  props: { meal: { type: Object, required: true } },
  emits: ['remove'],
  template: `
    <li class="meal">
      <span class="meal__name">{{ meal.name }}</span>
      <span class="meal__kcal">{{ meal.kcal }} kcal</span>
      <button
        class="meal__remove"
        type="button"
        :aria-label="'Smazat ' + meal.name"
        @click="$emit('remove', meal.id)"
      >×</button>
    </li>
  `,
});

app.component('DaySummary', {
  setup() {
    const { meals, total } = useMeals();
    const average = computed(() => (meals.value.length === 0 ? 0 : Math.round(total.value / meals.value.length)));
    return { meals, average };
  },

    <p class="draft summary">Porcí dnes: {{ meals.length }} · průměr {{ average }} kcal</p>

});
