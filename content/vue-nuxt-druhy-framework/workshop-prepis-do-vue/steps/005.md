# --description--

Po kliknutí na svačinu zůstává patička na 1250 kcal. Součet se spočítal jednou při startu a od té doby je to obyčejné číslo. Tímhle krokem začne patička reagovat.

**Úkol:** udělej ze součtu odvozenou hodnotu, která se přepočítá pokaždé, když se seznam změní.

Odvozená hodnota není stav. Neukládá se, počítá se ze seznamu — a Vue si samo zapamatuje, že ten seznam čte.

Na jiných datech:

```js
const longest = computed(() => Math.max(...trips.value.map((trip) => trip.minutes)));
```

V šabloně se s odvozenou hodnotou pracuje stejně jako dřív, měnit ji nemusíš.

# --help--

## --tip--

Hodnota, kterou odvozuješ z jiných reaktivních dat, má ve Vue vlastní funkci. Najdeš ji v části [computed se počítá, jen když je potřeba](see:vue-nuxt-druhy-framework/reaktivita-vue#computed-se-pocita-jen-kdyz-je-potreba).

## --tip-- 2

Ta funkce dostane funkci bez parametrů, která hodnotu vrátí, a je potřeba ji doimportovat z `vue`.

## --tip-- 2

Stejný tvar na jiných datech: `const count = computed(() => trips.value.length);`.

# --explain--

Vysvětli vlastními slovy, proč se součet v původní podobě nikdy nezměnil, i když se pole `meals` doopravdy měnilo.

## --model--

`meals.value.reduce(…)` proběhlo jednou při běhu `setup()` a vrátilo obyčejné číslo. Šablona pak vypisovala to číslo, ne výpočet — a číslo se nemá jak změnit. Teprve `computed` udělá z výpočtu efekt: Vue si při prvním běhu zapamatuje, že funkce četla `meals`, a po každé změně seznamu ji spustí znovu.

## --checklist--

- `setup()` proběhne jednou, takže jednorázový výpočet skončí obyčejnou hodnotou.
- Šablona vypisovala výsledek, ne předpis, jak ho spočítat.
- `computed` si zapamatuje, které reaktivní hodnoty jeho funkce četla.
- Po změně těch hodnot se výpočet spustí znovu a šablona dostane nový výsledek.

# --solution--

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    return { total, meals, addSnack };
  },
}).mount('#app');
```
