# --description--

Jedno tlačítko na jablko je málo — počítadlo musí umět zapsat cokoli. Tímhle krokem přibude pod seznam formulář a pod ním řádek, který se mění **při každém stisku klávesy**. Zapisovat se ještě nebude, to přijde hned potom.

**Úkol:** doplň do stránky formulář `<form class="add">` se dvěma poli (název a kalorie) a tlačítkem, a pod něj odstavec `<p class="draft">`, ve kterém průběžně stojí, co se zapíše.

Postup má dvě části:

```js
// 1. Pro každé pole jeden kus stavu
const mesto = ref('');
const nocu = ref(1);
// 2. Popisek, který se z nich odvodí
const shrnuti = computed(() => `${mesto.value} na ${nocu.value} nocí`);
```

Pole se stavem propojíš tak, aby psaní měnilo stav a stav zase hodnotu v poli — ve Vue je na to jedna direktiva místo dvojice `value` a `onChange`. U číselného pole nezapomeň na modifikátor, jinak z něj vypadne text.

Dokud je název prázdný, ať odstavec říká něco jako „Zatím nic nepíšeš."; jinak jméno jídla a počet kalorií.

Aby se formulář po stisku Enter nepokusil odeslat stránku, napiš na něj `@submit.prevent`.

# --hints--

Formulář má textové pole, číselné pole a pod ním je odstavec `.draft`.

```js
const form = document.querySelector('.add');
assert.ok(form, 've stránce má být formulář s třídou add');
assert.ok(form.querySelector('input[type="text"]'), 've formuláři má být textové pole na název jídla');
assert.ok(form.querySelector('input[type="number"]'), 've formuláři má být číselné pole na kalorie');
assert.ok(document.querySelector('.draft'), 'pod formulářem má být odstavec s třídou draft');
```

Odstavec `.draft` se mění při psaní názvu.

```js
const nazev = document.querySelector('.add input[type="text"]');
const pred = document.querySelector('.draft').textContent;
await helpers.type(nazev, 'Jablečný závin');
await helpers.flush();
const po = document.querySelector('.draft').textContent;
assert.notEqual(po.trim(), pred.trim(), 'odstavec .draft se má při psaní změnit');
assert.match(po, /Jablečný závin/, 'odstavec .draft má ukázat právě napsaný název');
```

V odstavci je i zadaný počet kalorií a obě pole jsou navázaná direktivou, ne ručně.

```js
await helpers.type(document.querySelector('.add input[type="text"]'), 'Jablečný závin');
await helpers.type(document.querySelector('.add input[type="number"]'), '250');
await helpers.flush();
assert.match(document.querySelector('.draft').textContent, /250/, 'odstavec .draft má ukázat i zadané kalorie');
assert.match(files['index.html'], /v-model/, 'pole formuláře navaž direktivou v-model, ne ručním :value a @input');
```

# --help--

## --tip--

Řízené pole se ve Vue nepíše jako dvojice atributů. Je na to jedna direktiva — najdeš ji v části [Formuláře: v-model místo řízeného pole](see:vue-nuxt-druhy-framework/prevodni-tabulka#formulare-v-model-misto-rizeneho-pole).

## --tip-- 1

Každé pole potřebuje vlastní kus stavu v `setup()` a obojí musí `setup()` vrátit, jinak na to šablona nedosáhne.

## --tip-- 3

Prohlížeč vrací z `<input>` vždy text, i z toho číselného. Direktiva má na to modifikátor, který se píše tečkou za jejím jménem.

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    return { total, meals, addSnack, removeMeal, draftName, draftKcal, draftLabel };
  },
}).mount('#app');
```
