# --description--

Šablona v `index.html` roste a řádek jídla je v ní nejsložitější kus. Tímhle krokem se z něj stane samostatná komponenta `MealRow` — stejná věc, jakou v Reactu děláš pořád, jen s jinými slovy. Na obrazovce se nesmí změnit vůbec nic; změní se to, kde ten kód bydlí.

**Úkol:** zaregistruj komponentu `MealRow`, která dostane jedno jídlo v props a vykreslí z něj celý `<li>`. V `index.html` ji použij v cyklu pod jménem `<meal-row>`.

Bez sestavovacího nástroje se komponenta píše jako objekt s vlastností `template`; v ostrém projektu by to byl soubor `MealRow.vue`. Aby šlo `app.component(…)` zavolat, ulož si aplikaci do proměnné a připoj ji až nakonec:

```js
const app = createApp({ setup() { /* … */ } });
app.component('TripCard', { props: { trip: Object }, template: `<li>{{ trip.city }}</li>` });
app.mount('#vylety');
```

Křížek uvnitř komponenty ale nesmí sahat do seznamu sám — seznam do komponenty nepatří. Místo toho vyšle ven událost s `id` jídla a rodič si ve své obsluze rozhodne, co s tím. V šabloně komponenty se na to hodí `$emit`, v `index.html` událost odchytíš stejnou direktivou jako kliknutí.

> [!NOTE]
> V šabloně psané přímo v HTML nefunguje zápis `<MealRow>` — prohlížeč značky nerozlišuje velikostí písmen. Proto se komponenta v `index.html` píše s pomlčkou a párově.

# --help--

## --tip--

Jak se v přepisu z Reactu do Vue mění props a zpětné volání, máš v části [Props a události](see:vue-nuxt-druhy-framework/prevodni-tabulka#props-a-udalosti). Pravidlo zní: data dolů, oznámení nahoru.

## --tip-- 3

Aby se `app.component(…)` dalo zavolat, nesmí být `createApp(…)` hned připojené — nejdřív aplikace do proměnné, pak registrace, až potom připojení.

## --tip-- 4

V šabloně komponenty je `$emit` k dispozici sám od sebe. Jméno události si vymyslíš a rodič ho pak použije v direktivě se zavináčem.

# --explain--

Vysvětli vlastními slovy, proč komponenta `MealRow` seznam jídel sama nemění, i když je tlačítko na smazání uvnitř ní.

## --model--

Komponenta dostává jedno jídlo v props a props jsou jen ke čtení — na seznam, ve kterém to jídlo leží, vůbec nevidí. Kdyby do něj sahala, musela by o něm vědět, a stala by se tím použitelná jen v téhle jedné aplikaci. Místo toho jen oznámí, co se stalo („na tomhle řádku někdo klikl na smazat, tady je jeho id"), a rozhodnutí nechá na rodiči. Ten seznam vlastní, takže ví, co s tím. Díky tomu jde ta samá komponenta použít i tam, kde smazání znamená něco jiného — třeba přesun do historie.

## --checklist--

- Props jsou jen ke čtení, potomek do nich nezapisuje.
- Komponenta nevidí na seznam, vidí jen na jedno jídlo.
- Událost je oznámení „stalo se tohle", ne příkaz „smaž to".
- Rozhoduje ten, kdo data vlastní — rodič.

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

    const remainingLabel = computed(() =>
      isOver.value
        ? `Překročeno o ${total.value - limit.value} kcal`
        : `Zbývá ${limit.value - total.value} kcal`,
    );

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, remainingLabel, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
--edit--
}).mount('#app');
--edit--
```

```js
    );

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,

app.component('MealRow', {
  props: { meal: { type: Object, required: true } },
  emits: ['remove'],
  template: `
    <li class="meal">
      <span class="meal__name">{{ meal.name }}</span>
      <span class="meal__kcal">{{ meal.kcal }} kcal</span>
      <button
        class="meal__remove"
        type="button"
        :aria-label="'Smazat ' + meal.name"
        @click="$emit('remove', meal.id)"
      >×</button>
    </li>
  `,
});
```
