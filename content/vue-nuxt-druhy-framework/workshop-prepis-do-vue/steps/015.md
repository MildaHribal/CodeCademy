# --description--

Store je hotový, ale aplikace ho nezná a pořád si drží vlastní seznam. Po tomhle kroku bude jediným vlastníkem dat `store.js` — a na obrazovce se přitom nesmí změnit nic. Právě to je na téhle změně to podstatné.

**Úkol:** naimportuj do `app.js` funkci ze store, vezmi si z ní seznam i součet a vlastní seznam a vlastní výpočet součtu z `setup()` odstraň. Všechno ostatní — svačina, mazání, formulář, limit i popisek — zůstává, jak je.

Importuj z `./store.js`; přípona v prohlížeči povinná je, na rozdíl od projektu s Vite.

Až budeš hotový, projdi si aplikaci: nic z toho, co umí, se nesmí rozbít. Když se něco rozbije, je to skoro vždy tím, že se z importu vzalo míň, než co `setup()` vrací šabloně.

# --help--

## --tip--

Import z vlastního souboru vypadá jako import z `vue`, jen místo jména balíčku je cesta začínající tečkou a lomítkem.

## --tip-- 3

Funkce ze store vrací objekt. Rozbalením do proměnných dostaneš krabičky, ne jejich obsah — a to je přesně to, co šablona potřebuje.

## --tip-- 1

Co `setup()` vrací, to šablona vidí. Návratový objekt tedy musí zůstat stejně bohatý jako předtím.

# --explain--

Vysvětli vlastními slovy, proč seznam jídel funguje stejně, i když teď vzniká v úplně jiném souboru a mimo jakoukoli komponentu.

## --model--

Reaktivita ve Vue nevisí na komponentě, ale na té krabičce. `ref` vyrobí objekt, který si u každé vlastnosti pamatuje, které efekty ji četly, a po zápisu je spustí. Kde ten objekt vznikl, je jedno — důležité je, že komponenta při vykreslení četla jeho obsah, a tím se u něj zapsala. Proto stačí, aby si obě strany předaly tutéž krabičku. Kdyby seznam vznikal až uvnitř `useMeals()`, dostal by každý volající vlastní objekt a sdílení by skončilo.

## --checklist--

- Reaktivita patří té krabičce, ne komponentě.
- Komponenta se u hodnoty zapsala tím, že ji při vykreslení četla.
- Sdílení funguje, dokud si obě strany předávají tentýž objekt.
- Kdyby data vznikala uvnitř funkce, měl by každý volající vlastní kopii.

import { createApp, ref, computed } from 'vue';

let nextId = 4;

const app = createApp({
  setup() {
--edit--
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));
--edit--

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

    const remainingLabel = computed(() =>
      isOver.value
        ? `Překročeno o ${total.value - limit.value} kcal`
        : `Zbývá ${limit.value - total.value} kcal`,
    );

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.

## --file-- store.js

```js
import { computed, ref } from 'vue';

// Jídla dnešního dne. Store je obyčejný modul: co v něm vznikne, žije mimo komponenty,
// takže se k tomu dostane kdokoli, kdo si o to řekne.
const dnesniJidla = [
  { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
  { id: 2, name: 'Kuřecí salát', kcal: 530 },
  { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
];

const meals = ref(dnesniJidla);
export function useMeals() {
  const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));
  return { meals, total };
}
```
