# --description--

Seznam jídel zatím vzniká uvnitř `setup()`, takže patří jedné jediné komponentě. Jakmile ho bude chtít i druhá, musí data bydlet jinde — ve **store**. Tenhle krok store napíše; v tom dalším ho zapojíš a přehled dne z něj bude číst tatáž data jako seznam.

**Úkol:** seřaď řádky v novém souboru `store.js` tak, aby vznikl modul, který drží seznam jídel a nabízí k němu i součet. Do mezer doplň jména dvou funkcí z Vue. Odsazení nastavíš klávesou Tab, dva řádky jsou navíc.

Trik je v tom, **kde** data vzniknou. Kdyby seznam vznikal uvnitř `useMeals()`, dostal by každý, kdo si funkci zavolá, vlastní kopii — a dvě komponenty by si pak každá počítala svůj den. Musí tedy vzniknout o úroveň výš, v modulu samotném, a funkce k němu jen dává přístup.

> [!NOTE]
> Přesně tenhle vzor má ve Vue vlastní knihovnu — [[Pinia]]. Ta k němu přidá jméno store, nástroje pro ladění a pár pojistek, ale jádro zůstává tohle: reaktivní data v modulu a funkce, která je vydá. Potkáš ji v lekci o SFC a Pinii.
>
> Náhled se tímhle krokem ještě nezmění — `store.js` zatím nikdo neimportuje.

# --hints--

Modul `store.js` vyváží funkci `useMeals`, která vydá seznam i součet.

```js
const store = await helpers.importFile('store.js');
assert.equal(typeof store.useMeals, 'function', 'store.js má vyvážet funkci useMeals');
const { meals, total } = store.useMeals();
assert.ok(meals && 'value' in meals, 'useMeals() má vrátit seznam jako reaktivní krabičku');
assert.equal(meals.value.length, 3, 'den začíná třemi jídly');
assert.equal(total.value, 1250, 'součet tří jídel je 1250 kcal');
```

Součet se přepočítá po každé změně seznamu.

```js
const { meals, total } = (await helpers.importFile('store.js')).useMeals();
meals.value.push({ id: 9, name: 'Jablko', kcal: 95 });
assert.equal(total.value, 1345, 'po přidání jablka má součet vyrůst na 1345 kcal');
meals.value = meals.value.filter((meal) => meal.id !== 2);
assert.equal(total.value, 815, 'po smazání kuřecího salátu má součet klesnout na 815 kcal');
```

Dvě volání `useMeals()` sdílejí tatáž data.

```js
const store = await helpers.importFile('store.js');
const seznam = store.useMeals();
const prehled = store.useMeals();
seznam.meals.value.push({ id: 9, name: 'Jablko', kcal: 95 });
assert.equal(prehled.total.value, 1345, 'druhé volání useMeals() má vidět stejný seznam — data patří modulu, ne volání');
assert.equal(prehled.meals.value.length, 4, 'obě volání mají ukazovat na tentýž seznam');
```

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

const app = createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

    const remainingLabel = computed(() =>
      isOver.value
        ? `Překročeno o ${total.value - limit.value} kcal`
        : `Zbývá ${limit.value - total.value} kcal`,
    );

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, remainingLabel, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
});

app.component('MealRow', {
  props: { meal: { type: Object, required: true } },
  emits: ['remove'],
  template: `
    <li class="meal">
      <span class="meal__name">{{ meal.name }}</span>
      <span class="meal__kcal">{{ meal.kcal }} kcal</span>
      <button
        class="meal__remove"
        type="button"
        :aria-label="'Smazat ' + meal.name"
        @click="$emit('remove', meal.id)"
      >×</button>
    </li>
  `,
});

app.mount('#app');
```
