# --description--

Počítadlo zatím jen sčítá. Po tomhle kroku si uživatel nastaví denní limit a patička **zčervená** ve chvíli, kdy ho součet přesáhne — okamžitá zpětná vazba bez jediného tlačítka navíc.

**Úkol:** přidej do hlavičky číselné pole s denním limitem (výchozí hodnota 2000) a nech patičku dostat třídu `card__foot--over`, jakmile je součet nad limitem.

Styly pro obojí v souboru připravené jsou — `.limit` pro popisek s polem v hlavičce a `.card__foot--over` pro zvýrazněnou patičku. Tvoje práce je dodat data a rozhodnutí.

Třída se na prvek přidává podmíněně objektem, kde klíč je jméno třídy a hodnota rozhoduje, jestli se použije:

```html
<article class="trip" :class="{ 'trip--full': obsazeno }"></article>
```

Statická třída na prvku může zůstat vedle toho podmíněného zápisu, Vue obojí spojí.

# --hints--

V hlavičce je číselné pole s limitem a při 1250 kcal patička zvýrazněná není.

```js
const pole = document.querySelector('.limit input');
assert.ok(pole, 'v hlavičce má být číselné pole s denním limitem uvnitř popisku .limit');
assert.equal(Number(pole.value), 2000, 'pole má po startu ukazovat výchozí limit 2000');
const paticka = document.querySelector('.card__foot');
assert.ok(!paticka.classList.contains('card__foot--over'), 'při 1250 kcal a limitu 2000 nemá být patička zvýrazněná');
```

Po snížení limitu pod součet patička zvýraznění dostane.

```js
await helpers.type(document.querySelector('.limit input'), '1000');
await helpers.flush();
assert.ok(document.querySelector('.card__foot').classList.contains('card__foot--over'), 'při limitu 1000 a součtu 1250 má patička dostat třídu card__foot--over');
assert.ok(document.querySelector('.card__foot').classList.contains('card__foot'), 'původní třída card__foot má na patičce zůstat');
```

Zvýraznění zase zmizí — jak po zvýšení limitu, tak po smazání jídla.

```js
const pole = document.querySelector('.limit input');
await helpers.type(pole, '1000');
await helpers.flush();
await helpers.type(pole, '3000');
await helpers.flush();
assert.ok(!document.querySelector('.card__foot').classList.contains('card__foot--over'), 'po zvýšení limitu na 3000 má zvýraznění zmizet');
await helpers.type(pole, '1000');
await helpers.flush();
await helpers.click(document.querySelector('.meal__remove'));
await helpers.click(document.querySelector('.meal__remove'));
await helpers.flush();
assert.ok(!document.querySelector('.card__foot').classList.contains('card__foot--over'), 'po smazání dvou jídel se má počítadlo zase vejít do limitu');
```

# --help--

## --tip--

Limit je stav, který uživatel mění — patří tedy do krabičky. To, jestli je den překročený, se z něj dá odvodit, takže na to vlastní krabičku nezakládej.

## --tip-- 1

Pole limitu se navazuje stejnou direktivou jako pole ve formuláři, včetně modifikátoru pro čísla. Popisek `.limit` může pole obalit, pak nepotřebuje `for`.

## --tip-- 2

Na patičce už jedna třída je. Druhá, podmíněná, se píše zvlášť atributem s dvojtečkou a objektem `{ 'jméno-třídy': podmínka }`.

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

--edit--
--edit--
    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
}).mount('#app');
```

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
}).mount('#app');
```
