# --description--

Teď totéž, ale ať to za tebe dělá Vue. Od tohohle kroku už do stránky nezapisuješ ručně — píšeš jen data a šablonu.

**Úkol:** nech součet do patičky vypsat Vue místo `textContent`.

Vue potřebuje dvě věci: kořenový prvek, do kterého bude vykreslovat (`#app` v seedu je), a aplikaci, která mu řekne, jaká data tam patří. V šabloně se hodnota vypisuje dvojitými složenými závorkami, takže do patičky napiš `{{ total }} kcal`.

Na jiných datech:

```js
import { createApp } from 'vue';

createApp({
  setup() {
    const city = 'Brno';
    return { city };            // co vrátíš, to šablona uvidí
  },
}).mount('#app');
```

Ruční `document.querySelector` z minulého kroku smaž.

# --hints--

Patička pořád ukazuje `1250 kcal`, ale text do ní vypisuje šablona Vue.

```js
assert.match(document.querySelector('#total').textContent, /1250\s*kcal/, '#total má vypsat „1250 kcal“');
assert.match(files['index.html'], /\{\{\s*total\s*\}\}/, 'index.html má v patičce vypisovat {{ total }}');
```

Aplikace Vue je připojená na `#app`.

```js
assert.ok(document.querySelector('#app').__vue_app__, 'na prvku #app má být připojená aplikace Vue (createApp(…).mount(\'#app\'))');
```

# --help--

## --tip--

Aplikaci zakládá `createApp` z balíčku `vue` a připojuje ji metoda `mount` se selektorem kořenového prvku. Zopakuj si [šablonu místo JSX](see:vue-nuxt-druhy-framework/prevodni-tabulka#sablona-misto-jsx).

## --tip-- 1

Do `#total` nepiš nic z JavaScriptu. Text patří do `index.html` a hodnota se do něj dostane dvojitými složenými závorkami.

## --file-- app.js

```js
import { createApp } from 'vue';

const meals = [
  { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
  { id: 2, name: 'Kuřecí salát', kcal: 530 },
  { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
];

createApp({
  setup() {
    const total = meals.reduce((sum, meal) => sum + meal.kcal, 0);
    return { total };
  },
}).mount('#app');
```
