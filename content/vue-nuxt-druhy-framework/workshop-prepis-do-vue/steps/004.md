# --description--

Seznam se vypisuje, ale je zamrzlý — `meals` je obyčejné pole, o jehož změně by se Vue nedozvědělo. Tímhle krokem přibude tlačítko, kterým si zapíšeš svačinu, a seznam na kliknutí zareaguje.

**Úkol:** udělej z `meals` reaktivní hodnotu uvnitř `setup()` a přidej obsluhu `addSnack`, která do seznamu přidá jablko (95 kcal). V `index.html` přidej nad patičku tlačítko s třídou `snack`, které obsluhu zavolá.

Nové jídlo potřebuje vlastní `id`. V seedu je na to připravený čítač `nextId`, který stačí použít a zvýšit.

Na jiných datech:

```js
const trips = ref([{ id: 1, city: 'Brno' }]);
const addTrip = () => {
  trips.value.push({ id: nextId++, city: 'Zlín' });
};
```

> [!NOTE]
> Součet v patičce se po kliknutí nezmění — pořád ukazuje 1250. To je správně: spočítal se jednou při startu. Spravíš to v dalším kroku.

# --hints--

Tlačítko `.snack` je ve stránce a po kliknutí přibude v seznamu čtvrtá položka.

```js
const button = document.querySelector('.snack');
assert.ok(button, 've stránce má být tlačítko s třídou snack');
await helpers.click(button);
await helpers.flush();
assert.equal(document.querySelectorAll('.meals .meal').length, 4, 'po kliknutí má být v seznamu čtvrtá položka');
```

Přidaná položka je jablko za 95 kcal.

```js
await helpers.click(document.querySelector('.snack'));
await helpers.flush();
const rows = [...document.querySelectorAll('.meals .meal')];
const last = rows.at(-1);
assert.match(last.querySelector('.meal__name').textContent, /[Jj]ablko/, 'poslední položka má být jablko');
assert.match(last.querySelector('.meal__kcal').textContent, /95\s*kcal/, 'jablko má mít 95 kcal');
```

Dvě kliknutí zapíšou dvě svačiny, každou s vlastním klíčem.

```js
const before = document.querySelectorAll('.meals .meal').length;
await helpers.click(document.querySelector('.snack'));
await helpers.click(document.querySelector('.snack'));
await helpers.flush();
assert.equal(document.querySelectorAll('.meals .meal').length, before + 2, 'po dvou kliknutích mají v seznamu přibýt dvě položky');
```

# --help--

## --tip--

Pole uvnitř `setup()` musí být v krabičce, o které Vue ví — jinak se o změně nedozví. Podívej se na [ref a .value](see:vue-nuxt-druhy-framework/reaktivita-vue#ref-je-krabicka-s-value).

## --tip-- 1

Mimo šablonu se k obsahu krabičky dostaneš přes `.value`. Metoda `push` se tedy volá na tom, co je uvnitř.

## --tip-- 3

Obsluha se v šabloně připojuje zavináčem: `@click="jmenoObsluhy"`. Tlačítko patří mezi seznam a patičku.

## --file-- app.js

```js
import { createApp, ref } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = meals.value.reduce((sum, meal) => sum + meal.kcal, 0);

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    return { total, meals, addSnack };
  },
}).mount('#app');
```
