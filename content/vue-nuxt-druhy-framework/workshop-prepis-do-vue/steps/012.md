# --description--

Patička ukazuje součet a umí zčervenat, ale číslo, které uživatele zajímá nejvíc, tam chybí: **kolik ještě může sníst**. Po tomhle kroku bude v patičce vlevo místo nápisu „Celkem dnes" živý popisek, který se mění se seznamem i s limitem.

**Úkol:** nahraď levý text v patičce prvkem s třídou `remaining`, ve kterém stojí buď `Zbývá 750 kcal`, nebo — když je den překročený — `Překročeno o 250 kcal`. Čísla jsou rozdíl limitu a součtu, vždy kladná.

Tenhle krok ti neříká, čím to napsat. Všechno potřebné už v souboru je a vybrat nástroj je teď na tobě: rozmysli si, jestli popisek patří mezi data, která si aplikace pamatuje, nebo mezi to, co si kdykoli dopočítá.

Kontrola, jestli jsi vybral dobře: až v dalších krocích seznam přestane vznikat tam, kde vzniká teď, nesmí se kvůli popisku měnit nic.

# --hints--

Při startu je v patičce vlevo, kolik kalorií ještě zbývá.

```js
const popisek = document.querySelector('.card__foot .remaining');
assert.ok(popisek, 'v patičce má být prvek s třídou remaining');
assert.match(popisek.textContent, /Zbývá\s*750\s*kcal/, 'při součtu 1250 a limitu 2000 má v patičce stát „Zbývá 750 kcal“');
```

Popisek se mění se seznamem.

```js
await helpers.click(document.querySelector('.snack'));
await helpers.flush();
assert.match(document.querySelector('.remaining').textContent, /Zbývá\s*655\s*kcal/, 'po jablku za 95 kcal má zbývat 655 kcal');
await helpers.click(document.querySelector('.meal__remove'));
await helpers.flush();
assert.match(document.querySelector('.remaining').textContent, /Zbývá\s*1075\s*kcal/, 'po smazání ovesné kaše (420 kcal) má zbývat 1075 kcal');
```

Po překročení limitu se popisek přepne a číslo zůstane kladné.

```js
await helpers.type(document.querySelector('.limit input'), '1000');
await helpers.flush();
const text = document.querySelector('.remaining').textContent;
assert.match(text, /Překročeno o\s*250\s*kcal/, 'při limitu 1000 a součtu 1250 má v patičce stát „Překročeno o 250 kcal“');
assert.ok(!text.includes('-'), 'překročení se hlásí kladným číslem, ne mínusem');
```

# --help--

## --tip--

Začni otázkou, jestli je popisek nová informace, nebo jen jiný pohled na to, co už aplikace ví. Odpověď rozhodne, kam v `setup()` patří.

## --tip-- 3

Podmínku, která rozlišuje obě věty, máš v souboru hotovou už od minulého kroku — ta samá, která zvýrazňuje patičku.

## --tip-- 3

Text se skládá z kusů a čísla, takže se hodí šablonový řetězec v backticích, do kterého se hodnota vloží přes `${ }`.

import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

--edit--
--edit--
    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
}).mount('#app');

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const limit = ref(2000);
    const isOver = computed(() => total.value > limit.value);

    const remainingLabel = computed(() =>
      isOver.value
        ? `Překročeno o ${total.value - limit.value} kcal`
        : `Zbývá ${limit.value - total.value} kcal`,
    );

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      // Od kolegy: ať se do seznamu nedostane prázdný řádek.
      if (!draftName.value.trim()) return;
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, limit, isOver, remainingLabel, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
}).mount('#app');
```
