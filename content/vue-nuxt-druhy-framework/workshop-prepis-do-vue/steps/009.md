# --description--

Smaž všechna tři jídla a zůstane po nich prázdné místo — vypadá to jako rozbitá stránka. Po tomhle kroku se místo prázdného seznamu ukáže věta, která uživateli řekne, co má udělat.

**Úkol:** nech seznam vykreslit jen tehdy, když v něm nějaké jídlo je. Jinak ať se na jeho místě ukáže odstavec `<p class="empty">` s vlastní větou.

Vue na to má dvojici direktiv: jedna prvek podmíněně vytvoří, druhá se na ni váže jako `else`. Musí být na sousedních prvcích, mezi nimi nesmí nic být.

Na jiných datech:

```html
<table v-if="trips.length" class="trips"></table>
<p v-else class="empty">Zatím žádný výlet.</p>
```

> [!NOTE]
> Tohle je něco jiného než schování stylem. Když podmínka neplatí, prvek v DOMu vůbec není — což si za chvíli ověříš testem.

Tady máš hotové počítadlo, které umí zapsat, smazat i spočítat celý den. Klidně si dej pauzu; zbytek workshopu na něm staví, ale tenhle stav sám o sobě stojí.

# --hints--

Dokud jsou v seznamu jídla, ukazuje se seznam a věta o prázdném dni ne.

```js
assert.ok(document.querySelector('.meals'), 'se třemi jídly se má vykreslit seznam');
assert.ok(!document.querySelector('.empty'), 'dokud je co ukazovat, odstavec .empty ve stránce být nemá');
```

Po smazání všech jídel seznam z DOMu zmizí a nastoupí odstavec `.empty`.

```js
for (let i = 0; i < 10 && document.querySelector('.meal__remove'); i += 1) {
  await helpers.click(document.querySelector('.meal__remove'));
  await helpers.flush();
}
assert.ok(!document.querySelector('.meals'), 'prázdný seznam se nemá vykreslit vůbec, ne jen schovat');
const prazdno = document.querySelector('.empty');
assert.ok(prazdno, 'místo seznamu má být odstavec s třídou empty');
assert.ok(prazdno.textContent.trim().length > 0, 'odstavec .empty má mít vlastní text');
```

Po zápisu prvního jídla se seznam vrátí a věta zmizí.

```js
for (let i = 0; i < 10 && document.querySelector('.meal__remove'); i += 1) {
  await helpers.click(document.querySelector('.meal__remove'));
  await helpers.flush();
}
await helpers.type(document.querySelector('.add input[type="text"]'), 'Vločky s jogurtem');
await helpers.type(document.querySelector('.add input[type="number"]'), '380');
await helpers.submit(document.querySelector('.add'));
await helpers.flush();
assert.ok(document.querySelector('.meals'), 'po zápisu prvního jídla se má seznam vrátit');
assert.ok(!document.querySelector('.empty'), 'věta o prázdném dni má zase zmizet');
assert.equal(document.querySelectorAll('.meals .meal').length, 1, 'v seznamu má být jedna položka');
```

# --help--

## --tip--

Podmíněné vykreslení má ve Vue vlastní direktivu — hledej ji v části [Seznamy a podmínky](see:vue-nuxt-druhy-framework/prevodni-tabulka#seznamy-a-podminky).

## --tip-- 2

Podmínka je obyčejný výraz JavaScriptu nad daty, která šablona vidí. Prázdné pole má délku `0`, což je nepravdivá hodnota.

## --tip-- 2

Druhá direktiva se píše bez hodnoty a musí sedět na prvku hned za tím prvním — jinak Vue ohlásí, že k ní nenašlo podmínku.

## --file-- app.js

```js
import { createApp, ref, computed } from 'vue';

let nextId = 4;

createApp({
  setup() {
    const meals = ref([
      { id: 1, name: 'Ovesná kaše s banánem', kcal: 420 },
      { id: 2, name: 'Kuřecí salát', kcal: 530 },
      { id: 3, name: 'Tvaroh s malinami', kcal: 300 },
    ]);
    const total = computed(() => meals.value.reduce((sum, meal) => sum + meal.kcal, 0));

    const addSnack = () => {
      meals.value.push({ id: nextId++, name: 'Jablko', kcal: 95 });
    };

    const removeMeal = (id) => {
      meals.value = meals.value.filter((meal) => meal.id !== id);
    };

    const draftName = ref('');
    const draftKcal = ref('');
    const draftLabel = computed(() =>
      draftName.value.trim() === ''
        ? 'Zatím nic nepíšeš.'
        : `Zapíšeš: ${draftName.value} (${draftKcal.value || 0} kcal)`,
    );

    const addMeal = () => {
      meals.value.push({ id: nextId++, name: draftName.value, kcal: draftKcal.value || 0 });
      draftName.value = '';
      draftKcal.value = '';
    };

    return { total, meals, addSnack, removeMeal, addMeal, draftName, draftKcal, draftLabel };
  },
}).mount('#app');
```
