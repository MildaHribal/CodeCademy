# --description--

Sekce mají nahoře i dole pevné odsazení 48 px. Na telefonu je to tak akorát, na monitoru působí stránka natlačeně a sekce splývají.

**Úkol:** svislé odsazení sekcí `.section` (nahoře i dole stejné) je na telefonu **48 px**, od šířky okna **1600 px** je **96 px** a mezi tím roste plynule. Na širším okně už neroste. Vodorovné odsazení sekcí zůstane nulové.

# --hints--

Při šířce 375 px mají sekce nahoře i dole odsazení 48 px.

```js
await helpers.resize(375);
const style = getComputedStyle(document.querySelector('.section'));
assert.ok(Math.abs(parseFloat(style.paddingTop) - 48) <= 1, `Při šířce 375 px má sekce nahoře ${style.paddingTop}, čekám 48 px`);
assert.equal(style.paddingBottom, style.paddingTop, 'Odsazení sekce nahoře a dole má být stejné');
assert.equal(style.paddingLeft, '0px', 'Sekce nemá mít vodorovné odsazení (padding-left)');
```

Při šířce 1600 px i 1920 px mají sekce odsazení 96 px.

```js
for (const width of [1600, 1920]) {
  await helpers.resize(width);
  const style = getComputedStyle(document.querySelector('.section'));
  assert.ok(Math.abs(parseFloat(style.paddingTop) - 96) <= 1, `Při šířce ${width} px má sekce nahoře ${style.paddingTop}, čekám 96 px`);
  assert.equal(style.paddingBottom, style.paddingTop, 'Odsazení sekce nahoře a dole má být stejné');
}
```

Mezi 700 a 1300 px odsazení roste plynule: na každé šířce po 200 px je aspoň o 4 px větší.

```js
let previous = 0;
for (const width of [700, 900, 1100, 1300]) {
  await helpers.resize(width);
  const padding = parseFloat(getComputedStyle(document.querySelector('.section')).paddingTop);
  assert.ok(padding >= previous + 4, `Při šířce ${width} px má sekce odsazení ${padding.toFixed(1)} px, o 200 px užší okno ${previous.toFixed(1)} px — má plynule růst`);
  previous = padding;
}
```

# --help--

## --tip--

Plynulá velikost s minimem a maximem funguje pro rozestupy stejně jako pro písmo, viz [Plynulé velikosti: clamp()](see:css-responzivita/mobile-first#plynule-velikosti-clamp).

## --tip--

Logická vlastnost pro odsazení nahoře i dole najednou je `padding-block` a patří do pravidla `.section`. Preferovaná hodnota musí v okně 1600 px vyjít aspoň 96 px.

## --tip--

Mezera mezi kartami v galerii, která má být 12 px na telefonu a 32 px od 1400 px, by měla minimum 0.75rem, maximum 2rem a mezi nimi součet malého `rem` a několika `vw`, spočtený pro 1400 px.

  const height = width * 0.75;
  return `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 300" width="${width}" height="${height}" role="img">
