# --description--

Ve vodorovné kartě je plakát nízký pruh s poměrem stran 16 : 9. Skutečné filmové plakáty jsou na výšku.

**Úkol:** do bloku `@container (width >= 28rem)` přidej pravidlo pro `.film__poster` s `aspect-ratio: 2 / 3`. Ve svislé kartě zůstane plakát 16 : 9, protože základní pravidlo se nemění.

Uvnitř jednoho bloku `@container` může být pravidel kolik chceš, stejně jako v media dotazu:

```css
@container (width >= 30rem) {
  .product {
    grid-template-columns: 1fr 1fr;
  }

  .product__photo {
    aspect-ratio: 1;
  }
}
```

# --hints--

Při šířce 1024 px má plakát v programu poměr stran 2 : 3 (výška je 1,5× šířka).

```js
const poster = document.querySelector('.program .film__poster').getBoundingClientRect();
const ratio = poster.height / poster.width;
assert.ok(Math.abs(ratio - 1.5) <= 0.02, `Plakát v programu má výšku ${ratio.toFixed(2)}× šířku, čekám 1,5×`);
```

Při šířce 1024 px má plakát v úzkém panelu dál poměr 16 : 9.

```js
const poster = document.querySelector('.sidebar .film__poster').getBoundingClientRect();
const ratio = poster.width / poster.height;
assert.ok(Math.abs(ratio - 16 / 9) <= 0.03, `Plakát v panelu má poměr šířky a výšky ${ratio.toFixed(2)}, čekám 1,78 (16 : 9)`);
```
