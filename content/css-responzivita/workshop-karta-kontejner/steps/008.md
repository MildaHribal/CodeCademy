# --description--

Časy promítání jsou tlačítka vedle sebe podle délky textu. V úzké kartě po nich zůstává vpravo prázdné místo a na telefonu se hůř trefují.

**Úkol:**

- V kartě, jejíž místo je užší než **28rem**, jsou tři časy v jednom řádku jako **stejně široká** tlačítka, která dohromady vyplní celou šířku těla karty.
- V kartě s místem aspoň 28rem jsou tlačítka jen tak široká jako čas a začínají u levého okraje textu.

Způsobů je víc a testy přijmou každý, který dá správný výsledek. Pamatuj, že tělo karty je od kolegovy změny taky kontejner.

# --hints--

Při šířce 1024 px jsou v úzkém panelu tři časy v jednom řádku, stejně široké a vyplní šířku těla karty.

```js
const body = document.querySelector('.sidebar .film__body').getBoundingClientRect();
const links = [...document.querySelectorAll('.sidebar .slot:first-child .film__times a')].map((a) => a.getBoundingClientRect());
assert.equal(links.length, 3, 'První karta v panelu má mít tři časy');
assert.ok(links.every((link) => Math.abs(link.top - links[0].top) <= 1), 'Časy v panelu mají být v jednom řádku');
assert.ok(links.every((link) => Math.abs(link.width - links[0].width) <= 1), `Časy v panelu mají šířky ${links.map((l) => Math.round(l.width)).join(', ')} px — mají být stejné`);
assert.ok(Math.abs(links[0].left - body.left) <= 1 && Math.abs(links[2].right - body.right) <= 1, `Časy v panelu mají vyplnit tělo karty (${Math.round(links[0].left)}–${Math.round(links[2].right)} px, tělo ${Math.round(body.left)}–${Math.round(body.right)} px)`);
```

Při šířce 1024 px jsou časy v kartě programu úzká tlačítka podle textu, zarovnaná vlevo.

```js
const body = document.querySelector('.program .film__body').getBoundingClientRect();
const links = [...document.querySelectorAll('.program .slot:first-child .film__times a')].map((a) => a.getBoundingClientRect());
assert.ok(links.every((link) => link.width < 90), `Časy v programu mají šířky ${links.map((l) => Math.round(l.width)).join(', ')} px — mají být jen tak široké jako text`);
assert.ok(Math.abs(links[0].left - body.left) <= 1, 'První čas v programu má začínat u levého okraje textu');
assert.ok(Math.abs(links[1].top - links[0].top) <= 1, 'Časy v programu mají být v jednom řádku');
```

# --help--

## --tip--

Úzká a široká varianta časů je stejná úloha jako popis: základ pro úzkou kartu a container query pro širší. Pro tlačítka stejné šířky se hodí mřížka nebo flex položky, které rostou; připomeň si [Kontejner: container-type a @container](see:css-responzivita/container-queries#kontejner-container-type-a-container).

## --tip--

Seznam `.film__times` je uvnitř těla karty. Podmínka bez jména se proto ptá těla, ne slotu. Buď podmínku pojmenuj, nebo počítej s šířkou těla.

## --tip--

Popis v předchozích krocích má stejnou strukturu: jedna varianta v základním pravidle a druhá v bloku pro 28rem.
