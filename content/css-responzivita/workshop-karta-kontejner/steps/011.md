# --description--

## Hlášení

Kolega na tablet a telefon přidal do panelu „Brzy v kině" vodorovné posouvání (blok s komentářem „napsal kolega" pod pravidly seznamů). Chtěl karty vedle sebe v řádku, který jde posunout prstem. Na tabletu (768 px) je teď ale pod nadpisem „Brzy v kině" **jen tenký proužek a žádný film**. Na počítači je panel v pořádku.

Přepni náhled na **768** a podívej se.

## Úkol

Oprav to tak, aby byly na tabletu i telefonu karty v panelu vedle sebe v jednom posuvném řádku a každá byla široká **18rem**. Na počítači zůstanou pod sebou přes celou šířku panelu. Změň co nejmenší kus kódu.

# --hints--

Při šířce 768 px jsou karty v panelu vedle sebe v jednom řádku a každá je široká 288 px.

```js
await helpers.resize(768);
const slots = [...document.querySelectorAll('.sidebar__list > .slot')].map((slot) => slot.getBoundingClientRect());
slots.forEach((slot, i) => {
  assert.ok(Math.abs(slot.width - 288) <= 1, `Při šířce 768 px je karta ${i + 1} v panelu široká ${Math.round(slot.width)} px, čekám 288 px (18rem)`);
});
assert.ok(Math.abs(slots[1].top - slots[0].top) <= 1 && slots[1].left > slots[0].right, 'Při šířce 768 px mají být karty v panelu vedle sebe');
```

Při šířce 375 px jde řádek s kartami posouvat a stránka jako celek do strany nejde.

```js
await helpers.resize(375);
const list = document.querySelector('.sidebar__list');
assert.ok(list.scrollWidth > list.clientWidth, 'Při šířce 375 px se dvě karty do panelu nevejdou, řádek má jít posouvat (scrollWidth > clientWidth)');
assert.ok(document.documentElement.scrollWidth <= document.documentElement.clientWidth, 'Při šířce 375 px nesmí jít posouvat celá stránka do strany');
```

Při šířce 1024 px jsou karty v panelu pod sebou přes celou šířku panelu.

```js
const panel = document.querySelector('.sidebar__list').getBoundingClientRect();
const slots = [...document.querySelectorAll('.sidebar__list > .slot')].map((slot) => slot.getBoundingClientRect());
assert.ok(slots[1].top >= slots[0].bottom, 'Při šířce 1024 px mají být karty v panelu pod sebou');
assert.ok(slots.every((slot) => Math.abs(slot.width - panel.width) <= 1), 'Při šířce 1024 px mají být karty v panelu přes celou šířku panelu');
```

# --help--

## --tip--

Sloty jsou kontejnery a teď jsou flex položkami. Co se stane s šířkou kontejneru, který ji bere z obsahu? Past popisuje [Kontejner bez vlastní šířky se zhroutí](see:css-responzivita/container-queries#kontejner-bez-vlastni-sirky-se-zhrouti).

## --tip--

Slot potřebuje šířku zvenku. Ve flex řádku ji dá výchozí velikost položky, která se nemá zmenšovat ani růst — a jen uvnitř kolegova media dotazu.

# --explain--

Vysvětli vlastními slovy, proč se sloty v kolegově posuvném řádku zhroutily na tenký proužek a proč pomohla výchozí velikost položky.

## --model--

Sloty jsou kontejnery s `container-type: inline-size`, a kontejner při výpočtu své šířky obsah nepočítá, aby nevznikl kruh mezi obsahem a podmínkami `@container`. Ve flex řádku ale položka s `flex-basis: auto` bere šířku právě z obsahu, takže jí vyšla nula. Když slot dostane výchozí velikost 18rem a nesmí se zmenšit, má šířku zvenku a karta v něm se vykreslí.

## --checklist--

- Kontejner nepočítá se šířkou svého obsahu.
- Flex položka s `flex-basis: auto` bere šířku z obsahu, a proto jí vyšla nula.
- Kontejner potřebuje šířku zvenku, třeba `flex-basis`, `width` nebo roztažení rodičem.
