# --description--

Název filmu má všude 20 px. Ve „Filmu týdne" je na hlavní sdělení malý, v úzkém panelu tak akorát. Velikost by se neměla řídit oknem, ale místem karty: v panelu na 1440 px monitoru je karta pořád úzká.

**Úkol:** nastav nadpisu `.film__title` velikost **12 px + 3 % šířky místa karty**, nejméně **18 px** a nejvýš **36 px**.

Kandidáti na „3 % šířky": `3vw`, `3cqi` nebo `3%`. Jen jeden z nich se vztahuje ke kontejneru; procenta u `font-size` se počítají z písma rodiče a `vw` z okna. Meze přidá funkce, kterou znáš z plynulých velikostí.

# --hints--

Při šířce 1024 px má nadpis v panelu (místo 320 px) asi 21,6 px, v programu (místo 632 px) asi 31 px a ve Filmu týdne 36 px.

```js
const size = (selector) => parseFloat(getComputedStyle(document.querySelector(selector)).fontSize);
const expected = { '.sidebar .film__title': 21.6, '.program .film__title': 30.96, '.featured .film__title': 36 };
for (const [selector, value] of Object.entries(expected)) {
  assert.ok(Math.abs(size(selector) - value) <= 1, `Nadpis ${selector} má ${size(selector).toFixed(1)} px, čekám asi ${value} px`);
}
```

Nadpis v panelu má stejnou velikost na oknech 1024 px i 1440 px, protože panel je pořád široký 320 px.

```js
const size = () => parseFloat(getComputedStyle(document.querySelector('.sidebar .film__title')).fontSize);
const at1024 = size();
await helpers.resize(1440);
const at1440 = size();
assert.ok(Math.abs(at1440 - at1024) <= 0.5, `Nadpis v panelu má na 1024 px ${at1024.toFixed(1)} px a na 1440 px ${at1440.toFixed(1)} px — má se řídit šířkou karty, ne okna`);
```

Při šířce 1440 px má nadpis ve Filmu týdne nejvýš 36 px, i když je karta široká přes 1000 px.

```js
await helpers.resize(1440);
const value = parseFloat(getComputedStyle(document.querySelector('.featured .film__title')).fontSize);
assert.ok(Math.abs(value - 36) <= 0.5, `Nadpis ve Filmu týdne má na 1440 px ${value.toFixed(1)} px, čekám 36 px (maximum)`);
```

# --help--

## --tip--

Jednotka, která se vztahuje k šířce kontejneru, je popsaná v části [Jednotky kontejneru: cqi](see:css-responzivita/container-queries#jednotky-kontejneru-cqi).

## --tip--

Deklarace `font-size` patří do pravidla `.film__title` a použije `clamp()`: minimum 1.125rem, maximum 2.25rem a uprostřed součet `rem` a jednotek kontejneru.

## --tip--

Cena v kartě produktu, která má být 14 px + 2 % šířky kontejneru, nejméně 16 px a nejvýš 24 px, by měla `clamp()` s minimem 1rem, maximem 1.5rem a uprostřed `0.875rem` plus dvě jednotky kontejneru.
