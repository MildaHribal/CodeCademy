# --description--

Stránka je plná pohybu: karty se zvedají, fotky přibližují, šipky a odznaky popojíždějí, nabídka i úvod vyjíždějí. Pro člověka, který má v systému zapnuté omezení pohybu, je to přesně to, čemu se chce vyhnout.

**Úkol:** když má uživatel zapnuté omezení pohybu:

- karta se při najetí ani fokusu nezvedne, fotka se nepřiblíží, šipka nepopojede a odznak se nezvětší,
- nabídka sdílení a prvky úvodu se jen prolnou průhledností, bez posunu,
- zpětná vazba bez pohybu zůstane: velký stín pod kartou se při najetí dál objeví a nabídka i úvod se dál plynule prolínají.

> [!TIP]
> Výsledek si prohlédni sám: otevři náhled v nové kartě, v DevTools v panelu **Rendering** přepni **prefers-reduced-motion** na `reduce` a projeď stránku myší i klávesou Tab.

# --hints--

Při omezeném pohybu se karta, fotka, šipka ani odznak při najetí nehýbou a nemění velikost.

```js
// Test nasimuluje zapnuté omezení pohybu: media dotazy na prefers-reduced-motion přepíše na podmínky, které platí (reduce) nebo neplatí (no-preference).
const emulateReducedMotion = () => {
  const visit = (rules) => {
    for (const rule of rules) {
      if (rule.media && /prefers-reduced-motion/.test(rule.media.mediaText)) {
        rule.media.mediaText = rule.media.mediaText
          .replace(/\(\s*prefers-reduced-motion\s*:\s*reduce\s*\)/g, '(min-width: 0px)')
          .replace(/\(\s*prefers-reduced-motion\s*:\s*no-preference\s*\)/g, '(max-width: 0px)')
          .replace(/\(\s*prefers-reduced-motion\s*\)/g, '(min-width: 0px)');
      }
      if (rule.cssRules) visit(rule.cssRules);
    }
  };
  for (const sheet of document.styleSheets) visit(sheet.cssRules);
};
// Test nasimuluje stav (najetí myší, stisk): pravidla s pseudotřídou převede na třídu a tu prvku přidá.
const forceState = (element, state = ':hover') => {
  const className = `akademie-${state.slice(1)}`;
  const visit = (rules) => {
    for (const rule of rules) {
      if (typeof rule.selectorText === 'string' && rule.selectorText.includes(state)) {
        rule.selectorText = rule.selectorText.replaceAll(state, `.${className}`);
      }
      if (rule.cssRules) visit(rule.cssRules);
    }
  };
  for (const sheet of document.styleSheets) visit(sheet.cssRules);
  element.classList.add(className);
};
emulateReducedMotion();
const rooms = [...document.querySelectorAll('.room')];
const featured = document.querySelector('.room--featured');
const measure = () => ({
  room: rooms[0].getBoundingClientRect().top,
  image: rooms[0].querySelector('.room__image').getBoundingClientRect().width,
  arrow: rooms[0].querySelector('.room__arrow').getBoundingClientRect().left,
  badge: featured.querySelector('.room__badge').getBoundingClientRect().width,
});
await helpers.wait(900);
const before = measure();
forceState(rooms[0]);
forceState(featured);
await helpers.wait(600);
const after = measure();
assert.ok(Math.abs(after.room - before.room) <= 0.5, `Při omezeném pohybu se karta posunula o ${(before.room - after.room).toFixed(1)} px`);
assert.ok(Math.abs(after.image - before.image) <= 0.5, 'Při omezeném pohybu se fotka v kartě zvětšila');
assert.ok(Math.abs(after.arrow - before.arrow) <= 0.5, 'Při omezeném pohybu šipka popojela');
assert.ok(Math.abs(after.badge - before.badge) <= 0.5, 'Při omezeném pohybu se odznak zvětšil');
```

# --help--

## --tip--

Media dotaz na omezení pohybu a co v něm zrušit a co nechat, popisuje [Omezený pohyb](see:css-animace/transition-transform#omezeny-pohyb-prefers-reduced-motion).

## --tip--

Nejkratší cesta je jeden blok `@media` na konci souboru, který stavům s pohybem vrátí samostatné transformační vlastnosti na výchozí hodnotu. U nabídky a úvodu hlídej `@starting-style`: pravidlo v media dotazu ho přepíše jen se stejnou specificitou, protože stojí níž v souboru — u nabídky tedy i se selektorem pro otevřený stav.

## --tip--

U galerie by blok pro omezený pohyb vracel na výchozí hodnotu `rotate` u `.photo:hover` a `translate` u `.lightbox` — pohyb pryč, prolínání `opacity` zůstane.

# --explain--

Vysvětli vlastními slovy, proč jsi při omezeném pohybu zrušil zvedání karty a vyjíždění nabídky, ale nechal stín a prolínání průhlednosti.

## --model--

Omezení pohybu si zapínají hlavně lidé, kterým posun, zvětšování a otáčení na obrazovce způsobují závrať nebo nevolnost, případně je ruší. Nevadí jim ale změna barvy nebo průhlednosti, protože se při ní nic nepohybuje. Když zruším jen pohyb, uživatel dál vidí, na které kartě je a že se nabídka otevřela, a nepřijde o zpětnou vazbu.

## --checklist--

- Potíže působí pohyb: posun, zvětšení, otočení.
- Změna barvy, stínu nebo průhlednosti není pohyb.
- Omezený pohyb neznamená žádnou zpětnou vazbu.
- Media dotaz `prefers-reduced-motion: reduce` přepíše jen pohyb.
