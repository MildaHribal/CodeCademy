# --description--

Tlačítka jsou hotová, teď karty pokojů. Karta, na kterou uživatel najede, se má o kousek nadzvednout — dává tím najevo, že se na ni dá kliknout (celá karta je odkaz díky `.room__link::before`).

**Úkol:**

1. Pod pravidlo `.room` přidej pravidlo `.room:hover` s deklarací `translate: 0 -6px`.
2. Do pravidla `.room` přidej `transition: translate 250ms ease-out`.

Proč `translate`, a ne `margin-top: -6px`? `translate` se uplatní až při skládání vrstev. Rozvržení stránky se nezmění, sekce s dotazy pod kartami se nepohne a prohlížeč v žádném snímku nepočítá rozvržení znovu.

Příklad na jiných datech — dlaždice v galerii fotek, která při najetí popojede doprava:

```css
.tile {
  transition: translate 200ms ease-out;
}

.tile:hover {
  translate: 4px 0;
}
```

# --hints--

Při najetí myší se první karta posune o 6 px nahoru.

```js
// Test nasimuluje stav (najetí myší, stisk): pravidla s pseudotřídou převede na třídu a tu prvku přidá.
const forceState = (element, state = ':hover') => {
  const className = `akademie-${state.slice(1)}`;
  const visit = (rules) => {
    for (const rule of rules) {
      if (typeof rule.selectorText === 'string' && rule.selectorText.includes(state)) {
        rule.selectorText = rule.selectorText.replaceAll(state, `.${className}`);
      }
      if (rule.cssRules) visit(rule.cssRules);
    }
  };
  for (const sheet of document.styleSheets) visit(sheet.cssRules);
  element.classList.add(className);
};
const room = document.querySelector('.room');
const before = room.getBoundingClientRect().top;
forceState(room);
await helpers.wait(500);
const shift = before - room.getBoundingClientRect().top;
assert.ok(Math.abs(shift - 6) <= 0.5, `Karta se při najetí posunula o ${shift.toFixed(1)} px nahoru, čekám 6 px`);
```

Posun se animuje přechodem, který trvá 200–300 ms.

```js
// Přechod dané vlastnosti ze spočtených stylů: { duration, delay } v ms, nebo null (i při nulové délce).
const transitionOf = (element, property, pseudo = null) => {
  const style = getComputedStyle(element, pseudo);
  const list = (value) => value.split(/,(?![^(]*\))/).map((part) => part.trim());
  const names = list(style.transitionProperty);
  // Zkratka (třeba background) platí i pro svou dílčí vlastnost (background-color).
  const index = names.findIndex((name) => name === property || name === 'all' || property.startsWith(`${name}-`));
  if (index === -1) return null;
  const ms = (value) => parseFloat(value) * (value.endsWith('ms') ? 1 : 1000);
  const durations = list(style.transitionDuration);
  const delays = list(style.transitionDelay);
  const found = { name: names[index], duration: ms(durations[index % durations.length]), delay: ms(delays[index % delays.length]) };
  return found.duration > 0 ? found : null;
};
const room = document.querySelector('.room');
const transition = transitionOf(room, 'translate') ?? transitionOf(room, 'transform');
assert.ok(transition, 'transition na .room má obsahovat translate');
assert.ok(transition.duration >= 200 && transition.duration <= 300, `Přechod posunu karty trvá ${transition.duration} ms, čekám 200–300 ms`);
```

# --explain--

Vysvětli vlastními slovy, proč se sekce s dotazy pod kartami nepohnula, a co by se stalo, kdyby karta při najetí dostala místo `translate` deklaraci `margin-top: -6px`.

## --model--

`translate` je transformace a uplatní se až po rozvržení, při skládání vrstev. Karta si v rozvržení drží původní místo, takže prvky pod ní o posunu nevědí. `margin-top` je vlastnost rozvržení: karta by se posunula spolu s obsahem v mřížce a prohlížeč by v každém snímku přechodu počítal rozvržení znovu, což na slabším zařízení zadrhává.

## --checklist--

- Transformace se uplatní až po rozvržení.
- Karta si v rozvržení drží původní místo, sousedé se nepohnou.
- `margin-top` mění rozvržení a hýbe i okolními prvky.
- Animace vlastnosti rozvržení přepočítává rozvržení v každém snímku.
