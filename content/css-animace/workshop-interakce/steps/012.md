title: Plus se otočí na křížek
see: css-animace/transition-transform#transformace-posun-zvetseni-otoceni
---

# --description--

Ikona `+` vedle otázky ukazuje, že jde dotaz rozbalit. U otevřeného dotazu se má otočit o 45 stupňů — ze znaku `+` se tak stane `×` a uživatel pozná, že dalším kliknutím dotaz zavře.

**Úkol:** ikona `.faq__icon` otevřeného dotazu je otočená o 45°, otočení se animuje 200–400 ms.

Otevřený `<details>` má atribut `open`, na který jde napsat selektor atributu. Na otočení se hodí samostatná vlastnost `rotate` nebo funkce `rotate()` ve `transform`; vyber a rozmysli si, jestli přechod patří ikoně vždycky, nebo jen otevřenému stavu.

# --hints--

Ikona otevřeného dotazu je otočená o 45°.

```js
const item = document.querySelector('.faq__item');
const icon = item.querySelector('.faq__icon');
const size = icon.getBoundingClientRect().width;
item.open = true;
await helpers.wait(600);
const rotated = icon.getBoundingClientRect().width;
// Čtverec otočený o 45° zabírá na šířku úhlopříčku, tedy √2 × strana.
assert.ok(Math.abs(rotated - size * Math.SQRT2) <= 1, `Ikona otevřeného dotazu zabírá na šířku ${rotated.toFixed(1)} px, otočená o 45° by měla ${(size * Math.SQRT2).toFixed(1)} px`);
```

Ikona zavřeného dotazu otočená není.

```js
const item = document.querySelectorAll('.faq__item')[1];
const icon = item.querySelector('.faq__icon');
const style = getComputedStyle(icon);
assert.ok(['none', '0deg'].includes(style.rotate) && style.transform === 'none', `Ikona zavřeného dotazu nemá být otočená (rotate ${style.rotate}, transform ${style.transform})`);
```

Otočení běží jako přechod oběma směry, 200–400 ms.

```js
// Přechod dané vlastnosti ze spočtených stylů: { duration, delay } v ms, nebo null.
const transitionOf = (element, property, pseudo = null) => {
  const style = getComputedStyle(element, pseudo);
  const list = (value) => value.split(/,(?![^(]*\))/).map((part) => part.trim());
  const names = list(style.transitionProperty);
  const index = names.findIndex((name) => name === property || name === 'all');
  if (index === -1) return null;
  const ms = (value) => parseFloat(value) * (value.endsWith('ms') ? 1 : 1000);
  const durations = list(style.transitionDuration);
  const delays = list(style.transitionDelay);
  return { name: names[index], duration: ms(durations[index % durations.length]), delay: ms(delays[index % delays.length]) };
};
const icon = document.querySelector('.faq__icon');
const transition = transitionOf(icon, 'rotate') ?? transitionOf(icon, 'transform');
assert.ok(transition, 'Zavřená ikona má mít transition na rotate — jinak se zavírání neanimuje');
assert.ok(transition.duration >= 200 && transition.duration <= 400, `Přechod otočení trvá ${transition.duration} ms, čekám 200–400 ms`);
```

# --help--

## --tip--

Otočení je transformace a transformace se animují stejně jako barva. Připomeň si [Transformace: posun, zvětšení, otočení](see:css-animace/transition-transform#transformace-posun-zvetseni-otoceni) a [kam patří transition](see:css-animace/transition-transform#zapis-transition-vlastnost-delka-krivka-zpozdeni).

## --tip--

Přechod patří do pravidla `.faq__icon`, otočení do nového pravidla, které vybere ikonu uvnitř `.faq__item` s atributem `open`.

## --tip--

Šipka u rozbalovacího menu `.dropdown[open] .chevron` se otáčí stejně, jen o půl otáčky (`0.5turn`), a její přechod je v pravidle `.chevron`.
