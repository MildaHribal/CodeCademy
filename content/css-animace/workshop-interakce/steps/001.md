# --description--

V tomhle workshopu oživíš web horské chaty: tlačítka, která reagují na stisk, karty pokojů, které se nadzvednou, nabídku sdílení, která se vysune, a akordeon s dotazy, který se plynule rozbalí. HTML i celý vzhled jsou hotové, píšeš jen CSS do `styles.css`, vždycky do zvýrazněného místa. Každý krok přidá jednu mikrointerakci, kterou uvidíš v náhledu.

Než přijdou přechody, jedna věc, kterou už znáš: stav prvku. Tenhle krok je bez návodu.

**Úkol:** tlačítka `.button` mají při najetí myší **i** při fokusu klávesnicí dostat tmavší pozadí z tokenu `--color-accent-dark`. Zatím bez přechodu, změna bude skokem.

> [!TIP]
> Stav `:hover` si v DevTools vynutíš bez myši: otevři náhled v nové kartě, klikni na tlačítko pravým tlačítkem → Prozkoumat, v panelu Styles klikni na `:hov` a zaškrtni `:hover`.

# --hints--

Tlačítko v hlavičce má při najetí myší pozadí z `--color-accent-dark`.

```js
// Test nasimuluje stav (najetí myší, stisk): pravidla s pseudotřídou převede na třídu a tu prvku přidá.
const forceState = (element, state = ':hover') => {
  const className = `akademie-${state.slice(1)}`;
  const visit = (rules) => {
    for (const rule of rules) {
      if (typeof rule.selectorText === 'string' && rule.selectorText.includes(state)) {
        rule.selectorText = rule.selectorText.replaceAll(state, `.${className}`);
      }
      if (rule.cssRules) visit(rule.cssRules);
    }
  };
  for (const sheet of document.styleSheets) visit(sheet.cssRules);
  element.classList.add(className);
};
const button = document.querySelector('.site-header .button');
const probe = document.createElement('div');
probe.style.backgroundColor = 'var(--color-accent-dark)';
document.body.append(probe);
const expected = getComputedStyle(probe).backgroundColor;
forceState(button);
assert.equal(getComputedStyle(button).backgroundColor, expected, 'Při najetí myší (:hover) má mít .button pozadí var(--color-accent-dark)');
```

Tlačítko v hlavičce má stejné pozadí i při fokusu klávesnicí.

```js
const button = document.querySelector('.site-header .button');
const probe = document.createElement('div');
probe.style.backgroundColor = 'var(--color-accent-dark)';
document.body.append(probe);
const expected = getComputedStyle(probe).backgroundColor;
button.focus({ preventScroll: true });
assert.ok(button.matches(':focus-visible'), 'Tlačítko po button.focus() nemá :focus-visible — test nejde vyhodnotit');
assert.equal(getComputedStyle(button).backgroundColor, expected, 'Při fokusu klávesnicí (:focus-visible) má mít .button pozadí var(--color-accent-dark)');
```

Bez najetí a fokusu zůstává tlačítko ve výchozí zelené.

```js
const button = document.querySelector('.site-header .button');
const probe = document.createElement('div');
probe.style.backgroundColor = 'var(--color-accent)';
document.body.append(probe);
assert.equal(getComputedStyle(button).backgroundColor, getComputedStyle(probe).backgroundColor, 'Bez najetí myší má .button pozadí var(--color-accent)');
```

# --help--

## --tip--

Stavy prvku popisují pseudotřídy. Pro myš je to `:hover`, pro fokus z klávesnice ta, která se neukáže po kliknutí myší.

## --tip--

Obě pseudotřídy můžou sdílet jedno pravidlo — seznam selektorů oddělených čárkou, nebo `:is(…)`.

## --tip--

Stejně by vypadal odkaz v patičce, který při najetí i fokusu zčervená: jedno pravidlo pro `.footer-link` se dvěma stavy a deklarací `color`.
