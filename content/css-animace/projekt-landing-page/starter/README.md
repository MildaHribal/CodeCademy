# Dělenka — landing page

Úvodní stránka aplikace Dělenka: úvod s nabídkou ke stažení, funkce, recenze, ceník, časté otázky a patička. Čisté HTML a CSS bez knihoven a bez sestavení.

Celé zadání s požadavky najdeš v Akademii u projektu, texty v `predloha.md` a vzhled v `navrh.md`.

## Spuštění

Nic se neinstaluje. Náhled vidíš přímo v Akademii u projektu. Mimo ni stačí otevřít `index.html` v prohlížeči a po uložení souboru stránku obnovit.

## Soubory

| soubor | co v něm je |
|---|---|
| `index.html` | struktura stránky — tady píšeš |
| `styles.css` | styly ve vrstvách — tady píšeš |
| `predloha.md` | texty a struktura od klienta |
| `navrh.md` | barvy, typografie, rozvržení a pohyb od designérky |

## Rozhodnutí

Sem na konci napiš tři rozhodnutí, která jsi při stavbě udělal, a proč. Třeba: proč je sekce funkcí v gridu a recenze ve flexboxu, jak jsi pojmenoval vrstvy, jak funguje tmavý motiv.
