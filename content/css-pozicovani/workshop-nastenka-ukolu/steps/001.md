# --description--

V tomhle workshopu postavíš nástěnku úkolů týmu, který dělá nový web městské knihovny: tři sloupce karet, rozbalovací nabídky, avatary řešitelů, oznámení a detail úkolu. Takové nástěnky znáš z Trella, GitHub Projects nebo Jiry. HTML, vzhled a škála vrstev v `:root` jsou hotové. Píšeš jen do `styles.css`.

U dvou karet je nabídka **⋯** otevřená, abys na ni viděl. Nabídka je `<details>`, takže se otevírá a zavírá bez JavaScriptu. Zatím leží v toku a roztahuje kartu.

Tenhle krok je bez návodu, znáš ho z minulého workshopu.

**Úkol:** nabídka `.card-menu` má ležet přes obsah karty, **40 px pod horní hranou karty a 12 px od její pravé hrany**. Karta se nesmí kvůli nabídce zvětšit.

# --hints--

Otevřená nabídka je 40 px pod horní hranou své karty a 12 px od její pravé hrany.

```js
document.querySelectorAll('.card-actions[open]').forEach((actions) => {
  const card = actions.closest('.card').getBoundingClientRect();
  const menu = actions.querySelector('.card-menu').getBoundingClientRect();
  assert.ok(Math.abs(menu.top - card.top - 40) <= 1, `Nabídka je ${Math.round(menu.top - card.top)} px pod horní hranou karty, čekám 40 px`);
  assert.ok(Math.abs(card.right - menu.right - 12) <= 1, `Nabídka je ${Math.round(card.right - menu.right)} px od pravé hrany karty, čekám 12 px`);
});
```

Otevřená nabídka kartu neroztahuje: karta zůstane vysoká nejvýš 170 px jako ostatní karty.

```js
const open = document.querySelector('.card-actions[open]').closest('.card').getBoundingClientRect();
assert.ok(open.height < 170, `Karta s otevřenou nabídkou je vysoká ${Math.round(open.height)} px — nabídka ji nemá roztahovat`);
```

# --help--

## --tip--

Prvek přes obsah, měřený od rohu jiného prvku, je vzor z části [absolute a obsahující blok](see:css-pozicovani/position#absolute-a-obsahujici-blok).

## --tip--

Pravidla jsou dvě: jedno pro kartu, od které se měří, druhé pro nabídku, která vypadne z toku a dostane dvě odsazení.

## --tip--

Stejně jsi v minulém workshopu posadil štítek „Novinka" do rohu karty trasy, jen k jiným hranám.
