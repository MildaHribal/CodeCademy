# --description--

Pod nástěnkou leží zelené oznámení „Úkol přesunut do Hotovo". Oznámení (*toast*) má být v pravém dolním rohu okna, 24 px od pravého i spodního okraje, a musí být vidět **nad vším** — nad kartami, otevřenými nabídkami i nad detailem úkolu, který přidáš za chvíli.

**Úkol:** přišpendli oznámení `.toast` do pravého dolního rohu okna a dej mu vrstvu ze škály.

Kandidáti na vrstvu: `--z-dropdown`, `--z-modal` a `--z-toast`. Testy kontrolují i hodně nízké okno, ve kterém se oznámení potká s přilepenou hlavičkou aplikace.

# --hints--

Oznámení je 24 px od pravého a spodního okraje okna, i po odrolování.

```js
const root = document.documentElement;
for (const y of [0, 600]) {
  window.scrollTo(0, y);
  const box = document.querySelector('.toast').getBoundingClientRect();
  assert.ok(Math.abs(root.clientWidth - box.right - 24) <= 2 && Math.abs(root.clientHeight - box.bottom - 24) <= 2, `Při odrolování o ${y} px je oznámení ${Math.round(root.clientWidth - box.right)} px od pravého a ${Math.round(root.clientHeight - box.bottom)} px od spodního okraje okna, čekám 24 a 24 px`);
}
```

V nízkém okně (1024 × 130 px) je oznámení nad přilepenou hlavičkou aplikace.

```js
await helpers.resize(1024, 130);
window.scrollTo(0, 0);
const toastEl = document.querySelector('.toast');
const toast = toastEl.getBoundingClientRect();
const header = document.querySelector('.app-header').getBoundingClientRect();
assert.ok(toast.top < header.bottom - 4, 'V nízkém okně se má oznámení překrývat s hlavičkou aplikace');
const hit = document.elementFromPoint(toast.left + toast.width / 2, (toast.top + header.bottom) / 2);
assert.ok(hit?.closest('.toast') === toastEl, `V místě, kde se oznámení a hlavička aplikace překrývají, je navrchu ${hit?.className || hit?.tagName} — má tam být oznámení`);
```

# --help--

## --tip--

Přišpendlení k oknu je [fixed: přišpendlené k oknu](see:css-pozicovani/position#fixed-prispendlene-k-oknu), výběr vrstvy [Škála z-index v tokenech](see:css-pozicovani/stacking-context#skala-z-index-v-tokenech).

## --tip--

Do pravidla `.toast` patří hodnota `position`, odsazení zprava a zdola (`1.5rem`) a vrstva, která je ve škále nejvyšší.

## --tip--

Lišta „Jste offline" `.offline-banner` přes celou šířku dole by měla stejnou hodnotu `position` i vrstvu, jen by se roztáhla zleva doprava.

# --explain--

Vysvětli vlastními slovy, proč je lepší psát `z-index: var(--z-toast)` než `z-index: 9999`.

## --model--

Pojmenovaná vrstva říká, kam prvek patří, a všechny vrstvy projektu jsou na jednom místě, takže vidím, co je nad čím. S náhodnými čísly každý přidá „o trochu víc" a za půl roku nikdo neví, jestli 9999 je nad 5000, protože to tak má být. Když se škála změní, změní se všechny prvky najednou. Škála ale platí jen ve stejném stacking contextu, prvek uvězněný v kartě s `opacity` nezachrání.

## --checklist--

- Token říká, do jaké vrstvy prvek patří.
- Všechny vrstvy jsou na jednom místě a jde vidět jejich pořadí.
- Změna škály se projeví všude najednou.
- Škála funguje jen v rámci stejného stacking contextu.
