# --description--

Odroluj pomalu dolů a sleduj horní hranu okna. Text článku pod hlavičkou zajíždí a rozostřuje se, ale fotka a karty tras jedou **přes** hlavičku a zakryjí logo.

Důvod je v pořadí vykreslení. Pozicované prvky se kreslí nad prvky v normálním toku, a ze dvou pozicovaných je navrchu ten, který je v HTML později. Hlavička je `sticky`, fotka i karty jsou `relative` — všechny pozicované, a hlavička je v HTML první.

**Úkol:** do pravidla `.site-header` přidej `z-index: 10`. Vyšší `z-index` vytáhne pozicovaný prvek nad pozicované prvky bez něj.

Proč zrovna 10 a ne 1? Stačilo by i 1. Malá rezerva se hodí, když pak přidáš vrstvy mezi obsah a hlavičku — jak to dělat systematicky, ukáže lekce o stacking contextu.

Příklad na jiných datech:

```css
.cookie-bar {
  position: fixed;
  z-index: 20;
}
```

# --hints--

Když pod hlavičku přijede karta trasy, hlavička zůstane navrchu.

```js
const card = document.querySelector('.trail-card');
window.scrollTo(0, card.getBoundingClientRect().top + window.scrollY - 20);
const header = document.querySelector('.site-header').getBoundingClientRect();
const box = card.getBoundingClientRect();
const hit = document.elementFromPoint(box.left + box.width / 2, header.top + header.height / 2);
assert.ok(hit?.closest('.site-header'), `V místě, kde se hlavička a karta překrývají, je navrchu ${hit?.className || hit?.tagName} — má tam být hlavička`);
```

Hlavička se dál lepí k horní hraně okna.

```js
window.scrollTo(0, 1500);
const top = document.querySelector('.site-header').getBoundingClientRect().top;
assert.ok(Math.abs(top) <= 1, `Po odrolování je horní hrana hlavičky na ${Math.round(top)} px, čekám 0 px`);
```

# --help--

## --tip--

Kdo je navrchu, když se pozicované prvky překrývají, vysvětluje [Překrývání: kdo je navrchu](see:css-pozicovani/position#prekryvani-kdo-je-navrchu).

## --tip--

Vrstvu měníš prvku, který má být nahoře — hlavičce, ne kartám.

## --tip--

Lišta s cookies `.cookie-bar` z příkladu se dostane nad obsah stejnou vlastností; hodnota je jen číslo větší než nula.
