# --description--

Klikni v nabídce první epizody na Stáhnout. Oznámení se otevře uprostřed okna přes seznam epizod, kde překáží.

**Úkol:** otevřené oznámení `.toast` má ležet v pravém dolním rohu okna: **24 px od pravého okraje** a spodní hranou **16 px nad přehrávačem**. Výška přehrávače je v custom property `--player-height`.

Než začneš, vzpomeň si, které výchozí styly popoveru ho posadily doprostřed okna.

# --hints--

Otevřené oznámení je 24 px od pravého okraje okna.

```js
const toast = document.querySelector('.toast');
toast.showPopover();
const root = document.documentElement;
const box = toast.getBoundingClientRect();
assert.ok(Math.abs(root.clientWidth - box.right - 24) <= 1.5, `Oznámení je ${Math.round(root.clientWidth - box.right)} px od pravého okraje okna, čekám 24 px`);
```

Spodní hrana otevřeného oznámení je 16 px nad horní hranou přehrávače.

```js
const toast = document.querySelector('.toast');
toast.showPopover();
const box = toast.getBoundingClientRect();
const player = document.querySelector('.player').getBoundingClientRect();
assert.ok(Math.abs(player.top - box.bottom - 16) <= 1.5, `Oznámení končí ${Math.round(player.top - box.bottom)} px nad přehrávačem, čekám 16 px`);
```

# --help--

## --tip--

Výchozí styly popoveru jsou v části [Výchozí styly, :popover-open a ::backdrop](see:css-pozicovani/top-layer-a-kotveni#vychozi-styly-popover-open-a-backdrop). Popover je `fixed`, takže se měří od okna.

## --tip--

V pravidle `.toast` přepiš odsazení od všech čtyř stran: pravé a spodní nastav, horní a levé vrať na `auto`. Automatický okraj popoveru pak centrovat přestane sám, protože nemá mezi čím. Spodní odsazení spočítej přes `calc()` z výšky přehrávače.

## --tip--

Tlačítko chatu v levém dolním rohu nad lištou s cookies by mělo odsazení zleva a zdola spočítané z výšky lišty a zbylé dvě strany `auto`.
