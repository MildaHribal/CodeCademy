# --description--

Teď tlačítko po načtení říká „sbaleno". Jenže když panel otevřeš, říká to pořád. Stav, který se nemění s tím, co je vidět, je horší než žádný: uživatel slyší „sbaleno", myslí si, že se nic nestalo, a klikne znovu.

V `script.js` najdeš posluchač, který přepíná `filters.hidden`. Přidej do něj nastavení atributu stavu tlačítka tak, aby po každém kliknutí odpovídal skutečnosti. Pozor na hodnotu: atribut je text, a ne každý zápis převrácené hodnoty dá, co čekáš.

**Úkol:** uprav posluchač tlačítka Filtry, aby stav rozbalení vždy odpovídal viditelnosti panelu.

# --hints--

Po prvním kliknutí je panel vidět a tlačítko má `aria-expanded="true"`.

```js
const toggle = document.querySelector('.filter-toggle');
toggle.click();
assert.equal(document.querySelector('#filters').hidden, false, 'po prvním kliknutí má být panel filtrů vidět');
assert.equal(toggle.getAttribute('aria-expanded'), 'true', `po otevření panelu má mít tlačítko aria-expanded="true", má "${toggle.getAttribute('aria-expanded')}"`);
```

Po druhém kliknutí je panel skrytý a tlačítko má znovu `aria-expanded="false"`.

```js
const toggle = document.querySelector('.filter-toggle');
toggle.click();
toggle.click();
assert.equal(document.querySelector('#filters').hidden, true, 'po druhém kliknutí má být panel filtrů skrytý');
assert.equal(toggle.getAttribute('aria-expanded'), 'false', `po zavření panelu má mít tlačítko aria-expanded="false", má "${toggle.getAttribute('aria-expanded')}"`);
toggle.click();
assert.equal(toggle.getAttribute('aria-expanded'), 'true', 'po třetím kliknutí má být stav znovu true');
```

# --help--

## --tip--

Stav se musí měnit spolu s obrazovkou, viz [Stav: co se s prvkem právě děje](see:html-pristupnost/strom-pristupnosti#stav-co-se-s-prvkem-prave-deje).

## --tip--

Atribut nastavíš metodou `setAttribute` na `filterToggle`, až po změně `filters.hidden`. Rozbaleno je tehdy, když panel **není** skrytý; hodnotu převeď na text přes `String(…)`.

## --tip--

U rozbalovací odpovědi v FAQ by to bylo `faqButton.setAttribute('aria-expanded', String(answer.hidden === false));` — jiné jméno tlačítka i panelu, stejná myšlenka.

## --file-- script.js

```js
// Kolegův skript obchodu: košík a panel filtrů.
const cartCount = document.querySelector('#cart-count');
const cartStatus = document.querySelector('#cart-status');
let itemCount = 0;

document.querySelectorAll('.product__buy').forEach((buyButton) => {
  buyButton.addEventListener('click', () => {
    itemCount += 1;
    cartCount.textContent = itemCount;
    cartStatus.textContent = `${buyButton.dataset.product} je v košíku.`;
  });
});

document.querySelector('.cart').addEventListener('click', () => {
  cartStatus.textContent = itemCount === 0 ? 'Košík je prázdný.' : `V košíku máš ${itemCount} ks kávy.`;
});

const filterToggle = document.querySelector('.filter-toggle');
const filters = document.querySelector('#filters');

filterToggle.addEventListener('click', () => {
  filters.hidden = !filters.hidden;
});
```

## --file-- script.js

```js
// Kolegův skript obchodu: košík a panel filtrů.
const cartCount = document.querySelector('#cart-count');
const cartStatus = document.querySelector('#cart-status');
let itemCount = 0;

document.querySelectorAll('.product__buy').forEach((buyButton) => {
  buyButton.addEventListener('click', () => {
    itemCount += 1;
    cartCount.textContent = itemCount;
    cartStatus.textContent = `${buyButton.dataset.product} je v košíku.`;
  });
});

document.querySelector('.cart').addEventListener('click', () => {
  cartStatus.textContent = itemCount === 0 ? 'Košík je prázdný.' : `V košíku máš ${itemCount} ks kávy.`;
});

const filterToggle = document.querySelector('.filter-toggle');
const filters = document.querySelector('#filters');

filterToggle.addEventListener('click', () => {
  filters.hidden = !filters.hidden;
  filterToggle.setAttribute('aria-expanded', String(!filters.hidden));
});
```
