# Portfolio — Ondřej Kovář

Osobní portfolio o třech stránkách: úvod, projekty a kontakt. Čisté HTML a CSS, bez knihoven a bez sestavení.

## Spuštění

Nic se neinstaluje. Stačí otevřít `index.html` v prohlížeči.

## Nasazení

Běží na GitHub Pages: https://ondrejkovar-dev.github.io/portfolio/

## Přístupnost

- Všechny tři stránky jsem prošel jen klávesnicí, fokus je všude vidět a „Přeskočit na obsah" vede do `main`.
- Se čtečkou NVDA jsem prošel osnovu nadpisů, oblasti stránky a odeslal kontaktní formulář.
- Kontrast textu a tlačítek jsem ověřil v DevTools, všude je aspoň 4,5 : 1.
