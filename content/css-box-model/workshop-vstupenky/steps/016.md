# --description--

Poslední úprava. Tlačítko „Odebírat novinky" ve formuláři je teď jen tak široké jako jeho text. Na telefonu se na ně palcem trefuje špatně a pod polem pro e-mail vypadá ztraceně.

**Úkol:** tlačítko `.newsletter__button` má být **přes celou šířku obsahu formuláře**, stejně jako pole pro e-mail nad ním, a nesmí přetéct. Tlačítko je `inline-block`, takže samo se neroztáhne jako blok.

## Co jsi v tomhle workshopu použil

- Reset `box-sizing: border-box` na všech prvcích: `width` je šířka od rámečku k rámečku a padding nic nepřetáhne.
- Sloupec stránky: `max-inline-size` pro nejvyšší šířku, `margin-inline: auto` pro vycentrování a `padding-inline` pro odsazení od okrajů telefonu.
- `padding` se dvěma hodnotami (nahoře a dole, pak po stranách).
- `min-block-size` a `min-inline-size`: box drží nejmenší velikost a s obsahem roste. Pevná výška nebo šířka by obsah nechala vytéct.
- Rámeček a margin jen na jedné straně přes logické vlastnosti (`border-inline-start`, `border-block-start`, `margin-block-end`).
- Blok, který má vyplnit rodiče, šířku nepotřebuje: `width: 100%` s marginem přeteče.
- Zvýraznění, které nic neposune: stín, obrys nebo barva místo nové vrstvy boxu.

Tyhle vzory najdeš na každém webu: obal stránky, karty, bannery, formuláře a tlačítka. V další lekci zjistíš, proč se odkazy a obrázky chovají jinak než bloky a proč jim výška nastavit nejde.

## Udělej po svém

- **Vizuální:** označ tarif „Celý festival" (`.ticket--featured`) výrazněji, třeba silnějším obrysem s odsazením, a ohlídej si, že se karty pod ním neposunou.
- **Funkční:** přidej pod pole pro e-mail drobný text o zpracování údajů a dej mu čitelnou délku řádku přes horní hranici šířky.
- **Tvoje téma:** přeměň stránku na vstupenky na akci, na kterou bys sám šel — koncert, závod nebo divadlo — s vlastními cenami a barvami v tokenech.

# --hints--

Tlačítko odběru je široké jako obsah formuláře a končí na stejném místě jako pole pro e-mail.

```js
const form = document.querySelector('.newsletter');
const style = getComputedStyle(form);
const box = form.getBoundingClientRect();
const contentWidth = box.width - parseFloat(style.paddingLeft) - parseFloat(style.paddingRight);
const button = document.querySelector('.newsletter__button').getBoundingClientRect();
const input = document.querySelector('.newsletter__input').getBoundingClientRect();
assert.ok(Math.abs(button.width - contentWidth) <= 1, `Tlačítko je široké ${Math.round(button.width)} px, obsah formuláře ${Math.round(contentWidth)} px`);
assert.ok(Math.abs(button.right - input.right) <= 1, `Tlačítko končí na ${Math.round(button.right)} px, pole na ${Math.round(input.right)} px`);
```

Na šířce 375 px tlačítko nepřetéká z formuláře.

```js
await helpers.resize(375);
const form = document.querySelector('.newsletter');
const contentRight = form.getBoundingClientRect().right - parseFloat(getComputedStyle(form).paddingRight);
const button = document.querySelector('.newsletter__button').getBoundingClientRect();
assert.ok(button.right <= contentRight + 1, `Při šířce 375 px končí tlačítko na ${Math.round(button.right)} px, obsah formuláře na ${Math.round(contentRight)} px`);
```

# --help--

## --tip--

Tlačítko se jako `inline-block` smršťuje na obsah, takže mu šířku nastavit musíš. S resetem `border-box` to jde bez přepočítávání paddingu, viz [box-sizing: co přesně měří width](see:css-box-model/box-model#box-sizing-co-presne-meri-width).

## --tip--

Deklarace patří do `.newsletter__button`. Podívej se, jak má šířku zapsanou pole `.newsletter__input` — tlačítko nemá žádný boční margin, takže tady pevná procenta nevadí.

## --tip--

Stejný vzor s jinou hodnotou: fotka v galerii, která má zabírat polovinu obsahu rodiče, dostane `inline-size: 50%`.
