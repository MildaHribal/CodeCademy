---
title: Patička ve stejném sloupci (zopakuj sám)
kind: recall
---

# --description--

Patička stránky `.site-footer` stojí mimo obal `.page`, a tak se její text na monitoru lepí k levému okraji okna, zatímco zbytek stránky je ve sloupci uprostřed.

**Úkol:** zařiď, aby text patičky začínal přesně tam, kde obsah stránky nad ní — na monitoru i na telefonu (šířka 375 px). HTML neměň. Všechno potřebné jsi napsal v prvních krocích tohohle workshopu.

# --hints--

Na šířce 1024 px začíná text patičky na stejném místě jako obsah stránky.

```js
const page = document.querySelector('.page');
const contentLeft = page.getBoundingClientRect().left + parseFloat(getComputedStyle(page).paddingLeft);
const text = document.querySelector('.site-footer__text').getBoundingClientRect();
assert.ok(Math.abs(text.left - contentLeft) <= 1, `Text patičky začíná na ${Math.round(text.left)} px, obsah stránky na ${Math.round(contentLeft)} px`);
```

Na šířce 375 px začíná text patičky na stejném místě jako obsah stránky a nepřetéká.

```js
await helpers.resize(375);
const page = document.querySelector('.page');
const contentLeft = page.getBoundingClientRect().left + parseFloat(getComputedStyle(page).paddingLeft);
const contentRight = page.getBoundingClientRect().right - parseFloat(getComputedStyle(page).paddingRight);
const text = document.querySelector('.site-footer__text').getBoundingClientRect();
assert.ok(Math.abs(text.left - contentLeft) <= 1, `Při šířce 375 px začíná text patičky na ${Math.round(text.left)} px, obsah stránky na ${Math.round(contentLeft)} px`);
assert.ok(text.right <= contentRight + 1, `Při šířce 375 px končí text patičky na ${Math.round(text.right)} px, obsah stránky na ${Math.round(contentRight)} px`);
```

# --help--

## --tip--

Patička potřebuje stejný sloupec jako obal stránky: nejvyšší šířku, vycentrování a odsazení od okrajů. Zopakuj si [Hranice velikosti](see:css-box-model/box-model#hranice-velikosti-min-a-max) a [Logické vlastnosti](see:css-box-model/box-model#logicke-vlastnosti-inline-a-block-misto-stran).

## --tip--

Porovnej pravidla `.page` a `.site-footer`. Patičce chybí tři deklarace, které jsi psal ve třetím až pátém kroku.

## --tip--

```css
.site-footer {
  /* 1. stejná nejvyšší šířka jako .page */
  /* 2. vycentrování */
  /* 3. odsazení od okrajů telefonu */
}
```
