# --description--

Karta vstupenky se má při najetí myší zvýraznit, aby bylo jasné, na kterou se člověk dívá. **Nic na stránce se přitom nesmí posunout**: ani text uvnitř karty, ani karty pod ní.

**Úkol:** napiš pravidlo pro kartu `.ticket` ve stavu `:hover`. Jak ji zvýrazníš, je na tobě. Testy přijmou každé zvýraznění, které nemění velikost ani polohu boxů v rozvržení.

Karta už má v seedu `transition`, takže se změna stínu nebo posunu přehraje plynule. Přechodům se podrobně věnuje sekce o animacích; tady si vyber, **čím** kartu zvýrazníš. Než napíšeš, rozmysli si aspoň dvě možnosti a u každé, jestli změní některou vrstvu boxu.

# --hints--

Ve stylech je pravidlo pro `.ticket:hover`, které kartu nějak změní.

```js
// Pravidla .ticket:hover, i vnořená (&:hover uvnitř .ticket).
const collect = (list, parent = '') => [...list].flatMap((rule) => {
  const selector = rule.selectorText ? rule.selectorText.replace(/&/g, parent) : parent;
  return [...(rule.selectorText ? [{ rule, selector }] : []), ...(rule.cssRules ? collect(rule.cssRules, selector) : [])];
});
const rules = [...document.styleSheets].flatMap((sheet) => collect(sheet.cssRules)).filter(({ selector }) => /\.ticket:hover\b/.test(selector)).map(({ rule }) => rule);
assert.ok(rules.length > 0, 'Chybí pravidlo se selektorem .ticket:hover');
assert.ok(rules.some((rule) => rule.style.length > 0), 'Pravidlo .ticket:hover nemá žádnou deklaraci');
```

Zvýraznění nemění velikost ani polohu karty v rozvržení (padding, margin, rozměry ani tloušťku rámečku).

```js
// Pravidla .ticket:hover, i vnořená (&:hover uvnitř .ticket).
const collect = (list, parent = '') => [...list].flatMap((rule) => {
  const selector = rule.selectorText ? rule.selectorText.replace(/&/g, parent) : parent;
  return [...(rule.selectorText ? [{ rule, selector }] : []), ...(rule.cssRules ? collect(rule.cssRules, selector) : [])];
});
const rules = [...document.styleSheets].flatMap((sheet) => collect(sheet.cssRules)).filter(({ selector }) => /\.ticket:hover\b/.test(selector)).map(({ rule }) => rule);
// Stav :hover nejde v testu vyvolat, proto se deklarace z pravidla použijí na kopii karty.
const sheet = document.createElement('style');
sheet.textContent = rules.map((rule) => `.ticket.probe-hover { ${rule.style.cssText} }`).join('\n');
document.head.append(sheet);
const ticket = document.querySelector('.ticket');
const clone = ticket.cloneNode(true);
clone.classList.add('probe-hover');
ticket.after(clone);
const before = getComputedStyle(ticket);
const after = getComputedStyle(clone);
const props = ['paddingTop', 'paddingRight', 'paddingBottom', 'paddingLeft', 'marginTop', 'marginRight', 'marginBottom', 'marginLeft', 'borderTopWidth', 'borderRightWidth', 'borderBottomWidth', 'borderLeftWidth'];
const changed = props.filter((prop) => before[prop] !== after[prop]).map((prop) => `${prop} ${before[prop]} → ${after[prop]}`);
const size = [ticket.offsetWidth, ticket.offsetHeight, clone.offsetWidth, clone.offsetHeight];
clone.remove();
sheet.remove();
assert.deepEqual(changed, [], `Při najetí se mění vrstvy boxu: ${changed.join(', ')} — obsah a okolí by poskočily`);
assert.ok(size[0] === size[2] && size[1] === size[3], `Při najetí se mění rozměry karty (${size[0]}×${size[1]} → ${size[2]}×${size[3]} px)`);
```

# --help--

## --tip--

Co zabírá místo v rozvržení a co ne, shrnuje poslední past v [Typické chyby a pasti](see:css-box-model/box-model#typicke-chyby-a-pasti).

## --tip--

Vrstvy boxu (padding, rámeček, margin) mění rozměry. Kreslí se ale i věci, které místo nezabírají: obrys, stín, barva pozadí nebo barva stávajícího rámečku.

## --tip--

Stejnou úlohu řeší náhled fotky v galerii, který se při najetí zvýrazní obrysem, ne novým rámečkem.

# --explain--

Vysvětli vlastními slovy, proč zvýraznění přes `border` nebo `padding` posune okolí, a čím kartu zvýraznit bez posunu.

## --model--

Rámeček a padding jsou vrstvy boxu, takže když přibudou nebo zesílí, box se zvětší a obsah v něm i prvky pod ním poskočí. `outline` a `box-shadow` se kreslí kolem boxu, ale místo v rozvržení nezabírají, a změna barvy nebo pozadí rozměry nemění vůbec. Proto zvýraznění stavím na nich, případně na rámečku, který má pořád stejnou tloušťku a mění jen barvu.

## --checklist--

- Padding a rámeček jsou součástí velikosti boxu.
- Když vrstva boxu při najetí přibude, obsah i okolí poskočí.
- `outline` a `box-shadow` místo v rozvržení nezabírají.
- Změna barvy stávajícího rámečku nic neposune.
