# --description--

Podívej se dolů na tmavý formulář „Novinky z programu". Pole pro e-mail má `width: 100%`, a přesto přečnívá přes pravý okraj tmavého rámu. Důvod znáš z lekce: ve výchozím `box-sizing: content-box` měří `width` jen obsah a padding s rámečkem pole se k 100 % přičtou.

Oprava, kterou začíná skoro každý moderní stylopis, je reset `box-sizing: border-box` pro všechny prvky i pseudoprvky. Pak `width` znamená šířku od rámečku k rámečku.

**Úkol:** seřaď řádky resetu do zvýrazněné oblasti nad pravidlem `body` a doplň hodnotu. Pořadí měníš šipkami nahoru a dolů, odsazení klávesou Tab. Dva řádky jsou navíc.

Po kontrole se pole pro e-mail vejde přesně do formuláře.

# --hints--

Pole pro e-mail nepřečnívá z formuláře: jeho pravý okraj končí tam, kde obsah formuláře.

```js
const form = document.querySelector('.newsletter');
const style = getComputedStyle(form);
const contentRight = form.getBoundingClientRect().right - parseFloat(style.paddingRight);
const input = document.querySelector('.newsletter__input').getBoundingClientRect();
assert.ok(Math.abs(input.right - contentRight) <= 1, `Pole končí na ${Math.round(input.right)} px, obsah formuláře na ${Math.round(contentRight)} px`);
```

Reset platí pro všechny prvky i pro pseudoprvky `::before` a `::after`.

```js
const probe = document.createElement('div');
probe.className = 'probe-reset';
document.body.append(probe);
const sheet = document.createElement('style');
sheet.textContent = '.probe-reset::before, .probe-reset::after { content: ""; }';
document.head.append(sheet);
const values = [getComputedStyle(probe).boxSizing, getComputedStyle(probe, '::before').boxSizing, getComputedStyle(probe, '::after').boxSizing];
sheet.remove();
probe.remove();
assert.deepEqual(values, ['border-box', 'border-box', 'border-box'], 'Prvek, jeho ::before i ::after mají mít box-sizing: border-box');
```

# --parsons--

```css
*,
*::before,
*::after {
  box-sizing: __1__;
}
```

## --distractors--

```css
* {
box-sizing: inherit;
```

## --blanks--

```text
1: border-box
```
