# --description--

Karty vstupenek na sebe doléhají. Mezi každými dvěma kartami má být mezera **24 px (1.5rem)**, ve které je vidět pozadí stránky, ne bílé pozadí karty.

**Úkol:** udělej mezery mezi kartami v pravidle `.ticket`.

Kandidáti: `padding-block-end`, `border-block-end` nebo `margin-block-end`. Jen jeden z nich dělá mezeru **vně** boxu, kam se nekreslí pozadí.

> [!NOTE]
> Svislé marginy sousedních bloků se umí slévat. Tady to nevadí, protože okolní karty jiný margin nemají. Proč a kdy se to stane, vysvětlí lekce Margin collapse a BFC.

# --hints--

Mezi sousedními kartami je mezera 24 px.

```js
const tickets = [...document.querySelectorAll('.ticket')].map((ticket) => ticket.getBoundingClientRect());
for (let i = 1; i < tickets.length; i++) {
  const space = tickets[i].top - tickets[i - 1].bottom;
  assert.ok(Math.abs(space - 24) <= 1, `Mezera mezi kartou ${i} a ${i + 1} je ${Math.round(space)} px, čekám 24 px`);
}
```

Karty mají dál vnitřní odsazení 24 px (mezera není uvnitř karty).

```js
document.querySelectorAll('.ticket').forEach((ticket, i) => {
  const style = getComputedStyle(ticket);
  assert.equal(style.paddingBottom, '24px', `Karta ${i + 1}: paddingBottom má zůstat 24px — mezera patří mimo kartu`);
  assert.equal(style.borderBottomWidth, '1px', `Karta ${i + 1}: spodní rámeček má zůstat 1px`);
});
```

# --help--

## --tip--

Mezera mezi boxy, kam se nekreslí pozadí, je jedna ze čtyř vrstev boxu. Zopakuj si [Čtyři vrstvy boxu](see:css-box-model/box-model#ctyri-vrstvy-boxu).

## --tip--

Padding i rámeček jsou uvnitř karty a mají její pozadí. Průhledná vrstva vně je margin; stačí ho dát na konec bloku (`block-end`).

## --tip--

Stejně by se oddělily odstavce článku: `.article p` s `margin-block-end: 1em`.
