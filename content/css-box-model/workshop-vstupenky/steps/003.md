# --description--

Na monitoru (náhled „Jako testy" má 1024 px) se text táhne přes celou šířku okna a řádky jsou dlouhé. Obsah stránky chceme držet v čitelném sloupci, ale na telefonu se má sloupec zúžit s oknem. Pevná `width` by to nezvládla, potřebuješ hranici shora.

Logická vlastnost `max-inline-size` je „nejvýš tak široký" ve směru řádku textu, v češtině tedy totéž co `max-width`. Příklad na jiném prvku:

```css
.article {
  max-inline-size: 60rem;
}
```

**Úkol:** do pravidla `.page` napiš `max-inline-size: 42rem`. Obsah se na monitoru zúží na 672 px a zatím zůstane u levého okraje, to spravíš v dalším kroku.

# --hints--

Obal stránky `.page` je na šířce 1024 px široký 42rem (672 px).

```js
const width = document.querySelector('.page').getBoundingClientRect().width;
assert.ok(Math.abs(width - 672) <= 1, `.page je široký ${Math.round(width)} px, má být 672 px (42rem)`);
```

Na šířce 375 px se `.page` zúží s oknem a nic nepřetéká do strany.

```js
await helpers.resize(375);
const width = document.querySelector('.page').getBoundingClientRect().width;
assert.ok(width <= 375, `Při šířce 375 px je .page široký ${Math.round(width)} px — má se zúžit s oknem`);
```
