# --description--

Grafik chce, aby byl banner na monitoru **aspoň 20rem (320 px) vysoký**, ať gradient vynikne. Zároveň víme, že pořadatelé budou úvodní text měnit a na telefonu se zalomí do víc řádků. Banner se proto nesmí nikdy useknout: když se text nevejde, musí růst.

**Úkol:** nastav výšku banneru `.hero` tak, aby splnil obojí.

Kandidáti jsou tři: `block-size` (logicky `height`), `min-block-size` a `max-block-size`. Než napíšeš, rozmysli si, co udělá každý z nich, když se do banneru přidá dlouhý text. Zkus to i naživo: připiš do odstavce `.hero__lead` v HTML pár vět a sleduj banner.

# --hints--

Na šířce 1024 px je banner vysoký 320 px (20rem).

```js
const height = document.querySelector('.hero').getBoundingClientRect().height;
assert.ok(Math.abs(height - 320) <= 1, `Banner je vysoký ${Math.round(height)} px, čekám 320 px (20rem)`);
```

Když se úvodní text prodlouží, banner roste a text z něj nevyteče.

```js
const hero = document.querySelector('.hero');
const lead = document.querySelector('.hero__lead');
lead.textContent = 'Tři dny hudby na soutoku Labe a Ohře. '.repeat(20);
const heroBox = hero.getBoundingClientRect();
const leadBox = lead.getBoundingClientRect();
const paddingBottom = parseFloat(getComputedStyle(hero).paddingBottom);
assert.ok(heroBox.height > 330, `S dlouhým textem je banner vysoký ${Math.round(heroBox.height)} px — má růst nad 320 px`);
assert.ok(leadBox.bottom <= heroBox.bottom - paddingBottom + 1, `Text končí na ${Math.round(leadBox.bottom)} px, banner (bez spodního paddingu) na ${Math.round(heroBox.bottom - paddingBottom)} px — text vytéká`);
```

# --help--

## --tip--

Hledáš hranici výšky, ne pevnou výšku. Rozdíl ukazuje část [Hranice velikosti: min-* a max-*](see:css-box-model/box-model#hranice-velikosti-min-a-max) a past s pevnou výškou v [Typické chyby a pasti](see:css-box-model/box-model#typicke-chyby-a-pasti).

## --tip--

Deklarace patří do pravidla `.hero`. Pevná výška text nechá vytéct, horní hranice banner nenechá dorůst na 320 px. Zbývá jedna vlastnost.

## --tip--

Stejný vzor u jiného prvku: textové pole, které má mít aspoň pět řádků a s delším textem růst, dostane `min-block-size: 8rem`.

# --explain--

Vysvětli vlastními slovy, proč banneru nestačí pevná výška a proč `min-block-size` zvládne obě přání grafika.

## --model--

Pevná výška (`height` nebo `block-size`) drží box pořád stejně vysoký, i když se obsah nevejde, takže delší text z banneru vyteče přes spodní okraj. `min-block-size` nastaví jen spodní hranici: na monitoru má banner aspoň 20rem a s delším nebo zalomeným textem se zvětší podle obsahu. Horní hranice `max-block-size` by naopak banner nenechala vůbec dorůst.

## --checklist--

- Pevná výška nedovolí boxu růst s obsahem.
- Obsah, který se do pevné výšky nevejde, vyteče ven.
- `min-block-size` určuje jen nejmenší výšku a box nad ní roste podle obsahu.
- `max-block-size` je horní hranice, na zvětšení na 20rem by nestačila.
