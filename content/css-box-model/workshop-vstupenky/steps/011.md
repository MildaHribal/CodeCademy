# --description--

Tlačítka „Koupit" jsou malá a na telefonu se do nich špatně trefuje. Tlačítko má být **aspoň 12rem (192 px) široké**. Obchodní oddělení ale už chystá delší texty („Koupit vstupenku pro celou rodinu") a s nimi má tlačítko růst, ne lámat text do tří řádků.

**Úkol:** nastav šířku tlačítka `.ticket__buy`.

Kandidáti: `inline-size`, `min-inline-size` a `max-inline-size`. Tlačítko `<button>` se chová jako `inline-block`, takže mu šířka nastavit jde; proč to u obyčejného odkazu nejde, uvidíš v lekci o normálním toku.

# --hints--

Tlačítko „Koupit" je široké 192 px (12rem).

```js
document.querySelectorAll('.ticket__buy').forEach((button, i) => {
  const width = button.getBoundingClientRect().width;
  assert.ok(Math.abs(width - 192) <= 1, `Tlačítko v kartě ${i + 1} je široké ${Math.round(width)} px, čekám 192 px`);
});
```

S delším textem je tlačítko širší než 192 px a text zůstane na jednom řádku.

```js
const button = document.querySelector('.ticket__buy');
button.textContent = 'Koupit vstupenku pro celou rodinu';
const box = button.getBoundingClientRect();
const style = getComputedStyle(button);
const lineHeight = parseFloat(style.lineHeight) || parseFloat(style.fontSize) * 1.5;
const textHeight = box.height - parseFloat(style.paddingTop) - parseFloat(style.paddingBottom);
assert.ok(box.width > 200, `S delším textem je tlačítko široké ${Math.round(box.width)} px — má růst nad 192 px`);
assert.ok(textHeight < lineHeight * 1.5, `S delším textem se text tlačítka zalomil do víc řádků (výška textu ${Math.round(textHeight)} px)`);
```

# --help--

## --tip--

Hledáš spodní hranici šířky, stejný typ úlohy jako výška banneru v sedmém kroku. Viz [Hranice velikosti: min-* a max-*](see:css-box-model/box-model#hranice-velikosti-min-a-max).

## --tip--

Deklarace patří do `.ticket__buy`. Pevná šířka nechá delší text zalomit, horní hranice tlačítko nezvětší na 192 px.

## --tip--

Stejný vzor: štítek s počtem položek v košíku, který má být aspoň kulatý, dostane `min-inline-size: 1.5rem` a s trojciferným číslem se rozšíří.
