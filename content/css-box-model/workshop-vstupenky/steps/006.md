# --description--

Text v barevném banneru `.hero` se lepí na jeho okraje. Banner potřebuje vnitřní odsazení: větší nahoře a dole, menší po stranách.

Zkratka `padding` se dvěma hodnotami bere **nejdřív nahoře a dole, pak vlevo a vpravo**. Příklad na jiném prvku:

```css
.tag {
  padding: 0.25rem 0.75rem;
}
```

**Úkol:** do pravidla `.hero` napiš `padding: 3rem 2rem`. Pozadí banneru se roztáhne i pod padding.

# --hints--

Banner má nahoře a dole vnitřní odsazení 48 px (3rem).

```js
const style = getComputedStyle(document.querySelector('.hero'));
assert.equal(style.paddingTop, '48px', 'getComputedStyle(.hero).paddingTop má být 48px');
assert.equal(style.paddingBottom, '48px', 'getComputedStyle(.hero).paddingBottom má být 48px');
```

Banner má vlevo a vpravo vnitřní odsazení 32 px (2rem).

```js
const style = getComputedStyle(document.querySelector('.hero'));
assert.equal(style.paddingLeft, '32px', 'getComputedStyle(.hero).paddingLeft má být 32px');
assert.equal(style.paddingRight, '32px', 'getComputedStyle(.hero).paddingRight má být 32px');
```
