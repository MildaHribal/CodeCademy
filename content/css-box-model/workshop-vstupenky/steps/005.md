# --description--

Přepni náhled na **375**. Banner a karty se dotýkají okrajů displeje, na telefonu to vypadá useknutě. Sloupec potřebuje vnitřní odsazení vlevo a vpravo.

Vlevo a vpravo je v češtině osa `inline`, takže deklarace je `padding-inline`. Díky resetu `border-box` z druhého kroku se padding odečte **dovnitř** ze 42rem a sloupec se na monitoru nerozšíří. Příklad na jiném prvku:

```css
.toolbar {
  padding-inline: 2rem;
}
```

**Úkol:** do pravidla `.page` doplň `padding-inline: 1rem`.

# --hints--

Na šířce 375 px začíná banner 16 px od levého okraje a končí 16 px od pravého.

```js
await helpers.resize(375);
const hero = document.querySelector('.hero').getBoundingClientRect();
const right = document.documentElement.clientWidth - hero.right;
assert.ok(Math.abs(hero.left - 16) <= 1, `Při šířce 375 px začíná banner ${Math.round(hero.left)} px od levého okraje, čekám 16 px`);
assert.ok(Math.abs(right - 16) <= 1, `Při šířce 375 px končí banner ${Math.round(right)} px od pravého okraje, čekám 16 px`);
```

Na šířce 1024 px zůstává `.page` široký 672 px a uprostřed okna, padding ho nerozšíří.

```js
const box = document.querySelector('.page').getBoundingClientRect();
const right = document.documentElement.clientWidth - box.right;
assert.ok(Math.abs(box.width - 672) <= 1, `.page je široký ${Math.round(box.width)} px, má zůstat 672 px`);
assert.ok(Math.abs(box.left - right) <= 1, `Vlevo od .page je ${Math.round(box.left)} px, vpravo ${Math.round(right)} px — sloupec má zůstat uprostřed`);
```
