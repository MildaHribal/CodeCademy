# --description--

Úvodní odstavec v banneru `.hero__lead` se na monitoru táhne přes celou šířku banneru a oko se na konci řádku těžko vrací na začátek dalšího. Odstavec má být **nejvýš 32rem (512 px) široký**. Na telefonu se má zúžit s bannerem a nesmí přetéct.

**Úkol:** omez šířku úvodního odstavce. Nadpis a datum se nemají změnit.

# --hints--

Na šířce 1024 px je úvodní odstavec široký 512 px.

```js
const width = document.querySelector('.hero__lead').getBoundingClientRect().width;
assert.ok(Math.abs(width - 512) <= 1, `Úvodní odstavec je široký ${Math.round(width)} px, čekám 512 px (32rem)`);
```

Na šířce 375 px se odstavec vejde do obsahu banneru.

```js
await helpers.resize(375);
const hero = document.querySelector('.hero');
const contentRight = hero.getBoundingClientRect().right - parseFloat(getComputedStyle(hero).paddingRight);
const lead = document.querySelector('.hero__lead').getBoundingClientRect();
assert.ok(lead.right <= contentRight + 1, `Při šířce 375 px končí odstavec na ${Math.round(lead.right)} px, obsah banneru na ${Math.round(contentRight)} px`);
```

Nadpis festivalu zůstává přes celou šířku obsahu banneru.

```js
const hero = document.querySelector('.hero');
const style = getComputedStyle(hero);
const contentWidth = hero.getBoundingClientRect().width - parseFloat(style.paddingLeft) - parseFloat(style.paddingRight);
const title = document.querySelector('.hero__title').getBoundingClientRect();
assert.ok(Math.abs(title.width - contentWidth) <= 1, `Nadpis je široký ${Math.round(title.width)} px, obsah banneru ${Math.round(contentWidth)} px`);
```

# --help--

## --tip--

Pevná šířka by na telefonu přetekla. Potřebuješ horní hranici, viz [Hranice velikosti: min-* a max-*](see:css-box-model/box-model#hranice-velikosti-min-a-max).

## --tip--

Deklarace patří do pravidla `.hero__lead`, ne do `.hero` — jinak by se zúžil celý banner včetně nadpisu.

## --tip--

Stejně se v článku omezuje délka řádku odstavců: `.article p` s `max-inline-size: 65ch`.
