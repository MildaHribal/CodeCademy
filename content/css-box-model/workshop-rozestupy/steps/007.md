# --description--

Mezery jsou teď stejné, jenže nadpis „Postup" stojí stejně daleko od surovin nad sebou jako od postupu pod sebou. Oko pak nepozná, ke kterému textu patří. Nadpis má být **blíž obsahu, který uvádí**.

**Úkol:** nad nadpisem `h2` uvnitř stacku, před kterým něco je, má být mezera **48 px** (`--space-xl`). Mezera pod nadpisy zůstane 16 px a mezera nad prvním nadpisem „Suroviny" (od fotky) se nezmění.

Kandidáti na selektor:

- `h2` — obyčejné pravidlo pro všechny nadpisy druhé úrovně,
- `.recipe__body h2` — jen nadpisy v obsahu receptu,
- `.stack > * + h2` — nadpis ve stacku, před kterým je sourozenec.

Dva z nich selžou, každý jinak. Rozhodne [[specificita]] proti pravidlům vzoru stack a to, jestli selektor vybere i první nadpis. Rozmysli si to, než napíšeš první řádek, a pak ověř v DevTools, které pravidlo v panelu Styles vyhrálo.

# --hints--

Nad nadpisem „Postup" je mezera 48 px a pod ním 16 px.

```js
const body = document.querySelector('.recipe__body');
const headings = [...body.querySelectorAll(':scope > h2')];
const second = headings[1];
const before = second.previousElementSibling.getBoundingClientRect();
const after = second.nextElementSibling.getBoundingClientRect();
const box = second.getBoundingClientRect();
assert.ok(Math.abs(box.top - before.bottom - 48) <= 1, `Nad nadpisem „Postup" je ${Math.round(box.top - before.bottom)} px, čekám 48 px`);
assert.ok(Math.abs(after.top - box.bottom - 16) <= 1, `Pod nadpisem „Postup" je ${Math.round(after.top - box.bottom)} px, čekám 16 px`);
```

Mezera mezi fotkou a prvním nadpisem „Suroviny" zůstává 32 px a pod ním 16 px.

```js
const photo = document.querySelector('.photo').getBoundingClientRect();
const first = document.querySelector('.recipe__body > h2');
const box = first.getBoundingClientRect();
const next = first.nextElementSibling.getBoundingClientRect();
assert.ok(Math.abs(box.top - photo.bottom - 32) <= 1, `Mezi fotkou a nadpisem „Suroviny" je ${Math.round(box.top - photo.bottom)} px, čekám 32 px`);
assert.ok(Math.abs(next.top - box.bottom - 16) <= 1, `Pod nadpisem „Suroviny" je ${Math.round(next.top - box.bottom)} px, čekám 16 px`);
```

# --help--

## --tip--

Mezery ve stacku drží pravidla vzoru a jiné pravidlo je přebije jen s vyšší specificitou nebo později ve stylopisu. Připomeň si [Mezery drží rodič: stack a gap](see:css-box-model/margin-collapse-a-bfc#mezery-drzi-rodic-stack-a-gap).

## --tip--

Pravidlo patří pod vzor stack v části Vzory. Obyčejný selektor typu prohraje s `.stack > * + *`, a selektor bez `+` vybere i první nadpis, kterému by margin utekl z obsahu receptu nahoru.

## --tip--

Stejný tvar selektoru použiješ, když ve stacku formuláře chceš větší mezeru jen nad tlačítkem, které není první: dítě stacku, před kterým je sourozenec, a za kombinátorem typ `button`.

# --explain--

Vysvětli vlastními slovy, proč pravidlo `h2 { margin-block-start: 3rem }` mezeru nad nadpisem ve stacku nezměnilo a proč `.recipe__body h2` nestačí.

## --model--

Mezeru nad dětmi stacku nastavuje pravidlo `.stack > * + *` se specificitou jedné třídy. Selektor `h2` má specificitu jen typu prvku, takže prohraje. `.recipe__body h2` sice vyhraje, ale vybere i první nadpis, kterému vzor margin nuluje; ten mu pak přidá mezeru nad celý obsah receptu. `.stack > * + h2` má vyšší specificitu než vzor a vybere jen nadpisy, před kterými je sourozenec.

## --checklist--

- Mezeru ve stacku nastavuje pravidlo `.stack > * + *` se specificitou jedné třídy.
- Selektor `h2` má nižší specificitu a prohraje.
- `.recipe__body h2` vybere i první nadpis, který margin mít nemá.
- `* + h2` vybere jen nadpis, před kterým je sourozenec.
