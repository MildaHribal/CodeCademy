# --description--

Text receptu je hustý. Mezery v obsahu receptu mají být **24 px** (`--space-m`) místo 16 px. Nadpisy si dál nechají 48 px nad sebou.

Vzor stack ale může mít na webu desítky míst a jinde má mezera zůstat 16 px. Druhý vzor s jiným číslem psát nechceš.

**Úkol:** udělej mezeru vzoru stack nastavitelnou vlastní vlastností `--stack-space`. Stack, kterému ji nikdo nenastaví, má dál mezeru 16 px. Obsahu receptu `.recipe__body` ji nastav na token 24 px.

Vlastní vlastnosti a jejich záložní hodnotu znáš ze sekce Základy CSS. Rozmysli si, **kde** se hodnota vlastnosti přečte: v pravidle vzoru se použije na dítě stacku, a dítě ji zdědí od rodiče.

# --hints--

V obsahu receptu je mezi dětmi 24 px a nad nadpisem „Postup" 48 px.

```js
const gaps = (parent) => {
  const kids = [...parent.children].map((el) => el.getBoundingClientRect());
  return kids.slice(1).map((box, i) => Math.round(box.top - kids[i].bottom));
};
const result = gaps(document.querySelector('.recipe__body'));
assert.deepEqual(result, [24, 48, 24, 24], 'Mezery v obsahu receptu (nadpis, suroviny, nadpis, postup, tip) mají být 24, 48, 24 a 24 px');
```

Stack, který `--stack-space` nemá, má dál mezeru 16 px; stack s `--stack-space: 40px` má 40 px.

```js
const gaps = (parent) => {
  const kids = [...parent.children].map((el) => el.getBoundingClientRect());
  return kids.slice(1).map((box, i) => Math.round(box.top - kids[i].bottom));
};
const plain = document.createElement('div');
plain.className = 'stack';
plain.innerHTML = '<p>a</p><p>b</p>';
const custom = document.createElement('div');
custom.className = 'stack';
custom.style.setProperty('--stack-space', '40px');
custom.innerHTML = '<p>a</p><p>b</p>';
document.body.append(plain, custom);
const result = [gaps(plain)[0], gaps(custom)[0]];
plain.remove();
custom.remove();
assert.equal(result[0], 16, 'Stack bez --stack-space má mít mezeru 16 px');
assert.equal(result[1], 40, 'Stack s --stack-space: 40px má mít mezeru 40 px — čte vzor mezeru z vlastní vlastnosti?');
```

# --help--

## --tip--

Vzor stack a jeho pravidla jsou v části [Mezery drží rodič: stack a gap](see:css-box-model/margin-collapse-a-bfc#mezery-drzi-rodic-stack-a-gap). Funkce `var()` bere jako druhý argument záložní hodnotu, která platí, když vlastnost nikdo nenastavil.

## --tip--

Změny jsou dvě: v pravidle vzoru se mezera přečte z `--stack-space` se záložní hodnotou z tokenu 16 px, a v pravidle `.recipe__body` se vlastnost nastaví. Pravidlo pro nadpisy se nemění.

## --tip--

Stejně funguje karta, jejíž zaoblení jde měnit: pravidlo `.card` čte `var(--card-radius, 1rem)` a varianta `.card--large` nastaví jen `--card-radius`.
