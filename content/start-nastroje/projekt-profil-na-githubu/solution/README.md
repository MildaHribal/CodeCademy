# Profil

Osobní stránka: kdo jsem, co se učím a na čem jsem pracoval. Statický web z HTML a CSS,
bez knihoven a bez JavaScriptu.

## Adresa

Web běží na <https://mildahribal.github.io/profil/>.

## Jak to spustit lokálně

Stáhnout repozitář a otevřít `index.html` v prohlížeči — nic dalšího není potřeba.

```sh
git clone git@github.com:mildahribal/profil.git
cd profil
```

## Co jsem se na tom naučil

Že `git push` je nasazení: co pošlu do větve `main`, je za minutu na veřejné adrese.
A že cesta začínající lomítkem funguje lokálně, ale na Pages míří mimo web — proto jsou
v projektu všechny cesty relativní.
