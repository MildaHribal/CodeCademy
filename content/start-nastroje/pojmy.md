## --term-- vybavování z paměti

en: retrieval practice
aliases: vybavování, vybavení z paměti, vybavit si z paměti, aktivní vybavování
lekce: start-nastroje/jak-se-ucit-v-akademii#vybavovani-z-pameti-a-opakovani-s-odstupem

Pokus vzpomenout si **bez nápovědy**, než se podíváš do materiálu. Samotné hledání v paměti
je to, co učí — proto je kontrolní otázka užitečnější než druhé přečtení výkladu.

## --term-- opakování s odstupem

en: spaced repetition
aliases: opakování s odstupy, opakováním s odstupem, rozložené opakování, spaced repetition
lekce: start-nastroje/jak-se-ucit-v-akademii#vybavovani-z-pameti-a-opakovani-s-odstupem

Vracení se k látce v rostoucích rozestupech (den, tři dny, týden, měsíc) místo jednoho
dlouhého bloku. Každé úspěšné vybavení paměťovou stopu prodlouží.

## --term-- Leitnerův systém

en: Leitner system
aliases: Leitnerova krabička, Leitnerův box, Leitnerově systému
lekce: start-nastroje/jak-se-ucit-v-akademii#vybavovani-z-pameti-a-opakovani-s-odstupem

## --term-- kalibrace

en: calibration
aliases: kalibraci, kalibrací, kalibrovat, jistota a kalibrace
lekce: start-nastroje/jak-se-ucit-v-akademii#jistota-a-kalibrace

a právě tam se učení vyplatí nejvíc. Proto se Akademie ptá na jistotu před odpovědí,
ne po ní.

## --term-- Git

en: Git
aliases: git, gitu, gitem, do gitu
mdn: https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Version_control
lekce: start-nastroje/workshop-prvni-repozitar/003

Systém pro správu verzí: ukládá stavy projektu v čase, umí se k nim vrátit a sloučit

## --term-- repozitář

en: repository
aliases: repozitáře, repozitáři, repozitářem, repozitářů, repo
lekce: start-nastroje/workshop-prvni-repozitar/003

Složka projektu plus skrytá složka `.git`, ve které Git drží celou historii. Založí se
příkazem `git init` a od té chvíle si Git všímá každé změny.

## --term-- vzdálený repozitář

en: remote repository
aliases: vzdáleného repozitáře, vzdáleném repozitáři, vzdáleným repozitářem, vzdálené repozitáře, remote, origin
lekce: start-nastroje/workshop-prvni-repozitar/014

Kopie repozitáře na serveru (typicky GitHub), se kterou si ta tvoje vyměňuje commity.
Dostane jméno — zvykem je `origin` — a pak se na ni odkazuješ jím místo celé adresy.

## --term-- GitHub Pages

en: GitHub Pages
aliases: GitHub Pages hosting, na GitHub Pages, GitHub Pagesech
lekce: start-nastroje/github-a-pages#co-jsou-github-pages

Bezplatný hosting statických stránek přímo z repozitáře na GitHubu. Co pushneš do
sledované větve, je za pár desítek vteřin na veřejné adrese.

## --term-- VS Code

en: Visual Studio Code
aliases: VS Code, VSCode, Visual Studio Code, ve VS Code, ve VS Codu
lekce: start-nastroje/vs-code#slozka-projektu

Editor kódu, ve kterém otevíráš **celou složku projektu**, ne jednotlivé soubory. Má
v sobě terminál, hledání napříč soubory a formátování při uložení.

## --term-- formátování při uložení

en: format on save
aliases: formátování na uložení, formátovat při uložení, format on save
lekce: start-nastroje/vs-code#formatovani-pri-ulozeni

Nastavení editoru, které při každém uložení srovná odsazení, uvozovky a mezery podle
jednoho pravidla. Přestaneš o formátu přemýšlet a v Gitu zmizí commity, ve kterých se
změnilo jen odsazení.
