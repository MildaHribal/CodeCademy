# --description--

Git neukládá všechno, co je ve složce. Mezi pracovní složkou a historií je ještě jedno patro: **staging area** — výčet změn, které půjdou do příštího commitu. Díky němu můžeš z deseti rozdělaných souborů uložit jen ty tři, co spolu souvisí.

**Úkol:** připrav k uložení soubory `index.html` a `styles.css` a hned za to vypiš stav, ať vidíš, jak se výpis změnil.

**Past, na kterou narazíš v kroku 13:** do staging area se uloží **obsah souboru v okamžiku, kdy ho přidáš**. Když soubor po `git add` ještě jednou změníš, ta změna v commitu nebude.

# --hints--

Oba soubory jsou připravené k uložení.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run(`${SANDBOX} git diff --cached --name-only`);
const staged = out.stdout.trim().split('\n').filter(Boolean).sort();
assert.deepEqual(staged, ['index.html', 'styles.css'], `Ke commitu jsou připravené ${JSON.stringify(staged)} — mají být index.html a styles.css`);
```

Nepořádek se k uložení nepřipravil.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run(`${SANDBOX} git diff --cached --name-only`);
assert.ok(!/DS_Store|fotky-originaly/.test(out.stdout), 'K uložení se dostal i .DS_Store nebo fotky-originaly/ — přidej jen ty dva soubory ze zadání, ne všechno');
```

Za přidáním je vidět, jak se stav změnil.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
const out = await helpers.run('bash run.sh');
assert.match(out.stdout, /Changes to be committed|k zapsání/i, `Po git add má následovat výpis stavu. Vypsalo se:\n${out.stdout.slice(-1200)}`);
const lines = files['commands.sh'].split('\n').map((l) => l.trim());
const add = lines.findIndex((l) => l.startsWith('git add'));
assert.ok(add !== -1 && lines[add + 1] === 'git status', 'Hned pod git add má být git status');
```

# --help--

## --tip--

Příkaz, který připraví soubor ke commitu, je `git add`.

## --tip--

Můžeš mu dát víc jmen souborů za sebou, oddělená mezerou. Pod něj přijde `git status`.

## --tip--

Kdybys chtěl přidat všechno ve složce, byla by to tečka (`git add .`) — tady to ale nechceš, ve složce je nepořádek.

# --explain--

Vysvětli vlastními slovy, k čemu je staging area — proč Git neuloží rovnou všechno, co je ve složce.

## --model--

Staging area je seznam změn, které půjdou do příštího commitu. Díky němu si vybíráš, **co spolu patří**: z deseti rozdělaných souborů uložíš jen ty tři, které řeší jednu věc, a zbytek necháš na příště. Commit pak jde v historii přečíst jako jedna srozumitelná změna a dá se sám o sobě vrátit. Kdyby Git ukládal rovnou celou složku, byl by každý commit směsí všeho, co jsi ten den dělal.

## --checklist--

- Staging area je výčet změn pro příští commit.
- Umožňuje uložit jen část rozdělané práce.
- Díky tomu je commit jedna srozumitelná změna.

## --file-- setup.sh

```sh
# Připraví web kempu tak, jak ti ho předala správkyně, a vedle něj prázdný „GitHub".
# Tenhle soubor neměň: každé spuštění začíná od stejného stavu.
mkdir -p fotky-originaly ../upravy

cat > index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header>
    <h1>Kemp Pod Lipou</h1>
    <p>Stany, karavany a dřevěné chatky přímo u břehu Lipna.</p>
  </header>
  <main>
    <h2>Otevírací doba</h2>
    <p>Od 1. května do 30. září, recepce denně 8:00–20:00.</p>
  </main>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0; font-family: system-ui, sans-serif; color: #1f2a1f; background: #f6f3ea; }
header { padding: 3rem 1.5rem; background: #2f5d3a; color: #fff; }
main { max-width: 40rem; margin-inline: auto; padding: 1.5rem; }
EOF

# Nepořádek, který do repozitáře nepatří: systémový soubor macOS a originály fotek.
printf 'Finder metadata\n' > .DS_Store
printf 'RAW 24 MB\n' > fotky-originaly/molo-pri-zapadu.cr3
printf 'RAW 31 MB\n' > fotky-originaly/chatky-v-lese.cr3

# Úpravy, které bys jinak udělal ve VS Code. Tady je zkopíruješ příkazem cp.
sed 's/recepce denně 8:00–20:00/recepce denně 8:00–20:00, v červenci a srpnu 7:30–21:00/' index.html > ../upravy/index-sezona.html
sed 's#<h2>Otevírací doba</h2>#<p><a href="cenik.html">Ceník ubytování</a></p>\n    <h2>Otevírací doba</h2>#' ../upravy/index-sezona.html > ../upravy/index-s-cenikem.html

cat > ../upravy/cenik-2026.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Ceník – Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <main>
    <h1>Ceník na sezónu 2026</h1>
    <ul>
      <li>Místo pro stan: 180 Kč za noc</li>
      <li>Místo pro karavan: 320 Kč za noc</li>
      <li>Chatka pro 4 osoby: 1 450 Kč za noc</li>
    </ul>
  </main>
</body>
</html>
EOF
sed -e 's/2026/2027/' -e 's/180 Kč/200 Kč/' -e 's/320 Kč/350 Kč/' -e 's/1 450 Kč/1 590 Kč/' ../upravy/cenik-2026.html > ../upravy/cenik-2027.html

# „GitHub": prázdný vzdálený repozitář ve vedlejší složce, bez sítě.
git init --bare --quiet -b main ../github/kemp.git
```

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii webu v sandbox/kemp a spustí v ní commands.sh.
# Git tu má vlastní nastavení v sandbox/gitconfig, tvoje skutečné nastavení nezmění.
rm -rf sandbox && mkdir -p sandbox/kemp && cd sandbox/kemp || exit 1
: > ../gitconfig
export GIT_CONFIG_GLOBAL="$PWD/../gitconfig" GIT_CONFIG_NOSYSTEM=1 GIT_CEILING_DIRECTORIES="$(dirname "$PWD")"
export LC_ALL=C.UTF-8 GIT_PAGER=cat GIT_EDITOR=true
bash ../../setup.sh
if [ -f ../../.gitignore ]; then cp ../../.gitignore .gitignore; fi
PS4='$ ' bash -x ../../commands.sh 2>&1
```
