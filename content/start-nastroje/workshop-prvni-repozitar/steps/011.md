# --description--

`.gitignore` zabírá hned, ale zatím ho máš jen u sebe. Aby platil i kolegům, musí se dostat do historie jako každý jiný soubor.

**Úkol:** připrav `.gitignore` ke commitu a ulož ho se zprávou `Ignorovat systémové soubory a originály fotek`.

Změnu v `index.html` z kroku 8 zatím nech být — patří do samostatného commitu. Jeden commit = jedna věc; kdyby se později ukázala jako chyba, jde vzít zpátky bez toho, aby s sebou vzala i ostatní.

# --hints--

Historie má druhý commit se správnou zprávou.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run(`${SANDBOX} git log --format=%s`);
const subjects = out.stdout.trim().split('\n').filter(Boolean);
assert.deepEqual(subjects, ['Ignorovat systémové soubory a originály fotek', 'Úvodní stránka kempu'], `Historie obsahuje ${JSON.stringify(subjects)}`);
```

Commit obsahuje jen .gitignore.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run(`${SANDBOX} git show --name-only --format= HEAD`);
const soubory = out.stdout.trim().split('\n').filter(Boolean);
assert.deepEqual(soubory, ['.gitignore'], `V commitu jsou ${JSON.stringify(soubory)} — má v něm být jen .gitignore`);
```

Změna stránky zůstala neuložená na příští commit.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run(`${SANDBOX} git status --porcelain`);
assert.match(out.stdout, /^\s*M\s+index\.html/m, `index.html má zůstat změněný a neuložený, git status --porcelain ukazuje:\n${out.stdout}`);
```

# --help--

## --tip--

Jsou to dva příkazy, které už znáš z kroků 5 a 6, jen s jiným souborem a jinou zprávou.

## --tip--

Nejdřív přidání jednoho souboru, pod ním commit se zprávou v uvozovkách.

# --explain--

Vysvětli vlastními slovy, proč se `.gitignore` commituje do repozitáře, zatímco ignorované soubory ne.

## --model--

`.gitignore` je pravidlo, ne smetí. Kdyby zůstal jen u tebe na disku, kolegům by se do repozitáře dál dostávaly `.DS_Store` a RAW fotky a každý by si musel pravidla nastavovat sám. Tím, že je v historii, platí pro všechny, kdo repozitář naklonují. Samotné ignorované soubory se necommitují proto, že jsou buď systémové smetí, nebo je jde kdykoli vyrobit znovu — a historie by s nimi jen rostla.

## --checklist--

- `.gitignore` je pravidlo pro celý tým, proto patří do historie.
- Bez commitu by platil jen na jednom počítači.
- Ignorované soubory jsou smetí nebo jde vyrobit znovu, v historii by jen zabíraly.

## --file-- setup.sh

```sh
# Připraví web kempu tak, jak ti ho předala správkyně, a vedle něj prázdný „GitHub".
# Tenhle soubor neměň: každé spuštění začíná od stejného stavu.
mkdir -p fotky-originaly ../upravy

cat > index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header>
    <h1>Kemp Pod Lipou</h1>
    <p>Stany, karavany a dřevěné chatky přímo u břehu Lipna.</p>
  </header>
  <main>
    <h2>Otevírací doba</h2>
    <p>Od 1. května do 30. září, recepce denně 8:00–20:00.</p>
  </main>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0; font-family: system-ui, sans-serif; color: #1f2a1f; background: #f6f3ea; }
header { padding: 3rem 1.5rem; background: #2f5d3a; color: #fff; }
main { max-width: 40rem; margin-inline: auto; padding: 1.5rem; }
EOF

# Nepořádek, který do repozitáře nepatří: systémový soubor macOS a originály fotek.
printf 'Finder metadata\n' > .DS_Store
printf 'RAW 24 MB\n' > fotky-originaly/molo-pri-zapadu.cr3
printf 'RAW 31 MB\n' > fotky-originaly/chatky-v-lese.cr3

# Úpravy, které bys jinak udělal ve VS Code. Tady je zkopíruješ příkazem cp.
sed 's/recepce denně 8:00–20:00/recepce denně 8:00–20:00, v červenci a srpnu 7:30–21:00/' index.html > ../upravy/index-sezona.html
sed 's#<h2>Otevírací doba</h2>#<p><a href="cenik.html">Ceník ubytování</a></p>\n    <h2>Otevírací doba</h2>#' ../upravy/index-sezona.html > ../upravy/index-s-cenikem.html

cat > ../upravy/cenik-2026.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Ceník – Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <main>
    <h1>Ceník na sezónu 2026</h1>
    <ul>
      <li>Místo pro stan: 180 Kč za noc</li>
      <li>Místo pro karavan: 320 Kč za noc</li>
      <li>Chatka pro 4 osoby: 1 450 Kč za noc</li>
    </ul>
  </main>
</body>
</html>
EOF
sed -e 's/2026/2027/' -e 's/180 Kč/200 Kč/' -e 's/320 Kč/350 Kč/' -e 's/1 450 Kč/1 590 Kč/' ../upravy/cenik-2026.html > ../upravy/cenik-2027.html

# „GitHub": prázdný vzdálený repozitář ve vedlejší složce, bez sítě.
git init --bare --quiet -b main ../github/kemp.git
```

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii webu v sandbox/kemp a spustí v ní commands.sh.
# Git tu má vlastní nastavení v sandbox/gitconfig, tvoje skutečné nastavení nezmění.
rm -rf sandbox && mkdir -p sandbox/kemp && cd sandbox/kemp || exit 1
: > ../gitconfig
export GIT_CONFIG_GLOBAL="$PWD/../gitconfig" GIT_CONFIG_NOSYSTEM=1 GIT_CEILING_DIRECTORIES="$(dirname "$PWD")"
export LC_ALL=C.UTF-8 GIT_PAGER=cat GIT_EDITOR=true
bash ../../setup.sh
if [ -f ../../.gitignore ]; then cp ../../.gitignore .gitignore; fi
PS4='$ ' bash -x ../../commands.sh 2>&1
```
