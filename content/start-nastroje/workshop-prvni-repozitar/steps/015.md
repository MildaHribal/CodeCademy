# --description--

Ceník je na GitHubu, ale z úvodní stránky na něj nevede žádný odkaz. Správkyně poslala
opravenou úvodní stránku do `../upravy/index-s-cenikem.html`.

**Úkol:** nahraď úvodní stránku touto verzí, zapiš změnu jako pátý commit a pošli ho na
GitHub. Větev už ví, kam patří, takže tentokrát žádné další argumenty nepotřebuješ.
Na konci musí být pracovní složka čistá a vzdálený repozitář stejný jako tvůj.

Tady máš hotový repozitář s historií, kterou každý přečte. Stejný cyklus budeš opakovat
v každém projektu, desetkrát denně: upravit, podívat se na stav a rozdíl, přidat, commit,
push.

## Udělej po svém

- **Vzhled:** zopakuj si cyklus na svém počítači: v kopii webu změň ve VS Code barvu
  hlavičky ve `styles.css`, prohlédni si rozdíl a zapiš ho jako samostatný commit.
- **Historie:** vyzkoušej si výpis historie s přepínačem, který ukáže i změněné soubory,
  a najdi v něm commit, který přidal ceník.
- **Chyba schválně:** commitni omylem soubor, který patří do `.gitignore`, a zjisti,
  proč ho pozdější vzor v `.gitignore` z repozitáře nevyhodí.
- **Tvoje téma:** zopakuj celý workshop na vlastním webu ve skutečném terminálu, třeba
  na profilové stránce z HTML sekce.

V lekci GitHub a GitHub Pages pošleš repozitář na skutečný GitHub a web z něj zveřejníš
na vlastní adrese.

# --hints--

Úvodní stránka v posledním commitu odkazuje na `cenik.html`.

```js
await helpers.run('bash run.sh');
const html = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git show HEAD:index.html');
assert.match(html.stdout, /href="cenik\.html"/, 'index.html v posledním commitu má obsahovat odkaz na cenik.html');
```

V historii je pět commitů a pracovní složka je čistá.

```js
await helpers.run('bash run.sh');
const count = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git rev-list --count HEAD');
assert.equal(count.stdout.trim(), '5', 'po spuštění commands.sh má být v historii pět commitů');
const status = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git status --porcelain');
assert.equal(status.stdout.trim(), '', `pracovní složka má být čistá, git status --porcelain ukazuje:\n${status.stdout}`);
```

Vzdálený repozitář má stejný poslední commit jako ty.

```js
await helpers.run('bash run.sh');
const local = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git rev-parse HEAD');
const remote = await helpers.run('git --git-dir=sandbox/github/kemp.git rev-parse --verify --quiet refs/heads/main');
assert.equal(remote.stdout.trim(), local.stdout.trim(), 'větev main ve vzdáleném repozitáři má ukazovat na tvůj poslední commit (poslal jsi ho?)');
```

# --help--

## --tip--

Je to celý cyklus z tohoto workshopu: úprava jako v kroku
[Úprava sledovaného souboru](see:start-nastroje/workshop-prvni-repozitar/009), commit
jako v kroku 12 a odeslání jako v kroku 14.

## --tip--

Za poslední výpis stavu přidej tři věci: kopírování nové verze přes `index.html`, commit
se zprávou (s přidáním souboru nebo s přepínačem `-a`) a odeslání bez argumentů.

## --tip--

Podcíle v pořadí: `# 1. přepiš index.html`, `# 2. commit`, `# 3. push`. Když push hlásí
`fatal: No configured push destination`, chybí mu vzdálený repozitář, který nastavil
předchozí krok.

# --explain--

Vysvětli, proč commit ještě není na GitHubu a co přesně udělá push.

## --model--

Commit se uloží jen do repozitáře na mém počítači, do složky `.git`. GitHub je jiný repozitář a o mém commitu neví. Push pošle commity, které vzdálený repozitář nemá, a posune v něm větev na můj poslední commit. Dokud nepushnu, práci nevidí nikdo jiný a o disk můžu přijít i s ní.

## --checklist--

- Commit se ukládá jen do lokálního repozitáře.
- Vzdálený repozitář je samostatná kopie, která o novém commitu neví.
- Push pošle chybějící commity a posune ve vzdáleném repozitáři větev.
- Bez pushe práci nikdo jiný nevidí a není zálohovaná.

## --file-- setup.sh

```sh
# Připraví web kempu tak, jak ti ho předala správkyně, a vedle něj prázdný „GitHub".
# Tenhle soubor neměň: každé spuštění začíná od stejného stavu.
mkdir -p fotky-originaly ../upravy

cat > index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header>
    <h1>Kemp Pod Lipou</h1>
    <p>Stany, karavany a dřevěné chatky přímo u břehu Lipna.</p>
  </header>
  <main>
    <h2>Otevírací doba</h2>
    <p>Od 1. května do 30. září, recepce denně 8:00–20:00.</p>
  </main>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0; font-family: system-ui, sans-serif; color: #1f2a1f; background: #f6f3ea; }
header { padding: 3rem 1.5rem; background: #2f5d3a; color: #fff; }
main { max-width: 40rem; margin-inline: auto; padding: 1.5rem; }
EOF

# Nepořádek, který do repozitáře nepatří: systémový soubor macOS a originály fotek.
printf 'Finder metadata\n' > .DS_Store
printf 'RAW 24 MB\n' > fotky-originaly/molo-pri-zapadu.cr3
printf 'RAW 31 MB\n' > fotky-originaly/chatky-v-lese.cr3

# Úpravy, které bys jinak udělal ve VS Code. Tady je zkopíruješ příkazem cp.
sed 's/recepce denně 8:00–20:00/recepce denně 8:00–20:00, v červenci a srpnu 7:30–21:00/' index.html > ../upravy/index-sezona.html
sed 's#<h2>Otevírací doba</h2>#<p><a href="cenik.html">Ceník ubytování</a></p>\n    <h2>Otevírací doba</h2>#' ../upravy/index-sezona.html > ../upravy/index-s-cenikem.html

cat > ../upravy/cenik-2026.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Ceník – Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <main>
    <h1>Ceník na sezónu 2026</h1>
    <ul>
      <li>Místo pro stan: 180 Kč za noc</li>
      <li>Místo pro karavan: 320 Kč za noc</li>
      <li>Chatka pro 4 osoby: 1 450 Kč za noc</li>
    </ul>
  </main>
</body>
</html>
EOF
sed -e 's/2026/2027/' -e 's/180 Kč/200 Kč/' -e 's/320 Kč/350 Kč/' -e 's/1 450 Kč/1 590 Kč/' ../upravy/cenik-2026.html > ../upravy/cenik-2027.html

# „GitHub": prázdný vzdálený repozitář ve vedlejší složce, bez sítě.
git init --bare --quiet -b main ../github/kemp.git
```

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii webu v sandbox/kemp a spustí v ní commands.sh.
# Git tu má vlastní nastavení v sandbox/gitconfig, tvoje skutečné nastavení nezmění.
rm -rf sandbox && mkdir -p sandbox/kemp && cd sandbox/kemp || exit 1
: > ../gitconfig
export GIT_CONFIG_GLOBAL="$PWD/../gitconfig" GIT_CONFIG_NOSYSTEM=1 GIT_CEILING_DIRECTORIES="$(dirname "$PWD")"
export LC_ALL=C.UTF-8 GIT_PAGER=cat GIT_EDITOR=true
bash ../../setup.sh
if [ -f ../../.gitignore ]; then cp ../../.gitignore .gitignore; fi
PS4='$ ' bash -x ../../commands.sh 2>&1
```
