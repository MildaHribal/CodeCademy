# --description--

Každý commit si pamatuje, kdo ho udělal. Git to neuhodne — jméno a e-mail mu musíš říct, jinak první commit odmítne udělat.

**Úkol:** nastav globálně jméno `Jana Nováková` a e-mail `jana.novakova@example.cz`.

Nastavení se tu ukládá do dočasného souboru v `sandbox/`, tvoje skutečné nastavení Gitu to nezmění.

# --hints--

Git zná jméno autorky commitů.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run('cd sandbox && git config --file gitconfig user.name');
assert.equal(out.stdout.trim(), 'Jana Nováková', `user.name je „${out.stdout.trim()}“ — má být Jana Nováková`);
```

Git zná i její e-mail.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
await helpers.run('bash run.sh');
const out = await helpers.run('cd sandbox && git config --file gitconfig user.email');
assert.equal(out.stdout.trim(), 'jana.novakova@example.cz', `user.email je „${out.stdout.trim()}“`);
```

Nastavení je globální, ne jen pro jeden repozitář.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
assert.match(files['commands.sh'], /git config\s+--global\s+user\.name/, 'Jméno nastav přepínačem --global, ať platí pro všechny repozitáře');
assert.match(files['commands.sh'], /git config\s+--global\s+user\.email/, 'E-mail nastav taky s --global');
```

# --help--

## --tip--

Nastavení Gitu se dělá příkazem `git config`; klíče se jmenují `user.name` a `user.email`.

## --tip--

Tvar je `git config --global <klíč> "<hodnota>"`. Hodnotu se jménem dej do uvozovek, je v ní mezera.

## --tip--

Bez `--global` by nastavení platilo jen pro repozitář, ve kterém zrovna stojíš.

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii webu v sandbox/kemp a spustí v ní commands.sh.
# Git tu má vlastní nastavení v sandbox/gitconfig, tvoje skutečné nastavení nezmění.
rm -rf sandbox && mkdir -p sandbox/kemp && cd sandbox/kemp || exit 1
: > ../gitconfig
export GIT_CONFIG_GLOBAL="$PWD/../gitconfig" GIT_CONFIG_NOSYSTEM=1 GIT_CEILING_DIRECTORIES="$(dirname "$PWD")"
export LC_ALL=C.UTF-8 GIT_PAGER=cat GIT_EDITOR=true
bash ../../setup.sh
if [ -f ../../.gitignore ]; then cp ../../.gitignore .gitignore; fi
PS4='$ ' bash -x ../../commands.sh 2>&1
```
