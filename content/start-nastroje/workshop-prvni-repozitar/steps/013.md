# --description--

## Hlášení

Kolega Petr doplnil do `commands.sh` stránku s ceníkem. Nejdřív tam dal loňský ceník,
pak ho přepsal ceníkem na rok 2027 a udělal commit „Ceník na sezónu 2027". Jenže v tom
commitu je stránka s nadpisem „Ceník na sezónu 2026" a starými cenami (stan 180 Kč) a výpis
stavu po commitu pořád hlásí `modified: cenik.html`.

## Úkol

Oprav Petrovy řádky tak, aby commit „Ceník na sezónu 2027" obsahoval ceník na rok 2027
a po commitu nezůstala žádná neuložená změna. Předchozí commity nech, jak jsou.

# --hints--

Commit „Ceník na sezónu 2027" obsahuje ceník na rok 2027.

```js
await helpers.run('bash run.sh');
const subject = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git log -1 --format=%s');
assert.equal(subject.stdout.trim(), 'Ceník na sezónu 2027', 'poslední commit má být Petrův „Ceník na sezónu 2027"');
const html = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git show HEAD:cenik.html');
assert.match(html.stdout, /Ceník na sezónu 2027/, 'cenik.html v posledním commitu má mít nadpis Ceník na sezónu 2027');
assert.match(html.stdout, /200 Kč/, 'cenik.html v posledním commitu má mít cenu stanu 200 Kč');
```

Po commitu ve složce nezůstala žádná neuložená změna.

```js
await helpers.run('bash run.sh');
const result = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git status --porcelain');
assert.equal(result.stdout.trim(), '', `pracovní složka má být po commitu čistá, git status --porcelain ukazuje:\n${result.stdout}`);
```

Historie má čtyři commity a ty předchozí zůstaly beze změny.

```js
await helpers.run('bash run.sh');
const result = await helpers.run('cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname "$PWD")" git log --format=%s');
assert.deepEqual(result.stdout.trim().split('\n'), ['Ceník na sezónu 2027', 'Letní otevírací doba recepce', 'Ignorovat systémové soubory a originály fotek', 'Úvodní stránka kempu'], 'historie má obsahovat čtyři commity: tři předchozí a ceník');
```

# --help--

## --tip--

Vzpomeň si na druhou past v kroku [Staging area](see:start-nastroje/workshop-prvni-repozitar/005):
`git add` ukládá obsah souboru v okamžiku přidání, ne v okamžiku commitu.

## --tip--

Podívej se, v jakém pořadí jdou Petrovy řádky: kdy se soubor přidává a kdy se naposledy
mění. Stačí přesunout jeden řádek.

## --tip--

Stejná chyba u stylů: přidat `styles.css`, pak ho přepsat novou verzí a udělat commit.
Oprava je přidat soubor až po poslední úpravě, těsně před commitem.

## --file-- commands.sh

```sh
# Příkazy pro web Kempu Pod Lipou.
# Běží shora dolů v čisté kopii webu (sandbox/kemp), jako bys je psal do terminálu.

pwd
ls -a

git config --global user.name "Jana Nováková"

git init -b main
git status

git add index.html styles.css
git status

git commit -m "Úvodní stránka kempu"
git log --oneline

cp ../upravy/index-sezona.html index.html
git status
git diff

git add .gitignore
git commit -m "Ignorovat systémové soubory a originály fotek"

git add index.html
git commit -m "Letní otevírací doba recepce"

# Ceník od Petra
cp ../upravy/cenik-2026.html cenik.html
git add cenik.html
cp ../upravy/cenik-2027.html cenik.html
git commit -m "Ceník na sezónu 2027"
git status
```

## --file-- setup.sh

```sh
# Připraví web kempu tak, jak ti ho předala správkyně, a vedle něj prázdný „GitHub".
# Tenhle soubor neměň: každé spuštění začíná od stejného stavu.
mkdir -p fotky-originaly ../upravy

cat > index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header>
    <h1>Kemp Pod Lipou</h1>
    <p>Stany, karavany a dřevěné chatky přímo u břehu Lipna.</p>
  </header>
  <main>
    <h2>Otevírací doba</h2>
    <p>Od 1. května do 30. září, recepce denně 8:00–20:00.</p>
  </main>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0; font-family: system-ui, sans-serif; color: #1f2a1f; background: #f6f3ea; }
header { padding: 3rem 1.5rem; background: #2f5d3a; color: #fff; }
main { max-width: 40rem; margin-inline: auto; padding: 1.5rem; }
EOF

# Nepořádek, který do repozitáře nepatří: systémový soubor macOS a originály fotek.
printf 'Finder metadata\n' > .DS_Store
printf 'RAW 24 MB\n' > fotky-originaly/molo-pri-zapadu.cr3
printf 'RAW 31 MB\n' > fotky-originaly/chatky-v-lese.cr3

# Úpravy, které bys jinak udělal ve VS Code. Tady je zkopíruješ příkazem cp.
sed 's/recepce denně 8:00–20:00/recepce denně 8:00–20:00, v červenci a srpnu 7:30–21:00/' index.html > ../upravy/index-sezona.html
sed 's#<h2>Otevírací doba</h2>#<p><a href="cenik.html">Ceník ubytování</a></p>\n    <h2>Otevírací doba</h2>#' ../upravy/index-sezona.html > ../upravy/index-s-cenikem.html

cat > ../upravy/cenik-2026.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Ceník – Kemp Pod Lipou</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <main>
    <h1>Ceník na sezónu 2026</h1>
    <ul>
      <li>Místo pro stan: 180 Kč za noc</li>
      <li>Místo pro karavan: 320 Kč za noc</li>
      <li>Chatka pro 4 osoby: 1 450 Kč za noc</li>
    </ul>
  </main>
</body>
</html>
EOF
sed -e 's/2026/2027/' -e 's/180 Kč/200 Kč/' -e 's/320 Kč/350 Kč/' -e 's/1 450 Kč/1 590 Kč/' ../upravy/cenik-2026.html > ../upravy/cenik-2027.html

# „GitHub": prázdný vzdálený repozitář ve vedlejší složce, bez sítě.
git init --bare --quiet -b main ../github/kemp.git
```

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii webu v sandbox/kemp a spustí v ní commands.sh.
# Git tu má vlastní nastavení v sandbox/gitconfig, tvoje skutečné nastavení nezmění.
rm -rf sandbox && mkdir -p sandbox/kemp && cd sandbox/kemp || exit 1
: > ../gitconfig
export GIT_CONFIG_GLOBAL="$PWD/../gitconfig" GIT_CONFIG_NOSYSTEM=1 GIT_CEILING_DIRECTORIES="$(dirname "$PWD")"
export LC_ALL=C.UTF-8 GIT_PAGER=cat GIT_EDITOR=true
bash ../../setup.sh
if [ -f ../../.gitignore ]; then cp ../../.gitignore .gitignore; fi
PS4='$ ' bash -x ../../commands.sh 2>&1
```
