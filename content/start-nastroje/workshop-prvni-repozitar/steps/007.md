# --description--

Commit existuje, ale zatím ho nevidíš. Výpis historie ti ukáže, co je uložené — a v krátké podobě se vejde jeden commit na řádek, takže se dá přehlédnout i dlouhá historie.

**Úkol:** vypiš historii v krátké podobě, jeden commit na řádek.

Na začátku řádku je **hash commitu** — jeho jednoznačné jméno. Git ho zkracuje na sedm znaků a s takovou zkratkou se dá pracovat všude, kde se commit jmenuje.

# --hints--

Výstup obsahuje historii v krátké podobě.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
const out = await helpers.run('bash run.sh');
assert.match(out.stdout, /[0-9a-f]{7}\s+Úvodní stránka kempu/, `Ve výstupu není řádek s hashem a zprávou commitu. Vypsalo se:\n${out.stdout.slice(-1200)}`);
```

Výpis je krátký, ne plný.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
assert.match(files['commands.sh'], /git log[^\n]*--oneline/, 'Použij git log s přepínačem --oneline, ať je commit na jednom řádku');
const out = await helpers.run('bash run.sh');
assert.ok(!/^commit [0-9a-f]{40}/m.test(out.stdout), 'Výpis je pořád plný — chybí přepínač pro krátkou podobu');
```

Výpis historie stojí až za commitem.

```js
const SANDBOX = 'cd sandbox/kemp && GIT_CEILING_DIRECTORIES="$(dirname \"$PWD\")" &&';
const lines = files['commands.sh'].split('\n').map((l) => l.trim()).filter(Boolean);
const commit = lines.findIndex((l) => l.startsWith('git commit'));
const log = lines.findIndex((l) => l.startsWith('git log'));
assert.ok(commit !== -1 && log > commit, 'git log patří až pod git commit — jinak by nebylo co vypisovat');
```


## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii webu v sandbox/kemp a spustí v ní commands.sh.
# Git tu má vlastní nastavení v sandbox/gitconfig, tvoje skutečné nastavení nezmění.
rm -rf sandbox && mkdir -p sandbox/kemp && cd sandbox/kemp || exit 1
: > ../gitconfig
export GIT_CONFIG_GLOBAL="$PWD/../gitconfig" GIT_CONFIG_NOSYSTEM=1 GIT_CEILING_DIRECTORIES="$(dirname "$PWD")"
export LC_ALL=C.UTF-8 GIT_PAGER=cat GIT_EDITOR=true
bash ../../setup.sh
if [ -f ../../.gitignore ]; then cp ../../.gitignore .gitignore; fi
PS4='$ ' bash -x ../../commands.sh 2>&1
```
