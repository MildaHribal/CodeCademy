# --description--

Kolega napsal skript `scripts/check-links.mjs`: projde stránky a u každého obrázku
vypíše, jestli existuje. Nalezené píše na **standardní výstup** (`OK: …`),
chybějící na **chybový výstup** (`Chybí: …`).

Spusť ho tak, aby **celý** jeho výstup — obě části — skončil v souboru `links.txt`
a v terminálu po něm nezůstalo nic. Samotné `>` nestačí (proč, víš z předpovědi
v lekci). Kandidáti: `2>`, `2>&1`, `&>` — a záleží na pořadí.

# --hints--

`links.txt` obsahuje řádky `OK: …` i řádek `Chybí: kontakt.html -> img/terasa.jpg`.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const links = await readFile(`${helpers.dir}/kafe-na-rohu/links.txt`, 'utf8').catch(() => null);
assert.ok(links !== null, 'po spuštění má v kořeni projektu existovat links.txt');
assert.ok(links.includes('OK: index.html -> img/latte.jpg'), 'links.txt má obsahovat standardní výstup kontroly (řádky OK: …)');
assert.ok(links.includes('Chybí: kontakt.html -> img/terasa.jpg'), 'links.txt má obsahovat i chybový výstup kontroly (řádek Chybí: kontakt.html -> img/terasa.jpg)');
```

Výstup kontroly se neobjeví v terminálu.

```js
const run = await helpers.run('bash run.sh');
const shown = run.stdout + run.stderr;
assert.ok(!shown.includes('Chybí:') && !shown.includes('OK: index.html'), 'v terminálu nemá z kontroly obrázků zůstat nic — oba výstupy mají jít do links.txt');
```

# --help--

## --tip--

Pořadí přesměrování je vysvětlené v části [Přesměrování do souboru](see:nastroje-git-terminal/terminal-do-hloubky#presmerovani-do-souboru) i s předpovědí.

## --tip--

`2>&1` pošle chybový výstup tam, kam **v tu chvíli** vede standardní. Nejdřív tedy
musí standardní výstup mířit do souboru, teprve pak ho chybový může následovat.

## --tip--

Stejný tvar na jiných datech — build se vším do logu:
`npm run build > build.log 2>&1`

# --explain--

Vysvětli, proč by `node scripts/check-links.mjs 2>&1 > links.txt` nechal řádek `Chybí: …` v terminálu.

## --model--

Program má dva výstupy a shell přesměrování čte zleva doprava. `2>&1` pošle chybový
výstup tam, kam v tu chvíli vede standardní, a to je pořád terminál. Až potom `>`
přesměruje standardní výstup do souboru, chybový ale zůstane mířit do terminálu.

## --checklist--

- Standardní a chybový výstup jsou dva oddělené proudy.
- Přesměrování se vyhodnocují zleva doprava.
- `2>&1` zkopíruje, kam vede stdout právě teď, nesleduje pozdější změny.

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF

// Vypíše plné adresy všech stránek. Adresu webu bere z proměnné prostředí SITE_URL.
import { readdirSync } from 'node:fs';

const siteUrl = process.env.SITE_URL;
if (!siteUrl) {
  console.error('Chybí proměnná prostředí SITE_URL (adresa webu, třeba https://example.cz).');
  process.exit(1);
}
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  console.log(new URL(page, siteUrl).href);
}
EOF
