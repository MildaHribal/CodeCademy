# --description--

Kolegovi pošleš soubor `report.txt` s tím, co jsi v projektu našel. První část bude
seznam fotek ve složce `img`.

Výstup příkazu nemusí jít do terminálu. `>` ho [[přesměrování|přesměruje]] do souboru:
soubor vytvoří, a když už existuje, **nejdřív ho vyprázdní**.

```sh
ls docs > documents.txt
```

**Úkol:** přidej příkaz, který zapíše výpis složky `img` do nového souboru
`report.txt` v kořeni projektu.

# --hints--

`report.txt` obsahuje právě jména čtyř fotek, každé na jednom řádku.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const report = await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => null);
assert.ok(report !== null, 'po spuštění má v kořeni projektu existovat report.txt');
const lines = report.split('\n').map((line) => line.trim()).filter(Boolean).sort();
assert.deepEqual(lines, ['IMG_2041.jpg', 'IMG_2042.jpg', 'interier.webp', 'latte.jpg'], 'report.txt má obsahovat jen výpis složky img: čtyři fotky, každou na řádku');
```

Když `report.txt` v projektu už je (třeba starý report), nový ho přepíše.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run(`rm -rf alt && mkdir alt && cp run.sh commands.sh alt/ && (cat setup.sh; echo; echo 'echo "starý report" > report.txt') > alt/setup.sh`);
await helpers.run('cd alt && bash run.sh');
const report = await readFile(`${helpers.dir}/alt/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
assert.ok(!report.includes('starý report'), 'když report.txt už existuje se starým obsahem, má ho příkaz přepsat, ne k němu připisovat');
```

# --explain--

Příkazy v `commands.sh` pouštíš pořád znovu. Vysvětli, proč report začíná `>`
a ne `>>`, a co by se stalo, kdybys je spouštěl opakovaně v jednom skutečném projektu.

## --model--

`>` soubor před zápisem vyprázdní, takže každé spuštění vyrobí report znovu od začátku
a vypadá pokaždé stejně. `>>` připisuje na konec. Ve skutečném projektu by každé
spuštění přidalo další kopii seznamu pod tu starou a report by rostl.

## --checklist--

- `>` soubor přepíše (nejdřív vyprázdní).
- `>>` připisuje na konec existujícího obsahu.
- První zápis do reportu má přepsat, aby opakované spuštění dalo stejný výsledek.

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF
