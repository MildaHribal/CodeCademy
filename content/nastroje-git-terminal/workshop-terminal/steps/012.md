# --description--

## Hlášení

Honza ti poslal ještě jeden kus do `commands.sh`: připraví čistou složku `dist/`
se stránkami a styly, které se nahrají na hosting. „U mě to funguje," píše.

Po spuštění ale z projektu zmizelo úplně všechno — stránky, fotky i report.
Ve výstupu je hláška `cd: dist: No such file or directory` (česky „Adresář nebo
soubor neexistuje") a po ní `cp` hlásí, že nenašel žádné `*.html`. U Honzy to
fungovalo, protože on složku `dist` už měl z minula.

## Úkol

Oprav kolegovy řádky tak, aby projekt přežil, i když `dist` ještě neexistuje,
a aby se `dist` dál vyprázdnila, když existuje. Změň co nejmenší kus.

# --hints--

Stránky, fotky i report po spuštění zůstanou v projektu.

```js
const { existsSync } = await import('node:fs');
await helpers.run('bash run.sh');
for (const name of ['index.html', 'img/latte.jpg', 'report.txt', 'links.txt']) {
  assert.ok(existsSync(`${helpers.dir}/kafe-na-rohu/${name}`), `po spuštění má v projektu zůstat ${name} — úklid dist nesmí mazat kořen projektu`);
}
```

Ve složce `dist` jsou právě tři stránky a `styles.css`.

```js
const { readdirSync } = await import('node:fs');
await helpers.run('bash run.sh');
let dist = [];
try { dist = readdirSync(`${helpers.dir}/kafe-na-rohu/dist`).sort(); } catch {}
assert.deepEqual(dist, ['index.html', 'kontakt.html', 'menu.html', 'styles.css'], 'kafe-na-rohu/dist má obsahovat index.html, kontakt.html, menu.html a styles.css');
```

Když `dist` už existuje se starým souborem, starý soubor zmizí.

```js
const { readdirSync } = await import('node:fs');
await helpers.run(`rm -rf alt && mkdir alt && cp run.sh commands.sh alt/ && (cat setup.sh; echo; echo 'mkdir -p dist && echo "stará akce" > dist/letni-akce.html') > alt/setup.sh`);
await helpers.run('cd alt && bash run.sh');
let dist = [];
try { dist = readdirSync(`${helpers.dir}/alt/kafe-na-rohu/dist`); } catch {}
assert.ok(!dist.includes('letni-akce.html'), 'když dist už existuje, mají se z ní staré soubory (letni-akce.html) před kopírováním smazat');
assert.ok(dist.includes('index.html'), 'dist má i pak obsahovat nové stránky');
```

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF

cat > scripts/sitemap.mjs <<'EOF'
// Vypíše plné adresy všech stránek. Adresu webu bere z proměnné prostředí SITE_URL.
import { readdirSync } from 'node:fs';

const siteUrl = process.env.SITE_URL;
if (!siteUrl) {
  console.error('Chybí proměnná prostředí SITE_URL (adresa webu, třeba https://example.cz).');
  process.exit(1);
}
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  console.log(new URL(page, siteUrl).href);
}
EOF
