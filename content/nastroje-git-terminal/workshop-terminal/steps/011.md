# --description--

Kontrola obrázků skončí [[návratový kód|návratovým kódem]] 1, když něco chybí,
a kódem 0, když je všechno v pořádku. Tlačítko **Spustit** ti kód posledního
příkazu ukáže pod výstupem.

**Úkol:** uprav řádek s kontrolou tak, aby do reportu připsal řádek
`POZOR: chybí obrázky, viz links.txt` — ale **jen když kontrola selže**. Když jsou
všechny obrázky na místě, v reportu žádné upozornění nebude. Výstup kontroly
dál končí celý v `links.txt`.

# --hints--

Kolegův projekt má chybějící obrázek, takže report obsahuje řádek `POZOR: chybí obrázky, viz links.txt`.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const lines = (await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '')).split('\n').map((row) => row.trim());
assert.ok(lines.includes('POZOR: chybí obrázky, viz links.txt'), 'když kontrola obrázků selže, má report.txt obsahovat řádek POZOR: chybí obrázky, viz links.txt');
```

Když všechny obrázky existují, report upozornění neobsahuje a `links.txt` je pořád plný.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run(`rm -rf alt && mkdir alt && cp run.sh commands.sh alt/ && sed 's#img/terasa.jpg#img/latte.jpg#' setup.sh > alt/setup.sh`);
await helpers.run('cd alt && bash run.sh');
const report = await readFile(`${helpers.dir}/alt/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
const links = await readFile(`${helpers.dir}/alt/kafe-na-rohu/links.txt`, 'utf8').catch(() => '');
assert.ok(!report.includes('POZOR'), 'když kontrola obrázků projde (kód 0), nemá report.txt obsahovat upozornění POZOR');
assert.ok(links.includes('OK: kontakt.html -> img/latte.jpg'), 'výstup kontroly má dál končit v links.txt');
```

# --help--

## --tip--

Spouštění podle výsledku předchozího příkazu je v části [Skládání příkazů podle výsledku](see:nastroje-git-terminal/terminal-do-hloubky#skladani-prikazu-podle-vysledku).

## --tip--

Ze tří spojek `;`, `&&` a `||` potřebuješ tu, která druhý příkaz spustí jen po
neúspěchu prvního. Patří na konec řádku s kontrolou, za přesměrování.

## --tip--

Stejný vzor na jiných datech — když testy neprojdou, zapiš to do souboru:
`npm test > test.log 2>&1 || echo "Testy selhaly" >> status.txt`

# --explain--

Vysvětli, podle čeho shell pozná, jestli má příkaz za spojkou spustit, a proč
by na tom místě středník nefungoval.

## --model--

Shell se neřídí textem výstupu, ale návratovým kódem: 0 je úspěch, cokoli jiného
chyba. `||` spustí druhý příkaz jen po nenulovém kódu, `&&` jen po nule. Středník
na kód nehledí a spustí druhý příkaz vždycky, takže by upozornění bylo v reportu
i u projektu bez chyb.

## --checklist--

- Rozhoduje návratový kód, ne vypsaný text.
- Kód 0 je úspěch, nenulový kód chyba.
- `||` spustí druhý příkaz jen po chybě.
- Středník spustí druhý příkaz vždycky.

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF

// Vypíše plné adresy všech stránek. Adresu webu bere z proměnné prostředí SITE_URL.
import { readdirSync } from 'node:fs';

const siteUrl = process.env.SITE_URL;
if (!siteUrl) {
  console.error('Chybí proměnná prostředí SITE_URL (adresa webu, třeba https://example.cz).');
  process.exit(1);
}
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {

}
EOF
