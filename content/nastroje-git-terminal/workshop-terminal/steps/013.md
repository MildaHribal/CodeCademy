# --description--

Hosting chce soubor se všemi adresami stránek. Kolegův skript `scripts/sitemap.mjs`
je vypíše, jen potřebuje vědět adresu webu — čte ji z proměnné prostředí `SITE_URL`.
Když ji nedostane, skončí chybou.

**Úkol:** vytvoř v kořeni projektu `sitemap.txt` s plnými adresami všech tří stránek
na webu `https://kafenarohu.cz`. Nastavení proměnné se nemá dostat do souborů
projektu.

# --hints--

`sitemap.txt` obsahuje adresy `https://kafenarohu.cz/index.html`, `…/kontakt.html` a `…/menu.html`.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const sitemap = await readFile(`${helpers.dir}/kafe-na-rohu/sitemap.txt`, 'utf8').catch(() => null);
assert.ok(sitemap !== null, 'po spuštění má v kořeni projektu existovat sitemap.txt');
const lines = sitemap.split('\n').map((row) => row.trim()).filter(Boolean).sort();
assert.deepEqual(lines, ['https://kafenarohu.cz/index.html', 'https://kafenarohu.cz/kontakt.html', 'https://kafenarohu.cz/menu.html'], 'sitemap.txt má obsahovat plné adresy tří stránek na https://kafenarohu.cz, každou na řádku');
```

Skript se proměnnou prostředí nechal nastavit, takže v terminálu nehlásí chybějící `SITE_URL`.

```js
const run = await helpers.run('bash run.sh');
assert.ok(!(run.stdout + run.stderr).includes('Chybí proměnná prostředí SITE_URL'), 'sitemap.mjs nemá hlásit chybějící SITE_URL — proměnnou mu předej při spuštění');
```

# --help--

## --tip--

Jak předat proměnnou prostředí jednomu příkazu, je v části [Proměnné prostředí a PATH](see:nastroje-git-terminal/terminal-do-hloubky#promenne-prostredi-a-path).

## --tip--

Proměnná napsaná na samostatném řádku bez `export` zůstane jen v shellu a `node`
ji nedostane. Buď ji napiš přímo před příkaz, nebo ji exportuj. Výstup pak přesměruj do souboru.

## --tip--

Stejný vzor na jiných datech: `PORT=8080 node server.js > server.log`

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF

cat > scripts/sitemap.mjs <<'EOF'
// Vypíše plné adresy všech stránek. Adresu webu bere z proměnné prostředí SITE_URL.
import { readdirSync } from 'node:fs';

const siteUrl = process.env.SITE_URL;
if (!siteUrl) {
  console.error('Chybí proměnná prostředí SITE_URL (adresa webu, třeba https://example.cz).');
  process.exit(1);
}
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  console.log(new URL(page, siteUrl).href);
}
EOF
