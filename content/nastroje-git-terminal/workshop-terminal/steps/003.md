# --description--

V kořeni leží `debug.log` a `npm-debug.log` z kolegova ladění. Do projektu nepatří.

`rm` soubory maže — **bez koše a bez ptaní**. Proto se vzor s hvězdičkou vyplatí
nejdřív zkusit přes `ls` a teprve pak ho dát do `rm`:

```sh
ls *.tmp
rm *.tmp
```

**Úkol:** přidej příkaz, který smaže všechny soubory `.log` v kořeni projektu.

> [!PITFALL]
> Mezera navíc mění všechno: `rm * .log` není „soubory končící na .log", ale
> „všechno (`*`) a k tomu soubor `.log`". Smazal by celý kořen projektu.

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF
