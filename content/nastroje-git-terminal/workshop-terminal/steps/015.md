# --description--

Poslední drobnost: ať kolega vidí report hned po spuštění, bez otevírání souboru.

**Úkol:** úplně na konci vypiš celý obsah `report.txt` do terminálu.

Tím je úklid hotový. Jednou sérií příkazů jsi přesunul a smazal soubory,
prohledal kód, spočítal prodeje rourou, rozdělil výstupy programu, podmínil příkaz
návratovým kódem, opravil nebezpečné `cd; rm` a předal skriptu proměnnou prostředí.
Přesně takhle vypadá každodenní práce v terminálu: log z buildu, hledání v cizím
projektu, skript na nasazení. V další lekci se podíváš, jak uvnitř funguje Git — i ten
budeš ovládat z terminálu.

## Udělej po svém

- **Vizuální:** udělej z reportu Markdown (`## TODO` místo `== TODO ==`) a otevři ho
  v náhledu VS Code.
- **Funkční:** přidej do reportu počet řádků CSS a JavaScriptu v projektu —
  `wc -l` umí víc souborů najednou.
- **Po svém:** vezmi vlastní projekt a napiš si `cleanup.sh`, který v něm najde
  `console.log`, `TODO` a soubory větší než 1 MB (`find -size`).

# --hints--

Výstup po spuštění končí celým obsahem `report.txt`.

```js
const { readFile } = await import('node:fs/promises');
const run = await helpers.run('bash run.sh');
const report = await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
const squash = (text) => text.split('\n').map((row) => row.trim().replace(/\s+/g, ' ')).filter(Boolean).join('\n');
assert.ok(squash(report).length > 0 && squash(run.stdout).endsWith(squash(report)), 'na konci výstupu commands.sh má být vypsaný celý report.txt');
```

Report má všechny části: fotky, TODO, počet `console.log`, nejprodávanější položky a chybějící obrázky.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const report = await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
for (const part of ['latte.jpg', '== TODO ==', '== console.log ==', '== Nejprodávanější ==', 'POZOR: chybí obrázky', 'Chybí: kontakt.html -> img/terasa.jpg']) {
  assert.ok(report.includes(part), `report.txt má pořád obsahovat „${part}"`);
}
```

Výpis souboru do terminálu znáš z [Přesměrování do souboru](see:nastroje-git-terminal/terminal-do-hloubky#presmerovani-do-souboru), tam se jím kontroluje `log.txt`.

cd dist && rm -rf * && cd ..

SITE_URL=https://kafenarohu.cz node scripts/sitemap.mjs > sitemap.txt
grep "Chybí" links.txt >> report.txt
--edit--

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF

cat > scripts/sitemap.mjs <<'EOF'
// Vypíše plné adresy všech stránek. Adresu webu bere z proměnné prostředí SITE_URL.
import { readdirSync } from 'node:fs';

const siteUrl = process.env.SITE_URL;
if (!siteUrl) {
  console.error('Chybí proměnná prostředí SITE_URL (adresa webu, třeba https://example.cz).');
  process.exit(1);
}
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  console.log(new URL(page, siteUrl).href);
}
EOF
