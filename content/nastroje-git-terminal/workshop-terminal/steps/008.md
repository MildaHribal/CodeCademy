# --description--

Majitelka chce vědět, co se v kavárně prodává nejvíc. Objednávky jsou v `data/orders.csv`:

```text
datum;polozka;cena
2026-09-01;Flat white;75
2026-09-01;Espresso;55
```

Tahle roura je delší než všechno dosud, proto ji poskládáš z řádků. Výsledkem má být
nadpis `== Nejprodávanější ==` a pod ním tři položky s počtem prodejů, od nejčastější.
Zpětné lomítko `\` na konci řádku znamená „příkaz pokračuje na dalším řádku", takže
dlouhou rouru jde číst shora dolů. Dva řádky jsou navíc.

# --hints--

Pod nadpisem `== Nejprodávanější ==` jsou tři řádky: `5 Flat white`, `4 Espresso`, `3 Cappuccino`.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const lines = (await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '')).split('\n').map((row) => row.trim().replace(/\s+/g, ' '));
const heading = lines.indexOf('== Nejprodávanější ==');
assert.ok(heading >= 0, 'report.txt má obsahovat nadpis == Nejprodávanější ==');
assert.deepEqual(lines.slice(heading + 1, heading + 4), ['5 Flat white', '4 Espresso', '3 Cappuccino'], 'pod nadpisem mají být tři nejprodávanější položky s počtem, od nejčastější');
```

Starší části reportu zůstaly.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const report = await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
assert.ok(report.includes('latte.jpg') && report.includes('== console.log =='), 'report.txt má dál obsahovat fotky i počet console.log — pořadí připisuj přes >>');
```

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF
