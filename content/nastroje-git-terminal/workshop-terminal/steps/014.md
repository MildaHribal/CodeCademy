# --description--

V `links.txt` jsou všechny výsledky kontroly. Kolegu zajímají jen problémy.

**Úkol:** připiš na konec reportu každý řádek z výsledků kontroly, který hlásí
chybějící obrázek — a žádný řádek `OK`. Nástroj vyber sám. Když kontrola najde
chybějících obrázků víc, v reportu budou všechny.

# --hints--

Report obsahuje řádek `Chybí: kontakt.html -> img/terasa.jpg` a žádný řádek začínající `OK:`.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const lines = (await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '')).split('\n').map((row) => row.trim());
assert.equal(lines.filter((row) => row === 'Chybí: kontakt.html -> img/terasa.jpg').length, 1, 'report.txt má jednou obsahovat řádek Chybí: kontakt.html -> img/terasa.jpg');
assert.ok(!lines.some((row) => row.startsWith('OK:')), 'report.txt nemá obsahovat řádky OK: — jen chybějící obrázky');
assert.ok(lines.includes('latte.jpg') && lines.includes('POZOR: chybí obrázky, viz links.txt'), 'starší části report.txt mají zůstat — řádky připiš na konec, nepřepisuj report');
```

Když chybí víc obrázků, report obsahuje všechny.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run(`rm -rf alt && mkdir alt && cp run.sh commands.sh alt/ && sed 's#img/latte.jpg#img/dyne-latte.jpg#' setup.sh > alt/setup.sh`);
await helpers.run('cd alt && bash run.sh');
const report = await readFile(`${helpers.dir}/alt/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
assert.ok(report.includes('Chybí: index.html -> img/dyne-latte.jpg') && report.includes('Chybí: kontakt.html -> img/terasa.jpg'), 'když chybí i img/dyne-latte.jpg na index.html, má report obsahovat oba řádky Chybí: … — ber je z výsledku kontroly, nepiš je ručně');
```

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF

cat > scripts/sitemap.mjs <<'EOF'
// Vypíše plné adresy všech stránek. Adresu webu bere z proměnné prostředí SITE_URL.
import { readdirSync } from 'node:fs';

const siteUrl = process.env.SITE_URL;
if (!siteUrl) {
  console.error('Chybí proměnná prostředí SITE_URL (adresa webu, třeba https://example.cz).');
  process.exit(1);
}
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  console.log(new URL(page, siteUrl).href);
}
EOF
