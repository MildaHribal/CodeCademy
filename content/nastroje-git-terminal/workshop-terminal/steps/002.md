# --description--

Fotky `IMG_2041.jpg`, `IMG_2042.jpg`, `latte.jpg` a `interier.webp` leží v kořeni
projektu, ale HTML stránky je hledají v `img/`. Přesuň je tam.

Příkaz `mv` přesouvá (a přejmenovává) soubory. Posledním argumentem je cíl, všechno
před ním se přesune. Nemusíš vypisovat každé jméno: hvězdičku `*` rozbalí shell na
všechna jména v aktuální složce, která vzoru odpovídají.

Stejný zápis na jiných datech — faktury do složky `docs`:

```sh
mv *.pdf *.docx docs/
```

**Úkol:** na konec `commands.sh` přidej jeden příkaz `mv`, který přesune všechny
soubory `.jpg` a `.webp` do `img/`. Po spuštění si všimni, že výpis kořene fotky
pořád ukazuje: `ls` stojí nad přesunem a příkazy běží v pořadí, v jakém je píšeš.

> [!PITFALL]
> Kdyby složka `img` neexistovala, `mv a.jpg b.jpg img/` skončí chybou
> `target 'img/': No such file or directory`. S jediným souborem je to horší:
> `mv latte.jpg img` bez složky soubor jen **přejmenuje** na `img`.

# --hints--

Všechny čtyři fotky jsou ve složce `img`.

```js
const { readdirSync } = await import('node:fs');
await helpers.run('bash run.sh');
let inImg = [];
try { inImg = readdirSync(`${helpers.dir}/kafe-na-rohu/img`); } catch {}
for (const photo of ['IMG_2041.jpg', 'IMG_2042.jpg', 'latte.jpg', 'interier.webp']) {
  assert.ok(inImg.includes(photo), `ve složce img má být ${photo}`);
}
```

V kořeni projektu nezůstal žádný soubor `.jpg` ani `.webp`.

```js
const { readdirSync } = await import('node:fs');
await helpers.run('bash run.sh');
const left = readdirSync(`${helpers.dir}/kafe-na-rohu`).filter((name) => /\.(jpg|webp)$/.test(name));
assert.deepEqual(left, [], 'v kořeni kafe-na-rohu/ nemají zůstat žádné fotky .jpg ani .webp');
```

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF
