# --description--

Kolega nechal v JavaScriptu poznámky `// TODO`. Pod nadpis `== TODO ==` připiš
každou z nich tak, aby bylo vidět, **ve kterém souboru a na kterém řádku** je.
Hledej jen ve složce `js` — v HTML je taky jedno TODO, ale to si kolega vyřeší sám.

K hledání textu v souborech slouží `grep`. Podívej se v lekci, který přepínač
prochází složky (`-r`), který přidá čísla řádků (`-n`) a které tu naopak nechceš
(`-l` vypíše jen jména souborů, `-c` jen počty). Výsledek připiš na konec reportu.

# --hints--

Report obsahuje všechna tři TODO ze složky `js` se jménem souboru a číslem řádku (`js/menu.js:7:…`).

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const report = await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '');
for (const [file, line] of [['app.js', 3], ['menu.js', 7], ['menu.js', 8]]) {
  const pattern = new RegExp(`js/${file.replace('.', '\\.')}:${line}:.*TODO`);
  assert.ok(report.split('\n').some((row) => pattern.test(row)), `report.txt má obsahovat řádek s TODO z js/${file} na řádku ${line} ve tvaru js/${file}:${line}:…`);
}
```

TODO z HTML v reportu není a TODO jsou až pod nadpisem `== TODO ==`.

```js
const { readFile } = await import('node:fs/promises');
await helpers.run('bash run.sh');
const lines = (await readFile(`${helpers.dir}/kafe-na-rohu/report.txt`, 'utf8').catch(() => '')).split('\n');
assert.ok(!lines.some((row) => row.includes('.html')), 'v report.txt nemá být TODO z HTML — hledej jen ve složce js');
const heading = lines.findIndex((row) => row.trim() === '== TODO ==');
const firstTodo = lines.findIndex((row) => row.includes('// TODO'));
assert.ok(heading >= 0 && firstTodo > heading, 'řádky s TODO mají být v report.txt pod nadpisem == TODO == (připsat, ne přepsat)');
```

# --help--

## --tip--

Hledání textu v celé složce je v lekci v části [Hledání textu a souborů](see:nastroje-git-terminal/terminal-do-hloubky#hledani-textu-a-souboru).

## --tip--

`grep` dostane nejdřív hledaný text, pak kde hledat. Bez `-r` neprojde složku
a bez `-n` nevypíše číslo řádku. Výstup připiš přes `>>`.

## --tip--

Stejný tvar na jiných datech — všechna volání `fetch` ve složce `src` do souboru `calls.txt`:
`grep -rn "fetch" src >> calls.txt`

// Projde HTML stránky a ověří, že existuje každý obrázek z atributu src.
// Nalezené píše na standardní výstup, chybějící na chybový. Když něco chybí, skončí kódem 1.
import { existsSync, readdirSync, readFileSync } from 'node:fs';

let missing = 0;
for (const page of readdirSync('.').filter((name) => name.endsWith('.html')).sort()) {
  const html = readFileSync(page, 'utf8');
  for (const [, src] of html.matchAll(/src="([^"]+\.(?:jpg|webp|png))"/g)) {
    if (existsSync(src)) {
      console.log(`OK: ${page} -> ${src}`);
    } else {
      console.error(`Chybí: ${page} -> ${src}`);
      missing += 1;
    }
  }
}
process.exit(missing > 0 ? 1 : 0);
EOF
