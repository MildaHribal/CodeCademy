# --description--

Na konec sepíšeš, co přibylo od vydání verze 1.0, třeba do poznámek k další verzi.
Git umí vypsat rozsah `A..B`: commity, které jsou v historii `B`, ale nejsou v historii
`A`. Místo `A` i `B` smí být větev, tag nebo hash.

**Úkol:** na úplný konec vypiš commity, které přibyly v `main` od tagu `v1.0`,
každý na jednom řádku (hash a zpráva, bez grafu).

Tím je práce hotová. Rozvětvil jsi repozitář, sloučil větev fast-forwardem
i merge commitem, vyřešil (a opravil) konflikt, vydal verzi tagem, srovnal historii
rebasem, odložil práci přes stash, zahodil nepovedenou úpravu a přenesl opravu mezi
větvemi. Přesně tohle dělá vývojář v týmu každý týden. V další lekci se naučíš,
co dělat, když se něco z toho pokazí: `reset`, `revert`, `reflog` a `bisect`.

## Udělej po svém

- **Vizuální:** vyzkoušej `git log --graph --all --format="%h %an %s"` a poskládej
  si vlastní formát výpisu, který se ti čte nejlépe.
- **Funkční:** přidej do `commands.sh` druhý konflikt — v `upravy/` si napiš skript,
  který na `main` i ve větvi změní stejný řádek `styles.css`, a vyřeš ho.
- **Po svém:** založ si ve vlastním projektu větev na rozdělanou funkci a dotáhni ji
  do `main` přes rebase a fast-forward.

# --hints--

Výpis končí třemi commity od verze 1.0 od nejnovějšího: oprava patičky, počasí, výlety.

```js
const run = await helpers.run('bash run.sh');
const commits = run.stdout.split('\n').filter((line) => /^[0-9a-f]{7,} /.test(line));
const subjects = commits.map((line) => line.replace(/^[0-9a-f]+ (\([^)]*\) )?/, ''));
assert.deepEqual(subjects, ['Oprav barvu patičky', 'Přidej počasí na trasách', 'Přidej tipy na výlety'], 'výpis má obsahovat jen commity od v1.0 do main, každý na řádku ve tvaru „hash zpráva"');
```

Výpis je poslední věc, kterou `commands.sh` vypíše.

```js
const run = await helpers.run('bash run.sh');
const last = run.stdout.trim().split('\n').at(-1) ?? '';
assert.match(last, /^[0-9a-f]{7,} (\([^)]*\) )?Přidej tipy na výlety$/, 'posledním řádkem výstupu má být nejstarší commit od v1.0: „hash Přidej tipy na výlety"');
```

## --tip--

Jednořádkový výpis historie znáš z [Grafu commitů](see:nastroje-git-terminal/git-model#graf-commitu), tady jen bez grafu a s rozsahem.

## --tip--

Za `git log` s přepínačem pro jeden řádek na commit patří rozsah: vlevo tag verze, vpravo `main`, mezi nimi dvě tečky.

## --file-- commands.sh

```sh
# Práce na webu Cyklotrasy Vysočiny.
# Příkazy běží shora dolů ve složce repozitáře, jako bys je psal do terminálu.

git log --oneline --graph --all

git switch -c feature/vyskovy-profil

bash ../upravy/vyskovy-profil.sh
git add .
git commit -m "Přidej výškový profil"

git switch main
git merge feature/vyskovy-profil

git branch -d feature/vyskovy-profil

git merge feature/mapa --no-edit

git merge jana/kontakt
cat partials/nav.html

# Petrovo vyřešení konfliktu:
cat > partials/nav.html <<'NAV'
<nav class="site-nav">
  <a href="index.html">Trasy</a>
  <a href="profil.html">Výškový profil</a>
  <a href="kontakt.html">Kontakt</a>
</nav>
NAV
git add partials/nav.html
git commit --no-edit
node scripts/build.mjs

git tag -a v1.0 -m "První verze webu"

git switch feature/vylety
git rebase main
git switch main
git merge feature/vylety

git switch feature/pocasi
git rebase main
git switch main
git merge feature/pocasi

git switch -c feature/tmavy-rezim
bash ../upravy/tmavy-rezim.sh

git stash
git switch main

bash ../upravy/oprava-paticky.sh
git add styles.css
git commit -m "Oprav barvu patičky"

git switch feature/tmavy-rezim
git stash pop

git restore styles.css

git merge main

--edit--

--edit--
```

## --file-- setup.sh

```sh
# Připraví repozitář webu Cyklotrasy Vysočiny i s rozdělanou prací kolegů.
# Tenhle soubor neměň: každé spuštění začíná od stejné historie.
git init -q -b main cyklotrasy
cd cyklotrasy || exit 1
mkdir -p pages partials scripts

commit() {
  git add -A
  git commit -q -m "$1"
}

cat > partials/nav.html <<'EOF'
<nav class="site-nav">
  <a href="index.html">Trasy</a>
</nav>
EOF

cat > pages/index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Cyklotrasy Vysočiny</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- nav -->
  <h1>Cyklotrasy Vysočiny</h1>
  <ul class="routes">
    <li>Kolem Velkého Dářka · 34 km</li>
  </ul>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0 auto; max-width: 56rem; font-family: system-ui, sans-serif; color: #1f2d24; background: #f4f7f2; }
.site-nav { display: flex; gap: 1rem; padding: 1rem 0; }
footer { color: #5b6b60; }
EOF

cat > scripts/build.mjs <<'EOF'
// Složí stránky z pages/ s navigací z partials/nav.html do složky dist/.
import { mkdirSync, readdirSync, readFileSync, writeFileSync } from 'node:fs';

const nav = readFileSync('partials/nav.html', 'utf8');
const markerLine = nav.split('\n').findIndex((line) => /^(<{7}|={7}|>{7})/.test(line));
if (markerLine >= 0) {
  console.error(`Chyba: partials/nav.html obsahuje značku konfliktu na řádku ${markerLine + 1}`);
  process.exit(1);
}
mkdirSync('dist', { recursive: true });
const pages = readdirSync('pages');
for (const page of pages) {
  writeFileSync(`dist/${page}`, readFileSync(`pages/${page}`, 'utf8').replace('<!-- nav -->', nav.trim()));
}
console.log(`Sestaveno stránek: ${pages.length}`);
EOF

echo 'dist/' > .gitignore
commit 'Základ webu cyklotras'

sed -i 's#    <li>Kolem Velkého Dářka · 34 km</li>#&\n    <li>Podél Sázavy ze Žďáru · 48 km</li>#' pages/index.html
commit 'Přidej trasu podél Sázavy'

git switch -q -c feature/mapa
printf '<h1>Mapa tras</h1>\n<!-- nav -->\n<img src="mapa-vysociny.webp" alt="Mapa cyklotras na Vysočině">\n' > pages/mapa.html
commit 'Přidej mapu tras'

git switch -q main
git switch -q -c jana/kontakt
sed -i 's#  <a href="index.html">Trasy</a>#&\n  <a href="kontakt.html">Kontakt</a>#' partials/nav.html
printf '<h1>Kontakt</h1>\n<!-- nav -->\n<p>Půjčovna kol, Nádražní 12, Žďár nad Sázavou</p>\n' > pages/kontakt.html
commit 'Přidej stránku Kontakt'

git switch -q main
git switch -q -c feature/vylety
printf '<h1>Tipy na výlety</h1>\n<!-- nav -->\n<p>Zámek Žďár a poutní kostel na Zelené hoře</p>\n' > pages/vylety.html
commit 'Přidej tipy na výlety'

git switch -q main
git switch -q -c feature/pocasi
printf '<h1>Počasí na trasách</h1>\n<!-- nav -->\n<p>Předpověď pro Žďár nad Sázavou na tři dny</p>\n' > pages/pocasi.html
commit 'Přidej počasí na trasách'

git switch -q main
cd ..

# Úpravy souborů, které bys jinak psal v editoru.
mkdir -p upravy
cat > upravy/vyskovy-profil.sh <<'EOF'
printf '<h1>Výškový profil</h1>\n<!-- nav -->\n<p>Nejprudší stoupání: Křemešník, 9 %%</p>\n' > pages/profil.html
sed -i 's#  <a href="index.html">Trasy</a>#&\n  <a href="profil.html">Výškový profil</a>#' partials/nav.html
EOF
cat > upravy/tmavy-rezim.sh <<'EOF'
printf '@media (prefers-color-scheme: dark) {\n  body { color: #e3ece5; background: #14201a; }\n}\n' >> styles.css
EOF
cat > upravy/oprava-paticky.sh <<'EOF'
sed -i 's#footer { color: \#5b6b60; }#footer { color: \#4a5a4f; }#' styles.css
EOF
```

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii a v repozitáři spustí tvoje commands.sh.
# Git tu běží bez tvého osobního nastavení a místo editoru přijme výchozí zprávu.
export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1 GIT_EDITOR=true LC_ALL=C
export GIT_AUTHOR_NAME='Tomáš Dvořák' GIT_AUTHOR_EMAIL='tomas@cyklotrasy.cz'
export GIT_COMMITTER_NAME='Tomáš Dvořák' GIT_COMMITTER_EMAIL='tomas@cyklotrasy.cz'
rm -rf work && mkdir work && cd work || exit 1
bash ../setup.sh
cd cyklotrasy || exit 1
bash ../../commands.sh
```
