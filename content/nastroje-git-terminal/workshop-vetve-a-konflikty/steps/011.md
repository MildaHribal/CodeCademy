# --description--

Větev `feature/pocasi` je na tom stejně jako výlety: vznikla ze starého `main`.
Dostaň počasí do `main` stejnou cestou, tentokrát bez skládání řádků. Na konci
má být historie za verzí 1.0 pořád rovná, bez merge commitu.

**Úkol:** přehraj `feature/pocasi` na aktuální `main` a pak ji do `main` slouč.

# --hints--

Poslední commit `main` je „Přidej počasí na trasách" a pod ním „Přidej tipy na výlety".

```js
await helpers.run('bash run.sh');
const subjects = await helpers.run('cd work/cyklotrasy && git log -2 --format=%s main');
assert.deepEqual(subjects.stdout.trim().split('\n'), ['Přidej počasí na trasách', 'Přidej tipy na výlety'], 'dva poslední commity main mají být „Přidej počasí na trasách" a pod ním „Přidej tipy na výlety"');
```

Za verzí 1.0 není žádný merge commit, `feature/pocasi` ukazuje na `main` a stojíš na `main`.

```js
await helpers.run('bash run.sh');
const merges = await helpers.run('cd work/cyklotrasy && git rev-list --merges v1.0..main');
assert.equal(merges.stdout.trim(), '', 'mezi v1.0 a main nemá být merge commit — nejdřív rebase, pak sloučení');
const hashes = await helpers.run('cd work/cyklotrasy && git rev-parse main feature/pocasi && git branch --show-current');
const [main, weather, current] = hashes.stdout.trim().split('\n');
assert.equal(weather, main, 'feature/pocasi a main mají ukazovat na tentýž commit');
assert.equal(current, 'main', 'na konci máš stát na main');
```

# --help--

## --tip--

Postup je stejný jako v [předchozím kroku](see:nastroje-git-terminal/workshop-vetve-a-konflikty/010), jen s jinou větví.

## --tip--

Rebase se spouští na větvi, kterou přehráváš, a jako argument dostane větev, na kterou ji přehráváš. Slučuje se na `main`.

## --tip--

Stejné čtyři kroky pro větev `feature/newsletter`: přepni na ni, přehraj ji na `main`, přepni na `main`, slouč `feature/newsletter`.

# --explain--

Vysvětli, čím se liší výsledek `git merge` a `git rebase` při zapracování větve, která vznikla ze staršího `main`.

## --model--

Merge nechá obě linie historie, jak byly, a spojí je novým merge commitem se dvěma
rodiči. Rebase přehraje commity větve na aktuální `main`, takže vzniknou nové commity
s novými hashi a historie je rovná. Merge nic nepřepisuje, rebase ano, a proto se
rebase nepoužívá na commity, které už mají ostatní.

## --checklist--

- Merge vytvoří merge commit se dvěma rodiči a zachová obě linie historie.
- Rebase přehraje commity větve na nový základ.
- Rebase vyrobí nové commity s novými hashi.
- Rebase se nedělá na historii, kterou už sdílíš s ostatními.

## --file-- commands.sh

```sh
# Práce na webu Cyklotrasy Vysočiny.
# Příkazy běží shora dolů ve složce repozitáře, jako bys je psal do terminálu.

git switch main

<nav class="site-nav">

</nav>
NAV
git add partials/nav.html
git commit --no-edit
node scripts/build.mjs

git tag -a v1.0 -m "První verze webu"

git switch feature/vylety
git rebase main
git switch main
git merge feature/vylety

--edit--

--edit--
```

## --file-- setup.sh

```sh
# Připraví repozitář webu Cyklotrasy Vysočiny i s rozdělanou prací kolegů.
# Tenhle soubor neměň: každé spuštění začíná od stejné historie.
git init -q -b main cyklotrasy
cd cyklotrasy || exit 1
mkdir -p pages partials scripts

commit() {
  git add -A
  git commit -q -m "$1"
}

cat > partials/nav.html <<'EOF'
<nav class="site-nav">
  <a href="index.html">Trasy</a>
</nav>
EOF

cat > pages/index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Cyklotrasy Vysočiny</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- nav -->
  <h1>Cyklotrasy Vysočiny</h1>
  <ul class="routes">
    <li>Kolem Velkého Dářka · 34 km</li>
  </ul>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0 auto; max-width: 56rem; font-family: system-ui, sans-serif; color: #1f2d24; background: #f4f7f2; }
.site-nav { display: flex; gap: 1rem; padding: 1rem 0; }
footer { color: #5b6b60; }
EOF

cat > scripts/build.mjs <<'EOF'
// Složí stránky z pages/ s navigací z partials/nav.html do složky dist/.
import { mkdirSync, readdirSync, readFileSync, writeFileSync } from 'node:fs';

const nav = readFileSync('partials/nav.html', 'utf8');
const markerLine = nav.split('\n').findIndex((line) => /^(<{7}|={7}|>{7})/.test(line));
if (markerLine >= 0) {
  console.error(`Chyba: partials/nav.html obsahuje značku konfliktu na řádku ${markerLine + 1}`);
  process.exit(1);
}
mkdirSync('dist', { recursive: true });
const pages = readdirSync('pages');
for (const page of pages) {
  writeFileSync(`dist/${page}`, readFileSync(`pages/${page}`, 'utf8').replace('<!-- nav -->', nav.trim()));
}
console.log(`Sestaveno stránek: ${pages.length}`);
EOF

echo 'dist/' > .gitignore
commit 'Základ webu cyklotras'

sed -i 's#    <li>Kolem Velkého Dářka · 34 km</li>#&\n    <li>Podél Sázavy ze Žďáru · 48 km</li>#' pages/index.html
commit 'Přidej trasu podél Sázavy'

git switch -q -c feature/mapa
printf '<h1>Mapa tras</h1>\n<!-- nav -->\n<img src="mapa-vysociny.webp" alt="Mapa cyklotras na Vysočině">\n' > pages/mapa.html
commit 'Přidej mapu tras'

git switch -q main
git switch -q -c jana/kontakt
sed -i 's#  <a href="index.html">Trasy</a>#&\n  <a href="kontakt.html">Kontakt</a>#' partials/nav.html
printf '<h1>Kontakt</h1>\n<!-- nav -->\n<p>Půjčovna kol, Nádražní 12, Žďár nad Sázavou</p>\n' > pages/kontakt.html
commit 'Přidej stránku Kontakt'

git switch -q main
git switch -q -c feature/vylety
printf '<h1>Tipy na výlety</h1>\n<!-- nav -->\n<p>Zámek Žďár a poutní kostel na Zelené hoře</p>\n' > pages/vylety.html
commit 'Přidej tipy na výlety'

git switch -q main
git switch -q -c feature/pocasi
printf '<h1>Počasí na trasách</h1>\n<!-- nav -->\n<p>Předpověď pro Žďár nad Sázavou na tři dny</p>\n' > pages/pocasi.html
commit 'Přidej počasí na trasách'

git switch -q main
cd ..

# Úpravy souborů, které bys jinak psal v editoru.
mkdir -p upravy
cat > upravy/vyskovy-profil.sh <<'EOF'
printf '<h1>Výškový profil</h1>\n<!-- nav -->\n<p>Nejprudší stoupání: Křemešník, 9 %%</p>\n' > pages/profil.html
sed -i 's#  <a href="index.html">Trasy</a>#&\n  <a href="profil.html">Výškový profil</a>#' partials/nav.html
EOF
cat > upravy/tmavy-rezim.sh <<'EOF'
printf '@media (prefers-color-scheme: dark) {\n  body { color: #e3ece5; background: #14201a; }\n}\n' >> styles.css
EOF
cat > upravy/oprava-paticky.sh <<'EOF'
sed -i 's#footer { color: \#5b6b60; }#footer { color: \#4a5a4f; }#' styles.css
EOF
```

bash ../../commands.sh
