# --description--

Stránka s profilem je hotová. Skript `../upravy/vyskovy-profil.sh` za tebe udělá, co
bys jinak psal v editoru: vytvoří `pages/profil.html` a přidá odkaz do
`partials/nav.html`. Spustíš ho přes `bash`.

Pak změny ulož do commitu, jak to znáš: `git add` a `git commit -m "…"`. Nová věc je,
co se stane s větvemi: **commit posune jen větev, na které stojíš**. `main` zůstane
na starém commitu.

Tentýž postup na jiných datech:

```sh
bash ../upravy/novy-cenik.sh
git add .
git commit -m "Přidej ceník půjčovny"
```

**Úkol:** spusť úpravu `vyskovy-profil.sh` a obě změněná místa ulož do jednoho commitu
se zprávou „Přidej výškový profil".

> [!PITFALL]
> `git commit -am "…"` vypadá jako zkratka za `add` a `commit`, ale přidá jen soubory,
> které Git už sleduje. Nový `pages/profil.html` by v commitu chyběl a `git status` by
> ho dál ukazoval pod `Untracked files`.

# --hints--

Poslední commit větve `feature/vyskovy-profil` obsahuje `pages/profil.html` i odkaz v navigaci.

```js
await helpers.run('bash run.sh');
const committed = await helpers.run('cd work/cyklotrasy && git show feature/vyskovy-profil:partials/nav.html && git ls-tree -r --name-only feature/vyskovy-profil');
assert.ok(committed.stdout.includes('pages/profil.html'), 'commit na feature/vyskovy-profil má obsahovat nový soubor pages/profil.html');
assert.ok(committed.stdout.includes('href="profil.html"'), 'commit na feature/vyskovy-profil má obsahovat odkaz na profil v partials/nav.html');
```

`main` se nepohnul a pracovní složka je po commitu čistá.

```js
await helpers.run('bash run.sh');
const main = await helpers.run('cd work/cyklotrasy && git log -1 --format=%s main');
assert.equal(main.stdout.trim(), 'Přidej trasu podél Sázavy', 'main má dál ukazovat na commit „Přidej trasu podél Sázavy" — commit posune jen větev, na které stojíš');
const status = await helpers.run('cd work/cyklotrasy && git status --porcelain');
assert.equal(status.stdout.trim(), '', 'git status --porcelain má být po commitu prázdný — obě změny patří do commitu');
```

## --file-- setup.sh

```sh
# Připraví repozitář webu Cyklotrasy Vysočiny i s rozdělanou prací kolegů.
# Tenhle soubor neměň: každé spuštění začíná od stejné historie.
git init -q -b main cyklotrasy
cd cyklotrasy || exit 1
mkdir -p pages partials scripts

commit() {
  git add -A
  git commit -q -m "$1"
}

cat > partials/nav.html <<'EOF'
<nav class="site-nav">
  <a href="index.html">Trasy</a>
</nav>
EOF

cat > pages/index.html <<'EOF'
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Cyklotrasy Vysočiny</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- nav -->
  <h1>Cyklotrasy Vysočiny</h1>
  <ul class="routes">
    <li>Kolem Velkého Dářka · 34 km</li>
  </ul>
</body>
</html>
EOF

cat > styles.css <<'EOF'
body { margin: 0 auto; max-width: 56rem; font-family: system-ui, sans-serif; color: #1f2d24; background: #f4f7f2; }
.site-nav { display: flex; gap: 1rem; padding: 1rem 0; }
footer { color: #5b6b60; }
EOF

cat > scripts/build.mjs <<'EOF'
// Složí stránky z pages/ s navigací z partials/nav.html do složky dist/.
import { mkdirSync, readdirSync, readFileSync, writeFileSync } from 'node:fs';

const nav = readFileSync('partials/nav.html', 'utf8');
const markerLine = nav.split('\n').findIndex((line) => /^(<{7}|={7}|>{7})/.test(line));
if (markerLine >= 0) {
  console.error(`Chyba: partials/nav.html obsahuje značku konfliktu na řádku ${markerLine + 1}`);
  process.exit(1);
}
mkdirSync('dist', { recursive: true });
const pages = readdirSync('pages');
for (const page of pages) {
  writeFileSync(`dist/${page}`, readFileSync(`pages/${page}`, 'utf8').replace('<!-- nav -->', nav.trim()));
}
console.log(`Sestaveno stránek: ${pages.length}`);
EOF

echo 'dist/' > .gitignore
commit 'Základ webu cyklotras'

sed -i 's#    <li>Kolem Velkého Dářka · 34 km</li>#&\n    <li>Podél Sázavy ze Žďáru · 48 km</li>#' pages/index.html
commit 'Přidej trasu podél Sázavy'

git switch -q -c feature/mapa
printf '<h1>Mapa tras</h1>\n<!-- nav -->\n<img src="mapa-vysociny.webp" alt="Mapa cyklotras na Vysočině">\n' > pages/mapa.html
commit 'Přidej mapu tras'

git switch -q main
git switch -q -c jana/kontakt
sed -i 's#  <a href="index.html">Trasy</a>#&\n  <a href="kontakt.html">Kontakt</a>#' partials/nav.html
printf '<h1>Kontakt</h1>\n<!-- nav -->\n<p>Půjčovna kol, Nádražní 12, Žďár nad Sázavou</p>\n' > pages/kontakt.html
commit 'Přidej stránku Kontakt'

git switch -q main
git switch -q -c feature/vylety
printf '<h1>Tipy na výlety</h1>\n<!-- nav -->\n<p>Zámek Žďár a poutní kostel na Zelené hoře</p>\n' > pages/vylety.html
commit 'Přidej tipy na výlety'

git switch -q main
git switch -q -c feature/pocasi
printf '<h1>Počasí na trasách</h1>\n<!-- nav -->\n<p>Předpověď pro Žďár nad Sázavou na tři dny</p>\n' > pages/pocasi.html
commit 'Přidej počasí na trasách'

git switch -q main
cd ..

# Úpravy souborů, které bys jinak psal v editoru.
mkdir -p upravy
cat > upravy/vyskovy-profil.sh <<'EOF'
printf '<h1>Výškový profil</h1>\n<!-- nav -->\n<p>Nejprudší stoupání: Křemešník, 9 %%</p>\n' > pages/profil.html
sed -i 's#  <a href="index.html">Trasy</a>#&\n  <a href="profil.html">Výškový profil</a>#' partials/nav.html
EOF
cat > upravy/tmavy-rezim.sh <<'EOF'
printf '@media (prefers-color-scheme: dark) {\n  body { color: #e3ece5; background: #14201a; }\n}\n' >> styles.css
EOF
cat > upravy/oprava-paticky.sh <<'EOF'
sed -i 's#footer { color: \#5b6b60; }#footer { color: \#4a5a4f; }#' styles.css
EOF
```

## --file-- run.sh

```sh
# Tlačítko Spustit i testy: vytvoří čistou kopii a v repozitáři spustí tvoje commands.sh.
# Git tu běží bez tvého osobního nastavení a místo editoru přijme výchozí zprávu.
export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1 GIT_EDITOR=true LC_ALL=C
export GIT_AUTHOR_NAME='Tomáš Dvořák' GIT_AUTHOR_EMAIL='tomas@cyklotrasy.cz'
export GIT_COMMITTER_NAME='Tomáš Dvořák' GIT_COMMITTER_EMAIL='tomas@cyklotrasy.cz'
rm -rf work && mkdir work && cd work || exit 1
bash ../setup.sh
cd cyklotrasy || exit 1
bash ../../commands.sh
```
