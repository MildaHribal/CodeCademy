# --description--

Formulář potřebuje protějšek: funkci, která vezme odeslaná data, zkontroluje je
a buď vrátí chyby, nebo hotový inzerát. V Next.js by to byla
[[serverová akce]] se `'use server'` a zápisem do databáze; tady je to obyčejná
`async` funkce se stejným tvarem výsledku.

**Úkol:** v `akce.js` seřaď řádky tak, aby `vytvorInzerat(predchoziStav, formData)`
vracela buď `{ chyby, hodnoty }`, nebo `{ ok: true, inzerat }`. Odsazení
nastavíš klávesou Tab, dva řádky jsou navíc.

Dva parametry nejsou překlep: první je předchozí výsledek akce (za chvíli uvidíš,
kdo ho posílá), druhý jsou data z formuláře.

# --hints--

Platná data projdou: akce vrátí `ok: true` a hotový inzerát s číselnou cenou.

```js
const { vytvorInzerat } = await helpers.importFile('akce.js');
assert.equal(typeof vytvorInzerat, 'function', 'akce.js má exportovat funkci vytvorInzerat');
const data = new FormData();
data.set('nazev', 'Kolo Author Solution');
data.set('cena', '7500');
data.set('popis', 'Jeté dvě sezony.');
const vysledek = await vytvorInzerat({}, data);
assert.equal(vysledek.ok, true, 'Platná data mají vrátit { ok: true }');
assert.ok(vysledek.inzerat, 'Výsledek má obsahovat vytvořený inzerát');
assert.equal(vysledek.inzerat.nazev, 'Kolo Author Solution', 'Inzerát má mít název z formuláře');
assert.equal(vysledek.inzerat.cena, 7500, 'Cena v inzerátu má být číslo 7500, ne text');
assert.equal(typeof vysledek.inzerat.id, 'string', 'Inzerát má mít vlastní id');
```

Krátký název i nulová cena skončí chybou u svého políčka.

```js
const { vytvorInzerat } = await helpers.importFile('akce.js');
const data = new FormData();
data.set('nazev', 'ab');
data.set('cena', '0');
data.set('popis', '');
const vysledek = await vytvorInzerat({}, data);
assert.ok(!vysledek.ok, 'Neplatná data nesmí projít');
assert.ok(vysledek.chyby, 'Výsledek má obsahovat objekt chyby');
assert.match(String(vysledek.chyby.nazev), /3 znaky/, 'U názvu kratšího než tři znaky má být chyba o třech znacích');
assert.ok(vysledek.chyby.cena, 'U ceny 0 má být chyba');
```

Po chybě přijdou zpátky i vyplněné hodnoty, aby je uživatel nemusel psát znovu.

```js
const { vytvorInzerat } = await helpers.importFile('akce.js');
const data = new FormData();
data.set('nazev', 'ab');
data.set('cena', '7500');
data.set('popis', 'Stan pro tři.');
const vysledek = await vytvorInzerat({}, data);
assert.ok(vysledek.hodnoty, 'Výsledek s chybou má obsahovat hodnoty, které uživatel vyplnil');
assert.equal(vysledek.hodnoty.nazev, 'ab', 'Ve hodnotách má být vyplněný název');
assert.equal(vysledek.hodnoty.cena, '7500', 'Ve hodnotách má být vyplněná cena');
assert.equal(vysledek.hodnoty.popis, 'Stan pro tři.', 'Ve hodnotách má být vyplněný popis');
```

Necelá ani záporná cena neprojde.

```js
const { vytvorInzerat } = await helpers.importFile('akce.js');
for (const spatna of ['12.5', '-5', '', 'abc']) {
  const data = new FormData();
  data.set('nazev', 'Stan Husky Bizon');
  data.set('cena', spatna);
  data.set('popis', '');
  const vysledek = await vytvorInzerat({}, data);
  assert.ok(!vysledek.ok, 'Cena „' + spatna + '" neměla projít');
  assert.ok(vysledek.chyby && vysledek.chyby.cena, 'U ceny „' + spatna + '" má být chyba u políčka cena');
}
```

```js
export async function vytvorInzerat(predchoziStav, formData) {
  const nazev = String(formData.get('nazev') ?? '').trim();
  const cena = String(formData.get('cena') ?? '').trim();
  const popis = String(formData.get('popis') ?? '').trim();
  await pauza(400);
  const chyby = __1__;
  if (nazev.length < 3) chyby.nazev = 'Název musí mít aspoň 3 znaky.';
  if (!Number.isInteger(Number(cena)) || Number(cena) <= 0) chyby.cena = 'Cena musí být kladné celé číslo.';
  if (Object.keys(chyby).length > 0) return { chyby, hodnoty: { nazev, cena, popis } };
  return { ok: true, inzerat: { id: 'inzerat-' + Date.now(), nazev, cena: Number(cena), popis } };
}
```
