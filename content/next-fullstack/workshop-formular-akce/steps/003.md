# --description--

Teď to podstatné: formulář, kterým uživatel přidá vlastní inzerát. V tomhle
kroku jde jen o značky — odesílání přijde hned potom.

**Úkol:** v `App.jsx` přidej **nad** sekci `<section className="nabidka">` formulář
`<form className="formular">` s nadpisem `<h2>Přidat inzerát</h2>` a třemi poli.
Každé pole je `<p className="pole">` a obsahuje popisek a ovládací prvek:

| popisek | prvek | `id` a `name` |
|---|---|---|
| Název | `<input>` | `nazev` |
| Cena v Kč | `<input type="number">` | `cena` |
| Popis | `<textarea>` | `popis` |

Na konec formuláře přijde `<button className="tlacitko" type="submit">` s textem
`Přidat inzerát`. Formulář zatím nikam nic neposílá, takže mu dej
`onSubmit={(udalost) => udalost.preventDefault()}` — jinak by prohlížeč při
odeslání načetl stránku znovu. V dalším kroku ho nahradíme něčím lepším.

Popisek propoj s políčkem přes `htmlFor` a `id` — bez toho neví čtečka obrazovky,
co má uživatel vyplnit, a políčko nejde odkliknout přes text popisku.

> [!PITFALL]
> Atribut `name` není zdobení. Podle něj se hodnota dostane do dat formuláře —
> políčko bez `name` se při odeslání chová, jako by neexistovalo.

# --hints--

Na stránce je formulář a v něm tlačítko „Přidat inzerát".

```js
const formular = document.querySelector('form');
assert.ok(formular, 'Na stránce má být formulář <form>');
const tlacitko = formular.querySelector('button[type="submit"]');
assert.ok(tlacitko, 'Formulář má mít odesílací tlačítko <button type="submit">');
assert.equal(helpers.normalize(tlacitko.textContent), 'Přidat inzerát', 'Tlačítko má mít text „Přidat inzerát"');
```

Formulář má políčka `nazev`, `cena` (číslo) a `popis` (víceřádkové).

```js
const formular = document.querySelector('form');
assert.ok(formular, 'Na stránce má být formulář <form>');
const nazev = formular.querySelector('[name="nazev"]');
const cena = formular.querySelector('[name="cena"]');
const popis = formular.querySelector('[name="popis"]');
assert.ok(nazev, 'Formulář má mít políčko s name="nazev"');
assert.ok(cena, 'Formulář má mít políčko s name="cena"');
assert.ok(popis, 'Formulář má mít políčko s name="popis"');
assert.equal(cena.type, 'number', 'Políčko cena má být <input type="number">');
assert.equal(popis.tagName, 'TEXTAREA', 'Popis má být víceřádkový <textarea>');
```

Každé políčko má propojený popisek.

```js
for (const jmeno of ['nazev', 'cena', 'popis']) {
  const prvek = document.querySelector('[name="' + jmeno + '"]');
  assert.ok(prvek.id, 'Políčko ' + jmeno + ' potřebuje id, aby na něj šel navázat popisek');
  const popisek = document.querySelector('label[for="' + prvek.id + '"]');
  assert.ok(popisek, 'K políčku ' + jmeno + ' chybí <label htmlFor="' + prvek.id + '">');
  assert.ok(helpers.normalize(popisek.textContent).length > 0, 'Popisek políčka ' + jmeno + ' nemá být prázdný');
}
```

## --file-- App.jsx

```jsx
import { pocatecniInzeraty } from './data';

const meny = new Intl.NumberFormat('cs-CZ', {
  style: 'currency',
  currency: 'CZK',
  maximumFractionDigits: 0,
});

export function formatujCenu(castka) {
  return meny.format(castka);
}

export default function Bazarek() {
  const inzeraty = pocatecniInzeraty;

  return (
    <main className="bazarek">
      <header className="hlavicka">
        <h1>Bazárek</h1>
        <p className="podtitulek">Věci, které někomu doma překážejí.</p>
      </header>

      <form className="formular" onSubmit={(udalost) => udalost.preventDefault()}>
        <h2>Přidat inzerát</h2>

        <p className="pole">
          <label htmlFor="nazev">Název</label>
          <input id="nazev" name="nazev" />
        </p>

        <p className="pole">
          <label htmlFor="cena">Cena v Kč</label>
          <input id="cena" name="cena" type="number" />
        </p>

        <p className="pole">
          <label htmlFor="popis">Popis</label>
          <textarea id="popis" name="popis" />
        </p>

        <button className="tlacitko" type="submit">Přidat inzerát</button>
      </form>

      <section className="nabidka">
        <h2>Na prodej</h2>
        <ul className="seznam" data-testid="seznam">
          {inzeraty.map((inzerat) => (
            <li className="karta" key={inzerat.id}>
              <h3>{inzerat.nazev}</h3>
              <p className="karta__cena">{formatujCenu(inzerat.cena)}</p>
              <p className="karta__popis">{inzerat.popis}</p>
            </li>
          ))}
        </ul>
      </section>
    </main>
  );
}
```
