title: Tlačítko, které si stav zjistí samo

# --description--

Tlačítko dnes ví o odesílání jen proto, že mu příznak podává komponenta okolo.
Jenže formulář poroste a příznak bys musel protahovat přes všechny vrstvy.

React na to má hook `useFormStatus` z `react-dom`: komponenta uvnitř formuláře
se jím **sama zeptá**, jestli zrovna běží odesílání.

**Úkol:** v `App.jsx` vytvoř komponentu `TlacitkoOdeslat`, která si stav zjistí
přes `useFormStatus()` a vykreslí stejné tlačítko jako dosud. Ve formuláři ji
použij místo dosavadního tlačítka a příznak `ceka` z `useActionState` už neber.

> [!PITFALL]
> `useFormStatus` funguje jen v komponentě, která je **uvnitř** `<form>`.
> V komponentě, která ten formulář sama vykresluje, vrátí `pending: false`
> pořád — proto musí být tlačítko ve vlastní komponentě.

## --tip-- 2

Hook vrací objekt s několika údaji o probíhajícím odeslání. Ten, který tě zajímá,
se jmenuje stejně jako v dokumentaci Reactu — anglicky „čekající".

## --tip-- 2

Novou komponentu napiš **nad** `Bazarek`, ne dovnitř. Komponenta definovaná
uvnitř jiné komponenty by se při každém vykreslení vytvářela znovu.

import { useActionState } from 'react';

import { vytvorInzerat } from './akce';
import { pocatecniInzeraty } from './data';

const meny = new Intl.NumberFormat('cs-CZ', {
  style: 'currency',
  currency: 'CZK',
  maximumFractionDigits: 0,
});

export function formatujCenu(castka) {
  return meny.format(castka);
}

export default function Bazarek() {
  const inzeraty = pocatecniInzeraty;
  const [stav, akce, ceka] = useActionState(vytvorInzerat, {});

  return (

      <header className="hlavicka">

        <p className="podtitulek">Věci, které někomu doma překážejí.</p>
      </header>

      <form className="formular" action={akce}>
        <h2>Přidat inzerát</h2>

        <p className="pole">
          <label htmlFor="nazev">Název</label>

          {stav.chyby?.nazev && <span className="chyba" role="alert">{stav.chyby.nazev}</span>}
        </p>

        <p className="pole">
          <label htmlFor="cena">Cena v Kč</label>
          <input id="cena" name="cena" type="number" defaultValue={stav.hodnoty?.cena ?? ''} aria-invalid={Boolean(stav.chyby?.cena)} />
          {stav.chyby?.cena && <span className="chyba" role="alert">{stav.chyby.cena}</span>}
        </p>

        <p className="pole">
          <label htmlFor="popis">Popis</label>
          <textarea id="popis" name="popis" defaultValue={stav.hodnoty?.popis ?? ''} />
        </p>

        <button className="tlacitko" type="submit" disabled={ceka}>
          {ceka ? 'Ukládám…' : 'Přidat inzerát'}
        </button>

        <p className="hlaseni">{stav.ok ? 'Inzerát je na bazárku.' : ''}</p>
      </form>

      <section className="nabidka">
        <h2>Na prodej</h2>
        <ul className="seznam" data-testid="seznam">
          {inzeraty.map((inzerat) => (
            <li className="karta" key={inzerat.id}>
              <h3>{inzerat.nazev}</h3>
              <p className="karta__cena">{formatujCenu(inzerat.cena)}</p>
              <p className="karta__popis">{inzerat.popis}</p>
            </li>
          ))}
        </ul>
      </section>
    </main>
  );
}

// Tahle funkce zastupuje serverovou akci. V Next.js by měla na prvním řádku
// 'use server', běžela by na serveru a zapisovala do databáze. Tady jen chvíli
// počká a vrátí stejný tvar výsledku, jaký by vrátila doopravdy.
const pauza = (ms) => new Promise((splnit) => setTimeout(splnit, ms));
export async function vytvorInzerat(predchoziStav, formData) {
  const nazev = String(formData.get('nazev') ?? '').trim();
  const cena = String(formData.get('cena') ?? '').trim();
  const popis = String(formData.get('popis') ?? '').trim();
  await pauza(400);
  const chyby = {};
  if (nazev.length < 3) chyby.nazev = 'Název musí mít aspoň 3 znaky.';
  if (!Number.isInteger(Number(cena)) || Number(cena) <= 0) chyby.cena = 'Cena musí být kladné celé číslo.';
  if (Object.keys(chyby).length > 0) return { chyby, hodnoty: { nazev, cena, popis } };
  return { ok: true, inzerat: { id: 'inzerat-' + Date.now(), nazev, cena: Number(cena), popis } };
}

import { useActionState } from 'react';
import { useFormStatus } from 'react-dom';

# --explain--

Vysvětli vlastními slovy, proč musí být tlačítko ve vlastní komponentě, aby
`useFormStatus` fungoval.

## --model--

`useFormStatus` čte stav nejbližšího formuláře **nad sebou** ve stromu. Komponenta,
která `<form>` sama vykresluje, žádný formulář nad sebou nemá, takže by dostala
`pending: false` i během odesílání. Tlačítko musí být potomek toho formuláře —
pak si stav zjistí samo a nikdo mu ho nemusí posílat propem.

## --checklist--

- `useFormStatus` čte stav formuláře, který je ve stromu nad komponentou.
- V komponentě, která formulář vykresluje, žádný formulář nad sebou není.
- Tlačítko proto musí být vlastní komponenta uvnitř `<form>`.
- Díky tomu se stav nemusí protahovat propem.
