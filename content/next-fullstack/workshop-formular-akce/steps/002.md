# --description--

`7500 Kč` je surové číslo. Česky se píše `7 500 Kč` — s mezerou po tisících
a bez haléřů.

**Úkol:** v `App.jsx` napiš a vyexportuj funkci `formatujCenu(castka)`, která
částku naformátuje podle českých zvyklostí, a použij ji v seznamu místo
`{inzerat.cena} Kč`.

Formátování čísel podle jazyka umí `Intl.NumberFormat`. Příklad na jiných datech:

```js
const vzdalenost = new Intl.NumberFormat('cs-CZ', { style: 'unit', unit: 'kilometer' });
vzdalenost.format(1250);        // → „1 250 km"
```

Formátovač si vyrob **jednou** nad komponentou, ne při každém vykreslení.

> [!TIP]
> Měnu zapneš volbami `style: 'currency'` a `currency: 'CZK'`. Haléře utne
> `maximumFractionDigits`.

```js
const prvni = document.querySelector('[data-testid="seznam"] li');
assert.ok(prvni, 'V seznamu má být aspoň jedna položka');

```

Cena je bez haléřů (žádné `,00`).

```js
const text = helpers.normalize(document.querySelector('[data-testid="seznam"]').textContent);
assert.ok(!text.includes(',00'), 'Ceny mají být bez haléřů — použij maximumFractionDigits: ' + text);
```

Funkce `formatujCenu` je vyexportovaná a zvládne i jinou částku.

```js
const modul = await helpers.importFile('App.jsx');
assert.equal(typeof modul.formatujCenu, 'function', 'App.jsx má exportovat funkci formatujCenu');
assert.equal(helpers.normalize(modul.formatujCenu(289)), '289 Kč', 'formatujCenu(289) má vrátit „289 Kč"');

```

# --solution--

## --file-- App.jsx

```jsx
import { pocatecniInzeraty } from './data';

const meny = new Intl.NumberFormat('cs-CZ', {
  style: 'currency',
  currency: 'CZK',
  maximumFractionDigits: 0,
});

export function formatujCenu(castka) {
  return meny.format(castka);
}

export default function Bazarek() {
  const inzeraty = pocatecniInzeraty;

  return (
    <main className="bazarek">
      <header className="hlavicka">
        <h1>Bazárek</h1>
        <p className="podtitulek">Věci, které někomu doma překážejí.</p>
      </header>

      <section className="nabidka">
        <h2>Na prodej</h2>
        <ul className="seznam" data-testid="seznam">
          {inzeraty.map((inzerat) => (
            <li className="karta" key={inzerat.id}>
              <h3>{inzerat.nazev}</h3>
              <p className="karta__cena">{formatujCenu(inzerat.cena)}</p>
              <p className="karta__popis">{inzerat.popis}</p>
            </li>
          ))}
        </ul>
      </section>
    </main>
  );
}
```
