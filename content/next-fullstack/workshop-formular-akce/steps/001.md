# --description--

Bazárek pro věci, které někomu doma překážejí. Stránka je nastylovaná,
v `data.js` čekají tři inzeráty — a v seznamu není nic.

**Úkol:** v `App.jsx` vypiš každý inzerát z pole `inzeraty` jako položku seznamu.
Každá položka je `<li className="karta">` a uvnitř má nadpis `<h3>` s názvem,
odstavec `<p className="karta__cena">` s cenou a `Kč` a odstavec
`<p className="karta__popis">` s popisem.

Tohle je opakování bez návodu — na seznamech z pole stojí každá aplikace, takže
si je vybav sám. Příklad na jiných datech:

```jsx
<ul>
  {filmy.map((film) => (
    <li key={film.id}>{film.nazev}</li>
  ))}
</ul>
```

# --hints--

V seznamu jsou tři položky — jedna za každý inzerát z pole.

```js
const polozky = document.querySelectorAll('[data-testid="seznam"] li');
assert.equal(polozky.length, 3, 'V seznamu mají být tři položky, jedna za každý inzerát z pole inzeraty');
```

Každá položka ukazuje název, cenu i popis inzerátu.

```js
const prvni = document.querySelector('[data-testid="seznam"] li');
assert.ok(prvni, 'V seznamu má být aspoň jedna položka');
const text = helpers.normalize(prvni.textContent);
assert.match(text, /Kolo Author Solution/, 'První položka má obsahovat název „Kolo Author Solution 29"');
assert.match(text, /7500/, 'První položka má obsahovat cenu 7500');
assert.match(text, /Jeté dvě sezony/, 'První položka má obsahovat popis inzerátu');
const nadpis = prvni.querySelector('h3');
assert.ok(nadpis && helpers.normalize(nadpis.textContent).includes('Kolo Author'), 'Název patří do nadpisu <h3>');
```

React si na položky seznamu nestěžuje do konzole — každá má svůj `key`.

```js
const stiznost = logs.find((zapis) => /unique "key"/.test(zapis.text));
assert.ok(!stiznost, 'Každá položka seznamu potřebuje vlastní key (React hlásí: ' + (stiznost ? stiznost.text : '') + ')');
```

## --file-- App.jsx

```jsx
import { pocatecniInzeraty } from './data';

export default function Bazarek() {
  const inzeraty = pocatecniInzeraty;

  return (
    <main className="bazarek">
      <header className="hlavicka">
        <h1>Bazárek</h1>
        <p className="podtitulek">Věci, které někomu doma překážejí.</p>
      </header>

      <section className="nabidka">
        <h2>Na prodej</h2>
        <ul className="seznam" data-testid="seznam">
          {inzeraty.map((inzerat) => (
            <li className="karta" key={inzerat.id}>
              <h3>{inzerat.nazev}</h3>
              <p className="karta__cena">{inzerat.cena} Kč</p>
              <p className="karta__popis">{inzerat.popis}</p>
            </li>
          ))}
        </ul>
      </section>
    </main>
  );
}
```
