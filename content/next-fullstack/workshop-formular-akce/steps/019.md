# --description--

Dvě drobnosti, které dělají rozdíl mezi cvičením a hotovou aplikací.

Za prvé: nadpis `Na prodej` má rovnou říct, kolik inzerátů je vidět — číslo
v závorce za nadpisem, například `Na prodej (3)`.

Za druhé: když filtr nic nenajde, zůstane po seznamu prázdné místo a uživatel
neví, jestli se něco nerozbilo. Místo prázdného seznamu ukaž odstavec
`<p className="prazdno">` s textem `Nic jsme nenašli.`

**Úkol:** doplň obojí. Počet i rozhodnutí ber z toho seznamu, který se právě
vypisuje — tedy včetně položky, která se zrovna ukládá.

# --hints--

V nadpisu je počet vypsaných inzerátů.

```js
const nadpis = [...document.querySelectorAll('h2')].find((prvek) => /Na prodej/.test(prvek.textContent));
assert.ok(nadpis, 'Nadpis „Na prodej" má zůstat na stránce');
assert.match(helpers.normalize(nadpis.textContent), /\(3\)/, 'V nadpisu má být počet (3), je tam: ' + helpers.normalize(nadpis.textContent));
```

Po zafiltrování se počet změní.

```js
await helpers.type(document.querySelector('#hledani'), 'stan');
const nadpis = await helpers.waitFor(() => [...document.querySelectorAll('h2')].find((prvek) => /Na prodej \(1\)/.test(helpers.normalize(prvek.textContent))));
assert.match(helpers.normalize(nadpis.textContent), /\(1\)/, 'Po zafiltrování má nadpis ukazovat počet nalezených');
```

Když filtr nic nenajde, je místo seznamu hláška „Nic jsme nenašli.".

```js
await helpers.type(document.querySelector('#hledani'), 'kajak');
await helpers.waitFor(() => document.querySelector('.prazdno'));
const prazdno = document.querySelector('.prazdno');
assert.equal(helpers.normalize(prazdno.textContent), 'Nic jsme nenašli.', 'Text hlášky má být „Nic jsme nenašli."');
assert.ok(!document.querySelector('[data-testid="seznam"]'), 'Prázdný seznam <ul> se nemá vykreslovat vůbec');
```

Po vymazání filtru je seznam zase zpátky.

```js
await helpers.type(document.querySelector('#hledani'), 'kajak');
await helpers.waitFor(() => document.querySelector('.prazdno'));
await helpers.type(document.querySelector('#hledani'), '');
await helpers.waitFor(() => document.querySelector('[data-testid="seznam"]'));
assert.equal(document.querySelectorAll('[data-testid="seznam"] li').length, 3, 'Po vymazání filtru mají být vidět zase všechny inzeráty');
assert.ok(!document.querySelector('.prazdno'), 'Hláška o prázdném výsledku má zmizet');
```

# --help--

## --tip-- 1

Počet je délka toho pole, které se vypisuje. Pozor, které z těch tří polí
v komponentě to je — vypisuje se dočasný pohled, ne původní data.

## --tip-- 3

Buď se vykreslí jedno, nebo druhé. V JSX se to píše ternárním operátorem
kolem celého bloku značek; celý blok se pak obaluje kulatými závorkami.

          <label htmlFor="cena">Cena v Kč</label>

        </p>
      </form>

      <section className="nabidka">
        <h2>Na prodej</h2>

            id="hledani"
            name="hledani"
            value={hledani}
            onChange={(udalost) => setHledani(udalost.target.value)}
          />
        </p>
        <ul className="seznam" data-testid="seznam">
          {seznam.map((inzerat) => (
            <li
              className={inzerat.ceka ? 'karta karta--ceka' : 'karta'}
              key={inzerat.id}
              aria-busy={inzerat.ceka ? 'true' : undefined}
            >
              <h3>{inzerat.nazev}</h3>
              <p className="karta__cena">{formatujCenu(inzerat.cena)}</p>
              <p className="karta__popis">{inzerat.popis}</p>
              {inzerat.ceka && <p className="karta__stav">Ukládám…</p>}
            </li>
          ))}
        </ul>
      </section>
    </main>
  );
}

// Tahle funkce zastupuje serverovou akci. V Next.js by měla na prvním řádku
// 'use server', běžela by na serveru a zapisovala do databáze. Tady jen chvíli
// počká a vrátí stejný tvar výsledku, jaký by vrátila doopravdy.
const pauza = (ms) => new Promise((splnit) => setTimeout(splnit, ms));
export async function vytvorInzerat(predchoziStav, formData) {
  const nazev = String(formData.get('nazev') ?? '').trim();
  const cena = String(formData.get('cena') ?? '').trim();
  const popis = String(formData.get('popis') ?? '').trim();
  await pauza(400);
  const chyby = {};
  if (nazev.length < 3) chyby.nazev = 'Název musí mít aspoň 3 znaky.';
  if (!Number.isInteger(Number(cena)) || Number(cena) <= 0) chyby.cena = 'Cena musí být kladné celé číslo.';
  if (Object.keys(chyby).length > 0) return { chyby, hodnoty: { nazev, cena, popis } };
  return { ok: true, inzerat: { id: 'inzerat-' + Date.now(), nazev, cena: Number(cena), popis } };
}
