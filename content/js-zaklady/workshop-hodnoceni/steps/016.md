# --description--

Pod výsledek studenta přidá přehled upozornění, když je co hlásit:

- za pětku `nedostatečná, nabídni opravný termín`,
- když se student oproti minulé písemce zhoršil **aspoň o dva stupně**, `zhoršení o 2 stupně` (s rozdílem, takže i `zhoršení o 3 stupně`),
- jinak nic, funkce vrátí `null`.

Pětka má přednost: kdo spadl z trojky na pětku, dostane jen upozornění na pětku.

**Úkol:** Pod `pointsCell` napiš funkci `warningFor(grade, previousGrade)`, která vrátí text upozornění, nebo `null`.

Pozor na [[okrajový případ]]: nový student minulou písemku nepsal a `previousGrade` je `null`. JavaScript při odčítání s `null` počítá, jako by to byla nula, takže `4 - null` je `4` — a nováček se čtyřkou by dostal falešné „zhoršení". Takový případ vyřiď dřív, než odčítáš. Hodí se `&&` v jedné podmínce, nebo brzký `return` — vyber.

# --hints--

`warningFor` za pětku vrátí `nedostatečná, nabídni opravný termín`, i když se student zároveň zhoršil nebo je nový.

```js
assert.equal(warningFor(5, 3), 'nedostatečná, nabídni opravný termín', "warningFor(5, 3) má vrátit 'nedostatečná, nabídni opravný termín' — pětka má přednost");
assert.equal(warningFor(5, null), 'nedostatečná, nabídni opravný termín', "warningFor(5, null) má vrátit 'nedostatečná, nabídni opravný termín'");
```

`warningFor` hlásí zhoršení aspoň o dva stupně i s rozdílem.

```js
assert.equal(warningFor(3, 1), 'zhoršení o 2 stupně', "warningFor(3, 1) má vrátit 'zhoršení o 2 stupně'");
assert.equal(warningFor(4, 1), 'zhoršení o 3 stupně', "warningFor(4, 1) má vrátit 'zhoršení o 3 stupně'");
```

`warningFor` vrátí `null` při zhoršení o jeden stupeň, při zlepšení a u nového studenta.

```js
assert.equal(warningFor(2, 1), null, 'warningFor(2, 1) má vrátit null — zhoršení o jeden stupeň se nehlásí');
assert.equal(warningFor(1, 3), null, 'warningFor(1, 3) má vrátit null — zlepšení se nehlásí');
assert.equal(warningFor(4, null), null, 'warningFor(4, null) má vrátit null — nový student nemá s čím srovnávat');
```

# --help--

## --tip--

Dvě podmínky v jedné spojuje `&&` — viz [Skládání podmínek](see:js-zaklady/porovnani-a-logika#skladani-podminek-a). Pořadí kontrol řeší [brzký return](see:js-zaklady/porovnani-a-logika#rozhodnuti-zabalene-do-funkce).

## --tip--

Nejdřív se zeptej na pětku. Pak na zhoršení, ale jen když minulá známka není `null`; rozdíl je nová známka minus minulá. Text s rozdílem slož šablonovým řetězcem. Když nic neplatí, vrať `null`.

## --tip--

Rozepsané na podcíle: `// 1. pětka → text o opravném termínu` `// 2. minulá známka existuje a rozdíl je aspoň 2 → text s rozdílem` `// 3. jinak null`

function hasPraise(percent, attendancePercent) {

function gradeColor(grade) {

      color = 'yellowgreen';
      break;

      color = 'gold';

  return Math.round((earned / max) * 100);

function gradeFor(percent) {
  if (percent < 0 || percent > 100) {
    return null;
  }
  if (percent >= 90) {
    return 1;
  } else if (percent >= 75) {
    return 2;
  } else if (percent >= 50) {
    return 3;
  } else if (percent >= 30) {
    return 4;
  } else {
    return 5;

    return 'výborná docházka';

    return 'docházka v pořádku';
  } else if (attendancePercent >= 60) {
    return 'nízká docházka';
  } else {
    return 'nelze klasifikovat';
  }
}

  return hasPraise(percent, attendancePercent) ? 'navrhnout pochvalu' : 'bez pochvaly';
}

// Má si výsledku všimnout třídní učitelka?
function needsAttention(grade, attendancePercent) {
  return grade === 5 || attendancePercent < 60;
}

// Body do tabulky třídy; kdo nepsal, nemá body.
function pointsCell(earned) {
  return earned ?? 'nepsal(a)';

  return grade === 5 || attendancePercent < 60;
}

// Body do tabulky třídy; kdo nepsal, nemá body.
function pointsCell(earned) {
  return earned ?? 'nepsal(a)';
}

// Upozornění k výsledku, nebo null, když není co hlásit.
function warningFor(grade, previousGrade) {
  if (grade === 5) {
    return 'nedostatečná, nabídni opravný termín';
  }
  if (previousGrade !== null && grade - previousGrade >= 2) {
    return `zhoršení o ${grade - previousGrade} stupně`;
  }
  return null;
}
