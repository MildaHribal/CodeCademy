# --description--

Písemka je splněná **od 50 %**. Na tohle se učitelka nad výsledkem ptá jako první.

**Úkol:** Pod výpis úspěšnosti založ konstantu `hasPassed` s výsledkem porovnání: `true`, když má Tereza aspoň 50 %, jinak `false`. Vypiš ji s popiskem, tedy `Splněno: true`.

Porovnání samo vrací `true` nebo `false`, takže `if` tu nepotřebuješ. Na jiných datech:

```js
// 1. porovnání uloží rovnou true, nebo false
const isAdult = age >= 18;
// 2. výpis s popiskem
console.log('Plnoletý:', isAdult);
```

„Od 50 %" znamená, že hranice do splněné písemky patří.

# --hints--

`hasPassed` je `true`.

```js
assert.equal(hasPassed, true, 'hasPassed má být true (90 % je víc než 50 %)');
```

`hasPassed` platí i přesně na hranici: pro 20 bodů (50 %) je `true`, pro 19 bodů (48 %) `false`.

```js
// Spustí tvůj kód znovu s jinými daty a vrátí vybrané proměnné a výpisy.
const rerun = (changes, names = '') => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  const lines = [];
  const quietConsole = { log: (...parts) => lines.push(parts.map(String).join(' ')) };
  const values = new Function('console', `${src}\nreturn { ${names} };`)(quietConsole);
  return { ...values, lines };
};
const edge = rerun([["const pointsInput = '36';", "const pointsInput = '20';"]], 'hasPassed');
assert.equal(edge.hasPassed, true, 'Pro 20 bodů ze 40 (přesně 50 %) má hasPassed být true — hranice do splněné písemky patří');
const below = rerun([["const pointsInput = '36';", "const pointsInput = '19';"]], 'hasPassed');
assert.equal(below.hasPassed, false, 'Pro 19 bodů ze 40 (48 %) má hasPassed být false');
```

V konzoli je řádek `Splněno: true`.

```js
const sameLine = (a) => a.normalize('NFC').replace(/\u00a0/g, ' ').replace(/\s+/g, ' ').trim();
assert.ok(logs.some((line) => sameLine(line.text) === sameLine('Splněno: true')), 'V konzoli má být řádek Splněno: true');
```

## --tip--

Vlevo od porovnání je `studentPercent`, vpravo hranice. Operátor musí hranici pustit: „větší nebo rovno".

## --tip--

Rozepsané na podcíle: `// 1. vlevo hodnota, na kterou se ptáš` `// 2. operátor, který hranici pustí` `// 3. vpravo hranice` `// 4. výsledek ulož do konstanty a vypiš s popiskem`

# --solution--

## --file-- script.js

```js
// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent > 90 && attendancePercent > 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = Math.round((studentPoints / maxPoints) * 100);
console.log(`Úspěšnost: ${studentPercent} %`);

const hasPassed = studentPercent >= 50;
console.log('Splněno:', hasPassed);
```
