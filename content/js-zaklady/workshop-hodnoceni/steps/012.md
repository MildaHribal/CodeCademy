# --description--

Třídní učitelka chce v přehledu zvýraznit každého, u koho je problém: kdo dostal **pětku**, nebo kdo má docházku **pod 60 %**. Stačí jedno z toho.

**Úkol:** Pod `praiseText` napiš funkci `needsAttention(grade, attendancePercent)`, která vrátí `true`, když si má učitelka výsledku všimnout, jinak `false`.

Dvě podmínky spojuje `&&` (musí platit obě) nebo `||` (stačí jedna). U kolegovy pochvaly bylo správně `&&`, tady rozhodni sám podle zadání. Porovnání vracejí `true` a `false`, takže složenou podmínku můžeš rovnou vrátit bez `if`.

# --hints--

`needsAttention` vrátí `true` pro pětku i pro docházku pod 60 %.

```js
assert.equal(needsAttention(5, 95), true, 'needsAttention(5, 95) má vrátit true — pětka stačí');
assert.equal(needsAttention(1, 50), true, 'needsAttention(1, 50) má vrátit true — docházka pod 60 % stačí');
assert.equal(needsAttention(5, 40), true, 'needsAttention(5, 40) má vrátit true');
```

`needsAttention` vrátí `false`, když není ani pětka, ani nízká docházka — i přesně na hranici 60 %.

```js
assert.equal(needsAttention(4, 60), false, 'needsAttention(4, 60) má vrátit false — 60 % docházky ještě není pod hranicí');
assert.equal(needsAttention(1, 100), false, 'needsAttention(1, 100) má vrátit false');
```

## --tip--

Spojování podmínek je v části [Skládání podmínek](see:js-zaklady/porovnani-a-logika#skladani-podminek-a).

## --tip--

Zadání říká „nebo" a „stačí jedno". Jedna podmínka se ptá na známku, druhá na docházku; „pod 60 %" hranici nepouští.

## --tip--

Rozepsané na podcíle: `// 1. otázka na pětku` `// 2. otázka na docházku pod hranicí` `// 3. spoj je tak, aby stačila jedna` `// 4. výsledek rovnou vrať`

function hasPraise(percent, attendancePercent) {

function gradeColor(grade) {

      break;
    case 3:
      color = 'gold';

    return 2;

    return 4;
  } else {
    return 5;
  }

    return 'výborná docházka';

    return 'docházka v pořádku';
  } else if (attendancePercent >= 60) {
    return 'nízká docházka';
  } else {
    return 'nelze klasifikovat';
  }

      return 'dobrý';

      return 'dostatečný';

      return 'nedostatečný';

      return 'neznámá známka';
  }
}
