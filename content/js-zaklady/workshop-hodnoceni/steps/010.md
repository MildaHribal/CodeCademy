# --description--

## Hlášení

Třídní učitelka navrhuje pochvalu, když má student v písemce **aspoň 90 %** a zároveň **aspoň 90 % docházky**. Tohle pravidlo je v komentáři nad kolegovou funkcí `hasPraise` nahoře v souboru.

Jakub Dvořák měl v písemce přesně 90 % a docházku 96 %. Návrh na pochvalu nedostal: `hasPraise(90, 96)` vrací `false`. Stejně dopadla Karolína s 97 % a docházkou přesně 90 %. Studenti s 95 % a docházkou 95 % pochvalu dostávají. V konzoli žádná chyba není.

## Úkol

Oprav `hasPraise`, aby hranice 90 % platila včetně. Změň co nejmenší kus kódu.

# --hints--

`hasPraise` navrhne pochvalu přesně na hranici 90 % v písemce i v docházce.

```js
assert.equal(hasPraise(90, 96), true, 'hasPraise(90, 96) má vrátit true — 90 % v písemce na pochvalu stačí');
assert.equal(hasPraise(97, 90), true, 'hasPraise(97, 90) má vrátit true — 90 % docházky na pochvalu stačí');
assert.equal(hasPraise(90, 90), true, 'hasPraise(90, 90) má vrátit true');
```

`hasPraise` dál vyžaduje obě podmínky zároveň a pod hranicí pochvalu nedá.

```js
assert.equal(hasPraise(95, 95), true, 'hasPraise(95, 95) má vrátit true');
assert.equal(hasPraise(89, 100), false, 'hasPraise(89, 100) má vrátit false — 89 % v písemce nestačí');
assert.equal(hasPraise(100, 89), false, 'hasPraise(100, 89) má vrátit false — 89 % docházky nestačí');
```

Tvoje funkce fungují dál: `gradeFor(90)` je `1` a `gradeLabel(2)` je `chvalitebný`.

```js
assert.equal(gradeFor(90), 1, 'gradeFor(90) má vrátit 1');
assert.equal(gradeLabel(2), 'chvalitebný', "gradeLabel(2) má vrátit 'chvalitebný'");
```

# --help--

## --tip--

Chyba je na hranici — viz past [Hranice](see:js-zaklady/porovnani-a-logika#hranice-misto).

## --tip--

Porovnej slovo „aspoň" z komentáře s oběma porovnáními v `return`. Pustí operátor hodnotu, která se hranici přesně rovná?

## --tip--

Na jiných datech: vstup „od 15 let" hlídá `age >= 15`; zápis `age > 15` pustí dovnitř až šestnáctileté.

# --explain--

Vysvětli vlastními slovy, proč kolegova funkce fungovala u studentů s 95 % a selhala právě u 90 %, a jak podobnou chybu příště odhalíš dřív.

## --model--

Operátor `>` hodnotu rovnou hranici nepustí, `90 > 90` je `false`. U 95 % je jedno, jestli je tam `>` nebo `>=`, obě porovnání platí, a proto chyba nebyla vidět. Rozdíl se ukáže jen přesně na hranici. Když zadání říká „aspoň" nebo „od", patří tam `>=`, a do příkladů si vždycky dám i hodnotu přesně na hranici.

## --checklist--

- `>` hodnotu rovnou hranici nepustí, `>=` ano.
- Mimo hranici dávají `>` i `>=` stejný výsledek, proto chyba nebyla vidět.
- „Aspoň" nebo „od" v zadání znamená `>=`.
- Hodnotu přesně na hranici je potřeba vždycky vyzkoušet.

```js
// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

--edit--
// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent > 90 && attendancePercent > 90;
}
--edit--

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// Úspěšnost v procentech zaokrouhlená na celé číslo.
function percentOf(earned, max) {
  return Math.round((earned / max) * 100);
}

function gradeFor(percent) {
  if (percent >= 90) {
    return 1;
  } else if (percent >= 75) {
    return 2;
  } else if (percent >= 50) {
    return 3;
  } else if (percent >= 30) {
    return 4;
  } else {
    return 5;
  }
}

// Slovní poznámka k docházce.
function attendanceNote(attendancePercent) {
  if (attendancePercent >= 90) {
    return 'výborná docházka';
  } else if (attendancePercent >= 75) {
    return 'docházka v pořádku';
  } else if (attendancePercent >= 60) {
    return 'nízká docházka';
  } else {
    return 'nelze klasifikovat';
  }
}

// Slovní název známky na vysvědčení.
function gradeLabel(grade) {
  switch (grade) {
    case 1:
      return 'výborný';
    case 2:
      return 'chvalitebný';
    case 3:
      return 'dobrý';
    case 4:
      return 'dostatečný';
    case 5:
      return 'nedostatečný';
    default:
      return 'neznámá známka';
  }
}

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = percentOf(studentPoints, maxPoints);
console.log(`Úspěšnost: ${studentPercent} %`);

const hasPassed = studentPercent >= 50;
console.log('Splněno:', hasPassed);

if (hasPassed) {
  console.log('Písemka je splněná.');
} else {
  console.log('Písemka není splněná, domluv si opravný termín.');
}

const studentGrade = gradeFor(studentPercent);
console.log(`Známka: ${studentGrade}`);
console.log(`Docházka ${attendance} %: ${attendanceNote(attendance)}`);
```
