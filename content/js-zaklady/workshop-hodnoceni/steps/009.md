# --description--

Na vysvědčení se píše slovo: 1 `výborný`, 2 `chvalitebný`, 3 `dobrý`, 4 `dostatečný`, 5 `nedostatečný`.

**Úkol:** Pod `attendanceNote` napiš funkci `gradeLabel(grade)`, která vrátí slovní název známky. Pro cokoli jiného než čísla 1 až 5 vrátí `neznámá známka`.

Tentokrát nehledáš rozsah, ale porovnáváš jednu hodnotu s pěti přesnými možnostmi. Hodí se řetěz `else if` s `===`, nebo `switch`, který je na přesné hodnoty stavěný. Ternární operátor na pět možností ne. Jak vypadá `switch` s `return`, na jiných datech:

```js
function dayType(dayNumber) {
  switch (dayNumber) {
    case 6:
    case 7:
      return 'víkend';
    default:
      return 'pracovní den';
  }
}
```

`return` funkci ukončí, takže za ním `break` psát nemusíš.

# --hints--

`gradeLabel` vrátí `výborný`, `chvalitebný` a `dobrý` pro 1, 2 a 3.

```js
assert.equal(gradeLabel(1), 'výborný', "gradeLabel(1) má vrátit 'výborný'");
assert.equal(gradeLabel(2), 'chvalitebný', "gradeLabel(2) má vrátit 'chvalitebný'");
assert.equal(gradeLabel(3), 'dobrý', "gradeLabel(3) má vrátit 'dobrý'");
```

`gradeLabel` vrátí `dostatečný` a `nedostatečný` pro 4 a 5.

```js
assert.equal(gradeLabel(4), 'dostatečný', "gradeLabel(4) má vrátit 'dostatečný'");
assert.equal(gradeLabel(5), 'nedostatečný', "gradeLabel(5) má vrátit 'nedostatečný'");
```

Pro jinou hodnotu, i pro text `'1'`, vrátí `gradeLabel` `neznámá známka`.

```js
assert.equal(gradeLabel(0), 'neznámá známka', "gradeLabel(0) má vrátit 'neznámá známka'");
assert.equal(gradeLabel(6), 'neznámá známka', "gradeLabel(6) má vrátit 'neznámá známka'");
assert.equal(gradeLabel('1'), 'neznámá známka', "gradeLabel('1') má vrátit 'neznámá známka' — text '1' není číslo 1, porovnávej přísně");
```

# --help--

## --tip--

Přesné hodnoty porovnává [`switch`](see:js-zaklady/porovnani-a-logika#switch-a-propadani); stejně dobře poslouží řetěz `else if` s `===`.

## --tip--

Každá známka je jedna větev, která vrátí slovo. Na „cokoli jiného" má `switch` větev `default`, řetěz `else if` poslední `else`.

## --tip--

Rozepsané na podcíle: `// 1. rozhoduj podle grade` `// 2. pro každou známku 1 až 5 vrať slovo` `// 3. pro všechno ostatní vrať text o neznámé známce`

# --explain--

Vysvětli vlastními slovy, proč ve `switch`, kde každá větev končí `return`, nepotřebuješ `break`, a co by se stalo, kdyby větve jen přiřazovaly do proměnné bez `break`.

## --model--

`switch` skočí na odpovídající `case` a odtud provádí příkazy dál, dokud ho něco nezastaví. `return` ukončí celou funkci, takže do dalšího `case` se program nedostane. Kdyby větve jen přiřazovaly do proměnné, bez `break` by propadly do dalších větví a poslední přiřazení by přepsalo to správné. Proto buď `return`, nebo `break` za každou větví.

## --checklist--

- `switch` od nalezeného `case` pokračuje dalšími větvemi, dokud ho nic nezastaví.
- `return` ukončí celou funkci, a tím zastaví i `switch`.
- Bez `break` by přiřazení propadlo do dalšího `case` a přepsalo se.
- Každá větev končí `return`, nebo `break`.
