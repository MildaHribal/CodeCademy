# --description--

Poslední krok: přehled pro celou třídu.

**Úkol:** Na konec souboru vypiš přehledy těchto pěti studentů, každého jedním voláním `reportFor`, v tomhle pořadí:

- Tereza Malá: 36 bodů, minule trojka,
- Jakub Dvořák: 11 bodů, minule trojka,
- Karolína Veselá: 21 bodů, minule jednička,
- Ondřej Kolář: 30 bodů, je ve třídě nový,
- Ema Horáková: písemku nepsala, minule dvojka.

V konzoli teď uvidíš hotový přehled: známky, slovní hodnocení i upozornění, u každého studenta jiné. Tím je modul hotový. Za sebou máš:

- porovnání, která vracejí `true` a `false`, a hranice s `>=`,
- `if`, `else` a řetěz `else if` od nejvyšší hranice,
- `switch` s `return`, ternární operátor, `&&` a `||`,
- `??`, který nechá nulu nulou,
- brzký `return` pro neplatné a chybějící vstupy,
- opravu dvou kolegových chyb: hranice s `>` a zapomenutý `break`.

Stejné rozhodování najdeš v každé aplikaci, která něco hodnotí nebo počítá podle pravidel: doprava zdarma v e-shopu, tarif podle spotřeby, sleva podle věku.

> [!REMEMBER]
> **Hranice vždycky vyzkoušej přesně na hraniční hodnotě a chybějící údaj (`null`) odliš od nuly.**

Příště se naučíš cykly. Pak přehled celé třídy vypíše jeden cyklus místo pěti ručních volání.

## Udělej po svém

- **Vzhled výpisu:** před přehledy vypiš nadpis s názvem písemky a mezi studenty oddělovací čáru z pomlček.
- **Funkce navíc:** přidej `retakeText(grade, retakesUsed)`, která opravný termín nabídne jen tomu, kdo má pětku a opravu ještě nepsal.
- **Tvoje téma:** předělej modul na hodnocení v běžeckém klubu (čas místo bodů, výkonnostní třídy místo známek) nebo na hvězdičky u recenzí v e-shopu.

# --help--

## --tip--

Hotové funkce jen voláš a výsledek vypisuješ — viz [Rozhodnutí zabalené do funkce](see:js-zaklady/porovnani-a-logika#rozhodnuti-zabalene-do-funkce).

## --tip--

Každý student je jeden výpis s voláním `reportFor`: jméno v uvozovkách, body jako číslo a minulá známka jako číslo. Kdo nepsal nebo je nový, má na místě chybějícího údaje `null`.

## --tip--

Stejně jsi v kroku se známkou a docházkou vložil volání funkce do výpisu. Tady je celé volání `reportFor` jediná věc, kterou vypisuješ.

## --file-- script.js

```js
// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent >= 90 && attendancePercent >= 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
      break;
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// Úspěšnost v procentech zaokrouhlená na celé číslo.
function percentOf(earned, max) {
  return Math.round((earned / max) * 100);
}

function gradeFor(percent) {
  if (percent < 0 || percent > 100) {
    return null;
  }
  if (percent >= 90) {
    return 1;
  } else if (percent >= 75) {
    return 2;
  } else if (percent >= 50) {
    return 3;
  } else if (percent >= 30) {
    return 4;
  } else {
    return 5;
  }
}

// Slovní poznámka k docházce.
function attendanceNote(attendancePercent) {
  if (attendancePercent >= 90) {
    return 'výborná docházka';
  } else if (attendancePercent >= 75) {
    return 'docházka v pořádku';
  } else if (attendancePercent >= 60) {
    return 'nízká docházka';
  } else {
    return 'nelze klasifikovat';
  }
}

// Slovní název známky na vysvědčení.
function gradeLabel(grade) {
  switch (grade) {
    case 1:
      return 'výborný';
    case 2:
      return 'chvalitebný';
    case 3:
      return 'dobrý';
    case 4:
      return 'dostatečný';
    case 5:
      return 'nedostatečný';
    default:
      return 'neznámá známka';
  }
}

// Text do přehledu: navrhnout pochvalu, nebo ne.
function praiseText(percent, attendancePercent) {
  return hasPraise(percent, attendancePercent) ? 'navrhnout pochvalu' : 'bez pochvaly';
}

// Má si výsledku všimnout třídní učitelka?
function needsAttention(grade, attendancePercent) {
  return grade === 5 || attendancePercent < 60;
}

// Body do tabulky třídy; kdo nepsal, nemá body.
function pointsCell(earned) {
  return earned ?? 'nepsal(a)';
}

// Upozornění k výsledku, nebo null, když není co hlásit.
function warningFor(grade, previousGrade) {
  if (grade === 5) {
    return 'nedostatečná, nabídni opravný termín';
  }
  if (previousGrade !== null && grade - previousGrade >= 2) {
    return `zhoršení o ${grade - previousGrade} stupně`;
  }
  return null;
}

// Tvar slova „bod" podle počtu.
function pointsWord(count) {
  if (count === 1) {
    return 'bod';
  }
  if (count >= 2 && count <= 4) {
    return 'body';
  }
  return 'bodů';
}

// Známka z bodů; kdo nepsal (null), známku nemá.
function gradeOf(earned) {
  if (earned === null) {
    return null;
  }
  return gradeFor(percentOf(earned, maxPoints));
}

// První řádek přehledu, třeba „Tereza Malá: 36 bodů (90 %)".
function headline(name, earned) {
  if (earned === null) {
    return `${name}: nepsal(a)`;
  }
  return `${name}: ${earned} ${pointsWord(earned)} (${percentOf(earned, maxPoints)} %)`;
}

// Druhý řádek přehledu se známkou.
function gradeLine(earned) {
  if (earned === null) {
    return 'Známka: bez známky';
  }
  const grade = gradeOf(earned);
  if (grade === null) {
    return 'Známka: chyba v bodech';
  }
  return `Známka: ${grade} (${gradeLabel(grade)})`;
}

// Celý přehled studenta: dva řádky a případně upozornění.
function reportFor(name, earned, previousGrade) {
  const report = `${headline(name, earned)}
${gradeLine(earned)}`;
  const warning = warningFor(gradeOf(earned), previousGrade);
  if (warning === null) {
    return report;
  }
  return `${report}
Upozornění: ${warning}`;
}

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = percentOf(studentPoints, maxPoints);
console.log(`Úspěšnost: ${studentPercent} %`);

const hasPassed = studentPercent >= 50;
console.log('Splněno:', hasPassed);

if (hasPassed) {
  console.log('Písemka je splněná.');
} else {
  console.log('Písemka není splněná, domluv si opravný termín.');
}

const studentGrade = gradeFor(studentPercent);
console.log(`Známka: ${studentGrade}`);
console.log(`Docházka ${attendance} %: ${attendanceNote(attendance)}`);

console.log(`${studentName}: ${studentPercent} % → ${studentGrade} (${gradeLabel(studentGrade)})`);

--edit--

--edit--
```
