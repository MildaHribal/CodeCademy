# --description--

Tereza je jen jedna z 28 studentů. Procenta, známku i hodnocení budeš počítat pro každého, a proto výpočty odteď balíš do **funkcí**: funkce dostane vstup v parametrech a výsledek vrátí přes `return`.

**Úkol:** Pod komentář `// ---- Tvoje funkce ----` napiš funkci `percentOf(earned, max)`, která vrátí úspěšnost v procentech zaokrouhlenou k nejbližšímu celému číslu. Řádek se `studentPercent` pak přepiš, aby výsledek počítal voláním `percentOf(studentPoints, maxPoints)`.

Na jiných datech:

```js
// Cena na osobu zaokrouhlená nahoru na koruny.
function pricePerPerson(total, people) {
  return Math.ceil(total / people);
}

const share = pricePerPerson(1227, 4);
```

Parametry `earned` a `max` jsou jen jména pro hodnoty, se kterými funkci zavoláš. Uvnitř funkce proto počítej s nimi, ne se `studentPoints` a `maxPoints` — jinak by funkce pro jiného studenta vracela pořád Tereziny procenta.

# --hints--

`percentOf(36, 40)` vrátí `90`.

```js
assert.equal(percentOf(36, 40), 90, 'percentOf(36, 40) má vrátit 90');
```

`percentOf` počítá z parametrů a zaokrouhluje k nejbližšímu číslu: `percentOf(29, 40)` je `73`, `percentOf(29, 60)` je `48`, `percentOf(45, 60)` je `75` a `percentOf(0, 50)` je `0`.

```js
assert.equal(percentOf(29, 40), 73, 'percentOf(29, 40) má vrátit 73 (72,5 zaokrouhleno k nejbližšímu)');
assert.equal(percentOf(29, 60), 48, 'percentOf(29, 60) má vrátit 48 (48,3 zaokrouhleno k nejbližšímu, ne nahoru)');
assert.equal(percentOf(45, 60), 75, 'percentOf(45, 60) má vrátit 75 — počítáš s parametry earned a max, ne s proměnnými nahoře?');
assert.equal(percentOf(0, 50), 0, 'percentOf(0, 50) má vrátit 0');
```

`studentPercent` se počítá voláním `percentOf` a je pořád `90`.

```js
const src = helpers.stripComments(files['script.js'], 'js');
assert.match(src, /studentPercent\s*=\s*percentOf\(/, 'studentPercent má vzniknout voláním percentOf(…)');
assert.equal(studentPercent, 90, 'studentPercent má zůstat 90');
```

## --tip--

Funkce s parametry a `return` je v lekci [Porovnání a logika](see:js-zaklady/porovnani-a-logika#rozhodnuti-zabalene-do-funkce).

## --tip--

Do těla funkce přesuň výpočet, který máš u `studentPercent`, jen místo proměnných nahoře použij parametry `earned` a `max`. Na řádku se `studentPercent` pak zůstane jen volání funkce.

## --tip--

Rozepsané na podcíle: `// 1. hlavička funkce s parametry earned a max` `// 2. v těle výpočet jen z parametrů` `// 3. výsledek vrať` `// 4. na řádku se studentPercent nech jen volání funkce`

## --file-- script.js

```js
// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent > 90 && attendancePercent > 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// Úspěšnost v procentech zaokrouhlená na celé číslo.
function percentOf(earned, max) {
  return Math.round((earned / max) * 100);
}

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = percentOf(studentPoints, maxPoints);
console.log(`Úspěšnost: ${studentPercent} %`);

const hasPassed = studentPercent >= 50;
console.log('Splněno:', hasPassed);

if (hasPassed) {
  console.log('Písemka je splněná.');
} else {
  console.log('Písemka není splněná, domluv si opravný termín.');
}
```
