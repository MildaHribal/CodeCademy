# --description--

Do přehledu se k výsledku píše buď `navrhnout pochvalu`, nebo `bez pochvaly`.

**Úkol:** Pod `gradeLabel` napiš funkci `praiseText(percent, attendancePercent)`, která zavolá opravenou `hasPraise` a podle výsledku vrátí jeden z těch dvou textů.

Vybíráš jednu ze **dvou hodnot**. `if` s `else` a dvěma `return` by fungoval, ale kratší a čitelnější je tu ternární operátor — výraz „podmínka, otazník, hodnota, dvojtečka, hodnota", který jde rovnou vrátit. Na jiných datech:

```js
function ticketType(age) {
  return age >= 18 ? 'plné' : 'dětské';
}
```

# --hints--

`praiseText` vrátí `navrhnout pochvalu`, když jsou obě hodnoty aspoň 90 %.

```js
assert.equal(praiseText(95, 95), 'navrhnout pochvalu', "praiseText(95, 95) má vrátit 'navrhnout pochvalu'");
assert.equal(praiseText(90, 90), 'navrhnout pochvalu', "praiseText(90, 90) má vrátit 'navrhnout pochvalu'");
```

`praiseText` vrátí `bez pochvaly`, když jedna z hodnot nestačí.

```js
assert.equal(praiseText(89, 100), 'bez pochvaly', "praiseText(89, 100) má vrátit 'bez pochvaly'");
assert.equal(praiseText(100, 60), 'bez pochvaly', "praiseText(100, 60) má vrátit 'bez pochvaly'");
```

`praiseText` vybírá text ternárním operátorem.

```js
const src = helpers.stripComments(files['script.js'], 'js');
const start = src.indexOf('function praiseText');
assert.ok(start !== -1, 'V souboru má být funkce praiseText');
assert.match(src.slice(start), /\?[^]*?:/, 'praiseText má vybrat jeden ze dvou textů ternárním operátorem (podmínka ? … : …)');
```

# --help--

## --tip--

Výběr jedné ze dvou hodnot je [ternární operátor](see:js-zaklady/porovnani-a-logika#ternarni-operator).

## --tip--

Podmínkou je volání `hasPraise` s oběma parametry. Za otazník patří text pro pochvalu, za dvojtečku text bez ní, a celý výraz vrať.

## --tip--

Rozepsané na podcíle: `// 1. podmínka: co vrátí hasPraise` `// 2. za otazníkem text pro pochvalu` `// 3. za dvojtečkou text bez pochvaly` `// 4. celý výraz vrať`

const maxPoints = 40;

function hasPraise(percent, attendancePercent) {
  return percent >= 90 && attendancePercent >= 90;
