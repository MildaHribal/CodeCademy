# --description--

Z hotových kousků teď složíš přehled jednoho studenta.

**Úkol:** Pod `gradeLine` napiš funkci `reportFor(name, earned, previousGrade)`, která vrátí text na dva nebo tři řádky:

- první řádek z `headline`,
- druhý řádek z `gradeLine`,
- třetí řádek `Upozornění: …` s textem z `warningFor`, ale jen tehdy, když pro studentovu známku a minulou známku nějaké upozornění je.

Víceřádkový text umí šablonový řetězec. Nový řádek začni úplně vlevo, jinak se mezery z odsazení stanou součástí textu.

# --hints--

`reportFor('Tereza Malá', 36, 3)` vrátí dva řádky: `Tereza Malá: 36 bodů (90 %)` a `Známka: 1 (výborný)`.

```js
const toLines = (text) => String(text).split('\n').map((line) => line.trim()).filter((line) => line !== '');
assert.deepEqual(toLines(reportFor('Tereza Malá', 36, 3)), ['Tereza Malá: 36 bodů (90 %)', 'Známka: 1 (výborný)'], "reportFor('Tereza Malá', 36, 3) má vrátit dva řádky: Tereza Malá: 36 bodů (90 %) / Známka: 1 (výborný) — bez upozornění");
```

Pětka i zhoršení přidají třetí řádek s upozorněním.

```js
const toLines = (text) => String(text).split('\n').map((line) => line.trim()).filter((line) => line !== '');
assert.deepEqual(toLines(reportFor('Jakub Dvořák', 11, 3)), ['Jakub Dvořák: 11 bodů (28 %)', 'Známka: 5 (nedostatečný)', 'Upozornění: nedostatečná, nabídni opravný termín'], "reportFor('Jakub Dvořák', 11, 3) má vrátit tři řádky, třetí Upozornění: nedostatečná, nabídni opravný termín");
assert.deepEqual(toLines(reportFor('Karolína Veselá', 21, 1)), ['Karolína Veselá: 21 bodů (53 %)', 'Známka: 3 (dobrý)', 'Upozornění: zhoršení o 2 stupně'], "reportFor('Karolína Veselá', 21, 1) má vrátit tři řádky, třetí Upozornění: zhoršení o 2 stupně");
```

Nový student a student, který nepsal, dostanou jen dva řádky.

```js
const toLines = (text) => String(text).split('\n').map((line) => line.trim()).filter((line) => line !== '');
assert.deepEqual(toLines(reportFor('Ondřej Kolář', 30, null)), ['Ondřej Kolář: 30 bodů (75 %)', 'Známka: 2 (chvalitebný)'], "reportFor('Ondřej Kolář', 30, null) má vrátit dva řádky — nový student nemá upozornění");
assert.deepEqual(toLines(reportFor('Ema Horáková', null, 2)), ['Ema Horáková: nepsal(a)', 'Známka: bez známky'], "reportFor('Ema Horáková', null, 2) má vrátit dva řádky: Ema Horáková: nepsal(a) / Známka: bez známky");
```

# --help--

## --tip--

Víc řádků v jednom textu umí [šablonový řetězec](see:js-zaklady/promenne-a-typy#sablonovy-retezec); o třetím řádku rozhoduje podmínka.

## --tip--

Upozornění získáš z `warningFor` se známkou za body (tu vrátí `gradeOf`) a s minulou známkou. Když je `null`, vrať jen první dva řádky, jinak k nim přidej třetí.

## --tip--

Na jiných datech: potvrzení objednávky má vždy řádek se jménem a cenou a řádek „Poznámka: …" jen tehdy, když zákazník nějakou napsal.

# --explain--

Vysvětli vlastními slovy, proč je lepší skládat přehled z malých funkcí `headline`, `gradeLine` a `warningFor`, než všechno napsat do jedné dlouhé funkce `reportFor`.

## --model--

Každá malá funkce dělá jednu věc a dá se vyzkoušet zvlášť, takže chybu najdu rychle — v tomhle workshopu ji testy zkontrolovaly hned po napsání. Stejné kousky použiju i jinde, třeba tvar slova „bod" nebo známku z bodů. Když se změní pravidlo, třeba stupnice známek, upravím jedno místo a projeví se všude. `reportFor` pak zůstane krátká a čte se jako popis přehledu.

## --checklist--

- Malá funkce dělá jednu věc a jde vyzkoušet zvlášť.
- Chyba se v malé funkci najde rychleji.
- Stejnou funkci použiju na víc místech.
- Změna pravidla se udělá na jednom místě.

// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent >= 90 && attendancePercent >= 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
      break;
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// Úspěšnost v procentech zaokrouhlená na celé číslo.
function percentOf(earned, max) {
  return Math.round((earned / max) * 100);
}

function gradeFor(percent) {
  if (percent < 0 || percent > 100) {
    return null;
  }
  if (percent >= 90) {
    return 1;
  } else if (percent >= 75) {
    return 2;
  } else if (percent >= 50) {
    return 3;
  } else if (percent >= 30) {
    return 4;
  } else {
    return 5;
  }
}

// Slovní poznámka k docházce.
function attendanceNote(attendancePercent) {
  if (attendancePercent >= 90) {
    return 'výborná docházka';
  } else if (attendancePercent >= 75) {
    return 'docházka v pořádku';
  } else if (attendancePercent >= 60) {
    return 'nízká docházka';
  } else {
    return 'nelze klasifikovat';
  }
}

// Slovní název známky na vysvědčení.
function gradeLabel(grade) {
  switch (grade) {
    case 1:
      return 'výborný';
    case 2:
      return 'chvalitebný';
    case 3:
      return 'dobrý';
    case 4:
      return 'dostatečný';
    case 5:
      return 'nedostatečný';
    default:
      return 'neznámá známka';
  }
}

// Text do přehledu: navrhnout pochvalu, nebo ne.
function praiseText(percent, attendancePercent) {
  return hasPraise(percent, attendancePercent) ? 'navrhnout pochvalu' : 'bez pochvaly';
}

// Má si výsledku všimnout třídní učitelka?
function needsAttention(grade, attendancePercent) {
  return grade === 5 || attendancePercent < 60;
}

// Body do tabulky třídy; kdo nepsal, nemá body.
function pointsCell(earned) {
  return earned ?? 'nepsal(a)';
}

// Upozornění k výsledku, nebo null, když není co hlásit.
function warningFor(grade, previousGrade) {
  if (grade === 5) {
    return 'nedostatečná, nabídni opravný termín';
  }
  if (previousGrade !== null && grade - previousGrade >= 2) {
    return `zhoršení o ${grade - previousGrade} stupně`;
  }
  return null;
}

// Tvar slova „bod" podle počtu.
function pointsWord(count) {
  if (count === 1) {
    return 'bod';
  }
  if (count >= 2 && count <= 4) {
    return 'body';
  }
  return 'bodů';
}

// Známka z bodů; kdo nepsal (null), známku nemá.
function gradeOf(earned) {
  if (earned === null) {
    return null;
  }
  return gradeFor(percentOf(earned, maxPoints));
}

// První řádek přehledu, třeba „Tereza Malá: 36 bodů (90 %)".
function headline(name, earned) {
  if (earned === null) {
    return `${name}: nepsal(a)`;
  }
  return `${name}: ${earned} ${pointsWord(earned)} (${percentOf(earned, maxPoints)} %)`;
}

// Druhý řádek přehledu se známkou.
function gradeLine(earned) {
  if (earned === null) {
    return 'Známka: bez známky';
  }
  const grade = gradeOf(earned);
  if (grade === null) {
    return 'Známka: chyba v bodech';
  }
  return `Známka: ${grade} (${gradeLabel(grade)})`;
}

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = percentOf(studentPoints, maxPoints);
console.log(`Úspěšnost: ${studentPercent} %`);

const hasPassed = studentPercent >= 50;
console.log('Splněno:', hasPassed);

if (hasPassed) {
  console.log('Písemka je splněná.');
} else {
  console.log('Písemka není splněná, domluv si opravný termín.');
}

const studentGrade = gradeFor(studentPercent);
console.log(`Známka: ${studentGrade}`);
console.log(`Docházka ${attendance} %: ${attendanceNote(attendance)}`);

console.log(`${studentName}: ${studentPercent} % → ${studentGrade} (${gradeLabel(studentGrade)})`);
