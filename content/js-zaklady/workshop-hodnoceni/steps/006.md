# --description--

Škola známkuje podle procent: **jednička od 90 %**, dvojka od 75 %, trojka od 50 %, čtyřka od 30 % a pod 30 % pětka.

**Úkol:** Seřaď řádky tak, aby funkce `gradeFor(percent)` vrátila známku podle téhle stupnice. Do mezery doplň porovnávací operátor. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc — patří k typickým chybám.

Řetěz `else if` se prochází shora a provede se jen první větev, jejíž podmínka platí. Proto záleží na pořadí: hranice jdou od nejvyšší. Takhle dlouhý řetěz vidíš poprvé, a tak ho tentokrát jen skládáš; v dalším kroku stejný vzor napíšeš sám.

# --hints--

`gradeFor` dá jedničku od 90 % a dvojku od 75 %, i přesně na hranici.

```js
assert.equal(gradeFor(100), 1, 'gradeFor(100) má vrátit 1');
assert.equal(gradeFor(90), 1, 'gradeFor(90) má vrátit 1 — jednička je od 90 % včetně');
assert.equal(gradeFor(89), 2, 'gradeFor(89) má vrátit 2');
assert.equal(gradeFor(75), 2, 'gradeFor(75) má vrátit 2 — dvojka je od 75 % včetně');
```

`gradeFor` dá trojku od 50 % a čtyřku od 30 %.

```js
assert.equal(gradeFor(74), 3, 'gradeFor(74) má vrátit 3');
assert.equal(gradeFor(50), 3, 'gradeFor(50) má vrátit 3');
assert.equal(gradeFor(49), 4, 'gradeFor(49) má vrátit 4');
assert.equal(gradeFor(30), 4, 'gradeFor(30) má vrátit 4');
```

`gradeFor` dá pětku pod 30 %.

```js
assert.equal(gradeFor(29), 5, 'gradeFor(29) má vrátit 5');
assert.equal(gradeFor(0), 5, 'gradeFor(0) má vrátit 5');
```

# --help--

## --tip--

Řetěz podmínek od nejvyšší hranice je v lekci [Rozhodování: if, else if, else](see:js-zaklady/porovnani-a-logika#rozhodovani-if-else-if-else).

## --tip--

Kdyby první podmínka byla `>= 30`, platila by i pro 95 % a jednička by nepadla nikdy. Každá hranice je „od", tedy včetně.

# --parsons--

```js
function gradeFor(percent) {
  if (percent __1__ 90) {
    return 1;
  } else if (percent >= 75) {
    return 2;
  } else if (percent >= 50) {
    return 3;
  } else if (percent >= 30) {
    return 4;
  } else {
    return 5;
  }
}
```

const maxPoints = 40;

const studentName = 'Tereza Malá';
const pointsInput = '36';

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent > 90 && attendancePercent > 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// Úspěšnost v procentech zaokrouhlená na celé číslo.
function percentOf(earned, max) {
  return Math.round((earned / max) * 100);
}
