# --description--

Známka se nedává z bodů, ale z procent: písemky mají různá maxima a 36 bodů ze 40 je jiný výkon než 36 bodů z 60.

**Úkol:** Pod výpis bodů založ konstantu `studentPercent` s úspěšností v procentech, zaokrouhlenou **k nejbližšímu** celému číslu (36 ze 40 je 90 %). Vypiš ji jako `Úspěšnost: 90 %`.

# --hints--

`studentPercent` je `90`.

```js
assert.equal(studentPercent, 90, 'studentPercent má být 90 (36 / 40 × 100)');
```

`studentPercent` se zaokrouhluje k nejbližšímu celému číslu: pro 7 bodů vyjde `18`, pro 29 bodů z maxima 60 vyjde `48`.

```js
// Spustí tvůj kód znovu s jinými daty a vrátí vybrané proměnné a výpisy.
const rerun = (changes, names = '') => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  const lines = [];
  const quietConsole = { log: (...parts) => lines.push(parts.map(String).join(' ')) };
  const values = new Function('console', `${src}\nreturn { ${names} };`)(quietConsole);
  return { ...values, lines };
};
const other = rerun([['const maxPoints = 40;', 'const maxPoints = 60;'], ["const pointsInput = '36';", "const pointsInput = '29';"]], 'studentPercent');
assert.equal(other.studentPercent, 48, 'Pro 29 bodů z 60 (48,3 %) má studentPercent vyjít 48 — dělíš proměnnou maxPoints a zaokrouhluješ k nejbližšímu celému číslu, ne nahoru?');
const few = rerun([["const pointsInput = '36';", "const pointsInput = '7';"]], 'studentPercent');
assert.equal(few.studentPercent, 18, 'Pro 7 bodů ze 40 (17,5 %) má studentPercent vyjít 18 — zaokrouhluješ k nejbližšímu celému číslu, ne dolů?');
```

V konzoli je řádek `Úspěšnost: 90 %`.

```js
assert.ok(logs.some((line) => line.text === 'Úspěšnost: 90 %'), 'V konzoli má být přesně řádek Úspěšnost: 90 %');
```

## --tip--

Zaokrouhlení najdeš v lekci [Proměnné a typy](see:js-zaklady/promenne-a-typy#zaokrouhleni-math-round-math-ceil-math-floor).

## --tip--

Podíl bodů a maxima vynásob stem. Ze tří funkcí objektu `Math` vyber tu, která zaokrouhluje k nejbližšímu číslu, ne vždy nahoru nebo dolů.

## --tip--

Rozepsané na podcíle: `// 1. vyděl body maximem` `// 2. vynásob stem` `// 3. zaokrouhli k nejbližšímu celému číslu` `// 4. vypiš s popiskem`

# --solution--

## --file-- script.js

```js
// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent > 90 && attendancePercent > 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = Math.round((studentPoints / maxPoints) * 100);
console.log(`Úspěšnost: ${studentPercent} %`);
```
