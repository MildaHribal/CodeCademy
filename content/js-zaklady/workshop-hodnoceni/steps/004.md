# --description--

Studentovi aplikace nepíše `true`, ale větu.

**Úkol:** Pod výpis `Splněno` napiš `if` s větví `else`. Když `hasPassed` platí, vypiš `Písemka je splněná.`, jinak `Písemka není splněná, domluv si opravný termín.`

Na jiných datech:

```js
if (isAdult) {
  console.log('Vstupenka: plná cena');
} else {
  console.log('Vstupenka: dětská');
}
```

Do závorky patří rovnou `hasPassed`. Porovnávat ho s `true` nemusíš, `if` se na pravdivost ptá sám.

# --hints--

Pro Terezu se vypíše `Písemka je splněná.` a druhá zpráva ne.

```js
const texts = logs.map((line) => line.text);
assert.ok(texts.includes('Písemka je splněná.'), 'Pro 90 % má být v konzoli Písemka je splněná.');
assert.ok(!texts.includes('Písemka není splněná, domluv si opravný termín.'), 'Pro 90 % se nemá vypsat zpráva o nesplněné písemce — provede se jen jedna větev');
```

Pro 10 bodů se vypíše `Písemka není splněná, domluv si opravný termín.` a první zpráva ne.

```js
// Spustí tvůj kód znovu s jinými daty a vrátí vybrané proměnné a výpisy.
const rerun = (changes, names = '') => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  const lines = [];
  const quietConsole = { log: (...parts) => lines.push(parts.map(String).join(' ')) };
  const values = new Function('console', `${src}\nreturn { ${names} };`)(quietConsole);
  return { ...values, lines };
};
const low = rerun([["const pointsInput = '36';", "const pointsInput = '10';"]]);
assert.ok(low.lines.includes('Písemka není splněná, domluv si opravný termín.'), 'Pro 10 bodů (25 %) má být v konzoli Písemka není splněná, domluv si opravný termín.');
assert.ok(!low.lines.includes('Písemka je splněná.'), 'Pro 10 bodů se nemá vypsat Písemka je splněná.');
```

# --help--

## --tip--

Jde o rozhodnutí mezi dvěma větvemi — viz [Rozhodování: if, else if, else](see:js-zaklady/porovnani-a-logika#rozhodovani-if-else-if-else).

## --tip--

Podmínka jde do kulatých závorek za `if`, každá zpráva do vlastních složených závorek. Texty zpráv opiš přesně i s tečkou.

## --tip--

Rozepsané na podcíle: `// 1. podmínka: platí hasPassed?` `// 2. větev pro ano: zpráva o splněné písemce` `// 3. větev else: zpráva o nesplněné písemce`

## --file-- script.js

```js
// Písemka z fyziky, třída 9.A. Maximum je 40 bodů.
const maxPoints = 40;

// Výsledek Terezy z formuláře. Formulář posílá body vždycky jako text.
const studentName = 'Tereza Malá';
const pointsInput = '36';
const attendance = 82; // docházka za pololetí v procentech

// ---- Od kolegy: funkce pro webový přehled třídy ----

// Návrh na pochvalu: aspoň 90 % v písemce a zároveň aspoň 90 % docházky.
function hasPraise(percent, attendancePercent) {
  return percent > 90 && attendancePercent > 90;
}

// Barva štítku se známkou v přehledu (barva pro CSS).
function gradeColor(grade) {
  let color;
  switch (grade) {
    case 1:
      color = 'green';
    case 2:
      color = 'yellowgreen';
      break;
    case 3:
      color = 'gold';
      break;
    case 4:
      color = 'orange';
      break;
    default:
      color = 'red';
  }
  return color;
}

// ---- Tvoje funkce ----

// ---- Výpis pro Terezu ----

const studentPoints = Number(pointsInput);
console.log(`${studentName}: ${studentPoints}/${maxPoints} bodů`);

const studentPercent = Math.round((studentPoints / maxPoints) * 100);
console.log(`Úspěšnost: ${studentPercent} %`);

const hasPassed = studentPercent >= 50;
console.log('Splněno:', hasPassed);

if (hasPassed) {
  console.log('Písemka je splněná.');
} else {
  console.log('Písemka není splněná, domluv si opravný termín.');
}
```
