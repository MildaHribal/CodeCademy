# --description--

Po každé písemce dělá školní aplikace, třeba Bakaláři nebo Edookit, totéž: z bodů spočítá procenta, přidělí známku, připíše slovní hodnocení a upozorní, když je něco špatně. V tomhle workshopu takový modul postavíš pro písemku z fyziky ve třídě 9.A. Výsledky se vypisují do konzole a po každém kroku v ní přibude řádek nebo nová funkce, kterou si hned vyzkoušíš.

V souboru `script.js` jsou nahoře data: maximum bodů a výsledek Terezy Malé tak, jak ho poslal formulář. Pod nimi jsou dvě funkce od kolegy, který dělá webový přehled třídy. Zatím je nech být, dostaneš se k nim. Data neměň: testy je během kontroly přepínají na jiné hodnoty, aby ověřily, že program počítá, a ne jen opisuje výsledek.

Začneš tím, co už umíš, a to bez návodu.

**Úkol:** Pod komentář `// ---- Výpis pro Terezu ----` založ konstantu `studentPoints` s body z `pointsInput` převedenými na číslo. Pak vypiš řádek `Tereza Malá: 36/40 bodů` — jméno, body i maximum vezmi z proměnných.

# --hints--

`studentPoints` je číslo `36`.

```js
assert.equal(typeof studentPoints, 'number', `studentPoints má být číslo, teď je to ${typeof studentPoints} — převádíš text z formuláře?`);
assert.equal(studentPoints, 36, "studentPoints má být 36 (z pointsInput '36')");
```

`studentPoints` se počítá z `pointsInput`: pro `'12'` vyjde `12`.

```js
// Spustí tvůj kód znovu s jinými daty a vrátí vybrané proměnné a výpisy.
const rerun = (changes, names = '') => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  const lines = [];
  const quietConsole = { log: (...parts) => lines.push(parts.map(String).join(' ')) };
  const values = new Function('console', `${src}\nreturn { ${names} };`)(quietConsole);
  return { ...values, lines };
};
const other = rerun([["const pointsInput = '36';", "const pointsInput = '12';"]], 'studentPoints');
assert.equal(other.studentPoints, 12, "Pro pointsInput '12' má studentPoints vyjít 12");
```
