# --description--

V předchozím kroku jsi viděl past s operátorem `+` a řetězcem. Teď to použij ve své kalkulačce.

Představ si, že vstup přijde z formuláře jako text. Přidej funkci `parseBill`, která převede text na číslo. Pokud text nejde převést (není platné číslo), funkce vrátí `0`.

Hodí se `Number()` pro převod a `Number.isNaN()` pro kontrolu, jestli výsledek je `NaN`.

# --hints--

`parseBill('486')` vrátí číslo `486`.

```js
assert.equal(parseBill('486'), 486, "parseBill('486') má vrátit 486");
```

`parseBill('abc')` vrátí `0`.

```js
assert.equal(parseBill('abc'), 0, "parseBill('abc') má vrátit 0 — text nejde převést na číslo");
```

`parseBill('')` vrátí `0`.

```js
assert.equal(parseBill(''), 0, "parseBill('') má vrátit 0 — prázdný řetězec");
```

# --help--

## --tip--

`Number('abc')` vrátí `NaN`. Funkce `Number.isNaN()` vrátí `true`, když je hodnota `NaN`.

## --tip--

Uvnitř funkce: převeď vstup přes `Number()`, zkontroluj přes `Number.isNaN()`, a vrať buď číslo, nebo `0`.

## --tip--

Na jiných datech: `const age = Number('25'); // 25` vs. `const age = Number('xx'); // NaN`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

const bill = 486;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
const people = 4;
const perPerson = Math.ceil(total / people);

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
```
