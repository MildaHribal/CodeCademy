# --description--

Čtyři podíly po 306 Kč dají 1 224 Kč, účet je ale 1 227 Kč. Tři koruny zbývají doplatit.

**Úkol:** Založ konstantu `remainder` — kolik korun zbyde po rozdělení `total` mezi `people` na celé koruny. Vypiš ji, třeba `Zbývá doplatit: 3 Kč`.

Dostaneš se k tomu dvěma cestami: operátorem zbytku po dělení `%`, nebo odečtením všech podílů od celkové částky. Vyber si tu, která se ti čte líp.

# --hints--

`remainder` je `3`.

```js
assert.equal(remainder, 3, 'remainder má být 3 (1227 − 4 × 306)');
```

`remainder` se počítá pro jiný počet lidí: pro 5 lidí `2`, pro 3 lidi `0`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const five = rerun([["const peopleInput = '4';", "const peopleInput = '5';"]], 'remainder');
assert.equal(five.remainder, 2, 'Pro 5 lidí (5 × 245 = 1225) má remainder vyjít 2');
const three = rerun([["const peopleInput = '4';", "const peopleInput = '3';"]], 'remainder');
assert.equal(three.remainder, 0, 'Pro 3 lidi (3 × 409 = 1227) má remainder vyjít 0');
```

Zbytek je vypsaný v konzoli.

```js
assert.ok(logs.some((line) => /Zbývá|zbývá|zbytek|Zbytek|doplatit/.test(line.text) && line.text.includes('3')), 'V konzoli má být řádek se zbytkem (3), třeba Zbývá doplatit: 3 Kč');
```

# --help--

## --tip--

Zbytek po celočíselném dělení vrací operátor z tabulky v [Operátory a přednost](see:js-zaklady/promenne-a-typy#operatory-a-prednost).

## --tip--

Zbytek dělení `total` počtem lidí je právě to, co po rozdělení na celé koruny zůstane. Druhá cesta: od `total` odečti součin `share` a `people`.

## --tip--

Na jiných datech: `17 % 5` je `2` — pět se do sedmnácti vejde třikrát a dvě zbydou.

// Rozúčtování večeře v bistru Lávka. Ceny jsou v korunách.
