# --description--

Napiš funkci `splitBill`, která dostane celkovou částku a počet lidí a vrátí částku na osobu zaokrouhlenou nahoru na celé koruny.

# --hints--

`splitBill(558.9, 4)` vrátí `140`.

```js
assert.equal(splitBill(558.9, 4), 140, 'splitBill(558.9, 4) má vrátit 140');
```

`splitBill(100, 3)` vrátí `34`.

```js
assert.equal(splitBill(100, 3), 34, 'splitBill(100, 3) má vrátit 34 (Math.ceil(33.33))');
```

`splitBill(200, 1)` vrátí `200`.

```js
assert.equal(splitBill(200, 1), 200, 'splitBill(200, 1) má vrátit 200');
```

# --help--

## --tip--

Dělení a zaokrouhlení nahoru — kombinace `/` a `Math.ceil`.

## --tip--

Na jiných datech: `function splitCost(total, parts) { return Math.ceil(total / parts); }`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

function calculateTip(billAmount, percent) {
  return billAmount * percent / 100;
}

function splitBill(totalAmount, numberOfPeople) {
  return Math.ceil(totalAmount / numberOfPeople);
}

const bill = 486;
const tipPercent = 15;
const people = 4;

const tip = calculateTip(bill, tipPercent);
const total = bill + tip;
const perPerson = splitBill(total, people);

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
```
