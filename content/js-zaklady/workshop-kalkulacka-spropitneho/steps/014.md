# --description--

Hosté často nechtějí řešit drobné. Aplikace proto nabídne druhou variantu: každý zaplatí svůj díl **zaokrouhlený nahoru na desetikoruny** a co se vybere navíc, dostane obsluha.

Zaokrouhlení na desítky je nový vzor: číslo vydělíš deseti, zaokrouhlíš a výsledek zase vynásobíš deseti. Tentokrát řádky jen skládáš; v dalším kroku stejný vzor napíšeš sám.

**Úkol:** Seřaď řádky tak, aby program spočítal přesný díl na osobu, zaokrouhlil ho nahoru na desetikoruny (`shareToTens`), spočítal, kolik se vybere (`collected`), kolik dostane obsluha navíc (`extraForStaff`), a výsledek vypsal. Do mezery doplň číslo, kterým se na konci násobí. Dva řádky jsou navíc — patří k typickým chybám.

# --hints--

`shareToTens` je díl zaokrouhlený nahoru na desetikoruny (`310`), i u dílu, který by `Math.round` zaokrouhlil dolů.

```js
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
assert.equal(shareToTens, 310, 'shareToTens má být 310 (306.75 nahoru na desítky)');
```

`extraForStaff` je, kolik se vybere navíc oproti účtu: `13` Kč (pro 3 lidi `3` Kč).


# --help--

## --tip--

Zaokrouhlení na desítky je v lekci [Zaokrouhlení](see:js-zaklady/promenne-a-typy#zaokrouhleni-math-round-math-ceil-math-floor).

## --tip--

Každý řádek smí použít jen proměnné z řádků nad ním. Obsluha dostane rozdíl mezi tím, co se vybere, a účtem — ne naopak.

# --parsons--

```js
const exactShare = total / people;
const shareToTens = Math.ceil(exactShare / 10) * __1__;
const collected = shareToTens * people;
const extraForStaff = collected - total;
console.log(`Bez drobných: každý ${shareToTens} Kč, obsluze navíc ${extraForStaff} Kč`);
```

## --distractors--

```js
const shareToTens = Math.round(exactShare / 10) * 10;
const extraForStaff = total - collected;
```

```js
const mainPrice = 239;
const drinkPrice = 55;
const soups = 2;
const mains = 3;
const drinks = 4;

// Co hosté vyplnili v aplikaci. Formulář posílá vždycky text.
const tipPercentInput = '10';
const peopleInput = '4';

// Ceník a údaje z rezervace

const years = 3;

console.log('Položek na stole:', itemCount);

console.log('Mezisoučet:', subtotal, 'Kč');

const tipPercent = Number(tipPercentInput);
console.log('Spropitné:', tipPercent, '%');

const tip = subtotal * tipPercent / 100;
console.log('Spropitné:', tip, 'Kč');

const total = Math.ceil(subtotal + tip);
console.log(`Celkem: ${total} Kč`);

const people = Number(peopleInput);
console.log(`Platí lidí: ${people}`);

const share = Math.floor(total / people);
console.log(`Každý zaplatí: ${share} Kč`);

console.log(`Zbývá doplatit: ${remainder} Kč`);

let cardPayment = share;
cardPayment += remainder;
console.log(`Kdo platí kartou, zaplatí: ${cardPayment} Kč`);

// Od kolegy: jídlo s sebou. Balné za krabičky přichází z pokladny jako text.
const packagingInput = '45';
const takeawayTotal = total + Number(packagingInput);
console.log(`S balným: ${takeawayTotal} Kč`);

const futurePrice = Math.round(total * (1 + yearlyIncreasePercent / 100) ** years);
console.log(`Stejná večeře za ${years} roky: ${futurePrice} Kč`);
```
