# --description--

Teď z účtu a procenta spočítáš kolik spropitného nechat.

Spropitné se počítá jako `účet * procento / 100`. Pro účet 486 Kč a 15 % to je `486 * 15 / 100` = `72.9`.

**Úkol:** Založ proměnnou `tip` a přiřaď do ní výpočet spropitného z `bill` a `tipPercent`. Vypiš `tip` do konzole.

```js
// Příklad na jiných datech:
const cena = 200;
const sleva = 10; // procent
const castkaSleva = cena * sleva / 100; // 20
```
