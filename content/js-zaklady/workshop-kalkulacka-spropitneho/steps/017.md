# --description--

Co se stane, když někdo zadá 0 lidí? Program dělí nulou a výsledek je `Infinity`. Uprav funkci `splitBill`, aby při nulovém nebo záporném počtu lidí vrátila celou částku místo dělení nulou.

# --hints--

`splitBill(500, 0)` vrátí `500` (ne Infinity).

```js
assert.equal(splitBill(500, 0), 500, 'splitBill(500, 0) má vrátit 500 — nedělí nulou');
```

`splitBill(500, -2)` vrátí `500`.

```js
assert.equal(splitBill(500, -2), 500, 'splitBill(500, -2) má vrátit 500 — záporný počet lidí');
```

`splitBill(500, 3)` pořád funguje správně.

```js
assert.equal(splitBill(500, 3), 167, 'splitBill(500, 3) má vrátit 167 (Math.ceil(166.67))');
```

# --help--

## --tip--

Na začátku funkce zkontroluj, jestli `numberOfPeople` je kladné. Pokud ne, vrať celou částku.

## --tip--

Na jiných datech: `if (delitel <= 0) { return celkova; }`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

function calculateTip(billAmount, percent) {
  return billAmount * percent / 100;
}

function splitBill(totalAmount, numberOfPeople) {
  if (numberOfPeople <= 0) {
    return totalAmount;
  }
  return Math.ceil(totalAmount / numberOfPeople);
}

function formatReceipt(bill, tip, total, people, perPerson) {
  return `=== Účtenka ===
Účet: ${bill} Kč
Spropitné: ${tip} Kč
Celkem: ${total} Kč
Počet lidí: ${people}
Na osobu: ${perPerson} Kč`;
}
```
