# --description--

Rezervační systém posílá délku návštěvy v minutách, v datech `visitMinutes` je `135`. Na účtence má být čitelně.

**Úkol:** Založ konstantu `visitLabel` s textem ve tvaru `2 h 15 min` — celé hodiny, mezera, `h`, mezera, zbylé minuty, mezera, `min`. Vypiš ji s popiskem, třeba `Délka návštěvy: 2 h 15 min`. Pro 59 minut má vyjít `0 h 59 min`, pro 180 minut `3 h 0 min`.

Tentokrát bez návodu — všechno potřebné jsi v tomhle workshopu už napsal.

# --hints--

`visitLabel` je `2 h 15 min`.

```js
assert.equal(visitLabel, '2 h 15 min', "visitLabel má být '2 h 15 min' pro 135 minut");
```

`visitLabel` funguje pro jiné délky: `59` → `0 h 59 min`, `180` → `3 h 0 min`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const short = rerun([['const visitMinutes = 135;', 'const visitMinutes = 59;']], 'visitLabel');
assert.equal(short.visitLabel, '0 h 59 min', "Pro 59 minut má visitLabel být '0 h 59 min'");
const long = rerun([['const visitMinutes = 135;', 'const visitMinutes = 180;']], 'visitLabel');
assert.equal(long.visitLabel, '3 h 0 min', "Pro 180 minut má visitLabel být '3 h 0 min'");
```

Délka návštěvy je vypsaná v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('2 h 15 min')), 'V konzoli má být řádek s 2 h 15 min');
```

# --help--

## --tip--

Potřebuješ celé hodiny a zbylé minuty — stejné dvě operace jako při dělení účtu, viz [Zaokrouhlení](see:js-zaklady/promenne-a-typy#zaokrouhleni-math-round-math-ceil-math-floor) a [Operátory a přednost](see:js-zaklady/promenne-a-typy#operatory-a-prednost).

## --tip--

Celé hodiny jsou jako podíl na osobu, zbylé minuty jako drobné po rozdělení — jen místo počtu lidí dělíš šedesáti. Obojí vlož do šablonového řetězce.

## --tip--

Rozepsané na podcíle: `// 1. kolik celých hodin je v minutách` `// 2. kolik minut zbyde` `// 3. slož text s mezerami, h a min`
