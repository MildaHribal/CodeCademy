# --description--

Spropitné máš, teď spočítáš celkovou částku — účet i se spropitným.

**Úkol:** Založ proměnnou `total` jako součet `bill` a `tip`. Změň `console.log` tak, aby vypsal text ve tvaru `Celkem: 558.9 Kč`. Použij šablonový řetězec (template literal) se zpětnými apostrofy a `${…}`.

```js
// Příklad šablonového řetězce:
const jmeno = 'Karel';
const vek = 23;
console.log(`Jméno: ${jmeno}, věk: ${vek}`);
// Vypíše: Jméno: Karel, věk: 23
```

# --hints--

`total` je součet účtu a spropitného.

```js
assert.equal(total, 558.9, 'total pro bill=486 a tip=72.9 má být 558.9');
```

Výpis obsahuje text `Celkem: 558.9 Kč`.

```js
assert.ok(logs.some(l => l.includes('Celkem: 558.9 Kč')), 'console.log má vypsat Celkem: 558.9 Kč');
```

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného
// Účet za večeři v restauraci (v Kč)

const bill = 486;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
console.log(`Celkem: ${total} Kč`);
```
