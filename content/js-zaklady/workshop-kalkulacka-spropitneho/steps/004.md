# --description--

Hosté vybrali v aplikaci spropitné 10 %. Formulář ale posílá **text**, proto je v `tipPercentInput` hodnota `'10'` v uvozovkách. S textem se počítá špatně — `+` by ho spojil s číslem místo sečtení.

**Úkol:** Založ konstantu `tipPercent` a ulož do ní hodnotu `tipPercentInput` převedenou na číslo funkcí `Number()`. Vypiš ji s popiskem, třeba `Spropitné: 10 %`.

Na jiných datech:

```js
const ageInput = '18';
const age = Number(ageInput);
```

# --hints--

`tipPercent` je číslo `10`, ne text.

```js
assert.equal(typeof tipPercent, 'number', `tipPercent má být číslo, teď je to ${typeof tipPercent} — převádíš přes Number()?`);
assert.equal(tipPercent, 10, 'tipPercent má být 10');
```

`tipPercent` se převádí z formuláře: pro vstup `'15'` vyjde `15`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {

    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const other = rerun([["const tipPercentInput = '10';", "const tipPercentInput = '15';"]], 'tipPercent');
assert.equal(other.tipPercent, 15, "Pro tipPercentInput = '15' má tipPercent vyjít 15 — převádíš tipPercentInput, nebo jsi napsal 10 napevno?");
```

Procento spropitného je vypsané v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('10')), 'V konzoli má být řádek s procentem spropitného (10)');
```
