# --description--

139.725 Kč v praxi nezaplatíš. Částku na osobu zaokrouhlíš nahoru na celé koruny, aby nikdo nedoplácal.

`Math.ceil` zaokrouhlí číslo **nahoru** na nejbližší celé číslo. `Math.ceil(139.725)` vrátí `140`.

```js
// Další příklady:
console.log(Math.ceil(3.2));   // 4
console.log(Math.ceil(7.0));   // 7
console.log(Math.ceil(-1.5));  // -1
```

**Úkol:** Změň výpočet `perPerson` tak, aby výsledek zaokrouhlil nahoru. Výpis by měl ukázat `Na osobu: 140 Kč`.

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného
// Účet za večeři v restauraci (v Kč)

const bill = 486;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
const people = 4;
const perPerson = Math.ceil(total / people);

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
```
