# --description--

Popisky zatím skládáš z víc hodnot oddělených čárkou. Hezčí a přehlednější je [[šablonový řetězec]]: text ve zpětných uvozovkách, do kterého vložíš hodnotu přes `${…}`.

**Úkol:** Založ konstantu `total` — mezisoučet plus spropitné. Pak ji vypiš šablonovým řetězcem přesně ve tvaru `Celkem: 1226.5 Kč`.

Na jiných datech:

```js
const deliveryTotal = orderPrice + deliveryFee;
console.log(`K úhradě: ${deliveryTotal} Kč`);
```

Zpětnou uvozovku napíšeš na české klávesnici přes pravý Alt a klávesu ý.

# --hints--

`total` je součet mezisoučtu a spropitného (`1226.5`).

```js
assert.equal(total, 1226.5, 'total má být 1226.5 (1115 + 111.5)');
```

V konzoli je řádek přesně `Celkem: 1226.5 Kč`.

```js
const sameLine = (a) => a.normalize('NFC').replace(/\u00a0/g, ' ').replace(/\s+/g, ' ').trim();
assert.ok(logs.some((line) => sameLine(line.text) === sameLine('Celkem: 1226.5 Kč')), 'V konzoli má být řádek přesně Celkem: 1226.5 Kč (dvojtečka, mezery, Kč)');
```

Výpis používá šablonový řetězec se `${total}`.

```js
const src = helpers.stripComments(files['script.js'], 'js');
assert.match(src, /`[^`]*\$\{\s*total\s*\}[^`]*`/, 'Vypiš total šablonovým řetězcem: zpětné uvozovky a ${total} uvnitř');
```

# --help--

## --tip--

Jde o [šablonový řetězec](see:js-zaklady/promenne-a-typy#sablonovy-retezec).

## --tip--

`total` je součet dvou proměnných. Ve výpisu napiš text `Celkem: ` a za něj `${total}` a ` Kč` — všechno uvnitř jedněch zpětných uvozovek.

## --tip--

Rozepsané na podcíle: `// 1. sečti mezisoučet a spropitné do konstanty` `// 2. otevři zpětné uvozovky` `// 3. pevný text piš rovnou, hodnotu vlož přes ${…}`

# --solution--

## --file-- script.js

```js
// Rozúčtování večeře v bistru Lávka. Ceny jsou v korunách.

// Objednávka stolu č. 7 z pokladny
const soupPrice = 89;
const mainPrice = 239;
const drinkPrice = 55;
const soups = 2;
const mains = 3;
const drinks = 4;

// Co hosté vyplnili v aplikaci. Formulář posílá vždycky text.
const tipPercentInput = '10';
const peopleInput = '4';

// Ceník a údaje z rezervace
const yearlyIncreasePercent = 6;
const years = 3;
const visitMinutes = 135;

console.log('Bistro Lávka, stůl 7');

const itemCount = soups + mains + drinks;
console.log('Položek na stole:', itemCount);

const subtotal = soupPrice * soups + mainPrice * mains + drinkPrice * drinks;
console.log('Mezisoučet:', subtotal, 'Kč');

const tipPercent = Number(tipPercentInput);
console.log('Spropitné:', tipPercent, '%');

const tip = subtotal * tipPercent / 100;
console.log('Spropitné:', tip, 'Kč');

const total = subtotal + tip;
console.log(`Celkem: ${total} Kč`);
```
