# --description--

Teď jsi viděl, jak `+` s řetězcem mění chování a jak `Number()` řeší převod. Vysvětli vlastními slovy, co je implicitní přetypování a proč je nebezpečné.

# --explain--

Proč operátor `+` s řetězcem a číslem nedá součet, ale spojení?

## --model--

JavaScript automaticky převádí typy, když operátor očekává jiný typ. U `+` to znamená, že pokud je jeden operand řetězec, druhý se převede na řetězec a oba se spojí. Proto `'120' + 30` dá `'12030'` místo `150`. Tomuhle se říká implicitní přetypování a je to past, protože program nespadne — prostě vrátí špatný výsledek.

## --checklist--

- `+` s řetězcem spojuje místo sčítání
- Výsledek je řetězec, ne číslo
- Program nespadne, chyba je tichá
- Řešení: explicitní převod přes `Number()` nebo unární `+`
