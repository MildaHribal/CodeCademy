# --description--

Ve formuláři hosté vyplnili, kolik lidí bude platit. I tahle hodnota přišla jako text, `peopleInput` je `'4'`.

**Úkol:** Založ konstantu `people` s počtem lidí jako **číslem** a vypiš ho s popiskem, třeba `Platí lidí: 4`.

Převést text na číslo umíš dvěma zápisy z lekce — funkcí z minulého převodu, nebo kratším plusem před hodnotou. Vyber si.

# --hints--

`people` je číslo `4`.

```js
assert.equal(typeof people, 'number', `people má být číslo, teď je to ${typeof people}`);
assert.equal(people, 4, 'people má být 4');
```

`people` se převádí z formuláře: pro vstup `'6'` vyjde `6`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const other = rerun([["const peopleInput = '4';", "const peopleInput = '6';"]], 'people');
assert.equal(other.people, 6, "Pro peopleInput = '6' má people vyjít 6 — převádíš peopleInput?");
```

Počet lidí je vypsaný v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('4')), 'V konzoli má být řádek s počtem lidí (4)');
```

# --help--

## --tip--

Jde o převod textu na číslo — viz [Text a číslo: operátor `+` a převod typů](see:js-zaklady/promenne-a-typy#text-a-cislo-operator-a-prevod-typu).

## --tip--

Převáděj proměnnou `peopleInput`. Obě varianty z lekce vrátí číslo; zkontroluj výpisem `typeof people`.

## --tip--

Na jiných datech: `const guests = +guestsInput;` nebo `const guests = Number(guestsInput);` — stejný výsledek.
