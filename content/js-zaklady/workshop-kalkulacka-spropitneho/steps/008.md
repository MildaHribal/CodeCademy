# --description--

Představ si, že chceš spočítat, kolik by stálo spropitné, kdyby se procento každý rok zdvojnásobilo — 15 %, 30 %, 60 %… To je mocnina dvou.

Operátor `**` umocní číslo: `2 ** 3` je `8` (dva na třetí).

**Úkol:** Založ proměnnou `doubledTip` — spropitné po třech zdvojnásobeních. Výpočet: `tipPercent * 2 ** 3`. Vypiš výsledek.

```js
// Příklad na jiných datech:
const zaklad = 5;
const mocnina = zaklad ** 2; // 25
```

# --hints--

`doubledTip` je `tipPercent * 2 ** 3`, tedy `120`.

```js
assert.equal(doubledTip, 120, 'doubledTip má být tipPercent * 2 ** 3 = 15 * 8 = 120');
```

# --help--

## --tip--

Operátor `**` má vyšší [prioritu](see:js-zaklady/prvni-program#prikazy-a-stredniky) než `*`, takže `15 * 2 ** 3` se počítá jako `15 * (2 ** 3)` = `15 * 8`.

## --tip--

`doubledTip` = `tipPercent * 2 ** 3`.

## --tip--

Na jiných datech: `const plocha = strana ** 2;`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného
// Účet za večeři v restauraci (v Kč)

const bill = 486;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
const people = 4;
const perPerson = Math.ceil(total / people);
const remainder = total % people;

const doubledTip = tipPercent * 2 ** 3;
console.log(`Zdvojnásobené procento (3×): ${doubledTip} %`);

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
console.log(`Zbytek: ${remainder} Kč`);
```
