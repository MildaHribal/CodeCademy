# --description--

Rozdělíš-li 558.9 Kč mezi 4 lidi a každý zaplatí 140 Kč, zaplatíte dohromady 560 Kč — o 1.1 Kč víc. To nevadí, ale je dobré vědět, kolik na zaokrouhlení „zbylo."

Operátor `%` (modulo) vrátí **zbytek po celočíselném dělení**: `7 % 3` je `1`, protože `7 = 2 × 3 + 1`.

**Úkol:** Založ proměnnou `remainder` — zbytek po dělení `total` počtem lidí. Přidej řádek `console.log`, který vypíše `Zbytek: 2.9 Kč`.

```js
// Příklad modula na jiných datech:
const bonbony = 10;
const deti = 3;
const zbytek = bonbony % deti; // 1 (každé dítě dostane 3, 1 zbyde)
```

# --help--

## --tip--

Operátor `%` funguje stejně jako u celých čísel — vrátí zbytek po dělení.

## --tip--

`remainder` = `total % people`.

## --tip--

Na jiných datech: `const zbytek = 100 % 7; // 2`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného
// Účet za večeři v restauraci (v Kč)

const bill = 486;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
const people = 4;
const perPerson = Math.ceil(total / people);
const remainder = total % people;

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
console.log(`Zbytek: ${remainder} Kč`);
```
