# --description--

Celý výpočet zatím máš v řadě proměnných. Teď ho zabalíš do funkce, aby šel použít s jakýmkoli účtem.

Napiš funkci `calculateTip`, která dostane účet a procento a vrátí výši spropitného.

# --hints--

`calculateTip(486, 15)` vrátí `72.9`.

```js
assert.equal(calculateTip(486, 15), 72.9, 'calculateTip(486, 15) má vrátit 72.9');
```

`calculateTip(200, 10)` vrátí `20`.

```js
assert.equal(calculateTip(200, 10), 20, 'calculateTip(200, 10) má vrátit 20');
```

`calculateTip(0, 15)` vrátí `0`.

```js
assert.equal(calculateTip(0, 15), 0, 'calculateTip(0, 15) má vrátit 0');
```

# --help--

## --tip--

Funkce přijme dva parametry a vrátí výsledek výpočtu `bill * percent / 100`.

## --tip--

Na jiných datech: `function calculateDiscount(price, percent) { return price * percent / 100; }`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

function calculateTip(billAmount, percent) {
  return billAmount * percent / 100;
}

const bill = 486;
const tipPercent = 15;

const tip = calculateTip(bill, tipPercent);
console.log(`Spropitné: ${tip} Kč`);
```
