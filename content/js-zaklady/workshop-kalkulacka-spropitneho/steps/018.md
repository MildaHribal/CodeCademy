# --description--

Kalkulačka je hotová. Umí spočítat spropitné, rozdělit účet, ošetřit špatný vstup a vypsat přehlednou účtenku. Všechny výpočty jsou v malých funkcích, které se dají použít znovu.

Příště tyhle dovednosti — proměnné, operátory, funkce, šablonové řetězce a převod typů — použiješ v podmínkách a cyklech.

## Udělej po svém

- Přidej výpočet pro různá procenta spropitného (10 %, 15 %, 20 %) a vypiš je vedle sebe.
- Přidej měnu: místo `Kč` ať funkce přijme název měny jako parametr (`'€'`, `'$'`).
- Přeměň kalkulačku na téma, které tě zajímá — třeba dělení nákladů na výlet nebo kalkulačku DPH.

# --hints--

Tento krok nemusíš měnit — stačí si přečíst shrnutí a vyzkoušet rozšíření.

```js
assert.ok(true, 'Přečti shrnutí a zkus jedno rozšíření');
```

// Kalkulačka spropitného

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

function calculateTip(billAmount, percent) {
  return billAmount * percent / 100;
}

function splitBill(totalAmount, numberOfPeople) {
  if (numberOfPeople <= 0) {
    return totalAmount;
  }
  return Math.ceil(totalAmount / numberOfPeople);
}

function formatReceipt(bill, tip, total, people, perPerson) {
  return `=== Účtenka ===
Účet: ${bill} Kč
Spropitné: ${tip} Kč
Celkem: ${total} Kč
Počet lidí: ${people}
Na osobu: ${perPerson} Kč`;
}

// --- Výpočet ---
const bill = parseBill('486');
const tipPercent = 15;
const people = 4;

const tip = calculateTip(bill, tipPercent);
const total = bill + tip;
const perPerson = splitBill(total, people);

console.log(formatReceipt(bill, tip, total, people, perPerson));
