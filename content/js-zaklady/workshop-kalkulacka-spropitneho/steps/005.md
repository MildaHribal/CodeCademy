# --description--

Spropitné je dané procento z mezisoučtu. Deset procent z 1 115 Kč je 1 115 krát 10 děleno 100.

**Úkol:** Založ konstantu `tip` se spropitným v korunách: `subtotal` krát `tipPercent` děleno `100`. Vypiš ji s popiskem, třeba `Spropitné: 111.5 Kč`.

Násobení a dělení jsou stejně silné, počítají se zleva doprava, takže závorky ani tady nepotřebuješ. Na jiných datech — sleva 20 % z ceny bot:

```js
const discount = shoesPrice * discountPercent / 100;
```

Desetinnou tečku ve výsledku zatím nech, zaokrouhlíš za dva kroky.

# --hints--

`tip` je `111.5`.

```js
assert.equal(tip, 111.5, 'tip má být 111.5 (10 % z 1115)');
```

`tip` se počítá z mezisoučtu a procenta: pro 15 % vyjde `167.25`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const other = rerun([["const tipPercentInput = '10';", "const tipPercentInput = '15';"]], 'tip');
assert.equal(other.tip, 167.25, "Pro spropitné '15' má tip vyjít 167.25 — počítáš ze subtotal a tipPercent?");
```

Spropitné je vypsané v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('111.5')), 'V konzoli má být řádek s spropitným v korunách (111.5)');
```

```js
// Rozúčtování večeře v bistru Lávka. Ceny jsou v korunách.

// Objednávka stolu č. 7 z pokladny
const soupPrice = 89;
const mainPrice = 239;
const drinkPrice = 55;
const soups = 2;
const mains = 3;
const drinks = 4;

// Co hosté vyplnili v aplikaci. Formulář posílá vždycky text.
const tipPercentInput = '10';
```
