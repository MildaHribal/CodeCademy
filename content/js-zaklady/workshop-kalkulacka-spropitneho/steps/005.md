# --description--

V restauraci jste čtyři. Teď celkovou částku rozdělíš rovným dílem.

**Úkol:** Založ proměnnou `people` s hodnotou `4`. Založ proměnnou `perPerson`, kde vydělíš `total` počtem lidí. Uprav výpis, aby vedle celkové částky ukázal i podíl na osobu:

```
Celkem: 558.9 Kč
Na osobu: 139.725 Kč
```

```js
// Příklad dělení na jiných datech:
const celkovaCena = 1200;
const pocetLidi = 3;
const castka = celkovaCena / pocetLidi; // 400
```

# --hints--

`people` má hodnotu `4`.

```js
assert.equal(people, 4, 'people má mít hodnotu 4');
```

`perPerson` je podíl celkové částky na jednu osobu.

```js
assert.equal(perPerson, 139.725, 'perPerson pro total=558.9 a people=4 má být 139.725');
```

Výpis obsahuje text `Na osobu: 139.725 Kč`.

```js
assert.ok(logs.some(l => l.includes('Na osobu: 139.725 Kč')), 'console.log má vypsat Na osobu: 139.725 Kč');
```

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného
// Účet za večeři v restauraci (v Kč)

const bill = 486;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
const people = 4;
const perPerson = total / people;

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
```
