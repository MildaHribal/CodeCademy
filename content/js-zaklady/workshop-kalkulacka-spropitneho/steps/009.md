# --description--

Restaurace účtuje bez DPH. Přidej k účtu 15% DPH a ulož výsledek.

Hodí se `+=` — operátor, který přičte hodnotu k proměnné: `x += 5` je to samé jako `x = x + 5`. Ale pozor: `const` proměnnou takhle změnit nejde, potřebuješ `let`.

**Úkol:** Změň `bill` na `let`. Pod něj přidej řádek, který k `bill` přičte 15% DPH pomocí `+=`. Celkový účet by měl být `558.9` (486 + 72.9 DPH).

# --hints--

`bill` po přičtení DPH má hodnotu `558.9`.

```js
assert.equal(bill, 558.9, 'bill po přičtení 15% DPH z 486 má být 558.9');
```

Kód používá `+=`.

```js
const src = helpers.stripComments(files['script.js']);
assert.ok(src.includes('+='), 'použij operátor += pro přičtení DPH k bill');
```

# --help--

## --tip--

Proměnnou deklarovanou přes `const` nejde přepisovat. Potřebuješ `let`, abys mohl/a měnit její hodnotu.

## --tip--

DPH je 15 % z `bill`: `bill * 15 / 100`. To přičti k `bill` pomocí `+=`.

## --tip--

Na jiných datech: `let skore = 80; skore += 10; // 90`

# --solution--

## --file-- script.js

```js
// Kalkulačka spropitného
// Účet za večeři v restauraci (v Kč)

let bill = 486;
bill += bill * 15 / 100;
const tipPercent = 15;

const tip = bill * tipPercent / 100;
const total = bill + tip;
const people = 4;
const perPerson = Math.ceil(total / people);
const remainder = total % people;

console.log(`Celkem: ${total} Kč`);
console.log(`Na osobu: ${perPerson} Kč`);
console.log(`Zbytek: ${remainder} Kč`);
```
