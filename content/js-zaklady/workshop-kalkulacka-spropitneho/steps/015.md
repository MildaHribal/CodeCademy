# --description--

Majitel chce budoucí cenu večeře z nového ceníku mít zaokrouhlenou tak, jak ceny v menu vypadají — **nahoru na desetikoruny**.

**Úkol:** Založ konstantu `futurePriceToTens` s hodnotou `futurePrice` zaokrouhlenou nahoru na desetikoruny a vypiš ji, třeba `Do nového ceníku: 1470 Kč`. Cena, která už na desítky končí, se nemění.

Vzor znáš z minulého kroku.

# --hints--

`futurePriceToTens` je `1470`.

```js
assert.equal(futurePriceToTens, 1470, 'futurePriceToTens má být 1470 (1461 nahoru na desítky)');
```

`futurePriceToTens` zaokrouhluje nahoru a cenu končící nulou nechá: za 5 let `1650`, bez zdražení při účtu 1 060 Kč zůstane `1060`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const fiveYears = rerun([['const years = 3;', 'const years = 5;']], 'futurePriceToTens');
assert.equal(fiveYears.futurePriceToTens, 1650, 'Za 5 let (1642 Kč) má futurePriceToTens vyjít 1650');
const round = rerun([["const tipPercentInput = '10';", "const tipPercentInput = '0';"], ['const drinks = 4;', 'const drinks = 3;'], ['const yearlyIncreasePercent = 6;', 'const yearlyIncreasePercent = 0;']], 'futurePriceToTens');
assert.equal(round.futurePriceToTens, 1060, 'Cena 1060 Kč už na desítky končí — futurePriceToTens má zůstat 1060, ne 1070');
```

Cena do ceníku je vypsaná v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('1470')), 'V konzoli má být řádek s cenou do ceníku (1470)');
```

# --help--

## --tip--

Stejný vzor jako v minulém kroku — viz [Zaokrouhlení](see:js-zaklady/promenne-a-typy#zaokrouhleni-math-round-math-ceil-math-floor).

## --tip--

Vyděl deseti, zaokrouhli funkcí, která jde vždycky nahoru, a vynásob deseti. U 1060 vyjde po dělení celé číslo, a to zaokrouhlení nezmění.

## --tip--

Podcíle na jiných datech — kapacita autobusů pro výlet: `// 1. vyděl počet žáků kapacitou autobusu` `// 2. zaokrouhli nahoru` `// 3. vynásob zpátky kapacitou, ať víš, kolik míst objednáváš`
