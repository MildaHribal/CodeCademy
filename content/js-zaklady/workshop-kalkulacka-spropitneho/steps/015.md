# --description--

Výpis teď vypadá jako hromada řádků. Napiš funkci `formatReceipt`, která dostane účet, spropitné, celkem, počet lidí a částku na osobu — a vrátí jeden přehledný řetězec se všemi údaji oddělenými novými řádky (`\n`).

Výstup pro `bill=486, tip=72.9, total=558.9, people=4, perPerson=140`:

```
=== Účtenka ===
Účet: 486 Kč
Spropitné (15 %): 72.9 Kč
Celkem: 558.9 Kč
Počet lidí: 4
Na osobu: 140 Kč
```

# --hints--

`formatReceipt` vrátí řetězec s účtem na prvním datovém řádku.

```js
const result = formatReceipt(486, 72.9, 558.9, 4, 140);
assert.ok(result.includes('Účet: 486 Kč'), "formatReceipt má obsahovat 'Účet: 486 Kč'");
```

Řetězec obsahuje spropitné.

```js
const result = formatReceipt(486, 72.9, 558.9, 4, 140);
assert.ok(result.includes('72.9 Kč'), "formatReceipt má obsahovat spropitné '72.9 Kč'");
```

Řetězec obsahuje částku na osobu.

```js
const result = formatReceipt(486, 72.9, 558.9, 4, 140);
assert.ok(result.includes('Na osobu: 140 Kč'), "formatReceipt má obsahovat 'Na osobu: 140 Kč'");
```

## --file-- script.js

```js
// Kalkulačka spropitného

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

function calculateTip(billAmount, percent) {
  return billAmount * percent / 100;
}

function splitBill(totalAmount, numberOfPeople) {
  return Math.ceil(totalAmount / numberOfPeople);
}

function formatReceipt(bill, tip, total, people, perPerson) {
  return `=== Účtenka ===
Účet: ${bill} Kč
Spropitné: ${tip} Kč
Celkem: ${total} Kč
Počet lidí: ${people}
Na osobu: ${perPerson} Kč`;
}

const bill = 486;
const tipPercent = 15;
const people = 4;

const tip = calculateTip(bill, tipPercent);
const total = bill + tip;
const perPerson = splitBill(total, people);

console.log(formatReceipt(bill, tip, total, people, perPerson));
```
