# --description--

Další krok bez návodu. Obsluha chce na účtence vidět, kolik položek stůl objednal.

**Úkol:** Založ konstantu `itemCount` s počtem všech objednaných položek — polévek, hlavních jídel a nápojů dohromady. Počty ber z proměnných `soups`, `mains` a `drinks`, čísla neopisuj. Pak počet vypiš do konzole s popiskem, třeba `Položek na stole: 9`.

# --hints--

`itemCount` je počet všech položek (`9`).

```js
assert.equal(itemCount, 9, 'itemCount má být 9 (2 polévky + 3 hlavní jídla + 4 nápoje)');
```

`itemCount` se počítá z proměnných: pro jiné počty jídel vyjde jinak.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const other = rerun([['const soups = 2;', 'const soups = 5;']], 'itemCount');
assert.equal(other.itemCount, 12, 'Pro 5 polévek, 3 hlavní jídla a 4 nápoje má itemCount vyjít 12 — sčítáš proměnné soups, mains a drinks, nebo opsaná čísla?');
```

Počet položek je vypsaný v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('9')), 'V konzoli má být řádek s počtem položek (9)');
```

# --help--

## --tip--

Jde o konstantu s výsledkem výpočtu — viz [`const` a `let`](see:js-zaklady/promenne-a-typy#const-a-let).

## --tip--

Na pravé straně `=` sečti tři proměnné s počty. Výpis s popiskem má dvě hodnoty oddělené čárkou.

## --tip--

Rozepsané na podcíle: `// 1. konstanta se součtem tří proměnných s počty` `// 2. výpis: popisek v uvozovkách, čárka, proměnná`
