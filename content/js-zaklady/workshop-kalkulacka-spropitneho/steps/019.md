# --description--

## Hlášení

Kolega na konec souboru přidal věrnostní program: za každých celých 100 Kč útraty dostane host jeden bod a za registraci v aplikaci 5 bodů navíc.

Host od stolu 7 se právě registroval. Za 1 227 Kč mu patří 12 bodů a 5 za registraci, tedy 17. Aplikace ale ukazuje `Věrnostní body: 12`. Žádná chyba v konzoli.

## Úkol

Oprav kolegův kód tak, aby se bonus za registraci k bodům opravdu přičetl. Změň co nejmenší kus kódu.

# --hints--

`loyaltyPoints` je `17`.

```js
assert.equal(loyaltyPoints, 17, 'loyaltyPoints má být 17 (12 za útratu + 5 za registraci)');
```

`loyaltyPoints` počítá s útratou: pro účet 1 428 Kč vyjde `19`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const other = rerun([['const mainPrice = 239;', 'const mainPrice = 300;']], 'loyaltyPoints');
assert.equal(other.loyaltyPoints, 19, 'Pro účet 1428 Kč má loyaltyPoints vyjít 19 (14 + 5)');
```

Zbytek účtenky funguje dál: DPH `131.46` a délka návštěvy `2 h 15 min`.

```js
assert.equal(vatAmount, 131.46, 'vatAmount má zůstat 131.46');
assert.equal(visitLabel, '2 h 15 min', "visitLabel má zůstat '2 h 15 min'");
```

# --help--

## --tip--

Chyba odpovídá pasti [Proměnná bez deklarace](see:js-zaklady/promenne-a-typy#promenna-bez-deklarace).

## --tip--

Porovnej písmeno po písmenu jméno proměnné, do které se bonus přičítá, se jménem, které se vypisuje.

## --tip--

Na jiných datech by oprava vypadala takhle: `totl = total + 10` přepsané na `total = total + 10`.

# --explain--

Vysvětli vlastními slovy, proč kolegův kód nespadl, i když přiřazoval do jména, které nikde nedeklaroval.

## --model--

V obyčejném skriptu, který neběží v přísném režimu, přiřazení do nedeklarovaného jména nevyhodí chybu, ale potichu založí novou globální proměnnou. Kvůli překlepu se bonus uložil do `loyaltyPoits` a `loyaltyPoints` zůstalo na 12. V přísném režimu nebo v modulech by to spadlo s `ReferenceError`. Proto každou proměnnou deklaruju a jména kontroluju, nejlépe s lintem v editoru.

## --checklist--

- Přiřazení do nedeklarovaného jména v obyčejném skriptu založí novou proměnnou.
- Hodnota se uložila do jiné proměnné, než která se vypisuje.
- V přísném režimu nebo v modulu by přiřazení spadlo s `ReferenceError`.
- Chybu odhalí kontrola jmen nebo lint v editoru.

```js
// Rozúčtování večeře v bistru Lávka. Ceny jsou v korunách.

// Objednávka stolu č. 7 z pokladny
const soupPrice = 89;
const mainPrice = 239;
const drinkPrice = 55;
const soups = 2;
const mains = 3;
const drinks = 4;

// Co hosté vyplnili v aplikaci. Formulář posílá vždycky text.
const tipPercentInput = '10';
const peopleInput = '4';

// Ceník a údaje z rezervace
const yearlyIncreasePercent = 6;
const years = 3;
const visitMinutes = 135;

console.log('Bistro Lávka, stůl 7');

const itemCount = soups + mains + drinks;
console.log('Položek na stole:', itemCount);

const subtotal = soupPrice * soups + mainPrice * mains + drinkPrice * drinks;
console.log('Mezisoučet:', subtotal, 'Kč');

const tipPercent = Number(tipPercentInput);
console.log('Spropitné:', tipPercent, '%');

const tip = subtotal * tipPercent / 100;
console.log('Spropitné:', tip, 'Kč');

const total = Math.ceil(subtotal + tip);
console.log(`Celkem: ${total} Kč`);

const people = Number(peopleInput);
console.log(`Platí lidí: ${people}`);

const share = Math.floor(total / people);
console.log(`Každý zaplatí: ${share} Kč`);

const remainder = total % people;
console.log(`Zbývá doplatit: ${remainder} Kč`);

let cardPayment = share;
cardPayment += remainder;
console.log(`Kdo platí kartou, zaplatí: ${cardPayment} Kč`);

// Od kolegy: jídlo s sebou. Balné za krabičky přichází z pokladny jako text.
const packagingInput = '45';
const takeawayTotal = total + Number(packagingInput);
console.log(`S balným: ${takeawayTotal} Kč`);

const futurePrice = Math.round(total * (1 + yearlyIncreasePercent / 100) ** years);
console.log(`Stejná večeře za ${years} roky: ${futurePrice} Kč`);

const exactShare = total / people;
const shareToTens = Math.ceil(exactShare / 10) * 10;
const collected = shareToTens * people;
const extraForStaff = collected - total;
console.log(`Bez drobných: každý ${shareToTens} Kč, obsluze navíc ${extraForStaff} Kč`);

const futurePriceToTens = Math.ceil(futurePrice / 10) * 10;
console.log(`Do nového ceníku: ${futurePriceToTens} Kč`);

const cashToHundred = Math.ceil(total / 100) * 100 - total;
console.log(`Do celé stovky chybí: ${cashToHundred} Kč`);

const visitLabel = `${Math.floor(visitMinutes / 60)} h ${visitMinutes % 60} min`;
console.log(`Délka návštěvy: ${visitLabel}`);

const vatAmount = Math.round((total - total / 1.12) * 100) / 100;
console.log(`Z toho DPH 12 %: ${vatAmount} Kč`);

--edit--
// Od kolegy: věrnostní body. Za každých celých 100 Kč jeden bod, za registraci 5 bodů navíc.
let loyaltyPoints = Math.floor(total / 100);
loyaltyPoits = loyaltyPoints + 5;
console.log(`Věrnostní body: ${loyaltyPoints}`);
--edit--
```
