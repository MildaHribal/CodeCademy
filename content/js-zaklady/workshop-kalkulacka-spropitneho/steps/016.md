# --description--

Host, který platí hotově, chce vědět, kolik má přidat, aby z celkové částky vznikla **celá stovka** — zbytek nechá jako dýško.

**Úkol:** Založ konstantu `cashToHundred` s počtem korun, které chybí od `total` do nejbližší vyšší celé stovky, a vypiš ji, třeba `Do celé stovky chybí: 73 Kč`. Když je `total` přesně na stovkách, chybí `0`.

Nástroj si vyber sám — rozumných cest je víc a všechny už znáš. Až bude hotovo, zkus si rozmyslet i druhou.

# --hints--

`cashToHundred` je `73` (od 1 227 do 1 300).

```js
assert.equal(cashToHundred, 73, 'cashToHundred má být 73 (1300 − 1227)');
```

`cashToHundred` funguje i pro jiné účty: pro 1 298 Kč `2`, pro 1 100 Kč přesně na stovkách `0`.

```js
const rerun = (changes, names) => {
  let src = files['script.js'];
  for (const [from, to] of changes) {
    assert.ok(src.includes(from), `Řádek ${from} nech v souboru beze změny — test ho přepíná na jiná data.`);
    src = src.replace(from, to);
  }
  return new Function(`${src}\nreturn { ${names} };`)();
};
const almost = rerun([["const tipPercentInput = '10';", "const tipPercentInput = '0';"], ['const mainPrice = 239;', 'const mainPrice = 300;']], 'cashToHundred');
assert.equal(almost.cashToHundred, 2, 'Pro účet 1298 Kč má cashToHundred vyjít 2');
const exact = rerun([["const tipPercentInput = '10';", "const tipPercentInput = '0';"], ['const mainPrice = 239;', 'const mainPrice = 234;']], 'cashToHundred');
assert.equal(exact.cashToHundred, 0, 'Pro účet přesně 1100 Kč má cashToHundred vyjít 0, ne 100');
```

Částka do celé stovky je vypsaná v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('73')), 'V konzoli má být řádek s částkou do celé stovky (73)');
```

# --help--

## --tip--

Potřebuješ zbytek po dělení nebo zaokrouhlení na stovky — porovnej [Operátory a přednost](see:js-zaklady/promenne-a-typy#operatory-a-prednost) a [Zaokrouhlení](see:js-zaklady/promenne-a-typy#zaokrouhleni-math-round-math-ceil-math-floor).

## --tip--

Dvě cesty: zaokrouhli `total` nahoru na stovky a odečti `total`, nebo z desetikorunového vzoru použij zbytek po dělení stem. U druhé cesty si ohlídej účet přesně na stovkách.

## --tip--

Rozepsané na podcíle pro jiná data — kolik minut zbývá do celé hodiny: `// 1. zjisti, kolik minut je za poslední celou hodinou` `// 2. odečti to od 60` `// 3. když je čas přesně na hodinách, ať vyjde 0`
