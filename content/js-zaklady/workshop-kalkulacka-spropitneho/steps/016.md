# --description--

Kalkulačka teď umí spočítat jeden účet. Přidej druhý účet — tentokrát za 1 250 Kč, spropitné 10 %, 3 lidi. Zavolej stejné funkce a vypiš druhou účtenku pod první.

# --hints--

Do konzole se vypíše účtenka s účtem 1250 Kč.

```js
assert.ok(logs.some(l => l.includes('1250 Kč')), 'druhý účet má být 1250 Kč');
```

Druhá účtenka má spropitné 125 Kč.

```js
assert.ok(logs.some(l => l.includes('125 Kč')), 'spropitné z 1250 při 10 % má být 125 Kč');
```

Druhá účtenka ukazuje počet lidí 3.

```js
assert.ok(logs.some(l => l.includes('3')), 'druhá účtenka má mít 3 lidi');
```

# --help--

## --tip--

Použij stejné funkce `calculateTip`, `splitBill` a `formatReceipt` s novými hodnotami.

## --tip--

Nový účet, nové procento, nový počet lidí — ale stejný postup.

function parseBill(text) {
  const num = Number(text);
  if (Number.isNaN(num)) {
    return 0;
  }
  return num;
}

function calculateTip(billAmount, percent) {
  return billAmount * percent / 100;
}

function splitBill(totalAmount, numberOfPeople) {
  return Math.ceil(totalAmount / numberOfPeople);
}

Účet: ${bill} Kč
