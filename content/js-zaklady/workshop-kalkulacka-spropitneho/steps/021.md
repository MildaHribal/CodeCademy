# --description--

Poslední krok. Majitel sleduje, kolik v průměru stojí jedna objednaná položka — podle toho ladí menu.

**Úkol:** Založ konstantu `averageItemPrice` s mezisoučtem vyděleným počtem položek, zaokrouhlenou na celé koruny k nejbližšímu číslu, a vypiš ji, třeba `Průměrná cena položky: 124 Kč`.

Tím je kalkulačka hotová. Za sebou máš:

- aritmetické operátory, přednost a závorky, `%` a `**`,
- převod textu z formuláře na číslo a past s `+`, který text spojí,
- zaokrouhlení nahoru, dolů, na desítky i na haléře,
- `const`, `let` a zkratku `+=`,
- šablonové řetězce i na víc řádků,
- opravu dvou kolegových chyb.

Přesně takové výpočty dělá každý e-shop v košíku, bankovní aplikace u splátek a aplikace na dělení účtů. Příště se naučíš program **rozhodovat** — třeba nabídnout dopravu zdarma jen nad určitou částku — a z výpočtů postavíš hodnocení studentů.

> [!REMEMBER]
> **Text z formuláře převeď na číslo hned, jak ho dostaneš, a zaokrouhlení vybírej podle toho, kdo nesmí přijít zkrátka.**

## Udělej po svém

- **Vzhled účtenky:** vypiš oddělovací čáry z pomlček a zarovnej částky pod sebe — pomůže ti víceřádkový šablonový řetězec.
- **Funkce navíc:** přidej slevu pro stálé hosty 5 % z mezisoučtu, která se odečte před spropitným.
- **Tvoje téma:** předělej kalkulačku na dělení nákladů za společný výlet — benzín, ubytování a jídlo mezi pět kamarádů.

# --hints--

```js
assert.equal(averageItemPrice, 124, 'averageItemPrice má být 124 (1115 / 9 ≈ 123.9)');
```

`averageItemPrice` počítá z objednávky: pro 10 nápojů vyjde `96`.

  return new Function(`${src}\nreturn { ${names} };`)();

Průměrná cena je vypsaná v konzoli.

```js
assert.ok(logs.some((line) => line.text.includes('124')), 'V konzoli má být řádek s průměrnou cenou položky (124)');
```

## --tip--

## --tip--

Mezisoučet i počet položek už máš v proměnných z prvních kroků. Vyděl je a výsledek zaokrouhli k nejbližšímu číslu.

## --tip--

Na jiných datech: průměrná délka skladby na albu je celková délka vydělená počtem skladeb, zaokrouhlená `Math.round`.

// Rozúčtování večeře v bistru Lávka. Ceny jsou v korunách.

// Objednávka stolu č. 7 z pokladny
const soupPrice = 89;
const mainPrice = 239;
const drinkPrice = 55;
const soups = 2;
const mains = 3;
const drinks = 4;

// Co hosté vyplnili v aplikaci. Formulář posílá vždycky text.
const tipPercentInput = '10';
const peopleInput = '4';

// Ceník a údaje z rezervace
const yearlyIncreasePercent = 6;
const years = 3;
const visitMinutes = 135;

console.log('Bistro Lávka, stůl 7');

const itemCount = soups + mains + drinks;
console.log('Položek na stole:', itemCount);

const subtotal = soupPrice * soups + mainPrice * mains + drinkPrice * drinks;
console.log('Mezisoučet:', subtotal, 'Kč');

const tipPercent = Number(tipPercentInput);
console.log('Spropitné:', tipPercent, '%');

const tip = subtotal * tipPercent / 100;
console.log('Spropitné:', tip, 'Kč');

const total = Math.ceil(subtotal + tip);
console.log(`Celkem: ${total} Kč`);

const people = Number(peopleInput);
console.log(`Platí lidí: ${people}`);

const share = Math.floor(total / people);
console.log(`Každý zaplatí: ${share} Kč`);

const remainder = total % people;
console.log(`Zbývá doplatit: ${remainder} Kč`);

let cardPayment = share;
cardPayment += remainder;
console.log(`Kdo platí kartou, zaplatí: ${cardPayment} Kč`);

// Od kolegy: jídlo s sebou. Balné za krabičky přichází z pokladny jako text.
const packagingInput = '45';
const takeawayTotal = total + Number(packagingInput);
console.log(`S balným: ${takeawayTotal} Kč`);

const futurePrice = Math.round(total * (1 + yearlyIncreasePercent / 100) ** years);
console.log(`Stejná večeře za ${years} roky: ${futurePrice} Kč`);

const exactShare = total / people;
const shareToTens = Math.ceil(exactShare / 10) * 10;
const collected = shareToTens * people;
const extraForStaff = collected - total;
console.log(`Bez drobných: každý ${shareToTens} Kč, obsluze navíc ${extraForStaff} Kč`);

const futurePriceToTens = Math.ceil(futurePrice / 10) * 10;
console.log(`Do nového ceníku: ${futurePriceToTens} Kč`);

const cashToHundred = Math.ceil(total / 100) * 100 - total;
console.log(`Do celé stovky chybí: ${cashToHundred} Kč`);

const visitLabel = `${Math.floor(visitMinutes / 60)} h ${visitMinutes % 60} min`;
console.log(`Délka návštěvy: ${visitLabel}`);

const vatAmount = Math.round((total - total / 1.12) * 100) / 100;
console.log(`Z toho DPH 12 %: ${vatAmount} Kč`);

// Od kolegy: věrnostní body. Za každých celých 100 Kč jeden bod, za registraci 5 bodů navíc.
let loyaltyPoints = Math.floor(total / 100);
loyaltyPoints = loyaltyPoints + 5;
console.log(`Věrnostní body: ${loyaltyPoints}`);

const smsText = `Bistro Lávka, stůl 7
Celkem ${total} Kč
Každý ${share} Kč, kartou ${cardPayment} Kč`;
console.log(smsText);
