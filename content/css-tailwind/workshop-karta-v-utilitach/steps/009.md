# --description--

Štítek „Poslední místa" je teď pod fotkou. Patří do jejího levého horního rohu, 16 px od obou okrajů. Z lekce o pozicování víš, že absolutně umístěný prvek se měří od nejbližšího předka, který má nastavené `position`.

**Úkol:** přesuň štítek `data-role="badge"` přes fotku, 16 px od jejího horního a levého okraje. Potřebuješ dvě utility pozicování (`relative`, `absolute`) na dvou různých prvcích a dvě utility pro odsazení (`top-*`, `left-*`).

# --hints--

Štítek je 16 px od horního okraje fotky.

```js
const image = document.querySelector('article img').getBoundingClientRect();
const badge = document.querySelector('[data-role="badge"]').getBoundingClientRect();
assert.ok(Math.abs(badge.top - image.top - 16) <= 0.5, `Štítek začíná ${Math.round(badge.top - image.top)} px pod horním okrajem fotky, čekám 16 px`);
```

Štítek je 16 px od levého okraje fotky.

```js
const image = document.querySelector('article img').getBoundingClientRect();
const badge = document.querySelector('[data-role="badge"]').getBoundingClientRect();
assert.ok(Math.abs(badge.left - image.left - 16) <= 0.5, `Štítek začíná ${Math.round(badge.left - image.left)} px od levého okraje fotky, čekám 16 px`);
```

Štítek je umístěný absolutně, takže pod fotkou po něm nezůstane prázdné místo.

```js
assert.equal(getComputedStyle(document.querySelector('[data-role="badge"]')).position, 'absolute', 'Štítek má mít position: absolute');
const image = document.querySelector('article img').getBoundingClientRect();
const wrapper = document.querySelector('article img').parentElement.getBoundingClientRect();
assert.ok(Math.abs(wrapper.height - image.height) <= 1, `Obal fotky je vysoký ${Math.round(wrapper.height)} px, fotka ${Math.round(image.height)} px — štítek nemá zabírat místo pod fotkou`);
```

# --help--

## --tip--

Od kterého prvku se měří absolutní pozice, vysvětluje [`absolute` a obsahující blok](see:css-pozicovani/position#absolute-a-obsahujici-blok).

## --tip--

`absolute` a odsazení patří na štítek. `relative` patří na prvek, od kterého se má štítek měřit, tedy na obal kolem fotky a štítku.

## --tip--

Ikona „oblíbené" v pravém dolním rohu náhledu by měla na obalu `relative` a na sobě `absolute right-2 bottom-2`.

# --explain--

Vysvětli, proč štítek s `absolute top-4 left-4` bez `relative` na obalu fotky neskončí v rohu fotky.

## --model--
Absolutně umístěný prvek se měří od nejbližšího předka, který má nastavené `position` jiné než `static`. Když ho obal nemá, hledá se dál nahoru, až k počátečnímu obsahujícímu bloku stránky, a štítek skončí v rohu okna. `relative` na obalu z něj udělá obsahující blok, aniž by se obal posunul.

## --checklist--
- Absolutní prvek se měří od nejbližšího předka s `position` jiným než `static`.
- Bez takového předka se měří od začátku stránky.
- `relative` udělá z obalu obsahující blok a obal zůstane na místě.
