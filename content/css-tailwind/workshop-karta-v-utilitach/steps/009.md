# --description--
Tlačítko tvoří úplný závěr a je to nejdůležitější místo celé karty, protože tady se dělá nákup. Odstraníš starou třídu a poskládáš vlastní hezké tlačítko. Hodí se k tomu barvy, padding pro vodorovnou a svislou osu (X a Y) a zakulacení.

Složením utilit jako `bg-gray-800 text-white px-4 py-2 rounded font-medium` si designeři vytvářejí úplně libovolná tlačítka, aniž by k tomu potřebovali velký CSS soubor.

**Úkol:** Vyměň `btn` na tlačítku za sadu Tailwind tříd. Chceme modrofialové pozadí `bg-indigo-600` s bílým textem. Vodorovný padding na ose X bude 6 (tj. `px-6`), svislý na ose Y bude 2 (`py-2`). Nakonec tlačítko zakulať do tvaru `rounded-lg` a text udělej polotučný (`font-semibold`).

# --hints--

Splněno.

```js
const btn = document.querySelector('button');
const styles = getComputedStyle(btn);

assert.ok(styles.backgroundColor.includes('oklch') || styles.backgroundColor.includes('rgb'), 'Pozadi tlacitka je modre.');;
assert.ok(styles.color.includes('oklch') || styles.color.includes('rgb'), 'Text je bily.');;
assert.ok(parseInt(styles.paddingLeft) >= 24, 'Tlačítko má levý a pravý padding aspoň 24px (px-6).');
assert.ok(parseInt(styles.paddingTop) >= 8, 'Tlačítko má svislý padding aspoň 8px (py-2).');
assert.ok(parseInt(styles.borderRadius) >= 8, 'Tlačítko má zaoblení rohů (rounded-lg).');
assert.equal(styles.fontWeight, '600', 'Text v tlačítku je polotučný (font-semibold).');
```

# --help--

## --tip--

Tlačítko má barvy a polotučný text.

Barvu pozadí určí `bg-indigo-600`, barvu textu `text-white` a tloušťku `font-semibold`.
Padding je rozdělený na osu X a osu Y.

## --tip--

Místo psaní odsazení zleva a zprava zvlášť se hodí `px-6`. Osa Y (nahoře a dole) se nastaví pomocí `py-2`.
Tlačítko je hezky zakulacené.

## --tip--

Velikost zaoblení `lg` aplikuješ pomocí `rounded-lg`.
