# --description--
Z běžného odstavce pro datum uděláme vizuální nadpisek, takzvaný *kicker*. Takový prvek čtenáři pomůže rychle zjistit dobu konání, než si přečte velký název akce. Dělá se to obvykle barvou, tloušťkou, velkými písmeny a mírně roztaženým mezerováním mezi znaky (letter-spacing).

V Tailwindu se mezerování mezi písmeny ovládá třídami jako `tracking-wide` nebo `tracking-wider`.

```html
<!-- Příklad: Kicker nadpis před hlavním titulkem -->
<p class="text-xs font-bold text-slate-500 uppercase tracking-widest">Sekce</p>
```

**Úkol:** Nahraď třídu `date` u prvního odstavce utilitami tak, aby text měl barvu `indigo-600`, tloušťku `semibold` (polotučné), velikost `text-sm`, velká písmena (`uppercase`) a mezerování `tracking-wide`.

# --hints--

Splněno.

```js
const date = document.querySelector('p.text-sm');
const styles = getComputedStyle(date);

assert.equal(styles.textTransform, 'uppercase', 'Datum je psané velkými písmeny.');
assert.ok(parseFloat(styles.letterSpacing) > 0, 'Písmena mají zvětšené mezery (tracking-wide).');
assert.ok(styles.color.includes('oklch') || styles.color.includes('rgb'), 'Datum má modrofialovou barvu.');;
```

# --help--

## --tip--

Datum je psané velkými písmeny.

Třída určující `text-transform: uppercase` se jmenuje jednoduše `uppercase`.
Písmena mají zvětšené mezery a datum je menší.

## --tip--

Pro velikost textu použij `text-sm`, pro rozestupy písmen `tracking-wide` a pro tučnost `font-semibold`.
Datum má barvu indigo-600.

## --tip--

Barva písma se aplikuje předponou `text-`. Napiš `text-indigo-600`.
