# --description--

## Hlášení

Kolega chtěl, aby přes červený štítek „Poslední místa" trochu prosvítala fotka. Přidal štítku `opacity-70`. Fotka prosvítá, jenže klientka píše: „Text na štítku je vybledlý a na telefonu na slunci se nedá přečíst." Štítek má mít poloprůhledné jen červené pozadí, bílý text má zůstat plně bílý.

## Úkol

Oprav třídy štítku tak, aby byla průhledná jen barva pozadí (70 % krytí) a text zůstal neprůhledný. Poloha a vzhled štítku se jinak nemění.

# --hints--

Štítek jako celek není průhledný (`opacity` je 1), takže text je plně bílý.

```js
const badge = getComputedStyle(document.querySelector('[data-role="badge"]'));
assert.equal(badge.opacity, '1', `Štítek má opacity ${badge.opacity}, text tak bledne s ním`);
assert.equal(badge.color, 'rgb(255, 255, 255)', `Text štítku má barvu ${badge.color}, čekám plně bílou`);
```

Pozadí štítku je poloprůhledné, s krytím kolem 70 %.

```js
const background = getComputedStyle(document.querySelector('[data-role="badge"]')).backgroundColor;
const numbers = background.match(/-?[\d.]+/g).map(Number);
const alpha = /\//.test(background) ? numbers.at(-1) : (numbers.length === 4 ? numbers[3] : 1);
assert.ok(alpha >= 0.5 && alpha <= 0.9, `Pozadí štítku ${background} má krytí ${alpha}, čekám kolem 0.7`);
```

Štítek zůstal v levém horním rohu fotky.

```js
const image = document.querySelector('article img').getBoundingClientRect();
const badge = document.querySelector('[data-role="badge"]').getBoundingClientRect();
assert.ok(Math.abs(badge.top - image.top - 16) <= 0.5 && Math.abs(badge.left - image.left - 16) <= 0.5, 'Štítek má zůstat 16 px od horního a levého okraje fotky');
```

# --help--

## --tip--

Rozdíl mezi průhledností prvku a průhledností barvy je v pasti [Typické chyby a pasti](see:css-tailwind/utility-first#typicke-chyby-a-pasti).

## --tip--

Chyba je v atributu `class` štítku. Jedna utilita tam zprůhledňuje celý prvek, průhlednost přitom patří jen do utility barvy pozadí.

## --tip--

Poloprůhledná tmavá lišta pod titulkem videa by měla `bg-black/60`, ne `bg-black opacity-60`.
