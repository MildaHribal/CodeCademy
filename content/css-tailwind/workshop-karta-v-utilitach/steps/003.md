# --description--

Datum, název a místo jsou nalepené na sobě. Mezery mezi položkami pod sebou v Tailwindu nejčastěji dělá flex kontejner ve sloupci s mezerou `gap`, stejně jako vzor *stack* z gridu a flexboxu.

**Úkol:** blok s textem `data-role="body"` udělej flex kontejnerem ve sloupci s mezerou **8 px** mezi položkami. Hodí se utility `flex`, `flex-col` a `gap-2`.

Stejný vzor na jiném místě: seznam písniček s mezerou 12 px by měl `flex flex-col gap-3`.

# --hints--

Mezi datem a názvem koncertu je 8 px.

```js
const date = document.querySelector('[data-role="date"]').getBoundingClientRect();
const title = document.querySelector('[data-role="body"] h2').getBoundingClientRect();
assert.ok(Math.abs(title.top - date.bottom - 8) <= 0.5, `Mezi datem a názvem je ${Math.round(title.top - date.bottom)} px, čekám 8 px`);
```

Mezi názvem a místem konání je 8 px.

```js
const title = document.querySelector('[data-role="body"] h2').getBoundingClientRect();
const place = document.querySelector('[data-role="place"]').getBoundingClientRect();
assert.ok(Math.abs(place.top - title.bottom - 8) <= 0.5, `Mezi názvem a místem je ${Math.round(place.top - title.bottom)} px, čekám 8 px`);
```
