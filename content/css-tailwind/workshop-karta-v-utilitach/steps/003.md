# --description--
Texty jsou zatím nalepené na okrajích karty a na sobě. Aby se lépe četly, dáme obsahu jednotný prostor (padding) kolem dokola a mezi jednotlivými řádky nastavíme bezpečné mezery přes flexbox.

Tailwind má škálu rozměrů. `p-1` znamená odsazení `0.25rem` (4 px), `p-4` je `1rem` (16 px) a `p-6` je `1.5rem` (24 px). Stejná stupnice platí pro mezery.

```html
<!-- Příklad: Formulář s mezerami -->
<form class="p-4 flex flex-col gap-2">
  <input type="text">
  <button>Odeslat</button>
</form>
```

**Úkol:** Najdi obalový `<div>`, který ukrývá texty koncertu (datum, název, místo). Dej mu ze všech stran vnitřní odsazení (`padding`) o velikosti `6`. Proměň ho na svislý flexbox a nastav mezeru (`gap`) mezi prvky na `4`.

# --hints--

Splněno.

```js
const content = document.querySelectorAll('article > div')[1];
const styles = getComputedStyle(content);

assert.ok(parseInt(styles.padding) >= 24, 'Obsah má padding aspoň 24px (p-6).');
assert.equal(styles.display, 'flex', 'Obsah je flex kontejner.');
assert.equal(styles.flexDirection, 'column', 'Flex box směřuje seshora dolů.');
assert.ok(parseInt(styles.gap) >= 16, 'Mezi prvky je mezera aspoň 16px (gap-4).');
```

# --help--

## --tip--

Obal obsahu má padding p-6.

Utilitní třída pro padding ze všech stran začíná `p-`.

## --tip--

Přidej `p-6`.
Kontejner je svislý flexbox.

## --tip--

Musíš mu dát třídu `flex`, aby se stal flex kontejnerem.

Směr změníš třídou `flex-col`.
Kontejner má mezeru velikosti 4.

Třída pro mezeru začíná slovem `gap-`.

Napiš `gap-4`.
