# --description--

Když na tlačítko „Koupit" přejdeš klávesou Tab, preflight mu nechá jen nevýrazný obrys prohlížeče, který na tmavé záři skoro není vidět. Kdo nakupuje z klávesnice, musí vidět, kde je.

**Úkol:** když tlačítko dostane fokus z klávesnice, objeví se kolem něj souvislý obrys silný 2 px v barvě tlačítka (`sky-600`), odsazený 2 px od jeho okraje. Při kliknutí myší se obrys ukazovat nemá, proto použij variantu pro fokus z klávesnice, ne pro každý fokus. Vyzkoušej to v náhledu klávesou Tab.

# --hints--

Tlačítko má pravidlo s variantou pro fokus z klávesnice (`:focus-visible`).

```js
const button = document.querySelector('[data-role="buy"]');
const found = [];
const walk = (rules) => {
  for (const rule of rules) {
    if (rule.selectorText?.includes(':focus-visible')) {
      try {
        if (button.matches(rule.selectorText.replaceAll(':focus-visible', ''))) found.push(rule);
      } catch {}
    }
    if (rule.cssRules) walk(rule.cssRules);
  }
};
for (const sheet of document.styleSheets) walk(sheet.cssRules);
assert.ok(found.length > 0, 'Tlačítko nemá žádné pravidlo pro :focus-visible (varianta focus-visible:)');
```

S fokusem z klávesnice má tlačítko souvislý obrys 2 px odsazený 2 px.

```js
const button = document.querySelector('[data-role="buy"]');
button.focus();
await helpers.flush();
const style = getComputedStyle(button);
assert.equal(style.outlineStyle, 'solid', `S fokusem má tlačítko outlineStyle ${style.outlineStyle}, čekám solid`);
assert.equal(style.outlineWidth, '2px', `S fokusem má tlačítko outlineWidth ${style.outlineWidth}, čekám 2px`);
assert.equal(style.outlineOffset, '2px', `S fokusem má tlačítko outlineOffset ${style.outlineOffset}, čekám 2px`);
```

Obrys má barvu tlačítka (`sky-600`).

```js
const button = document.querySelector('[data-role="buy"]');
button.focus();
await helpers.flush();
assert.equal(getComputedStyle(button).outlineColor, getComputedStyle(button).backgroundColor, `S fokusem má obrys barvu ${getComputedStyle(button).outlineColor}, čekám barvu pozadí tlačítka`);
```

# --help--

## --tip--

Proč fokus musí být vidět a čím se liší `:focus` od `:focus-visible`, je v [Viditelný fokus](see:html-pristupnost/klavesnice-a-fokus#viditelny-fokus).

## --tip--

Obrys dělají utility `outline-*` (šířka, barva) a `outline-offset-*`. Každá z nich dostane prefix varianty pro fokus z klávesnice.

## --tip--

Pole formuláře s obrysem 4 px ve fialové, odsazeným 1 px, by mělo `focus-visible:outline-4 focus-visible:outline-offset-1 focus-visible:outline-violet-500`.
