# --description--
Obrázek je teď příliš vysoký. Správná karta koncertu by měla mít fotku jako širokoúhlý banner.

Místo nastavování pevné výšky v pixelech využijeme moderní vlastnost `aspect-ratio`. V Tailwindu je pro to zkratka `aspect-video`, která zajistí poměr stran 16:9. Aby se obrázek při změně poměru nedeformoval, musíme ho správně oříznout.

```html
<!-- Příklad: Čtvercový profilový obrázek -->
<img class="w-24 aspect-square object-cover" src="..." alt="Profil">
```

**Úkol:** Přidej prvku `<img>` utilitní třídy tak, aby zabral `100 %` šířky karty, měl poměr stran videa a jeho obsah se nedeformoval.

# --hints--

Splněno.

```js
const img = document.querySelector('img');
const styles = getComputedStyle(img);

assert.equal(styles.width, '384px', 'Obrázek zabírá 100% šířky karty.');
assert.equal(styles.aspectRatio, '16 / 9', 'Obrázek má poměr stran aspect-video (16/9).');
assert.equal(styles.objectFit, 'cover', 'Obrázek vyplňuje prostor přes object-cover.');
```

# --help--

## --tip--

Fotka zabírá celou šířku kontejneru (`w-full`).

Šířku na 100 % zařídí utilita z rodiny `w-`.

## --tip--

Přidej atribut `class` obrázku a do něj napiš `w-full`.
Fotka má poměr stran 16:9.

## --tip--

Třída pro filmový poměr stran se jmenuje `aspect-video`.
Fotka se roztáhne bez deformace.

Slouží k tomu vlastnost `object-fit: cover`.

V Tailwindu se jmenuje `object-cover`.
