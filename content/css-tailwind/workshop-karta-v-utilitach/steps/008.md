# --description--

Fotky z klubů mají každá jiný poměr stran a karty ve výpisu by pak měly různou výšku. Proto se obrázku v kartě pevně určí poměr stran a fotka se do něj ořízne, místo aby se zdeformovala.

Z CSS znáš obě vlastnosti: `aspect-ratio` určí poměr a `object-fit: cover` vyplní rámeček bez deformace. V Tailwindu mají utility se stejným začátkem (`aspect-*` a `object-*`).

**Úkol:** obrázek v kartě má poměr stran **16 : 9** a fotka ho vyplní bez zkreslení, přebytek se ořízne. Pro 16 : 9 má Tailwind pojmenovanou hodnotu podle videa.

# --hints--

Obrázek má poměr stran 16 : 9.

```js
const image = document.querySelector('article img').getBoundingClientRect();
assert.ok(Math.abs(image.height - image.width * 9 / 16) <= 1, `Obrázek je ${Math.round(image.width)} × ${Math.round(image.height)} px, čekám výšku ${Math.round(image.width * 9 / 16)} px (16 : 9)`);
```

Fotka rámeček vyplní bez deformace (`object-fit: cover`).

```js
const fit = getComputedStyle(document.querySelector('article img')).objectFit;
assert.equal(fit, 'cover', `Obrázek má objectFit ${fit}, čekám cover`);
```

# --help--

## --tip--

Poměr stran a `object-fit` vysvětluje lekce o přetékání: [Obrázky: hranice šířky, poměr stran a `object-fit`](see:css-box-model/preteceni#obrazky-hranice-sirky-pomer-stran-a-object-fit).

## --tip--

Obě utility patří na `<img>`. Poměr stran má utility `aspect-square` a `aspect-video`, způsob vyplnění `object-contain` a `object-cover`.

## --tip--

Čtvercový avatar, který se nedeformuje, by měl `aspect-square object-cover`.
