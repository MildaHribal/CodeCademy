# --description--

Na tmavé stránce se bílá karta s obyčejným šedým stínem ztrácí. Pod kartou koncertu bude místo toho **modrá záře**, jako by na ni svítil reflektor z fotky.

Stín v Tailwindu skládáš ze dvou utilit: jedna určí velikost a rozmazání (`shadow-sm` až `shadow-2xl`), druhá jeho barvu (`shadow-<barva>`). Průhlednost barvy se ve všech barevných utilitách píše **za lomítko** jako procento: `/50` je 50 %.

**Úkol:** kartě `<article>` dej největší stín ze stupnice a obarvi ho odstínem `sky-500` s průhledností 30 %. Hodí se kombinace utility velikosti stínu a utility barvy stínu s lomítkem.

# --hints--

Karta má velký stín s rozmazáním aspoň 50 px.

```js
const layers = getComputedStyle(document.querySelector('article')).boxShadow.split(/,(?![^(]*\))/);
const blurs = layers.map((layer) => {
  const lengths = layer.replace(/\w+\([^)]*\)/, '').trim().split(/\s+/).map(parseFloat);
  return lengths[2] || 0;
});
assert.ok(Math.max(...blurs) >= 50, `Největší rozmazání stínu karty je ${Math.max(...blurs)} px, čekám aspoň 50 px (shadow-2xl)`);
```

Stín je barevný (modrý), ne černý, a poloprůhledný.

```js
const layers = getComputedStyle(document.querySelector('article')).boxShadow.split(/,(?![^(]*\))/);
const big = layers.find((layer) => (layer.replace(/\w+\([^)]*\)/, '').trim().split(/\s+/).map(parseFloat)[2] || 0) >= 50);
assert.ok(big, 'Karta nemá velký stín, nejdřív nastav jeho velikost');
const color = big.match(/\w+\([^)]*\)/)[0];
const numbers = color.match(/-?[\d.]+/g).map(Number);
const alpha = /\//.test(color) ? numbers.at(-1) : (numbers.length === 4 ? numbers[3] : 1);
const colorful = color.startsWith('rgb')
  ? Math.max(...numbers.slice(0, 3)) - Math.min(...numbers.slice(0, 3)) > 40
  : color.startsWith('oklch') ? numbers[1] > 0.05 : Math.abs(numbers[1]) + Math.abs(numbers[2]) > 0.05;
assert.ok(colorful, `Barva stínu je ${color}, čekám modrou, ne černou nebo šedou`);
assert.ok(alpha > 0.15 && alpha < 0.45, `Průhlednost barvy stínu je ${alpha}, čekám 0.3`);
```

# --help--

## --tip--

Průhlednost barvy za lomítkem je v lekci u pasti s `opacity`: [Typické chyby a pasti](see:css-tailwind/utility-first#typicke-chyby-a-pasti).

## --tip--

Obě utility patří do `class` prvku `<article>`. Velikost stínu je poslední stupeň řady `shadow-sm`, `shadow-md`, `shadow-lg`, `shadow-xl`… a barva stínu má tvar `shadow-` + jméno barvy + lomítko + procento.

## --tip--

Tlačítko se zeleným stínem o síle 40 % by mělo `shadow-lg shadow-emerald-600/40`.

# --explain--

Vysvětli, proč se průhlednost barvy píše za lomítko (`shadow-sky-500/30`), místo aby paleta měla samostatnou světlejší barvu.

## --model--
Lomítko vezme existující barvu z palety a jen jí nastaví průhlednost, takže záře zůstane přesně v barvě značky. Nemusím do palety přidávat další token pro každou míru průhlednosti. A na rozdíl od `opacity` se průhlednost týká jen té jedné barvy, ne celého prvku s textem.

## --checklist--
- Lomítko nastaví průhlednost existující barvě z palety.
- Není potřeba nový token pro každou průhlednost.
- Průhlednost se týká jen té barvy, ne celého prvku jako u `opacity`.
