# --description--
Zbyly nám cena a tlačítko. Zatím jsou pod sebou. Cenu chceme zarovnat nalevo a tlačítko doprava.

Když chceme dát dva prvky vedle sebe a rozstrčit je na kraje, napíšeme v CSS `display: flex; justify-content: space-between; align-items: center;`. V Tailwindu to přeložíme slovo od slova na odpovídající utilitní třídy. Aby byla patička dál od textu s místem, hodí se jí navíc přidat horní margin.

```html
<!-- Příklad: Karta s oddělenou patičkou -->
<div class="mt-8 flex items-center justify-between">
  <span>Počet kusů: 2</span>
  <button>Pokračovat</button>
</div>
```

**Úkol:** Vyměň u patičkového `<div>` třídu `footer` za flexbox. Nastav mu zarovnání na střed (`items-center`), roztažení na kraje (`justify-between`) a přidej vrchní vnější odsazení (margin-top) `mt-4`.

# --hints--

Splněno.

```js
const footer = document.querySelectorAll('article div')[1];
const styles = getComputedStyle(footer);

assert.equal(styles.display, 'flex', 'Patička je flex kontejner.');
assert.equal(styles.alignItems, 'center', 'Patička zarovnává položky na střed (items-center).');
assert.equal(styles.justifyContent, 'space-between', 'Patička dává položky na kraje (justify-between).');
assert.ok(parseInt(styles.marginTop) >= 16, 'Patička je odsazená odshora (mt-4).');
```

# --help--

## --tip--

Patička je flexbox s položkami vedle sebe.

Místo `footer` napiš `flex`. Směr `row` je pro flexbox výchozí, takže stačí tohle.
Položky jsou vertikálně uprostřed a roztlačené do krajů.

## --tip--

Pro svislé zarovnání slouží `items-center`. Roztažení prvků doprava a doleva udělá `justify-between`.
Patička má horní margin `mt-4`.

## --tip--

Přidej do atributu class třídu `mt-4`.
