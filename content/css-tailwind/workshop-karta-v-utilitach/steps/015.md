# --description--

Názvy turné bývají dlouhé („Tichá dohoda a hosté: Podzimní tour s novým albem Mezi řádky a speciálním hostem"). Ve výpisu by takový název kartu roztáhl a tlačítka sousedních karet by se rozjela.

**Úkol:** název koncertu `<h2>` má nejvýš **dva řádky**. Text, který se nevejde, se ořízne a na konci druhého řádku se ukáže výpustka (…). Krátký název zůstane beze změny. Vyzkoušej to tak, že název v HTML dočasně prodloužíš.

# --hints--

Dlouhý název zabere právě dva řádky (60 px) a přebytek je oříznutý.

```js
const title = document.querySelector('[data-role="body"] h2');
title.textContent = 'Tichá dohoda a hosté: Podzimní tour s novým albem Mezi řádky a speciálním hostem z Brna';
await helpers.flush();
const height = title.getBoundingClientRect().height;
assert.ok(height >= 59 && height <= 61, `Dlouhý název je vysoký ${Math.round(height)} px, čekám dva řádky po 30 px`);
assert.equal(getComputedStyle(title).overflow, 'hidden', 'Přebytek textu má být oříznutý (overflow: hidden)');
```

Krátký název zůstane na jednom řádku.

```js
const title = document.querySelector('[data-role="body"] h2');
title.textContent = 'Tichá dohoda';
await helpers.flush();
const height = title.getBoundingClientRect().height;
assert.ok(height >= 29 && height <= 31, `Krátký název je vysoký ${Math.round(height)} px, čekám jeden řádek 30 px`);
```

# --help--

## --tip--

Ořez na jeden řádek s výpustkou znáš z [Jeden řádek se třemi tečkami](see:css-box-model/preteceni#jeden-radek-se-tremi-teckami). Na víc řádků je v CSS vlastnost `line-clamp`.

## --tip--

Utilita patří na `<h2>` a její jméno kopíruje vlastnost CSS, za pomlčkou je počet řádků.

## --tip--

Perex článku, který má mít nejvýš tři řádky, by dostal utilitu pro ořez na počet řádků s číslem 3.
