# --description--

Začneme s prázdným HTML a postupně vytvoříme kartu koncertu. Namísto vlastního CSS budeme psát utilitní třídy přímo do HTML prvku. Karta zatím nevypadá nijak úhledně. Dáme jí proto tvar.

```html
<!-- Příklad: Upozornění s pozadím, zaoblením a stínem -->
<div class="bg-yellow-50 rounded-lg shadow-md max-w-md w-full overflow-hidden">
  <p>Tohle je varování</p>
</div>
```

**Úkol:** Smaž třídu `card` na prvku `<article>` a pomocí Tailwind utilit mu nastav:
- bílé pozadí (`bg-white`)
- zakulacené rohy velikosti `2xl`
- velký stín (`xl`)
- oříznutí přetékajícího obsahu (aby nám později nevyčuhovala fotka)
- maximální šířku pro malé prvky (`sm`)
- a šířku na 100 % (`w-full`).

# --hints--

Karta má bílé pozadí a zakulacené rohy.

```js
const card = document.querySelector('article');
const styles = getComputedStyle(card);
assert.equal(styles.backgroundColor, 'rgb(255, 255, 255)', `Karta má bílé pozadí, actual: ${styles.backgroundColor}`);
assert.ok(parseInt(styles.borderRadius) >= 16, 'Karta má zakulacené rohy (aspoň 16 px).');
```

Karta ořezává přetékající obsah.

```js
const card = document.querySelector('article');
const styles = getComputedStyle(card);
assert.equal(styles.overflow, 'hidden', 'Karta ořezává obsah (overflow: hidden).');
```

Karta má maximální šířku 384px (`max-w-sm`) a jinak zabere celou šířku (`w-full`).

```js
const card = document.querySelector('article');
const styles = getComputedStyle(card);
assert.equal(styles.maxWidth, '384px', 'Karta má maximální šířku 384px (max-w-sm).');

```

# --help--


## --tip--

Barvu pozadí nastavíš pomocí utilit s předponou `bg-`. Zakulacení nastavíš předponou `rounded-`.

## --tip--

Zkus použít třídy `bg-white` a `rounded-2xl`. Pro ořezávání obsahu pak přidej `overflow-hidden`.

## --tip--

Maximální šířku určuje předpona `max-w-`. Pro plnou šířku je to `w-full`. Použij `max-w-sm` a `w-full`.
