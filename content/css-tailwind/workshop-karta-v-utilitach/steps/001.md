# --description--

Vstupenky na koncerty prodává každý klub a každý festival a karta akce s fotkou, datem, cenou a tlačítkem je na takových webech všude. V tomhle workshopu ji postavíš jen z utilit Tailwindu, bez jediného řádku vlastního CSS. HTML i texty jsou hotové, Tailwind je na stránce zapnutý. Atributy `data-role` nech, testy podle nich prvky hledají.

Začneš něčím, co znáš z flexboxu a gridu. Tenhle krok je bez návodu.

**Úkol:** karta `<article>` má být uprostřed okna, vodorovně i svisle. Prvek `<main>` už je vysoký jako okno (`min-h-screen`). Utility napiš do jeho atributu `class`.

# --hints--

Karta je vodorovně uprostřed okna.

```js
const card = document.querySelector('article').getBoundingClientRect();
const center = card.left + card.width / 2;
assert.ok(Math.abs(center - innerWidth / 2) <= 2, `Střed karty je na ${Math.round(center)} px, střed okna na ${Math.round(innerWidth / 2)} px`);
```

Karta je svisle uprostřed okna.

```js
const card = document.querySelector('article').getBoundingClientRect();
const center = card.top + card.height / 2;
assert.ok(Math.abs(center - innerHeight / 2) <= 2, `Svislý střed karty je na ${Math.round(center)} px, střed okna na ${Math.round(innerHeight / 2)} px`);
```

# --help--

## --tip--

Jde o vycentrování jedné položky v kontejneru, jen zapsané utilitami. Jak se jména utilit odvozují od vlastností, shrnuje [Čtení dlouhého `class` po skupinách](see:css-tailwind/utility-first#cteni-dlouheho-class-po-skupinach).

## --tip--

Kontejner je `<main>`. Potřebuje `display: grid` nebo `display: flex` a zarovnání položky na obou osách.

## --tip--

Utility mají jména podle vlastností: `display: flex` je `flex`, `align-items: center` je `items-center`, `justify-content: center` je `justify-center`. U gridu zkratka `place-items: center` je `place-items-center`.
