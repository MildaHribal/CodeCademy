# --description--

Koncert se vyprodává a my potřebujeme lidi trochu popostrčit. Chceme štítek „Poslední lístky" přilepit přes fotku do levého horního rohu.

V obyčejném CSS bychom kartě dali `position: relative` a štítku `position: absolute`, nastavili horní a levé odsazení a pak ho hezky nabarvili. Úplně stejně to uděláme teď. Třídu `badge` štítku odstraň. Obalový `<div>` okolo štítku jsme smazali za tebe.

```html
<!-- Příklad: Absolutně pozicovaný prvek uvnitř relativního kontejneru -->
<div class="relative ...">
  <img src="..." alt="...">
  <div class="absolute top-2 right-2 bg-black text-white px-2 py-1 rounded-md">
    Novinka
  </div>
</div>
```

**Úkol:** 
1. Přidej prvku `<article>` třídu `relative`.
2. Smaž z prvku `<span>` třídu `badge`.
3. Nastav `<span>` jako `absolute`.
4. Osaď ho odshora a zleva o hodnotu `4` (třídy `top-4`, `left-4`).
5. Přidej štítku vizuál: červené pozadí `bg-rose-600`, bílý text `text-white`, zakulacení jako pilulka `rounded-full`, tučné písmo `font-bold` a zmenši ho na `text-sm`. Nakonec mu dej padding: vodorovně `px-3` a svisle `py-1`.

# --hints--

Splněno.

```js
const article = document.querySelector('article');
const badge = document.querySelector('span');
const articleStyles = getComputedStyle(article);
const badgeStyles = getComputedStyle(badge);

assert.equal(articleStyles.position, 'relative', 'Karta slouží jako záchytný bod (relative).');
assert.equal(badgeStyles.position, 'absolute', 'Štítek má absolutní pozici.');
assert.ok(parseInt(badgeStyles.top) > 0, 'Štítek je odsazený od horního okraje.');
assert.ok(parseInt(badgeStyles.left) > 0, 'Štítek je odsazený zleva.');
assert.ok(badgeStyles.backgroundColor.includes('oklch') || badgeStyles.backgroundColor.includes('rgb'), 'Štítek má barevné pozadí.');
```

# --help--

## --tip--

Do atributu class u `<article>` zapiš třídu `relative`.

## --tip--

Třídy se jmenují přesně jako vlastnosti, takže `absolute`, `top-4` a `left-4`.
Barvy textu se zadávají jako `text-<barva>`, takže zkus `text-white`. Pro pozadí je to `bg-<barva>`, použij `bg-rose-600`.

## --tip--

Pilulkový tvar se dělá extrémně velkým zaoblením. K tomu je tu `rounded-full`.
