# --description--

Název koncertu je stejně malý jako zbytek textu, protože preflight nadpisům vzal velikost i tučnost. Typografii v Tailwindu skládáš ze tří druhů utilit:

- `text-*` nastaví velikost písma **a k ní výšku řádku**: `text-2xl` je 24 px s řádkem 32 px.
- `font-*` nastaví váhu: `font-bold` je 700.
- `leading-*` výšku řádku přepíše: `leading-tight` je 1.25násobek velikosti písma.

Velké nadpisy mají menší výšku řádku, aby dva řádky názvu držely pohromadě.

**Úkol:** nadpis `<h2>` v kartě dostane velikost `text-2xl`, váhu `font-bold` a výšku řádku `leading-tight`.

Na jiném prvku: podnadpis s 20 px, polotučný a s řádkem 1.375 by měl `text-xl font-semibold leading-snug`.

# --hints--

Název koncertu má velikost písma 24 px.

```js
const title = getComputedStyle(document.querySelector('[data-role="body"] h2'));
assert.equal(title.fontSize, '24px', `Název má fontSize ${title.fontSize}, čekám 24px`);
```

Název je tučný (váha aspoň 700).

```js
const title = getComputedStyle(document.querySelector('[data-role="body"] h2'));
assert.ok(Number(title.fontWeight) >= 700, `Název má fontWeight ${title.fontWeight}, čekám aspoň 700`);
```

Výška řádku názvu je 1.25násobek velikosti písma, tedy 30 px.

```js
const title = getComputedStyle(document.querySelector('[data-role="body"] h2'));
assert.equal(title.lineHeight, '30px', `Název má lineHeight ${title.lineHeight}, čekám 30px (24 × 1.25)`);
```
