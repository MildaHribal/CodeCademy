# --description--

Tlačítko „Koupit" na najetí myší nijak nereaguje, takže nepůsobí jako něco, na co se dá kliknout.

**Úkol:** když na tlačítko najedeš myší, jeho pozadí ztmavne na odstín `sky-700`. Změna barvy neproběhne skokem, ale plynule. Kurzor nad tlačítkem si ověř v náhledu.

# --hints--

Tlačítko má pravidlo pro najetí myší (`:hover`), které mu změní barvu pozadí na tmavší.

```js
const button = document.querySelector('[data-role="buy"]');
const hoverRules = [];
const walk = (rules) => {
  for (const rule of rules) {
    if (rule.selectorText?.includes(':hover')) {
      try {
        if (button.matches(rule.selectorText.replaceAll(':hover', ''))) hoverRules.push(rule);
      } catch {}
    }
    if (rule.cssRules) walk(rule.cssRules);
  }
};
for (const sheet of document.styleSheets) walk(sheet.cssRules);
const rule = hoverRules.find((item) => item.style.backgroundColor);
assert.ok(rule, 'Tlačítko nemá pravidlo pro :hover, které by měnilo barvu pozadí');
const probe = document.createElement('span');
probe.style.backgroundColor = rule.style.backgroundColor;
button.parentElement.append(probe);
const hoverColor = getComputedStyle(probe).backgroundColor;
probe.remove();
const reference = document.createElement('span');
reference.className = 'bg-sky-700';
button.parentElement.append(reference);
await helpers.flush();
assert.equal(hoverColor, getComputedStyle(reference).backgroundColor, `Při najetí myší má tlačítko pozadí ${hoverColor}, čekám odstín sky-700`);
```

Změna barvy pozadí proběhne plynule (přechod s nenulovou délkou).

```js
const style = getComputedStyle(document.querySelector('[data-role="buy"]'));
const properties = style.transitionProperty.split(',').map((item) => item.trim());
assert.ok(properties.includes('all') || properties.includes('background-color'), `Tlačítko má transitionProperty „${style.transitionProperty}", přechod se musí týkat barvy pozadí`);
assert.ok(style.transitionDuration.split(',').some((item) => parseFloat(item) > 0), `Tlačítko má transitionDuration ${style.transitionDuration}, čekám nenulovou délku`);
```

# --help--

## --tip--

Plynulá změna barvy je `transition` ze sekce o animacích: [Zápis `transition`](see:css-animace/transition-transform#zapis-transition-vlastnost-delka-krivka-zpozdeni). Stav při najetí myší je [[varianta]] z lekce [Čtení dlouhého `class` po skupinách](see:css-tailwind/utility-first#cteni-dlouheho-class-po-skupinach).

## --tip--

Potřebuješ na tlačítku dvě utility: jednu, která zapne přechod barev, a barvu pozadí s prefixem varianty pro najetí myší.

## --tip--

Odkaz v patičce, který na najetí myší zbělá a plynule, by měl `transition-colors hover:text-white`.
