# --description--
Pokračujeme v nastavování hierarchie velikostí a barev. Hlavní nadpis by měl být výrazný, kdežto doplňující text pod ním nesmí tolik křičet a bude proto zašedlý.

U nadpisů často používáme třídu `leading-tight`, která zajistí menší výšku řádku (line-height). Jinak by text rozlomený na dva řádky vypadal příliš roztaženě. 

```html
<!-- Příklad: Nadpis se zúženým řádkováním -->
<h1 class="text-4xl font-extrabold leading-tight text-black">Novinky ze světa</h1>
```

**Úkol:** 
1. Nahraď třídu `title` u elementu `<h2>`: dej mu velikost `text-2xl`, tučné písmo (`font-bold`), velmi tmavou šedou (`text-slate-900`) a utáhni mu výšku řádku (`leading-tight`).
2. Třídu `location` na odstavci pod ním přepiš jen na šedou barvu `text-slate-600`.

# --hints--

Splněno.

```js
const title = document.querySelector('h2');
const location = document.querySelectorAll('p')[1];
const titleStyles = getComputedStyle(title);
const locationStyles = getComputedStyle(location);

assert.ok(parseInt(titleStyles.fontSize) >= 24, 'Nadpis je velký (aspoň 24px - text-2xl).');
assert.equal(titleStyles.fontWeight, '700', 'Nadpis je tučný (font-bold).');
assert.ok(locationStyles.color.includes('oklch') || locationStyles.color.includes('rgb'), 'Místo konání má barvu.');;
```

# --help--


## --tip--

Nadpis má správnou velikost a tloušťku.

## --tip--

Na `<h2>` napiš třídy `text-2xl font-bold text-slate-900 leading-tight`.
Místo konání má barvu `slate-600`.

## --tip--

Na odstavec s místem přidej třídu `text-slate-600`.
