# --description--

Cena a tlačítko „Koupit" jsou pod sebou. Patří do jedné řady: cena vlevo zabere volné místo, tlačítko vpravo bude jen tak široké, jak potřebuje, a oba budou svisle na středu. V CSS bys to zapsal mřížkou se sloupci `1fr auto`.

Pro takové sloupce Tailwind pojmenovanou utilitu nemá (`grid-cols-2` dělá dva stejné sloupce). Použiješ proto libovolnou hodnotu v hranatých závorkách. Pozor na mezeru uvnitř hodnoty.

**Úkol:** patičku `data-role="footer"` udělej mřížkou se sloupci `1fr auto`, položky svisle vycentruj a mezi sloupci nech 16 px. Hodí se `grid`, `grid-cols-[…]`, `items-*` a `gap-*`.

# --hints--

Patička je mřížka se dvěma sloupci: první zabere volné místo, druhý je široký jako tlačítko.

```js
const footer = document.querySelector('[data-role="footer"]');
const style = getComputedStyle(footer);
assert.equal(style.display, 'grid', `Patička má display ${style.display}, čekám grid`);
const columns = style.gridTemplateColumns.split(' ').map(parseFloat);
assert.equal(columns.length, 2, `Patička má sloupce „${style.gridTemplateColumns}", čekám dva`);
const button = document.querySelector('[data-role="buy"]').getBoundingClientRect();
assert.ok(Math.abs(columns[1] - button.width) <= 1, `Druhý sloupec je široký ${Math.round(columns[1])} px, tlačítko ${Math.round(button.width)} px — druhý sloupec má mít šířku auto`);
assert.ok(columns[0] > columns[1], 'První sloupec (cena) má zabrat volné místo');
```

Cena a tlačítko jsou svisle na středu řady.

```js
const price = document.querySelector('[data-role="price"]').getBoundingClientRect();
const button = document.querySelector('[data-role="buy"]').getBoundingClientRect();
const priceCenter = price.top + price.height / 2;
const buttonCenter = button.top + button.height / 2;
assert.ok(Math.abs(priceCenter - buttonCenter) <= 1, `Střed ceny je na ${Math.round(priceCenter)} px, střed tlačítka na ${Math.round(buttonCenter)} px`);
assert.ok(price.height < 40 && button.height < 50, 'Cena ani tlačítko nemají být natažené na výšku řady');
```

Mezi cenou a tlačítkem je mezera sloupců 16 px.

```js
const gap = getComputedStyle(document.querySelector('[data-role="footer"]')).columnGap;
assert.equal(gap, '16px', `Patička má columnGap ${gap}, čekám 16px`);
```

# --help--

## --tip--

Zápis hodnoty, pro kterou utilita není, i to, jak do ní dostat mezeru, je v [Libovolné hodnoty: únikový ventil](see:css-tailwind/utility-first#libovolne-hodnoty-unikovy-ventil).

## --tip--

Všechny čtyři utility patří na `data-role="footer"`. Hodnota v hranatých závorkách je přesně to, co bys napsal za `grid-template-columns:`, jen s podtržítkem místo mezery.

## --tip--

Mřížka s pevným sloupcem 12rem vlevo a zbytkem vpravo by byla `grid grid-cols-[12rem_1fr]`.
