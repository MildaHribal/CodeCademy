# --description--
## Hlášení

Kolega chtěl štítku na fotce nastavit poloprůhledné pozadí, aby přes něj fotka trochu prosvítala. Přidal proto ke štítku třídu `opacity-50`. Jenže místo průhledného pozadí zprůhlednil úplně všechno, včetně textu. Nápis se teď špatně čte. 

## Úkol

Odstraň `opacity-50` tak, aby text zůstal plně neprůhledný, ale zajisti, aby barva samotného pozadí (`bg-rose-600`) měla padesátiprocentní krytí.

# --hints--

Splněno.

```js
const badge = document.querySelector('span');
const styles = getComputedStyle(badge);

assert.equal(badge.classList.contains("opacity-50"), false, "Trida opacity-50 je smazana");
// Pozadí by mělo obsahovat průhlednost
assert.ok(styles.backgroundColor.includes('0.5') || styles.backgroundColor.includes('50%'), 'Pozadí štítku je poloprůhledné (krytí 50 %).');
```

# --help--

## --tip--

`opacity-50` nastavuje průhlednost **celého prvku**, tedy i textu v něm. Průhlednost
jen jedné barvy se v Tailwindu zapisuje jinak — je to zápis se šikmým lomítkem.

## --tip--

Za jméno barevné utility se přidá lomítko a číslo v procentech. U pozadí a padesáti
procent krytí je to tedy jméno barvy, lomítko a `50`.

## --tip--

Stejně se dá ztlumit cokoli barevného: `text-white/70`, `border-black/10`,
`shadow-black/25`.
