# --description--
Máme krásnou komponentu vlastnosti. Teď stačí přidat další, ať mřížka není prázdná.

Tento krok máš jako **Udělej po svém**. Zkus přidat do divu mřížky další dva tagy `<article>` s podobnými třídami jako ten první.

- Změň barvy tlačítek
- Udělej tlačítko větší nebo menší.

# --hints--
Splněno.
```js
assert.ok(document.querySelectorAll('article').length > 1, 'Pridana dalsi karta.');
```

## --tip--
Udělej po svém
