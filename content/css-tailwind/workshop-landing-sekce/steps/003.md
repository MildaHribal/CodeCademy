# --description--
Velkým trendem je text vyplněný barevným přechodem. V Tailwindu na to existuje trik: nastavíš přechodové pozadí textu a samotný text zprůhledníš.

**Úkol:** Vyměň `<h1 class="title">` za `text-5xl font-extrabold text-transparent bg-clip-text bg-gradient-to-r from-blue-600 to-indigo-600`.

# --hints--
Splněno.
```js
const h1 = document.querySelector('h1'); assert.ok(h1.classList.contains('text-transparent'), 'Text je průhledný.'); assert.ok(h1.classList.contains('bg-clip-text'), 'Pozadí je oříznuté na text.');
```

# --help--
## --tip--
Napiš `text-5xl font-extrabold text-transparent bg-clip-text bg-gradient-to-r from-blue-600 to-indigo-600`.
