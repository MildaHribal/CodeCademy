# --description--

Postavíme moderní *landing page* (vstupní stránku). Bude mít horní uvítací sekci (hero) a mřížku s výhodami (features). Na rozdíl od karty se teď zaměříme i na responzivitu a tmavý režim (dark mode).

**Úkol:** Nastav hlavnímu tagu `<main>` barvu pozadí `bg-slate-50` a pro tmavý režim `dark:bg-slate-950`.

# --hints--

Nastaveno pozadí pro světlý i tmavý režim.
```js
const main = document.querySelector('main');
assert.ok(main.classList.contains('bg-slate-50'), 'Má světlé pozadí.');
assert.ok(main.classList.contains('dark:bg-slate-950'), 'Má tmavé pozadí přes dark:.');
```

# --help--

## --tip--

Přidej `bg-slate-50` pro světlý režim. Pro tmavý režim se používá předpona `dark:`, takže přidej `dark:bg-slate-950`.

# --seed--

## --file-- index.html

```html
<main class="">

</main>
```
