# --description--
Každá výhoda dostane svoji kartu. Na světlém pozadí bude bílá, na tmavém tmavě šedá.

**Úkol:** První `<article class="card">` změň na `bg-white dark:bg-slate-900 p-6 rounded-2xl shadow-lg border border-slate-100 dark:border-slate-800`.

# --hints--
Splněno.
```js
const c = document.querySelector('article'); assert.ok(c.classList.contains('dark:bg-slate-900'), 'Má dark mode barvu pozadí.'); assert.ok(c.classList.contains('shadow-lg'), 'Má stín.');
```

# --help--
## --tip--
Nakombinuj světlé barvy a ty s předponou `dark:`.

# --seed--
## --file-- index.html
```html
<main class="bg-slate-50 dark:bg-slate-950">
  <section class="min-h-screen flex flex-col justify-center items-center p-6">
    <h1 class="text-5xl font-extrabold text-transparent bg-clip-text bg-gradient-to-r from-blue-600 to-indigo-600 text-center">Tvoje nová aplikace</h1>
    <button class="bg-blue-600 text-white px-8 py-3 rounded-full hover:bg-blue-700 hover:scale-105 transition mt-8">Začít zdarma</button>
    <div class="grid gap-8 grid-cols-1 md:grid-cols-2 lg:grid-cols-3 w-full max-w-6xl mt-16">
      <article class="card">
        <h3 class="feat-title">Rychlost</h3>
        <p class="feat-text">Blesková odezva a načítání.</p>
      </article>
    </div>
  </section>
</main>
```
