# --description--
Hlavní sekce (hero) by měla zabrat celou výšku okna a vycentrovat obsah.

**Úkol:** `<section class="hero">` nahraď za Tailwind třídy tak, aby sekce měla minimální výšku obrazovky (`min-h-screen`), flexbox (`flex`), rozložení do sloupce (`flex-col`), obsah zarovnaný doprostřed svisle (`justify-center`) i vodorovně (`items-center`) a padding `p-6`.

# --hints--
Splněno.
```js
const sec = document.querySelector('section'); assert.ok(sec.classList.contains('min-h-screen') && sec.classList.contains('flex') && sec.classList.contains('flex-col'), 'Je to flex sloupec na celou obrazovku.'); assert.ok(sec.classList.contains('justify-center') && sec.classList.contains('items-center'), 'Zarovnáno na střed.');
```

# --help--
## --tip--
Použij třídy: `min-h-screen flex flex-col justify-center items-center p-6`.
