# --description--
Tmavá karta má černý text, takže nejde přečíst. Musíme ho přepnout.

**Úkol:** `<h3 class="feat-title">` změň na `text-xl font-bold text-slate-900 dark:text-white` a `<p class="feat-text">` na `text-slate-600 dark:text-slate-400`.

# --hints--
Splněno.
```js
const h3 = document.querySelector('h3'); assert.ok(h3.classList.contains('dark:text-white'), 'Nadpis je v tmavém režimu bílý.');
```

# --help--
## --tip--
Kombinuj běžný text a `dark:text-`.
