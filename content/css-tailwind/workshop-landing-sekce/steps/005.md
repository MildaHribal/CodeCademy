# --description--
Pod hero sekcí bude přehled vlastností v mřížce. Na mobilu chceme 1 sloupec, na tabletu (`md:`) 2 a na počítači (`lg:`) 3 sloupce.

**Úkol:** `<div class="features">` změň na `grid gap-8 grid-cols-1 md:grid-cols-2 lg:grid-cols-3 w-full max-w-6xl mt-16`.

# --hints--
Splněno.
```js
const g = document.querySelectorAll('div')[0]; assert.ok(g.classList.contains('grid-cols-1') && g.classList.contains('md:grid-cols-2') && g.classList.contains('lg:grid-cols-3'), 'Mřížka je responzivní.');
```

# --help--
## --tip--
Použij breakpointy: `grid-cols-1`, `md:grid-cols-2` a `lg:grid-cols-3`.
