# --description--
## Hlášení

Kolega se pokusil přidat ke kartě z předchozího kroku hover efekt, který ji posune nahoru a zvětší stín. Jenže stín nefunguje.

## Úkol

Oprav hover efekt. Třída `hover-shadow-xl` není platná. Najdi v kódu nesmyslnou třídu a změň ji na správný zápis (`hover:shadow-xl`).

# --hints--
Splněno.
```js
const c = document.querySelector('article'); assert.ok(c.classList.contains('hover:shadow-xl'), 'Karta má správný hover stín.');
```

# --help--

## --tip--

Varianta se od utility odděluje **dvojtečkou**, ne pomlčkou. Pomlčka je součást jména
utility, takže neznámá kombinace se prostě nevygeneruje — a Tailwind na to neupozorní.

## --tip--

Podívej se na ostatní varianty v souboru (`md:`, `focus-visible:`) a porovnej zápis
s tím kolegovým.
