# --description--

Tokeny značky máš hotové, ale všechny jsou **primitivní** — říkají, jaká je to barva,
ne k čemu slouží. Proto by tmavý motiv znamenal projít každou třídu na stránce.

Poslední krok to otočí: přidáš dva **sémantické** tokeny (`--color-plocha`
a `--color-text`), použiješ je v hlavním obalu a tmavý motiv uděláš tím, že je
v pravidle `.tmavy` přepíšeš. Značka `<main>` už třídu `tmavy` má připravenou.

**Úkol:** do `@theme` přidej `--color-plocha: #fffaf5` a `--color-text: #2d2418`.
Hlavnímu obalu dej třídy `bg-plocha` a `text-text`. Pak pod blok `@theme` dopiš pravidlo
`.tmavy`, které obě proměnné přepíše na `#2d2418` a `#fffaf5`.

Všimni si, že se přitom nedotkneš jediné třídy uvnitř — mění se jen hodnoty tokenů.

## Co jsi postavil

Motiv pražírny, který stojí na vlastních tokenech:

- barvy, písmo i rozestup značky žijí v jednom bloku `@theme`,
- utility (`bg-primary`, `font-brand`, `gap-huge`) z nich vznikly samy,
- překlep v názvu tokenu se pozná podle toho, že utilita prostě nic neudělá,
- a tmavý motiv je výměna dvou hodnot, ne průchod celým souborem.

Přesně tohle je rozdíl mezi „používám Tailwind" a „mám v Tailwindu design systém".
V další lekci se podíváš na varianty — kdy má který token platit.

## Udělej po svém

- **Vzhled:** přidej token `--radius-karta` a použij ho na článku i na tlačítku, ať mají
  stejné zaoblení řízené z jednoho místa.
- **Funkce:** přidej třetí sémantický token `--color-okraj` a dej článku rámeček, který
  se v tmavém motivu taky změní.
- **Vyzkoušej:** zkus do `@theme` napsat `--color-primary` starým zápisem
  `rgb(139, 92, 246)` a podívej se, co to udělá s `bg-primary/50`.
- **Tvoje téma:** přebarvi celou pražírnu na značku, kterou máš rád — stačí změnit
  hodnoty v `@theme` a nic jiného.

# --hints--

V `@theme` jsou oba sémantické tokeny.

```js
const css = files['style.css'];
assert.match(css, /--color-plocha:\s*#fffaf5/i, 'V @theme chybí token --color-plocha: #fffaf5');
assert.match(css, /--color-text:\s*#2d2418/i, 'V @theme chybí token --color-text: #2d2418');
```

Hlavní obal používá sémantické utility, ne konkrétní barvu.

```js
const main = document.querySelector('main');
assert.ok(main.classList.contains('bg-plocha'), 'Hlavní obal má mít třídu bg-plocha');
assert.ok(main.classList.contains('text-text'), 'Hlavní obal má mít třídu text-text');
assert.equal(getComputedStyle(main).backgroundColor, 'rgb(255, 250, 245)', `Pozadí je ${getComputedStyle(main).backgroundColor} — token --color-plocha se nepropsal`);
```

Pravidlo `.tmavy` oba tokeny přepisuje.

```js
const css = files['style.css'];
const pravidlo = /\.tmavy\s*\{([^}]*)\}/.exec(css);
assert.ok(pravidlo, 'V style.css chybí pravidlo .tmavy');
assert.match(pravidlo[1], /--color-plocha:\s*#2d2418/i, 'Pravidlo .tmavy má přepsat --color-plocha na #2d2418');
assert.match(pravidlo[1], /--color-text:\s*#fffaf5/i, 'Pravidlo .tmavy má přepsat --color-text na #fffaf5');
```

Tmavý motiv se opravdu projeví.

```js
const main = document.querySelector('main');
main.classList.add('tmavy');
await helpers.waitFor(() => getComputedStyle(main).backgroundColor === 'rgb(45, 36, 24)', 2000).catch(() => {});
assert.equal(getComputedStyle(main).backgroundColor, 'rgb(45, 36, 24)', `Po přidání třídy tmavy je pozadí ${getComputedStyle(main).backgroundColor} — přepsání tokenu se nepropsalo`);
assert.equal(getComputedStyle(main).color, 'rgb(255, 250, 245)', 'V tmavém motivu má být i text světlý');
main.classList.remove('tmavy');
```

Tokeny z předchozích kroků zůstaly.

```js
const btn = document.querySelector('button');
assert.equal(getComputedStyle(btn).backgroundColor, 'rgb(139, 92, 246)', 'Tlačítko má zůstat v barvě --color-primary');
const h1 = document.querySelector('h1');
assert.ok(getComputedStyle(h1).fontFamily.includes('Georgia'), 'Nadpis má zůstat ve fontu --font-brand');
```

# --help--

## --tip--

Rozdíl mezi primitivními a sémantickými tokeny je v části
[Sémantické tokeny a tmavý motiv](see:css-tailwind/theme-a-tokeny#semanticke-tokeny-a-tmavy-motiv).

## --tip--

Tokeny přidáš do `@theme` stejně jako ty předchozí. Pravidlo `.tmavy` se píše **pod**
blok `@theme` jako obyčejný CSS selektor a nastavuje ty samé proměnné na jiné hodnoty.

## --tip--

U motivu webu by to vypadalo stejně: `--color-plocha` a `--color-text` v `@theme`,
pak `[data-theme="dark"] { --color-plocha: …; }` — a v komponentách se nemění nic.

# --explain--

Vysvětli vlastními slovy, proč tmavý motiv nevyžaduje sáhnout na jedinou třídu v HTML.

## --model--

Třídy `bg-plocha` a `text-text` neříkají konkrétní barvu, ale **roli** — „pozadí plochy"
a „barva textu". Utilita se odkazuje na proměnnou `var(--color-plocha)`, takže když
proměnnou přepíšeš, změní se všechno, co ji používá. Tmavý motiv je proto změna dvou
hodnot na jednom místě, ne průchod celým projektem. S primitivními třídami jako
`bg-bezova` by to nešlo — jméno by lhalo.

## --checklist--

- Sémantická utilita se odkazuje na proměnnou, ne na pevnou barvu.
- Přepsání proměnné se propíše všude, kde se používá.
- Jméno tokenu říká roli, ne konkrétní barvu.
- Komponenty se tím pádem nemusí měnit vůbec.

## --file-- style.css

```css
@theme {
  --color-primary: #8b5cf6;
  --font-brand: Georgia, serif;
  --color-secondary: #fb923c;
  --spacing-huge: 5rem;
  --color-danger: #e11d48;

  /* Sémantické tokeny — světlý motiv */
  --color-plocha: #fffaf5;
  --color-text: #2d2418;
}

/* Tmavý motiv: mění se jen hodnoty, ne třídy v HTML. */
.tmavy {
  --color-plocha: #2d2418;
  --color-text: #fffaf5;
}
```
