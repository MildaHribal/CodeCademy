# --description--
Tady tvoje tvorba design tokenů končí! Nyní máš v CSS jeden `theme` blok se sadou vlastních barev, písem a mezer.

Vyzkoušej si:
- Změň barvy na své oblíbené.
- Přidej nový font `--font-mono: monospace` a použij ho.

# --hints--
Splněno.
```js
assert.ok(document.querySelector('.moje-trida'), 'Byla pridana vlastni trida.');
```

# --help--
## --tip--
Neboj se experimentovat v `style.css`.

# --seed--
## --file-- index.html
```html
button class="bg-primary text-white px-4 py-2 rounded-md">
    Odeslat
  </button>

  <div class="bg-danger text-white p-4 rounded-md error-box">
    Pozor, akce nejde vzít zpět.
  </div>
</main>
```

## --file-- style.css
```css
@theme {
  --color-primary: #8b5cf6;
  --font-brand: Georgia, serif;
  --color-secondary: #fb923c;
  --spacing-huge: 5rem;
  --color-danger: #e11d48;
}
```
