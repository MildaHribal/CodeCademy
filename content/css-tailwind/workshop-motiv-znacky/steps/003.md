# --description--
Ke kartám služeb chceme dát jemné oranžové pozadí. V manuálu je to secondary barva `#fb923c`.

**Úkol:** Přidej do `@theme` barvu s názvem `--color-secondary` a daným hex kódem. Poté aplikuj na článek `<article>` třídu `bg-secondary`.

# --hints--
Splněno.
```js
const a = document.querySelector('article'); assert.ok(a.classList.contains('bg-secondary'), 'Článek má bg-secondary.'); assert.equal(getComputedStyle(a).backgroundColor, 'rgb(251, 146, 60)', 'Barva pozadí článku je správná.');
```

# --help--
## --tip--
V CSS zapiš proměnnou pro sekudnární barvu. A nezapomeň aplikovat `bg-secondary` v HTML.
