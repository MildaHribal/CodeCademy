# --description--
Firemní značka používá patkové písmo *Georgia* pro všechny nadpisy. Můžeme mu říkat `brand`.

**Úkol:** Přidej do `@theme` definici `--font-brand: Georgia, serif;`. Pak nadpisu `<h1>` přidej utilitu `font-brand`.

# --hints--
Splněno.
```js
const h1 = document.querySelector('h1'); assert.ok(h1.classList.contains('font-brand'), 'Nadpis používá nový font.'); assert.ok(getComputedStyle(h1).fontFamily.includes('Georgia'), 'Font je skutečně Georgia.');
```

# --help--
## --tip--
V CSS použij `--font-brand`. V HTML dej `<h1>` třídu `font-brand`.
