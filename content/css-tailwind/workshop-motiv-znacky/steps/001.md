# --description--
Dostali jsme z Figmy design manuál. Hlavní firemní barva je sytě fialová `#8b5cf6`. Zatím to není v Tailwindu pojmenované.

**Úkol:** V souboru `style.css` najdi direktivu `@theme` a přidej dovnitř vlastnost `--color-primary` s odpovídajícím hex kódem. Pak v `index.html` změň tlačítku `bg-blue-500` na `bg-primary`.

# --hints--
Splněno.
```js
const btn = document.querySelector('button'); assert.ok(btn.classList.contains('bg-primary'), 'Tlačítko má bg-primary.'); assert.equal(getComputedStyle(btn).backgroundColor, 'rgb(139, 92, 246)', 'Barva odpovídá hex #8b5cf6.');
```

# --help--
## --tip--
V CSS vytvoř novou vlastnost s barvou. V HTML přepiš `bg-blue-500` na `bg-primary`.
