# --description--
## Hlášení

Kolega zkoušel přidat speciální `danger` barvu pro varování, ale Tailwind ji vůbec nenabízí a barva pozadí selhává.

## Úkol

Najdi a oprav chybu v definici proměnné v CSS. Pozor, nezapomeň, že u barev musíš Tailwindu říct, že jde opravdu o barvu, pomocí specifického jména proměnné.

# --hints--
Splněno.
```js
const err = document.querySelector('.error-box'); assert.ok(getComputedStyle(err).backgroundColor === 'rgb(225, 29, 72)', 'Varování je zbarveno růžově.');
```
