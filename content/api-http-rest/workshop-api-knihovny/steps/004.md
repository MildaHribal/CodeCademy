# --description--

Zkus v HTTP klientovi `DELETE /api/books/3`. Server odpoví `404 Tahle adresa
neexistuje` — a to je lež: adresa existuje, jen na ní nejde mazat. Klient, který
dostane `404`, si myslí, že má špatnou adresu, a hledá chybu na úplně jiném místě.

Pro tenhle případ je stavový kód `405 Method Not Allowed` a k němu povinná hlavička
`Allow` se seznamem metod, které adresa umí, třeba `Allow: GET, DELETE`.

**Úkol:** uprav `handleRequest` v `server.js`:

- když cesta odpovídá nějaké routě, ale žádná z nich nemá metodu požadavku, odpověz
  `405` a nastav hlavičku `Allow` se všemi metodami rout, které cestě odpovídají
  (oddělené čárkou a mezerou),
- když cestě neodpovídá žádná routa, zůstává `404`.

Hlavičku nastavíš před odesláním přes `res.setHeader(jméno, hodnota)`. `sendJson` ji
pak odešle spolu s ostatními, protože `writeHead` hlavičky nastavené dřív nezahodí.
Stejný vzor posbírání hodnot během procházení:

```js
const matchingSizes = [];
for (const shoe of shoes) {
  if (shoe.model === wantedModel) {
    matchingSizes.push(shoe.size);
  }
}
res.setHeader('X-Available-Sizes', matchingSizes.join(', '));
```

# --explain--

Vysvětli, proč na `DELETE /api/books/3` patří `405` s hlavičkou `Allow`, a ne `404`.

## --model--

`404` říká, že adresa neexistuje, jenže kniha 3 existuje a `GET` na ni funguje.
`405` klientovi řekne přesně, co je špatně: metoda. Hlavička `Allow` mu k tomu
vyjmenuje metody, které adresa umí, takže vývojář frontendu nemusí hádat, jestli má
překlep v adrese, nebo jestli mazání API vůbec nepodporuje.

## --checklist--

- `404` znamená, že adresa neexistuje, a ta tady existuje.
- `405` pojmenuje skutečný problém: metodu.
- Hlavička `Allow` vyjmenuje metody, které adresa umí.
- Přesný kód šetří čas tomu, kdo API volá a hledá chybu.

```js
export function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

export function sendError(res, status, message) {
  sendJson(res, status, { error: message });
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí undefined.
export async function readJson(req) {
  const chunks = [];
  for await (const chunk of req) {
    chunks.push(chunk);
  }
  try {
    return JSON.parse(Buffer.concat(chunks).toString('utf8'));
  } catch {
    return undefined;
  }
}
```

```js
// Porovná cestu se vzorem routy. Vrátí objekt s parametry, nebo null.
export function matchPath(pattern, pathname) {
  const patternParts = pattern.split('/');
  const pathParts = pathname.split('/');
  if (patternParts.length !== pathParts.length) return null;
  const params = {};
  for (let i = 0; i < patternParts.length; i++) {
    if (patternParts[i].startsWith(':')) {
      params[patternParts[i].slice(1)] = pathParts[i];
    } else if (patternParts[i] !== pathParts[i]) {
      return null;
    }
  }
  return params;
}
```

# --solution--

## --file-- server.js

```js
import { createServer } from 'node:http';
import { sendError } from './http.js';
import { matchPath } from './router.js';
import { routes } from './routes.js';

const port = Number(process.env.PORT ?? 3000);

async function handleRequest(req, res) {
  const { pathname, searchParams } = new URL(req.url, 'http://localhost');

  const allowedMethods = [];
  for (const route of routes) {
    const params = matchPath(route.path, pathname);
    if (params === null) {
      continue;
    }
    if (route.method === req.method) {
      return route.handler(req, res, { params, query: searchParams });
    }
    allowedMethods.push(route.method);
  }

  if (allowedMethods.length > 0) {
    res.setHeader('Allow', allowedMethods.join(', '));
    return sendError(res, 405, 'Tahle metoda tu není povolená.');
  }
  sendError(res, 404, 'Tahle adresa neexistuje.');
}

createServer(async (req, res) => {
  try {
    await handleRequest(req, res);
  } catch (error) {
    console.error(error);
    sendError(res, 500, 'Na serveru se něco pokazilo.');
  }
}).listen(port, () => {
  console.log(`API knihovny běží na http://localhost:${port}`);
});
```
