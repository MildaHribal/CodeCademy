# --description--

Městská knihovna chce k webovému katalogu API: seznam knih s filtrem, řazením
a stránkováním a výpůjčky, které hlídají, aby jednu knihu neměli dva čtenáři
najednou. Za tenhle workshop ho postavíš bez frameworku, ve stejném Node, jaké znáš
z [workshopu HTTP serveru](see:node-zaklady/workshop-http-server/001).

Kostra je připravená a oproti minule je jinak rozdělená:

- `data.js` — knihy a výpůjčky v paměti (po restartu serveru se data vrátí do původního stavu),
- `http.js` — pomocné funkce pro odpovědi a čtení těla požadavku,
- `routes.js` — tabulka rout: metoda, cesta a funkce, která požadavek obslouží,
- `books.js` — obsluha rout pro knihy,
- `server.js` — přijme požadavek, najde routu v tabulce a zavolá její funkci.

Server zatím na nic neodpoví: funkce `sendJson` v `http.js` je prázdná a všechny
odpovědi přes ni procházejí.

**Úkol:** doplň `sendJson(res, status, data)` tak, aby poslala odpověď se stavovým
kódem `status`, hlavičkou `Content-Type: application/json; charset=utf-8` a tělem
`data` převedeným na JSON. Tohle už jsi psal, zkus to bez nápovědy.

Pak klikni na **Spustit** a v panelu HTTP klienta pošli `GET /api/books`.

# --hints--

`GET /api/books` vrátí stav `200` a všech 12 knih z `data.js`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(`${server.url}/api/books`, { signal: AbortSignal.timeout(3000) })
  .catch(() => assert.fail('GET /api/books: server do 3 sekund neodpověděl — ukončuje sendJson odpověď?'));
assert.equal(res.status, 200, 'GET /api/books má vrátit stav 200');
const books = await res.json().catch(() => assert.fail('tělo odpovědi GET /api/books nedorazilo celé nebo není platný JSON'));
assert.equal(Array.isArray(books), true, 'GET /api/books má vrátit pole knih');
assert.equal(books.length, 12, 'GET /api/books má vrátit všech 12 knih');
assert.equal(books[0].title, 'Krakatit', 'první kniha v odpovědi GET /api/books má být Krakatit');
```

Odpověď má hlavičku `Content-Type: application/json; charset=utf-8`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(`${server.url}/api/books`, { signal: AbortSignal.timeout(3000) })
  .catch(() => assert.fail('GET /api/books: server do 3 sekund neodpověděl'));
const type = res.headers.get('content-type') ?? '(chybí)';
assert.match(type, /^application\/json/i, `GET /api/books má mít Content-Type application/json, přišlo: ${type}`);
assert.match(type, /charset=utf-8/i, `Content-Type u GET /api/books má obsahovat charset=utf-8, přišlo: ${type}`);
```

Neznámá adresa vrátí stav `404` a JSON s klíčem `error`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(`${server.url}/api/ctenari`, { signal: AbortSignal.timeout(3000) })
  .catch(() => assert.fail('GET /api/ctenari: server do 3 sekund neodpověděl'));
assert.equal(res.status, 404, 'GET /api/ctenari (neznámá adresa) má vrátit stav 404 — používá sendJson parametr status?');
const body = await res.json().catch(() => assert.fail('tělo odpovědi 404 nedorazilo celé nebo není platný JSON'));
assert.equal(typeof body.error, 'string', 'odpověď 404 má mít klíč error s textem');
```

```js
import { books } from './data.js';
import { sendError, sendJson } from './http.js';

export function listBooks(req, res, { query }) {
  sendJson(res, 200, books);
}

export function getBook(req, res, { params }) {
  const book = books.find((item) => item.id === Number(params.id));
  if (!book) {
    return sendError(res, 404, 'Kniha nenalezena.');
  }
  sendJson(res, 200, book);
}
```

## --file-- server.js

```js
import { createServer } from 'node:http';
import { sendError } from './http.js';
import { routes } from './routes.js';

const port = Number(process.env.PORT ?? 3000);

async function handleRequest(req, res) {
  const { pathname, searchParams } = new URL(req.url, 'http://localhost');

  const route = routes.find((item) => item.method === req.method && item.path === pathname);
  if (!route) {
    return sendError(res, 404, 'Tahle adresa neexistuje.');
  }
  await route.handler(req, res, { params: {}, query: searchParams });
}

createServer(async (req, res) => {
  try {
    await handleRequest(req, res);
  } catch (error) {
    console.error(error);
    sendError(res, 500, 'Na serveru se něco pokazilo.');
  }
}).listen(port, () => {
  console.log(`API knihovny běží na http://localhost:${port}`);
});
```

## --file-- http.js

```js
// Pomocné funkce pro odpovědi. Každá odpověď serveru prochází přes sendJson.

export function sendJson(res, status, data) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(data));
}

export function sendError(res, status, message) {
  sendJson(res, status, { error: message });
}

// Přečte tělo požadavku a převede ho z JSON. Když tělo není platný JSON, vrátí undefined.
export async function readJson(req) {
  const chunks = [];
  for await (const chunk of req) {
    chunks.push(chunk);
  }
  try {
    return JSON.parse(Buffer.concat(chunks).toString('utf8'));
  } catch {
    return undefined;
  }
}
```
