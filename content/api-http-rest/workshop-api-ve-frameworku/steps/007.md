# --description--

`logRequests` je hotový, ale aplikace o něm neví. Middleware se zapojuje stejně jako
`express.json()`, a tady záleží na tom, **kam** řádek napíšeš. Express prochází middlewary
a routy v pořadí, v jakém jsou v kódu. Požadavek, který obslouží routa nad tvým middlewarem,
k němu vůbec nedojde, protože routa `next()` nevolá.

**Úkol:** zapoj `logRequests` v `app.js` tak, aby se v terminálu objevil řádek za **každý**
požadavek: seznam i detail knih, výpůjčky i neplatné požadavky. Pak spusť server, pošli
v HTTP klientovi pár požadavků a sleduj výstup.

Kandidáti na umístění: hned za vytvořením aplikace, mezi routami knih a routerem výpůjček,
nebo na konci souboru. Jen jedno z nich zachytí všechno.

# --hints--

Server vypíše řádek za `GET /api/books/3` i za `POST /api/loans` s neplatnými daty.

```js
const server = await helpers.startServer('server.js');
await fetch(`${server.url}/api/books/3`, { signal: AbortSignal.timeout(3000) })
  .catch(() => assert.fail('GET /api/books/3: server do 3 sekund neodpověděl'));
await fetch(`${server.url}/api/loans`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ bookId: 3, reader: '' }),
  signal: AbortSignal.timeout(3000),
}).catch(() => assert.fail('POST /api/loans: server do 3 sekund neodpověděl'));
await helpers.waitFor(() => /POST \/api\/loans 422 \d+ ms/.test(server.output()), 2000).catch(() => {});
const output = server.output();
assert.match(output, /GET \/api\/books\/3 200 \d+ ms/, `v terminálu serveru chybí řádek „GET /api/books/3 200 … ms" — je logRequests zapojený před routami knih? Výstup:\n${output.slice(-300)}`);
assert.match(output, /POST \/api\/loans 422 \d+ ms/, `v terminálu serveru chybí řádek „POST /api/loans 422 … ms". Výstup:\n${output.slice(-300)}`);
```

# --help--

## --tip--

Jak middleware funguje a proč volá `next()`, najdeš v popisu [předchozího kroku](see:api-http-rest/workshop-api-ve-frameworku/006).

## --tip--

Routa, která odpoví, řetěz ukončí. Middleware, který má vidět všechny požadavky, proto
musí být před první routou i před routerem. Zapojuje se přes `app.use` s funkcí bez závorek.

## --tip--

Stejná situace: kontrola přihlášení zapojená až pod routou `/api/admin` tu routu nechrání,
požadavek na ni ke kontrole nikdy nedojde.

## --file-- catalog.js

```js
import { loans } from './data.js';

// Povolená řazení. Klient smí poslat jen jméno, které tu je.
export const sorters = {
  title: (a, b) => a.title.localeCompare(b.title, 'cs'),
  author: (a, b) => a.author.localeCompare(b.author, 'cs'),
  year: (a, b) => a.year - b.year,
};

// Převede hodnotu z query na celé číslo v rozsahu. Když to nejde, vrátí null.
// Express dá u opakovaného parametru (?page=1&page=2) pole, proto kontrola typu.
export function parseIntInRange(value, min, max) {
  if (typeof value !== 'string' || value.trim() === '') {
    return null;
  }
  const number = Number(value);
  if (!Number.isInteger(number) || number < min || number > max) {
    return null;
  }
  return number;
}

// Kniha tak, jak ji vidí klient: data z katalogu a dostupnost spočítaná z výpůjček.
export function toBookResponse(book) {
  return { ...book, available: !loans.some((loan) => loan.bookId === book.id) };
}
```

## --file-- loan-rules.js

```js
import { books, loans } from './data.js';

// Kontrola těla nové výpůjčky. Vrátí { status, error }, nebo null, když je vstup v pořádku.
export function checkLoanInput(input) {
  if (typeof input !== 'object' || input === null || Array.isArray(input)) {
    return { status: 400, error: 'Tělo požadavku musí být JSON objekt.' };
  }
  if (!Number.isInteger(input.bookId) || input.bookId < 1) {
    return { status: 422, error: 'bookId musí být kladné celé číslo.' };
  }
  if (typeof input.reader !== 'string' || input.reader.trim() === '') {
    return { status: 422, error: 'reader musí být jméno čtenáře.' };
  }
  return null;
}

// Kontrola, jestli jde knihu půjčit. Vrátí { status, error }, nebo null.
export function checkAvailability(bookId) {
  if (!books.some((book) => book.id === bookId)) {
    return { status: 422, error: 'Kniha s tímhle id neexistuje.' };
  }
  if (loans.some((loan) => loan.bookId === bookId)) {
    return { status: 409, error: 'Kniha je právě vypůjčená.' };
  }
  return null;
}

// Datum vrácení: dnes + 28 dní, ve tvaru RRRR-MM-DD.
export function dueDateFromToday() {
  const date = new Date();
  date.setDate(date.getDate() + 28);
  return date.toISOString().slice(0, 10);
}
```

## --file-- app.js

```js
import express from 'express';
import { books } from './data.js';
import { parseIntInRange, sorters, toBookResponse } from './catalog.js';
import { loansRouter } from './loans-router.js';

export const app = express();

app.use(express.json());

app.get('/api/books', (req, res) => {
  const { genre, sort } = req.query;
  let result = genre === undefined ? books : books.filter((book) => book.genre === genre);
  if (sort !== undefined) {
    if (!Object.hasOwn(sorters, sort)) {
      return res.status(400).json({ error: 'Řadit jde jen podle title, author nebo year.' });
    }
    result = result.toSorted(sorters[sort]);
  }

  const page = parseIntInRange(req.query.page ?? '1', 1, Infinity);
  const limit = parseIntInRange(req.query.limit ?? '5', 1, 50);
  if (page === null || limit === null) {
    return res.status(400).json({ error: 'page musí být celé číslo od 1 a limit celé číslo od 1 do 50.' });
  }
  const start = (page - 1) * limit;
  res.json({
    data: result.slice(start, start + limit).map(toBookResponse),
    meta: { page, limit, total: result.length, totalPages: Math.ceil(result.length / limit) },
  });
});

app.get('/api/books/:id', (req, res) => {
  const book = books.find((item) => item.id === Number(req.params.id));
  if (!book) {
    return res.status(404).json({ error: 'Kniha nenalezena.' });
  }
  res.json(toBookResponse(book));
});

app.use('/api/loans', loansRouter);
```

## --file-- loans-router.js

```js
import express from 'express';
import { loans } from './data.js';
import { checkAvailability, checkLoanInput, dueDateFromToday } from './loan-rules.js';

// Routy výpůjček. V app.js se připojí pod /api/loans.
export const loansRouter = express.Router();

loansRouter.get('/:id', (req, res) => {
  const loan = loans.find((item) => item.id === Number(req.params.id));
  if (!loan) {
    return res.status(404).json({ error: 'Výpůjčka nenalezena.' });
  }
  res.json(loan);
});

loansRouter.post('/', (req, res) => {
  const problem = checkLoanInput(req.body) ?? checkAvailability(req.body.bookId);
  if (problem) {
    return res.status(problem.status).json({ error: problem.error });
  }

  const loan = {
    id: Math.max(0, ...loans.map((item) => item.id)) + 1,
    bookId: req.body.bookId,
    reader: req.body.reader,
    dueDate: dueDateFromToday(),
  };
  loans.push(loan);
  res.status(201).location(`/api/loans/${loan.id}`).json(loan);
});
```

```js
// Middleware, který po odeslání odpovědi vypíše metodu, adresu, stav a dobu zpracování,
// třeba: GET /api/books?page=2 200 3 ms
export function logRequests(req, res, next) {
  const startedAt = performance.now();
  res.on('finish', () => {
    const ms = Math.round(performance.now() - startedAt);
    console.log(`${req.method} ${req.originalUrl} ${res.statusCode} ${ms} ms`);
  });
  next();
}
```
