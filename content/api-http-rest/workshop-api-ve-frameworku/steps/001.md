# --description--

API knihovny z minulého workshopu funguje, ale polovinu kódu tvoří věci, které nemají nic
společného s knihovnou: porovnání cesty se vzorem, čtení těla po kouscích, `writeHead`
s hlavičkou `Content-Type`. Tohle za tebe v praxi dělá framework. Nejrozšířenější pro Node
je **Express**, tady ve verzi 5, a stejné API do něj teď přepíšeš.

Kostra je připravená:

- `data.js` — knihy a výpůjčky jako minule,
- `catalog.js` — řazení, převod čísel z query a dostupnost knihy z minulého workshopu,
- `loan-rules.js` — kontroly nové výpůjčky,
- `app.js` — aplikace Express, zatím bez rout,
- `server.js` — spustí aplikaci na portu. Aplikace je oddělená od `listen`, aby ji šlo
  spustit i v testech.

Routa v Expressu je volání metody aplikace, která se jmenuje jako HTTP metoda: cesta
a funkce `(req, res)`. `res.json(data)` udělá najednou to, co dřív `sendJson`: nastaví
stav `200`, hlavičku `Content-Type: application/json; charset=utf-8` a převede data na JSON.
Na jiných datech:

```js
app.get('/api/cinemas', (req, res) => {
  res.json(cinemas.map(toCinemaResponse));
});
```

**Úkol:** v `app.js` přidej routu `GET /api/books`, která vrátí všechny knihy převedené přes
`toBookResponse` (každá kniha tak dostane pole `available`). Stránkování přijde později.

# --hints--

`GET /api/books` vrátí stav `200` a všech 12 knih s polem `available`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(`${server.url}/api/books`, { signal: AbortSignal.timeout(3000) })
  .catch(() => assert.fail('GET /api/books: server do 3 sekund neodpověděl'));
assert.equal(res.status, 200, `GET /api/books má vrátit 200, přišlo ${res.status}`);
const books = await res.json().catch(() => assert.fail('GET /api/books má vrátit JSON — posíláš odpověď přes res.json?'));
assert.equal(books.length, 12, 'GET /api/books má vrátit všech 12 knih');
assert.deepEqual(books[3], { id: 4, title: 'Válka s mloky', author: 'Karel Čapek', genre: 'sci-fi', year: 1936, available: false },
  'čtvrtá kniha v GET /api/books má být Válka s mloky s available: false — převádíš knihy přes toBookResponse?');
```

Odpověď má hlavičku `Content-Type: application/json; charset=utf-8`.

```js
const server = await helpers.startServer('server.js');
const res = await fetch(`${server.url}/api/books`, { signal: AbortSignal.timeout(3000) })
  .catch(() => assert.fail('GET /api/books: server do 3 sekund neodpověděl'));
const type = res.headers.get('content-type') ?? '(chybí)';
assert.match(type, /^application\/json; charset=utf-8$/i, `GET /api/books má mít Content-Type application/json; charset=utf-8, přišlo: ${type}`);
```

```js
import { loans } from './data.js';

// Povolená řazení. Klient smí poslat jen jméno, které tu je.
export const sorters = {
  title: (a, b) => a.title.localeCompare(b.title, 'cs'),
  author: (a, b) => a.author.localeCompare(b.author, 'cs'),
  year: (a, b) => a.year - b.year,
};

// Převede hodnotu z query na celé číslo v rozsahu. Když to nejde, vrátí null.
// Express dá u opakovaného parametru (?page=1&page=2) pole, proto kontrola typu.
export function parseIntInRange(value, min, max) {
  if (typeof value !== 'string' || value.trim() === '') {
    return null;
  }
  const number = Number(value);
  if (!Number.isInteger(number) || number < min || number > max) {
    return null;
  }
  return number;
}

// Kniha tak, jak ji vidí klient: data z katalogu a dostupnost spočítaná z výpůjček.
export function toBookResponse(book) {
  return { ...book, available: !loans.some((loan) => loan.bookId === book.id) };
}
```

## --file-- loan-rules.js

```js
import { books, loans } from './data.js';

// Kontrola těla nové výpůjčky. Vrátí { status, error }, nebo null, když je vstup v pořádku.
export function checkLoanInput(input) {
  if (typeof input !== 'object' || input === null || Array.isArray(input)) {
    return { status: 400, error: 'Tělo požadavku musí být JSON objekt.' };
  }
  if (!Number.isInteger(input.bookId) || input.bookId < 1) {
    return { status: 422, error: 'bookId musí být kladné celé číslo.' };
  }
  if (typeof input.reader !== 'string' || input.reader.trim() === '') {
    return { status: 422, error: 'reader musí být jméno čtenáře.' };
  }
  return null;
}

// Kontrola, jestli jde knihu půjčit. Vrátí { status, error }, nebo null.
export function checkAvailability(bookId) {
  if (!books.some((book) => book.id === bookId)) {
    return { status: 422, error: 'Kniha s tímhle id neexistuje.' };
  }
  if (loans.some((loan) => loan.bookId === bookId)) {
    return { status: 409, error: 'Kniha je právě vypůjčená.' };
  }
  return null;
}

// Datum vrácení: dnes + 28 dní, ve tvaru RRRR-MM-DD.
export function dueDateFromToday() {
  const date = new Date();
  date.setDate(date.getDate() + 28);
  return date.toISOString().slice(0, 10);
}
```
