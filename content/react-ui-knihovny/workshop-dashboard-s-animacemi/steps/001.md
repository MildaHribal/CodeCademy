# --description--

Půjčovna elektrokol Kolovna má přehled pro dispečink: boční menu, tři karty statistik, seznam
výpůjček s filtrem, panel detailu kola a oznámení. Všechno už funguje, jen nic nemá vzhled
a nic se nehýbe. V tomhle workshopu to rozpohybuješ přes Motion — ale nejdřív vzhled.

**Úkol:** V seedu jsou `components/ui/card.jsx` a `components/ui/button.jsx` — stejné
komponenty, jaké jsi psal pro kadeřnictví, jen s jinými barvami. Použij je:

- karty statistik v `components/StatCards.jsx` obal komponentou `Card` místo holého `div`,
- tlačítko „Nová výpůjčka" v `components/RentalList.jsx` nech ve výchozí variantě,
- „Detail" u řádku výpůjčky ať je malé a tiché, „Ukončit" malé a nebezpečné.

Jména variant najdeš v `buttonVariants`. Ze souboru nic neopisuj, stačí props.

# --hints--

Každá karta statistiky je vykreslená komponentou `Card`: zaoblení 16 px, rámeček a odsazení 20 px.

```js
for (const id of ['rented', 'revenue', 'battery']) {
  const label = document.querySelector(`[data-testid="stat-${id}"] p`);
  assert.ok(label, `karta stat-${id} má mít popisek`);
  const card = label.parentElement;
  const style = getComputedStyle(card);
  await helpers.waitFor(() => style.borderTopLeftRadius === '16px', 2000).catch(() => {});
  assert.equal(style.borderTopLeftRadius, '16px', `karta stat-${id} má mít zaoblení z komponenty Card (rounded-2xl = 16 px)`);
  assert.equal(style.paddingTop, '20px', `karta stat-${id} má mít odsazení z komponenty Card (p-5 = 20 px)`);
  assert.equal(style.borderTopWidth, '1px', `karta stat-${id} má mít rámeček z komponenty Card`);
}
```

Tlačítko „Nová výpůjčka" je `Button` ve výchozí variantě: 40 px vysoké s pozadím značky.

```js
const button = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Nová výpůjčka');
assert.ok(button, 'nad seznamem má být tlačítko „Nová výpůjčka"');
```

V řádku výpůjčky je „Detail" malé tiché tlačítko a „Ukončit" malé nebezpečné.

```js
const row = document.querySelector('[data-testid="rental-row"]');
const find = (text) => [...row.querySelectorAll('button')].find((el) => el.textContent.trim() === text);
const detail = find('Detail');
const end = find('Ukončit');
assert.ok(detail && end, 'řádek výpůjčky má mít tlačítka „Detail" a „Ukončit"');

assert.equal(getComputedStyle(detail).height, '32px', '„Detail" má být malé (size sm = 32 px)');
assert.equal(getComputedStyle(detail).backgroundColor, 'rgba(0, 0, 0, 0)', '„Detail" má být v tiché variantě ghost (průhledné pozadí)');
assert.equal(getComputedStyle(end).height, '32px', '„Ukončit" má být malé (size sm = 32 px)');
assert.equal(getComputedStyle(end).backgroundColor, 'rgb(190, 18, 60)', '„Ukončit" má být v nebezpečné variantě danger');
```

# --help--

## --tip--

Komponentu nejdřív naimportuj — cesta je relativní k souboru, ve kterém ji použiješ. Připomenutí najdeš v [lekci o variantách](see:react-ui-knihovny/tailwind-v-reactu#varianty-v-mape-trid).

## --tip--

Varianta i velikost jsou props komponenty `Button`; když je vynecháš, platí `defaultVariants`.

## --file-- App.jsx

```jsx
import { useState } from 'react';
import { BikePanel } from './components/BikePanel';
import { RentalList } from './components/RentalList';
import { Sidebar } from './components/Sidebar';
import { StatCards } from './components/StatCards';
import { Toast } from './components/Toast';
import { bikes, initialRentals, revenueBeforeToday, walkInRental } from './data';
import './styles.css';

export default function App() {
  const [page, setPage] = useState('Přehled');
  const [rentals, setRentals] = useState(initialRentals);
  const [revenue, setRevenue] = useState(revenueBeforeToday);
  const [selectedId, setSelectedId] = useState(null);
  const [message, setMessage] = useState(null);
  const [nextNumber, setNextNumber] = useState(1045);

  const lowBatteryCount = bikes.filter((bike) => bike.battery < 20).length;
  const selectedRental = rentals.find((rental) => rental.id === selectedId) ?? null;
  const selectedBike = selectedRental ? bikes.find((bike) => bike.id === selectedRental.bikeId) : null;

  function endRental(id) {
    const rental = rentals.find((item) => item.id === id);
    setRentals(rentals.filter((item) => item.id !== id));
    setRevenue(revenue + rental.price);
    setMessage(`Výpůjčka ${id} ukončena, tržba +${rental.price} Kč`);
  }

  function addRental() {
    setRentals([{ ...walkInRental, id: `V-${nextNumber}` }, ...rentals]);
    setNextNumber(nextNumber + 1);
  }

  return (
    <div className="flex min-h-screen bg-surface text-slate-900">
      <Sidebar active={page} onSelect={setPage} />
      <main className="flex-1 space-y-6 p-8">
        <h1 className="text-2xl font-semibold">{page}</h1>
        <StatCards rentedCount={rentals.length} revenue={revenue} lowBatteryCount={lowBatteryCount} />
        <RentalList rentals={rentals} onEnd={endRental} onDetail={setSelectedId} onAdd={addRental} />
      </main>
      <BikePanel rental={selectedRental} bike={selectedBike} onClose={() => setSelectedId(null)} />
      <div className="fixed right-6 bottom-6">
        <Toast message={message} onClose={() => setMessage(null)} />
      </div>
    </div>
  );
}
```

```jsx
import { useState } from 'react';

const filters = [
  { value: 'all', label: 'Vše' },
  { value: 'active', label: 'Aktivní' },
  { value: 'late', label: 'Po termínu' },
];

export function RentalList({ rentals, onEnd, onDetail, onAdd }) {
  const [filter, setFilter] = useState('all');
  const visibleRentals = filter === 'all' ? rentals : rentals.filter((rental) => rental.status === filter);

  return (
    <section aria-labelledby="rentals-heading" className="rounded-2xl border border-slate-200 bg-white p-5">
      <div className="flex items-center justify-between gap-4">
        <h2 id="rentals-heading" className="text-lg font-semibold">Výpůjčky</h2>
        <button onClick={onAdd}>Nová výpůjčka</button>
      </div>

      <div role="group" aria-label="Filtr výpůjček" className="mt-4 inline-flex rounded-lg bg-slate-100 p-1">
        {filters.map((option) => (
          <button
            key={option.value}
            aria-pressed={filter === option.value}
            onClick={() => setFilter(option.value)}
            className="relative rounded-md px-3 py-1.5 text-sm font-medium text-slate-700"
          >
            {filter === option.value && (
              <span data-testid="filter-indicator" className="absolute inset-0 rounded-md bg-white shadow-sm" />
            )}
            <span className="relative">{option.label}</span>
          </button>
        ))}
      </div>

      <ul className="relative mt-4">
        {visibleRentals.map((rental) => (
          <li
            key={rental.id}
            data-testid="rental-row"
            className="flex w-full items-center justify-between gap-4 border-b border-slate-100 bg-white py-3"
          >
            <div>
              <p className="text-sm font-medium">{rental.customer}</p>
              <p className="text-xs text-muted">
                {rental.id} · kolo {rental.bikeId} · od {rental.from}
              </p>
            </div>
            <div className="flex gap-2">
              <button onClick={() => onDetail(rental.id)}>Detail</button>
              <button onClick={() => onEnd(rental.id)}>Ukončit</button>
            </div>
          </li>
        ))}
      </ul>
    </section>
  );
}
```

```jsx
export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand disabled:pointer-events-none disabled:opacity-50',

        ghost: 'bg-transparent text-slate-700 hover:bg-slate-100',
        danger: 'bg-danger text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'solid', size: 'md' },
  },
);

export function Button({ className, variant, size, ...props }) {
  return <button className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
```
