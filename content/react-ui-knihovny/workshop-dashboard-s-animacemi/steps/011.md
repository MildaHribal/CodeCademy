# --description--

Řádek už odjíždí, ale zbylé řádky pod ním pak skočí o řádek nahoru. Chceš dvě věci: aby
odcházející řádek hned uvolnil místo a aby ostatní řádky na nové místo plynule dojely.

**Úkol:** V `components/RentalList.jsx` zařiď obojí:

- Odcházející řádek se má okamžitě vytrhnout z toku stránky. Na to má `AnimatePresence`
  režimy přes prop `mode` — vyber ze `sync`, `wait` a `popLayout` ten, který to dělá.
- Zbylé řádky mají změnu pozice doanimovat. To nejde CSS přechodem, protože se nemění
  žádná vlastnost, jen výsledek layoutu. Motion na to má [[layout animaci]].

Seznam už má `relative`, aby se vytržený řádek měl k čemu vztahovat.

# --hints--

Odcházející řádek se hned po kliknutí vytrhne z toku (`position: absolute`).

```js
const rows = () => [...document.querySelectorAll('[data-testid="rental-row"]')];
const jana = rows().find((el) => el.textContent.includes('Jana Dvořáková'));
assert.ok(jana, 'v seznamu má být výpůjčka Jany Dvořákové');
await helpers.click([...jana.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Ukončit'));
await helpers.flush();
const leaving = rows().find((el) => el.textContent.includes('Jana Dvořáková'));
assert.ok(leaving, 'hned po kliknutí má řádek Jany Dvořákové ještě odjíždět');
assert.equal(getComputedStyle(leaving).position, 'absolute', 'odcházející řádek má okamžitě uvolnit místo — režim, který ho vytrhne z toku');
```

Řádek pod ukončenou výpůjčkou dojede na nové místo plynule.

```js
const rows = () => [...document.querySelectorAll('[data-testid="rental-row"]')];
const jana = rows().find((el) => el.textContent.includes('Jana Dvořáková'));
const petr = rows().find((el) => el.textContent.includes('Petr Svoboda'));
const before = petr.getBoundingClientRect().top;
await helpers.click([...jana.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Ukončit'));
await helpers.flush();
let slid = false;
const start = performance.now();
while (!slid && performance.now() - start < 900) {
  const transform = getComputedStyle(petr).transform;
  if (transform !== 'none' && transform !== 'matrix(1, 0, 0, 1, 0, 0)') slid = true;
  await new Promise((resolve) => requestAnimationFrame(resolve));
}
assert.ok(slid, 'řádek Petra Svobody má na nové místo dojet animací (během přesunu má transform)');
await helpers.waitFor(() => getComputedStyle(petr).transform === 'none' || getComputedStyle(petr).transform === 'matrix(1, 0, 0, 1, 0, 0)', 2000).catch(() => {});
assert.ok(petr.getBoundingClientRect().top < before - 10, 'řádek Petra Svobody má po dojetí stát výš, na místě ukončené výpůjčky');
```

# --help--

## --tip--

Režimy `AnimatePresence` jsou popsané v lekci u [odchodů z DOM](see:react-ui-knihovny/motion-for-react#animatepresence-odchod-z-dom), plynulá změna pozice u [layout animací](see:react-ui-knihovny/motion-for-react#layout-animace-a-layoutid).

## --tip--

Režim patří na obal, který odchody hlídá. Prop pro layout animaci patří na každý řádek — bez hodnoty, stačí samotné jméno.

## --tip--

U galerie fotek by vypadal obal `<AnimatePresence mode="wait">` a dlaždice `<motion.figure layout>` — tady ovšem `wait` nechceš, počkal by s ostatními, až řádek odjede.

# --explain--

Proč seznam, ze kterého řádky ubývají, potřebuje `mode="popLayout"`, a ne jen `layout` na řádcích?

## --model--

Ve výchozím režimu zůstane odcházející řádek v toku stránky a drží místo, dokud jeho `exit` nedoběhne. Zbylé řádky se tedy posunou až potom — nejdřív čekají, pak dojedou, a celé to trvá dvakrát tak dlouho. `popLayout` odcházející řádek hned vytrhne z toku (dá mu `position: absolute`), takže ostatní začnou dojíždět ve stejném okamžiku, kdy on odjíždí.

## --checklist--

- Ve výchozím režimu odcházející prvek drží místo až do konce `exit`.
- Zbylé řádky se pak posouvají až po jeho odchodu.
- `popLayout` odcházející prvek hned vytrhne z toku.
- Odjezd a dojetí ostatních řádků pak běží současně.

```jsx
import { useState } from 'react';
import { BikePanel } from './components/BikePanel';
import { RentalList } from './components/RentalList';
import { Sidebar } from './components/Sidebar';
import { StatCards } from './components/StatCards';
import { Toast } from './components/Toast';
import { bikes, initialRentals, revenueBeforeToday, walkInRental } from './data';
import './styles.css';

export default function App() {
  const [page, setPage] = useState('Přehled');
  const [rentals, setRentals] = useState(initialRentals);
  const [revenue, setRevenue] = useState(revenueBeforeToday);
  const [selectedId, setSelectedId] = useState(null);
  const [message, setMessage] = useState(null);
  const [nextNumber, setNextNumber] = useState(1045);

  const lowBatteryCount = bikes.filter((bike) => bike.battery < 20).length;
  const selectedRental = rentals.find((rental) => rental.id === selectedId) ?? null;
  const selectedBike = selectedRental ? bikes.find((bike) => bike.id === selectedRental.bikeId) : null;

  function endRental(id) {
    const rental = rentals.find((item) => item.id === id);
    setRentals(rentals.filter((item) => item.id !== id));
    setRevenue(revenue + rental.price);
    setMessage(`Výpůjčka ${id} ukončena, tržba +${rental.price} Kč`);
  }

  function addRental() {
    setRentals([{ ...walkInRental, id: `V-${nextNumber}` }, ...rentals]);
    setNextNumber(nextNumber + 1);
  }

  return (
    <div className="flex min-h-screen bg-surface text-slate-900">
      <Sidebar active={page} onSelect={setPage} />
      <main className="flex-1 space-y-6 p-8">
        <h1 className="text-2xl font-semibold">{page}</h1>
        <StatCards rentedCount={rentals.length} revenue={revenue} lowBatteryCount={lowBatteryCount} />
        <RentalList rentals={rentals} onEnd={endRental} onDetail={setSelectedId} onAdd={addRental} />
      </main>
      <BikePanel rental={selectedRental} bike={selectedBike} onClose={() => setSelectedId(null)} />
      <div className="fixed right-6 bottom-6">
        <Toast message={message} onClose={() => setMessage(null)} />
      </div>
    </div>
  );
}
```

```jsx
import { useState } from 'react';
import { AnimatePresence, motion } from 'motion/react';
import { Button } from './ui/button';

const filters = [
  { value: 'all', label: 'Vše' },
  { value: 'active', label: 'Aktivní' },
  { value: 'late', label: 'Po termínu' },
];

export function RentalList({ rentals, onEnd, onDetail, onAdd }) {
  const [filter, setFilter] = useState('all');
  const visibleRentals = filter === 'all' ? rentals : rentals.filter((rental) => rental.status === filter);

  return (
    <section aria-labelledby="rentals-heading" className="rounded-2xl border border-slate-200 bg-white p-5">
      <div className="flex items-center justify-between gap-4">
        <h2 id="rentals-heading" className="text-lg font-semibold">Výpůjčky</h2>
        <Button onClick={onAdd}>Nová výpůjčka</Button>
      </div>

      <div role="group" aria-label="Filtr výpůjček" className="mt-4 inline-flex rounded-lg bg-slate-100 p-1">
        {filters.map((option) => (
          <button
            key={option.value}
            aria-pressed={filter === option.value}
            onClick={() => setFilter(option.value)}
            className="relative rounded-md px-3 py-1.5 text-sm font-medium text-slate-700"
          >
            {filter === option.value && (
              <motion.span
                layoutId="filter-indicator"
                data-testid="filter-indicator"
                className="absolute inset-0 rounded-md bg-white shadow-sm"
              />
            )}
            <span className="relative">{option.label}</span>
          </button>
        ))}
      </div>

      <ul className="relative mt-4">
        <AnimatePresence>
          {visibleRentals.map((rental) => (
            <motion.li
              key={rental.id}
              exit={{ opacity: 0, x: 40 }}
              transition={{ duration: 0.3 }}
              data-testid="rental-row"
              className="flex w-full items-center justify-between gap-4 border-b border-slate-100 bg-white py-3"
            >
              <div>
                <p className="text-sm font-medium">{rental.customer}</p>
                <p className="text-xs text-muted">
                  {rental.id} · kolo {rental.bikeId} · od {rental.from}
                </p>
              </div>
              <div className="flex gap-2">
                <Button variant="ghost" size="sm" onClick={() => onDetail(rental.id)}>
                  Detail
                </Button>
                <Button variant="danger" size="sm" onClick={() => onEnd(rental.id)}>
                  Ukončit
                </Button>
              </div>
            </motion.li>
          ))}
        </AnimatePresence>
      </ul>
    </section>
  );
}
```

```jsx
import { useEffect } from 'react';
import { animate, motion, useMotionValue, useTransform } from 'motion/react';
import { formatCzk } from '../lib/format';

export function RevenueCounter({ value }) {
  const count = useMotionValue(0);
  const text = useTransform(() => formatCzk(Math.round(count.get())));

  useEffect(() => {
    const controls = animate(count, value, { duration: 0.8, ease: 'easeOut' });
    return () => controls.stop();
  }, [count, value]);

  return <motion.span>{text}</motion.span>;
}
```
