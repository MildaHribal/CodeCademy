# --description--

Jedna z dispečerek má v systému zapnuté „omezit pohyb" — z vyjíždějících panelů a přejíždějících
ukazatelů se jí dělá špatně. Dashboard na to zatím nijak nereaguje.

**Úkol:** V `App.jsx` zařiď, aby všechny animace v aplikaci respektovaly systémové nastavení
omezeného pohybu: u takové uživatelky se posuny a zvětšení vypnou, průhlednost zůstane.
Nechceš to řešit v každé komponentě zvlášť — jedno nastavení má platit pro menu, karty, seznam,
panel i oznámení.

Tím je dashboard hotový. Karty přilétají přes varianty, tržba dopočítává přes motion value,
ukazatele v menu a filtru přejíždějí přes `layoutId`, řádky odjíždějí v `AnimatePresence`
se stabilním `key` a ostatní dojedou přes `layout`, panel z Radixu odjede díky `forceMount`
a oznámení jde odhodit tažením. Stejné vzory potkáš v každé administraci, e-shopu
i aplikaci s oznámeními — a ve vlajkovém projektu React sekce je použiješ znovu.

# --help--

## --tip--

Nastavení pro celý strom komponent je v lekci u [omezeného pohybu](see:react-ui-knihovny/motion-for-react#omezeny-pohyb).

## --tip--

Je to komponenta z `motion/react`, která obalí všechno, co `App` vrací, a dostane jednu prop s hodnotou, která znamená „řiď se systémem".

# --explain--

Proč stačí jedno nastavení v kořeni aplikace a nemusíš v každé komponentě s animací zjišťovat, jestli má uživatel omezený pohyb?

## --model--

Nastavení se předává kontextem, takže ho vidí každý `motion` prvek pod ním, i ten v portálu Radixu. Motion podle něj sám zahodí posuny a zvětšení a průhlednost nechá. Kdybych to řešil v komponentách, musel bych hook volat všude a nová komponenta by na to snadno zapomněla. Hook si nechám jen na případy, kdy chci chování změnit víc, třeba vypnout automatické přehrávání.

## --checklist--

- Nastavení se předává kontextem všem `motion` prvkům pod ním.
- Platí i pro prvky vykreslené do portálu.
- Motion vypne posuny a zvětšení, průhlednost nechá.
- Kontrola v každé komponentě by se u nové komponenty snadno zapomněla.

import { useState } from 'react';
import { BikePanel } from './components/BikePanel';
import { RentalList } from './components/RentalList';
import { Sidebar } from './components/Sidebar';
import { StatCards } from './components/StatCards';
import { Toast } from './components/Toast';
import { bikes, initialRentals, revenueBeforeToday, walkInRental } from './data';
import './styles.css';

export default function App() {
  const [page, setPage] = useState('Přehled');
  const [rentals, setRentals] = useState(initialRentals);
  const [revenue, setRevenue] = useState(revenueBeforeToday);
  const [selectedId, setSelectedId] = useState(null);
  const [message, setMessage] = useState(null);
  const [nextNumber, setNextNumber] = useState(1045);

  const lowBatteryCount = bikes.filter((bike) => bike.battery < 20).length;
  const selectedRental = rentals.find((rental) => rental.id === selectedId) ?? null;
  const selectedBike = selectedRental ? bikes.find((bike) => bike.id === selectedRental.bikeId) : null;

  function endRental(id) {
    const rental = rentals.find((item) => item.id === id);
    setRentals(rentals.filter((item) => item.id !== id));
    setRevenue(revenue + rental.price);
    setMessage(`Výpůjčka ${id} ukončena, tržba +${rental.price} Kč`);
  }

  function addRental() {
    setRentals([{ ...walkInRental, id: `V-${nextNumber}` }, ...rentals]);
    setNextNumber(nextNumber + 1);
  }

  return (
    <div className="flex min-h-screen bg-surface text-slate-900">
      <Sidebar active={page} onSelect={setPage} />
      <main className="flex-1 space-y-6 p-8">
        <h1 className="text-2xl font-semibold">{page}</h1>
        <StatCards rentedCount={rentals.length} revenue={revenue} lowBatteryCount={lowBatteryCount} />
        <RentalList rentals={rentals} onEnd={endRental} onDetail={setSelectedId} onAdd={addRental} />
      </main>
      <BikePanel rental={selectedRental} bike={selectedBike} onClose={() => setSelectedId(null)} />
      <div className="fixed right-6 bottom-6">
        <Toast message={message} onClose={() => setMessage(null)} />
      </div>
    </div>
  );
}

import { useState } from 'react';
import { AnimatePresence, motion } from 'motion/react';
import { Button } from './ui/button';

const filters = [
  { value: 'all', label: 'Vše' },
  { value: 'active', label: 'Aktivní' },
  { value: 'late', label: 'Po termínu' },
];

export function RentalList({ rentals, onEnd, onDetail, onAdd }) {
  const [filter, setFilter] = useState('all');
  const visibleRentals = filter === 'all' ? rentals : rentals.filter((rental) => rental.status === filter);

  return (
    <section aria-labelledby="rentals-heading" className="rounded-2xl border border-slate-200 bg-white p-5">
      <div className="flex items-center justify-between gap-4">
        <h2 id="rentals-heading" className="text-lg font-semibold">Výpůjčky</h2>
        <Button onClick={onAdd}>Nová výpůjčka</Button>
      </div>

      <div role="group" aria-label="Filtr výpůjček" className="mt-4 inline-flex rounded-lg bg-slate-100 p-1">
        {filters.map((option) => (
          <button
            key={option.value}
            aria-pressed={filter === option.value}
            onClick={() => setFilter(option.value)}
            className="relative rounded-md px-3 py-1.5 text-sm font-medium text-slate-700"
          >
            {filter === option.value && (
              <motion.span
                layoutId="filter-indicator"
                data-testid="filter-indicator"
                className="absolute inset-0 rounded-md bg-white shadow-sm"
              />
            )}
            <span className="relative">{option.label}</span>
          </button>
        ))}
      </div>

      <ul className="relative mt-4">
        <AnimatePresence initial={false} mode="popLayout">
          {visibleRentals.map((rental) => (
            <motion.li
              key={rental.id}
              layout
              initial={{ opacity: 0, y: -12 }}
              animate={{ opacity: 1, y: 0 }}
              exit={{ opacity: 0, x: 40 }}
              transition={{ duration: 0.3 }}

                  {rental.id} · kolo {rental.bikeId} · od {rental.from}
                </p>
              </div>
              <div className="flex gap-2">
                <Button variant="ghost" size="sm" onClick={() => onDetail(rental.id)}>

                  Ukončit

  );

import { useEffect } from 'react';
import { animate, motion, useMotionValue, useTransform } from 'motion/react';
import { formatCzk } from '../lib/format';

export function RevenueCounter({ value }) {
  const count = useMotionValue(0);
  const text = useTransform(() => formatCzk(Math.round(count.get())));

  useEffect(() => {
    const controls = animate(count, value, { duration: 0.8, ease: 'easeOut' });
    return () => controls.stop();
  }, [count, value]);

  return <motion.span>{text}</motion.span>;
}

import { AnimatePresence, motion } from 'motion/react';

const toastClasses =
  'flex w-80 items-center justify-between gap-4 rounded-xl bg-slate-900 px-4 py-3 text-sm text-white shadow-lg';

export function Toast({ message, onClose }) {
  return (
    <AnimatePresence>
      {message && (
        <motion.div key={message} role="status" className={toastClasses}
          initial={{ opacity: 0, y: 16 }}
          animate={{ opacity: 1, y: 0 }}
          exit={{ opacity: 0, y: 16 }}
          drag="x"
          dragConstraints={{ left: 0, right: 0 }}
          onDragEnd={(event, info) => {
            if (Math.abs(info.offset.x) > 100) onClose();
          }}
        >
          <p>{message}</p>
          <button onClick={onClose}>Zavřít</button>
        </motion.div>
      )}
    </AnimatePresence>
  );
}
