# --description--

Když dispečer ukončí výpůjčku, tržba se zvýší — ale číslo prostě přeskočí a změnu snadno
přehlédneš. Necháš ho dopočítat. Kdyby ses mezihodnoty snažil držet v `useState`, komponenta
by se překreslila v každém snímku. Motion na to má [[motion value]]: hodnotu, která se mění
mimo React, a `motion` prvek, který ji umí rovnou vypsat.

**Úkol:** Vytvoř `components/RevenueCounter.jsx` s komponentou `RevenueCounter({ value })`:

1. `const count = useMotionValue(0)` — hodnota, ze které se počítá.
2. `const text = useTransform(() => formatCzk(Math.round(count.get())))` — odvozená hodnota,
   která se přepočítá vždy, když se `count` změní.
3. V `useEffect` se závislostí na `value` spusť `animate(count, value, { duration: 0.8 })`
   a v úklidu animaci zastav (`controls.stop()`).
4. Vrať `<motion.span>{text}</motion.span>`.

Pak v `StatCards.jsx` zobraz v kartě tržby `<RevenueCounter value={revenue} />` místo
přímého formátování. Všechno kromě `formatCzk` se importuje z `motion/react`.

Stejný vzor pro procenta nabití:

```jsx
const level = useMotionValue(0);
const label = useTransform(() => `${Math.round(level.get())} %`);

useEffect(() => {
  const controls = animate(level, battery, { duration: 1 });
  return () => controls.stop();
}, [level, battery]);
```

# --explain--

Proč se počítadlo tržby píše přes `useMotionValue` a ne tak, že by se mezihodnoty ukládaly do `useState`?

## --model--

Hodnota v `useState` by při každé změně překreslila komponentu, tedy zhruba šedesátkrát za vteřinu po dobu animace. Motion value se mění mimo React: `motion.span` si ji sám vypíše do DOM, takže komponenta se překreslí jen jednou, když přijde nová tržba. Ušetří to práci prohlížeči a nerozbije to ostatní stav, který by se při překreslení počítal znovu.

## --checklist--

- Změna `useState` překreslí komponentu.
- Animace mění hodnotu v každém snímku, takže by se překreslovalo desítkykrát za vteřinu.
- Motion value se mění mimo React render.
- `motion` prvek vypíše motion value přímo do DOM.

import { useState } from 'react';
import { BikePanel } from './components/BikePanel';
import { RentalList } from './components/RentalList';
import { Sidebar } from './components/Sidebar';
import { StatCards } from './components/StatCards';
import { Toast } from './components/Toast';
import { bikes, initialRentals, revenueBeforeToday, walkInRental } from './data';
import './styles.css';

export default function App() {
  const [page, setPage] = useState('Přehled');
  const [rentals, setRentals] = useState(initialRentals);
  const [revenue, setRevenue] = useState(revenueBeforeToday);
  const [selectedId, setSelectedId] = useState(null);
  const [message, setMessage] = useState(null);
  const [nextNumber, setNextNumber] = useState(1045);

  const lowBatteryCount = bikes.filter((bike) => bike.battery < 20).length;
  const selectedRental = rentals.find((rental) => rental.id === selectedId) ?? null;
  const selectedBike = selectedRental ? bikes.find((bike) => bike.id === selectedRental.bikeId) : null;

  function endRental(id) {
    const rental = rentals.find((item) => item.id === id);
    setRentals(rentals.filter((item) => item.id !== id));
    setRevenue(revenue + rental.price);
    setMessage(`Výpůjčka ${id} ukončena, tržba +${rental.price} Kč`);
  }

  function addRental() {
    setRentals([{ ...walkInRental, id: `V-${nextNumber}` }, ...rentals]);
    setNextNumber(nextNumber + 1);
  }

  return (
    <div className="flex min-h-screen bg-surface text-slate-900">
      <Sidebar active={page} onSelect={setPage} />
      <main className="flex-1 space-y-6 p-8">
        <h1 className="text-2xl font-semibold">{page}</h1>
        <StatCards rentedCount={rentals.length} revenue={revenue} lowBatteryCount={lowBatteryCount} />
        <RentalList rentals={rentals} onEnd={endRental} onDetail={setSelectedId} onAdd={addRental} />
      </main>
      <BikePanel rental={selectedRental} bike={selectedBike} onClose={() => setSelectedId(null)} />
      <div className="fixed right-6 bottom-6">
        <Toast message={message} onClose={() => setMessage(null)} />
      </div>
    </div>
  );
}

## --file-- components/RevenueCounter.jsx

```jsx
import { useEffect } from 'react';
import { animate, motion, useMotionValue, useTransform } from 'motion/react';
import { formatCzk } from '../lib/format';

export function RevenueCounter({ value }) {
  const count = useMotionValue(0);
  const text = useTransform(() => formatCzk(Math.round(count.get())));

  useEffect(() => {
    const controls = animate(count, value, { duration: 0.8, ease: 'easeOut' });
    return () => controls.stop();
  }, [count, value]);

  return <motion.span>{text}</motion.span>;
}
```
