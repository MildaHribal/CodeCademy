# --description--

**Úkol:** Záložky fungují, ale nepoznáš, která je aktivní. Primitivum dává každému spouštěči
atribut `data-state` s hodnotou `active`, nebo `inactive` — nastyluj podle něj aktivní záložku
variantou `data-[state=active]:`: pozadí `bg-znacka` a bílý text. Neaktivní ať mají `text-popisek`.

Žádný stav v komponentě k tomu nepotřebuješ. V DevTools si na spouštěči ten atribut najdi
a sleduj, jak se mění při přepínání.

# --hints--

Aktivní záložka má fialové pozadí a bílý text.

```js
const aktivni = document.querySelector('[role="tab"][data-state="active"]');
const styl = getComputedStyle(aktivni);
await helpers.waitFor(() => styl.backgroundColor === 'rgb(124, 58, 237)', 3000).catch(() => {});
assert.equal(styl.backgroundColor, 'rgb(124, 58, 237)', 'Aktivní záložka má mít pozadí bg-znacka');
assert.equal(styl.color, 'rgb(255, 255, 255)', 'Aktivní záložka má mít bílý text');
```

Neaktivní záložka pozadí nemá.

```js
const neaktivni = document.querySelector('[role="tab"][data-state="inactive"]');
const styl = getComputedStyle(neaktivni);
await helpers.waitFor(() => styl.backgroundColor === 'rgba(0, 0, 0, 0)', 3000).catch(() => {});
assert.equal(styl.backgroundColor, 'rgba(0, 0, 0, 0)', 'Neaktivní záložka nemá mít pozadí');
assert.notEqual(styl.color, 'rgb(255, 255, 255)', 'Neaktivní záložka nemá mít bílý text');
```

Zvýraznění se přesune spolu s přepnutím.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[1]);
await helpers.flush();
await helpers.waitFor(() => getComputedStyle(zalozky[1]).backgroundColor === 'rgb(124, 58, 237)', 3000).catch(() => {});
assert.equal(getComputedStyle(zalozky[1]).backgroundColor, 'rgb(124, 58, 237)', 'Po přepnutí má být zvýrazněná druhá záložka');
assert.equal(getComputedStyle(zalozky[0]).backgroundColor, 'rgba(0, 0, 0, 0)', 'První záložka se má vrátit do neaktivního vzhledu');
```

# --help--

## --tip--

Stav primitiva se veze v atributu `data-state` — a na atributy má Tailwind variantu, kterou znáš z lekce o třídách v komponentách.

## --tip--

Varianta se píše před utilitu, na kterou má platit. Pro dvě utility ji musíš napsat dvakrát.

## --tip--

Na jiných datech: `data-[state=open]:rotate-180` otočí šipku u rozbaleného panelu.

```tsx
import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
```
