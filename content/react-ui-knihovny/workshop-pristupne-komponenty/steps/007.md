title: Zvýrazněná položka menu

# --description--

**Úkol:** Projdi menu šipkami — položka pod kurzorem se nijak neliší. Primitivum na ni dává atribut
`data-highlighted` (bez hodnoty); nastyluj podle něj obě položky: obyčejnou světle fialovým pozadím
`bg-znacka-svetla`, nebezpečnou červeným pozadím a bílým textem. K oběma přidej
`data-[highlighted]:outline-none`, ať se nepere obrys prohlížeče s pozadím.

Varianta bez hodnoty se píše jen s názvem atributu v hranatých závorkách. Zvýraznění reaguje
na myš i na šipky, takže obojí vypadá stejně.

# --hints--

Položka pod kurzorem šipek má světle fialové pozadí.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
await helpers.click(document.querySelector('[data-testid="zarizeni-pixel"] button[aria-label]'));
await helpers.flush();
const menu = document.querySelector('[role="menu"]');
const polozky = [...document.querySelectorAll('[role="menuitem"]')];
assert.equal(getComputedStyle(polozky[0]).backgroundColor, 'rgba(0, 0, 0, 0)', 'Nezvýrazněná položka nemá mít pozadí');
await helpers.press(menu, 'ArrowDown');
await helpers.flush();
await helpers.waitFor(() => getComputedStyle(polozky[0]).backgroundColor === 'rgb(237, 233, 254)', 3000).catch(() => {});
assert.equal(polozky[0].hasAttribute('data-highlighted'), true, 'Po šipce dolů má mít první položka data-highlighted');
assert.equal(getComputedStyle(polozky[0]).backgroundColor, 'rgb(237, 233, 254)', 'Zvýrazněná položka má mít pozadí bg-znacka-svetla');
```

Nebezpečná položka se zvýrazní červeně a bílým textem.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
await helpers.click(document.querySelector('[data-testid="zarizeni-pixel"] button[aria-label]'));
await helpers.flush();
const menu = document.querySelector('[role="menu"]');
const polozky = [...document.querySelectorAll('[role="menuitem"]')];
await helpers.press(menu, 'ArrowDown');
await helpers.flush();
await helpers.press(document.activeElement, 'ArrowDown');
await helpers.flush();
assert.equal(polozky[1].hasAttribute('data-highlighted'), true, 'Po druhé šipce dolů má mít data-highlighted nebezpečná položka');
await helpers.waitFor(() => getComputedStyle(polozky[1]).backgroundColor === 'rgb(190, 18, 60)', 3000).catch(() => {});
assert.equal(getComputedStyle(polozky[1]).backgroundColor, 'rgb(190, 18, 60)', 'Zvýrazněná nebezpečná položka má mít červené pozadí');
assert.equal(getComputedStyle(polozky[1]).color, 'rgb(255, 255, 255)', 'Zvýrazněná nebezpečná položka má mít bílý text');
```

# --help--

## --tip--

Tenhle stav nese atribut bez hodnoty — varianta se proto píše kratší než u `data-state`.

## --tip--

Obě položky potřebují svoje třídy zvlášť; společné je jen zrušení obrysu.

## --tip--

Na jiných datech: `data-[disabled]:opacity-50` zbledne vypnutou položku.

```tsx
import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
```
