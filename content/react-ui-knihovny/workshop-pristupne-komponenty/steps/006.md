# --description--

**Úkol:** Napoj obě položky na stav. Položka `Skrýt z historie` přidá id zařízení do stavu `skryta`
(řádek pak zbledne — třída na to v seedu čeká), položka `Odhlásit zařízení` odstraní zařízení
ze stavu `zarizeni`.

Akce se u položky menu nepíše do `onClick`, ale do **`onSelect`**: primitivum tak pokryje i výběr
klávesou Enter nebo mezerníkem a samo pak menu zavře.

Stav měň funkcí, která dostane předchozí hodnotu — v obou případech vyrábíš nové pole.

# --hints--

Po výběru „Odhlásit zařízení" zmizí řádek ze seznamu.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];

await helpers.flush();

assert.equal(document.querySelectorAll('[data-testid^="zarizeni-"]').length, 2, 'V seznamu mají zbýt dvě zařízení');
```

Po výběru „Skrýt z historie" řádek zbledne, ale zůstane.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
```

Výběr položky klávesnicí funguje stejně jako myší a akce visí na `onSelect`.

```js
assert.match(files['App.tsx'], /onSelect=/, 'Akce položky patří do onSelect, ne do onClick');
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
const spoustec = document.querySelector('[data-testid="zarizeni-televize"] button[aria-label]');
await helpers.click(spoustec);
await helpers.flush();

assert.ok(menu, 'Po kliknutí na spouštěč má být v dokumentu prvek s rolí menu');

await helpers.flush();
await helpers.press(document.activeElement, 'ArrowDown');
await helpers.flush();

await helpers.flush();
assert.equal(document.querySelector('[data-testid="zarizeni-televize"]'), null, 'Druhá položka vybraná klávesnicí má zařízení odhlásit');
assert.equal(document.querySelectorAll('[data-testid^="zarizeni-"]').length, 2, 'V seznamu mají zbýt dvě zařízení');
```

# --help--

## --tip--

Položka menu se dá vybrat myší i klávesnicí — proto má vlastní událost místo `onClick`.

## --tip--

Obě obsluhy pracují se stavem, který už v komponentě je (`zarizeni` a `skryta`). Jedno pole filtruješ, do druhého přidáváš.

## --tip--

Na jiných datech: `onSelect={() => setOblibene((stav) => [...stav, kniha.id])}` přidá knihu mezi oblíbené.

# --explain--

Proč je rozbalovací menu z primitiva lepší než seznam `<button>` prvků, který si sám schováš a ukážeš?

## --model--

Menu není jen vizuální seznam: má roli `menu` a položky roli `menuitem`, takže ho čtečka ohlásí jako menu a řekne, kolik má položek. Šipky po něm chodí, Escape ho zavírá, Tab z něj vyskočí, kliknutí mimo ho zavře a fokus se vrátí na spouštěč. To všechno bych u vlastních tlačítek musel napsat a otestovat sám, včetně `aria-expanded` na spouštěči.

## --checklist--

- Primitivum dá menu a položkám správné role pro čtečku.
- Ovládání šipkami, Escapem a návrat fokusu řeší knihovna.
- Spouštěč sám hlásí `aria-expanded`.
- Akce se píše do `onSelect`, aby platila pro myš i klávesnici.

```tsx
import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
```
