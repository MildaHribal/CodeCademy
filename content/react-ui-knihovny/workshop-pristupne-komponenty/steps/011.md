# --description--

**Úkol:** V záložce Profil přibude nad seznamem údajů výběr jazyka aplikace. Nativní `<select>` by
stačil, ale návrh chce stejný vzhled jako zbytek aplikace, takže použijeme primitivum `Select`.
Má o dva díly víc než menu: `Select.Value` ukazuje ve spouštěči vybranou hodnotu a `Select.Viewport`
je posuvná oblast se seznamem.

1. Přidej stav `jazyk` s výchozí hodnotou `'cs'` a naimportuj `jazyky` ze souboru `data.ts`.
2. Nad `<dl>` s údaji vlož nadpis „Jazyk aplikace" a pod něj `Select.Root` řízený tím stavem.
3. Volby vygeneruj z pole `jazyky` (`kod` do `value`, `nazev` do `Select.ItemText`).

Skladba dílů: `Root` → `Trigger` (uvnitř `Value`) → `Portal` → `Content` → `Viewport` → `Item`
(uvnitř `ItemText`). Spouštěč potřebuje jméno pro čtečku „Jazyk aplikace" (bez něj je to pro ni jen tlačítko s textem)
a testovací identifikátor `vyber-jazyka`. Zvýraznění položek nastyluj stejně jako v menu.

# --hints--

Ve výběru je vidět aktuální jazyk a spouštěč má jméno pro čtečku.

```js
const spoustec = document.querySelector('[data-testid="vyber-jazyka"]');
assert.ok(spoustec, 'V záložce Profil má být spouštěč výběru jazyka');
assert.equal(spoustec.getAttribute('aria-label'), 'Jazyk aplikace', 'Spouštěč má mít aria-label „Jazyk aplikace"');
assert.match(spoustec.textContent, /Čeština/, 'Ve spouštěči má být vidět vybraný jazyk');
```

Po otevření je v dokumentu seznam se třemi jazyky.

```js
const spoustec = document.querySelector('[data-testid="vyber-jazyka"]');
await helpers.click(spoustec);
await helpers.flush();
assert.ok(document.querySelector('[role="listbox"]'), 'Po kliknutí má být v dokumentu prvek s rolí listbox');
const volby = [...document.querySelectorAll('[role="option"]')];
assert.equal(volby.length, 3, 'Na výběr mají být tři jazyky');
assert.deepEqual(
  volby.map((el) => el.textContent.trim()),
  ['Čeština', 'Slovenčina', 'English'],
  'Jazyky mají být Čeština, Slovenčina a English',
);
```

Výběr jiného jazyka klávesou Enter se propíše do spouštěče.

```js
const spoustec = document.querySelector('[data-testid="vyber-jazyka"]');
await helpers.click(spoustec);
await helpers.flush();
const anglictina = [...document.querySelectorAll('[role="option"]')].find((el) => el.textContent.trim() === 'English');
assert.ok(anglictina, 'V seznamu má být volba English');
anglictina.focus();
await helpers.press(anglictina, 'Enter');
await helpers.flush();
await helpers.waitFor(() => !document.querySelector('[role="listbox"]'), 2000).catch(() => {});
assert.match(document.querySelector('[data-testid="vyber-jazyka"]').textContent, /English/, 'Po výběru má být ve spouštěči English');
```

# --help--

## --tip--

Skladba je delší než u menu, ale princip stejný: kořen drží hodnotu, spouštěč ji ukazuje, obsah je v portálu.

## --tip--

Řízená hodnota se u výběru nejmenuje `open`, ale `value`, a změnu hlásí `onValueChange`.

## --tip--

Volby vyrob z pole stejně, jako vyrábíš řádky zařízení — každá potřebuje `key` a `value`.

# --explain--

Nativní `<select>` umí klávesnici, čtečku i výběr na mobilu zadarmo. Proč ho v týmu přesto někdy vyměníte za primitivum `Select`?

## --model--

Protože nativní rozbalený seznam nastyluje operační systém, ne my: nejdou v něm ikony, dvouřádkové položky ani barvy značky a na každé platformě vypadá jinak. Primitivum vykreslí obyčejné prvky, které nastylujeme jako zbytek aplikace, a role, šipky i Escape nám dodá. Daň je vyšší: víc kódu, víc DOM a na mobilu přijdeme o nativní kolečko výběru — takže to má cenu jen tehdy, když návrh vzhled opravdu potřebuje.

## --checklist--

- Nativní `<select>` má rozbalený seznam od systému a nejde nastylovat.
- Primitivum dá vzhled do našich rukou a přístupnost si drží samo.
- Platí se za to větším kódem a ztrátou nativního ovládání na mobilu.
- Když návrh nic zvláštního nechce, zůstaň u `<select>`.

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',

      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
