# --description--

**Úkol:** V seedu je `components/ui/button.tsx` — přesně ta komponenta, kterou jsi psal v minulém
workshopu. Použij ji na dvě tlačítka stránky: „Uložit změny" v hlavičce necháš ve výchozím vzhledu
a „Zrušit předplatné" udělej malé a nebezpečné.

Varianty se jmenují stejně jako minule (`variant`, `size`), do souboru se dívat nemusíš — a když
si nebudeš jistý, mrkni do něj, je tvůj.

Po tomhle kroku má stránka konečně vzhled značky. Zbytek workshopu je o chování: záložky, menu,
dialogy a přepínače nad primitivy Radixu.

# --hints--

Tlačítko „Uložit změny" je vykreslené komponentou `Button` ve výchozí variantě.

```js
const tlacitko = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Uložit změny');
assert.ok(tlacitko, 'V hlavičce má být tlačítko „Uložit změny"');
const styl = getComputedStyle(tlacitko);
await helpers.waitFor(() => styl.height === '40px', 3000).catch(() => {});
assert.equal(styl.height, '40px', 'Výchozí velikost tlačítka je 40 px');
assert.equal(styl.backgroundColor, 'rgb(124, 58, 237)', 'Výchozí varianta má mít pozadí bg-znacka');
```

Tlačítko „Zrušit předplatné" je malé a v nebezpečné variantě.

```js
const tlacitko = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zrušit předplatné');
assert.ok(tlacitko, 'V sekci Předplatné má být tlačítko „Zrušit předplatné"');
const styl = getComputedStyle(tlacitko);
await helpers.waitFor(() => styl.height === '32px', 3000).catch(() => {});
assert.equal(styl.height, '32px', 'Tlačítko má být malé (size sm)');
assert.equal(styl.backgroundColor, 'rgb(190, 18, 60)', 'Tlačítko má mít pozadí varianty nebezpeci');
```

## --file-- components/ui/button.tsx

```tsx
import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
```
