# --description--

**Úkol:** U zařízení svítí strojové datum `2026-09-15T21:40:00`. Ukaž ho česky, ve tvaru
`15. září v 21:40`: den číslem, měsíc slovem, hodina a minuta dvojciferně.

Formátovač si vyrob jednou nad komponentou, ne při každém vykreslení. Tohle už znáš z JavaScriptu,
tak bez nápovědy.

# --hints--

U zařízení je datum českým zápisem, ne strojovým.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
const radek = document.querySelector('[data-testid="zarizeni-pixel"]').textContent.replace(/\s+/g, ' ');
assert.match(radek, /15\. září/, 'U Pixelu má být datum „15. září"');
assert.match(radek, /21:40/, 'U Pixelu má být čas 21:40');
assert.doesNotMatch(radek, /2026-09-15/, 'Strojový zápis data se už zobrazovat nemá');
```

Formát platí pro všechna zařízení.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
const macbook = document.querySelector('[data-testid="zarizeni-macbook"]').textContent.replace(/\s+/g, ' ');
assert.match(macbook, /14\. září/, 'U MacBooku má být datum „14. září"');
assert.match(macbook, /8:05/, 'U MacBooku má být čas 8:05');
```

Datum formátuje `Intl.DateTimeFormat`, ne ruční skládání řetězce.

```js
const zdroj = helpers.stripComments(files['App.tsx'], 'js');
assert.match(zdroj, /Intl\.DateTimeFormat/, 'Na formát data použij Intl.DateTimeFormat');
assert.match(zdroj, /['"]cs-CZ['"]/, "Formátovač má dostat české nastavení 'cs-CZ'");
```
