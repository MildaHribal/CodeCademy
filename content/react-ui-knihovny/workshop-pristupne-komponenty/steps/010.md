# --description--

**Úkol:** Do záložky Předplatné přidej pod oddělovací čáru sekci „Smazat účet" (odstavec s popisem
a tlačítko) a nad ni pověs **`AlertDialog`** — primitivum pro nevratné akce. Skládá se stejně jako
`Dialog`, jen má místo `Close` dvojici `Cancel` (zpět) a `Action` (potvrzení) a **nezavře ho klik
mimo**.

Spouštěč i obě tlačítka udělej přes `asChild` nad svým `Button`em, ať vypadají jako zbytek stránky.
Obsahu dialogu dej testovací identifikátor `dialog-smazani`, testy podle něj hledají.

Tohle je zatím poslední velký kus chování. Máš hotové záložky, menu i oba druhy dialogů — dobré
místo na pauzu.

# --hints--

Tlačítko „Smazat účet" otevře dialog s rolí `alertdialog` a s názvem.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[1]);
await helpers.flush();
const spoustec = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Smazat účet');
assert.ok(spoustec, 'V záložce Předplatné má být tlačítko „Smazat účet"');
await helpers.click(spoustec);
await helpers.flush();
const dialog = document.querySelector('[data-testid="dialog-smazani"]');
assert.ok(dialog, 'Po kliknutí má být dialog v dokumentu');
assert.equal(dialog.getAttribute('role'), 'alertdialog', 'Nevratná akce má mít roli alertdialog');
const nazev = document.getElementById(dialog.getAttribute('aria-labelledby'));
assert.ok(nazev && nazev.textContent.trim().length > 0, 'AlertDialog má mít název přes aria-labelledby');
```

Klik mimo dialog ho nezavře, tlačítko „Zpět" ano.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[1]);
await helpers.flush();
const spoustec = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Smazat účet');

await helpers.flush();
assert.ok(document.querySelector('[data-testid="dialog-smazani"]'), 'Klik mimo nesmí nevratný dialog zavřít');
```

Dialog má dvě tlačítka a fokus je po otevření uvnitř.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[1]);
await helpers.flush();
const spoustec = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Smazat účet');
await helpers.click(spoustec);
await helpers.flush();
const dialog = document.querySelector('[data-testid="dialog-smazani"]');
const tlacitka = [...dialog.querySelectorAll('button')].map((el) => el.textContent.trim());
assert.deepEqual(tlacitka, ['Zpět', 'Smazat účet'], 'Dialog má mít tlačítka Zpět a Smazat účet');
await helpers.waitFor(() => dialog.contains(document.activeElement), 2000).catch(() => {});
assert.ok(dialog.contains(document.activeElement), 'Po otevření má být fokus uvnitř dialogu');
const zpet = [...dialog.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zpět');
await helpers.click(zpet);
await helpers.flush();
await helpers.waitFor(() => document.activeElement === spoustec, 2000).catch(() => {});
assert.equal(document.activeElement, spoustec, 'Po zavření se má fokus vrátit na tlačítko „Smazat účet"');
```

# --help--

## --tip--

Primitivum pro nevratné akce se jmenuje skoro stejně jako obyčejný dialog a bere se ze stejného balíčku.

## --tip--

Díly se jmenují `Trigger`, `Portal`, `Overlay`, `Content`, `Title`, `Description`, a místo zavírání má dvojici tlačítek s vlastními jmény.

## --tip--

Na jiných datech: u „Smazat fotku" by `Cancel` byl „Nechat" a `Action` „Smazat" — a `Action` je to jediné tlačítko, které akci opravdu provede.

```tsx
import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
```
