# --description--

## Hlášení

Tester prošel nastavení se čtečkou obrazovky a píše: „Když otevřu zrušení předplatného, čtečka
ohlásí jen *dialog* a pak rovnou text o zaplaceném období. Nevím, co ten dialog je, dokud ho
nepřečtu celý. U dialogu o smazání účtu to přitom funguje a ohlásí se jeho název."

Vizuálně je všechno v pořádku: nadpis „Zrušit předplatné" je v dialogu vidět.

## Úkol

Oprav `components/zruseni-predplatneho.tsx` tak, aby dialog měl přístupný název. Změň co nejmenší
kus kódu — vzhled nadpisu musí zůstat stejný.

# --hints--

Otevřený dialog odkazuje atributem `aria-labelledby` na svůj nadpis.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[1]);
await helpers.flush();
const zrusit = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zrušit předplatné');
await helpers.click(zrusit);
await helpers.flush();
const dialog = document.querySelector('[data-testid="dialog-ruseni"]');
const idNazvu = dialog.getAttribute('aria-labelledby');
assert.ok(idNazvu, 'Dialog má mít aria-labelledby — tím se čtečce představí');
const nadpis = document.getElementById(idNazvu);
assert.ok(nadpis, 'aria-labelledby má odkazovat na prvek, který v dokumentu existuje');
assert.equal(nadpis.textContent.trim(), 'Zrušit předplatné', 'Název dialogu má být „Zrušit předplatné"');
```

Nadpis vypadá pořád stejně a popis i tlačítka fungují dál.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[1]);
await helpers.flush();
const zrusit = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zrušit předplatné');
await helpers.click(zrusit);
await helpers.flush();
const dialog = document.querySelector('[data-testid="dialog-ruseni"]');
const nadpis = document.getElementById(dialog.getAttribute('aria-labelledby'));
assert.ok(nadpis, 'Dialog má mít aria-labelledby mířící na svůj nadpis');
const styl = getComputedStyle(nadpis);
await helpers.waitFor(() => styl.fontSize === '18px', 3000).catch(() => {});
assert.equal(styl.fontSize, '18px', 'Nadpis má zůstat velký text-lg, tedy 18 px');
assert.equal(styl.fontWeight, '600', 'Nadpis má zůstat polotučný (font-semibold)');
const popis = document.getElementById(dialog.getAttribute('aria-describedby'));
assert.ok(popis && popis.textContent.includes('zaplaceného období'), 'Popis dialogu má zůstat propojený přes aria-describedby');
const nechat = [...dialog.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Nechat předplatné');
await helpers.click(nechat);
await helpers.flush();
assert.equal(document.querySelector('[data-testid="dialog-ruseni"]'), null, 'Tlačítko „Nechat předplatné" má dialog pořád zavírat');
```

## --tip--

Porovnej dialog o zrušení s tím o smazání účtu: jeden díl primitiva v něm chybí a kolegyně ho nahradila obyčejným odstavcem.

## --tip--

Ten díl má stejné props jako každý jiný prvek, takže si vezme i třídy, které nadpis má teď.

import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
