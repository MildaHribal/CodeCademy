# --description--

**Úkol:** Nad výběr jazyka přidej přepínač „Přehrávat explicitní obsah": stav `explicitni`
(výchozí `false`), `Label.Root` s `htmlFor` a `Switch.Root` se `Switch.Thumb` uvnitř.

Vzhled: kolejnice `h-6 w-11 rounded-full bg-tlumena p-0.5 transition-colors`, ve stavu `checked`
pozadí značky; puntík `block size-5 rounded-full bg-white transition-transform`, ve stavu `checked`
posunutý o `translate-x-5`. Obojí navěs na variantu `data-[state=checked]:`.

Přepínač si pojmenuj `explicitni` — stejnou hodnotu potřebuje jeho `id` i `htmlFor` popisku,
a testovací identifikátor je `prepinac-explicitni`. Díky propojenému popisku přepne stav i klik
na text — a přesně ten text čtečka ohlásí jako jméno přepínače.

# --hints--

Přepínač má roli `switch`, jméno z popisku a je vypnutý.

```js
const prepinac = document.querySelector('[data-testid="prepinac-explicitni"]');
assert.ok(prepinac, 'V záložce Profil má být přepínač explicitního obsahu');
assert.equal(prepinac.getAttribute('role'), 'switch', 'Přepínač má mít roli switch');
assert.equal(prepinac.getAttribute('data-state'), 'unchecked', 'Na začátku má být přepínač vypnutý');
const popisek = document.querySelector('label[for="explicitni"]');
assert.ok(popisek, 'Přepínač má mít popisek propojený přes htmlFor');
assert.match(popisek.textContent, /explicitní obsah/i, 'Popisek má mluvit o explicitním obsahu');
```

Kliknutí na popisek přepínač zapne a obarví.

```js
const prepinac = document.querySelector('[data-testid="prepinac-explicitni"]');
const popisek = document.querySelector('label[for="explicitni"]');
await helpers.click(popisek);
await helpers.flush();
assert.equal(prepinac.getAttribute('data-state'), 'checked', 'Klik na popisek má přepínač zapnout');
await helpers.waitFor(() => getComputedStyle(prepinac).backgroundColor === 'rgb(124, 58, 237)', 3000).catch(() => {});
assert.equal(getComputedStyle(prepinac).backgroundColor, 'rgb(124, 58, 237)', 'Zapnutý přepínač má mít pozadí značky');
```

Puntík se po zapnutí posune doprava.

```js
const prepinac = document.querySelector('[data-testid="prepinac-explicitni"]');
const puntik = prepinac.firstElementChild;
assert.ok(puntik, 'Uvnitř přepínače má být puntík');
await helpers.waitFor(() => getComputedStyle(puntik).width === '20px', 3000).catch(() => {});
assert.equal(getComputedStyle(puntik).width, '20px', 'Puntík má být velký size-5, tedy 20 px');
const odsazeni = () => Math.round(puntik.getBoundingClientRect().left - prepinac.getBoundingClientRect().left);
const ustalene = async () => {
  const stav = await helpers.waitFor(async () => {
    const prvni = odsazeni();
    await helpers.wait(60);
    return odsazeni() === prvni ? { hodnota: prvni } : false;
  }, 3000);
  return stav.hodnota;
};
const predtim = await ustalene();
assert.ok(predtim <= 6, 'Vypnutý přepínač má mít puntík u levého okraje kolejnice — posun patří až do stavu checked');
await helpers.click(prepinac);
await helpers.flush();
assert.equal(prepinac.getAttribute('data-state'), 'checked', 'Klik na kolejnici má přepínač zapnout');
const potom = await ustalene();
assert.ok(potom - predtim >= 18, 'Zapnutý přepínač má puntík posunutý doprava o translate-x-5, tedy o 20 px');
```

# --help--

## --tip--

Přepínač je primitivum se dvěma díly: kolejnice a puntík uvnitř ní.

## --tip--

Popisek není jen text vedle — musí být propojený s přepínačem přes jeho `id`, jinak na něj nejde kliknout a čtečka jméno nenajde.

## --tip--

Stav se hlásí atributem `data-state` s hodnotami `checked` a `unchecked`; na obojí platí stejná varianta jako u záložek.

import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
