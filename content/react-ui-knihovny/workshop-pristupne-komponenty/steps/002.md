# --description--

**Úkol:** Tři sekce pod sebou nahraď záložkami z primitiva `Tabs` (`import { Tabs } from 'radix-ui'`).
Kostra je vždycky stejná: `Tabs.Root` s `defaultValue`, uvnitř `Tabs.List` se třemi `Tabs.Trigger`
a pak tři `Tabs.Content`. Každý spouštěč a obsah spojuje stejná hodnota `value`
(`profil`, `predplatne`, `zarizeni`), výchozí je profil.

Nadpisy `<h2>` uvnitř sekcí zruš — jejich práci teď dělají záložky.

Na jiných datech vypadá kostra takhle:

```tsx
<Tabs.Root defaultValue="dnes">
  <Tabs.List>
    <Tabs.Trigger value="dnes">Dnes</Tabs.Trigger>
    <Tabs.Trigger value="tyden">Týden</Tabs.Trigger>
  </Tabs.List>
  <Tabs.Content value="dnes">…</Tabs.Content>
  <Tabs.Content value="tyden">…</Tabs.Content>
</Tabs.Root>
```

Atributy `data-testid` na obsazích nech, testy podle nich hledají.

Radix nechává obálku každého panelu v DOM i zavřenou — jen jí přidá `hidden` a její obsah
nevykreslí. Proto se v testu ptáme na `[role="tabpanel"]:not([hidden])`, ne na počet panelů.

# --hints--

Stránka má tři záložky a jeden viditelný panel.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
assert.equal(zalozky.length, 3, 'Stránka má mít tři záložky (role tab)');
assert.deepEqual(
  zalozky.map((el) => el.textContent.trim()),
  ['Profil', 'Předplatné', 'Zařízení'],
  'Záložky mají být Profil, Předplatné a Zařízení',
);
const viditelne = document.querySelectorAll('[role="tabpanel"]:not([hidden])');
assert.equal(viditelne.length, 1, 'Viditelný (bez hidden) má být právě jeden panel');
```

Ve výchozím stavu je otevřený profil a obsah ostatních záložek se nevykresluje.

```js
assert.ok(document.body.textContent.includes('Karel Novák'), 'Ve výchozím stavu má být vidět obsah profilu');
const zarizeni = document.querySelector('[data-testid="sekce-zarizeni"]');
assert.ok(zarizeni, 'V dokumentu má být panel s data-testid="sekce-zarizeni"');
assert.equal(zarizeni.textContent.trim(), '', 'Obsah zavřené záložky se nemá vykreslovat (panel má zůstat prázdný)');
const aktivni = document.querySelector('[role="tab"][data-state="active"]');
assert.ok(aktivni, 'Právě jedna záložka má mít data-state="active"');
assert.equal(aktivni.textContent.trim(), 'Profil', 'Výchozí záložka má být Profil');
```

Kliknutí na záložku Zařízení přepne obsah.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
await helpers.click(zalozky[2]);
await helpers.flush();
const zarizeni = document.querySelector('[data-testid="sekce-zarizeni"]');
assert.ok(zarizeni && !zarizeni.hasAttribute('hidden'), 'Po kliknutí na Zařízení má být panel zařízení viditelný');
assert.equal(document.querySelectorAll('[data-testid^="zarizeni-"]').length, 3, 'V seznamu mají být tři zařízení');
const profil = document.querySelector('[data-testid="sekce-profil"]');
assert.equal(profil.textContent.trim(), '', 'Obsah profilu se už vykreslovat nemá');
```

# --help--

## --tip--

Primitivum je sada dílů, které se skládají do sebe — viz [Radix primitiva: chování bez vzhledu](see:react-ui-knihovny/shadcn-a-radix#radix-primitiva-chovani-bez-vzhledu).

## --tip--

Spouštěč a obsah k sobě nepatří podle pořadí, ale podle stejné hodnoty props `value`. Výchozí záložku určíš na kořeni.

## --tip--

Import je pojmenovaný: z balíčku `radix-ui` si vytáhneš celé primitivum a jeho díly pak píšeš s tečkou, stejně jako `Slot.Root` u tlačítka.

import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
