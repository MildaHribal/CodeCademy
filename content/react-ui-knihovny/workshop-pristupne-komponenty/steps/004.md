# --description--

**Úkol:** Zkus projít stránku klávesnicí: Tabem se dostaneš na aktivní záložku a šipkami mezi nimi
přepínáš — o tohle se primitivum stará samo. Co za tebe neudělá, je **jméno**: čtečka ohlásí jen
„seznam záložek" a uživatel netuší, čeho se týká. Dej `Tabs.List` popisek `Nastavení účtu`
atributem `aria-label`.

Tohle je přesně ta půlka práce, která zůstává na tobě: chování knihovna umí, význam ne.

# --hints--

Seznam záložek má přístupné jméno „Nastavení účtu".

```js
const seznam = document.querySelector('[role="tablist"]');
assert.ok(seznam, 'Na stránce má být seznam záložek');
assert.equal(seznam.getAttribute('aria-label'), 'Nastavení účtu', 'Seznam záložek má mít aria-label „Nastavení účtu"');
```

Šipka vpravo přepne na další záložku.

```js
const zalozky = [...document.querySelectorAll('[role="tab"]')];
zalozky[0].focus();
await helpers.press(zalozky[0], 'ArrowRight');
await helpers.flush();
assert.equal(zalozky[1].getAttribute('data-state'), 'active', 'Šipka vpravo má aktivovat druhou záložku');
assert.equal(document.activeElement, zalozky[1], 'Fokus má být na druhé záložce');
```

# --help--

## --tip--

Popisek pro čtečku se dává atributem, který znáš z přístupnosti — ne textem do stránky.

## --tip--

Patří na ten prvek, který roli `tablist` nese, tedy na seznam, ne na jednotlivé záložky.

import type { ComponentProps } from 'react';
import { cva, type VariantProps } from 'class-variance-authority';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-lg font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-znacka disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        plna: 'bg-znacka text-white hover:bg-znacka-tmava',
        ticha: 'bg-transparent text-slate-700 hover:bg-tlumena',
        nebezpeci: 'bg-nebezpeci text-white hover:bg-rose-800',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        md: 'h-10 px-4 text-sm',
      },
    },
    defaultVariants: { variant: 'plna', size: 'md' },
  },
);

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}
