title: Tlačítko se zapojenými variantami
---

# --description--

**Úkol:** Zapoj `buttonVariants` do komponenty `Button`. Komponenta má přijmout props `variant`
a poslat ji do `buttonVariants(...)`; výsledek jde spolu s `className` do `cn()`. Dlouhý seznam
tříd z původního zápisu tím z komponenty zmizí — bydlí teď v `buttonVariants`.

Typ props zatím doplň ručně: `variant` je nepovinná hodnota `'plna' | 'ticha'`.

Pak v `App.tsx` dej tlačítku „Zobrazit profil" tichou variantu. V náhledu se z druhého zeleného
tlačítka stane nenápadné.

# --hints--

Tlačítko „Zobrazit profil" má průhledné pozadí, ale pořád velikost tlačítka.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const profil = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zobrazit profil');
assert.ok(profil, 'V kartě Jany má být tlačítko „Zobrazit profil"');
const styl = getComputedStyle(profil);
await helpers.waitFor(() => styl.backgroundColor === 'rgba(0, 0, 0, 0)', 3000).catch(() => {});
assert.equal(styl.backgroundColor, 'rgba(0, 0, 0, 0)', 'Tichá varianta má mít průhledné pozadí');
assert.equal(styl.height, '40px', 'Tlačítko má zůstat vysoké 40 px — základní třídy platí pro obě varianty');
```

Tlačítko „Rezervovat" bez props vypadá dál jako plná varianta.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const rezervovat = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Rezervovat');
await helpers.waitFor(() => getComputedStyle(rezervovat).backgroundColor === 'rgb(15, 118, 110)', 3000).catch(() => {});
assert.equal(getComputedStyle(rezervovat).backgroundColor, 'rgb(15, 118, 110)', 'Bez props má platit výchozí varianta plna');
assert.equal(getComputedStyle(rezervovat).color, 'rgb(255, 255, 255)', 'Plná varianta má mít bílý text');
```

Třídy zvenku pořád fungují: `className` se skládá přes `cn()` až za variantami.

```js
const { cn } = await helpers.importFile('lib/utils.ts');
const { buttonVariants } = await helpers.importFile('components/ui/button.tsx');
assert.equal(
  cn(buttonVariants({ variant: 'plna' }), 'px-8').includes('px-8'),
  true,
  'Třída px-8 poslaná zvenku musí ve výsledku zůstat',
);
assert.equal(
  cn(buttonVariants({ variant: 'plna' }), 'px-8').includes('px-4'),
  false,
  'Třída px-4 z varianty musí při konfliktu ustoupit třídě zvenku',
);
```

# --help--

## --tip--

Komponenta teď skládá třídy ze dvou zdrojů: z variant a z toho, co přijde zvenku.

## --tip--

Funkce `buttonVariants` bere objekt se zvolenými variantami a vrací řetězec tříd. Ten řetězec patří do `cn()` jako první argument.

## --tip--

Props, které komponenta sama zpracovává, si vytáhni z destrukturalizace, ať se nedostanou do `...props` a odtud na prvek HTML — `<button variant="ticha">` by prohlížeč nepochopil.

## --file-- App.tsx

```tsx
import { useState, type FormEvent } from 'react';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button>Zrušit rezervaci</Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                {osoba.volneTerminy.length > 0 ? (
                  <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                ) : (
                  <Badge className="bg-tlumena text-popisek" title="Dnes už má plno">
                    Dnes obsazeno
                  </Badge>
                )}
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <span key={cas} className="rounded-lg border border-slate-200 px-3 py-1 text-sm">
                      {cas}
                    </span>
                  ))}
                </div>
              </div>

              <div className="mt-6 flex flex-wrap gap-3">
                <Button>Rezervovat</Button>
                <Button>Zobrazit profil</Button>
              </div>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <Button>Odeslat</Button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

## --file-- components/ui/button.tsx

```tsx
import type { ComponentProps } from 'react';
import { cn } from '../../lib/utils';

import { cva } from 'class-variance-authority';
export const buttonVariants = cva('inline-flex h-10 items-center justify-center rounded-lg px-4 text-sm font-medium transition-colors', {
  variants: {
    variant: {
      plna: 'bg-znacka text-white hover:bg-znacka-tmava',
      ticha: 'bg-transparent text-slate-700 hover:bg-slate-100',
    },
  },
  defaultVariants: { variant: 'plna' },
});

type ButtonProps = ComponentProps<'button'> & { variant?: 'plna' | 'ticha' };

export function Button({ className, variant, ...props }: ButtonProps) {
  return <button className={cn(buttonVariants({ variant }), className)} {...props} />;
}
```
