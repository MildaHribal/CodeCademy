# --description--

**Úkol:** V souboru `lib/utils.ts` napiš a vyexportuj funkci `cn`, která poskládá třídy z argumentů
a vyřeší konflikty tailwindových utilit. Tenhle soubor je první, co si do nového projektu zkopíruješ,
a bude ho používat každá komponenta v tomhle workshopu.

Tohle už umíš z lekce — teď to napiš zpaměti. Funkce musí zvládnout tři věci: spojit řetězce,
zahodit `false` a `undefined` a z dvou tříd pro stejnou vlastnost nechat tu poslední.

Stránka se po tomhle kroku nezmění, výsledek uvidíš až v testech. Hned v dalším kroku ji použije
první komponenta.

# --hints--

Soubor `lib/utils.ts` exportuje funkci `cn`, která spojí dvě třídy mezerou.

```js
const { cn } = await helpers.importFile('lib/utils.ts');
assert.equal(typeof cn, 'function', 'lib/utils.ts má exportovat funkci cn');
assert.equal(cn('rounded-lg', 'px-4'), 'rounded-lg px-4', "cn('rounded-lg', 'px-4') má vrátit 'rounded-lg px-4'");
```

`cn` zahodí `false` a `undefined` a z objektu vezme jen klíče s pravdivou hodnotou.

```js
const { cn } = await helpers.importFile('lib/utils.ts');
assert.equal(
  cn('rounded-lg', false, undefined, { 'p-2': true, 'p-6': false }),
  'rounded-lg p-2',
  "cn('rounded-lg', false, undefined, { 'p-2': true, 'p-6': false }) má vrátit 'rounded-lg p-2'",
);
```

Ze dvou utilit pro stejnou vlastnost nechá `cn` poslední.

```js
const { cn } = await helpers.importFile('lib/utils.ts');
assert.equal(cn('px-4 py-2', 'px-8'), 'py-2 px-8', "cn('px-4 py-2', 'px-8') má vrátit 'py-2 px-8' — px-4 musí zmizet");
assert.equal(cn('bg-znacka', 'bg-nebezpeci'), 'bg-nebezpeci', "cn('bg-znacka', 'bg-nebezpeci') má nechat jen poslední pozadí");
```

# --help--

## --tip--

Jde o pomocníka ze dvou knihoven, který jsi viděl v lekci [`cn()`: clsx a tailwind-merge v jednom](see:react-ui-knihovny/tailwind-v-reactu#cn-clsx-a-tailwind-merge-v-jednom).

## --tip--

Jedna knihovna umí podmínky a objekty, druhá konflikty utilit. Pořadí volání není jedno: nejdřív se z argumentů musí stát jeden řetězec.

## --tip--

Funkce bere libovolný počet argumentů, takže má parametr s třemi tečkami — stejně jako `function soucet(...cisla)` z lekcí o funkcích.

## --file-- lib/utils.ts

```ts
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```
