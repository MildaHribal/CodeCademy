# --description--

**Úkol:** Cena se vypisuje jako `Cena od 1490 Kč`. Naformátuj ji tak, jak ji Čech čeká: s mezerou
mezi tisíci a s korunou, tedy `Cena od 1 490 Kč`. Formátovač si vyrob **jednou** mimo komponentu,
ne při každém vykreslení.

Tohle už umíš z JavaScriptu, tak jen bez nápovědy — a bez ručního skládání řetězce z `replace`.

# --hints--

Ceny se vypisují s mezerou mezi tisíci a s korunou.

```js
const tereza = document.querySelector('[data-testid="karta-tereza"]').textContent.replace(/\s+/g, ' ');
assert.match(tereza, /Cena od 1 490 Kč/, 'U Terezy má být „Cena od 1 490 Kč"');
assert.doesNotMatch(tereza, /1490/, 'Cena už nemá být slepená jako 1490');
```

Ceny pod tisíc zůstanou beze změny a měna je u každé.

```js
const jana = document.querySelector('[data-testid="karta-jana"]').textContent.replace(/\s+/g, ' ');
assert.match(jana, /Cena od 890 Kč/, 'U Jany má být „Cena od 890 Kč"');
const marek = document.querySelector('[data-testid="karta-marek"]').textContent.replace(/\s+/g, ' ');
assert.match(marek, /Cena od 590 Kč/, 'U Marka má být „Cena od 590 Kč"');
```

Formátování dělá formátovač čísel, ne ruční skládání řetězce.

```js
const zdroj = helpers.stripComments(files['App.tsx'], 'js');
assert.match(zdroj, /Intl\.NumberFormat/, 'Na formát ceny použij Intl.NumberFormat');
assert.match(zdroj, /['"]cs-CZ['"]/, "Formátovač má dostat české nastavení 'cs-CZ'");
```

# --help--

## --tip--

Formátování čísel podle jazyka umí prohlížeč sám — hledej to, co jsi používal na ceny v sekcích o řetězcích a číslech.

## --tip--

Objekt s nastavením umí přidat i měnu; bez zaokrouhlení by se u celých korun objevily dvě desetinné nuly.

## --tip--

Vyrobit takový formátovač je drahé, proto se dělá jednou a používá pořád dokola — v modulu nad komponentou, ne uvnitř ní.

```tsx
import { useRef, useState, type FormEvent } from 'react';
import { Avatar } from './components/ui/avatar';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { Card, CardContent, CardFooter, CardHeader } from './components/ui/card';
import { Input } from './components/ui/input';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');
  const poleJmeno = useRef<HTMLInputElement>(null);
  const [vybranyTermin, setVybranyTermin] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const prazdne = jmeno.trim() === '';
    setChyba(prazdne ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
    if (prazdne) poleJmeno.current?.focus();
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button variant="ticha" tone="nebezpeci" size="sm">
            Zrušit rezervaci
          </Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li key={osoba.id} data-testid={'karta-' + osoba.id}>
              <Card>
                <CardHeader>
                  <div className="flex items-center gap-4">
                    <Avatar fotka={osoba.fotka} jmeno={osoba.jmeno} iniciely={osoba.iniciely} />
                    <div>
                      <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                      <p className="text-sm text-slate-600">{osoba.specializace}</p>
                    </div>
                  </div>
                  {osoba.volneTerminy.length > 0 ? (
                    <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                  ) : (
                    <Badge stav="obsazeno" title="Dnes už má plno">
                      Dnes obsazeno
                    </Badge>
                  )}
                </CardHeader>

                <CardContent>
                  <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                  <div className="mt-3 flex flex-wrap gap-2">
                    {osoba.volneTerminy.map((cas) => (
                      <Button
                        key={cas}
                        variant="ticha"
                        size="sm"
                        data-vybrany={vybranyTermin === osoba.id + ' ' + cas}
                        onClick={() => setVybranyTermin(osoba.id + ' ' + cas)}
                        className="border border-slate-200 data-[vybrany=true]:border-znacka data-[vybrany=true]:bg-znacka-svetla"
                      >
                        {cas}
                      </Button>
                    ))}
                  </div>
                </CardContent>

                <CardFooter>
                  <Button>Rezervovat</Button>
                  <Button variant="ticha" asChild>
                    <a href={'#profil-' + osoba.id}>Zobrazit profil</a>
                  </Button>
                </CardFooter>
              </Card>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <Input
              ref={poleJmeno}
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              aria-invalid={chyba !== '' ? true : undefined}
            />
            <Button>Odeslat</Button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

```tsx
export function Button({ className, variant, size, tone, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size, tone }), className)} {...props} />;
```
