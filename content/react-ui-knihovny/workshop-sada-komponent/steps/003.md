# --description--

**Úkol:** Uprav `Badge` tak, aby přijala `className` a zbytek props a poslala je na `<span>`.
Třídy slož přes `cn`, aby zvenku šla přebít i barva pozadí. Pak v `App.tsx` odděl oba stavy:
u volné kadeřnice zůstane zelený štítek s `title`, u obsazené použiješ štítek s třídami
`bg-tlumena text-popisek` a s `title="Dnes už má plno"`.

Bez `cn` by přepsání zvenku neprošlo: `bg-znacka-svetla` z komponenty a `bg-tlumena` z props jsou
dvě utility pro stejnou vlastnost a vyhrála by ta, která je ve vygenerovaném CSS níž.

Na jiných datech vypadá komponenta, která pustí props dál, takhle:

```tsx
export function Kicker({ className, ...props }: ComponentProps<'p'>) {
  return <p className={cn('text-xs uppercase', className)} {...props} />;
}
```

V náhledu pak Tereza dostane šedý štítek a při najetí myší na oba štítky vyskočí bublina z `title`.

# --hints--

Štítek „Dnes obsazeno" má šedé pozadí z `className`, ne zelené z komponenty.

```js
const karta = document.querySelector('[data-testid="karta-tereza"]');
const stitek = [...karta.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Dnes obsazeno');
assert.ok(stitek, 'V kartě Terezy má být štítek „Dnes obsazeno"');
assert.equal(
  getComputedStyle(stitek).backgroundColor,
  'rgb(226, 232, 240)',
  'Štítek „Dnes obsazeno" má mít pozadí bg-tlumena z className — zelená z komponenty musí ustoupit',
);
```

Zelený štítek u Jany zůstal zelený.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const stitek = [...karta.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Volno dnes');
await helpers.waitFor(() => getComputedStyle(stitek).backgroundColor === 'rgb(204, 251, 241)', 3000).catch(() => {});
assert.equal(getComputedStyle(stitek).backgroundColor, 'rgb(204, 251, 241)', 'Štítek „Volno dnes" má zůstat světle zelený');
assert.equal(getComputedStyle(stitek).paddingLeft, '12px', 'Štítek „Volno dnes" má mít pořád odsazení px-3');
```

Oba štítky nesou `title` z props.

```js
const jana = document.querySelector('[data-testid="karta-jana"]');
const volno = [...jana.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Volno dnes');
assert.equal(volno.getAttribute('title'), 'Nejbližší termín 9:30', 'Badge má poslat title z props dál na <span>');
const tereza = document.querySelector('[data-testid="karta-tereza"]');
const obsazeno = [...tereza.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Dnes obsazeno');
assert.equal(obsazeno.getAttribute('title'), 'Dnes už má plno', 'I štítek „Dnes obsazeno" má nést title z props');
```

# --help--

## --tip--

Komponenta, která nepustí `className` a zbytek props dál, se nedá použít v jiném kontextu — viz pasti v lekci [Typické chyby a pasti](see:react-ui-knihovny/tailwind-v-reactu#typicke-chyby-a-pasti).

## --tip--

V destrukturalizaci props si vytáhni `className` zvlášť a zbytek posbírej do jedné proměnné třemi tečkami. Ta se pak rozprostře na výsledný prvek.

## --tip--

Do `cn()` patří obojí v jednom volání a `className` **jako poslední argument** — jinak nemá `tailwind-merge` podle čeho rozhodnout, co vyhrálo.

# --explain--

Proč komponenta v knihovně komponent skoro vždycky přijímá `className` a zbytek props, i když je zrovna nikdo neposílá?

## --model--

Komponenta bez `className` se dá použít jen přesně tam, kde ji autor zamýšlel. Jakmile ji potřebuješ o kousek jinde (roztáhnout na celou šířku, jiný okraj), musel bys ji rozkopírovat nebo přidávat props na každou drobnost. `className` je jedno místo, kudy se dá dostylovat zvenku, a `...props` pustí dál `onClick`, `title`, `aria-*` a `type`, takže komponenta zůstane obyčejným prvkem HTML s lepším vzhledem.

## --checklist--

- `className` nechá volajícího dostylovat komponentu bez zásahu do ní.
- Bez `...props` by se zahodily `onClick`, `title` i atributy `aria-*`.
- Třídy zvenku musí projít `cn()`, jinak konflikt utilit zůstane neuklizený.

## --file-- App.tsx

```tsx
import { useState, type FormEvent } from 'react';
import { Badge } from './components/ui/badge';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <button>Zrušit rezervaci</button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                <Badge>{osoba.volneTerminy.length > 0 ? 'Volno dnes' : 'Dnes obsazeno'}</Badge>
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <span key={cas} className="rounded-lg border border-slate-200 px-3 py-1 text-sm">
                      {cas}
                    </span>
                  ))}
                </div>
              </div>

              <div className="mt-6 flex flex-wrap gap-3">
                <button>Rezervovat</button>
                <button>Zobrazit profil</button>
              </div>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <button>Odeslat</button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}

import type { ComponentProps } from 'react';
import { cn } from '../../lib/utils';

export function Badge({ className, ...props }: ComponentProps<'span'>) {
  return (
    <span
      className={cn(
        'inline-flex items-center rounded-full bg-znacka-svetla px-3 py-1 text-xs font-medium text-znacka',
        className,
      )}
      {...props}
    />
  );
}
