# --description--

**Úkol:** Tlačítko „Zrušit rezervaci" má být tiché a červené. Přidej do `buttonVariants` třetí osu
`tone` s hodnotami `normalni` a `nebezpeci` — obě zatím **prázdné** — a v `compoundVariants` popiš,
co má platit pro jejich kombinace s variantou:

- `plna` + `nebezpeci`: `bg-nebezpeci text-white hover:bg-rose-800`
- `ticha` + `nebezpeci`: `text-nebezpeci hover:bg-rose-50`

Výchozí tón je `normalni`. Pak v `App.tsx` dej hornímu tlačítku „Zrušit rezervaci" tichou variantu,
tón `nebezpeci` a velikost `sm`.

> [!PITFALL]
> Kdybys červenou barvu dal rovnou do varianty `tone`, přebila by se s barvami z varianty `variant`
> a vyhrálo by to, co je v CSS níž. `compoundVariants` jsou přesně na to: pravidla, která platí jen
> pro **kombinaci** hodnot.

Tohle je zatím poslední krok o variantách. Máš hotové dvě komponenty sady — `Button` i `Badge` —
a stránka už drží pohromadě. Klidně si dej pauzu.

# --hints--

Tlačítko „Zrušit rezervaci" je malé, tiché a červené.

```js
const tlacitko = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zrušit rezervaci');
assert.ok(tlacitko, 'Nahoře má být tlačítko „Zrušit rezervaci"');
const styl = getComputedStyle(tlacitko);
await helpers.waitFor(() => styl.color === 'rgb(190, 18, 60)', 3000).catch(() => {});
assert.equal(styl.color, 'rgb(190, 18, 60)', 'Tiché nebezpečné tlačítko má mít červený text (text-nebezpeci)');
assert.equal(styl.backgroundColor, 'rgba(0, 0, 0, 0)', 'Tiché tlačítko má mít průhledné pozadí');
assert.equal(styl.height, '32px', 'Tlačítko má být malé (size sm)');
```

Kombinace `plna` + `nebezpeci` dá červené pozadí a bílý text.

```js
const { buttonVariants } = await helpers.importFile('components/ui/button.tsx');
const plnaNebezpecna = buttonVariants({ variant: 'plna', tone: 'nebezpeci' });
assert.match(plnaNebezpecna, /bg-nebezpeci/, "buttonVariants({ variant: 'plna', tone: 'nebezpeci' }) má obsahovat bg-nebezpeci");
assert.match(plnaNebezpecna, /text-white/, 'plné nebezpečné tlačítko má mít bílý text');
assert.doesNotMatch(buttonVariants({ variant: 'plna' }), /bg-nebezpeci/, 'bez tónu nebezpeci nesmí být tlačítko červené');
```

Ostatní tlačítka zůstala beze změny.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const rezervovat = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Rezervovat');
await helpers.waitFor(() => getComputedStyle(rezervovat).backgroundColor === 'rgb(15, 118, 110)', 3000).catch(() => {});
assert.equal(getComputedStyle(rezervovat).backgroundColor, 'rgb(15, 118, 110)', 'Tlačítko „Rezervovat" má zůstat zelené');
const profil = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zobrazit profil');
const zrusit = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Zrušit rezervaci');
assert.notEqual(
  getComputedStyle(profil).color,
  getComputedStyle(zrusit).color,
  'Tiché tlačítko bez tónu nebezpeci nesmí mít stejnou barvu textu jako to nebezpečné',
);
```

# --help--

## --tip--

Osa `tone` sama o sobě nic nekreslí — nese jen informaci, ke které se pravidla přiváží.

## --tip--

Pole s kombinacemi je třetí klíč v objektu pro `cva`, vedle `variants` a `defaultVariants`. Každá položka je objekt s hodnotami variant a klíčem `class`.

## --tip--

Na jiných datech: `{ size: 'sm', tone: 'nebezpeci', class: 'font-semibold' }` znamená „jen když je zároveň malé a nebezpečné".

```tsx
import { useState, type FormEvent } from 'react';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();

  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">

          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button>Zrušit rezervaci</Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                {osoba.volneTerminy.length > 0 ? (
                  <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                ) : (
                  <Badge stav="obsazeno" title="Dnes už má plno">

                  </Badge>
                )}
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <Button key={cas} variant="ticha" size="sm" className="border border-slate-200">
                      {cas}
                    </Button>
                  ))}
                </div>
              </div>

              value={jmeno}

            />

          </div>

        </form>
      </div>
    </main>
  );
}
```

```tsx
export const badgeVariants = cva('inline-flex items-center rounded-full px-3 py-1 text-xs font-medium', {
  variants: {
    stav: {
      volno: 'bg-znacka-svetla text-znacka',
      obsazeno: 'bg-tlumena text-popisek',
    },
  },
  defaultVariants: { stav: 'volno' },
});

type BadgeProps = ComponentProps<'span'> & { stav?: 'volno' | 'obsazeno' };

export function Badge({ className, stav, ...props }: BadgeProps) {
  return <span className={cn(badgeVariants({ stav }), className)} {...props} />;
}
```

## --file-- components/ui/button.tsx

```tsx
import type { ComponentProps } from 'react';
import { cn } from '../../lib/utils';

import { cva } from 'class-variance-authority';
export const buttonVariants = cva('inline-flex items-center justify-center rounded-lg font-medium transition-colors', {
  variants: {
    variant: {
      plna: 'bg-znacka text-white hover:bg-znacka-tmava',
      ticha: 'bg-transparent text-slate-700 hover:bg-slate-100',
    },
    size: {
      sm: 'h-8 px-3 text-xs',
      md: 'h-10 px-4 text-sm',
    },
    tone: {
      normalni: '',
      nebezpeci: '',
    },
  },
  compoundVariants: [
    { variant: 'plna', tone: 'nebezpeci', class: 'bg-nebezpeci text-white hover:bg-rose-800' },
    { variant: 'ticha', tone: 'nebezpeci', class: 'text-nebezpeci hover:bg-rose-50' },
  ],
  defaultVariants: { variant: 'plna', size: 'md', tone: 'normalni' },
});

type ButtonProps = ComponentProps<'button'> & {
  variant?: 'plna' | 'ticha';
  size?: 'sm' | 'md';
  tone?: 'normalni' | 'nebezpeci';
};

export function Button({ className, variant, size, tone, ...props }: ButtonProps) {
  return <button className={cn(buttonVariants({ variant, size, tone }), className)} {...props} />;
}
```
