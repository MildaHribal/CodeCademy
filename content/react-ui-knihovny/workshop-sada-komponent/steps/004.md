# --description--

**Úkol:** V `components/ui/button.tsx` napiš komponentu `Button` podle stejného vzoru jako `Badge`:
přijme `className` a zbytek props, třídy složí přes `cn`. Základní vzhled:

```text
inline-flex h-10 items-center justify-center rounded-lg bg-znacka px-4 text-sm font-medium text-white
```

Pak v `App.tsx` nahraď **všechna čtyři** holá tlačítka (`Zrušit rezervaci`, `Rezervovat`,
`Zobrazit profil`, `Odeslat`) komponentou `Button`.

Zatím vypadají všechna stejně — varianty přijdou hned v dalších krocích. I tak je to velký skok:
v náhledu se ze čtyř systémových tlačítek stanou tlačítka značky.

# --hints--

Tlačítko „Rezervovat" v kartě Jany je vysoké 40 px a má pozadí značky.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const tlacitko = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Rezervovat');
assert.ok(tlacitko, 'V kartě Jany má být tlačítko „Rezervovat"');
const styl = getComputedStyle(tlacitko);
await helpers.waitFor(() => styl.height === '40px', 3000).catch(() => {});
assert.equal(styl.height, '40px', 'Tlačítko má být vysoké h-10, tedy 40 px');
assert.equal(styl.backgroundColor, 'rgb(15, 118, 110)', 'Tlačítko má mít pozadí bg-znacka');
assert.equal(styl.color, 'rgb(255, 255, 255)', 'Text tlačítka má být bílý');
```

Tlačítko má zaoblené rohy a vnitřní odsazení `px-4`.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const tlacitko = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Rezervovat');
const styl = getComputedStyle(tlacitko);
await helpers.waitFor(() => styl.borderRadius === '8px', 3000).catch(() => {});
assert.equal(styl.borderRadius, '8px', 'Tlačítko má mít rounded-lg, tedy 8 px');
assert.equal(styl.paddingLeft, '16px', 'Tlačítko má mít odsazení px-4, tedy 16 px');
```

Komponentu používají všechna tlačítka stránky — „Zrušit rezervaci" i „Odeslat".

```js
const vsechna = [...document.querySelectorAll('button')];
for (const popis of ['Zrušit rezervaci', 'Odeslat', 'Zobrazit profil']) {
  const tlacitko = vsechna.find((el) => el.textContent.trim() === popis);
  assert.ok(tlacitko, `Na stránce má být tlačítko „${popis}"`);
  await helpers.waitFor(() => getComputedStyle(tlacitko).height === '40px', 3000).catch(() => {});
  assert.equal(getComputedStyle(tlacitko).height, '40px', `Tlačítko „${popis}" má být vykreslené komponentou Button (40 px)`);
}
```

# --help--

## --tip--

Je to přesně ten samý vzor jako u `Badge` o krok zpátky, jen nad prvkem `<button>`.

## --tip--

Typ props pro tlačítko se vezme z Reactu: `ComponentProps<'button'>` popisuje všechno, co umí HTML tlačítko.

## --tip--

Když komponenta nemá vlastní obsah, stačí samozavírací zápis prvku a rozprostřený zbytek props — tak, jak to má `Badge`.

## --file-- App.tsx

```tsx
import { useState, type FormEvent } from 'react';
import { Badge } from './components/ui/badge';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <button>Zrušit rezervaci</button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                {osoba.volneTerminy.length > 0 ? (
                  <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                ) : (
                  <Badge className="bg-tlumena text-popisek" title="Dnes už má plno">
                    Dnes obsazeno
                  </Badge>
                )}
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <span key={cas} className="rounded-lg border border-slate-200 px-3 py-1 text-sm">
                      {cas}
                    </span>
                  ))}
                </div>
              </div>

              <div className="mt-6 flex flex-wrap gap-3">
                <button>Rezervovat</button>
                <button>Zobrazit profil</button>
              </div>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <button>Odeslat</button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
