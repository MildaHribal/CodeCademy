# --description--

**Úkol:** Poslední komponenta sady: `Input` v `components/ui/input.tsx`. Přijme `className`
a zbytek props jako ostatní, základní vzhled je `h-10 w-full rounded-lg border border-slate-300
px-3 text-sm`.

Navíc má umět **chybový stav**, a to bez další props: styl navěsíš na variantu `aria-invalid:`,
která platí, když má prvek atribut `aria-invalid`. Chybné pole má červený rámeček
(`aria-invalid:border-nebezpeci`) a světle růžové pozadí (`aria-invalid:bg-rose-50`).

V `App.tsx` pak nahraď `<input>` komponentou `Input` a dej jí `aria-invalid`, když je ve stavu chyba.
Zkus si v náhledu odeslat formulář s prázdným jménem.

> [!REMEMBER]
> Chybový stav nese **atribut pro přístupnost**, ne props. Čtečka se z `aria-invalid` dozví totéž,
> co uživatel z červeného rámečku, a styl se veze s ním.

# --hints--

Pole je vykreslené komponentou `Input`: vysoké 40 px, zaoblené, přes celou šířku.

```js
const pole = document.querySelector('[data-testid="pole-jmeno"]');
assert.ok(pole, 'Ve formuláři má být pole se jménem');
const styl = getComputedStyle(pole);
await helpers.waitFor(() => styl.height === '40px', 3000).catch(() => {});
assert.equal(styl.height, '40px', 'Pole má být vysoké h-10, tedy 40 px');
assert.equal(styl.borderRadius, '8px', 'Pole má mít zaoblení rounded-lg, tedy 8 px');
assert.equal(styl.paddingLeft, '12px', 'Pole má mít odsazení px-3, tedy 12 px');
```

Po odeslání prázdného formuláře má pole atribut `aria-invalid` a červený rámeček.

```js
const pole = document.querySelector('[data-testid="pole-jmeno"]');
assert.equal(pole.getAttribute('aria-invalid'), null, 'Na začátku pole chybu hlásit nemá');
const odeslat = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Odeslat');
await helpers.click(odeslat);
await helpers.flush();
assert.equal(pole.getAttribute('aria-invalid'), 'true', 'Po odeslání prázdného formuláře má mít pole aria-invalid="true"');
await helpers.waitFor(() => getComputedStyle(pole).borderTopColor === 'rgb(190, 18, 60)', 3000).catch(() => {});
assert.equal(getComputedStyle(pole).borderTopColor, 'rgb(190, 18, 60)', 'Chybné pole má mít červený rámeček z varianty aria-invalid:');
```

Vyplněné jméno chybu nevyvolá a pole se vrátí do klidného stavu.

```js
const pole = document.querySelector('[data-testid="pole-jmeno"]');
const klidnyRamecek = getComputedStyle(pole).borderTopColor;
const odeslat = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Odeslat');
await helpers.click(odeslat);
await helpers.flush();
await helpers.type(pole, 'Karel Novák');
await helpers.click(odeslat);
await helpers.flush();
assert.equal(pole.getAttribute('aria-invalid'), null, 'S vyplněným jménem už pole nemá hlásit chybu');
await helpers.waitFor(() => getComputedStyle(pole).borderTopColor === klidnyRamecek, 3000);
assert.equal(getComputedStyle(pole).borderTopColor, klidnyRamecek, 'Rámeček se má vrátit do klidné barvy');
```

# --help--

## --tip--

Je to stejný vzor jako `Badge` a `Button`, jen nad prvkem `<input>` a bez variant `cva` — stav se veze na atributu.

## --tip--

Varianta `aria-invalid:` se píše před utilitu, kterou má ovlivnit, stejně jako `hover:` nebo `focus-visible:`. Patří do základních tříd komponenty.

## --tip--

Atribut se v JSX nastavuje podmíněně tak, že pro „nenastaveno" pošleš `undefined` — `aria-current={aktivni ? true : undefined}` u odkazu v menu funguje stejně.

## --file-- App.tsx

```tsx
import { useState, type FormEvent } from 'react';
import { Avatar } from './components/ui/avatar';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { Card, CardContent, CardFooter, CardHeader } from './components/ui/card';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button variant="ticha" tone="nebezpeci" size="sm">
            Zrušit rezervaci
          </Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li key={osoba.id} data-testid={'karta-' + osoba.id}>
              <Card>
                <CardHeader>
                  <div className="flex items-center gap-4">
                    <Avatar fotka={osoba.fotka} jmeno={osoba.jmeno} iniciely={osoba.iniciely} />
                    <div>
                      <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                      <p className="text-sm text-slate-600">{osoba.specializace}</p>
                    </div>
                  </div>
                  {osoba.volneTerminy.length > 0 ? (
                    <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                  ) : (
                    <Badge stav="obsazeno" title="Dnes už má plno">
                      Dnes obsazeno
                    </Badge>
                  )}
                </CardHeader>

                <CardContent>
                  <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                  <div className="mt-3 flex flex-wrap gap-2">
                    {osoba.volneTerminy.map((cas) => (
                      <Button key={cas} variant="ticha" size="sm" className="border border-slate-200">
                        {cas}
                      </Button>
                    ))}
                  </div>
                </CardContent>

                <CardFooter>
                  <Button>Rezervovat</Button>
                  <Button variant="ticha" asChild>
                    <a href={'#profil-' + osoba.id}>Zobrazit profil</a>
                  </Button>
                </CardFooter>
              </Card>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <Button>Odeslat</Button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

```tsx
import { cn } from '../../lib/utils';

export const badgeVariants = cva('inline-flex items-center rounded-full px-3 py-1 text-xs font-medium', {
  variants: {
    stav: {
      volno: 'bg-znacka-svetla text-znacka',
      obsazeno: 'bg-tlumena text-popisek',
    },
  },
  defaultVariants: { stav: 'volno' },
});

type BadgeProps = ComponentProps<'span'> & VariantProps<typeof badgeVariants>;

export function Badge({ className, stav, ...props }: BadgeProps) {
  return <span className={cn(badgeVariants({ stav }), className)} {...props} />;
}
```

```tsx
import type { ComponentProps } from 'react';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

import { cva, type VariantProps } from 'class-variance-authority';
export const buttonVariants = cva('inline-flex items-center justify-center rounded-lg font-medium transition-colors', {
  variants: {
    variant: {
      plna: 'bg-znacka text-white hover:bg-znacka-tmava',
      ticha: 'bg-transparent text-slate-700 hover:bg-slate-100',
    },
    size: {
      sm: 'h-8 px-3 text-xs',
      md: 'h-10 px-4 text-sm',
    },
    tone: {
      normalni: '',
      nebezpeci: '',
    },
  },
  compoundVariants: [
    { variant: 'plna', tone: 'nebezpeci', class: 'bg-nebezpeci text-white hover:bg-rose-800' },
    { variant: 'ticha', tone: 'nebezpeci', class: 'text-nebezpeci hover:bg-rose-50' },
  ],
  defaultVariants: { variant: 'plna', size: 'md', tone: 'normalni' },
});

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, tone, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size, tone }), className)} {...props} />;
}
```
