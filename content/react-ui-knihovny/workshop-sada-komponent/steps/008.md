# --description--

**Úkol:** Přepiš `Badge` na `cva` stejně, jako jsi to udělal u tlačítka. Varianta se bude jmenovat
`stav` a bude mít dvě hodnoty:

- `volno`: `bg-znacka-svetla text-znacka`
- `obsazeno`: `bg-tlumena text-popisek`

Výchozí je `volno`. Barvy přitom zmizí ze základních tříd — ty zůstanou na tvar a typografii.
Export pojmenuj `badgeVariants`.

V `App.tsx` pak u obsazené kadeřnice nahraď dostylování přes `className` variantou `stav="obsazeno"`.
Vzhled zůstane stejný, ale volající už nemusí vědět, jaké třídy to znamená — a když se odstín změní,
mění se na jednom místě.

# --hints--

`components/ui/badge.tsx` exportuje `badgeVariants` s variantou `stav`.

```js
const { badgeVariants } = await helpers.importFile('components/ui/badge.tsx');
assert.equal(typeof badgeVariants, 'function', 'badge.tsx má exportovat funkci badgeVariants');
assert.match(badgeVariants({ stav: 'obsazeno' }), /bg-tlumena/, "badgeVariants({ stav: 'obsazeno' }) má vrátit bg-tlumena");
assert.match(badgeVariants(), /bg-znacka-svetla/, 'bez argumentu má platit výchozí varianta volno');
```

Štítek „Dnes obsazeno" vypadá dál šedě, ale řídí ho varianta, ne `className`.

```js
const karta = document.querySelector('[data-testid="karta-tereza"]');
const stitek = [...karta.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Dnes obsazeno');
assert.ok(stitek, 'V kartě Terezy má být štítek „Dnes obsazeno"');
await helpers.waitFor(() => getComputedStyle(stitek).backgroundColor === 'rgb(226, 232, 240)', 3000).catch(() => {});
assert.equal(getComputedStyle(stitek).backgroundColor, 'rgb(226, 232, 240)', 'Štítek „Dnes obsazeno" má mít pozadí bg-tlumena');
assert.equal(getComputedStyle(stitek).color, 'rgb(71, 85, 105)', 'Štítek „Dnes obsazeno" má mít text v barvě text-popisek');
```

Štítek „Volno dnes" zůstal zelený a pořád nese `title`.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const stitek = [...karta.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Volno dnes');
await helpers.waitFor(() => getComputedStyle(stitek).backgroundColor === 'rgb(204, 251, 241)', 3000).catch(() => {});
assert.equal(getComputedStyle(stitek).backgroundColor, 'rgb(204, 251, 241)', 'Výchozí varianta štítku má zůstat světle zelená');
assert.equal(stitek.getAttribute('title'), 'Nejbližší termín 9:30', 'Badge má pořád posílat zbytek props dál');
```

# --help--

## --tip--

Stejný vzor jako u tlačítka: základní třídy, mapa variant, výchozí varianta.

## --tip--

Rozmysli si, které třídy jsou společné (tvar, odsazení, velikost písma) a které patří do varianty (barva pozadí a textu). Společné zůstanou v prvním argumentu `cva`.

## --tip--

V `App.tsx` už štítek nepotřebuje `className` — místo něj pošli props s názvem varianty, stejně jako posíláš `variant` tlačítku.

## --file-- App.tsx

```tsx
import { useState, type FormEvent } from 'react';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button>Zrušit rezervaci</Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                {osoba.volneTerminy.length > 0 ? (
                  <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                ) : (
                  <Badge className="bg-tlumena text-popisek" title="Dnes už má plno">
                    Dnes obsazeno
                  </Badge>
                )}
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <Button key={cas} variant="ticha" size="sm" className="border border-slate-200">
                      {cas}
                    </Button>
                  ))}
                </div>
              </div>

              <div className="mt-6 flex flex-wrap gap-3">
                <Button>Rezervovat</Button>
                <Button variant="ticha">Zobrazit profil</Button>
              </div>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <Button>Odeslat</Button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

import type { ComponentProps } from 'react';
import { cn } from '../../lib/utils';

import { cva } from 'class-variance-authority';
export const buttonVariants = cva('inline-flex items-center justify-center rounded-lg font-medium transition-colors', {
  variants: {
    variant: {
      plna: 'bg-znacka text-white hover:bg-znacka-tmava',
      ticha: 'bg-transparent text-slate-700 hover:bg-slate-100',
    },
    size: {
      sm: 'h-8 px-3 text-xs',
      md: 'h-10 px-4 text-sm',
    },
  },
  defaultVariants: { variant: 'plna', size: 'md' },
});

type ButtonProps = ComponentProps<'button'> & { variant?: 'plna' | 'ticha'; size?: 'sm' | 'md' };

export function Button({ className, variant, size, ...props }: ButtonProps) {
  return <button className={cn(buttonVariants({ variant, size }), className)} {...props} />;
}

## --file-- components/ui/badge.tsx

```tsx
import type { ComponentProps } from 'react';
import { cva } from 'class-variance-authority';
import { cn } from '../../lib/utils';

export const badgeVariants = cva('inline-flex items-center rounded-full px-3 py-1 text-xs font-medium', {
  variants: {
    stav: {
      volno: 'bg-znacka-svetla text-znacka',
      obsazeno: 'bg-tlumena text-popisek',
    },
  },
  defaultVariants: { stav: 'volno' },
});

type BadgeProps = ComponentProps<'span'> & { stav?: 'volno' | 'obsazeno' };

export function Badge({ className, stav, ...props }: BadgeProps) {
  return <span className={cn(badgeVariants({ stav }), className)} {...props} />;
}
```
