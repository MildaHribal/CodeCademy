# --description--

**Úkol:** Když někdo odešle formulář s prázdným jménem, má kurzor skončit v tom poli — jinak ho
uživatel s klávesnicí musí najít sám.

Potřebuješ na pole odkaz (`useRef`) a v obsluze odeslání ho při chybě zaostřit. `Input` kvůli tomu
upravovat nemusíš: v Reactu 19 je `ref` obyčejná props, takže projde tvým `...props` až na `<input>`.

Ověř si to v náhledu: odešli prázdný formulář a piš — text jde rovnou do pole.

# --hints--

Po odeslání prázdného formuláře je kurzor v poli se jménem.

```js
const pole = document.querySelector('[data-testid="pole-jmeno"]');
const odeslat = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Odeslat');
await helpers.click(odeslat);
await helpers.flush();
assert.equal(document.activeElement, pole, 'Po odeslání prázdného formuláře má být kurzor v poli se jménem');
```

Chybová hláška se pořád ukazuje a pole hlásí chybu i čtečce.

```js
const pole = document.querySelector('[data-testid="pole-jmeno"]');
const odeslat = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Odeslat');
await helpers.click(odeslat);
await helpers.flush();
assert.equal(pole.getAttribute('aria-invalid'), 'true', 'Pole má pořád hlásit chybu atributem aria-invalid');
const formular = document.querySelector('[data-testid="zadost"]');
assert.match(formular.textContent, /Vyplň jméno/, 'Ve formuláři má být vidět hláška „Vyplň jméno…"');
```

S vyplněným jménem se kurzor nikam nepřesouvá.

```js
const pole = document.querySelector('[data-testid="pole-jmeno"]');
const odeslat = [...document.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Odeslat');
await helpers.type(pole, 'Karel Novák');
await helpers.click(odeslat);
await helpers.flush();
assert.equal(document.activeElement, odeslat, 'Když je jméno vyplněné, má fokus zůstat na tlačítku, kam ho dal klik');
```

# --help--

## --tip--

Na prvek DOM se v Reactu ukazuje schránkou z `useRef`, kterou pošleš prvku jako props `ref`. Tohle je z lekcí o Reactu, jen teď přes vlastní komponentu.

## --tip--

Obsluha odeslání už rozhoduje o tom, jestli je jméno prázdné. Zaostření patří do té samé větve, kde se nastavuje chyba.

## --tip--

Ve schránce může být `null` (třeba když prvek zrovna není v DOM), takže na `.current` sahej opatrně — hodí se volitelné volání.

# --explain--

Proč `ref` dojde přes tvoji komponentu `Input` až na `<input>`, i když jsi v ní nic takového nenapsal?

## --model--

V Reactu 19 je `ref` u funkčních komponent obyčejná props jako každá jiná. `Input` si z props bere jen `className` a zbytek posílá dál přes `...props`, takže se `ref` sveze s nimi a skončí na prvku `<input>`. Ve starších verzích Reactu se na tohle musela komponenta obalit do `forwardRef`, jinak `ref` do komponenty vůbec nedošel.

## --checklist--

- V Reactu 19 je `ref` běžná props funkční komponenty.
- `...props` ji pošle dál na skutečný prvek DOM.
- Dřív se k tomu musel použít `forwardRef`.

import { useRef, useState, type FormEvent } from 'react';
import { Avatar } from './components/ui/avatar';
import { Badge } from './components/ui/badge';

import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');
  const poleJmeno = useRef<HTMLInputElement>(null);

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const prazdne = jmeno.trim() === '';

    if (prazdne) poleJmeno.current?.focus();
