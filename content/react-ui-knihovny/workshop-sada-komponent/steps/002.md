# --description--

**Úkol:** V `components/ui/badge.tsx` napiš komponentu `Badge`, která vykreslí `<span>` se štítkovým
vzhledem, a v `App.tsx` ji použij místo holého `<span>` se stavem kadeřnice.

Štítek má tyhle třídy:

```text
inline-flex items-center rounded-full bg-znacka-svetla px-3 py-1 text-xs font-medium text-znacka
```

Barvy `znacka` a `znacka-svetla` nejsou vymyšlené — jsou to tokeny značky ze `styles.css`, takže
`bg-znacka-svetla` je obyčejná tailwindová utilita nad proměnnou `--color-znacka-svetla`.

Komponenta dostane obsah přes `children`. Na jiných datech vypadá takový kus kódu takhle:

```tsx
export function Kicker({ children }: ComponentProps<'p'>) {
  return <p className="text-xs uppercase tracking-wide text-slate-500">{children}</p>;
}
```

Po tomhle kroku se v náhledu poprvé ukáže zelená pilulka místo holého textu — u všech tří kadeřnic,
protože komponentu použiješ na jednom místě v `map`.

# --hints--

Štítek „Volno dnes" v kartě Jany je `<span>` se světle zeleným pozadím a odsazením `px-3`.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
assert.ok(karta, 'V náhledu má být karta Jany Procházkové');
const stitek = [...karta.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Volno dnes');
assert.ok(stitek, 'V kartě Jany má být <span> s textem „Volno dnes"');
const styl = getComputedStyle(stitek);
await helpers.waitFor(() => styl.backgroundColor === 'rgb(204, 251, 241)', 3000).catch(() => {});
assert.equal(styl.backgroundColor, 'rgb(204, 251, 241)', 'Štítek má mít pozadí bg-znacka-svetla');
assert.equal(styl.paddingLeft, '12px', 'Štítek má mít vnitřní odsazení px-3, tedy 12 px');
```

Text štítku je malý, polotučný a v barvě značky.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const stitek = [...karta.querySelectorAll('span')].find((el) => el.textContent.trim() === 'Volno dnes');
const styl = getComputedStyle(stitek);
await helpers.waitFor(() => styl.color === 'rgb(15, 118, 110)', 3000).catch(() => {});
assert.equal(styl.color, 'rgb(15, 118, 110)', 'Text štítku má mít barvu text-znacka');
assert.equal(styl.fontSize, '12px', 'Text štítku má být text-xs, tedy 12 px');
assert.equal(styl.fontWeight, '500', 'Text štítku má být font-medium, tedy váha 500');
```

Stejný štítek má i karta Terezy, která dnes volno nemá.

```js
const karta = document.querySelector('[data-testid="karta-tereza"]');

```

# --help--

## --tip--

Komponenta je obyčejná funkce, která vrací JSX. Blok utilit, který se opakuje, se v Reactu pojmenovává komponentou — viz [Problém: stejný blok tříd na pěti místech](see:react-ui-knihovny/tailwind-v-reactu#problem-stejny-blok-trid-na-peti-mistech).

## --tip--

Obsah mezi značkami komponenty najdeš v props pod jménem `children`. V `App.tsx` nahraď element `<span>` značkou `<Badge>` a nech uvnitř ten samý výraz s podmínkou.

## --tip--

Import ze souboru vedle: `import { Kicker } from './components/ui/kicker';` — cesta je relativní k souboru, ve kterém import píšeš.

## --file-- App.tsx

```tsx
import { useState, type FormEvent } from 'react';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <button>Zrušit rezervaci</button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                <span>{osoba.volneTerminy.length > 0 ? 'Volno dnes' : 'Dnes obsazeno'}</span>
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <span key={cas} className="rounded-lg border border-slate-200 px-3 py-1 text-sm">
                      {cas}
                    </span>
                  ))}
                </div>
              </div>

              <div className="mt-6 flex flex-wrap gap-3">
                <button>Rezervovat</button>
                <button>Zobrazit profil</button>
              </div>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <button>Odeslat</button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}
```

```tsx
import type { ComponentProps } from 'react';

export function Badge({ children }: ComponentProps<'span'>) {
  return (
    <span className="inline-flex items-center rounded-full bg-znacka-svetla px-3 py-1 text-xs font-medium text-znacka">

  );
}
```
