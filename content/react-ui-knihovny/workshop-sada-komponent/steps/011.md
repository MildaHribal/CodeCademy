# --description--

**Úkol:** „Zobrazit profil" má vést na jinou stránku, takže to musí být odkaz `<a>` — ale vypadat
má jako tlačítko. Dej `Button` props `asChild`: když je `true`, komponenta nevykreslí `<button>`,
ale předá svoje třídy a props **svému potomkovi**. Umí to komponenta `Slot` z balíčku `radix-ui`
(`import { Slot } from 'radix-ui'`, prvek se jmenuje `Slot.Root`).

Pak v `App.tsx` obal odkaz na profil tlačítkem s `asChild`. Adresa profilu je `#profil-` a id osoby.

V náhledu poznáš rozdíl podle kurzoru a stavového řádku prohlížeče: teď je to skutečný odkaz.

# --hints--

„Zobrazit profil" je odkaz `<a>` s adresou profilu.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const profil = [...karta.querySelectorAll('a')].find((el) => el.textContent.trim() === 'Zobrazit profil');
assert.ok(profil, 'V kartě Jany má být odkaz „Zobrazit profil"');
assert.equal(profil.getAttribute('href'), '#profil-jana', 'Odkaz má vést na #profil-jana');
```

Odkaz vypadá jako tiché tlačítko — dostal třídy z variant.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const profil = [...karta.querySelectorAll('a')].find((el) => el.textContent.trim() === 'Zobrazit profil');
const styl = getComputedStyle(profil);
await helpers.waitFor(() => styl.height === '40px', 3000).catch(() => {});
assert.equal(styl.height, '40px', 'Odkaz má být vysoký 40 px jako tlačítko velikosti md');
assert.equal(styl.borderRadius, '8px', 'Odkaz má mít zaoblení z tlačítkových tříd');
assert.equal(styl.backgroundColor, 'rgba(0, 0, 0, 0)', 'Odkaz má mít průhledné pozadí tiché varianty');
```

Nikde nevznikl odkaz uvnitř tlačítka a ostatní tlačítka zůstala tlačítky.

```js
assert.equal(document.querySelectorAll('button a').length, 0, 'Odkaz nesmí zůstat vnořený uvnitř <button> — to není platné HTML');
const karta = document.querySelector('[data-testid="karta-jana"]');
const rezervovat = [...karta.querySelectorAll('button')].find((el) => el.textContent.trim() === 'Rezervovat');
assert.equal(rezervovat.tagName, 'BUTTON', 'Tlačítko „Rezervovat" má zůstat <button>');
assert.equal(document.querySelectorAll('a[href^="#profil-"]').length, 3, 'Odkaz na profil má mít každá ze tří kadeřnic');
```

# --help--

## --tip--

Komponenta si může vybrat, jaký prvek vykreslí: element v JSX může být proměnná, ve které je buď řetězec (`'button'`), nebo jiná komponenta. Jméno takové proměnné musí začínat velkým písmenem.

## --tip--

Props `asChild` patří do destrukturalizace props (s výchozí hodnotou `false`), ať se nedostane na výsledný prvek.

## --tip--

Na jiných datech: `const Nadpis = uroven === 2 ? 'h2' : 'h3';` a pak `<Nadpis className=…>` vykreslí jednou `<h2>`, jednou `<h3>`.

# --explain--

Proč se odkaz stylovaný jako tlačítko řeší přes `asChild` a ne tak, že se `<a>` napíše dovnitř `<button>`?

## --model--

`<a>` uvnitř `<button>` není platné HTML: obojí je interaktivní prvek a prohlížeč i čtečka z toho mají zmatek — klávesnice narazí na dva cíle, role se překrývají. `asChild` místo toho nevykreslí vlastní prvek vůbec: vezme svoje třídy a props a předá je potomkovi, takže v DOM zůstane jediný prvek, `<a>`, jen se vzhledem tlačítka.

## --checklist--

- Interaktivní prvek se nesmí vnořit do jiného interaktivního prvku.
- `asChild` nevykreslí vlastní prvek, jen předá třídy a props potomkovi.
- V DOM zůstane jeden prvek se správnou rolí a správným chováním klávesnice.

```tsx
import { useState, type FormEvent } from 'react';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button variant="ticha" tone="nebezpeci" size="sm">
            Zrušit rezervaci
          </Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li
              key={osoba.id}
              data-testid={'karta-' + osoba.id}
              className="rounded-karta border border-slate-200 bg-white p-6"
            >
              <div className="flex items-start justify-between gap-4">
                <div>
                  <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                  <p className="text-sm text-slate-600">{osoba.specializace}</p>
                </div>
                {osoba.volneTerminy.length > 0 ? (
                  <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                ) : (
                  <Badge stav="obsazeno" title="Dnes už má plno">
                    Dnes obsazeno
                  </Badge>
                )}
              </div>

              <div className="mt-4">
                <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                <div className="mt-3 flex flex-wrap gap-2">
                  {osoba.volneTerminy.map((cas) => (
                    <Button key={cas} variant="ticha" size="sm" className="border border-slate-200">
                      {cas}
                    </Button>
                  ))}
                </div>
              </div>

              <div className="mt-6 flex flex-wrap gap-3">
                <Button>Rezervovat</Button>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>

            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              className="h-10 w-full rounded-lg border border-slate-300 px-3 text-sm"
            />
            <Button>Odeslat</Button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>

  );
```

```tsx
import type { ComponentProps } from 'react';
import { Slot } from 'radix-ui';
import { cn } from '../../lib/utils';

import { cva, type VariantProps } from 'class-variance-authority';
export const buttonVariants = cva('inline-flex items-center justify-center rounded-lg font-medium transition-colors', {
  variants: {
    variant: {
      plna: 'bg-znacka text-white hover:bg-znacka-tmava',
      ticha: 'bg-transparent text-slate-700 hover:bg-slate-100',
    },
    size: {
      sm: 'h-8 px-3 text-xs',
      md: 'h-10 px-4 text-sm',
    },
    tone: {
      normalni: '',
      nebezpeci: '',
    },
  },
  compoundVariants: [
    { variant: 'plna', tone: 'nebezpeci', class: 'bg-nebezpeci text-white hover:bg-rose-800' },
    { variant: 'ticha', tone: 'nebezpeci', class: 'text-nebezpeci hover:bg-rose-50' },
  ],
  defaultVariants: { variant: 'plna', size: 'md', tone: 'normalni' },
});

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, tone, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size, tone }), className)} {...props} />;
}
```
