# --description--

## Hlášení

Kolega přidal do hlavičky karty komponentu `Avatar` nad primitivem `Avatar` z `radix-ui` a napojil
ji na data. Fotky kadeřnic se ale zatím nefotily, takže soubory `/fotky/*.jpg` na serveru nejsou —
a v kartách je **prázdné šedé kolečko**. Návrhářka čekala, že se v takovém případě ukážou iniciály
(`JP`, `MD`, `TK`); ostatně `Avatar` je v props dostává.

Konzole nic nehlásí, stránka funguje, jen to kolečko je prázdné.

## Úkol

Oprav `components/ui/avatar.tsx` tak, aby se při nedostupné fotce ukázaly iniciály. Změň co nejmenší
kus kódu — hotový obrázek i tvar kolečka nech, jak jsou.

# --hints--

Ve všech třech kartách jsou vidět iniciály kadeřnice.

```js
for (const [id, iniciely] of [['jana', 'JP'], ['marek', 'MD'], ['tereza', 'TK']]) {
  const karta = document.querySelector(`[data-testid="karta-${id}"]`);
  assert.ok(karta, `V náhledu má být karta ${id}`);
  assert.ok(
    karta.textContent.includes(iniciely),
    `V kartě ${id} mají být vidět iniciály ${iniciely}, dokud se nenačte fotka`,
  );
}
```

Kolečko avataru si nechalo velikost i tvar a jméno kadeřnice je pořád v nadpisu.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const nadpis = karta.querySelector('h2');
assert.equal(nadpis.textContent.trim(), 'Jana Procházková', 'Jméno v nadpisu karty má zůstat');
const kolecko = [...karta.querySelectorAll('span, div')].find((el) => el.textContent.trim() === 'JP');
assert.ok(kolecko, 'Iniciály mají být uvnitř kolečka avataru');
const obal = kolecko.closest('[class*="size-12"]') ?? kolecko.parentElement;
const styl = getComputedStyle(obal);
await helpers.waitFor(() => styl.width === '48px', 3000).catch(() => {});
assert.equal(styl.width, '48px', 'Kolečko avataru má zůstat široké 48 px (size-12)');
assert.equal(styl.height, '48px', 'Kolečko avataru má zůstat vysoké 48 px (size-12)');
```

# --help--

## --tip--

Primitivum `Avatar` má tři díly: kořen, obrázek a **náhradu** pro případ, že obrázek není k dispozici. V kódu jsou zatím jen dva z nich.

## --tip--

Náhrada se vykreslí jako potomek kořene hned vedle obrázku. Vlastnost `delayMs` říká, jak dlouho se čeká, než se ukáže — nula znamená hned.

import { useState, type FormEvent } from 'react';
import { Avatar } from './components/ui/avatar';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { Card, CardContent, CardFooter, CardHeader } from './components/ui/card';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setChyba(jmeno.trim() === '' ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">

        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button variant="ticha" tone="nebezpeci" size="sm">
            Zrušit rezervaci
          </Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li key={osoba.id} data-testid={'karta-' + osoba.id}>
              <Card>
                <CardHeader>
                  <div className="flex items-center gap-4">
                    <Avatar fotka={osoba.fotka} jmeno={osoba.jmeno} iniciely={osoba.iniciely} />
                    <div>
                      <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                      <p className="text-sm text-slate-600">{osoba.specializace}</p>
                    </div>
                  </div>
                  {osoba.volneTerminy.length > 0 ? (
                    <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                  ) : (
                    <Badge stav="obsazeno" title="Dnes už má plno">
                      Dnes obsazeno
                    </Badge>
                  )}
                </CardHeader>

                <CardContent>
                  <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                  <div className="mt-3 flex flex-wrap gap-2">
                    {osoba.volneTerminy.map((cas) => (
                      <Button key={cas} variant="ticha" size="sm" className="border border-slate-200">
                        {cas}
                      </Button>
                    ))}
                  </div>
                </CardContent>

                <CardFooter>
                  <Button>Rezervovat</Button>
                  <Button variant="ticha" asChild>
                    <a href={'#profil-' + osoba.id}>Zobrazit profil</a>

            <input
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}

  );

import { Avatar as RadixAvatar } from 'radix-ui';
import { cn } from '../../lib/utils';

type AvatarProps = {
  fotka: string;
  jmeno: string;
  iniciely: string;
  className?: string;
};

export function Avatar({ fotka, jmeno, iniciely, className }: AvatarProps) {
  return (
    <RadixAvatar.Root
      className={cn('inline-flex size-12 shrink-0 overflow-hidden rounded-full bg-slate-100', className)}
    >
      <RadixAvatar.Image src={fotka} alt={jmeno} className="size-full object-cover" />
      <RadixAvatar.Fallback
        delayMs={0}
        className="flex size-full items-center justify-center text-sm font-medium text-slate-600"
      >
        {iniciely}
      </RadixAvatar.Fallback>
    </RadixAvatar.Root>
  );
}
