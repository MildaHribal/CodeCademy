# --description--

**Úkol:** Termíny jdou zmáčknout, ale nic se nestane. Zařiď, aby si stránka pamatovala **jeden**
vybraný termín (napříč všemi kadeřnicemi) a aby vybrané tlačítko vypadalo jinak než ostatní —
změnou pozadí a rámečku.

Jak stav dostaneš do vzhledu, je na tobě: nabízí se datový atribut a varianta `data-[…]:`, podmínka
v `cn()` nebo props `variant`. Každá z těch cest projde testy, tak vyber tu, kterou bys napsal
v práci, a uměj říct proč.

Pozor na to, že termín „11:00" má Jana i někdo další — ve stavu proto potřebuješ i to, čí ten termín je.

# --hints--

Po kliknutí na termín vypadá jen ten jeden jinak než předtím.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const terminy = [...karta.querySelectorAll('button')].filter((el) => /^\d{1,2}:\d{2}$/.test(el.textContent.trim()));
assert.equal(terminy.length, 3, 'Karta Jany má mít tři tlačítka s termíny');
const predtim = getComputedStyle(terminy[1]).backgroundColor;
await helpers.click(terminy[1]);
await helpers.flush();
await helpers
  .waitFor(() => getComputedStyle(terminy[1]).backgroundColor !== predtim, 3000)
  .catch(() => {});
const potom = getComputedStyle(terminy[1]).backgroundColor;
assert.notEqual(potom, predtim, 'Vybraný termín má po kliknutí vypadat jinak (jiné pozadí)');
assert.notEqual(potom, getComputedStyle(terminy[0]).backgroundColor, 'Vybraný termín se má lišit od nevybraných');
```

Vybraný je vždycky jen jeden termín.

```js
const karta = document.querySelector('[data-testid="karta-jana"]');
const terminy = [...karta.querySelectorAll('button')].filter((el) => /^\d{1,2}:\d{2}$/.test(el.textContent.trim()));
const klidne = getComputedStyle(terminy[1]).backgroundColor;
await helpers.click(terminy[1]);
await helpers.flush();
await helpers.waitFor(() => getComputedStyle(terminy[1]).backgroundColor !== klidne, 3000).catch(() => {});
await helpers.click(terminy[0]);
await helpers.flush();
await helpers.waitFor(() => getComputedStyle(terminy[0]).backgroundColor !== klidne, 3000).catch(() => {});
assert.equal(getComputedStyle(terminy[1]).backgroundColor, klidne, 'Dřív vybraný termín se má vrátit do nevybraného stavu');
assert.notEqual(getComputedStyle(terminy[0]).backgroundColor, klidne, 'Nově vybraný termín má být zvýrazněný');
```

Výběr rozlišuje kadeřnice: stejný čas u dvou lidí není jeden výběr.

```js
const jana = document.querySelector('[data-testid="karta-jana"]');
const marek = document.querySelector('[data-testid="karta-marek"]');
const janaTermin = [...jana.querySelectorAll('button')].find((el) => el.textContent.trim() === '9:30');
const marekTermin = [...marek.querySelectorAll('button')].find((el) => el.textContent.trim() === '10:00');
const klidne = getComputedStyle(marekTermin).backgroundColor;
await helpers.click(janaTermin);
await helpers.flush();
await helpers.waitFor(() => getComputedStyle(janaTermin).backgroundColor !== klidne, 3000).catch(() => {});
assert.equal(getComputedStyle(marekTermin).backgroundColor, klidne, 'Výběr u Jany nesmí zvýraznit termín u Marka');
await helpers.click(marekTermin);
await helpers.flush();
await helpers.waitFor(() => getComputedStyle(marekTermin).backgroundColor !== klidne, 3000).catch(() => {});
assert.notEqual(getComputedStyle(marekTermin).backgroundColor, klidne, 'Po kliknutí má být zvýrazněný termín u Marka');
assert.equal(getComputedStyle(janaTermin).backgroundColor, getComputedStyle([...jana.querySelectorAll('button')].find((el) => el.textContent.trim() === '11:00')).backgroundColor, 'Termín u Jany se má vrátit do nevybraného stavu');
```

# --help--

## --tip--

Stav drží komponenta, která vykresluje všechny karty — jeden vybraný termín pro celou stránku.

## --tip--

Do stavu potřebuješ dvě informace najednou (kdo a kdy). Stačí je spojit do jednoho řetězce, nebo si uložit objekt.

## --tip--

Vzhled pak buď navěsíš na datový atribut a variantu, nebo přidáš třídy podmínkou uvnitř `cn()`. Obojí je v pořádku — v DevTools se ale lépe ladí to první.

import { useRef, useState, type FormEvent } from 'react';
import { Avatar } from './components/ui/avatar';
import { Badge } from './components/ui/badge';
import { Button } from './components/ui/button';
import { Card, CardContent, CardFooter, CardHeader } from './components/ui/card';
import { Input } from './components/ui/input';
import { kadernice } from './data';
import './styles.css';

export default function App() {
  const [jmeno, setJmeno] = useState('');
  const [chyba, setChyba] = useState('');
  const poleJmeno = useRef<HTMLInputElement>(null);

  function odeslat(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const prazdne = jmeno.trim() === '';
    setChyba(prazdne ? 'Vyplň jméno, ať víme, komu se ozvat.' : '');
    if (prazdne) poleJmeno.current?.focus();
  }

  return (
    <main className="min-h-screen bg-plocha px-6 py-10 text-slate-900">
      <div className="mx-auto max-w-3xl">
        <header className="mb-6">
          <h1 className="text-2xl font-semibold">Střih &amp; Styl</h1>
          <p className="mt-1 text-slate-600">Rezervace na dnešek, Ostrava-Poruba.</p>
        </header>

        <div className="mb-6 flex items-center justify-between gap-4 rounded-karta border border-slate-200 bg-white px-6 py-4">
          <p className="text-sm">Máš rezervaci na 16:00 u Marka Dvořáka.</p>
          <Button variant="ticha" tone="nebezpeci" size="sm">
            Zrušit rezervaci
          </Button>
        </div>

        <ul className="flex flex-col gap-4">
          {kadernice.map((osoba) => (
            <li key={osoba.id} data-testid={'karta-' + osoba.id}>
              <Card>
                <CardHeader>
                  <div className="flex items-center gap-4">
                    <Avatar fotka={osoba.fotka} jmeno={osoba.jmeno} iniciely={osoba.iniciely} />
                    <div>
                      <h2 className="text-lg font-semibold">{osoba.jmeno}</h2>
                      <p className="text-sm text-slate-600">{osoba.specializace}</p>
                    </div>
                  </div>
                  {osoba.volneTerminy.length > 0 ? (
                    <Badge title={'Nejbližší termín ' + osoba.volneTerminy[0]}>Volno dnes</Badge>
                  ) : (
                    <Badge stav="obsazeno" title="Dnes už má plno">
                      Dnes obsazeno
                    </Badge>
                  )}
                </CardHeader>

                <CardContent>
                  <p className="text-sm text-slate-600">Cena od {osoba.cenaOd} Kč</p>
                  <div className="mt-3 flex flex-wrap gap-2">
                    {osoba.volneTerminy.map((cas) => (
                      <Button key={cas} variant="ticha" size="sm" className="border border-slate-200">
                        {cas}
                      </Button>
                    ))}
                  </div>
                </CardContent>

                <CardFooter>
                  <Button>Rezervovat</Button>
                  <Button variant="ticha" asChild>
                    <a href={'#profil-' + osoba.id}>Zobrazit profil</a>
                  </Button>
                </CardFooter>
              </Card>
            </li>
          ))}
        </ul>

        <form onSubmit={odeslat} data-testid="zadost" className="mt-8 rounded-karta border border-slate-200 bg-white p-6">
          <h2 className="text-lg font-semibold">Nevyhovuje ti žádný termín?</h2>
          <p className="mt-1 text-sm text-slate-600">Nech nám jméno a ozveme se s náhradním termínem.</p>
          <div className="mt-4 flex items-start gap-3">
            <Input
              ref={poleJmeno}
              data-testid="pole-jmeno"
              value={jmeno}
              onChange={(event) => setJmeno(event.target.value)}
              placeholder="Jméno a příjmení"
              aria-invalid={chyba !== '' ? true : undefined}
            />
            <Button>Odeslat</Button>
          </div>
          {chyba !== '' && <p className="mt-2 text-sm text-nebezpeci">{chyba}</p>}
        </form>
      </div>
    </main>
  );
}

export const badgeVariants = cva('inline-flex items-center rounded-full px-3 py-1 text-xs font-medium', {

    stav: {
      volno: 'bg-znacka-svetla text-znacka',

    },
  },
  defaultVariants: { stav: 'volno' },
});

type BadgeProps = ComponentProps<'span'> & VariantProps<typeof badgeVariants>;

    variant: {

      normalni: '',
      nebezpeci: '',
    },
  },
  compoundVariants: [
    { variant: 'plna', tone: 'nebezpeci', class: 'bg-nebezpeci text-white hover:bg-rose-800' },
    { variant: 'ticha', tone: 'nebezpeci', class: 'text-nebezpeci hover:bg-rose-50' },
  ],
  defaultVariants: { variant: 'plna', size: 'md', tone: 'normalni' },
});

type ButtonProps = ComponentProps<'button'> &
  VariantProps<typeof buttonVariants> & { asChild?: boolean };

export function Button({ className, variant, size, tone, asChild = false, ...props }: ButtonProps) {
  const Prvek = asChild ? Slot.Root : 'button';
  return <Prvek className={cn(buttonVariants({ variant, size, tone }), className)} {...props} />;
}
