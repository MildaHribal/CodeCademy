# --description--

Pozice `slot-3` jde přečíst, ale má úroveň `0`. Hra přitom zná jen úrovně 1 až 50. Kdyby takovou pozici načetla, farma by se otevřela bez polí a bez zvířat. Taková data se musí odmítnout **dřív**, než je hra použije.

**Úkol:** Napiš funkci `checkLevel(level)`. Když `level` není celé číslo od 1 do 50, vyhodí `RangeError` se zprávou, ve které je i špatná hodnota, třeba `Úroveň musí být celé číslo 1–50, ne 77`. Jinak úroveň vrátí.

Chybu vyhodíš příkazem `throw` a objektem chyby. `RangeError` se hodí, protože typ sedí (je to číslo), ale hodnota je mimo rozsah. Na jiných datech:

```js
function checkVolume(volume) {
  if (volume < 0 || volume > 100) {
    throw new RangeError(`Hlasitost musí být 0–100, ne ${volume}`);
  }
  return volume;
}
```

Jestli je číslo celé, zjistí `Number.isInteger(value)`.

Pod funkci si zkus zavolat `checkLevel(77)` a přečti si v konzoli hlášku `Uncaught RangeError`. Pak volání smaž — nechytnutá chyba by zastavila zbytek skriptu.

# --hints--

`checkLevel` vrátí platnou úroveň beze změny.

```js
assert.equal(checkLevel(12), 12, 'checkLevel(12) má vrátit 12');
assert.equal(checkLevel(1), 1, 'checkLevel(1) má vrátit 1 — jednička je ještě platná úroveň');
assert.equal(checkLevel(50), 50, 'checkLevel(50) má vrátit 50 — padesátka je ještě platná úroveň');
```

`checkLevel` vyhodí `RangeError` pro úroveň mimo 1–50.

```js
for (const level of [0, 51, -3]) {
  let error;
  try {
    checkLevel(level);
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof RangeError, `checkLevel(${level}) má vyhodit RangeError, vyhodila ${error === undefined ? 'nic' : String(error)}`);
}
```

`checkLevel` vyhodí `RangeError` i pro desetinné číslo a text.

```js
for (const level of [2.5, '12']) {
  let error;
  try {
    checkLevel(level);
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof RangeError, `checkLevel(${JSON.stringify(level)}) má vyhodit RangeError — úroveň musí být celé číslo`);
}
```

Zpráva chyby obsahuje špatnou hodnotu.

```js
let error;
try {
  checkLevel(77);
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof Error, 'checkLevel(77) má vyhodit objekt chyby');
assert.match(error.message, /77/, 'zpráva chyby z checkLevel(77) má obsahovat hodnotu 77');
```

# --help--

## --tip--

Chybu vyhodíš příkazem `throw` s objektem chyby — viz [Co vyhodit](see:js-chyby-ladeni/vyjimky#co-vyhodit-objekt-error-se-srozumitelnou-zpravou).

## --tip--

Podmínka má tři části spojené přes „nebo": není celé číslo, je menší než 1, je větší než 50. Text `'12'` neprojde přes `Number.isInteger`, takže ho chytí první část.
