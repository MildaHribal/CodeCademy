# --description--

Poslední krok: menu **Nahrát hru** ukážeš hráči na obrazovce. V kroku přibyly soubory `index.html` se stránkou menu, `styles.css` s jejím vzhledem a `ui.js` s obsluhou formuláře pro vložení pozice. Náhled teď ukazuje stránku místo konzole. Karty slotů se po najetí myší zvednou — to je `transition`, dostaneš se k němu v sekci o animacích.

**Úkol:** Napiš funkci `renderMenu()`, která do seznamu `#slots` vypíše jednu položku `li` za každý slot ze `savedGames` kromě záloh. Text položky je stejný řádek jako v `menuLines()`. Položka slotu, jehož pozici nejde načíst, dostane třídu `broken` (styly ji zbarví a dají jí křížek). Když funkci zavoláš znovu, seznam ukazuje jen aktuální sloty, nic se nezdvojí. Na konci `script.js` funkci zavolej, aby se menu ukázalo hned po načtení.

Práci se stránkou podrobně probírá sekce DOM, události a prohlížeč. Tady stačí pět nástrojů:

- `document.querySelector('#id')` najde prvek na stránce,
- `document.createElement('li')` vytvoří nový prvek,
- `element.textContent = text` nastaví jeho text,
- `element.classList.toggle('třída', podmínka)` třídu přidá, když podmínka platí, jinak ji odebere,
- `list.replaceChildren(...elements)` nahradí celý obsah prvku zadanými prvky.

Až testy projdou, vyzkoušej formulář pod menu: vlož platný kód a pak ho uřízni v půlce. Obsluha v `ui.js` volá tvoji `importSave` v `try…catch…finally` — hláška pod tlačítkem je zpráva chyby s příčinou a `finally` menu překreslí, ať import dopadne jakkoli.

Hotovo. Za sebou máš:

- vyhození chyby přes `throw` se srozumitelnou zprávou a správným druhem (`TypeError`, `RangeError`),
- `try…catch` s náhradní hodnotou i se zprávou chyby,
- úklid ve `finally` a past s `return` ve `finally`,
- obalení chyby přes `cause` a sbírání chyb do `AggregateError`,
- chytání jen očekávaného druhu chyby a znovu vyhození zbytku,
- rozhodnutí, kde chybu chytit: nahoře, u tlačítka.

Stejné vzory potkáš v každé aplikaci, která čte data odjinud: načtení profilu, import CSV, odeslání formuláře. Příště z nich uděláš vlastní druhy chyb a validaci objednávky, která u každého políčka řekne, co je špatně.

> [!REMEMBER]
> **Chybu vyhoď tam, kde vznikla, a chyť ji tam, kde víš, co s ní udělat.**

## Udělej po svém

- **Vzhled menu:** poškozenou pozici ukaž jinak než barvou — třeba šedou kartou s tlačítkem „Obnovit ze zálohy", které půjde použít jen u slotu se zálohou.
- **Smazání poškozených:** napiš `removeBroken()`, která z `savedGames` odstraní sloty z `brokenSlots()`, vrátí jejich počet a menu překreslí.
- **Automatická záloha:** uprav `saveSlot` tak, aby před přepsáním platné pozice zavolala `backupSlot`.
- **Tvoje téma:** přepiš data na hru nebo aplikaci, kterou znáš — uložené koncepty e-mailů, rozehrané šachové partie, nastavení editoru.

# --hints--

Po načtení stránky je v `#slots` jedna položka `li` za každý slot kromě záloh, s textem řádku z `menuLines()`.

```js
const rows = [...document.querySelectorAll('#slots li')];
const expected = menuLines();
assert.equal(rows.length, expected.length, `v #slots má být ${expected.length} položek li, jedna za každý slot — zavoláš renderMenu() na konci script.js?`);
rows.forEach((row, index) => {
  assert.equal(row.textContent.trim(), expected[index], `položka č. ${index + 1} má mít text „${expected[index]}"`);
});
```

Položky slotů, které nejde načíst, mají třídu `broken`, ostatní ne.

```js
const rows = [...document.querySelectorAll('#slots li')];
const broken = rows.filter((row) => row.classList.contains('broken')).map((row) => row.textContent.trim().split(' · ')[0]);
assert.deepEqual(broken, ['slot-2', 'slot-3', 'slot-4'], `třídu broken mají mít jen slot-2, slot-3 a slot-4, mají ji: ${broken.join(', ') || 'žádné'}`);
```

Když `renderMenu()` zavoláš znovu po změně `savedGames`, seznam ukazuje jen aktuální sloty a zálohy vynechá.

```js
savedGames['slot-1'] = '{"player":"Eliška","level":';
savedGames['slot-6'] = '{"player":"Ondra","level":2,"coins":40,"savedAt":"2026-09-14T08:00:00"}';
savedGames['slot-6-backup'] = savedGames['slot-6'];
renderMenu();
const rows = [...document.querySelectorAll('#slots li')];
assert.equal(rows.length, 6, 'po přidání slot-6 (a jeho zálohy) a novém renderMenu() má být v #slots 6 položek — staré se nahradí, zálohy se nezobrazí');
const slotOne = rows.find((row) => row.textContent.startsWith('slot-1 '));
const slotSix = rows.find((row) => row.textContent.startsWith('slot-6 '));
assert.ok(slotOne?.classList.contains('broken'), 'slot-1 je po uříznutí poškozený — jeho položka má mít třídu broken');
assert.ok(slotSix && !slotSix.classList.contains('broken'), 'slot-6 jde načíst — jeho položka nemá mít třídu broken');
```

Po vložení poškozeného kódu přes formulář ukáže stránka hlášku a menu zůstane beze změny; po vložení platného kódu přibude slot 5.

```js
const form = document.querySelector('#import-form');

```

# --help--

## --tip--

Z pole slotů vyrábíš pole prvků stejné délky a podmínku „jde načíst" už umí jedna tvoje funkce — viz [`try` a `catch`: chytit a pokračovat](see:js-chyby-ladeni/vyjimky#try-a-catch-chytit-a-pokracovat).

## --tip--

Klíče bez záloh vybereš stejně jako v `menuLines`. V `map` pro každý slot vytvoř `li`, nastav text a třídu `broken` podle toho, jestli `tryReadSave` vrátí `null`, a prvek vrať. Pole prvků rozprostři do `replaceChildren` na seznamu `#slots`.

## --tip--

Kostra rozepsaná na podcíle — kód k nim už napíšeš sám:

```js
// 1. najdi seznam #slots
// 2. z klíčů savedGames bez záloh vyrob pole prvků li: text jako v menuLines, třída broken podle toho, jestli slot jde načíst
// 3. nahraď celý obsah seznamu novými prvky
// 4. na konci souboru funkci zavolej
```

// Uložené pozice hry Farma Lísková. Klíč je slot, hodnota text ve formátu JSON —
// přesně tak, jak hra pozice ukládá do úložiště prohlížeče.
const savedGames = {
  'slot-1': '{"player":"Eliška","level":12,"coins":340,"savedAt":"2026-09-12T18:40:00"}',
  'slot-2': '{"player":"Tonda","level":3,"coins":',
  'slot-3': '{"player":"Mája","level":0,"coins":25,"savedAt":"2026-09-01T09:15:00"}',
  'slot-4': '{"player":"Radek","level":7,"coins":-20,"savedAt":"2026-09-11T16:30:00"}',
  autosave: '{"player":"Eliška","level":12,"coins":355,"savedAt":"2026-09-13T21:05:00"}',
};

// Když je loader.busy true, hra ukazuje točící se ikonu nahrávání.
const loader = { busy: false };

// ----- Od kolegy -----

// Zkontroluje počet mincí v uložené hře a vrátí ho.
function checkCoins(coins) {
  if (!Number.isInteger(coins) || coins < 0) {
    throw new RangeError(`Počet mincí musí být nezáporné celé číslo, ne ${coins}`);
  }
  return coins;
}

// Zkopíruje pozici do zálohy (slot-1 → slot-1-backup).
// Vrátí true, když se záloha povedla, jinak false.
function backupSlot(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    savedGames[`${slotId}-backup`] = JSON.stringify(save);
    return true;
  } catch {
    return false;
  }
}

// ----- Tvoje funkce -----

// Z textu uložené pozice vrátí objekt hry.
function readSave(text) {
  return JSON.parse(text);
}

console.log(readSave(savedGames['slot-1']));

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}

// Vrátí uloženou hru, nebo null, když ji nejde načíst.
function tryReadSave(text) {
  try {
    return validateSave(readSave(text));
  } catch {
    return null;
  }
}

console.log('slot-2:', tryReadSave(savedGames['slot-2']));

// Popisek pozice do menu, nebo důvod, proč ji nejde načíst.
function slotLabel(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    return `${save.player} · úroveň ${save.level} · ${save.coins} mincí`;
  } catch (error) {
    return `Nejde načíst: ${error.message}`;
  }
}

console.log(slotLabel('slot-1'));
console.log(slotLabel('slot-3'));

function loadSlot(slotId) {
  loader.busy = true;
  try {
    return validateSave(readSave(savedGames[slotId]));
  } finally {
    loader.busy = false;
  }
}

// Uloží hru do slotu. Neplatnou hru neuloží a vyhodí chybu.
function saveSlot(slotId, save) {
  loader.busy = true;
  try {
    validateSave(save);
    savedGames[slotId] = JSON.stringify(save);
  } finally {
    loader.busy = false;
  }
}

// Načte hru ze slotu. Když to nejde, vyhodí chybu s původní chybou v cause.
function loadGame(slotId) {
  if (!Object.hasOwn(savedGames, slotId)) {
    throw new Error(`Pozice ${slotId} neexistuje`);
  }
  try {
    return loadSlot(slotId);
  } catch (error) {
    throw new Error(`Pozici ${slotId} nejde načíst`, { cause: error });
  }
}

try {
  loadGame('slot-2');
} catch (error) {
  console.log(error.message, '←', error.cause.message);
}

// Pozice vložená ze schránky. Prázdný nebo poškozený text vrátí null,
// jiná chyba (třeba volání s číslem místo textu) vyletí dál.
function readSaveOrNull(text) {
  try {
    return JSON.parse(text.trim());
  } catch (error) {
    if (error instanceof SyntaxError) {
      return null;
    }
    throw error;
  }
}

// Sloty, jejichž pozici nejde načíst.
function brokenSlots() {
  return Object.keys(savedGames).filter((slotId) => tryReadSave(savedGames[slotId]) === null);
}

console.log('Poškozené pozice:', brokenSlots());

// Načte všechny zadané sloty. Když některé nejdou, vyhodí AggregateError se všemi chybami.
function loadAll(slotIds) {
  const saves = [];
  const errors = [];
  for (const slotId of slotIds) {
    try {
      saves.push(loadGame(slotId));
    } catch (error) {
      errors.push(error);
    }
  }
  if (errors.length > 0) {
    throw new AggregateError(errors, `Nejde načíst ${errors.length} z ${slotIds.length} uložených her`);
  }
  return saves;
}

try {
  loadAll(Object.keys(savedGames));
} catch (error) {
  console.log(error.message);
}

// Naposledy uložená hra ze všech, které jdou načíst.
function newestSave() {
  let newest;
  for (const text of Object.values(savedGames)) {
    const save = tryReadSave(text);
    if (save !== null && (newest === undefined || save.savedAt > newest.savedAt)) {
      newest = save;
    }
  }
  return newest;
}

console.log('Pokračovat ve hře:', newestSave());

// Tlačítko Hrát: buď obrazovka farmy s hrou, nebo menu s hláškou.
function startGame(slotId) {
  try {
    return { screen: 'farm', save: loadGame(slotId) };
  } catch (error) {
    const reason = error.cause ? ` (${error.cause.message})` : '';
    return { screen: 'menu', notice: `${error.message}${reason}` };
  }
}

console.log(startGame('slot-3'));

// Načte hru ze slotu; když je poškozená, obnoví ji ze zálohy.
function restoreBackup(slotId) {
  try {
    return loadGame(slotId);
  } catch (originalError) {
    try {
      const save = loadGame(`${slotId}-backup`);
      savedGames[slotId] = savedGames[`${slotId}-backup`];
      return save;
    } catch (backupError) {
      throw new AggregateError([originalError, backupError], `Pozici ${slotId} ani její zálohu nejde načíst`);
    }
  }
}

// Vloží pozici z textu do slotu. Neplatnou pozici nevloží a vyhodí chybu s příčinou.
function importSave(slotId, text) {
  let save;
  try {
    save = validateSave(readSave(text));
  } catch (error) {
    throw new Error(`Import do ${slotId} se nepovedl`, { cause: error });
  }
  savedGames[slotId] = JSON.stringify(save);
  return save;
}

// Souhrn načítání pro obrazovku nastavení.
function loadingReport(slotIds) {
  try {
    const saves = loadAll(slotIds);
    return `Načteno ${saves.length} z ${slotIds.length}.`;
  } catch (error) {
    if (!(error instanceof AggregateError)) {
      throw error;
    }
    const loaded = slotIds.length - error.errors.length;
    const reasons = error.errors.map((item) => item.message).join('; ');
    return `Načteno ${loaded} z ${slotIds.length}. Chyby: ${reasons}`;
  }
}

console.log(loadingReport(['slot-1', 'slot-2', 'autosave']));

// Řádky menu Nahrát hru pro všechny sloty kromě záloh.
function menuLines() {
  return Object.keys(savedGames)
    .filter((slotId) => !slotId.endsWith('-backup'))
    .map((slotId) => `${slotId} · ${slotLabel(slotId)}`);
}

console.log(menuLines().join('\n'));

// Obsluha formuláře pro vložení pozice. Události probírá sekce DOM, události
// a prohlížeč; tady stačí vědět, že funkce uvnitř se spustí po odeslání formuláře.

  const code = document.querySelector('#import-code').value;

    const save = importSave('slot-5', code);
    importNotice.textContent = `Vloženo: ${save.player}, úroveň ${save.level}`;

  } catch (error) {
    const reason = error.cause ? ` (${error.cause.message})` : '';

    importNotice.classList.add('is-error');

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}

  }

// Načte hru ze slotu. Když to nejde, vyhodí chybu s původní chybou v cause.

// Načte všechny zadané sloty. Když některé nejdou, vyhodí AggregateError se všemi chybami.
function loadAll(slotIds) {
  const saves = [];
  const errors = [];
  for (const slotId of slotIds) {
    try {
      saves.push(loadGame(slotId));
    } catch (error) {
      errors.push(error);
    }
  }
  if (errors.length > 0) {
    throw new AggregateError(errors, `Nejde načíst ${errors.length} z ${slotIds.length} uložených her`);
  }
  return saves;
}

try {
  loadAll(Object.keys(savedGames));
} catch (error) {
  console.log(error.message);
}

// Naposledy uložená hra ze všech, které jdou načíst.
function newestSave() {
  let newest;
  for (const text of Object.values(savedGames)) {
    const save = tryReadSave(text);
    if (save !== null && (newest === undefined || save.savedAt > newest.savedAt)) {
      newest = save;
    }
  }
  return newest;
}

console.log('Pokračovat ve hře:', newestSave());

// Načte hru ze slotu; když je poškozená, obnoví ji ze zálohy.
function restoreBackup(slotId) {
  try {
    return loadGame(slotId);
  } catch (originalError) {
    try {
      const save = loadGame(`${slotId}-backup`);
      savedGames[slotId] = savedGames[`${slotId}-backup`];
      return save;
    } catch (backupError) {
      throw new AggregateError([originalError, backupError], `Pozici ${slotId} ani její zálohu nejde načíst`);
    }
  }
}

// Souhrn načítání pro obrazovku nastavení.
function loadingReport(slotIds) {
  try {
    const saves = loadAll(slotIds);
    return `Načteno ${saves.length} z ${slotIds.length}.`;
  } catch (error) {
    if (!(error instanceof AggregateError)) {
      throw error;
    }
    const loaded = slotIds.length - error.errors.length;
    const reasons = error.errors.map((item) => item.message).join('; ');
    return `Načteno ${loaded} z ${slotIds.length}. Chyby: ${reasons}`;
  }
}
