# --description--

`loadSlot('slot-2')` vyhodí `SyntaxError: Unexpected end of JSON input`. Hra bude brzy načítat pozice na víc místech (menu, pokračování, import) a z téhle zprávy nikdo nepozná, **která** pozice je rozbitá.

**Úkol:** Napiš funkci `loadGame(slotId)`, která zavolá `loadSlot(slotId)` a pozici vrátí. Když `loadSlot` vyhodí chybu, `loadGame` vyhodí **novou** chybu `Error` se zprávou `Pozici slot-2 nejde načíst` (se skutečným slotem) a původní chybu k ní připojí jako příčinu.

Pod funkci zavolej `loadGame('slot-2')` v bloku `try…catch` a v `catch` vypiš zprávu nové chyby i zprávu její příčiny.

Hodit se ti bude:

- `catch (error)` — potřebuješ původní chybu,
- druhý argument konstruktoru `Error` — objekt s volbou `cause`,
- `error.cause` — tam příčinu najdeš, když chybu chytíš.

# --hints--

`loadGame` vrátí pozici z platného slotu.

```js
assert.equal(loadGame('slot-1').player, 'Eliška', "loadGame('slot-1') má vrátit pozici Elišky");
```

Na poškozené pozici vyhodí `loadGame` chybu, jejíž zpráva obsahuje jméno slotu.

```js
let error;
try {
  loadGame('slot-2');
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof Error, "loadGame('slot-2') má vyhodit objekt chyby");
assert.match(error.message, /slot-2/, "zpráva chyby z loadGame('slot-2') má obsahovat slot-2");
```

Původní chyba je v `cause`: u `slot-2` `SyntaxError`, u `slot-3` `RangeError`.

```js
let parseError;
try {
  loadGame('slot-2');
} catch (caught) {
  parseError = caught;
}
assert.ok(parseError?.cause instanceof SyntaxError, "chyba z loadGame('slot-2') má mít v cause původní SyntaxError z JSON.parse");

let levelError;
try {
  loadGame('slot-3');
} catch (caught) {
  levelError = caught;
}
assert.ok(levelError?.cause instanceof RangeError, "chyba z loadGame('slot-3') má mít v cause původní RangeError z checkLevel");
assert.match(levelError.message, /slot-3/, "zpráva chyby z loadGame('slot-3') má obsahovat slot-3");
```

`loadGame` nevrací původní chybu, ale novou: její zpráva se liší od zprávy příčiny.

```js
let error;
try {
  loadGame('slot-3');
} catch (caught) {
  error = caught;
}
assert.notEqual(error?.message, error?.cause?.message, "loadGame('slot-3') má vyhodit novou chybu se zprávou o slotu, ne původní chybu z checkLevel");
```

# --help--

## --tip--

Jde o obalení chyby — viz [Obalení chyby přes `cause`](see:js-chyby-ladeni/vyjimky#obaleni-chyby-pres-cause).

## --tip--

V `try` vrať výsledek `loadSlot`. V `catch` vyhoď `new Error(…)` se šablonovým řetězcem a jako druhý argument předej objekt, ve kterém je chycená chyba pod klíčem `cause`.

## --tip--

Kostra: `// 1. try: vrať pozici z loadSlot`, `// 2. catch: vyhoď novou chybu se slotem ve zprávě`, `// 3. druhý argument konstruktoru: původní chyba jako příčina`.

# --explain--

Vysvětli vlastními slovy, proč `loadGame` chybu obaluje, místo aby nechala vyletět původní `SyntaxError`.

## --model--

Původní zpráva `Unexpected end of JSON input` říká, co selhalo, ale ne při čem — nepoznám z ní, která pozice je rozbitá. `loadGame` proto vyhodí novou chybu se zprávou o konkrétním slotu, která dává smysl v menu i v záznamu chyb. Původní chybu přidá jako `cause`, takže detail z `JSON.parse` se neztratí a kdo bude problém hledat, najde obojí.

## --checklist--

- Původní zpráva neříká, u které pozice chyba vznikla.
- Nová chyba má zprávu na úrovni hry (který slot).
- Původní chyba zůstane dostupná v `cause`.
- Obalení chybu neschová, nová chyba letí dál.

// Uložené pozice hry Farma Lísková. Klíč je slot, hodnota text ve formátu JSON —
// přesně tak, jak hra pozice ukládá do úložiště prohlížeče.
const savedGames = {
  'slot-1': '{"player":"Eliška","level":12,"coins":340,"savedAt":"2026-09-12T18:40:00"}',
  'slot-2': '{"player":"Tonda","level":3,"coins":',
  'slot-3': '{"player":"Mája","level":0,"coins":25,"savedAt":"2026-09-01T09:15:00"}',
  'slot-4': '{"player":"Radek","level":7,"coins":-20,"savedAt":"2026-09-11T16:30:00"}',
  autosave: '{"player":"Eliška","level":12,"coins":355,"savedAt":"2026-09-13T21:05:00"}',
};

// Když je loader.busy true, hra ukazuje točící se ikonu nahrávání.
const loader = { busy: false };

// ----- Od kolegy -----

// Zkontroluje počet mincí v uložené hře a vrátí ho.
function checkCoins(coins) {
  if (!Number.isInteger(coins) || coins < 0) {
    throw 'Počet mincí musí být nezáporné celé číslo';
  }
  return coins;
}

// Zkopíruje pozici do zálohy (slot-1 → slot-1-backup).
// Vrátí true, když se záloha povedla, jinak false.
function backupSlot(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    savedGames[`${slotId}-backup`] = JSON.stringify(save);
    return true;
  } catch {
    return false;
  } finally {
    // ať funkce vždycky něco vrátí
    return true;
  }
}

// ----- Tvoje funkce -----

// Z textu uložené pozice vrátí objekt hry.
function readSave(text) {
  return JSON.parse(text);
}

console.log(readSave(savedGames['slot-1']));

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}

// Vrátí uloženou hru, nebo null, když ji nejde načíst.
function tryReadSave(text) {
  try {
    return validateSave(readSave(text));
  } catch {
    return null;
  }
}

console.log('slot-2:', tryReadSave(savedGames['slot-2']));

// Popisek pozice do menu, nebo důvod, proč ji nejde načíst.
function slotLabel(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    return `${save.player} · úroveň ${save.level} · ${save.coins} mincí`;
  } catch (error) {
    return `Nejde načíst: ${error.message}`;
  }
}

console.log(slotLabel('slot-1'));
console.log(slotLabel('slot-3'));

function loadSlot(slotId) {
  loader.busy = true;
  try {
    return validateSave(readSave(savedGames[slotId]));
  } finally {
    loader.busy = false;
  }
}

// Uloží hru do slotu. Neplatnou hru neuloží a vyhodí chybu.
function saveSlot(slotId, save) {
  loader.busy = true;
  try {
    validateSave(save);
    savedGames[slotId] = JSON.stringify(save);
  } finally {
    loader.busy = false;
  }
}
