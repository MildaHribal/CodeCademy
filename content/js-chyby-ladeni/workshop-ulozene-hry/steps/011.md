# --description--

Hra umí vložit pozici ze schránky — hráči si tak posílají kódy pozic. Když hráč vloží prázdný nebo rozbitý text, je to **očekávaná chyba**: stačí vrátit `null` a menu ukáže „Kód pozice je neplatný". Když ale funkci někdo z týmu omylem zavolá s číslem nebo `undefined`, je to **chyba programu** a ta se nesmí ztratit v `null`.

**Úkol:** Napiš funkci `readSaveOrNull(text)`, která:

- z textu (s oříznutými mezerami na začátku a konci) načte objekt přes `JSON.parse` a vrátí ho,
- když je text poškozený nebo prázdný, vrátí `null`,
- když selže cokoli jiného (třeba volání `trim` na čísle), chybu nechá vyletět ven.

Pozice se tu nekontroluje přes `validateSave`, jde jen o přečtení textu.

Na výběr máš:

- chytit všechno a v `catch` rozhodnout podle druhu chyby — `instanceof` a znovu vyhození přes `throw`,
- ořezat text ještě **před** blokem `try`, aby do něj patřilo jen `JSON.parse`.

Oba způsoby jsou správně, vyber si. Jaký druh chyby vyhazuje `JSON.parse` na rozbitém textu, víš z menu u `slot-2`.

# --hints--

`readSaveOrNull` vrátí objekt z platného textu, i s mezerami okolo.

```js
assert.deepEqual(readSaveOrNull('  {"player":"Vojta","level":5}\n'), { player: 'Vojta', level: 5 }, 'readSaveOrNull(\'  {"player":"Vojta","level":5}\\n\') má vrátit { player: "Vojta", level: 5 }');
```

Pro poškozený, prázdný nebo jen mezerový text vrátí `null`.

```js
assert.equal(readSaveOrNull(savedGames['slot-2']), null, "readSaveOrNull(savedGames['slot-2']) má vrátit null");
assert.equal(readSaveOrNull(''), null, "readSaveOrNull('') má vrátit null");
assert.equal(readSaveOrNull('   '), null, "readSaveOrNull('   ') má vrátit null");
```

Když funkci někdo zavolá s číslem nebo `undefined`, chyba programu vyletí ven.

```js
assert.throws(() => readSaveOrNull(42), TypeError, 'readSaveOrNull(42) má nechat vyletět TypeError — volání s číslem je chyba programu, ne neplatný kód pozice');
assert.throws(() => readSaveOrNull(undefined), TypeError, 'readSaveOrNull(undefined) má nechat vyletět TypeError');
```

# --help--

## --tip--

Jde o chytání jen očekávaného druhu chyby — viz [Kde chybu chytat](see:js-chyby-ladeni/vyjimky#kde-chybu-chytat) a [chyba uživatele a chyba programu](see:js-chyby-ladeni/vyjimky#chyba-uzivatele-a-chyba-programu).

## --tip--

`JSON.parse` vyhazuje `SyntaxError`, `trim` na čísle `TypeError`. V `catch (error)` zjistíš druh přes `error instanceof SyntaxError`; chybu, kterou neumíš vyřešit, vyhodíš znovu příkazem `throw` se stejnou proměnnou.

## --tip--

Kostra pro chytání všeho: `// 1. try: vrať přečtený objekt`, `// 2. catch: je to chyba rozbitého textu? → null`, `// 3. jinak: stejnou chybu vyhoď dál`. Pro druhý způsob stačí `// 1. ořízni text`, `// 2. try jen kolem čtení JSON`.

# --explain--

Vysvětli vlastními slovy, proč `readSaveOrNull(42)` nemá vrátit `null`, i když by to aplikace „přežila".

## --model--

Prázdný nebo rozbitý kód pozice je očekávaná chyba — hráč vložil špatný text a `null` je rozumná odpověď. Volání s číslem je ale chyba programu: někdo v kódu funkci použil špatně. Kdyby ji `catch` proměnil v `null`, hra by tvrdila, že kód je neplatný, a skutečnou chybu v kódu by nikdo nenašel. Proto chytám jen `SyntaxError` a všechno ostatní vyhodím dál.

## --checklist--

- Neplatný text od hráče je očekávaná chyba.
- Volání s číslem je chyba programu.
- `null` by chybu programu schoval za „neplatný kód".
- Chytám jen `SyntaxError`, ostatní chyby vyhodím znovu.

```js
// Uložené pozice hry Farma Lísková. Klíč je slot, hodnota text ve formátu JSON —
// přesně tak, jak hra pozice ukládá do úložiště prohlížeče.
const savedGames = {
  'slot-1': '{"player":"Eliška","level":12,"coins":340,"savedAt":"2026-09-12T18:40:00"}',
  'slot-2': '{"player":"Tonda","level":3,"coins":',
  'slot-3': '{"player":"Mája","level":0,"coins":25,"savedAt":"2026-09-01T09:15:00"}',
  'slot-4': '{"player":"Radek","level":7,"coins":-20,"savedAt":"2026-09-11T16:30:00"}',
  autosave: '{"player":"Eliška","level":12,"coins":355,"savedAt":"2026-09-13T21:05:00"}',
};

// Když je loader.busy true, hra ukazuje točící se ikonu nahrávání.
const loader = { busy: false };

// ----- Od kolegy -----

// Zkontroluje počet mincí v uložené hře a vrátí ho.
function checkCoins(coins) {
  if (!Number.isInteger(coins) || coins < 0) {
    throw new RangeError(`Počet mincí musí být nezáporné celé číslo, ne ${coins}`);
  }
  return coins;
}

// Zkopíruje pozici do zálohy (slot-1 → slot-1-backup).
// Vrátí true, když se záloha povedla, jinak false.
function backupSlot(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    savedGames[`${slotId}-backup`] = JSON.stringify(save);
    return true;
  } catch {
    return false;
  } finally {
    // ať funkce vždycky něco vrátí
    return true;
  }
}

// ----- Tvoje funkce -----

// Z textu uložené pozice vrátí objekt hry.
function readSave(text) {
  return JSON.parse(text);
}

console.log(readSave(savedGames['slot-1']));

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}

// Vrátí uloženou hru, nebo null, když ji nejde načíst.
function tryReadSave(text) {
  try {
    return validateSave(readSave(text));
  } catch {
    return null;
  }
}

console.log('slot-2:', tryReadSave(savedGames['slot-2']));

// Popisek pozice do menu, nebo důvod, proč ji nejde načíst.
function slotLabel(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    return `${save.player} · úroveň ${save.level} · ${save.coins} mincí`;
  } catch (error) {
    return `Nejde načíst: ${error.message}`;
  }
}

console.log(slotLabel('slot-1'));
console.log(slotLabel('slot-3'));

function loadSlot(slotId) {
  loader.busy = true;
  try {
    return validateSave(readSave(savedGames[slotId]));
  } finally {
    loader.busy = false;
  }
}

// Uloží hru do slotu. Neplatnou hru neuloží a vyhodí chybu.
function saveSlot(slotId, save) {
  loader.busy = true;
  try {
    validateSave(save);
    savedGames[slotId] = JSON.stringify(save);
  } finally {
    loader.busy = false;
  }
}

// Načte hru ze slotu. Když to nejde, vyhodí chybu s původní chybou v cause.
function loadGame(slotId) {
  if (!Object.hasOwn(savedGames, slotId)) {
    throw new Error(`Pozice ${slotId} neexistuje`);
  }
  try {
    return loadSlot(slotId);
  } catch (error) {
    throw new Error(`Pozici ${slotId} nejde načíst`, { cause: error });
  }
}

try {
  loadGame('slot-2');
} catch (error) {
  console.log(error.message, '←', error.cause.message);
}
```
