# --description--

Menu hry potřebuje u každého slotu rychle zjistit, jestli jde pozici načíst. Když ne, slot zešedne. Na poškozené pozici ale `readSave` i `validateSave` vyhodí chybu, a ta by shodila celé menu.

**Úkol:** Napiš funkci `tryReadSave(text)`, která z textu načte a zkontroluje pozici (`readSave` a `validateSave`) a vrátí ji. Když cokoli z toho vyhodí chybu, vrátí `null`. Pod funkci vypiš výsledek pro `slot-2`.

Kód, který může selhat, dáš do bloku `try`. Když v něm vznikne výjimka, běh skočí do `catch`. Objekt chyby tu nepotřebuješ, takže smíš napsat jen `catch { … }`. Na jiných datech — převod textu na adresu URL, který na nesmyslu vyhodí `TypeError`:

```js
function toUrl(text) {
  try {
    return new URL(text);
  } catch {
    return null;
  }
}
```

Tahle funkce chytá **všechno**. U ní je to záměr: menu se ptá jen „jde to, nebo ne". Přesnější chytání, které nechá chyby programu projít, napíšeš za pár kroků.

# --hints--

`tryReadSave` vrátí platnou pozici jako objekt.

```js
const save = tryReadSave('{"player":"Vojta","level":5,"coins":120,"savedAt":"2026-09-02T10:00:00"}');
assert.deepEqual(save, { player: 'Vojta', level: 5, coins: 120, savedAt: '2026-09-02T10:00:00' }, 'tryReadSave(platný text Vojtovy pozice) má vrátit objekt pozice');
```

`tryReadSave` vrátí `null` pro poškozený i prázdný text.

```js
assert.equal(tryReadSave(savedGames['slot-2']), null, "tryReadSave(savedGames['slot-2']) má vrátit null — text pozice je uříznutý");
assert.equal(tryReadSave(''), null, "tryReadSave('') má vrátit null");
```

`tryReadSave` vrátí `null` i pro pozici, která neprojde kontrolou.

```js
assert.equal(tryReadSave(savedGames['slot-3']), null, "tryReadSave(savedGames['slot-3']) má vrátit null — úroveň 0 neprojde přes validateSave");
assert.equal(tryReadSave('{"level":5,"coins":1}'), null, 'tryReadSave(pozice bez jména hráče) má vrátit null');
```

# --help--

## --tip--

Jde o blok `try…catch` — viz [`try` a `catch`: chytit a pokračovat](see:js-chyby-ladeni/vyjimky#try-a-catch-chytit-a-pokracovat).

## --tip--

Do `try` patří obě volání (`validateSave` nad výsledkem `readSave`) i `return` hotové pozice. `catch` vrátí `null`.

function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');

  checkLevel(save.level);
  checkCoins(save.coins);

function tryReadSave(text) {
  try {
    return validateSave(readSave(text));
  } catch {
    return null;
  }
}
