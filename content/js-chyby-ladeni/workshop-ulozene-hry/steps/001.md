# --description--

Každá hra, která se dá uložit, jednou narazí na poškozenou pozici: vypne se počítač uprostřed ukládání, uživatel vloží špatný kód nebo novější verze hry změní formát. Dobrá hra v tu chvíli nespadne, ale ukáže v menu srozumitelnou hlášku. Přesně takové menu **Nahrát hru** teď postavíš pro farmářskou hru Farma Lísková.

V `script.js` je objekt `savedGames`. Klíčem je slot (`slot-1`, `autosave`…) a hodnotou text ve formátu JSON, tak jak ho hra ukládá do úložiště prohlížeče. Každá pozice má jméno hráče (`player`), úroveň (`level`), počet mincí (`coins`) a čas uložení (`savedAt`). Některé pozice jsou schválně rozbité. Nad daty jsou dvě funkce od kolegy — k nim se ve workshopu ještě vrátíš.

Začni tím, co už umíš z JSON, a to bez návodu.

**Úkol:** Pod řádek `// ----- Tvoje funkce -----` napiš funkci `readSave(text)`, která z textu pozice vrátí objekt hry. Pod ni vypiš do konzole načtený `slot-1`.

# --hints--

`readSave` vrátí z textu pozice objekt se všemi údaji.

```js
const text = '{"player":"Vojta","level":5,"coins":120,"savedAt":"2026-09-02T10:00:00"}';
assert.deepEqual(
  readSave(text),
  { player: 'Vojta', level: 5, coins: 120, savedAt: '2026-09-02T10:00:00' },
  "readSave('{\"player\":\"Vojta\",\"level\":5,…}') má vrátit objekt { player: 'Vojta', level: 5, coins: 120, savedAt: '2026-09-02T10:00:00' }",
);
```

`readSave` načte i pozici `slot-1` ze `savedGames`.

```js
const save = readSave(savedGames['slot-1']);
assert.equal(save.player, 'Eliška', "readSave(savedGames['slot-1']).player má být 'Eliška'");
assert.equal(save.level, 12, "readSave(savedGames['slot-1']).level má být číslo 12");
```

# --help--

## --tip--

Text ve formátu JSON převádí na objekt metoda `JSON.parse`. Funkce má výsledek **vrátit**.

## --tip--

Stejný tvar na jiných datech: funkce `readSettings(text)` by vracela výsledek `JSON.parse` nad textem nastavení.
