# --description--

Při přechodu na nový počítač hra načte všechny pozice najednou. Kdyby skončila u první chyby, hráč by opravil `slot-2`, spustil import znovu a narazil na `slot-3` — a tak pořád dokola. Lepší je zkusit všechny sloty a nakonec nahlásit všechny chyby.

**Úkol:** Napiš funkci `loadAll(slotIds)`, která každý slot z pole načte funkcí `loadGame`:

- když se všechny povedou, vrátí pole pozic ve stejném pořadí,
- když některé selžou, zkusí i ty zbylé a nakonec vyhodí `AggregateError`. V jeho poli chyb budou všechny chyby z `loadGame` (v pořadí slotů) a zpráva zní `Nejde načíst 2 z 3 uložených her` (se skutečnými čísly).

Pod funkci zavolej `loadAll` se všemi klíči `savedGames` v `try…catch` a v `catch` vypiš zprávu.

Hodit se ti bude cyklus přes sloty s `try…catch` uvnitř, dvě pomocná pole (povedené pozice, chyby) a konstruktor `AggregateError`, který dostane pole chyb a zprávu.

> [!PITFALL]
> Když dáš `try…catch` **kolem** celého cyklu místo dovnitř, první chyba cyklus ukončí a další sloty se už nezkusí.

# --hints--

`loadAll` vrátí pozice všech slotů, když se všechny načtou.

```js
const saves = loadAll(['autosave', 'slot-1']);
assert.ok(Array.isArray(saves), "loadAll(['autosave', 'slot-1']) má vrátit pole");
assert.deepEqual(saves.map((save) => save.coins), [355, 340], "loadAll(['autosave', 'slot-1']) má vrátit pozice v pořadí slotů (mince 355, 340)");
```

`loadAll([])` vrátí prázdné pole.

```js
assert.deepEqual(loadAll([]), [], 'loadAll([]) má vrátit []');
```

Když některé sloty selžou, `loadAll` vyhodí `AggregateError` se všemi chybami v pořadí slotů.

```js
let error;
try {
  loadAll(['slot-2', 'slot-1', 'slot-3', 'slot-9']);
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof AggregateError, "loadAll(['slot-2', 'slot-1', 'slot-3', 'slot-9']) má vyhodit AggregateError");
assert.equal(error.errors.length, 3, 'AggregateError má obsahovat 3 chyby — slot-2, slot-3 a slot-9; slot-1 jde načíst');
assert.match(error.errors[0].message, /slot-2/, 'první chyba v errors má být chyba ze slot-2');
assert.match(error.errors[1].message, /slot-3/, 'druhá chyba v errors má být chyba ze slot-3 — cyklus má po chybě pokračovat');
assert.match(error.errors[2].message, /slot-9/, 'třetí chyba v errors má být chyba ze slot-9');
```

Zpráva `AggregateError` říká, kolik slotů z kolika nejde načíst.

```js
let error;
try {
  loadAll(['slot-1', 'slot-2', 'slot-3']);
} catch (caught) {
  error = caught;
}
assert.equal(error?.message, 'Nejde načíst 2 z 3 uložených her', "loadAll(['slot-1', 'slot-2', 'slot-3']) má vyhodit AggregateError se zprávou 'Nejde načíst 2 z 3 uložených her'");
```

# --help--

## --tip--

Jde o sbírání chyb do `AggregateError` — viz [Víc chyb najednou](see:js-chyby-ladeni/vyjimky#vic-chyb-najednou-aggregateerror).

## --tip--

V cyklu `for…of` každé volání `loadGame` obal zvlášť: v `try` přidej pozici do pole pozic, v `catch` chybu do pole chyb. Za cyklem rozhodni podle délky pole chyb, jestli vyhodit, nebo vrátit pozice.

## --tip--

Na jiných datech: `` throw new AggregateError(failedUploads, `Nahrání selhalo u ${failedUploads.length} fotek`) `` za cyklem nahrávání.

# --explain--

Vysvětli vlastními slovy, kdy je lepší vyhodit `AggregateError` se všemi chybami než skončit u první.

## --model--

Když zpracovávám víc nezávislých věcí najednou — třeba import všech pozic nebo kontrolu formuláře —, chci uživateli ukázat všechny problémy naráz. Kdybych skončil u první chyby, opravil by jednu věc, spustil to znovu a narazil na další. `AggregateError` nese pole všech chyb, takže volající je může vypsat všechny. U jedné operace, která po chybě stejně nemůže pokračovat, stačí vyhodit první chybu.

## --checklist--

- U víc nezávislých položek chci vidět všechny chyby naráz.
- Skončit u první chyby nutí opakovat akci po každé opravě.
- `AggregateError` nese všechny chyby v poli `errors`.
- Když operace po chybě pokračovat nemůže, stačí jedna chyba.

```js
// Uložené pozice hry Farma Lísková. Klíč je slot, hodnota text ve formátu JSON —
// přesně tak, jak hra pozice ukládá do úložiště prohlížeče.
const savedGames = {
  'slot-1': '{"player":"Eliška","level":12,"coins":340,"savedAt":"2026-09-12T18:40:00"}',
  'slot-2': '{"player":"Tonda","level":3,"coins":',
  'slot-3': '{"player":"Mája","level":0,"coins":25,"savedAt":"2026-09-01T09:15:00"}',
  'slot-4': '{"player":"Radek","level":7,"coins":-20,"savedAt":"2026-09-11T16:30:00"}',
  autosave: '{"player":"Eliška","level":12,"coins":355,"savedAt":"2026-09-13T21:05:00"}',
};

// Když je loader.busy true, hra ukazuje točící se ikonu nahrávání.
const loader = { busy: false };

// ----- Od kolegy -----

// Zkontroluje počet mincí v uložené hře a vrátí ho.
function checkCoins(coins) {
  if (!Number.isInteger(coins) || coins < 0) {
    throw new RangeError(`Počet mincí musí být nezáporné celé číslo, ne ${coins}`);
  }
  return coins;
}

// Zkopíruje pozici do zálohy (slot-1 → slot-1-backup).
// Vrátí true, když se záloha povedla, jinak false.
function backupSlot(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    savedGames[`${slotId}-backup`] = JSON.stringify(save);
    return true;
  } catch {
    return false;
  } finally {
    // ať funkce vždycky něco vrátí
    return true;
  }
}

// ----- Tvoje funkce -----

// Z textu uložené pozice vrátí objekt hry.
function readSave(text) {
  return JSON.parse(text);
}

console.log(readSave(savedGames['slot-1']));

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}

// Vrátí uloženou hru, nebo null, když ji nejde načíst.
function tryReadSave(text) {
  try {
    return validateSave(readSave(text));
  } catch {
    return null;
  }
}

console.log('slot-2:', tryReadSave(savedGames['slot-2']));

// Popisek pozice do menu, nebo důvod, proč ji nejde načíst.
function slotLabel(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    return `${save.player} · úroveň ${save.level} · ${save.coins} mincí`;
  } catch (error) {
    return `Nejde načíst: ${error.message}`;
  }
}

console.log(slotLabel('slot-1'));
console.log(slotLabel('slot-3'));

function loadSlot(slotId) {
  loader.busy = true;
  try {
    return validateSave(readSave(savedGames[slotId]));
  } finally {
    loader.busy = false;
  }
}

// Uloží hru do slotu. Neplatnou hru neuloží a vyhodí chybu.
function saveSlot(slotId, save) {
  loader.busy = true;
  try {
    validateSave(save);
    savedGames[slotId] = JSON.stringify(save);
  } finally {
    loader.busy = false;
  }
}

// Načte hru ze slotu. Když to nejde, vyhodí chybu s původní chybou v cause.
function loadGame(slotId) {
  if (!Object.hasOwn(savedGames, slotId)) {
    throw new Error(`Pozice ${slotId} neexistuje`);
  }
  try {
    return loadSlot(slotId);
  } catch (error) {
    throw new Error(`Pozici ${slotId} nejde načíst`, { cause: error });
  }
}

try {
  loadGame('slot-2');
} catch (error) {
  console.log(error.message, '←', error.cause.message);
}

// Pozice vložená ze schránky. Prázdný nebo poškozený text vrátí null,
// jiná chyba (třeba volání s číslem místo textu) vyletí dál.
function readSaveOrNull(text) {
  try {
    return JSON.parse(text.trim());
  } catch (error) {
    if (error instanceof SyntaxError) {
      return null;
    }
    throw error;
  }
}

// Sloty, jejichž pozici nejde načíst.
function brokenSlots() {
  return Object.keys(savedGames).filter((slotId) => tryReadSave(savedGames[slotId]) === null);
}

console.log('Poškozené pozice:', brokenSlots());

// Načte všechny zadané sloty. Když některé nejdou, vyhodí AggregateError se všemi chybami.
function loadAll(slotIds) {
  const saves = [];
  const errors = [];
  for (const slotId of slotIds) {
    try {
      saves.push(loadGame(slotId));
    } catch (error) {
      errors.push(error);
    }
  }
  if (errors.length > 0) {
    throw new AggregateError(errors, `Nejde načíst ${errors.length} z ${slotIds.length} uložených her`);
  }
  return saves;
}

try {
  loadAll(Object.keys(savedGames));
} catch (error) {
  console.log(error.message);
```
