# --description--

Úroveň umíš zkontrolovat. Pozice má ale víc údajů a hra potřebuje jednu funkci, která prověří celou.

**Úkol:** Napiš funkci `validateSave(save)`, která:

1. vyhodí `TypeError` se zprávou `Uložená hra nemá jméno hráče`, když `save.player` není text nebo je to text jen z mezer,
2. zkontroluje úroveň funkcí `checkLevel`,
3. zkontroluje mince kolegovou funkcí `checkCoins`,
4. když všechno projde, vrátí `save`.

Proč `TypeError`? Jméno má být text, a když přijde číslo nebo `undefined`, je špatně typ hodnoty.

Všimni si, že v bodech 2 a 3 nepíšeš žádný `try…catch`. Když `checkLevel` vyhodí chybu, vyletí z ní a proletí i přes `validateSave` až k tomu, kdo ji zavolal. Kontrola se tak skládá z menších kontrol. Na jiných datech:

```js
function validateTrack(track) {
  // 1. vlastní kontrola
  if (typeof track.title !== 'string') {
    throw new TypeError('Skladba nemá název');
  }
  // 2. menší kontroly — jejich chyby letí dál samy
  checkDuration(track.seconds);
  return track;
}
```

Konzole se v tomhle kroku nezmění — funkci použiješ hned v dalším kroku, zatím ji prověří seznam kontrol.

# --hints--

`validateSave` vrátí platnou pozici — tentýž objekt, který dostala.

```js
const save = { player: 'Vojta', level: 5, coins: 120, savedAt: '2026-09-02T10:00:00' };
assert.equal(validateSave(save), save, 'validateSave({ player: Vojta, level: 5, coins: 120 }) má vrátit tentýž objekt');
```

Pozice bez jména hráče nebo se jménem z mezer vyhodí `TypeError`.

```js
for (const player of [undefined, 42, '', '   ']) {
  let error;
  try {
    validateSave({ player, level: 5, coins: 120 });
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof TypeError, `validateSave s player: ${JSON.stringify(player)} má vyhodit TypeError`);
  assert.equal(error.message, 'Uložená hra nemá jméno hráče', `zpráva chyby pro player: ${JSON.stringify(player)} má být „Uložená hra nemá jméno hráče"`);
}
```

Pozice se špatnou úrovní vyhodí chybu z `checkLevel`.

```js
let error;
try {
  validateSave({ player: 'Mája', level: 0, coins: 25 });
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof RangeError, 'validateSave({ player: Mája, level: 0 }) má vyhodit RangeError z checkLevel');
```

Pozice se záporným počtem mincí neprojde.

```js
assert.throws(
  () => validateSave({ player: 'Radek', level: 7, coins: -20 }),
  'validateSave({ player: Radek, level: 7, coins: -20 }) má vyhodit chybu — zavoláš checkCoins?',
);
```

# --help--

## --tip--

Kontroly za sebou, jejichž chyby letí nahoru samy — viz [Co udělá `throw`](see:js-chyby-ladeni/vyjimky#co-udela-throw).

## --tip--

Nejdřív podmínka na jméno: `typeof` řekne, jestli jde o text, a `trim()` odstraní mezery. Pak dvě volání kontrol s `save.level` a `save.coins` a nakonec `return`.

// přesně tak, jak hra pozice ukládá do úložiště prohlížeče.
const savedGames = {
  'slot-1': '{"player":"Eliška","level":12,"coins":340,"savedAt":"2026-09-12T18:40:00"}',
  'slot-2': '{"player":"Tonda","level":3,"coins":',
  'slot-3': '{"player":"Mája","level":0,"coins":25,"savedAt":"2026-09-01T09:15:00"}',
  'slot-4': '{"player":"Radek","level":7,"coins":-20,"savedAt":"2026-09-11T16:30:00"}',
  autosave: '{"player":"Eliška","level":12,"coins":355,"savedAt":"2026-09-13T21:05:00"}',
};

// Když je loader.busy true, hra ukazuje točící se ikonu nahrávání.
const loader = { busy: false };

// ----- Od kolegy -----

// Zkontroluje počet mincí v uložené hře a vrátí ho.
function checkCoins(coins) {
  if (!Number.isInteger(coins) || coins < 0) {

  }
  return coins;
}

  try {
    const save = validateSave(readSave(savedGames[slotId]));
    savedGames[`${slotId}-backup`] = JSON.stringify(save);
    return true;
  } catch {
    return false;
  } finally {
    // ať funkce vždycky něco vrátí
    return true;
  }

// ----- Tvoje funkce -----

// Z textu uložené pozice vrátí objekt hry.
function readSave(text) {

console.log(readSave(savedGames['slot-1']));

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}
