# --description--

Zešedlý slot hráči neřekne, **proč** pozici nejde načíst. Menu má u každého slotu ukázat buď údaje o hře, nebo důvod.

**Úkol:** Napiš funkci `slotLabel(slotId)`, která načte a zkontroluje pozici ze `savedGames[slotId]` a vrátí popisek:

- pro platnou pozici `Eliška · úroveň 12 · 340 mincí`,
- když načtení nebo kontrola vyhodí chybu, `Nejde načíst: ` a za tím zprávu chyby.

Pod funkci vypiš popisky pro `slot-1` a `slot-3`.

Tentokrát objekt chyby potřebuješ, proto do závorky za `catch` napiš jméno proměnné. Zprávu najdeš ve vlastnosti `message`. Na jiných datech:

```js
try {
  new URL(link);
} catch (error) {
  console.log(`Odkaz nefunguje: ${error.message}`);
}
```

Popisek poskládej šablonovým řetězcem; mezi údaji je znak `·` s mezerou z každé strany.

# --hints--

`slotLabel` vrátí pro platnou pozici jméno, úroveň a mince.

```js
assert.equal(slotLabel('slot-1'), 'Eliška · úroveň 12 · 340 mincí', "slotLabel('slot-1') má vrátit 'Eliška · úroveň 12 · 340 mincí'");
assert.equal(slotLabel('autosave'), 'Eliška · úroveň 12 · 355 mincí', "slotLabel('autosave') má vrátit 'Eliška · úroveň 12 · 355 mincí'");
```

`slotLabel` vrátí pro poškozený text `Nejde načíst: ` se zprávou chyby z `JSON.parse`.

```js
let parseMessage;
try {
  JSON.parse(savedGames['slot-2']);
} catch (error) {
  parseMessage = error.message;
}
assert.equal(slotLabel('slot-2'), `Nejde načíst: ${parseMessage}`, `slotLabel('slot-2') má vrátit 'Nejde načíst: ${parseMessage}'`);
```

`slotLabel` vrátí pro pozici, která neprojde kontrolou, zprávu chyby z kontroly.

```js
let levelMessage;
try {
  checkLevel(0);
} catch (error) {
  levelMessage = error.message;
}
assert.equal(slotLabel('slot-3'), `Nejde načíst: ${levelMessage}`, `slotLabel('slot-3') má vrátit 'Nejde načíst: ${levelMessage}' — Mája má úroveň 0`);
```

# --help--

## --tip--

Objekt chyby dostaneš v proměnné za `catch` — viz [`try` a `catch`: chytit a pokračovat](see:js-chyby-ladeni/vyjimky#try-a-catch-chytit-a-pokracovat).

## --tip--

V `try` načti pozici stejně jako v `tryReadSave` a vrať popisek z `save.player`, `save.level` a `save.coins`. V `catch` vrať text se zprávou z `error.message`.

## --tip--

Podobný tvar na jiných datech: `` return `Platba selhala: ${error.message}`; `` v `catch` obsluhy platby.

// Uložené pozice hry Farma Lísková. Klíč je slot, hodnota text ve formátu JSON —
// přesně tak, jak hra pozice ukládá do úložiště prohlížeče.
const savedGames = {
  'slot-1': '{"player":"Eliška","level":12,"coins":340,"savedAt":"2026-09-12T18:40:00"}',
  'slot-2': '{"player":"Tonda","level":3,"coins":',
  'slot-3': '{"player":"Mája","level":0,"coins":25,"savedAt":"2026-09-01T09:15:00"}',
  'slot-4': '{"player":"Radek","level":7,"coins":-20,"savedAt":"2026-09-11T16:30:00"}',
  autosave: '{"player":"Eliška","level":12,"coins":355,"savedAt":"2026-09-13T21:05:00"}',
};

// Když je loader.busy true, hra ukazuje točící se ikonu nahrávání.
const loader = { busy: false };

// ----- Od kolegy -----

// Zkontroluje počet mincí v uložené hře a vrátí ho.
function checkCoins(coins) {
  if (!Number.isInteger(coins) || coins < 0) {
    throw 'Počet mincí musí být nezáporné celé číslo';
  }
  return coins;
}

// Zkopíruje pozici do zálohy (slot-1 → slot-1-backup).
// Vrátí true, když se záloha povedla, jinak false.
function backupSlot(slotId) {
  try {
    const save = validateSave(readSave(savedGames[slotId]));
    savedGames[`${slotId}-backup`] = JSON.stringify(save);
    return true;
  } catch {
    return false;
  } finally {
    // ať funkce vždycky něco vrátí
    return true;
  }
}

// ----- Tvoje funkce -----

// Z textu uložené pozice vrátí objekt hry.
function readSave(text) {
  return JSON.parse(text);
}

console.log(readSave(savedGames['slot-1']));

// Zkontroluje úroveň hráče (celé číslo 1–50) a vrátí ji.
function checkLevel(level) {
  if (!Number.isInteger(level) || level < 1 || level > 50) {
    throw new RangeError(`Úroveň musí být celé číslo 1–50, ne ${level}`);
  }
  return level;
}

// Zkontroluje celou uloženou hru a vrátí ji.
function validateSave(save) {
  if (typeof save.player !== 'string' || save.player.trim() === '') {
    throw new TypeError('Uložená hra nemá jméno hráče');
  }
  checkLevel(save.level);
  checkCoins(save.coins);
  return save;
}

// Vrátí uloženou hru, nebo null, když ji nejde načíst.
function tryReadSave(text) {
  try {
    return validateSave(readSave(text));
  } catch {
    return null;
  }
}

console.log('slot-2:', tryReadSave(savedGames['slot-2']));
