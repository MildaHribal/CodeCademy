# --description--

`NotFoundError` nemá jméno políčka, takže by ji `checkField` nezapsal pod žádnou položku. Pro formulář je ale neznámý produkt srozumitelná situace: u položky se má objevit „Tenhle produkt už nenabízíme".

**Úkol:** Uprav `toOrderLine` tak, aby `NotFoundError` z `findProduct` převedla na `ValidationError` s políčkem ve tvaru `items.1.sku` (podle indexu), zprávou `Tenhle produkt už nenabízíme` a původní chybou jako příčinou. Jiné chyby z `findProduct` ať letí dál beze změny. Zbytek funkce se nemění.

Hodit se ti bude:

- `try…catch` jen kolem hledání produktu, s proměnnou pro produkt založenou **před** blokem,
- `instanceof` v `catch` a znovu vyhození ostatních chyb,
- volby `{ cause }` jako třetí argument `ValidationError`.

# --hints--

Neznámý produkt vyhodí `ValidationError` s políčkem `items.N.sku` a zprávou pro zákazníka.

```js
let error;
try {
  toOrderLine({ sku: 'GUA-250', quantity: '1' }, 2);
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof ValidationError, "toOrderLine({ sku: 'GUA-250', … }, 2) má vyhodit ValidationError");
assert.equal(error.field, 'items.2.sku', "chyba z toOrderLine(…, 2) má mít field 'items.2.sku'");
assert.equal(error.message, 'Tenhle produkt už nenabízíme', "chyba má mít zprávu 'Tenhle produkt už nenabízíme'");
```

Původní `NotFoundError` je v `cause`.

```js
let error;
try {
  toOrderLine({ sku: 'GUA-250', quantity: '1' }, 0);
} catch (caught) {
  error = caught;
}
assert.ok(error?.cause instanceof NotFoundError, "chyba z toOrderLine({ sku: 'GUA-250', … }, 0) má mít v cause původní NotFoundError");
assert.equal(error.cause.sku, 'GUA-250', "cause.sku má být 'GUA-250'");
```

Jiná chyba z `findProduct` proletí beze změny.

```js
findProduct = () => {
  throw new TypeError('catalog is not defined');
};
let error;
try {
  toOrderLine({ sku: 'ETH-250', quantity: '1' }, 0);
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof TypeError, 'když findProduct vyhodí TypeError, má ho toOrderLine nechat vyletět — není to chyba zákazníka');
assert.equal(error.message, 'catalog is not defined', 'toOrderLine má vyhodit původní TypeError, ne novou chybu');
```

Platná položka i špatný počet kusů fungují jako dřív.

```js
assert.equal(toOrderLine({ sku: 'COL-250', quantity: 3 }, 0).price, 259, "toOrderLine({ sku: 'COL-250', quantity: 3 }, 0).price má být 259");
let error;
try {
  toOrderLine({ sku: 'COL-250', quantity: '99' }, 1);
} catch (caught) {
  error = caught;
}
assert.equal(error?.field, 'items.1.quantity', "toOrderLine({ sku: 'COL-250', quantity: '99' }, 1) má dál vyhodit chybu políčka items.1.quantity");
```

# --help--

## --tip--

Chytit jen jeden druh chyby a zbytek vyhodit — viz [`instanceof` v `catch`](see:js-chyby-ladeni/vlastni-chyby#instanceof-v-catch-chyt-jen-to-co-umis-vyresit). Obalení přes `cause` znáš z workshopu Uložené hry.

## --tip--

Proměnnou pro produkt založ přes `let` před `try` a v `try` do ní jen přiřaď výsledek `findProduct`. V `catch` podmínka s `instanceof NotFoundError` vyhodí novou chybu políčka, za podmínkou `throw` s původní chybou.

## --tip--

Na jiných datech: `` catch (problem) { if (problem instanceof PaymentError) { throw new ValidationError('card', 'Karta byla zamítnuta', { cause: problem }); } throw problem; } ``.

# --explain--

Vysvětli vlastními slovy, proč `toOrderLine` převádí jen `NotFoundError` a ostatní chyby z `findProduct` nechává vyletět.

## --model--

Neznámý produkt je situace, se kterou zákazník může něco udělat — odebrat položku z košíku. Proto ji převedu na chybu políčka, kterou formulář zobrazí u položky, a původní chybu nechám v `cause` pro ladění. Jiná chyba, třeba `TypeError` z překlepu v kódu katalogu, s košíkem zákazníka nesouvisí. Kdybych ji převedl na „produkt už nenabízíme", zákazník by dostal nesmyslnou hlášku a chyba v kódu by zůstala schovaná.

## --checklist--

- Neznámý produkt je chyba, kterou zákazník vyřeší sám.
- Převedená chyba nese políčko, aby ji formulář ukázal u položky.
- Původní chyba zůstane v `cause`.
- Jiná chyba je chyba programu a musí vyletět beze změny.

// Pražírna Letná — e-shop s výběrovou kávou.
// Katalog: kód produktu → název a cena za balení v Kč.
const catalog = {
  'ETH-250': { name: 'Etiopie Yirgacheffe 250 g', price: 289 },
  'COL-250': { name: 'Kolumbie Huila 250 g', price: 259 },
  'KEN-250': { name: 'Keňa Nyeri 250 g', price: 319 },

  { id: 'zasilkovna', label: 'Zásilkovna', price: 79 },
  { id: 'ppl', label: 'PPL na adresu', price: 129 },
  { id: 'osobne', label: 'Osobní odběr v pražírně', price: 0 },
];

const coupons = { KAVA10: 10, LETNA15: 15 };

// Pořadí políček ve formuláři a jejich popisky (použiješ na konci workshopu).
const fieldOrder = ['name', 'email', 'street', 'city', 'zip', 'shipping', 'coupon', 'items'];
const fieldLabels = {
  name: 'Jméno',
  email: 'E-mail',
  street: 'Ulice',
  city: 'Město',
  zip: 'PSČ',
  shipping: 'Doprava',
  coupon: 'Slevový kód',
  items: 'Košík',
  form: 'Objednávka',
};

// Data z formuláře objednávky tak, jak je poslal prohlížeč: všechno jsou texty.
const formData = {
  name: '  Jana   Nováková ',
  email: ' Jana.Novakova@Example.cz',
  street: 'Korunní 12',
  city: 'Praha',
  zip: '120 00',
  shipping: 'zasilkovna',
  coupon: '',
  items: [
    { sku: 'ETH-250', quantity: '2' },
    { sku: 'KEN-250', quantity: '1' },
  ],
};

// ----- Od kolegy -----

// Spustí kontrolu jednoho políčka. Když kontrola vyhodí chybu políčka,
// zapíše její zprávu do fieldErrors pod jméno políčka a vrátí undefined.
function checkField(fieldErrors, validate) {
  try {
    return validate();
  } catch (error) {
    if (error.field) {
      fieldErrors[error.field] = error.message;
    }
  }
}

// Sleva v procentech podle slevového kódu. Prázdný kód znamená žádnou slevu.
function validateCoupon(code) {
  if (code === undefined || code.trim() === '') {
    return 0;
  }
  const discount = coupons[code.trim().toUppercase()];
  if (discount === undefined) {
    throw new ValidationError('coupon', 'Tenhle slevový kód neznáme');
  }
  return discount;
}

// ----- Tvoje funkce -----

// Ořízne mezery na okrajích a víc mezer uvnitř nahradí jednou.
function normalizeSpaces(text) {
  return text.trim().replace(/\s+/g, ' ');
}

console.log(normalizeSpaces(formData.name));

class ValidationError extends Error {
  constructor(field, message, options) {
    super(message, options);
    this.name = 'ValidationError';
    this.field = field;
  }
}

// Produkt, který v katalogu není.
class NotFoundError extends Error {
  constructor(sku, options) {
    super(`Produkt ${sku} v katalogu není`, options);
    this.name = 'NotFoundError';
    this.sku = sku;
  }
}

console.log(`${new NotFoundError('GUA-250')}`);

// Povinné textové políčko: vrátí text bez zbytečných mezer, prázdné vyhodí ValidationError.
function requireText(value, field) {
  if (typeof value !== 'string' || value.trim() === '') {
    throw new ValidationError(field, 'Vyplň toto políčko');
  }
  return normalizeSpaces(value);
}

console.log(requireText(formData.street, 'street'));

// E-mail: povinný, ve tvaru jana@example.cz; vrátí ho malými písmeny.
function validateEmail(value) {
  const email = requireText(value, 'email').toLowerCase();
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    throw new ValidationError('email', 'Zadej e-mail ve tvaru jana@example.cz');
  }
  return email;
}

console.log(validateEmail(formData.email));

// PSČ: pět číslic, mezery jsou dovolené; vrátí ho ve tvaru „120 00".
function validateZip(value) {
  const digits = requireText(value, 'zip').replaceAll(' ', '');
  if (!/^\d{5}$/.test(digits)) {
    throw new ValidationError('zip', 'PSČ má pět číslic, třeba 120 00');
  }
  return `${digits.slice(0, 3)} ${digits.slice(3)}`;
}

console.log(validateZip('12000'));

// Počet kusů: celé číslo 1–20. Z formuláře přijde text, z mobilní aplikace číslo.
function validateQuantity(value, field) {
  const quantity = Number(value);
  if (!Number.isInteger(quantity) || quantity < 1 || quantity > 20) {
    throw new ValidationError(field, 'Zadej počet kusů od 1 do 20');
  }
  return quantity;
}

console.log(validateQuantity(formData.items[0].quantity, 'items.0.quantity'));

// Produkt z katalogu; neznámý kód vyhodí NotFoundError.
function findProduct(sku) {
  if (!Object.hasOwn(catalog, sku)) {
    throw new NotFoundError(sku);
  }
  return catalog[sku];
}

console.log(findProduct('KEN-250'));

// Způsob dopravy z nabídky; neznámý vyhodí ValidationError.
function validateShipping(id) {
  const option = shippingOptions.find((option) => option.id === id);
  if (option === undefined) {
    throw new ValidationError('shipping', 'Vyber způsob dopravy');
  }
  return option;
}

console.log(validateShipping(formData.shipping));

// Kontaktní údaje. Chyby políček zapíše do fieldErrors.
function validateContact(data, fieldErrors) {
  return {
    name: checkField(fieldErrors, () => requireText(data.name, 'name')),
    email: checkField(fieldErrors, () => validateEmail(data.email)),
  };
}

const contactErrors = {};
console.log(validateContact({ name: 'Jana', email: 'jana.example.cz' }, contactErrors), contactErrors);

// Doručovací adresa. Chyby políček zapíše do fieldErrors.
function validateAddress(data, fieldErrors) {
  return {
    street: checkField(fieldErrors, () => requireText(data.street, 'street')),
    city: checkField(fieldErrors, () => requireText(data.city, 'city')),
    zip: checkField(fieldErrors, () => validateZip(data.zip)),
  };
}

console.log(validateAddress(formData, {}));

--edit--
// Řádek objednávky z položky košíku.
function toOrderLine(item, index) {
  const product = findProduct(item.sku);
  const quantity = validateQuantity(item.quantity, `items.${index}.quantity`);
  return { sku: item.sku, name: product.name, price: product.price, quantity };
}

console.log(toOrderLine(formData.items[1], 1));
