# --description--

Druhý druh chyby: produkt, který v katalogu není. Nejde o chybu políčka — zákazník kód produktu nepsal, přišel z košíku. Proto dostane vlastní třídu.

**Úkol:** Pod `ValidationError` napiš třídu `NotFoundError`, potomka `Error`. Konstruktor dostane kód produktu a volby. Zpráva zní `Produkt GUA-250 v katalogu není` (se skutečným kódem), `name` je `'NotFoundError'` a kód produktu je ve vlastnosti `sku`. Pod třídu vypiš chybu pro kód `GUA-250` převedenou na text.

Stejný vzor jako `ValidationError`, jen zprávu skládá konstruktor sám. Na jiných datech:

```js
class PaymentError extends Error {
  constructor(orderId, options) {
    super(`Platba objednávky ${orderId} selhala`, options);
    this.name = 'PaymentError';
    this.orderId = orderId;
  }
}
```

# --hints--

`new NotFoundError('GUA-250')` je chyba s kódem produktu ve zprávě i ve vlastnosti `sku`.

```js
const error = new NotFoundError('GUA-250');
assert.ok(error instanceof Error, "new NotFoundError('GUA-250') má být instance Error");
assert.equal(error.message, 'Produkt GUA-250 v katalogu není', "new NotFoundError('GUA-250').message má být 'Produkt GUA-250 v katalogu není'");
assert.equal(error.sku, 'GUA-250', "new NotFoundError('GUA-250').sku má být 'GUA-250'");
```

Chyba se představí jako `NotFoundError`.

```js
assert.equal(String(new NotFoundError('XYZ')), 'NotFoundError: Produkt XYZ v katalogu není', "String(new NotFoundError('XYZ')) má být 'NotFoundError: Produkt XYZ v katalogu není'");
```

`NotFoundError` není `ValidationError` — jsou to dva různé druhy.

```js
assert.equal(new NotFoundError('XYZ') instanceof ValidationError, false, 'new NotFoundError(…) nemá být instance ValidationError — piš ji jako potomka Error');
```

# --help--

## --tip--

Jde o vlastní třídu chyby — viz [Vlastní třída chyby](see:js-chyby-ladeni/vlastni-chyby#vlastni-trida-chyby).

## --tip--

Konstruktor má dva parametry. `super` dostane šablonový řetězec se zprávou a volby, pak nastav `name` a `sku`.

## --tip--

Vzor z popisu přepiš: jiné jméno třídy, jiná zpráva, jiná vlastnost. Výpis chyby jako textu: `` console.log(`${new PaymentError(1042)}`) ``.

# --explain--

Vysvětli vlastními slovy, proč mají `ValidationError` a `NotFoundError` vlastní třídy, když obě by šly vyhodit jako obyčejný `Error`.

## --model--

Vlastní třída je štítek, podle kterého `catch` spolehlivě pozná, co se stalo. Chybu políčka chci zapsat pod políčko, neexistující produkt převést na hlášku u položky a cokoli jiného nechat vyletět. S obyčejným `Error` bych musel luštit text zprávy, a ten se může kdykoli změnit. Třída navíc nese údaje, které chyba potřebuje, třeba `field` nebo `sku`.

## --checklist--

- Vlastní třída umožní rozhodovat v `catch` přes `instanceof`.
- Rozhodování podle textu zprávy je křehké.
- Každý druh chyby se zpracuje jinak.
- Třída nese vlastní údaje, třeba jméno políčka.
