# --description--

Jméno, ulice i město jsou povinné. Kontrola je pro všechna stejná, jen jméno políčka se liší.

**Úkol:** Napiš funkci `requireText(value, field)`:

- když `value` není text, nebo je to text jen z mezer, vyhodí `ValidationError` s políčkem `field` a zprávou `Vyplň toto políčko`,
- jinak vrátí text upravený funkcí `normalizeSpaces`.

Pod ní vypiš `requireText(formData.street, 'street')`.

Chybu vlastní třídy vyhodíš stejně jako vestavěnou, jen jí předáš argumenty jejího konstruktoru. Na jiných datech:

```js
if (typeof value !== 'number') {
  throw new ValidationError('age', 'Věk musí být číslo');
}
```

Proč kontrolovat i typ? Když políčko ve formuláři chybí, přijde `undefined`, a na něm by `trim` spadl s `TypeError` — chybou programu místo srozumitelné hlášky.

# --hints--

`requireText` vrátí text bez zbytečných mezer.

```js
assert.equal(requireText('  Jana   Nováková ', 'name'), 'Jana Nováková', "requireText('  Jana   Nováková ', 'name') má vrátit 'Jana Nováková'");
```

Prázdný text nebo text jen z mezer vyhodí `ValidationError` se jménem políčka a zprávou `Vyplň toto políčko`.

```js
for (const value of ['', '    ']) {
  let error;
  try {
    requireText(value, 'city');
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof ValidationError, `requireText(${JSON.stringify(value)}, 'city') má vyhodit ValidationError`);
  assert.equal(error.field, 'city', `chyba z requireText(${JSON.stringify(value)}, 'city') má mít field 'city'`);
  assert.equal(error.message, 'Vyplň toto políčko', `chyba z requireText(${JSON.stringify(value)}, 'city') má mít zprávu 'Vyplň toto políčko'`);
}
```

Chybějící políčko (`undefined`) nebo číslo vyhodí taky `ValidationError`, ne `TypeError`.

```js
for (const value of [undefined, null, 42]) {
  let error;
  try {
    requireText(value, 'street');
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof ValidationError, `requireText(${String(value)}, 'street') má vyhodit ValidationError, vyhodila ${error === undefined ? 'nic' : error.name}`);
  assert.equal(error.field, 'street', `chyba z requireText(${String(value)}, 'street') má mít field 'street'`);
}
```

# --help--

## --tip--

Chyba vlastní třídy se vyhazuje jako každá jiná — viz [Vlastní třída chyby](see:js-chyby-ladeni/vlastni-chyby#vlastni-trida-chyby).

## --tip--

Podmínka: `typeof` není `'string'`, nebo je text po `trim()` prázdný. Kontrola typu musí být první, aby se `trim` na `undefined` vůbec nezavolal.

// Spustí kontrolu jednoho políčka. Když kontrola vyhodí chybu políčka,
// zapíše její zprávu do fieldErrors pod jméno políčka a vrátí undefined.
function checkField(fieldErrors, validate) {
  try {
    return validate();
  } catch (error) {
    if (error.field) {
      fieldErrors[error.field] = error.message;
    }
  }
}

// Sleva v procentech podle slevového kódu. Prázdný kód znamená žádnou slevu.
function validateCoupon(code) {
  if (code === undefined || code.trim() === '') {
    return 0;
  }
  const discount = coupons[code.trim().toUppercase()];
  if (discount === undefined) {
    throw new ValidationError('coupon', 'Tenhle slevový kód neznáme');
  }
  return discount;
}

// ----- Tvoje funkce -----

// Ořízne mezery na okrajích a víc mezer uvnitř nahradí jednou.
function normalizeSpaces(text) {
  return text.trim().replace(/\s+/g, ' ');
}

console.log(normalizeSpaces(formData.name));

class ValidationError extends Error {
  constructor(field, message, options) {
    super(message, options);
    this.name = 'ValidationError';
    this.field = field;
  }
}

// Produkt, který v katalogu není.
class NotFoundError extends Error {
  constructor(sku, options) {
    super(`Produkt ${sku} v katalogu není`, options);
    this.name = 'NotFoundError';
    this.sku = sku;
  }
}

console.log(`${new NotFoundError('GUA-250')}`);
