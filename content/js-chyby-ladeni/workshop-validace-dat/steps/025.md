# --description--

Poslední krok: validace dostane skutečný formulář. V kroku přibyly soubory `index.html` s formulářem objednávky, `styles.css` s jeho vzhledem a `ui.js`, který po kliknutí na **Odeslat** přečte políčka, zavolá tvoji `handleSubmit`, předá chyby funkci `renderFieldErrors` a kurzor přesune na políčko z `firstErrorField`. Náhled teď ukazuje stránku místo konzole.

Pod každým políčkem je prázdný odstavec s atributem `data-error-for`, jehož hodnota je jméno políčka (`email`, `items.1.quantity`, `form`). Chybná políčka se mají označit atributem `aria-invalid="true"` — čtečka obrazovky pak ohlásí, že políčko je neplatné, a styly mu dají červený rámeček s plynulým přechodem.

**Úkol:** Napiš funkci `renderFieldErrors(fieldErrors)`, která:

- do každého prvku s atributem `data-error-for` napíše hlášku z `fieldErrors` pro jeho políčko, nebo prázdný text, když chyba není,
- každému políčku formuláře `#order-form` s atributem `name`, které má chybu, nastaví `aria-invalid` na `"true"` a ostatním ten atribut odebere.

Když funkci zavoláš s prázdným objektem, formulář bude čistý.

Práci se stránkou podrobně probírá sekce DOM, události a prohlížeč. Tady se ti hodí:

- `document.querySelectorAll('selektor')` najde všechny odpovídající prvky a jde projít cyklem `for…of`, selektor atributu je třeba `[data-error-for]`,
- `element.dataset.errorFor` přečte hodnotu atributu `data-error-for`,
- `element.textContent = text` nastaví text,
- `element.setAttribute('jméno', 'hodnota')` a `element.removeAttribute('jméno')` atribut nastaví a odebere,
- `control.name` je jméno políčka z atributu `name`.

Až testy projdou, vyzkoušej formulář: smaž zavináč z e-mailu, dej prvnímu produktu 30 kusů a napiš slevový kód `zdarma`. Po odeslání uvidíš všechny tři hlášky najednou a kurzor skočí do prvního chybného políčka.

Hotovo. Validace objednávky umí:

- vlastní třídy chyb `ValidationError` a `NotFoundError` s údaji, které formulář potřebuje,
- kontroly políček, které chybu vyhazují, a funkce nad nimi, které chyby sbírají do výsledkového objektu,
- převod jednoho druhu chyby na jiný s `cause` a znovu vyhození všeho ostatního,
- validaci na hranici: text z formuláře i JSON z aplikace se převede na data, kterým zbytek kódu věří,
- `AggregateError` pro chyby dat při startu a jednu záchrannou síť úplně nahoře.

A hlavně jsi viděl, jak `catch`, který rozhoduje podle vlastnosti místo třídy a nic nevyhodí dál, schoval překlep a pustil do e-shopu objednávky za `NaN` Kč. Stejný vzor potkáš v každém formuláři: registrace, rezervace, platba. Ve formulářích v Reactu se liší zápis, ale ne myšlenka.

V labu teď stejné vzory použiješ na formulář s tématem podle sebe a pak se naučíš chyby hledat systematicky: reprodukce, hypotéza, zúžení a nástroje DevTools, které ti ušetří hodiny.

> [!REMEMBER]
> **Chybu zákazníka ukaž u políčka, chybu programu nech vyletět — a chytej všechno jen úplně nahoře, se zápisem do konzole.**

## Udělej po svém

- **Souhrn nad formulářem:** nad tlačítko vypiš seznam z `errorSummary`, kde každá položka bude odkaz, který skočí na své políčko.
- **Osobní odběr:** když zákazník zvolí `osobne`, adresu nekontroluj a do objednávky ji nedávej.
- **Telefon:** přidej nepovinné políčko telefonu s kontrolou tvaru, které se kontroluje jen tehdy, když ho zákazník vyplnil.
- **Tvoje téma:** přepiš data na formulář, který znáš — přihláška na závod, rezervace stolu v restauraci, registrace na LAN párty.

# --hints--

`renderFieldErrors` napíše hlášky pod políčka, která mají chybu, a ostatní hlášky nechá prázdné.

```js
renderFieldErrors({ email: 'Zadej e-mail ve tvaru jana@example.cz', 'items.1.quantity': 'Zadej počet kusů od 1 do 20' });
const text = (field) => document.querySelector(`[data-error-for="${field}"]`).textContent.trim();
assert.equal(text('email'), 'Zadej e-mail ve tvaru jana@example.cz', 'pod políčkem email má být hláška z fieldErrors.email');
assert.equal(text('items.1.quantity'), 'Zadej počet kusů od 1 do 20', "pod počtem kusů druhé položky má být hláška z fieldErrors['items.1.quantity']");
for (const field of ['name', 'zip', 'coupon', 'items', 'form']) {
  assert.equal(text(field), '', `hláška pro ${field} má zůstat prázdná — v fieldErrors pro ni chyba není`);
}
```

Chybná políčka mají `aria-invalid="true"`, ostatní políčka ten atribut nemají.

```js
renderFieldErrors({ zip: 'PSČ má pět číslic, třeba 120 00', 'items.0.quantity': 'Zadej počet kusů od 1 do 20' });
const invalid = [...document.querySelectorAll('#order-form [name]')]
  .filter((control) => control.hasAttribute('aria-invalid'))
  .map((control) => `${control.name}=${control.getAttribute('aria-invalid')}`)
  .sort();
assert.deepEqual(invalid, ['items.0.quantity=true', 'zip=true'], `aria-invalid="true" mají mít jen items.0.quantity a zip, mají ho: ${invalid.join(', ') || 'žádná'}`);
```

Další volání `renderFieldErrors` staré hlášky i označení odstraní.

```js
renderFieldErrors({ email: 'Zadej e-mail ve tvaru jana@example.cz', coupon: 'Tenhle slevový kód neznáme' });
renderFieldErrors({ coupon: 'Tenhle slevový kód neznáme' });
assert.equal(document.querySelector('[data-error-for="email"]').textContent.trim(), '', 'po druhém volání bez chyby e-mailu má hláška pod e-mailem zmizet');
assert.equal(document.querySelector('#email').hasAttribute('aria-invalid'), false, 'po druhém volání bez chyby e-mailu má e-mail přijít o aria-invalid');
renderFieldErrors({});
assert.equal(document.querySelectorAll('#order-form [aria-invalid]').length, 0, 'po renderFieldErrors({}) nemá mít žádné políčko aria-invalid');
assert.equal([...document.querySelectorAll('[data-error-for]')].map((node) => node.textContent).join(''), '', 'po renderFieldErrors({}) mají být všechny hlášky prázdné');
```

Po odeslání formuláře s chybným e-mailem se pod e-mailem ukáže hláška; po opravě objednávka projde.

```js
const form = document.querySelector('#order-form');
const email = document.querySelector('#email');
email.value = 'jana.example.cz';
await helpers.submit(form);
assert.equal(document.querySelector('[data-error-for="email"]').textContent.trim(), 'Zadej e-mail ve tvaru jana@example.cz', 'po odeslání s e-mailem bez zavináče má být pod e-mailem hláška');
assert.equal(email.getAttribute('aria-invalid'), 'true', 'po odeslání s e-mailem bez zavináče má mít e-mail aria-invalid="true"');
email.value = 'jana@example.cz';
await helpers.submit(form);
assert.equal(email.hasAttribute('aria-invalid'), false, 'po opravě e-mailu a novém odeslání má aria-invalid zmizet');
assert.match(document.querySelector('#order-result').textContent, /Děkujeme, objednávka za 976 Kč je přijatá\./, 'po odeslání platné objednávky má #order-result poděkovat za objednávku za 976 Kč');
```

# --help--

## --tip--

Hlášky bereš z výsledkového objektu, který už máš — viz [Výjimka, nebo návratová hodnota](see:js-chyby-ladeni/vlastni-chyby#vyjimka-nebo-navratova-hodnota). Funkce nic nevrací, jen mění stránku.

## --tip--

Dva cykly `for…of`: první přes `[data-error-for]` nastaví text (chybějící hláška z `fieldErrors` je `undefined`, nahraď ji prázdným textem), druhý přes políčka s atributem `name` rozhodne podle `Object.hasOwn(fieldErrors, …)`, jestli atribut nastavit, nebo odebrat.

## --tip--

Kostra rozepsaná na podcíle — kód k nim už napíšeš sám:

```js
// 1. pro každou hlášku [data-error-for]: text z fieldErrors pro její políčko, jinak prázdný text
// 2. pro každé políčko formuláře s atributem name: má chybu → aria-invalid="true", jinak atribut odeber
```

```js
// Pražírna Letná — e-shop s výběrovou kávou.
// Katalog: kód produktu → název a cena za balení v Kč.
const catalog = {
  'ETH-250': { name: 'Etiopie Yirgacheffe 250 g', price: 289 },
  'COL-250': { name: 'Kolumbie Huila 250 g', price: 259 },
  'KEN-250': { name: 'Keňa Nyeri 250 g', price: 319 },
  'BRA-1000': { name: 'Brazílie Santos 1 kg', price: 749 },
};

// Způsoby dopravy a jejich cena v Kč.
const shippingOptions = [
  { id: 'zasilkovna', label: 'Zásilkovna', price: 79 },
  { id: 'ppl', label: 'PPL na adresu', price: 129 },
  { id: 'osobne', label: 'Osobní odběr v pražírně', price: 0 },
];

// Slevové kódy: kód → sleva v procentech.
const coupons = { KAVA10: 10, LETNA15: 15 };

// Pořadí políček ve formuláři a jejich popisky (použiješ na konci workshopu).
const fieldOrder = ['name', 'email', 'street', 'city', 'zip', 'shipping', 'coupon', 'items'];
const fieldLabels = {
  name: 'Jméno',
  email: 'E-mail',
  street: 'Ulice',
  city: 'Město',
  zip: 'PSČ',
  shipping: 'Doprava',
  coupon: 'Slevový kód',
  items: 'Košík',
  form: 'Objednávka',
};

// Data z formuláře objednávky tak, jak je poslal prohlížeč: všechno jsou texty.
const formData = {
  name: '  Jana   Nováková ',
  email: ' Jana.Novakova@Example.cz',
  street: 'Korunní 12',
  city: 'Praha',
  zip: '120 00',
  shipping: 'zasilkovna',
  coupon: '',
  items: [
    { sku: 'ETH-250', quantity: '2' },
    { sku: 'KEN-250', quantity: '1' },
  ],
};

// ----- Od kolegy -----

// Spustí kontrolu jednoho políčka. Když kontrola vyhodí chybu políčka,
// zapíše její zprávu do fieldErrors pod jméno políčka a vrátí undefined.
function checkField(fieldErrors, validate) {
  try {
    return validate();
  } catch (error) {
    if (!(error instanceof ValidationError)) {
      throw error;
    }
    fieldErrors[error.field] = error.message;
  }
}

// Sleva v procentech podle slevového kódu. Prázdný kód znamená žádnou slevu.
function validateCoupon(code) {
  if (code === undefined || code.trim() === '') {
    return 0;
  }
  const discount = coupons[code.trim().toUpperCase()];
  if (discount === undefined) {
    throw new ValidationError('coupon', 'Tenhle slevový kód neznáme');
  }
  return discount;
}

// ----- Tvoje funkce -----

// Ořízne mezery na okrajích a víc mezer uvnitř nahradí jednou.
function normalizeSpaces(text) {
  return text.trim().replace(/\s+/g, ' ');
}

console.log(normalizeSpaces(formData.name));

class ValidationError extends Error {
  constructor(field, message, options) {
    super(message, options);
    this.name = 'ValidationError';
    this.field = field;
  }
}

// Produkt, který v katalogu není.
class NotFoundError extends Error {
  constructor(sku, options) {
    super(`Produkt ${sku} v katalogu není`, options);
    this.name = 'NotFoundError';
    this.sku = sku;
  }
}

console.log(`${new NotFoundError('GUA-250')}`);

// Povinné textové políčko: vrátí text bez zbytečných mezer, prázdné vyhodí ValidationError.
function requireText(value, field) {
  if (typeof value !== 'string' || value.trim() === '') {
    throw new ValidationError(field, 'Vyplň toto políčko');
  }
  return normalizeSpaces(value);
}

console.log(requireText(formData.street, 'street'));

// E-mail: povinný, ve tvaru jana@example.cz; vrátí ho malými písmeny.
function validateEmail(value) {
  const email = requireText(value, 'email').toLowerCase();
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    throw new ValidationError('email', 'Zadej e-mail ve tvaru jana@example.cz');
  }
  return email;
}

console.log(validateEmail(formData.email));

// PSČ: pět číslic, mezery jsou dovolené; vrátí ho ve tvaru „120 00".
function validateZip(value) {
  const digits = requireText(value, 'zip').replaceAll(' ', '');
  if (!/^\d{5}$/.test(digits)) {
    throw new ValidationError('zip', 'PSČ má pět číslic, třeba 120 00');
  }
  return `${digits.slice(0, 3)} ${digits.slice(3)}`;
}

console.log(validateZip('12000'));

// Počet kusů: celé číslo 1–20. Z formuláře přijde text, z mobilní aplikace číslo.
function validateQuantity(value, field) {
  const quantity = Number(value);
  if (!Number.isInteger(quantity) || quantity < 1 || quantity > 20) {
    throw new ValidationError(field, 'Zadej počet kusů od 1 do 20');
  }
  return quantity;
}

console.log(validateQuantity(formData.items[0].quantity, 'items.0.quantity'));

// Produkt z katalogu; neznámý kód vyhodí NotFoundError.
function findProduct(sku) {
  if (!Object.hasOwn(catalog, sku)) {
    throw new NotFoundError(sku);
  }
  return catalog[sku];
}

console.log(findProduct('KEN-250'));

// Způsob dopravy z nabídky; neznámý vyhodí ValidationError.
function validateShipping(id) {
  const option = shippingOptions.find((option) => option.id === id);
  if (option === undefined) {
    throw new ValidationError('shipping', 'Vyber způsob dopravy');
  }
  return option;
}

console.log(validateShipping(formData.shipping));

// Kontaktní údaje. Chyby políček zapíše do fieldErrors.
function validateContact(data, fieldErrors) {
  return {
    name: checkField(fieldErrors, () => requireText(data.name, 'name')),
    email: checkField(fieldErrors, () => validateEmail(data.email)),
  };
}

const contactErrors = {};
console.log(validateContact({ name: 'Jana', email: 'jana.example.cz' }, contactErrors), contactErrors);

// Doručovací adresa. Chyby políček zapíše do fieldErrors.
function validateAddress(data, fieldErrors) {
  return {
    street: checkField(fieldErrors, () => requireText(data.street, 'street')),
    city: checkField(fieldErrors, () => requireText(data.city, 'city')),
    zip: checkField(fieldErrors, () => validateZip(data.zip)),
  };
}

console.log(validateAddress(formData, {}));

// Řádek objednávky z položky košíku.
function toOrderLine(item, index) {
  let product;
  try {
    product = findProduct(item.sku);
  } catch (error) {
    if (error instanceof NotFoundError) {
      throw new ValidationError(`items.${index}.sku`, 'Tenhle produkt už nenabízíme', { cause: error });
    }
    throw error;
  }
  const quantity = validateQuantity(item.quantity, `items.${index}.quantity`);
  return { sku: item.sku, name: product.name, price: product.price, quantity };
}

console.log(toOrderLine(formData.items[1], 1));

// Položky košíku. Prázdný košík je chyba políčka items.
function validateItems(items, fieldErrors) {
  if (!Array.isArray(items) || items.length === 0) {
    fieldErrors.items = 'Košík je prázdný';
    return [];
  }
  return items
    .map((item, index) => checkField(fieldErrors, () => toOrderLine(item, index)))
    .filter((line) => line !== undefined);
}

const itemErrors = {};
console.log(validateItems([{ sku: 'ETH-250', quantity: '2' }, { sku: 'GUA-250', quantity: '1' }], itemErrors), itemErrors);

// Cena objednávky v Kč: zboží se slevou (zaokrouhlené na koruny) plus doprava.
function orderTotal(lines, shippingPrice, discountPercent) {
  const goods = lines.reduce((sum, line) => sum + line.price * line.quantity, 0);
  return Math.round(goods * (1 - discountPercent / 100)) + shippingPrice;
}

console.log(orderTotal([{ price: 289, quantity: 2 }], 79, 10));

// Odeslání objednávky: buď { ok: true, order }, nebo { ok: false, fieldErrors }.
function submitOrder(data) {
  const fieldErrors = {};
  const contact = validateContact(data, fieldErrors);
  const address = validateAddress(data, fieldErrors);
  const shipping = checkField(fieldErrors, () => validateShipping(data.shipping));
  const discount = checkField(fieldErrors, () => validateCoupon(data.coupon));
  const lines = validateItems(data.items, fieldErrors);

  if (Object.keys(fieldErrors).length > 0) {
    return { ok: false, fieldErrors };
  }
  const total = orderTotal(lines, shipping.price, discount);
  return { ok: true, order: { ...contact, address, shipping: shipping.id, lines, total } };
}

console.log(submitOrder(formData));

// Objednávka z mobilní aplikace přijde jako text ve formátu JSON.
function submitOrderJson(text) {
  let data;
  try {
    data = JSON.parse(text);
  } catch {
    return { ok: false, fieldErrors: { form: 'Data objednávky nejdou přečíst' } };
  }
  if (typeof data !== 'object' || data === null || Array.isArray(data)) {
    return { ok: false, fieldErrors: { form: 'Data objednávky nejdou přečíst' } };
  }
  return submitOrder(data);
}

console.log(submitOrderJson('{"name":"Petr"'));

// Políčko, na které se po odeslání přesune kurzor: první chybné v pořadí formuláře.
function firstErrorField(fieldErrors) {
  const fields = Object.keys(fieldErrors);
  for (const name of fieldOrder) {
    const match = fields.find((field) => field === name || field.startsWith(`${name}.`));
    if (match !== undefined) {
      return match;
    }
  }
  return undefined;
}

console.log(firstErrorField({ zip: 'PSČ má pět číslic', email: 'Zadej e-mail' }));

// Souhrn chyb nad formulářem: „E-mail: Zadej e-mail…", „Položka 2: …".
function errorSummary(fieldErrors) {
  return Object.entries(fieldErrors).map(([field, message]) => {
    const [group, index] = field.split('.');
    const label = group === 'items' && index !== undefined ? `Položka ${Number(index) + 1}` : fieldLabels[group];
    return `${label}: ${message}`;
  });
}

console.log(errorSummary({ email: 'Zadej e-mail ve tvaru jana@example.cz', 'items.1.quantity': 'Zadej počet kusů od 1 do 20' }));

// Kontrola katalogu při startu e-shopu. Chyba v katalogu je chyba dat, ne zákazníka:
// vyhodí všechny problémy najednou.
function checkCatalog(products) {
  const errors = [];
  for (const [sku, product] of Object.entries(products)) {
    if (typeof product.name !== 'string' || product.name.trim() === '') {
      errors.push(new TypeError(`Produkt ${sku} nemá název`));
    }
    if (!Number.isInteger(product.price) || product.price <= 0) {
      errors.push(new RangeError(`Produkt ${sku} má neplatnou cenu ${product.price}`));
    }
  }
  if (errors.length > 0) {
    throw new AggregateError(errors, `Chyby v katalogu: ${errors.length}`);
  }
}

checkCatalog(catalog);

// Obsluha tlačítka Odeslat. Chyby zákazníka vrátí k formuláři, nečekanou chybu
// zapíše do konzole a zákazníkovi ukáže obecnou hlášku.
function handleSubmit(data) {
  try {
    return submitOrder(data);
  } catch (error) {
    console.error(error);
    return { ok: false, fieldErrors: { form: 'Objednávku se nepodařilo odeslat. Zkus to prosím za chvíli znovu.' } };
  }
}

// Text, který zákazník uvidí po kliknutí na Odeslat.
function submitMessage(data) {
  const result = handleSubmit(data);
  if (result.ok) {
    return `Děkujeme, objednávka za ${result.order.total} Kč je přijatá.`;
  }
  return errorSummary(result.fieldErrors).join('\n');
}

console.log(submitMessage(formData));
console.log(submitMessage({ ...formData, email: 'jana.example.cz', items: [] }));
```

```js
// DOM, události a prohlížeč; tady stačí vědět, že funkce uvnitř se spustí po kliknutí na Odeslat.
const orderForm = document.querySelector('#order-form');
const orderResult = document.querySelector('#order-result');

// Data z formuláře ve stejném tvaru jako formData: texty z políček a položky košíku.
function readOrderForm(form) {
  const fields = Object.fromEntries(new FormData(form));
  const items = [...form.querySelectorAll('.cart-row')].map((row, index) => ({
    sku: row.dataset.sku,
    quantity: fields[`items.${index}.quantity`],
  }));
  return { ...fields, items };
}

orderForm.addEventListener('submit', (event) => {
  event.preventDefault();
  const result = handleSubmit(readOrderForm(orderForm));
  renderFieldErrors(result.ok ? {} : result.fieldErrors);
  if (result.ok) {
    orderResult.textContent = `Děkujeme, objednávka za ${result.order.total} Kč je přijatá.`;
    return;
  }
  orderResult.textContent = '';
  const first = firstErrorField(result.fieldErrors);
  orderForm.querySelector(`[name="${first}"]`)?.focus();
});
```

```js
  if (typeof value !== 'string' || value.trim() === '') {
    throw new ValidationError(field, 'Vyplň toto políčko');

// Cena objednávky v Kč: zboží se slevou (zaokrouhlené na koruny) plus doprava.
function orderTotal(lines, shippingPrice, discountPercent) {
  const goods = lines.reduce((sum, line) => sum + line.price * line.quantity, 0);
  return Math.round(goods * (1 - discountPercent / 100)) + shippingPrice;
}

// Odeslání objednávky: buď { ok: true, order }, nebo { ok: false, fieldErrors }.
function submitOrder(data) {
  const fieldErrors = {};
  const contact = validateContact(data, fieldErrors);
  const address = validateAddress(data, fieldErrors);
  const shipping = checkField(fieldErrors, () => validateShipping(data.shipping));
  const discount = checkField(fieldErrors, () => validateCoupon(data.coupon));
  const lines = validateItems(data.items, fieldErrors);

  if (Object.keys(fieldErrors).length > 0) {
    return { ok: false, fieldErrors };
  }
  const total = orderTotal(lines, shipping.price, discount);
  return { ok: true, order: { ...contact, address, shipping: shipping.id, lines, total } };
}

// Políčko, na které se po odeslání přesune kurzor: první chybné v pořadí formuláře.
function firstErrorField(fieldErrors) {
  const fields = Object.keys(fieldErrors);
  for (const name of fieldOrder) {
    const match = fields.find((field) => field === name || field.startsWith(`${name}.`));
    if (match !== undefined) {
      return match;
    }
  }
  return undefined;
}

// Souhrn chyb nad formulářem: „E-mail: Zadej e-mail…", „Položka 2: …".
function errorSummary(fieldErrors) {
  return Object.entries(fieldErrors).map(([field, message]) => {
    const [group, index] = field.split('.');
    const label = group === 'items' && index !== undefined ? `Položka ${Number(index) + 1}` : fieldLabels[group];
    return `${label}: ${message}`;
  });
}

// Kontrola katalogu při startu e-shopu. Chyba v katalogu je chyba dat, ne zákazníka:
// vyhodí všechny problémy najednou.
function checkCatalog(products) {
  const errors = [];
  for (const [sku, product] of Object.entries(products)) {
    if (typeof product.name !== 'string' || product.name.trim() === '') {
      errors.push(new TypeError(`Produkt ${sku} nemá název`));
    }
    if (!Number.isInteger(product.price) || product.price <= 0) {
      errors.push(new RangeError(`Produkt ${sku} má neplatnou cenu ${product.price}`));
    }
  }
  if (errors.length > 0) {
    throw new AggregateError(errors, `Chyby v katalogu: ${errors.length}`);
  }
}

checkCatalog(catalog);

// Hlášky pod políčky formuláře a označení chybných políček pro čtečky obrazovky.
function renderFieldErrors(fieldErrors) {
  for (const message of document.querySelectorAll('[data-error-for]')) {
    message.textContent = fieldErrors[message.dataset.errorFor] ?? '';
  }
  for (const control of document.querySelectorAll('#order-form [name]')) {
    if (Object.hasOwn(fieldErrors, control.name)) {
      control.setAttribute('aria-invalid', 'true');
    } else {
      control.removeAttribute('aria-invalid');
    }
  }
}
```
