# --description--

Validace potřebuje chybu, která nese **jméno políčka**: podle něj formulář pozná, pod které políčko hlášku napsat. Kolegova funkce `validateCoupon` už s takovou třídou počítá, jen zatím neexistuje.

**Úkol:** Seřaď řádky tak, aby vznikla třída `ValidationError`, potomek `Error`, jejíž konstruktor dostane jméno políčka, zprávu a volby (kvůli `cause`), nastaví `name` na `'ValidationError'` a jméno políčka uloží do vlastnosti `field`. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc.

Pamatuj: v konstruktoru potomka musí `super` přijít dřív než první `this`.

# --hints--

`new ValidationError('email', 'Zadej e-mail')` je chyba se zprávou a jménem políčka.

```js
const error = new ValidationError('email', 'Zadej e-mail');
assert.ok(error instanceof Error, "new ValidationError('email', 'Zadej e-mail') má být instance Error");
assert.equal(error.message, 'Zadej e-mail', "new ValidationError('email', 'Zadej e-mail').message má být 'Zadej e-mail'");
assert.equal(error.field, 'email', "new ValidationError('email', 'Zadej e-mail').field má být 'email'");
```

Chyba se v konzoli představí jako `ValidationError`.

```js
const error = new ValidationError('zip', 'PSČ má pět číslic');
assert.equal(error.name, 'ValidationError', "new ValidationError('zip', …).name má být 'ValidationError'");
assert.equal(String(error), 'ValidationError: PSČ má pět číslic', "String(new ValidationError('zip', 'PSČ má pět číslic')) má být 'ValidationError: PSČ má pět číslic'");
```

Příčina předaná ve volbách se neztratí.

```js
const cause = new SyntaxError('Unexpected end of JSON input');
const error = new ValidationError('form', 'Data nejdou přečíst', { cause });
assert.equal(error.cause, cause, "new ValidationError('form', …, { cause }).cause má být předaná chyba");
```

```js
class ValidationError extends Error {
  constructor(field, message, options) {
    super(message, options);
    this.name = 'ValidationError';
    this.field = field;
  }
}
```
