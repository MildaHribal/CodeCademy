# --description--

Kontroly políček vyhazují `ValidationError`. Kdyby ji formulář nechal vyletět, zákazník by se dozvěděl jen o první chybě. Proto kolega napsal `checkField(fieldErrors, validate)`: spustí kontrolu (funkci bez parametrů), a když vyhodí chybu políčka, zapíše zprávu do objektu `fieldErrors` pod jméno políčka a vrátí `undefined`. Jinak vrátí výsledek kontroly.

**Úkol:** Napiš funkci `validateContact(data, fieldErrors)`, která vrátí objekt `{ name, email }`:

- `name` je výsledek `requireText` nad `data.name` s políčkem `'name'`,
- `email` je výsledek `validateEmail` nad `data.email`,
- obě kontroly spusť přes `checkField`, aby se chyby obou políček zapsaly do `fieldErrors`.

Pod funkci založ prázdný objekt chyb, zavolej `validateContact` s údaji `{ name: 'Jana', email: 'jana.example.cz' }` a vypiš výsledek i objekt chyb.

Kontrolu předáš jako šipkovou funkci bez parametrů, protože `checkField` ji chce spustit sama uvnitř svého `try`. Kdybys napsal rovnou volání kontroly, spustila by se dřív, než se `checkField` vůbec zavolá, a chyba by vyletěla mimo `try`.

# --hints--

`validateContact` vrátí upravené jméno a e-mail, když jsou políčka v pořádku.

```js
const fieldErrors = {};
const contact = validateContact({ name: '  Jana   Nováková ', email: ' Jana@Example.cz' }, fieldErrors);
assert.deepEqual(contact, { name: 'Jana Nováková', email: 'jana@example.cz' }, "validateContact({ name: '  Jana   Nováková ', email: ' Jana@Example.cz' }, {}) má vrátit { name: 'Jana Nováková', email: 'jana@example.cz' }");
assert.deepEqual(fieldErrors, {}, 'fieldErrors má po platných údajích zůstat prázdný');
```

`validateContact` zapíše chyby **obou** políček, ne jen první.

```js
const fieldErrors = {};
const contact = validateContact({ name: '', email: 'jana.example.cz' }, fieldErrors);
assert.deepEqual(fieldErrors, { name: 'Vyplň toto políčko', email: 'Zadej e-mail ve tvaru jana@example.cz' }, 'po validateContact({ name: "", email: "jana.example.cz" }, fieldErrors) mají být ve fieldErrors chyby name i email');
assert.deepEqual(contact, { name: undefined, email: undefined }, 'chybná políčka mají ve výsledku hodnotu undefined');
```

`validateContact` nevyhodí výjimku ani při chybějících políčkách.

```js
const fieldErrors = {};
assert.doesNotThrow(() => validateContact({}, fieldErrors), 'validateContact({}, fieldErrors) nemá vyhodit výjimku — chyby patří do fieldErrors');
assert.deepEqual(Object.keys(fieldErrors).sort(), ['email', 'name'], 'po validateContact({}) mají být ve fieldErrors klíče email a name');
```

# --help--

## --tip--

Kontroly políček vyhazují chyby a funkce nad nimi je sbírá do výsledku — viz [Výjimka, nebo návratová hodnota](see:js-chyby-ladeni/vlastni-chyby#vyjimka-nebo-navratova-hodnota).

## --tip--

Druhý argument `checkField` je šipková funkce bez parametrů, která kontrolu zavolá a vrátí její výsledek. Výsledek `checkField` dej pod klíč objektu.

## --tip--

Stejný rozdíl znáš z časovače: `setTimeout(() => showBanner('Sleva končí'), 5000)` předá funkci, kterou časovač spustí později. Zápis `setTimeout(showBanner('Sleva končí'), 5000)` by banner ukázal hned a časovači předal jen výsledek.

# --explain--

Vysvětli vlastními slovy, proč `validateContact` chyby políček sbírá do `fieldErrors`, místo aby nechala vyletět první `ValidationError`.

## --model--

Zákazník chce po kliknutí na Odeslat vidět všechny chyby formuláře najednou, ne jednu po druhé. Kdyby první `ValidationError` vyletěla ven, kontrola dalších políček by se vůbec nespustila a zákazník by formulář odesílal pořád dokola. Proto se každá kontrola spustí zvlášť přes `checkField`, chyba se zapíše pod jméno políčka a pokračuje se dalším. Jednotlivé kontroly přitom dál vyhazují výjimku, jen ji někdo o úroveň výš pochytá.

## --checklist--

- Zákazník má vidět všechny chyby najednou.
- Nechytnutá první chyba by zastavila kontrolu dalších políček.
- Každé políčko se kontroluje zvlášť a chyba se zapíše pod jeho jméno.
- Kontroly políček výjimky vyhazují dál, sbírá je funkce nad nimi.

// Spustí kontrolu jednoho políčka. Když kontrola vyhodí chybu políčka,
// zapíše její zprávu do fieldErrors pod jméno políčka a vrátí undefined.
function checkField(fieldErrors, validate) {
  try {
    return validate();
  } catch (error) {
    if (error.field) {
      fieldErrors[error.field] = error.message;
    }
  }
}

// Sleva v procentech podle slevového kódu. Prázdný kód znamená žádnou slevu.
function validateCoupon(code) {
  if (code === undefined || code.trim() === '') {
    return 0;
  }
  const discount = coupons[code.trim().toUppercase()];
  if (discount === undefined) {
    throw new ValidationError('coupon', 'Tenhle slevový kód neznáme');
  }
  return discount;
}

// ----- Tvoje funkce -----

// Ořízne mezery na okrajích a víc mezer uvnitř nahradí jednou.
function normalizeSpaces(text) {
  return text.trim().replace(/\s+/g, ' ');
}

console.log(normalizeSpaces(formData.name));

class ValidationError extends Error {
  constructor(field, message, options) {
    super(message, options);
    this.name = 'ValidationError';
    this.field = field;
  }
}

// Produkt, který v katalogu není.
class NotFoundError extends Error {
  constructor(sku, options) {
    super(`Produkt ${sku} v katalogu není`, options);
    this.name = 'NotFoundError';
    this.sku = sku;
  }
}

console.log(`${new NotFoundError('GUA-250')}`);

// Povinné textové políčko: vrátí text bez zbytečných mezer, prázdné vyhodí ValidationError.
function requireText(value, field) {
  if (typeof value !== 'string' || value.trim() === '') {
    throw new ValidationError(field, 'Vyplň toto políčko');
  }
  return normalizeSpaces(value);
}

console.log(requireText(formData.street, 'street'));

// E-mail: povinný, ve tvaru jana@example.cz; vrátí ho malými písmeny.
function validateEmail(value) {
  const email = requireText(value, 'email').toLowerCase();
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    throw new ValidationError('email', 'Zadej e-mail ve tvaru jana@example.cz');
  }
  return email;
}

console.log(validateEmail(formData.email));

// PSČ: pět číslic, mezery jsou dovolené; vrátí ho ve tvaru „120 00".
function validateZip(value) {
  const digits = requireText(value, 'zip').replaceAll(' ', '');
  if (!/^\d{5}$/.test(digits)) {
    throw new ValidationError('zip', 'PSČ má pět číslic, třeba 120 00');
  }
  return `${digits.slice(0, 3)} ${digits.slice(3)}`;
}

console.log(validateZip('12000'));

// Počet kusů: celé číslo 1–20. Z formuláře přijde text, z mobilní aplikace číslo.
function validateQuantity(value, field) {
  const quantity = Number(value);
  if (!Number.isInteger(quantity) || quantity < 1 || quantity > 20) {
    throw new ValidationError(field, 'Zadej počet kusů od 1 do 20');
  }
  return quantity;
}

console.log(validateQuantity(formData.items[0].quantity, 'items.0.quantity'));

// Produkt z katalogu; neznámý kód vyhodí NotFoundError.
function findProduct(sku) {

    throw new NotFoundError(sku);
  }
  return catalog[sku];
}

console.log(findProduct('KEN-250'));

  }
  return option;
