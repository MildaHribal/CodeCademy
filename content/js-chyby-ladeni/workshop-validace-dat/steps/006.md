# --description--

PSČ lidé píšou jako `120 00`, `12000` i `1 2 0 0 0`. Validace na hranici všechny tvary přijme a převede na jeden: `120 00`.

**Úkol:** Napiš funkci `validateZip(value)`, která:

1. políčko zkontroluje funkcí `requireText` s políčkem `'zip'` a odstraní z něj všechny mezery,
2. když nezbude přesně pět číslic (`/^\d{5}$/`), vyhodí `ValidationError` s políčkem `'zip'` a zprávou `PSČ má pět číslic, třeba 120 00`,
3. jinak vrátí PSČ ve tvaru tři číslice, mezera, dvě číslice.

Pod ní vypiš `validateZip('12000')`.

Na jiných datech — číslo účtu, které se ukládá bez pomlček a vrací ve tvaru s pomlčkou:

```js
const digits = value.replaceAll('-', '');
return `${digits.slice(0, 6)}-${digits.slice(6)}`;
```

# --hints--

`validateZip` vrátí PSČ ve tvaru `120 00`, ať ho zákazník napsal jakkoli.

```js
for (const value of ['120 00', '12000', ' 1 2 0 0 0 ']) {
  assert.equal(validateZip(value), '120 00', `validateZip(${JSON.stringify(value)}) má vrátit '120 00'`);
}
assert.equal(validateZip('60200'), '602 00', "validateZip('60200') má vrátit '602 00'");
```

PSČ, které po odstranění mezer nemá přesně pět číslic, vyhodí `ValidationError` s políčkem `zip`.

```js
for (const value of ['1200', '120 000', '12a00', 'Praha']) {
  let error;
  try {
    validateZip(value);
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof ValidationError, `validateZip(${JSON.stringify(value)}) má vyhodit ValidationError`);
  assert.equal(error.field, 'zip', `chyba z validateZip(${JSON.stringify(value)}) má mít field 'zip'`);
  assert.equal(error.message, 'PSČ má pět číslic, třeba 120 00', `chyba z validateZip(${JSON.stringify(value)}) má mít zprávu 'PSČ má pět číslic, třeba 120 00'`);
}
```

Prázdné PSČ vyhodí `ValidationError` s políčkem `zip`.

```js
let error;
try {
  validateZip('');
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof ValidationError, "validateZip('') má vyhodit ValidationError");
assert.equal(error.field, 'zip', "chyba z validateZip('') má mít field 'zip'");
```

# --help--

## --tip--

Kontrola a převod na jeden tvar patří k sobě — viz [Validace na hranici](see:js-chyby-ladeni/vlastni-chyby#validace-na-hranici).

## --tip--

Mezery odstraní `replaceAll(' ', '')` nad výsledkem `requireText`. Tvar `120 00` poskládáš z `slice(0, 3)` a `slice(3)`.
