# --description--

E-mail je povinný a musí mít tvar `něco@doména.koncovka`. Ukládá se malými písmeny, aby `Jana.Novakova@Example.cz` a `jana.novakova@example.cz` byl jeden zákazník.

**Úkol:** Napiš funkci `validateEmail(value)`, která:

1. políčko zkontroluje funkcí `requireText` s políčkem `'email'` a výsledek převede na malá písmena,
2. když e-mail neodpovídá regulárnímu výrazu `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`, vyhodí `ValidationError` s políčkem `'email'` a zprávou `Zadej e-mail ve tvaru jana@example.cz`,
3. jinak e-mail vrátí.

Pod ní vypiš `validateEmail(formData.email)`.

Výraz říká: pár znaků kromě mezer a zavináče, zavináč, zase pár znaků, tečka a zbytek. Na přesnou kontrolu e-mailu nestačí (tu udělá až potvrzovací e-mail), na odhalení překlepu ano.

Všimni si, že chybu z `requireText` nechytáš — prázdný e-mail vyletí jako `ValidationError` s políčkem `'email'` sám. Na jiných datech:

```js
function validatePhone(value) {
  // 1. povinné políčko — chyba z requireText letí dál sama
  const phone = requireText(value, 'phone').replaceAll(' ', '');
  // 2. vlastní kontrola tvaru
  if (!/^\+?\d{9,12}$/.test(phone)) {
    throw new ValidationError('phone', 'Zadej telefon, třeba 777 123 456');
  }
  return phone;
}
```

# --hints--

`validateEmail` vrátí e-mail oříznutý a malými písmeny.

```js
assert.equal(validateEmail(' Jana.Novakova@Example.cz'), 'jana.novakova@example.cz', "validateEmail(' Jana.Novakova@Example.cz') má vrátit 'jana.novakova@example.cz'");
```

E-mail ve špatném tvaru vyhodí `ValidationError` s políčkem `email`.

```js
for (const value of ['jana.example.cz', 'jana@example', 'jana novakova@example.cz', '@example.cz']) {
  let error;
  try {
    validateEmail(value);
  } catch (caught) {
    error = caught;
  }
  assert.ok(error instanceof ValidationError, `validateEmail(${JSON.stringify(value)}) má vyhodit ValidationError`);
  assert.equal(error.field, 'email', `chyba z validateEmail(${JSON.stringify(value)}) má mít field 'email'`);
  assert.equal(error.message, 'Zadej e-mail ve tvaru jana@example.cz', `chyba z validateEmail(${JSON.stringify(value)}) má mít zprávu 'Zadej e-mail ve tvaru jana@example.cz'`);
}
```

Prázdný e-mail vyhodí `ValidationError` s políčkem `email` a zprávou z `requireText`.

```js
let error;
try {
  validateEmail('  ');
} catch (caught) {
  error = caught;
}
assert.ok(error instanceof ValidationError, "validateEmail('  ') má vyhodit ValidationError");
assert.equal(error.field, 'email', "chyba z validateEmail('  ') má mít field 'email'");
assert.equal(error.message, 'Vyplň toto políčko', "chyba z validateEmail('  ') má mít zprávu 'Vyplň toto políčko'");
```

# --help--

## --tip--

Chyba z `requireText` proletí přes `validateEmail` sama — viz [Co udělá `throw`](see:js-chyby-ladeni/vyjimky#co-udela-throw).

## --tip--

Regulární výraz má metodu `test`, která vrátí `true`/`false`. Na malá písmena převádí `toLowerCase`.
