# --description--

Štítky jsou seznam odkazů na výpisy — čtenář jimi projde na další články na stejné téma. Že vypadají jako pilulky vedle sebe, zařídí stylopis podle třídy `tags`.

**Úkol:** udělej ze štítků seznam s třídou `tags`, kde každá položka je odkaz na `/stitek/<štítek>`. Mezery ve štítku nahraď pomlčkou (`/stitek/mestske-kolo`). Slovo „Štítky:“ smaž.

# --hints--

Štítky jsou seznam se čtyřmi položkami a třídou tags.

```js
const list = document.querySelector('article ul.tags');
assert.ok(list, 'V článku chybí seznam <ul class="tags">');
assert.equal(list.querySelectorAll('li').length, 4, `Seznam štítků má ${list.querySelectorAll('li').length} položek, mají být čtyři`);
```

Každý štítek je odkaz na svůj výpis.

```js
const pairs = [...document.querySelectorAll('article ul.tags li a')].map((a) => [a.textContent.replace(/\s+/g, ' ').trim(), a.getAttribute('href')]);
assert.deepEqual(pairs, [['dojíždění', '/stitek/dojíždění'], ['Brno', '/stitek/Brno'], ['městské kolo', '/stitek/městské-kolo'], ['zima na kole', '/stitek/zima-na-kole']], 'Štítky mají mít texty a cíle ze zadání — mezery v adrese nahraď pomlčkou');
```

Původní řádek se štítky zmizel.

```js
assert.ok(!/Štítky:/.test(document.body.textContent), 'Slovo „Štítky:“ smaž — seznam mluví sám za sebe');
```

# --help--

## --tip--

Jak se zapisuje adresa uvnitř vlastního webu, je v části [Relativní a absolutní adresa](see:html-zaklady/jak-funguje-web#relativni-a-absolutni-adresa).

## --tip--

Struktura je stejná jako u navigace: `<ul>` → `<li>` → `<a>`. Seznam navíc dostane atribut `class`.
