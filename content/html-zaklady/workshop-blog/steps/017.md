# --description--

Patička má dvě věci: kontakt na redakci a copyright. U kontaktu použiješ stejný prvek jako u autorky článku a `(c)` nahradíš skutečným znakem, který na klávesnici nenajdeš.

**Úkol:** obal obsah patičky prvkem `<div>` (stylopis na něj spoléhá), z řádku s redakcí udělej kontaktní údaje a z copyrightu odstavec, ve kterém `(c)` nahradíš entitou pro znak ©.

# --hints--

Obsah patičky je v obalu a kontakt má svůj prvek.

```js
const footer = document.querySelector('footer.site');
assert.ok(footer.querySelector(':scope > div'), 'Obsah patičky má být v prvku <div>');
const address = footer.querySelector('address');
assert.ok(address, 'V patičce chybí <address>');
assert.match(address.textContent, /Veveří 15/, 'V <address> má být adresa redakce');
```

Copyright je odstavec se znakem ©.

```js
const p = [...document.querySelectorAll('footer.site p')].find((el) => /2026/.test(el.textContent));
assert.ok(p, 'V patičce chybí odstavec s copyrightem');
assert.match(p.textContent, /©/, 'Místo (c) má být znak © — zapiš ho entitou');
assert.ok(!/\(c\)/i.test(p.textContent), 'Zápis (c) v textu zůstal');
assert.equal(p.textContent.replace(/\s+/g, ' ').trim(), '© 2026 Na kole po Brně', `Odstavec obsahuje „${p.textContent.trim()}“`);
```

V patičce nezůstal holý text mimo prvky.

```js
const div = document.querySelector('footer.site > div');
const loose = [...div.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE && n.textContent.trim() !== '');
assert.equal(loose.length, 0, 'V patičce zůstal text mimo prvky');
```

# --help--

## --tip--

Prvek pro kontaktní údaje a zápis znaků, které nejsou na klávesnici, jsou v částech [Obsah s významem](see:html-zaklady/semanticka-struktura#obsah-s-vyznamem-time-address-blockquote-a-cite) a [Bílé znaky, entity a komentáře](see:html-zaklady/anatomie-dokumentu#bile-znaky-entity-a-komentare).

## --tip--

Kontakt je `<address>` jako u autorky. Entita pro © začíná `&` a končí `;` — její jméno najdeš na MDN pod heslem *HTML entity*.
