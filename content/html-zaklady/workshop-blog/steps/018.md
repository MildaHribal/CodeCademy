# --description--

Kdo chodí po webu klávesnicí, musí na každé stránce protabovat celou navigaci, než se dostane k textu. Proto má skoro každý web úplně první odkaz, který navigaci přeskočí — vidět je až po zaostření, stylopis to už umí přes třídu `skip`.

**Úkol:** dej hlavnímu obsahu jmenovku `obsah` a hned na začátek těla stránky, ještě před hlavičku, vlož odkaz s třídou `skip` a textem `Přeskočit na článek`, který na tu jmenovku míří.

Jmenovku i odkaz na místo ve stránce jsi dělal u receptu.

# --hints--

Hlavní obsah má jmenovku obsah.

```js
const main = document.querySelector('main');
assert.equal(main.getAttribute('id'), 'obsah', `<main> má id „${main.getAttribute('id') ?? 'nic'}“ — má mít obsah`);
assert.equal(document.querySelectorAll('#obsah').length, 1, 'Jmenovka obsah má být v dokumentu jen jednou');
```

Odkaz na přeskočení je první věc v těle stránky.

```js
const first = document.body.firstElementChild;
assert.equal(first?.localName, 'a', 'Prvním prvkem v <body> má být odkaz <a>');
assert.ok(first.classList.contains('skip'), 'Odkaz má mít třídu skip');
assert.equal(first.getAttribute('href'), '#obsah', `Odkaz míří na „${first.getAttribute('href')}“ — má mířit na #obsah`);
assert.equal(first.textContent.replace(/\s+/g, ' ').trim(), 'Přeskočit na článek', `Text odkazu je „${first.textContent.trim()}“`);
```

Odkaz je běžně schovaný a vykoukne až po zaostření.

```js
const link = document.querySelector('a.skip');
assert.ok(link.getBoundingClientRect().right < 0, 'Odkaz má být mimo obrazovku — to zařídí třída skip ze stylopisu');
link.focus();
assert.ok(link.getBoundingClientRect().right > 0, 'Po zaostření má být odkaz vidět');
```

# --help--

## --tip--

Co je fragment adresy, je v části [URL: z čeho se adresa skládá](see:html-zaklady/jak-funguje-web#url-z-ceho-se-adresa-sklada).

## --tip--

Jmenovka je atribut `id` na `<main>`, odkaz má v `href` mřížku a její jméno a dostane atribut `class`.
