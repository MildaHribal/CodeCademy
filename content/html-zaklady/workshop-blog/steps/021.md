# --description--

Poslední drobnost, kterou má dnes skoro každý blog: kolik času si má čtenář vyhradit. Použiješ na to stejný prvek jako u data, jen se strojovým zápisem **doby trvání** místo data.

**Úkol:** pod kontakt na autorku přidej odstavec s prvkem pro čas, textem `4 minuty čtení` a strojovým zápisem `PT4M`.

Zápis doby trvání začíná `P` (perioda), `T` odděluje čas a `4M` znamená čtyři minuty.

## Co jsi postavil

Stránka blogu, která vypadá a chová se jako skutečný článek:

- orientační oblasti `header`, `main`, `aside` a `footer`, mezi kterými čtečka obrazovky skáče,
- `article` s osnovou `h1` → `h2` a odkazem, který navigaci přeskočí,
- datum, autorka, citace se zdrojem a doba čtení prvky, které nesou význam,
- fotky, ze kterých si prohlížeč sám vybere velikost podle displeje i formát podle toho, čemu rozumí,
- obsah článku, štítky a dvě navigace — v hlavičce a v patičce.

Tohle rozvržení má pod sebou skoro každý magazín, dokumentace i e-shop. Zatím drží pohromadě jen výchozími styly prohlížeče a jedním hotovým stylopisem; v další sekci se naučíš stylopis psát sám a stejnou stránku si obarvíš a rozvrhneš po svém.

## Udělej po svém

- **Vzhled:** přidej k článku pod nadpis štítek s dobou trasy a vzdáleností a najdi pro něj prvek, který nese význam.
- **Obsah:** dopiš čtvrtý oddíl „Co bych udělala jinak“ i s jmenovkou a odkazem v obsahu článku.
- **Obrázky:** dej zimní fotce taky obal `picture` s nabídkou WebP a porovnej v DevTools na kartě Network, co se stáhne.
- **Tvoje téma:** přepiš článek na to, co děláš ty — zápisník z hraní, recenzi hry, návod na opravu kola. Struktura zůstane stejná, mění se jen texty a fotky.

# --hints--

Pod kontaktem na autorku je doba čtení.

```js
const times = [...document.querySelectorAll('article time')];
assert.ok(times.length >= 2, `V článku je ${times.length} prvků <time> — mají být dva: datum a doba čtení`);
const doba = times.find((t) => /minut/.test(t.textContent));
assert.ok(doba, 'Chybí <time> s textem o době čtení');
assert.equal(doba.textContent.replace(/\s+/g, ' ').trim(), '4 minuty čtení', `<time> obsahuje „${doba.textContent.trim()}“`);
```

Doba čtení má strojový zápis trvání.

```js
const doba = [...document.querySelectorAll('article time')].find((t) => /minut/.test(t.textContent));
assert.equal(doba.getAttribute('datetime'), 'PT4M', `datetime je „${doba.getAttribute('datetime') ?? 'nic'}“ — doba trvání se zapisuje jako PT4M`);
assert.equal(doba.closest('p')?.tagName, 'P', 'Doba čtení má být v odstavci <p>');
```

Datum vydání zůstalo se svým zápisem.

```js
const datum = [...document.querySelectorAll('article time')].find((t) => t.getAttribute('datetime') === '2026-09-14');
assert.ok(datum, 'Datum vydání s datetime="2026-09-14" má zůstat');
```

Stránka drží pohromadě: oblasti, osnova a obě navigace.

```js
for (const sel of ['header.site nav li a', 'main#obsah article h1', 'main aside h2', 'footer.site nav li a', 'a.skip[href="#obsah"]']) {
  assert.ok(document.querySelector(sel), `Na stránce chybí „${sel}“ — něco z dřívějších kroků se ztratilo`);
}
const levels = [...document.querySelectorAll('h1, h2, h3, h4, h5, h6')].map((el) => Number(el.localName[1]));
for (let i = 1; i < levels.length; i += 1) {
  assert.ok(levels[i] <= levels[i - 1] + 1, `Z úrovně h${levels[i - 1]} se skáče rovnou na h${levels[i]}`);
}
```

## --tip--

Prvek pro čas je v části [Obsah s významem](see:html-zaklady/semanticka-struktura#obsah-s-vyznamem-time-address-blockquote-a-cite); tvary zápisu najdeš na MDN pod heslem *time datetime*.

## --tip--

Je to stejný prvek jako u data vydání, jen v `datetime` stojí doba trvání místo data.
