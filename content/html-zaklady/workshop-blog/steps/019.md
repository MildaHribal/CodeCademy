# --description--

Článek má tři oddíly a čtenář na mobilu netuší, co ho čeká. Obsah nahoře je seznam odkazů na jmenovky jednotlivých nadpisů — a protože je to navigace po stránce, patří do `nav`.

**Úkol:** dej třem mezinadpisům jmenovky `cesta`, `pocasi` a `penize` (v tom pořadí) a pod perex vlož navigaci s třídou `toc`, v ní odstavec `V článku:` a číslovaný seznam odkazů na ty tři jmenovky. Text odkazu je celý nadpis.

# --hints--

Všechny tři mezinadpisy mají jmenovku.

```js
const ids = [...document.querySelectorAll('article h2')].map((h) => h.getAttribute('id'));
assert.deepEqual(ids, ['cesta', 'pocasi', 'penize'], `Jmenovky nadpisů jsou ${JSON.stringify(ids)} — mají být cesta, pocasi a penize`);
```

Pod perexem je navigace s obsahem článku.

```js
const toc = document.querySelector('article nav.toc');
assert.ok(toc, 'V článku chybí <nav class="toc">');
assert.match(toc.querySelector('p')?.textContent ?? '', /V článku/, 'V obsahu chybí odstavec „V článku:“');
assert.ok(toc.querySelector('ol'), 'Obsah má být číslovaný seznam <ol> — na pořadí oddílů záleží');
const lead = document.querySelector('p.lead');
assert.ok(lead.compareDocumentPosition(toc) & Node.DOCUMENT_POSITION_FOLLOWING, 'Obsah má stát pod perexem');
```

Každý odkaz míří na existující nadpis a nese jeho text.

```js
const links = [...document.querySelectorAll('article nav.toc li a')];
assert.equal(links.length, 3, `V obsahu jsou ${links.length} odkazy, mají být tři`);
for (const a of links) {
  const href = a.getAttribute('href') ?? '';
  assert.match(href, /^#/, `Odkaz „${a.textContent.trim()}“ má mířit na jmenovku ve stránce, tedy začínat mřížkou`);
  const cil = document.querySelector(href);
  assert.ok(cil, `Odkaz míří na „${href}“, ale takový prvek na stránce není`);
  assert.equal(cil.localName, 'h2', 'Cílem odkazu má být mezinadpis článku');
  assert.equal(a.textContent.replace(/\s+/g, ' ').trim(), cil.textContent.replace(/\s+/g, ' ').trim(), 'Text odkazu má být celý nadpis, na který míří');
}
```

# --help--

## --tip--

Fragment adresy je v části [URL: z čeho se adresa skládá](see:html-zaklady/jak-funguje-web#url-z-ceho-se-adresa-sklada).

## --tip--

Jmenovka je atribut `id` na nadpisu. Obsah je `<nav>` s atributem `class`, uvnitř odstavec a číslovaný seznam.
