# --description--

JPEG umí každý prohlížeč, ale WebP je při stejné kvalitě zhruba o třetinu menší. Nedá se ale použít natvrdo — na starém telefonu by se neukázalo nic. HTML na to má obal, ve kterém si prohlížeč vybere první formát, kterému rozumí.

**Úkol:** obal fotku prvkem `picture` a dovnitř před obrázek přidej nabídku ve formátu WebP: typ `image/webp`, stejné tři velikosti s příponou `.webp` a stejné `sizes`.

Původní `<img>` v obalu zůstane jako poslední možnost.

# --hints--

Obrázek je v obalu picture s nabídkou navíc.

```js
const picture = document.querySelector('article figure picture');
assert.ok(picture, 'V příloze chybí obal <picture>');
const source = picture.querySelector('source');
assert.ok(source, 'V <picture> chybí <source> s nabídkou WebP');
assert.ok(picture.querySelector('img'), 'V <picture> má zůstat původní <img>');
```

Nabídka WebP má svůj typ, tři velikosti i sizes.

```js
const source = document.querySelector('article figure picture source');
assert.equal(source.getAttribute('type'), 'image/webp', `type je „${source.getAttribute('type') ?? 'nic'}“ — má být image/webp`);
const srcset = source.getAttribute('srcset') ?? '';
for (const [soubor, sirka] of [['cesta-400.webp', '400w'], ['cesta-800.webp', '800w'], ['cesta-1200.webp', '1200w']]) {
  assert.ok(srcset.includes(soubor) && srcset.includes(sirka), `V srcset nabídky chybí „img/${soubor} ${sirka}“`);
}
assert.match((source.getAttribute('sizes') ?? '').replace(/\s+/g, ' '), /\(min-width:\s*60rem\)\s*40rem/, 'Nabídka má mít stejné sizes jako <img>');
```

Nabídka stojí před obrázkem — prohlížeč bere první, které rozumí.

```js
const picture = document.querySelector('article figure picture');
const kids = [...picture.children].map((el) => el.localName);
assert.equal(kids[kids.length - 1], 'img', 'Prvek <img> má být v <picture> poslední');
assert.ok(kids.indexOf('source') < kids.indexOf('img'), '<source> má stát před <img>');
assert.match(picture.querySelector('img').getAttribute('alt') ?? '', /Cyklostezka podél Svitavy/, 'Alternativní text má zůstat na <img>');
```

# --help--

## --tip--

Jak se na MDN čte stránka prvku a jeho atributů, je v části [Stránka prvku](see:html-zaklady/mdn-a-dokumentace#stranka-prvku-co-kde-je).

## --tip--

Obal se jmenuje `picture`, nabídka uvnitř `source`. Alternativní text zůstává na obrázku, ne na nabídce.

## --tip--

Pro stejný obrázek ve formátu AVIF by přibyl druhý `<source type="image/avif" …>` úplně na začátek.
