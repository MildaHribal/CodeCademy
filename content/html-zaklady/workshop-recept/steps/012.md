# --description--

Tohle už jsi dělal, tak to zkus bez nápovědy. Řádky `Na těsto` a `Na smažení a podávání` jsou podnadpisy uvnitř Surovin. Musí být o úroveň níž než nadpis, pod který patří — osnova nesmí přeskakovat.

**Úkol:** udělej z obou řádků nadpisy správné úrovně.

# --hints--

Obě skupiny surovin mají nadpis o úroveň níž než Suroviny.

```js
const h3s = [...document.querySelectorAll('main h3')].map((el) => el.textContent.trim());
assert.deepEqual(h3s, ['Na těsto', 'Na smažení a podávání'], `Nadpisy třetí úrovně jsou ${JSON.stringify(h3s)} — mají být „Na těsto“ a „Na smažení a podávání“`);
```

Osnova nadpisů nepřeskakuje úroveň.

```js
const levels = [...document.querySelectorAll('main h1, main h2, main h3, main h4, main h5, main h6')].map((el) => Number(el.localName[1]));
for (let i = 1; i < levels.length; i += 1) {
  assert.ok(levels[i] <= levels[i - 1] + 1, `Z úrovně h${levels[i - 1]} se skáče rovnou na h${levels[i]} — osnova má klesat po jedné`);
}
```

Mimo nadpisy už názvy skupin nezůstaly jako holý text.

```js
const main = document.querySelector('main.recipe');
const loose = [...main.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE && /Na těsto|Na smažení/.test(n.textContent));
assert.equal(loose.length, 0, 'Názvy skupin zůstaly i mimo nadpisy jako holý text');
```

# --help--

## --tip--

Pravidlo o úrovních je v části [Osnova nadpisů](see:html-zaklady/semanticka-struktura#osnova-nadpisu).

## --tip--

Pod `<h2>` patří `<h3>`, ne `<h4>`. Oba řádky jsou uvnitř sekce Suroviny.

# --explain--

Vysvětli vlastními slovy, proč u nadpisů záleží na úrovni a co se stane, když se úroveň přeskočí.

## --model--

Z nadpisů `h1` až `h6` vzniká osnova stránky — strom, ve kterém je každý nadpis podřízený tomu nejbližšímu vyšší úrovně. Čtečka obrazovky ji nabízí jako obsah, takže po ní čtenář skáče místo čtení odshora. Když se z `h2` skočí rovnou na `h4`, vznikne v osnově díra: čtenář nepozná, ke které sekci `h4` patří, a vypadá to, že nějaká úroveň chybí. Úroveň se proto vybírá podle místa ve struktuře, ne podle toho, jak velké písmo se hodí.

## --checklist--

- Z nadpisů vzniká osnova, podle které se čtenář orientuje.
- Úroveň se volí podle struktury, ne podle velikosti písma.
- Přeskočená úroveň udělá v osnově díru a není jasné, kam nadpis patří.
