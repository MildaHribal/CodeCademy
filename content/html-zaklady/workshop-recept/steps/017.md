# --description--

Bez odkazů by web nebyl web. Na konec receptu patří odkaz na cizí stránku — a text odkazu musí dávat smysl i vytržený z věty, protože čtečka obrazovky umí odkazy vypsat zvlášť.

**Úkol:** udělej z řádku `Další čtení` nadpis druhé úrovně, z věty pod ním odstavec a ze slov `článek o majoránce na Wikipedii` odkaz na `https://cs.wikipedia.org/wiki/Majoránka_zahradní`.

Na cizí web vede vždycky celá adresa včetně `https://`.

# --hints--

Sekce Další čtení má nadpis druhé úrovně a odstavec.

```js
const h2 = [...document.querySelectorAll('main h2')].find((el) => el.textContent.trim() === 'Další čtení');
assert.ok(h2, 'Chybí nadpis <h2> s textem Další čtení');
const p = [...document.querySelectorAll('main p')].find((el) => /dává majoránka/.test(el.textContent));
assert.ok(p, 'Věta o majoránce má být odstavec <p>');
```

Odkaz míří na článek na Wikipedii celou adresou.

```js
const link = [...document.querySelectorAll('main a')].find((a) => /wikipedia/i.test(a.getAttribute('href') ?? ''));
assert.ok(link, 'Chybí odkaz na Wikipedii');
const href = decodeURIComponent(link.getAttribute('href'));
assert.equal(href, 'https://cs.wikipedia.org/wiki/Majoránka_zahradní', `Odkaz míří na „${href}“`);
```

Textem odkazu je to, kam vede — ne „tady\“ ani „klikni sem\“.

```js
const link = [...document.querySelectorAll('main a')].find((a) => /wikipedia/i.test(a.getAttribute('href') ?? ''));
assert.equal(link.textContent.replace(/\s+/g, ' ').trim(), 'článek o majoránce na Wikipedii', `Text odkazu je „${link.textContent.trim()}“`);
```

# --help--

## --tip--

Rozdíl mezi celou a zkrácenou adresou je v části [Relativní a absolutní adresa](see:html-zaklady/jak-funguje-web#relativni-a-absolutni-adresa).

## --tip--

Odkaz je prvek `<a>` a cíl nese atribut `href`. Obal jím jen ta slova uvnitř věty, ne celou větu.

## --tip--

Odkaz na dokumentaci by vypadal `<a href="https://developer.mozilla.org/">dokumentace MDN</a>`.
