# --description--

Hlavička stojí, teď do tabulky patří pět řádků s hodnotami. Tělo tabulky je vlastní skupina — díky tomu prohlížeč ví, co je záhlaví a co data, a tabulka se dá na mobilu rolovat nezávisle na hlavičce.

**Úkol:** doplň do tabulky tělo a v něm pět řádků. V každém je vlevo název živiny a vpravo hodnota, obojí jako obyčejná buňka.

Názvy a hodnoty najdeš pod tabulkou jako holý text — ten po přepsání zmizí.

# --hints--

Tabulka má tělo s pěti řádky.

```js
const body = document.querySelector('main table tbody');
assert.ok(body, 'Tabulce chybí tělo <tbody>');
assert.equal(body.querySelectorAll('tr').length, 5, `Tělo má ${body.querySelectorAll('tr').length} řádků, má mít 5`);
```

Každý řádek má dvě obyčejné buňky se správnými hodnotami.

```js
const rows = [...document.querySelectorAll('main table tbody tr')].map((tr) => [...tr.querySelectorAll('td')].map((td) => td.textContent.replace(/\s+/g, ' ').trim()));
assert.deepEqual(rows, [['Energie', '1 480 kJ'], ['Bílkoviny', '9 g'], ['Sacharidy', '42 g'], ['Tuky', '16 g'], ['Vláknina', '5 g']], 'Řádky mají obsahovat pět dvojic živina + hodnota v pořadí ze zadání');
```

Hlavička z minulého kroku zůstala a hodnoty už nejsou holý text.

```js
const heads = [...document.querySelectorAll('main table thead th')].map((th) => th.textContent.trim());
assert.deepEqual(heads, ['Živina', 'Na 1 porci'], 'Hlavička tabulky má zůstat');
const main = document.querySelector('main.recipe');
const loose = [...main.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE && /Bílkoviny|Vláknina/.test(n.textContent));
assert.equal(loose.length, 0, 'Hodnoty zůstaly i mimo tabulku jako holý text');
```

# --help--

## --tip--

Vnořování prvků je v části [Prvek, značka a atribut](see:html-zaklady/anatomie-dokumentu#prvek-znacka-a-atribut).

## --tip--

Tělo tabulky je `<tbody>`, obyčejná buňka `<td>`. Struktura je stejná jako v hlavičce, jen místo `<th>` je `<td>`.

## --tip--

Řádek ceníku by vypadal `<tr><td>Měsíční tarif</td><td>349 Kč</td></tr>`.

# --explain--

Vysvětli vlastními slovy, k čemu je v tabulce rozdíl mezi `th` a `td`, když obojí je buňka.

## --model--

`th` je buňka záhlaví: říká, co znamenají ostatní buňky ve svém sloupci (nebo řádku). `td` je obyčejná datová buňka. Rozdíl není ve vzhledu, ale v tom, že prohlížeč a čtečka obrazovky podle `th` vědí, čeho se která hodnota týká — u buňky „9 g“ ohlásí i „Na 1 porci“, takže se čtenář neztratí v dlouhé tabulce. Skupiny `thead` a `tbody` k tomu přidávají, která část tabulky je záhlaví a která data.

## --checklist--

- `th` je záhlaví, `td` obyčejná buňka s daty.
- Podle `th` čtečka u hodnoty ohlásí i to, čeho se týká.
- `thead` a `tbody` oddělují záhlaví od dat.
