# --description--

## Hlášení

Autorka Jitka připsala pod fotku těsta tip se dvěma radami a dala mu třídu `tip`, pro kterou má stylopis béžový rámeček s proužkem vlevo. Píše: „V rámečku je jen první věta. Obě rady pod ním jsou mimo rámeček, jako by k tipu nepatřily. Třídu mám správně, CSS jsem nekontrolovala, ale u jiných receptů funguje."

V DevTools v panelu Elements je vidět, že za rámečkem stojí seznam jako samostatný prvek a za ním ještě prázdný odstavec, který v souboru nikde není.

## Úkol

Zjisti, proč prohlížeč seznam z tipu vystrčil, a oprav HTML tak, aby celý tip včetně obou rad ležel v jednom rámečku. Stylopis neměň a změň co nejmenší kus kódu.

# --hints--

Celý tip, úvodní věta i obě rady, leží uvnitř prvku s třídou `tip`.

```js
const tip = document.querySelector('.tip');
assert.ok(tip, 'Na stránce chybí prvek s třídou tip');
assert.match(tip.textContent.replace(/\s+/g, ' '), /Když se těsto na pánvi rozpadá:/, 'Rámeček .tip má obsahovat úvodní větu „Když se těsto na pánvi rozpadá:"');
const items = [...tip.querySelectorAll('li')].map((li) => li.textContent.replace(/\s+/g, ' ').trim());
assert.deepEqual(items, ['přimíchej ještě lžíci mouky,', 'nech ho pět minut odpočinout.'], 'Obě rady mají být jako položky seznamu uvnitř rámečku .tip');
```

Na stránce nevznikl žádný prázdný odstavec.

```js
const empty = [...document.querySelectorAll('p')].filter((p) => p.textContent.trim() === '' && !p.querySelector('img'));
assert.equal(empty.length, 0, `Na stránce je ${empty.length} prázdných odstavců <p> — parser je vyrábí z osiřelého </p>`);
```

Zbytek receptu zůstal: tip stojí pod fotkou těsta a nad nadpisem Nutriční hodnoty.

```js
const tip = document.querySelector('.tip');
const figures = document.querySelectorAll('figure');
const nutrition = [...document.querySelectorAll('h2')].find((h) => h.textContent.trim() === 'Nutriční hodnoty');
assert.equal(figures.length, 2, 'Na stránce mají zůstat obě fotky');
assert.ok(figures[1].compareDocumentPosition(tip) & Node.DOCUMENT_POSITION_FOLLOWING, 'Tip má být pod fotkou těsta');
assert.ok(tip.compareDocumentPosition(nutrition) & Node.DOCUMENT_POSITION_FOLLOWING, 'Tip má být nad nadpisem Nutriční hodnoty');
assert.equal(document.querySelectorAll('table tbody tr').length, 5, 'Tabulka nutričních hodnot má mít dál pět řádků');
```

# --help--

## --tip--

Jde o chybu ve vnořování, kterou parser tiše opravil. Stejný případ s poznámkou na výlet je v části [Prohlížeč chyby tiše opravuje](see:html-zaklady/anatomie-dokumentu#prohlizec-chyby-tise-opravuje).

## --tip--

Podívej se, který prvek nese třídu `tip` a co smí obsahovat. Seznam v něm stát nesmí, takže třídu musí nést prvek, který seznam obsahovat smí.

## --tip--

Kontakt s telefonem v blokovém obalu vypadá takhle: obecný blokový obal s třídou `contact`, uvnitř něj úvodní text a teprve pak další bloky.
