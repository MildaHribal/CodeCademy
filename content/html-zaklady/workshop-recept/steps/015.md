# --description--

Nutriční hodnoty jsou dvojice název a hodnota — to je tabulka. Aby jí čtečka obrazovky rozuměla, musí poznat, které buňky jsou záhlaví sloupců: pak u každé hodnoty ohlásí i to, čeho se týká.

**Úkol:** udělej z řádku `Nutriční hodnoty` nadpis druhé úrovně a založ tabulku s hlavičkou, v níž jsou dvě záhlaví: `Živina` a `Na 1 porci`. Řádky s hodnotami nech zatím být.

Tabulka má tři patra: tabulka → řádek → buňka. Řádek hlavičky navíc patří do vlastní skupiny.

# --hints--

Nutriční hodnoty mají nadpis druhé úrovně.

```js
const h2 = [...document.querySelectorAll('main h2')].find((el) => el.textContent.trim() === 'Nutriční hodnoty');
assert.ok(h2, 'Chybí nadpis <h2> s textem Nutriční hodnoty');
```

Na stránce je tabulka se skupinou hlavičky.

```js
const table = document.querySelector('main table');
assert.ok(table, 'Na stránce chybí <table>');
assert.ok(table.querySelector('thead'), 'Tabulce chybí skupina hlavičky <thead>');
assert.equal(table.querySelectorAll('thead tr').length, 1, 'V hlavičce má být právě jeden řádek <tr>');
```

Hlavička má dvě záhlaví sloupců.

```js
const heads = [...document.querySelectorAll('main table thead th')].map((th) => th.textContent.replace(/\s+/g, ' ').trim());
assert.deepEqual(heads, ['Živina', 'Na 1 porci'], `Záhlaví jsou ${JSON.stringify(heads)} — mají být „Živina“ a „Na 1 porci“`);
```

Řádek s názvy sloupců už není na stránce jako holý text.

```js
const main = document.querySelector('main.recipe');
const loose = [...main.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE && /Živina/.test(n.textContent));
assert.equal(loose.length, 0, 'Řádek „Živina / Na 1 porci“ zůstal i mimo tabulku');
```

# --help--

## --tip--

Jak se prvky do sebe vnořují, je v části [Prvek, značka a atribut](see:html-zaklady/anatomie-dokumentu#prvek-znacka-a-atribut); tabulku najdeš na MDN pod heslem *table*.

## --tip--

Prvky se jmenují `<table>`, `<thead>`, `<tr>` a pro buňku záhlaví `<th>`. Buňka nesmí stát přímo v tabulce, vždy je v řádku.

## --tip--

Tabulka parametrů notebooku by začínala stejně: `<thead>` s `<th>Parametr</th>` a `<th>Hodnota</th>`.
