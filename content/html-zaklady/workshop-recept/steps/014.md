# --description--

Tohle jsi dělal v krocích 8 až 10, teď to zvládneš najednou a bez návodu.

**Úkol:** vlož pod postup přílohu s fotkou `img/testo.jpg`, rozměry 800 × 533, alternativním textem `Těsto na bramboráky v míse, nastrouhané brambory s vejci a majoránkou` a popiskem, který je už na stránce.

# --hints--

Pod postupem je druhá příloha s fotkou těsta.

```js
const figures = [...document.querySelectorAll('main figure')];
assert.equal(figures.length, 2, `Na stránce je ${figures.length} příloh <figure> — mají být dvě`);
const img = figures[1].querySelector('img');
assert.ok(img, 'Druhá příloha nemá obrázek');
assert.match(img.getAttribute('src') ?? '', /testo\.jpg$/, `Druhá fotka má src „${img.getAttribute('src')}“ — má být img/testo.jpg`);
```

Fotka těsta má alternativní text i rozměry.

```js
const img = [...document.querySelectorAll('main figure img')][1];
assert.equal((img.getAttribute('alt') ?? '').replace(/\s+/g, ' ').trim(), 'Těsto na bramboráky v míse, nastrouhané brambory s vejci a majoránkou', `alt je „${img.getAttribute('alt')}“`);
assert.equal(img.getAttribute('width'), '800', 'Fotce těsta chybí width="800"');
assert.equal(img.getAttribute('height'), '533', 'Fotce těsta chybí height="533"');
```

Popisek je uvnitř přílohy a text zůstal stejný.

```js
const caption = [...document.querySelectorAll('main figure figcaption')][1];
assert.ok(caption, 'Druhá příloha nemá <figcaption>');
assert.equal(caption.textContent.replace(/\s+/g, ' ').trim(), 'Takhle má vypadat těsto: husté a bez vody na dně mísy.', `Popisek obsahuje „${caption.textContent.trim()}“`);
const main = document.querySelector('main.recipe');
const loose = [...main.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE && /Takhle má vypadat těsto/.test(n.textContent));
assert.equal(loose.length, 0, 'Popisek zůstal i mimo <figure> jako holý text');
```

Příloha stojí pod postupem a nad nutričními hodnotami.

```js
const figure = [...document.querySelectorAll('main figure')][1];
const ol = document.querySelector('main ol');
assert.ok(ol.compareDocumentPosition(figure) & Node.DOCUMENT_POSITION_FOLLOWING, 'Fotka těsta má být pod postupem');
```

# --help--

## --tip--

Vzor máš v kroku 10 a v části [Obsah s významem](see:html-zaklady/semanticka-struktura#obsah-s-vyznamem-time-address-blockquote-a-cite).

## --tip--

Pořadí je stejné jako u první fotky: příloha, v ní obrázek se třemi atributy a pak titulek.

      <p>Křupavé bramboráky podle babičky Jitky z Vysočiny. Nejdůležitější je <strong>dobře vymačkat nastrouhané brambory</strong>, jinak se na pánvi rozpadnou.</p>

      <p>Majoránku přidej do těsta <em>až nakonec</em>, aby neztratila vůni.</p>

      </figure>

      <h2>Suroviny</h2>
      <h3>Na těsto</h3>
      <ul>
        <li>1 kg brambor</li>
        <li>2 vejce</li>
        <li>3 stroužky česneku</li>
        <li>4 lžíce hladké mouky</li>
        <li>2 lžičky sušené majoránky</li>
        <li>sůl a pepř</li>
      </ul>
      <h3>Na smažení a podávání</h3>
      <ul>
        <li>sádlo nebo řepkový olej</li>
        <li>zakysaná smetana</li>
      </ul>

      <h2>Postup</h2>
      <ol>
        <li>Brambory oloupej a najemno nastrouhej.</li>
        <li>Nastrouhané brambory vymačkej v utěrce, dokud z nich teče voda.</li>
        <li>Přidej vejce, prolisovaný česnek, mouku, majoránku, sůl a pepř a promíchej.</li>
        <li>Na pánvi rozehřej sádlo a lžící do něj rozprostři tenké placky.</li>
        <li>Smaž z obou stran asi 4 minuty dozlatova.</li>
      </ol>

--edit--
      Takhle má vypadat těsto: husté a bez vody na dně mísy.
--edit--

      Energie 1 480 kJ
