# --description--

Načti si náhled na pomalém připojení a uvidíš, co Jitce vadí: text pod fotkou nejdřív vyskočí nahoru a ve chvíli, kdy se fotka stáhne, poskočí dolů. Prohlížeč totiž do té doby neví, kolik místa si má na obrázek nechat.

**Úkol:** doplň fotce její rozměry v pixelech — šířku `800` a výšku `533`.

Rozměry se píšou bez jednotek. Skutečnou velikost na stránce pak řídí CSS, tohle je jen poměr stran dopředu.

# --hints--

Fotka má zapsanou šířku i výšku.

```js
const img = document.querySelector('main img');
assert.equal(img.getAttribute('width'), '800', `width je „${img.getAttribute('width') ?? 'nic'}“, má být 800`);
assert.equal(img.getAttribute('height'), '533', `height je „${img.getAttribute('height') ?? 'nic'}“, má být 533`);
```

Rozměry jsou zapsané bez jednotek.

```js
const img = document.querySelector('main img');
assert.ok(!/px|%/.test(img.getAttribute('width') + img.getAttribute('height')), 'Do width a height se píše jen číslo, bez px a bez procent');
```

Alternativní text u fotky zůstal.

```js
const img = document.querySelector('main img');
assert.match(img.getAttribute('alt') ?? '', /zlatavé bramboráky/, 'Alternativní text fotky má zůstat');
```

# --help--

## --tip--

Proč prohlížeč potřebuje rozměry dopředu, vysvětluje část [Co prohlížeč udělá s HTML](see:html-zaklady/jak-funguje-web#co-prohlizec-udela-s-html).

## --tip--

Rozměry se zapisují jako dva atributy přímo na `<img>`, vedle `src` a `alt`.

## --tip--

Logo v hlavičce by mělo `<img src="logo.svg" alt="Plotna" width="120" height="32">`.

      4 lžíce hladké mouky
