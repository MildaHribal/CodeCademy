# --description--

Popisek pod fotkou zatím visí ve vzduchu jako holý text — nic neříká, že patří k obrázku nad ním. HTML na dvojici obrázek + popisek má vlastní pár prvků.

**Úkol:** obal fotku i popisek prvkem pro samostatnou přílohu a z popisku udělej její titulek.

Dvojice se jmenují `figure` a `figcaption`. Popisek smí být v `figure` právě jeden a bývá první nebo poslední.

# --hints--

Fotka i popisek leží v jedné příloze.

```js
const figure = document.querySelector('main figure');
assert.ok(figure, 'Na stránce chybí prvek <figure>');
assert.ok(figure.querySelector('img'), 'Fotka má být uvnitř <figure>');
```

Popisek je titulkem přílohy.

```js
const caption = document.querySelector('main figure figcaption');
assert.ok(caption, 'V <figure> chybí <figcaption>');
assert.equal(caption.textContent.replace(/\s+/g, ' ').trim(), 'Bramboráky podávej hned z pánve, dokud jsou křupavé.', `<figcaption> obsahuje „${caption.textContent.trim()}“`);
```

Mimo přílohu už popisek nezůstal.

```js
const main = document.querySelector('main.recipe');
const loose = [...main.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE && /podávej hned z pánve/.test(n.textContent));
assert.equal(loose.length, 0, 'Popisek fotky zůstal i mimo <figure> jako holý text');
```

# --help--

## --tip--

Prvky pro obsah s vlastním významem najdeš v části [Obsah s významem](see:html-zaklady/semanticka-struktura#obsah-s-vyznamem-time-address-blockquote-a-cite).

## --tip--

Oba prvky jsou pojmenované v zadání. Vnější obaluje přílohu jako celek, vnitřní je její titulek — a oba jdou kolem obrázku, ne dovnitř něj.

## --tip--

U grafu v článku by příloha obsahovala obrázek grafu a pod ním titulek „Vývoj cen bytů v Brně 2015–2026“.

      2 vejce

      4 lžíce hladké mouky

      sůl a pepř

      sádlo nebo řepkový olej

      Brambory oloupej a najemno nastrouhej.
