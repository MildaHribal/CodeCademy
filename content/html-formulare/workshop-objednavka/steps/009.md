title: "Podmíněná validace"

# --description--

Pokud uživatel zaškrtne "Nakupuji na firmu", sice mu ukážeme pole IČO, ale vůbec nic ho nenutí ho vyplnit. Tlačítko Objednat se povolí hned, jak vyplní jméno a e-mail.

**Úkol:** V posluchači `change` nad zaškrtávátkem (`checkbox.addEventListener`) uprav požadavek na pole IČO. Když se checkbox zaškrtne, musí být pole `ico` povinné (`required = true`). Když se odškrtne, tak už povinné být nesmí. Nezapomeň si ho najít a uložit do proměnné.

Navíc je dobré po této změně vyvolat na formuláři ručně událost `input`, aby se ihned přehodnotilo povolení tlačítka. To už jsme za tebe dopsali.

# --hints--

Nastavuje se IČO jako povinné podle checkboxu?
```js
const checkbox = document.getElementById('is-company');
const icoInputLocal = document.querySelector('input[name="ico"]');

checkbox.checked = true;
checkbox.dispatchEvent(new Event('change'));
assert.equal(icoInputLocal.required, true, 'Když se checkbox zaškrtne, IČO musí být required');

checkbox.checked = false;
checkbox.dispatchEvent(new Event('change'));
assert.equal(icoInputLocal.required, false, 'Když se checkbox odškrtne, IČO nesmí být required');
```

# --help--

## --tip--

Povinnost pole se v JavaScriptu přepíná vlastností `required` — stejně jako atribut
`required` v HTML, jen za běhu.

## --tip--

Hodnotu vezmi rovnou ze zaškrtávátka: je-li zaškrtnuté, pole povinné být má.
Zaškrtnutí zjistíš vlastností `checked`.

## --tip--

Stejný vzor u dopravy: při volbě „na adresu" se stane povinným pole s ulicí,
při volbě „na výdejnu" ne.

# --solution--

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');
const summaryName = document.getElementById('summary-name');
const btn = document.querySelector('form button');
const icoInput = document.querySelector('input[name="ico"]');

form.addEventListener('input', () => {
  const data = new FormData(form);
  summaryName.textContent = data.get('name');
  btn.disabled = !form.checkValidity();
});

form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    errorDiv.textContent = 'Zkontroluj prosím zvýrazněná pole.';
  } else {
    errorDiv.textContent = 'Všechno v pořádku.';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
    icoInput.required = true;
  } else {
    companyInfo.style.display = 'none';
    icoInput.required = false;
  }
  form.dispatchEvent(new Event('input'));
});
```
