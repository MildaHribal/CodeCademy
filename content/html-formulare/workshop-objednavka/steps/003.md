# --description--

Vypsat chybu do konzole je sice pěkné, ale uživatel ji neuvidí. Zobrazíme ji přímo ve formuláři.

Do HTML jsme ti předpřipravili `<div id="error"></div>`. 
**Úkol:** Změň tvůj kód tak, aby místo `console.log` vložil zprávu "Chybí jméno" jako text do `div`u s id `error`. Pokud uživatel jméno zadal správně, smaž text prvku `error` (nastav mu prázdný řetězec), aby chybová hláška z minula zmizela.

# --hints--

Vypíše se chyba do divu?
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');

form.querySelector('input[name="name"]').value = '';
form.dispatchEvent(new Event('submit'));
assert.equal(errorDiv.textContent, 'Chybí jméno', 'Prvek #error musí obsahovat zprávu "Chybí jméno"');
```

Smaže se chyba, když se zadá jméno?
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');

errorDiv.textContent = 'Stara chyba';
form.querySelector('input[name="name"]').value = 'Karel';
form.dispatchEvent(new Event('submit'));
assert.equal(errorDiv.textContent, '', 'Když se jméno vyplní, prvek #error musí být prázdný');
```

# --solution--

## --file-- index.html
```html
<form id="order" novalidate>
  <div id="error" style="color: red;"></div>
  <input type="text" name="name" required placeholder="Jméno">
  <input type="email" name="email" required placeholder="E-mail">
  <button>Objednat</button>
</form>
```

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  const data = new FormData(form);
  if (data.get('name').length === 0) {
    errorDiv.textContent = 'Chybí jméno';
  } else {
    errorDiv.textContent = '';
  }
});
```
