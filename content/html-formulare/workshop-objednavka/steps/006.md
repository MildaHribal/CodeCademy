# --description--

Zákazník potřebuje vidět jméno, na které odesílá, v bočním panelu s předběžným souhrnem objednávky. Ten by se měl měnit okamžitě, když zákazník do pole píše.

**Úkol:** V HTML je div s id `summary-name`. Navěš na celý `form` posluchač události `input`. V něm opět získej zadaná data (`new FormData()`) a nastav text do elementu `summary-name` z políčka `name`.

# --hints--

Aktualizuje se souhrn při změně políčka?
```js
const form = document.getElementById('order');
const summary = document.getElementById('summary-name');

form.querySelector('input[name="name"]').value = 'František';
form.dispatchEvent(new Event('input', { bubbles: true }));
assert.equal(summary.textContent, 'František', 'Prvek summary-name musí mít ihned hodnotu pole name po vyvolání události input');
```

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');
const summaryName = document.getElementById('summary-name');

form.addEventListener('input', () => {
  const data = new FormData(form);
  summaryName.textContent = data.get('name');
});

form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    errorDiv.textContent = 'Zkontroluj prosím zvýrazněná pole.';
  } else {
    errorDiv.textContent = 'Všechno v pořádku.';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
  } else {
    companyInfo.style.display = 'none';
  }
});
```
