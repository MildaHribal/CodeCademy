# --description--

Máme tu naši malou chybovou kontrolu `if (data.get('name').length === 0)`, ale co e-mail a budoucí další pole? HTML5 validace (`required`, `type="email"`) tu kontrolu vlastně zvládne udělat za nás i na pozadí, a JavaScript s ní může jednoduše mluvit.

**Úkol:** V obsluze odeslání (submit) místo ruční kontroly prázdnosti volej nad formulářem metodu `checkValidity()`. Pokud vrátí `false`, do `errorDiv` napiš "Zkontroluj prosím zvýrazněná pole." a pokud projde, napiš "Všechno v pořádku." a chybu smaž.

# --hints--

Využívá kód metodu checkValidity?
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');

form.querySelector('input[name="name"]').value = '';
form.dispatchEvent(new Event('submit'));
assert.equal(errorDiv.textContent, 'Zkontroluj prosím zvýrazněná pole.', 'Když checkValidity vrátí false, do errorDiv musí přijít upozornění');

form.querySelector('input[name="name"]').value = 'Karel';
form.querySelector('input[name="email"]').value = 'karel@example.com';
form.dispatchEvent(new Event('submit'));
assert.equal(errorDiv.textContent, 'Všechno v pořádku.', 'Když checkValidity projde, napiš Všechno v pořádku.');
```

# --help--

## --tip--

Metody formuláře, které vrací platnost všech polí naráz, jsou v části
[Validace v prohlížeči](see:html-formulare/validace-v-prohlizeci). Hledej tu, která
vrací `true` nebo `false` a nic nevypisuje.

## --tip--

Metodu volej na formuláři, ne na jednotlivých polích — projde si je sama. Výsledek je
obyčejný boolean, takže se dá rovnou dát do `if`.

## --tip--

Stejný tvar u jiného formuláře: `if (!prihlaska.checkValidity()) { zprava.textContent = '…'; return; }`.

```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  --edit--
  const data = new FormData(form);

    errorDiv.textContent = 'Chybí jméno';
  } else {
    errorDiv.textContent = '';
  }
  --edit--
});

  if (checkbox.checked) {
    companyInfo.style.display = 'block';
  } else {
    companyInfo.style.display = 'none';
  }
});
```

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    errorDiv.textContent = 'Zkontroluj prosím zvýrazněná pole.';
  } else {
    errorDiv.textContent = 'Všechno v pořádku.';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
  } else {
    companyInfo.style.display = 'none';
  }
});
```
