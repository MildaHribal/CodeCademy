# --description--

Zákazník nakoupil v e-shopu a jde platit. Potřebujeme si formulář převzít pod svou kontrolu v JavaScriptu, protože data chceme zpracovat a odeslat na pozadí. Pokud prohlížeč odešle data sám, stránka se znovu načte a my ztratíme náš lokální stav.

**Úkol:** V souboru `script.js` navěš na formulář posluchač události `submit`. Uvnitř zabraň výchozímu chování prohlížeče. Kód formuláře je pro tebe už připravený s `novalidate`, aby se nezapojovaly bubliny prohlížeče.

# --hints--

Má formulář událost submit a volá preventDefault?
```js
const form = document.querySelector('form');
let prevented = false;
const event = new Event('submit', { cancelable: true });
event.preventDefault = function() { prevented = true; };
form.dispatchEvent(event);
assert.ok(prevented, 'Musíš zavolat preventDefault() nad událostí submit');
```

```js
const form = document.getElementById('order');

form.addEventListener('submit', (e) => {
  e.preventDefault();
});
```
