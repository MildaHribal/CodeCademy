# --description--

Když máme formulář odchycený, můžeme si z něj vytáhnout zadaná data přes objekt `FormData`. 

**Úkol:** V obsluze odeslání vytvoř z formuláře objekt `FormData`. Pak pomocí jeho metody `get('name')` získej hodnotu pole `name` a pokud je prázdná (její délka je `0`), vypiš do `console.log` zprávu `"Chybí jméno"`.

# --hints--

Vypíše se chybová zpráva, když je jméno prázdné?
```js
{
  const form = document.getElementById('order');
  const logs = [];
  const originalLog = console.log;
  console.log = (...args) => logs.push(args.join(' '));

  form.querySelector('input[name="name"]').value = '';
  form.dispatchEvent(new Event('submit'));

  console.log = originalLog;
  assert.ok(logs.some(l => l.includes('Chybí jméno')), 'Když je jméno prázdné, do console.log se má vypsat "Chybí jméno"');
}
```

# --solution--

## --file-- index.html
```html
<form id="order" novalidate>
  <input type="text" name="name" required placeholder="Jméno">
  <input type="email" name="email" required placeholder="E-mail">
  <button>Objednat</button>
</form>
```

## --file-- script.js
```js
const form = document.getElementById('order');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  const data = new FormData(form);
  if (data.get('name').length === 0) {
    console.log('Chybí jméno');
  }
});
```
