# --description--

HTML validace ukáže při špatném e-mailu zprávu jako "Zadejte e-mailovou adresu", ale co když chceme říct vlastní, lidštější text? K tomu slouží na samotném poli metoda `setCustomValidity`.

**Úkol:** V události `input` celého formuláře přidej podmínku: Získej element pole `name` a zkontroluj jeho vlastnost `value`. Pokud je v ní zadané slovo "test" (malými písmeny), zavolej na tomto poli metodu `setCustomValidity('Jméno nesmí být "test"')`. V opačném případě zavolej `setCustomValidity('')` (prázdný text), abys chybu smazal.

# --hints--

Využívá se setCustomValidity při slovu "test"?
```js
const form = document.getElementById('order');
const nameInput = document.querySelector('input[name="name"]');

nameInput.value = 'test';
form.dispatchEvent(new Event('input', { bubbles: true }));
assert.equal(nameInput.validationMessage, 'Jméno nesmí být "test"', 'Pro slovo "test" se musí nastavit chyba Jméno nesmí být "test"');

nameInput.value = 'Karel';
form.dispatchEvent(new Event('input', { bubbles: true }));
assert.equal(nameInput.validationMessage, '', 'Pro běžné jméno se musí chyba vymazat předáním prázdného řetězce');
```

## --file-- script.js
```js
const form = document.getElementById('order');
const errorDiv = document.getElementById('error');
const checkbox = document.getElementById('is-company');
const companyInfo = document.getElementById('company-info');
const summaryName = document.getElementById('summary-name');
const btn = document.querySelector('form button');
const icoInput = document.querySelector('input[name="ico"]');
const nameInput = document.querySelector('input[name="name"]');

form.addEventListener('input', () => {
  if (nameInput.value === 'test') {
    nameInput.setCustomValidity('Jméno nesmí být "test"');
  } else {
    nameInput.setCustomValidity('');
  }

  const data = new FormData(form);
  summaryName.textContent = data.get('name');
  btn.disabled = !form.checkValidity();
});

form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    errorDiv.textContent = 'Zkontroluj prosím zvýrazněná pole.';
  } else {
    errorDiv.textContent = 'Všechno v pořádku.';
  }
});

checkbox.addEventListener('change', () => {
  if (checkbox.checked) {
    companyInfo.style.display = 'block';
    icoInput.required = true;
  } else {
    companyInfo.style.display = 'none';
    icoInput.required = false;
  }
  form.dispatchEvent(new Event('input'));
});
```
