# --description--

Zpráva "Zkontroluj prosím zvýrazněná pole" nedává smysl, pokud pole zvýrazněná nejsou. Místo toho, abychom přes JavaScript hledali všechna vadná pole a přidávali jim třídu `.error`, využijeme CSS pseudo-třídu pro validaci. 

Chceme ale uživatele na chybu upozornit až ve chvíli, kdy tam něco zkusí napsat, nebo až když se pokusí formulář odeslat.

**Úkol:** V souboru `style.css` vytvoř pravidlo pro `input` (text i e-mail), které obarví rámeček načerveno (`border-color: red`), když obsahuje chybu, ale *jen pokud* s ním uživatel interagoval.

# --hints--

Má input obarvený rámeček v nesprávném stavu?
```js
assert.match(files['style.css'], /input:user-invalid/, 'CSS musí používat pseudo-třídu :user-invalid pro tag input');
assert.match(files['style.css'], /border-color:\s*red/, 'Rámeček (border-color) má být red');
```

# --solution--

## --file-- style.css
```css
input {
  border: 1px solid #ccc;
  padding: 5px;
}
input:user-invalid {
  border-color: red;
}
```
