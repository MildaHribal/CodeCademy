# --description--

Stavíme registraci na frontendovou konferenci. Ze všeho nejdřív potřebujeme připravit samotný formulář, který data odešle na správnou adresu.

**Úkol:** Vytvoř `<form>`, který se odešle metodou POST na adresu `/api/register`.

# --hints--

Vytvořil jsi značku `<form>`?
```js
assert.ok(document.querySelector('form'), 'Na stránce musí být <form>');
```

Formulář má správnou metodu.
```js
assert.equal(document.querySelector('form')?.method.toUpperCase(), 'POST', 'Metoda formuláře musí být POST');
```

Formulář má správnou adresu pro odeslání.
```js
assert.equal(document.querySelector('form')?.getAttribute('action'), '/api/register', 'Atribut action musí být /api/register');
```

# --help--

## --tip--

K odeslání dat měnících stav se hodí metoda `POST`. Obojí se nastavuje atributy na obalovací značce `<form>`.

## --tip--

Základ formuláře vypadá takto: `<form action="/api/uloz" method="POST"></form>`.
