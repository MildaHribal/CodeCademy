# --description--

První pole: jméno účastníka. Každé pole potřebuje dvě věci. **`name`**, pod kterým se odešle, a **[[popisek pole|popisek]]** `<label>`, který říká, co do pole patří.

Popisek s polem propojíš tak, že poli dáš `id` a popisku atribut `for` se stejnou hodnotou. Propojení není jen kosmetika:

- kliknutí na text popisku přesune kurzor do pole (větší plocha pro klik, hlavně na telefonu),
- čtečka obrazovky při vstupu do pole přečte „Jméno a příjmení, upravit text" místo jen „upravit text".

`id` a `name` mají jinou práci: `id` propojuje popisek (a slouží CSS), `name` je klíč při odeslání. Často mají podobnou hodnotu, ale nemusí.

Vzor na jiném formuláři:

```html
<div class="field">
  <label for="delivery-city">Město</label>
  <input id="delivery-city" name="city">
</div>
```

**Úkol:** nad tlačítka přidej pole pro jméno. Popisek bude **Jméno a příjmení**, pole dostane `id="full-name"` a odešle se pod jménem `fullName`. Obal popisek i pole do `<div class="field">`, ať dostanou připravený vzhled.

Pak si v náhledu klikni na text popisku — kurzor skočí do pole.

# --hints--

Ve formuláři je nad tlačítky pole s propojeným popiskem „Jméno a příjmení".

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const form = document.querySelector('form.signup');
const input = [...form.querySelectorAll('input')].find((el) => [...el.labels].some((label) => clean(label) === 'Jméno a příjmení'));
assert.ok(input, 've formuláři chybí pole, se kterým je propojený popisek „Jméno a příjmení" (label for = id pole)');
const actions = form.querySelector('.actions');
assert.ok(input.compareDocumentPosition(actions) & Node.DOCUMENT_POSITION_FOLLOWING, 'pole „Jméno a příjmení" má být nad tlačítky');
```

Pole se odešle pod jménem `fullName`.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const input = [...document.querySelectorAll('form.signup input')].find((el) => [...el.labels].some((label) => clean(label) === 'Jméno a příjmení'));
assert.equal(input?.name, 'fullName', 'pole „Jméno a příjmení" má mít name="fullName"');
input.value = 'Jana Dvořáková';
assert.equal(new FormData(input.form).get('fullName'), 'Jana Dvořáková', 'po vyplnění „Jana Dvořáková" se má odeslat fullName=Jana Dvořáková');
```
