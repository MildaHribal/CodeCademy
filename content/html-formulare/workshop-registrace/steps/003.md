# --description--

HTML5 přineslo nové typy polí. Například pole pro e-mail samo kontroluje, jestli obsahuje zavináč, a na mobilech otevře klávesnici s `@`.

**Úkol:** Přidej další `<div>` s polem pro e-mail (`name="email"`). Nastav mu správný `type` a vytvoř k němu popisek „E-mail".

# --hints--

Existuje pole typu email?
```js
const input = document.querySelector('form div input[type="email"]');
assert.ok(input, 'Musí existovat pole s type="email"');
assert.equal(input.name, 'email', 'Pole musí mít name="email"');
```

Je popisek spárovaný s e-mailovým polem?
```js
const input = document.querySelector('input[type="email"]');
assert.ok(input.id, 'Pole musí mít id');
const label = document.querySelector(`label[for="${input.id}"]`);
assert.ok(label, 'Musí existovat spárovaný label');
assert.match(label.textContent, /E-mail/i, 'Label má obsahovat text "E-mail"');
```

# --help--

## --tip--

Pro kontrolu formátu a zobrazení správné klávesnice se používá speciální typ vstupu.

## --tip--

Místo `text` nastavíš `type="email"`.

## --tip--

```html
<label for="kontakt">Kontakt</label>
<input type="email" id="kontakt" name="kontakt">
```
