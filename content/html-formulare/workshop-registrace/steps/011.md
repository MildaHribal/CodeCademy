# --description--

## Hlášení

Kolega přidal pod formulář tlačítko **Zpět na popis akce**. Má jen posunout stránku nahoru ke kartě konference, a to jeho `onclick` taky udělá. Jenže testerka píše:

„Vyplnila jsem půlku registrace, chtěla jsem si znovu přečíst termín, klikla na Zpět na popis akce — a formulář se odeslal. Na testovacím serveru teď mám rozpracovanou registraci bez e-mailu."

Na produkci by server dostal neúplná data a uživatel by přišel o to, co vyplnil.

## Úkol

Oprav tlačítko **Zpět na popis akce** tak, aby formulář neodesílalo. Tlačítko **Dokončit registraci** musí formulář odesílat dál. Změň co nejmenší kus kódu.

# --hints--

Kliknutí na „Zpět na popis akce" formulář neodešle.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const form = document.querySelector('form.signup');
const back = [...form.querySelectorAll('button, a')].find((el) => clean(el) === 'Zpět na popis akce');
assert.ok(back, 've formuláři má zůstat ovládací prvek „Zpět na popis akce"');
let submitted = false;
form.addEventListener('submit', (event) => {
  event.preventDefault();
  submitted = true;
});
await helpers.click(back);
await helpers.wait(50);
assert.equal(submitted, false, 'kliknutí na „Zpět na popis akce" nemá odeslat formulář');
```

Kliknutí na „Dokončit registraci" formulář dál odešle.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const form = document.querySelector('form.signup');
const finish = [...form.querySelectorAll('button')].find((el) => clean(el) === 'Dokončit registraci');
let submitter = null;
form.addEventListener('submit', (event) => {
  event.preventDefault();
  submitter = event.submitter;
});
await helpers.click(finish);
assert.ok(submitter && submitter === finish, 'kliknutí na „Dokončit registraci" má odeslat formulář');
```

# --help--

## --tip--

Podívej se, jaký typ má tlačítko, když `type` chybí — část [Tlačítka: `submit`, `button` a `reset`](see:html-formulare/jak-funguje-formular#tlacitka-submit-button-a-reset).

## --tip--

Chyba není v `onclick`. Po něm proběhne ještě výchozí akce tlačítka. Tlačítku „Zpět na popis akce" chybí jeden atribut, který výchozí akci změní.

## --tip--

Stejnou chybu by mělo tlačítko „Přidat dalšího účastníka" — opravuje se typem `button`. Když prvek jen vede jinam, můžeš místo tlačítka použít i odkaz `<a href="…">`.

# --explain--

Vysvětli vlastními slovy, proč tlačítko se zdánlivě neškodným `onclick` odeslalo formulář a proč pomohla oprava, kterou jsi udělal.

## --model--

Tlačítko uvnitř formuláře bez atributu `type` je odesílací, `type="submit"` je výchozí. Kliknutí nejdřív spustilo `onclick`, ale pak proběhla výchozí akce tlačítka a ta formulář odeslala. `type="button"` výchozí akci vypne, takže tlačítko dělá jen to, co mu řekne skript. Kdyby jen vedlo jinam, hodí se místo něj odkaz.

## --checklist--

- Tlačítko ve formuláři bez `type` je `submit`.
- Po `onclick` proběhne ještě výchozí akce tlačítka.
- `type="button"` výchozí odeslání vypne.
- Prvek, který jen vede jinam, může být odkaz `<a>`.
