# --description--

Řečníci konference rádi vidí, kdo sedí v sále. Přidej do kontaktních údajů nepovinné pole pro odkaz na GitHub nebo portfolio.

Typ pole vyber sám. Kandidáti jsou `text`, `url` a `email`. Rozmysli si, který z nich:

- na telefonu nabídne klávesnici s `/` a `.cz`,
- při odeslání pozná, že `github.com/jana` není úplná adresa (chybí `https://`),
- a který by naopak pustil cokoli.

**Úkol:** do skupiny **Kontaktní údaje** pod telefon přidej pole s popiskem **GitHub nebo portfolio**, které se odešle pod jménem `portfolio` a má typ pro webové adresy. Obal ho do `.field` jako ostatní.

# --hints--

Ve skupině „Kontaktní údaje" je pod telefonem pole s propojeným popiskem „GitHub nebo portfolio", které se odešle pod jménem `portfolio`.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const input = [...document.querySelectorAll('form.signup input')].find((el) => [...el.labels].some((label) => clean(label) === 'GitHub nebo portfolio'));
assert.ok(input, 've formuláři chybí pole s propojeným popiskem „GitHub nebo portfolio"');
assert.equal(input.name, 'portfolio', 'pole „GitHub nebo portfolio" má mít name="portfolio"');
const fieldset = input.closest('fieldset');
assert.ok(fieldset && clean(fieldset.querySelector('legend')) === 'Kontaktní údaje', 'pole „GitHub nebo portfolio" má být ve skupině „Kontaktní údaje"');
const phone = document.querySelector('form.signup input[name="phone"]');
assert.ok(phone.compareDocumentPosition(input) & Node.DOCUMENT_POSITION_FOLLOWING, 'pole „GitHub nebo portfolio" má být pod telefonem');
```

Pole pozná neúplnou webovou adresu `github.com/jana` a úplnou `https://github.com/jana` přijme.

```js
const input = document.querySelector('form.signup input[name="portfolio"]');
assert.ok(input, 've formuláři chybí pole portfolio');
input.value = 'github.com/jana';
assert.equal(input.validity.valid, false, 'hodnota „github.com/jana" má být pro pole portfolio neplatná — zvol typ pro webové adresy');
input.value = 'https://github.com/jana';
assert.equal(input.validity.valid, true, 'hodnota „https://github.com/jana" má být pro pole portfolio platná');
```

# --help--

## --tip--

Typ pole mění klávesnici i kontrolu hodnoty — vzpomeň si na [krok s e-mailem](see:html-formulare/workshop-registrace/004) a podívej se na [`<input>` typy v MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input#input_types).

## --tip--

Hledáš typ, jehož jméno je zkratka pro webovou adresu. `text` nekontroluje nic a `email` by odkaz odmítl kvůli chybějícímu zavináči.

## --tip--

Stejně by vypadalo pole „Web firmy" s `id="company-web"` a `name="companyWeb"` — liší se jen popisek, `id` a `name`.
