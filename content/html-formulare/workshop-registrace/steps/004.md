# --description--

K registraci patří účet. Pro ten potřebujeme heslo. To by ale nemělo být při psaní vidět.

**Úkol:** Přidej další pole pro heslo (`name="heslo"`) s popiskem „Heslo". Musí být obalené v `<div>` a obsahovat správný typ, aby znaky byly nahrazené tečkami.

# --hints--

Existuje pole typu password?
```js
const input = document.querySelector('input[type="password"]');
assert.ok(input, 'Musí existovat pole s type="password"');
assert.equal(input.name, 'heslo', 'Pole musí mít name="heslo"');
```

Má pole spárovaný popisek?
```js
const input = document.querySelector('input[type="password"]');
assert.ok(input.id, 'Pole musí mít id');
const label = document.querySelector(`label[for="${input.id}"]`);
assert.ok(label, 'Musí existovat spárovaný label');
```

# --help--

## --tip--

Aby se text maskoval tečkami nebo hvězdičkami, má HTML typ `password`.

## --tip--

Použij atribut `type="password"`.

## --tip--

```html
<label for="tajemstvi">Kód</label>
<input type="password" id="tajemstvi" name="heslo">
```
