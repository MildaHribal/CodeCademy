# --description--

Organizátoři potřebují vědět, jaké jídlo objednat. Uživatel vybere **jednu** ze tří možností stravy, a ty mají být vidět všechny najednou — to je práce pro skupinu přepínačů (`type="radio"`).

Skupina přepínačů stojí na třech pravidlech:

- **všechny přepínače skupiny mají stejné `name`** — podle něj prohlížeč pozná, že patří k sobě, a dovolí vybrat jen jeden,
- každý má vlastní `value`, které se odešle,
- skupina je obalená v `<fieldset>` a její společná otázka je v `<legend>` jako **první prvek** uvnitř. Čtečka pak u každého přepínače přečte i otázku: „Strava, skupina — Veganská, přepínač, 3 ze 3".

Jednotlivé přepínače mají vlastní popisek obalením, jako políčko s novinkami. Atribut `checked` označí výchozí volbu.

**Úkol:** seřaď řádky tak, aby vznikla skupina **Strava** s možnostmi Bez omezení (výchozí), Vegetariánská a Veganská. Odsazení nastavíš klávesou Tab. Dva řádky jsou navíc.

# --hints--

Pod výběrem vstupenky je `<fieldset>`, jehož první prvek je `<legend>` s textem „Strava".

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const fieldset = [...document.querySelectorAll('form.signup fieldset')].find((el) => el.firstElementChild?.tagName === 'LEGEND' && clean(el.firstElementChild) === 'Strava');
assert.ok(fieldset, 've formuláři chybí <fieldset> s <legend>Strava</legend> jako prvním prvkem');
const ticket = document.querySelector('form.signup select[name="ticket"]');
assert.ok(ticket.compareDocumentPosition(fieldset) & Node.DOCUMENT_POSITION_FOLLOWING, 'skupina Strava má být pod výběrem vstupenky');
```

Skupina obsahuje tři přepínače `diet` s popisky Bez omezení, Vegetariánská a Veganská a vybrat jde jen jeden.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const radios = [...document.querySelectorAll('form.signup fieldset input[type="radio"]')];
assert.deepEqual(radios.map((radio) => radio.name), ['diet', 'diet', 'diet'], 've skupině mají být tři přepínače se stejným name="diet"');
assert.deepEqual(radios.map((radio) => clean(radio.labels[0] ?? radio)), ['Bez omezení', 'Vegetariánská', 'Veganská'], 'popisky přepínačů');
radios[1].checked = true;
radios[2].checked = true;
assert.deepEqual(new FormData(radios[0].form).getAll('diet'), ['vegan'], 'po výběru Vegetariánská a pak Veganská se má odeslat jen diet=vegan');
```

Bez zásahu uživatele se odešle `diet=standard`.

```js
const form = document.querySelector('form.signup');
assert.deepEqual(new FormData(form).getAll('diet'), ['standard'], 'výchozí volba (checked) má být Bez omezení s value="standard"');
```
