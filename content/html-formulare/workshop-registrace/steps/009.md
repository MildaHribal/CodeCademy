title: "Promo kód podle vzoru"
---

# --description--

Konference umožňuje zadat promo kód, který garantuje slevu. Promo kód má přísný formát: přesně čtyři velká písmena od A do Z, nic jiného.

**Úkol:** Před tlačítko (ale už mimo `fieldset`) přidej pole pro promo kód (`name="promo"`) s popiskem "Promo kód". Nastav mu atribut pro validaci formátu pomocí regulárního výrazu. Vzor je `[A-Z]{4}`. Taktéž obal toto pole a label do svého `<div>`.

# --hints--

Existuje pole s name="promo"?
```js
const promo = document.querySelector('input[name="promo"]');
assert.ok(promo, 'Pole pro promo kód musí existovat');
```

Má pole nastavený vzor?
```js
const promo = document.querySelector('input[name="promo"]');
assert.equal(promo.getAttribute('pattern'), '[A-Z]{4}', 'Atribut pattern musí být přesně [A-Z]{4}');
```

Má pole spárovaný popisek?
```js
const promo = document.querySelector('input[name="promo"]');
const label = document.querySelector(`label[for="${promo.id}"]`);
assert.ok(label, 'Promo kód musí mít spárovaný popisek');
```

# --help--

## --tip--

Pro kontrolu pomocí regulárního výrazu se používá atribut `pattern`.

## --tip--

Nastavíš atribut `pattern="[A-Z]{4}"` přímo na tagu inputu. Zbytek (id, label) uděláš stejně jako u dřívějších polí.

## --tip--

```html
<div>
  <label for="kupon">Kupón</label>
  <input type="text" id="kupon" name="kupon" pattern="[0-9]{3}">
</div>
```
