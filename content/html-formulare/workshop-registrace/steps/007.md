# --description--

Jméno, e-mail a telefon zná prohlížeč uživatele z předchozích formulářů. Atributem **`autocomplete`** mu řekneš, **jaký údaj** pole chce, a prohlížeč ho nabídne jedním klepnutím. Na telefonu to je rozdíl mezi „vyplním za 3 sekundy" a „odejdu".

Hodnoty nejsou libovolné, jsou to domluvená slova ze specifikace HTML. Nejčastější:

| údaj | hodnota `autocomplete` |
|---|---|
| celé jméno | `name` |
| e-mail | `email` |
| telefon | `tel` |
| ulice a číslo | `street-address` |
| PSČ | `postal-code` |
| nové heslo při registraci | `new-password` |

Prohlížeč se podle `name` ani podle textu popisku spolehlivě neřídí — hádá. S `autocomplete` hádat nemusí. Vzor:

```html
<input id="zip" name="zip" autocomplete="postal-code">
```

**Úkol:** doplň vhodné `autocomplete` poli se jménem, e-mailem a telefonem.

> [!NOTE]
> V náhledu kurzu prohlížeč nic nenabídne, protože běží v izolovaném rámu. Na skutečné stránce si to vyzkoušíš ve vlastním projektu.

# --hints--

Pole „Jméno a příjmení" má `autocomplete` pro celé jméno.

```js
const input = document.querySelector('form.signup input[name="fullName"]');
assert.equal(input?.autocomplete, 'name', 'pole fullName má mít autocomplete="name"');
```

Pole „E-mail" má `autocomplete` pro e-mail.

```js
const input = document.querySelector('form.signup input[name="email"]');
assert.equal(input?.autocomplete, 'email', 'pole email má mít autocomplete="email"');
```

Pole „Telefon" má `autocomplete` pro telefonní číslo.

```js
const input = document.querySelector('form.signup input[name="phone"]');
assert.equal(input?.autocomplete, 'tel', 'pole phone má mít autocomplete="tel"');
```
