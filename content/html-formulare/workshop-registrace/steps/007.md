# --description--

Zatím mohl uživatel kliknout na tlačítko a poslat serveru prázdný formulář. Tím bychom sice získali záznam, ale nevěděli bychom koho.

**Úkol:** Všechna tři pole (`jmeno`, `email`, `heslo`) označ jako povinná, takže formulář bez nich nepůjde odeslat a prohlížeč ukáže bublinu.

# --hints--

Je pole "jmeno" povinné?
```js
const jmeno = document.querySelector('input[name="jmeno"]');
assert.ok(jmeno.required, 'Pole pro jméno musí mít atribut required');
```

Je pole "email" povinné?
```js
const email = document.querySelector('input[name="email"]');
assert.ok(email.required, 'Pole pro e-mail musí mít atribut required');
```

Je pole "heslo" povinné?
```js
const heslo = document.querySelector('input[name="heslo"]');
assert.ok(heslo.required, 'Pole pro heslo musí mít atribut required');
```

# --help--

## --tip--

Pro zamezení odeslání prázdného pole se používá logický atribut. Nastuduj [Základní validační atributy](see:html-formulare/validace-v-prohlizeci#zakladni-validacni-atributy).

## --tip--

Stačí přidat atribut `required` ke každému tagu `<input>`. Nepotřebuje žádnou hodnotu.

## --tip--

```html
<input type="text" id="mesto" name="mesto" required>
```

      </div>

    <button>Registrovat se</button>
  </form>
</body>
</html>
