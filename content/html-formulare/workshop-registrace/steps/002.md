# --description--

Aby server věděl, kdo se hlásí, přidáme textové pole pro jméno. Formulářové prvky se samy o sobě nedají dobře přečíst (pro čtečky obrazovky), pokud jim nedáme popisek. 

**Úkol:** Přidej do formuláře textové pole s atributem `name="jmeno"`. Přidej k němu `<label>` s textem „Tvoje jméno" a propoj je pomocí `id` a `for`. Obal je do značky `<div>`.

# --hints--

Existuje pole pro jméno obalené v divu?
```js
const input = document.querySelector('form div input[type="text"]');
assert.ok(input, 'Musí existovat textové pole v divu');
assert.equal(input.name, 'jmeno', 'Pole musí mít name="jmeno"');
```

Je popisek spárovaný s polem?
```js
const input = document.querySelector('input[name="jmeno"]');
assert.ok(input.id, 'Pole musí mít nějaké id');
const label = document.querySelector(`label[for="${input.id}"]`);
assert.ok(label, 'Musí existovat label spárovaný přes atribut for');
assert.match(label.textContent, /Tvoje jméno/i, 'Label má obsahovat text "Tvoje jméno"');
```

# --help--

## --tip--

Pro textový vstup se používá `<input type="text">`. Odesílací název se určuje atributem `name`.

## --tip--

Aby se popisek spároval, musíš dát inputu atribut `id` a labelu atribut `for` se stejnou hodnotou.

## --tip--

```html
<div>
  <label for="prijmeni">Příjmení</label>
  <input type="text" id="prijmeni" name="prijmeni">
</div>
```
