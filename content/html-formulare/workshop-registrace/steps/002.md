# --description--

Formulář zatím nemá čím se odeslat. Přidej tlačítko — zase bez návodu, z lekce víš, na co si dát pozor.

**Úkol:** na konec formuláře (pod nadpis) přidej `<button>` s textem **Dokončit registraci**, který formulář odešle. Typ tlačítka napiš výslovně, i když by tady fungoval i výchozí — u dalších tlačítek se ti to bude hodit.

Aby tlačítko dostalo připravený vzhled, obal ho do `<div class="actions">` a tlačítku dej třídu `button`.

# --hints--

Ve formuláři je tlačítko `<button>` s textem „Dokončit registraci".

```js
const form = document.querySelector('form.signup');
const button = [...form.querySelectorAll('button')].find((b) => b.textContent.replace(/\s+/g, ' ').trim() === 'Dokončit registraci');
assert.ok(button, 've formuláři .signup chybí <button> s textem „Dokončit registraci"');
```

Tlačítko má výslovně napsaný typ `submit` a kliknutí na něj formulář odešle.

```js
const form = document.querySelector('form.signup');
const button = [...form.querySelectorAll('button')].find((b) => b.textContent.replace(/\s+/g, ' ').trim() === 'Dokončit registraci');
assert.equal(button?.getAttribute('type'), 'submit', 'tlačítko „Dokončit registraci" má mít výslovně type="submit"');
let submitter = null;
form.addEventListener('submit', (event) => {
  event.preventDefault();
  submitter = event.submitter;
});
await helpers.click(button);
assert.equal(submitter, button, 'kliknutí na „Dokončit registraci" má odeslat formulář');
```
