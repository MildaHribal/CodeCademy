# --description--

Formulář se začíná prodlužovat. Když související pole seskupíš, uživatel ho snáz přelétne očima a čtečka obrazovky při vstupu do skupiny přečte její název. Tentokrát skupinu napíšeš sám: jméno, e-mail a telefon patří pod společný nadpis **Kontaktní údaje**.

Použij stejné dva prvky jako u stravy v předchozím kroku. Rozmysli si:

- kam patří nadpis skupiny, aby ho prohlížeč vzal jako její název (a ne jako obyčejný text),
- kde skupina začíná a končí, aby v ní nebyla vstupenka ani strava,
- jakou třídu jí dát, aby vypadala stejně jako skupina Strava.

`<fieldset>` se hodí i pro skupinu obyčejných textových polí, nejen pro přepínače. U přepínačů a políček je ale nutný, protože bez něj by chyběla společná otázka.

**Úkol:** obal pole se jménem, e-mailem a telefonem skupinou s nadpisem **Kontaktní údaje**.

# --hints--

Ve formuláři je `<fieldset>`, jehož první prvek je `<legend>` s textem „Kontaktní údaje".

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const fieldset = [...document.querySelectorAll('form.signup fieldset')].find((el) => el.firstElementChild?.tagName === 'LEGEND' && clean(el.firstElementChild) === 'Kontaktní údaje');
assert.ok(fieldset, 've formuláři chybí <fieldset> s <legend>Kontaktní údaje</legend> jako prvním prvkem');
```

Ve skupině „Kontaktní údaje" jsou pole se jménem, e-mailem a telefonem.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const fieldset = [...document.querySelectorAll('form.signup fieldset')].find((el) => el.firstElementChild?.tagName === 'LEGEND' && clean(el.firstElementChild) === 'Kontaktní údaje');
assert.ok(fieldset, 've formuláři chybí skupina „Kontaktní údaje"');
for (const name of ['fullName', 'email', 'phone']) {
  assert.ok(fieldset.querySelector(`[name="${name}"]`), `pole ${name} má být ve skupině „Kontaktní údaje"`);
}
```

Vstupenka, strava a novinky zůstávají mimo skupinu „Kontaktní údaje".

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const fieldset = [...document.querySelectorAll('form.signup fieldset')].find((el) => el.firstElementChild?.tagName === 'LEGEND' && clean(el.firstElementChild) === 'Kontaktní údaje');
assert.ok(fieldset, 've formuláři chybí skupina „Kontaktní údaje"');
for (const name of ['ticket', 'diet', 'newsletter']) {
  assert.ok(document.querySelector(`form.signup [name="${name}"]`), `pole ${name} má ve formuláři zůstat`);
  assert.equal(fieldset.querySelector(`[name="${name}"]`), null, `pole ${name} nemá být ve skupině „Kontaktní údaje"`);
}
```

# --help--

## --tip--

Seskupení polí je `<fieldset>` s nadpisem `<legend>` — vzor máš v [kroku se stravou](see:html-formulare/workshop-registrace/012).

## --tip--

`<fieldset>` začni hned pod nadpisem formuláře a zavři ho za polem Telefon. `<legend>` musí být první prvek uvnitř `<fieldset>`. Třídu zkopíruj ze skupiny Strava.

## --tip--

Adresa doručení by vypadala stejně: skupina s nadpisem „Doručovací adresa" a v ní pole ulice, město a PSČ, každé ve svém `.field`.
