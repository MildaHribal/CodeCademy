# --description--

Organizátoři chtějí vědět, co účastníky zajímá, aby podle toho rozdělili sály. Na rozdíl od stravy tu jde vybrat **libovolný počet** možností, i žádnou.

Rozmysli si, čím se skupina liší od stravy:

- jaký typ pole dovolí vybrat víc možností najednou,
- jestli mají pole mít **stejné**, nebo **různé** `name`, když server chce seznam témat pod jedním klíčem,
- jestli má být některé pole předem zaškrtnuté.

Obal skupinu do `<fieldset>` s `<legend>` jako u stravy — u zaškrtávacích políček platí stejný důvod: bez společné otázky čtečka přečte jen „React, zaškrtávací políčko" a uživatel neví, na co odpovídá.

**Úkol:** pod stravu přidej skupinu s nadpisem **Co tě nejvíc zajímá** a třemi zaškrtávacími políčky: **Moderní CSS** (hodnota `css`), **Přístupnost** (`a11y`) a **React** (`react`). Vybraná témata se odešlou jako `topics=css&topics=react`.

# --hints--

Pod stravou je skupina s nadpisem „Co tě nejvíc zajímá" a třemi zaškrtávacími políčky s popisky Moderní CSS, Přístupnost a React.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
const fieldset = [...document.querySelectorAll('form.signup fieldset')].find((el) => el.firstElementChild?.tagName === 'LEGEND' && clean(el.firstElementChild) === 'Co tě nejvíc zajímá');
assert.ok(fieldset, 've formuláři chybí <fieldset> s <legend>Co tě nejvíc zajímá</legend> jako prvním prvkem');
const boxes = [...fieldset.querySelectorAll('input[type="checkbox"]')];
assert.deepEqual(boxes.map((box) => clean(box.labels[0] ?? box)), ['Moderní CSS', 'Přístupnost', 'React'], 'popisky zaškrtávacích políček ve skupině');
const diet = document.querySelector('form.signup input[name="diet"]');
assert.ok(diet.compareDocumentPosition(fieldset) & Node.DOCUMENT_POSITION_FOLLOWING, 'skupina „Co tě nejvíc zajímá" má být pod stravou');
```

Po zaškrtnutí Moderní CSS a React se odešle `topics=css&topics=react`.

```js
const boxes = [...document.querySelectorAll('form.signup input[type="checkbox"]')].filter((box) => box.name !== 'newsletter');
assert.equal(boxes.length, 3, 'mimo novinky mají být ve formuláři tři zaškrtávací políčka s tématy');
boxes[0].checked = true;
boxes[2].checked = true;
assert.deepEqual(new FormData(boxes[0].form).getAll('topics'), ['css', 'react'], 'po zaškrtnutí Moderní CSS a React se má odeslat topics=css a topics=react');
```

Bez zaškrtnutí se žádné téma neodešle.

```js
const form = document.querySelector('form.signup');
assert.ok(form.querySelector('input[type="checkbox"][name="topics"]'), 've formuláři chybí zaškrtávací políčka name="topics"');
assert.deepEqual(new FormData(form).getAll('topics'), [], 'bez zásahu uživatele se nemá odeslat žádné téma (nic není předem zaškrtnuté)');
```

# --help--

## --tip--

Víc hodnot pod jedním klíčem vysvětluje část [`name` je klíč, `value` je hodnota](see:html-formulare/jak-funguje-formular#name-je-klic-value-je-hodnota). Stavbu skupiny máš u [stravy](see:html-formulare/workshop-registrace/012).

## --tip--

Políčka jsou `type="checkbox"`, všechna se stejným `name` a každé s jinou `value`. Popisek každého políčka udělej obalením, stejně jako u novinek.

## --tip--

Výběr jazyků by vypadal stejně: skupina „Jazyky" a v ní políčka s `name="languages"` a hodnotami `cs`, `en` a `de`.

# --explain--

Vysvětli vlastními slovy, proč mají všechna tři políčka stejné `name` a co server dostane, když uživatel nezaškrtne nic.

## --model--

Stejné `name` znamená, že se každé zaškrtnuté políčko odešle jako další dvojice se stejným klíčem, třeba `topics=css&topics=react`, a server z nich složí seznam. Rozliší je `value`. Nezaškrtnuté políčko se neodešle vůbec, takže když uživatel nevybere nic, klíč `topics` v datech úplně chybí. Server proto musí počítat s tím, že tam klíč není.

## --checklist--

- Každé zaškrtnuté políčko pošle vlastní dvojici se stejným klíčem.
- Políčka od sebe odliší `value`.
- Nezaškrtnuté políčko se neodešle.
- Když není zaškrtnuté nic, klíč v datech chybí úplně.
