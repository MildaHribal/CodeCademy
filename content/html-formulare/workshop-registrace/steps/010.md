# --description--

Čtyři vstupenky se dělí na dvě skupiny: jen konference, nebo konference s workshopem. Prvek **`<optgroup>`** obalí související možnosti a dá jim nadpis v atributu `label`. Prohlížeč nadpis ukáže v rozbaleném seznamu tučně a vybrat nejde, takže uživatel v delším seznamu rychleji najde, co hledá.

Na odeslání skupina nemá vliv — pořád se posílá jen `value` vybrané `<option>`.

Vybírej mezi dvěma místy, kam skupiny dát: kolem dvojic možností uvnitř `<select>`, nebo kolem celého `<select>`? Jen jedno z toho prohlížeč pochopí.

**Úkol:** rozděl možnosti vstupenky do dvou skupin. První s nadpisem **Konference** obsahuje Standard a Student, druhá s nadpisem **Konference a workshop** obsahuje obě vstupenky s workshopem. Texty ani hodnoty možností neměň.

# --hints--

Výběr vstupenky má skupinu „Konference" s možnostmi `standard` a `student`.

```js
const groups = [...document.querySelectorAll('form.signup select[name="ticket"] > optgroup')];
const group = groups.find((el) => el.label === 'Konference');
assert.ok(group, 'v <select name="ticket"> chybí <optgroup label="Konference">');
assert.deepEqual([...group.querySelectorAll('option')].map((option) => option.value), ['standard', 'student'], 'možnosti ve skupině „Konference"');
```

Výběr vstupenky má skupinu „Konference a workshop" s možnostmi `standard-workshop` a `student-workshop`.

```js
const groups = [...document.querySelectorAll('form.signup select[name="ticket"] > optgroup')];
const group = groups.find((el) => el.label === 'Konference a workshop');
assert.ok(group, 'v <select name="ticket"> chybí <optgroup label="Konference a workshop">');
assert.deepEqual([...group.querySelectorAll('option')].map((option) => option.value), ['standard-workshop', 'student-workshop'], 'možnosti ve skupině „Konference a workshop"');
```

Výběr se dál odesílá jako hodnota možnosti.

```js
const select = document.querySelector('form.signup select[name="ticket"]');
assert.equal(select?.options.length, 4, '<select name="ticket"> má mít dál čtyři možnosti');
select.value = 'student-workshop';
assert.equal(new FormData(select.form).get('ticket'), 'student-workshop', 'po výběru „Student + workshop" se má odeslat ticket=student-workshop');
```

# --help--

## --tip--

Skupina možností je prvek `<optgroup>` — viz [`<optgroup>` v MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/optgroup). Pracuješ se seznamem z [předchozího kroku](see:html-formulare/workshop-registrace/009).

## --tip--

`<optgroup>` patří dovnitř `<select>` a obaluje `<option>`. Nadpis skupiny se nepíše jako text mezi značky, ale do atributu `label`.

## --tip--

Seznam měst by se dělil stejně: `<optgroup label="Morava">` a v něm `<option value="brno">Brno</option>` a `<option value="olomouc">Olomouc</option>` a skupinu zase uzavřeš.
