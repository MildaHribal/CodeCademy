# --description--

Někdy chce uživatel začít úplně znovu a vyčistit si všechna pole najednou. Můžeme mu to usnadnit tlačítkem typu reset.

**Úkol:** Hned vedle tlačítka "Registrovat se" přidej další `<button>Vyčistit</button>`. Dej pozor, aby toto tlačítko formulář **neodeslalo**, ale vyčistilo – nastav mu správný typ!

# --hints--

Existuje tlačítko pro vyčištění?
```js
const buttons = document.querySelectorAll('form button');
assert.ok(buttons.length >= 2, 'Ve formuláři musí být dvě tlačítka');
const resetBtn = Array.from(buttons).find(b => b.textContent.includes('Vyčistit'));
assert.ok(resetBtn, 'Musí existovat tlačítko s textem "Vyčistit"');
```

Má tlačítko správný typ?
```js
const buttons = document.querySelectorAll('form button');
const resetBtn = Array.from(buttons).find(b => b.textContent.includes('Vyčistit'));
assert.equal(resetBtn.type, 'reset', 'Tlačítko Vyčistit musí mít type="reset"');
```

# --help--

## --tip--

Výchozí typ tlačítka uvnitř formuláře je `submit`. Pro vymazání všech polí musíš typ změnit na `reset`.

## --tip--

Atribut `type="reset"` zajistí, že tlačítko jen zruší všechny hodnoty a nepošle je.

## --tip--

```html
<button type="reset">Smazat</button>
```
