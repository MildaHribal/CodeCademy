# --description--

Když máme ve formuláři logické bloky, je dobré je vizuálně i sémanticky oddělit. Slouží k tomu rámeček se svým vlastním nadpisem.

**Úkol:** Obal všechna tři dosavadní pole (tedy všechny tři `<div>`) do skupiny, kterou tvoří element `fieldset`. Jako první prvek do něj vlož obal nadpisu `legend` s textem „Osobní údaje".

# --hints--

Je vše v poli fieldset?
```js
const fieldset = document.querySelector('fieldset');
assert.ok(fieldset, 'Musí existovat prvek fieldset');
assert.equal(fieldset.querySelectorAll('div').length, 3, 'Fieldset musí obalovat všechny tři divy s poli');
```

Má skupina nadpis přes legend?
```js
const legend = document.querySelector('fieldset legend');
assert.ok(legend, 'Fieldset musí obsahovat legend');
assert.match(legend.textContent, /Osobní údaje/i, 'Legend má text "Osobní údaje"');
```

# --help--

## --tip--

Pro seskupení příbuzných polí v HTML formuláři se používá blok pojmenovaný fieldset. Jeho popisek tvoří značka pro legendu.

## --tip--

Značkou obalíš požadované elementy. Značka pro legendu musí být prvním potomkem skupiny.

## --tip--

Vyhledej si, jak se píše fieldset a legend na MDN, pokud nevíš syntaxi.

## --file-- index.html
```html
<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <title>Registrace</title>
</head>
```

```html
    <fieldset>

        <input type="text" id="jmeno" name="jmeno">

        <input type="password" id="heslo" name="heslo">
      </div>
    </fieldset>
  </form>

</html>
```
