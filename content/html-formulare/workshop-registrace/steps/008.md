# --description--

Heslo by nemělo být příliš krátké, aby ho nebylo snadné uhodnout.

**Úkol:** Nastav u pole heslo minimální požadovanou délku na 8 znaků. Pokud jich uživatel napíše méně, prohlížeč mu ukáže chybu.

# --hints--

Má heslo nastavenou minimální délku?
```js
const heslo = document.querySelector('input[name="heslo"]');
assert.equal(heslo.getAttribute('minlength'), '8', 'Pole heslo musí mít atribut minlength="8"');
```

# --help--

## --tip--

Pro vynucení minimálního počtu znaků v poli slouží atribut, který omezuje délku vstupu.

## --tip--

Použij na inputu s heslem atribut `minlength` s odpovídající hodnotou.

## --tip--

```html
<input type="text" minlength="5">
```
