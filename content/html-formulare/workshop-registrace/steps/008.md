# --description--

Grafik poslal návrh, ve kterém formulář nemá popisky. Text „Telefon" je šedě přímo v poli jako **`placeholder`** a po začátku psaní zmizí. Vypadá to čistě, ale je to jedna z nejčastějších chyb formulářů:

- **Text zmizí, jakmile uživatel začne psát.** Kdo se v půlce zamyslí nebo se k formuláři vrátí, neví, co do pole patřilo. U předvyplněného pole ho neuvidí vůbec.
- Šedý text má slabý kontrast a špatně se čte.
- Prohlížeče a čtečky placeholder jako jméno pole použijí jen nouzově a ne všechny. Popisek `<label>` je jediný spolehlivý způsob.
- Uživatel si šedý text snadno splete s už vyplněnou hodnotou a pole přeskočí.

Na co placeholder použít smíš: **ukázka formátu vedle skutečného popisku**. Popisek říká *co*, placeholder *jak to může vypadat*. Vzor na jiném poli:

```html
<label for="iban">Číslo účtu</label>
<input id="iban" name="iban" placeholder="např. 123456789/0800">
```

**Úkol:** popisek **Telefon** nech, jak je, a poli s telefonem přidej `placeholder` s ukázkou čísla, například `např. 777 123 456`.

# --hints--

Pole s telefonem má `placeholder` s ukázkou čísla (obsahuje číslice).

```js
const phone = document.querySelector('form.signup input[name="phone"]');
assert.match(phone?.placeholder ?? '', /\d/, 'pole phone má mít placeholder s ukázkou čísla, třeba „např. 777 123 456"');
```

Všechna textová pole mají dál svůj popisek `<label>`.

```js
const clean = (el) => el.textContent.replace(/\s+/g, ' ').trim();
for (const [name, text] of [['fullName', 'Jméno a příjmení'], ['email', 'E-mail'], ['phone', 'Telefon']]) {
  const input = document.querySelector(`form.signup input[name="${name}"]`);
  assert.ok(input && [...input.labels].some((label) => clean(label) === text), `pole ${name} má mít dál propojený popisek „${text}" — placeholder ho nenahrazuje`);
}
```

# --explain--

Vysvětli vlastními slovy, proč placeholder nestačí místo popisku `<label>`.

## --model--

Placeholder zmizí, jakmile uživatel začne psát, takže pak už neví, co do pole patřilo, a u předvyplněného pole ho neuvidí vůbec. Má slabý kontrast a dá se splést s vyplněnou hodnotou. Popisek je vidět pořád, kliknutím na něj se dostanu do pole a čtečka ho spolehlivě přečte jako jméno pole. Placeholder je nanejvýš ukázka formátu vedle popisku.

## --checklist--

- Placeholder po začátku psaní zmizí, popisek zůstane.
- Šedý placeholder se špatně čte a plete se s vyplněnou hodnotou.
- Popisek je spolehlivé jméno pole pro čtečky obrazovky.
- Kliknutí na popisek přesune kurzor do pole.
- Placeholder se hodí jen na ukázku formátu vedle popisku.
