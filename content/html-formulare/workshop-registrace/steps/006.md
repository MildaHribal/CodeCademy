# --description--

Formulář sice máme, ale nejde nijak odeslat. Tedy kromě stisknutí klávesy Enter uvnitř pole, čemuž se říká implicitní odeslání. My mu dáme skutečné tlačítko.

**Úkol:** Na úplný konec formuláře (až za `</fieldset>`) přidej tlačítko s textem „Registrovat se". 

# --hints--

Má formulář odesílací tlačítko?
```js
const button = document.querySelector('form button');
assert.ok(button, 'Formulář musí mít <button>');
assert.match(button.textContent, /Registrovat se/i, 'Tlačítko má text "Registrovat se"');
```

# --help--

## --tip--

Pro vytvoření tlačítka, které odešle formulář, použij značku `<button>`. Uvnitř formuláře je její výchozí typ `submit` (odeslání).

## --tip--

Dej tlačítko nakonec formuláře, před koncový tag `</form>`.

## --tip--

```html
<button>Přihlásit se</button>
```
